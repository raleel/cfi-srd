#### Appraise (هەڵسەنگاندن)

(Divination - پێشبینی)

| | |
| :-- | :-- |
| **پلە:** Mage 0 | **کاتی ئەنجامدان:** ١ خول |
| **بوار:** هیچ | **ماوە:** دەستبەجێ |
| **تێچوو:** ١ | **مەودا:** دەست لێدان |
| **ناوچە:** ١ شت | **بەرگری:** هیچ |

هەڵسەنگاندن ڕێگە بە هەڵسەنگاندنی خێرای کوالێتی کەلوپەلە فیزیکییەکان دەدات. جادووەکە دیاری دەکات کە ئایا شتەکان کوالێتییەکی وەک یەکیان هەیە یان نا، یان ئەگەر یەکێکیان کەم و کوڕی هەبێت یان کوالێتی بەرزتری هەبێت. جادووەکە کاریگەری لەسەر شتە زیندەوەرەکان نییە، تەنها لەسەر شتە بێ گیانەکانە. هەروەها ناتوانێت کەم و کوڕی یان بەهێزکارییەکانی ناو شتەکان دیاری بکات؛ تەنها ئەوە دەزانێت کە بوونیان هەیە. ئەمە بۆ ناسینەوە یان دۆزینەوەی جادوو بەکارهێنانی نییە.

#### Armor (زرێ)

(Conjuration - بانگهێشتکردن)

| | |
| :-- | :-- |
| **پلە:** Mage 1 | **کاتی ئەنجامدان:** ١ خولەک (دەور) |
| **بوار:** هیچ | **ماوە:** بڕوانە خوارەوە |
| **تێچوو:** ٣ +١/بەهێزی | **مەودا:** دەست لێدان |
| **ناوچە:** ١ ئامانج | **بەرگری:** هیچ |

کاتێک ئەم جادوووە ئەنجام دەدرێت، کەسەکە وەردەگرێت بوارێکی نەبینراوی هێزی جادووگەری کە وەک زرێی قەپاڵی (scale armor) پارێزگاری دەکات، و ٤ خاڵی پارێزگاری (Armor Points) دەداتە هەر بەشێکی لەش. ئەگەر کەسەکە خۆی زرێی لەبەردابێت کاریگەری نابێت. بەڵام بۆ ماوەی جادووەکە شوێنی زرێی سروشتی دەگرێتەوە، ئەگەر پارێزگارییەکی باشتری هەبێت. ئەگەر لەسەر بوونەوەرێک بەکاربێت کە زیاتر لە ٤ خاڵی زرێی سروشتی هەیە، ئەوا ٤ خاڵی زرێیەکە بۆ ١ بەرز دەکاتەوە لە هەموو شوێنێک. ئەم پارێزگارییە جادووییە ڕێگری لە جووڵە یان ئەنجامدانی جادوو ناکات. جادووەکە تا ئەو کاتە دەمێنێتەوە کە بە جادوو ڕەش بکرێتەوە، یان ئەوەی جادووگەرەکە ٨ خاڵی زیان (damage) لە یەک هێرشدا وەردەگرێت، +١ بۆ هەر ئاستێکی زیاتری بەهێزی (خشتەی خوارەوە ببینە). بێگومان، جادووگەر دەتوانێت هەر کاتێک بیەوێت جادووەکە هەڵبوەشێنێتەوە، و دەبێت بیکات بۆ ئەوەی بخەوێت.

| بەهێزی | تێچوو | کاریگەری گۆڕاو |
| :-: | :-: | :-- |
| ١ | ٣ | ٤ خاڵی زرێ؛ دەمێنێتەوە تا ٨ زیان لە ١ هێرشدا وەردەگرێت |
| ٢ | ٤ | ٤ خاڵی زرێ؛ دەمێنێتەوە تا ٩ زیان لە ١ هێرشدا وەردەگرێت |
| ٣ | ٥ | ٤ خاڵی زرێ؛ دەمێنێتەوە تا ١٠ زیان لە ١ هێرشدا وەردەگرێت |
| ٤ | ٦ | ٤ خاڵی زرێ؛ دەمێنێتەوە تا ١١ زیان لە ١ هێرشدا وەردەگرێت |
| +١ | +١ | بەردەوامبوونی زیادبوون |

#### Astral Spell (جادووی ئەستێری)

(Transmutation - گۆڕانکاری)

| | |
| :-- | :-- |
| **پلە:** Cleric 5, Mage 5 | **کاتی ئەنجامدان:** ٢ جووڵە (Actions) |
| **بوار:** Astral | **ماوە:** بڕوانە خوارەوە |
| **تێچوو:** ٣ +١/بۆ هەر بەهێزی زیادە | **مەودا:** دەست لێدان |
| **ناوچە:** بڕوانە خوارەوە | **بەرگری:** نەخێر |

ئەم جادوووە ڕێگە بە جادووگەر و تا پێنج کەسی تر دەدات (یەک کەس بۆ هەر ئاستێکی زیادەی بەهێزی) بچنە ناو بۆشایی ئەستێری (Astral Plane). هەموویان دەبێت دەستیان یەک بگرن و بازنەیەک دروست بکەن کاتێک جادووەکە ئەنجام دەدرێت. لەشی گەشتیارەکان لە پلانی ڕەسەن دەمێنێتەوە، و بە شێوەیەکی گشتی هیچ جلوبەرگ یان کەلوپەلێکیان لەگەڵ نابەن، تەنها ئەوانە نەبێت کە خۆیان تیشکی جادوویی دەردەخەن؛ ئەم شتانە دەگۆڕێن بۆ هاوتای ئەستێری شێوە ئاساییەکەیان. ماوەی جادووەکە تا ئەو کاتە دەمێنێتەوە کە جادووگەر دەیەوێت کۆتایی پێ بهێنێت. هەرچۆنێک بێت، دەکرێت پێشوەختە لەلایەن هێزێکی دەرەکییەوە وەک Dispel Magic کۆتایی پێ بێت. کوشتنی لەشی فیزیکی جادووگەرەکەش جادووەکە کۆتایی پێ دەهێنێت، هەرچەندە ئەمە کاریگەرییەکی خراپی دەبێت بۆ جێهێشتنی هەر گەشتیارێک کە لەگەڵ جادووگەرەکەدایە.

#### Augury (پەیام)

(Divination - پێشبینی)

| | |
| :-- | :-- |
| **پلە:** Cleric 2 | **کاتی ئەنجامدان:** ٢ خولەک |
| **بوار:** Divination | **ماوە:** دەستبەجێ |
| **تێچوو:** ٣/بەهێزی | **مەودا:** ٦٠ پێ |
| **ناوچە:** جادووگەر | **بەرگری:** نەخێر |

ئەم جادوووە ڕێگە بە جادووگەر دەدات دیاری بکات کە ئایا کارێکی دیاریکراو لە ٣٠ خولەکی داهاتوودا سوودبەخش دەبێت یان زیانبەخش بۆ تاکێک یان گروپێک. پێویستە خاڵێکی سەرنج ڕاکێش هەبێت بۆ دیاریکردنی نیشانەکان، باوترین شێواز نینۆک یان ئێسکی بچووکی ئەژدیها، مرواری، یان زێڕی پەتی بە بەهای کەمتر لە ١٠٠ درهەم، کە ورد کرابێت یان تواوە بێت. جادووەکە زۆرترین بەهێزی ٤-ی هەیە. ئەم تاقیکردنەوەیە دەبێت لەلایەن بەڕێوەبەری یارییەکەوە (Games Master) بکرێت، چونکە جادووگەرەکە هەرگیز نابێت بە تەواوی دڵنیا بێت کە ئایا ئەنجامەکان بە دروستی لێکدراونەتەوە یان نا.

| بەهێزی | تێچوو | کاریگەری گۆڕاو |
| :-: | :-: | :-- |
| ١ | ٣ | تاقیکردنەوەی ئاستی سەختی "Formidable" بۆ لێهاتوویی Channel |
| ٢ | ٦ | تاقیکردنەوەی ئاستی سەختی "Hard" بۆ لێهاتوویی Channel |
| ٣ | ٩ | تاقیکردنەوەی ئاستی سەختی "Standard" بۆ لێهاتوویی Channel |
| ٤ | ١٢ | تاقیکردنەوەی ئاستی سەختی "Easy" بۆ لێهاتوویی Channel |

ئەگەر تاقیکردنەوەکە سەرکەوتوو بوو، یەکێک لەم ئەنجامانە دەدات:

| Augury | واتاکەی | 
| :-: | :-- |
| بەڵێ | کارەکە سوودبەخش دەبێت |
| نەخێر | کارەکە زیانبەخش دەبێت |
| بەڵێ و نەخێر | کارەکە هەم سوودبەخش و هەم زیانبەخش دەبێت |
| هیچ | کارەکە نە سوودبەخش و نە زیانبەخش دەبێت |

کەوتنی جادووگەر (Fumble) دەبێت ببێتە هۆی ئەوەی بەڕێوەبەری یارییەکە پێچەوانەی ڕاستییەکە بە جادووگەرەکە بڵێت.

(Abjuration - پاراستن)

| | |
| :-- | :-- |
| **پلە:** Cleric 0, Mage 0 | **کاتی ئەنجامدان:** دەستبەجێ |

#### Befuddle (سەرلێشێوان)

(Enchantment (Charm) - جادووکردن)

| | |
| :-- | :-- |
| **پلە:** Cleric 0, Mage 0 | **کاتی ئەنجامدان:** ١ خول |
| **بوار:** Charm | **ماوە:** ٣٠ خولەک |
| **تێچوو:** ١ | **مەودا:** ٦٠ پێ |
| **ناوچە:** ١ ئامانج | **بەرگری:** هێزی ویست (Willpower) |

Befuddle دەبێتە هۆی سەرلێشێوانی مێشکی ئامانجێک. ئامانجەکە کێشەی لە بیرکردنەوەدا دەبێت، بیردەچێتەوە لە کوێیە، چی دەکات، و بۆچی - زۆرجار تووشی بیرکردنەوەی پچڕپچڕ دەبێت. ئامانجە سەرسامکراوەکان هێشتا دەتوانن بۆ بەرگری لە خۆیان کاربکەن بەڵام ناتوانن هیچ کارێکی بنیاتنەر دەست پێ بکەن تا جادووەکە کۆتایی دێت. هەر جۆرە هێرشێک یان کارێکی هەڕەشەئامێز دەستبەجێ جادووەکە دەشکێنێت، جا بە ئامانجی سەرسامکراوەکە بووبێت یان نا.

#### Blade Barrier (دیواری شمشێرەکان)

(Evocation - دەرخستن)

| | |
| :-- | :-- |
| **پلە:** Cleric 4 | **کاتی ئەنجامدان:** ٢ جووڵە |
| **بوار:** پاسەوان، دروستکردن | **ماوە:** ٣ دەور/بەهێزی |
| **تێچوو:** ٣+١/بۆ هەر بەهێزی زیادە | **مەودا:** ١٠٠ پێ |
| **ناوچە:** ٥-٣٠ پێ تیشک (radius) | **بەرگری:** بڕوانە خوارەوە |

ئەم جادوووە دیوارێکی شمشێر، خەنجەر و چەقۆی دەوری دروست دەکات کە بە دەوری خاڵێکی جێگیردا دەسوڕێنەوە و ١د٨ خاڵ زیان بە ١د٤+٢ شوێنی لەشی هەرکەسێک دەگەیەنێت کە بە ناوچەی کاریگەرییەکەدا تێپەڕدەبێت. زرێ تەنها نیوەی پارێزگاری ئاسایی خۆی دەکات. خاڵەکانی زرێی جادوویی زیان کەم دەکەنەوە وەک ئاسایی. لەبەر ئەوەی چەکەکان بە خێراییەکی زۆر دەسوڕێنەوە و بە چڕی دانراون، ئەستەمە پارێزگاری (Parry) لێیان بکەیت یان خۆتیان لێ لابدەیت (Evade). دەکرێت قەڵغان بەکاربهێنرێت بۆ پاراستنی شوێنەکانی لەش بە شێوەیەکی پاسیڤ. لەم حاڵەتەدا، زیانی هەژمارکراو بە زرێ و خاڵەکانی ژیانی قەڵغانەکە بەراورد بکە.

جادووەکە دەکرێت بە شێوەیەکی بەرگری ئەنجام بدرێت بۆ پاراستنی قەشەکە یان هاوپەیمانەکان یان بە شێوەیەکی هێرشبەر بۆ تەڵەکردنی دوژمنان. هەرچۆنێک بێت، دوژمنە گەمارۆدراوەکانی ناو ٥ پێی لێواری دیوارەکە کاتێک دروست دەبێت، دەتوانن تاقیکردنەوەی خۆلادان (Evade) بکەن بۆ هەڵاتن. سەرەڕای سەرکەوتن، دوژمنەکە دەکەوێتە سەر زەوی، تەنها لە دەرەوەی ناوچەی کاریگەرییەکە. سەرکەوتن لە تاقیکردنەوەکەدا دەبێتە هۆی ئەوەی هیچ زیانێکی بەرنەکەوێت؛ بە پێچەوانەوە، کاریگەری تەواویان بەر دەکەوێت.

#### Bless (R) (بەرەکەت)

(Conjuration - بانگهێشتکردن)

| | |
| :-- | :-- |
| **پلە:** Cleric 1 | **کاتی ئەنجامدان:** ١ خولەک (دەور) |
| **بوار:** هەموو | **ماوە:** ٥ خولەک |
| **تێچوو:** ١ | **مەودا:** ١٨٠ پێ |
| **ناوچە:** ٢٥ پێ تیشک | **بەرگری:** هێزی ویست (Willpower) |

کاتێک ئەم جادوووە ئەنجام دەدرێت، قەشەکە بەرەکەت دەداتە گروپێک لە هاوپەیمانەکان لە ناوچەی کاریگەرییەکەدا. ئەوانەی کاریگەرییان لەسەرە ڕەنگدانەوەی هاوتایی (Alignment) جادووگەرەکەن، یان چاک یان خراپ. هیچ بەرەکەتێکی بێلایەن (Neutrality) نییە. هەموو هاوپەیمانەکانی ناو تیرەی جادووەکە ٥٪+ بۆ هەموو تاقیکردنەوەکانی لێهاتوویی و بەرگری وەردەگرن. هەروەها، چەکەکانیان ١د٣+ زیان بە مردووە زیندووەکانی زیرەک (intelligent undead) دەگەیەنێت و هەروەها بوونەوەرەکانی دەرەوەی پلانەکان کە هاوتایی دژبەریان هەیە بە قەشەکە، وەک شەیتانەکان، یان فریشتەکان. تێبینی بکە کە ئەگەرچی مردووە زیندووەکان وەک ئێسک و پەیکەر بە سروشت خراپ نین، بەڵام بە گشتی بە جادووی خراپ زیندوو دەکرێنەوە و بۆیە بەم زیانە کاریگەریان لەسەر دەبێت.

پێچەوانەی ئەم جادوووە، نەفرەت (Curse)، ڕێگە بە قەشەکە دەدات دوژمنەکان نەفرەت بکات، و وایان لێ دەکات لێهاتووییەکان پێچەوانەی سوودەکانی سەرەوە وەربگرن. زیانی چەکی نەفرەتکراو وەک سزایەک ئەژمار دەکرێت، و ئەم زیانە ناتوانێت لە ١ خاڵ کەمتر بێت.

#### Burning Hands (دەستی گڕگرتوو)

(Transmutation - گۆڕانکاری)

| | |
| :-- | :-- |
| **پلە:** Mage 1 | **کاتی ئەنجامدان:** ١ جووڵە |
| **بوار:** هیچ | **ماوە:** دەستبەجێ |
| **تێچوو:** ٣+١/بۆ هەر بەهێزی زیادە | **مەودا:** ٠ |
| **ناوچە:** ڵولەی ١٢٠ پلەیی، ٥ پێ درێژ | **بەرگری:** خۆلادان (Evade) |

ئەم جادوووە دەبێتە هۆی ئەوەی بڵێسە لە دەستی جادووگەرەوە لە کەوانەی ١٢٠ پلەییدا تەقەی لێ بکرێت. ئەگەر مینیاچەر لە شەڕدا بەکاردێت، Burning Hands زیان بە هەر ئامانجێک دەگەیەنێت کە ١ چوارگۆشەی پێشەوەی جادووگەرەکە داگیردەکات. ئەنجامدانی Burning Hands لە ئاستی بەهێزی بەرزتردا پێویستی بە جادووگەرێکی پلە بەرزتر هەیە. ئەم زیانە هەموو ئامانجەکانی ناوچەکە بە زیانێک دەگرێتەوە کە بەپێی بەهێزی جادووگەرەکە دیاری دەکرێت، تا زۆرترین بەهێزی ٩. تاقیکردنەوەیەکی سەرکەوتووی Evade، بە فڕێدانی خۆ بۆ سەر زەوی، ڕێگە بە قوربانییەکە دەدات هیچ زیانێکی بەرنەکەوێت.

| بەهێزی | تێچوو | پلەی کەمترین | کاریگەری گۆڕاو |
| :-: | :-: | :-: | :-- |
| ١ | ٣ | ١ | ١د٣+١ خاڵی زیان بۆ هەموو شوێنەکانی لەش |
| ٣ | ٤ | ١ | ١د٣+٢ خاڵی زیان بۆ هەموو شوێنەکانی لەش |
| ٥ | ٥ | ١ | ١د٣+٣ خاڵی زیان بۆ هەموو شوێنەکانی لەش |
| ٧ | ٦ | ٢ | ١د٣+٤ خاڵی زیان بۆ هەموو شوێنەکانی لەش |
| ٩ | ٧ | ٣ | ١د٣+٥ خاڵی زیان بۆ هەموو شوێنەکانی لەش |

زرێی لەبەرکراو پارێزگاری ناکات، بەڵام خاڵەکانی زرێی جادوویی یان زرێی سروشتی بوونەوەرێک زیان کەم دەکەنەوە. ئەم جادوووە بەهێزە بە مەودای زۆر کورتی هاوسەنگ دەکرێت، واتە جادووگەرەکە دەبێت ئەوەندە نزیک بێت کە لە بارێکی زۆر خراپدایە.

Burning Hands ئەگەری گڕگرتنی شتە گڕگرتووەکانی هەیە یەکسان بە زیانی ئەژمارکراو x٥٪. بڕوانە بەشی [ئاگر](0007_Game_System.md?id=fire-based-attacks) بۆ زانیاری زیاتر.

#### Calm (هێورکردنەوە)

(Enchantment (Charm) - جادووکردن)

| | |
| :-- | :-- |
| **پلە:** Cleric 0 | **کاتی ئەنجامدان:** ١ جووڵە |
| **بوار:** Charm | **ماوە:** دەستبەجێ |
| **تێچوو:** ١ | **مەودا:** دەست لێدان |
| **ناوچە:** ١ ئامانج | **بەرگری:** هێزی ویست (Willpower) |

Calm هەوڵ دەدات ئارەزووەکانی ئامانجێکی مرۆڤی SIZ ١-٢٠ هێور بکاتەوە، ڕەنگە بۆ ئەوەی دڵخوازێک بە زۆر داوای خۆی نەسەپێنێت، یان ڕکابەرێک بۆ یارمەتی هاوار نەکات، یان چەک بە تووڕەییەوە دەرنەهێنرێت. کەسێکی هێورکراوە لە ڕووی عەقڵییەوە بە شێوەیەکی تر کاریگەری لەسەر نابێت؛ بۆیە، هەر جۆرە هێرشێک یان کارێکی هەڕەشەئامێز هێشتا ڕێگە بە ئامانجەکە دەدات بەرگری لە خۆی بکات، و تەنانەت هێرش بکات، ئەگەرچی بە شێوەیەکی هێمن و عەقڵانی ئەنجامی دەدات.

#### Chain Lightning (زنجیرەی بروسکە)

(Evocation - دەرخستن)

| | |
| :-- | :-- |
| **پلە:** Mage 4 | **کاتی ئەنجامدان:** ٢ جووڵە |
| **بوار:** هیچ | **ماوە:** دەستبەجێ |
| **تێچوو:** ٣+١/بۆ هەر بەهێزی زیادە | **مەودا:** ٥٠ پێ/بەهێزی |
| **ناوچە:** بڕوانە خوارەوە | **بەرگری:** خۆلادان (Evade) |

کاتێک جادووەکە ئەنجام دەدرێت، جادووگەرەکە بروسکەیەک بە پانی پێنج پێ لە پەنجەکانییەوە دەردەکات کە دەتوانێت یەک ئامانج لە مەوداکەدا بە ١د٦+١ خاڵی زیان بۆ هەر ٢ بەهێزییەک بپێکێت. پاشان بروسکەکە دەپەڕێتەوە بۆ نزیکترین شت یان بوونەوەر، کە زیانی ئەژمارکراوی پێشوو منهای ١ خاڵ وەردەگرێت، و پاشان دەپەڕێتەوە بۆ نزیکترین، بە زیانی منهای ٢ خاڵ، و بە هەمان شێوە. دەکرێت تەنانەت بگەڕێتەوە بۆ سەر هاوپەیمانێک یان جادووگەرەکە خۆی! هەرچەندە ئامانجی سەرەکی دەبێت لەبەرچاوی جادووگەرەکە بێت، ئامانجەکانی تر دەبێت نەبینرێن.

هەر پەڕینەوەیەک مەودای ٥٠ پێی خۆی هەیە. Chain Lightning بەردەوام دەبێت لە لێدان ئەگەر زیانی مابێت تا ئەو کاتەی شتێک لێ دەدات کە دەبێتە هۆی زەوین کردنی (قەفەسی کانزایی، ئاو، و هتد) یان چیتر شت یان بوونەوەر نەماوە بۆ لێدان.

هەر بوونەوەرێک زیانەکە لە شوێنێکی لەشدا وەردەگرێت. تاقیکردنەوەیەکی سەرکەوتووی Evade، بە فڕێدانی خۆ بۆ سەر زەوی، ڕێگە بە قوربانییەکە دەدات هیچ زیانێکی بەرنەکەوێت.

| :-: | :-: | :-- |
| ١ | ٣ | مەودای ٥٠ پێ؛ ١د٦+١ زیان |
| ٢ | ٤ | مەودای ١٠٠ پێ؛ ١د٦+١ زیان |
| ٣ | ٥ | مەودای ١٥٠ پێ؛ ٢د٦+٢ زیان |
| ٤ | ٦ | مەودای ٢٠٠ پێ؛ ٢د٦+٢ زیان |

#### Change Appearance (گۆڕینی دەرکەوتن)

(Illusion - خەیاڵ)

| | |
| :-- | :-- |
| **پلە:** Mage 1 | **کاتی ئەنجامدان:** ١ جووڵە |
| **بوار:** هیچ | **ماوە:** ٢د٦ خولەک/بەهێزی |
| **تێچوو:** ١/بەهێزی | **مەودا:** ٠ |
| **ناوچە:** جادووگەر | **بەرگری:** نەخێر |

ئەم جادوووە دەرکەوتنی جادووگەرەکە دەگۆڕێت بۆ هەر شێوەیەکی مرۆیی یان دوو پێی. گۆڕانی باڵا و کێش سنوردارە بە ٥ SIZ +/-. لەم مەودایەدا، جادووگەر دەتوانێت قەڵەو یان لاواز، بەرز یان کورت بێت، یان تەنانەت ڕەگەزەکەی بگۆڕێت. قژ، جلوبەرگ و کەلوپەل دەکرێت لەگەڵ دەرکەوتندا بگۆڕدرێن. تایبەتمەندییەکانی دەموچاوی جادووگەر دەکرێت بەو شێوەیەی دەخوازێت بگۆڕدرێت. جادووەکە خاوەن بیروباوەڕی شکاندنی جادوو نییە (disbelief) وەک جادووەکانی تری خەیاڵ. جادووەکە بۆنی جادووگەرەکە ناگۆڕێت.

#### Chant (سروود)

(Conjuration - بانگهێشتکردن)

| | |
| :-- | :-- |
| **پلە:** Cleric 2 | **کاتی ئەنجامدان:** ٢ جووڵە |
| **بوار:** شەڕ | **ماوە:** سەرنجدان (Concentration) |
| **تێچوو:** ١ | **مەودا:** ٠ |
| **ناوچە:** ٣٠ پێ تیشک | **بەرگری:** نەخێر |

هەموو ئەوانەی لە ناوچەی کاریگەرییەکەدان ٥٪+ بۆ هەموو تاقیکردنەوەکانی لێهاتوویی و ١+ بۆ زیان وەردەگرن، هەریەکەیان بەپێی ئاستی بەهێزی. دوژمنەکانی ناو هەمان ناوچە پێچەوانەی سوودەکانی سەرەوە وەردەگرن.

Chant دەبێت بە درێژایی ماوەی جادووەکە پارێزگاری لێ بکرێت، ئەگینا کاریگەرییەکان کۆتایی دێت. ئەنجامدانی Dispel Magic هیچ کاریگەرییەکی لەسەر کاریگەرییە بەردەوامەکانی Chant نییە چونکە سروودخوێندنەکە خۆی جادوویی نییە؛ بەڵام، ئەنجامدانی بێدەنگی (Silence) سوودەکانی جادووەکە پوچەڵ دەکاتەوە. کاریگەرییەکانی Chant لەگەڵ Bless و Curse تێکەڵ دەبن. بەهۆی پێویستی سروودخوێندنەوە، ئەنجامدانی جادووی تر ئەستەمە.

#### Charm Person (جادووی مرۆڤ)

(Enchantment (Charm) - جادووکردن)

| | |
| :-- | :-- |
| **پلە:** Mage 1 | **کاتی ئەنجامدان:** ١ جووڵە |
| **بوار:** هیچ | **ماوە:** ١ هەفتە/بەهێزی |
| **تێچوو:** ٣+١/بۆ هەر بەهێزی زیادە | **مەودا:** ٣٦٠ پێ |
| **ناوچە:** ١ مرۆڤی زیندوو، نیمچە مرۆڤ یان مرۆڤ-شێوە | **بەرگری:** هێزی ویست (Willpower) |

کاتێک ئەم جادوووە ئەنجام دەدرێت، یەک ئامانجی مرۆڤی ژیری زیندوو (مردوو زیندووەکان کاریگەرییان نابێت) SIZ ١-٢٠ هەموو دوژمنایەتییەک بەرامبەر بە جادووگەرەکە و هاوپەیمانەکانی ڕادەگرێت، و لەبری ئەوە پێشنیاری یارمەتی و پاراستن دەکات ئەگەر تاقیکردنەوەی بەرگری شکستی هێنا. تێبینی بکە کە یارمەتیدان/پاراستن دەکرێت کاریگەری نەرێنی یان نەویستی هەبێت بۆ جادووگەرەکە، چونکە ئامانجەکە بەپێی ئەوەی هەستی پێ دەکات باشترین ڕێگەیە بۆ پاراستن/یارمەتیدان کار دەکات. سەبارەت بە فەرمانەکان، ئامانجێک هەرگیز فەرمانی خۆکوشتن یان کارێکی دیار زیانبەخش ئەنجام نادات بەڵام دەکرێت قەناعەتی پێ بکرێت کە شتێکی زۆر مەترسیدار شایەنی ئەنجامدانە.

هەر کارێکی دوژمنکارانە بەرامبەر بە ئامانجی جادووکردن لەلایەن جادووگەرەکە یان هاوپەیمانەکانییەوە جادووکردنەکە دەشکێنێت. تێبینی: ئەگەر کەسانی تر گومان لە سروشتی جادووکردنەکە بکەن، ئامانجەکە دەکرێت تاقیکردنەوەی بەرگری بکات، بەپێی بڕیاری بەڕێوەبەری یارییەکە. جادووگەرەکە دەبێت بتوانێت قسە لەگەڵ کەسی جادووکراودا بکات بۆ ئەوەی هەر جۆرە "داواکارییەکی" ئاڵۆز پێشکەش بکات؛ بۆیە زانینی زمانی ئامانجەکە گرنگە، بەڵام بۆ جادووکردنە سەرەتاییەکە پێویست نییە.

دوای تاقیکردنەوە سەرەتاییەکە بۆ بەرگری، دەبێت ١ هەفتە تێپەڕێت پێش ئەوەی ئامانجەکە بتوانێت جارێکی تر تاقیکردنەوەی بەرگری بکات.

کاتێک ئەم جادوووە ئەنجام دەدرێت، قەشەکە دەتوانێت فەرمانێکی یەک وشەیی بە یەک بوونەوەری زیندووی SIZ ١-٢٠ بدات، و لە دەوری داهاتووی ئامانجەکەدا، فەرمانەکە ئەنجام دەدرێت ئەگەر تاقیکردنەوەی بەرگرییان شکستی هێنا. ئەگەر قوربانییەکە هیچ خاڵێکی جووڵەی تری نەمابێت، فەرمانەکە لە یەکەم دەوری داهاتوودا ئەنجام دەدرێت. فەرمانەکە خۆی ناتوانێت هیچ زیانێکی ڕاستەقینە بە ئامانجەکە بگەیەنێت؛ بەڵام، زیان دەکرێت وەک کاریگەرییەکی لاوەکی فەرمانەکە بێت.

- **Halt (وەستان):** ئامانجەکە دەستبەجێ دەوەستێت.
- **Flee (هەڵاتن):** ئامانجەکە دەگەڕێتەوە و لە جادووگەرەکە هەڵدێت.
