# پاشکۆ: خشتەکانی گۆڕانکاری

---
#### گۆڕینی کێش و پێوانە ئیمپریاییەکان بۆ پێوانەی مەتریک

بۆ ئەوەی _Classic Fantasy Imperative_ دەرکەوتنێکی ڕێکخراوتر و خوێندنەوەیەکی ئاسانتری هەبێت، هەروەها کورتکردنەوەی باسکردن و خشتەکان، زنجیرەی _Classic Fantasy Imperative_ تەنها سەرنج دەخاتە سەر پێوانە ئیمپریاییەکان نەک هەردوو سیستەمی ئیمپریایی و مەتریک. سیستەمی ئیمپریایی بۆ ئەوە هەڵبژێردرا کە گۆڕینی کەرەستە بەکارهاتووەکان ئاسانتر بکات، چونکە زۆربەی سەرکێشییەکان، فەرشەکانی شەڕکردن (battlemats)، و نەخشەکانی تری ئەم جۆرە یارییانە سیستەمی ئیمپریایی بەکاردەهێنن. لەگەڵ ئەوەشدا، بۆ ئەوانەی دەیانەوێت سیستەمی مەتریک بەکاربهێنن، باوترین کێش و پێوانەکان بەکارهاتوون و لە خشتەکانی خوارەوەدا گۆڕدراون. لەبەر ئەوەی ئێمە بە گشتی مامەڵە لەگەڵ بوونەوەر، جادوو، و شتەکانی دنیای ڕاستەقینە ناکەین، دەتوانین کەمێک نەرمی بنوێنین لەو کێش و پێوانانەی بۆیانمان داناوە. لە جیاتی بەکارهێنانی گۆڕانکاری ورد، ئاسانترە ئەوەیەک بەکاربهێنین کە بە ئاسانی لەبیر دەکرێت، بەمەش یارییەکە ئاسانتر دەبێت.

| میل لە کاتژمێرێکدا | جۆر | کاریگەری لەسەر کارامەییەکان | کاریگەری لەسەر جووڵە |
| :-: | :-- | :-- | :-- |
| 0-10 | هێمن | نییە | نییە |
| 11-20 | باهۆزی مامناوەند | نییە | نییە |
| 21-30 | بای بەهێز | نییە | دوو لەسەر سێ |
| 31-40 | بای سووک | سەخت | دوو لەسەر سێ |
| 41-50 | بای مامناوەند | سەخت | نیوە |
| 51-60 | بای بەهێز | دژوار | نیوە |
| 60+ | گەردەلوول/تۆفان | دژوار | یەک لەسەر سێ |

با، بەتایبەتی بای بەهێز، دەتوانێت کاریگەری نەرێنی لەسەر چالاکییەکان هەبێت. هێزی (STR) با بە میل لە کاتژمێرێکدا دەپێورێت. کاریگەرییەکەی لەسەر کارامەییە جەستەییەکان – ئەوانەی پەیوەندییان بە هێز (STR) یان چالاکی (DEX)ـەوە هەیە – لە ستوونی کارامەییەکاندا وردەکاری خراوەتە ڕوو؛ کاریگەرییەکانی لەسەر ڕێژەی جووڵە لە ستوونی ڕێژەی جووڵەدایە.
 
_بۆ نموونە، بایەکی سووک بە هێزی 40 خێرایی ڕۆیشتنی مرۆڤ بۆ دوو لەسەر سێ کەم دەکاتەوە و کارامەییەکان بە سەختی (Hard) هەژمار دەکرێن._

#### خشتەی پلەی گەرمی

| پلەی گەرمی (ºF) | جۆر | مەترسی |
| :-: | :-: | :-- |
| < 2º | بەستەڵەک | بەدوای گەرمیدا بگە دەستبەجێ |
| 3-14º | بەستوو | 15 خولەک |
| 13-32º | سارد | کاتژمێری |
| 33-50º | فێنک | ڕۆژانە |
| 51-68º | مامناوەند | - |
| 69-86º | گەرم | - |
| > 86º | زۆر گەرم | کاتژمێری |

پلەی گەرمی دەکرێت بەهۆی کەشوهەوا، وەرز، و بەرزاییەوە بە شێوەیەکی بەرچاو بگۆڕێت، ئەوەش دەوەستێتە سەر دنیای کەمپەینەکە و شوێنی ڕووداوەکان. خشتەی سەرەوە ڕێنماییەک بۆ کاریگەری پلەی گەرمی توند لەسەر کارەکتەرەکان دابین دەکات.

لەبەرکردنی جلی گونجاو ڕێگە بە کارەکتەر دەدات ماوەیەکی کاتی بەپێی کاتژمێرەکانی (CON)ـی خۆی هەبێت پێش ئەوەی کاریگەرییەکان دەست پێ بکەن، وەک لە ستوونی مەترسیدا دیارە. دوای ئەم خاڵە پێویستە پەناگەیەک بدۆزنەوە یان دەست بە لەدەستدانی ماندوێتی (Fatigue) دەکەن. کارەکتەرە تەڕەکان ڕێژەی مەترسییەکە یەک پلە ساردتر دەکەن. هەروەها بای سووک یان مامناوەند ڕێژەی مەترسییەکە یەک پلە ساردتر دەکات، لە کاتێکدا بای بەهێز و گەردەلوولەکان دوو پلە ساردتری دەکەن.
