# پێداویستییەکان

1. تێگەیشتنێکی سەرەتایی لە [زمانی مارکداون (markdown)](https://www.markdownguide.org/basic-syntax/).

2. پێویستە ئەکاونتێکی بێبەرامبەری [گیتھەب (github)](https://github.com/) دروست بکەیت ئەگەر ئەکاونتت نییە. پێشنیار دەکەین ناوی یارییەکەت بەکاربهێنیت چونکە ئەمە دەبێتە بەشێک لەو ناونیشانەی (URL) خەڵکی بۆ گەیشتن بە SRD-ەکەت بەکاری دەهێنن.

3. دەتوانیت ئەم پرۆسەیە بە تەواوی لە ڕێگەی وێبگەڕەکەتەوە ئەنجام بدەیت بەبێ ئەوەی پێویست بکات شارەزای گیت (git) بیت. هەرچەندە فێربوونی بەرنامەی github desktop ڕێگەت پێدەدات پێش ئەوەی گۆڕانکارییەکان بە شێوەیەکی گشتی بڵاو بکەیتەوە، لەسەر کۆمپیوتەری خۆت تاقییان بکەیتەوە.

> ئەگەر ناوی دۆمەینێکت کڕیوە، دەتوانیت لەم پرۆسەیەدا بەکاریبهێنیت بۆ دروستکردنی SRD وەک ئەوەی من کردوومە https://srd.7thextinctionrpg.com

# پرۆسەکە

## دروستکردنی کۆگایەک (Repository) لە گیتھەب

1. بچۆرە ناو ئەکاونتی گیتھەبەکەت.

2. بچۆرە سەر تەمپڵێتی گشتی (public template) بەم ناونیشانە: https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. کلیک لە "Use this template" بکە.

![Step3](/_media/Step3.png)

4. "Create a new repository" هەڵبژێرە.

5. ناوێک بۆ کۆگاکەت (repository name) دابنێ.

![Step5](/_media/Step5.png)

6. 'Private' (تایبەت) هەڵبژێرە.

7. 'Create repository' هەڵبژێرە.

٥ بۆ ٣٠ چرکەی پێ دەچێت تا تەمپڵێتەکە کۆپی دەبێت، پاشان کۆپییەکی تایبەت بە خۆت دەبێت.

8. دڵنیابەرەوە کە فایلی ".nojekyll" بوونی هەیە، ئەمە فایلێکی بەتاڵە کە پێویستە کاتێک وێبسایتێک لەسەر گیتھەب دادەنێیت، ئەگەرنا SRD-ەکە بە دروستی دەرناکەوێت. *(بە گیتھەب دەڵێت کە فایلە بڵاوکراوەکان بەناو جێکێڵ (Jekyll)دا تێپەڕ نەکات).*


## زیادکردنی ناوەڕۆکەکەت

### فایلەکانی *.md

فایلەکانی .md بریتیین لە فایلەکانی مارکداون. مارکداون زمانێکی سوکی نیشانکردنە (markup language) کە دەتوانیت بەکاریبهێنیت بۆ زیادکردنی شێواز (formatting) بۆ دەقە سادەکان. بەپێی قەبارەی ناوەڕۆکەکەت، دەتوانیت هەموو زانیارییەکانی یارییەکەت لە یەک فایلی *.md دابنێیت، یان وەک ئەوەی من لە [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) کردوومە، بۆ هەر بەشێک فایلێکی جیاواز دروست بکەیت. فایلی "sample.md" هەندێک نموونەی شێوازکردنی تێدایە.

فێربوونی زمانی مارکداون زۆر ئاسانە، بۆ لیستی تەواوی ڕێساکان سوود لەو لینکە وەربگرە کە لە خاڵی ٢ی بەشی پێداویستییەکان ئاماژەی پێکراوە.

### _Sidebar.md

ئەمە پێرستی سەرەکی و پەڕەی گەڕانەکەتە لە لای چەپی وێبسایتەکە. کاتێک فایلی مارکداونێکت بۆ کۆگاکەت زیاد کرد، پێویستە فایلەکە لەم شوێنە زیاد بکەیت تاکو ناوەڕۆکەکەی لە وێبسایتەکەدا دەربکەوێت. هەمان شێوازی پێشوو پەیڕەو بکە.


## چالاککردنی Github Pages بۆ گۆڕینی کۆگاکە بۆ وێبسایت

1. لە ناو کۆگاکەتدا کلیک لە 'Settings' بکە.

![Website-Step1](/_media/Website-Step1.png)

2. لە پێرستی لای چەپدا 'Pages' هەڵبژێرە.

![Website-Step2](/_media/Website-Step2.png)

3. ئەگەر کۆگاکەت نەکردووە بە 'public' (گشتی)، دوو بژاردەت هەیە:
    a. کۆگاکە بکە بە گشتی (public) تا ڕێگەت پێ بدات بەبێ بەرامبەر وێبسایتی SRD-ەکەت لەسەر Github pages میوانداری بکەیت.
    b. ئەکاونتی گیتھەبەکەت بەرز بکەرەوە (لە کاتی نووسینی ئەم ڕێنماییەدا تێچووەکەی ٤ دۆلارە لە مانگێکدا یان ٤٨ دۆلار بۆ ساڵێک).

4. لە بەشی 'Branch' بژاردەی 'main' هەڵبژێرە و کلیک لە save بکە.

5. ١٠ بۆ ٢٠ چرکە چاوەڕێ بکە و پاشان لاپەڕەکە تازە بکەرەوە (refresh).

6. ئێستا دەتوانیت ناونیشانی وێبسایتەکەت ببینیت، بۆ نموونە: https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)


## گۆڕینی فۆنتەکان

1. فایلی /_assets/style.css دەستکاری بکە.

2. لە بەشی 'body section' هەردوو بەشی siteFont و headingFont دەدۆزیتەوە.

3. ئەمانە بگۆڕە بۆ ئەو فۆنتانەی دەتەوێت بەکاریان بهێنیت.


## بەکارهێنانی پلەگینی Fontawesome و/یان Material Icons بۆ نیشاندانی ئایکۆنی بێبەرامبەر لە SRD-ەکەتدا

### Fontawesome

بۆ بەدەستهێنانی ئایکۆنی بێبەرامبەر و ئایکۆنی جووڵاو لە Fontawesome کەڵک وەربگرە. بەکارهێنەرە سەبسکرایب کراوەکان دەتوانن ئایکۆنە پڕۆکان بەکاربهێنن.

1. ئایکۆنەکە لە [Fontawesome](https://fontawesome.com/icons) بدۆزەرەوە.
2. ئایکۆنەکە هەڵبژێرە.
3. لە پەنجەرە بچووکەکەدا (popup window)، لە ژێر تابی HTML، هەموو ئەوەی لەنێوان " " دایە کۆپی بکە.

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. ئەو دەقەی کۆپیت کردووە لەنێوان `:` دایبنێ بەبێ بۆشایی.

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

بۆ ئایکۆنی بێبەرامبەری زیاتر، Material Icons بەکاربهێنە.

1. ئایکۆنەکان لە [Material Icons](https://fonts.google.com/icons) بدۆزەرەوە.
2. لینکی span-ی وێبەکە کۆپی بکە و ڕاستەوخۆ لە فایلەکانی مارکداونت دایبنێ.

```markup
<span class="material-icons">face</span>
```
