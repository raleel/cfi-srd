# Lampiran: Tabel Konversi

---
#### Konversi Ukuran lan Bobot Imperial menyang Metrik

Supaya _Classic Fantasy Imperative_ katon luwih resik, luwih gampang diwaca, lan luwih ringkes ing katrangan lan tabel, seri _Classic Fantasy Imperative_ bakal fokus ing pangukuran Imperial tinimbang campuran Imperial lan Metrik. Sistem Imperial dipilih kanggo nggampangake konversi materi sing wis ana amarga umume petualangan, battlemat, lan peta sing digunakake dening game liya ing genre iki nggunakake sistem Imperial. Nanging, kanggo sing pengin nggunakake Sistem Metrik, bobot lan ukuran sing paling asring digunakake wis dikonversi nggunakake tabel ing ngisor iki. Amarga kita biasane ora ngangani makhluk, mantra, lan liya-liyane sing nyata, kita bisa menehi keluwesan sethithik ing bobot lan ukuran sing wis digawe. Tinimbang nggunakake konversi sing pas, luwih gampang nggunakake sing gampang dieling, supaya luwih gampang anggone dolanan.

#### Tabel Suhu

| Suhu (ºF) | Jinis | Risiko |
| :-: | :-: | :-- |
| < 2º | Glasial | Golek Anget Langsung |
| 3-14º | Mbeku | 15 Menit |
| 13-32º | Adhem | Saben Jam |
| 33-50º | Tis-tis | Saben Dina |
| 51-68º | Kelangan | - |
| 69-86º | Anget | - |
| > 86º | Panas | Saben Jam |

Suhu bisa beda-beda drastis amarga iklim, mangsa, lan elevasi, gumantung ing donya kampanye lan ing ngendi skenario disetel. Tabel ing ndhuwur nyedhiyakake pandhuan kanggo efek suhu ekstrem ing karakter.

Nganggo klambi sing cocog ngidini karakter entuk wektu tenggang sajrone CON ing jam sadurunge paparan diwiwiti, kaya sing dituduhake ing kolom Risiko. Sawise titik iki, dheweke kudu golek papan perlindungan utawa wiwit ngalami ilang Fatigue. Karakter sing teles ngowahi Tingkat Risiko siji tingkat luwih adhem. Angin gedhe sing entheng utawa moderat uga ngowahi Tingkat Risiko siji tingkat luwih adhem, dene angin gedhe lan badai ngowahi rong tingkat.
