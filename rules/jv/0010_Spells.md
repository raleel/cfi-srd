## Katrangan Mantra

---
#### Appraise (Naksir)

(Divinasi)

| | |
| :-- | :-- |
| **Rank:** Penyihir 0 | **Wektu Nganalisis:** 1 Giliran |
| **Sphere:** Ora ana | **Durasi:** Instan |
| **Baya:** 1 | **Jarak:** Tutul |
| **Area:** 1 Barang | **Resist:** Ora ana |

Appraise ngidini pambiji cepet babagan kualitas barang fisik kanthi ENC gabungan ing 'Bab' utawa SIZ sing padha karo POW perapal. Mantra iki nemtokake manawa barang sing katon padha iku nduweni kualitas sing padha utawa meh padha, utawa yen siji utawa luwih barang kasebut cacat utawa luwih dhuwur kualitasé. Mantra iki ora bisa digunakake ing bab-bab organik, mung ing obyek mati. Mantra iki uga ora nemtokake cacat utawa tambahan apa sing ana; mung yen ana. Mantra iki ora ana gunane kanggo ngenali utawa ndeteksi sihir.

#### Armor (Waja)

(Konjurasi)

| | |
| :-- | :-- |
| **Rank:** Penyihir 1 | **Wektu Nganalisis:** 1 Ronde |
| **Sphere:** Ora ana | **Durasi:** Deleng ing ngisor |
| **Baya:** 3 +1/Intensitas | **Jarak:** Tutul |
| **Area:** 1 Target | **Resist:** Ora ana |

Nalika mantra iki dirapal, subjek diwenehi lapangan gaya sihir sing ora katon sing padha karo waja sisik, menehi 4 Poin Waja ing saben Lokasi Awak. Iki ora ana pengaruhe yen dirapal marang wong sing wis nganggo waja. Nanging, iki bakal nggantèkaké waja alami kanggo Durasiné, kanthi nganggep waja kasebut menehi perlindungan sing luwih apik. Yen dirapal marang makhluk sing nduweni luwih saka 4 poin waja alami, iki bakal nambah Poin Waja kanthi 1 ing kabeh lokasi. Perlindungan sihir iki ora ngalangi gerakan utawa ngrapal mantra. Mantra bakal tetep ana nganti dibatalake dening sihir, utawa perapal nampa 8 poin karusakan saka siji serangan, +1 saben tingkat Intensitas tambahan (deleng tabel ing ngisor). Mesthi wae, perapal bisa milih kanggo mungkasi mantra kapan wae yen dikarepake lan kudu nindakake iku kanggo turu.

| Intensitas | Baya | Efek Variabel |
| :-: | :-: | :-- |
| 1 | 3 | 4 Poin Waja; Bertahan nganti nampa 8 karusakan saka 1 serangan |
| 2 | 4 | 4 Poin Waja; Bertahan nganti nampa 9 karusakan saka 1 serangan |
| 3 | 5 | 4 Poin Waja; Bertahan nganti nampa 10 karusakan saka 1 serangan |
| 4 | 6 | 4 Poin Waja; Bertahan nganti nampa 11 karusakan saka 1 serangan |
| +1 | +1 | Terusake progres |

#### Astral Spell (Mantra Astral)

(Transmutasi)

| | |
| :-- | :-- |
| **Rank:** Pandhita 5, Penyihir 5 | **Wektu Nganalisis:** 2 Aksi |
| **Sphere:** Astral | **Durasi:** Deleng ing ngisor |
| **Baya:** 3 +1/Intensitas tambahan | **Jarak:** Tutul |
| **Area:** Deleng ing ngisor | **Resist:** N/A |

Mantra iki ngidini perapal lan nganti limang wong liya (siji saben tingkat Intensitas tambahan) kanggo mlebu ing Bidhang Astral. Kabeh kudu tutul-tutulan lan nggawe bunder nalika mantra dirapal. Awak para pangumbara ditinggal ing bidhang asal, lan padha biasane ora nggawa sandhangan utawa peralatan, kajaba sing memancar aura sihir; barang-barang iki malih dadi bentuk astral sing padha karo wujud asline. Durasi bakal terus nganti perapal pengin mandheg. Nanging, mantra iki bisa diakhiri luwih awal dening pasukan njaba kayata Dispel Magic. Mateni awak fisik perapal uga bakal mungkasi mantra luwih awal, sanajan iki duwe efek samping sing ala yaiku nggandholake para pangumbara sing ngancani perapal.
