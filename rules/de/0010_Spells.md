## Zauberbeschreibungen

---
#### Appraise (Abschätzen)

(Wahrsagung)

| | |
| :-- | :-- |
| **Rang:** Magier 0 | **Zauberzeit:** 1 Runde |
| **Sphäre:** Keine | **Dauer:** Augenblicklich |
| **Kosten:** 1 | **Reichweite:** Berührung |
| **Bereich:** 1 Gegenstand | **Widerstand:** Keine |

Appraise erlaubt die sofortige Einschätzung der Qualität physischer Waren mit einem kombinierten Belastungswert in „Dingen“ oder einer GRÖ (Größe), die der MÄ (Magischen Äquivalenz/Macht) des Zaubernden entspricht. Der Zauber bestimmt, ob identisch aussehende Gegenstände von gleicher oder ähnlicher Qualität sind, oder ob eines oder mehrere fehlerhaft oder von höherer Qualität sind. Der Zauber funktioniert nicht bei organischen Dingen, nur bei unbelebten Objekten. Er bestimmt auch nicht, welche Mängel oder Verbesserungen vorhanden sind; er stellt lediglich fest, dass sie existieren. Er ist nicht dazu geeignet, Magie zu identifizieren oder aufzuspüren.

#### Armor (Rüstung)

(Beschwörung)

| | |
| :-- | :-- |
| **Rang:** Magier 1 | **Zauberzeit:** 1 Runde |
| **Sphäre:** Keine | **Dauer:** Siehe unten |
| **Kosten:** 3 +1/Intensität | **Reichweite:** Berührung |
| **Bereich:** 1 Ziel | **Widerstand:** Keine |

Wenn dieser Zauber gewirkt wird, erhält das Ziel ein unsichtbares Feld magischer Kraft, das dem Schutz einer Schuppenrüstung entspricht und jeder Trefferzone 4 Rüstungspunkte gewährt. Er hat keinen Effekt, wenn er auf jemanden gewirkt wird, der bereits eine Rüstung trägt. Er ersetzt jedoch für seine Dauer eine natürliche Rüstung, vorausgesetzt, er bietet einen überlegenen Schutz. Wenn er auf eine Kreatur gewirkt wird, die über mehr als 4 Punkte natürliche Rüstung verfügt, erhöht er stattdessen die Rüstungspunkte an allen Orten um 1. Dieser magische Schutz behindert weder Bewegung noch das Zauberwirken. Der Zauber hält an, bis er durch Magie gebannt wird oder der Zaubernde 8 Schadenspunkte aus einem einzigen Angriff erleidet, +1 pro Stufe zusätzlicher Intensität (siehe Tabelle unten). Natürlich kann der Zaubernde entscheiden, den Zauber jederzeit abzubrechen, wenn gewünscht, und muss dies tun, um zu schlafen.

| Intensität | Kosten | Variabler Effekt |
| :-: | :-: | :-- |
| 1 | 3 | 4 Rüstungspunkte; Hält an, bis 8 Schaden durch 1 Angriff erlitten werden |
| 2 | 4 | 4 Rüstungspunkte; Hält an, bis 9 Schaden durch 1 Angriff erlitten werden |
| 3 | 5 | 4 Rüstungspunkte; Hält an, bis 10 Schaden durch 1 Angriff erlitten werden |
| 4 | 6 | 4 Rüstungspunkte; Hält an, bis 11 Schaden durch 1 Angriff erlitten werden |
| +1 | +1 | Fortsetzung der Progression |

#### Astral Spell (Astralzauber)

(Umwandlung)

| | |
| :-- | :-- |
| **Rang:** Kleriker 5, Magier 5 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Astral | **Dauer:** Siehe unten |
| **Kosten:** 3 +1/zusätzliche Intensität | **Reichweite:** Berührung |
| **Bereich:** Siehe unten | **Widerstand:** N/A |

Dieser Zauber erlaubt es dem Zaubernden und bis zu fünf anderen (einer pro zusätzlicher Stufe der Intensität), die Astralebene zu betreten. Alle müssen sich berühren und einen Kreis bilden, während der Zauber gewirkt wird. Die Körper der Reisenden bleiben in der Ursprungsebene zurück, und sie bringen typischerweise keine Kleidung oder Ausrüstung mit, außer solchen Gegenständen, die selbst eine magische Aura ausstrahlen; diese Gegenstände verwandeln sich in astrale Äquivalente ihrer normalen Form. Die Dauer währt, bis der Zaubernde wünscht, dass sie endet. Es ist jedoch möglich, dass sie vorzeitig durch eine äußere Kraft wie *Dispel Magic* beendet wird. Das Töten des physischen Körpers des Zaubernden beendet den Zauber ebenfalls vorzeitig, obwohl dies den unglücklichen Nebeneffekt hat, alle den Zaubernden begleitenden Reisenden stranden zu lassen.

#### Augury (Augurium)

(Wahrsagung)

| | |
| :-- | :-- |
| **Rang:** Kleriker 2 | **Zauberzeit:** 2 Minuten |
| **Sphäre:** Wahrsagung | **Dauer:** Augenblicklich |
| **Kosten:** 3/Intensität | **Reichweite:** 60 Fuß |
| **Bereich:** Zaubernder | **Widerstand:** N/A |

Dieser Zauber erlaubt es dem Zaubernden zu bestimmen, ob eine bestimmte Handlung, die innerhalb der nächsten 30 Minuten unternommen werden soll, vorteilhaft oder schädlich für das Wohlbefinden eines Einzelnen und/oder einer Gruppe sein wird. Ein Fokuspunkt irgendeiner Art wird benötigt, um die Vorzeichen zu deuten; am häufigsten sind dies Krallen oder kleinere Knochen eines Drachen, eine Perle oder reines Gold im Wert von nicht weniger als 100 GM, das zerkleinert oder eingeschmolzen wurde. Der Zauber hat eine maximale Intensität von 4. Dieser Wurf sollte vom Spielleiter durchgeführt werden, da der Zaubernde niemals zweifelsfrei wissen sollte, ob die Ergebnisse richtig interpretiert wurden.

| Intensität | Kosten | Variabler Effekt |
| :-: | :-: | :-- |
| 1 | 3 | Schwieriger Kanalisieren-Fertigkeitswurf |
| 2 | 6 | Schwerer Kanalisieren-Fertigkeitswurf |
| 3 | 9 | Standard Kanalisieren-Fertigkeitswurf |
| 4 | 12 | Einfacher Kanalisieren-Fertigkeitswurf |

Wenn der Wahrsagungswurf gelingt, liefert er eines der folgenden Ergebnisse:

| Augurium | Bedeutung | 
| :-: | :-- |
| Ja | Die Handlung wird vorteilhaft sein |
| Nein | Die Handlung wird schädlich sein |
| Ja und Nein | Die Handlung wird sowohl vorteilhaft als auch schädlich sein |
| Nichts | Die Handlung wird weder vorteilhaft noch schädlich sein |

Ein Patzer sollte dazu führen, dass der Spielleiter das Gegenteil der Realität mitteilt.

#### Avert (Abwenden)

(Bannung)

| | |
| :-- | :-- |
| **Rang:** Kleriker 0, Magier 0 | **Zauberzeit:** Augenblicklich |
| **Sphäre:** Schutz | **Dauer:** Augenblicklich |
| **Kosten:** 1 | **Reichweite:** 60 Fuß |
| **Bereich:** 1 Zauber | **Widerstand:** Keine |

*Avert* wird verwendet, um einen anderen Zauber des Rangs 0 innerhalb der Reichweite aufzuheben. *Avert* kann reaktiv gewirkt werden, um offensive Zauber des Rangs 0 durch den Einsatz der reaktiven Aktion *Counter Magic* zu neutralisieren.

#### Befuddle (Verwirrung)

(Verzauberung (Bezauberung))

| | |
| :-- | :-- |
| **Rang:** Kleriker 0, Magier 0 | **Zauberzeit:** 1 Runde |
| **Sphäre:** Bezauberung | **Dauer:** 30 Minuten |
| **Kosten:** 1 | **Reichweite:** 60 Fuß |
| **Bereich:** 1 Ziel | **Widerstand:** Willenskraft |

*Befuddle* verursacht Verwirrung im Geist eines körperlichen Ziels. Das Subjekt des Zaubers hat Schwierigkeiten, klar zu denken, vergisst, wo es ist, was es tut und warum – oft verfällt es in assoziationslose Gedankengänge. Verwirrte Ziele können zwar noch in Selbstverteidigung handeln, aber keine konstruktive Aktivität einleiten, bis der Zauber endet. Jede Art von Angriff oder drohender Handlung bricht den Zauber sofort, unabhängig davon, ob er speziell gegen das verwirrte Ziel gerichtet war oder nicht.

#### Blade Barrier (Klingenbarriere)

(Hervorrufung)

| | |
| :-- | :-- |
| **Rang:** Kleriker 4 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Wächter, Erschaffung | **Dauer:** 3 Runden/Intensität |
| **Kosten:** 3 +1/zusätzliche Intensität | **Reichweite:** 100 Fuß |
| **Bereich:** 5–30 Fuß Radius | **Widerstand:** Siehe unten |

Dieser Zauber erschafft eine Barriere aus wirbelnden, schneidenden Schwertern, Dolchen und Messern, die um einen fixen Punkt peitschen und 1W8 Schadenspunkte an 1W4+2 zufälligen Trefferzonen bei jedem verursachen, der durch den Wirkungsbereich geht. Rüstung bietet nur die Hälfte ihres normalen Schutzes. Magische Rüstungspunkte reduzieren den Schaden wie gewohnt. Da die Waffen mit blendender Geschwindigkeit wirbeln und eng gepackt sind, ist es unmöglich, ihnen auszuweichen oder sie zu parieren. Man kann einen Schild verwenden, um Trefferzonen passiv wie gewohnt zu blocken. In diesem Fall daran denken, den gewürfelten Schaden mit der Rüstung und den Trefferpunkten des Schildes zu vergleichen.

Der Zauber kann defensiv gewirkt werden, um den Kleriker oder einen oder mehrere Verbündete zu schützen, oder offensiv, um Feinde einzufangen. Eingekreiste Feinde innerhalb von fünf Fuß vom Rand der Barriere, während diese sich formt, können jedoch einen Ausweichen-Wurf machen, um zu entkommen. Unabhängig vom Erfolg landet der Gegner liegend direkt außerhalb des Wirkungsbereichs. Ein erfolgreicher Wurf führt zu keinem Schaden; andernfalls erleiden sie den vollen Effekt.

#### Bless (R) (Segen)

(Beschwörung)

| | |
| :-- | :-- |
| **Rang:** Kleriker 1 | **Zauberzeit:** 1 Runde |
| **Sphäre:** Alle | **Dauer:** 5 Minuten |
| **Kosten:** 1 | **Reichweite:** 180 Fuß |
| **Bereich:** 25 Fuß Radius | **Widerstand:** Willenskraft |

Wenn dieser Zauber gewirkt wird, segnet der Kleriker eine Gruppe von Verbündeten innerhalb des Wirkungsbereichs. Die Betroffenen strahlen die Gesinnung des Zaubernden aus, entweder Gut oder Böse. Es gibt keine Segnungen der Neutralität. Alle Verbündeten innerhalb des Radius des Zaubers erhalten einen Bonus von +5 % auf alle Fertigkeits- und Widerstandswürfe. Zusätzlich verursachen ihre Waffen +1W3 Schaden gegen intelligente Untote sowie Kreaturen von den äußeren Ebenen, die gegensätzliche Gesinnungen zum Zaubernden haben, wie etwa Dämonen, Teufel oder Engel. Beachte, dass animierte Untote wie Skelette und Zombies zwar nicht von Natur aus böse sind, aber typischerweise durch böse Magie animiert wurden und daher diesem Schaden unterliegen.

Die Umkehrung dieses Zaubers, *Fluch*, erlaubt es dem Kleriker, Feinde zu verfluchen, wodurch die genannten Fertigkeiten den umgekehrten Wert der oben genannten Vorteile erleiden. Der Schaden einer verfluchten Waffe wird stattdessen als Abzug berechnet, wobei dieser Schaden nicht zu weniger als 1 Punkt führen kann.

#### Burning Hands (Brennende Hände)

(Umwandlung)

| | |
| :-- | :-- |
| **Rang:** Magier 1 | **Zauberzeit:** 1 Aktion |
| **Sphäre:** Keine | **Dauer:** Augenblicklich |
| **Kosten:** 3 +1/zusätzliche Intensität | **Reichweite:** 0 |
| **Bereich:** 120-Grad-Kegel, 5 Fuß lang | **Widerstand:** Ausweichen |

Dieser Zauber bewirkt, dass Flammen aus den Händen des Zaubernden in einem 120-Grad-Bogen schießen. Bei Verwendung von Miniaturen im Kampf schädigt *Burning Hands* jedes Ziel, das eines der vorderen Felder des Zaubernden besetzt. Das Wirken von *Burning Hands* auf höheren Intensitätsstufen erfordert einen Magier höheren Rangs. Dieser Schaden trifft alle Ziele im Bereich mit einem Schaden, der auf der Intensität des Zaubers basiert, bis zu einer maximalen Intensität von 9, wie folgt. Ein erfolgreicher Ausweichen-Wurf, bei dem man sich zu Boden wirft, erlaubt es dem Opfer, keinen Schaden zu erleiden. Jemand mit der Fähigkeit „Gewiefter Ausweicher“ hat die Option, auszuweichen, ohne sich hinzulegen.

| Intensität | Kosten | Min. Rang | Variabler Effekt |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1W3+1 Schadenspunkte an allen Trefferzonen |
| 3 | 4 | 1 | 1W3+2 Schadenspunkte an allen Trefferzonen |
| 5 | 5 | 1 | 1W3+3 Schadenspunkte an allen Trefferzonen |
| 7 | 6 | 2 | 1W3+4 Schadenspunkte an allen Trefferzonen |
| 9 | 7 | 3 | 1W3+5 Schadenspunkte an allen Trefferzonen |

Getragene Rüstung schützt nicht, aber magische Rüstungspunkte oder die natürliche Rüstung einer Kreatur reduzieren den Schaden wie gewohnt. Dieser mächtige Zauber wird durch seine auffallend kurze Reichweite ausgeglichen, was bedeutet, dass der Magiewirker nahe genug sein muss, um sich in einer sehr nachteiligen Position zu befinden.

Da größere Kreaturen typischerweise größer als der Wirkungsbereich des Zaubers sind, neigen sie dazu, weniger betroffene Trefferzonen zu haben. Solche mit GRÖ 21 bis 30 erleiden den Schaden an Kopf, Brust, Bauch und Armen, während solche mit GRÖ 31+ den Schaden an Bauch und Beinen erleiden. #### Befehl

(Verzauberung (Bezauberung))

| | |
| :-- | :-- |
| **Rang:** Kleriker 1 | **Zauberzeit:** 1 Aktion |
| **Sphäre:** Bezauberung | **Dauer:** 1 Minute |
| **Kosten:** 3 | **Reichweite:** 100 Fuß |

Wenn dieser Zauber gewirkt wird, kann der Kleriker einen Ein-Wort-Befehl an ein lebendes Wesen von SIZ 1-20 aussprechen, und in der nächsten Runde des Subjekts wird der Befehl buchstabengetreu befolgt, wenn es nicht widersteht. - **Fliehen:** Das Subjekt dreht sich um und flieht vor dem Zauberer.

- **Gehen:** Das Subjekt dreht sich um und geht auf dem Weg, auf dem es gekommen ist, zurück.
- **Rasten:** Das Subjekt lässt sich in eine sitzende Position fallen und holt Luft.
- **Laufen:** Das Subjekt beginnt zu laufen.
- **Schreien:** Das Subjekt schreit.
- **Sinken:** Das Subjekt hört auf zu schwimmen.

(Nekromantie)

| | |
| :-- | :-- |
| **Grad:** Magier 4 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Keine | **Wirkungsdauer:** Augenblicklich |

*Beispiel: Rengarth wirkt den Todeszauber in einen Bereich, der von vier Orks der GRÖ 16 und zwei Hügelriesen der GRÖ 32 besetzt ist, und wählt eine Intensität von 3. Da jeder Ork 1 Punkt entspricht, verbleiben 8 Punkte. Dies reicht aus, um einen Hügelriesen mit 5 Punkten zu beeinflussen, wobei die restlichen 3 Punkte verloren gehen. Der wütende Hügelriese hat jedoch kein Problem damit, seinen einfachen Widerstandswurf zu bestehen, und stürmt auf Rengarth zu.*

#### Gegenstand verzaubern

(Verzauberung)

| | |
| :-- | :-- |
| **Rang:** Magier 4 | **Zauberzeit:** Siehe unten |
| **Sphäre:** Keine | **Dauer:** Siehe unten |
| **Kosten:** 3 + Siehe unten | **Reichweite:** Berührung |
| **Bereich:** 1 Gegenstand | **Widerstand:** N/A |

Das Wirken dieses Zaubers bereitet einen Gegenstand auf eine Verzauberung vor. Das Objekt muss in gutem Zustand sein und von feinster Konstruktion und Handwerkskunst. Zusätzliche Kosten von mindestens 100 GM sind erforderlich, um die Kosten für zusätzliches Werkzeug, Schnitzereien, Stickereien, Juwelenbesatz, Gravuren usw. zu decken. Schließlich erfordert der Verzauberungsprozess ein Labor oder eine Werkstatt.

Während der Zauber gewirkt wird, muss der Magiekundige den Gegenstand während der gesamten Zauberzeit von 1d8+2 Tagen berühren. Dies berücksichtigt Ruhe- und Schlafperioden, während derer der Gegenstand in Armeslänge des Zaubernden bleiben muss. Zu keinem Zeitpunkt während des Wirkens darf der Magiekundige einen anderen Zauber wirken oder eine andere Form von Magie ausüben. Das Brechen einer dieser Vorgaben führt automatisch zum Fehlschlag des Zaubers.

Sobald der Zauber erfolgreich gewirkt wurde, ist der Gegenstand für den letzten Schritt bereit, bei dem der Zaubernde den gewünschten Zauber in ihn einbettet. Dazu muss er den Zauber im Gedächtnis oder auf einer Schriftrolle haben und ihn innerhalb von 24 Stunden in den Gegenstand wirken, sonst muss der gesamte Prozess von vorne begonnen werden. Sobald das Wirken des ausgewählten Zaubers beginnt, kann der Prozess die oben genannten 24 Stunden überschreiten. Das Einbetten des ausgewählten Zaubers in den Gegenstand kostet die normalen Magiepunkte für die gewünschte Intensität und dauert 1d12 Stunden pro Zauberrang. Während des gesamten Einbettungsprozesses muss der Zaubernde den Gegenstand berühren oder während Ruhephasen in Armeslänge bleiben, wie oben beschrieben, und am Ende der Zauberperiode ist ein arkana Zauberwurf erforderlich, um den Zauber erfolgreich einzubetten. Die normalen Erfolgsgrade für das Zauberwirken werden befolgt; bei einem Fehlschlag kann der Zauber jedoch nicht erzwungen werden. Nachfolgende Zauber können in den Gegenstand eingebettet werden, vorausgesetzt, der Zauberprozess wird innerhalb von 24 Stunden nach Abschluss des vorherigen Zaubers begonnen. Dies gilt auch im Falle eines zuvor fehlgeschlagenen Zaubers. Jeder nachfolgende Zauber erfordert die normalen Zauberkosten.

Bei Verwendung des Gegenstands kann jeder darin enthaltene Zauber nur einmal gewirkt werden, allerdings können mehrere Versionen desselben Zaubers gemäß dem oben genannten Verfahren eingebettet werden. Es ist auch möglich, einen einzelnen Zauber einzubetten und anschließend den Rang-4-Zauber Permanenz zu wirken. In diesem Fall kann der Zauber so oft wie gewünscht gewirkt werden, unter Beachtung der Einschränkungen, die unter der Beschreibung des Zaubers Permanenz aufgeführt sind.

Es ist nicht möglich, andere magische Effekte in einen Gegenstand einzubetten, die nicht einem spezifischen Zauber entsprechen, und viele magische Gegenstände aus längst vergangenen Zeiten können in der heutigen Zeit schlicht nicht nachgebildet werden.

#### Vertrauten finden

(Beschwörung)

| | |
| :-- | :-- |
| **Rang:** Magier 1 | **Zauberzeit:** 2d12 Stunden |
| **Sphäre:** Keine | **Dauer:** Spezial |
| **Kosten:** 3/Intensität, +1 EP | **Reichweite:** 0 |
| **Bereich:** ½ Meile Radius/Intensität | **Widerstand:** N/A |

Dieser Zauber erlaubt es dem Zaubernden, zu versuchen, einen Vertrauten zu beschwören, der zu einer Erweiterung der Sinne und Kräfte seines Meisters wird. Vertraute können telepathisch mit ihrem Meister kommunizieren und geben gute Wächter und Späher ab. Wenn der eigene Vertraute getötet wird, bringt dies aufgrund der engen Verbindung gewisse Risiken für den Magiekundigen mit sich, was einen Vertrauten zu einer Gefahr niedrigen Rangs macht.

Um einen Vertrauten zu beschwören, muss der Magiekundige das Ritual beginnen, während er ein Kohlebecken am Brennen hält, und wenn es intensiv brennt, Weihrauch im Wert von 100 GM hinzufügen. Während diese Zutaten brennen, muss der Zaubernde das Ritual fortsetzen, bis der Vertraute eintrifft oder die Zauberzeit ohne Erfolg abläuft.

Selbst wenn dieser Zauber erfolgreich gewirkt wird, beträgt die Chance, dass ein geeigneter Vertrauter auf den Ruf des Magiekundigen antwortet, nur 50 %, und der Magiekundige kann diesen Zauber nur einmal pro Jahr versuchen. Jede zusätzliche Intensitätsstufe über der ersten hinaus erweitert die Reichweite des Zaubers um eine weitere halbe Meile, was wiederum die Wahrscheinlichkeit erhöht, dass ein potenzieller Vertrauter gefunden wird, um 5 %, bis zu einem Maximum von 95 %. Es gibt keine Kontrolle über die genaue Art der Kreatur, die auf den Ruf antworten wird, aber was auch immer ankommt, wird ein treuer Diener und Verbündeter sein. Es liegt an der spezifischen Kreatur, auf den Ruf zu antworten; daher garantiert der Aufenthalt in einer Region, von der bekannt ist, dass sie von einer bestimmten Art von Kreatur bewohnt wird, dem Zaubernden _keinen_ Erfolg.

Wenn eine Kreatur auf die Beschwörung des Zaubernden antwortet, muss der Magiekundige dennoch 1 Erfahrungswurf opfern, um eine spirituelle Verbindung zwischen sich und dem Vertrauten zu schaffen. Sobald dies geschehen ist, ist das Ritual abgeschlossen.

Während sich der Vertraute und sein Meister innerhalb von 120 Fuß voneinander befinden, gewinnt der Magiekundige die Fähigkeit, auch die Magiepunkte des Vertrauten zu nutzen. Zusätzlich erhält der Magiekundige eine telepathische Verbindung zum Vertrauten und alle zusätzlichen besonderen Fähigkeiten oder Fertigkeitsboni, die in den Tabellen unten vermerkt sind.

#### Feuerschild

(Evokation)

| | |
| :-- | :-- |
| **Rang:** Magier 3 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Keine | **Dauer:** 2 Minuten/Intensität |
| **Kosten:** 3+1/zusätzliche Intensität | **Reichweite:** 0 |
| **Bereich:** Zauberer | **Widerstand:** N/A |

Dieser Zauber erschafft einen Schild aus feinen Flammen, der den Zauberer einhüllt, aber an sich keinen Schaden verursacht. Stattdessen schützen die Flammen den Empfänger entweder vor Feuer oder Kälte, abhängig davon, welche der beiden Varianten im Gedächtnis gespeichert ist: Kälteschild, der blaue oder grüne Flammen erzeugt und vor Hitze- und feuerspezifischem Schaden schützt, oder Wärmeschild, der violette oder blaue Flammen erzeugt und vor Kälte- und eisspezifischem Schaden schützt. Die Farbe der Flammen sollte zufällig mit einer 50%igen Chance für jede bestimmt werden, da die Tatsache, dass beide Typen blaue Flammen aussenden können, ein Element der Unsicherheit auf Seiten jedes Angreifers erzeugt. Die Entscheidung, welche Variante man auswendig lernt, wird beim Vorbereiten der Zauber getroffen; beide können bei Bedarf gelernt werden. Diese Flammen geben keine Hitze ab und erzeugen Licht mit nur der halben Helligkeit einer Fackel. Die Einzelheiten jeder Variante sind unten aufgeführt.

- **Kälteschild:** Diese Flammen fühlen sich kühl an und reduzieren jeglichen Feuer- oder hitzebasierten Schaden auf die Hälfte des Gesamtschadens. - **Wärmeschild:** Diese Flammen fühlen sich warm an und reduzieren jeglichen kältebasierten Schaden auf die Hälfte des Gesamtschadens. Ein erfolgreicher Widerstandswurf hebt den gesamten Schaden auf. Der Widerstandswurf ist um einen Grad einfacher und führt im Fall von Ausweichen nicht dazu, dass der Verteidiger zu Boden geht.

Nahkampfangriffe gegen den Empfänger einer der beiden Varianten, ob bewaffnet oder unbewaffnet, verursachen normalen Schaden, es sei denn, es werden eines der Elemente verwendet, gegen die Schutz besteht. In diesem Fall ist der Zauberer vor dem elementaren Teil des Angriffs geschützt und der Angreifer erhält Schaden in Höhe des zugefügten Schadens. Getragene Rüstung auf Seiten des Angreifers bietet keinen Schutz, aber magische Rüstungspunkte oder die natürliche Rüstung einer Kreatur reduzieren den Schaden wie gewohnt. Kreaturen mit angeborener Magieresistenz können Feuerschild bei einem erfolgreichen Willenskraftwurf bannen, wenn der Empfänger zum ersten Mal getroffen wird. Wenn der Magieresistenzwurf fehlschlägt, kann der Gegner den Feuerschild später nicht mehr aufheben.

#### Fleisch zu Stein (R)

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Magier 4 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Keine | **Dauer:** Permanent |
| **Kosten:** 3/Intensität | **Reichweite:** 9 m/Intensität |
| **Bereich:** 1 Ziel | **Widerstand:** Willenskraft |

Beim Zaubern erhält ein Opfer innerhalb der Reichweite einen Willenskraft-Widerstandswurf. Wenn dieser fehlschlägt, werden es und alle getragenen oder angelegten Besitztümer vollständig in festen Stein verwandelt. Diese Verwandlung ist kein Tod, sondern eine Form von suspendierter Animation. Das Zaubern der umgekehrten Version dieses Zaubers oder ein Wunsch können verwendet werden, um das Opfer wieder zum Leben zu erwecken. Jeder Schaden, den das Opfer erleidet, während es Stein ist, bleibt bestehen und tritt unmittelbar bei der Wiederherstellung in Kraft. Große Kreaturen (GRÖ 21-40) sind weniger anfällig für diesen Zauber, wobei der Widerstandswurf „Einfach“ ist; der Widerstandswurf für riesige Kreaturen (GRÖ 41+) ist „Sehr Einfach“.

Die Umkehrung dieses Zaubers, Stein zu Fleisch, wird verwendet, um ein Opfer wiederherzustellen; hierbei ist kein Widerstandswurf erforderlich. Der Zauber kann jedoch auch umgekehrt werden, um Stein zu verwandeln, der zuvor niemals lebendig war, wobei er auf eine von mehreren kreativen Arten verwendet werden kann. Zum Beispiel kann eine Steinmauer von 10 Kubikfuß Größe pro Intensitätsstufe in weiches Fleisch verwandelt werden, ein „Fleischtunnel“ von bis zu 1 Meter Breite und einer Länge von 3 Metern pro Intensität könnte erschaffen werden, ein einzelnes Ziel wie eine Steinstatue könnte in einen Körper verwandelt werden, und sogar ein Steingolem könnte mittels dieses Zaubers in einen Fleischgolem verwandelt werden. Im letzteren Fall hätte der Steingolem jedoch wie üblich einen Willenskraftwurf zur Verfügung, um zu widerstehen. Auf diese Weise in Fleisch verwandelter Stein ist weich und biegsam, und obwohl er seine tatsächlichen Trefferpunkte behält, besitzt er keine Rüstungspunkte, was es einfacher macht, ihn zu zerhacken.

#### Polymorph (Anderer)

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Magier 3 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Keine | **Wirkungsdauer:** Permanent |
| **Kosten:** 3, +1/zusätzliche Intensität (+1 EP) | **Reichweite:** 15 Fuß/Intensität |
| **Bereich:** 1 Ziel | **Widerstand:** Willenskraft |

Der Zaubernde kann die Form einer körperlichen Zielkreatur in die einer anderen ändern, wobei jeder Intensitätspunkt die SIZ um bis zu 5 Punkte verändert. Daher würde die Verwandlung eines Orks mit SIZ 16 in einen Hasen mit SIZ 1 drei Intensitätsstufen erfordern (15 SIZ-Punkte Unterschied). Dem Subjekt dieses Zaubers steht ein Willenskraftwurf zu, um zu widerstehen. Große Kreaturen (SIZ 21-40) sind weniger anfällig für eine Polymorphie, wobei ihr Widerstandswurf „Leicht“ ist, während der Widerstandswurf für riesige Kreaturen (SIZ 41+) „Sehr Leicht“ ist.

Der gesamte Verwandlungsprozess dauert eine volle Runde und kann für die betreffende Kreatur sehr stressig sein, was einen zweiten Willenskraftwurf erfordert, um ihre ursprüngliche Persönlichkeit zu bewahren. Ein Fehlschlag betäubt das Subjekt für 1w10 Minuten, und ein Patzer führt zum Tod durch mentalen Schock. Jede Verdopplung oder Halbierung der ursprünglichen SIZ der Kreatur macht den Willenskraftwurf zur Bewahrung der Persönlichkeit um eine Stufe schwieriger, ebenso wie eine vollständige Veränderung der Umgebung, wie zum Beispiel die Verwandlung einer Person in einen Fisch. Ein erfolgreicher Wurf erlaubt es dem Opfer, seine INT und CHA sowie alle Fertigkeiten, die diese Eigenschaften erfordern, beizubehalten.

Die Verwandlung gewährt dem Empfänger die Atemform der angenommenen Kreatur, falls diese von der normalen abweicht; alle natürlichen Angriffe; und alle gewöhnlichen Bewegungsarten. Sie gewährt keine gesteigerten oder magischen Fähigkeiten der Kreatur. Zum Beispiel wird eine Kreatur, die in einen Drachen verwandelt wurde, nicht den Odemangriff oder die zauberähnlichen Fähigkeiten der Kreatur erhalten, aber sie wird die Fähigkeit zum Fliegen, ihre zähe Haut, ihren tödlichen Biss, ihre Klauenangriffe usw. erhalten. Zusätzlich erhält das Opfer die körperlichen Fertigkeiten der neuen Form wie Athletik, Kraft, Fliegen, Schwimmen sowie deren Trefferpunkte und Schadensmodifikator. Vorausgesetzt, das verwandelte Individuum hat seine INT behalten, verliert es dennoch die Fähigkeit zu sprechen, es sei denn, die neue Form besitzt die Fähigkeit, Worte zu artikulieren. Diejenigen, die in ihrer vorherigen Form Zauber wirken konnten, könnten dies auch in der neuen Form tun, vorausgesetzt, sie besitzen noch die Fähigkeit, die verbalen und somatischen Komponenten auszuführen. Im Falle einer drastischen Veränderung, wie zum Beispiel vom Zweibeiner zum Vierbeiner oder vom Landtier zum Meerestier, sollte sich der Spielleiter frei fühlen, die Nutzung jeglicher Fertigkeiten, die Zeit zum Lernen erfordern würden, während man sich an die neue Form anpasst, um mindestens eine Schwierigkeitsstufe zu bestrafen, bis genügend Zeit zum Üben vorhanden war. Dies gilt insbesondere für körperliche Fertigkeiten wie Athletik, Unbewaffneter Kampf, Schwimmen, Fliegen, Kampffertigkeiten usw.

Der Willenskraftwurf zur Bewahrung der Persönlichkeit ist jeden Tag erforderlich, den das Subjekt verwandelt bleibt, bis er fehlschlägt. Dies führt dazu, dass die Person schließlich der Mentalität der neuen Form erliegt, wobei sich INT bei einer nicht-sapienten Kreatur in INS ändert. Alle speziellen und magischen Fähigkeiten, die die neue Form besitzt und die nicht zuvor erworben wurden, wie Blickangriffe, Odemwaffen usw., stehen der Kreatur nun zur Verfügung, da die Verwandlung vollständig ist. Charaktere, die auf diese Weise ihre Identität verlieren, werden zu Nicht-Spieler-Charakteren unter der Kontrolle des Spielleiters.

Bevor die polymorphte Kreatur mental der Verwandlung erliegt, ist sie anfällig für Magie bannen wie gewohnt, wobei kein Widerstandswurf erforderlich ist, da es der unterbewusste Wunsch wäre, zum Normalzustand zurückzukehren. Die Verwandlung erfordert jedoch einen weiteren Willenskraftwurf, um der Belastung zu widerstehen, wobei ein Fehlschlag das Subjekt für 1w10 Minuten betäubt und ein Patzer zum Tod durch mentalen Schock führt.

Wenn das Opfer zuvor der neuen Form erlegen war, kann Magie bannen immer noch verwendet werden; das Opfer wird jedoch versuchen, einer Rückkehr in die natürliche Form mit einem Willenskraftwurf zu widerstehen. Ein Fehlschlag dieses Wurfs bedeutet, dass sich das Opfer in die natürliche Form zurückverwandelt, was natürlich einen weiteren Willenskraftwurf erfordert, um dem mentalen Schock durch die Verwandlung zu widerstehen. Sobald verloren, ist die natürliche Identität eines Opfers nicht mehr erreichbar; stattdessen nimmt das Opfer an, die seltsame und fremde Form sei nicht natürlich, und sehnt sich danach, in seine frühere „normale“ Form zurückverwandelt zu werden. _Beispiel: Ein Ork, der in einen Hasen verwandelt wurde und die Identität der Kreatur angenommen hat, würde glauben, dass er jetzt ein Hase ist, der ziemlich unhöflich in einen Ork verwandelt wurde._ Nur ein Wunsch oder eine andere ähnliche Magie hat eine Chance, die Identität des Opfers wiederherzustellen, sobald sie verloren ist.

Alle getragene und mitgeführte Ausrüstung verschmilzt magisch mit der neuen Form; in einigen Fällen kann der Spielleiter jedoch zulassen, dass magische Gegenstände, die auch in der neuen Form der Kreatur verwendet werden könnten, erhalten bleiben, wie ein magischer Ring oder Stiefel. Beachte, dass dies erfordert, dass die neue SIZ der Kreatur nicht wesentlich von der ursprünglichen abweicht. Es besteht eine MÄS x1%-Chance für jeden getragenen magischen Gegenstand nicht-offensiver Natur, vorbehaltlich der Zustimmung des Spielleiters, seine Effekte auf die neue Form der Kreatur zu übertragen. Eine Kreatur mit einem +1-Schutzring könnte zum Beispiel einen +1-Bonus auf ihre natürlichen Rüstungspunkte erhalten. Kreaturen mit der natürlichen Fähigkeit zur Gestaltwandlung, wie Doppelgänger und Lykantrophen, werden wie gewohnt verwandelt, können aber nach 1 Runde ihre normale Form annehmen. Wenn sie getötet wird, kehrt eine polymorphte Kreatur in ihre natürliche Form zurück, selbst wenn sie zuvor alle Spuren ihrer Identität verloren hat.

#### Polymorph (Selbst)

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Magier 3 | **Zauberzeit:** 2 Aktionen |
| **Sphäre:** Keine | **Wirkungsdauer:** 20 Minuten/Intensität |
| **Kosten:** 3, +1/zusätzliche Intensität | **Reichweite:** 0 |
| **Bereich:** Zaubernder | **Widerstand:** k. A. |

Der Zaubernde kann die Form jeder anderen körperlichen Kreatur annehmen, von SIZ 1 bis SIZ 40. Jeder Intensitätspunkt ermöglicht eine Vergrößerung oder Verkleinerung der SIZ um bis zu 10 Punkte. Daher könnte ein Magieanwender mit SIZ 13 die Gestalt eines Grizzlybären mit SIZ 34 bei 3 Intensitätsstufen annehmen. Der Verwandlungsprozess dauert eine volle Runde und gewährt dem Zaubernden die Atemform der angenommenen Kreatur (falls diese von der eigenen abweicht, z. B. unter Wasser atmen), alle natürlichen Angriffe, Trefferpunkte, Schadensmodifikator und deren normale Bewegungsart. Er gewährt keine gesteigerten oder magischen Fähigkeiten der Kreatur. Ein Magieanwender, der sich beispielsweise in einen Falken verwandelt hat, erhält nicht das außergewöhnliche Sehvermögen des Vogels. Der Zaubernde erhält die körperlichen Fertigkeiten der Kreatur wie Athletik, Kraft, Fliegen, Schwimmen usw., behält aber alle geistigen und sozialen Fertigkeiten (diejenigen, die INT und CHA erfordern). Der Zaubernde verliert die Fähigkeit zu sprechen, es sei denn, die fragliche Kreatur besitzt die Fähigkeit, Worte zu artikulieren. Wenn dies der Fall ist, kann der Zaubernde in der neuen Form immer noch Zauber wirken, vorausgesetzt, er kann die somatischen Komponenten eines Zaubers bilden.

Der Zaubernde kann den Effekt jederzeit beenden, wobei alle in der neuen Form erlittenen leichten Wunden verloren gehen und schwere Wunden auf leichte Wunden reduziert werden (halbe Trefferpunkte in jedem zutreffenden Bereich verloren). Schwere Wunden sind von der Verwandlung nicht betroffen und bleiben in der natürlichen Form bestehen. Es findet keine Heilung statt, wenn sich der Zaubernde von der natürlichen in die Tierform verwandelt.

#### Tote erwecken \(R\)

(Nekromantie)

| | |
| :-- | :-- |
| **Grad:** Kleriker 3 | **Zauberzeit:** 1 Minute |
| **Sphäre:** Nekromantisch | **Dauer:** Permanent |
| **Kosten:** 3, +1/zusätzliche Intensität, +1 EP | **Reichweite:** 100 Fuß |
| **Bereich:** 1 Ziel | **Widerstand:** KEINER (Willenskraft) |

Dieser Zauber kann auf die Leiche einer Kreatur gewirkt werden, die vor weniger als 24 Stunden pro Intensitätsgrad verstorben ist. Wenn die Gesinnung des Subjekts etwas anderes als „Böse“ war, kann sie/er dem Zauber mit einem gegnerischen Willenskraft-Wurf widerstehen und, falls erfolgreich, die Effekte des Zaubers zunichtemachen. Dies liegt daran, dass die Seele oder der Geist des Verstorbenen selten bereit ist, in das Leben zurückzukehren, sobald sie die ewige Belohnung erreicht hat. Der Spielleiter kann entscheiden, auf den Wurf zu verzichten, wenn der Empfänger unerledigte Angelegenheiten hat, nicht von seiner/ihrer wahren Liebe getrennt werden kann oder einen anderen heldenhaften Grund zum Weiterleben hat.

Im Falle böser Seelen, die gerne auf die materielle Ebene zurückkehren würden, anstatt ewige Verdammnis zu erleiden, ist es nicht die Willenskraft des Verstorbenen, die widersteht, sondern die des Dämons, Teufels und so weiter, der mit ihrer Bestrafung beauftragt wurde – ihrem Peiniger. In diesem Fall muss der Zaubernde die Willenskraft des Peinigers überwinden. Wenn diese unbekannt ist, gehe davon aus, dass sie mindestens 20 Punkte höher ist als die des Verstorbenen, um darzustellen, dass ein stärkerer Wille der Seele ein mächtigeres Wesen erfordert, das mit ihrer Verdammnis beauftragt wird. Wenn der Zaubernde erfolgreich ist, hat er/sie den Geist erfolgreich in den Körper zurückgebracht, während ein fehlgeschlagener Wurf dazu führt, dass das Opfer entweder unwillig oder unfähig ist, zurückzukehren.

Wenn das Wirken erfolgreich ist, wird das Subjekt mit vollen Trefferpunkten ins Leben zurückgeholt, obwohl abgetrennte Gliedmaßen verloren bleiben. Das bedeutet, dass ein Opfer, das enthauptet oder in zwei Hälften geschnitten wurde, nicht wiederbelebt werden kann, bevor Kopf oder Torso nicht wieder befestigt wurden. Dies kann vor dem Wirken von Tote erwecken durch physisches Wiederanbringen der abgetrennten Stelle erfolgen, was ein Heiler-Kit und eine erfolgreiche Anwendung der Heilkunde-Fertigkeit erfordert und typischerweise eine deutliche und verräterische Narbe hinterlässt. Andere Leiden, wie Gift oder Krankheit, müssen vor oder nach dem Wirken von Tote erwecken behandelt werden, da die Ergebnisse sonst nur vorübergehend sind. Schließlich hat Tote erwecken keine Wirkung auf eine Kreatur, die das Ende ihrer natürlichen Lebensspanne erreicht hat und eines natürlichen Todes gestorben ist.

Der Akt, von den Toten auferweckt zu werden, ist für das Subjekt sehr belastend, welches für 24 Stunden für jeden Tag, den es tot war, auf den Erschöpfungsgrad „Handlungsunfähig“ reduziert wird. Das Wirken von Erschöpfung heilen hat während dieser Zeit der Genesung keine Wirkung auf den Patienten. Nach diesem Zeitpunkt erholt sich der Charakter normal und ohne Einschränkung von der Erschöpfung.

Wenn umgekehrt, kann Lebende töten verwendet werden, um ein vom Kleriker zum Zeitpunkt des Wirkens bestimmtes Opfer zu töten. Dieses Opfer darf einen Willenskraft-Wurf ablegen, um zu widerstehen, modifiziert durch den Grad oder die SIZ des Ziels, je nachdem, was dem Ziel das vorteilhaftere Ergebnis liefert, wie in der folgenden Tabelle detailliert.

| 2 | 21-40 | Standard |
| 3 | 41-60 | Einfach |
| 4-5 | 61+ | Sehr einfach |

_\* Diese Kategorie umfasst Charaktere, die keine Klasse besitzen._

Wenn der Widerstandswurf erfolglos ist, wird das Opfer sofort getötet. Ein erfolgreicher Wurf wird gemäß den Effekten von Schwere Wunden verursachen behandelt. Rüstung bietet keinen Schutz gegen diesen Schaden.

#### Auferstehung (R)

(Nekromantie)

| | |
| :-- | :-- |
| **Rang:** Kleriker 5 | **Zauberzeit:** 10 Minuten |
| **Sphäre:** Nekromantisch | **Dauer:** Permanent |
| **Kosten:** 3, +1/zusätzliche Intensität, +2 ERW | **Reichweite:** Berührung |
| **Bereich:** 1 Ziel | **Widerstand:** k. A. (Willenskraft) |

*Auferstehung* belebt jede Kreatur wieder, die nicht länger als 20 Jahre pro Intensitätsstufe tot ist. Die Kreatur erhält nicht nur das Leben zurück, sondern wird auch zu voller Stärke gebracht und von Verletzungen geheilt; sogar verlorene Gliedmaßen werden wiederhergestellt. Es ist nur ein kleiner Teil der tatsächlichen Kreatur nötig, damit der Zauber wirksam ist. Zum Beispiel könnte *Auferstehung* genutzt werden, um ein Wesen nach 145 Jahren wieder zum Leben zu erwecken, selbst wenn man nur einen Fingerknochen besitzt, vorausgesetzt, der Zauber wird mit Intensität 8 gewirkt. Das wiederbelebte Individuum benötigt keine Ruhephase und ist sofort voll funktionsfähig. Der Zauber hat keine Wirkung auf eine Kreatur, die am Ende ihrer zugewiesenen Lebensspanne eines natürlichen Todes gestorben ist.

Wenn die Gesinnung des Subjekts nicht böse war, kann es dem Zauber mit einem *Widerstandswurf auf Willenskraft* widerstehen und die Wirkungen bei Erfolg annullieren. Dies liegt daran, dass die Seele oder der Geist des Verstorbenen selten bereit ist, zu den Lebenden zurückzukehren, sobald er seine ewige Belohnung erreicht hat. Der Spielleiter kann jedoch entscheiden, auf den Wurf zu verzichten, wenn der Empfänger unerledigte Dinge hat, nicht von seiner wahren Liebe getrennt sein kann oder einen anderen heldenhaften Grund zum Weiterleben hat. Im Fall böser Seelen, die lieber zurückkehren würden, anstatt ewige Verdammnis zu erleiden, ist es nicht die Willenskraft des Verstorbenen, die widersteht, sondern die des Dämons, Teufels oder ähnlichen Wesens, das für seine Bestrafung zuständig ist – sein Peiniger. In diesem Fall muss der Zaubernde die Willenskraft des Peinigers überwinden. Wenn diese unbekannt ist, gehe davon aus, dass sie mindestens 20 Punkte höher ist als die des Verstorbenen, um darzustellen, dass je stärker der Wille der Seele ist, desto mächtiger das Wesen ist, das für seine Verdammnis zuständig ist. Wenn der Zaubernde Erfolg hat, wurde das Subjekt erfolgreich wiederbelebt; ein gescheiterter Wurf führt dazu, dass das Opfer entweder nicht gewillt oder nicht in der Lage ist, zurückzukehren.

*Auferstehung* zehrt sehr an den Kräften und lässt den Kleriker um 3 % seiner typischen Lebensspanne altern (3 Jahre bei einem menschlichen Zaubernden). Siehe die Regeln für [Altern](0007_Game_System.md?id=aging).

Wenn umgekehrt gewirkt, kann *Zerstörung* dazu verwendet werden, ein Opfer zu töten, das sich zum Zeitpunkt der Wirkung in Kontakt mit dem Kleriker befindet. Dieses Opfer darf einen Willenskraft-Widerstandswurf ablegen, modifiziert durch den Rang oder die GRÖ des Ziels (je nachdem, was für das Opfer das vorteilhaftere Ergebnis liefert), wie in der folgenden Tabelle aufgeführt.

| Ziel-Rang | Ziel-GRÖ | Willenskraft-Modifikator |
| :-: | :-: | :-- |
| 0-1* | 1-20 | Beeindruckend |
| 2 | 21-40 | Schwer |
| 3 | 41-60 | Standard |
| 4 | 61-80 | Leicht |
| 5 | 81+ | Sehr leicht |

*\* Diese Kategorie umfasst Charaktere, die keine Klasse besitzen.*

Wenn dieser Widerstandswurf misslingt, wird das Subjekt auf der Stelle getötet und sein Körper zu Staub zerfallen. Nur das Wirken eines *Wunsches* bringt das Opfer in diesem Stadium zurück. Bei einem erfolgreichen Wurf wird das Subjekt immer noch auf negative 1d4 Trefferpunkte an der berührten Trefferzone reduziert. Rüstung bietet gegen diesen Schaden keinen Schutz. *Zerstörung* lässt den Zaubernden bei Anwendung nicht altern.

Stattdessen werden die Toxine, die sich im Körper ausbreiten, so weit verlangsamt, dass hoffentlich zusätzliche heilende Maßnahmen gefunden werden können. Die Einsetzzeit eines Toxins tritt erst ein, nachdem die Dauer des Zaubers abgelaufen ist.

Zum Beispiel hat Kobr Gift eine Einsetzzeit wie folgt: Qualen nach 1d6+4 Minuten und Asphyxie nach 1d6+6 Stunden. Eine einzige Intensität von *Gift verlangsamen* schiebt die Einsetzzeit daher um 1 Stunde hinaus, wonach 1d6+4 Minuten später die Qualen wie normal einsetzen.

Als letztes Mittel gilt: Wenn der Zaubernde innerhalb von 10 Minuten zu einer Person gelangen kann, die an einer Vergiftung "gestorben" ist, verzögert *Gift verlangsamen* den Tod eines Opfers um 1 Stunde pro Intensität, während derer das Opfer im Koma bleibt. Wunsch kann die Realität auf eine dauerhafte und bedeutende Weise verändern. Um diesen Zauber zu wirken, muss der Magiekundige 3 Magiepunkte und 1 oder mehr EP-Würfe ausgeben, abhängig von den gewünschten Ergebnissen. Jedes aufeinanderfolgende Wirken von Wunsch innerhalb eines Zeitraums von 1 Monat verdoppelt den normalerweise erforderlichen EP-Aufwand. Die Zauberzeit wird typischerweise benötigt, um die Einzelheiten des Wunsches verbal darzulegen. Nach Abschluss erleidet der Zaubernde einen Verlust an Erschöpfung in Höhe der ausgegebenen EP und altert um 5% seiner normalen Lebenserwartung (für Menschen wären das fünf Jahre). Die Ergebnisse eines Wunsches sollten wörtlich genommen werden und sind offen für die Interpretation durch den Spielleiter. Gierige Wünsche enden typischerweise schlecht. Es besteht eine Chance von 10%, dass ein aus gierigen Motiven geäußerter Wunsch auf irgendeine Weise nach hinten losgeht. Zum Beispiel könnte das Wünschen von Reichtum diesen aus den Schatzkammern des lokalen Fürsten oder Königs herbeiteleportieren. Ein Wunsch kann keine Dekrete gottgleicher Wesen aufheben, es sei denn, ein solches Wesen hat besagten Wunsch selbst ausgesprochen.

#### Magierblick

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Magier 3 | **Zauberzeit:** 1 Minute |
| **Sphäre:** Keine | **Dauer:** 1 Minute/Intensität |
| **Kosten:** 1/Intensität | **Reichweite:** 0 |
| **Bereich:** Siehe unten | **Widerstand:** KA |

Dieser Zauber erschafft ein kleines unsichtbares 'Auge', durch das der Magiekundige für die Dauer des Zaubers sehen kann. Dieses Auge kann vor der Gruppe her bewegt oder ausgesandt werden, um um Ecken und in Räume zu blicken, mit einer Bewegungsrate von 20 Fuß pro Runde (240 Fuß pro Minute), wenn nur nach 'offensichtlichen' Bedrohungen oder interessanten Gegenständen gescannt wird. Dies erstreckt sich typischerweise nur auf den Boden und die unteren Wände. Wenn versucht wird, gründlicher vorzugehen (auch die vollständigen Wände und die Decke zu untersuchen), reduziert sich die Bewegungsrate auf 10 Fuß pro Runde (120 Fuß pro Minute). Der Spielleiter sollte sich frei fühlen, Wahrnehmungswürfe auf Seiten des Zaubernden zuzulassen, wo dies notwendig ist, um visuelle Anomalien zu entdecken. Das Auge ist körperlich, unfähig, durch feste Materie zu dringen, und besitzt normale Sicht bis zu 60 Fuß und Infrasicht bis zu 10 Fuß. Der Zaubernde muss während der gesamten Dauer die Konzentration auf das Auge aufrechterhalten, sonst bleibt es träge, bis die Konzentration wieder hergestellt ist. Jegliche Blickangriffe, die normalerweise den Zaubernden betreffen würden, betreffen den Zaubernden weiterhin wie gewohnt; das Auge wird jedoch in Bezug auf Blindheit, Dunkelheitszauber und so weiter als unabhängig vom Zaubernden betrachtet. Um durch kleine Öffnungen zu passen, ist das Auge nicht größer als 1 Zoll und hat eine SIZ von 1.

#### Wort der Rückkehr

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Kleriker 4 | **Zauberzeit:** 1 Aktion |
| **Sphäre:** Beschwörung | **Dauer:** Siehe unten |
| **Kosten:** 3, +1/zusätzliche Intensität | **Reichweite:** 0 |
| **Bereich:** Der Zaubernde | **Widerstand:** KA |

Wenn dieser Zauber gewirkt wird, wird der Kleriker sofort zu einem zuvor bestimmten Zufluchtsort und einem festgelegten Ankunftspunkt von nicht mehr als 10 Fuß Radius teleportiert. Es gibt keine Begrenzung der tatsächlichen Teleportationsreichweite, einschließlich zwischen mehreren Ebenen. Innerhalb einer einzigen Ebene gibt es keine Chance auf ein Missgeschick; das Überqueren auch nur einer Ebene gibt jedoch eine Patzerchance von 91-00%, zwei Ebenen geben einen Patzer bei einem Wurf von 81-00%, und so weiter. Dies ersetzt die normale Patzerchance des Zaubernden. Ein Patzer beim Überqueren von Ebenen bedeutet, dass der Kleriker unwiderruflich verloren ist. Patzer innerhalb einer einzigen Ebene folgen den normalen Regeln.

Zusätzlich zu sich selbst und jeglicher mitgeführter Ausrüstung kann der Kleriker weitere 3 Gegenstände pro Intensität transportieren, wobei jeder nicht größer als SIZ/9 'Dinge' ist. Das zusätzlich transportierte Material kann Schatz, Ausrüstung oder lebende Wesen sein. Transportierte Kreaturen müssen jedoch den Zauber auf einer ausreichenden Intensitätsstufe gewirkt haben, um jegliche mitgeführte Ausrüstung abzudecken.
