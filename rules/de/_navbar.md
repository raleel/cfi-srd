### Charakterinformationen

| Feld | Beschreibung |
| :--- | :--- |
| Name | Der Name des Charakters. |
| Spezies/Kultur | Die Spezies und der kulturelle Hintergrund des Charakters. |
| Alter | Das Alter des Charakters. |
| Geschlecht | Das Geschlecht des Charakters. |
| Heimat | Der Ort der Herkunft des Charakters. |
| Gottheit | Die Gottheit, der der Charakter folgt. |
| Aktuelle Stufe | Die Erfahrung des Charakters. |
| Körpergröße | Die physische Größe. |
