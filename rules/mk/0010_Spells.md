#### Проценка (Appraise)

(Гатање/Divination)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 0 | **Време на фрлање:** 1 потег |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 1 | **Домет:** Допир |
| **Област:** 1 предмет | **Отпор:** Никаков |

Проценка овозможува итна оцена на квалитетот на материјалните добра со комбиниран ENC во „Нешта“ или SIZ еднаков на моќта (POW) на магионичарот. Магијата утврдува дали идентично изгледни предмети се со ист или сличен квалитет, или дали еден или повеќе се со маана или со повисок квалитет. Магијата не функционира на органски нешта, само на неживи предмети. Исто така не утврдува какви маани или подобрувања се присутни; само дека постојат. Не е од корист при идентификување или откривање на магија.

#### Оклоп (Armor)

(Призивање/Conjuration)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 рунда |
| **Сфера:** Ниедна | **Времетраење:** Види подолу |
| **Цена:** 3 +1/интензитет | **Домет:** Допир |
| **Област:** 1 цел | **Отпор:** Никаков |

Кога ќе се фрли оваа магија, на целта ѝ се подарува невидливо поле на магична сила еднакво на заштитата на лушпест оклоп, давајќи 4 оклопни поени на секоја погодена локација. Нема ефект ако се фрли на некој што веќе носи оклоп. Сепак, ќе го надмине природниот оклоп во текот на неговото траење, под претпоставка дека нуди супериорна заштита. Ако се фрли на суштество кое поседува повеќе од 4 поени природен оклоп, наместо тоа ќе ги зголеми оклопните поени за 1 на сите локации. Оваа магична заштита не го попречува движењето или фрлањето магии. Магијата ќе опстои додека не се растера со магија или додека фрлачот не претрпи 8 поени штета од еден напад, +1 за секое ниво на дополнителен Интензитет (види ја табелата подолу). Се разбира, фрлачот може да избере да ја прекине магијата во секое време доколку сака, а мора да го направи тоа за да спие.

| Интензитет | Цена | Варијабилен ефект |
| :-: | :-: | :-- |
| 1 | 3 | 4 оклопни поени; се одржува до примање 8 штета од 1 напад |
| 2 | 4 | 4 оклопни поени; се одржува до примање 9 штета од 1 напад |
| 3 | 5 | 4 оклопни поени; се одржува до примање 10 штета од 1 напад |
| 4 | 6 | 4 оклопни поени; се одржува до примање 11 штета од 1 напад |
| +1 | +1 | Продолжува прогресијата |

#### Астрална магија (Astral Spell)

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 5, Волшебник 5 | **Време на фрлање:** 2 акции |
| **Сфера:** Астрална | **Времетраење:** Види подолу |
| **Цена:** 3 +1/дополнителен интензитет | **Домет:** Допир |
| **Област:** Види подолу | **Отпор:** Не е применливо |

Оваа магија им овозможува на фрлачот и на уште пет други лица (едно по дополнително ниво на Интензитет) да влезат во Астралната рамнина. Сите мора да се допираат и да формираат круг додека се фрла магијата. Телата на патниците остануваат зад себе во рамнината на потекло и тие обично не носат со себе никаква облека или опрема, освен она што само по себе зрачи со магична аура; овие предмети се трансформираат во астрални еквиваленти на нивната нормална форма. Времетраењето трае додека фрлачот не посака да престане. Сепак, можно е да биде прекинато предвреме од надворешна сила како што е Dispel Magic (Растерување на магија). Убивањето на физичкото тело на фрлачот, исто така, ја прекинува магијата порано, иако ова има несреќен несакан ефект на заглавување на сите патници што го придружуваат фрлачот.

#### Пророштво (Augury)

(Гатање/Divination)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 2 | **Време на фрлање:** 2 минути |
| **Сфера:** Гатање | **Времетраење:** Инстантно |
| **Цена:** 3/Интензитет | **Домет:** 60 стапки |
| **Област:** Фрлач | **Отпор:** Не е применливо |

Оваа магија му овозможува на фрлачот да утврди дали одредена акција што треба да се преземе во следните 30 минути ќе биде корисна или штетна за добросостојбата на поединецот и/или групата. Потребна е фокусна точка од некој вид за да се согледаат знаците, при што најчести се канџите или помалите коски на змеј, бисер или чисто злато во вредност од најмалку 100 златици, што е згмечено или стопено. Магијата има максимален интензитет од 4. Ова фрлање на коцка треба да го направи Господарот на играта (Games Master), бидејќи фрлачот никогаш не треба да знае без сенка на сомнеж дали резултатите се правилно протолкувани.

| Интензитет | Цена | Варијабилен ефект |
| :-: | :-: | :-- |
| 1 | 3 | Формидабилно фрлање на вештина за канал |
| 2 | 6 | Тешко фрлање на вештина за канал |
| 3 | 9 | Стандардно фрлање на вештина за канал |
| 4 | 12 | Лесно фрлање на вештина за канал |

Ако фрлањето за гатање успее, тоа дава еден од следниве резултати:

| Пророштво | Импликација | 
| :-: | :-- |
| Да | Акцијата ќе биде корисна |
| Не | Акцијата ќе биде штетна |
| Да и Не | Акцијата ќе биде и корисна и штетна |
| Ништо | Акцијата нема да биде ниту корисна ниту штетна |

Погрешен потег (Fumble) треба да резултира со тоа што Господарот на играта ќе ја каже спротивноста на реалноста.

(Абјурација/Abjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 0, Волшебник 0 | **Време на фрлање:** Инстантно |
| **Сфера:** Заштита | **Времетраење:** Инстантно |

Avert се користи за отфрлање на друга магија од ранг 0 во домет. Avert може да се фрли реактивно за да се неутрализираат офанзивни магии од ранг 0, со користење на реактивната акција Counter Magic (Контра магија).

#### Збунување (Befuddle)

(Омајување/Enchantment (Charm))

| | |
| :-- | :-- |
| **Ранг:** Свештеник 0, Волшебник 0 | **Време на фрлање:** 1 потег |
| **Сфера:** Омајување | **Времетраење:** 30 минути |
| **Цена:** 1 | **Домет:** 60 стапки |
| **Област:** 1 цел | **Отпор:** Сила на волја |

Befuddle предизвикува конфузија во умот на телесна цел. Субјектот на магијата има тешкотии да размислува право, заборавајќи каде е, што прави и зошто – често запаѓајќи во десоцијализирани линии на размислување. Збунетите цели сè уште можат да дејствуваат во самоодбрана, но не можат да започнат никаква конструктивна активност додека не заврши магијата. Каков било напад или заканувачка акција моментално ја прекинува магијата, без разлика дали била насочена конкретно кон збунетата цел или не.

#### Бариера од сечила (Blade Barrier)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 4 | **Време на фрлање:** 2 акции |
| **Сфера:** Чувар, Креирање | **Времетраење:** 3 рунди/интензитет |
| **Цена:** 3+1/дополнителен интензитет | **Домет:** 100 стапки |
| **Област:** Радиус од 5-30 стапки | **Отпор:** Види подолу |

Оваа магија создава бариера од вртливи мечеви, ками и ножеви кои камшикуваат и сечат околу фиксна точка и предизвикуваат 1d8 поени штета на 1d4+2 случајни погодени локации на _секој_ што минува низ областа на ефект. Оклопот нуди само половина од својата нормална заштита. Магичните оклопни поени ја намалуваат штетата како и обично. Бидејќи оружјето се врти со заслепувачка брзина и е цврсто спакувано, невозможно е да се избегнат (Parry или Evade). Човек може да користи штит за пасивно блокирање на погодените локации нормално. Во овој случај, не заборавајте да ја споредите истрланата штета со оклопот и погодените поени на штитот.

Магијата може да се фрли дефанзивно за да се заштити свештеникот или еден или повеќе сојузници, или офанзивно за да се заробат непријателите. Сепак, опколените непријатели во рок од пет стапки од работ на бариерата додека таа се формира, можат да направат фрлање за избегнување (Evade) за да побегнат. Без оглед на успехот, противникот завршува легнат (prone), веднаш надвор од областа на ефект. Успешното фрлање резултира со нула штета; во спротивно, тие ја трпат целата штета.

#### Благослов (Bless \(R\))

(Призивање/Conjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 1 | **Време на фрлање:** 1 рунда |
| **Сфера:** Сите | **Времетраење:** 5 минути |
| **Цена:** 1 | **Домет:** 180 стапки |
| **Област:** Радиус од 25 стапки | **Отпор:** Сила на волја |

Кога ќе се фрли оваа магија, свештеникот благословува група сојузници во областа на ефект. Оние што се погодени зрачат со усогласувањето на фрлачот, или Добро или Зло. Не постојат благослови за Неутралност. Сите сојузници во радиусот на магијата добиваат бонус од +5% на сите вештини и фрлања за отпор. Покрај тоа, нивното оружје предизвикува +1d3 штета на интелигентните немртовци, како и на суштествата од надворешните рамнини кои имаат спротивни усогласувања од оној на фрлачот, како што се демони, ѓаволи или ангели. Забележете дека иако анимираните немртовци како скелети и зомби не се инхерентно зли, тие обично се анимирани со зла магија и затоа подлежат на оваа штета.

Спротивната магија, Проклетство (Curse), му овозможува на свештеникот да ги проколне непријателите, правејќи наведените вештини да трпат инверзија на придобивките споменати погоре. Штетата на проколнатото оружје се пресметува како казна, и оваа штета не може да резултира со помалку од 1 поен.

#### Горечки раце (Burning Hands)

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 3+1/дополнителен интензитет | **Домет:** 0 |
| **Област:** Конус од 120 степени, 5 стапки долг | **Отпор:** Избегнување (Evade) |

Оваа магија предизвикува пламен да пука од рацете на фрлачот во лак од 120 степени. Ако користите минијатури во борба, Burning Hands ќе оштети секоја цел што зазема 1 од предните полиња на фрлачот. Фрлањето Burning Hands на повисоки нивоа на Интензитет бара волшебник од повисок ранг. Оваа штета ги зафаќа сите цели во областа со штета базирана на Интензитетот на магијата, до максимален интензитет од 9, на следниов начин. Успешното фрлање за избегнување, со фрлање на себе легнат, му овозможува на жртвата да не претрпи никаква штета. Некој со способноста Вешт додворувач (Artful Dodger) има опција да избегне без да легне.

| Интензитет | Цена | Мин. ранг | Варијабилен ефект |
| :-: | :-: | :-- | :-: | :-- |

| 3 | 4 | 1 | 1d3+2 поени штета на сите локации |
| 5 | 5 | 1 | 1d3+3 поени штета на сите локации |
| 7 | 6 | 2 | 1d3+4 поени штета на сите локации |
| 9 | 7 | 3 | 1d3+5 поени штета на сите локации |

Носениот оклоп не штити, но магичните оклопни поени или природниот оклоп на суштеството ја намалуваат штетата како и обично. Оваа моќна магија е балансирана со нејзиниот забележливо краток домет, што значи дека за да ја фрли, магионичарот мора да биде доволно блиску за да биде во многу неповолна положба.

Бидејќи поголемите суштества се обично поголеми од областа на ефект на магијата, тие ќе имаат помалку погодени локации. Оние со SIZ 21 до 30 ја примаат штетата на главата, градите, стомакот и рацете, додека оние со SIZ 31+ ќе ја примаат штетата на стомакот и нозете. Господарите на играта треба да ги прилагодат овие локации во зависност од обликот и положбата на целта во однос на фрлачот. Burning Hands има шанса да запали запаливи материјали еднаква на истрланата штета x5%. Погледнете го делот за [Пожари](0007_Game_System.md?id=fire-based-attacks) за дополнителни информации.

#### Верижна молња (Chain Lightning)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 4 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 3+1/дополнителен интензитет | **Домет:** 50 стапки/интензитет |
| **Област:** Види подолу | **Отпор:** Избегнување (Evade) |

По фрлањето, магионичарот ослободува сноп на електрична енергија широк пет стапки од врвовите на прстите што може да погоди една цел во домет за 1d6+1 поени штета на секои 2 Интензитети. Снопот потоа се лачи кон следниот најблизок предмет или суштество, кое ја зема претходно истрланата штета минус 1 поен, а потоа се лачи кон следниот најблизок, нанесувајќи ја истрланата штета минус 2 поени, и така натаму. Може дури и да се лачи назад кон сојузник или фрлачот! Додека почетната цел мора да биде видлива за фрлачот, целите погодени од лачен сноп не мора да бидат.

Секој лак има свој домет од 50 стапки, што може да го постави снопот надвор од оригиналниот домет кога се фрла магијата. Chain Lightning продолжува да удира ако има преостаната штета сè додека не удри во предмет што предизвикува заземјување (метален кафез или решетки, голем базен со вода и слично) или повеќе нема предмети или суштества за удирање.

Секое погодено суштество ја прима штетата на една погодена локација, при што носениот оклоп не нуди заштита, а природниот оклоп и магичните оклопни поени ја намалуваат штетата како и обично.

Со успешно фрлање за избегнување, со фрлање на себе легнат, жртвата не претрпува никаква штета. Некој со способноста Вешт додворувач може да избегне без да легне, но успехот во овој случај само ја намалува штетата за половина.

Молњата има шанса да запали запаливи материјали еднаква на истрланата штета x1%. Погледнете го делот за [Пожари](0007_Game_System.md?id=fire-based-attacks) за дополнителни информации. Молњата исто така може да скрши или уништи неживи предмети од чисто удар.

| 1 | 3 | 50-ст домет; 1d6+1 штета |
| 2 | 4 | 100-ст домет; 1d6+1 штета |
| 3 | 5 | 150-ст домет; 2d6+2 штета |
| 4 | 6 | 200-ст домет; 2d6+2 штета |
| 5 | 7 | 250-ст домет; 3d6+3 штета |

#### Промена на изглед (Change Appearance)

(Илузија/Illusion)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** 2d6 минути/интензитет |
| **Цена:** 1/интензитет | **Домет:** 0 |
| **Област:** Фрлач | **Отпор:** Не е применливо |

Оваа магија го менува изгледот на фрлачот во форма на кој било хуманоид или бипедална форма во форма на личност. Промената на висината и тежината е ограничена на ±5 SIZ, соодветно, но во тој опсег, фрлачот може да избере да стане дебел или слаб, висок или низок, па дури и да го промени полот. Косата, облеката и опремата може да се сменат заедно со изгледот. Цртите на лицето на фрлачот може да се сменат по желба, дури и до степен на совршено имитирање на друга постоечка личност. Магијата не го менува мирисот на фрлачот, а ако се допре, фрлачот сè уште се чувствува исто како оригиналната форма и облека.

#### Пој (Chant)

(Призивање/Conjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 2 | **Време на фрлање:** 2 акции |
| **Сфера:** Борба | **Времетраење:** Концентрација |
| **Цена:** 1 | **Домет:** 0 |

Сите оние во областа на ефект добиваат бонус од +5% на сите фрлања за вештини и +1 бонус на штета, секој по ниво на Интензитет. Непријателите во истата област трпат инверзија на придобивките споменати погоре.

Ефектите од Chant се собираат со оние од Bless и Curse. Поради барањето за појување во текот на целото времетраење, фрлањето други магии е невозможно.

#### Омајување личност (Charm Person)

(Омајување/Enchantment (Charm))

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** 1 недела/интензитет |
| **Цена:** 3+1/дополнителен интензитет | **Домет:** 360 стапки |
| **Област:** 1 жив човек, деми-хуманоид или хуманоид | **Отпор:** Сила на волја |

Кога ќе се фрли оваа магија, една жива (немртвите суштества се незасегнати) разумна хуманоидна цел со SIZ 1-20 ќе прекине секакво непријателство кон магионичарот и сојузниците на магионичарот, и наместо тоа ќе понуди помош и заштита ако целта не успее во фрлањето за отпор. Забележете дека помагањето/заштитата може да има несакан или дури негативен ефект за фрлачот, бидејќи субјектот постапува врз основа на она што смета дека е најдобар начин за заштита/помош. Што се однесува до наредбите, целта никогаш нема да се покорува на самоубиствени или очигледно штетни акции, но може да биде убедена дека нешто крајно опасно вреди да се направи.

Секое непријателско дејство против субјектот на мајата од страна на магионичарот или сојузниците ја прекинува магијата. Забелешка: Ако други ја оспорат природата на омајувањето, целта може исто така да направи фрлање за отпор, по дискреција на Господарот на играта. Магионичарот мора да може да зборува со омаениот за да му даде каков било вид сложено „барање“; затоа, познавањето на јазикот на целта може да биде важно, но не е потребно за основната магија.

По почетното фрлање за отпор, мора да помине 1 недела пред субјектот да може повторно да направи фрлање за отпор. Ефектите се во тек додека не се направи успешно фрлање за отпор. Фрлањето Charm Person на повисоки нивоа на Интензитет бара волшебник од повисок ранг и има максимално времетраење од 4 недели. Во текот на времетраењето на магијата, вкупниот број на магични поени на фрлачот се намалува за бројот потрошен за фрлање на магијата, според правилата за [трајни магични трошоци](0009_Magic.md?id=enduring-magic-costs).

| :-: | :-: | :-- | :-: | :-- |
| 1 | 3 | 1 | Омаен за 1 недела |
| 2 | 4 | 2 | Омаен за 2 недели |
| 3 | 5 | 3 | Омаен за 3 недели |
| 4 | 6 | 4 | Омаен за 4 недели |

Кога ќе се фрли оваа магија, свештеникот може да изговори команда со еден збор до едно живо суштество со SIZ 1-20, и на следниот потег на субјектот, командата ќе биде следена до буква ако не успее да се спротивстави. Ова во суштина предизвикува жртвата да го пропушти следниот потег завршувајќи ја командата и троши акциона точка додека ја извршува. Ако жртвата нема повеќе акциони поени, командната акција ќе се изврши за време на нивниот прв потег од следната рунда. Самата команда не може да предизвика никаква реална повреда на целта; сепак, повредата може да дојде како секундарен ефект од командата.

На пример, командата за умирање би резултирала со тоа жртвата да се сруши во состојба слична на смрт за 1 рунда предизвикувајќи никаква реална повреда; сепак, командата за паѓање дадена на суштество што се качува по 100-стапка висока карпа може да биде повеќе од смртоносна.

Субјектот на командата мора да може да го разбере јазикот што го зборува фрлачот и му е дозволен тест за сила на волја за отпор.

**Некои примери на команди**

- **Crawl (Ползи):** Субјектот паѓа на стомак и почнува да ползи.
- **Die (Умри):** Субјектот паѓа на стомак влегувајќи во коматозна состојба слична на смрт.
- **Fall (Падни):** Субјектот паѓа на стомак.
- **Fumble (Збуни се):** Субјектот ја збунува физичката акција што треба да се преземе.
- **Sleep (Спиј):** Субјектот заспива.
- **Flee (Бегај):** Субјектот се врти и бега од фрлачот.
- **Fly (Летај):** Субјектот мафта со рацете и трча во кругови.
- **Go (Оди):** Субјектот почнува да оди во правецот кон кој бил свртен.
- **Halt (Запри):** Субјектот веднаш застанува и стои на место.
- **Leave (Замини):** Субјектот се врти и заминува по патот по кој влегол.
- **Rest (Одмори се):** Субјектот паѓа во седечка положба и си го доаѓа здивот.
- **Run (Трчај):** Субјектот почнува да трча.
- **Scream (Вришти):** Субјектот вика.
- **Sink (Потони):** Субјектот престанува да плива.
- **Surrender (Предај се):** Субјектот го фрла оружјето и ги прекинува непријателствата.

Нема ефект врз отсечен екстремитет, што бара или Heal, ако екстремитетот е сè уште присутен, или Regeneration за да се врати. Под претпоставка дека примачот е сè уште жив и локацијата била ранета во рок од неколку часа еднакви на Интензитетот на магијата, тогаш Cure Major Wounds лекува 1d8+4 штета речиси веднаш.

Ако повредата се случила порано, тогаш делот од телото мора да помине низ потрауматична поправка, што бара едно фрлање на Cure Major Wounds и број на денови на целосен одмор и закрепнување еднаков на стапката на закрепнување (Healing Rate) на ликот. Истрланите погодени поени се усреднуваат и се враќаат во текот на наведениот период на закрепнување. Ако овој период на закрепнување се прекине пред да заврши лекувањето, локацијата останува осакатена и неупотреблива, способна да се излечи само со магијата Heal.

Кога се превртува, Cause Major Wounds може да се користи за да се намали една погодена локација за 1d8+4 погодени поени. Фрлањето на вештината Канал на фрлачот функционира како фрлање за погодување на противникот и се претпоставува дека е дел од соматското барање на магијата. Не е потребно дополнително фрлање за погодување. Оваа магија не може да ја отсече локацијата, но може да ја згмечи или осакати нормално. Ниту носениот ниту природниот оклоп не нудат никаква заштита, но магичните оклопни поени ја намалуваат штетата како и обично.

#### Магија на смртта (Death Spell)

(Некромантија/Necromancy)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 4 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |

Успешното фрлање на оваа магија убива варијабилен број суштества со SIZ 40 или помалку во областа на ефект. Волшебникот фрла 1d6 за секое ниво на Интензитет за да го одреди бројот на засегнати суштества. Каде суштествата од различни SIZ категории ја окупираат областа на ефект, суштествата со големина на човек (SIZ 1-20) секогаш се засегнати пред поголемите. | Интензитет | Цена | Варијабилен ефект |
| :-: | :-: | :-- |

| 3 | 5 +2 EXP | 90 ст домет; 3d6 засегнати суштества |

Фрлањето на магијата со доволен Интензитет за да се изедначи или надмине бројот на потенцијални цели е пожелно, бидејќи недоволни поени се губат. Оваа магија нема ефект врз ликантропи, немртовци или други планарни суштества. Само Wish (Желба) може да ги врати оние што се засегнати од оваа магија од мртвите.

_Пример: Ренгарт ја фрла магијата на смртта во област окупирана од четири SIZ 16 орки и два SIZ 32 ридски џинови, избирајќи Интензитет од 3. Три од четирите орки не успеваат во своето фрлање за отпор и подлегнуваат на смртта. Бидејќи секој орк е еднаков на 1 поен, остануваат 8 поени. Ова е доволно за да се погоди еден ридски џин за 5 поени, при што преостанатите 3 поени се губат. Сепак, лутиот ридски џин нема проблем да успее во своето лесно фрлање за отпор и напаѓа кон Ренгарт._

#### Волшебен предмет (Enchant Item)

(Омајување/Enchantment)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 4 | **Време на фрлање:** Види подолу |
| **Сфера:** Ниедна | **Времетраење:** Види подолу |
| **Цена:** 3 + Види подолу | **Домет:** Допир |
| **Област:** 1 предмет | **Отпор:** Не е применливо |

Фрлањето на оваа магија го подготвува предметот за Омајување. Предметот мора да биде во добра состојба и со најфина изработка. Потребна е дополнителна цена од најмалку 100 златици за да се покрие трошокот за дополнително алати, резбарење, вез, накит, гравирање итн. Конечно, процесот на Омајување бара лабораторија или работилница.

Додека ја фрла магијата, магионичарот мора да го допира предметот во текот на целото време на фрлање од 1d8+2 дена. Ова ги вклучува периодите на одмор и спиење, при што предметот мора да остане на дофат на раката од фрлачот. Во ниту еден момент во текот на фрлањето, магионичарот не смее да фрли друга магија или да изврши каква било друга форма на магија. Кршењето на кој било од овие строги правила автоматски ќе предизвика неуспех на магијата.

Откако успешно ќе се фрли, предметот е подготвен за последниот чекор, при што фрлачот ја става посакуваната магија во него. За да го направи тоа, тие мора да ја имаат магијата во меморија или на свиток и да ја фрлат во предметот во рок од 24 часа, или целиот процес ќе треба да се започне одново од почеток. Откако ќе започне фрлањето на избраната магија, процесот може да ги надмине гореспоменатите 24 часа. Внесувањето на избраната магија во предметот чини нормален број на магични поени за посакуваниот Интензитет и одзема 1d12 часа по ранг на магија. Во текот на процесот на внесување, фрлачот мора да остане во допир со предметот или да остане на дофат на раката за време на периодите на одмор, како погоре, и потребно е Арканско фрлање (Arcane Casting) на крајот на периодот на фрлање за успешно да се внесе магијата. Се следат нормалните степени на успех на фрлање магија, меѓутоа, во однос на резултат на неуспех, магијата не може да се присили. Успешните магии можат да се внесат во предметот, обезбедувајќи процесот на фрлање да започне во рок од 24 часа од завршувањето на претходната магија. Ова важи дури и во случај на претходно неуспешна магија. Секоја последователна магија бара нормална цена за фрлање.

При користење на предметот, секоја содржана магија може да се фрли само еднаш, меѓутоа повеќе верзии од истата магија може да се внесат следејќи ја гореспоменатата процедура. Исто така е можно да се внесе една магија, проследена со фрлање на магијата од 4. ранг Permanency (Трајност). Во овој случај, магијата може да се фрла колку што е посакувано, следејќи ги ограничувањата утврдени под описот на магијата Permanency.

Не е можно да се внесат други магични ефекти во предметот кои не се во согласност со одредена магија, и многу магични предмети од времињата одамна поминати едноставно не можат да се рекреираат во ова време.

Магијата ги избрка сите форми на поседување со Интензитет до половина од Интензитетот на магијата. Што ќе се случи следно зависи од ставот и типот на ентитетот, ако го има, но оние кои се воинствени и имаат моќ да се дезинтегрираат може да бидат во искушение да вклучат други блиски цели во духовна борба. Третирајте како магичен дуел, меѓутоа, ако ентитетот победи, тие можат да го поседуваат губитникот. Ако ентитетот изгуби, тој се испраќа назад во неговата рамнина на потекло. Според тоа, оваа магија може да биде потенцијално опасна за фрлачот или неговите придружници. Времето на фрлање е многу случајно и не може да се прекине без да се наруши ритуалот.

#### Пронаоѓање фамилијар (Find Familiar)

(Призивање/Conjuration)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 2d12 часа |
| **Сфера:** Ниедна | **Времетраење:** Специјално |
| **Цена:** 3/интензитет, +1 EXP | **Домет:** 0 |
| **Област:** Радиус од ½ милја/интензитет | **Отпор:** Не е применливо |

Оваа магија му овозможува на фрлачот да се обиде да повика фамилијар, кој станува продолжување на сетилата и моќта на својот господар. Фамилијарите можат да разговараат со својот господар телепатски и се добри чувари и извидници. Убивањето на сопствениот фамилијар претставува одредени ризици за магионичарот поради нивната блиска врска, што го прави поседувањето фамилијар опасност од низок ранг.

За да повика фамилијар, магионичарот мора да го започне ритуалот држејќи мангал наполнет со јаглен, и кога гори со интензитет, да додаде темјан во вредност од 100 златици. Со овие состојки што горат, фрлачот мора потоа да го продолжи ритуалот додека фамилијарот не пристигне или времето на фрлање не истече без успех.

Дури и ако оваа магија е успешно фрлена, шансата соодветен фамилијар да одговори на повикот на магионичарот е само 50%, а магионичарот може да ја обиде оваа магија само еднаш годишно. Секое дополнително ниво на Интензитет над првото го продолжува дометот на магијата за уште половина милја, што пак ја зголемува веројатноста за наоѓање потенцијален фамилијар за 5%, до максимум 95%. Не постои контрола врз точниот тип на суштество што ќе одговори на повикот, но она што ќе пристигне ќе биде верен слуга и сојузник. До самото суштество е да одговори на повикот, затоа престојот во регион за кој се знае дека е населен од одреден тип на суштество _не_ му го обезбедува на фрлачот успехот.

Ако суштество одговори на повиците на фрлачот, магионичарот сепак мора да жртвува 1 фрлање за искуство (EXP) за да создаде духовна врска помеѓу себе и фамилијарот. Откако ќе се направи ова, ритуалот е завршен.

Додека фамилијарот и неговиот господар се наоѓаат во рок од 120 стапки еден од друг, магионичарот добива способност да ги користи и магичните поени на фамилијарот. Покрај тоа, магионичарот добива телепатска врска со фамилијарот и какви било дополнителни посебни способности или бонуси на вештини наведени во табелите подолу.

Во случај на смрт на фамилијарот, фрлачот губи 5 фрлања за искуство. Фрлач кој моментално нема фрлања за искуство мора да ги изгуби сите понатамошни фрлања за искуство додека не се исплати салдото.

Типот на фамилијар што ќе се појави, ако воопшто, се одредува според следнава табела. Под повеќето околности, обичните фамилијари не се исклучително големи, со големина помеѓу SIZ 1-4, и го користат описот за мало животно.

#### Огнен штит (Fire Shield)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 3 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** 2 минути/интензитет |
| **Цена:** 3+1/дополнителен интензитет | **Домет:** 0 |
| **Област:** Фрлач | **Отпор:** Не е применливо |

Оваа магија создава штит од лелеави пламени кои го согоруваат фрлачот, но не предизвикуваат никаква штета сама по себе. Наместо тоа, пламенот го штити примачот од оган или студ, во зависност од која од двете варијанти е во меморија: Chill Shield, кој создава сини или зелени пламени и штити од топлина и штета базирана на оган, или Warm Shield, кој создава виолетови или сини пламени и штити од студ и штета базирана на мраз. Бојата на пламенот треба да се одреди случајно со 50% шанса за било која, бидејќи фактот дека двата типа можат да испуштаат сини пламени создава елемент на неизвесност кај кој било напаѓач. Одлуката за тоа која да се меморира се донесува кога се подготвуваат магиите, а и двете може да се меморираат ако се сака. Овие пламени не испуштаат топлина и испуштаат светлина со само половина од осветленоста на факел. Спецификите на секоја варијанта се детално опишани подолу.

- **Chill Shield:** Овие пламени се ладни на допир и ја намалуваат секоја штета базирана на оган или топлина на половина од вкупната. Успешното фрлање за отпор ќе ја поништи целата штета. Фрлањето за отпор е една класа полесно и, во случај на избегнување (Evade), нема да го направи бранителот легнат.
- **Warm Shield:** Овие пламени се топли на допир и ја намалуваат секоја штета базирана на студ на половина од вкупната. Успешното фрлање за отпор ќе ја поништи целата штета. Фрлањето за отпор е една класа полесно, а во случај на избегнување, нема да го направи бранителот легнат.

Меле нападите врз примачот на која било варијанта, без разлика дали се вооружени или невооружени, нанесуваат нормална штета освен ако не се користат еден од заштитените елементи. Во овој случај, фрлачот е заштитен од елементарниот дел од нападот, а напаѓачот добива штета еднаква на онаа што е нанесена. Носениот оклоп од страна на напаѓачот не нуди заштита, но магичните оклопни поени или природниот оклоп на суштеството ја намалуваат штетата како и обично. Суштествата со вроден магичен отпор можат да го растераат Fire Shield со успешно фрлање за сила на волја кога примачот првпат ќе биде погоден. Ако фрлањето за магичен отпор не успее, противникот не може подоцна да го поништи Fire Shield.

#### Пламен удар (Flame Strike)

#### Од месо во камен (Flesh to Stone \(R\))

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 4 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Трајно |
| **Цена:** 3/Интензитет | **Домет:** 30 стапки/интензитет |
| **Област:** 1 цел | **Отпор:** Сила на волја |

Кога ќе се фрли, една жртва во домет има право на фрлање за отпор со сила на волја. Ако не успее, таа и сите носени и облечени предмети се целосно трансформирани во цврст камен. Оваа трансформација не е смрт, туку форма на суспендирана анимација. Фрлањето на превртената верзија на оваа магија, или Wish, може да се користи за враќање на жртвата во живот. Секоја штета што жртвата ќе ја претрпи додека е камен се пренесува, преземајќи ефект веднаш по враќањето. Големите суштества (SIZ 21-40) се помалку подложни на оваа магија со фрлање за отпор што е лесно, а фрлањето за отпор за огромни суштества (SIZ 41+) е многу лесно.

Спротивната магија, Stone to Flesh, се користи за враќање на жртвата и не е потребно фрлање за отпор. Сепак, магијата може да се преврти и за трансформирање на камен кој никогаш претходно не бил жив; се користи на неколку креативни начини. На пример, ѕид од камен од 10 кубни стапки по ниво на Интензитет може да се трансформира во меко месо, „тунел“ од месо широк до 3 стапки, со должина од 10 стапки по Интензитет би можел да се создаде, една цел како што е камена статуа би можела да се трансформира во тело, па дури и камениот голем би можел да се трансформира во голем од месо со помош на оваа магија. Сепак, во последниот случај, камениот голем би имал право на фрлање за сила на волја за отпор како и обично. Каменот претворен во месо на овој начин е мек и еластичен, и додека ги задржува своите вистински погодени поени, не поседува оклопни поени, што го прави полесно за сечење на парчиња.

#### Порта (Gate)

(Призивање/Conjuration)

#### Шарм (Glamour \(R\))

Glamour ја прави целта привлечна така што луѓето се природно привлечени кон нив. Ефектот мора да се избере кога ќе се фрли и може да биде сè од голема брадавица на врвот на носот, глас со високи тонови или дури и силен мирис на телото. Што и да се избере, тоа ќе предизвика луѓето да се свртат од жртвата или да најдат изговори да го напуштат нејзиното присуство што е можно поскоро.

Ниту една верзија на оваа магија нема ефект врз немртовците, суштествата повредени само од железо, сребро или магично оружје, или нетелесни суштества.

(Илузија/Illusion)

| | |
| :-- | :-- |

Оваа илузија може да биде сè од отворена ливада до антички црвен змеј, ако се вклопува во областа на ефект на магијата. Иако не може да се направи вистинска штета со илузијата, ниту да се создаде температура, умот може да биде убеден дека чувствува болка, трпејќи ги ефектите од повредата, или чувствувајќи екстреми на топлина или студ; сепак, предметите нема да изгледаат како да замрзнуваат или да согоруваат, освен ако фрлачот не се концентрира и на овие ефекти. Така, на пример, ако фрлачот посака да направи паднат илузорен факел да предизвика суви лисја да изгледаат како да се запалиле, фрлачот би можел да се концентрира како слободна акција за да го стори тоа.

#### Невидливост (Invisibility)

(Илузија/Illusion)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** 6 часа/интензитет |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** Допир |
| **Област:** 1 цел | **Отпор:** Не е применливо |

Кога ќе се фрли оваа магија, субјектот и сета носена опрема исчезнуваат, невидливи за сите форми на нормален вид. Ова, сепак, не ја прави личноста незабележлива со други средства како слух, допир, мирис итн., или со природни способности како Life Sense или Sonar.

Оние под ефектите на Invisibility остануваат такви во текот на времетраењето на магијата (макс. 24 часа), освен ако не се растера или субјектот не направи напад, во кој случај магијата се поништува, а поединецот се појавува _по_ нападот. Целта би се сметала под ефект на [Изненадување](0008_Combat.md?id=surprise). Ниту една друга акција не влијае негативно на времетраењето на магијата, дозволувајќи му на субјектот да отвора врати, зборува, се качува, трча, краде џеб итн. Дури и фрлањето магии нема да го прекине времетраењето освен ако не влијаат негативно на еден или повеќе специфични непријатели во борба. Многу од претходно споменатите акции би можеле да дозволат други средства за откривање, како што е можно фрлање за перцепција за да се слушне некој што трча, или да се почувствува како некој го краде џебот. Господарот на играта ќе додели казни или бонуси на оние што се обидуваат да откријат според тоа колку е забележливо.

#### Невидливост, радиус 10 стапки (Invisibility, 10 ft. Radius)

(Илузија/Illusion)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 2 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** 6 часа/интензитет |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** Допир |
| **Област:** 1 цел, 10 ст | **Отпор:** Не е применливо |

Оваа магија функционира идентично како магијата [Invisibility](0010_Spells.md?id=invisibility); сепак, сите поединци во рок од 10 стапки од примачот (што може да биде самиот фрлач) кога се фрла магијата се прават невидливи исто така. Оние под ефектите на магијата можат да се гледаат меѓу себе; сепак, ова не дава способност за гледање на други невидливи суштества. Ако некој се помести надвор од областа на ефект, неговата невидливост се губи, затоа мора да се внимава секој да се држи во домет од оригиналниот субјект. Оние што се враќаат во областа на ефект откако нивната невидливост се изгубила, или не биле присутни кога се фрлила, немаат корист од нејзините ефекти. Нападите направени од заштитата на Invisibility, вклучително и офанзивно фрлање магија од кој било друг освен оригиналниот субјект, ја прекинуваат невидливоста за таа личност, но немаат ефект врз другите ликови во областа на ефект. Сепак, напад направен од оригиналниот примач на магијата ги прави сите повторно видливи. Погледнете ја основната магија [Invisibility](0010_Spells.md?id=invisibility) за дополнителни детали.

#### Поголема невидливост (Invisibility, Greater)

(Илузија/Illusion)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 3 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** 3 рунди/интензитет |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** Допир |
| **Област:** 1 цел | **Отпор:** Не е применливо |

Оваа магија функционира според основната магија [Invisibility](0010_Spells.md?id=invisibility); сепак, ниту една акција преземена од страна на субјектот нема да го заврши времетраењето предвреме. Целта може да прави меле или напади со дострел, да фрла магии итн. Забележете дека постојат видливи индиции дека акцијата се случила, како што е визуелно изобличување. Ова му овозможува на секој со видно поле кон субјектот да направи Формидабилно фрлање за перцепција по преземањето на акцијата, или евентуално претходно ако ликот е одложен, за да ја утврди локацијата на невидливиот напаѓач. Напад со една класа на тешкотија може да се направи во истата рунда кога субјектот дејствувал од оние што ја согледуваат локацијата на невидливата личност. Погледнете ја магијата [Invisibility](0010_Spells.md?id=invisibility) за дополнителни детали.

#### Железна рака (Ironhand)

(Абјурација/Abjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 0 | **Време на фрлање:** 1 акција |
| **Сфера:** Заштита | **Времетраење:** 10 минути |
| **Цена:** 1 | **Домет:** Допир |

Ironhand му овозможува на примачот да држи сè што инаку би предизвикало штета (како што се исклучително топли или ладни предмети, или оние што капат киселина) без да се повреди. Така, корисникот може да фати жар од оган, да подигне врела казан од плунка, па дури и да посегне низ отвор за пареа за да фати предмет од другата страна. Не дава целосен имунитет од штета, само спречува спроведување низ кожата на примачот. Магијата не штити ништо што се носи на раката, така што прстени, ракавици и слично ќе трпат ефекти од изворот.

#### Отклучување (Knock \(R\))

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 2 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** Види подолу |
| **Цена:** 1/интензитет | **Домет:** 180 стапки |
| **Област:** 1 порта | **Отпор:** Не е применливо |

Оваа магија може да се фрли за да се отвори една врата или друг сличен отвор од дрво, камен или метал ако е заклучен, заглавен, Held или Mage Locked. Нема ефект врз порта или влез. Вратата може да поседува до 25 погодени поени по Интензитет и може да вклучува заклучени сандаци или кутии, тајни врати, па дури и окови и синџири. Дури и отвор претходно заварен ќе се ослободи од своите врски. Максимум два различни аспекти може да бидат засегнати со фрлање на Knock, на пример, врата што е заклучена, заклучена со резе и Held ќе бара фрлање на 2 магии Knock. Против Mage Locked врати, омајувањето едноставно се суспендира 10 минути, по што се враќа во својата магично заклучена состојба.

Кога се превртува, Lock (Заклучување) затвора и заклучува еден отвор како што е забележано погоре под претпоставка дека постои механизам за заклучување. Може да се постават до две различни функции, заклучување, со резе, со пречка итн.

| Интензитет | Цена | Варијабилен ефект |
| :-: | :-: | :-- |
| 1 | 1 | до 25 HP порта; окови, катанци, типичен дрвен сандак или врата |
| 2 | 2 | до 50 HP порта; дрвен засилен сандак или врата |
| 3 | 3 | до 75 HP порта; железна кутија или врата |

#### Познавање усогласување (Know Alignment \(R\))

(Гатање/Divination)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 1, Волшебник 2 | **Време на фрлање:** 1 акција |
| **Сфера:** Гатање | **Времетраење:** 1 рунда/интензитет |
| **Цена:** 1/интензитет | **Домет:** 30 стапки |
| **Област:** 1 цел | **Отпор:** Сила на волја |

Оваа магија му овозможува на фрлачот да го согледа усогласувањето и страстите на едно суштество, кое добива фрлање за отпор. Ако фрлањето за отпор не успее, фрлачот ќе го согледа етичкиот кодекс на целта во однос на законот, неутралноста и хаосот. Концентрирањето уште една рунда е потребно за да се согледа моралното усогласување на целта во однос на доброто, неутралноста и злото. Секоја дополнителна рунда надвор од ова ќе согледа една друга случајна преостаната страст. Господарот на играта ја открива „силата“ на согледаното усогласување и страсти на целта според следната табела:

**Табела за јачина на усогласување/страст**

| Процент | Јачина |
| :-: | :-- |
| 01-29% | Слаба |
| 30-69% | Просечна |
| 70-99% | Силна |
| 100% + | Многу силна |

Спротивната магија, Obscure Alignment (Прикривање усогласување), ги прави усогласувањето и страстите на целта нечитливи 24 часа, дури и од фрлање на Know Alignment или Detect Evil/Good.

#### Познавање јазици (Know Languages \(R\))

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 минута |
| **Сфера:** Ниедна | **Времетраење:** 5 минути/интензитет |
| **Цена:** 1/интензитет | **Домет:** Допир |
| **Област:** 1 разумно суштество | **Отпор:** Не е применливо |

Оваа магија му овозможува на фрлачот да разбере и чита речиси секој не-магичен јазик. „Говорот“ на не-разумните животни или суштества не се разбира, само вистинските јазици на разумните суштества. Кога ќе се фрли оваа магија, магионичарот може да одреди себеси, една цел, суштество или предмет, од не повеќе од 20 SIZ (+10 SIZ по дополнителен Интензитет), и да левитира тој поединец од земјата. Кога ќе се фрли оваа магија, глобус на светлина се материјализира на место по избор на фрлачот, што може да биде на предмет, или дури и во празен воздух, и може да биде отфрлен од фрлачот во секое време. #### Молња (Lightning Bolt)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 2 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** 50 ст/интензитет |
| **Област:** Патека широка 10 ст | **Отпор:** Избегнување (Evade) |

Додека магионичарот ја започнува вербалната инкантација и гестови на првиот потег од фрлањето, електричен полнеж почнува да се лачи помеѓу прстите. На вториот потег, откако инкантацијата е завршена, магионичарот испраќа сноп од молња од врвот на прстот лачејќи во права линија низ сите цели во патека широка 10 ст што се протега низ дометот на магијата. Оваа штета предизвикува 1d6 поени штета за секои 2 поени Интензитет, или дел од нив, на сите жртви во областа на ефект. Оваа штета се фрла еднаш, и се применува на секоја од погодените локации на целта, при што носениот и природниот оклоп не нудат заштита, но магичните оклопни поени ја намалуваат штетата како и обично.

Успешното фрлање за избегнување, со фрлање на себе легнат, му овозможува на жртвата да не претрпи никаква штета. Некој со способноста Вешт додворувач има опција да избегне без да легне, но успехот во овој случај ќе ја намали штетата само за половина, освен ако не се во рок од 5 стапки од работ на областа на ефект.

Молњата има шанса да запали запаливи материјали еднаква на истрланата штета x1%. Погледнете го делот за [Пожари](0007_Game_System.md?id=fire-based-attacks) за дополнителни информации. Молњата исто така може да скрши или уништи неживи предмети од чисто удар.

#### Лоцирање предмет (Locate Object \(R\))

(Гатање/Divination)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 2, Волшебник 2 | **Време на фрлање:** 1 акција |
| **Сфера:** Гатање | **Времетраење:** 1 минута/интензитет |
| **Цена:** 1/интензитет | **Домет:** 0 |
| **Област:** 60 ст/интензитет | **Отпор:** Не е применливо |

Со фрлањето на Locate Object, фрлачот се насочува кон познат или запознаен предмет, чувствувајќи ја насоката кон предметот додека фрлачот стои и полека се врти. Предметот мора да биде во рамките на областа на ефект на магијата, сепак. Предметот може да биде кој било генерички предмет како кревет, сандак, скали или злато на пример, а магијата ќе го насочи фрлачот кон најблиската репрезентација на тој предмет. Специфичните предмети од друга страна, како што е долгиот меч на Ташана, бараат фрлачот да има точна ментална слика, откако го видел лично во рок од 30 стапки, или преку магични средства. Затоа, личен или уникатен предмет не може да се лоцира со помош на оваа магија освен ако фрлачот не е запознаен со него. Магијата не може да лоцира живи или неживи суштества.

Спротивната магија, Obscure Object (Прикривање предмет), го сокрива еден предмет од откривање со магични средства, како што се кристални топки, Detect Magic итн., во текот на истото времетраење.

#### Магична стрела (Magic Missile)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 1 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 1/Интензитет | **Домет:** 100 ст/интензитет |
| **Област:** 1-5 цели | **Отпор:** Види подолу |

Кога ќе се фрли оваа магија, една или повеќе стрели на магична енергија излетуваат од врвовите на прстите на магионичарот и ја погодуваат целта. Максималниот број на стрели што може да се генерираат се заснова на нивото на вештина за Arcane Casting на фрлачот, при што втора стрела се генерира на вештина од 60%, трета на 70%, четврта на 80% и петта и последна стрела на 90%. За да се генерираат овие стрели, магијата мора да се фрли со Интензитет еднаков на саканиот број на стрели. На пример, под 60%, магионичар кој фрла Magic Missile со 3 Интензитет ќе го постигне подолгиот домет, меѓутоа ќе се генерира само една стрела. Магионичар со ниво на вештина од 70% би можел да ја фрли магијата со истиот 3 Интензитет и да го постигне истиот домет, но би можел да генерира 3 стрели. Оваа магија има максимален интензитет од 5. Видете ја табелата подолу.

Magic Missile ќе погоди непогрешливо, дури и ако целта е во меле борба или има делумно покривање. Овие стрели не можат да се избегнат; сепак, противник во целосна покриеност не може да биде цел на оваа магија. Магијата Shield автоматски ќе ги одбие Magic Missiles под претпоставка дека целта е свесна и/или свртена кон фрлачот. Magic Missiles прават 1d6+1 поени штета и носениот оклоп не штити, но природниот оклоп или магичните оклопни поени на суштеството ја намалуваат штетата како и обично. Magic Missiles не предизвикуваат штета на неживи предмети како што се врати, брави итн.

При пукање со повеќе стрели, фрлачот може да ги насочи кон едно суштество или да таргетира неколку суштества. Секоја Magic Missile ќе погоди случајна локација - специфичните локации не можат да бидат таргетирани. Фрлачот мора да ги назначи поединечните цели на секоја стрела пред да фрли за штета.

| :-: | :-: | :-- |
| 1 | 1 | 100 ст домет; 1 стрела |
| 2 | 2 | 200 ст домет; 2 стрели ако 60% вештина |
| 3 | 3 | 300 ст домет; 3 стрели ако 70% вештина |
| 4 | 4 | 400 ст домет; 4 стрели ако 80% вештина |
| 5 макс. | 5 | 500 ст домет; 5 стрели ако 90% вештина |

#### Волшебна уста (Magic Mouth)

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 2 | **Време на фрлање:** 1 минута |
| **Сфера:** Ниедна | **Времетраење:** Види подолу |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** 30 ст |
| **Област:** 1 предмет | **Отпор:** Не е применливо |

Оваа магија создава уста на предмет или нешто, која магично се појавува кога е активирана од одреден настан или време назначено од магионичарот кога магијата првпат се фрла. Оваа уста потоа ќе каже која било предефинирана фраза што фрлачот ја избрал во времето на фрлање. Оваа фраза мора да се состои од не повеќе од 25 зборови и устата ги изговара со брзина од околу 1 збор во секунда. Устата не може да изговара зборови на моќ или да фрла магии.

Оваа магија може да се фрли на кој било нормално нежив предмет, од столб или дрво, до камени ѕидови или сандак; сепак, особено е ефикасна кога се фрла на статуа, бидејќи самата статуа би изгледала како да зборува. Не може да се фрли на ниту едно живо суштество со каква било форма на интелигенција или инстинкт. Ова важи за оние што биле порано живи. Кога се фрла оваа магија, магионичарот ја одредува ситуацијата што ќе ја активира омајувањето. Може да биде дизајнирано да се активира преку сè, од изговорен збор до создавање на каква било бучава. Може да биде толку општо како „кога следната личност ќе влезе во оваа соба...“ до толку специфично како „кога женски свештеник на Седона ќе дојде во рок од 10 стапки од статуата на крајот од ходникот во сабота...“. Ефектот на активирање не може да биде нешто што не може да се согледа не-магично, како што е невидливо суштество, усогласување на суштество, вештина, класа итн. Меѓутоа, може да назначи носена облека. Максималното растојание што магијата може да се активира е 25 стапки по Интензитет.

Времетраењето на оваа магија е трајно додека не се активира омајувањето и потоа магијата завршува.

#### Дожд од метеори (Meteor Shower)

(Евокација/Evocation)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 5 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Инстантно |
| **Цена:** 3/Интензитет | **Домет:** 20 ст/интензитет |

Кога магионичарот ќе ја фрли оваа магија, два микро-метеори по ниво на Интензитет стрелаат од испружената рака. Метеорите се лачат кон својата цел, удирајќи по надолна траекторија, оставајќи трага од искри и жар во својата патека. При удар, тие детонираат во повеќе огнени експлозии околу целната точка. Првиот метеор секогаш ја погодува таргетираната локација, додека сите дополнителни метеори удираат случајно околу неа, секој со експлозивен радиус од 30 стапки.     <img src="_media/CFI_10_Meteor_Shower_Grid.png" style="width: 25%;" />
</div>


Секој метеор прави 1d10 поени огнена штета на оние во областа на ефект. Сепак, поради радиусот на секоја експлозија, многу ќе се преклопуваат, правејќи дополнителна штета на оние што ќе бидат зафатени од нив. Фрлањата за штета се комбинираат и се применуваат на секоја од погодените локации на целта, при што носениот оклоп не нуди заштита, но магичните оклопни поени или природниот оклоп на суштеството ја намалуваат штетата како и обично.

Успешното фрлање за избегнување му овозможува на жртвата да не претрпи никаква штета. Некој со способноста Вешт додворувач има опција да избегне без да легне, но успехот во овој случај ќе ја намали штетата само за половина, освен ако не се во рок од 5 стапки од работ на областа на ефект.

Сите, вклучително и оние надвор од областа на ефект, но во рок од 60 стапки од точката на удар, се должни да успеат во фрлање за атлетика за да останат исправени.

Meteor Shower има шанса да запали запаливи материјали еднаква на истрланата штета x5%. Погледнете го делот за [Пожари](0007_Game_System.md?id=fire-based-attacks) за дополнителни информации.

#### Илузорна слика (Mirror Image)

(Илузија/Illusion)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 2 | **Време на фрлање:** 1 акција |
| **Сфера:** Ниедна | **Времетраење:** 3 рунди/интензитет |
| **Цена:** 1/интензитет | **Домет:** 0 |
| **Област:** Радиус од 5 стапки | **Отпор:** Не е применливо |

Кога ќе се фрли оваа магија, 2d4 дупликати од магионичарот се појавуваат во радиус од 5 стапки, точно имитирајќи ги движењата на фрлачот. Покрај тоа, целата област на ефект се ниша и трепери, што го прави точното место на фрлачот невозможно да се утврди. Удирањето на една од илузорните слики предизвикува нејзино исчезнување; сепак, преостанатите слики остануваат незасегнати. Удирањето на фрлачот нема ефект врз преостанатите слики и бидејќи сликите секогаш се менуваат, нема начин да се знае дали целта е вистинскиот фрлач ако се нападне повторно. Сите повреди претрпени од фрлачот се дуплираат и на сликите. Постојат бројни начини на кои Господарот на играта може да утврди дали вистинскиот фрлач е погоден или една од сликите. Еден е да се утврди колку потенцијални цели се достапни, вклучувајќи го и фрлачот, и да се фрли коцка со најблиската деноминација. На пример, со 4 слики и фрлачот, напаѓачот треба да фрли 1d6, повторно фрлајќи резултат од 6, при што фрлачот се погодува при фрлање од 1. Друг би бил да имате неколку маркери еднакви на бројот на потенцијални цели, означувајќи еден како фрлач. Маркер се извлекува секој пат кога се прави напад и ако целта е погодена, се применува штета; во спротивно, една слика исчезнува, отстранувајќи еден од маркерите. Сликите исчезнуваат на крајот од времетраењето на магијата.

#### Полиморф - друга цел (Polymorph Other)

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Волшебник 3 | **Време на фрлање:** 2 акции |
| **Сфера:** Ниедна | **Времетраење:** Трајно |
| **Цена:** 3, +1/дополнителен интензитет (+1 EXP) | **Домет:** 15 ст/интензитет |
| **Област:** 1 цел | **Отпор:** Сила на волја |

Фрлачот може да ја измени формата на едно телесно таргетирано суштество во форма на друго, при што секој поен на Интензитет ја менува SIZ до 5 поени. Затоа, трансформирањето на орк од SIZ 16 во SIZ 1 зајак би барало 3 нивоа на Интензитет (15 SIZ поени разлика). Субјектот на оваа магија има право на фрлање за отпор со сила на волја. Големите суштества (SIZ 21-40) се помалку подложни на полиморф, при што фрлањето за отпор е лесно, а фрлањето за отпор за огромни суштества (SIZ 41+) е многу лесно.

Целиот процес на трансформација одзема цела рунда и може да биде прилично стресен за предметното суштество, барајќи второ фрлање за сила на волја за да се задржи нивната оригинална личност, при што неуспехот го онесвестува субјектот за 1d10 минути, а Fumble резултира со смрт од ментален шок. Секое удвојување или преполовување на оригиналниот SIZ на суштеството го прави фрлањето за сила на волја за задржување на личноста една класа потешко, како и комплетна промена на околината, како што е менување на личност во риба. Успешното фрлање му овозможува на жртвата да ги задржи своите INT и CHA, како и сите вештини што ги бараат тие карактеристики.

Трансформацијата му дава на примачот форма на дишење на претпоставеното суштество, ако е различна од нормалната; какви било природни напади; и сите световни начини на движење. Не дава никакви зголемени или магични способности што ги поседува суштеството. На пример, суштество кое било полиморфно во змеј нема да добие здив или магични способности на суштеството, но ќе добие способност за летање, цврста кожа, смртоносен каснување, напади со канџи итн. Покрај тоа, жртвата ги добива физичките вештини на новата форма како што се Атлетика, Brawn, Лет, Пливање, како и нејзините погодени поени и модификатор на штета. Под претпоставка дека трансформираниот поединец ја задржал својата INT, тие сè уште ја губат способноста за зборување, освен ако новата форма нема способност да артикулира зборови. Оние што можеле да фрлаат магии во својата претходна форма сè уште би можеле да фрлаат во новата форма, под претпоставка дека сè уште ја поседуваат способноста да ги произведат вербалните и соматските компоненти. Во случај на драстична промена, како на пример менување од бипед во квадрупед, или копнено животно во морско суштество, Господарот на играта слободно може да ја казни за најмалку една класа на тешкотија употребата на какви било вештини што би одземале време за учење додека се прилагодуваат на новата форма додека не се има доволно време за вежбање. Ова е особено точно за физичките вештини како што се Атлетика, Невооружена борба, Пливање, Лет, Борбени вештини итн.

Фрлањето за сила на волја за задржување на својата личност е потребно секој ден додека субјектот останува трансформиран додека не се неуспее, предизвикувајќи личноста конечно да подлегне на менталитетот на новата форма, при што INT се менува во INS во случај на неразумно суштество. Сите специјални и магични способности во сопственост на новата форма што не биле претходно стекнати, како што се напади со поглед, оружје со здив итн., сега се достапни на суштеството додека трансформацијата е завршена. Ликовите кои го губат својот идентитет на овој начин стануваат ликови кои не се играчи под контрола на Господарот на играта.

Пред да подлегне ментално на трансформацијата, полиморфното суштество е подложно на Dispel Magic како и обично, без потреба од фрлање за отпор.

#### Молитва (Prayer)

(Призивање/Conjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 3 | **Време на фрлање:** 1 минута |
| **Сфера:** Борба | **Времетраење:** 10 минути/интензитет |
| **Цена:** 3, +1/дополнителен интензитет | **Домет:** 0 |
| **Област:** Радиус од 60 стапки | **Отпор:** Не е применливо |

Кога ќе се фрли, оваа магија ги благословува свештеникот и сите сојузници во областа на ефект, додека ги проколнува оние што се во опозиција. Сојузниците добиваат привремен бонус од +5% на сите фрлања за вештини и отпор заедно со +1 бонус на целата нанесена штета, додека непријателите добиваат казна од -5% и намалување на штетата од -1. Оваа магија може да се фрли заедно со Chant ако е фрлена од истиот свештеник, или друг свештеник од истата религија, дозволувајќи двата ефекта да се соберат, давајќи бонус од +10% на вештините и +2 на штетата, додека непријателите го добиваат спротивното.

#### Предвидување време (Predict Weather)

(Гатање/Divination)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 1, Волшебник 1 | **Време на фрлање:** 1 минута |
| **Сфера:** Време | **Времетраење:** Инстантно |
| **Цена:** 1/интензитет | **Домет:** 0 |
| **Област:** Радиус од 5 милји | **Отпор:** Не е применливо |

Оваа магија му овозможува на фрлачот да го предвиди времето со 100% сигурност во радиус од 5 милји. Оваа прогноза е за следните 4 часа по ниво на Интензитет и вклучува температура, врнежи, акумулација на снег, брзина на ветерот итн.

#### Зачувување (Preserve)

(Трансмутација)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 0, Волшебник 0 | **Време на фрлање:** 1 потег |
| **Сфера:** Животно, Растение | **Времетраење:** 1d3 месеци |
| **Цена:** 1 | **Домет:** Допир |
| **Област:** Види подолу | **Отпор:** Не е применливо |

Preserve ја спречува органската материја, и растителна и животинска, од бактериско распаѓање и трулење за 1d3 месеци, со стерилизирање. Ако материјалот подоцна се пуши, кисели или соли, тој е зачуван на неодредено време. Магијата може да го запре распаѓањето што започнало, но не и да го пресврти. Фрлачот може да влијае на количина на органска материја еднаква во „Нешта“ или SIZ на неговата POW.

#### Заштита (Protection)

(Абјурација/Abjuration)

| | |
| :-- | :-- |
| **Ранг:** Свештеник 0, Волшебник 0 | **Време на фрлање:** 1 акција |
| **Сфера:** Заштита | **Времетраење:** Опасност/окинувач |
| **Цена:** 1 | **Домет:** Допир |
| **Област:** 1 цел | **Отпор:** Не е применливо |

Protection е корисна во широк спектар на задачи каде што постои ризик од случајна повреда, како што е работа во леарница или рудник. Првиот пат кога ликот нормално би претрпел штета што продира во заштитна облека или оклоп, магијата Protection ќе се активира и ќе ја намали штетата за 1d3 поени. Магијата потоа се распрснува. Оваа магија се собира со сите други форми на магија за заштита. Магијата штити само од физичка штета, па нема да помогне против настани како оган, задушување итн. Верзијата на волшебникот на оваа магија може да се фрли само на себе
