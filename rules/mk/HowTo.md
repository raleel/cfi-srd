# Предуслови

1. Основно разбирање на [markdown јазикот](https://www.markdownguide.org/basic-syntax/).

2. Ќе треба да креирате бесплатна [GitHub](https://github.com/) сметка доколку ја немате. Ви препорачуваме да го користите името на вашата RPG игра бидејќи тоа ќе стане дел од URL-адресата што луѓето ќе ја користат за пристап до вашиот SRD.

3. Целиот овој процес можете да го направите преку прелистувачот без да го познавате git. Сепак, учењето на GitHub Desktop ќе ви овозможи локално да ги тестирате сите промени пред да ги објавите во живо за светот да ги види.

> Ако имате регистрирано име на домен, можете да го користите со овој процес за да креирате SRD како што направив јас https://srd.7thextinctionrpg.com

# Процесот

## Креирање на складиште (репозиториум) на Github

1. Најавете се на Github

2. Одете до јавниот шаблон https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Кликнете на "Use this template"

![Step3](/_media/Step3.png)

4. Изберете "Create a new repository"

5. Внесете име за складиштето

![Step5](/_media/Step5.png)

6. Изберете 'Private' (Приватно)

7. Изберете 'Create repository'

Ќе бидат потребни 5-30 секунди за да се копира шаблонот, потоа ќе ја имате сопствената копија.

8. Осигурајте се дека ја имате датотеката ".nojekyll". Ова е празна датотека која е потребна при хостирање на веб-локација на Github, во спротивно SRD нема да се прикажува правилно. *(Му кажува на GitHub Pages да не ги обработува објавените датотеки преку Jekyll).*


## Додавање на вашата содржина

### *.md датотеки

.md датотеките се markdown датотеки. Markdown е лесен јазик за означување кој можете да го користите за додавање елементи за форматирање на документи со обичен текст. Во зависност од големината на вашата содржина, можете или да ги поставите сите информации за вашата игра во една *.md датотека, или како што направив јас на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), да креирате посебни датотеки за секое поглавје. "Sample.md" датотеката обезбедува некои примери за форматирање.

Markdown јазикот е многу лесен за учење, користете ја врската дадена во точка 2 под Предуслови погоре за целосен список на синтаксата.

### _sidebar.md

Ова е вашето мени, навигациско окно на левата страна од веб-локацијата. Откако ќе додадете markdown датотека во вашето складиште, треба да ја додадете датотеката тука за нејзината содржина да биде вклучена. Следете го постоечкото форматирање.


## Овозможување на Github Pages за претворање на складиштето во веб-локација

1. Во вашето складиште кликнете на 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. Изберете 'Pages' од менито на левата страна

![Website-Step2](/_media/Website-Step2.png)

3. Ако не сте го направиле складиштето 'public' (јавно), имате два избора:
    a. Направете го складиштето јавно, што потоа ќе ви овозможи да го користите Github pages за бесплатно хостирање на вашата SRD веб-локација
    b. Надградете ја вашата Github сметка (во времето кога го пишувам ова, чини 4 долари месечно или 48 долари годишна членарина)

4. Под 'Branch' изберете 'main' и кликнете Save

5. Почекајте 10-20 секунди, а потоа освежете ја страницата

6. Сега ќе ја видите вашата URL-адреса, на пример https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)


## Промена на фонтови

2. Под 'body section' ќе ги најдете siteFont & headingFont

3. Променете ги со фонтовите што сакате да ги користите


## Користење на приклучокот Fontawesome и/или Material Icons за прикажување на бесплатни икони во вашиот SRD

### Fontawesome

Користете Fontawesome за да добиете бесплатни и анимирани икони. Претплатените корисници можат да користат Pro икони.

1. Најдете ја иконата на [Fontawesome](https://fontawesome.com/icons)
2. Изберете ја иконата
3. Во скокачкиот прозорец, под јазичето HTML копирајте сè меѓу " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Ставете го копираниот текст меѓу `:` без празни места

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Користете Material Icons за повеќе бесплатни икони.

1. Најдете ги иконите на [Material Icons](https://fonts.google.com/icons)
2. Копирајте и вметнете ја веб span врската директно во вашите markdown датотеки

```markup
<span class="material-icons">face</span>
```
