#### Appraise (Hindamine)

(Ennustamine)

| | |
| :-- | :-- |
| **Aste:** Maag 0 | **Loitsimisaeg:** 1 käik |
| **Sfäär:** Puudub | **Kestus:** Hetkeline |
| **Maksumus:** 1 | **Ulatus:** Puudutus |
| **Ala:** 1 ese | **Vastupanu:** Puudub |

Hindamine võimaldab koheselt hinnata füüsiliste kaupade kvaliteeti, mille kogumass (ENC) "asjades" või suurus (SIZ) on võrdne loitsija väe (POW) väärtusega. Loits määrab, kas sarnase välimusega esemed on sama kvaliteediga või kas mõni neist on defektne või kõrgema kvaliteediga. Loits ei toimi orgaaniliste asjade, vaid ainult elutute objektide puhul. Samuti ei määra see, millised konkreetsed vead või täiustused esinevad; ainult seda, et need on olemas. See ei aita maagia tuvastamisel ega avastamisel.

#### Armor (Soomus)

(Kutsumine)

| | |
| :-- | :-- |
| **Aste:** Maag 1 | **Loitsimisaeg:** 1 voor |
| **Sfäär:** Puudub | **Kestus:** Vaata allpool |
| **Maksumus:** 3 + 1/intensiivsus | **Ulatus:** Puudutus |
| **Ala:** 1 sihtmärk | **Vastupanu:** Puudub |

Selle loitsu korraldamisel kingitakse subjektile nähtamatu maagilise jõu väli, mis pakub kaitset, mis on võrdne soomussärgiga, lisades igale tabamuskohale 4 soomuspunkti. Loits ei toimi, kui sihtmärk kannab juba soomust. See aga asendab loomulikku soomust kogu oma kestuse vältel, eeldades, et see pakub paremat kaitset. Kui loitsida olendile, kellel on juba rohkem kui 4 punkti loomulikku soomust, suurendab see hoopis soomuspunkte 1 võrra igas tabamuskohas. See maagiline kaitse ei takista liikumist ega loitsimist. Loits kestab kuni maagiaga hajutamiseni või kuni loitsija saab ühe rünnakuga 8 punkti kahju (+1 iga täiendava intensiivsuse taseme kohta; vaata tabelit allpool). Loomulikult võib loitsija soovi korral loitsu igal ajal katkestada, mida tuleb teha ka magamiseks.

| Intensiivsus | Maksumus | Muutuv mõju |
| :-: | :-: | :-- |
| 1 | 3 | 4 soomuspunkti; kestab kuni 8 kahju saamiseni 1 rünnakust |
| 2 | 4 | 4 soomuspunkti; kestab kuni 9 kahju saamiseni 1 rünnakust |
| 3 | 5 | 4 soomuspunkti; kestab kuni 10 kahju saamiseni 1 rünnakust |
| 4 | 6 | 4 soomuspunkti; kestab kuni 11 kahju saamiseni 1 rünnakust |

#### Astral Spell (Astraalloits)

(Muundumine)

| | |
| :-- | :-- |
| **Aste:** Preester 5, Maag 5 | **Loitsimisaeg:** 2 tegevust |
| **Sfäär:** Astraal | **Kestus:** Vaata allpool |
| **Maksumus:** 3 + 1/täiendav intensiivsus | **Ulatus:** Puudutus |
| **Ala:** Vaata allpool | **Vastupanu:** N/A |

See loits võimaldab loitsijal ja kuni viiel teisel isikul (üks iga täiendava intensiivsuse taseme kohta) siseneda Astraaltasandile. Loitsimise ajal peavad kõik üksteist puudutama ja moodustama ringi. Reisijate kehad jäävad algtasandile ja nad ei võta tavaliselt kaasa riideid ega varustust, välja arvatud esemeid, mis kiirgavad maagilist aurat; need esemed muutuvad astraalseteks ekvivalentideks. Kestus kestab kuni loitsija soovib selle lõpetada. Siiski on võimalik seda ennetähtaegselt lõpetada välise jõuga, nagu näiteks *Dispel Magic*. Loitsija füüsilise keha surm lõpetab samuti loitsu, kuigi sellel on kahetsusväärne kõrvalmõju: kõik koos loitsijaga reisinud isikud jäävad astraaltasandile lõksu.

(Ennustamine)

See loits võimaldab loitsijal kindlaks teha, kas konkreetne tegevus, mis sooritatakse järgmise 30 minuti jooksul, on kasulik või kahjulik üksikisikule ja/või rühmale. Ennete tõlgendamiseks on vaja fookuspunkti, millest levinumad on draakoni küünised või väiksemad luud, pärl või puhas kuld väärtusega vähemalt 100 GP, mis on purustatud või sulatatud. Loitsu maksimaalne intensiivsus on 4. Selle täringuveeretuse peab tegema Mängujuht, sest loitsija ei tohiks kunagi kindlalt teada, kas tulemusi tõlgendati õigesti.

#### Befuddle (Segadus)

(Nõiumine (Võlumine))

| | |
| :-- | :-- |
| **Aste:** Preester 0, Maag 0 | **Loitsimisaeg:** 1 käik |
| **Sfäär:** Võlumine | **Kestus:** 30 minutit |
| **Maksumus:** 1 | **Ulatus:** 60 jalga |
| **Ala:** 1 sihtmärk | **Vastupanu:** Willpower (Tahtejõud) |

*Befuddle* tekitab kehalises sihtmärgis vaimse segaduse. Subjektil on raskusi sirgelt mõtlemisega, unustades kus ta on, mida ta teeb ja miks – sageli libisedes lahtiühendatud mõttekäikudesse. Segaduses subjektid võivad endiselt end kaitsta, kuid ei saa alustada mingit konstruktiivset tegevust kuni loitsu lõpuni. Igasugune rünnak või ähvardav tegevus lõpetab loitsu hetkega, olenemata sellest, kas see oli suunatud konkreetselt segaduses subjekti vastu.

#### Blade Barrier (Terade müür)

(Evokatsioon)

| | |
| :-- | :-- |
| **Aste:** Preester 4 | **Loitsimisaeg:** 2 tegevust |
| **Sfäär:** Valvur, Loomine | **Kestus:** 3 vooru/intensiivsus |
| **Maksumus:** 3+1/täiendav intensiivsus | **Ulatus:** 100 jalga |
| **Ala:** 5–30 jala raadius | **Vastupanu:** Vaata allpool |

See loits loob keerlevate lõikavate mõõkade, pistodade ja nugade tõkke, mis piitsutavad ja lõikavad ümber fikseeritud punkti, põhjustades 1d8 punkti kahju 1d4+2 juhuslikule tabamuskohale *kõigile*, kes läbivad mõjuala. Soomus pakub vaid poole oma tavapärasest kaitsest. Maagilised soomuspunktid vähendavad kahju tavapäraselt. Kuna relvad keerlevad pimestava kiirusega ja on tihedalt pakitud, on võimatu neid tõrjuda (Parry) ega vältida (Evade). Kilpi võib kasutada passiivseks kehaosade blokeerimiseks. Sel juhul pidage meeles võrrelda veeretatud kahju kilbi soomuse ja tabamispunktidega.

Loitsu võib kasutada kaitsvalt, et kaitsta preestrit või liitlasi, või ründavalt, et püüda vaenlasi lõksu. Siiski võivad piiratud vaenlased, kes asuvad müüri moodustumisel selle servast viie jala kaugusel, teha väldikuveeretuse (Evade), et põgeneda. Sõltumata edust maandub vastane pikali, otse mõjualast väljas. Edukas veeretamine tähendab null kahju; vastasel juhul kannatavad nad täit mõju.

#### Bless (R) (Õnnistus)

(Kutsumine)

| | |
| :-- | :-- |
| **Aste:** Preester 1 | **Loitsimisaeg:** 1 voor |
| **Sfäär:** Kõik | **Kestus:** 5 minutit |
| **Maksumus:** 1 | **Ulatus:** 180 jalga |
| **Ala:** 25 jala raadius | **Vastupanu:** Willpower (Tahtejõud) |

Selle loitsu korraldamisel õnnistab preester mõjualas viibivaid liitlasi. Mõjutatud kiirgavad loitsija maailmavaadet, kas head või kurja. Neutraalsuse õnnistusi ei eksisteeri. Kõik liitlased raadiuses saavad +5% boonuse kõigile oskuste ja vastupanu veeretustele. Lisaks põhjustavad nende relvad +1d3 kahju intelligentsele surnutele ja välistasandite olenditele, kelle maailmavaade on vastandlik loitsija omale (nt deemonid, kuradid või inglid). Pange tähele, et kuigi animeeritud surnud, nagu skeletid ja zombid, ei ole oma olemuselt kurjad, on nad tavaliselt animeritud kurja maagia abil ja seega nendele kahjudele allutatud.

Loitsu pöördkülg, *Curse* (Needus), võimaldab preestril vaenlasi neada, tehes märgitud oskustele vastupidist mõju. Needusrelva kahju arvutatakse karistusena ja see ei saa olla väiksem kui 1 punkt.

See loits põhjustab leekide purskamist loitsija kätest 120-kraadises kaares. See kahju haarab kõiki alas viibijaid, lähtudes intensiivsusest, maksimaalse intensiivsusega 9. Edukas väldikuveeretamine, pikali viskumine, võimaldab ohvril null kahju saada.
