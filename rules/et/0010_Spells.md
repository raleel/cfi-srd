#### Appraise (Hindamine)

(Ennustus)

| | |
| :-- | :-- |
| **Aste:** Maag 0 | **Loitsimisaeg:** 1 käik |
| **Sfäär:** Puudub | **Kestus:** Hetkeline |
| **Maksumus:** 1 | **Kaugus:** Puudutus |
| **Ala:** 1 ese | **Vastupanu:** Puudub |

Appraise võimaldab koheselt hinnata füüsiliste kaupade kvaliteeti, mille kogumaht 'asjades' või SUU on võrdne loitsija VÄG-ga. Loits määrab, kas välimuselt identsed esemed on sama või sarnase kvaliteediga, või kas üks või mitu neist on vigased või kõrgema kvaliteediga. Loits ei toimi orgaanilistele asjadele, ainult elututele esemetele. Samuti ei määra see, millised vead või täiustused on esemel olemas; vaid seda, et need on olemas. See ei ole kasulik maagia tuvastamiseks ega avastamiseks.

#### Armor (Turvis)

(Manamine)

| | |
| :-- | :-- |
| **Aste:** Maag 1 | **Loitsimisaeg:** 1 voor |
| **Sfäär:** Puudub | **Kestus:** Vt allpool |
| **Maksumus:** 3 +1/Intensiivsus | **Kaugus:** Puudutus |
| **Ala:** 1 sihtmärk | **Vastupanu:** Puudub |

Kui see loits heidetakse, kingitakse subjektile nähtamatu maagilise jõu väli, mis pakub sama palju kaitset kui soomusturvis, andes 4 Turvapunkti igale tabamuskohale. Kui loits heidetakse kellelegi, kes juba kannab turvist, pole sellel mingit mõju. Küll aga asendab see oma Kestuse ajal loomuliku turvise, eeldades, et see pakub paremat kaitset. Kui loits heidetakse olendile, kellel on rohkem kui 4 punkti loomulikku turvist, suurendab see selle asemel Turvapunktide arvu 1 võrra kõigis kohtades. See maagiline kaitse ei takista liikumist ega loitsimist. Loits kestab, kuni see maagia abil hajutatakse või kuni loitsija saab ühe rünnakuga 8 punkti kahju, +1 iga täiendava Intensiivsuse taseme kohta (vt allolevat tabelit). Muidugi võib loitsija soovi korral loitsu igal ajal katkestada, mida tuleb teha ka magamiseks.

| Intensiivsus | Maksumus | Muutuv mõju |
| :-: | :-: | :-- |
| 1 | 3 | 4 Turvapunkti; kestab kuni 8 punkti kahju saamiseni ühest rünnakust |
| 2 | 4 | 4 Turvapunkti; kestab kuni 9 punkti kahju saamiseni ühest rünnakust |
| 3 | 5 | 4 Turvapunkti; kestab kuni 10 punkti kahju saamiseni ühest rünnakust |
| 4 | 6 | 4 Turvapunkti; kestab kuni 11 punkti kahju saamiseni ühest rünnakust |
| +1 | +1 | Jätka progresseerumist |

#### Astral Spell (Astraalloits)

(Transmutatsioon)

| | |
| :-- | :-- |
| **Aste:** Vaimulik 5, Maag 5 | **Loitsimisaeg:** 2 tegevust |
| **Sfäär:** Astraal | **Kestus:** Vt allpool |
| **Maksumus:** 3 +1/täiendav Intensiivsus | **Kaugus:** Puudutus |
| **Ala:** Vt allpool | **Vastupanu:** N/A |

See loits võimaldab loitsijal ja kuni viiel teisel isikul (üks iga täiendava Intensiivsuse taseme kohta) siseneda Astraaltasandile. Kõik peavad loitsu heitmise ajal üksteist puudutama ja moodustama ringi. Rändurite kehad jäävad päritolutasandile ja nad ei võta tavaliselt kaasa mingeid riideid ega varustust, välja arvatud need, mis ise kiirgavad maagilist aurat; need esemed muutuvad oma tavapärase vormi astraalseteks ekvivalentideks. Kestus kestab seni, kuni loitsija soovib selle lõpetada. Siiski on võimalik, et välise jõu, nagu Dispel Magic, tõttu saab see enneaegselt lõppeda. Loitsija füüsilise keha tapmine lõpetab samuti loitsu enneaegselt, kuigi sellel on kahetsusväärne kõrvalmõju, jättes kõik loitsijat saatvad rändurid hätta.

#### Augury (Ennustus)

(Ennustus)

| | |
| :-- | :-- |
| **Aste:** Vaimulik 2 | **Loitsimisaeg:** 2 minutit |
| **Sfäär:** Ennustus | **Kestus:** Hetkeline |
| **Maksumus:** 3/Intensiivsus | **Kaugus:** 60 jalga |
| **Ala:** Loitsija | **Vastupanu:** N/A |

See loits võimaldab loitsijal kindlaks teha, kas teatud tegevus, mida kavatsetakse ette võtta järgmise 30 minuti jooksul, on üksikisiku ja/või rühma heaolule kasulik või kahjulik. Ennete märkamiseks on vaja mingit fookuspunkti, millest kõige tavalisemad on draakoni küünised või väiksemad luud, pärl või puhas kuld, mille väärtus on vähemalt 100 GP ja mis on purustatud või sulatatud. Loitsu maksimaalne Intensiivsus on 4. Selle veeretuse peaks tegema Mängujuht, kuna loitsija ei tohiks kunagi kahtlusteta teada, kas tulemusi tõlgendati õigesti.

| Intensiivsus | Maksumus | Muutuv mõju |
| :-: | :-: | :-- |
| 1 | 3 | Vormidabel (Hirmuäratav) Channel (Kanaldamise) oskuse veeretamine |
| 2 | 6 | Hard (Raske) Channel (Kanaldamise) oskuse veeretamine |
| 3 | 9 | Standardne Channel (Kanaldamise) oskuse veeretamine |
| 4 | 12 | Easy (Lihtne) Channel (Kanaldamise) oskuse veeretamine |

Kui ennustuse veeretamine õnnestub, annab see ühe järgmistest tulemustest:

| Augury (Ennustus) | Tähendus | 
| :-: | :-- |
| Jah | Tegevus on kasulik |
| Ei | Tegevus on kahjulik |
| Jah ja ei | Tegevus on nii kasulik kui ka kahjulik |
| Mitte midagi | Tegevus ei ole ei kasulik ega kahjulik |

Fumble (koperdamine) peaks lõppema sellega, et Mängujuht ütleb reaalsusele vastupidise tulemuse.

(Abjuratsioon)

| | |
| :-- | :-- |
| **Aste:** Vaimulik 0, Maag 0 | **Loitsimisaeg:** Hetkeline |
| **Sfäär:** Kaitse | **Kestus:** Hetkeline |

Averti kasutatakse teise 0. astme loitsu tühistamiseks Kauguse piires. Averti saab heita reaktiivselt, et neutraliseerida ründavaid 0. astme loitse, kasutades Counter Magic (Vastumaagia) reaktiivset tegevust.

#### Befuddle (Segadus)

(Nõidumine (Võlumine))

| | |
| :-- | :-- |
| **Aste:** Vaimulik 0, Maag 0 | **Loitsimisaeg:** 1 käik |
| **Sfäär:** Võlumine | **Kestus:** 30 minutit |
| **Maksumus:** 1 | **Kaugus:** 60 jalga |
| **Ala:** 1 sihtmärk | **Vastupanu:** VÄG (Võimekus) |

Befuddle põhjustab kehalise sihtmärgi mõtetes segadust. Loitsu subjektil on raske selgelt mõelda, ta unustab, kus ta on, mida ta teeb ja miks – langedes sageli lahtistesse mõttekäikudesse. Segaduses sihtmärgid saavad endiselt enesekaitseks tegutseda, kuid ei saa alustada mingit konstruktiivset tegevust enne loitsu lõppu. Igasugune rünnak või ähvardav tegevus katkestab loitsu koheselt, olenemata sellest, kas see oli suunatud konkreetselt segaduses sihtmärgile või mitte.

#### Blade Barrier (Terade barjäär)

(Evokatsioon)

| | |
| :-- | :-- |
| **Aste:** Vaimulik 4 | **Loitsimisaeg:** 2 tegevust |
| **Sfäär:** Valvur, Loomine | **Kestus:** 3 vooru/Intensiivsus |
| **Maksumus:** 3+1/täiendav Intensiivsus | **Kaugus:** 100 jalga |
| **Ala:** 5–30 jala raadius | **Vastupanu:** Vt allpool |

See loits loob keerlevate viilutavate mõõkade, pistodade ja nugade barjääri, mis piitsutavad ja lõikavad ümber kindla punkti ning põhjustavad 1d8 punkti kahju 1d4+2 juhuslikule tabamuskohale _kõigile_, kes läbivad Mõjuala. Turvis pakub vaid poole oma tavapärasest kaitsest. Maagilised Turvapunktid vähendavad kahju tavapäraselt. Kuna relvad keerlevad pimestava kiirusega ja on tihedalt pakitud, on võimatu neid Parry (tõrjuda) või Evade (vältida). Kilpi saab kasutada tabamiskohtade passiivseks blokeerimiseks tavapärasel viisil. Sel juhul pidage meeles, et võrrelge veeretatud kahju kilbi turvise ja tabamispunktidega.

Loitsu võib heita kaitsvalt vaimuliku või ühe või mitme liitlase kaitsmiseks või ründavalt vaenlaste lõksupüüdmiseks. Küll aga võivad piiratud vaenlased, kes asuvad barjääri moodustamisel selle servast viie jala raadiuses, põgenemiseks sooritada Evade (vältimise) veeretuse. Sõltumata edust lõpetab vastane maaslamavas asendis, kohe väljaspool Mõjuala. Edukas veeretamine ei põhjusta kahju; vastasel juhul kannatavad nad täieliku mõju all.

#### Bless \(R\) (Õnnistus)

(Manamine)

| | |
| :-- | :-- |
| **Aste:** Vaimulik 1 | **Loitsimisaeg:** 1 voor |
| **Sfäär:** Kõik | **Kestus:** 5 minutit |
| **Maksumus:** 1 | **Kaugus:** 180 jalga |
| **Ala:** 25 jala raadius | **Vastupanu:** VÄG (Võimekus) |

Kui see loits heidetakse, õnnistab vaimulik liitlaste rühma Mõjualas. Mõjutatud kiirgavad loitsija Joondumust, kas Hea või Kurja. Neutraalsuse õnnistusi ei ole. Kõik liitlased loitsu raadiuses saavad +5% boonuse kõigile oskuste ja Vastupanu veeretustele. Lisaks põhjustavad nende relvad +1d3 kahju intelligentsele elavsurnule ning välistasandite olenditele, kellel on loitsijaga vastandlikud joondumused, näiteks deemonid, kuradid või inglid. Pange tähele, et kuigi animeeritud elavsurnud, nagu luukered ja zombrid, ei ole loomu poolest kurjad, on nad tavaliselt animeeritud kurja maagiaga ja seetõttu selle kahju suhtes vastuvõtlikud.

Selle loitsu pöördkülg, Curse (Needus), võimaldab vaimulikul vaenlasi neada, pannes nimetatud oskused kannatama ülaltoodud hüvede pöördväärtuse all. Needuses relva kahju arvutatakse karistusena ja see kahju ei saa olla väiksem kui 1 punkt.

#### Burning Hands (Põlevad käed)

(Transmutatsioon)

| | |
| :-- | :-- |
| **Aste:** Maag 1 | **Loitsimisaeg:** 1 tegevus |
| **Sfäär:** Puudub | **Kestus:** Hetkeline |
| **Maksumus:** 3+1/täiendav Intensiivsus | **Kaugus:** 0 |
| **Ala:** 120-kraadine koonus, 5 jalga pikk | **Vastupanu:** Evade (Vältimine) |

See loits põhjustab leekide väljapurskumise loitsija kätest 120-kraadises kaares. Kui lahingus kasutatakse miniatuure, kahjustab Burning Hands iga sihtmärki, mis hõivab 1 loitsija eesmistest ruutudest. Burning Handsi heitmine kõrgematel Intensiivsuse tasemetel nõuab kõrgema astme maagi. See kahju neelab kõik alal olevad sihtmärgid kahjuga, mis põhineb loitsu Intensiivsusel, kuni maksimaalse Intensiivsuseni 9, järgmiselt. Edukas Evade (vältimise) veeretamine, end pikali heites, võimaldab ohvril kahju mitte saada. Isikul, kellel on Artful Dodger (Osav kõrvalehiilija) võime, on võimalus vältida ilma pikali heitmata.

#### Tulekilp (Fire Shield)

(Evokatsioon)

| | |
| :-- | :-- |
| **Auaste:** Mage 3 | **Loitsimisaeg:** 2 tegevust |
| **Sfäär:** Puudub | **Kestus:** 2 minutit/intensiivsus |
| **Kulu:** 3+1/lisaintensiivsus | **Ulatus:** 0 |
| **Ala:** Loitsija | **Vastupanu:** N/A |

See loits loob õhukeste leekide kilbi, mis ümbritseb loitsijat, kuid ei tekita iseenesest kahju. Selle asemel kaitsevad leegid saajat kas tule või külma eest, sõltuvalt sellest, kumb variant on meeles: Chill Shield (Jahutuskilp), mis loob sinised või rohelised leegid ja kaitseb kuumuse ning tulepõhise kahju eest, või Warm Shield (Soojenduskilp), mis loob violetsed või sinised leegid ja kaitseb külma ning jääpõhise kahju eest. Leekide värvus tuleks määrata juhuslikult 50% tõenäosusega mõlemale, kuna asjaolu, et mõlemad tüübid võivad kiirgada siniseid leeke, tekitab ründajas ebakindlust. Otsus, kumba meelde jätta, tehakse loitsude ettevalmistamisel ja soovi korral võib meelde jätta mõlemad. Need leegid ei anna soojust ja heidavad valgust vaid poole tõrviku heledusest. - **Warm Shield:** Need leegid on puudutades soojad ja vähendavad kogu külmapõhise kahju poole võrra. Edukas vastupanuvise tühistab kogu kahju. Vastupanuvise on ühe astme võrra kergem ja Evade’i puhul ei pane see kaitsjat kõhuli.

Lähivõitlusrünnakud kummagi variandi saaja vastu, olgu relvastatud või relvastamata, tekitavad tavalist kahju, välja arvatud juhul, kui kasutatakse üht elementidest, mille eest kaitstakse. Sel juhul on loitsija kaitstud rünnaku elementaarse osa eest ja ründaja saab kahju, mis on võrdne tekitatuga. Ründaja kantav soomus ei paku kaitset, kuid maagilised soomuspunktid või olendi loomulik soomus vähendavad kahju tavapärasel viisil. Olendid, kellel on kaasasündinud maagiline vastupanu (Innate Magic Resistance), võivad Fire Shieldi hajutada eduka VÄG-viskega, kui saajat esimest korda tabatakse. Kui maagilise vastupanu vise ebaõnnestub, ei saa vastane Fire Shieldi hiljem tühistada.

Sõltuvalt sellest, mis põlema pandi, võivad leegid levida, kui neid ei summutata või mingil moel ei peatata. Seda loitsu kasutatakse tavaliselt küünalde, tõrvikute või laternate süütamiseks kaugelt. Seda saab kasutada ka lõkke või toiduvalmistamise tule süütamiseks ebasoodsates tingimustes, näiteks niiske hagu kasutades või tugeva tuulega.

Kustutamine summutab viivitamatult mõõduka suuruse ja kuumusega leegid ja väikesed tuled. See on kasulik küünalde, laternate, tõrvikute või väikeste toidutulede kustutamiseks, kuid see ei toimi maagiliste või suuremate, raevukamate tulekahjude puhul nagu tuleriidad, põlevad majad või draakonituli.

#### Magic Missile

(Evokatsioon)

| | |
| :-- | :-- |
| **Auaste:** Mage 1 | **Loitsimisaeg:** 1 tegevus |
| **Sfäär:** Puudub | **Kestus:** Hetkeline |
| **Maksumus:** 1/Intensiivsus | **Ulatus:** 100 jalga/Intensiivsus |
| **Ala:** 1-5 sihtmärki | **Vastupanu:** Vaata allpool |

Selle loitsu manamisel sööstavad maagia kasutaja sõrmeotstest välja üks või mitu maagilise energia raketti ja tabavad sihtmärki. Maksimaalne rakettide arv, mida saab genereerida, põhineb manaja Arcane Casting-oskustasemel: teine rakett genereeritakse 60% oskuse juures, kolmas 70% juures, neljas 80% juures ja viies ning viimane rakett 90% juures. Nende rakettide genereerimiseks peab loits olema manatud intensiivsusega, mis võrdub soovitud rakettide arvuga. Näiteks alla 60% oskuse korral saavutab maagia kasutaja, kes manab Magic Missile-loitsu 3. intensiivsusega, küll pikema ulatuse, kuid genereeritakse vaid üks rakett. 70% oskustasemega maagia kasutaja võiks manada loitsu sama 3. intensiivsusega, saavutada sama ulatuse, kuid genereerida 3 raketti. Selle loitsu maksimaalne intensiivsus on 5. Vaadake allolevat tabelit.

Magic Missile tabab eksimatult, isegi kui sihtmärk on lähivõitluses või osaliselt varjus. Neid rakette ei saa vältida; aga täielikus varjus olevat vastast ei saa selle loitsuga sihtida. Shield-loits tõrjub Magic Missile-raketid automaatselt eeldusel, et sihtmärk on teadlik ja/või suunatud manaja poole. Magic Missile teeb 1d6+1 kahjupunkti ja kantav soomus ei kaitse, kuid olendi loomulik soomus või maagilised soomuspunktid vähendavad kahju tavapäraselt. Magic Missile ei põhjusta kahju elututele objektidele, nagu uksed, lukud jne.

Mitme raketi tulistamisel võib manaja lasta neil tabada ühte olendit või sihtida mitut olendit. Iga Magic Missile tabab juhuslikku tabamiskohta – konkreetseid tabamiskohti ei saa sihtida. Manaja peab enne kahju veeretamist määrama iga raketi individuaalsed sihtmärgid.

#### Magic Mouth

(Transmutatsioon)

| | |
| :-- | :-- |
| **Auaste:** Mage 2 | **Loitsimisaeg:** 1 minut |
| **Sfäär:** Puudub | **Kestus:** Vaata allpool |
| **Maksumus:** 3, +1/lisaintensiivsus | **Ulatus:** 30 jalga |

See suu lausub seejärel mis tahes eelnevalt määratletud fraasi, mille manaja loitsimise ajal valis. See fraas ei tohi koosneda rohkem kui 25 sõnast ja suu lausub need kiirusega umbes 1 sõna sekundis. Suu ei tohi lausuda väesõnu ega manada loitse.

Seda loitsu saab manada mis tahes tavaliselt elutule objektile, alates sambast või puust kuni kiviseina või kirstuni; see on aga eriti tõhus, kui see manatakse kujule, kuna kuju ise näeks välja, nagu ta räägiks. Käivitav efekt ei saa olla midagi, mida ei saa tuvastada mittemaagiliselt, näiteks nähtamatu olend, olendi maailmavaade, oskus, klass jne. Siiski võib see määratleda kantavaid riideid. Maksimaalne kaugus, millelt loitsu saab käivitada, on 25 jalga intensiivsuse kohta.

Selle loitsu kestus on püsiv kuni lummus on aktiveeritud, misjärel loits lõpeb.

#### Polymorph Other

(Transmutatsioon)

| | |

Transformatsioon annab saajale eeldatud olendi hingamisviisi, kui see erineb tavalisest; kõik looduslikud rünnakud; ja kõik maised liikumisviisid. See ei anna mingeid kõrgendatud või maagilisi võimeid, mida olend omas. Näiteks olend, kes on polümorfeeritud draakoniks, ei saa draakoni hingeõhurünnakut ega loitsulaadseid võimeid, kuid saab lennuvõime, karmi naha, surmava hammustuse, küünistega rünnakud jne. Lisaks omandab ohver uue vormi füüsilised oskused, nagu Kergejõustik, Toorus (Brawn), Lendamine, Ujumine, samuti selle Elupunktid ja Kahjumuutja. Eeldades, et transformeeritud isik säilitas oma INT, kaotab ta siiski võime rääkida, välja arvatud juhul, kui uuel vormil on võime sõnu liigendada. Need, kes olid võimelised oma eelmises vormis loitse heitma, suudaksid seda endiselt uues vormis, eeldades, et neil on endiselt võime tekitada verbaalseid ja somaatilisi komponente. Drastilise muutuse korral, näiteks kahejalgselt neljajalgseks või maa-loomast mereolendiks muutumisel, peaks mängujuht tundma end vabalt karistamaks vähemalt ühe raskusastmega nende oskuste kasutamist, mille õppimine võtaks aega uue vormiga kohanemisel, kuni on olnud piisavalt aega harjutamiseks. See kehtib eriti füüsiliste oskuste kohta nagu Kergejõustik, Relvitu, Ujumine, Lendamine, Võitlusoskused jne.

VÄG-i vise isiksuse säilitamiseks on nõutav iga päev, mil subjekt jääb transformeerituks, kuni see ebaõnnestub, põhjustades inimesel lõpuks alistumise uue vormi mentaliteedile, kusjuures mittetundliku olendi puhul muutub INT INS-ks. Kõik uue vormi erilised ja maagilised võimed, mida varem ei omandatud, nagu pilgurünnakud, hingeõhurünnakud jne, on nüüd olendile kättesaadavad, kui transformatsioon on lõppenud. Tegelased, kes sel viisil oma identiteedi kaotavad, muutuvad Mängujuhi kontrollitavateks Mitte-Mängija Tegelasteks (NPC-deks).

Enne transformatsioonile vaimselt alistumist on polümorfeeritud olend vastuvõtlik Dispel Magic loitsule tavapärasel viisil, ilma et oleks vaja vastupanuvistet, kuna see oleks kellegi alateadlik soov naasta normaalsesse olekusse. Transformatsioon nõuab pingele vastuseismiseks veel ühte VÄG-i viset, kusjuures ebaõnnestumine uimastab subjekti 1d10 minutiks ja äpardus (fumble) põhjustab surma vaimse šoki tõttu.

Kui ohver oli varem uuele vormile alistunud, võib Dispel Magic loitsu siiski kasutada; siiski üritab ohver loomulikku vormi naasmisele vastu seista VÄG-i viskega. Selle viske ebaõnnestumine tähendab, et ohver muutub tagasi loomulikku vormi, mis muidugi nõuab veel ühte VÄG-i viset transformatsioonist tingitud vaimse šoki tõrjumiseks. Kui ohvri loomulik identiteet on kord kadunud, pole see enam saavutatav; selle asemel eeldab ohver, et kummaline ja võõras vorm on loomulik, ning igatseb naasta oma eelmise "normaalse" oleku juurde. _Näiteks ork, kes oli polümorfeeritud küülikuks ja võttis omaks olendi identiteedi, usuks, et ta on nüüd küülik, kes on üsna ebaviisakalt orkiks muudetud._ Ainult Wish või muu sarnane maagia võib ohvri identiteedi taastada, kui see on kord kadunud.

Kogu kantav ja kaasasolev varustus sulandub maagiliselt uude vormi; siiski võib mängujuht mõnel juhul lubada maagilistel esemetel, mida saaks uues vormis kasutada, alles jääda, näiteks maagiline sõrmus või saapad. Pange tähele, et see nõuab, et olendi uus SUU ei oleks algsest oluliselt erinev. Iga mitte-ründava maagilise eseme kohta on VÄG x1% tõenäosus (mängujuhi heakskiidul), et see kannab oma efektid üle olendi uude vormi. Näiteks +1 kaitsega sõrmust kandev olend võib saada +1 boonuse oma loomulikele Soomuspunktele. Olendid, kellel on loomulik võime vormi muuta, nagu doppelgängerid ja lükantroobid, transformeeritakse tavapäraselt, kuid võivad pärast 1 vooru oma loomuliku vormi võtta. Kui polümorfeeritud olend tapetakse, pöördub ta tagasi oma loomuliku vormi, isegi kui ta on varem kaotanud kõik identiteedi jäljed.

**Tulemüür:** See loitsu versioon loob statsionaarse tulemüüri pikkusega 20 jalga intensiivsuse kohta. Sõltumata lõplikust intensiivsusest on müüri kõrgus loitsimisel soovi kohaselt 10 kuni 20 jalga. Tulemüüril on ulatus 180 jalga ja seda ei tohi kutsuda horisontaalselt.

**Tulerõngas:** See loitsu versioon loob loitsu esitaja ümber tulerõnga, mis liigub nendega kaasa. Selle raadius on 10 jalga, pluss 5 jalga iga täiendava intensiivsuse kohta pärast esimest. Sõltumata lõplikust intensiivsusest on rõnga kõrgus loitsimisel soovi kohaselt 10 kuni 20 jalga. Tulerõngas peab ümbritsema loitsu esitajat ja selle ulatus on 0.

Müüri või rõnga loitsu esitajast eemale suunatud külg kiirgab kõrvetavat kuumust, põhjustades 1d6 kahju voorus kõigile 10 jala raadiuses ja 1d4 kahju kuni 20 jala kaugusel. See kahju rakendub tavaliselt vooru lõpus enne järgmise vooru alustamist. Kui ohver hõivab mõlemas soojusvööndis ühe vooru jooksul, rakendub suurem kahju. Leekidest läbi hüppajad saavad 2d6 punkti kahju, pluss ühe lisapunkti kahju iga intensiivsuse kohta pärast esimest. See kahju rakendub igale tabamiskohale ja kantav soomus ei paku kaitset, kuid maagilised soomuspunktid või olendi loomulik soomus vähendavad kahju tavapäraselt. Edukas vältimise (Evade) vastupanuvise võimaldab ohvril mitte saada kahju voorus, mil loits ellu ärkab, kui ohver üritab kuumuse eest või leekidest mööda hüpata. Tuld kasutavad olendid saavad poole sellest kahjust ja külma kasutavad olendid topelt. Leekidel on võimalus süüdata kergestisüttivaid materjale võrdselt veeretatud kahjuga x5%. Lisateabe saamiseks vaadake jaotist [Tuli](0007_Game_System.md?id=fire-based-attacks).

Kui see ebaõnnestub, jääb sihtmärk kinni, olles suutmatu ainult jõuga vabaneda. Läbilõikamisega vabanemise üritamine eksponeerib kasutatava tööriista või relva samale protsessile. Hoolimata levinud uskumusest ei ole võrgud tuleohtlikud, kuid tegelane võib leegiga aeglaselt võrku läbi põletada, et kiud kokku tõmbuksid (tulekahju eirab võrgu soomuspunkte).

#### Soov

Soov võib muuta reaalsust püsivalt ja märkimisväärsel viisil. Selle loitsu esitamiseks peab maag kulutama 3 maagilist punkti ja 1 või enam EXP-punkti, sõltuvalt soovitud tulemustest. Iga järgnev Soovi esitamine 1-kuulise perioodi jooksul kahekordistab tavapäraselt nõutava EXP-kulu. Loitsimisaeg kulub tavaliselt soovi eripärade suuliseks üksikasjalikuks kirjeldamiseks. Pärast lõpetamist kannatab loitsu esitaja väsimuse all, mis võrdub kulutatud EXP-ga, ja vananeb 5% oma normaalsest elueast (inimeste puhul oleks see viis aastat). On 10% võimalus, et ahnete kavatsustega tehtud Soov nurjub mingil viisil. Näiteks rikkuse soovimine võib selle teleportida kohaliku isanda või kuninga varakambritest. Soov ei saa tühistada jumalike olendite dekreete, välja arvatud juhul, kui selline olend ise nimetatud Soovi väljastas.

#### Maagi nägemine

(Transmutatsioon)

| | |
| :-- | :-- |
| **Auaste:** Maag 3 | **Loitsimisaeg:** 1 minut |
| **Sfäär:** Puudub | **Kestus:** 1 minut/intensiivsus |
| **Kulu:** 1/intensiivsus | **Ulatus:** 0 |
| **Ala:** Vaata allpool | **Vastupanu:** Puudub |

See loits loob väikese nähtamatu "silma", mida maag võib loitsu kestuse ajal läbi vaadata. Seda silma saab liigutada rühma ees või saata seda nurkade taha ja tubadesse vaatama, liikumiskiirusega 20 jalga voorus (240 jalga minutis), kui skaneeritakse ainult 'ilmsete' ohtude või huvipakkuvate esemete suhtes. See laieneb tavaliselt ainult põrandale ja alumistele seintele. Kui püütakse olla põhjalikum (uurides ka kõiki seinu ja lage), väheneb selle liikumiskiirus 10 jalani voorus (120 jalga minutis). Mängujuht peaks tundma end vabalt, lubades vajadusel loitsu esitajal teha tajumise (Perception) viskeid seoses visuaalsete anomaaliate märkamisega. Silm on korpuskulaarne, ei suuda läbida tahket mateeriat ja sellel on normaalne nägemine kuni 60 jala ulatuses ning hämarikunägemine kuni 10 jala ulatuses. Loitsu esitaja peab silma peal kontsentreerumist kogu kestuse jooksul säilitama, vastasel juhul jääb see inertsena püsima, kuni kontsentratsioon on uuesti loodud. Kõik pilgurünnakud, mis tavaliselt mõjutaksid loitsu esitajat, mõjutavad teda endiselt tavapäraselt; silma loetakse siiski loitsu esitajast sõltumatuks pimestamise, pimeduse loitsude ja muu sellise osas. Väikestest avaustest läbimahtumiseks ei ole silm suurem kui 1 toll ja selle SUU on 1.

#### Tagasikutsumise sõna

(Transmutatsioon)

| | |
| :-- | :-- |
| **Auaste:** Vaimulik 4 | **Loitsimisaeg:** 1 tegevus |
| **Sfäär:** Kutsumine | **Kestus:** Vaata allpool |
| **Kulu:** 3, +1 iga täiendava intensiivsuse kohta | **Ulatus:** 0 |
| **Ala:** Loitsu esitaja | **Vastupanu:** Puudub |

Kui see loits on esitatud, teleportreeritakse vaimulik viivitamatult eelnevalt määratud pühamusse ja määratud saabumispunkti, mis pole suurem kui 10-jalane raadius. Teleporteeritava tegeliku ulatuse suhtes pole piiranguid, sealhulgas mitme tasandi vahel. Ühe tasandi piires pole õnnetuse võimalust, kuid isegi ühe tasandi ületamine annab põrumisvõimaluse (Fumble) 91-00%, kahe tasandi ületamine annab põrumise 81-00% veerel ja nii edasi. See asendab loitsu esitaja tavalise põrumisvõimaluse. Põrumine tasandite vahetamisel tähendab, et vaimulik on jäädavalt kadunud. Põrumised ühe tasandi piires järgivad tavalisi reegleid.

Lisaks endale ja kaasaskantavale varustusele võib vaimulik transportida veel 3 eset intensiivsuse kohta, igaüks mitte suurem kui SUU/9 'asja'. Transportitav täiendav materjal võib olla aare, varustus või elusolendid. Siiski peab transporditavate olendite jaoks loits olema esitatud piisava intensiivsuse tasemel, et katta kogu kaasaskantav varustus.
