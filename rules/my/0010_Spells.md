#### Appraise (တန်ဖိုးဖြတ်ခြင်း)

(Divination - နိမိတ်ဖတ်ခြင်း)

| | |
| :-- | :-- |
| **အဆင့်:** မှော်ဆရာ 0 | **အသုံးပြုချိန်:** 1 Turn |
| **နယ်ပယ်:** မရှိ | **ကြာချိန်:** ချက်ချင်း |
| **ကုန်ကျစရိတ်:** 1 | **အကွာအဝေး:** ထိတွေ့ |
| **ဧရိယာ:** 1 Item | **ခုခံမှု:** မရှိ |

Appraise သည် မှော်သုံးသူ၏ POW နှင့်ညီမျှသော SIZ သို့မဟုတ် 'Things' တွင်ပေါင်းစပ်ထားသော ရုပ်ပိုင်းဆိုင်ရာပစ္စည်းများ၏ အရည်အသွေးကို ချက်ချင်း အကဲဖြတ်ခွင့်ပေးသည်။ ဤစာလုံးပေါင်းသည် ပုံစံတူပစ္စည်းများမှာ အရည်အသွေးချင်း တူညီသည် သို့မဟုတ် ဆင်တူသည်ကိုလည်းကောင်း၊ တစ်ခုခုမှာ ချို့ယွင်းနေသည် သို့မဟုတ် ပိုမိုအရည်အသွေးမြင့်မားသည်ကိုလည်းကောင်း ဆုံးဖြတ်ပေးသည်။ ဤစာလုံးပေါင်းသည် အော်ဂဲနစ်မဟုတ်သော အရာဝတ္ထုများအတွက်သာ အလုပ်လုပ်ပြီး အော်ဂဲနစ်အရာများအတွက် အလုပ်မလုပ်ပါ။ ၎င်းသည် ချို့ယွင်းချက်များ သို့မဟုတ် တိုးတက်မှုများ ရှိနေသည်ဟုသာ ပြောပြနိုင်ပြီး၊ မည်သည့်ချို့ယွင်းချက် သို့မဟုတ် တိုးတက်မှုမျိုးလဲဆိုသည်ကို မဆုံးဖြတ်ပေးနိုင်ပါ။ မှော်ပညာကို ခွဲခြားသတ်မှတ်ရန် သို့မဟုတ် ရှာဖွေရန်အတွက်မူ ၎င်းကို အသုံးမပြုနိုင်ပါ။

#### Armor (သံချပ်ကာ)

(Conjuration - ဆင့်ခေါ်ခြင်း)

| | |
| :-- | :-- |
| **အဆင့်:** မှော်ဆရာ 1 | **အသုံးပြုချိန်:** 1 Round |
| **နယ်ပယ်:** မရှိ | **ကြာချိန်:** အောက်တွင်ကြည့်ပါ |
| **ကုန်ကျစရိတ်:** 3 +1/Intensity | **အကွာအဝေး:** ထိတွေ့ |
| **ဧရိယာ:** 1 Target | **ခုခံမှု:** မရှိ |

ဤစာလုံးပေါင်းကို အသုံးပြုသောအခါ၊ ပစ်မှတ်သည် သံချပ်ကာအဆင့်နှင့်ညီမျှသော မမြင်နိုင်သော မှော်စွမ်းအင်တံတိုင်းတစ်ခုကို ရရှိမည်ဖြစ်ပြီး ထိမှန်နိုင်သောနေရာ (Hit Location) တစ်ခုစီအတွက် 4 Armor Points ကို ပေးအပ်သည်။ အကယ်၍ သံချပ်ကာ ဝတ်ဆင်ထားပြီးသားသူအပေါ်တွင် အသုံးပြုပါက အကျိုးသက်ရောက်မှု မရှိပါ။ သို့သော် ၎င်းသည် ပိုမိုကောင်းမွန်သော ကာကွယ်မှုပေးပါက ၎င်း၏ကြာချိန်အတွင်း သဘာဝသံချပ်ကာထက် သာလွန်မည်ဖြစ်သည်။ သဘာဝသံချပ်ကာ 4 မှတ်ထက်ပိုသော သတ္တဝါအပေါ်တွင် အသုံးပြုပါက၊ ထိမှန်နိုင်သောနေရာအားလုံးတွင် Armor Points ကို 1 မှတ် တိုးမြှင့်ပေးမည်ဖြစ်သည်။ ဤမှော်ကာကွယ်မှုသည် လှုပ်ရှားမှု သို့မဟုတ် စာလုံးပေါင်းရွတ်ဆိုခြင်းကို အနှောင့်အယှက်မဖြစ်စေပါ။ ဤစာလုံးပေါင်းသည် မှော်ပညာဖြင့် ဖျက်သိမ်းခြင်း မခံရသရွေ့ သို့မဟုတ် မှော်သုံးသူသည် တိုက်ခိုက်မှုတစ်ခုတည်းမှ ထိခိုက်မှု 8 မှတ် (Intensity တစ်ဆင့်စီအတွက် +1 မှတ်) ခံရသည့်တိုင်အောင် တည်ရှိနေမည်ဖြစ်သည်။ မှော်သုံးသူသည် လိုအပ်ပါက အချိန်မရွေး ဖျက်သိမ်းနိုင်ပြီး အိပ်စက်ရန်အတွက်လည်း ဖျက်သိမ်းရမည်ဖြစ်သည်။
