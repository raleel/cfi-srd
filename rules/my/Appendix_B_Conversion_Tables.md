# နောက်ဆက်တွဲ- အတိုင်းအတာပြောင်းလဲခြင်း ဇယားများ

---
#### အင်ပီးရီးယား အလေးချိန်နှင့် အတိုင်းအတာများမှ မက်ထရစ်စနစ်သို့ ပြောင်းလဲခြင်း

_Classic Fantasy Imperative_ အား ပိုမိုရှင်းလင်းပြတ်သားပြီး ဖတ်ရှုရလွယ်ကူစေရန်နှင့် ဖော်ပြချက်များ၊ ဇယားများကို ကျစ်လျစ်စေရန်အတွက် _Classic Fantasy Imperative_ စာတန်းသည် အင်ပီးရီးယားနှင့် မက်ထရစ် နှစ်မျိုးလုံးအစား အင်ပီးရီးယား အတိုင်းအတာများကိုသာ အဓိကထား အသုံးပြုထားပါသည်။ ဤအမျိုးအစားတွင် အခြားဂိမ်းများအသုံးပြုသည့် စွန့်စားခန်းများ၊ တိုက်ပွဲမြေပြင် (battlemats) နှင့် မြေပုံအများစုသည် အင်ပီးရီးယားစနစ်ကို အသုံးပြုသောကြောင့် လက်ရှိပစ္စည်းများကို ပြောင်းလဲအသုံးပြုရ လွယ်ကူစေရန် အင်ပီးရီးယားစနစ်ကို ရွေးချယ်ခြင်းဖြစ်သည်။ သို့သော် မက်ထရစ်စနစ်ကို အသုံးပြုလိုသူများအတွက် အများဆုံးအသုံးပြုသော အလေးချိန်နှင့် အတိုင်းအတာများကို အောက်ပါဇယားများတွင် ပြောင်းလဲဖော်ပြထားပါသည်။ ကျွန်ုပ်တို့သည် လက်တွေ့ကမ္ဘာရှိ သတ္တဝါများ၊ စာလုံးပေါင်းများနှင့် အခြားအရာများကို ကိုင်တွယ်နေခြင်းမဟုတ်သည့်အတွက် ကျွန်ုပ်တို့ဖန်တီးထားသော အလေးချိန်နှင့် အတိုင်းအတာများတွင် အနည်းငယ် လိုက်လျောမှုပြုလုပ်နိုင်ပါသည်။ တိကျသော ပြောင်းလဲမှုများကို အသုံးပြုမည့်အစား အလွယ်တကူမှတ်မိနိုင်ပြီး ဂိမ်းကစားခြင်းကို ပိုမိုလွယ်ကူစေမည့် ပြောင်းလဲမှုများကို အသုံးပြုခြင်းက ပို၍သင့်လျော်ပါသည်။

လေတိုက်နှုန်း၊ အထူးသဖြင့် လေတိုက်နှုန်း အလွန်ပြင်းထန်ခြင်းသည် လုပ်ဆောင်ချက်များအပေါ် ဆိုးကျိုးသက်ရောက်နိုင်ပါသည်။ လေ၏အား (STR) ကို တစ်နာရီလျှင် မိုင်နှုန်းဖြင့် ဖော်ပြသည်။ ရုပ်ပိုင်းဆိုင်ရာ ကျွမ်းကျင်မှုများ - STR သို့မဟုတ် DEX ပါဝင်သည့် ကျွမ်းကျင်မှုများ - အပေါ် သက်ရောက်မှုကို ကျွမ်းကျင်မှု ကော်လံတွင် အသေးစိတ်ဖော်ပြထားပြီး ရွေ့လျားမှုနှုန်းအပေါ် သက်ရောက်မှုကို ရွေ့လျားမှုနှုန်း ကော်လံတွင် ကြည့်ရှုနိုင်ပါသည်။
 
_ဥပမာအားဖြင့်၊ STR 40 ရှိသည့် လေမုန်တိုင်းအပျော့သည် လူသားတစ်ဦး၏ လမ်းလျှောက်နှုန်းကို သုံးပုံနှစ်ပုံအထိ လျှော့ချပေးပြီး ကျွမ်းကျင်မှုများကို ခက်ခဲသော အခက်အခဲအဆင့်ဖြင့် လှိမ့်ကစားရမည်ဖြစ်သည်။_

#### အပူချိန်ဇယား

| အပူချိန် (ºF) | အမျိုးအစား | အန္တရာယ် |
| :-: | :-: | :-- |
| < 2º | ရေခဲပြင်ကဲ့သို့အေး | ချက်ချင်းအနွေးဓာတ်ရှာပါ |
| 3-14º | အေးခဲ | ၁၅ မိနစ် |
| 13-32º | အေး | တစ်နာရီလျှင် |
| 33-50º | အေးစိမ့် | တစ်ရက်လျှင် |
| 51-68º | အေးမြ | - |
| 69-86º | နွေး | - |
| > 86º | ပူ | တစ်နာရီလျှင် |

ရာသီဥတု၊ ရာသီနှင့် အမြင့်ပေတို့ပေါ်မူတည်၍ အပူချိန်သည် သိသိသာသာ ကွာခြားနိုင်ပြီး ကမ်ပိန်းကမ္ဘာနှင့် ဇာတ်လမ်းတည်ဆောက်ထားသည့် နေရာပေါ်တွင် မူတည်ပါသည်။ အထက်ပါဇယားသည် ဇာတ်ကောင်များအပေါ် အစွန်းရောက် အပူချိန်၏ သက်ရောက်မှုများအတွက် လမ်းညွှန်ချက်ကို ပံ့ပိုးပေးပါသည်။

သင့်လျော်သောအဝတ်အစားကို ဝတ်ဆင်ထားခြင်းဖြင့် ဇာတ်ကောင်တစ်ဦးသည် ၎င်းတို့၏ CON ပမာဏအတိုင်း နာရီအလိုက် အန္တရာယ်ကို ခံနိုင်ရည်ရှိသည့် အချိန်ကာလကို ရရှိမည်ဖြစ်သည်။ ဤအချိန်ကျော်လွန်ပါက ၎င်းတို့သည် အမိုးအကာရှာရန် သို့မဟုတ် ပင်ပန်းနွမ်းနယ်မှု (Fatigue) ဆုံးရှုံးမှုကို စတင်ခံစားရပါမည်။ ကိုယ်စိုရွှဲနေသော ဇာတ်ကောင်များသည် အန္တရာယ်နှုန်းကို တစ်ဆင့်ပို၍ အေးသည့်အဆင့်သို့ ပြောင်းလဲသွားစေသည်။ လေမုန်တိုင်းအပျော့ သို့မဟုတ် အလတ်စားလေတိုက်နှုန်းများသည်လည်း အန္တရာယ်နှုန်းကို တစ်ဆင့်ပို၍ အေးသည့်အဆင့်သို့ ပြောင်းလဲစေပြီး လေမုန်တိုင်းအပြင်းနှင့် မုန်တိုင်းများသည် နှစ်ဆင့်ပို၍ ပြောင်းလဲစေသည်။
