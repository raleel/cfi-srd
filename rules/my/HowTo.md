# ကြိုတင်လိုအပ်ချက်များ

၁။ [markdown ဘာသာစကား](https://www.markdownguide.org/basic-syntax/) အကြောင်း အခြေခံနားလည်မှု။

၂။ အကယ်၍ သင့်တွင် [github](https://github.com/) အကောင့်မရှိသေးပါက အခမဲ့အကောင့်တစ်ခု ပြုလုပ်ရန် လိုအပ်ပါမည်။ သင့် RPG ဂိမ်း၏အမည်ကို အသုံးပြုရန် အကြံပြုလိုပါသည်၊ အဘယ်ကြောင့်ဆိုသော် ၎င်းသည် လူများက သင့် SRD ကိုဝင်ရောက်ကြည့်ရှုရန် အသုံးပြုမည့် URL ၏ အစိတ်အပိုင်းတစ်ခု ဖြစ်လာမည်ဖြစ်သောကြောင့် ဖြစ်သည်။

၃။ Git ကိုမသိဘဲ ဘရောက်ဆာမှတစ်ဆင့် ဤလုပ်ငန်းစဉ်တစ်ခုလုံးကို သင်လုပ်ဆောင်နိုင်ပါသည်။ သို့သော် github desktop ကို သင်ယူခြင်းက ကမ္ဘာ့လူအများအား မပြသမီ ပြောင်းလဲမှုမှန်သမျှကို ဒေသတွင်း (locally) စမ်းသပ်နိုင်စေမည်ဖြစ်သည်။

> အကယ်၍ သင့်တွင် မှတ်ပုံတင်ထားသော domain name တစ်ခုရှိပါက၊ ဤလုပ်ငန်းစဉ်နှင့်အတူ အသုံးပြု၍ ကျွန်ုပ်ပြုလုပ်ထားသည့် https://srd.7thextinctionrpg.com ကဲ့သို့သော SRD တစ်ခုကို ဖန်တီးနိုင်ပါသည်။

## သင့်အကြောင်းအရာများကို ထည့်သွင်းခြင်း

### *.md ဖိုင်များ

.md ဖိုင်များသည် markdown ဖိုင်များဖြစ်သည်။ Markdown သည် စာသားစာရွက်စာတမ်းများတွင် ဖော်မတ်ချသည့် အစိတ်အပိုင်းများကို ထည့်သွင်းရန် သင်အသုံးပြုနိုင်သော ပေါ့ပါးသည့် markup ဘာသာစကားတစ်ခုဖြစ်သည်။ သင့်အကြောင်းအရာ၏ အရွယ်အစားပေါ်မူတည်၍ သင့်ဂိမ်းအချက်အလက်အားလုံးကို *.md ဖိုင်တစ်ခုတည်းတွင် ထည့်သွင်းနိုင်သည်၊ သို့မဟုတ် ကျွန်ုပ်၏ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) တွင် ပြုလုပ်ထားသကဲ့သို့ အခန်းတစ်ခုစီအတွက် သီးခြားဖိုင်များ ခွဲ၍ဖန်တီးနိုင်ပါသည်။ "sample.md" တွင် ဖော်မတ်ချခြင်းဆိုင်ရာ နမူနာအချို့ ပါဝင်သည်။

Markdown ဘာသာစကားသည် သင်ယူရန် အလွန်လွယ်ကူသည်။ စာကြောင်းဆက်စပ်မှု (syntax) အပြည့်အစုံအတွက် အထက်ပါ ကြိုတင်လိုအပ်ချက်များအောက်ရှိ အချက် ၂ တွင် ပေးထားသော လင့်ခ်ကို အသုံးပြုပါ။

### _Sidebar.md

၎င်းသည် ဝဘ်ဆိုက်၏ ဘယ်ဘက်ခြမ်းတွင်ရှိသော သင်၏ မီနူးနှင့် လမ်းညွှန်ချက်ပြား ဖြစ်သည်။ သင်၏ repository ထဲသို့ markdown ဖိုင်တစ်ခု ထည့်သွင်းပြီးသည်နှင့် ၎င်း၏အကြောင်းအရာများ ပါဝင်လာစေရန်အတွက် ဤနေရာတွင် ထိုဖိုင်ကို ထည့်သွင်းရန် လိုအပ်သည်။ ရှိပြီးသား ဖော်မတ်စနစ်အတိုင်း လိုက်နာပါ။


## Repository ကို ဝဘ်ဆိုက်တစ်ခုအဖြစ် ပြောင်းလဲရန် Github Pages ကို ဖွင့်ခြင်း

၁။ သင့် repository ထဲတွင် 'Settings' ကို နှိပ်ပါ။

![Website-Step1](/_media/Website-Step1.png)

၂။ ဘယ်ဘက်ခြမ်း မီနူးရှိ 'Pages' ကို ရွေးချယ်ပါ။

![Website-Step2](/_media/Website-Step2.png)

၃။ အကယ်၍ သင်သည် repository ကို 'public' (အများသုံး) မဖြစ်သေးပါက ရွေးချယ်စရာနှစ်ခု ရှိပါသည်
    က။ Repository ကို public လုပ်ခြင်းဖြင့် သင့် SRD ဝဘ်ဆိုက်ကို Github pages တွင် အခမဲ့ hosting လုပ်နိုင်မည်။
    ခ။ သင့် Github အကောင့်ကို အဆင့်မြှင့်တင်ခြင်း (ဤစာရေးချိန်တွင် တစ်လလျှင် $4 သို့မဟုတ် တစ်နှစ်လျှင် $48 ကျသင့်သည်)

၄။ 'Branch' အောက်တွင် 'main' ကို ရွေးချယ်ပြီး save ကို နှိပ်ပါ။

၅။ ၁၀ စက္ကန့်မှ စက္ကန့် ၂၀ ခန့် စောင့်ပြီးနောက် စာမျက်နှာကို refresh လုပ်ပါ။

၆။ ယခုအခါ https://coweater.github.io/mysrd/ ကဲ့သို့သော သင့် URL ကို မြင်တွေ့ရပါမည်။

## ဖောင့်များပြောင်းလဲခြင်း

၁။ /_assets/style.css ဖိုင်ကို ပြင်ဆင်ပါ။

၂။ 'body section' အောက်တွင် siteFont နှင့် headingFont တို့ကို တွေ့ရပါမည်။

၃။ ၎င်းတို့ကို သင်အသုံးပြုလိုသော ဖောင့်များဖြင့် ပြောင်းလဲပါ။


## သင့် SRD တွင် အခမဲ့ icon များပြသရန် Fontawesome နှင့်/သို့မဟုတ် Material Icons plugin ကို အသုံးပြုခြင်း

### Fontawesome

အခမဲ့ icon များနှင့် အန်နီမေးရှင်း icon များရယူရန် Fontawesome ကို အသုံးပြုပါ။ အခပေး (Subcribed) အသုံးပြုသူများသည် Pro Icons များကို သုံးနိုင်ပါသည်။

၁။ [Fontawesome](https://fontawesome.com/icons) တွင် icon ကို ရှာပါ။
၂။ icon ကို ရွေးချယ်ပါ။
၃။ ပေါ်လာသော window တွင် HTML tab အောက်မှ " " ကြားရှိ အရာအားလုံးကို ကူးယူပါ။

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

၄။ ကူးယူထားသော စာသားကို `:` ကြားတွင် နေရာလပ်မထားဘဲ ထည့်ပါ။

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ပိုမိုများပြားသော အခမဲ့ icon များအတွက် Material Icons ကို အသုံးပြုပါ။

၁။ [Material Icons](https://fonts.google.com/icons) တွင် icon များကို ရှာပါ။
၂။ web span လင့်ခ်ကို ကူးယူပြီး သင့် markdown ဖိုင်များထဲသို့ တိုက်ရိုက် ထည့်သွင်းပါ။

```markup
<span class="material-icons">face</span>
```
