#### மதிப்பீடு (Appraise)

(முன்னுணர்தல் - Divination)

| | |
| :-- | :-- |
| **தரம்:** மந்திரவாதி 0 | **மந்திர உச்சரிப்பு நேரம்:** 1 திருப்பம் (Turn) |
| **கோளம்:** எதுவுமில்லை | **கால அளவு:** உடனடி |
| **செலவு:** 1 | **வரம்பு:** தொடுதல் |
| **பரப்பு:** 1 பொருள் | **எதிர்ப்பு:** எதுவுமில்லை |

மதிப்பீடு மந்திரமானது, மந்திரவாதியின் POW-க்கு சமமான அளவுள்ள, ஒரு பொருளின் தரத்தை உடனடியாக மதிப்பிட அனுமதிக்கிறது. ஒரே மாதிரியான தோற்றமுடைய பொருட்கள் அதே அல்லது ஒத்த தரத்தில் உள்ளதா, அல்லது ஏதேனும் ஒன்று குறைபாடுடையதா அல்லது உயர்ந்த தரத்தில் உள்ளதா என்பதை இந்த மந்திரம் தீர்மானிக்கிறது. இந்த மந்திரம் உயிரற்ற பொருட்களுக்கு மட்டுமே வேலை செய்யும், உயிருள்ள பொருட்களுக்கு வேலை செய்யாது. இது என்ன குறைபாடுகள் அல்லது மேம்பாடுகள் உள்ளன என்பதைத் தீர்மானிக்காது; அவை இருப்பதை மட்டுமே உறுதிப்படுத்தும். மந்திரத்தை அடையாளம் காணவோ அல்லது கண்டறியவோ இது உதவாது.

#### கவசம் (Armor)

(படைப்பு - Conjuration)

| | |
| :-- | :-- |
| **தரம்:** மந்திரவாதி 1 | **மந்திர உச்சரிப்பு நேரம்:** 1 சுற்று (Round) |
| **கோளம்:** எதுவுமில்லை | **கால அளவு:** கீழே காண்க |
| **செலவு:** 3 +1/தீவிரம் | **வரம்பு:** தொடுதல் |
| **பரப்பு:** 1 இலக்கு | **எதிர்ப்பு:** எதுவுமில்லை |

இந்த மந்திரம் உச்சரிக்கப்படும் போது, இலக்கிற்கு மாய சக்தியால் ஆன ஒரு கண்ணுக்குத் தெரியாத கவசம் கிடைக்கிறது. இது செதில்கவசத்திற்கு (scale armor) சமமான பாதுகாப்பை அளித்து, ஒவ்வொரு உடல் பகுதிக்கும் (Hit Location) 4 கவச புள்ளிகளை வழங்குகிறது. ஏற்கனவே கவசம் அணிந்திருக்கும் ஒருவருக்கு இதைப் பயன்படுத்தினால் எந்தப் பலனும் இல்லை. இருப்பினும், அதன் கால அளவிற்கு இது இயற்கையான கவசத்தை விட சிறந்த பாதுகாப்பை வழங்கினால், அதை விட மேலோங்கி நிற்கும். 4 புள்ளிகளுக்கு மேல் இயற்கையான கவசத்தைக் கொண்ட ஒரு உயிரினத்தின் மீது இதைப் பயன்படுத்தினால், இது அனைத்து இடங்களிலும் கவச புள்ளிகளை 1 ஆக அதிகரிக்கும். இந்த மாய பாதுகாப்பு இயக்கத்தையோ அல்லது மந்திர உச்சரிப்பதையோ தடுக்காது. மந்திரம் கலைக்கப்படும் வரை அல்லது மந்திரவாதி ஒரு தாக்குதலில் இருந்து 8 புள்ளிகள் சேதத்தை எதிர்கொள்ளும் வரை இந்த மந்திரம் நீடிக்கும். கூடுதல் தீவிரம் இருந்தால் (கீழே உள்ள அட்டவணையைப் பார்க்கவும்), ஒவ்வொரு நிலைக்கு +1 சேதம் சேரும். நிச்சயமாக, மந்திரவாதி விரும்பும் எந்த நேரத்திலும் மந்திரத்தைக் கைவிடலாம், மேலும் தூங்குவதற்கு அதைச் செய்ய வேண்டும்.

இந்த மந்திரம் மந்திரவாதியையும், அவருடன் மேலும் ஐந்து பேரையும் (ஒவ்வொரு கூடுதல் தீவிரம் நிலைக்கும் ஒரு நபர்) விண்மீன் தளத்திற்கு (Astral Plane) நுழைய அனுமதிக்கிறது. மந்திரம் உச்சரிக்கப்படும்போது அனைவரும் ஒருவரை ஒருவர் தொட்டுக்கொண்டு ஒரு வட்டத்தில் இருக்க வேண்டும். பயணிகளின் உடல் உண்மையான தளத்திலேயே இருக்கும், மேலும் மந்திர சக்தியை கதிர்வீச்சு செய்யும் பொருட்களைத் தவிர மற்ற ஆடைகளையோ அல்லது உபகரணங்களையோ அவர்கள் எடுத்துச் செல்ல முடியாது. கால அளவு மந்திரவாதி விரும்பும் வரை நீடிக்கும். இருப்பினும், 'Dispel Magic' போன்ற வெளி சக்திகளால் இது முன்கூட்டியே முடிவுக்கு வரலாம். மந்திரவாதியின் உடல் அழிக்கப்பட்டாலும் மந்திரம் பாதியில் நின்றுவிடும், இது மந்திரவாதியுடன் சென்ற பயணிகளை அங்கு சிக்க வைக்கும் அபாயகரமான விளைவைக் கொண்டுள்ளது.

#### சகுனம் (Augury)

(முன்னுணர்தல் - Divination)

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 2 | **மந்திர உச்சரிப்பு நேரம்:** 2 நிமிடங்கள் |
| **கோளம்:** முன்னுணர்தல் | **கால அளவு:** உடனடி |
| **செலவு:** 3/தீவிரம் | **வரம்பு:** 60 அடி |
| **பரப்பு:** மந்திரவாதி | **எதிர்ப்பு:** N/A |

இந்த மந்திரம், அடுத்த 30 நிமிடங்களுக்குள் மேற்கொள்ளப்படும் ஒரு குறிப்பிட்ட செயல், ஒரு தனிநபருக்கோ அல்லது குழுவிற்கோ நன்மை பயக்குமா அல்லது தீங்கு விளைவிக்குமா என்பதைத் தீர்மானிக்க மந்திரவாதியை அனுமதிக்கிறது. சகுனங்களை அறிய ஒரு குறிப்பிட்ட மையப் புள்ளி தேவை, பொதுவாக டிராகன் நகங்கள், சிறிய எலும்புகள், முத்து அல்லது 100 GP மதிப்புள்ள தூளாக்கப்பட்ட தங்கம். மந்திரத்தின் அதிகபட்ச தீவிரம் 4 ஆகும். இந்த முடிவுகளை கேம் மாஸ்டர் எடுக்க வேண்டும், ஏனெனில் முடிவுகள் சரியாகப் புரிந்துகொள்ளப்பட்டனவா என்பதை மந்திரவாதி ஒருபோதும் முழுமையாக உறுதிப்படுத்தக்கூடாது.

| தீவிரம் | செலவு | மாறக்கூடிய விளைவு |
| :-: | :-: | :-- |
| 1 | 3 | வலிமையான (Formidable) சேனல் திறமை உருட்டல் |
| 2 | 6 | கடினமான (Hard) சேனல் திறமை உருட்டல் |
| 3 | 9 | நிலையான (Standard) சேனல் திறமை உருட்டல் |
| 4 | 12 | எளிதான (Easy) சேனல் திறமை உருட்டல் |

சகுன உருட்டல் வெற்றியடைந்தால், பின்வரும் முடிவுகளில் ஒன்று கிடைக்கும்:

| சகுனம் | பொருள் |
| :-: | :-- |
| ஆம் | செயல் நன்மை பயக்கும் |
| இல்லை | செயல் தீங்கு விளைவிக்கும் |
| ஆம் மற்றும் இல்லை | செயல் நன்மை மற்றும் தீங்கு ஆகிய இரண்டையும் விளைவிக்கும் |
| எதுவும் இல்லை | செயல் நன்மை அல்லது தீங்கு விளைவிக்காது |

தவறான உருட்டல் (Fumble) ஏற்பட்டால், கேம் மாஸ்டர் உண்மைக்கு நேர்மாறான முடிவைச் சொல்ல வேண்டும்.

#### தடுப்பு (Avert)

(பாதுகாப்பு - Abjuration)

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 0, மந்திரவாதி 0 | **மந்திர உச்சரிப்பு நேரம்:** உடனடி |
| **கோளம்:** பாதுகாப்பு | **கால அளவு:** உடனடி |
| **செலவு:** 1 | **வரம்பு:** 60 அடி |
| **பரப்பு:** 1 மந்திரம் | **எதிர்ப்பு:** எதுவுமில்லை |

'Avert' என்பது வரம்பிற்குள் உள்ள மற்றொரு தரம் 0 மந்திரத்தை நீக்கப் பயன்படுகிறது. தற்காப்பு மந்திரத்தை (Counter Magic Reactive Action) பயன்படுத்தி தாக்குதல் நடத்தும் தரம் 0 மந்திரங்களை நடுநிலையாக்க இதை பயன்படுத்தலாம்.

#### குழப்பம் (Befuddle)

(மயக்கம் - Enchantment (Charm))

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 0, மந்திரவாதி 0 | **மந்திர உச்சரிப்பு நேரம்:** 1 திருப்பம் |
| **கோளம்:** மயக்கம் | **கால அளவு:** 30 நிமிடங்கள் |
| **செலவு:** 1 | **வரம்பு:** 60 அடி |
| **பரப்பு:** 1 இலக்கு | **எதிர்ப்பு:** மன உறுதி (Willpower) |

குழப்பம் என்பது ஒரு உடலமைப்பு கொண்ட இலக்கின் மனதில் குழப்பத்தை ஏற்படுத்துகிறது. இலக்கு தெளிவாகச் சிந்திக்க முடியாமல், தான் எங்கே இருக்கிறோம், என்ன செய்கிறோம், ஏன் செய்கிறோம் என்பதை மறந்துவிடும். குழப்பமடைந்த இலக்குகள் தற்காப்பு நடவடிக்கைகளை எடுக்கலாம், ஆனால் மந்திரம் முடியும் வரை ஆக்கபூர்வமான எதையும் செய்ய முடியாது. எந்தவொரு தாக்குதல் அல்லது அச்சுறுத்தும் செயலும் மந்திரத்தை உடனடியாக உடைத்துவிடும்.

#### கத்தித் தடுப்பு (Blade Barrier)

(தூண்டுதல் - Evocation)

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 4 | **மந்திர உச்சரிப்பு நேரம்:** 2 செயல்கள் |
| **கோளம்:** பாதுகாவலர், படைப்பு | **கால அளவு:** 3 சுற்றுகள்/தீவிரம் |
| **செலவு:** 3+1/கூடுதல் தீவிரம் | **வரம்பு:** 100 அடி |
| **பரப்பு:** 5-30 அடி ஆரம் | **எதிர்ப்பு:** கீழே காண்க |

இந்த மந்திரம் ஒரு நிலையான புள்ளியைச் சுற்றி சுழலும் வாள்கள், கத்திகள் மற்றும் குத்துக்கத்திகளின் ஒரு தடுப்பை உருவாக்குகிறது. இது விளைவுப் பரப்புக்குள் நுழையும் எவருக்கும் 1d8 சேதத்தை ஏற்படுத்தும். கவசம் அதன் சாதாரண பாதுகாப்பில் பாதியை மட்டுமே வழங்கும், ஆனால் மாய கவச புள்ளிகள் சேதத்தை வழக்கம்போல குறைக்கும். ஆயுதங்கள் மிக வேகமாகச் சுழல்வதால், அவற்றை 'Parry' அல்லது 'Evade' செய்வது சாத்தியமில்லை. கவசத்தைப் பயன்படுத்தி உடல் பகுதிகளைத் தடுக்கலாம்.

மந்திரத்தை தற்காப்புக்காகவோ அல்லது எதிரிகளை சிக்க வைக்கவோ பயன்படுத்தலாம். இருப்பினும், தடுப்பு உருவாகும்போது விளிம்பிலிருந்து ஐந்து அடிக்குள் இருக்கும் எதிரிகள் தப்பிக்க 'Evade' உருட்டலைச் செய்யலாம். வெற்றி பெற்றால், அவர்கள் சேதமடைய மாட்டார்கள்; தோல்வியுற்றால், முழு சேதத்தையும் பெறுவார்கள்.

#### ஆசி (Bless \(R\))

(படைப்பு - Conjuration)

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 1 | **மந்திர உச்சரிப்பு நேரம்:** 1 சுற்று |
| **கோளம்:** அனைத்தும் | **கால அளவு:** 5 நிமிடங்கள் |
| **செலவு:** 1 | **வரம்பு:** 180 அடி |
| **பரப்பு:** 25 அடி ஆரம் | **எதிர்ப்பு:** மன உறுதி |

இந்த மந்திரம் உச்சரிக்கப்படும்போது, மதகுரு ஆரம் பகுதிக்குள் உள்ள கூட்டாளிகளை ஆசீர்வதிக்கிறார். பாதிக்கப்பட்டவர்கள் மதகுருவின் சீரமைப்பை (Alignment) வெளிப்படுத்துகிறார்கள் (நன்மை அல்லது தீமை). அனைத்து கூட்டாளிகளும் அனைத்து திறமை மற்றும் எதிர்ப்பு உருட்டல்களில் +5% போனஸைப் பெறுவார்கள். மேலும், அவர்களின் ஆயுதங்கள் அறிவார்ந்த இறந்தவர்கள் மற்றும் பாதாள உலக உயிரினங்களுக்கு எதிராக +1d3 சேதத்தை உண்டாக்கும்.

இதன் மாற்றாக, 'சாபம்' (Curse) என்ற மந்திரம் எதிரிகளை சபிக்கப் பயன்படுகிறது. இது ஆசிக்கு நேர்மாறான விளைவுகளைத் தரும்.

#### அமைதி (Calm)

(மயக்கம் - Enchantment (Charm))

| | |
| :-- | :-- |
| **தரம்:** மதகுரு 0 | **மந்திர உச்சரிப்பு நேரம்:** 1 செயல் |
| **கோளம்:** மயக்கம் | **கால அளவு:** உடனடி |
