# முன்நிபந்தனைகள்

1. [markdown மொழி](https://www.markdownguide.org/basic-syntax/) பற்றிய அடிப்படை அறிவு.

2. உங்களிடம் கணக்கு இல்லை என்றால், இலவச [github](https://github.com/) கணக்கை உருவாக்க வேண்டும். உங்கள் RPG-இன் பெயரைப் பயன்படுத்த பரிந்துரைக்கிறேன், ஏனெனில் இது மக்கள் உங்கள் SRD-ஐ அணுகப் பயன்படுத்தும் URL-இன் ஒரு பகுதியாக மாறும்.

3. கிட் (git) தெரியாமலேயே உலாவியின் (browser) மூலம் இந்த முழு செயல்முறையையும் நீங்கள் செய்யலாம். இருப்பினும், கிட்ஹப் டெஸ்க்டாப்பைக் கற்றுக்கொள்வது, உலகிற்குத் தெரியப்படுத்தும் முன் உங்கள் மாற்றங்களை உள்ளூர் கணினியில் சோதிக்க உதவும்.

> உங்களிடம் ஏற்கனவே டொமைன் பெயர் பதிவு செய்யப்பட்டிருந்தால், அதை இந்தச் செயல்முறையுடன் சேர்த்து நான் உருவாக்கியது போல ஒரு SRD-ஐ உருவாக்கலாம் https://srd.7thextinctionrpg.com

## உங்கள் உள்ளடக்கத்தைச் சேர்த்தல்

### *.md கோப்புகள்

.md கோப்புகள் மார்க்டவுன் கோப்புகள் ஆகும். மார்க்டவுன் என்பது எளிய உரை ஆவணங்களுக்கு வடிவமைப்புகளைச் சேர்க்கப் பயன்படும் ஒரு இலகுரக மார்கப் மொழியாகும். உங்கள் உள்ளடக்கத்தின் அளவைப் பொறுத்து, உங்கள் விளையாட்டின் அனைத்து தகவல்களையும் ஒரே ஒரு *.md கோப்பில் வைக்கலாம், அல்லது நான் [7thextinctionrpg.com](https://srd.7thextinctionrpg.com)-இல் செய்தது போல ஒவ்வொரு அத்தியாயத்திற்கும் தனித்தனி கோப்புகளை உருவாக்கலாம். "sample.md" சில வடிவமைப்பு உதாரணங்களை வழங்குகிறது.

மார்க்டவுன் மொழியைக் கற்றுக்கொள்வது மிகவும் எளிது. முழுமையான தொடரியல் (syntax) பட்டியலுக்கு மேலே உள்ள முன்நிபந்தனைகளில் புள்ளி 2-இல் கொடுக்கப்பட்டுள்ள இணைப்பைப் பயன்படுத்தவும்.

## உங்கள் SRD-இல் இலவச ஐகான்களைக் காட்ட Fontawesome மற்றும்/அல்லது Material Icons செருகுநிரலைப் பயன்படுத்துதல்

### Fontawesome

இலவச ஐகான்கள் மற்றும் அனிமேஷன் ஐகான்களைப் பெற Fontawesome-ஐப் பயன்படுத்தவும். சந்தா பெற்ற பயனர்கள் Pro ஐகான்களைப் பயன்படுத்தலாம்.

1. [Fontawesome](https://fontawesome.com/icons)-இல் ஐகானைக் கண்டறியவும்
2. ஐகானைத் தேர்ந்தெடுக்கவும்
3. பாப்அப் விண்டோவில், HTML டேப்பின் கீழ் " " என்பவற்றிற்கு இடையே உள்ள அனைத்தையும் நகலெடுக்கவும்

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. நகலெடுக்கப்பட்ட உரையை `:` குறியீட்டிற்கு இடையில் இடைவெளி இல்லாமல் இடவும்

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

மேலும் பல இலவச ஐகான்களுக்கு Material Icons-ஐப் பயன்படுத்தவும்

1. [Material Icons](https://fonts.google.com/icons)-இல் ஐகான்களைக் கண்டறியவும்
2. இணைய ஸ்பான் (web span) இணைப்பை நகலெடுத்து நேரடியாக உங்கள் மார்க்டவுன் கோப்புகளில் செருகவும்

```markup
<span class="material-icons">face</span>
```
