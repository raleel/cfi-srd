# ข้อกำหนดเบื้องต้น

1. ความเข้าใจพื้นฐานเกี่ยวกับ [ภาษา markdown](https://www.markdownguide.org/basic-syntax/)

2. คุณจำเป็นต้องสร้างบัญชี [github](https://github.com/) ฟรี หากคุณยังไม่มี แนะนำให้ใช้ชื่อของเกม RPG ของคุณ เนื่องจากชื่อนี้จะกลายเป็นส่วนหนึ่งของ URL ที่ผู้คนจะใช้เข้าถึง SRD ของคุณ

3. คุณสามารถทำกระบวนการทั้งหมดนี้ผ่านเบราว์เซอร์ได้โดยไม่ต้องมีความรู้เรื่อง git แม้ว่าการเรียนรู้การใช้งาน github desktop จะช่วยให้คุณสามารถทดสอบการเปลี่ยนแปลงต่างๆ ในเครื่องก่อนที่จะเผยแพร่จริงเพื่อให้คนทั้งโลกได้เห็นก็ตาม

> หากคุณมีชื่อโดเมนที่ลงทะเบียนไว้ คุณสามารถใช้ร่วมกับกระบวนการนี้เพื่อสร้าง SRD ดังเช่นที่ผมทำได้ที่ https://srd.7thextinctionrpg.com

# กระบวนการ

1. ลงชื่อเข้าใช้ Github

2. ไปที่เทมเพลตสาธารณะ https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. คลิก "Use this template"

![Step3](/_media/Step3.png)

4. เลือก "Create a new repository"

5. ใส่ชื่อ repository

![Step5](/_media/Step5.png)

6. เลือก 'Private' 

7. เลือก 'Create repository'

ระบบจะใช้เวลาประมาณ 5-30 วินาทีในการคัดลอกเทมเพลต จากนั้นคุณก็จะมีสำเนาเป็นของตัวเอง

8. ตรวจสอบให้แน่ใจว่าคุณมีไฟล์ ".nojekyll" ซึ่งเป็นไฟล์ว่างที่จำเป็นสำหรับการโฮสต์เว็บไซต์บน Github มิฉะนั้น SRD จะแสดงผลไม่ถูกต้อง *(เป็นการบอก GitHub Pages ว่าไม่ต้องประมวลผลไฟล์ที่เผยแพร่ผ่าน Jekyll)*


## การเพิ่มเนื้อหาของคุณ

### ไฟล์ *.md

ไฟล์ .md คือไฟล์ markdown โดย Markdown เป็นภาษา markup ที่มีน้ำหนักเบา ซึ่งคุณสามารถใช้เพื่อเพิ่มองค์ประกอบการจัดรูปแบบให้กับเอกสารที่เป็นข้อความธรรมดาได้ ขึ้นอยู่กับขนาดของเนื้อหาของคุณ คุณสามารถใส่ข้อมูลทั้งหมดของเกมไว้ในไฟล์ *.md ไฟล์เดียว หรือจะสร้างไฟล์แยกสำหรับแต่ละบทก็ได้ ดังที่ผมทำที่ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) ไฟล์ "sample.md" มีตัวอย่างการจัดรูปแบบให้ดูบางส่วน

ภาษา Markdown เรียนรู้ได้ง่ายมาก โปรดใช้ลิงก์ที่ให้ไว้ในข้อ 2 ภายใต้ข้อกำหนดเบื้องต้นด้านบนเพื่อดูรายการไวยากรณ์ทั้งหมด

### _Sidebar.md

นี่คือเมนูหรือบานหน้าต่างนำทางทางด้านซ้ายของเว็บไซต์ เมื่อคุณเพิ่มไฟล์ markdown ลงใน repository แล้ว คุณจำเป็นต้องเพิ่มชื่อไฟล์ที่นี่เพื่อให้เนื้อหาถูกรวมเข้าไปด้วย โดยให้ทำตามรูปแบบที่มีอยู่เดิม

## การเปิดใช้งาน Github Pages เพื่อเปลี่ยน Repository ให้เป็นเว็บไซต์

1. ใน repository ของคุณ ให้คลิกที่ 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. เลือก 'Pages' บนเมนูด้านซ้ายมือ

![Website-Step2](/_media/Website-Step2.png)

3. หากคุณยังไม่ได้ตั้งค่า repository เป็น 'public' คุณจะมีสองทางเลือก:
    a. ทำให้ repository เป็นสาธารณะ (public) ซึ่งจะช่วยให้คุณสามารถใช้ Github pages เพื่อโฮสต์เว็บไซต์ SRD ของคุณได้ฟรี
    b. อัปเกรดบัญชี Github ของคุณ (ณ เวลาที่เขียนบทความนี้มีค่าใช้จ่าย 4 ดอลลาร์ต่อเดือน หรือค่าธรรมเนียมรายปี 48 ดอลลาร์)

4. ภายใต้ 'Branch' ให้เลือก 'main' แล้วคลิก save

5. รอประมาณ 10-20 วินาที แล้วรีเฟรชหน้าเว็บ

6. คุณจะเห็น URL ของคุณปรากฏขึ้น เช่น https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## การใช้ปลั๊กอิน Fontawesome และ/หรือ Material Icons เพื่อแสดงไอคอนฟรีใน SRD ของคุณ

### Fontawesome

ใช้ Fontawesome เพื่อรับไอคอนฟรีและไอคอนเคลื่อนไหว ผู้ใช้ที่สมัครสมาชิกสามารถใช้ Pro Icons ได้

1. ค้นหาไอคอนที่ [Fontawesome](https://fontawesome.com/icons)
2. เลือกไอคอน
3. ในหน้าต่างป๊อปอัป ใต้แท็บ HTML ให้คัดลอกทุกอย่างที่อยู่ระหว่าง " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. วางข้อความที่คัดลอกมาไว้ระหว่าง `:` โดยไม่ต้องเว้นวรรค

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ใช้ Material Icons สำหรับไอคอนฟรีเพิ่มเติม

1. ค้นหาไอคอนที่ [Material Icons](https://fonts.google.com/icons)
2. คัดลอกและแทรกลิงก์ span ของเว็บลงในไฟล์ markdown ของคุณโดยตรง

```markup
<span class="material-icons">face</span>
```
