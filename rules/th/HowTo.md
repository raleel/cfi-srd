# ข้อกำหนดเบื้องต้น

1. ความเข้าใจพื้นฐานเกี่ยวกับ [ภาษา markdown](https://www.markdownguide.org/basic-syntax/)

2. คุณจำเป็นต้องสร้างบัญชี [GitHub](https://github.com/) ฟรีหากคุณยังไม่มี เราขอแนะนำให้คุณใช้ชื่อเกม RPG ของคุณเนื่องจากชื่อนี้จะกลายเป็นส่วนหนึ่งของ URL ที่ผู้คนจะใช้เข้าถึง SRD ของคุณ

3. คุณสามารถทำกระบวนการทั้งหมดนี้ผ่านเบราว์เซอร์ได้โดยไม่ต้องรู้เรื่อง git แม้ว่าการเรียนรู้ GitHub Desktop จะช่วยให้คุณทดสอบการเปลี่ยนแปลงใดๆ ในเครื่องก่อนที่จะนำไปใช้งานจริงเพื่อให้โลกได้เห็นก็ตาม

> หากคุณมีชื่อโดเมนที่จดทะเบียนไว้ คุณสามารถใช้ร่วมกับกระบวนการนี้เพื่อสร้าง SRD เหมือนกับที่ผมทำได้ที่ https://srd.7thextinctionrpg.com

# กระบวนการ

## การสร้างที่เก็บข้อมูล (Repository) บน Github

1. เข้าสู่ระบบ Github

2. ไปที่เทมเพลตสาธารณะ https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. คลิก "Use this template" (ใช้เทมเพลตนี้)

![Step3](/_media/Step3.png)

4. เลือก "Create a new repository" (สร้างที่เก็บข้อมูลใหม่)

5. ป้อนชื่อที่เก็บข้อมูล

![Step5](/_media/Step5.png)

6. เลือก 'Private' (ส่วนตัว)

7. เลือก 'Create repository' (สร้างที่เก็บข้อมูล)

จะใช้เวลา 5-30 วินาทีในการคัดลอกเทมเพลต จากนั้นคุณจะมีสำเนาเป็นของตัวเอง

8. ตรวจสอบให้แน่ใจว่าคุณมีไฟล์ ".nojekyll" ซึ่งเป็นไฟล์เปล่าที่จำเป็นเมื่อโฮสต์เว็บไซต์บน Github มิฉะนั้น SRD จะแสดงผลไม่ถูกต้อง *(บอก GitHub Pages ไม่ให้รันไฟล์ที่เผยแพร่ผ่าน Jekyll)*

## การเพิ่มเนื้อหาของคุณ

### ไฟล์ *.md

ไฟล์ .md คือไฟล์ markdown ซึ่ง Markdown เป็นภาษามาร์กอัปน้ำหนักเบาที่คุณสามารถใช้เพื่อเพิ่มองค์ประกอบการจัดรูปแบบให้กับเอกสารข้อความธรรมดา ขึ้นอยู่กับขนาดของเนื้อหาของคุณ คุณสามารถใส่ข้อมูลเกมทั้งหมดของคุณไว้ในไฟล์ *.md ไฟล์เดียว หรือสร้างไฟล์แยกสำหรับแต่ละบทเหมือนที่ผมทำที่ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) ไฟล์ "Sample.md" ได้ให้ตัวอย่างการจัดรูปแบบไว้บางส่วน

ภาษา Markdown เรียนรู้ได้ง่ายมาก ใช้ลิงก์ที่ให้ไว้ในข้อ 2 ภายใต้ข้อกำหนดเบื้องต้นด้านบนเพื่อดูรายการไวยากรณ์ทั้งหมด

### _sidebar.md

นี่คือเมนูและบานหน้าต่างนำทางทางด้านซ้ายของเว็บไซต์ เมื่อคุณเพิ่มไฟล์ markdown ลงในที่เก็บข้อมูลของคุณแล้ว คุณต้องเพิ่มไฟล์ที่นี่เพื่อให้รวมเนื้อหาของไฟล์นั้นไว้ด้วย ให้ทำตามรูปแบบที่มีอยู่เดิม

## เปิดใช้งาน Github Pages เพื่อเปลี่ยนที่เก็บข้อมูลให้เป็นเว็บไซต์

1. ในที่เก็บข้อมูลของคุณ ให้คลิกที่ 'Settings' (การตั้งค่า)

![Website-Step1](/_media/Website-Step1.png)

2. เลือก 'Pages' ทางเมนูด้านซ้าย

![Website-Step2](/_media/Website-Step2.png)

3. หากคุณยังไม่ได้ตั้งค่าที่เก็บข้อมูลเป็น 'public' (สาธารณะ) คุณมีสองทางเลือก:
    a. ทำให้ที่เก็บข้อมูลเป็นสาธารณะ ซึ่งจะทำให้คุณสามารถใช้ Github pages เพื่อโฮสต์เว็บไซต์ SRD ของคุณได้ฟรี
    b. อัปเกรดบัญชี Github ของคุณ (ณ เวลาที่เขียนนี้ มีค่าใช้จ่าย $4 ต่อเดือน หรือค่าธรรมเนียมรายปี $48)

4. ภายใต้ 'Branch' (สาขา) ให้เลือก 'main' แล้วคลิก Save (บันทึก)

5. รอ 10-20 วินาที แล้วรีเฟรชหน้าเว็บ

6. คุณจะเห็น URL ของคุณ เช่น https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## การใช้ปลั๊กอิน Fontawesome และ/หรือ Material Icons เพื่อแสดงไอคอนฟรีใน SRD ของคุณ

### Fontawesome

ใช้ Fontawesome เพื่อรับไอคอนฟรีและไอคอนเคลื่อนไหว ผู้ใช้ที่สมัครสมาชิกสามารถใช้ Pro Icons ได้

1. ค้นหาไอคอนบน [Fontawesome](https://fontawesome.com/icons)
2. เลือกไอคอน
3. ในหน้าต่างป๊อปอัป ใต้แท็บ HTML ให้คัดลอกทุกอย่างระหว่าง " "

```EXAMPLE
<i ชนชั้น="fa-solid fa-dice-d20"></i>
```

4. วางข้อความที่คัดลอกไว้ระหว่าง `:` โดยไม่ต้องเว้นวรรค

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ใช้ Material Icons สำหรับไอคอนฟรีเพิ่มเติม

1. ค้นหาไอคอนบน [Material Icons](https://fonts.google.com/icons)
2. คัดลอกและแทรกลิงก์ web span ลงในไฟล์ markdown ของคุณโดยตรง

```markup
<span ชนชั้น="material-icons">face</span>
```
