#### Appraise (การประเมินราคา)

(การพยากรณ์ - Divination)

| | |
| :-- | :-- |
| **ระดับ:** นักเวท 0 | **ระยะเวลาร่าย:** 1 รอบ (Turn) |
| **สาย:** ไม่มี | **ระยะเวลาส่งผล:** ทันที |
| **ค่าใช้จ่าย:** 1 | **ระยะ:** สัมผัส |
| **พื้นที่:** 1 ชิ้น | **ต้านทาน:** ไม่มี |

Appraise ช่วยให้สามารถประเมินคุณภาพของสินค้าทางกายภาพที่มีน้ำหนักรวม (ENC) ในหน่วย 'สิ่งของ' หรือขนาด (SIZ) เท่ากับค่า POW ของผู้ร่ายได้ทันที เวทมนตร์นี้จะระบุว่าสิ่งของที่ดูเหมือนกันนั้นมีคุณภาพเดียวกันหรือใกล้เคียงกันหรือไม่ หรือสิ่งของนั้นมีตำหนิหรือมีคุณภาพสูงกว่าหรือไม่ เวทมนตร์นี้ไม่ส่งผลต่อสิ่งมีชีวิต ทำงานได้เฉพาะกับวัตถุที่ไม่มีชีวิตเท่านั้น และไม่สามารถระบุได้ว่าตำหนิหรือความพิเศษเหล่านั้นคืออะไร เพียงแค่บอกว่ามีอยู่จริง และไม่มีประโยชน์ในการตรวจสอบหรือตรวจจับเวทมนตร์

#### Armor (เกราะเวทมนตร์)

(การเสกสร้าง - Conjuration)

| | |
| :-- | :-- |
| **ระดับ:** นักเวท 1 | **ระยะเวลาร่าย:** 1 รอบ (Round) |
| **สาย:** ไม่มี | **ระยะเวลาส่งผล:** ดูด้านล่าง |
| **ค่าใช้จ่าย:** 3 + 1 ต่อความเข้มข้น (Intensity) | **ระยะ:** สัมผัส |
| **พื้นที่:** 1 เป้าหมาย | **ต้านทาน:** ไม่มี |

เมื่อร่ายเวทมนตร์นี้ เป้าหมายจะได้รับเกราะพลังงานเวทมนตร์ล่องหนที่มีพลังป้องกันเทียบเท่าเกราะเกล็ด (Scale Armor) โดยให้ค่าพลังป้องกัน (Armor Points) 4 แต้มแก่ทุกตำแหน่งที่ถูกโจมตี (Hit Location) เวทมนตร์นี้จะไม่มีผลหากร่ายใส่ผู้ที่สวมเกราะอยู่แล้ว อย่างไรก็ตาม มันจะอยู่เหนือเกราะธรรมชาติหากให้การป้องกันที่เหนือกว่า หากร่ายใส่สิ่งมีชีวิตที่มีพลังป้องกันธรรมชาติมากกว่า 4 แต้ม เวทมนตร์นี้จะเพิ่มค่าพลังป้องกันอีก 1 แต้มในทุกตำแหน่งแทน การป้องกันด้วยเวทมนตร์นี้จะไม่ขัดขวางการเคลื่อนไหวหรือการร่ายเวทมนตร์ เวทมนตร์จะคงอยู่จนกว่าจะถูกลบด้วยเวทมนตร์ หรือผู้ร่ายได้รับความเสียหาย 8 แต้มจากการโจมตีครั้งเดียว +1 ต่อระดับความเข้มข้นเพิ่มเติม (ดูตารางด้านล่าง) แน่นอนว่าผู้ร่ายสามารถเลือกยกเลิกเวทมนตร์เมื่อใดก็ได้ และต้องทำเช่นนั้นหากต้องการนอนหลับ

| ความเข้มข้น (Intensity) | ค่าใช้จ่าย | ผลลัพธ์ผันแปร |
| :-: | :-: | :-- |
| 1 | 3 | พลังป้องกัน 4 แต้ม; คงอยู่จนกว่าจะได้รับความเสียหาย 8 แต้มจากการโจมตีครั้งเดียว |
| 2 | 4 | พลังป้องกัน 4 แต้ม; คงอยู่จนกว่าจะได้รับความเสียหาย 9 แต้มจากการโจมตีครั้งเดียว |
| 3 | 5 | พลังป้องกัน 4 แต้ม; คงอยู่จนกว่าจะได้รับความเสียหาย 10 แต้มจากการโจมตีครั้งเดียว |
| 4 | 6 | พลังป้องกัน 4 แต้ม; คงอยู่จนกว่าจะได้รับความเสียหาย 11 แต้มจากการโจมตีครั้งเดียว |
| +1 | +1 | เพิ่มขึ้นตามลำดับ |

#### Astral Spell (เวทมนตร์ดารา)

(การแปรสภาพ - Transmutation)

| | |
| :-- | :-- |
| **ระดับ:** นักบวช 5, นักเวท 5 | **ระยะเวลาร่าย:** 2 แอคชัน |
| **สาย:** Astral | **ระยะเวลาส่งผล:** ดูด้านล่าง |
| **ค่าใช้จ่าย:** 3 + 1 ต่อความเข้มข้นเพิ่มเติม | **ระยะ:** สัมผัส |
| **พื้นที่:** ดูด้านล่าง | **ต้านทาน:** ไม่มี |

เวทมนตร์นี้ช่วยให้ผู้ร่ายและผู้ร่วมเดินทางสูงสุด 5 คน (คนละหนึ่งคนต่อระดับความเข้มข้น) เดินทางเข้าสู่ระนาบดารา (Astral Plane) ทุกคนต้องสัมผัสกันและสร้างเป็นวงกลมในขณะที่ร่ายเวทมนตร์ ร่างกายของผู้เดินทางจะถูกทิ้งไว้ในระนาบเดิม และปกติแล้วพวกเขาจะไม่สามารถนำเสื้อผ้าหรืออุปกรณ์ใดๆ ติดตัวไปด้วยได้ ยกเว้นสิ่งที่มีออร่าเวทมนตร์ในตัวเอง สิ่งของเหล่านี้จะเปลี่ยนรูปเป็นร่างดาราที่เทียบเท่ากับร่างปกติ ระยะเวลาจะคงอยู่จนกว่าผู้ร่ายจะต้องการให้ยุติ อย่างไรก็ตาม เวทมนตร์นี้อาจยุติลงก่อนกำหนดได้ด้วยพลังภายนอก เช่น Dispel Magic การทำลายร่างทางกายภาพของผู้ร่ายก็จะยุติเวทมนตร์นี้ก่อนกำหนดเช่นกัน ซึ่งจะส่งผลร้ายแรงคือการทำให้ผู้ร่วมเดินทางติดอยู่ในระนาบดารา

#### Chain Lightning (สายฟ้าโซ่)

เมื่อร่ายเวทมนตร์ นักเวทจะปล่อยสายฟ้ากว้าง 5 ฟุตจากปลายนิ้วซึ่งสามารถโจมตีเป้าหมายหนึ่งในระยะด้วยความเสียหาย 1d6+1 ต่อความเข้มข้นทุกๆ 2 หน่วย จากนั้นสายฟ้าจะโค้งไปยังวัตถุหรือสิ่งมีชีวิตที่ใกล้ที่สุดตัวถัดไป ซึ่งจะได้รับความเสียหายตามค่าที่ทอดได้ก่อนหน้าลบ 1 แต้ม และโค้งต่อไปยังตัวถัดไปโดยได้รับความเสียหายที่ทอดได้ลบ 2 แต้ม ไปเรื่อยๆ มันอาจย้อนกลับไปหาพันธมิตรหรือตัวผู้ร่ายเอง! แม้ว่าเป้าหมายแรกต้องมองเห็นได้สำหรับผู้ร่าย แต่เป้าหมายที่สายฟ้าโค้งไปหาไม่จำเป็นต้องมองเห็น

สายฟ้าแต่ละโค้งมีระยะ 50 ฟุต ซึ่งอาจทำให้สายฟ้าไปไกลกว่าระยะเดิมเมื่อร่ายเวทมนตร์ Chain Lightning จะยังคงโจมตีต่อไปหากมีความเสียหายเหลืออยู่ จนกว่าจะไปโดนวัตถุที่ทำให้มันลงดิน (เช่น กรงโลหะ, สระน้ำขนาดใหญ่) หรือไม่มีวัตถุหรือสิ่งมีชีวิตเหลือให้โจมตีแล้ว

สิ่งมีชีวิตแต่ละตัวที่ถูกโจมตีจะได้รับความเสียหายในหนึ่งตำแหน่งร่างกาย โดยที่เกราะที่สวมใส่อยู่ไม่ป้องกัน แต่เกราะธรรมชาติและค่าพลังป้องกันเวทมนตร์จะลดความเสียหายตามปกติ
