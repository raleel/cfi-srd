# Classic Fantasy Imperative System Reference Document

เวอร์ชัน 1.0, กันยายน 2023

_Classic Fantasy Imperative_ เป็นเวอร์ชันโอเพนซอร์สที่ได้รับอนุญาตภายใต้ใบอนุญาต ORC ของชุดกฎ _Mythras_ โดยมุ่งเน้นไปที่การสำรวจดันเจี้ยน การผจญภัยครั้งใหญ่ และการเผชิญหน้าที่ตึงเครียดซึ่งเกี่ยวข้องกับสมบัติ เวทมนตร์ และศัตรูที่ร้ายกาจ _Classic Fantasy Imperative_ ถ่ายทอดความตื่นเต้นดั้งเดิมของเกมสวมบทบาทเกมแรกๆ ในวงการ แต่เข้าถึงผ่านมุมมองของระบบเกม _Mythras_ ซึ่งใช้ d100 (หรือระบบเปอร์เซ็นต์) แทนที่จะใช้ d20

เอกสารนี้มีชุดกฎที่ครอบคลุมแต่ไม่ได้ระบุไว้ทั้งหมด รวมถึงการสร้างตัวละคร เผ่าพันธุ์และชนชั้นของตัวละคร ทักษะ กฎสำหรับสถานการณ์ทั่วไปบางอย่าง การต่อสู้ และเวทมนตร์ ซึ่งเพียงพอที่จะทำให้ทั้งผู้เล่นและผู้คุมเกมเริ่มต้นได้ และเป็นพื้นฐานที่มั่นคงสำหรับการพัฒนาต่อไป _Classic Fantasy_ สามารถใช้งานร่วมกับ _Classic Fantasy Imperative_, กฎหลักของ _Mythras_ และ _Mythras Imperative_ ได้อย่างสมบูรณ์ ยิ่งไปกว่านั้น ยังสามารถใช้งานร่วมกับระบบเกมที่ใช้เปอร์เซ็นต์อื่นๆ ที่ได้รับอนุญาตภายใต้ ORC ได้อีกด้วย

## การอนุญาตภายใต้ ORC

_Classic Fantasy Imperative_ ถูกเผยแพร่โดยใช้ใบอนุญาต ORC ใบอนุญาต ORC เป็นช่องทางให้ผู้สร้างเกมสามารถแบ่งปันกลไกของเกมได้อย่างเปิดเผย และอนุญาตให้ผู้ใช้ปลายทางใช้งาน ดัดแปลง และแบ่งปันการดัดแปลงกลไกเกมเหล่านี้ได้อย่างอิสระ

สิ่งที่แบ่งปันอย่างเปิดเผยภายใต้ ORC เรียกว่า **เนื้อหาที่ได้รับอนุญาต (Licensed Material)** และรวมถึงองค์ประกอบการทำงานที่กว้างขวางของเกม เช่น บล็อกค่าสถานะ กฎของเกม คุณลักษณะของตัวละคร และวิธีการและระบบที่มีอยู่ในการเล่นเกม รวมถึงสิ่งอื่นใดที่ผู้ออกใบอนุญาตต้องการแบ่งปันอย่างชัดเจน ใบอนุญาตนี้กว้างขวางและช่วยให้คุณสามารถใช้เนื้อหาที่ได้รับอนุญาตทั่วโลกที่เกี่ยวข้องกับหนังสือสิ่งพิมพ์ วิดีโอเกม พอดแคสต์ AI หรือเทคโนโลยีอื่นๆ ที่อาจมีอยู่หรือจะถูกสร้างขึ้นในอนาคต เนื้อหาส่วนใหญ่ที่พบใน _Classic Fantasy Imperative_ ถือเป็นเนื้อหาที่ได้รับอนุญาต

สิ่งที่ไม่ได้แบ่งปันภายใต้ ORC เรียกว่า **เนื้อหาที่สงวนไว้ (Reserved Material)** และรวมถึงเครื่องหมายการค้า ตำแหน่งของโลก โครงเรื่อง ตัวละครที่โดดเด่น และงานศิลปะภาพ เราได้ระบุเนื้อหาที่สงวนไว้ในประกาศ ORC ด้านล่าง

ภายใต้ใบอนุญาต ORC คุณสามารถใช้ แบ่งปัน ดัดแปลง และสร้างต่อจากเนื้อหาที่ได้รับอนุญาตได้ตามที่คุณเห็นสมควร ตราบใดที่คุณให้การอ้างอิงที่เหมาะสมในรูปแบบของประกาศในผลงานที่คุณเผยแพร่ ประกาศนี้ให้เครดิตทั้งผู้ออกใบอนุญาตต้นทางและการสนับสนุนของพวกเขาที่มีต่อผลงาน รวมถึงเป็นช่องทางที่ง่ายสำหรับผู้ใช้ปลายทางในการให้เครดิตผู้เขียนผลงานที่มีประกาศนั้นปรากฏอยู่ โดยการใช้เนื้อหาที่ได้รับอนุญาตภายใต้ ORC คุณตกลงโดยอัตโนมัติที่จะอนุญาตให้ใช้กลไกเกมของคุณในผลงานที่คุณเผยแพร่ภายใต้เงื่อนไขเดียวกัน หากคุณพัฒนาเนื้อหาที่สงวนไว้ของคุณเอง นั่นถือเป็นทรัพย์สินเฉพาะของคุณ

#### ประกาศ ORC

_Classic Fantasy Imperative_ ได้รับอนุญาตภายใต้ใบอนุญาต ORC ซึ่งตั้งอยู่ที่หอสมุดรัฐสภาและมีให้บริการออนไลน์ในสถานที่ต่างๆ รวมถึง [Paizo.com](https://paizo.com/community/blog/v5748dyo6sico?ORC-License-The-Final-Version-is-Here) และที่อื่นๆ

การรับประกันทั้งหมดถูกปฏิเสธตามที่ระบุไว้ในนั้น

## มือใหม่กับระบบ d100 ใช่หรือไม่?

_Classic Fantasy Imperative_ เป็นระบบ d100 หรือระบบเปอร์เซ็นต์ ลูกเต๋าเปอร์เซ็นต์ หรือ 1d100 ใช้สำหรับตัดสินการกระทำที่สำคัญ ไม่ว่าจะเป็นการใช้ทักษะ การต่อสู้ การร่ายเวทมนตร์ และอื่นๆ นี่เป็นระบบการทอยให้ได้ต่ำกว่าเป้าหมาย ซึ่งหมายความว่าตัวเลขเป้าหมายจะแสดงเป็นเปอร์เซ็นต์ (ตัวอย่างเช่น กรีฑา 65%) และทั้งผู้คุมเกมและผู้เล่นต่างก็พยายามทอยลูกเต๋าให้ได้ค่าเท่ากับหรือน้อยกว่าตัวเลขเป้าหมายนี้ โดยใช้ 1d100 เพื่อให้ประสบความสำเร็จ เป็นเรื่องง่ายมากที่จะเปลี่ยนจากการใช้ 1d100 มาเป็น d20 หากต้องการ โดยนำเปอร์เซ็นต์ทั้งหมดมาหารด้วย 5 (ปัดเศษขึ้น) เพื่อให้ได้ตัวเลขเป้าหมายสำหรับการทอย d20 ตัวอย่างเช่น กรีฑา 65% จะกลายเป็น กรีฑา 13 อย่างไรก็ตาม 1d100 มอบความยืดหยุ่นและรายละเอียดที่ลึกซึ้งซึ่งเป็นรากฐานของทั้งเกม ดังนั้นคำแนะนำของเราคือให้ลองใช้วิธี 1d100 ดูก่อน แม้ว่าอาจดูขัดกับความรู้สึกที่ต้องทอยให้ได้ _น้อยกว่า_ (ในหลายเกม ยิ่งได้ค่าสูงมักจะดีกว่า!) แต่การมีตัวเลขเป้าหมายที่แสดงเป็นช่วงเปอร์เซ็นต์ที่คุณจำเป็นต้องทอยให้ได้ภายในช่วงนั้น ทำให้ง่ายและชัดเจนในการดูโอกาสประสบความสำเร็จของคุณ และเปิดโอกาสให้เกิด 'ลูกเล่นของลูกเต๋า' เช่น การทอยแบบประชัน, การพลาดขั้นรุนแรง และการพลาดขั้นรุนแรง (พลาดขั้นรุนแรง) รวมถึงสิ่งอื่นๆ ที่จะสำรวจในภายหลังในกฎเหล่านี้ การสวมบทบาทด้วยเปอร์เซ็นต์มีมานานแล้วและเป็นระบบเกมที่มั่นคงพร้อมกลไกหลักที่ผ่านการพิสูจน์แล้วว่ามีความยืดหยุ่น ใช้งานง่าย และมักจะกลมกลืนไปกับฉากหลังระหว่างการเล่น

## การทำให้ง่ายขึ้น

ผู้ที่ใช้ _Mythras_ และ _Classic Fantasy_ มานานจะสังเกตเห็นว่าในบางจุด กฎของ _Classic Fantasy Imperative_ ได้รับการทำให้ง่ายขึ้น เพื่อให้ผู้คุมเกมสามารถแนะนำเกมให้กับผู้เล่นใหม่ได้อย่างรวดเร็วด้วยความยุ่งยากที่น้อยที่สุด อีกประเด็นที่ _Classic Fantasy Imperative_ แตกต่างออกไปคือการใช้หน่วยวัดแบบอิมพีเรียลแทนเมตริก การใช้ทั้งสองระบบจะกินพื้นที่มากเกินไปและต้องใช้ตารางหลายชุดเมื่อจัดการกับอาวุธระยะไกลและสิ่งต่างๆ ที่คล้ายกัน ระบบอิมพีเรียลถูกเลือกมาเพียงเพื่ออำนวยความสะดวกในการใช้แผนที่การต่อสู้ที่มีอยู่มากมาย และทำให้การแปลงการผจญภัยจากระบบเกมอื่นที่ใช้หน่วยวัดอิมพีเรียลทำได้ง่ายขึ้น เมื่อกรอกใบบันทึกตัวละครของคุณ สามารถใช้ตารางการแปลงในภาคผนวก และระบบการวัดใดก็ตามที่คุณพบว่ามีประโยชน์และคุ้นเคยมากที่สุด

## การปัดเศษตัวเลขและผลลัพธ์

ในบางโอกาส คุณจะต้องหารตัวเลข โดยปกติคือระดับในทักษะ (เช่น เพื่อกำหนดความสำเร็จขั้นวิกฤต ซึ่งเท่ากับ 1/10 ของค่าทักษะ) เมื่อใดก็ตามที่ผลลัพธ์จากการหารมีเศษ ให้ปัดเศษขึ้นเป็นจำนวนเต็มเสมอ ดังนั้น ตัวอย่างเช่น 1/10 ของ 64% คือ 6.4 ซึ่งจะปัดเศษขึ้นเป็น 7

## ลูกเต๋าที่ใช้ในเกม

_Classic Fantasy Imperative_ ใช้ชุดลูกเต๋ามาตรฐาน: d4, d6, d8, d10, d12, d20 และ d100 นอกจากนี้ยังมีการเรียกใช้ลูกเต๋าต่อไปนี้:

- **d2:** ทอยลูกเต๋าใดก็ได้ ถ้าได้เลขคี่เท่ากับ 1 และเลขคู่เท่ากับ 2 หรือโยนเหรียญ

- **d3:** ทอยลูกเต๋าหกหน้า ถ้าได้ 1-2 = 1, 3-4 = 2, 5-6 = 3
