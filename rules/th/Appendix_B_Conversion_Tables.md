# ภาคผนวก: ตารางแปลงค่า

---
#### การแปลงหน่วยวัดและน้ำหนักของอิมพีเรียลเป็นเมตริก

เพื่อให้ _Classic Fantasy Imperative_ มีรูปแบบการนำเสนอที่สะอาดตายิ่งขึ้น อ่านง่ายขึ้น และกระชับคำบรรยายและตารางต่างๆ _Classic Fantasy Imperative_ จึงเน้นใช้หน่วยวัดแบบอิมพีเรียลแทนการใช้ทั้งอิมพีเรียลและเมตริก โดยเลือกใช้หน่วยวัดแบบอิมพีเรียลเพื่อช่วยให้การแปลงเนื้อหาที่มีอยู่เดิมทำได้ง่ายขึ้น เนื่องจากเกมส่วนใหญ่ในแนวนี้ใช้การผจญภัย แผ่นรองเล่นต่อสู้ และแผนที่ที่ใช้ระบบอิมพีเรียล อย่างไรก็ตาม สำหรับผู้ที่ต้องการใช้ระบบเมตริก เราได้แปลงน้ำหนักและหน่วยวัดที่ใช้กันบ่อยที่สุดโดยใช้ตารางต่อไปนี้ เนื่องจากเราไม่ได้จัดการกับสิ่งมีชีวิต เวทมนตร์ หรือสิ่งต่างๆ ในโลกแห่งความเป็นจริงโดยตรง เราจึงสามารถยืดหยุ่นหน่วยวัดที่เรากำหนดขึ้นสำหรับสิ่งเหล่านั้นได้บ้าง แทนที่จะใช้ค่าการแปลงที่แม่นยำ การใช้ค่าที่จำง่ายกว่านั้นจะช่วยให้การเล่นเกมสะดวกยิ่งขึ้น

#### ตารางลม

| ไมล์ต่อชั่วโมง | ประเภท | ผลกระทบต่อทักษะ | ผลกระทบต่อการเคลื่อนที่ |
| :-: | :-- | :-- | :-- |
| 0-10 | สงบ | ไม่มี | ไม่มี |
| 11-20 | ลมพัดปานกลาง | ไม่มี | ไม่มี |
| 21-30 | ลมแรง | ไม่มี | สองในสาม |
| 31-40 | ลมพายุเบา | ยาก | สองในสาม |
| 41-50 | ลมพายุปานกลาง | ยาก | ครึ่งหนึ่ง |
| 51-60 | ลมพายุแรง | โหดหิน | ครึ่งหนึ่ง |
| 60+ | พายุ/เฮอริเคน | โหดหิน | หนึ่งในสาม |

ลม โดยเฉพาะลมที่แรงมาก สามารถส่งผลเสียต่อกิจกรรมได้ ความแรง (กำลัง) ของลมจะระบุเป็นความเร็วหน่วยไมล์ต่อชั่วโมง ผลกระทบต่อทักษะทางกายภาพ (ทักษะที่เกี่ยวข้องกับกำลังหรือความคล่องแคล่ว) จะแสดงไว้ในคอลัมน์ทักษะ ส่วนผลกระทบต่ออัตราการเคลื่อนที่จะอยู่ในคอลัมน์อัตราการเคลื่อนที่

_ตัวอย่างเช่น ลมพายุเบาที่มีกำลัง 40 จะลดความเร็วในการเดินของมนุษย์เหลือสองในสาม และทักษะต่างๆ จะต้องทอยในระดับความยากที่ "ยาก"_

#### ตารางอุณหภูมิ

| อุณหภูมิ (ºF) | ประเภท | ความเสี่ยง |
| :-: | :-: | :-- |
| < 2º | เยือกแข็ง | รีบหาความอบอุ่นทันที |
| 3-14º | หนาวจัด | 15 นาที |
| 13-32º | หนาว | รายชั่วโมง |
| 33-50º | เย็น | รายวัน |
| 51-68º | อากาศเย็นสบาย | - |
| 69-86º | อบอุ่น | - |
| > 86º | ร้อน | รายชั่วโมง |

อุณหภูมิอาจแตกต่างกันอย่างมากตามสภาพอากาศ ฤดูกาล และระดับความสูง ขึ้นอยู่กับโลกในแคมเปญและสถานที่ที่ฉากนั้นตั้งอยู่ ตารางข้างต้นเป็นแนวทางสำหรับผลกระทบของอุณหภูมิสุดโต่งที่มีต่อตัวละคร

การสวมใส่เสื้อผ้าที่เหมาะสมช่วยให้ตัวละครมีระยะเวลาผ่อนผันตามค่าความอดทน (ความอดทน) เป็นชั่วโมงก่อนที่จะได้รับผลกระทบจากสภาพอากาศ ดังที่แสดงในคอลัมน์ความเสี่ยง หลังจากจุดนี้ พวกเขาจำเป็นต้องหาที่พักพิงมิฉะนั้นจะเริ่มสูญเสียความล้า ตัวละครที่ตัวเปียกจะทำให้อัตราความเสี่ยงขยับไปอยู่ในขั้นที่เย็นกว่าหนึ่งระดับ ลมพายุเบาหรือปานกลางก็ทำให้อัตราความเสี่ยงขยับไปอยู่ในขั้นที่เย็นกว่าหนึ่งระดับเช่นกัน ในขณะที่ลมพายุแรงและพายุจะทำให้อัตราขยับไปสองระดับ
