# ภาคผนวก: ตารางการแปลงหน่วย

---
#### การแปลงหน่วยวัดแบบอิมพีเรียลเป็นเมตริก

เพื่อให้ _Classic Fantasy Imperative_ มีการนำเสนอที่สะอาดตายิ่งขึ้น อ่านง่ายขึ้น และกระชับรายละเอียดและตารางต่างๆ สายผลิตภัณฑ์ _Classic Fantasy Imperative_ จะเน้นไปที่หน่วยวัดแบบอิมพีเรียลแทนที่จะใช้ทั้งหน่วยอิมพีเรียลและเมตริก เหตุผลที่เลือกใช้ระบบอิมพีเรียลเพื่อให้ง่ายต่อการแปลงเนื้อหาที่มีอยู่ เนื่องจากเกมส่วนใหญ่ในแนวนี้ รวมถึงการผจญภัย แผ่นตารางต่อสู้ และแผนที่ มักใช้ระบบอิมพีเรียล อย่างไรก็ตาม สำหรับผู้ที่ต้องการใช้ระบบเมตริก ได้มีการแปลงหน่วยน้ำหนักและมาตรวัดที่ใช้บ่อยที่สุดไว้ในตารางต่อไปนี้ เนื่องจากเราไม่ได้เกี่ยวข้องกับสิ่งมีชีวิต เวทมนตร์ หรืออื่นๆ ในโลกแห่งความเป็นจริงโดยตรง เราจึงสามารถยืดหยุ่นในเรื่องหน่วยน้ำหนักและมาตรวัดที่เราสร้างขึ้นมาได้ แทนที่จะใช้การแปลงหน่วยแบบแม่นยำ การใช้หน่วยที่จำง่ายจะช่วยให้การเล่นเกมสะดวกขึ้นมากกว่า

#### ตารางลม

| ไมล์ต่อชั่วโมง | ประเภท | ผลกระทบต่อทักษะ | ผลกระทบต่อการเคลื่อนที่ |
| :-: | :-- | :-- | :-- |
| 0-10 | สงบ | ไม่มี | ไม่มี |
| 11-20 | ลมพัดปานกลาง | ไม่มี | ไม่มี |
| 21-30 | ลมแรง | ไม่มี | สองในสาม |
| 31-40 | พายุลมเบา | ยาก | สองในสาม |
| 41-50 | พายุลมปานกลาง | ยาก | ครึ่งหนึ่ง |
| 51-60 | พายุลมแรง | โหดหิน | ครึ่งหนึ่ง |
| 60+ | พายุ/เฮอริเคน | โหดหิน | หนึ่งในสาม |

ลม โดยเฉพาะลมที่แรงมาก อาจส่งผลเสียต่อกิจกรรมต่างๆ ความแรง (กำลัง) ของลมวัดเป็นหน่วยไมล์ต่อชั่วโมง ผลกระทบต่อทักษะทางกายภาพ (ทักษะที่เกี่ยวข้องกับกำลังหรือความคล่องแคล่ว) จะแสดงรายละเอียดไว้ในคอลัมน์ทักษะ และผลกระทบต่ออัตราการเคลื่อนที่จะแสดงในคอลัมน์อัตราการเคลื่อนที่

_ตัวอย่างเช่น พายุลมเบาที่มีความแรง 40 จะลดความเร็วในการเดินของมนุษย์เหลือสองในสาม และทักษะต่างๆ จะต้องทอยในระดับยาก_

#### ตารางอุณหภูมิ

| อุณหภูมิ (ºF) | ประเภท | ความเสี่ยง |
| :-: | :-: | :-- |
| < 2º | เยือกแข็ง | รีบหาความอบอุ่นโดยทันที |
| 3-14º | หนาวจัด | 15 นาที |
| 13-32º | หนาว | รายชั่วโมง |
| 33-50º | เย็น | รายวัน |
| 51-68º | อุ่นสบาย | - |
| 69-86º | อบอุ่น | - |
| > 86º | ร้อน | รายชั่วโมง |

อุณหภูมิอาจแตกต่างกันอย่างมากเนื่องจากสภาพอากาศ ฤดูกาล และระดับความสูง ขึ้นอยู่กับโลกในแคมเปญและสถานที่ที่ฉากนั้นตั้งอยู่ ตารางข้างต้นให้แนวทางเกี่ยวกับผลกระทบของอุณหภูมิที่รุนแรงต่อตัวละคร

การสวมใส่เสื้อผ้าที่เหมาะสมจะทำให้ตัวละครมีระยะเวลาผ่อนผันเท่ากับค่าความอดทนเป็นชั่วโมง ก่อนที่ผลกระทบจากสภาพอากาศจะเริ่มแสดงผล ดังที่แสดงในคอลัมน์ความเสี่ยง หลังจากช่วงเวลานี้ พวกเขาจำเป็นต้องหาที่กำบังหรือเริ่มสูญเสียความล้า ตัวละครที่ตัวเปียกจะเลื่อนระดับความเสี่ยงให้เย็นขึ้นหนึ่งขั้น ลมพัดแรงปานกลางก็เลื่อนระดับความเสี่ยงให้เย็นขึ้นหนึ่งขั้นเช่นกัน ในขณะที่ลมพายุแรงและพายุฝนจะเลื่อนระดับความเสี่ยงขึ้นสองขั้น
