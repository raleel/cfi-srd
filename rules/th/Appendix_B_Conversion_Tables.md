# ภาคผนวก: ตารางการแปลงหน่วย

---
#### การแปลงหน่วยน้ำหนักและมาตรวัดแบบอิมพีเรียลเป็นเมตริก

เพื่อให้ _Classic Fantasy Imperative_ มีการนำเสนอที่สะอาดตา อ่านง่ายขึ้น และกระชับคำอธิบายรวมถึงตารางต่างๆ _Classic Fantasy Imperative_ จึงเลือกใช้มาตรวัดแบบอิมพีเรียลเป็นหลักแทนที่จะใช้ทั้งอิมพีเรียลและเมตริกควบคู่กัน การเลือกใช้ระบบอิมพีเรียลมีจุดประสงค์เพื่ออำนวยความสะดวกในการแปลงเนื้อหาที่มีอยู่เดิม เนื่องจากเกมส่วนใหญ่ในแนวนี้มักใช้มาตรวัดแบบอิมพีเรียลสำหรับเนื้อเรื่อง การผจญภัย แผ่นรองเล่น (battlemat) และแผนที่ อย่างไรก็ตาม สำหรับผู้ที่ต้องการใช้ระบบเมตริก เราได้จัดทำตารางแปลงหน่วยน้ำหนักและมาตรวัดที่ใช้บ่อยที่สุดไว้ให้ด้านล่างนี้ เนื่องจากเราไม่ได้จัดการกับสิ่งมีชีวิต เวทมนตร์ หรือองค์ประกอบอื่นๆ ในโลกแห่งความเป็นจริง เราจึงสามารถผ่อนปรนค่าการแปลงหน่วยที่เรากำหนดขึ้นมาได้เล็กน้อย แทนที่จะใช้ค่าการแปลงที่แม่นยำตามหลักวิทยาศาสตร์ เราเลือกใช้ค่าที่จดจำได้ง่ายเพื่อช่วยให้การเล่นเกมราบรื่นยิ่งขึ้น

#### ตารางลม

| ไมล์ต่อชั่วโมง (MPH) | ประเภท | ผลกระทบต่อทักษะ | ผลกระทบต่อการเคลื่อนที่ |
| :-: | :-- | :-- | :-- |
| 0-10 | สงบ | ไม่มี | ไม่มี |
| 11-20 | ลมอ่อน | ไม่มี | ไม่มี |
| 21-30 | ลมแรง | ไม่มี | สองในสาม |
| 31-40 | พายุลมแรงเบา | ยาก (Hard) | สองในสาม |
| 41-50 | พายุลมแรงปานกลาง | ยาก (Hard) | ครึ่งหนึ่ง |
| 51-60 | พายุลมแรงจัด | น่าเกรงขาม (Formidable) | ครึ่งหนึ่ง |
| 60+ | พายุ/พายุเฮอริเคน | น่าเกรงขาม (Formidable) | หนึ่งในสาม |

ลม โดยเฉพาะลมที่แรงมาก สามารถส่งผลกระทบในทางลบต่อกิจกรรมต่างๆ ได้ ความแรงของลม (STR) จะแสดงเป็นไมล์ต่อชั่วโมง ผลกระทบต่อทักษะทางกายภาพ (ทักษะที่เกี่ยวข้องกับ STR หรือ DEX) จะแสดงอยู่ในคอลัมน์ผลกระทบต่อทักษะ ส่วนผลกระทบต่ออัตราการเคลื่อนที่อยู่ในคอลัมน์อัตราการเคลื่อนที่

_ตัวอย่างเช่น พายุลมแรงเบาที่มีความแรง 40 ไมล์ต่อชั่วโมง จะลดความเร็วในการเดินของมนุษย์เหลือสองในสาม และการทดสอบทักษะจะมีความยากระดับ ยาก (Hard)_

#### ตารางอุณหภูมิ

| อุณหภูมิ (ºF) | ประเภท | ความเสี่ยง |
| :-: | :-: | :-- |
| < 2º | เยือกแข็ง | รีบหาที่อบอุ่นโดยทันที |
| 3-14º | หนาวจัด | 15 นาที |
| 13-32º | หนาว | ทุกชั่วโมง |
| 33-50º | เย็น | ทุกวัน |
| 51-68º | เย็นสบาย | - |
| 69-86º | อุ่น | - |
| > 86º | ร้อน | ทุกชั่วโมง |

อุณหภูมิอาจแตกต่างกันอย่างมากตามสภาพอากาศ ฤดูกาล และความสูง ขึ้นอยู่กับโลกในแคมเปญและสถานที่ที่เหตุการณ์เกิดขึ้น ตารางข้างต้นให้แนวทางเกี่ยวกับผลกระทบของอุณหภูมิสุดโต่งที่มีต่อตัวละคร

การสวมใส่เสื้อผ้าที่เหมาะสมจะช่วยให้ตัวละครมีเวลาผ่อนผันเท่ากับค่า CON (เป็นชั่วโมง) ก่อนที่จะเริ่มได้รับผลกระทบจากสภาพอากาศตามที่ระบุในคอลัมน์ความเสี่ยง หลังจากจุดนี้ ตัวละครจำเป็นต้องหาที่พักพิงมิเช่นนั้นจะเริ่มสูญเสียค่าความเหนื่อยล้า (Fatigue) ตัวละครที่ตัวเปียกจะได้รับความเสี่ยงเพิ่มขึ้นหนึ่งระดับ ลมแรงระดับเบาหรือปานกลางก็จะเพิ่มความเสี่ยงอีกหนึ่งระดับเช่นกัน ในขณะที่ลมพายุแรงและพายุฝนจะเพิ่มความเสี่ยงขึ้นสองระดับ
