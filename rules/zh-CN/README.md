# 经典奇幻要旨 (Classic Fantasy Imperative) 资源文档

版本 1.0，2023 年 9 月

《经典奇幻要旨》(Classic Fantasy Imperative) 是《Mythras》规则集的一个开放、采用 ORC 授权的版本，专注于地下城探索、宏大的冒险，以及涉及宝藏、魔法和致命敌人的紧张遭遇战。《经典奇幻要旨》复刻了这一爱好中最初的角色扮演游戏所带来的刺激感，但它是通过《Mythras》游戏系统的视角来实现的，该系统基于 d100（百分制），而不是使用 d20。

本文件提供了一套全面但非详尽的规则，包括角色创建、角色种族与职业、技能、特定典型情况的规则、战斗和魔法——足以让玩家和游戏主持人（Games Master）上手，并为进一步发展奠定坚实基础。《经典奇幻要旨》与《经典奇幻要旨》原版、《Mythras》核心规则以及《Mythras Imperative》完全兼容。此外，它还与其他采用 ORC 授权的百分制游戏系统兼容。

## ORC 授权

《经典奇幻要旨》是使用 ORC 授权发布的。ORC 授权为游戏创作者提供了一种公开分享游戏机制的方法，并允许下游用户自由使用、修改和重新分享这些游戏机制的改编版本。

在 ORC 下公开分享的内容被称为**授权材料 (Licensed Material)**，包括游戏广泛的功能要素，例如属性块、游戏规则、角色属性、玩游戏固有的方法和系统，以及许可人明确希望分享的任何其他内容。该授权范围广泛，允许您在全球范围内将授权材料用于印刷书籍、电子游戏、播客、人工智能或任何可能存在或将来可能创建的其他技术。《经典奇幻要旨》中发现的绝大部分内容均构成授权材料。

不在 ORC 下分享的内容被称为**保留材料 (Reserved Material)**，包括商标、世界设定、故事弧线、独特角色和视觉艺术。我们在下方的 ORC 通知中列出了保留材料。

根据 ORC 授权，只要您以发布作品中的通知形式给予适当的署名，就可以随意使用、分享、改编和构建授权材料。此通知既标注了上游许可人及其对作品的贡献，也为下游用户提供了一种简便的方式来标注出现该通知的作品的作者。通过使用受 ORC 授权的材料，您即自动同意在您的发布作品中根据相同的条款授权您的游戏机制。如果您开发了自己的保留材料，那将是您的独有财产。

## 初次接触 d100？

《经典奇幻要旨》是一个 d100 或百分制系统。百分制骰子（即 1d100）用于解析关键动作——技能使用、战斗、魔法施放等。这是一个向下掷骰系统，意味着目标数值以百分比表示（例如：运动 65%），游戏主持人和玩家都希望使用 1d100 掷出等于或小于此目标数值的结果，以实现成功。如果愿意，可以非常轻松地用 d20 替换 1d100，只需将所有百分比除以 5（向上取整）即可获得 d20 掷骰的目标数值。以我们的例子为例，运动 65% 将变为运动 13。然而，1d100 提供了支撑整个游戏的大量灵活性和细微差别，因此我们建议先尝试 1d100 方法。虽然必须掷出“小于”某个数值可能显得反直觉（在许多游戏中，通常是越高越好！），但拥有一个需要掷入的百分比范围目标数值，使得查看成功几率变得简单直接，并允许使用相当多的“骰子技巧”，例如对抗掷骰、暴击和大失败，以及本规则稍后探讨的其他一些内容。百分制角色扮演游戏已经存在很长时间了，是一个基础稳固的游戏系统，具有经过验证的核心机制，灵活、直观，并且在游戏过程中往往会融入背景中，不会喧宾夺主。

## 简化

《Mythras》和《Classic Fantasy》的老玩家会注意到，《经典奇幻要旨》规则在某些地方进行了简化。这样做是为了让游戏主持人能够更快速地以最少的麻烦将游戏介绍给新玩家。另一个《经典奇幻要旨》不同的地方在于采用了英制单位而非公制单位。同时包含两者会占用太多空间，并且在处理远程武器等内容时需要多个表格。选择英制系统只是为了方便使用现有的无数战斗垫，并使转换使用英制系统的其他游戏系统的冒险变得更简单。在填写角色卡时，请随意使用附录中的转换表，以及您认为最有用和最熟悉的度量系统。

## 数值与结果的取整

在某些情况下，您需要进行除法运算——通常是技能等级（例如计算暴击成功时，为技能数值的 1/10）。每当除法结果产生小数时，请始终向上取整为整数。例如，64% 的 1/10 是 6.4；向上取整为 7。

## 游戏中使用的骰子

《经典奇幻要旨》使用标准的多面骰子组合：d4、d6、d8、d10、d12、d20 和 d100。此外，还需要使用以下骰子：

- **d2：** 掷任意骰子。奇数等于 1，偶数等于 2。或者掷硬币。

- **d3：** 掷一枚六面骰；1-2 = 1，3-4 = 2，5-6 = 3。
