# 经典奇幻指令系统资源文档

版本 1.0，2023年9月

《经典奇幻指令》(Classic Fantasy Imperative) 是《Mythras》规则集的开放 ORC 授权版本，专注于地下城探索、高难度冒险以及涉及宝藏、魔法和致命敌人的紧张遭遇战。《经典奇幻指令》模仿了爱好中最早的角色扮演游戏的原始快感，但通过《Mythras》游戏系统的视角进行诠释，该系统基于 1d100（或百分制），而不是使用 d20。

本文件提供了一套全面但不详尽的规则，包括角色创建、角色种族与职业、技能、特定典型情况的规则、战斗以及魔法——这些内容对于玩家和游戏主持人（Games Master）起步绰绰有余，并为后续发展奠定了坚实的基础。《经典奇幻指令》与《经典奇幻指令》、《Mythras》核心规则以及《Mythras 指令》(Mythras Imperative) 完全兼容。此外，它也与其他 ORC 授权的百分制游戏系统兼容。

## ORC 授权

《经典奇幻指令》使用 ORC 授权发布。ORC 授权为游戏创作者提供了一种公开分享其游戏机制的途径，并允许下游用户自由使用、修改和重新分享这些游戏机制的改编版本。

在 ORC 下公开分享的内容被称为**授权材料 (Licensed Material)**，包括游戏的功能性元素，如属性块、游戏规则、角色属性以及游戏固有的方法和系统，以及许可方明确希望分享的任何其他内容。该授权非常广泛，允许您在全球范围内将授权材料用于印刷书籍、电子游戏、播客、人工智能或未来可能存在或创造的任何其他技术。《经典奇幻指令》中绝大部分内容均构成授权材料。

不在 ORC 下分享的内容被称为**保留材料 (Reserved Material)**，包括商标、世界设定、故事弧、独特角色和视觉艺术。我们在下方的 ORC 通知中列出了保留材料。

根据 ORC 授权，只要您在出版作品中以通知的形式提供适当的署名，就可以根据需要使用、分享、改编和构建授权材料。此通知既标注了上游许可方及其对作品的贡献，也为下游用户提供了一种简便的方式来标注出现该通知的作品作者。通过使用 ORC 授权的材料，您即自动同意在您的出版作品中按相同条款授权您的游戏机制。如果您开发了自己的保留材料，那是您的专属财产。

## 对 d100 感到陌生？

《经典奇幻指令》是一个 d100 或百分制系统。百分制骰子（即 1d100）用于判定关键动作——技能使用、战斗、魔法施放等。这是一个“掷点需低于目标值”的系统，意味着目标数值以百分比表示（例如：运动 65%），游戏主持人与玩家均需掷出 1d100，点数等于或低于该目标数值即视为成功。如果喜欢，完全可以用 d20 代替 1d100，只需将所有百分比除以 5（向上取整）即可获得 d20 的目标值。在我们的例子中，运动 65% 将变为运动 13。然而，1d100 提供了大量的灵活性和细微差别，这些是整个游戏的基础，因此我们的建议是先尝试 1d100 的方式。虽然掷出“低于”某数值可能看起来有悖常理（在许多游戏中，掷出更高点数通常更好！），但将目标数值表示为需要掷入的百分比范围，使得查看成功概率变得简单明了，并允许进行许多“骰子技巧”，如对抗掷骰、暴击、大失败，以及本书后面探讨的其他内容。百分制角色扮演游戏已经存在很长时间了，是一个有着久经考验的核心机制的成熟游戏系统，它灵活、直观，并且在游戏过程中往往会退居幕后，让人专注于体验。

## 简化

《Mythras》和《经典奇幻》的老玩家会注意到，《经典奇幻指令》的规则在某些地方进行了简化。这样做是为了让游戏主持人能以最少的繁琐工作，更快地将游戏介绍给新玩家。《经典奇幻指令》另一个不同之处在于采用了英制单位而非公制。同时包含两者会占用太多篇幅，并且在处理远程武器等内容时需要多个表格。选择英制系统仅仅是为了方便使用现有的无数战斗地图，并使转换使用英制单位的其他游戏系统的冒险模块变得更简单。在填写角色表时，请随意使用附录中的转换表，以及您认为最有用和最熟悉的度量系统。

## 数字与结果的四舍五入

有时您需要进行除法——通常是针对技能等级（例如确定暴击成功时，为技能值的 1/10）。每当除法结果产生小数时，始终向上取整为整数。例如，64% 的 1/10 是 6.4；向上取整为 7。

## 游戏中使用的骰子

《经典奇幻指令》使用标准的多元骰子集：d4、d6、d8、d10、d12、d20 和 d100。此外，还需要以下骰子：

- **d2：** 投掷任何骰子。奇数等于 1，偶数等于 2。或者投掷一枚硬币。

- **d3：** 投掷一颗六面骰；1-2 = 1，3-4 = 2，5-6 = 3。
