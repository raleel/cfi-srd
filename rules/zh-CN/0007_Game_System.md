# 第7章：游戏系统

在《经典幻想要务》（_Classic Fantasy Imperative_）的游戏过程中，会发生许多不同的事情。有些通过技能使用或战斗、魔法等主要游戏机制来解决；另一些则需要各自的判定规则。本章为玩家在游戏过程中将遇到的各种情景提供了规则和指导。

此列表并非详尽无遗，但涵盖了最常见的情况。如果游戏主持人（GM）发现还有其他需要某种形式游戏系统判定的情况，且这些情况似乎经常发生，则鼓励他们使用本章提供的规则作为基础进行推演或开发，制定自己的规则来应对这些特殊情况。

## 老化

所有角色都会老化，而年龄会带来一定的后果。老化的迹象始于“初老期”（人类为40岁——其他物种的老化速度更快或更慢，如下所示）。当角色进入一个新的“年龄段”时，他们必须以注明的难度等级进行耐力（Endurance）和意志（Willpower）检定。如果检定失败，他或她将经历“老化效果”表格中所示的老化效果。

每项受老化影响的特性（Characteristic）减少1d3点。这些点数可以通过特性提升来恢复或至少部分抵消，这代表了他们随着年龄增长为保持精干和敏捷所做的努力。如果任何特性因老化而降低至零，角色将因身体终末期虚弱而死亡。一旦角色达到“耄耋期”年龄段，无论种族如何，每年都必须进行老化检定。

老化过程中会出现哪些具体的衰弱影响，由游戏主持人决定。例如，降低力量（STR）、体质（CON）或敏捷（DEX）代表身体的普遍损耗，表现为关节咯吱作响和行动能力逐渐丧失。降低智力（INT）表明年龄开始对思想和记忆产生负面影响，而降低魅力（CHA）则表明角色随着年龄增长变得更加粗糙，或许也更加急躁。

## 窒息

角色屏住呼吸的秒数等于其耐力技能点数。但是，角色必须做好准备（尽可能多地吸入空气）；如果没做好准备，则如果是处于被动状态，屏息时间减半；如果是在进行剧烈活动，则减为五分之一。

屏息时间结束后，角色必须进行耐力检定：

- 如果检定为大成功，则不会进一步恶化。
- 如果检定为成功，角色会额外积累一级疲劳（Fatigue）。
- 如果检定失败，角色该轮额外承受1d2级疲劳。
- 如果检定为大失败，角色该轮额外承受1d3级疲劳。

在没有辅助的情况下，因窒息导致的死亡通常很快。如果窒息在角色死亡前结束，他们恢复因窒息而损失的疲劳等级的速度相对较快，每分钟恢复一级。

根据窒息的方式，游戏主持人可能希望阻止完全恢复，从而施加一种持久的疲劳等级，以代表因吸入烟雾或水而对肺部造成的损伤。

## 角色成长

每个《经典幻想要务》角色都能随着时间和经验不断成长。提升可以在几个领域进行：

- 提升现有技能
- 提升激情（Passions）
- 学习新技能
- 学习新能力

#### 经验骰

大多数角色成长的机制是“经验骰”（Experience Roll）。游戏主持人会在战役的适当节点发放经验骰：在每次成功的剧情或故事情节结束时；或者如果故事较长，需要较长时间完成，则可以在两到三次游戏会话后发放。频率由游戏主持人决定。高频率的经验骰将导致角色以更快的速度成长。

发放经验骰没有绝对正确或错误的时机，但故事中的自然停顿点通常是合适的时机。然而，游戏主持人永远是最终决策者。虽然玩家不能强求经验骰，但他们有权在特定时刻期待它们——因为他们的角色若没有经验骰将无法成长。

经验骰的奖励数量也由游戏主持人决定。不过，一个好的经验法则是每距离上次发放后每场游戏会话奖励1-3个经验骰。

#### 提升现有技能

角色卡上的任何技能（标准或专业）都可以通过花费一个经验骰来提升。玩家可以选择“不”将经验骰用于提升技能，而是积累起来用于提升其他方面——例如职业能力（见下文）。

- 玩家掷1d100并将其与要提升的技能进行比较。角色的智力（INT）加到检定结果中。
- 如果掷出的数值**等于或大于**正在提升的技能值，该技能提升1d4+1%。
- 如果掷出的数值**小于**所选技能值，技能仍然提升，但仅提升1%。
- 如果角色在上一次游戏会话期间（即上次发放经验骰和本次之间）对任何技能进行了大失败（Fumble）检定，则该大失败的技能可获得1%的免费提升。正如俗话所说，我们从错误中学到的比成功中学到的更多，这代表了角色在经历灾难性的失败后所进行的自省。同一技能的多次大失败不叠加。如果大失败的技能同时也被经验骰提升，则1%的来自大失败的提升会先于经验骰的加成应用。

同一技能在每场游戏会话中不得受益于超过一个经验骰。

#### 提升激情

如[激情](0004_Alignment_and_Passions.md?id=passions)章节所述，激情的值可以用经验骰以与技能相同的方式提升。如果剧情支持，游戏主持人甚至可能允许使用经验骰来降低激情。

例如，长期的单相思可能会耗尽即使是最热情的恋人的激情，尤其是那些希望追求新关系而不愿被过去幽灵困扰的人。

#### 学习新技能

有些角色可能希望学习他们从未有机会从文化或职业中学习的专业技能。在他们开始投入经验骰之前，必须首先找到获取知识的来源。这可以是像行会或组织提供的职业导师那样平凡的途径，也可以是更异国情调的教育来源，例如古老且残破的训练卷轴。

一旦找到教育来源，角色必须花费整整一个月的时间进行学习和练习，以获得该技能的基础（以基础水平学习）。这需要花费3个经验骰，以及支付老师费用（如果有）和购买（或租用）所需设备工具的任何游戏内费用。

#### 学习新职业能力

假设角色满足必要等级（Rank）和技能水平（如果有），则可以消耗一个或多个经验骰来获得或提升职业能力。详情请参阅[第3章：职业](0003_Classes.md)中的相关职业条目。与技能不同，这通常不需要寻找学习相关能力的知识来源，因为这假设是通过反复使用任何必要技能从而获得的高级技术。经验骰的成本等于角色当前的等级，并且许多能力在达到特定等级之前是锁定的。

## 坠落

坠落造成的伤害取决于跌落距离。护甲值（Armor Points）不会减少坠落伤害，但坠落角色或生物的伤害修正（Damage Modifier）适用于伤害骰。

##### 坠落距离表

| **坠落高度** | **伤害** |
| :-- | :-- |
| 5英尺或以下 | 无伤害 |
| 6至15英尺 | 随机一处部位受到1d6点伤害 |
| 16至30英尺 | 随机两处部位各受到2d6点伤害 |
| 31至45英尺 | 随机三处部位各受到3d6点伤害 |
| 46至60英尺 | 随机四处部位各受到4d6点伤害 |
| 每增加15英尺 | +1d6伤害 |

#### 坠落物体

坠落物体造成的伤害基于其体型（SIZ）和跌落距离。物体每6点SIZ（或其分数）造成1d6伤害，再加上相当于“坠落距离表”中“伤害”栏的伤害值——包括对较小尺寸物体的减损。

## 疲劳

疲劳衡量的是疲倦及其递增的影响。它用于追踪许多不同的事物，从剧烈活动到疾病的衰弱影响。

积累疲劳的主要方式是进行某种形式的体力活动。运动或工作越艰苦，角色疲劳得就越快。由游戏主持人决定，角色必须进行适当的技能检定——运动（Athletics）、强壮（Brawn）或耐力（Endurance）——以抵御疲劳等级的上升。

每失败一次检定就会积累一级疲劳。如[疲劳等级表](0007_Game_System.md?id=fatigue-levels-table)所示，每一级疲劳都会对技能使用、移动、先攻（Initiative）和行动点（Action Points）造成惩罚。窒息、失血以及其他受环境影响的因素也会导致疲劳积累。

对于大多数角色来说，当达到“丧失行为能力”（Incapacitated）级别时，任何种类的活动几乎都变得不可能。在此阶段，角色仍然有意识，但除了最绝望的活动外，无法进行任何操作。

超过“丧失行为能力”后，角色将完全无法行动。疲劳等级——“半昏迷”、“昏迷”和“死亡”——通常用于衡量窒息、疾病、失血、饥饿、暴露等的最极端影响。

### 从疲劳中恢复

角色从疲劳中恢复的速度取决于其愈合率（Healing Rate）。从每一级积累的疲劳中恢复所需的完全休息时间等于“恢复期”除以角色的愈合率。

请注意，该表格代表的是体力消耗后的疲劳恢复。从[窒息](0007_Game_System.md?id=f)中恢复时，疲劳恢复可能会快得多；而从[失血](0007_Game_System.md?id=blood-loss)中恢复时，则可能较慢。

## 火焰

当火焰被用作武器或失去控制肆虐时，它们总是危险的来源。下方的[火焰强度表](0007_Game_System.md?id=fire-intensity-table)给出了热伤害的五种不同强度及其示例。每轮造成的伤害在“伤害”一栏中给出。由于规模相对较小，强度1和2的火源将其伤害应用于单个命中部位，通常是接触火源的部位。强度3和4的火源更大，会将伤害应用于最近的1d4+1个命中部位，表明了辐射热的程度。强度5的火源会同时影响所有命中部位。火焰可以点燃易燃材料。如果未立即扑灭，此类材料会在火源强度指示的若干轮内燃烧。一旦点燃，易燃材料会持续燃烧直到被物理扑灭。伤害直接应用于材料的生命值（Hit Points），忽略护甲值，并应用于下方的任何皮肉。如果处于失控状态，火焰每轮会扩散到与其强度相等数量的命中部位。

##### 火焰强度表

| **强度** | **示例** | **点燃时间** | **伤害** |
| :-: | :-- | :-: | :-: |
| 1 | 蜡烛 | 1d4 | 1d2 |
| 2 | 火把 | 1d3 | 1d4 |
| 3 | 篝火 | 1d2 | 1d6 |
| 4 | 填满房间的烈火 | 1d2 | 2d6 |
| 5 | 火山熔岩 | 即时 | 3d6 |

#### 火焰攻击

火焰攻击通常有一定百分比的概率点燃易燃材料，因为它们通常在一轮内结束。除非另有说明，火焰攻击的点燃概率为（伤害骰数值x5%），电气攻击的点燃概率为（伤害骰数值x1%）。一旦点燃，易燃材料每轮造成1d3-1点伤害，直到被物理扑灭。将此伤害直接应用于材料的生命值，忽略护甲值，并应用于下方的任何皮肉。但是，生物的天然护甲提供其正常的保护。受害者可以通过俯卧并进行一次成功的运动（Athletics）检定来尝试扑灭火焰，这需要消耗一个行动点，并且每回合可以尝试一次。如果其他人以某种方式协助扑灭火焰，则检定难度等级降低一级。如果伤害骰结果为零，则火焰在该部位自动熄灭。对于每个自动熄灭的部位，扑灭火焰的检定难度等级也会降低一级。

## 游戏时间

在《经典幻想要务》中，时间是一个重要因素，主要用于确定什么事情按什么顺序发生，以便在应该应用游戏机制时应用它们。请记住，游戏内时间通常不等同于游玩时间。有时，GM可能需要用一句话总结数天的事件，例如“你们花了一周时间到达格雷迈尔城堡”，而有时，特别是在战斗中，仅仅几秒钟的动作可能需要花费几分钟甚至更长时间来解决。

相关说明：一些法术、物品或效果被标注为每天可以使用一次或多次。一种跟踪此项的简单方法，而不是记录每次此类动作发生的具体时间，是假设在角色睡了一个完整的夜晚后，时间重置。因此，即便一件每天可用三次的魔法物品在睡觉前刚刚使用过，当角色下次醒来时，它的所有使用次数都会恢复。

以下是游戏时间的重要区分：

#### 战斗轮（Combat Rounds）

一个战斗轮代表现实时间中的五秒钟。它们用于衡量那些瞬间完成的简短、狂热的活动，或衡量需要逐次解析的非常详细的活动。例如，猎人与猎物之间的追逐，其中每一轮决定了追逐的曲折变化。

#### 探索轮（Exploration Rounds）

一个探索轮代表现实时间中的五分钟，并允许队伍以其基础移动速度的三倍进行移动（人类和人类大小的亚人类为60英尺，小型亚人类种族为45英尺）。探索轮通常用于衡量地下城中的移动，保持高度警惕非常重要。角色移动缓慢，对陷阱和伏击保持警觉，并试图保持隐蔽。这也假设队伍中有人在绘制地图。如果没有人在绘图，探索轮可以被视为持续一分钟。使用探索轮可以让你在不受到惩罚的情况下进行感知检定，然而，正如往常一样，其他惩罚可能依然适用。除非你在黑暗区域使用光源（如火把或灯笼），否则敌人会发现以探索速度移动的队伍更难被察觉。如果角色决定放弃谨慎，你可以使用战斗轮穿过地下城。然而，在这种情况下，感知检定难度提高一个等级，并且敌人在察觉角色方面不会受到感知惩罚。请注意，当使用向玩家揭示整个地下城的战斗地图时，或者当游戏主持人为他们绘制地下城时，应**始终**假设队伍正在绘制地图，因此以探索速度移动。

#### 技能时间（Skill Time）

技能时间代表几分钟到几个小时，用于衡量那些不需要战斗轮那样详细关注，但需要明确的努力并能产生确定结果的活动。撬锁可能需要五分钟，而观察城堡墙壁周围守卫小队的巡逻路径可能需要几个小时。两者都是技能时间的例子。#### 叙事时间

这是当游戏主持人（Games Master）向玩家进行叙述，或者玩家之间进行讨论时所消耗的时间。除非有特殊原因，否则大多数实际的角色扮演都发生在叙事时间内。在进行角色扮演时，叙事时间类似于现实时间，即一场对话所需的时间与游戏中所花费的时间相同。如果游戏流程中包含长途旅行，或者那些精确时间并不重要的活动时期，那么时间会被大幅压缩，变成游戏时间里的寥寥数刻。

### 短暂休息（Short Rests）

短暂休息代表了一段约15分钟的时间，冒险者们在此期间停下来喘口气，所做的事情不超过阅读、进食、饮水、祈祷和处理伤口这些不费力的活动。队伍决定休息多久，然后执行相关的15分钟动作，每个玩家在进入下一个动作前执行一个动作。队伍在一天之内可以进行的短暂休息次数没有限制，通常在扎营后以及早上出发前会进行几次休息动作。每个15分钟的休息动作详述如下，除非另有说明，否则可以多次执行。

- **食用口粮（Eat a Ration）：** 此15分钟休息动作每天只能执行一次，因为口粮是作为每日消耗品进行跟踪的。它可以消除**任意**一个不高于“力竭（Exhausted）”等级的疲劳，并平息饥饿感。由于这是一种非剧烈活动，角色在进食后，如果疲劳程度不高于“气喘（Winded）”，还可以额外降低一个疲劳等级。
- **向神祇祈祷或研读法术书（Pray to a Deity or Study spell book）：** 在祈祷或研读中每花费一个15分钟休息动作，即可恢复1点魔法值。由于这是一种非剧烈活动，角色在执行此动作后，如果疲劳程度不高于“气喘（Winded）”，可以降低一个疲劳等级。
- **处理伤口（Tend to wounds）：** 花费一个15分钟休息动作使用“急救（First Aid）”技能，或花费四个15分钟休息动作（一小时）使用“治疗（Healing）”技能。
- **施展一个或多个法术（Cast one or more spells）：** 在15分钟休息动作期间，可以施展任意数量的法术来治疗或增益队伍成员，受限于可用的魔法值。
- **准备新法术（Prepare a new spell）：** 在至少8小时的睡眠后，施法者可以使用一个15分钟的休息动作来记忆或遗忘一个奥术或神术法术，具体需遵循[记忆法术](0009_Magic.md?id=memorizing-spells)下的详细限制。
- **徘徊（Dither）：** 除非选择了其他动作，否则这是默认的15分钟休息动作。角色只是浪费15分钟做些无意义的事。如果队伍的其他成员仍在执行休息动作而你没事可做，通常会执行此休息动作。由于这是一种非剧烈活动，角色在执行此动作后，如果疲劳程度不高于“气喘（Winded）”，可以降低一个疲劳等级。

## 命中部位（Hit Locations）

大多数成功的（武器）攻击会命中特定的命中部位。这可以随机确定，或者在某些情况下由诸如“选择部位（Choose Location）”之类的特殊效果来指定。要随机计算命中了哪个部位，掷1d20并将结果与相关的人形生物或生物命中部位表进行对比。

动物和怪物的命中部位表通常与人形生物略有不同，以反映其独特的生理结构。这些列表作为每个生物描述的一部分，通常仅供游戏主持人参考。

为了方便查阅，此处重复列出人形生物命中部位表。

### 人形生物命中部位表

| **1d20** | **命中部位** |
| :-: | :-- |
| 1-3 | 右腿 |
| 4-6 | 左腿 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右臂 |
| 16-18 | 左臂 |
| 19-20 | 头部 |

请注意，某些攻击，尤其是魔法攻击，或者是特定怪物产生的攻击（例如红龙的烈焰吐息），可能会同时击中多个命中部位。单个命中部位可以拥有护甲，这来自于穿着的防护装备或生物外表的自然坚韧。在考虑下文的伤害和伤势等级时，这一点非常重要。

### 伤害和伤势等级（Damage and Wound Levels）

如果攻击成功命中，它会根据武器的伤害等级造成伤害（参见[金钱与装备](0006_Money_and_Equipment.md?)章节中[近战武器](0006_Money_and_Equipment.md?id=basic-melee-weapons)和[远程武器](0006_Money_and_Equipment.md?id=basic-ranged-weapons)的表格条目）。例如，短剑造成1d6伤害。

武器或攻击所投出的伤害值会按照特定顺序受到某些条件的修正：

- 应用进行攻击的角色的伤害修正。
- 修正来自任何武器强化（或削弱）魔法的伤害。
- 如果被格挡，根据相对武器尺寸适当减少伤害。
- 如果命中部位有护甲，则扣除护甲值（Armor Points）。

如果攻击造成的伤害大于零，则该命中部位承受相应伤害，伤害总量立即从该部位的生命值中扣除。记录下该部位剩余的生命值，以及由此产生的伤势类别。

- **轻伤（Minor Wound）：** 命中部位仍有正生命值。
- **重伤（Serious Wound）：** 命中部位生命值降至零或以下。
- **致命伤（Major Wound）：** 命中部位降至负值，且数值等于或超过其起始生命值。

如果一个部位受到重伤或致命伤，请使用以下规则。请注意，需要进行耐久度（Endurance）检定的伤势，需将其与原始攻击掷骰的数值进行对抗检定。这反映了高技能战士做出更致命打击的能力。除非该部位再次受伤，否则耐久度检定不会重复。

#### 轻伤

轻伤包括割伤、擦伤、淤青和扭伤。它们会引起疼痛并可能流血，但不足以减慢或阻碍受害者。

#### 重伤

如果一个部位的生命值降至零或以下，受害者会受到重伤。该部位会留下永久性疤痕，并且由于受到重伤带来的惊吓或疼痛干扰，受害者在接下来的1d3个轮次内无法攻击或开始施法（但仍可以进行格挡或闪避）。

肢体受到重伤的角色必须立即用其耐久度对敌人的成功攻击掷骰进行对抗检定。失败会导致该肢体废弃，直到该部位恢复到正生命值。如果是腿部受伤，受害者会倒地（Prone）。如果是手臂受伤，除非物体被系带固定住（此处需运用常识），否则持有的任何东西都会掉落。

腹部、胸部或头部受到重伤的角色必须立即用其耐久度对敌人的成功攻击掷骰进行对抗检定。失败会导致昏迷，昏迷时间（分钟）等于造成重伤的攻击所造成的伤害值。可以使用“急救”或“治疗”技能帮助昏迷的受害者从重伤部位恢复。

由游戏主持人决定，即使角色仍然可以行动，所有需要使用该命中部位的任务都将受到一个难度等级（Difficulty Grade）的持续减益，直到伤势减轻为轻伤。

#### 致命伤

如果一个部位降至负值且数值等于或超过其起始生命值，角色会受到致命伤。角色立即陷入“丧失能力（Incapacitated）”，无法继续战斗。致命伤会导致肢体被截断、贯穿、粉碎或撕裂。角色会倒地，身体丧失能力，并必须立即用耐久度对敌人的成功攻击掷骰进行对抗检定。失败会导致因剧痛而昏迷。如果被切断、刺穿或撕裂的部位没有在等于其治疗率（Healing Rate）五倍的分钟数内得到处理，角色会因失血和休克而死亡。

腹部、胸部或头部受到致命伤的受害者会昏迷并彻底丧失能力，且必须立即用耐久度对敌人的成功攻击掷骰进行对抗检定。失败会导致即时且惨烈的死亡（被斩首、腰斩、刺穿心脏、被撕碎等）。如果他们幸存下来，且该部位没有在等于其治疗率两倍的战斗轮次内得到处理，他们仍会因失血和休克而死亡。

由于大多数致命伤需要某种形式的手术或高级魔法才能治愈，受伤者极不可能及时从致命伤中恢复以重返战场。根据可用的治疗方法，受伤的部位可能会致残（参见[从伤病中恢复](0007_Game_System.md?id=healing-from-injury)）。

### 失血（Blood Loss）

由外部和内部伤口引起的失血（通常在战斗中发生）会很快削弱角色。其影响通过疲劳等级的积累来衡量，类似于[窒息](0007_Game_System.md?id=asphyxiation)。不受控制的失血通常会在没有某种形式医疗救助的情况下导致死亡。与窒息不同的是，严重失血对疲劳的影响是持久的。角色从失血中损失的疲劳以每天一级的速度恢复，从失血停止后的第二天开始。

#### 英雄般的最后行动（Heroic Last Actions）

在关键角色受到致命伤的特殊情况下，游戏主持人可能会允许进行一次英雄般的最后行动——例如发出最后一个法术、试图斩杀对手、爬走躲藏，或试图为自己的伤口止血。他们必须拥有适用于该行动的有效肢体，并消耗一个幸运点（Luck Point）。他们有一次尝试该行动的机会，然后立即倒地陷入昏迷，并可能死亡。

## 从伤病中恢复（Healing from Injury）

从伤口和伤害中自然愈合基于角色的“治疗率”。治疗率决定了在一个部位在一段时间内恢复的生命值，具体取决于伤势的性质：

- 轻伤：以天计
- 重伤：以周计
- 致命伤：以月计

因此，一个治疗率为3的角色，如果其某个部位受到伤害至–3（重伤），他将以每周3点生命值的速度自然愈合，直到伤势恢复到零以上，然后以每天3点生命值的速度愈合，直到完全康复。

自然愈合有一定的限制：

- 正在愈合的角色不能进行剧烈活动：否则治疗率会减少1d3。因此，即使是正在从轻伤中恢复的角色，如果他们决定从事任何可能加重伤势的体力工作，其康复进度也可能会停滞。
- 致命伤在受害者未通过成功使用[治疗](0005_Skills.md?id=healing-intpow)技能或施展“治愈伤口（Cure Wounds）”系列法术进行处理之前，不会开始自然愈合。非截肢性的致命伤如果未能在等于治疗技能值二十分之一的天数内得到处理，将导致伤残，永久降低该部位的生命值。

### 魔法治疗（Magical Healing）

有些魔法可以治愈受害者受到的创伤。但每种法术可以治疗的伤势等级都有具体的限制。例如，神术“治愈轻伤（Cure Minor Wounds）”正如其名，对轻伤最有效，而“治愈重伤（Cure Serious Wounds）”法术对轻伤和重伤都最有效。只有最强大的魔法才能瞬间逆转致命伤带来的创伤。

无论治疗法术多么低级，其施用总是足以稳定任何类型的伤口，防止出血和即时死亡，即使它并没有真正治愈潜在的损伤。请注意，这仅适用于严重的身体创伤，不适用于窒息、中毒等引起的情况。

## 幸运点（Luck Points）

幸运点有助于将英雄与普通人区分开来。它们代表了角色将失败转化为成功，甚至欺骗死亡的能力。

达到2级（Rank 2）时，以及此后的每一级，所有角色都会获得一个额外的幸运点。这在某种程度上模拟了基于等级的游戏中额外生命值的获得，允许更高等级的角色在面对龙、恶魔、魔鬼等威胁时更好地保护自己，而不至于让他们承受比非洲雄象还多的伤害。

幸运点可以在游戏过程中使用，并在下一场游戏开始时恢复到其通常的数值。

#### 使用幸运点

幸运点可以通过多种方式使用。每个特定的行动只能使用一个幸运点。幸运点不能用于经验或训练掷骰。以下每个选项消耗一个幸运点。

#### 欺骗命运（Cheat Fate）

角色可以使用一个幸运点来重掷或交换（例如，75可以变为57）他们所做的任何骰子掷骰。这可以是技能掷骰、伤害掷骰或任何其他有某种效果的掷骰。角色甚至可以强迫对手重掷针对他们发起的攻击或伤害掷骰。

#### 孤注一掷（Desperate Effort）

如果一个角色在战斗中耗尽了行动点（Action Points），并且需要最后爆发出一股绝望的能量来避免糟糕的结局，他们可以花费一个幸运点来获得一个额外的行动点。

#### 减轻伤害（Mitigate Damage）

受到致命伤的角色可以花费一个幸运点，将伤势降级为重伤。这会将受到的伤害减少到比造成致命伤所需的数值少1点。

## 陷阱（Traps）

陷阱是各种文化中随处可见的装置，从捕捉动物的陷阱坑，到守护陵墓万世之久的死亡陷阱。这些装置建造的目的各异，每一种都是专门为了报警、捕获入侵者或直接致残和杀害窃贼而量身定制的。

建造陷阱要求建造者掌握“机械（Mechanisms）”或“工程（Engineering）”技能。小型陷阱（如捕熊夹或锁具陷阱）需要“机械”技能，而大型建筑（如尖刺坑或翻滚巨石）则需要“工程”技能。

除了雇用合格的工匠外，陷阱通常还需要非常昂贵的组件或人工成本。作为一个通用指南，报警陷阱的成本为制作者技能数值的铜币，诱捕陷阱为同等数量的银币，而死亡陷阱需要支付金币。

所有陷阱都有一个难度等级（Difficulty rating），代表其被察觉、解除或避免的困难程度。在进行对抗检定时，该数值被视为陷阱的技能。

尽管讲故事的人讲述了许多有趣的传说，但陷阱——尤其是那些旨在杀人的陷阱——一旦启动，很少有巧妙地避免或逆转其效果的方法。如果没有魔法或好运，那些掉入死亡陷阱的人通常会屈服于其高效的目的。简而言之，它们的设计初衷并非让人存活。除非陷阱有某种狡猾的设计，或者是某种持久的魔法附魔，否则一旦触发，就必须手动重置。

### 陷阱特性（Trap Traits）

陷阱使用以下特性进行描述。

#### 用途（Purpose）

陷阱的用途。主要有四种类型：

- **报警（Alarm）：** 陷阱发出静默或可闻的信号，表明它已被触发。
- **诱捕（Ensnaring）：** 陷阱旨在捕获任何触发或进入它的人。
- **致残（Maiming）：** 陷阱旨在严重伤害任何触发它的人。
- **死亡（Death）：** 陷阱旨在杀死那些激活其致命装置的人。

#### 触发（Trigger）

陷阱启动的方式。

#### 难度（Difficulty）

陷阱的挑战等级，等于创造它的“机械”或“工程”技能数值。例如，一个由掌握70%“机械”技能的工匠在宝箱底部建造的镰刀陷阱，其难度为70%。此后，陷阱将在对抗检中使用该数值，以查看刀刃是否会被发现、闪避或解除。

#### 抵抗（Resistance）

如何抵抗陷阱——通常使用“强壮（Brawn）”、“闪避（Evade）”或使用带有盾牌的战斗技能进行“格挡（Parrying）”。陷阱触发时进行抵抗掷骰。

#### 效果（Effect）

陷阱启动且受害者未能抵抗时会发生什么？如果是报警陷阱，通常会导致对手被惊动；如果是诱捕陷阱，会导致受害者被捕。致残陷阱和死亡陷阱显然会伤害受害者，尽管有些死亡陷阱利用除直接伤害以外的其他手段来造成伤害，例如溺水或中毒。为了限制过于致命的陷阱，大多数机械装置造成的伤害受到其创造者技能的限制。然而，其他如使受害者中毒的陷阱则不考虑制作者的实际技能。这通常通过所使用毒药的昂贵程度来平衡。另一个例外是陷阱坑，其伤害仅基于坑的深度。在这些情况下，创造者的技能用于确定发现、闪避和解除陷阱的几率；伤害根据毒药类型或坠落距离适当确定。对于可以格挡的射弹陷阱，标注了力度（Force）。

##### 死亡陷阱伤害限制

| **制作者技能** | **伤害** | **尺寸/力度** |
| :-: | :-: | :-: |
| 1-10% | 1d2 | 小型 |
| 11-20% | 1d4 | 小型 |
| 21-30% | 1d6 | 中型 |
| 31-40% | 1d8 | 中型 |
| 41-50% | 1d10 | 大型 |
| 51-60% | 2d6 | 大型 |
| 61-70% | 1d8+1d6 | 巨大 |
| 71-80% | 2d8 | 巨大 |
| 81-90% | 1d10+1d8 | 极巨 |
| 91-100% | 2d10 | 极巨 |

伤害可能会影响多个随机命中部位，每增加一个部位，伤害就会在“死亡陷阱伤害限制表”上降低一个等级。例如，技能为50%的陷阱设计师可以设计一个陷阱，对单个部位造成1d10伤害，对1d2个命中部位造成1d8伤害，对1d3个部位造成1d6伤害，以此类推。潜在部位的数量在设计陷阱时设定，且无法更改。由于额外的命中部位数量是随机的，因此整体造成的伤害可能会更少。

### 陷阱示例

#### 陷阱坑（Pitfall）

陷阱坑是各种文化中使用的原型陷阱。它可以是简单的挖坑，上面覆盖树枝和树叶，也可以是结构复杂、带有铰链假底的石墙储水池，假底配有平衡装置，在受害者掉入后能自动弹回原位。

陷阱坑不必非常深。如果旨在捕获，简单的双耳瓶或龙虾篓形状将防止通过攀爬逃脱，凿成光滑的墙壁或由受力即碎的易碎材料制成的墙壁也能达到同样效果。旨在杀人的陷阱坑通常会在底部铺满数十根木桩，排列紧密，使坠落的角色不可避免地被刺穿。其他选项可能包括在底部填充弱酸、足够深的水以致溺水，或饥饿的老鼠。

- **用途：** 诱捕或死亡
- **触发：** 走过覆盖坑口的假表面
- **难度：** 60%
- **抵抗：** 进行“闪避”以跳开，或进行高难度的“运动（Athletics）”掷骰以在坠落时抓住边缘。
- **效果：** 坠入陷阱会对随机命中部位造成2d6伤害，护甲无法防御。次要效果留给游戏主持人发挥想象力。#### 毒针陷阱

这是另一种常见的陷阱，从国王的寝室到被遗忘的陵墓，随处可见。这种陷阱通常设置在宝箱上，但也能发现它被用来保护门锁。除非使用正确的钥匙开启，否则陷阱会向任何试图撬锁的人的手中射出一枚小型毒针。

- **目的：** 诱捕或致死
- **触发：** 尝试撬开被陷阱保护的物体上的锁。
- **难度：** 60%
- **抵抗：** 耐力
- **效果：** 当触发时，一枚小型毒针会弹出并刺入任何尝试撬锁者手中。任何毒药都可用于涂抹毒针。游戏主持人（Game Master）可以决定毒药的具体细节——这些内容在《经典奇幻》（_Classic Fantasy_）主规则中有详细说明。
