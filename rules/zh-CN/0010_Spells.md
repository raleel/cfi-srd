## 法术描述

---
#### Appraise（鉴定）

(Divination - 预言系)

| | |
| :-- | :-- |
| **等级：** 法师 0 | **施法时间：** 1 轮 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 1 | **范围：** 接触 |
| **区域：** 1 件物品 | **抵抗：** 无 |

鉴定允许立即评估物理货物的质量，总 ENC（重量单位“Things”）或 SIZ 需等于施法者的 POW。该法术可确定外观相同的物品是否具有相同或相似的质量，或者其中一个或多个是否存在缺陷或更高质量。该法术对有机物无效，仅适用于无生命物体。它也不能确定具体存在什么缺陷或增强，仅仅能确定它们的存在。它在识别或探测魔法方面毫无用处。

#### Armor（护甲术）

(Conjuration - 咒法系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 1 回合 |
| **领域：** 无 | **持续时间：** 见下文 |
| **消耗：** 3 +1/强度 | **范围：** 接触 |
| **区域：** 1 个目标 | **抵抗：** 无 |

当此法术施放时，受术者会被赋予一层隐形的魔法力场，其防护力等同于鳞甲，为每个命中部位提供 4 点护甲值。如果目标已经穿戴护甲，则此法术无效。但是，只要该力场提供的保护优于自然护甲，它将在持续时间内取代自然护甲。如果施加于拥有超过 4 点自然护甲值的生物，它将增加所有部位 1 点护甲值。这种魔法防护不会阻碍移动或施法。法术将持续存在，直到被魔法驱散，或者施法者在单次攻击中承受了 8 点伤害（每增加一级强度额外增加 1 点，见下表）。当然，施法者可以随时选择撤销法术，且睡眠时必须撤销。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3 | 4 点护甲；持续直至单次攻击承受 8 点伤害 |
| 2 | 4 | 4 点护甲；持续直至单次攻击承受 9 点伤害 |
| 3 | 5 | 4 点护甲；持续直至单次攻击承受 10 点伤害 |
| 4 | 6 | 4 点护甲；持续直至单次攻击承受 11 点伤害 |
| +1 | +1 | 继续递增 |

#### Astral Spell（星界法术）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 牧师 5, 法师 5 | **施法时间：** 2 行动 |
| **领域：** 星界 | **持续时间：** 见下文 |
| **消耗：** 3 +1/额外强度 | **范围：** 接触 |
| **区域：** 见下文 | **抵抗：** 不适用 |

此法术允许施法者及最多另外五人（每增加一级强度增加一人）进入星界。施法时所有人必须互相接触并围成一个圈。旅行者的肉体留在原位，通常不会携带任何衣服或装备，除非该物品本身散发魔法光环；这些物品会转化为其原始形态的星界对应物。持续时间直到施法者希望停止为止。然而，它也可能被外部力量（如“驱散魔法”）提前终止。杀死施法者的肉体也会提前结束法术，但这有一个不幸的副作用：随行的旅行者将被困住。

#### Augury（占卜术）

(Divination - 预言系)

| | |
| :-- | :-- |
| **等级：** 牧师 2 | **施法时间：** 2 分钟 |
| **领域：** 预言 | **持续时间：** 瞬时 |
| **消耗：** 3/强度 | **范围：** 60 英尺 |
| **区域：** 施法者 | **抵抗：** 不适用 |

此法术允许施法者判断在接下来的 30 分钟内采取的特定行动对个人和/或团队的福祉是否有益或有害。需要某种焦点物来辨识征兆，最常见的是龙爪或小骨头、珍珠，或价值不低于 100 金币且已粉碎或熔化的纯金。该法术的最大强度为 4。此检定应由游戏管理员（GM）进行，因为施法者永远不应确切知道结果是否解读正确。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3 | 艰巨（Formidable）引导技能检定 |
| 2 | 6 | 困难（Hard）引导技能检定 |
| 3 | 9 | 标准（Standard）引导技能检定 |
| 4 | 12 | 容易（Easy）引导技能检定 |

如果预言检定成功，将获得以下结果之一：

| 占卜结果 | 含意 | 
| :-: | :-- |
| 是 | 行动将是有益的 |
| 否 | 行动将是有害的 |
| 是与否 | 行动将兼具益处与害处 |
| 无 | 行动既无益也无害 |

大失败（Fumble）的结果应由 GM 告知与现实相反的结果。

#### Avert（回避术）

(Abjuration - 防护系)

| | |
| :-- | :-- |
| **等级：** 牧师 0, 法师 0 | **施法时间：** 瞬时 |
| **领域：** 防护 | **持续时间：** 瞬时 |
| **消耗：** 1 | **范围：** 60 英尺 |
| **区域：** 1 个法术 | **抵抗：** 无 |

Avert 用于在范围内抵消另一个 0 等级法术。Avert 可以通过使用“反制魔法”反应动作来被动地中和攻击性的 0 等级法术。

#### Befuddle（困惑术）

(Enchantment (Charm) - 附魔系（魅惑）)

| | |
| :-- | :-- |
| **等级：** 牧师 0, 法师 0 | **施法时间：** 1 轮 |
| **领域：** 魅惑 | **持续时间：** 30 分钟 |
| **消耗：** 1 | **范围：** 60 英尺 |
| **区域：** 1 个目标 | **抵抗：** 意志 |

Befuddle 在物质目标的思维中引起混乱。受术者难以清晰思考，忘记了自己身在何处、在做什么以及为什么——通常会陷入思维断层。受到困惑的目标仍然可以进行自卫，但在法术结束前无法发起任何建设性活动。任何形式的攻击或威胁行动都会立即打破法术，无论是否针对该困惑目标。

#### Blade Barrier（刃之壁）

(Evocation - 塑能系)

| | |
| :-- | :-- |
| **等级：** 牧师 4 | **施法时间：** 2 行动 |
| **领域：** 守护，创造 | **持续时间：** 3 轮/强度 |
| **消耗：** 3+1/额外强度 | **范围：** 100 英尺 |
| **区域：** 5-30 英尺半径 | **抵抗：** 见下文 |

此法术创建一个旋转的利剑、匕首和刀具壁垒，在固定点周围挥舞切割，对_任何_穿过效应区域的目标，造成 1d8 点伤害，命中 1d4+2 个随机部位。护甲仅提供一半保护。魔法护甲值正常减少伤害。由于武器以极快速度旋转且排列紧密，无法格挡（Parry）或闪避（Evade）它们。受术者可以使用盾牌被动地阻挡部位伤害，在此情况下，记得将滚动伤害与盾牌的护甲和生命值进行比较。

此法术可以防御性地保护牧师或盟友，或进攻性地困住敌人。然而，当壁垒形成时，位于边缘五英尺内的被困敌人可以进行闪避（Evade）检定以逃离。无论成功与否，对手最终都会倒地，位于效应区域之外。成功检定则不造成伤害；否则承受全部影响。

#### Bless \(R\)（祝福术）

(Conjuration - 咒法系)

| | |
| :-- | :-- |
| **等级：** 牧师 1 | **施法时间：** 1 回合 |
| **领域：** 全领域 | **持续时间：** 5 分钟 |
| **消耗：** 1 | **范围：** 180 英尺 |
| **区域：** 25 英尺半径 | **抵抗：** 意志 |

当此法术施放时，牧师祝福效应区域内的盟友群体。受影响者散发出施法者的阵营（善良或邪恶）。没有中立阵营的祝福。半径内的所有盟友获得所有技能和抵抗检定 +5% 的加值。此外，他们的武器对智慧型不死生物以及与施法者阵营对立的外层位面生物（如恶魔、魔鬼或天使）造成 +1d3 点伤害。请注意，虽然骨骼和僵尸等不死生物并非天生邪恶，但它们通常由邪恶魔法动画化，因此受到此伤害影响。

该法术的逆转，诅咒（Curse），允许牧师诅咒敌人，使其注明的技能受到上述加值的相反惩罚。诅咒武器的伤害被计算为减值，且此伤害结果不得少于 1 点。

#### Burning Hands（燃烧之手）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 3+1/额外强度 | **范围：** 0 |
| **区域：** 120 度扇形，5 英尺长 | **抵抗：** 闪避 |

此法术使火焰从施法者的手中射出，形成 120 度的扇形弧线。若在战斗中使用微缩模型，燃烧之手将伤害占据施法者前方 1 格的每个目标。以更高强度施放需要更高等级的法师。该伤害吞没区域内所有目标，伤害基于法术强度（最大强度 9）。成功的闪避检定（滚倒在地）使受害者免受伤害。拥有“狡猾闪避（Artful Dodger）”能力的生物可以选择不倒地而进行闪避。

| 强度 | 消耗 | 最低等级 | 可变效果 |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 对所有命中部位造成 1d3+1 点伤害 |
| 3 | 4 | 1 | 对所有命中部位造成 1d3+2 点伤害 |
| 5 | 5 | 1 | 对所有命中部位造成 1d3+3 点伤害 |
| 7 | 6 | 2 | 对所有命中部位造成 1d3+4 点伤害 |
| 9 | 7 | 3 | 对所有命中部位造成 1d3+5 点伤害 |

穿戴的护甲不提供保护，但魔法护甲值或生物的自然护甲正常减少伤害。该法术强大的平衡点在于其极短的射程，这意味着施法者必须非常接近敌人，处于极其不利的位置。

#### Chain Lightning（连环闪电）

(Evocation - 塑能系)

| | |
| :-- | :-- |
| **等级：** 法师 4 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 3+1/额外强度 | **范围：** 50 英尺/强度 |
| **区域：** 见下文 | **抵抗：** 闪避 |

施放时，法师从指尖释放出一道五英尺宽的电流，可击中范围内的一个目标，造成每 2 点强度 1d6+1 点伤害。闪电随后会弧射向最近的物体或生物，造成之前的滚动伤害减去 1 点，然后再弧射向下一个，造成滚动伤害减去 2 点，依此类推。甚至可能弧射向盟友或施法者！虽然初始目标必须在施法者的视野内，但后续被弧射的目标不必在视野内。

#### Command（命令术）

(Enchantment (Charm) - 附魔系（魅惑）)

| | |
| :-- | :-- |
| **等级：** 牧师 1 | **施法时间：** 1 行动 |
| **领域：** 魅惑 | **持续时间：** 1 分钟 |
| **消耗：** 3 | **范围：** 100 英尺 |
| **区域：** 1 个目标 | **抵抗：** 意志 |

当此法术施放时，牧师可以对一个 SIZ 1-20 的活生物发出一个词的命令，若目标意志抵抗失败，将在其下一回合严格服从该命令。这本质上导致受害者浪费下一回合来完成命令，并损失一个行动点。如果受害者没有剩余行动点，命令将在下一轮的第一回合执行。命令本身不能对目标造成任何实际伤害；然而，伤害可能作为命令的次要影响产生。

例如，命令“死”会导致受害者进入长达 1 轮的类似死亡的昏迷状态，不造成实际伤害；然而，命令一个正攀爬 100 英尺高悬崖的生物“掉落”可能导致致命后果。

被命令者必须能够理解施法者所说的语言，并可进行意志检定以抵抗。

**部分命令示例**

- **Crawl（爬行）：** 目标倒地并开始爬行。
- **Die（死亡）：** 目标倒地进入类似死亡的昏迷状态。
- **Fall（跌倒）：** 目标倒地。
- **Fumble（笨拙）：** 目标使即将进行的身体动作失败。
- **Sleep（睡眠）：** 目标入睡。
- **Flee（逃跑）：** 目标转身逃离施法者。
- **Fly（飞翔）：** 目标扇动双臂在原地转圈。
- **Go（前进）：** 目标开始向面向的方向行走。
- **Halt（停止）：** 目标立即停止并站在原地。
- **Leave（离开）：** 目标转身离开。
- **Rest（休息）：** 目标坐下喘息。
- **Run（奔跑）：** 目标开始奔跑。
- **Scream（尖叫）：** 目标大叫。
- **Sink（下沉）：** 目标停止游泳。
- **Surrender（投降）：** 目标扔掉武器并停止敌对。

#### Cure Major Wounds \(R\)（治愈重伤）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 牧师 2 | **施法时间：** 1 回合 |
| **领域：** 治疗 | **持续时间：** 永久 |
| **消耗：** 3/强度 | **范围：** 接触 |
| **区域：** 1 个目标 | **抵抗：** 不适用（耐力或闪避） |

此法术功能与“治愈轻伤”相同，除以下注明外。

此法术治愈受重伤的单个命中部位，无论其是被粉碎还是毁损。它对断肢无效，断肢需要“愈合（Heal）”法术（若肢体尚存）或“再生（Regeneration）”法术修复。只要受术者尚存且受伤时间在法术强度的小时数内，治愈重伤几乎瞬时恢复 1d8+4 点伤害。

当逆转时，“导致重伤（Cause Major Wounds）”可用于减少单个命中部位 1d8+4 点生命值。施法者的引导检定作为命中对手的检定，并被视为法术体感需求的一部分。无需额外的命中检定。此法术不能切断部位，但可以将其正常粉碎或毁损。穿戴或自然护甲不提供保护，但魔法护甲值正常减少伤害。

#### Cure Minor Wounds \(R\)（治愈轻伤）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 牧师 1 | **施法时间：** 2 行动 |

治愈轻伤有几种不同的效果，取决于其所作用的病痛类型。当施加于受轻伤的生物时，受伤部位瞬间治愈 1d4+1 点生命值。它对重伤和重创伤的影响有限，只能恢复 1 点生命值。然而，该法术无论受损程度如何都能稳定该部位，停止一切出血并防止濒死。

或者，该法术可导致轻微的病痛，如头痛、背痛、宿醉、感冒、疣等。此种法术实例仅消耗 1 点魔法点。

#### Death Spell（死亡法术）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 法师 4 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 3 +1/强度，+2 经验点 | **范围：** 30 英尺/强度 |
| **区域：** 15 英尺半径 | **抵抗：** 耐力 |

此法术的成功施放会杀死效应区域内一定数量的 SIZ 40 或更小的生物。法师每级强度滚动 1d6 以确定受影响的生物数量。当不同 SIZ 类别的生物占据效应区域时，人类大小（SIZ 1-20）的生物总是先受影响。大型生物（SIZ 21-40）更难被杀死，抵抗检定为“容易（Easy）”，但每只大型生物计为 5 只人类大小生物。超过 SIZ 40 的生物不受此法术影响。

| 3 | 5 +2 经验点 | 90 英尺范围；3d6 个生物受影响 |

*示例：Rengarth 向四个 SIZ 16 的半兽人和两个 SIZ 32 的食人魔所在区域施放死亡法术，选择强度为 3。3d6 的滚动结果为 12 点。虽然每只食人魔需要 5 点才能被杀死，但较小的半兽人优先被影响。四个半兽人中有三个抵抗失败死亡。每只半兽人等于 1 点，剩余 8 点。这足以影响一个食人魔（5 点），剩余 3 点流失。然而，愤怒的食人魔通过了“容易”抵抗检定，并向 Rengarth 发起冲锋。*

通过此法术，施法者可以在 90 度角内，探测 180 英尺外强烈的邪恶气息。它仅能发现超自然性质的邪恶生物（如恶魔和吸血鬼）或 GM 确定的具有邪恶或恶毒意图的凡人。然而，它不会探测到陷阱、毒药、诅咒物品等。施法者可以透过最多 3 英尺厚的实木、1 英尺厚的石头或泥土、以及 1 英寸厚的坚硬金属观察这些气息。由于魔法光环需要时间形成，每分钟不得扫描超过一个 60° 角。恶魔、魔鬼、天使和元素本身并非魔法，但如果它们被召唤，该召唤法术会在施放地点注册其 magnitude x 10 分钟。此法术的逆转，“侦测善良”，遵循上述相同规则。

(Abjuration - 防护系)

| | |

驱散魔法可用于防御，通过使用“反制法术”反应动作来中和 incoming 的攻击性法术。

#### Enchant Item（附魔物品）

(Enchantment - 附魔系)

| | |
| :-- | :-- |
| **等级：** 法师 4 | **施法时间：** 见下文 |
| **领域：** 无 | **持续时间：** 见下文 |
| **消耗：** 3 + 见下文 | **范围：** 接触 |
| **区域：** 1 件物品 | **抵抗：** 不适用 |

此法术的施放为物品准备附魔。物体必须处于良好状态，且工艺上乘。至少额外支付 100 金币以覆盖额外的加工、雕刻、刺绣、珠宝镶嵌、雕版等费用。最后，附魔过程需要一个实验室或工作室。

施法时，法师必须在整个 1d8+2 天的施法时间内接触物品。这包括休息和睡眠时间，在此期间物品必须保持在施法者触手可及的距离内。施法过程中，施法者不得施放其他法术或执行任何其他魔法形式。打破任何限制将自动导致法术失败。

成功施放后，物品准备好进行最后一步，即将选定的法术置入其中。为此，他们必须记住该法术或持有卷轴，并在 24 小时内将其施加于物品上，否则整个过程将需要从头开始。一旦开始施放所选法术，过程可能会超过上述 24 小时。为物品灌注选定法术需要支付所需强度的正常魔法点，且每个法术等级需耗时 1d12 小时。灌注过程中，施法者必须保持接触或在休息时保持在触及范围内，且在施法周期结束时需进行“奥术施法（Arcane Casting）”检定以成功灌注法术。遵循正常的法术施放成功度，然而，若失败，法术无法被强制灌注。在完成前一个法术后 24 小时内开始施法过程，可在同一物品中灌注连续法术。即使在前一个法术失败的情况下也适用此规定。每个连续法术都需要正常的施法消耗。

使用物品时，其中包含的每个法术只能施放一次，然而可以通过上述程序灌注相同法术的多个版本。也可以在物品中灌注单个法术，随后施放 4 级法术“永恒术（Permanency）”。在此情况下，法术可以根据永恒术描述中设定的限制随心所欲地施放。

不可能将不符合特定法术的魔法效果灌注到物品中，并且许多远古时代的魔法物品在今天根本无法复刻。

| | |
| :-- | :-- |

#### Feather Fall（羽落术）

(Transmutation - 变化系)

当此法术施放时，效应区域内的一些人、生物或物体（SIZ 合计每级强度不超过 20）体重被减轻到如羽毛般。受影响者坠落速度不超过 10 英尺/轮或 120 英尺/分钟，在法术持续时间内不会受到坠落伤害。他们轻到对任何大于 5 英尺的击退效果有效免疫，如果撞到任何东西也不会受伤，因为他们会缓慢地漂浮后退。

在此法术影响下，飞行的生物（如鸟或龙）其飞行动态会发生改变，若想保持飞行，每轮持续时间需要进行“困难”飞行检定。成功则可随意移动，但仅有半速；失败则生物会被轻轻地甩出控制，随机向与预想移动方向相同距离的方向翻滚。如果让其直接坠落，飞行生物可以使用翅膀将着陆点调整每轮 5 英尺。

由于法术的瞬时施法时间，法师可以被动或主动使用羽落术。这允许防御意外坠落，或甚至中断他人的行动以减慢诸如箭矢或投掷长矛等抛射物的速度，这些抛射物随后会在攻击者和目标之间轻轻落在地上，不造成伤害。

#### Find Familiar（寻找魔宠）

(Conjuration - 咒法系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 2d12 小时 |
| **领域：** 无 | **持续时间：** 特殊 |
| **消耗：** 3/强度，+1 经验点 | **范围：** 0 |
| **区域：** ½ 英里半径/强度 | **抵抗：** 无 |

此法术允许施法者尝试召唤一个魔宠，成为主人感官和力量的延伸。魔宠可以与其主人心灵感应沟通，也是很好的守卫和侦察兵。魔宠被杀会给施法者带来风险，使其成为低等级危险。

要召唤魔宠，施法者必须在炉膛里焚烧木炭，当其燃烧剧烈时，加入价值 100 金币的香料。在这些材料燃烧的同时，法师必须持续仪式直到魔宠到来或施法时间耗尽。

即使成功施放，适合的魔宠回答呼唤的几率也仅有 50%，且施法者每年只能尝试一次。每增加一级强度将扩展法术范围半英里，从而增加 5% 的发现可能性，上限 95%。对于会出现的具体生物种类无法控制，但到来的将是忠实的仆人和盟友。魔宠是否响应取决于特定的生物，因此身处特定生物栖息区域并不能保证成功。

如果有生物响应召唤，施法者仍需牺牲 1 经验点以在自己和魔宠之间建立精神连接。一旦完成，仪式结束。

如果魔宠死亡，施法者损失 5 经验点。目前没有任何经验点的施法者必须没收所有进一步获得的经验点，直到余额还清。

#### Fire Shield（火焰护盾）

(Evocation - 塑能系)

| | |
| :-- | :-- |
| **等级：** 法师 3 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 2 分钟/强度 |
| **消耗：** 3+1/额外强度 | **范围：** 0 |
| **区域：** 施法者 | **抵抗：** 不适用 |

此法术创造一层轻盈火焰护盾，燃烧施法者但自身不造成伤害。相反，火焰保护受术者免受火或冷的伤害，具体取决于记忆中的两种变体：寒冷护盾（蓝色或绿色火焰，保护免受热和火伤害）或温暖护盾（紫色或蓝色火焰，保护免受寒冷和冰伤害）。火焰颜色应随机决定（两种各 50% 几率），因为两者都能发出蓝色火焰的事实让攻击者感到不确定。选择哪种变体在准备法术时确定，若需要可同时记忆两者。火焰本身不发热，照明范围仅为火把亮度的一半。

- **寒冷护盾：** 这些火焰摸起来很凉，将任何火或热伤害降低至总数的一半。成功的意志抵抗检定会抵消所有伤害。意志检定难度降低一级，且在闪避情况下，不会使防御者倒地。
- **温暖护盾：** 这些火焰摸起来温暖，将任何寒冷伤害降低至总数的一半。成功的意志抵抗检定会抵消所有伤害。意志检定难度降低一级，且在闪避情况下，不会使防御者倒地。

除使用上述对应元素外，任何针对护盾受术者的近战攻击（无论是徒手或武装）均造成正常伤害。在此情况下，施法者免受攻击的元素部分伤害，且攻击者受到等同于其造成的伤害。攻击者的护甲不提供保护，但自然护甲或魔法护甲值正常减少伤害。具有天生魔法抗性的生物在第一次受击时可通过意志成功检定驱散“火焰护盾”。如果意志抗性检定失败，对手之后无法再抵消该护盾。

#### Flesh to Stone \(R\)（石化术）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 4 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 永久 |
| **消耗：** 3/强度 | **范围：** 30 英尺/强度 |
| **区域：** 1 个目标 | **抵抗：** 意志 |

当施放时，范围内一个受害者有一次意志抵抗检定。如果失败，他们及所有携带和穿戴的物品都将完全转化为坚固的石头。这种转化不是死亡，而是处于悬浮动画状态。逆转此法术或使用“祈愿术”可恢复受害者生命。受害者在石化状态下遭受的任何伤害都会延续，并在恢复原状时立即生效。大型生物（SIZ 21-40）不太容易被石化，抵抗为“容易（Easy）”，巨型生物（SIZ 41+）抵抗为“非常容易（Very Easy）”。

该法术的逆转，“石化解除（Stone to Flesh）”，用于恢复受害者，无需进行抵抗检定。然而，法术也可以逆转以转化从未活过的石头；这有多种创造性用法。例如，可以将每级强度 10 立方英尺的石墙转化为柔软的肉体，可以创建一条每级强度 10 英尺长、3 英尺宽的肉质“隧道”，可以将石像等单个目标转化为肉体，甚至通过此法术将石像鬼转化为血肉像鬼。然而在后一种情况下，石像鬼将正常进行意志检定抵抗。这样转化的肉体是柔软且易弯曲的，虽然保留其实际生命值，但没有护甲值，更容易被砍碎。

当施放时，此法术允许受术者在持续时间内正常行动，而不受妨碍移动或惩罚攻击的其他法术或效果的影响。这包括抵消来自泥浆和雪等地形带来的惩罚。在水下，受术者可以以正常的陆地速度移动，挥舞的武器（剑、斧、棍、锤等）具有全面效果。然而，此法术不赋予水下呼吸能力。此法术中和妨碍法术（如缠绕、减速、定身、麻痹、蛛网等）对移动和行动惩罚的影响。

#### Frostbite（冻伤术）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 0 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 1 | **范围：** 60 英尺 |
| **区域：** 1 个目标 | **抵抗：** 耐力 |

冻伤术直接作用于活体有机组织，在受术者的肢体末端造成麻木和疼痛（例如手指、脚趾、臀部、鼻子和耳朵等）。施法者必须触摸特定肢体，或者如果是远程施法则随机滚动。如果法术未被抵抗，受影响区域会经历麻木后的持续疼痛，持续时间延长，使得利用该部位的技能测试难度增加一级。冻伤术不造成直接伤害，但使受影响部位在一段时间内受限。例如，臀部冻伤的目标坐下时会有剧烈的不适。

大型生物（SIZ 21-40）抵抗较容易，巨型生物（SIZ 41+）抵抗非常容易。

#### Fumble（笨拙术）

(Enchantment (Charm) - 附魔系（魅惑）)

| | |
| :-- | :-- |
| **等级：** 法师 3 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 1 轮/强度 |
| **消耗：** 3+1/额外强度 | **范围：** 30 英尺/强度 |
| **区域：** 10 英尺半径 | **抵抗：** 意志 |

此法术导致效应区域内所有对手变得笨拙，任何物理技能检定难度增加一级，且所有失败均导致大失败（Fumble）。甚至通常不需要技能检定的物理动作（拾取掉落物品、快步走、爬楼梯）也需要“运动”技能检定。在这种情况下，失败导致大失败，在移动的情况下通常会导致尴尬的摔倒，或者在拾取物品时意外将其踢得更远。GM 应具有创意，但非战斗情况下的结果应尽量避免直接致死。然而在战斗中，大失败按正常规则处理，可能产生正常的特殊效果。

| 2 | 4 | 2 轮；60 英尺范围 |
| 3 | 5 | 3 轮；90 英尺范围 |
| 4 | 6 | 4 轮；120 英尺范围 |
| +1 | +1 | 继续递增 |

#### Gate（传送门/召唤术）

(Conjuration - 咒法系)

| | |
| :-- | :-- |
| **等级：** 牧师 5, 法师 5 | **施法时间：** 2 回合 |
| **领域：** 召唤 | **持续时间：** 见下文 |

施放 Gate 需要施法者知道要召唤的实体的真名，该实体通常是来自其他位面的生物（如恶魔、魔鬼、天使、半神甚至是神）。当成功施放时，在施法者所在的位面与实体的位面之间打开一道传送门。无论施放成功与否，该法术都会自动获得实体的关注。此法术极其强大且消耗巨大，不仅消耗 3 点魔法点和 3 经验点，还会导致施法者衰老 5% 的预期寿命（以人类施法者为例即 5 年）。如果实体在抵抗检定中成功，通常不会亲自到来，但假设法术成功，“某种东西”会穿过传送门。下表用于确定一些常见实体、它们的平均意志以及通常会派遣的代理人。GM 可随意选择最适合当前战役本质的生物。

响应的形式将很大程度上取决于特定的实体、双方阵营以及请求的具体细节。如果实体认为打断的理由是琐碎或无足轻重的，他们的回应可能从简单离开到直接攻击不等。然而，绝望的情况，尤其是施法者受到实体强烈反对的东西威胁时，更有可能得到更积极的回应。如果 GM 认为存在灰色地带且回应存疑，施法者及其盟友可以尝试通过技能、奉承、恳求和/或贿赂来辩解。然而，大多数实体会避免被卷入与力量相等或更大的敌人的冲突中，许多会要求支付报酬（不论事前或事后）。传送门将保持打开，直到实体决定在此停留，或穿过它离开。在此期间，传送门可能被他人通行，提供两个位面之间的双向旅行。

| **消耗：** 1 | **范围：** 60 英尺 |
| **区域：** 1 个目标 | **抵抗：** 意志 |

魅力术使目标引人注目，从而吸引他人。魅力效果必须在施法时选择，可以是增加自然美、更柔和诱人的声音，甚至是迷人的身体气味。虽然此法术不提供任何机械加值，但它确保受术者有机会聚集听众、引起他们想要联系的人的注意，或提供分心机会，使共犯有机会执行邪恶的计划。

#### Heal  \(R\)（愈合术）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 牧师 4 | **施法时间：** 1 分钟 |
| **领域：** 治疗 | **持续时间：** 永久 |
| **消耗：** 3 +1/强度 | **范围：** 接触 |
| **区域：** 1 个生物 | **抵抗：** 不适用（耐力或闪避） |

施放“愈合术”时，牧师可以通过一次触摸治愈身体病痛、心理创伤或大量受伤。恢复程度基于法术强度。每级强度，该法术治愈目标一种任意 POT 的疾病，治愈任何失明或耳聋，消除受伤或魔法带来的心理障碍，或治愈单个命中部位最多 12 点伤害。然而，它不会恢复断肢，这需要“再生（Regeneration）”术。每增加一级强度可用于治愈另一种病痛或治愈另一个命中部位。因此，治愈一个全身烧伤的人需要 7 级强度。与限制长期伤害有效性的较弱治疗法术不同，该法术在受伤时间持续时间方面没有限制。

当逆转时，“伤害（Harm）”，在抵抗检定失败的情况下对受害者的一个命中部位造成 12 点魔法伤害。或者， infliction 一个病痛，其效果与“治愈疾病”的逆转“导致疾病”相同，但在 POT 上增加 +20。施法者的引导检定作为命中对手的检定。无需额外的命中检定。穿戴或自然护甲均不提供保护，但魔法护甲值正常减少伤害，并完全阻挡 inflicted 疾病。每增加一级强度影响另一个相邻的命中部位。该法术任一版本对不死生物、仅受铁、银或魔法武器伤害的生物、或非实体生物均无效。

#### Ignite \(R\)（点燃术）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 0 | **施法时间：** 1 行动 |
| **领域：** 元素（火） | **持续时间：** 瞬时 |
| **消耗：** 1 | **范围：** 10 英尺 |
| **区域：** 1 个小火源 | **抵抗：** 无 |

此法术可用于两种不同方式，即“点燃”或“熄灭”。施法时选择其一。

点燃仅适用于可燃的无机物，导致小物体或手掌大小的区域燃起火焰。根据被点燃物体的不同，火焰可能会蔓延。此法术通常用于远程点亮蜡烛、火把或灯笼。它也可以在恶劣条件下点燃营火或烹饪火。

熄灭立即扑灭中等大小和热度的火焰和小火。它适用于熄灭蜡烛、灯笼、火把或小型厨火，但对魔法或更凶猛的火灾（如柴堆、燃烧的房屋或龙火）无效。

#### Illusion（幻术）

(Illusion - 幻术系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 专注；见下文 |

| **区域：** 50 英尺半径/强度 | **抵抗：** 不信 |

此法术创造施法者想要的任何物体的视觉幻象。它对其他感官无效，不发声，不产生气味、温度或触感等。

此幻象可以是任何东西，从开阔的草地到古代红龙，只要它适合法术的效应区域。幻象仅持续到施法者维持专注，或对手触摸/进入它；这会导致维持魔法解开并消散。然而，施法者可以通过花费 1 点魔法点并指挥其相应反应以避免引起怀疑，从而在物理接触后维持幻象。例如，正常情况下，食人魔幻象在被箭射中时会消失；但施法者可以花费 1 点魔法点使其假装耸肩无视攻击并冲锋。注意实际的箭矢不会被幻象阻挡，仍可能击中 manifestation 后的某人。

虽然幻象不能造成实际伤害，也不能产生温度，但思维可以确信它感到疼痛，遭受伤害，或者感到极端的冷热；然而，物体不会看起来冻结或燃烧，除非施法者也专注于这些效果。法术施放后，法师可以通过专注于期望的效果随时添加额外的视觉效果。这通常不费时间，且可视为自由动作。例如，若施法者希望掉落的幻象火把使干叶看起来燃烧，施法者可以作为自由动作专注达成。

参见[幻术与幻影（Illusions and Phantasms）](0009_Magic.md?id=illusions-and-phantasms)章节获取更多信息。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 1 | 50 英尺半径；100 英尺范围 |
| 2 | 2 | 100 英尺半径；200 英尺范围 |
| 3 | 3 | 150 英尺半径；300 英尺范围 |
| 4 | 4 | 200 英尺半径；400 英尺范围 |
| +1 | +1 | 继续递增 |

#### Invisibility（隐形术）

(Illusion - 幻术系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 6 小时/强度 |
| **消耗：** 3, +1/额外强度 | **范围：** 接触 |
| **区域：** 1 个目标 | **抵抗：** 无 |

当此法术施放时，受术者及携带的装备消失，对所有形式的正常视觉不可见。然而，这并不意味着个体对其他感知方式不可见，如听觉、触觉、嗅觉等，或被诸如“生命侦测（Life Sense）”或“声呐”之类的自然能力侦测到。

处于隐形术影响下的人在法术持续时间（最长 24 小时）内保持隐形，除非受术者进行攻击，此时法术被中和，个体在攻击_后_重新显现。目标被视为受到[突袭（Surprise）](0008_Combat.md?id=surprise)影响。没有任何其他行动会负面影响法术持续时间，允许受术者开门、谈话、攀爬、奔跑、扒窃等。即使施法也不会结束持续时间，除非它们在战斗中负面影响一个或多个特定敌人。上述许多行动可能允许其他侦测手段，例如察觉某人跑过，或感觉口袋被掏。GM 将根据注意到程度分配侦测罚值或奖励。

#### Magic Missile（魔法飞弹）

(Evocation - 塑能系)

| | |
| :-- | :-- |
| **等级：** 法师 1 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 1/强度 | **范围：** 100 英尺/强度 |
| **区域：** 1-5 个目标 | **抵抗：** 见下文 |

当此法术施放时，一枚或多枚魔法能量飞弹从法师指尖射出并击中目标。可产生的飞弹最大数量基于施法者的“奥术施法”技能等级，60% 产生第二枚，70% 第三枚，80% 第四枚，90% 第五枚。要产生这些飞弹，法术必须以等于期望飞弹数量的强度施放。例如，在 60% 以下，施法者以 3 强度施放魔法飞弹将获得较长的范围，但仅能生成一枚飞弹。技能等级 70% 的法师以同样 3 强度施放则获得同样范围并能生成 3 枚飞弹。该法术最高强度为 5。见下表。

魔法飞弹必然命中，即使目标处于近战中或有部分掩护。这些飞弹不可闪避；然而，完全掩护的目标不可被此法术指定。如果目标意识到或面向施法者，护盾术会自动偏转魔法飞弹。魔法飞弹造成 1d6+1 点伤害，穿戴护甲无效，但自然护甲或魔法护甲正常减少伤害。魔法飞弹对门、锁等无生命物体无效。

发射多枚飞弹时，施法者可指定单体或多个目标。每枚魔法飞弹击中随机部位——不可指定部位。施法者必须在滚动伤害前指定每枚飞弹的目标。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 1 | 100 英尺范围；1 枚飞弹 |
| 2 | 2 | 200 英尺范围；60% 技能下 2 枚飞弹 |
| 3 | 3 | 300 英尺范围；70% 技能下 3 枚飞弹 |
| 4 | 4 | 400 英尺范围；80% 技能下 4 枚飞弹 |
| 5 max. | 5 | 500 英尺范围；90% 技能下 5 枚飞弹 |

#### Magic Mouth（魔法嘴巴）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 2 | **施法时间：** 1 分钟 |
| **领域：** 无 | **持续时间：** 见下文 |
| **消耗：** 3, +1/额外强度 | **范围：** 30 英尺 |
| **区域：** 1 个物体 | **抵抗：** 无 |

此法术在物品或物体上创造一张嘴，当触发特定的预定事件或法师在施法时指定的时间时会自动出现。这张嘴会说出法师在施法时预定义的短语。短语不得超过 25 个词，说话速率约每秒 1 个词。此嘴不可说出“力量词汇”或施放法术。

此法术可施加于任何无生命物体，从柱子、树木到石墙或箱子；然而当施于雕像时效果尤其出众，因为雕像看起来就像真的在说话。无法施加于任何具有任何智力或本能的活体生物，包括曾经活过的生物。施法时，法师确定触发附魔的情况。触发器可以是任何事件，从口令到创造噪音。可以笼统如“当下一个人进入此房间时……”，也可以具体如“当 Sedona 的女性牧师在周六走近大厅尽头的雕像 10 英尺内时……”。触发效果的最大距离为每级强度 25 英尺。

该法术持续时间在附魔激活前是永久的，激活后即终止。

#### Meteor Shower（流星雨）

(Evocation - 塑能系)

| | |
| :-- | :-- |
| **等级：** 法师 5 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 瞬时 |
| **消耗：** 3/强度 | **范围：** 20 英尺/强度 |
| **区域：** 见下文 | **抵抗：** 闪避 |

当法师施放此法术时，每级强度两枚微流星从伸出的手掌疾射而出。流星向目标弧线划过，呈下降轨迹，沿途留下火花和煤渣。撞击时，它们在目标点周围多次猛烈爆炸。第一颗流星总是击中指定位置，而任何额外的流星则随机散布在周围，每个都有 30 英尺的爆炸半径。为确定击中位置，滚动 1d8 决定方向。

每个流星对效应区域内的目标造成 1d10 点火伤害。然而，由于每场爆炸的半径，许多流星会重叠，对陷入其中的倒霉蛋造成额外伤害。伤害滚动组合在一起应用于目标的每个命中部位，穿戴护甲无保护，但自然护甲或魔法护甲值正常减少伤害。

成功的闪避检定使受害者免受伤害。拥有“狡猾闪避”能力的生物可选择不倒地而进行闪避，但成功仅减半伤害，除非位于效应区域边缘五英尺内。

所有包括效应区域外但位于撞击点 60 英尺内的生物，都需要进行“运动”检定以保持站立。

流星雨引燃可燃材料的几率等于伤害滚动值 x5%。请参考[火焰](0007_Game_System.md?id=fire-based-attacks)章节。

| | |
| :-- | :-- |

#### Polymorph Other（变形术，他用）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 3 | **施法时间：** 2 行动 |
| **领域：** 无 | **持续时间：** 永久 |
| **消耗：** 3, +1/额外强度 (+1 经验点) | **范围：** 15 英尺/强度 |
| **区域：** 1 个目标 | **抵抗：** 意志 |

施法者可以将一个实体生物的目标形态改变为另一种形态，每级强度可改变最高 5 点 SIZ。因此，将一个 SIZ 16 的半兽人转化为 SIZ 1 的兔子需要 3 级强度（15 点 SIZ 差值）。受术者有一次意志抵抗检定。大型生物不太容易被变形，难度为“容易”，巨型生物难度为“非常容易”。

整个转化过程需要整整一轮，对生物来说压力巨大，需要第二次意志检定以保留人格，失败则使受术者晕眩 1d10 分钟，大失败则导致精神休克死亡。SIZ 的翻倍或减半使保留人格的意志检定难度提高一级，环境彻底改变（如将人变成鱼）也是如此。成功检定允许受害者保留他们的 INT 和 CHA，以及需要这些属性的技能。

转化授予受术者该生物的呼吸形式、任何自然攻击、所有正常的移动方式。它不赋予生物拥有的增强或魔法能力。例如，变成龙的个体不会获得龙息或类法术能力，但会获得龙的坚硬外皮、致命咬合、爪击等。此外，受害者获得新形态的物理技能（如运动、强壮、飞行、游泳）、生命值和伤害修正。假设转化者保留了 INT，他们仍能讲话（若新形态有发音能力）。在原形态能施法的受害者若仍有能力形成法术的言语和手势成分，则仍能施法。如果改变巨大，如从两足到四足，或从陆地动物到海洋生物，GM 应随意处罚需要练习的技能（运动、空手、游泳、飞行、战斗技能），直至其有时间练习。

保留人格的意志检定在受术者保持转化状态的每一天都需要进行，直至失败，此时受害者最终 succumb 于新形态的思维方式，如果是非智慧生物，INT 将转变为 INS。新形式未曾拥有、且原本没有的任何特殊和魔法能力（如凝视攻击、喷吐武器等）现在在转化完成后可供生物使用。以此方式失去身份的角色成为由 GM 控制的 NPC。

在精神 succumb 到新形式之前，被变形的生物仍受“驱散魔法”影响，无需抵抗检定，因为回归正常是潜意识的渴望。转化需要另一意志检定抵抗压力，失败则晕眩，大失败精神休克死亡。

如果受害者之前 succumb 到了新形式，驱散魔法仍可使用；然而，受害者会尝试通过意志抵抗检定回到正常形式。抵抗失败意味着受害者转化回自然形式，同样需要意志检定抵抗转化带来的精神休克。一旦失去，受害者的自然身份不再可及，受害者转而认为这种怪异的外星形态才是自然的，并渴望回到之前的“正常”。*例如，被转化为兔子并假设了兔子身份的半兽人，会认为自己是一只被粗暴转化为半兽人的兔子。* 一旦身份失去，只有“祈愿术”或其他类似魔法有机会恢复。

所有穿戴和携带的装备会魔法融合到新形式中；然而，某些情况下 GM 可以允许在生物新形态下仍能使用的魔法物品保留，如戒指或靴子。注意这要求生物的新 SIZ 与原始 SIZ 差异不大。每件非攻击性魔法物品有 POW x1% 的机会转移效果，需 GM 批准。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3, +1 EXP | 15 英尺范围；1-5 SIZ 点差值 |
| 2 | 4, +1 EXP | 30 英尺范围；6-10 SIZ 点差值 |
| 3 | 5, +1 EXP | 45 英尺范围；11-15 SIZ 点差值 |
| 4 | 6, +1 EXP | 60 英尺范围；16-20 SIZ 点差值 |
| +1 | +1 | 继续递增 |

#### Polymorph Self（变形术，自用）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 法师 3 | **施法时间：** 2 行动 |

#### Raise Dead \(R\)（死者复生）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 牧师 3 | **施法时间：** 1 分钟 |
| **领域：** 死灵 | **持续时间：** 永久 |

| 4-5 | 61+ | 容易 |

_* 此类别包括不拥有职业的角色。_

如果抵抗检定失败，受害者即死。成功检定则如同“治愈伤残”的效果。护甲无法抵抗此伤害。屠戮活物在被使用时不会使施法者衰老。

当施放时，牧师可触摸一个生物并再生一个切断的命中部位。缺失肢体将每 10 分钟恢复 1 点生命值直到完全愈合。然而，如果被切断的部位就在眼前并接触受害者，整个恢复时间缩短至 1 分钟。此法术不能通过再生两个独立部分来“克隆”一个人，只有连接大脑和中枢神经系统的部分会受益。每级强度将再生一个独立的部位。此法术虽可缓慢治疗轻伤，但有较低等级、成本较低的法术可做同样的事情。

该法术逆转，“枯萎（Wither）”，导致施法者触摸的部位萎缩并最终脱落。该过程每 10 分钟造成接触部位 1 点伤害，在 0 生命值时变得不可用，在完全负值时脱落。后果只能通过施放“再生术”来抵消。

#### Resurrection \(R\)（复活术）

(Necromancy - 死灵系)

| | |
| :-- | :-- |
| **等级：** 牧师 5 | **施法时间：** 10 分钟 |
| **领域：** 死灵 | **持续时间：** 永久 |
| **消耗：** 3, +1/额外强度, +2 经验点 | **范围：** 接触 |
| **区域：** 1 个目标 | **抵抗：** 无（意志） |

复活术可复活死亡时间每级强度不超过 20 年的任何生物。生物不仅恢复生命，还恢复至全盛力量并治愈受伤，甚至恢复残肢。实际剩下的尸体无需完整，例如，145 年后用一根指骨复活某人，假设强度为 8 即可。被复活的个体无需休息，立即完全有效。该法术对自然死亡者无效。

若非邪恶阵营，可以通过意志对抗检定来拒绝。对于邪恶灵魂，则是折磨者的意志。如果施法者成功，受者复活，反之则失败。

复活术非常消耗牧师，使其衰老其典型预期寿命的 3%（人类即 3 年）。详见[衰老（Aging）](0007_Game_System.md?id=aging)规则。

该法术逆转，“毁灭（Destruction）”，可杀掉一个接触到的受害者。受害者可根据目标等级或 SIZ 修正进行意志抵抗检定。

| 目标等级 | 目标 SIZ | 意志修正 |
| :-: | :-: | :-- |
| 0-1* | 1-20 | 艰巨 |
| 2 | 21-40 | 困难 |
| 3 | 41-60 | 标准 |
| 4 | 61-80 | 容易 |
| 5 | 81+ | 非常容易 |

_* 此类别包括不拥有职业的角色。_

如果抵抗失败，受害者即死，尸体化为灰烬。只有“祈愿术”能在此情况下复活。成功抵抗则视为“导致伤残”的效果。护甲不提供此项伤害的防护。毁灭在被使用时不会使施法者衰老。

#### Word of Recall（召回术）

(Transmutation - 变化系)

| | |
| :-- | :-- |
| **等级：** 牧师 4 | **施法时间：** 1 行动 |
| **领域：** 召唤 | **持续时间：** 见下文 |
| **消耗：** 3, +1/额外强度 | **范围：** 0 |
| **区域：** 施法者 | **抵抗：** 无 |

当此法术施放时，牧师被瞬间传送到一个预先指定的避难所及其半径 10 英尺内的指定到达点。传送的实际范围没有限制，包括在多个位面之间。在单个位面内，没有出错的可能性，然而，跨越甚至一个位面会产生 91-00% 的大失败（Fumble）几率，跨越两个位面则在 81-00% 时大失败，依此类推。这取代了施法者正常的 Fumble 几率。跨越位面时的大失败意味着牧师被无可挽回地迷失。单个位面内的大失败遵循正常规则。

除自身及装备外，牧师可额外携带每级强度 3 个物体，每个不超过 SIZ/9“Things”。所携带的额外材料可以是宝藏、装备或生物。然而，携带生物时必须以足够的强度施放以覆盖任何携带的装备。
