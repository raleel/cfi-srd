## 法术描述

---
#### Appraise（鉴定）

(占卜系)

| | |
| :-- | :-- |
| **位阶：** 法师 0 | **施法时间：** 1 回合 |
| **领域：** 无 | **持续时间：** 立即 |
| **消耗：** 1 | **射程：** 接触 |
| **范围：** 1 件物品 | **抵抗：** 无 |

鉴定允许对体格（体型）等于施法者灵力（灵力）的物品质量进行即时评估。该法术可确定外观相同的物品是否属于相同或相似的质量，或者其中之一是否存在瑕疵或更高质量。该法术对有机物无效，仅适用于无生命物体。它也不能确定具体存在什么瑕疵或增强，仅能确定它们是否存在。它在识别或探测魔法方面毫无用处。

#### 护甲（护甲）

(咒法系)

| | |
| :-- | :-- |
| **位阶：** 法师 1 | **施法时间：** 1 轮 |
| **领域：** 无 | **持续时间：** 见下文 |
| **消耗：** 3 +1/强度等级 | **射程：** 接触 |
| **范围：** 1 个目标 | **抵抗：** 无 |

当此法术施放时，目标将被赋予一层不可见的魔法力场，其防护效果相当于鳞甲，为每个命中部位提供 4 点护甲。如果施加在已经穿着护甲的人身上，则无效。然而，若其防护能力优于天然护甲，该法术在持续时间内将取代天然护甲。如果施加在拥有超过 4 点天然护甲的生物身上，则改为在所有部位增加 1 点护甲。这种魔法防护不会阻碍移动或施法。法术将持续存在，直到被魔法解除，或者施法者受到单次攻击造成的 8 点伤害（每增加 1 级强度，增加 1 点，见下表）。当然，施法者可以随时选择撤销法术，睡眠时必须撤销。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3 | 4 点护甲；持续直到受到单次攻击造成的 8 点伤害 |
| 2 | 4 | 4 点护甲；持续直到受到单次攻击造成的 9 点伤害 |
| 3 | 5 | 4 点护甲；持续直到受到单次攻击造成的 10 点伤害 |
| 4 | 6 | 4 点护甲；持续直到受到单次攻击造成的 11 点伤害 |
| +1 | +1 | 延续递进 |

#### Astral Spell（星界法术）

(变化系)

| | |
| :-- | :-- |
| **位阶：** 牧师 5, 法师 5 | **施法时间：** 2 行动 |
| **领域：** 星界 | **持续时间：** 见下文 |
| **消耗：** 3 +1/额外强度 | **射程：** 接触 |
| **范围：** 见下文 | **抵抗：** 不适用 |

此法术允许施法者及最多另外五人（每增加一级强度增加一人）进入星界。施法时所有人必须保持接触并形成一个圆圈。旅行者的肉体留在原位，通常不携带任何衣物或装备，除非该物品本身散发着魔法光环；这些物品会转化为其正常形式的星界对应物。持续时间直到施法者希望停止为止。然而，外部力量（如解除魔法）可能会使其提前结束。杀害施法者的肉体也会导致法术提前结束，尽管这会造成一个不幸的副作用：将陪伴施法者的任何旅行者困在星界。

#### Augury（预兆）

(占卜系)

| | |
| :-- | :-- |
| **位阶：** 牧师 2 | **施法时间：** 2 分钟 |
| **领域：** 占卜 | **持续时间：** 立即 |
| **消耗：** 3/强度等级 | **射程：** 60 英尺 |
| **范围：** 施法者 | **抵抗：** 不适用 |

此法术允许施法者判断在接下来的 30 分钟内采取的特定行动，对个人和/或团队的福祉是有益还是有害。辨别预兆需要某种焦点物，最常见的是龙爪或小骨头、珍珠，或者价值不低于 100 金币（GP）并经压碎或熔化的纯金。该法术的最大强度为 4。此掷骰应由游戏管理员（GM）执行，因为施法者绝不应完全确定结果是否被正确解读。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3 | 艰巨的引导技能掷骰 |
| 2 | 6 | 困难的引导技能掷骰 |
| 3 | 9 | 标准的引导技能掷骰 |
| 4 | 12 | 简单的引导技能掷骰 |

如果引导掷骰成功，将获得以下结果之一：

| 预兆 | 含义 |
| :-: | :-- |
| 是 | 行动将是有益的 |
| 否 | 行动将是有害的 |
| 是与否 | 行动将既是有益的也是有害的 |
| 无 | 行动既无益也无害 |

大失误应导致游戏管理员告知与现实相反的结果。

#### Avert（避让）

(防护系)

| | |
| :-- | :-- |
| **位阶：** 牧师 0, 法师 0 | **施法时间：** 立即 |
| **领域：** 防护 | **持续时间：** 立即 |
| **消耗：** 1 | **射程：** 60 英尺 |
| **范围：** 1 个法术 | **抵抗：** 无 |

避让用于消除射程内的另一个位阶 0 法术。避让可以通过使用“反制魔法”反应行动，作为对攻击性位阶 0 法术的即时应对措施来施放。

#### Befuddle（困惑）

(附魔系（魅惑）)

| | |
| :-- | :-- |
| **位阶：** 牧师 0, 法师 0 | **施法时间：** 1 回合 |
| **领域：** 魅惑 | **持续时间：** 30 分钟 |
| **消耗：** 1 | **射程：** 60 英尺 |
| **范围：** 1 个目标 | **抵抗：** 意志力 |

困惑会在实体目标的脑海中引起混乱。受术者难以清晰思考，忘记自己身在何处、正在做什么以及原因——通常会陷入脱节的思维链中。受困惑的目标仍然可以进行自卫，但在法术结束前无法发起任何建设性活动。任何形式的攻击或威胁行动都会立即打破法术，无论它是否专门针对被困惑的目标。

#### Blade Barrier（刃壁）

(塑能系)

| | |
| :-- | :-- |
| **位阶：** 牧师 4 | **施法时间：** 2 行动 |
| **领域：** 守护，创造 | **持续时间：** 3 轮/强度等级 |
| **消耗：** 3+1/额外强度 | **射程：** 100 英尺 |
| **范围：** 5-30 英尺半径 | **抵抗：** 见下文 |

此法术创造了一道由飞舞的刀剑、匕首和刀具组成的屏障，绕着一个固定点飞速旋转切割，对任何穿过作用范围的物体造成 1d8 点伤害，命中 1d4+2 个随机命中部位。护甲仅提供其正常防护的一半。魔法护甲点正常减少伤害。由于武器以眩目的速度旋转且排列密集，因此不可能对其进行招架（Parry）或闪避（闪避）。一个人可以使用盾牌被动地进行常规的命中部位格挡。在这种情况下，记得将掷出的伤害与盾牌的护甲和生命值进行对比。

该法术可以被动地施放以保护牧师或一名或多名盟友，也可以攻击性地困住敌人。然而，当屏障形成时，距离边缘五英尺内的被围困敌人可以进行闪避掷骰以逃脱。无论成功与否，对手最终都会倒地，刚好位于作用范围之外。成功掷骰则不造成伤害；否则，他们承受全部效果。

#### Bless \(R\)（祝福）

(咒法系)

| | |
| :-- | :-- |
| **位阶：** 牧师 1 | **施法时间：** 1 轮 |
| **领域：** 全领域 | **持续时间：** 5 分钟 |
| **消耗：** 1 | **射程：** 180 英尺 |
| **范围：** 25 英尺半径 | **抵抗：** 意志力 |

当此法术施放时，牧师祝福作用范围内的盟友群体。受影响者散发出施法者的阵营气息，即善良或邪恶。没有中立的祝福。作用范围内的所有盟友在所有技能和抵抗掷骰上获得 +5% 的加值。此外，他们的武器对智能亡灵以及来自外层位面且与施法者阵营对立的生物（如恶魔、魔鬼或天使）造成 +1d3 伤害。请注意，虽然骨骼和僵尸等受动画驱动的亡灵本身并非天生邪恶，但它们通常是由邪恶魔法驱使，因此也受此伤害影响。

该法术的逆转，即“诅咒”（Curse），允许牧师诅咒敌人，使其提到的技能遭受上述收益的倒数减值。受诅咒武器的伤害被计为减值，且此伤害结果不得少于 1 点。

#### Burning Hands（燃烧之手）

(变化系)

| | |
| :-- | :-- |
| **位阶：** 法师 1 | **施法时间：** 1 行动 |
| **领域：** 无 | **持续时间：** 立即 |
| **消耗：** 3+1/额外强度 | **射程：** 0 |
| **范围：** 120 度锥形，5 英尺长 | **抵抗：** 闪避 |

此法术使火焰从施法者的手中射出，呈 120 度扇形。如果在战斗中使用微缩模型，燃烧之手将伤害占据施法者前方 1 个格子的每个目标。在更高强度等级下施放燃烧之手需要更高位阶的法师。该伤害覆盖范围内的所有目标，伤害基于法术的强度，最大强度为 9，如下所示。通过闪避掷骰（让自己倒地）可以使受害者不受伤害。拥有“狡诈闪避者”（Artful Dodger）能力的受害者可以选择在不倒地的情况下进行闪避。

| 强度 | 消耗 | 最低位阶 | 可变效果 |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 点伤害至所有命中部位 |

#### 命令

(附魔系（魅惑）)

| | |
| :-- | :-- |
| **位阶:** 牧师 1 | **施法时间:** 1 行动 |
| **领域:** 魅惑 | **持续时间:** 1 分钟 |
| **消耗:** 3 | **射程:** 100 英尺 |
| **区域:** 1 目标 | **抵抗:** 意志力 |

当施放此法术时，牧师可以对一个体型 1-20 的活体生物下达一个单字命令，如果受害者未能抵抗，他们将在下一轮行动中严格执行该命令。这本质上导致受害者错过下一回合来完成所命令的动作，并浪费了一个行动点数。如果受害者没有剩余的行动点数，所命令的动作将在下一轮的第一个回合中执行。命令本身不能对目标造成任何实际伤害；然而，伤害可能是命令的次生影响。

例如，命令“死亡”会导致受害者陷入昏迷的死亡状态 1 回合，不会造成实际伤害；然而，命令“跌倒”施加于一个正在攀爬 100 英尺高悬崖的生物，后果可能是致命的。

命令的目标必须能够理解施法者所说的语言，并且允许进行一次意志力测试来抵抗。

**部分命令示例**

- **爬行:** 受害者卧倒并开始爬行。
- **死亡:** 受害者倒下并进入昏迷的死亡状态。
- **跌倒:** 受害者跌倒。
- **大失误:** 受害者在即将采取的身体行动中出现大失误。
- **睡眠:** 受害者昏昏欲睡。
- **逃跑:** 受害者转身并逃离施法者。
- **飞翔:** 受害者拍打手臂并原地转圈奔跑。
- **前进:** 受害者开始朝着其面对的方向行走。
- **停止:** 受害者立即停止并在原位站立。
- **离开:** 受害者转身并从进入的方向离开。
- **休息:** 受害者坐下并喘口气。
- **奔跑:** 受害者开始奔跑。
- **尖叫:** 受害者大喊大叫。
- **下沉:** 受害者停止游泳。
- **投降:** 受害者丢弃武器并停止敌对行动。

（防护系）

| | |
| :-- | :-- |

解除魔法可以针对特定目标或指定区域施展，一旦施展，目标点 15 英尺半径内的所有魔法都可能被消除。它结束目标身上正在进行的法术，但对其他魔法效果没有作用。它对魔法生物或不死生物无效。解除魔法以位阶低于法术强度的魔法消除范围内所有其他魔法。例外情况是魔法物品和诸如“魅惑人类”之类的诱导类法术的受害者，这些必须单独作为目标。法术的效果不能被部分消除。

#### 附魔物品

(附魔)

| | |
| :-- | :-- |
| **位阶：** 法师 4 | **施法时间：** 见下文 |
| **领域：** 无 | **持续时间：** 见下文 |
| **消耗：** 3 + 见下文 | **射程：** 接触 |
| **范围：** 1 件物品 | **抵抗：** 不适用 |

施展此法术是为了让一件物品做好“附魔”准备。物体必须处于良好状态，且工艺和做工均为上乘。此外还需要至少 100 金币的额外费用，用于支付额外的工具、雕刻、刺绣、镶嵌宝石、刻字等费用。最后，附魔过程需要一个实验室或工作室。

在施法期间，魔法使用者必须在整个 1d8+2 天的施法时间内保持接触物品。这包括休息和睡眠期间，在此期间物品必须保持在施法者的触及范围内。在整个施法过程中，魔法使用者不得施展其他法术或进行任何其他形式的魔法。打破任何这些限制都会自动导致法术失败。

一旦成功施法，该物品就准备好进行最后一步了，施法者将所需的法术放入其中。为此，他们必须将法术储存在记忆中或卷轴上，并在 24 小时内将其施加到物品上，否则整个过程将需要从零开始重新开始。一旦开始施展所选法术，过程可能会超过上述的 24 小时。为物品灌注所选法术需要为所需的强度支付正常的魔法点数，且每法术位阶耗时 1d12 小时。在整个灌注过程中，施法者必须保持接触物品，或者像上面提到的那样在休息期间保持在触及范围内，并在施法期结束时需要进行一次奥术施法检定，以成功灌注法术。遵循正常的法术施放成功等级，然而，关于失败结果，法术不能被强行施放。如果是在前一个法术完成后的 24 小时内开始施法过程，则可以在物品中灌注连续的法术。即使是在先前失败的法术情况下也适用。每个后续法术都需要正常的施法消耗。

使用该物品时，所包含的每个法术只能施展一次，但可以按照上述程序灌注同一法术的多个版本。也可以灌注单个法术，随后施展 4 阶法术“永久术”。在这种情况下，该法术可以根据“永久术”法术说明中设定的限制随心所欲地施展。

无法将不符合特定法术的其他魔法效果灌注到物品中，许多早已消失的魔法物品在当今时代根本无法再造。

施展此法术时，会产生一阵恐怖波浪向外扩散，导致所有抵抗检定失败的人惊慌逃窜。受影响者会以冲刺速度直接背离施法者逃跑，持续时间等于法术强度的 2 倍（轮）。这种恐惧是如此吞噬一切，以至于那些在抵抗掷骰中出现大失误的对手会扔掉任何没有以某种方式固定住的持有物品。大型生物（体型 21-40）对此法术的易感性较低，抵抗检定难度为“简单”，而极其巨大生物（体型 41+）的抵抗检定难度为“非常简单”。

#### 羽落术

(变化)

| | |
| :-- | :-- |

由于此法术具有“瞬间”施法时间，法师可以被动地以及主动地使用“羽落术”。这使得该法术可以防御意外坠落，甚至可以中断他人的行动以减缓投射物（如箭矢或投掷长矛），这些投射物随后会在攻击者和目标之间轻轻漂浮到地面，造成零伤害。

#### 火焰之盾

(塑能)

| | |
| :-- | :-- |
| **位阶:** 法师 3 | **施法时间:** 2 行动 |
| **领域:** 无 | **持续时间:** 2 分钟/强度 |
| **消耗:** 3+1/额外强度 | **射程:** 0 |
| **影响范围:** 施法者 | **抵抗:** 不适用 |

本法术创造出一面由轻盈火焰组成的盾牌，将施法者笼罩其中，但火焰本身不会造成伤害。相反，火焰保护受术者免受火或冷的影响，具体取决于记忆中的两种变体：冷焰之盾，创造蓝色或绿色火焰，保护免受热和基于火的伤害；暖焰之盾，创造紫色或蓝色火焰，保护免受冷和基于冰的伤害。火焰颜色应随机确定，各有 50% 的几率，因为两种类型都可能发出蓝色火焰，这给攻击者制造了不确定性。关于记忆哪种变体的决定在准备法术时做出，如果需要，两者皆可记忆。这些火焰不产生热量，且发出的光线仅为火炬亮度的一半。每种变体的具体细节如下：

- **冷焰之盾：** 这些火焰摸起来很凉，并将任何火或基于热的伤害减少到总额的一半。成功的抵抗检定可以抵消所有伤害。抵抗检定难度等级下调一级，若是闪避，则不会使防守者俯卧。
- **暖焰之盾：** 这些火焰摸起来很暖，并将任何基于冷的伤害减少到总额的一半。成功的抵抗检定可以抵消所有伤害。抵抗检定难度等级下调一级，若是闪避，则不会使防守者俯卧。

针对受术者的近战攻击（无论武装与否）均造成正常伤害，除非攻击中包含被保护的元素。在这种情况下，施法者免受攻击的元素部分伤害，且攻击者会受到等同于该次攻击所造成伤害量的伤害。攻击者身穿的护甲不提供保护，但魔法护甲点数或生物的天然护甲会按常理减少伤害。具有先天魔法抗性的生物在受术者第一次被击中时，通过一次成功的意志力检定即可驱散“火焰之盾”。如果魔法抗性检定失败，对手之后将无法抵消该“火焰之盾”。

#### 石化术 \(R\)

(变化)

| | |
| :-- | :-- |
| **位阶:** 法师 4 | **施法时间:** 2 行动 |
| **领域:** 无 | **持续时间:** 永久 |
| **消耗:** 3/强度 | **射程:** 30 英尺/强度 |
| **影响范围:** 1 目标 | **抵抗:** 意志力 |

施法时，射程内的一名受害者允许进行一次意志力抵抗检定。如果失败，他们及其所携带和穿戴的所有物品将完全转化为坚硬的岩石。这种转化并非死亡，而是一种假死状态。施放此法术的逆转版本，或使用“许愿术”，可以用于使受害者恢复生命。受害者在石化期间受到的任何伤害都会保留，并在恢复原状后立即生效。大型生物（体型 21-40）对此法术的易感性较低，抵抗检定为“简单”，而巨型生物（体型 41+）的抵抗检定则为“非常简单”。

此法术的逆转版本“解石术”用于使受害者恢复，无需进行抵抗检定。然而，该法术也可以被逆转来转化从未有过生命的石头；这可以有几种创造性的用法。例如，每强度等级可转化 10 立方英尺的石墙为软肉；可以创造一个宽达 3 英尺、每强度等级长达 10 英尺的肉质“隧道”；单个目标（如石像）可以转化为肉体；甚至通过此法术将石魔像转化为血肉魔像。但在后一种情况下，石魔像仍可按常理进行意志力抵抗检定。以这种方式转化为肉体的石头是柔软且柔韧的，虽然它保留了其实际生命值，但不再拥有护甲点数，使其更容易被砍碎。

(防护, 附魔)

| | |
| :-- | :-- |

#### 冻伤

(变化)

| | |
| :-- | :-- |
| **位阶:** 法师 0 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 瞬发 |
| **消耗:** 1 | **射程:** 60 英尺 |
| **影响范围:** 1 目标 | **抵抗:** 体质 |

“冻伤”直接作用于活体有机组织，在受术者的肢体末端造成麻木和疼痛，例如手指、脚趾、臀部、鼻子、耳朵等。施法者必须触摸特定肢体，若在射程外施放则随机投骰。如果法术未被抵抗，受影响区域会产生感知麻木，随后在持续时间内伴随阵痛，使利用该部位进行的技能检定难度等级提高一级。冻伤不造成直接伤害，但会使受影响区域在一段时间内难以使用。例如，臀部患有冻伤的受害者如果不忍受极度不适就无法坐下。

大型生物（体型 21-40）对此法术的易感性较低，抵抗检定为“简单”，而巨型生物（体型 41+）的抵抗检定则为“非常简单”。

#### 大失误

(附魔（魅惑）)

| | |
| :-- | :-- |
| **位阶:** 法师 3 | **施法时间:** 2 行动 |
| **领域:** 无 | **持续时间:** 1 回合/强度 |
| **消耗:** 3+1/额外强度 | **射程:** 30 英尺/强度 |
| **影响范围:** 10 英尺半径 | **抵抗:** 意志力 |

此法术导致影响范围内的所有对手变得笨拙，任何身体技能检定难度上调一级，且所有失败均会导致“大失误”。即使是通常不需要技能检定的身体行为，例如捡起掉落的物品、快步跑或爬楼梯，也需要进行体能技能检定。在此情况下，失败导致大失误，通常表现为移动时的尴尬跌倒，或尝试捡东西时意外将物品踢得更远。游戏管理员应创造性地处理大失误的结果；然而，在非战斗情况下，少有结果会直接致命。但在战斗中，大失误与任何其他大失误一样对待，可以按常理导致特殊效果。

成功的抵抗检定使受害者在当前回合避免法术效果；然而，如果受害者在下一回合仍处于影响范围内，则必须再次按常理进行抵抗检定。原始攻击者的盟友也需要留在影响范围外，否则会遭受与对手同样的限制。

| :-: | :-: | :-- |
| 1 | 3 | 1 回合；30 英尺射程 |
| 2 | 4 | 2 回合；60 英尺射程 |
| 3 | 5 | 3 回合；90 英尺射程 |
| 4 | 6 | 4 回合；120 英尺射程 |
| +1 | +1 | 持续递增 |

#### 传送门

(召唤)

| | |
| :-- | :-- |
| **位阶:** 牧师 5, 法师 5 | **施法时间:** 2 回合 |
| **领域:** 召唤 | **持续时间:** 见下文 |
| **消耗:** 3 +1/强度,+3 经验值 | **射程:** 100 英尺 |
| **影响范围:** 见下文 | **抵抗:** 意志力 |

施放“传送门”要求施法者知道被召唤实体的真名，通常是来自其他存在位面的生物，例如恶魔或魔鬼、天使、半神甚至是神祇。施法成功后，施法者所在位面与实体所在位面之间会开启一道传送门。施法会自动引起实体的注意，无论成功与否。此法术威力巨大且消耗极高，不仅消耗施法者注明的 3 点魔法点数和 3 次经验值，还会使他们衰老其典型寿命的 5%（若施法者为人类，则为 5 年）。如果实体在抵抗检定中获胜，他们通常不会亲自前来，但假设法术成功，“某些东西”就会穿过传送门。下表用于确定一些常见的实体、它们的平均灵力以及通常会派出的仆从。游戏管理员可根据当前战役的性质自由选择最合适的内容。

##### 位面外实体表

| 强度 | 消耗 | 可变效果 | 灵力 |
| :-: | :-: | :-- | :-- |
| 1 | 3 | 次级恶魔或次级魔鬼 | 按具体实体 |
| 2 | 4 | 下等恶魔或魔鬼 | 按具体实体 |
| 3 | 5 | 劣等恶魔或魔鬼 | 按具体实体 |
| 4 | 6 | 高等恶魔或魔鬼 | 按具体实体 |
| 5 | 7 | 恶魔/魔鬼亲王或大公、大天使或半神 | 121-140% |
| 6 | 8 | 恶魔领主、大魔鬼或劣等神祇 | 141-160% |
| 7 | 9 | 高等神祇 | 161-180% |
| 8 | 10 | 统治神祇 | 181%+ |

响应的形式在很大程度上取决于具体的实体、双方的阵营以及请求的具体内容。如果实体认为中断的原因琐碎或无关紧要，他们的反应可能是直接离开到直接发动攻击。然而，如果情况危急，尤其是施法者正受到实体强烈反对之物的威胁时，很可能会得到更有利的反应。如果游戏管理员认为存在灰色地带且反应存疑，施法者及其盟友可以尝试通过结合技能、奉承、恳求和/或贿赂来辩解。然而，大多数实体会避免卷入与同等或更强大对手的冲突，许多实体会要求支付报酬，无论是在履行行为之前还是之后。传送门将保持开启，直至实体选择在该位面停留的时间结束，并在他们决定离开时关闭。在此期间，其他人有可能穿过传送门，实现两个现实之间的双向旅行。

#### 魅力术 \(R\)

(附魔（魅惑）)

| | |
| :-- | :-- |
| **位阶:** 法师 0 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 专注 |
| **消耗:** 1 | **射程:** 60 英尺 |
| **影响范围:** 1 目标 | **抵抗:** 意志力 |

“魅力术”使目标变得迷人，从而使人们自然而然地被其吸引。魅力的本质必须在施法时选择，可以是增加的自然美貌、更加柔和撩人的嗓音，甚至是诱人的体香。虽然该法术不提供任何机械收益，但它确实确保了受术者有机会聚集听众、吸引他们希望接触之人的注意，或提供干扰，使同伙有机会进行邪恶的勾当。

当逆转为“厌恶术”时，它会扭曲目标的外貌，使所有看到、听到或闻到他们的人产生反感。效果必须在施法时选择，可以是鼻尖上的巨大疣、高音鼻音，甚至是刺鼻的体味。无论选择什么，它都会使人们远离受害者，或找借口尽快离开他们的视线。

#### 治疗 \(R\)

(死灵系)

| | |
| :-- | :-- |
| **位阶:** 牧师 4 | **施法时间:** 1 分钟 |
| **领域:** 治疗 | **持续时间:** 永久 |
| **消耗:** 3 +1/强度 | **射程:** 接触 |
| **范围:** 1 个生物 | **抵抗:** 无（耐力或闪避） |

通过施放治疗术，牧师可以通过单次接触治愈身体疾病、精神创伤或显著的身体伤害。这种恢复的实际程度基于法术的强度，具体如下：每 1 级强度，法术可治愈目标 1 种任何潜能 (POT) 的疾病，治愈任何失明或失聪，消除因受伤或魔法带来的精神错乱，或为一个命中部位治疗至多 12 点伤害。但是，它无法恢复断肢，因为那需要施放再生术。每一级额外强度可用于治愈另一种疾病或治疗另一个命中部位。因此，若要治愈全身遭受烧伤的个体，需要施放强度为 7 的法术。与那些限制针对长期伤害有效性的较弱治疗法术不同，该法术不受目标遭受伤害持续时间长短的限制。

反向施放时，伤害术在对抗抵抗失败后，会对受害者的一个命中部位造成 12 点魔法伤害。或者，对其施加一种疾病，其效果等同于导致疾病术（治愈疾病术的反向），但潜能 +20。施法者的引导 (Channel) 掷骰用作对抗对手的命中掷骰，并被视为法术躯体要求的一部分。无需额外的命中掷骰。穿着的护甲和天然护甲均无法提供保护，但魔法护甲点数可正常减少伤害，并能完全阻挡被施加的疾病。每一级额外强度会影响与第一个命中部位相连的另一个部位，效果由初始的抵抗掷骰决定。该法术的两个版本对不死生物、仅受铁/银/魔法武器伤害的生物，或非物质生物均无效果。

疾飞雨夹雪（持续时间：1 回合/强度）：此法术变体制造一道在 60 英尺宽、120 英尺长的路径区域内猛烈抽打的雨夹雪，使受影响者失明。施法时可指定具体路径。此外，受影响区域的地面结冰，使移动速率降低 50%，并使未能通过艰巨飞行技能掷骰的飞行生物坠落。地面上的目标必须每回合通过一次体能掷骰来抵抗倒地，如果移动速度快于步行，则掷骰难度提高两个等级。拥有杂技技能的角色可根据需要替换该技能。冰层会在法术持续时间结束后融化，具体速率由游戏主持根据环境温度决定；但即使在温暖天气下，至少也会持续 10 分钟。营火和火把等小火会自动熄灭。此法术会抵消金属加热术的效果。

#### 辨识

(预言系)

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 分钟 |
| **领域:** 防护 | **持续时间:** 1 分钟/强度 |
| **消耗:** 1/强度 | **射程:** 0 |
| **范围:** 施法者 | **抵抗:** 无 |

通过施放此法术，魔法使用者可以尝试辨识一件被拿在手中的物品或物体的魔法属性（如有）。仅接触物品通常是不够的，物品必须按照其设计方式佩戴或持有，例如，头盔必须戴在头上，护身符必须套在颈部，近战武器必须紧握，戒指戴在手指上，以此类推。如果奥术施法掷骰成功，后续的奥术知识掷骰将辨识出该物品拥有的一种魔法属性。在法术持续时间内，每分钟可进行一次奥术知识尝试。如果某属性需要激活词，它也将与该属性一同被辨识出。带有充能的物品将显示当前可用总数及正常最大值，拥有魔法点数矩阵的物品亦然。

诅咒物品通常在装备首次穿戴或使用时激活；因此，施放此法术将使魔法使用者遭受任何可能存在的诅咒效果。如果奥术施法技能测试成功，魔法使用者可以进行意志力测试以避免诅咒效果。但这并不能解除物体上的诅咒，但它允许施法者移除该物品而不受影响。

一颗价值至少 100GP 的珍珠被研磨成粉，并与其他普通的施法材料一同消耗以施放此法术。如果混入一颗磨碎的幸运石，奥术施法掷骰的难度为正常，并且在法术持续时间内，每分钟处理的任何一件物品的所有魔法属性都会被自动知晓，无需进一步掷骰。

#### 点燃 \(R\)

(变化系)

| | |
| :-- | :-- |
| **位阶:** 法师 0 | **施法时间:** 1 行动 |
| **领域:** 元素（火） | **持续时间:** 瞬时 |
| **消耗:** 1 | **射程:** 10 英尺 |
| **范围:** 1 个小火 | **抵抗:** 无 |

此法术可用于两种不同方式，即点燃或熄灭。施法时需选择其一。

点燃仅作用于可燃的无机物，使一个小物体或手掌大小的区域燃起火焰。根据被点燃物体的不同，一旦燃烧，火焰可能会扩散，除非以某种方式扑灭或反制。此法术通常用于远程点亮蜡烛、火把或灯笼。它也可用于在不利条件下（如使用潮湿的引火物或强风中）引燃营火或烹饪火。

熄灭可立即扑灭中等大小和热度的火焰和小火。它适用于熄灭蜡烛、灯笼、火把或小型烹饪火，但对魔法火焰或更大、更猛烈的火势（如柴堆、燃烧的房屋或龙火）无效。

#### 幻象

(幻术系)

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 专注；见下文 |
| **消耗:** 1/强度 | **射程:** 100 英尺/强度 |
| **范围:** 50 英尺半径/强度 | **抵抗:** 不信则无 |

此法术创造施法者所渴望的任何事物的视觉幻象。它对其他感官无效，不会产生声音、气味、温度或质感等。

如果符合法术的范围，此幻象可以是任何事物，从开阔的草地到古老的红龙。幻象仅在施法者保持专注时存在，一旦对手触碰或进入其中，维持它的魔法就会解开并消散。然而，施法者可以通过消耗 1 点魔法点数并引导其对接触做出适当反应，以避免引起怀疑，从而在物理接触后维持幻象。例如，在正常情况下，食人魔的幻象在被箭矢击中时会消失；但施法者可以通过花费 1 点魔法点数，让食人魔表现出无视打击并向攻击者冲锋的样子。需要注意的是，真实的箭矢不会被幻象阻挡，仍可能击中表现物后的某人或某物。

虽然幻象本身无法造成实际伤害，也不会产生任何温度，但思维可能会相信它感受到了疼痛，从而遭受伤害效果，或感觉到极热或极冷；然而，物体看起来不会结冰或燃烧，除非施法者也专注于这些效果。一旦法术施放，魔法使用者可以通过专注于所需效果来随意添加额外的视觉效果。这通常不耗费时间，可作为自由行动处理。例如，如果施法者希望掉落的幻影火把使干枯的叶子看起来着火，施法者可以作为自由行动进行专注以实现。

更多信息请参阅[幻象与幻觉](0009_Magic.md?id=illusions-and-phantasms)章节。

| 4 | 4 | 200 英尺半径；400 英尺射程 |

闪电有一定概率点燃易燃材料，概率等于所投出的伤害点数 x 1%。有关更多信息，请参阅关于 [Fires](0007_Game_System.md?id=fire-based-attacks) 的章节。闪电也可能因巨大的冲击力而粉碎或摧毁无生命物体。

#### Magic Missile

(塑能系)

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 瞬间 |
| **消耗:** 1/等级 | **射程:** 100 英尺/等级 |
| **范围:** 1-5 个目标 | **抗力:** 见下文 |

当施展此法术时，一枚或多枚魔法能量飞弹从法师指尖射出并击中目标。产生的最大飞弹数量取决于施法者的奥术施法技能等级：60% 技能可产生第二枚飞弹，70% 为第三枚，80% 为第四枚，90% 为第五枚（最终）。要产生这些飞弹，施法必须以等于所需飞弹数量的等级进行。例如，在 60% 以下时，以 3 等级施展 Magic Missile 的法师将获得更长的射程，但只会产生一枚飞弹。70% 技能等级的法师以同样 3 等级施展时，可获得相同射程并产生 3 枚飞弹。此法术的最大等级为 5。见下表。

Magic Missile 将无误地击中目标，即使目标处于近战中或有部分掩护。这些飞弹无法闪避；然而，完全掩护下的对手无法被此法术指定。Shield 法术会自动偏转 Magic Missiles，前提是目标意识到施法者或正面向施法者。Magic Missiles 造成 1d6+1 点伤害，穿戴的护甲无法提供保护，但生物的天然护甲或魔法护甲点数可正常减免伤害。Magic Missiles 对门、锁等无生命物体不造成伤害。

发射多枚飞弹时，施法者可以让它们击中单个生物，或指定多个目标。每枚 Magic Missile 都会随机命中一个命中部位（Hit 位置）——无法指定特定部位。施法者必须在掷伤害骰之前为每枚飞弹指定单独的目标。

| 3 | 3 | 300 英尺射程；70% 技能时 3 枚飞弹 |
| 4 | 4 | 400 英尺射程；80% 技能时 4 枚飞弹 |

#### Magic Mouth

(变形系)

| | |
| :-- | :-- |
| **位阶:** 法师 2 | **施法时间:** 1 分钟 |
| **领域:** 无 | **持续时间:** 见下文 |
| **消耗:** 3, +1/额外等级 | **射程:** 30 英尺 |
| **范围:** 1 个物体 | **抗力:** 无 |

此法术在物品或物体上创造一个嘴巴，当触发施法者在施法时设定的特定事件或时间点时，嘴巴会显现出来。该嘴巴会说出施法者预设的短语。短语不得超过 25 个单词，且以大约每秒 1 个单词的速度讲出。嘴巴不能说出力量之语或施展法术。

此法术可施加于任何通常的无生命物体上，从柱子、树木到石墙或箱子；施加于雕像上效果尤佳，因为雕像看起来就像真的在说话。它不能施加于任何具有任何形式灵智或本能的活物身上。这也适用于曾经活着的人。施法时，法师决定触发附魔的情况。触发方式可以是从说出的一个词到发出的任何噪音。触发条件可以通用如“当下一个人进入这个房间时……”，也可以具体如“当塞多纳的女性牧师在周六走进大厅尽头的雕像 10 英尺范围内时……”。触发效果不能是无法非魔法分辨的事物，例如隐形生物、生物的阵营、技能、职业等。但可以指定穿戴的服饰。法术可被触发的最远距离为每等级 25 英尺。

该法术持续有效，直至附魔被触发，随后法术结束。

(幻术系)

| | |
| :-- | :-- |
| **位阶:** 法师 2 | **施法时间:** 1 行动 |

| **消耗:** 1/等级 | **射程:** 0 |

当施展此法术时，法师的 2d4 个复制品出现在 5 英尺半径内，准确模仿施法者的动作。此外，整个影响区域波动闪烁，使得法师的确切位置无法确定。击中一个幻影会导致其消失；然而，其余图像不受影响。击中法师本人对剩余图像没有影响，且由于图像不断移动，如果再次被攻击，无法判断目标是否为真正的法师。法师所受的任何伤害也会同步体现在图像上。游戏主持人可以通过多种方式判断实际法师是否被击中或被击中的是图像。一种方法是确定包括法师在内的潜在目标数量，并掷出对应面数的骰子。例如，如果有 4 个图像和法师本人，攻击者应投掷 1d6，重投 6 的结果，并在投出 1 时击中法师。另一种方法是准备与潜在目标数量相等的标记，并将其中一个标记为法师。每次攻击时抽取一个标记，如果击中目标，则应用伤害；否则，消失一个图像，并移除一个标记。图像在法术持续时间结束时消失。

#### 永恒术

(变形术)

| | |
| :-- | :-- |
| **位阶:** 法师 4 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 永久 |
| **消耗:** 3，+2 经验值 | **射程:** 见下文 |
| **范围:** 见下文 | **抵抗:** 无 |

施放此法术可将某些其他法术的持续时间改为永久。要使用此法术，魔法使用者将首先施放预定永久化的法术。然而，在完成该法术施放后，法术被暂留，并消耗额外的行动点数施放永恒术，之后选定的法术便以其永久形式施放。每个永久化法术除了原法术的正常施法消耗外，还需要消耗施法者 2 点经验掷骰以及注明的 3 点魔法点数。在施放永恒术期间施放解除魔法 (Dispel Magic)，不仅会解除永恒术，还会解除原法术。

永恒术也是使用附魔物品 (Enchant Item) 法术制作魔法物品的关键应用。除了下述法术外，经由游戏管理员许可，其他法术也可被永久化。

以下个人法术（仅影响施法者自身的法术）将受益于此法术。它们不可在其他生物身上永久化：

- 规避 (Avert)
- 协调 (Coordination)
- 暗视 (Darkvision)

#### 变形他人

(变形术)

| | |
| :-- | :-- |
| **位阶:** 法师 3 | **施法时间:** 2 行动 |
| **领域:** 无 | **持续时间:** 永久 |
| **消耗:** 3，每增加一级强度需 +1 (+1 经验值) | **射程:** 15 英尺/强度 |
| **范围:** 1 个目标 | **抵抗:** 意志力 |

施法者可以改变一个有实体的目标生物形态为另一种，每点强度改变至多 5 点 体型。因此，将一个 体型 16 的兽人变为 体型 1 的兔子需要 3 级强度（相差 15 点 体型）。该法术的目标允许进行意志力掷骰进行抵抗。大型生物 (体型 21-40) 对变形的抵抗力较弱，其抵抗掷骰为简单 (简单)，而巨大生物 (体型 41+) 的抵抗掷骰为非常简单 (Very 简单)。

整个变形过程需要整整 1 回合，对相关生物来说压力巨大，需要进行第二次意志力掷骰以保持原有的人格，失败会使目标昏迷 1d10 分钟，大失误 (大失误) 则导致因精神冲击而死亡。生物原有 体型 每翻倍或减半一次，保持人格的意志力掷骰难度都会增加一个等级，彻底改变环境也是如此（例如将人变成鱼）。掷骰成功允许受害者保留其智力和魅力，以及任何需要这些特征值的技能。

变形赋予受体所假定生物的呼吸形式（若非正常呼吸）；任何天生攻击；以及所有常见的移动方式。它不赋予该生物拥有的任何增强或魔法能力。例如，被变形成龙的生物不会获得该生物的喷吐攻击或类法术能力，但会获得飞行能力、坚硬外皮、致命撕咬、爪击等。此外，受害者获得新形态的体能技能，例如体能、蛮力、飞行、游泳，以及该形态的生命值和伤害修正。假设被变形的个体保留了智力，他们仍会丧失说话能力，除非新形态具备清晰发出字词的能力。前一个形态能施法的个体仍能在新形态下施法，前提是他们仍有能力产生法术的语言和姿势成分。在发生剧烈改变的情况下（例如从双足变成四足，或从陆地动物变成海洋生物），游戏管理员应随时视情况对那些在调整到新形态前需要学习时间的技能使用进行至少一个难度等级的惩罚，直到有足够的时间练习。这对体能、徒手、游泳、飞行、战斗技能等体能技能尤其如此。

只要受害者保持变形状态，每天都需要进行意志力掷骰以保持人格，直到失败，这会导致该人最终屈服于新形态的思维方式，如果是非智慧生物，智力将变为洞察。新形态拥有的所有在之前未曾获得的特殊和魔法能力（如注视攻击、喷吐武器等）现在随着变形完成而可用。以这种方式失去自我的角色将变成由游戏管理员控制的非玩家角色。

在精神上屈服于变形之前，被变形的生物仍会像往常一样受到解除魔法的影响，无需掷骰抵抗，因为回归正常是受试者潜意识的渴望。变形确实需要另一次意志力掷骰来抵抗压力，失败会使受试者昏迷 1d10 分钟，大失误则导致因精神冲击而死亡。

如果受害者之前已经屈服于新形态，仍可使用解除魔法；然而，受害者将尝试以意志力掷骰抵抗回归自然形态。此掷骰失败意味着受害者变回自然形态，这当然需要另一次意志力掷骰来抵抗变形带来的精神冲击。一旦丢失，受害者的自然身份将不再可得，受害者转而认为那种奇怪而陌生的形态才是不自然的，并渴望回归到之前的“正常”状态。*例如，一个被变形成兔子并认同了该生物身份的兽人，会认为自己现在是一只兔子，被相当粗鲁地变成了兽人。* 只有许愿术或其他类似的魔法才有机会在受害者的身份丢失后将其恢复。

所有穿戴和携带的装备会魔法般地融入新形态；然而在某些情况下，游戏管理员可以允许在生物新形态下仍能使用的魔法物品保留，例如魔法戒指或靴子。注意这要求生物的新 体型 与原始 体型 相差不能太大。对于每件非攻击性的已穿戴魔法物品（视游戏管理员批准而定），有 灵力 x1% 的几率将其效果转移到生物的新形态。例如，拥有 +1 保护戒指的生物可以获得 +1 的护甲点数奖励。具有天生变形能力的生物（如变形怪和狼人）将照常被变形，但可以在 1 回合后恢复其正常形态。如果被杀，被变形的生物会恢复其自然形态，即使它之前已经丧失了所有身份痕迹。

| 强度 | 消耗 | 可变效果 |
| :-: | :-: | :-- |
| 1 | 3, +1 经验值 | 15 英尺射程；1-5 点 体型 差异 |
| 2 | 4, +1 经验值 | 30 英尺射程；6-10 点 体型 差异 |
| 3 | 5, +1 经验值 | 45 英尺射程；11-15 点 体型 差异 |
| 4 | 6, +1 经验值 | 60 英尺射程；16-20 点 体型 差异 |
| +1 | +1 | 继续推进 |

#### 自我变形

(变形术)

| | |
| :-- | :-- |
| **位阶:** 法师 3 | **施法时间:** 2 行动 |
| **领域:** 无 | **持续时间:** 20 分钟/强度 |
| **消耗:** 3，每增加一级强度需 +1 | **射程:** 0 |
| **范围:** 施法者 | **抵抗:** 无 |

施法者可以假定任何其他有实体生物的形态，从 体型 1 小到 体型 40 大。每点强度允许增加或减少至多 10 点 体型。因此，一个 体型 13 的魔法使用者可以在 3 级强度下假定为 体型 34 的灰熊形态。变形过程需要整整 1 回合，并赋予施法者所假定生物的呼吸形式（若与自身不同，例如在水中呼吸）、任何天生攻击、生命值、伤害修正及其正常的移动模式。它不赋予该生物拥有的任何增强或魔法能力。例如，一个变形成鹰的魔法使用者不会获得该鸟类非凡的视力。施法者获得该生物的体能技能，如体能、蛮力、飞行、游泳等，但保留任何心智和社会技能（需要智力和魅力的技能）。除非该生物具备清晰发出字词的能力，否则施法者会丧失说话能力。如果是这样，假设施法者能形成法术的姿势成分，施法者仍能以新形态施法。

施法者可随时结束效果，在此过程中，在新形态下获得的所有轻伤 (Minor Wounds) 都会消失，严重伤害 (Serious Wounds) 会减少为轻伤（每个适用位置损失的生命值减半）。重伤 (Major Wounds) 不受变形影响，并会带回自然形态。从自然形态变形为动物形态时没有治疗效果。

变形术受解除魔法影响。在这种情况下，施法者无法从治疗中受益。如果被杀，施法者将恢复其自然形态。如果变形成飞行生物并需要进行飞行技能掷骰，可以使用体能或杂技代替，难度增加两个等级。然而，经常使用这种形态的角色可以选择正常发展飞行技能，基础值为力量+敏捷。

| :-: | :-: | :-- |

| 2 | 4 | 40 分钟；11-20 点 体型 差异 |
| 3 | 5 | 60 分钟；21-30 点 体型 差异 |
| 4 | 6 | 80 分钟；31-40 点 体型 差异 |
| +1 | +1 | 继续推进 |

#### 复原

(死灵系)

| | |
| :-- | :-- |
| **位阶:** 牧师 3 | **施法时间:** 3 分钟 |
| **领域:** 治疗 | **持续时间:** 永久 |
| **消耗:** 3, +1/额外灵力 | **射程:** 接触 |
| **范围:** 1 目标 | **抵抗:** 无 |

施展此法术时，之前因能量吸取或类似效果而被耗尽生命力的受害者可恢复一级之前丧失的疲劳。在 1 点灵力时，此法术仅对过去 24 小时内被吸取的生物有效。每增加 1 点灵力，可恢复的时间窗口延长 24 小时。例如，一个在 48 小时前被吸取的受害者需要以 2 点灵力施展此法术才有效。多级丧失的疲劳需要额外多次施展复原。无论持续时间如何，除了恢复疲劳外，此法术还能恢复所有的精神能力，例如那些因魔法或任何形式的精神错乱或痴呆而丧失的能力。复原也可用于移除因人工衰老（如某些法术导致的）而丧失的岁月。若要以此方式施展，除了正常的施法消耗外，牧师必须为恢复受术者典型寿命的每 1% 消耗 1 次经验修正（对于人类而言即 1 年）。该法术不能使受术者的当前年龄降低到其实际年龄以下。

#### 复活 (R)

(死灵系)

| | |
| :-- | :-- |
| **位阶:** 牧师 5 | **施法时间:** 10 分钟 |
| **领域:** 死灵 | **持续时间:** 永久 |
| **消耗:** 3, +1/额外灵力, +2 经验 | **射程:** 接触 |
| **范围:** 1 目标 | **抵抗:** 无（意志力） |

复活可使死亡时间不超过每级灵力 20 年的任何生物复生。该生物不仅获得生命，还能恢复全部体力并治愈伤势，甚至长回缺失的肢体。即使实际生物只剩下极少部分，法术依然有效。例如，复活可用于使一个 145 年前死亡的生命复生，即使只拥有一块指骨，只要法术以 8 点灵力施展即可。复活后的个体无需休息期，可立即恢复全部功能。此法术对因自然原因在寿命耗尽时死亡的生物无效。

如果受术者的阵营并非邪恶，他们可以通过意志力对抗掷骰来抵抗此法术；若成功，则效果抵消。这是因为死者的灵魂或精神一旦到达了永恒的奖赏之地，通常不愿回到人间。然而，游戏主持可以决定若受术者有未了心愿、无法与真爱分离，或有其他英雄般的原因必须活着，则可豁免此掷骰。对于邪恶的灵魂，他们宁愿回归也不愿遭受永恒的诅咒，因此抵抗的不是死者的意志力，而是负责惩罚他们的恶魔、魔鬼等拷问者的意志力。在此情况下，施法者必须克服拷问者的意志力。若其意志力未知，则假设其至少比死者高 20 点，以体现灵魂意志越强，负责其诅咒的生物就越强大。如果施法者成功，则复活成功；掷骰失败则意味着受害者不愿意或无法回归。

复活非常消耗精力，会使牧师衰老其典型寿命的 3%（对于人类施法者，即 3 年）。参见 [衰老](0007_Game_System.md?id=aging) 规则。

反转后的法术，“毁灭”，可用于杀死施法时与牧师接触的一名受害者。该受害者可以进行意志力掷骰来抵抗，并根据目标的位阶或体型进行修正（取对受害者最有利的结果），具体如表所示。

| 目标位阶 | 目标体型 | 意志力修正 |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | 艰巨 |
| 2 | 21-40 | 困难 |
| 3 | 41-60 | 标准 |
| 4 | 61-80 | 简单 |
| 5 | 81+ | 非常简单 |

_\* 此类别包括未拥有职业的角色。_

若此抵抗掷骰失败，受害者将直接死亡，躯体化为尘土。此阶段仅有“许愿术”能使受害者复生。若掷骰成功，受害者仍会受到伤害，受接触的命中部位生命值降低 1d4 点。护甲无法防范此伤害。毁灭在被使用时不会使施法者衰老。

#### 护盾

(塑能系)

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 5 回合/灵力 |
| **消耗:** 3, +1/额外灵力 | **射程:** 0 |

护盾创造出一面无形的移动力场盘，悬浮在施法者面前，通过将攻击弹开来增加来自该方向的攻击难度。在微缩模型战斗中，护盾仅能阻挡穿过施法者前方方格的伤害。魔法使用者除了施展此法术外无需进行任何技能测试，因为法术会自动在攻击与施法者之间插入护盾。对穿过施法者正面攻击的减值取决于攻击类型，详见下表。

(变化系)

| | |
| :-- | :-- |
| **位阶:** 牧师 2 | **施法时间:** 2 行动 |
| **领域:** 守卫 | **持续时间:** 见下文 |
| **消耗:** 3, +1/额外灵力 | **射程:** 360 英尺 |

#### 睡眠

(附魔系 (魅惑))

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 行动 |
| **领域:** 无 | **持续时间:** 5 分钟/灵力 |
| **消耗:** 3, +1/额外灵力 | **射程:** 60 英尺 |
| **范围:** 10 英尺半径 | **抵抗:** 意志力 |

此法术使 10 英尺半径圆内每级灵力对应的一个活物陷入魔法睡眠。法术的效果范围以空间或地面上的一点为中心，最近的生物首先进行抵抗，然后是次近的，依此类推。若两个或以上生物距离相等，随机决定谁受影响。每个生物均有一次抵抗机会，若其中一人成功，则换下一人尝试，直到被影响的总数等于法术的灵力值，或范围内不再有生物。处于高度警觉状态或战斗中的生物在进行抵抗掷骰时，难度会降低一个等级。

大型生物（体型 21-40）对睡眠的抵抗力较低，抵抗掷骰为简单，而巨型生物（体型 41+）的抵抗掷骰为非常简单。较小的生物总是比较大的生物先受影响；因此，体型 20 或以下的生物总是比体型 21-40 的生物先受影响，后者又比体型 41+ 的生物先受影响。

在睡眠期间，受影响的生物处于无助状态，正常的噪音不会影响他们，但他们可以被摇晃或掌掴醒来。任何攻击（假设非致命）也会导致他们醒来（尽管攻击会造成突袭）。尝试唤醒一个生物需要 1 个战斗回合。

| 灵力 | 消耗 | 变量效果 |
| :-: | :-: | :-- |
| 1 | 3 | 5 分钟持续时间；1 个生物 |
| 2 | 4 | 10 分钟持续时间；2 个生物 |
| 3 | 5 | 15 分钟持续时间；3 个生物 |
| 4 | 6 | 20 分钟持续时间；4 个生物 |
| +1 | +1 | 延续进程 |

#### 缓慢毒素

(死灵系)

| | |
| :-- | :-- |
| **位阶:** 牧师 1 | **施法时间:** 1 行动 |
| **领域:** 治疗 | **持续时间:** 1 小时/灵力 |
| **消耗:** 3, +1/额外灵力 | **射程:** 接触 |
| **范围:** 1 目标 | **抵抗:** 无 |

此法术允许施法者减缓毒药和毒液的效果；然而，它并不能中和毒素。相反，在体内扩散的毒素被减缓，以期能找到额外的治疗措施。毒素的起效时间直到法术持续时间过期后才会开始计算。

例如，眼镜蛇毒液的起效时间如下：1d6+4 分钟后产生剧痛，1d6+6 小时后导致窒息。因此，1 点灵力的“缓慢毒素”会将起效时间推迟 1 小时，之后 1d6+4 分钟，剧痛才会如常出现。

如果在症状出现后对受害者施展“缓慢毒素”，症状会停止直到法术持续时间结束，然后如常继续。

作为最后的手段，如果施法者能在受害者因中毒“死亡”后的 10 分钟内接触到他们，“缓慢毒素”可将受害者的死亡推迟每点灵力 1 小时，在此期间受害者保持昏迷。如果在此时间内受害者能治愈毒素，他们可能幸存并被急救或魔法治疗救活。

#### 日光射线 (Sun Ray)

(塑能系，转化系)

| | |
| :-- | :-- |
| **位阶:** 牧师 5 | **施法时间:** 2 行动点数 |
| **领域:** 太阳 | **持续时间:** 1d4+1 小时 |

施法时，牧师可以在法术持续时间内的任何时刻通过施展魔法行动召唤一道辉煌的神圣光束。该光束为自然日光，半径五英尺。范围内的目标必须进行闪避以保护双眼，否则将致盲 1d3 分钟。如果未能通过抵抗掷骰，日光射线将使拥有黑暗视觉的生物致盲 2d4 分钟，并使其在范围外 20 英尺内失去黑暗视觉能力，持续 1d4+1 分钟。对于觉得自然日光会伤害视力的生物，若抵抗失败则永久致盲，若成功则致盲 2d6 小时。

#### 火墙/火环 (Wall of Fire/Circle of Fire)

(塑能系)

| | |
| :-- | :-- |
| **位阶:** 牧师 3, 法师 3 | **施法时间:** 2 行动点数 |
| **领域:** 战斗, 元素（火） | **持续时间:** 见下文 |
| **消耗:** 3, 每增加 1 强度额外 +1 | **射程:** 见下文 |
| **范围:** 见下文 | **抵抗:** 见下文 |

此法术允许施法者召唤出一堵火墙或一个火环（视施法时选择而定），火焰呈紫色或红蓝色。如果保持专注，法术持续时间有效；一旦专注结束，则持续 1 小时/强度。具体细节根据类型分类如下：

**火墙：** 该版本的法术创建一堵静止的火墙，每强度长 20 英尺。无论最终强度如何，火墙的高度可根据施法时的意愿设定在 10 到 20 英尺之间。火墙射程为 180 英尺，不能水平召唤。

**火环：** 该版本的法术在施法者周围创建一个随其移动的火环。其半径为 10 英尺，每额外增加一级强度半径增加 5 英尺。无论最终强度如何，火环的高度可根据施法时的意愿设定在 10 到 20 英尺之间。火环必须环绕施法者，射程为 0。

背向施法者的火墙或火环一侧会散发灼热的高温，对 10 英尺内的所有目标造成每小时 1d6 点伤害，并在 20 英尺范围内造成 1d4 点伤害。此伤害通常在每小时结束、进入下一小时前计算。若受害者在同一小时内同时处于两个受热区，则应用较高伤害值。穿过火焰者将承受 2d6 点伤害，若强度超过一级，每增加一级额外增加 1 点伤害。该伤害作用于每个命中部位，穿戴的护甲不提供任何保护，但魔法护甲点数或生物的天然护甲可以正常减免伤害。若通过抵抗掷骰（闪避），受害者可以在法术产生的瞬间避免受伤，因为受害者试图从热源处避开或绕过火焰。火属性生物受到一半伤害，冰属性生物受到双倍伤害。火焰有几率点燃易燃材料，概率等于掷出的伤害值 x 5%。有关更多信息，请参阅[火](0007_Game_System.md?id=fire-based-attacks)部分。

#### 蛛网术 (Web)

(塑能系)

| | |
| :-- | :-- |
| **位阶:** 法师 1 | **施法时间:** 1 行动点数 |
| **领域:** 无 | **持续时间:** 20 分钟/强度 |
| **消耗:** 3, 每增加 1 强度额外 +1 | **射程:** 30 英尺/强度 |
| **范围:** 20 英尺半径 | **抵抗:** 闪避，外加见下文 |

此法术会导致长条状的粘性蛛网从施法者手中射出，这些蛛网可以固定在地板与天花板之间，或墙壁之间，以封锁通道或阻碍前进。它们也可以直接喷射到对手身上以将其纠缠。

假设目标有空间避开蛛网，成功的闪避掷骰将使目标处于范围之外；但这需要消耗一个行动点数。抵抗掷骰失败则会导致受害者动弹不得，且 1d3 个命中部位被纠缠。正如[纠缠](https://cfi-srd.mythras.net/#/0008_Combat?id=entangle)特殊效果所述，被蛛网包裹的部位无法使用。被纠缠的手臂无法使用手中的任何物品，被纠缠的胸部、腹部或腿部会使所有物理技能掷骰难度提高一级（尝试挣脱的蛮力掷骰除外），被网住的头部会导致窒息，详情见[窒息](0007_Game_System.md?id=asphyxiation)。

在随后的回合中，受害者可以花费一个行动点数尝试从蛛网中挣脱。魔法蛛网极其强韧且具有粘性，拥有 6 点护甲值和等同于法术强度 3 倍的生命值。尝试挣脱需要受害者在蛮力对抗蛛网粘性（等同于施法者的奥术施法技能）的对抗掷骰中获胜。如果失败，目标仍被束缚，无法单凭力量挣脱。尝试切割挣脱会使所使用的工具或武器受到同样的过程。尽管人们普遍认为蛛网易燃，但事实并非如此，但角色可以使用火焰慢慢烧毁蛛网纤维（火属性伤害忽略蛛网的护甲点数）。

| :-: | :-: | :-- |
| 1 | 3 | 20 分钟；30 英尺射程；6 护甲，3 生命值 |
| 2 | 4 | 40 分钟；60 英尺射程；6 护甲，6 生命值 |
| 3 | 5 | 60 分钟；90 英尺射程；6 护甲，9 生命值 |
| 4 | 6 | 80 分钟；120 英尺射程；6 护甲，12 生命值 |
| +1 | +1 | 继续顺延 |

#### 祈愿术 (Wish)

(召唤系，塑能系)

| | |
| :-- | :-- |
| **位阶:** 法师 5 | **施法时间:** 见下文 |
| **领域:** 无 | **持续时间:** 见下文 |
| **消耗:** 3, 外加 1 或更多经验修正 | **射程:** 无限 |
| **范围:** 见下文 | **抵抗:** 见下文 |

祈愿术可以永久且显著地改变现实。施展此法术时，魔法使用者必须根据预期结果花费 3 点魔法点数和 1 次或多次经验修正。在 1 个月内连续施展祈愿术会使所需的经验修正消耗翻倍。施法时间通常用于口头陈述祈愿的具体细节。施法完成后，施法者会遭受等同于所花费经验修正点的疲劳损失，并老化正常预期寿命的 5%（对人类而言，即五年）。有关半人类种族的平均预期寿命，请参阅[衰老](0007_Game_System.md?id=aging)。

祈愿术的结果应按字面理解，且由游戏主持人进行解释。贪婪的愿望通常会带来糟糕的后果。出于贪婪意图所作的祈愿有 10% 的几率以某种方式反噬。例如，祈求财富可能会将其从当地领主或国王的金库中传送而来。除非神祇类实体自身发出了祈愿，否则该法术无法取消此类实体的敕令。

(转化系)

| | |
| :-- | :-- |

此法术创造一个小型的隐形“眼睛”，魔法使用者在法术持续时间内可以通过它进行观察。这只眼睛可以移动到队伍前方或绕过拐角窥视房间，其移动速率为每回合 20 英尺（每分钟 240 英尺，若仅扫描“明显”威胁或感兴趣的物品）。通常只会扫描到地面和下层墙壁。若尝试进行更彻底的搜索（同时检查完整的墙壁和天花板），其移动速率会降低至每回合 10 英尺（每分钟 120 英尺）。如有必要，游戏主持人应自由允许施法者进行感知掷骰，以探测视觉异常。眼睛是实体的，无法穿过固体物质，在 60 英尺内拥有普通视觉，在 10 英尺内拥有黑暗视觉。施法者必须在整个持续时间内对眼睛保持专注，否则它将保持惰性，直到重新建立专注。任何通常会影响施法者的凝视攻击仍会如常影响施法者；然而，在失明、黑暗术等方面，该眼睛被视为独立于施法者。为了穿过狭窄开口，眼睛尺寸不超过 1 英寸，体型 (体型) 为 1。

#### 回归术 (Word of Recall)

(转化系)

| | |
| :-- | :-- |
| **位阶:** 牧师 4 | **施法时间:** 1 行动点数 |
| **领域:** 召唤 | **持续时间:** 见下文 |
| **消耗:** 3, 每增加 1 强度额外 +1 | **射程:** 0 |
| **范围:** 施法者本人 | **抵抗:** 无需 |

施展此法术时，牧师会被瞬间传送到预先指定的圣所，抵达点半径不超过 10 英尺。实际传送射程没有限制，包括跨越多个位面。在同一位面内，没有出错的几率；然而，跨越一个位面即有 91-00% 的大失误 (大失误) 几率，跨越两个位面则 81-00% 会发生大失误，以此类推。这取代了施法者正常的大失误几率。跨越位面时发生大失误意味着牧师将不可挽回地迷失。在同一位面内的大失误遵循正常规则。

除了自己和携带的装备外，牧师每强度还可以额外传送 3 个物品，每个物品尺寸不超过 体型/9“个单位”。额外传送的物资可以是财宝、装备或活体生物。然而，传送生物时必须以足够的法术强度等级来覆盖其所携带的任何装备。
