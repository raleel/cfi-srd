# 第4章：阵营与激情

在《Classic Fantasy Imperative》中使用阵营与激情，可以极大地帮助玩家和游戏主持人（GM）深化角色本质，引入基于角色渴望或偏见的剧情钩子，并帮助玩家理解其角色是谁、什么在驱动着他，等等。虽然本章中阵营与激情的具体选择由玩家决定，但上一章中与角色[职业](0003_Classes.md)相关的某些选择是游玩该角色所必需的。本文件中的所有职业都不要求特定的阵营或激情，但某些职业（如牧师和加入盗贼公会的游荡者）要求对其秩序或公会宣誓。誓言在游戏机制上可以被视为一种激情。

---
## 阵营

所有角色都必须拥有一个阵营，该阵营由两部分组成：道德准则和伦理准则。伦理准则定义了对秩序与混乱的态度，而道德准则决定了对善良与邪恶的感受。然后，角色为每一项选择一个或两个决定性元素，并确定起始百分比。例如，混乱（无组织且贪婪）55%，善良（乐于助人且慷慨）55%。你不能选择两次中立；相反，你会忽略道德和伦理准则，直接选择“绝对中立”作为你唯一的阵营。伦理准则和道德准则及其决定性元素详述如下。

#### 伦理准则

从秩序、中立或混乱中选择一个，基础等级为智力+灵力+30。

- **秩序**：选择一个或两个最能描述你伦理准则的决定性元素：_遵守传统；精于算计；思想封闭；憎恨混乱；有伦理；诚实；光荣；好评判；缺乏适应力；缺乏幽默感；服从合法权威；有组织；可预测；可靠；轻信；值得信赖；举止优雅。_
- **中立**：选择一个最能描述你伦理准则的决定性元素：_认为秩序与混乱都是偏见且危险的极端；谨慎；自负；在涉及秩序与混乱时没有强烈偏向；灵活；行动自由；没有既定的伦理准则；务实；尊重自然。_
- **混乱**：选择一个或两个最能描述你伦理准则的决定性元素：_举止粗鲁；嗜血；好奇；犬儒；不诚实；不光荣；无组织；无视合法权威；利己主义；自由；憎恨秩序；不负责任；无法无天；狂妄自大；恶作剧者；易怒；狂暴；鲁莽；多疑；不可控；不可信；不可预测；不可靠。_

#### 道德准则

从善良、中立或邪恶中选择一个，基础等级为智力+灵力+30。

- **善良**：选择一个或两个最能描述你道德准则的决定性元素：_令人钦佩；利他；天使般；威严；慷慨；对伤害无辜感到良心不安；体面；宽恕；友好；憎恨邪恶；乐于助人；善良；热爱自然；仁慈；乐观；积极；素食主义。_
- **中立**：选择一个最能描述你道德准则的决定性元素：_认为善良与邪恶都是偏见且危险的极端；谨慎；在涉及善良与邪恶时没有强烈偏向；灵活；行动自由；缺乏为了保护或帮助他人而做出牺牲的承诺；通过个人关系而非道德准则与他人建立联系；没有既定的道德准则；务实；很少寻求社交。_
- **邪恶**：选择一个或两个最能描述你道德准则的决定性元素：_虐待狂；食人；贪求；残忍；专横；以伤害无辜为乐；贪婪；憎恨善良；淫欲；操纵；冷酷；骄傲；施虐癖；以自我为中心；自私；蓄奴；怀恨在心；虚荣；暴力。_

#### 绝对中立

绝对中立的起始基础等级为智力+灵力+30。

- **绝对中立**：或者，选择一个或两个最能描述你既无道德准则也无伦理准则的决定性元素：_矛盾；谨慎；通过个人关系与他人建立联系；灵活；行动自由；思想开放；务实；尊重自然；力求平衡。_

## 激情

激情用于协助玩家和游戏主持人深化角色本质，引入基于角色渴望或偏见的剧情钩子，并帮助玩家理解其角色是谁、什么在驱动着他，等等。

激情可以针对任何事物——一个人、一个组织、一个理想，甚至一个物体。激情通常用动词来描述，例如：渴望、鄙视、摧毁、信奉、恐惧、逃避、放弃、憎恨、热爱、忠诚于、保护、背弃、尊重、寻求、颠覆、折磨或维护。

激情的衡量方式与技能相同；其等级在1到100（或更高）之间。激情可以通过与技能相同的方式进行提升，也可以根据具体情况由游戏主持人进行增加或减少。

起始角色最多可以拥有三个激情，每个激情基于两个特征值，第一个获得+40的加成，第二个获得+30，第三个获得+20，玩家决定重要性顺序。这些激情可以与文化、职业或个人怪癖相关联。例如，不信任（游荡者）；忠于女王；热爱家庭；击败混乱。激情在许多角色职业中扮演着尤为重要的角色，详见下一章。对于其中一些职业，维持激情在最低等级是保留职业特定特殊能力所必需的，在极端情况下，失去激情可能导致失去职业。

激情的起始数值根据其类型而异；请见下方的[激情表](0004_Alignment_and_Passions.md?id=passion-table)。

本节仅详细说明了激情的代表含义及其默认数值。激情如何在游戏中运用，将在下文讨论。

##### 激情表

| 激情的对象 | 起始百分比 |
| :-- | :-- |
| 一个人，在浪漫或家庭背景下 | 灵力+魅力 |
| 一个组织或一群人 | 灵力+智力 |
| 一个种族或物种 | 角色灵力 x2 |
| 一个地点 | 角色灵力+智力 |
| 一个物体或物质 | 角色灵力 x2 |
| 一个性格特征 | 角色灵力+魅力 |

## 使用阵营与激情

阵营或激情是任何有能力在游戏过程中影响事件的深层承诺。虽然它们可以作为独立的“能力”使用（将它们称为技能是对它们的一种贬低），但下文对激情进行了进一步扩展，解释了它们的工作原理以及它们如何影响《Classic Fantasy Imperative》的角色和战役。

总之，阵营与激情可以通过以下方式使用：

- **增强其他技能**：反映了情感的深度以及它如何驱动行动。当以此方式使用时，如果这种增强在主题和戏剧性上很重要，阵营或激情将为其所使用的技能增加其数值的20%。
- **作为驱动选择、欲望和情感反应的能力**：当以此方式使用时，针对阵营或激情进行一次标准掷骰，以确定角色对某事物的思考和感受程度。如果掷骰成功，则角色会按照阵营或激情的指引行动。如果掷骰失败，则角色可以自由行动，而不受激情驱动的约束。
- **对抗其他阵营或激情**：甚至是同一角色所持有的。这通常用于阵营与激情冲突，或者两个激情相互冲突的情况。例如，个人爱慕可能要求采取与誓言或忠诚相反的行动。此时，在阵营与激情之间，或者两个激情之间进行对抗掷骰，成功率更高的一方决定角色如何行动。
- **作为对某项事业的承诺、信仰和忠诚深度的通用衡量标准**：阵营或激情数值越高，角色就越投入。拥有相似阵营或激情的角色可以比较他们的等级，以确定谁表现出更深层的承诺。
- **抵御某种心理操纵或魔法支配**：在某些情况下，角色被迫执行违反其阵营或激情的行为，他们可以在对抗掷骰中用阵营或激情代替意志力。

如果角色持续无视其所选的道德和/或伦理，其阵营分数可能会在游戏过程中下降。如果分数低于角色的基础等级，它将转变为对立阵营，例如从善良变为中立或邪恶。游戏主持人应根据具体情况确定新的阵营和等级。阵营的改变可能导致失去访问职业能力的机会。详情请参阅相关的职业描述。

如果在游戏环节中情况允许，可以在《Classic Fantasy Imperative》中的任何时刻培养新的激情。如果某人做了强烈引发憎恨的事情，一个人可能会立即产生“憎恨某人”的激情。领主或首领号召宣誓时，一旦该誓言被作出或立下，就会立即建立“忠诚于某人”的激情——这是每个[职业](0003_Classes.md)中“阵营/誓言”部分进一步探讨的内容。

以这种方式在游戏中新发展的激情无需支付经验值，且会立即建立。当然，角色也可以选择在提升过程中建立激情，以支付经验掷骰的代价获得基础数值的激情：请参阅[文化与种族](0002_Culture_and_Races.md)章节中的各个阵营与激情部分。

## 加深与减弱

阵营、激情和誓言可以在游戏过程中独立于经验掷骰而增加，具体取决于触发增加事件的强度。同样，它们也可以并且确实会减弱。一个深信不疑的信念可能会受到许多事情的动摇，导致激情减弱，或者在更极端的情况下完全逆转。

例如，一个拥有“信任酋长”的角色，如果他的酋长行为背信弃义，可能会降低他的激情，或者以相同的百分比将其转变为“不信任酋长”。游戏主持人需要确定激情是减弱还是逆转。如果是减弱，那么它将根据导致变化的来源强度进行调整。

加深与减弱表显示了激情变化的程度。

| 激情深度 | 激情调整值 |
| :-- | :-- |
| 微弱 | 1d10 |
| 中等 | 1d10+5 |
| 强烈 | 1d10+10 |
