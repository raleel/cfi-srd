# 第四章：阵营与热情

在《经典奇幻要义》（_Classic Fantasy Imperative_）中使用阵营（Alignment）和热情（Passions）可以极大地帮助玩家和游戏主持（Games Master）深化角色的本质，根据角色的欲望或偏见引入情节钩子，并帮助玩家理解其角色是谁、驱动力是什么等等。虽然玩家在本章中选择的具体阵营和热情由其自行决定，但上一章中关于角色[职业](0003_Classes.md)的部分内容是游玩该角色所必需的。本文档中的任何职业都不要求特定的阵营或热情，但某些职业（如牧师和加入盗贼公会的游荡者）要求对其组织或公会立誓。在游戏机制方面，誓言（Oath）可以被视为一种热情。

---
## 阵营

所有角色都必须拥有一个阵营，该阵营由两部分组成：道德准则（Ethical Code）和伦理准则（Moral Code）。道德准则定义了对秩序与混乱的立场，而伦理准则决定了对善与恶的感受。角色随后为每一项选择一到两个定义要素，并确定起始百分比。例如，混乱（无组织且贪婪）55%，善良（乐于助人且慷慨）55%。你不能两次选择“中立”；相反，你应该忽略道德和伦理准则，选择“绝对中立”作为你的单一阵营。道德和伦理准则及其定义要素详述如下。

#### 道德准则

选择“守序”、“中立”或“混乱”之一，基础等级为 INT+POW+30。

- **守序**：选择一到两个最能描述你道德准则的定义要素：*遵守传统；精于计算；思想封闭；憎恶混乱；有道德；诚实；光荣；好评判；缺乏适应性；没有幽默感；服从合法权威；有组织；可预测；可靠；轻信；值得信赖；举止得体。*
- **中立**：选择一个最能描述你道德准则的定义要素：*认为秩序与混乱是偏见和危险的极端；谨慎；自负；在秩序与混乱方面没有强烈的感受；灵活；行动自由；没有既定的道德准则；务实；尊重自然。*
- **混乱**：选择一到两个最能描述你道德准则的定义要素：*举止恶劣；嗜血；好奇；愤世嫉俗；不诚实；不光荣；无组织；无视合法权威；利己主义；自由；憎恶秩序；不负责任；无法无天；狂妄自大；恶作剧者；易怒；狂暴；鲁莽；多疑；失控；不可信；不可预测；不可靠。*

#### 伦理准则

选择“善良”、“中立”或“邪恶”之一，基础等级为 INT+POW+30。

- **善良**：选择一到两个最能描述你伦理准则的定义要素：*令人钦佩；利他；天使般；威严；慷慨；对伤害无辜者感到愧疚；体面；宽恕；友好；憎恶邪恶；乐于助人；善良；热爱自然；仁慈；乐观；积极；素食主义。*
- **中立**：选择一个最能描述你伦理准则的定义要素：*认为善良与邪恶是偏见和危险的极端；谨慎；在善良与邪恶方面没有强烈的感受；灵活；行动自由；缺乏为了保护或帮助他人而做出牺牲的承诺；通过个人关系而非伦理准则对他人负责；没有既定的伦理准则；务实；很少寻求伙伴。*
- **邪恶**：选择一到两个最能描述你伦理准则的定义要素：*虐待；食人；贪婪；残忍；专横；喜欢伤害无辜者；贪婪；憎恶善良；色欲；操纵性；无情；骄傲；虐待狂；以自我为中心；自私；蓄奴；怀恨在心；虚荣；暴力。*

#### 绝对中立

绝对中立的起始基础等级为 INT+POW+30。

- **绝对中立**：或者，选择一到两个最能描述你既缺乏伦理准则又缺乏道德准则的定义要素：*矛盾；谨慎；通过个人关系对他人负责；灵活；行动自由；思想开明；务实；尊重自然；追求平衡。*

## 热情

热情用于帮助玩家和游戏主持深化角色的本质，根据角色的欲望或偏见引入情节钩子，并帮助玩家理解其角色是谁、驱动力是什么等等。

热情可以针对任何事物——一个人、一个组织、一个理想，甚至是一个物体。热情通常用动词描述，例如：渴望、鄙视、摧毁、信奉、恐惧、逃避、放弃、憎恨、热爱、忠诚于、保护、背弃、尊重、寻求、颠覆、折磨或维护。

热情的衡量方式与技能相同；它们的评级在 1 到 100（或更高）之间。热情可以像技能一样得到提升，也可以根据情况由游戏主持增加或减少。

初始角色最多可以拥有三个热情，每个热情基于两个特性，第一个加成 +40，第二个 +30，第三个 +20，由玩家决定重要性顺序。这些热情可以与文化、职业或个人弱点挂钩。例如，不信任（游荡者）；效忠女王；热爱家庭；击败混乱。正如下一章所详述，热情在许多角色职业中起着特别重要的作用。对于其中一些职业，保持最低水平的热情是保留职业特定特殊能力所必需的，在极端情况下，失去热情可能导致失去职业。

热情的起始值根据其类型而异；请参阅下方的[热情表](0004_Alignment_and_Passions.md?id=passion-table)。

本节仅详细说明热情的代表含义及其默认值。热情在游戏中的具体使用方法将在下文讨论。

##### 热情表

| 热情对象 | 起始百分比 |
| :-- | :-- |
| 浪漫或家庭背景下的人 | POW+CHA |
| 组织或群体 | POW+INT |
| 种族或物种 | 角色 POW x2 |
| 地点 | 角色 POW+INT |
| 物体或物质 | 角色 POW x2 |
| 性格特征 | 角色 POW+CHA |

## 使用阵营和热情

阵营或热情是任何具有影响游戏过程中事件能力的深层承诺。虽然它们可以作为独立的能力使用（称其为技能是对它们的一种贬低），但热情在下文进行了进一步扩展，以更详细地解释它们的工作原理以及它们如何影响《经典奇幻要义》中的角色和战役。

总之，阵营和热情可以这样使用：

- 增强其他技能，反映情感的深度及其如何驱动行动。在这种情况下使用时，如果增强在主题和戏剧上很重要，阵营或热情会将其值的 20% 添加到正在使用的技能中。
- 作为驱动选择、欲望以及情感行动和反应的能力。以这种方式使用时，会对阵营或热情进行标准掷骰，以确定角色对某事物的思考和感受有多强烈。如果掷骰成功，那么角色就会按照阵营或热情所决定的方式行事。如果掷骰失败，那么角色可以自由行动，而不受热情驱动力的束缚。
- 对抗其他阵营或热情——甚至是同一个角色持有的阵营或热情。这通常用于阵营与热情冲突，甚至两个热情发生冲突的情况。例如，个人情感可能会导致采取与誓言或忠诚相悖的行动。此时，在阵营和热情之间，或两个热情之间使用对抗掷骰，由更成功的一方决定角色的行为。
- 作为衡量对事业的承诺、信念和忠诚深度的一般指标。阵营或热情的值越高，角色就越投入。拥有相似阵营或热情的角色可以比较他们的等级，以确定谁表现出更深的承诺。
- 抵御某种形式的心理操纵或魔法控制。在某些情况下，当角色被迫执行与其阵营或热情相悖的行动时，他们可以用它们代替意志力（Willpower）进行对抗掷骰。

如果角色持续忽视其选择的道德和/或伦理，其阵营分数可能会在游戏过程中下降。如果它降至低于角色的基础等级，它将改变为对立的阵营，例如从善良变为中立或邪恶。游戏主持应根据情况确定新的阵营和等级。阵营的改变可能会导致失去对职业能力的访问权限。详情请参阅相关职业说明。

如果在《经典奇幻要义》游戏过程中情况允许，可以随时发展新的热情。某人可能在其他人做出强烈引发仇恨的行为时，立即产生“憎恨 X”。领主或首领呼吁立誓时，一旦该誓言被做出或宣誓，就会立即确立“效忠 X”的热情——这一内容在各[职业](0003_Classes.md)的阵营/誓言章节中会有更深入的探讨。

以这种方式在游戏过程中发展的新热情不需要消耗经验掷骰（Experience Rolls），而是即时确立的。当然，角色也可以选择在提升阶段建立热情，消耗一次经验掷骰以获得该热情的基准值：请参阅[文化与种族](0002_Culture_and_Races.md)章节中的各种阵营和热情部分。

## 加深与减弱

阵营、热情和誓言可以在游戏过程中独立于经验掷骰而增加，具体取决于触发增加事件的强度。此外，它们也可以并且确实会减弱。一个坚定的信念可能会因许多事情而动摇，导致该热情被削弱，或者在更极端的情况下，完全逆转。

例如，一个持有“信任首领”的角色，如果他的首领表现出背信弃义的行为，可能会减少他的热情，或者将其变为相同百分比的“不信任首领”。游戏主持需要确定热情是减弱还是逆转。如果减弱，则根据变化来源的强度进行调整。

“加深与减弱表”显示了热情变化的程度。

| :-- | :-- |
| 微弱 | 1d10 |
| 中等 | 1d10+5 |
