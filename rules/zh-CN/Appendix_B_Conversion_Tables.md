#### 英制单位与公制单位换算

为了使《经典奇幻：指令》(Classic Fantasy Imperative) 的呈现更加简洁、易读，并压缩说明和表格，本系列将专注于英制单位，而非同时使用英制和公制。选择英制单位是为了更好地促进现有资料的转化，因为该类型的其他游戏所使用的大多数冒险、战斗地图和地图均采用英制系统。然而，对于希望使用公制系统的玩家，我们已使用下表对最常用的度量衡进行了换算。由于我们通常处理的不是现实世界的生物、法术等，因此我们可以对为它们虚构的度量衡给予一定的余地。与其使用精确的换算，不如使用易于记忆的换算，从而更好地促进游戏进程。

#### 风速表

| 英里/小时 | 类型 | 对技能的影响 | 对移动的影响 |
| :-: | :-- | :-- | :-- |
| 0-10 | 无风 | 无 | 无 |
| 11-20 | 微风 | 无 | 无 |
| 21-30 | 强风 | 无 | 三分之二 |
| 31-40 | 轻烈风 | 困难 | 三分之二 |
| 41-50 | 中烈风 | 困难 | 一半 |
| 51-60 | 强烈风 | 艰巨 | 一半 |
| 60+ | 风暴/飓风 | 艰巨 | 三分之一 |

风，尤其是非常强劲的风，会对活动产生不利影响。风的强度（力量）以每小时英里数的速度表示。其对体能技能（涉及力量或敏捷的技能）的影响详见技能栏；对移动速率的影响详见移动速率栏。
 
_例如，40强度的轻烈风将人类的步行速度降低至三分之二，且技能判定难度为困难。_

#### 温度表

| 温度 (ºF) | 类型 | 风险 |
| :-: | :-: | :-- |
| < 2º | 冰川 | 寻求即时保暖 |
| 3-14º | 冰冻 | 15分钟 |
| 13-32º | 寒冷 | 每小时 |
| 33-50º | 凉爽 | 每天 |
| 51-68º | 凉快 | - |
| 69-86º | 温暖 | - |
| > 86º | 炎热 | 每小时 |

根据战役世界和场景设定的位置，温度会因气候、季节和海拔而发生巨大变化。上表提供了极端温度对角色影响的指南。

穿着合适的服装可使角色在暴露于环境前获得一段等同于其体质（体质）数值小时数的宽限期，如风险栏所示。在此之后，他们需要寻找庇护所，否则将开始遭受疲劳损失。全身潮湿的角色风险等级会向更冷的方向偏移一个档位。轻度或中度烈风也会使风险等级偏移一个档位，而强烈风和风暴则会使其偏移两个档位。
