#### 英制单位与公制单位换算

为了使《经典奇幻要旨》（*Classic Fantasy Imperative*）呈现得更整洁、更易于阅读，并精简描述与表格，《经典奇幻要旨》系列将侧重于使用英制单位，而非同时使用英制和公制。选择英制单位是为了更好地促进现有资料的转换，因为该类型游戏中其他作品所使用的大多数冒险、战术地图和地图都采用英制系统。然而，对于那些希望使用公制系统的人，最常用的重量和度量衡已使用下表进行了转换。由于我们通常处理的不是现实世界的生物、法术等，我们可以在为它们编造的重量和度量衡上给予一些回旋余地。与其使用精确的换算，不如使用易于记忆的换算，从而更好地促进游戏进行。

#### 风力表

| 英里/小时 | 类型 | 对技能的影响 | 对移动的影响 |
| :-: | :-- | :-- | :-- |
| 0-10 | 无风 | 无 | 无 |
| 11-20 | 和风 | 无 | 无 |
| 21-30 | 强风 | 无 | 三分之二 |
| 31-40 | 小疾风 | 困难 | 三分之二 |
| 41-50 | 中疾风 | 困难 | 一半 |
| 51-60 | 大疾风 | 艰巨 | 一半 |
| 60+ | 风暴/飓风 | 艰巨 | 三分之一 |

风，尤其是强风，会对活动产生不利影响。风的强度（力量）以每小时英里数表示。其对身体技能——涉及力量（力量）或敏捷（敏捷）的技能——的影响详见“技能”一栏；对移动速率的影响详见“移动速率”一栏。
 
_例如，40英里/小时的“小疾风”将人类的步行速度降低至三分之二，且技能掷骰难度为“困难”。_

| 13-32º | 寒冷 | 每小时 |
| 33-50º | 凉寒 | 每天 |
| 51-68º | 凉爽 | - |
| 69-86º | 温暖 | - |
| > 86º | 炎热 | 每小时 |

根据战役世界设定和场景地点，温度可能会因气候、季节和海拔高度而发生巨大变化。上表提供了极端温度对角色影响的指导方针。

穿着合适的衣服可以让角色获得一段等同于其体质（体质）数值（以小时计）的宽限期，之后才会出现风险，如“风险”一栏所示。在此之后，他们需要寻找避难所，否则将开始承受疲劳损失。被淋湿的角色其风险速率会向寒冷方向偏移一级。小疾风或中疾风也会使风险速率向寒冷方向偏移一级，而大疾风和风暴则会使其偏移两级。
