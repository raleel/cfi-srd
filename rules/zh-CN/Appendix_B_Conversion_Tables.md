# 附录：换算表

---
#### 英制单位与公制单位换算

为了使《经典奇幻要旨》（*Classic Fantasy Imperative*）的呈现更为简洁、易读，并精简描述与表格，《经典奇幻要旨》系列将专注于使用英制单位，而非同时使用英制与公制。选择英制是为了更方便地转换现有资料，因为该类型的大多数冒险、战斗地图和绘图都采用了英制系统。然而，对于希望使用公制系统的玩家，我们已使用下表对最常用的度量单位进行了换算。由于我们通常处理的不是现实世界的生物、法术等，因此我们可以在为它们编造度量衡时留有一定的余地。与其使用精确的换算，不如使用更易记忆的数值，从而更好地促进游戏进程。

#### 风力表

| 英里/小时 (MPH) | 类型 | 对技能的影响 | 对移动的影响 |
| :-: | :-- | :-- | :-- |
| 0-10 | 无风 | 无 | 无 |
| 11-20 | 和风 | 无 | 无 |
| 21-30 | 强风 | 无 | 三分之二 |
| 31-40 | 疾风 | 困难 | 三分之二 |
| 41-50 | 大风 | 困难 | 一半 |
| 51-60 | 烈风 | 艰巨 | 一半 |
| 60+ | 风暴/飓风 | 艰巨 | 三分之一 |

风力，尤其是极强的风力，会对活动产生不利影响。风的强度（STR）以每小时英里速度表示。其对身体技能（涉及力量 STR 或敏捷 DEX 的技能）的影响详见“对技能的影响”一栏；对移动速度的影响详见“对移动的影响”一栏。
 
_例如，STR 40 的疾风会使人类步行速度降低至三分之二，且技能判定难度为“困难”。_

#### 温度表

| 温度 (ºF) | 类型 | 风险 |
| :-: | :-: | :-- |
| < 2º | 冰川 | 立即寻求温暖 |
| 3-14º | 严寒 | 15 分钟 |
| 13-32º | 寒冷 | 每小时 |
| 33-50º | 阴冷 | 每天 |
| 51-68º | 凉爽 | - |
| 69-86º | 温暖 | - |
| > 86º | 炎热 | 每小时 |

温度会因气候、季节和海拔而发生巨大变化，具体取决于战役世界和场景设定的地点。上表提供了极端温度对角色影响的指南。

身着合适的服装可以让角色拥有以其体质（CON）数值为准的（小时数）缓冲时间，之后才会出现风险栏中所述的情况。在此之后，他们需要寻找庇护所，否则将开始承受疲劳损失。潮湿的角色风险等级会向更冷的方向偏移一级。轻度或中度疾风也会使风险等级向更冷的方向偏移一级，而烈风和风暴则会使其偏移两级。
