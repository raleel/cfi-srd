# 附录：换算表

#### 英制与公制单位换算

为了使《经典奇幻要点》（*Classic Fantasy Imperative*）呈现更清晰、更易于阅读，并精简描述和表格，《经典奇幻要点》系列将专注于英制单位，而非同时使用英制和公制。选择英制是为了更好地转换现有资料，因为该类型游戏中大多数冒险、战斗地图和绘图都使用英制系统。然而，对于希望使用公制系统的读者，最常用的重量和度量单位已通过下表进行了转换。由于我们通常处理的不是现实世界的生物、法术等，因此我们可以在为它们设定的重量和度量上给予一点余地。与其使用精确的换算，不如使用易于记忆的换算，从而更好地促进游戏进程。

#### 风力表

| 英里/小时 | 类型 | 对技能的影响 | 对移动的影响 |
| :-: | :-- | :-- | :-- |
| 0-10 | 无风 | 无 | 无 |
| 11-20 | 和风 | 无 | 无 |
| 21-30 | 强风 | 无 | 三分之二 |
| 31-40 | 轻微大风 | 困难 | 三分之二 |
| 41-50 | 中度大风 | 困难 | 一半 |
| 51-60 | 强劲大风 | 艰巨 | 一半 |
| 60+ | 风暴/飓风 | 艰巨 | 三分之一 |

风，尤其是强风，会对活动产生不利影响。风的强度（STR）以每小时英里速度表示。其对身体技能（涉及STR或DEX的技能）的影响在“技能”栏中详细说明；对移动速度的影响在“移动速度”栏中说明。
 
_例如，STR 40的轻微大风会将人类的行走速度降低到三分之二，且技能判定为困难难度。_

#### 温度表

| 温度 (ºF) | 类型 | 风险 |
| :-: | :-: | :-- |
| < 2º | 冰川 | 立即寻求温暖 |
| 3-14º | 结冰 | 15分钟 |
| 13-32º | 寒冷 | 每小时 |
| 33-50º | 凉爽 | 每日 |
| 51-68º | 舒适 | - |
| 69-86º | 温暖 | - |
| > 86º | 炎热 | 每小时 |

根据战役世界和场景设置的位置，气温会因气候、季节和海拔高度而发生巨大变化。上表提供了极端温度对角色影响的指导方针。

穿着合适的衣服可以让角色在暴露于极端环境前获得一段等同于其CON数值（以小时计）的宽限期，如“风险”栏所示。超过此时间点，他们需要寻求庇护，否则将开始承受疲劳损失。潮湿的角色会将风险等级向寒冷方向提升一级。轻微或中度的大风也会将风险等级向寒冷方向提升一级，而强劲的大风和风暴则会提升两级。
