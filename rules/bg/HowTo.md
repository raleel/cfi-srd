# Предпоставки

1. Базово разбиране на [езика markdown](https://www.markdownguide.org/basic-syntax/).

2. Ще трябва да създадете безплатен акаунт в [GitHub](https://github.com/), ако нямате такъв. Препоръчваме ви да използвате името на вашата ролева игра, тъй като то ще стане част от URL адреса, който хората ще използват за достъп до вашия SRD.

3. Можете да извършите целия процес през браузъра, без да знаете git. Въпреки това, научаването на GitHub Desktop ще ви позволи да тествате всякакви промени локално, преди да ги публикувате на живо за целия свят.

> Ако имате регистриран домейн, можете да го използвате в този процес, за да създадете SRD, подобно на това, което направих на https://srd.7thextinctionrpg.com

# Процесът

## Създаване на хранилище (Repository) в Github

1. Влезте в Github

2. Отидете до публичния шаблон https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Кликнете върху "Use this template"

![Step3](/_media/Step3.png)

4. Изберете "Create a new repository"

5. Въведете име на хранилището

![Step5](/_media/Step5.png)

6. Изберете 'Private'

7. Изберете 'Create repository'

Ще отнеме 5-30 секунди за копиране на шаблона, след което ще имате собствено копие.

8. Уверете се, че имате файла ".nojekyll" – това е празен файл, който е необходим при хостване на уебсайт в Github, в противен случай SRD няма да се показва правилно. *(Указва на GitHub Pages да не прекарва публикуваните файлове през Jekyll).*


## Добавяне на вашето съдържание

### *.md файлове

.md файловете са markdown файлове; Markdown е лек език за маркиране, който можете да използвате, за да добавяте елементи за форматиране към текстови документи с обикновен текст. В зависимост от обема на вашето съдържание, можете или да поставите цялата информация за играта си в един *.md файл, или, както направих аз в [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), да създадете отделни файлове за всяка глава. "Sample.md" предоставя някои примери за форматиране.

Езикът Markdown е много лесен за научаване; използвайте връзката, предоставена в точка 2 под "Предпоставки" по-горе, за пълен списък със синтаксиса.

### _sidebar.md

Това е вашето меню, навигационен панел от лявата страна на уебсайта. След като добавите markdown файл към вашето хранилище, трябва да добавите файла тук, така че съдържанието му да бъде включено. Следвайте съществуващото форматиране.


## Активиране на Github Pages за превръщане на хранилището в уебсайт

1. Във вашето хранилище кликнете върху 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. Изберете 'Pages' от менюто от лявата страна

![Website-Step2](/_media/Website-Step2.png)

3. Ако не сте направили хранилището 'public', имате два избора:
    a. Направете хранилището публично, което ще ви позволи да използвате Github pages, за да хоствате своя SRD уебсайт безплатно
    b. Надстройте своя Github акаунт (към момента на писане на това, струва $4 на месец или $48 годишна такса)

4. Под 'Branch' изберете 'main' и кликнете Save

5. Изчакайте 10-20 секунди, след което опреснете страницата

6. Вече ще виждате своя URL адрес, например https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## Използване на плъгин Fontawesome и/или Material Icons за показване на безплатни икони във вашия SRD

### Fontawesome

Използвайте Fontawesome, за да получите безплатни икони и анимирани икони. Абонираните потребители могат да използват Pro Icons.

1. Намерете иконата в [Fontawesome](https://fontawesome.com/icons)
2. Изберете иконата
3. В изскачащия прозорец, под раздела HTML копирайте всичко между " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Поставете копирания текст между `:` без интервали

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Използвайте Material Icons за още безплатни икони.

1. Намерете иконите в [Material Icons](https://fonts.google.com/icons)
2. Копирайте и поставете уеб span връзката директно във вашите markdown файлове

```markup
<span class="material-icons">face</span>
```
