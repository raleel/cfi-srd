# Передумови

1. Базове розуміння [мови розмітки markdown](https://www.markdownguide.org/basic-syntax/).

2. Вам потрібно буде створити безкоштовний обліковий запис на [github](https://github.com/), якщо у вас його немає. Рекомендую використовувати назву вашої RPG, оскільки вона стане частиною URL-адреси, яку люди використовуватимуть для доступу до вашого SRD.

3. Ви можете виконати весь цей процес через браузер, не знаючи git. Хоча вивчення Github Desktop дозволить вам тестувати будь-які зміни локально, перш ніж оприлюднювати їх для всього світу.

> Якщо у вас є зареєстроване доменне ім'я, ви можете використати його разом із цим процесом для створення SRD, як це зробив я: https://srd.7thextinctionrpg.com

# Процес

## Створення репозиторію на Github

1. Увійдіть до Github

2. Перейдіть до публічного шаблону https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Натисніть "Use this template" (Використати цей шаблон)

![Step3](/_media/Step3.png)

4. Виберіть "Create a new repository" (Створити новий репозиторій)

5. Введіть назву репозиторію

![Step5](/_media/Step5.png)

6. Виберіть "Private" (Приватний)

7. Виберіть "Create repository" (Створити репозиторій)

Копіювання шаблону займе 5-30 секунд, після чого у вас буде власна копія.

8. Переконайтеся, що у вас є файл ".nojekyll". Це порожній файл, необхідний при розміщенні веб-сайту на Github, інакше SRD не відображатиметься належним чином. *(Повідомляє GitHub Pages не обробляти опубліковані файли через Jekyll).*


## Додавання вашого контенту

### Файли *.md

Файли .md — це файли markdown. Markdown — це полегшена мова розмітки, яку можна використовувати для додавання елементів форматування до документів із звичайним текстом. Залежно від обсягу вашого контенту, ви можете розмістити всю інформацію про гру в одному файлі *.md або, як я зробив на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), створити окремі файли для кожного розділу. Файл "sample.md" містить кілька прикладів форматування.

Мову Markdown дуже легко вивчити. Використовуйте посилання, надане в пункті 2 розділу "Передумови" вище, щоб отримати повний список синтаксису.

### _Sidebar.md

Це ваше меню, навігаційна панель у лівій частині веб-сайту. Після того, як ви додали файл markdown до свого репозиторію, вам потрібно додати файл сюди, щоб його вміст було включено. Дотримуйтесь існуючого форматування.


## Увімкнення Github Pages для перетворення репозиторію на веб-сайт

1. У своєму репозиторії натисніть "Settings" (Налаштування)

![Website-Step1](/_media/Website-Step1.png)

2. Виберіть "Pages" у меню зліва

![Website-Step2](/_media/Website-Step2.png)

3. Якщо ви не зробили репозиторій "публічним", у вас є два варіанти:
    a. Зробити репозиторій публічним, що дозволить вам використовувати Github Pages для безкоштовного розміщення вашого сайту SRD
    b. Оновити свій обліковий запис Github (на момент написання цього тексту це коштує 4 долари на місяць або 48 доларів на рік)

4. У розділі "Branch" виберіть "main" і натисніть "save" (зберегти)

5. Зачекайте 10-20 секунд, а потім оновіть сторінку

6. Тепер ви побачите свою URL-адресу, наприклад https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## Використання плагіна Fontawesome та/або Material Icons для відображення безкоштовних ікон у вашому SRD

### Fontawesome

Використовуйте Fontawesome, щоб отримати безкоштовні іконки та анімовані іконки. Користувачі з підпискою можуть використовувати Pro Icons.

1. Знайдіть іконку на [Fontawesome](https://fontawesome.com/icons)
2. Виберіть іконку
3. У спливаючому вікні на вкладці HTML скопіюйте все, що знаходиться між " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Вставте скопійований текст між `:` без пробілів

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Використовуйте Material Icons для отримання інших безкоштовних іконок.

1. Знайдіть іконки на [Material Icons](https://fonts.google.com/icons)
2. Скопіюйте та вставте посилання на веб-span безпосередньо у ваші файли markdown

```markup
<span class="material-icons">face</span>
```
