## Описи заклинань

---
#### Оцінка

(Дивінація)

| | |
| :-- | :-- |
| **Ранг:** Маг 0 | **Час створення:** 1 хід |
| **Сфера:** Відсутня | **Тривалість:** Миттєво |
| **Вартість:** 1 | **Дальність:** Дотик |
| **Область:** 1 предмет | **Опір:** Відсутній |

Оцінка дозволяє негайно визначити якість фізичних товарів з сумарною місткістю (ENC) у «речах» або розміром (SIZ), що дорівнює силі (POW) заклинателя. Заклинання визначає, чи є візуально однакові предмети однаковими або схожими за якістю, або чи є один або кілька з них бракованими чи вищої якості. Заклинання не працює на органічні об’єкти, лише на неживі предмети. Воно також не визначає, які саме недоліки або покращення присутні, лише те, що вони є. Воно марне для ідентифікації чи виявлення магії.

#### Обладунок

(Кон'юрація)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час створення:** 1 раунд |
| **Сфера:** Відсутня | **Тривалість:** Див. нижче |
| **Вартість:** 3 + 1/інтенсивність | **Дальність:** Дотик |
| **Область:** 1 ціль | **Опір:** Відсутній |

При накладанні цього заклинання об’єкт отримує невидиме поле магічної сили, захист якого дорівнює лускатому обладунку, надаючи 4 очки захисту кожній зоні влучання. Воно не має ефекту, якщо накладене на когось, хто вже носить обладунок. Проте воно витісняє природний захист на час своєї дії, якщо пропонує кращий захист. Якщо накладене на істоту, що має більше ніж 4 очки природного захисту, воно збільшить кількість очок захисту на 1 у всіх зонах. Цей магічний захист не заважає руху чи накладанню заклинань. Заклинання діятиме до розвіювання магією або доки заклинатель не отримає 8 очок пошкоджень від однієї атаки, +1 за кожен рівень додаткової інтенсивності (див. таблицю нижче). Звісно, заклинатель може вирішити припинити дію заклинання в будь-який час, що необхідно зробити перед сном.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | 4 очки захисту; триває до отримання 8 пошкоджень від 1 атаки |
| 2 | 4 | 4 очки захисту; триває до отримання 9 пошкоджень від 1 атаки |
| 3 | 5 | 4 очки захисту; триває до отримання 10 пошкоджень від 1 атаки |
| 4 | 6 | 4 очки захисту; триває до отримання 11 пошкоджень від 1 атаки |
| +1 | +1 | Продовження прогресії |

#### Астральна подорож

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 5, Маг 5 | **Час створення:** 2 дії |
| **Сфера:** Астральна | **Тривалість:** Див. нижче |
| **Вартість:** 3 + 1/додаткова інтенсивність | **Дальність:** Дотик |
| **Область:** Див. нижче | **Опір:** Н/З |

Це заклинання дозволяє заклинателю і ще до п’яти іншим (один на кожен додатковий рівень інтенсивності) увійти в Астральну площину. Усі повинні торкатися один одного, утворюючи коло під час накладання заклинання. Тіла подорожуючих залишаються в площині походження, і вони зазвичай не беруть з собою одяг чи обладнання, окрім тих, що самі випромінюють магічну ауру; ці предмети перетворюються на астральні еквіваленти своєї звичайної форми. Тривалість заклинання діє доти, доки заклинатель не забажає його припинити. Однак його можна передчасно завершити зовнішньою силою, наприклад, Розвіюванням магії. Вбивство фізичного тіла заклинателя також достроково завершує заклинання, хоча це має прикрий побічний ефект — залишає всіх подорожуючих, які супроводжують заклинателя, у пастці.

#### Віщування

(Дивінація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 2 | **Час створення:** 2 хвилини |
| **Сфера:** Дивінація | **Тривалість:** Миттєво |
| **Вартість:** 3/інтенсивність | **Дальність:** 60 футів |
| **Область:** Заклинатель | **Опір:** Н/З |

Це заклинання дозволяє заклинателю визначити, чи буде певна дія, здійснена протягом наступних 30 хвилин, корисною чи шкідливою для благополуччя особи та/або групи. Для розпізнавання знамень потрібна фокусна точка певного типу, найчастіше це кігті чи менші кістки дракона, перлина або чисте золото вартістю не менше 100 золотих монет, які були подрібнені або переплавлені. Заклинання має максимальну інтенсивність 4. Цей кидок має здійснювати Майстер Гри, оскільки заклинатель ніколи не повинен знати напевно, чи були результати інтерпретовані правильно.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | Кидок навичку Каналізації (складно) |
| 2 | 6 | Кидок навичку Каналізації (важко) |
| 3 | 9 | Кидок навичку Каналізації (стандартно) |
| 4 | 12 | Кидок навичку Каналізації (легко) |

Якщо кидок віщування успішний, він дає один з наступних результатів:

| Віщування | Наслідок | 
| :-: | :-- |
| Так | Дія буде корисною |
| Ні | Дія буде шкідливою |
| Так і ні | Дія буде як корисною, так і шкідливою |
| Нічого | Дія не буде ні корисною, ні шкідливою |

У разі невдачі (Fumble) Майстер Гри повинен повідомити протилежне реальності.

(Зачарування (Чарівність))

Затьмарення викликає плутанину в розумі тілесної цілі. Суб’єкт заклинання має труднощі з логічним мисленням, забуваючи, де він знаходиться, що робить і чому — часто занурюючись у хаотичний потік думок. Затьмарені цілі все ще можуть діяти для самозахисту, але не можуть ініціювати жодної конструктивної діяльності до закінчення дії заклинання. Будь-яка атака чи загрозлива дія миттєво розриває заклинання, незалежно від того, чи була вона спрямована саме на затьмарену ціль.

#### Бар’єр лез

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 4 | **Час створення:** 2 дії |
| **Сфера:** Охорона, Створення | **Тривалість:** 3 раунди/інтенсивність |
| **Вартість:** 3+1/додаткова інтенсивність | **Дальність:** 100 футів |
| **Область:** 5-30 футів радіусу | **Опір:** Див. нижче |

Це заклинання створює бар’єр із вихором ножів, кинджалів та лез, що січуть навколо фіксованої точки і завдають 1d8 очок пошкоджень 1d4+2 випадковим зонам влучання будь-кому, хто проходить крізь область ефекту. Обладунок пропонує лише половину свого звичайного захисту. Магічні очки захисту зменшують пошкодження як зазвичай. Оскільки зброя обертається з шаленою швидкістю і щільно упакована, неможливо парирувати або ухилитися від неї. Можна використовувати щит для пасивного блокування зон влучання як зазвичай. У цьому випадку не забудьте порівняти нанесені пошкодження з захистом і очками здоров’я щита.

Заклинання можна накласти оборонно для захисту клірика або союзників, або наступально, щоб упіймати ворогів у пастку. Проте вороги, оточені в межах п’яти футів від краю бар’єру, коли він формується, можуть зробити кидок на Ухилення, щоб втекти. Незалежно від успіху, супротивник опиняється лежачим прямо за межами області ефекту. Успішний кидок призводить до відсутності пошкоджень; інакше вони зазнають повного ефекту.

(Кон'юрація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 1 | **Час створення:** 1 раунд |
| **Сфера:** Все | **Тривалість:** 5 хвилин |
| **Вартість:** 1 | **Дальність:** 180 футів |

Коли це заклинання накладено, клірик благословляє групу союзників у межах області ефекту. Впливові особи випромінюють світогляд заклинателя, або Добро, або Зло. Не існує благословень Нейтралітету. #### Палаючі руки

| | |
| :-- | :-- |

Це заклинання викликає полум’я, що виривається з рук заклинателя 120-градусною дугою. Оскільки більші істоти, як правило, більші за область ефекту заклинання, у них буде менше вражених зон. Майстри Гри повинні коригувати ці зони залежно від форми цілі та її положення щодо заклинателя. Палаючі руки мають шанс підпалити займисті матеріали, що дорівнює отриманому пошкодженню x5%. #### Ланцюгова блискавка

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час створення:** 2 дії |
| **Сфера:** Відсутня | **Тривалість:** Миттєво |
| **Вартість:** 3+1/додаткова інтенсивність | **Дальність:** 50 футів/інтенсивність |
| **Область:** Див. нижче | **Опір:** Ухилення |

Після накладання маг випускає з кінчиків пальців п’ятифутовий струм електрики, який може вразити одну ціль у межах дальності на 1d6+1 очок пошкоджень за кожні 2 інтенсивності. Потім блискавка перестрибує на наступний найближчий об’єкт або істоту, які отримують раніше кинуті пошкодження мінус 1 очко, потім перестрибує на наступну, завдаючи кинуті пошкодження мінус 2 очки, і так далі. Вона може навіть перестрибнути назад на союзника або самого заклинателя! Хоча початкова ціль має бути видимою для заклинателя, цілі, уражені блискавкою, що перестрибує, можуть і не бути видимими.

Кожна дуга має власну дальність 50 футів, що може вивести блискавку за межі початкової дальності. Ланцюгова блискавка продовжує бити, якщо має залишок пошкоджень, доки не влучить в об’єкт, що заземлює її (металева клітка, ґрати, велика калюжа води тощо), або поки не залишиться інших об’єктів чи істот для удару.

Кожна уражена істота отримує пошкодження в одну зону влучання, причому ношений обладунок не пропонує жодного захисту, а природний захист і магічні очки захисту зменшують пошкодження як зазвичай.

З успішним кидком на Ухилення (лягаючи на землю) жертва не отримує пошкоджень. Той, хто має здатність «Майстерний ухилянт», може ухилитися без падіння, але успіх у цьому випадку лише зменшує пошкодження вдвічі.

Блискавка має шанс підпалити займисті матеріали, що дорівнює отриманому пошкодженню x1%. Дивіться розділ про [Пожежі](0007_Game_System.md?id=fire-based-attacks) для додаткової інформації. Блискавка також може розбити або знищити неживі предмети від чистого удару.

| :-: | :-: | :-- |
| 1 | 3 | 50 футів; 1d6+1 пошкодження |
| 2 | 4 | 100 футів; 1d6+1 пошкодження |
| 3 | 5 | 150 футів; 2d6+2 пошкодження |
| 4 | 6 | 200 футів; 2d6+2 пошкодження |
| 5 | 7 | 250 футів; 3d6+3 пошкодження |
| +1 | +1 | Продовження прогресії |

Коли це заклинання накладено, клірик може вимовити наказ з одного слова одній живій істоті розміром SIZ 1-20, і на наступному ходу суб’єкт виконає наказ, якщо не зможе чинити опір. Сам наказ не може спричинити жодного реального пошкодження цілі; проте пошкодження може виникнути як вторинний ефект.

Наприклад, наказ «померти» призведе до того, що жертва впаде в смертеподібний стан на 1 раунд, не завдаючи жодних реальних пошкоджень; проте наказ «впасти», даний істоті, що лізе на 100-футову скелю, може виявитися смертельним.

Суб’єкт наказу повинен розуміти мову заклинателя і має право на перевірку Сили волі для опору.

**Деякі приклади наказів**

- **Повзти:** Суб’єкт падає на живіт і починає повзти.
- **Померти:** Суб’єкт падає на живіт у коматозний смертеподібний стан.
- **Впасти:** Суб’єкт падає на живіт.
- **Незграбність:** Суб’єкт провалює фізичну дію, яку збирався виконати.
- **Сон:** Суб’єкт засинає.
- **Втекти:** Суб’єкт повертається і тікає від заклинателя.
- **Літати:** Суб’єкт махає руками і бігає колами.
- **Йти:** Суб’єкт починає йти у напрямку, куди дивився.
- **Зупинитися:** Суб’єкт негайно зупиняється і стоїть на місці.
- **Залишити:** Суб’єкт повертається і йде тією дорогою, якою прийшов.
- **Відпочити:** Суб’єкт сідає і переводить подих.
- **Бігти:** Суб’єкт починає бігти.
- **Кричати:** Суб’єкт кричить.
- **Тонути:** Суб’єкт припиняє плавати.
- **Здатися:** Суб’єкт кидає зброю і припиняє бойові дії.

Це заклинання створює кулю світла, еквівалентну за яскравістю повному денному світлу, у точці на вибір заклинателя. Воно напівпостійне і тимчасово нейтралізується входом в область магічної темряви. Зір може бути відновлений лише накладанням «Вилікування сліпоти та глухоти» або «Розвіюванням магії» з інтенсивністю вищою за Вічне світло. Ефекти заклинання нерухомі, але його можна накласти на портативний або рухомий об’єкт.
