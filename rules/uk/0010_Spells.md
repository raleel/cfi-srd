## Описи заклинань

---
#### Оцінка

(Дивінація)

| | |
| :-- | :-- |
| **Ранг:** Маг 0 | **Час накладання:** 1 хід |
| **Сфера:** Відсутня | **Тривалість:** Миттєва |
| **Вартість:** 1 | **Дистанція:** Дотик |
| **Область:** 1 предмет | **Опір:** Немає |

Оцінка дозволяє миттєво визначити якість фізичних товарів із сукупною вартістю в «речах» або розміром (SIZ), що дорівнює POW заклинателя. Заклинання визначає, чи є однаково виглядаючі предмети однаковою або схожою якістю, або чи є один чи більше з них дефектними чи вищої якості. Заклинання не діє на органічні речі, лише на неживі об'єкти. Воно також не визначає, які саме дефекти чи покращення присутні; лише те, що вони існують. Воно не приносить користі у виявленні або детекції магії.

---
#### Обладунок

(Конжурація)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 раунд |
| **Сфера:** Відсутня | **Тривалість:** Див. нижче |
| **Вартість:** 3 + 1/Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Немає |

Коли накладається це заклинання, суб'єкт отримує невидиме поле магічної сили, еквівалентне захисту лускатого обладунку, що надає 4 пункти захисту (Armor Points) кожній частині тіла. Воно не має ефекту, якщо накладено на того, хто вже носить обладунок. Проте воно витісняє природний захист на час своєї дії, якщо пропонує кращий захист. Якщо накладено на істоту, що має більше 4 пунктів природного захисту, воно натомість збільшує пункти захисту на 1 у всіх місцях. Цей магічний захист не перешкоджає руху чи накладанню заклинань. Заклинання діятиме, поки його не розвіють магією, або поки заклинатель не отримає 8 пунктів шкоди від однієї атаки, +1 за кожен рівень додаткової Інтенсивності (див. таблицю нижче). Звісно, заклинатель може за бажанням скинути заклинання будь-коли, і повинен це зробити перед сном.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | 4 пункти захисту; діє до отримання 8 шкоди від 1 атаки |
| 2 | 4 | 4 пункти захисту; діє до отримання 9 шкоди від 1 атаки |
| 3 | 5 | 4 пункти захисту; діє до отримання 10 шкоди від 1 атаки |
| 4 | 6 | 4 пункти захисту; діє до отримання 11 шкоди від 1 атаки |
| +1 | +1 | Продовження прогресії |

#### Астральне заклинання

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 5, Маг 5 | **Час накладання:** 2 дії |
| **Сфера:** Астральна | **Тривалість:** Див. нижче |
| **Вартість:** 3 + 1/додаткова Інтенсивність | **Дистанція:** Дотик |
| **Область:** Див. нижче | **Опір:** Н/З |

Це заклинання дозволяє заклинателю і до п'яти іншим особам (одній на кожен додатковий рівень Інтенсивності) увійти в Астральну площину. Під час накладання заклинання всі повинні торкатися одне одного, утворюючи коло. Фізичні тіла мандрівників залишаються в початковій площині, і вони, як правило, не беруть із собою одяг або спорядження, за винятком того, що само по собі випромінює магічну ауру; ці предмети перетворюються на астральні аналоги. Тривалість заклинання триває, поки заклинатель не забажає її припинити. Однак його можна передчасно перервати зовнішньою силою, як-от «Розвіювання магії». Вбивство фізичного тіла заклинателя також достроково завершує заклинання, хоча це має прикрий побічний ефект — залишає мандрівників, що супроводжували заклинателя, без шляху назад.

#### Віщування

(Дивінація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 2 | **Час накладання:** 2 хвилини |
| **Сфера:** Дивінація | **Тривалість:** Миттєва |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 60 футів; |
| **Область:** Заклинатель | **Опір:** Н/З |

Це заклинання дозволяє заклинателю визначити, чи буде конкретна дія, яку потрібно вжити протягом наступних 30 хвилин, корисною чи шкідливою для добробуту особи та/або групи. Для розпізнавання знамень потрібна фокусна точка певного типу, найпоширенішими є кігті або дрібні кістки дракона, перлина або чисте золото вартістю не менше 100 золотих, які були подрібнені або розплавлені. Заклинання має максимальну інтенсивність 4. Цей кидок має здійснювати Майстер Гри, оскільки заклинатель ніколи не повинен знати напевно, чи були результати інтерпретовані правильно.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | Кидок навичок "Канал" зі складністю Фортифікований (Formidable) |
| 2 | 6 | Кидок навичок "Канал" зі складністю Важкий (Hard) |
| 3 | 9 | Кидок навичок "Канал" зі складністю Стандартний (Standard) |
| 4 | 12 | Кидок навичок "Канал" зі складністю Легкий (Easy) |

Якщо кидок на віщування успішний, він дає один із наступних результатів:

| Віщування | Значення |
| :-: | :-- |
| Так | Дія буде корисною |
| Ні | Дія буде шкідливою |
| Так і Ні | Дія буде і корисною, і шкідливою |
| Нічого | Дія не буде ні корисною, ні шкідливою |

Провал (Fumble) має призвести до того, що Майстер Гри повідомить протилежне до реальності.

Одурення спричиняє плутанину в розумі тілесної цілі. Суб'єкт заклинання має труднощі з мисленням, забуває, де він знаходиться, що робить і чому — часто впадаючи в розірвані ланцюжки думок. Одурені цілі все ще можуть діяти для самооборони, але не можуть ініціювати будь-яку конструктивну діяльність, поки заклинання не закінчиться. Будь-яка атака або загрозлива дія миттєво розриває заклинання, незалежно від того, була вона спрямована безпосередньо на одурену ціль чи ні.

#### Бар'єр лез

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 4 | **Час накладання:** 2 дії |
| **Сфера:** Вартовий, Створення | **Тривалість:** 3 раунди/Інтенсивність |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 100 футів |
| **Область:** радіус 5-30 футів | **Опір:** Див. нижче |

Це заклинання створює бар'єр із вируючих мечів, кинджалів і ножів, які обертаються і ріжуть навколо фіксованої точки та завдають 1d8 пунктів шкоди 1d4+2 випадковим частинам тіла *будь-кого*, хто проходить крізь область дії. Обладунок пропонує лише половину свого звичайного захисту. Магічні пункти захисту зменшують шкоду як зазвичай. Оскільки зброя вирує зі сліпучою швидкістю і щільно упакована, парирувати чи ухилитися від неї неможливо. Можна використовувати щит для пасивного блокування частин тіла як зазвичай. У цьому випадку не забудьте порівняти отриману шкоду із захистом і очками здоров'я щита.

Заклинання можна накласти оборонно, щоб захистити клірика або одного чи більше союзників, або наступально, щоб спіймати ворогів у пастку. Однак оточені вороги в межах п'яти футів від краю бар'єру в момент його формування можуть зробити кидок на ухилення, щоб втекти. Незалежно від успіху, опонент опиняється в положенні лежачи, прямо за межами області дії. Успішний кидок означає відсутність шкоди; в іншому випадку вони отримують повний ефект.

#### Ланцюгова блискавка

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 2 дії |
| **Сфера:** Відсутня | **Тривалість:** Миттєва |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 50 футів/Інтенсивність |
| **Область:** Див. нижче | **Опір:** Ухилення |

Після накладання маг випускає з кінчиків пальців п'ятифутовий промінь електрики, який може вдарити одну ціль у межах дистанції на 1d6+1 очок шкоди за кожні 2 пункти Інтенсивності. Потім блискавка перескакує на найближчий предмет або істоту, яка отримує попередньо кинуту шкоду мінус 1, потім перескакує на наступну найближчу, завдаючи шкоди мінус 2, і так далі. Вона може навіть перескочити назад на союзника або заклинателя! Хоча початкова ціль повинна бути видна заклинателю, цілі, уражені блискавкою, що перескакує, можуть бути і невидимими.

Кожна дуга має власну дистанцію 50 футів, що може вивести блискавку за межі початкової дистанції, коли заклинання було накладено. «Ланцюгова блискавка» продовжує бити, якщо має шкоду, доки не вдарить об'єкт, який призведе до заземлення (металева клітка або ґрати, велика калюжа води тощо), або доки більше немає об'єктів чи істот для удару.

Кожна уражена істота отримує шкоду в одну частину тіла, причому носимий обладунок не пропонує захисту, а природний захист і магічні пункти захисту зменшують шкоду як зазвичай.

З успішним кидком на ухилення, кидаючись на землю, жертва не отримує шкоди. Хтось зі здібністю «Спритний шахрай» може ухилитися, не падаючи на землю, але успіх у цьому випадку лише зменшує шкоду вдвічі, якщо вони не знаходяться в п'яти футах від краю області дії.

Блискавка має шанс підпалити вогненебезпечні матеріали, що дорівнює кинутій шкоді x1%. Див. розділ про [Пожежі](0007_Game_System.md?id=fire-based-attacks) для отримання додаткової інформації. Блискавка також може розбити або знищити неживі предмети від чистого удару.

| :-: | :-: | :-- |
| 1 | 3 | Дистанція 50 футів; 1d6+1 шкоди |
| 2 | 4 | Дистанція 100 футів; 1d6+1 шкоди |
| 3 | 5 | Дистанція 150 футів; 2d6+2 шкоди |
| 4 | 6 | Дистанція 200 футів; 2d6+2 шкоди |
| 5 | 7 | Дистанція 250 футів; 3d6+3 шкоди |
| +1 | +1 | Продовження прогресії |

(Евокація)

Заклинатель створює конус пекучого холоду, що виходить з його руки. Область дії — це дуга 90 градусів ("конус"), що простягається на 10 футів у довжину на кожен рівень Інтенсивності. Киньте шкоду один раз і застосуйте її до кожної частини тіла цілі, причому носимий обладунок пропонує лише половину захисту, але природний захист істоти або магічні пункти захисту зменшують шкоду як зазвичай. Хтось зі здібністю «Спритний шахрай» може ухилитися, не падаючи на землю, але успіх у цьому випадку лише зменшує шкоду вдвічі, якщо вони не знаходяться в п'яти футах від краю області дії. «Конус холоду» має шанс покрити жертву шаром льоду, що дорівнює кинутій шкоді (після модифікації) x5%. #### Просторова брама

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Час накладання:** 1 дія |
| **Сфера:** Відсутня | **Тривалість:** Миттєва |

«Просторова брама» — це форма короткодистанційної телепортації. Заклинатель миттєво стрибає на відстань до 100 футів на кожен рівень Інтенсивності, не перетинаючи проміжний простір, без жодного шансу на помилку. Усе фізично перенесене спорядження (нежива матерія) стрибає разом із заклинателем. Жива матерія SIZ не більше 20 може супроводжувати заклинателя. Наприклад, персонаж SIZ 11 може стрибнути разом із заклинателем, за умови, що обидва торкаються один одного. Заклинателю та будь-якій перенесеній живій істоті потрібен повний раунд для відновлення. Якщо під час цього часу вони будуть атаковані, такі індивіди можуть зробити не більше ніж захищатися.

(Аб'юрація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 2, Маг 2 | **Час накладання:** 2 дії |
| **Сфера:** Захист | **Тривалість:** Миттєва |

«Розвіювання магії» може бути накладено або проти конкретної цілі, або в зазначеній області, і після накладання вся магія в радіусі 15 футів від цільової точки стає вразливою до усунення. «Розвіювання магії» починається з найпотужнішої магії в області дії. Якщо воно не може усунути жодне заклинання (оскільки величина заклинання занадто висока), то заклинання закінчується, і жодна магія більше не може бути усунена.

«Розвіювання магії» можна використовувати оборонно для нейтралізації вхідних наступальних заклинань за допомогою реактивної дії «Контр-заклинання».

#### Зачарування предмета

(Зачарування)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** Див. нижче |
| **Сфера:** Відсутня | **Тривалість:** Див. нижче |
| **Вартість:** 3 + див. нижче | **Дистанція:** Дотик |
| **Область:** 1 предмет | **Опір:** Н/З |

Накладання цього заклинання готує предмет для Зачарування. Об'єкт має бути в гарному стані та найтоншої конструкції та виконання. Потрібна додаткова вартість щонайменше 100 золотих, щоб покрити витрати на додаткове інструментування, різьблення, вишивку, оздоблення коштовностями, гравіювання тощо. Нарешті, процес Зачарування вимагає лабораторії чи майстерні.

Під час накладання заклинання магічний користувач повинен торкатися предмета протягом усього часу накладання, що становить 1d8+2 дні. Це враховує періоди відпочинку та сну, протягом яких предмет повинен залишатися на відстані витягнутої руки від заклинателя. Протягом усього часу накладання магічний користувач не може накладати інше заклинання або виконувати будь-яку іншу форму магії. Порушення будь-якої з цих умов автоматично призведе до провалу заклинання.

Після успішного накладання предмет готовий до останнього кроку, коли магічний користувач вкладає в нього бажане заклинання. Для цього він повинен мати заклинання в пам'яті або на сувої та накласти його на предмет протягом 24 годин, інакше весь процес доведеться починати з нуля. Після початку накладання обраного заклинання процес може перевищувати вищезгадані 24 години. Наділення предмета обраним заклинанням коштує звичайну кількість магічних пунктів для бажаної Інтенсивності та займає 1d12 годин на кожен ранг заклинання. Протягом процесу наділення заклинатель повинен торкатися предмета або залишатися на відстані витягнутої руки під час періодів відпочинку, як зазначено вище, і наприкінці періоду накладання потрібен кидок на «Арканне накладання» для успішного наділення заклинання. Звичайні ступені успіху накладання заклинання дотримуються, проте щодо результату провалу, заклинання не може бути форсовано. Послідовні заклинання можуть бути наділені в предмет, за умови, що процес накладання розпочато протягом 24 годин після завершення попереднього заклинання. Це застосовується навіть у випадку попереднього невдалого заклинання. Кожне наступне заклинання потребує звичайну вартість накладання.

При використанні предмета кожне заклинання, що міститься всередині, може бути накладено лише один раз, проте кілька версій одного і того ж заклинання можуть бути наділені згідно з вищезазначеною процедурою. Також можливо наділити одне заклинання, після чого слідує накладання заклинання 4-го рангу «Постійність». У цьому випадку заклинання може бути накладено стільки разів, скільки бажано, дотримуючись обмежень, встановлених в описі заклинання «Постійність».

Це заклинання дозволяє заклинателю спробувати викликати фамільяра, який стає розширенням почуттів та сили свого господаря. Фамільяри можуть спілкуватися зі своїм господарем телепатично і є гарними вартовими та розвідниками. Смерть свого фамільяра становить певні ризики для магічного користувача через їхній тісний зв'язок, що робить наявність фамільяра небезпекою низького рангу.

Щоб викликати фамільяра, магічний користувач повинен почати ритуал, тримаючи жаровню, наповнену вугіллям, і коли воно розгорається, додати ладану на 100 золотих. З цими інгредієнтами, що горять, заклинатель повинен продовжувати ритуал, поки фамільяр не прибуде, або поки час накладання не закінчиться без успіху.

Навіть якщо це заклинання успішно накладено, шанс на те, що відповідний фаміляр відгукнеться на заклик магічного користувача, становить лише 50%, і магічний користувач може спробувати це заклинання лише раз на рік. Кожен додатковий рівень Інтенсивності понад перший подовжує дистанцію заклинання на пів милі, що, своєю чергою, збільшує ймовірність знаходження потенційного фамільяра на 5%, до максимуму 95%. Немає контролю над точним типом істоти, яка відгукнеться на заклик, але те, що прибуде, буде вірним слугою і союзником. Від самої істоти залежить, чи відгукнеться вона на заклик, тому перебування в регіоні, відомому мешканням певного типу істот, не гарантує заклинателю успіху.

Якщо істота відгукується на заклик заклинателя, магічний користувач все ще повинен принести в жертву 1 кидок досвіду, щоб створити духовний зв'язок між собою і фамільяром. Після цього ритуал завершено.

Поки фаміляр і його господар знаходяться в межах 120 футів один від одного, магічний користувач отримує здатність використовувати магічні пункти фамільяра також. Крім того, магічний користувач отримує телепатичний зв'язок з фамільяром та будь-які додаткові спеціальні здібності або бонуси до навичок, зазначені в таблицях нижче.

#### Вогняний щит

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Час накладання:** 2 дії |
| **Сфера:** Відсутня | **Тривалість:** 2 хвилини/Інтенсивність |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 0 |
| **Область:** Заклинатель | **Опір:** Н/З |

Це заклинання створює щит із розмитого полум'я, яке спалює заклинателя, але саме по собі не завдає шкоди. Замість цього полум'я захищає отримувача від або вогню, або холоду, залежно від того, який з двох варіантів знаходиться в пам'яті: «Холодний щит», який створює синє або зелене полум'я і захищає від спеки та шкоди на основі вогню; або «Теплий щит», який створює фіолетове або синє полум'я і захищає від шкоди на основі холоду та льоду. Колір полум'я слід визначати випадковим чином з 50% шансом на будь-який, оскільки той факт, що обидва типи можуть випромінювати синє полум'я, створює елемент невизначеності з боку будь-якого нападника. Рішення про те, який запам'ятати, приймається при підготовці заклинань, і обидва можуть бути запам'ятовані, якщо бажано. Це полум'я не дає тепла і випромінює світло лише з половиною яскравості смолоскипа. Специфіка кожного варіанта детально описана нижче.

- **Холодний щит:** Це полум'я прохолодне на дотик і зменшує будь-яку шкоду на основі вогню або спеки до половини від загальної. Успішний кидок на опірність нівелює всю шкоду. Кидок на опірність на один рівень легший, і у випадку ухилення не звалить захисника на землю.
- **Теплий щит:** Це полум'я тепле на дотик і зменшує будь-яку шкоду на основі холоду до половини від загальної. Успішний кидок на опірність нівелює всю шкоду. Кидок на опірність на один рівень легший, і у випадку ухилення не звалить захисника на землю.

Атаки ближнього бою проти отримувача будь-якого варіанта, будь то озброєні чи неозброєні, завдають звичайної шкоди, якщо не використовується один з елементів, від яких здійснюється захист. У цьому випадку заклинатель захищений від елементальної частини атаки, а нападник отримує шкоду, рівну завданій. Носимий обладунок нападника не пропонує захисту, але магічні пункти захисту або природний захист істоти зменшують шкоду як зазвичай. Істоти з вродженою магічною опірністю можуть розвіяти «Вогняний щит» при успішному кидку на Силу волі, коли отримувач вперше вражений. Якщо кидок на магічну опірність провалюється, опонент не може пізніше нівелювати «Вогняний щит».

#### Плоть у камінь (R)

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 2 дії |
| **Сфера:** Відсутня | **Тривалість:** Постійна |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 30 футів/Інтенсивність |
| **Область:** 1 ціль | **Опір:** Сила волі |

Коли накладено, одна жертва в межах дистанції має право на кидок на опірність Силою волі. Якщо невдало, вона та всі перенесені й одягнені речі повністю трансформуються в твердий камінь. Це перетворення не є смертю, а формою призупиненої анімації. Накладання або скасованої версії цього заклинання, або «Бажання» можна використовувати для повернення жертви до життя. Будь-яка шкода, якої жертва зазнає, будучи каменем, переноситься, набуваючи сили одразу після відновлення. Великі істоти (SIZ 21-40) менш схильні до цього заклинання, кидок на опірність — Легкий, а кидок на опірність для Величезних істот (SIZ 41+) — Дуже легкий.

Зворотний варіант цього заклинання, «Камінь у плоть», використовується для відновлення жертви, і жодного кидка на опірність не потрібно. Однак заклинання можна також скасувати, щоб трансформувати камінь, який ніколи раніше не був живим; використовуючи його в один з кількох творчих способів. Наприклад, стіну каменю розміром 10 кубічних футів на рівень Інтенсивності можна трансформувати в м'яку плоть, можна створити «тунель» із плоті завширшки до 3 футів і довжиною 10 футів на кожен рівень Інтенсивності, одну ціль, як-от кам'яну статую, можна трансформувати в тіло, і навіть кам'яного голема можна трансформувати в м'ясного голема за допомогою цього заклинання. Проте в останньому випадку кам'яний голем мав би право на кидок на Силу волі для опору як зазвичай. Камінь, перетворений на плоть таким чином, м'який і податливий, і хоча він зберігає свої фактичні очки здоров'я, він не володіє пунктами захисту, що полегшує його розрубування.

Це заклинання спричиняє незграбність усіх опонентів в області дії, роблячи будь-які кидки на фізичні навички на один рівень складнішими і спричиняючи всі провали, що призводять до незграбності. Навіть фізичні дії, які зазвичай не потребують кидка навички, такі як підняття впущеного предмета, швидший рух, ніж ходьба, або підйом по сходах, вимагають кидка на навичку «Атлетика». Провал у цьому випадку призводить до незграбності, і, як правило, незграбного падіння у випадку руху, або випадкового відкидання предмета далі при спробі його підняти. Майстер гри повинен творчо підходити до результатів кидка на незграбність; однак мало які з них мають бути відверто смертельними в небойових ситуаціях. У бою, однак, незграбність розглядається як будь-яка інша і може призвести до спеціальних ефектів як зазвичай.

Успішний кидок на опірність дозволяє жертві уникнути ефектів заклинання на поточний раунд; однак, якщо жертва все ще займає область дії наступного раунду, інший кидок на опірність повинен бути зроблений знову як зазвичай. Союзники початкового атакуючого також повинні залишатися поза межами області дії, інакше вони зазнають тих самих обмежень, що й їхні опоненти.

Це заклинання також може бути спрямоване на конкретну істоту, яка буде страждати від ефектів протягом усієї тривалості заклинання при невдалому кидку на опірність. Накладене таким чином, «Незграбність» не створює області дії. У цьому випадку успішний кидок на опірність призводить до того, що жертва страждає від ефектів заклинання 2-го рангу «Сповільнення».

Накладання «Брами» вимагає від заклинателя знання справжнього імені істоти, яку потрібно викликати, яка зазвичай є істотою з однієї з інших площин існування, наприклад, демоном або дияволом, ангелом, напівбогом або навіть богом. Після успішного накладання відкривається портал між площиною перебування заклинателя та площиною істоти. Накладання заклинання автоматично привертає увагу істоти, успішно чи ні. Якщо істота проходить кидок на опірність, вона, як правило, не прийде особисто, однак, припускаючи, що заклинання успішне, «щось» прийде крізь нього. Наступна таблиця використовується для визначення деяких звичайних істот, їхніх середніх показників Сили волі та типових слуг, яких відправили б на їхнє місце. Майстер гри вільний вибирати найкраще підходящий характер для природи поточної кампанії.

З накладанням «Зцілення» клірик може вилікувати фізичну недугу, ментальну травму або значну кількість шкоди одним дотиком. Фактичний ступінь цього відновлення базується на Інтенсивності заклинання наступним чином. На кожен рівень Інтенсивності заклинання зцілює суб'єкта від однієї хвороби будь-якого POT, лікує будь-яку сліпоту чи глухоту, нівелює ментальний розлад, викликаний травмою чи магією, або зцілює одну частину тіла до 12 пунктів шкоди. Однак воно не відновить відірвану кінцівку, оскільки це вимагає накладання заклинання «Регенерація», якщо кінцівка все ще присутня. Кожна додаткова Інтенсивність може бути використана для лікування іншої недуги або зцілення іншої частини тіла. Таким чином, для лікування особи, що страждає від опіків всього тіла, знадобилося б накладання з Інтенсивністю 7. На відміну від менш потужних заклинань зцілення, що обмежують свою ефективність проти довготривалих травм, заклинання не має обмежень щодо тривалості, протягом якої суб'єкт страждав від ефектів травми.

При зворотному варіанті, «Шкода», можна завдати 12 пунктів магічної травми одній з частин тіла жертви при невдалому кидку на опірність. Альтернативно, на них накладається недуга, ефекти якої такі ж, як у заклинання «Спричинення хвороби», зворотного варіанта «Зцілення хвороби», але при +20 POT. Кидок заклинателя на Канал функціонує як кидок для влучання в опонента і вважається частиною соматичної вимоги заклинання. Додатковий кидок для влучання не потрібен. Ні носимий, ні природний обладунок не пропонують жодного захисту, але магічні пункти захисту зменшують шкоду як зазвичай, і повністю блокують завдані недуги. Кожна додаткова Інтенсивність впливає на іншу частину тіла, суміжну з першою, з ефектами, визначеними початковим кидком на опірність. Жодна версія цього заклинання не діє на нежить, істот, яких можна вразити лише залізом, сріблом або магічною зброєю, або нематеріальних істот.

(Трансмутація)

| | |
| :-- | :-- |

Це заклинання може бути використане двома окремими способами, або для запалювання, або для гасіння. Вибір того, що робити, здійснюється під час накладання.

Запалювання працює лише на вогненебезпечній неорганічній матерії, змушуючи малий об'єкт або ділянку розміром з руку спалахнути. Це заклинання зазвичай використовується для запалювання свічок, смолоскипів або ліхтарів здалеку. Його також можна використовувати для розпалювання багаття для табору або приготування їжі в несприятливих умовах, наприклад, з використанням сирого хмизу або при сильному вітрі.

Гасіння негайно нівелює полум'я та невеликі вогні скромного розміру та спеки. Воно корисне для гасіння свічок, ліхтарів, смолоскипів або дрібних вогнів для готування, але не працюватиме на магічних або більших, більш лютих пожежах, як-от похоронні багаття, палаючі будинки або драконяче полум'я.

#### Ілюзія

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 дія |
| **Сфера:** Відсутня | **Тривалість:** Концентрація; Див. нижче |
| **Вартість:** 1/Інтенсивність | **Дистанція:** 100 футів/Інтенсивність |
| **Область:** радіус 50 футів/Інтенсивність | **Опір:** Невір'я |

Це заклинання створює візуальну ілюзію будь-чого, що бажає заклинатель. Воно не має ефекту на інші почуття, не створює звуку, запаху, температури чи текстури тощо.

Ця ілюзія може бути будь-чим, від відкритого лугу до стародавнього червоного дракона, якщо це поміщається в область дії заклинання. Ілюзія триватиме лише доти, доки заклинатель підтримує концентрацію, або доки опонент не торкнеться або не увійде в неї; це спричиняє розпад магії, що підтримує її, і розсіювання ілюзії. Однак заклинатель може підтримувати ілюзію після фізичного контакту, витрачаючи 1 магічний пункт і спрямовуючи її на відповідну реакцію на контакт, щоб не створити підозри. Наприклад, за звичайних обставин ілюзія огра зникла б при влучанні стрілою; однак заклинатель міг би змусити огра знизати плечима на удар і кинутися на атакуючого, витративши 1 магічний пункт. Слід зазначити, що справжня стріла не зупиняється ілюзією і може все ще вразити щось або когось за проявом.

Хоча ілюзія не може завдати жодної шкоди, ні створити температуру, розум може бути переконаний, що відчуває біль, страждаючи від ефектів травми, або відчуває екстремальні температури; проте об'єкти не виглядатимуть замерзлими або згорілими, якщо заклинатель не сконцентрується і на цих ефектах. Після того, як заклинання було накладено, додаткові візуальні ефекти можуть бути додані магічним користувачем за бажанням, концентруючись на бажаному ефекті. Це зазвичай не займає часу і може бути оброблено як «Вільна дія». Наприклад, якщо заклинатель бажав би, щоб кинутий ілюзорний смолоскип змусив сухе листя спалахнути, він міг би сконцентруватися як «Вільна дія», щоб зробити це.

#### Невидимість

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 дія |
| **Сфера:** Відсутня | **Тривалість:** 6 годин/Інтенсивність |
| **Вартість:** 3, +1/додаткова Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Н/З |

Коли накладено, суб'єкт і будь-яке перенесене спорядження зникають, стаючи невидимими для всіх форм звичайного зору. Це, однак, не робить індивіда невиявленим іншими засобами, як-от слух, дотик, нюх тощо, або природними здібностями, як-от «Відчуття життя» або «Сонар».

Ті, хто знаходиться під ефектом невидимості, залишаються такими протягом усієї тривалості (макс. 24 години), якщо заклинання не розвіяно або суб'єкт не зробить атаку, у такому випадку заклинання нівелюється, і індивід з'являється *після* атаки. Ціль вважатиметься під ефектами [Несподіванки](0008_Combat.md?id=surprise). Жодні інші дії негативно не впливають на тривалість заклинання, що дозволяє суб'єкту відчиняти двері, говорити, лазити, бігати, залізти в кишеню тощо. Навіть накладання заклинань не завершить тривалість, якщо вони не впливають негативно на одного або більше конкретних ворогів у бою. Багато з вищезгаданих дій можуть дозволити інші способи виявлення, наприклад, можлива перевірка Сприйняття, щоб почути, як хтось біжить повз, або відчути руку, що лізе в кишеню. Майстер гри призначить штрафи або бонуси тим, хто намагається виявлення, залежно від того, наскільки це помітно.

Проте атака, зроблена початковим отримувачем заклинання, робить усіх видимими знову. Див. основне заклинання [Невидимість](0010_Spells.md?id=invisibility) для отримання детальнішої інформації.

#### Магічна стріла

(Евокація)

| | |
| :-- | :-- |

Коли накладено, одна або більше стріл магічної енергії вилітають з кінчиків пальців магічного користувача і влучають у ціль. Максимальна кількість стріл, які можуть бути згенеровані, базується на рівні навички «Арканного накладання» заклинателя, причому друга стріла генерується при 60% навички, третя при 70%, четверта при 80% і п'ята, остання, при 90%. Див. таблицю нижче.

#### Магічні вуста

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 2 | **Час накладання:** 1 хвилина |
| **Сфера:** Відсутня | **Тривалість:** Див. нижче |
| **Вартість:** 3, +1/додаткова Інтенсивність | **Дистанція:** 30 футів |

Це заклинання створює вуста на предметі або об'єкті, які магічно з'являються при спрацюванні від конкретної події або часу, призначеного магічним користувачем під час першого накладання заклинання. Ці вуста потім проголосять будь-яку заздалегідь визначену фразу, обрану заклинателем під час накладання. Ця фраза повинна складатися не більше ніж із 25 слів і вимовляється вустами зі швидкістю приблизно 1 слово на секунду. Вуста не можуть вимовляти слова сили або накладати заклинання.

Це заклинання можна накласти на будь-який зазвичай неживий об'єкт, від стовпа або дерева до кам'яної стіни або скрині; проте воно особливо ефективне при накладанні на статую, оскільки статуя сама виглядала б так, ніби говорить. Його не можна накласти на будь-яку живу істоту з будь-якою формою інтелекту чи інстинкту. Це стосується і тих, хто був раніше живим. Під час накладання цього заклинання магічний користувач визначає ситуацію, яка активує зачарування. Воно може бути розроблене для спрацювання через будь-що, від вимовленого слова до виникнення будь-якого шуму. Це може бути загально як «коли наступна особа увійде в цю кімнату...» або специфічно, «коли жіночий клірик Седони підійде на 10 футів до статуї в кінці залу в суботу...». Ефект спрацювання не може бути чимось, що неможливо розпізнати немагічно, наприклад, невидима істота, світогляд істоти, навичка, клас тощо. Однак воно може вказувати на одяг. Максимальна дистанція, на якій можна спрацювати заклинання, становить 25 футів на Інтенсивність.

Тривалість дії цього заклинання постійна, поки зачарування не активовано, після чого заклинання закінчується.

Магічні фокуси — це чудова форма розваги серед простолюдинів, пригноблених, і особливо дітей. Деякі ефекти, що зазвичай створюються за допомогою магічних фокусів, включають пориви вітру, щоб мерехтіли свічки, витягування срібної монети з-за вуха дитини, змушування квітки швидко розквітнути, виконання карткових фокусів, створення моторошної ефірної музики, що виходить нізвідки тощо. Магічні фокуси не можуть завдати навіть одного пункту шкоди або будь-якої міри відволікання в бою, але можуть бути використані, щоб зайняти натовп, поки решта групи прокрадається повз.

#### Метеоритний дощ

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 5 | **Час накладання:** 2 дії |
| **Сфера:** Відсутня | **Тривалість:** Миттєва |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 20 футів/Інтенсивність |
| **Область:** Див. нижче | **Опір:** Ухилення |

Коли магічний користувач накладає це заклинання, два мікро-метеорити на кожен рівень Інтенсивності вилітають з витягнутої руки. Метеорити рухаються до своєї цілі по траєкторії вниз, залишаючи шлейф іскор і вугілля за собою. При ударі вони детонують у множинних вогняних вибухах навколо цільової точки. Перший метеорит завжди влучає в цільове місце, тоді як будь-які додаткові метеорити влучають випадковим чином навколо нього, кожен з радіусом вибуху 30 футів. Щоб визначити, куди вони влучають, киньте 1d8 для напрямку.

Кожен метеорит завдає 1d10 очок шкоди вогнем тим, хто перебуває в області дії. Однак через радіус кожного вибуху багато хто перекриватиметься, завдаючи додаткової шкоди тим, кому не пощастило потрапити під них. Кидки шкоди поєднуються і застосовуються до кожної частини тіла цілі, причому носимий обладунок не пропонує захисту, але магічні пункти захисту або природний захист істоти зменшують шкоду як зазвичай.

Успішний кидок на ухилення дозволяє жертві не отримати шкоди. Хтось зі здібністю «Спритний шахрай» має можливість ухилитися, не падаючи, але успіх у цьому випадку зменшить шкоду лише вдвічі, якщо вони не знаходяться в 5 футах від краю області дії.

Усі, включаючи тих, хто поза межами області дії, але в межах 60 футів від точки удару, зобов'язані досягти успіху в кидку на «Атлетику», щоб залишитися стояти.

«Метеоритний дощ» має шанс підпалити вогненебезпечні матеріали, що дорівнює кинутій шкоді x5%. Див. розділ про [Пожежі](0007_Game_System.md?id=fire-based-attacks) для отримання додаткової інформації.

#### Дзеркальний образ

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 2 | **Час накладання:** 1 дія |
| **Сфера:** Відсутня | **Тривалість:** 3 раунди/Інтенсивність |
| **Вартість:** 1/Інтенсивність | **Дистанція:** 0 |
| **Область:** радіус 5 футів | **Опір:** Н/З |

Коли накладено, 2d4 дублікатів магічного користувача з'являються в радіусі 5 футів, точно імітуючи рухи заклинателя. Крім того, вся область дії тремтить і мерехтить, роблячи точне місцезнаходження заклинателя неможливим для встановлення. Удар по одному з ілюзорних образів змушує його зникнути; проте інші образи залишаються неушкодженими. Удар по заклинателю не впливає на інші образи, і оскільки образи завжди зміщуються, немає способу дізнатися, чи є ціль справжнім заклинателем, якщо атакувати знову. Будь-які травми, завдані заклинателю, дублюються і на образах. Майстер гри може використовувати численні способи визначити, чи було вражено справжнього заклинателя чи одного з образів. Один із способів — визначити, скільки потенційних цілей доступно, включаючи заклинателя, і кинути кубик найближчого номіналу. Наприклад, з 4 образами і заклинателем, атакуючий повинен кинути 1d6, перекидаючи результат 6, причому заклинатель вражається на кидку 1. Інший — мати кілька маркерів, що дорівнюють кількості потенційних цілей, позначивши один як заклинателя. Маркер витягується кожного разу, коли здійснюється атака, і якщо ціль вражена, застосовується шкода; в іншому випадку образ зникає, видаляючи один із маркерів. Образи зникають після завершення тривалості заклинання.

#### Постійність

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 1 дія |
| **Сфера:** Відсутня | **Тривалість:** Постійна |
| **Вартість:** 3, +2 EXP | **Дистанція:** Див. нижче |
| **Область:** Див. нижче | **Опір:** Н/З |

Накладання цього заклинання змінює тривалість певних інших заклинань на «Постійну». Щоб використовувати це заклинання, магічний користувач спочатку накладе заклинання, яке має стати постійним. Однак після завершення накладання цього заклинання воно затримується, і витрачається додатковий Action Point на накладання «Постійності», після чого обране заклинання накладається у своїй постійній формі. Кожне заклинання, зроблене постійним, коштує заклинателю 2 кидки досвіду (EXP), а також зазначені 3 магічні пункти, на додаток до звичайної вартості накладання початкового заклинання. «Постійність» також є ключовим застосуванням при створенні магічних предметів за допомогою заклинання «Зачарування предмета». На додаток до заклинань, зазначених нижче, інші заклинання можуть бути зроблені постійними з дозволу Майстра гри.

Наступні персональні заклинання, ті, що впливають лише на заклинателя, отримають переваги від цього заклинання. Вони не можуть бути зроблені постійними на інших істотах:

| **Область:** 1 ціль | **Опір:** Сила волі |

Заклинатель може змінити форму однієї цільової тілесної істоти на іншу, причому кожен пункт Інтенсивності змінює SIZ на 5 пунктів. Отже, перетворення орка SIZ 16 у кролика SIZ 1 потребуватиме 3 рівнів Інтенсивності (15 пунктів SIZ різниці). Суб'єкт цього заклинання має право на кидок на опірність Силою волі. Великі істоти (SIZ 21-40) менш схильні до перетворення, їхній кидок на опірність — Легкий, а кидок на опірність для Величезних істот (SIZ 41+) — Дуже легкий.

Весь процес перетворення займає повний раунд і може бути досить стресовим для відповідної істоти, вимагаючи другого кидка на Силу волі для збереження особистості, невдалий кидок приголомшує суб'єкта на 1d10 хвилин, а провал (Fumble) призводить до смерті від ментального шоку. Кожне подвоєння або зменшення вдвічі початкового SIZ істоти робить кидок на Силу волі для збереження особистості на один рівень складнішим, як і повна зміна середовища, наприклад, зміна людини на рибу. Успішний кидок дозволяє жертві зберегти свої INT та CHA, а також будь-які навички, що вимагають цих характеристик.

Перетворення дарує отримувачу спосіб дихання assumed істоти, якщо він інший, ніж звичайний; будь-які природні атаки; і всі мирські способи руху. Воно не дарує жодних загострених або магічних здібностей, якими володіє істота. Наприклад, істота, яку перетворили на дракона, не отримає дихальної атаки чи заклинальних здібностей істоти, але отримає здатність літати, її жорстку шкуру, смертельний укус, атаки кігтями тощо. Крім того, жертва отримує фізичні навички нової форми, такі як Атлетика, Бrawn, Політ, Плавання, а також її очки здоров'я та модифікатор шкоди. Припускаючи, що перетворений індивід зберіг свою INT, він все ще втрачає здатність говорити, якщо нова форма не володіє здатністю чітко вимовляти слова. Ті, хто був здатний накладати заклинання в своїй попередній формі, все ще зможуть накладати їх у новій формі, припускаючи, що вони все ще мають здатність утворювати вербальні та соматичні компоненти. У випадку радикальної зміни, як-от перетворення з двоногого на чотириногого, або з наземної тварини на морську істоту, наприклад, Майстер гри має право штрафувати як мінімум на один рівень складності використання будь-яких навичок, доки не буде достатньо часу для практики та адаптації. Це особливо стосується фізичних навичок, таких як Атлетика, Беззбройний бій, Плавання, Політ, Бойові навички тощо.

Кидок на Силу волі для збереження особистості потрібен щодня, поки суб'єкт залишається трансформованим, до провалу, що змушує особу остаточно піддатися менталітету нової форми, причому INT змінюється на INS у випадку нерозумної істоти. Усі спеціальні та магічні здібності, що належать новій формі, які не були набуті раніше, такі як атаки поглядом, дихальні зброї тощо, тепер доступні істоті після завершення трансформації. Персонажі, які втрачають свою ідентичність таким чином, стають неігровими персонажами під контролем Майстра гри.

До того як ментально піддатися трансформації, поліморфна істота вразлива до «Розвіювання магії» як зазвичай, жодного кидка на опірність не потрібно, оскільки це буде підсвідоме бажання повернутися до нормального стану. Трансформація потребує ще одного кидка на Силу волі, щоб протистояти напрузі, причому провал приголомшує суб'єкта на 1d10 хвилин, а провал (Fumble) призводить до смерті від ментального шоку.

Якщо жертва раніше піддалася новій формі, «Розвіювання магії» все ще можна використовувати; проте жертва намагатиметься протистояти поверненню до природної форми за допомогою кидка на Силу волі. Провал цього кидка означає, що жертва перетворюється назад у природну форму, що, звісно, потребує ще одного кидка на Силу волі, щоб протистояти ментальному шоку від трансформації. Після втрати природна ідентичність жертви більше не досяжна; замість цього жертва вважає дивну і чужу форму природною і прагне повернутися до свого попереднього «нормального» стану. _Наприклад, орк, який був перетворений на кролика і прийняв ідентичність істоти, вважав би, що він тепер кролик, якого досить грубо перетворили на орка._ Лише «Бажання» або інша подібна магія має шанс відновити ідентичність жертви, як тільки вона була втрачена.

Усе носиме та перенесене спорядження магічно вливається в нову форму; проте в деяких випадках Майстер гри може дозволити магічним предметам, які можна було б використовувати в новій формі істоти, залишатися, як-от магічне кільце або чоботи. Зауважте, що це вимагає, щоб новий SIZ істоти не був значно відмінним від оригіналу. Існує шанс POW x1% для кожного носимого магічного предмета небойового характеру, за умови схвалення Майстром гри, перенести свої ефекти на нову форму істоти. Істота з кільцем захисту +1, наприклад, могла б отримати бонус +1 до свого природного захисту. Істоти з природною здатністю до зміни форми, такі як доппельгангер і лікантроп, будуть трансформовані як зазвичай, але можуть прийняти свою нормальну форму через 1 раунд. Якщо істота вбита, вона повертається до своєї природної форми, навіть якщо раніше втратила всі сліди ідентичності.

Заклинатель може прийняти форму будь-якої іншої тілесної істоти, від SIZ 1 до SIZ 40. Кожен пункт Інтенсивності дозволяє збільшення або зменшення до 10 пунктів SIZ. Отже, магічний користувач з SIZ 13 міг би прийняти форму SIZ 34 грізлі при 3 рівнях Інтенсивності. Процес трансформації займає повний раунд і дарує заклинателю форму дихання істоти (якщо іншу, ніж власну, наприклад, дихання водою), будь-які природні атаки, очки здоров'я, модифікатор шкоди та звичайний спосіб руху. Це не дарує жодних загострених або магічних здібностей, якими володіє істота. Магічний користувач, який перетворився на яструба, наприклад, не отримає надзвичайного зору птаха. Заклинатель отримує фізичні навички істоти, такі як Атлетика, Бrawn, Політ, Плавання тощо, але зберігає будь-які ментальні та соціальні навички (ті, що потребують INT та CHA). Заклинатель втрачає здатність говорити, якщо істота в питанні не володіє здатністю чітко вимовляти слова. Якщо так, заклинатель все ще може накладати заклинання в новій формі, припускаючи, що він може сформувати соматичні компоненти заклинання.

Заклинатель може закінчити ефект будь-коли, і в процесі всі легкі рани, отримані під час перебування в новій формі, втрачаються, а серйозні рани зменшуються до легких (половина втрачених очок здоров'я в кожній відповідній частині тіла). Тяжкі рани не впливають на трансформацію і переносяться на природну форму. При переході від природної форми до тваринної немає зцілення.

«Поліморф» підлягає «Розвіюванню магії». У цьому випадку заклинатель не отримує переваг від зцілення. Якщо вбитий, заклинатель повернеться до природної форми. Якщо перетворений на літуна і потрібно зробити кидок на навичку «Політ», Атлетику або Акробатику можна замінити з двома рівнями складності. Однак персонаж, який часто використовує цю форму, може вибрати розвивати навичку «Політ» нормально з базовим значенням STR+DEX.

#### Воскресіння померлих (R)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 3 | **Час накладання:** 1 хвилина |
| **Сфера:** Некромантична | **Тривалість:** Постійна |
| **Вартість:** 3, +1/додаткова Інтенсивність, +1 EXP | **Дистанція:** 100 футів |
| **Область:** 1 ціль | **Опір:** Н/З (Сила волі) |

Це заклинання може бути накладено на труп істоти, мертвої менше 24 годин на кожний рівень Інтенсивності. Якщо світогляд суб'єкта був будь-яким, крім злого, вони можуть протистояти заклинанням за допомогою опозиційного кидка на Силу волі і, у разі успіху, нівелювати ефекти заклинання. Це тому, що душа або дух померлого рідко бажають повернутися до життя, як тільки досягли своєї вічної винагороди. Майстер гри може вирішити скасувати кидок, якщо отримувач має незавершені справи, не може бути відокремлений від справжнього кохання або має іншу героїчну причину жити.

У випадку злих душ, які із задоволенням повернулися б на матеріальну площину замість страждань у вічному проклятті, чинить опір не Сила волі померлого, а тортура, поставлений відповідальним за їхнє покарання. У цьому випадку заклинатель повинен подолати Силу волі тортура. Якщо це невідомо, припустіть, що вона принаймні на 20 пунктів вища за Силу волі померлого, щоб представити, що чим сильніша воля душі, тим потужніша істота, поставлена відповідальною за їхнє прокляття. Якщо заклинатель досягає успіху, він успішно повернув дух у тіло, тоді як невдалий кидок призводить до того, що жертва або не бажає, або не здатна повернутися.

Якщо накладання успішне, суб'єкт повертається до життя з повними очками здоров'я, хоча втрачені частини тіла залишаються втраченими. Це означає, що жертва, обезголовлена або розрізана навпіл, не може бути воскрешена, поки її голова або тулуб не будуть попередньо прикріплені. Це можна зробити до накладання «Воскресіння померлих» шляхом фізичного повторного прикріплення відокремленої частини тіла, що вимагає набору цілителя та успішного застосування навички «Зцілення», і зазвичай залишає очевидний і характерний шрам. Інші недуги, такі як отрута чи хвороба, повинні бути усунені до або після накладання, інакше результати будуть лише тимчасовими. Нарешті, «Воскресіння померлих» не має ефекту на істоту, яка досягла кінця свого природного терміну життя і померла від старості.

Акт повернення з мертвих є дуже виснажливим для суб'єкта, який зменшується до рівня втоми «Недієздатний» протягом 24 годин на кожен день, протягом якого вони були мертві. Накладання «Зцілення втоми» не має ефекту на пацієнта протягом цього часу одужання. Після цього моменту персонаж відновлюється від втоми нормально і без обмежень.

При зворотному варіанті, «Вбивство живого», можна використовувати для вбивства однієї жертви, призначеної кліриком під час накладання. Ця жертва має право на кидок на опірність Силою волі, модифікований рангом або SIZ цілі, залежно від того, що дає цілі більш вигідний результат, як детально описано в наступній таблиці.

| Ранг цілі | SIZ цілі | Модифікатор Сили волі |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | Важкий |
| 2 | 21-40 | Стандартний |
| 3 | 41-60 | Легкий |
| 4-5 | 61+ | Дуже легкий |

_\* Ця категорія включає персонажів, які не володіють класом._

Якщо кидок на опірність невдалий, жертва вбивається на місці. Успішний кидок розглядається як ефект «Спричинення серйозних ран». Обладунок не пропонує захисту від цієї шкоди. «Вбивство живого» не старить заклинателя при використанні.

Це заклинання є першим заклинанням, якому вчать учнів магічних користувачів, бо саме через нього вони можуть читати магічні записи іншого заклинателя. Магічні записи магів завжди зрозумілі їм самим. Після того, як це заклинання було використане для читання та ідентифікації магічних написів, магічному користувачеві не потрібно накладати «Читати магію», щоб прочитати їх знову; проте те саме заклинання на окремому сувої, книзі тощо потребуватиме іншого накладання «Читати магію».

«Читати магію» можна використовувати для всіх магічних шкіл.

#### Регенерація (R)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 4 | **Час накладання:** 3 хвилини |
| **Сфера:** Зцілення | **Тривалість:** Постійна |
| **Вартість:** 3/Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 істота | **Опір:** Н/З (Парирування або Ухилення) |

Після накладання клірик може торкнутися однієї істоти і регенерувати відірвану частину тіла. Втрачені кінцівки повністю відростуть зі швидкістю 1 пункт здоров'я кожні 10 хвилин до повного зцілення. Однак, якщо відокремлена частина тіла присутня і торкається жертви, весь час відновлення скорочується до 1 хвилини. Це заклинання не може бути використане для «клонування» індивіда шляхом регенерації двох окремих частин, причому лише частина, з'єднана з мозком і центральною нервовою системою, отримує переваги від ефектів заклинання. Кожен рівень Інтенсивності відростить окрему частину тіла. Хоча заклинання можна використовувати для повільного лікування меншої травми, для цього існують нижчі ранги менш витратних заклинань.

При зворотному варіанті, «В'янення», спричинить частину тіла, якої торкається заклинатель, зморщитися і згодом відпасти від жертви. Процес спричиняє втрату 1 пункту здоров'я в ураженій частині тіла кожні 10 хвилин, причому частина тіла стає непридатною при 0 пунктів здоров'я і відпадає, коли вони стають повністю від'ємними. Ефекти можуть бути нівельовані лише накладанням «Регенерації».
