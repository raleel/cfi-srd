#### Appraise (Оцінка)

(Віщування)

| | |
| :-- | :-- |
| **Ранг:** Маг 0 | **Час накладання:** 1 хід |
| **Сфера:** Немає | **Тривалість:** Миттєво |
| **Вартість:** 1 | **Дистанція:** Дотик |
| **Область:** 1 предмет | **Опір:** Немає |

Appraise дозволяє миттєво оцінити якість фізичних товарів із сукупною ENC у «Речах» або SIZ, що дорівнює POW заклинателя. Заклинання визначає, чи є однакові на вигляд предмети однакової або схожої якості, чи один або кілька з них є бракованими або вищої якості. Заклинання не діє на органічні речі, лише на неживі предмети. Воно також не визначає, які саме недоліки чи переваги присутні; лише те, що вони існують. Воно не корисне для ідентифікації чи виявлення магії.

#### Armor (Обладунок)

(Заклинання)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 раунд |
| **Сфера:** Немає | **Тривалість:** Див. нижче |
| **Вартість:** 3 +1/Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Немає |

Коли це заклинання накладено, суб'єкт отримує невидиме поле магічної сили, еквівалентне захисту лускатого обладунку, що надає 4 пункти захисту (Armor Points) кожній зоні ураження. Воно не має ефекту, якщо накладено на того, хто вже носить обладунок. Проте воно замінить природний захист на час своєї дії, якщо пропонує кращий захист. Якщо накладено на істоту, що має більше 4 пунктів природного захисту, воно натомість збільшить показник захисту на 1 у всіх зонах. Цей магічний захист не перешкоджає руху чи використанню заклинань. Заклинання діятиме доти, доки його не розвіє магія, або заклинатель не отримає 8 пунктів шкоди від однієї атаки, +1 за кожен рівень додаткової Інтенсивності (див. таблицю нижче). Звісно, заклинатель може вирішити припинити дію заклинання в будь-який час, якщо забажає, і повинен зробити це перед сном.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | 4 пункти захисту; діє до отримання 8 пунктів шкоди від 1 атаки |
| 2 | 4 | 4 пункти захисту; діє до отримання 9 пунктів шкоди від 1 атаки |
| 3 | 5 | 4 пункти захисту; діє до отримання 10 пунктів шкоди від 1 атаки |
| 4 | 6 | 4 пункти захисту; діє до отримання 11 пунктів шкоди від 1 атаки |
| +1 | +1 | Продовження прогресії |

#### Astral Spell (Астральне заклинання)

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 5, Маг 5 | **Час накладання:** 2 дії |
| **Сфера:** Астральна | **Тривалість:** Див. нижче |
| **Вартість:** 3 +1/додаткова Інтенсивність | **Дистанція:** Дотик |
| **Область:** Див. нижче | **Опір:** Не застосовується |

Це заклинання дозволяє заклинателю та ще п'ятьом іншим особам (по одній на додатковий рівень Інтенсивності) увійти в Астральний план. Усі повинні торкатися одне одного і утворювати коло під час накладання заклинання. Фізичні тіла мандрівників залишаються на початковому плані, і зазвичай вони не беруть із собою жодного одягу чи спорядження, крім того, що саме випромінює магічну ауру; ці предмети перетворюються на астральні еквіваленти своєї звичайної форми. Тривалість заклинання триває доти, доки заклинатель не забажає його припинити. Проте його можна перервати передчасно зовнішньою силою, наприклад, Dispel Magic. Вбивство фізичного тіла заклинателя також достроково завершує заклинання, хоча це має неприємний побічний ефект — усі мандрівники, що супроводжували заклинателя, опиняються в пастці.

#### Augury (Віщування)

(Віщування)

| | |
| :-- | :-- |
| **Ранг:** Клірик 2 | **Час накладання:** 2 хвилини |
| **Сфера:** Віщування | **Тривалість:** Миттєво |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 60 футів |
| **Область:** Заклинатель | **Опір:** Не застосовується |

Це заклинання дозволяє заклинателю визначити, чи буде певна дія, вчинена протягом наступних 30 хвилин, корисною чи шкідливою для благополуччя індивіда та/або групи. Для розпізнавання знамень потрібен певний фокус: найпоширенішими є пазурі або дрібні кістки дракона, перлина або чисте золото вартістю не менше 100 золотих монет, які були роздроблені або розплавлені. Максимальна Інтенсивність заклинання — 4. Цей кидок повинен робити Майстер гри, оскільки заклинатель ніколи не повинен знати напевно, чи правильно були витлумачені результати.

| Інтенсивність | Вартість | Змінний ефект |
| :-: | :-: | :-- |
| 1 | 3 | Кидок навичкою Channel (складно) |
| 2 | 6 | Кидок навичкою Channel (важко) |
| 3 | 9 | Кидок навичкою Channel (стандарт) |
| 4 | 12 | Кидок навичкою Channel (легко) |

Якщо кидок на віщування успішний, він дає один із наступних результатів:

| Augury (Віщування) | Значення | 
| :-: | :-- |
| Так | Дія буде корисною |
| Ні | Дія буде шкідливою |
| Так і ні | Дія буде і корисною, і шкідливою |
| Нічого | Дія не буде ні корисною, ні шкідливою |

Провал (Fumble) має призвести до того, що Майстер гри скаже протилежне реальності.

#### Befuddle (Збентеження)

(Зачарування (Очарування))

| | |
| :-- | :-- |
| **Ранг:** Клірик 0, Маг 0 | **Час накладання:** 1 хід |
| **Сфера:** Очарування | **Тривалість:** 30 хвилин |
| **Вартість:** 1 | **Дистанція:** 60 футів |
| **Область:** 1 ціль | **Опір:** Willpower (Сила волі) |

Befuddle викликає плутанину в розумі тілесної цілі. Суб'єкт заклинання відчуває труднощі з ясним мисленням, забуває, де він знаходиться, що робить і чому — часто впадаючи в беззв'язні роздуми. Збентежені цілі все ще можуть діяти для самозахисту, але не можуть ініціювати будь-яку конструктивну діяльність, поки заклинання не закінчиться. Будь-яка атака чи загрозлива дія миттєво розриває заклинання, незалежно від того, чи була вона спрямована саме на збентежену ціль.

#### Blade Barrier (Бар'єр із клинків)

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Клірик 4 | **Час накладання:** 2 дії |
| **Сфера:** Охоронець, Створення | **Тривалість:** 3 раунди/Інтенсивність |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 100 футів |
| **Область:** Радіус 5-30 футів | **Опір:** Див. нижче |

Це заклинання створює бар'єр із вихору ріжучих мечів, кинджалів та ножів, що кружляють і січуть навколо фіксованої точки, завдаючи 1d8 пунктів шкоди 1d4+2 випадковим зонам ураження будь-кого, хто проходить через область дії. Обладунок пропонує лише половину свого звичайного захисту. Магічні пункти захисту зменшують шкоду як завжди. Оскільки зброя кружляє з неймовірною швидкістю і щільно упакована, неможливо парирувати або ухилитися від неї. Можна використовувати щит, щоб пасивно блокувати зони ураження як зазвичай. У цьому випадку пам'ятайте про порівняння кинутої шкоди з бронею та пунктами здоров'я щита.

Заклинання можна використовувати оборонно, щоб захистити клірика або одного чи кількох союзників, або наступально, щоб заманити ворогів у пастку. Проте оточені вороги, що знаходяться в межах п'яти футів від краю бар'єру, коли він формується, можуть зробити кидок на ухилення, щоб втекти. Незалежно від успіху, супротивник опиняється ниць, просто за межами області дії. Успішний кидок призводить до відсутності шкоди; в іншому випадку вони отримують повний ефект.

#### Chain Lightning (Ланцюгова блискавка)

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 2 дії |
| **Сфера:** Немає | **Тривалість:** Миттєво |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 50 футів/Інтенсивність |
| **Область:** Див. нижче | **Опір:** Ухилення |

При накладанні маг випускає з кінчиків пальців розряд електрики шириною п'ять футів, який може вразити одну ціль у межах дистанції на 1d6+1 пунктів шкоди на кожні 2 пункти Інтенсивності. Потім розряд перекидається на наступний найближчий предмет або істоту, які отримують раніше кинуту шкоду мінус 1 пункт, а потім на наступного, завдаючи шкоду мінус 2 пункти, і так далі. Він може навіть перекинутися назад на союзника або заклинателя! Хоча початкова ціль повинна бути видима для заклинателя, цілі, уражені наступними розрядами, не обов'язково повинні бути видимими.

Кожен розряд має власну дистанцію в 50 футів, що може вивести його за межі початкової дистанції, коли заклинання було накладене. Chain Lightning продовжує вражати, якщо залишилася шкода, доки не влучить у предмет, що заземлить його (металева клітка чи ґрати, велика калюжа води тощо), або не залишиться більше доступних цілей.

Кожна уражена істота отримує шкоду в одну зону ураження, причому ношений обладунок не пропонує жодного захисту, а природний захист і магічні пункти захисту зменшують шкоду як завжди.

При успішному кидку на ухилення, коли ціль падає ниць, вона не отримує шкоди. Той, хто володіє навичкою Artful Dodger, може ухилитися без падіння ниць, але успіх у цьому випадку лише вдвічі зменшує шкоду.

Блискавка має шанс підпалити легкозаймисті матеріали, рівний кинутій шкоді, помноженій на 1%. Дивіться розділ про [вогонь](0007_Game_System.md?id=fire-based-attacks) для додаткової інформації. Блискавка також може розбити або знищити неживі предмети від удару.

| 1 | 3 | Дистанція 50 футів; 1d6+1 шкода |
| 2 | 4 | Дистанція 100 футів; 1d6+1 шкода |
| 3 | 5 | Дистанція 150 футів; 2d6+2 шкода |
| 4 | 6 | Дистанція 200 футів; 2d6+2 шкода |
| 5 | 7 | Дистанція 250 футів; 3d6+3 шкода |
| +1 | +1 | Продовження прогресії |

Cleanse використовується для очищення предмета, людини або невеликої області від бруду, жиру, сажі, поганих запахів тощо. Воно не впорядковує чи прибирає, а лише очищає до ідеального стану. Це заклинання часто використовують для прання одягу. Заклинатель може очистити площу, що дорівнює POWx5 квадратних футів (квадрат 5х5 футів — це 25 квадратних футів).

Dishevel (Забруднення) — це зворотна форма Cleanse. Зачеплені об'єкти негайно вкриваються брудом, пилом, павутиною тощо. Заклинання можна використовувати, щоб надати новим речам старого та зношеного вигляду або щоб допомогти людям, які зазвичай добре виглядають, стати невпізнанними.

#### Command (Наказ)

(Зачарування (Очарування))

| | |
| :-- | :-- |
| **Ранг:** Клірик 1 | **Час накладання:** 1 дія |
| **Сфера:** Очарування | **Тривалість:** 1 хвилина |
| **Вартість:** 3 | **Дистанція:** 100 футів |
| **Область:** 1 ціль | **Опір:** Willpower (Сила волі) |

Коли це заклинання накладено, клірик може вимовити однослівний наказ одній живій істоті SIZ 1-20, і в наступний хід цілі наказ буде виконаний буквально, якщо вона не пройде перевірку на опір. Це, по суті, змушує жертву пропустити наступний хід, виконуючи наказану дію, і витрачає Action Point. Якщо у жертви не залишилося Action Points, наказана дія буде виконана під час її першого ходу в наступному раунді. Сам наказ не може спричинити жодної реальної шкоди цілі; проте шкода може бути вторинним наслідком наказу.

Наприклад, наказ померти призведе до того, що жертва впаде у стан, подібний до смерті на 1 раунд, не завдаючи реальної шкоди; проте наказ впасти, даний істоті, що лізе на 100-футову скелю, може виявитися смертельним.

Об'єкт наказу повинен розуміти мову, якою говорить заклинатель, і має право на перевірку Сили волі для опору.

**Деякі приклади наказів:**

- **Crawl (Повзти):** Суб'єкт падає ниць і починає повзти.
- **Die (Померти):** Суб'єкт падає ниць, впадаючи в коматозний стан, подібний до смерті.
- **Fall (Впасти):** Суб'єкт падає ниць.
- **Fumble (Впустити):** Суб'єкт упускає фізичну дію, яку збирався виконати.
- **Sleep (Спати):** Суб'єкт засинає.
- **Flee (Втекти):** Суб'єкт розвертається і тікає від заклинателя.
- **Fly (Летіти):** Суб'єкт махає руками і бігає колами.
- **Go (Йти):** Суб'єкт починає йти в напрямку, куди дивиться.
- **Halt (Стій):** Суб'єкт негайно зупиняється і стоїть на місці.
- **Leave (Піти):** Суб'єкт розвертається і йде шляхом, яким прийшов.
- **Rest (Відпочити):** Суб'єкт сідає і переводить подих.
- **Run (Бігти):** Суб'єкт починає бігти.
- **Scream (Кричати):** Суб'єкт кричить.
- **Sink (Тонути):** Суб'єкт припиняє плавати.
- **Surrender (Здатися):** Суб'єкт кидає зброю і припиняє бойові дії.

#### Cone of Cold (Конус холоду)

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Час накладання:** 1 раунд |
| **Сфера:** Немає | **Тривалість:** Миттєво |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 0 |
| **Область:** Див. нижче | **Опір:** Ухилення |

Заклинатель створює конус пекучого холоду, що виходить з його рук. Область дії — це 90-градусна дуга ("конус") завдовжки 10 футів на кожен рівень Інтенсивності. Заклинання завдає 1d6+1 пунктів шкоди на кожні 2 пункти Інтенсивності, або їх частку, всім жертвам в області дії. Киньте шкоду один раз і застосуйте її до кожної зони ураження цілі; при цьому ношений обладунок пропонує лише половину захисту, але природний захист істоти або магічні пункти захисту зменшують шкоду як завжди. Майстер гри може вибрати кількість уражених зон будь-яким способом, який вважає за потрібне, якщо величезна істота більша за область дії.

Успішний кидок на ухилення, коли ціль падає ниць, дозволяє уникнути шкоди. Той, хто володіє навичкою Artful Dodger, може ухилитися, не падаючи ниць, але успіх у цьому випадку лише вдвічі зменшує шкоду, якщо тільки ціль не знаходиться в межах п'яти футів від краю області дії. Cone of Cold має шанс покрити жертву шаром льоду, рівний кинутій шкоді (після модифікації), помноженій на 5%. Якщо ціль заморожена, вона може раз на раунд витратити Action Point і зробити кидок на Brawn (Фізичну силу), щоб спробувати вирватися; однак, до успіху нещасна жертва не може рухатися або виконувати інші дії.

| | |

Це заклинання створює кулю світла, еквівалентну за яскравістю повному денному світлу, у місці, обраному заклинателем, яким може бути предмет або навіть повітря. Зір можна відновити лише накладанням Cure Blindness and Deafness будь-якої інтенсивності або накладанням Dispel Magic з інтенсивністю вищою за Магнітуду Continual Light. Ефекти заклинання нерухомі, але його можна накласти на портативний чи рухомий предмет.

#### Enchant Item (Зачарувати предмет)

(Зачарування)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** Див. нижче |
| **Сфера:** Немає | **Тривалість:** Див. нижче |
| **Вартість:** 3 + Див. нижче | **Дистанція:** Дотик |

Накладання цього заклинання готує предмет до зачарування. Об'єкт повинен бути в хорошому стані, найкращої роботи. Потрібна додаткова вартість у щонайменше 100 золотих монет для покриття витрат на додаткові інструменти, різьблення, вишивку, гравіювання тощо. Нарешті, процес зачарування вимагає лабораторії або майстерні.

Під час накладання маг повинен торкатися предмета протягом всього часу накладання 1d8+2 дні. Це враховує періоди відпочинку та сну, протягом яких предмет повинен залишатися на відстані витягнутої руки від заклинателя. Протягом усього часу маг не може накладати інші заклинання або виконувати іншу магію. Порушення будь-якої з цих умов автоматично призведе до провалу заклинання.

Після успішного накладання предмет готовий до останнього кроку: заклинатель поміщає бажане заклинання в нього. Для цього він повинен мати заклинання в пам'яті або на сувої і накласти його на предмет протягом 24 годин, інакше процес потрібно починати з нуля. Після початку накладання вибраного заклинання процес може тривати довше згаданих 24 годин. Наповнення предмета обраним заклинанням коштує нормальну кількість магічних пунктів для бажаної Інтенсивності і займає 1d12 годин на кожний ранг заклинання. Протягом процесу наповнення заклинатель повинен торкатися предмета або залишатися на відстані витягнутої руки, і в кінці потрібен кидок на Arcane Casting (Магічне накладання). Звичайні ступені успіху враховуються, проте при провалі заклинання не можна форсувати. У предмет можна наповнити наступні заклинання, якщо процес накладання розпочато протягом 24 годин після завершення попереднього. Кожне наступне заклинання потребує нормальної вартості.

Під час використання предмета кожне заклинання може бути використане лише один раз; однак можна наповнити кілька версій одного й того самого заклинання. Можна також наповнити одне заклинання і додати накладання заклинання 4 рангу Permanency. У цьому випадку заклинання можна використовувати так часто, як забажаєте, дотримуючись обмежень, встановлених у заклинанні Permanency.

Неможливо наповнити предмет іншими магічними ефектами, які не відповідають конкретному заклинанню, і багато магічних предметів із давніх часів просто неможливо відтворити сьогодні.

Exorcism також можна використовувати проти домінування певних предметів і магічних предметів, заклинань, проклять і навіть очарувань. Що станеться далі, залежить від ставлення та типу сутності, але войовничі істоти зі здатністю виходити з тіла можуть бути спокушені вступити в бій з іншими поруч знаходящимися цілями. Трактуйте це як магічну дуель, однак, якщо сутність переможе, вона може опанувати переможеним. Якщо сутність програє, вона відправляється назад на свій план походження. Таким чином, це заклинання може бути потенційно небезпечним для заклинателя або його товаришів. Час накладання дуже випадковий і не може бути перерваний без порушення ритуалу.

(Трансмутація)

| | |

#### Find Familiar (Знайти фамільяра)

(Заклинання)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 2d12 годин |
| **Сфера:** Немає | **Тривалість:** Особлива |
| **Вартість:** 3/Інтенсивність, +1 EXP | **Дистанція:** 0 |
| **Область:** Радіус ½ милі/Інтенсивність | **Опір:** Не застосовується |

Це заклинання дозволяє заклинателю спробувати викликати фамільяра, який стає продовженням чуттів та сили свого господаря. Фамільяри можуть розмовляти зі своїм господарем телепатично і є хорошими вартовими та розвідниками. Втрата фамільяра становить певні ризики для мага через їхній тісний зв'язок, що робить наявність фамільяра небезпекою низького рангу.

Щоб викликати фамільяра, маг повинен розпочати ритуал, тримаючи жаровню з вугіллям, а коли вона розжариться, додати пахощі вартістю 100 золотих монет. З цими палаючими інгредієнтами заклинатель повинен продовжувати ритуал, доки фаміляр не прибуде або час накладання не закінчиться без успіху.

Навіть якщо це заклинання накладено успішно, шанс того, що відповідний фаміляр відповість на заклик мага, становить лише 50%, і маг може намагатися накласти це заклинання лише раз на рік. Кожен додатковий рівень Інтенсивності понад перший збільшує дальність заклинання ще на пів милі, що, у свою чергу, збільшує ймовірність того, що потенційний фаміляр буде знайдений, на 5%, до максимуму 95%. Немає контролю над типом істоти, яка відповість на заклик, але той, хто прибуде, буде вірним слугою і союзником. Справа конкретної істоти — відповідати на заклик, тому перебування в регіоні, відомому тим, що там мешкає певний тип істот, не гарантує заклинателю успіху.

Якщо істота відповідає на заклик заклинателя, магу все одно потрібно принести в жертву 1 кидок на досвід (Experience Roll), щоб створити духовний зв'язок між собою та фамільяром. Після цього ритуал завершено.

Поки фаміляр і його господар знаходяться в межах 120 футів один від одного, маг отримує можливість використовувати також магічні пункти фамільяра. Крім того, маг отримує телепатичний зв'язок із фамільяром та будь-якими додатковими особливими здібностями або бонусами навичок, зазначеними в таблицях нижче.

У разі смерті фамільяра заклинатель втрачає 5 кидків на досвід. Заклинатель, який зараз не має жодного кидка на досвід, повинен відмовитися від усіх подальших кидків на досвід до виплати боргу.

Тип фамільяра, що з'явиться, визначається згідно з наступною таблицею. За більшості обставин звичайні фамільяри не є винятково великими, будучи між SIZ 1-4, і використовують опис малої тварини.

#### Fire Shield (Вогняний щит)

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Час накладання:** 2 дії |
| **Сфера:** Немає | **Тривалість:** 2 хвилини/Інтенсивність |
| **Вартість:** 3+1/додаткова Інтенсивність | **Дистанція:** 0 |
| **Область:** Заклинатель | **Опір:** Не застосовується |

Це заклинання створює щит із розмитого полум'я, який обпалює заклинателя, але сам по собі шкоди не завдає. Натомість полум'я захищає отримувача або від вогню, або від холоду, залежно від того, який з двох варіантів знаходиться в пам'яті: Chill Shield (Крижаний щит), який створює сині або зелені язики полум'я і захищає від спеки та шкоди на основі вогню; або Warm Shield (Теплий щит), який створює фіолетове або блакитне полум'я і захищає від шкоди на основі холоду та льоду. Колір полум'я слід визначати випадково з 50% шансом на кожний, оскільки той факт, що обидва типи можуть випромінювати синє полум'я, створює елемент невизначеності для будь-якого нападника. Рішення про те, який варіант запам'ятовувати, приймається під час підготовки заклинань, і, якщо забажаєте, можна запам'ятати обидва. Це полум'я не випромінює тепла і дає світло лише на половину яскравості факела. Специфіка кожного варіанту детально описана нижче.

- **Chill Shield:** Це полум'я холодне на дотик і зменшує будь-яку шкоду на основі вогню або тепла до половини від загальної. Успішний кидок на опір нівелює всю шкоду. Кидок на опір на один ступінь легший, і у випадку ухилення захисник не падатиме ниць.
- **Warm Shield:** Це полум'я тепле на дотик і зменшує будь-яку шкоду на основі холоду до половини від загальної. Успішний кидок на опір нівелює всю шкоду. Кидок на опір на один ступінь легший, і у випадку ухилення захисник не падатиме ниць.

Атаки ближнього бою проти отримувача будь-якого варіанту, будь то озброєні чи беззбройні, завдають звичайну шкоду, якщо не використовують елемент, від якого захищаються. У цьому випадку заклинатель захищений від елементальної частини атаки, а нападник отримує шкоду, рівну завданій. Ношений нападником обладунок не пропонує жодного захисту, але магічні пункти захисту або природний захист істоти зменшують шкоду як завжди. Істоти з вродженою магічною стійкістю можуть розвіяти Fire Shield на успішному кидку на Силу волі, коли отримувач вперше вражений. Якщо кидок на магічну стійкість не вдається, супротивник не може пізніше нівелювати Fire Shield.

#### Flesh to Stone \(R\) (Плоть у камінь)

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 2 дії |
| **Сфера:** Немає | **Тривалість:** Постійно |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 30 футів/Інтенсивність |
| **Область:** 1 ціль | **Опір:** Willpower (Сила волі) |

При накладанні одна жертва в межах дистанції отримує кидок на опір Сили волі. Якщо невдало, вона та всі перенесені й ношені речі повністю перетворюються на твердий камінь. Це перетворення не є смертю, а формою призупиненого стану. Накладання або зворотного варіанту цього заклинання, або Wish, може бути використано для відновлення жертви до життя знову. Будь-яка шкода, яку жертва отримує, будучи каменем, переноситься, набуваючи сили відразу після відновлення. Великі істоти (SIZ 21-40) менш сприйнятливі до перетворення (кидок на опір легкий), а для величезних істот (SIZ 41+) кидок на опір дуже легкий.

Зворотний варіант цього заклинання, Stone to Flesh, використовується для відновлення жертви, і кидок на опір не потрібен. Однак заклинання можна також розвернути для трансформації каміння, яке ніколи раніше не було живим; воно може бути використане кількома творчими способами. Наприклад, стіна каміння розміром 10 кубічних футів на рівень Інтенсивності може бути перетворена на м'яку плоть, "тунель" з плоті шириною до 3 футів і довжиною 10 футів на Інтенсивність, одна ціль, як-от кам'яна статуя, може бути перетворена на тіло, і навіть кам'яний голем може бути перетворений на голема з плоті. Проте в останньому випадку кам'яний голем матиме право на кидок на Силу волі для опору як зазвичай. Каміння, перетворене на плоть таким чином, м'яке і податливе, і хоча воно зберігає свої реальні пункти здоров'я, воно не має пунктів захисту, що робить його легшим для розрубання.

#### Gate (Брама)

| | |
| :-- | :-- |

Накладання Gate вимагає від заклинателя знання справжнього імені істоти, яку потрібно викликати, зазвичай це істота з інших планів існування, як-от демон, диявол, ангел, напівбог або навіть бог. Коли це успішно накладено, відкривається портал між планом заклинателя і планом істоти. Накладання заклинання автоматично привертає увагу істоти, успішно чи ні. #### Glamour \(R\) (Чарівність)

| :-- | :-- |

Glamour робить ціль привабливою, тому люди природно тягнуться до неї. Хоча заклинання не надає жодних механічних переваг, воно гарантує, що отримувач матиме можливість зібрати аудиторію, привернути увагу того, з ким він бажає зв'язатися, або забезпечити відволікання, що дасть спільникам можливість виконувати підлі справи.

Ефект повинен бути обраний під час накладання і може бути чим завгодно, від великої бородавки на кінчику носа, носового голосу чи навіть їдкого запаху тіла. Що б не було обрано, це змусить людей відвернутися від жертви або вигадувати виправдання, щоб якнайшвидше залишити її присутність.

#### Heal  \(R\) (Зцілення)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 4 | **Час накладання:** 1 хвилина |
| **Сфера:** Зцілення | **Тривалість:** Постійно |
| **Вартість:** 3 +1/Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 істота | **Опір:** Не застосовується (Endurance або Ухилення) |

З накладанням Heal клірик може вилікувати фізичну недугу, ментальну травму або значну кількість шкоди одним дотиком. Фактична міра одужання базується на інтенсивності заклинання. На кожен рівень Інтенсивності заклинання зцілює суб'єкта від однієї хвороби будь-якого рівня POT, лікує від сліпоти чи глухоти, нівелює психічний розлад, спричинений травмою або магією, або зцілює одну зону ураження на 12 пунктів шкоди. Проте воно не відновить відрізану кінцівку, оскільки це вимагає накладання заклинання Regenerate. Кожну додаткову Інтенсивність можна використовувати для лікування іншої недуги або зцілення іншої зони ураження. Тому для лікування людини, що отримала опіки всього тіла, знадобиться накладання з Інтенсивністю 7. На відміну від менших цілющих заклинань, які обмежують свою ефективність проти довготривалих травм, заклинання не має обмежень за часом, протягом якого суб'єкт страждав від ефектів травми.

При зворотному накладанні, Harm (Шкода), наносить 12 пунктів магічної шкоди одній із зон ураження жертви при невдалому кидку на опір. Альтернативно, на неї накладається недуга, ефекти якої такі ж, як заклинання Cause Disease, зворотне Cure Disease, але з +20 POT. Кидок клірика на Channel функціонує як кидок для влучання по супротивнику і вважається частиною соматичних вимог заклинання. Додатковий кидок на влучання не потрібен. Ні ношений, ні природний обладунок не пропонують жодного захисту, але магічні пункти захисту зменшують шкоду як завжди і повністю блокують накладені недуги. Кожна додаткова Інтенсивність впливає на іншу зону ураження, суміжну з першою, з ефектами, як визначено початковим кидком на опір. Жодна версія цього заклинання не має ефекту на нежить, істот, яких можна пошкодити лише залізом, сріблом або магічною зброєю, або нетілесних істот.

#### Illusion (Ілюзія)

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 дія |
| **Сфера:** Немає | **Тривалість:** Концентрація; див. нижче |
| **Вартість:** 1/Інтенсивність | **Дистанція:** 100 футів/Інтенсивність |
| **Область:** Радіус 50 футів/Інтенсивність | **Опір:** Невіра |

Це заклинання створює візуальну ілюзію всього, що забажає заклинатель. Воно не має ефекту на інші чуття, не створює звуку, запаху, температури чи текстури тощо.

Ця ілюзія може бути будь-чим, від відкритої галявини до стародавнього червоного дракона, якщо він поміщається в області дії заклинання. Ілюзія триватиме лише доти, доки заклинатель підтримує концентрацію, або доки супротивник не торкнеться чи не увійде в неї; це спричиняє розпад магії, що її підтримує, і розсіювання ілюзії. Проте заклинатель може підтримувати ілюзію після фізичного контакту, витрачаючи 1 магічний пункт і скеровуючи її реагувати відповідно до контакту, щоб не викликати підозр. Наприклад, за звичайних обставин ілюзія огра зникне, коли її вразить стріла; проте заклинатель може змусити огру, наприклад, знизати плечима від удару і кинутися на нападника, витративши 1 магічний пункт. Слід зазначити, що справжня стріла не зупиняється ілюзією і може вразити когось позаду неї.

Хоча ілюзія не може завдати шкоди, як і створити температуру, розум може бути переконаний, що відчуває біль, страждаючи від наслідків травми або відчуваючи спеку чи холод; проте предмети не будуть здаватися замороженими або палаючими, якщо заклинатель також не зосередиться на цих ефектах. Після накладання заклинання заклинатель може за бажанням додавати додаткові візуальні ефекти, концентруючись на бажаному. Зазвичай це не займає часу і може бути виконано як вільна дія. Наприклад, якщо заклинатель хоче, щоб впущений ілюзорний факел спричинив підпал сухого листя, заклинатель може зосередитися як на вільній дії, щоб зробити це.

#### Invisibility (Невидимість)

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Час накладання:** 1 дія |
| **Сфера:** Немає | **Тривалість:** 6 годин/Інтенсивність |
| **Вартість:** 3, +1/додаткова Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Не застосовується |

Коли це заклинання накладено, суб'єкт і будь-яке ношене спорядження зникають, стаючи невидимими для всіх форм звичайного зору. Це, проте, не робить індивіда невиявленим іншими засобами, такими як слух, дотик, запах тощо, або природними здібностями, такими як відчуття життя чи сонар.

Ті, хто перебуває під впливом Invisibility, залишаються невидимими протягом всієї тривалості заклинання (макс. 24 години), якщо воно не розвіяне або якщо суб'єкт не здійснює атаку, у такому випадку заклинання нівелюється, і індивід з'являється _після_ атаки. Ціль вважається під ефектом [Surprise](0008_Combat.md?id=surprise). Жодні інші дії негативно не впливають на тривалість заклинання, дозволяючи суб'єкту відчиняти двері, говорити, лазити, бігати, витягувати гаманець тощо. Багато з раніше згаданих дій можуть дозволити інші засоби виявлення, наприклад, можлива перевірка на Perception, щоб почути когось, хто пробігає повз, або відчути, як витягують гаманець. Майстер гри призначить штрафи чи бонуси тим, хто намагається виявити, залежно від того, наскільки це помітно.

#### Invisibility, 10 ft. Radius (Невидимість у радіусі 10 футів)

(Ілюзія)

| | |
| :-- | :-- |
| **Ранг:** Маг 2 | **Час накладання:** 2 дії |

Це заклинання функціонує ідентично до заклинання [Invisibility](0010_Spells.md?id=invisibility); проте всі особи в межах 10 футів від отримувача (яким може бути і сам заклинатель) під час накладання також стають невидимими. Проте атака, зроблена початковим отримувачем заклинання, знову робить усіх видимими. Дивіться базове заклинання [Invisibility](0010_Spells.md?id=invisibility) для додаткових деталей.

#### Meteor Shower (Метеоритний дощ)

(Евокація)

| | |
| :-- | :-- |
| **Ранг:** Маг 5 | **Час накладання:** 2 дії |
| **Сфера:** Немає | **Тривалість:** Миттєво |
| **Вартість:** 3/Інтенсивність | **Дистанція:** 20 футів/Інтенсивність |
| **Область:** Див. нижче | **Опір:** Ухилення |

Коли маг накладає це заклинання, два мікрометеорити на рівень Інтенсивності вилітають з витягнутої руки. Вони прямують до цілі, залишаючи шлейф іскор. Після удару вони детонують у множинних вогняних вибухах. Перший метеорит завжди вражає цільове місце, будь-які додаткові вражають навколо нього випадково, кожен з радіусом вибуху 30 футів.

</div>

Кожен метеорит завдає 1d10 пунктів шкоди від вогню тим, хто в області дії. Оскільки радіуси вибухів перекриваються, багато хто отримує додаткову шкоду. Кидки шкоди комбінуються і застосовуються до кожної зони ураження цілі; ношений обладунок не пропонує захисту, але магічні пункти захисту або природний захист істоти зменшують шкоду як завжди.

Всі, хто знаходиться в межах 60 футів від точки удару, повинні пройти перевірку на Athletics, щоб встояти.

Meteor Shower має шанс підпалити легкозаймисті матеріали, рівний кинутій шкоді, помноженій на 5%. Дивіться розділ про [вогонь](0007_Game_System.md?id=fire-based-attacks) для додаткової інформації.

#### Permanency (Постійність)

(Трансмутація)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Час накладання:** 1 дія |

Накладання цього заклинання змінює тривалість певних інших заклинань на "постійно". Для використання цього заклинання маг спочатку накладає заклинання, яке має стати постійним. #### Raise Dead \(R\) (Воскресити мертвих)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 3 | **Час накладання:** 1 хвилина |
| **Сфера:** Некромантія | **Тривалість:** Постійно |
| **Вартість:** 3, +1/додаткова Інтенсивність, +1 EXP | **Дистанція:** 100 футів |
| **Область:** 1 ціль | **Опір:** Не застосовується (Willpower) |

Це заклинання можна накласти на труп істоти, мертвої менше 24 годин на кожний рівень Інтенсивності. Якщо світогляд суб'єкта був будь-яким, окрім злого, він може чинити опір заклинаню за допомогою протилежного кидка на Willpower і, якщо успішно, нівелювати ефекти заклинання. Це тому, що душа або дух покійного рідко хоче повернутися до життя, як тільки досягла своєї вічної винагороди. Майстер гри може вирішити відмовитися від кидка, якщо отримувач має незавершені справи, не може бути відділений від свого справжнього кохання або має іншу героїчну причину жити.

У випадку злих душ, які радо повернулися б на матеріальний план замість страждань у вічному проклятті, чинить опір не Willpower покійного, а душа демона, диявола тощо, поставленого відповідальним за їхнє покарання, їхній мучитель. У цьому випадку заклинатель повинен подолати Willpower мучителя. Якщо це невідомо, припустіть, що він принаймні на 20 пунктів вищий за Willpower покійного, щоб представити, що чим сильніша воля душі, тим могутнішою є істота, відповідальна за її прокляття. Якщо заклинатель досягає успіху, він успішно повернув дух у тіло, тоді як невдалий кидок призводить до того, що жертва або не хоче, або не може повернутися.

Якщо накладання успішне, суб'єкт повертається до життя з повними пунктами здоров'я, хоча відірвані кінцівки залишаються втраченими. Це означає, що жертву, обезголовлену або розрізану навпіл, неможливо воскресити, доки її голова або тулуб не будуть спочатку прикріплені. Це можна зробити до накладання Raise Dead шляхом фізичного приєднання severed зони, що потребує набору лікаря та успішного застосування навички Healing, і зазвичай залишає очевидний і помітний шрам. Інші недуги, як-от отруєння або хвороби, повинні бути усунені до або після накладання Raise Dead, інакше результати будуть лише тимчасовими. Нарешті, Raise Dead не має ефекту на істоту, яка досягла кінця природного терміну життя і померла від старості.

Акт повернення з мертвих дуже напружує суб'єкта, який зводиться до рівня втоми Incapacitated на період 24 години на кожен день, протягом якого вони були мертві. Накладання Cure Fatigue не має ефекту на пацієнта під час цього часу одужання. Після цього персонаж відновлюється від втоми нормально і без обмежень.

Ця жертва має право на кидок на Willpower для опору, модифікований рангом або SIZ цілі, залежно від того, що дає більш корисний результат для цілі, як детально описано в таблиці нижче.

Це заклинання не можна використовувати для "клонування" індивіда шляхом регенерації двох окремих частин; переваги отримує лише частина, підключена до мозку та центральної нервової системи. Кожен рівень Інтенсивності відрощуватиме окрему зону ураження. Хоча заклинання можна було б використовувати для повільного лікування меншої травми, для цього існують менші заклинання з меншими витратами.

При зворотному накладанні, Wither (В'янення), спричиняє всихання зони, якої торкається заклинатель, і врешті-решт вона відпадає від жертви. Процес призводить до втрати 1 пункту здоров'я в уражену зону на кожні 10 хвилин, причому зона стає непридатною для використання на 0 пунктах здоров'я і відпадає, коли вони стають повністю від'ємними. Ефекти можна нівелювати лише накладанням Regenerate.

У випадку злих душ, які радо повернулися б на матеріальний план замість страждань у вічному проклятті, чинить опір не Willpower покійного, а душа демона, диявола тощо, поставленого відповідальним за їхнє покарання. У цьому випадку заклинатель повинен подолати Willpower мучителя. Якщо успішно, вони успішно закріпили дух у господаря.

Якщо накладання успішне, за 1d6x10 хвилин з'являється повністю сформоване доросле тіло, що містить свідомість покійного. Заклинатель не має контролю над формою чи статтю, в якій повертається душа — киньте за таблицею нижче. Попередній клас персонажа і ранг зберігаються. Це означає, що персонажу може знадобитися певне переконання, що він — це він, при спілкуванні з друзями, родиною та колишніми знайомими; це включає їхній орден чи гільдію, коли приходить час для Advancement, якщо це актуально. Найкраще це представлено Influence кидками персонажа, модифікованими тим, наскільки радикальною є зміна, як визначено Майстром гри. Наприклад, дварф, реінкарнований в іншого дварфа, може вимагати стандартного кидка Influence, щоб переконати колишнього союзника у своїй справжній особистості, тоді як перетворення на гнома або гафлінга може зробити кидок на один ступінь складнішим.

Всі характеристики визначаються випадково згідно з новою формою, окрім INT, POW та CHA, які залишаються незмінними. Колишні расові здібності втрачаються і замінюються здібностями нового виду. Якщо нова форма не підходить для старого класу персонажа, єдиний вибір — змиритися з цим або вивчити новий клас. Реінкарнований індивід пам'ятає більшу частину свого попереднього життя, хоча Майстер гри може попросити персонажа зробити кидок на Willpower, щоб запам'ятати значні факти протягом першого тижня. Wish може повернути реінкарновану особу до її попередньої форми, якщо цього захочеться пізніше.

(Аб'юрація)

|  |  |
| :-- | :-- |

- 51-75: Бойові навички та кидки на опір на 2 ступені складніші.
- 76-00: Всі провалені перевірки навичок трактуються як Fumble.

#### Restoration (Відновлення)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 3 | **Час накладання:** 3 хвилини |
| **Сфера:** Зцілення | **Тривалість:** Постійно |
| **Вартість:** 3, +1/додаткова Інтенсивність | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Не застосовується |

При накладанні жертва, раніше виснажена від життєвої сили за допомогою Energy Drain або подібних ефектів, відновлює один раніше втрачений рівень втоми. Restoration можна також використовувати для зняття років, втрачених через штучне старіння, наприклад, від певних заклинань. Для того, щоб заклинання було накладено таким чином, на додаток до нормальної вартості накладання, клірик повинен витратити 1 EXP Roll на кожен 1% життя отримувача, який потрібно відновити (1 рік для людини). Заклинання не може зменшити поточний вік суб'єкта нижче його справжнього віку.

#### Resurrection \(R\) (Воскресіння)

(Некромантія)

| | |
| :-- | :-- |
| **Ранг:** Клірик 5 | **Час накладання:** 10 хвилин |
| **Сфера:** Некромантія | **Тривалість:** Постійно |
| **Вартість:** 3, +1/додаткова Інтенсивність, +2 EXP | **Дистанція:** Дотик |
| **Область:** 1 ціль | **Опір:** Не застосовується (Willpower) |

Resurrection воскрешає будь-яку істоту, мертву не більше 20 років на кожний рівень Інтенсивності. Істота не тільки повертається до життя, а й відновлюється до повної сили та зцілюється від травм, навіть відновлюючи втрачені кінцівки. Мало що від реальної істоти повинно залишитися, щоб заклинання все ще було ефективним. Наприклад, Resurrection можна використовувати, щоб повернути істоту з мертвих через 145 років, навіть володіючи лише кісткою пальця, якщо заклинання накладено з Інтенсивністю 8. Воскрешений індивід потребує ніякого відпочинку і є повністю функціональним негайно. Заклинання не має ефекту на істоту, яка померла з природних причин наприкінці відведеного терміну життя.

Якщо світогляд суб'єкта був будь-яким, окрім злого, він може чинити опір заклинаню за допомогою протилежного кидка на Willpower і в разі успіху нівелювати ефекти. Це тому, що душа покійного рідко хоче повернутися. У випадку злих душ, які радо повернулися б замість страждань у вічному проклятті, чинить опір не Willpower покійного, а мучитель, поставлений відповідальним за їхнє покарання. У цьому випадку заклинатель повинен подолати Willpower мучителя. Якщо успішно, суб'єкт був успішно воскрешений, тоді як невдалий кидок призводить до того, що жертва або не хоче, або не може повернутися.

Resurrection дуже виснажливий, старить клірика на 3% від його типової тривалості життя (3 роки у випадку з людиною-заклинателем). Дивіться правила [Aging](0007_Game_System.md?id=aging).

При зворотному накладанні, Destruction, може бути використано для вбивства однієї жертви, що контактує з кліриком під час накладання. Ця жертва має право на кидок на Willpower для опору, модифікований рангом або SIZ цілі, залежно від того, що дає більш корисний результат для жертви, як детально описано в таблиці нижче.

| Ранг цілі | SIZ цілі | Модифікатор Willpower |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | Складно |
| 2 | 21-40 | Важко |
| 3 | 41-60 | Стандарт |
| 4 | 61-80 | Легко |
| 5 | 81+ | Дуже легко |

_\* Ця категорія включає персонажів, які не володіють класом._

Якщо цей кидок на опір невдалий, суб'єкт вбивається прямо на місці, його тіло перетворюється на пил. Тільки накладання Wish поверне жертву назад на цьому етапі. При успішному кидку суб'єкт зводиться до мінус 1d4 пунктів здоров'я в ураженій зоні. Обладунок не пропонує жодного захисту від цієї шкоди. Destruction не старить заклинателя при використанні.

| | |
| :-- | :-- |
