# Vedlegg: Konverteringstabeller

---
#### Konvertering fra imperiale vekter og mål til metrisk

For å gi _Classic Fantasy Imperative_ en renere fremstilling, gjøre den lettere å lese, og kondensere beskrivelser og tabeller, vil _Classic Fantasy Imperative_ fokusere på imperiale måleenheter fremfor både imperiale og metriske. Imperiale mål ble valgt for å forenkle konvertering av eksisterende materiale, ettersom de fleste eventyr, kampbrett og kart som brukes av andre spill i sjangeren benytter det imperiale systemet. For de som ønsker å bruke det metriske systemet, har de mest brukte vektene og målene blitt konvertert ved hjelp av tabellene nedenfor. Siden vi vanligvis ikke har å gjøre med skapninger, formler og lignende fra den virkelige verden, kan vi tillate oss litt spillerom i vektene og målene vi har diktet opp for dem. I stedet for å bruke nøyaktige konverteringer, er det lettere å bruke mål som er enkle å huske, noe som letter spillopplevelsen.

#### Vindtabell

| MPH | Type | Effekt på ferdigheter | Effekt på bevegelse |
| :-: | :-- | :-- | :-- |
| 0-10 | Stille | Ingen | Ingen |
| 11-20 | Lett bris | Ingen | Ingen |
| 21-30 | Frisk bris | Ingen | To tredjedeler |
| 31-40 | Lett kuling | Vanskelig | To tredjedeler |
| 41-50 | Laber kuling | Vanskelig | Halvparten |
| 51-60 | Stiv kuling | Formidabel | Halvparten |
| 60+ | Storm/orkan | Formidabel | En tredjedel |

Vind, spesielt svært sterk vind, kan ha en negativ effekt på aktivitet. Vindens styrke (STR) uttrykkes i miles per time (MPH). Effekten på fysiske ferdigheter – de som involverer STR eller DEX – er detaljert i kolonnen for ferdigheter; effekter på bevegelseshastighet er i kolonnen for bevegelse.
 
_For eksempel reduserer en lett kuling med STR 40 menneskers ganghastighet til to tredjedeler, og ferdighetskast utføres med vanskelighetsgraden "Vanskelig"._

#### Temperaturtabell

| Temperatur (ºF) | Type | Risiko |
| :-: | :-: | :-- |
| < 2º | Glasial | Søk varme umiddelbart |
| 3-14º | Frost | 15 minutter |
| 13-32º | Kaldt | Hver time |
| 33-50º | Kjølig | Hver dag |
| 51-68º | Mildt | - |
| 69-86º | Varmt | - |
| > 86º | Hett | Hver time |

Temperaturen kan variere dramatisk basert på klima, årstid og høyde, avhengig av kampanjeverdenen og hvor scenariene utspiller seg. Tabellen ovenfor gir en veiledning for effektene av ekstreme temperaturer på figurer.

Ved å bruke egnede klær får en figur en nådeperiode tilsvarende sin CON i timer før eksponeringen begynner, som vist i risikokolonnen. Etter dette punktet må de søke ly eller begynne å lide av tretthetstap (Fatigue loss). Figurer som er våte, forskyver risikonivået ett trinn ned mot kaldere temperaturer. Lett eller moderat kuling forskyver også risikonivået ett trinn, mens stiv kuling og storm forskyver det to trinn.
