# Προαπαιτούμενα

1. Μια βασική κατανόηση της [γλώσσας markdown](https://www.markdownguide.org/basic-syntax/).

2. Θα χρειαστεί να δημιουργήσετε έναν δωρεάν [λογαριασμό στο GitHub](https://github.com/), αν δεν έχετε ήδη. Συνιστούμε να χρησιμοποιήσετε το όνομα του RPG σας, καθώς αυτό θα αποτελέσει μέρος του URL που θα χρησιμοποιεί ο κόσμος για να αποκτήσει πρόσβαση στο SRD σας.

3. Μπορείτε να κάνετε όλη αυτή τη διαδικασία μέσω του προγράμματος περιήγησης χωρίς να γνωρίζετε git. Παρόλο που η εκμάθηση του GitHub Desktop θα σας επιτρέψει να δοκιμάσετε τυχόν αλλαγές τοπικά πριν τις δημοσιεύσετε για να τις δει ο κόσμος.

> Αν έχετε κατοχυρωμένο όνομα τομέα (domain name), μπορείτε να το χρησιμοποιήσετε σε αυτή τη διαδικασία για να δημιουργήσετε ένα SRD όπως έχω κάνει εγώ https://srd.7thextinctionrpg.com

# Η Διαδικασία

## Δημιουργία του Αποθετηρίου (Repository) στο Github

1. Συνδεθείτε στο Github

2. Μεταβείτε στο δημόσιο πρότυπο https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Κάντε κλικ στο "Use this template"

![Step3](/_media/Step3.png)

4. Επιλέξτε "Create a new repository"

5. Εισαγάγετε ένα όνομα αποθετηρίου

![Step5](/_media/Step5.png)

6. Επιλέξτε 'Private' (Ιδιωτικό)

7. Επιλέξτε 'Create repository'

Θα χρειαστούν 5-30 δευτερόλεπτα για να αντιγραφεί το πρότυπο, και μετά θα έχετε το δικό σας αντίγραφο.

8. Βεβαιωθείτε ότι έχετε το αρχείο ".nojekyll", πρόκειται για ένα κενό αρχείο που είναι απαραίτητο κατά τη φιλοξενία μιας ιστοσελίδας στο Github, αλλιώς το SRD δεν θα εμφανίζεται σωστά. *(Λέει στο GitHub Pages να μην επεξεργάζεται τα δημοσιευμένα αρχεία μέσω του Jekyll).*


## Προσθήκη του Περιεχομένου σας

### Αρχεία *.md

Τα αρχεία .md είναι αρχεία markdown. Το Markdown είναι μια ελαφριά γλώσσα σήμανσης που μπορείτε να χρησιμοποιήσετε για να προσθέσετε στοιχεία μορφοποίησης σε έγγραφα απλού κειμένου. Ανάλογα με το μέγεθος του περιεχομένου σας, μπορείτε είτε να τοποθετήσετε όλες τις πληροφορίες του παιχνιδιού σας σε ένα μόνο αρχείο *.md, είτε, όπως έχω κάνει εγώ στο [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), να δημιουργήσετε ξεχωριστά αρχεία για κάθε κεφάλαιο. Το "Sample.md" παρέχει ορισμένα παραδείγματα μορφοποίησης.

Η γλώσσα Markdown είναι πολύ εύκολη στην εκμάθηση, χρησιμοποιήστε τον σύνδεσμο που παρέχεται στο σημείο 2 στα Προαπαιτούμενα παραπάνω για μια πλήρη λίστα σύνταξης.

### _sidebar.md

Αυτό είναι το μενού σας, το πλαίσιο πλοήγησης στην αριστερή πλευρά της ιστοσελίδας. Μόλις προσθέσετε ένα αρχείο markdown στο αποθετήριό σας, πρέπει να προσθέσετε το αρχείο εδώ ώστε να συμπεριληφθούν τα περιεχόμενά του. Ακολουθήστε την υπάρχουσα μορφοποίηση.


## Ενεργοποίηση του Github Pages για τη μετατροπή του Αποθετηρίου σε Ιστοσελίδα

1. Στο αποθετήριό σας κάντε κλικ στο 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. Επιλέξτε 'Pages' από το μενού στην αριστερή πλευρά

![Website-Step2](/_media/Website-Step2.png)

3. Αν δεν έχετε κάνει το αποθετήριο 'public' (δημόσιο), έχετε δύο επιλογές:
    a. Κάντε το αποθετήριο δημόσιο, το οποίο θα σας επιτρέψει στη συνέχεια να χρησιμοποιήσετε το Github pages για να φιλοξενήσετε την SRD ιστοσελίδα σας δωρεάν
    b. Αναβαθμίστε τον λογαριασμό σας στο Github (τη στιγμή που γράφεται αυτό, κοστίζει 4 δολάρια τον μήνα ή 48 δολάρια ετήσια συνδρομή)

4. Στην ενότητα 'Branch' επιλέξτε 'main' και κάντε κλικ στο Save

5. Περιμένετε 10-20 δευτερόλεπτα και μετά ανανεώστε τη σελίδα

6. Τώρα θα δείτε το URL σας, όπως για παράδειγμα https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## Χρήση του πρόσθετου Fontawesome ή/και Material Icons για την εμφάνιση δωρεάν εικονιδίων στο SRD σας

### Fontawesome

Χρησιμοποιήστε το Fontawesome για να αποκτήσετε δωρεάν εικονίδια και κινούμενα εικονίδια. Οι εγγεγραμμένοι χρήστες μπορούν να χρησιμοποιούν Pro Icons.

1. Βρείτε το εικονίδιο στο [Fontawesome](https://fontawesome.com/icons)
2. Επιλέξτε το εικονίδιο
3. Στο αναδυόμενο παράθυρο, κάτω από την καρτέλα HTML αντιγράψτε τα πάντα ανάμεσα στα " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Τοποθετήστε το κείμενο που αντιγράψατε ανάμεσα στα `:` χωρίς κενά

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Χρησιμοποιήστε τα Material Icons για περισσότερα δωρεάν εικονίδια

1. Βρείτε τα εικονίδια στο [Material Icons](https://fonts.google.com/icons)
2. Αντιγράψτε & εισαγάγετε τον σύνδεσμο web span απευθείας στα αρχεία markdown σας

```markup
<span class="material-icons">face</span>
```
