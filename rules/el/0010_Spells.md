#### Appraise

(Μαντεία)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 0 | **Χρόνος Εκμαγείας:** 1 Γύρος |
| **Σφαίρα:** Καμία | **Διάρκεια:** Άμεση |
| **Κόστος:** 1 | **Εμβέλεια:** Αφή |
| **Περιοχή:** 1 Αντικείμενο | **Αντίσταση:** Καμία |

Το Appraise επιτρέπει την άμεση εκτίμηση της ποιότητας φυσικών αγαθών με συνδυασμένο ENC σε 'Πράγματα' ή SIZ ίσο με το POW του μάγου. Το ξόρκι προσδιορίζει αν αντικείμενα που μοιάζουν πανομοιότυπα είναι της ίδιας ή παρόμοιας ποιότητας, ή αν ένα ή περισσότερα είναι ελαττωματικά ή ανώτερης ποιότητας. Το ξόρκι δεν λειτουργεί σε οργανικά πράγματα, μόνο σε άψυχα αντικείμενα. Ούτε καθορίζει ποια ελαττώματα ή βελτιώσεις υπάρχουν· απλώς ότι υπάρχουν. Δεν είναι χρήσιμο στην αναγνώριση ή ανίχνευση μαγείας.

#### Armor

(Επίκληση)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 1 | **Χρόνος Εκμαγείας:** 1 Γύρος |
| **Σφαίρα:** Καμία | **Διάρκεια:** Δείτε παρακάτω |
| **Κόστος:** 3 +1/Ένταση | **Εμβέλεια:** Αφή |
| **Περιοχή:** 1 Στόχος | **Αντίσταση:** Καμία |

Όταν εκτοξεύεται αυτό το ξόρκι, το υποκείμενο προικίζεται με ένα αόρατο πεδίο μαγικής δύναμης ίσο με πανοπλία λέπιας στην προστασία, παρέχοντας 4 Πόντους Πανοπλίας σε κάθε Σημείο Χτυπήματος. Δεν έχει καμία επίδραση αν εκτοξευθεί σε κάποιον που φορά ήδη πανοπλία. Ωστόσο, θα υπερισχύσει της φυσικής πανοπλίας για τη Διάρκειά του, υποθέτοντας ότι προσφέρει ανώτερη προστασία. Αν εκτοξευθεί σε πλάσμα που διαθέτει περισσότερους από 4 πόντους φυσικής πανοπλίας, θα αυξήσει αντίθετα τους Πόντους Πανοπλίας κατά 1 σε όλες τις τοποθεσίες. Αυτή η μαγική προστασία δεν εμποδίζει την κίνηση ή την εκτόξευση ξορκιών. Το ξόρκι θα παραμείνει μέχρι να διαλυθεί από μαγεία, ή ο μάγος υποστεί 8 πόντους ζημιάς από μία μόνο επίθεση, +1 ανά επίπεδο πρόσθετης Έντασης (δείτε τον παρακάτω πίνακα). Φυσικά, ο μάγος μπορεί να επιλέξει να διακόψει το ξόρκι ανά πάσα στιγμή αν το επιθυμεί και πρέπει να το κάνει για να κοιμηθεί.

| Ένταση | Κόστος | Μεταβλητό Αποτέλεσμα |
| :-: | :-: | :-- |
| 1 | 3 | 4 Πόντοι Πανοπλίας; Διατηρείται μέχρι να υποστεί 8 ζημιά από 1 επίθεση |
| 2 | 4 | 4 Πόντοι Πανοπλίας; Διατηρείται μέχρι να υποστεί 9 ζημιά από 1 επίθεση |
| 3 | 5 | 4 Πόντοι Πανοπλίας; Διατηρείται μέχρι να υποστεί 10 ζημιά από 1 επίθεση |
| 4 | 6 | 4 Πόντοι Πανοπλίας; Διατηρείται μέχρι να υποστεί 11 ζημιά από 1 επίθεση |
| +1 | +1 | Συνέχιση προόδου |

#### Astral Spell

(Μεταστοιχείωση)

| | |
| :-- | :-- |
| **Βαθμός:** Ιερέας 5, Μάγος 5 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Αστρική | **Διάρκεια:** Δείτε παρακάτω |
| **Κόστος:** 3 +1/πρόσθετη Ένταση | **Εμβέλεια:** Αφή |
| **Περιοχή:** Δείτε παρακάτω | **Αντίσταση:** N/A |

Αυτό το ξόρκι επιτρέπει στον μάγο και έως πέντε άλλους (έναν ανά πρόσθετο επίπεδο Έντασης) να εισέλθουν στο Αστρικό Επίπεδο. Όλοι πρέπει να αγγίζονται και να σχηματίζουν κύκλο ενώ εκτοξεύεται το ξόρκι. Τα σώματα των ταξιδιωτών αφήνονται πίσω στο επίπεδο προέλευσης, και συνήθως δεν φέρουν μαζί τους ρούχα ή εξοπλισμό, εκτός από ό,τι ακτινοβολεί μαγική αύρα· αυτά τα αντικείμενα μεταμορφώνονται σε αστρικά αντίστοιχα της κανονικής τους μορφής. Η Διάρκεια διαρκεί μέχρι ο μάγος να επιθυμήσει να σταματήσει. Ωστόσο, είναι δυνατόν να τερματιστεί πρόωρα από εξωτερική δύναμη όπως το Dispel Magic. Η θανάτωση του φυσικού σώματος του μάγου τερματίζει επίσης το ξόρκι νωρίς, αν και αυτό έχει την ατυχή παρενέργεια του εγκλωβισμού τυχόν ταξιδιωτών που συνοδεύουν τον μάγο.

#### Augury

(Μαντεία)

| | |
| :-- | :-- |
| **Βαθμός:** Ιερέας 2 | **Χρόνος Εκμαγείας:** 2 Λεπτά |
| **Σφαίρα:** Μαντεία | **Διάρκεια:** Άμεση |
| **Κόστος:** 3/Ένταση | **Εμβέλεια:** 60 πόδια; |
| **Περιοχή:** Μάγος | **Αντίσταση:** N/A |

Αυτό το ξόρκι επιτρέπει στον μάγο να καθορίσει αν μια συγκεκριμένη ενέργεια που θα ληφθεί εντός των επόμενων 30 λεπτών θα είναι ωφέλιμη ή επιζήμια για την ευημερία ενός ατόμου ή/και ομάδας. Απαιτείται ένα εστιακό σημείο κάποιου τύπου για να διακριθούν οι οιωνοί, με τα πιο κοινά να είναι τα νύχια ή μικρότερα οστά ενός δράκου, ένα μαργαριτάρι, ή καθαρός χρυσός αξίας τουλάχιστον 100GP, που έχει συνθλιβεί ή λιώσει. Το ξόρκι έχει Μέγιστη Ένταση 4. Αυτή η ζαριά πρέπει να γίνει από τον Games Master, καθώς ο μάγος δεν πρέπει ποτέ να ξέρει πέρα από κάθε αμφιβολία αν τα αποτελέσματα ερμηνεύτηκαν σωστά.

| Ένταση | Κόστος | Μεταβλητό Αποτέλεσμα |
| :-: | :-: | :-- |
| 1 | 3 | Ζαριά ικανότητας Formidable Channel |
| 2 | 6 | Ζαριά ικανότητας Hard Channel |
| 3 | 9 | Ζαριά ικανότητας Standard Channel |
| 4 | 12 | Ζαριά ικανότητας Easy Channel |

Αν η ζαριά μαντείας πετύχει, παρέχει ένα από τα ακόλουθα αποτελέσματα:

| Augury | Συνέπεια | 
| :-: | :-- |
| Yes | Η ενέργεια θα είναι ωφέλιμη |
| No | Η ενέργεια θα είναι επιζήμια |
| Yes and No | Η ενέργεια θα είναι και ωφέλιμη και επιζήμια |
| Nothing | Η ενέργεια δεν θα είναι ούτε ωφέλιμη ούτε επιζήμια |

Ένα Fumble θα πρέπει να έχει ως αποτέλεσμα ο Games Master να πει το αντίθετο της πραγματικότητας.

#### Befuddle

(Γοητεία (Γοητεία))

| | |
| :-- | :-- |
| **Βαθμός:** Ιερέας 0, Μάγος 0 | **Χρόνος Εκμαγείας:** 1 Γύρος |
| **Σφαίρα:** Γοητεία | **Διάρκεια:** 30 Λεπτά |
| **Κόστος:** 1 | **Εμβέλεια:** 60 πόδια |
| **Περιοχή:** 1 Στόχος | **Αντίσταση:** Willpower |

Το Befuddle προκαλεί σύγχυση στο μυαλό ενός υλικού στόχου. Το υποκείμενο του ξορκιού δυσκολεύεται να σκεφτεί καθαρά, ξεχνώντας πού βρίσκεται, τι κάνει, και γιατί – συχνά υποπίπτοντας σε αποσυνδεδεμένες γραμμές σκέψης. Οι μπερδεμένοι στόχοι μπορούν ακόμα να δράσουν για αυτοάμυνα αλλά δεν μπορούν να ξεκινήσουν καμία εποικοδομητική δραστηριότητα μέχρι να λήξει το ξόρκι. Οποιαδήποτε επίθεση ή απειλητική ενέργεια σπάει αμέσως το ξόρκι, είτε στράφηκε ειδικά στον μπερδεμένο στόχο είτε όχι.

#### Blade Barrier

(Εξέγερση)

| | |
| :-- | :-- |
| **Βαθμός:** Ιερέας 4 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Φύλακας, Δημιουργία | **Διάρκεια:** 3 Γύροι/Ένταση |
| **Κόστος:** 3+1/πρόσθετη Ένταση | **Εμβέλεια:** 100 πόδια |
| **Περιοχή:** 5-30 πόδια ακτίνα | **Αντίσταση:** Δείτε παρακάτω |

Αυτό το ξόρκι δημιουργεί ένα φράγμα από σπαθιά, στιλέτα και μαχαίρια που περιστρέφονται και τεμαχίζουν γύρω από ένα σταθερό σημείο και προκαλούν 1d8 πόντους ζημιάς σε 1d4+2 τυχαία Σημεία Χτυπήματος οποιουδήποτε περνά μέσα από την Περιοχή Επίδρασης. Η πανοπλία προσφέρει μόνο τη μισή της κανονική προστασία. Οι Πόντοι Μαγικής Πανοπλίας μειώνουν τη ζημιά κανονικά. Επειδή τα όπλα περιστρέφονται με εκτυφλωτική ταχύτητα και είναι στενά πακεταρισμένα, είναι αδύνατο να τα Parry ή Evade. Κάποιος μπορεί να χρησιμοποιήσει μια ασπίδα για να μπλοκάρει παθητικά τα Σημεία Χτυπήματος κανονικά. Σε αυτή την περίπτωση, θυμηθείτε να συγκρίνετε τη ζημιά που προέκυψε με την πανοπλία και τους Πόντους Ζωής της ασπίδας.

Το ξόρκι μπορεί να εκτοξευθεί αμυντικά για την προστασία του ιερέα ή ενός ή περισσότερων συμμάχων ή επιθετικά για να παγιδεύσει εχθρούς. Ωστόσο, οι εχθροί που είναι κυκλωμένοι εντός πέντε ποδιών από την άκρη του φράγματος καθώς σχηματίζεται, μπορούν να κάνουν μια ζαριά Evade για να ξεφύγουν. Ανεξάρτητα από την επιτυχία, ο αντίπαλος καταλήγει πρηνής, ακριβώς έξω από την Περιοχή Επίδρασης. Μια επιτυχημένη ζαριά έχει ως αποτέλεσμα μηδενική ζημιά· διαφορετικά, υφίστανται το πλήρες αποτέλεσμα.

| | |

Το Burning Hands έχει πιθανότητα ανάφλεξης εύφλεκτων υλικών ίση με τη ζημιά που προέκυψε x5%. Δείτε την ενότητα [Φωτιές](0007_Game_System.md?id=fire-based-attacks) για πρόσθετες πληροφορίες.

#### Chain Lightning

(Εξέγερση)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 4 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Καμία | **Διάρκεια:** Άμεση |
| **Κόστος:** 3+1/πρόσθετη Ένταση | **Εμβέλεια:** 50 πόδια/Ένταση |
| **Περιοχή:** Δείτε παρακάτω | **Αντίσταση:** Evade |

Κατά την εκτόξευση, ο μάγος απελευθερώνει μια αστραπή πάχους πέντε ποδιών από τα δάχτυλά του που μπορεί να χτυπήσει έναν στόχο εντός εμβέλειας για 1d6+1 πόντους ζημιάς ανά 2 Έντασης. Η αστραπή στη συνέχεια καμπυλώνει προς το επόμενο πλησιέστερο αντικείμενο ή πλάσμα, το οποίο δέχεται τη ζημιά που υπολογίστηκε προηγουμένως μείον 1 πόντο, και μετά καμπυλώνει προς το επόμενο πλησιέστερο, προκαλώντας τη ζημιά μείον 2 πόντους, και ούτω καθεξής. Θα μπορούσε ακόμη και να καμπυλώσει πίσω σε σύμμαχο ή στον μάγο! Ενώ ο αρχικός στόχος πρέπει να είναι ορατός στον μάγο, οι στόχοι που χτυπήθηκαν από μια καμπυλωτή αστραπή δεν χρειάζεται να είναι.

Κάθε καμπύλη έχει τη δική της εμβέλεια 50 ποδιών, η οποία μπορεί να τοποθετήσει την αστραπή πέρα από την αρχική εμβέλεια όταν εκτοξεύτηκε το ξόρκι. Το Chain Lightning συνεχίζει να χτυπά αν έχει απομείνει ζημιά μέχρι να χτυπήσει ένα αντικείμενο που το αναγκάζει να γειωθεί (ένα μεταλλικό κλουβί ή κάγκελα, μεγάλη λίμνη νερού κ.λπ.) ή δεν υπάρχουν άλλα διαθέσιμα αντικείμενα ή πλάσματα για να χτυπήσει.

Κάθε πλάσμα που χτυπιέται δέχεται τη ζημιά σε ένα μόνο Σημείο Χτυπήματος, με τη φορεμένη πανοπλία να μην προσφέρει καμία προστασία, και τη φυσική πανοπλία και τους μαγικούς Πόντους Πανοπλίας να μειώνουν τη ζημιά κανονικά.

Με μια επιτυχημένη ζαριά Evade, ρίχνοντας τον εαυτό πρηνή, το θύμα δεν υφίσταται ζημιά. Κάποιος με την ικανότητα Artful Dodger μπορεί να κάνει Evade χωρίς να πέσει πρηνής, αλλά μια Επιτυχία σε αυτή την περίπτωση μειώνει τη ζημιά μόνο κατά το ήμισυ, εκτός αν βρίσκονται εντός πέντε ποδιών από την άκρη της Περιοχής Επίδρασης.

| :-: | :-: | :-- |
| 1 | 3 | 50-πόδια εμβέλεια; 1d6+1 ζημιά |
| 2 | 4 | 100-πόδια εμβέλεια; 1d6+1 ζημιά |
| 3 | 5 | 150-πόδια εμβέλεια; 2d6+2 ζημιά |
| 4 | 6 | 200-πόδια εμβέλεια; 2d6+2 ζημιά |
| 5 | 7 | 250-πόδια εμβέλεια; 3d6+3 ζημιά |
| +1 | +1 | Συνέχιση προόδου |

#### Charm Person

(Γοητεία (Γοητεία))

| | |
| :-- | :-- |

Όταν εκτοξεύεται αυτό το ξόρκι, ένας ζωντανός (τα απέθαντα πλάσματα δεν επηρεάζονται) νοήμονας ανθρωποειδής στόχος SIZ 1-20 θα σταματήσει κάθε εχθροπραξία κατά του μάγου και των συμμάχων του, και αντ' αυτού θα προσφέρει βοήθεια και προστασία αν ο στόχος αποτύχει στη ζαριά Αντίστασης. Σημείωση: Αν άλλοι αμφισβητήσουν τη φύση της Γοητείας, ο στόχος μπορεί επίσης να κάνει μια ζαριά Αντίστασης, κατά τη διακριτική ευχέρεια του Games Master. Ο μάγος πρέπει να είναι σε θέση να μιλήσει με τον γοητευμένο για να του δώσει οποιοδήποτε είδος σύνθετου "αιτήματος"· επομένως, η γνώση της γλώσσας του στόχου μπορεί να είναι σημαντική, αλλά δεν απαιτείται για τη βασική Γοητεία.

Τα αποτελέσματα είναι συνεχιζόμενα μέχρι να γίνει μια επιτυχημένη ζαριά Αντίστασης. Η εκτόξευση του Charm Person σε υψηλότερα επίπεδα Έντασης απαιτεί μάγο υψηλότερου Βαθμού και έχει μέγιστη Διάρκεια 4 εβδομάδες. #### Command

(Γοητεία (Γοητεία))

Το Cone of Cold έχει πιθανότητα να καλύψει ένα θύμα με ένα στρώμα πάγου ίση με τη ζημιά που προέκυψε (μετά την τροποποίηση) x5%. #### Continual Light

(Μεταστοιχείωση)

Αυτό το ξόρκι δημιουργεί μια σφαίρα φωτός ισοδύναμη σε φωτεινότητα με το φως της ημέρας σε ένα σημείο που επιλέγει ο μάγος, το οποίο μπορεί να είναι ένα αντικείμενο ή ακόμα και στον αέρα. Τα πλάσματα με αποστροφή στο φως της ημέρας υποφέρουν τις κανονικές ποινές που σχετίζονται με αυτό όταν βρίσκονται εντός της σχετικής Περιοχής Επίδρασης. Αν εκτοξευθεί πάνω σε ένα πλάσμα, ο στόχος έχει το δικαίωμα για ένα τεστ Willpower για να αντισταθεί, με μια Επιτυχία να υποδεικνύει ότι το ξόρκι έχει επηρεάσει την περιοχή ακριβώς πίσω από το πλάσμα και όχι το ίδιο το πλάσμα. Αν εστιαστεί στα μάτια ενός πλάσματος, μια αποτυχημένη ζαριά Willpower έχει ως αποτέλεσμα μερική τύφλωση, αυξάνοντας τη δυσκολία όλων των ζαριών ικανότητας και Αντίστασης που απαιτούν όραση κατά μία βαθμίδα. Η όραση μπορεί να αποκατασταθεί μόνο με την εκτόξευση Cure Blindness and Deafness σε οποιαδήποτε Ένταση, ή με την εκτόξευση Dispel Magic σε Ένταση μεγαλύτερη από το Μέγεθος του Continual Light. Τα αποτελέσματα του ξορκιού είναι ακίνητα αλλά μπορούν να εκτοξευθούν σε φορητό ή μετακινούμενο αντικείμενο.

#### Dimension Door

(Μεταστοιχείωση)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 3 | **Χρόνος Εκμαγείας:** 1 Ενέργεια |
| **Σφαίρα:** Καμία | **Διάρκεια:** Άμεση |

| **Περιοχή:** Μάγος | **Αντίσταση:** N/A |

Το Dimension Door είναι μια μορφή τηλεμεταφοράς μικρής εμβέλειας. Ο μάγος πηδά αμέσως έως και 100 πόδια ανά Ένταση χωρίς να διασχίσει τον ενδιάμεσο χώρο, χωρίς πιθανότητα σφάλματος. Η επιθυμητή τοποθεσία μπορεί είτε να είναι οπτικά ορατή είτε να καθοριστεί με κατεύθυνση: 40 πόδια κατευθείαν μπροστά, 65 πόδια κάτω, 45° αριστερά, κ.λπ. Όλος ο φυσικά μεταφερόμενος εξοπλισμός (μη ζωντανή, άψυχη ύλη) πηδά μαζί με τον μάγο. Ζωντανή ύλη όχι μεγαλύτερη από 20 SIZ μπορεί να συνοδεύσει τον μάγο. Για παράδειγμα, ένας χαρακτήρας SIZ 11 μπορεί να πηδήξει μαζί με τον μάγο υποθέτοντας ότι και οι δύο αγγίζονται. Ο μάγος, και οποιοδήποτε ζωντανό πλάσμα μεταφέρεται επίσης, απαιτεί έναν πλήρη Γύρο για να ανακάμψει. Αν δεχτεί επίθεση κατά τη διάρκεια αυτού του χρόνου, τέτοια άτομα δεν μπορούν να κάνουν περισσότερα από το να αμυνθούν.

#### Dispel Magic

(Αποτροπή)

| | |
| :-- | :-- |
| **Βαθμός:** Ιερέας 2, Μάγος 2 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Προστασία | **Διάρκεια:** Άμεση |
| **Κόστος:** 1 | **Εμβέλεια:** 360 πόδια |
| **Περιοχή:** 15 πόδια Ακτίνα | **Αντίσταση:** N/A |

Το Dispel Magic μπορεί να εκτοξευθεί είτε κατά ενός συγκεκριμένου στόχου είτε κατά μιας σημειωμένης περιοχής, και μόλις εκτοξευθεί, όλη η μαγεία εντός ακτίνας 15 ποδιών από το σημείο στόχου είναι επιρρεπής σε απόρριψη. Τερματίζει τα συνεχιζόμενα ξόρκια στον στόχο του αλλά δεν κάνει τίποτα σε άλλα μαγικά αποτελέσματα. Δεν έχει καμία επίδραση σε μαγικά πλάσματα ή τους απέθαντους. Το Dispel Magic εξαλείφει όλη την άλλη μαγεία στην Περιοχή Επίδρασης με Μέγεθος μικρότερο από την Ένταση του ξορκιού. Η εξαίρεση σε αυτό θα ήταν τα μαγικά αντικείμενα και τα θύματα ξορκιών τύπου γοητείας όπως το Charm Person, τα οποία πρέπει να στοχευθούν ξεχωριστά. Τα αποτελέσματα ενός ξορκιού δεν μπορούν να εξαλειφθούν μερικά.

Το Dispel Magic ξεκινά με την πιο ισχυρή μαγεία στην Περιοχή Επίδρασης. Αν αποτύχει να εξαλείψει οποιοδήποτε ξόρκι (επειδή το Μέγεθος του ξορκιού είναι πολύ υψηλό), τότε το ξόρκι τερματίζεται, και δεν μπορεί να εξαλειφθεί άλλη μαγεία.

Το Dispel Magic μπορεί να χρησιμοποιηθεί αμυντικά για την εξουδετέρωση εισερχόμενων επιθετικών ξορκιών, χρησιμοποιώντας την Αντιδραστική Ενέργεια Counter Spell.

#### Enchant Item

(Γοητεία)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 4 | **Χρόνος Εκμαγείας:** Δείτε παρακάτω |
| **Σφαίρα:** Καμία | **Διάρκεια:** Δείτε παρακάτω |
| **Κόστος:** 3 + Δείτε παρακάτω | **Εμβέλεια:** Αφή |
| **Περιοχή:** 1 Αντικείμενο | **Αντίσταση:** N/A |

Η εκτόξευση αυτού του ξορκιού προετοιμάζει ένα αντικείμενο για Γοητεία. Το αντικείμενο πρέπει να είναι σε καλή κατάσταση και της καλύτερης κατασκευής και δεξιοτεχνίας. Απαιτείται επιπλέον κόστος τουλάχιστον 100GP για να καλυφθεί το κόστος επιπλέον εργαλείων, σκάλισμα, κέντημα, κοσμήματα, χαρακτική κ.λπ. Τέλος, η διαδικασία Γοητείας απαιτεί εργαστήριο ή εργαστήριο.

Κατά την εκτόξευση του ξορκιού, ο χρήστης μαγείας πρέπει να αγγίζει το αντικείμενο καθ' όλη τη διάρκεια του Χρόνου Εκμαγείας των 1d8+2 ημερών. Αυτό δικαιολογεί περιόδους ανάπαυσης και ύπνου, κατά τη διάρκεια των οποίων το αντικείμενο πρέπει να παραμένει σε απόσταση ενός χεριού από τον μάγο. Σε καμία στιγμή κατά την εκτόξευση ο χρήστης μαγείας δεν μπορεί να εκτοξεύσει άλλο ξόρκι ή να εκτελέσει οποιαδήποτε άλλη μορφή μαγείας. Η παραβίαση οποιουδήποτε από αυτούς τους περιορισμούς θα προκαλέσει αυτόματα την αποτυχία του ξορκιού.

Μόλις εκτοξευθεί με επιτυχία, το αντικείμενο είναι έτοιμο για το τελευταίο βήμα, με τον μάγο να τοποθετεί το επιθυμητό ξόρκι σε αυτό. Για να το κάνει, πρέπει να έχει το ξόρκι στη μνήμη ή σε πάπυρο και να το εκτοξεύσει στο αντικείμενο εντός 24 ωρών, διαφορετικά ολόκληρη η διαδικασία θα πρέπει να ξεκινήσει από την αρχή. Μόλις ξεκινήσει η εκτόξευση του επιλεγμένου ξορκιού, η διαδικασία μπορεί να υπερβεί τις προαναφερθείσες 24 ώρες. Η εμποτισμός του αντικειμένου με το επιλεγμένο ξόρκι κοστίζει τον κανονικό αριθμό Μαγικών Πόντων για την επιθυμητή Ένταση και παίρνει 1d12 ώρες ανά Βαθμό ξορκιού. Καθ' όλη τη διάρκεια της διαδικασίας εμποτισμού, ο μάγος πρέπει να παραμένει αγγίζοντας το αντικείμενο ή να παραμένει σε απόσταση χεριού κατά τη διάρκεια περιόδων ανάπαυσης, όπως παραπάνω, και απαιτείται ζαριά Arcane Casting στο τέλος της περιόδου εκτόξευσης για να εμποτιστεί με επιτυχία το ξόρκι. Ακολουθούνται οι κανονικοί βαθμοί επιτυχίας Εκτόξευσης Ξορκιών, ωστόσο, όσον αφορά το αποτέλεσμα Αποτυχίας, το ξόρκι δεν μπορεί να εξαναγκαστεί. Διαδοχικά ξόρκια μπορεί να εμποτιστούν εντός του αντικειμένου, παρέχοντας η διαδικασία εκτόξευσης να ξεκινήσει εντός 24 ωρών από την ολοκλήρωση του προηγούμενου ξορκιού. Αυτό ισχύει ακόμη και στην περίπτωση ενός προηγουμένως αποτυχημένου ξορκιού. Κάθε διαδοχικό ξόρκι απαιτεί το κανονικό Κόστος Εκτόξευσης.

Κατά τη χρήση του αντικειμένου, κάθε ξόρκι που περιέχεται μπορεί να εκτοξευθεί μόνο μία φορά, ωστόσο πολλαπλές εκδόσεις του ίδιου ξορκιού μπορεί να εμποτιστούν ακολουθώντας την παραπάνω διαδικασία. Είναι επίσης δυνατόν να εμποτιστεί ένα μόνο ξόρκι, ακολουθούμενο από μια εκτόξευση του ξορκιού Βαθμού 4 Permanency. Σε αυτή την περίπτωση, το ξόρκι μπορεί να εκτοξευθεί όσο συχνά επιθυμείτε, ακολουθώντας τους περιορισμούς που ορίζονται στη γραφή του ξορκιού Permanency.

Δεν είναι δυνατός ο εμποτισμός άλλων μαγικών αποτελεσμάτων σε ένα αντικείμενο που δεν συμμορφώνονται με ένα συγκεκριμένο ξόρκι, και πολλά μαγικά αντικείμενα από παλαιότερες εποχές απλά δεν μπορούν να αναδημιουργηθούν στις μέρες μας.

| **Περιοχή:** ½ Μίλι Ακτίνα/Ένταση | **Αντίσταση:** N/A |

Αυτό το ξόρκι επιτρέπει στον μάγο να επιχειρήσει να καλέσει ένα εξοικειωμένο πλάσμα (familiar), το οποίο γίνεται προέκταση των αισθήσεων και της δύναμης του κυρίου του. Τα εξοικειωμένα πλάσματα μπορούν να συνομιλούν με τον κύριό τους τηλεπαθητικά και αποτελούν καλούς φύλακες και ανιχνευτές. Η θανάτωση του εξοικειωμένου πλάσματός σας παρουσιάζει ορισμένους κινδύνους για τον χρήστη μαγείας λόγω της στενής τους σύνδεσης, γεγονός που καθιστά το να έχει κανείς ένα εξοικειωμένο πλάσμα έναν κίνδυνο χαμηλού βαθμού.

Για να καλέσει ένα εξοικειωμένο πλάσμα, ο χρήστης μαγείας πρέπει να ξεκινήσει το τελετουργικό διατηρώντας ένα μαγκάλι γεμάτο με κάρβουνο, και όταν καίει με ένταση, να προσθέσει 100GP αξίας θυμιάματος. Με αυτά τα συστατικά να καίγονται, ο μάγος πρέπει στη συνέχεια να συνεχίσει το τελετουργικό μέχρι να φτάσει το εξοικειωμένο πλάσμα ή ο Χρόνος Εκμαγείας να λήξει χωρίς επιτυχία.

Ακόμα κι αν αυτό το ξόρκι εκτοξευθεί με επιτυχία, η πιθανότητα ενός κατάλληλου εξοικειωμένου πλάσματος να απαντήσει στο κάλεσμα του χρήστη μαγείας είναι μόνο 50%, και ο χρήστης μαγείας μπορεί να επιχειρήσει αυτό το ξόρκι μόνο μία φορά το χρόνο. Κάθε επιπλέον επίπεδο Έντασης πέραν του πρώτου επεκτείνει την Εμβέλεια του ξορκιού κατά άλλο μισό μίλι, το οποίο με τη σειρά του αυξάνει την πιθανότητα εύρεσης ενός πιθανού εξοικειωμένου πλάσματος κατά 5%, έως το μέγιστο του 95%. Δεν υπάρχει έλεγχος πάνω στον ακριβή τύπο πλάσματος που θα απαντήσει στο κάλεσμα, αλλά ό,τι φτάσει θα είναι ένας πιστός υπηρέτης και σύμμαχος. Εξαρτάται από το συγκεκριμένο πλάσμα να απαντήσει στο κάλεσμα, επομένως το να βρίσκεστε σε μια περιοχή γνωστή ότι κατοικείται από έναν ορισμένο τύπο πλάσματος δεν διασφαλίζει στον μάγο την επιτυχία.

Αν ένα πλάσμα απαντήσει στο κάλεσμα του μάγου, ο χρήστης μαγείας πρέπει ακόμη να θυσιάσει 1 Ζαριά Εμπειρίας (Experience Roll) για να δημιουργήσει έναν πνευματικό δεσμό μεταξύ τους. Μόλις γίνει αυτό, το τελετουργικό ολοκληρώνεται.

Ενώ το εξοικειωμένο πλάσμα και ο κύριός του βρίσκονται εντός 120 ποδών ο ένας από τον άλλο, ο χρήστης μαγείας αποκτά την ικανότητα να χρησιμοποιεί και τους Μαγικούς Πόντους του εξοικειωμένου πλάσματος. Επιπλέον, ο χρήστης μαγείας αποκτά τηλεπαθητικό δεσμό με το εξοικειωμένο πλάσμα και τυχόν επιπλέον ειδικές Ικανότητες ή μπόνους ικανότητας που σημειώνονται στους παρακάτω πίνακες.

Στην περίπτωση θανάτου του εξοικειωμένου πλάσματος, ο μάγος χάνει 5 Ζαριές Εμπειρίας. Ένας μάγος που δεν διαθέτει τρέχουσες Ζαριές Εμπειρίας πρέπει να παραιτηθεί από όλες τις περαιτέρω Ζαριές Εμπειρίας που απονέμονται μέχρι να εξοφληθεί το υπόλοιπο.

Ο τύπος του εξοικειωμένου πλάσματος που θα εμφανιστεί, αν υπάρξει, προσδιορίζεται σύμφωνα με τον παρακάτω πίνακα. Υπό τις περισσότερες συνθήκες, τα κοινά εξοικειωμένα πλάσματα δεν είναι εξαιρετικά μεγάλα, όντας μεταξύ SIZ 1-4, και χρησιμοποιούν τη γραφή Μικρού Ζώου.

#### Fireball

(Εξέγερση)

#### Fire Shield

(Εξέγερση)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 3 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Καμία | **Διάρκεια:** 2 Λεπτά/Ένταση |
| **Κόστος:** 3+1/πρόσθετη Ένταση | **Εμβέλεια:** 0 |
| **Περιοχή:** Μάγος | **Αντίσταση:** N/A |

Αυτό το ξόρκι δημιουργεί μια ασπίδα από λεπτές φλόγες που καίει τον μάγο αλλά δεν προκαλεί ζημιά από μόνη της. Αντίθετα, οι φλόγες προστατεύουν τον παραλήπτη είτε από τη φωτιά είτε από το κρύο, ανάλογα με ποια από τις δύο παραλλαγές βρίσκεται στη μνήμη: Chill Shield, που δημιουργεί μπλε ή πράσινες φλόγες και προστατεύει από ζημιά από θερμότητα και φωτιά, ή Warm Shield, που δημιουργεί βιολετί ή μπλε φλόγες και προστατεύει από ζημιά από κρύο και πάγο. Το χρώμα των φλογών πρέπει να καθοριστεί τυχαία με 50% πιθανότητα για καθεμία, καθώς το γεγονός ότι και οι δύο τύποι μπορούν να εκπέμπουν μπλε φλόγες δημιουργεί ένα στοιχείο αβεβαιότητας εκ μέρους οποιουδήποτε επιτιθέμενου. Η απόφαση για το ποιο να απομνημονεύσετε λαμβάνεται όταν προετοιμάζονται τα ξόρκια, και μπορούν να απομνημονευθούν και τα δύο αν επιθυμείτε. Αυτές οι φλόγες δεν εκπέμπουν θερμότητα και ρίχνουν φως στη μισή φωτεινότητα ενός πυρσού.

- **Chill Shield:** Αυτές οι φλόγες είναι κρύες στην αφή και μειώνουν οποιαδήποτε ζημιά από φωτιά ή θερμότητα στο μισό του συνόλου. Μια επιτυχημένη ζαριά Αντίστασης θα ακυρώσει όλη τη ζημιά. Η ζαριά Αντίστασης είναι μία βαθμίδα ευκολότερη και, στην περίπτωση του Evade, δεν θα καταστήσει τον αμυνόμενο πρηνή.
- **Warm Shield:** Αυτές οι φλόγες είναι ζεστές στην αφή και μειώνουν οποιαδήποτε ζημιά από κρύο στο μισό του συνόλου. Μια επιτυχημένη ζαριά Αντίστασης θα ακυρώσει όλη τη ζημιά. Η ζαριά Αντίστασης είναι μία βαθμίδα ευκολότερη και στην περίπτωση του Evade, δεν θα καταστήσει τον αμυνόμενο πρηνή.

Οι επιθέσεις μάχης κατά του παραλήπτη οποιασδήποτε παραλλαγής, είτε οπλισμένες είτε άοπλες, προκαλούν κανονική ζημιά εκτός αν χρησιμοποιούν ένα από τα στοιχεία που προστατεύονται. Σε αυτή την περίπτωση, ο μάγος προστατεύεται από το στοιχειακό μέρος της επίθεσης, και ο επιτιθέμενος δέχεται ζημιά ίση με εκείνη που προκλήθηκε. Η φορεμένη πανοπλία εκ μέρους του επιτιθέμενου δεν προσφέρει προστασία, αλλά οι μαγικοί Πόντοι Πανοπλίας ή η φυσική πανοπλία ενός πλάσματος μειώνουν τη ζημιά κανονικά. Τα πλάσματα με Έμφυτη Μαγική Αντίσταση μπορούν να διαλύσουν το Fire Shield σε μια επιτυχημένη ζαριά Willpower όταν χτυπηθεί για πρώτη φορά ο παραλήπτης. Αν η ζαριά Μαγικής Αντίστασης αποτύχει, ο αντίπαλος δεν μπορεί αργότερα να ακυρώσει το Fire Shield.

#### Flesh to Stone \(R\)

(Μεταστοιχείωση)

| | |
| :-- | :-- |
| **Βαθμός:** Μάγος 4 | **Χρόνος Εκμαγείας:** 2 Ενέργειες |
| **Σφαίρα:** Καμία | **Διάρκεια:** Μόνιμη |
| **Κόστος:** 3/Ένταση | **Εμβέλεια:** 30 πόδια/Ένταση |
| **Περιοχή:** 1 Στόχος | **Αντίσταση:** Willpower |

Όταν εκτοξεύεται, ένα θύμα εντός Εμβέλειας έχει το δικαίωμα για μια ζαριά Αντίστασης Willpower. Αν αποτύχει, αυτός και όλα τα φερόμενα και φορεμένα υπάρχοντα μεταμορφώνονται πλήρως σε συμπαγή πέτρα. Αυτή η μεταμόρφωση δεν είναι θάνατος, αλλά μάλλον μια μορφή ανασταλμένης κίνησης. Η εκτόξευση είτε της αναστραμμένης έκδοσης αυτού του ξορκιού, είτε ενός Wish, μπορεί να χρησιμοποιηθεί για να επαναφέρει το θύμα στη ζωή. Οποιαδήποτε ζημιά υποστεί το θύμα ενώ είναι πέτρα μεταφέρεται, ισχύοντας αμέσως μετά την αποκατάσταση. Τα Μεγάλα πλάσματα (SIZ 21-40) είναι λιγότερο ευάλωτα σε αυτό το ξόρκι με τη ζαριά Αντίστασης να είναι Εύκολη (Easy), και η ζαριά αντίστασης για τα Τεράστια πλάσματα (SIZ 41+) είναι Πολύ Εύκολη (Very Easy).

Η αναστροφή αυτού του ξορκιού, Stone to Flesh, χρησιμοποιείται για να αποκαταστήσει ένα θύμα και δεν απαιτείται καμία ζαριά αντίστασης. Ωστόσο, το ξόρκι μπορεί επίσης να αντιστραφεί για να μεταμορφώσει πέτρα που δεν ήταν ποτέ ζωντανή· χρησιμοποιούμενο με έναν από τους πολλούς δημιουργικούς τρόπους.

#### Floating Disk

Αυτή η ζημιά ρίχνεται μία φορά, και εφαρμόζεται σε κάθε Σημείο Χτυπήματος του στόχου, με τη φορεμένη και φυσική πανοπλία να μην προσφέρουν καμία προστασία, αλλά οι μαγικοί Πόντοι Πανοπλίας μειώνουν τη ζημιά κανονικά.

| | |
