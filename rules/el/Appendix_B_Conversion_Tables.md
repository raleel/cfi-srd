# Παράρτημα: Πίνακες Μετατροπής

---
#### Μετατροπή Αυτοκρατορικών Μονάδων Μέτρησης σε Μετρικές

Για να αποκτήσει το _Classic Fantasy Imperative_ μια πιο καθαρή παρουσίαση, να γίνει πιο ευανάγνωστο και να συμπυκνωθούν οι περιγραφές και οι πίνακες, η σειρά _Classic Fantasy Imperative_ θα επικεντρωθεί στις Αυτοκρατορικές μονάδες μέτρησης αντί για τον συνδυασμό Αυτοκρατορικών και Μετρικών. Οι Αυτοκρατορικές μονάδες επιλέχθηκαν για να διευκολύνουν τη μετατροπή υπάρχοντος υλικού, καθώς τα περισσότερα παιχνίδια, οι χάρτες μάχης (battlemats) και οι χάρτες που χρησιμοποιούνται από άλλα παιχνίδια του είδους αξιοποιούν το Αυτοκρατορικό σύστημα. Ωστόσο, για όσους επιθυμούν να χρησιμοποιήσουν το Μετρικό Σύστημα, οι πιο συχνά χρησιμοποιούμενες μονάδες βάρους και μέτρησης έχουν μετατραπεί χρησιμοποιώντας τους παρακάτω πίνακες. Επειδή συνήθως δεν έχουμε να κάνουμε με πραγματικά πλάσματα, ξόρκια, κ.λπ., μπορούμε να παρέχουμε κάποια ελαστικότητα στα βάρη και τα μέτρα που έχουμε επινοήσει για αυτά. Αντί να χρησιμοποιούμε ακριβείς μετατροπές, είναι ευκολότερο να χρησιμοποιούμε μία που μπορεί να απομνημονευτεί εύκολα, διευκολύνοντας έτσι το παιχνίδι.

#### Πίνακας Ανέμου

| Μίλια ανά ώρα | Τύπος | Επίδραση στις Δεξιότητες | Επίδραση στην Κίνηση |
| :-: | :-- | :-- | :-- |
| 0-10 | Άπνοια | Καμία | Καμία |
| 11-20 | Μέτριο αεράκι | Καμία | Καμία |
| 21-30 | Ισχυρό αεράκι | Καμία | Δύο Τρίτα |
| 31-40 | Ελαφρά θύελλα | Δύσκολο | Δύο Τρίτα |
| 41-50 | Μέτρια θύελλα | Δύσκολο | Μισή |
| 51-60 | Ισχυρή θύελλα | Τρομερό | Μισή |
| 60+ | Καταιγίδα/Τυφώνας | Τρομερό | Ένα Τρίτο |

Ο άνεμος, ειδικά οι πολύ ισχυροί άνεμοι, μπορεί να έχει αρνητική επίδραση στη δραστηριότητα. Η Ισχύς (ΔΥΝ) ενός ανέμου εκφράζεται σε μίλια ανά ώρα ταχύτητας. Η επίδρασή του στις σωματικές δεξιότητες – εκείνες που περιλαμβάνουν ΔΥΝ ή ΕΠΙ – περιγράφεται αναλυτικά στη στήλη "Δεξιότητες". Οι επιδράσεις στον Ρυθμό Κίνησης στη στήλη "Ρυθμός Κίνησης".
 
_Για παράδειγμα, μια Ελαφρά θύελλα ΔΥΝ 40 μειώνει την ταχύτητα βαδίσματος του ανθρώπου στα δύο τρίτα και οι δεξιότητες εκτελούνται με βαθμό δυσκολίας Δύσκολο._

#### Πίνακας Θερμοκρασίας

| Θερμοκρασία (ºF) | Τύπος | Κίνδυνος |
| :-: | :-: | :-- |
| < 2º | Παγετώδης | Αναζητήστε άμεση θέρμανση |
| 3-14º | Παγωμένος | 15 Λεπτά |
| 13-32º | Ψυχρός | Ωριαία |
| 33-50º | Κρύος | Καθημερινά |
| 51-68º | Δροσερός | - |
| 69-86º | Θερμός | - |
| > 86º | Καυτός | Ωριαία |

Η θερμοκρασία μπορεί να ποικίλλει δραματικά λόγω κλίματος, εποχής και υψομέτρου, ανάλογα με τον κόσμο της εκστρατείας και το πού διαδραματίζονται τα σενάρια. Ο παραπάνω πίνακας παρέχει μια κατευθυντήρια γραμμή για τις επιπτώσεις της ακραίας θερμοκρασίας στους χαρακτήρες.

Η χρήση κατάλληλης ενδυμασίας επιτρέπει στον χαρακτήρα μια περίοδο χάριτος ίση με την ΑΝΤ του σε ώρες πριν ξεκινήσει η έκθεση, όπως φαίνεται στη στήλη "Κίνδυνος". Μετά από αυτό το σημείο, πρέπει να αναζητήσουν καταφύγιο ή να αρχίσουν να υποφέρουν από απώλεια Κόπωσης. Οι βρεγμένοι χαρακτήρες μετατοπίζουν τον Ρυθμό Κινδύνου κατά μία βαθμίδα προς το ψυχρότερο. Οι ελαφροί ή μέτριοι θυελλώδεις άνεμοι μετατοπίζουν επίσης τον Ρυθμό Κινδύνου κατά μία βαθμίδα προς το ψυχρότερο, ενώ οι ισχυρές θύελλες και οι καταιγίδες τον μετατοπίζουν κατά δύο βαθμίδες.
