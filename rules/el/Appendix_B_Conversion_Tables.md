# Παράρτημα: Πίνακες Μετατροπής

---
#### Μετατροπή Αυτοκρατορικών Μονάδων Μέτρησης σε Μετρικές

Για να προσφέρει το _Classic Fantasy Imperative_ μια πιο καθαρή παρουσίαση, να γίνει πιο ευανάγνωστο και να συνοψιστούν οι περιγραφές και οι πίνακες, η σειρά _Classic Fantasy Imperative_ θα επικεντρωθεί στις αυτοκρατορικές μονάδες μέτρησης αντί για τον συνδυασμό αυτοκρατορικών και μετρικών. Οι αυτοκρατορικές μονάδες επιλέχθηκαν για να διευκολύνουν καλύτερα τη μετατροπή υπαρχόντων υλικών, καθώς οι περισσότερες περιπέτειες, χάρτες μάχης (battlemats) και χάρτες που χρησιμοποιούνται από άλλα παιχνίδια του είδους χρησιμοποιούν το αυτοκρατορικό σύστημα. Ωστόσο, για όσους επιθυμούν να χρησιμοποιήσουν το Μετρικό Σύστημα, τα πιο συχνά χρησιμοποιούμενα βάρη και μέτρα έχουν μετατραπεί χρησιμοποιώντας τους παρακάτω πίνακες. Επειδή συνήθως δεν έχουμε να κάνουμε με πλάσματα, ξόρκια κ.λπ. του πραγματικού κόσμου, μπορούμε να δώσουμε κάποια ελευθερία στα βάρη και τα μέτρα που έχουμε επινοήσει για αυτά. Αντί για ακριβείς μετατροπές, είναι ευκολότερο να χρησιμοποιηθούν τιμές που απομνημονεύονται εύκολα, διευκολύνοντας έτσι το παιχνίδι.

#### Πίνακας Ανέμου

| MPH (Μίλια ανά ώρα) | Τύπος | Επίδραση σε Δεξιότητες | Επίδραση στην Κίνηση |
| :-: | :-- | :-- | :-- |
| 0-10 | Άπνοια | Καμία | Καμία |
| 11-20 | Μέτριο αεράκι | Καμία | Καμία |
| 21-30 | Ισχυρό αεράκι | Καμία | Δύο Τρίτα |
| 31-40 | Ελαφρά θύελλα | Δύσκολη | Δύο Τρίτα |
| 41-50 | Μέτρια θύελλα | Δύσκολη | Μισή |
| 51-60 | Ισχυρή θύελλα | Εξαιρετικά δύσκολη | Μισή |
| 60+ | Καταιγίδα/Τυφώνας | Εξαιρετικά δύσκολη | Ένα Τρίτο |

Ο άνεμος, ειδικά οι πολύ ισχυροί άνεμοι, μπορεί να έχει αρνητική επίδραση στη δραστηριότητα. Η Ισχύς (STR) ενός ανέμου εκφράζεται σε μίλια ανά ώρα ταχύτητας. Η επίδρασή της στις σωματικές δεξιότητες – αυτές που περιλαμβάνουν STR ή DEX – περιγράφεται αναλυτικά στη στήλη Δεξιότητες· η επίδραση στο Ρυθμό Κίνησης στη στήλη Ρυθμός Κίνησης.
 
_Για παράδειγμα, μια Ελαφρά θύελλα με STR 40 μειώνει την ταχύτητα περπατήματος του ανθρώπου στα δύο τρίτα και οι δεξιότητες εκτελούνται με δυσκολία "Δύσκολη"._

#### Πίνακας Θερμοκρασίας

| Θερμοκρασία (ºF) | Τύπος | Κίνδυνος |
| :-: | :-: | :-- |
| < 2º | Παγετός | Αναζητήστε άμεσα ζεστασιά |
| 3-14º | Καταψυκτική | 15 Λεπτά |
| 13-32º | Κρύο | Ωριαίος |
| 33-50º | Ψυχρό | Ημερήσιος |
| 51-68º | Δροσερό | - |
| 69-86º | Θερμό | - |
| > 86º | Καυτό | Ωριαίος |

Η θερμοκρασία μπορεί να ποικίλλει δραματικά λόγω κλίματος, εποχής και υψομέτρου, ανάλογα με τον κόσμο της εκστρατείας και το πού διαδραματίζονται τα σενάρια. Ο παραπάνω πίνακας παρέχει μια κατευθυντήρια γραμμή για τις επιπτώσεις της ακραίας θερμοκρασίας στους χαρακτήρες.

Η χρήση κατάλληλης ενδυμασίας επιτρέπει στον χαρακτήρα μια περίοδο χάριτος ίση με το CON του σε ώρες πριν ξεκινήσει η έκθεση, όπως φαίνεται στη στήλη Κίνδυνος. Μετά από αυτό το σημείο, πρέπει να αναζητήσουν καταφύγιο ή θα αρχίσουν να υποφέρουν από απώλεια Κόπωσης (Fatigue). Οι βρεγμένοι χαρακτήρες μετατοπίζουν τον Ρυθμό Κινδύνου κατά ένα επίπεδο προς το πιο κρύο. Οι άνεμοι επιπέδου ελαφράς ή μέτριας θύελλας μετατοπίζουν επίσης τον Ρυθμό Κινδύνου κατά ένα επίπεδο προς το πιο κρύο, ενώ οι ισχυρές θύελλες και οι καταιγίδες τον μετατοπίζουν κατά δύο επίπεδα.
