# 第8章：戦闘

戦闘はロールプレイングゲームにおいて重要な要素である。暴力的な対立は、復讐に燃える宿敵同士の争いから、戦争時における軍隊の衝突に至るまで、常に問題を解決する手段となってきた。それにもかかわらず、戦闘は必ずしも死に至るような野蛮な戦いである必要はない。戦闘遭遇の中には、負傷することなく終わる剣劇のような決闘や、あるいは気楽な酒場での乱闘もあり得る。_『Classic Fantasy Imperative』_では、戦闘の核心的な要素を説明するためにいくつかの用語を使用している。これらは以下の節で詳しく説明するが、概要としては以下の通りである：

- **戦闘スタイル（戦闘スタイル）:** 文化や職業の一部として習得する、一連の武器を扱う技能。
- **戦闘ラウンド（Combat Rounds）:** 5秒ごとの記録用時間セグメント。
- **戦闘アクション（Combat Actions）:** キャラクターが行動ポイントを消費することで、ラウンド中に実行可能な行為。
- **武器のサイズ（Weapon 体格）:** 特定の武器をパリィ（受け流し）することの難易度。
- **交戦（Engagement）:** 状況に応じて、戦闘員が直接対戦相手を攻撃したり、攻撃を受けたりする状態。
- **特殊効果（特殊効果）:** 戦闘員が優位に立った場合に使用できる戦闘上の操作。

---
## 戦闘スタイル

戦闘スタイルは、「クラス」によって関連付けられた複数の武器の「パッケージ」を表しており、個々の武器を別々に習得する必要性を排除している。

戦闘スタイルにおいて最も重要な点は、キャラクターがそのスタイルに含まれる各武器を、単体でも組み合わせでも、必要に応じて交換して使用する方法を学習するということである。戦闘訓練は、単に特定の武器を最適な条件下で使うことだけに焦点を当てるのではなく、著しく不利な状況に置かれたときにどうすべきかもカバーしている。このようなクロス・トレーニングは、武器の破損や武装解除が常に起こり得る戦場という予測不可能な出来事に備えるための、戦闘員準備の主要な部分である。

すべてのキャラクター・クラスが、その戦闘スタイルにおける訓練を提供している。これは魔法使いのように少数の武器である場合もあれば、戦士のようにすべての武器や盾を含む包括的なものである場合もある。

## 戦闘の進行

その本質的な激しさを強調するため、戦闘は一撃ごとの単位で追跡される。記録の手間を省くため、戦いはそれぞれ5秒間の戦闘ラウンドに分割される。この期間中、戦闘員は白兵戦での攻撃やその防御、戦闘への出入り、遠隔武器の射撃や投擲などを行うことができる。現実と同様、一度開始された戦闘のほとんどは、数分ではなく数秒のうちに決着する。ゲーム上の用語では、これは参加者がイニシアチブを再設定したり、戦術状況を再評価したり、あるいは再開する前に一瞬の休息を取るために離脱したりしない限り、数回の戦闘ラウンド（通常は3回以下）を意味する。よく拮抗した敵同士や、連続する敵との戦いだけが、それ以上長引く傾向にある。

戦闘ラウンドではいくつかの重要な用語を使用する：

- **イニシアチブ（イニシアチブ）:** ターンの順番は、戦闘ラウンド中に誰がいつ行動するかを示す。ゲームマスターは高い値から低い値へとイニシアチブの値をカウントダウンし、各参加者がその数字に達したときに行動するチャンスを得られるようにする。
- **ターン（Turns）:** 各5秒の戦闘ラウンド中、各参加者は自分が持つ行動ポイントの数と、それらをどのように使用するかに応じて、1回以上のターンを行う機会を得る。自分のターンにおいて、参加者は戦闘アクションを1つ実行する。これには宣言、可能な移動、必要なダイスロール（リアクションを含む）、およびアクションの解決が含まれる。参加者に行動ポイントが残っている場合、プレイヤーはイニシアチブ順に次のターンを行うことができる。行動ポイントが残っていない場合、あるいは残りがリアクションのために保持されている場合、プレイは次の戦闘ラウンドへ進行する。

各用語については、以下に詳しく説明する。

### イニシアチブ

イニシアチブは、戦闘ラウンドにおける参加者のアクションの順番を決定する。これは戦いの開始時にロールされ、各キャラクターがいつ行動するかを決定する。特定の戦闘アクションや特殊効果など、状況を変化させる何かが起こらない限り、イニシアチブは強制的に振り直しさせられるまで有効である。

イニシアチブは、各参加者が1d10をロールし、イニシアチブ修正を加算して計算する。最も高い結果を出した者が最初に行動し、次に高い者が続く。2人以上の参加者が同点になった場合、DEXが高い者が最初に行動する。それでも同点の場合は、各人がダイスをロールし、高い目を出した者が先に行動する。

### 戦闘中のアクション

イニシアチブが決定されると、参加者は各戦闘ラウンド中に複数の戦闘アクションを実行できる可能性がある。初心キャラクターはラウンドごとに2つの行動ポイントを得るが、階級が上がるとより多くのポイントを獲得できる。ただし、いつ行動できるかは、そのアクションが「能動的」か「受動的」かによって制限される。能動的アクションは、キャラクター自身のターン、つまりイニシアチブの最中にのみ試みることができる。能動的アクションとは、キャラクターが武器で攻撃を行うなど、扇動者となる行為である。

受動的アクションとは、自分に向けられた行為に対抗したり抵抗したりするためにキャラクターが行うものである。脅威1つにつき、1回のリアクション試行のみが許可される。例として、攻撃をパリィしようとする場合などが挙げられる。

未使用の行動ポイントは、次のラウンドに持ち越すことはできない。

## 戦闘アクション

戦闘アクションとは、戦闘中に実行可能な行為のことである。武器を抜く、呪文を唱える、あるいは攻撃を避けるために飛び込むなどは、すべて戦闘アクションの例である。ほとんどは戦闘自体の要素に関係しているが、呪文や武器の領域外の活動に関係するものもある。

前述の通り、キャラクターがラウンドごとに何回行動できるかは、利用可能な行動ポイントによって制限される。これらは、様々な戦闘アクションを実行するために各戦闘ラウンドを通じて消費される。戦闘員の行動ポイントが消費し尽くされると、そのラウンドの残りの時間は行動できなくなり、次のラウンドの開始時にポイントがリセットされるまで待たなければならない。

特に指定がない限り、すべての戦闘アクション（「フリー」アクションを除く）は1行動ポイントを消費する。したがって、戦闘員は行動ポイントをどのように、いつ使用するかを慎重に検討する必要がある。彼らは望むままに攻撃的、あるいは防御的に行動し、戦闘の進化する状況に動的に反応することができる。

---
### 能動的アクション

以下は、キャラクターが行動ポイントを消費して自分のターンに試みることができる活動である。呪文詠唱や再装填など、完了までに数ターンかかるアクションがあることに注意すること。各ターンはそれぞれ1行動ポイントを消費する。

#### 攻撃（Attack）

キャラクターは白兵武器で攻撃するか、遠隔武器を使用することができる。

#### 防御態勢（Brace）

キャラクターはしっかりとした立ち位置を取り、迫り来る攻撃の方向に身を乗り出すことで防御態勢を取る。ノックバックや跳躍攻撃に抵抗する目的において、キャラクターの体格は50%大きいものとして扱われる。殴打特殊効果に対しては、体格は2倍になる。

#### 魔法詠唱（Cast Magic）

キャラクターは呪文を唱えたり、特定の種族やクラスのアビリティを発動したり、その他の魔法的効果を生み出したりすることを試みることができる。複雑な魔法は、詠唱を完了するのに数アクションを要する場合がある。完了後、魔法は術者の次のターンまでの間、いつでも解放することができる。それ以降は後ほど使用するために保持することも可能だが、そのためには後述の[[Hold Magic]]（魔法保持）アクションを実行し、後の解放に向けて準備を維持しなければならない。

#### 射程変更（Change 射程）

キャラクターは対戦相手に接近する、あるいは退避することを試みることができる。

#### 突撃（Charge）

突撃アクションにより、キャラクターは走行または疾走速度で交戦射程に移動し、突撃の勢いを利用してより強力な近接攻撃を行うことができる。[[Charging]]（突撃）については後述する。

#### 遅延（Delay）

キャラクターは、割り込みやパリィなどの受動的アクションを後で行うために、1つ以上のアクションを温存する。遅延の行動ポイント消費は、最終的に実行された行為によって賄われる。もし遅延されたアクションが次のラウンドの自分のターンまでに実行されなかった場合、キャラクターは「パス」したものと見なされ、行動ポイントは失われる。

#### 逡巡（Dither）

他のアクションが選択されない場合のデフォルトのオプションであり、キャラクターはターン中に役に立つことを何もせず浪費する。

#### 魔法保持（Hold Magic）

詠唱が完了した後、キャラクターは魔法を一時的に停止させ、解放する最適な瞬間を待つことができる。魔法は、キャラクターが後続のターンでこのアクションを取り続ける限り保持できるが、これは関連する呪文であれば敵によるカウンター・スペル（呪文相殺）のリアクションを自由に許可することになる。保持された呪文を唱えるための実際の技能判定は、実際に唱えられるまで行われない。

#### 大急ぎ（Hustle）

対戦相手と交戦していない場合、キャラクターは走行（基本移動速度の最大3倍）または疾走（移動速度の最大5倍）で移動できる。ただし、このターン中は他の移動を含め、他の能動的アクションを実行することはできないし、既に実行されていてもならない。

#### 騎乗（Mount）

キャラクターは騎乗生物や乗り物に乗り降りできる。特に大型の乗り物の場合は、完了までに数ターンを要することがある。

#### 移動（Move）

対戦相手と交戦していない場合、キャラクターは基本移動速度まで移動できる。これが敵との接触をもたらす場合、追加のアクションを消費することなく近接攻撃を行うことができる。いずれにせよ、キャラクターはその時点で交戦していると見なされる。「大急ぎ」アクションとは異なり、「移動」アクションは戦闘ラウンド中に複数回行うことができる。

#### 窮地脱出（Outmaneuver）

キャラクターは、回避技能のグループ対抗判定で複数の対戦相手と交戦できる。彼のロールに勝てなかった者は、その戦闘ラウンド中に彼を攻撃できない。[[Outmaneuvering]]（窮地脱出）の節を参照のこと。

#### 準備（Ready）

キャラクターは武器やその他のオブジェクトを取り出す、抜く、鞘に収める、引っ込める、または再装填できる。近くに落ちているオブジェクトを拾うには2アクションを要する：1アクションは移動してオブジェクトに手を伸ばすため、もう1アクションは準備態勢に戻るためである。一部の飛び道具は再装填に複数のアクションを必要とする。

#### 足場回復（Regain Footing）

対戦相手と交戦していない場合、キャラクターは転倒やノックダウンの状態から自動的に足場を回復できる。交戦中の場合、キャラクターは立ち上がる前に、対戦相手との腕力または運動の対抗判定に勝利しなければならない。

#### 抵抗（Struggle）

キャラクターが特定の種類の攻撃や特殊効果の犠牲者となった場合、その状況から脱出を試みることができる。例えば、組み付きから抜け出すなど。

#### 遮蔽利用（Take Cover）

遮蔽利用は、キャラクターがすぐ近くにある遮蔽物の背後に身を隠すことで、遠隔攻撃や呪文に対するある程度の保護を得ることを可能にする能動的アクションである。回避とは異なり、ユーザーを伏せ状態にはしないが、何らかの形の遮蔽物が存在することに依存する。例えば、廊下の角を曲がって戻る、酒場のテーブルの後ろにしゃがみ込むなどである。

### 受動的アクション

このリストは、差し迫った脅威への対応として、戦闘ラウンド中のいつでも使用できるリアクションを指定する。前のリストと同様、リアクションを実行するには1行動ポイントを消費する。

#### 呪文相殺（Counter Spell）

キャラクターは、飛来する呪文を無効化または相殺することを試みることができる。これは相殺側の魔法の詠唱時間が1ターンのものであると想定している。そうでなければ事前に準備し、魔法保持アクションを使用して一時的に保留しておく必要がある。このようにして魔法を遮断することに成功すると、たとえ対象が複数であったり効果範囲を持つものであっても、呪文全体を無効化すると見なされる。

#### 回避（回避）

キャラクターは回避技能を使用して、飛来する飛び道具や突撃攻撃などの脅威から安全な場所へ飛び込むことを試みることができる。これは、アビリティや特別な状況によって軽減されない限り、キャラクターを伏せ状態にする。そのため、キャラクターの次のターンは、通常は立ち上がるための足場回復アクションに費やされる。ブレス攻撃やその他の範囲効果攻撃を回避する場合、その効果範囲の端から10フィート以内であれば、回避に成功することで安全な場所へ飛び込み、半減ではなく無傷で済むことができる。これは、そのペナルティを無効化できるいかなる特別な結果に関係なく、依然として伏せ状態となる。詳細については[[Evading]]（回避）を参照のこと。

#### 割り込み（Interrupt）

遅延中のキャラクター専用である。この受動的アクションは、遅延アクションを実行するために、対戦相手のターンを任意の時点で停止させる。戦術的な状況に変化がないと想定した場合、対戦相手はキャラクターのターンが完了した後にターンを継続する。元の宣言を達成できない場合、対戦相手の行動ポイントは浪費される。割り込みは、遅延中のキャラクターのすぐ近くを通り過ぎる者や、武器の間合い内にいる者に対して、機会攻撃を行うためにも使用できる。

#### パリィ（Parry）

キャラクターは、パリィ、身を乗り出す、しゃがむ、足さばきでかわす動作を組み合わせて飛来する攻撃を防御することを試み、打撃を最小限に抑えることができる。

### フリーアクション

フリーアクション（以下にリスト）は、戦闘ラウンド中のいつでも実行でき、実行するための行動ポイントは消費しない。

#### 状況評価（Assess Situation）

交戦していない場合、キャラクターは行動ポイントを消費せずに知覚ロールを行うことができる。成功すれば戦術状況における関連する変化（突撃を開始しようとする敵を見つけるなど）が明らかになる。走行中に評価を行うと知覚ロールに困難なペナルティが付き、疾走中であれば至難となる。

#### アイテムを落とす（Drop Item）

アイテムを落とすことはフリーアクションである。

#### 合図（Signal）

交戦していない場合、1人以上の参加者に対してジェスチャーや合図を送ることは（相手がその合図を知覚できれば）フリーアクションである。

#### 話す（Speak）

キャラクターは戦闘中いつでも話すことができるが、話す内容は5秒以内に発声できる短いフレーズに制限されるべきである。例えば、「後ろに気をつけろ！」や「地獄へ落ちろ！」など。

#### 幸運ポイントの使用（Use Luck Point）

幸運ポイントの使用（例えば特定のダイス結果を振り直すためなど）はフリーアクションである。

#### 位置防護（Ward 位置）

キャラクターは、自身の武器の1つを専用に割り当ててその領域をパッシブにブロックすることで、特定の部位判定の場所が攻撃されるのを防ぐ。その場所に命中した打撃は、その武器のサイズに応じて、パリィ武器の通常通りにダメージが自動的に軽減される。このカバーは、専用の武器が攻撃やアクティブなパリィに使用されるまで継続する。対象となる部位判定の場所の設定や変更は、対戦相手がキャラクターへの攻撃ロールを行う前に行わなければならない。その設計上、盾は複数の領域をカバーできる。

詳細な説明については[[Passive Blocking]]（パッシブ・ブロッキング）を参照のこと。

## 移動

以下のルールが戦闘における交戦を規定する：

- 移動は、移動、大急ぎ、または突撃アクションのいずれかによって実行される。
- 移動アクションにより、キャラクターは基本移動速度に等しい距離を移動できる。
- 大急ぎアクションにより、キャラクターは基本移動速度の3倍の距離を走行、あるいは5倍の速度で疾走できる。
- 移動は交戦していないキャラクターのみが実行できる（窮地脱出のような特殊なケースを除く）。
- 特定のケース（突撃など）を除き、キャラクターが意図する対戦相手の交戦射程に入ると、すべての重要な移動は停止する。
- 特定のケース（接触を通じた突撃など）を除き、対戦相手の交戦ゾーンへの移動は、各戦闘員を互いに交戦状態に置く。
- 一度交戦すると、近接戦闘から離脱しない限り、キャラクターは対戦相手から離れて移動することはできない。
- 遅延アクションを使用している非交戦状態の敵の横を通り過ぎようとすると、（特定の例外として）その敵は通り過ぎるキャラクターを攻撃したり、キャラクターの進行をブロックしたりすることを許可され、次のターンまたはラウンドで近接戦闘が発生する。

### 状況に応じた移動速度

これらの移動速度は状況に応じたものであり、常に選択肢となるわけではない。多くは他の場所で詳細が説明されているが、便宜上ここに含める。これらの状況に応じた速度のほとんどは、定められた制限の下で通常の移動速度に加えて使用できる。そのような情報は、以下の各説明で詳述される。

#### 登攀（Climb）

登攀可能な表面やオブジェクトに隣接して移動する、あるいはターンの開始時に隣接しているキャラクターは、基本移動速度に等しい速度で登攀できる。キャラクターは歩行よりも速く移動することはできず、移動力を残しておく必要があり、登攀した距離は既に使用した移動力分だけ減少する。着用している防具は登攀を妨げ、軽防具で覆われた各部位は運搬する「モノ」として追加で1つ分、重防具で覆われた各部位は追加で2つ分として計算される。

#### 匍匐（Crawl）

ターンの開始時に伏せ状態であるキャラクターは、通常の移動の代わりにターンごとに最大5フィートの速度で匍匐できる。本来の移動モードとして自然に這うクリーチャーは、代わりに上記の歩行、走行、疾走のルールを使用する。

#### 跳躍（Jump）

跳躍可能な障害物に隣接して移動する、あるいはターンの開始時に隣接しているキャラクターは、それを飛び越えることを試みることができる。キャラクターは跳躍の時点まで任意の速度で移動していてもよい。運動ロールに成功すると、自身の身長の最大2倍の水平距離、または自身の身長の最大半分までの垂直距離（キャラクターが少なくとも15フィートの助走をとれる場合）を跳躍できる。立ち位置から跳躍する場合、これらの距離は半分になる。跳躍距離（フィート単位）から、運搬している「モノ」の合計の半分を差し引く。着用している防具は跳躍を妨げ、上記の計算において軽防具で覆われた部位は「モノ」1つ分、重防具は2つ分として計算される。

詳細については[[運動]]（運動）技能の説明を参照のこと。

クリティカル成功時、キャラクターは合計距離にさらに5フィートを加算し、着地時に直立したままとなる。

ファンブルは、キャラクターがぎこちなく着地したことを示す。キャラクターは直ちに持久力ロールを行わなければならない。持久力ロールが成功した場合、一方の脚に1ポイントのダメージを受ける。持久力判定に失敗した場合、代わりに1d4ポイントのダメージを受ける。

#### 水泳（水泳）

水域に隣接して移動する、あるいはターンの開始時に隣接しているキャラクターは、基本移動速度から既に使用した移動力を引いた速度で水泳できる。詳細については[[水泳]]（水泳）技能の説明を参照のこと。通常の条件下では、ラウンドごとのキャラクターの最大水泳速度は移動速度に等しく、運搬している「モノ」がキャラクターの筋力を超えるごとに-1される。着用している防具は水泳を妨げ、軽防具で覆われた各部位は追加で1つ分、重防具で覆われた各部位は追加で2つ分として計算される。合計の装備重量（ENC）により水泳距離が0以下になった場合、キャラクターは自動的に溺れ始める（[[Asphyxiation]]（窒息）のルールを参照のこと）。

ミニチュアを使用した戦闘では、1インチの正方形グリッドを持つバトルマットを使用することを前提としている。

**攻撃**は、キャラクターの前方または側方のマスのいずれに対しても実行できます。

**回避**は、背後のマスからの攻撃以外に対しては常に標準難易度で行われます。背後からの攻撃は至難であり、攻撃が来ていることを察知するには知覚判定に成功する必要があります。

### 地形が移動に与える影響

戦場には通常、障害物や困難な地形として表される、移動を妨げる何らかの地形が存在します。

障害物は、巨大な木、壁、高い柵、扉、穴など、何でもあり得ます。障害物は移動を完全に遮断し、対戦相手はそれを迂回する必要があります。ただし、幽霊や飛行する生物のように、障害物の影響を受けないクリーチャーもいます。椅子、小さな木、茂みのように、マスを完全に遮断しない物体は、困難な地形として扱われます。

困難な地形は、進入するのに通常の2倍の移動力を消費します。したがって、5フィートのマスにある困難な地形エリアへの移動は、10フィートの移動としてカウントされます。困難な地形に妨げられている動きの遅いクリーチャーでも、最低5フィートは移動できます。困難な地形の例としては、浅い水たまり、瓦礫、低い柵、茂み、背の高い草や雑草、死体などがあります。幽霊や飛行する生物のように、困難な地形の影響を受けないクリーチャーもいます。基本移動速度よりも速い速度で困難な地形を通過するには、つまずいて転倒するのを防ぐために至難の運動判定、または標準のアクロバット判定が必要です。

## 戦闘の仕組み

_Classic Fantasy Imperative_における戦闘は、各攻撃やパリィ（受け流し）が単一の突き、振り、呪文の詠唱、または武器の射撃を表すものとして解決されます。いかなる攻撃的な行動も、リアクションによって抵抗される可能性があります。したがって、キャラクターが対戦相手を攻撃できたとしても、敵は攻撃が命中する前にその一撃をパリィできるかどうかを確認するための独自の判定を行うことが許可されます。この考え方は、ミサイル武器を放つ標的が物陰に飛び込む場合や、巨大なタコの鉄のような締め付けから脱出しようとする場合でも同様に適用されます。

### 攻撃とパリィ

接近戦は、以下の手順で処理されます。

1. 自分のターンに、攻撃側は行動ポイントを消費し、戦闘技能で判定を行い、結果を記録します。
2. 必要に応じて、防御側は行動ポイントを消費し、戦闘技能で判定を行い、結果を記録します。
3. 結果の成功レベルを[差分判定](0005_Skills.md?id=differential-rolls)に従って比較します。
4. その差によって、より優れた判定を行った成功した戦闘側に1つ以上の特殊効果が与えられます。
5. 攻撃側が成功またはクリティカルを達成した場合、武器のダメージをロールし、ダメージ修正（もしあれば）を適用できます。該当する場合、打撃位置を部位判定で決定します。
6. 防御側が成功またはクリティカルを達成した場合、使用された武器の比較サイズに従って、与えられたダメージを軽減します。
7. 残りのダメージから、自然な防護または着用している防具の防具ポイントを減算します。

交換によって生成されるいかなる特殊効果も、ダメージが与えられたかどうかとは独立していることに注意してください。防御側がより高い成功レベルを獲得しても、なお負傷を被ることは十分にあり得ます。

### 武器のサイズ

_Classic Fantasy Imperative_のすべての武器は、与えるダメージから扱うために必要な手の数まで、いくつかの異なる特性を持っています。サイズは武器の質量、レバレッジ、安定性の組み合わせであり、武器がダメージを与え、パリィする能力を決定するために使用されます。サイズカテゴリは「小型」「中型」「大型」「巨大」「超巨大」です。クリーチャーの徒手攻撃には、その身体的特徴に応じて同様のカテゴリが割り当てられます。

### ダメージ軽減

防御側がパリィに成功した場合、使用された武器の相対的なサイズに応じて、攻撃側のダメージ（もしあれば）を軽減できます。

- 「同等かそれ以上」のサイズの武器や盾で攻撃をパリィすると、すべてのダメージを偏向します。
- 「1サイズ小さい」武器や盾でパリィすると、ダメージの半分のみを偏向します。
- 「2サイズ以上小さい」武器や盾でパリィすると、いかなるダメージも偏向できません。

例えば、グレートアックス（巨大）をカイトシールド（同じく巨大）でパリィすればすべてのダメージを防げますが、グレイブ（大型）でパリィすればダメージは半分になり、ショートソード（中型）でパリィした場合はダメージを全く止められません。

### 防具

防御側のパリィを貫通したダメージは、そのキャラクターが持つ自然な防護（鱗や甲殻など）や着用している防具の防具ポイントによってさらに軽減されます。防御側がその両方を持っている場合、2つを合計してダメージを軽減します。

その質量と移動の制限により、キャラクターが「着用」している防具の最高防具ポイント値は、イニシアチブ判定へのペナルティとして機能します。

### 外れた攻撃をパリィする

攻撃者が初期の攻撃ロールを外した場合でも、防御側は行動ポイントを消費してパリィするオプションを持っています。最初から外れる攻撃をパリィするのは無意味に思えるかもしれませんが、熟練した防御者はこれを利用して1つ以上の特殊効果を得ることで、敵を弱体化させたり無力化したりし、次のターンを別の行動のために温存することができます。

### パリィできない、またはパリィしたくない場合

行動ポイントが残っていないために防御側がパリィできない状況、あるいは一撃を耐え抜く自信があるためにパリィしないことを選択した場合、それらは自動的に「失敗」をロールしたものとして扱われます。これは、成功した攻撃側に1つ以上の特殊効果を与えるという結果をもたらします。

### 失敗した判定とファンブル

両方の戦闘員が判定に失敗した場合、または防御側が外れた攻撃を利用しないと決めた場合、攻撃/パリィのシーケンスは終了し、戦闘は次の最高イニシアチブを持つ参加者へと続きます。

## 特殊効果

戦闘とは、単に相手を傷つけたり殺したりすること以上のものです。戦闘芸術は、敵を無力化したり、必ずしも危害を加えることなく降伏を強いるような状況に追い込んだりする、敵を「打ち負かす」多くの方法を教えています。特殊効果はこれらの技術を表現し、プレイ中にどのように発生するかを制御します。

対戦相手がそれぞれの戦闘技能で差分判定を行うたびに、その結果生じる成功レベルの差は、特殊効果が発生する機会を示します。これは、一方の戦闘員が相手を狡猾なトリックや戦術を用いて利用できる不利な状況へ追い込むことを反映しています。

受け取れる特殊効果の数は、[差分判定結果表](0005_Skills.md?id=differential-roll-results-table)に示されている通り、成功レベルの差に依存します。

交換中に何らかの特殊効果が獲得された場合、それらはダメージや部位判定（もしあれば）をロールする前に選択する必要があります。特殊効果を受けることに加えて相手がひどく負傷している場合、持久力判定は効果を適用した後に解決されます。

特殊効果は、多様な状況や技術を網羅しています。攻撃専用に設計されたものもあれば、防御を目的としたものもあり、どちらの状況にも適応できるものもわずかに存在します。特定の特殊効果は、特定の武器タイプや特定のダイスロールに限定される場合もあり、例えば技能チェックでクリティカルやファンブルの結果を必要とする場合があります。

2つ以上の特殊効果が得られた場合、各効果の前提条件が満たされている限り、戦闘員はそれらを自由かつ柔軟に組み合わせることができます。いくつかの効果はスタック可能です。例えば、クリティカル成功をロールして2つの特殊効果を獲得した攻撃者は、2つの別々の攻撃的操作を選択する代わりに、「ダメージ最大化」を2回選択することができます。

### 特殊効果の詳細

#### 偶発的負傷

防御側が相手の攻撃を偏向させたりひねったりして、攻撃側がファンブルし、自身を傷つけるようにします。攻撃側は、攻撃に使用した武器を使って、ランダムな部位判定で自分自身に対してダメージをロールしなければなりません。徒手の場合、攻撃側は何か内部の組織を引き裂いたり壊したりし、ダメージロールはあらゆる防具を無視します。

#### 起床

防御側がわずかな隙を利用して、足を使って立ち上がることを可能にします。

#### 殴打

攻撃側は意図的に相手を殴打してバランスを崩させます。防御側がどれだけ後ろや横にふらつくかは、使用されている武器に依存します。盾は3ダメージごとに5フィート（防具やパリィによる減算前）、殴打武器は5ダメージごとに5フィート相手を後退させます。殴打は攻撃側の体格の2倍までのクリーチャーにのみ有効です。対象が障害物へ向かって強制的に後退させられた場合、転倒や躓きを防ぐために困難難易度でアクロバットまたは運動判定を行う必要があります。

#### 出血

攻撃によって主要な血管が切り開かれます。一撃が防具ポイントを克服して標的を負傷させた場合、防御側は元の攻撃ロールに対して持久力の対抗判定を行わなければなりません。防御側が失敗した場合、大量に出血し始めます。各戦闘ラウンドの開始時に、対象は倒れて死亡する可能性があるまで疲労のレベルを1つ失います。出血している傷は応急手当技能判定に成功すれば止血できますが、対象は傷を再び開くことなく激しい行動や暴力的な行動をとることはできなくなります。[失血](0007_Game_System.md?id=blood-loss)を参照してください。

#### 敵の盲目化

クリティカル時、防御側は砂を投げたり、盾で日光を反射させたり、その他の戦術で攻撃者の視界を一時的に妨害し、相手を短時間盲目にします。攻撃側は、防御側の元のパリィロールに対して、回避技能（盾を使用している場合は武器技能）で対抗判定を行わなければなりません。攻撃側が失敗した場合、盲目化の方法に応じて、次の1d3ターンの間、困難または至難の状況修正を受けます。

#### 防具貫通

クリティカル時、攻撃側は防御側の自然な防具または着用している防具の隙間を見つけます。防御側が自然な防護を超えて防具を着用している場合、攻撃側はどちらを貫通するかを決定しなければなりません。この効果はスタックして両方を貫通させることも可能です。この効果の目的において、魔法から得られる物理的保護は着用している防具とみなされます。

#### 部位選択

近接武器を使用する場合、攻撃側は、その部位が通常リーチ内にあれば、一撃が命中する部位を自由に選択できます。遠隔武器を使用する場合、標的が近距離内にあり、静止しているか、攻撃側に気づいていない場合を除き、部位選択はクリティカル成功時のみとなります。

#### パリィ回避

クリティカル時、攻撃側は成功したはずのパリィを完全に回避できます。

#### 武器破損

キャラクターが攻撃またはパリィの一部として相手の武器を損傷させることを可能にします。攻撃する場合、キャラクターは防御側のパリィ武器を狙い、使用者にではなくその武器に対してダメージロールを適用します。標的となった武器は、ダメージを抵抗するために自身の防具ポイントを使用します。ヒットポイントがゼロになると、武器は壊れます。

#### 武装解除

キャラクターが相手の武器を叩く、引き抜く、またはねじって手から落とさせます。相手はキャラクターの元のロールに対して自身の戦闘スタイルで対抗判定を行わなければなりません。武装解除を受けた側が負けた場合、武器は武装解除した側のダメージ修正 x 3フィートの距離だけ投げ飛ばされます。ダメージ修正がない場合、武器は武装解除された人の足元に落ちます。武器の相対的なサイズがロールに影響します。武装解除するキャラクターの武器が1サイズ大きくなるごとに、相手のロールの難易度が1段階上昇します。逆に、武装解除するキャラクターの武器が1サイズ小さくなるごとに、難易度が1段階容易になります。武装解除は攻撃側の体格の2倍までのクリーチャーにのみ有効です。

#### パリィ強化

クリティカル時、防御側は武器のサイズに関係なく、攻撃の全勢力を偏向させることに成功します。

#### 絡め取り

鞭や網などの絡め取り武器を使用するキャラクターが、命中した部位を固定することを可能にします。絡め取られた腕は持っているものを使用できなくなり、絡め取られた脚は対象の移動を阻止し、頭部、胸部、または腹部が絡められた場合はすべての技能判定が1段階困難になります。次のターン、使用者は行動ポイントを消費して自動的に「相手の転倒」を試みることができます。絡め取られた犠牲者は、自分のターンに腕力を使用して引き抜く対抗判定を試みるか、特殊効果を勝ち取って「武器破損」、「武装解除」、または「離脱」を選択することで、自身を解放しようとすることができます。

#### 強制失敗

相手がファンブルした際に使用します。キャラクターは「強制失敗」を、対抗判定を必要とする他のあらゆる特殊効果と組み合わせることができます。強制失敗は、相手が抵抗ロールをデフォルトで失敗させるため、自動的に武装解除や転倒などが発生します。

#### 掴み

相手が攻撃側の徒手戦闘リーチ内にいる場合、空いている手（または掴む能力を持つ同様の四肢）を使用して相手を保持し、戦闘から離脱できないようにすることができます。相手は自分のターンに、掴んでいる側が好む2つの技能のいずれかを使用して、腕力または徒手による対抗判定を行い、脱出を試みることができます。

#### 突き刺し

武器ダメージを2回ロールし、攻撃側はその2つの結果のうちどちらを使用するかを選択します。近接武器と仮定し、防具を貫通して傷を負わせた場合、攻撃者は武器を傷口に残したままにするか、次のターンに引き抜くかを選択できます。武器を傷口に残すと、犠牲者の将来の技能判定に難易度ペナルティが課されます。ペナルティの深刻度は、以下の「突き刺し効果表」にあるように、クリーチャーのサイズと武器のサイズの両方に依存します。簡略化のため、同じサイズの武器による追加の突き刺しは追加のペナルティを課しません。近接戦闘中に突き刺した武器を引き抜くには、「武器の準備」戦闘アクションを使用する必要があります。使用者は、反対されない腕力ロールに成功（または相手が抵抗する場合は対抗腕力ロールに勝利）しなければなりません。成功すると武器を引き抜くことができますが、同じ部位に対して、ダメージ修正なしの武器の通常ダメージロールの半分に等しい追加の負傷を与えます。失敗は、武器が傷口に刺さったままで追加の効果がないことを意味しますが、使用者は次のターンにもう一度試みることができます。特に返しがついた武器（銛など）は通常のダメージを与えます。防具は引き抜きダメージを軽減しません。刺さっている間、攻撃側はその突き刺し武器をパリィに使用することはできません。

#### 狙撃手

射撃が命中した部位を、隣接する身体部位へと1段階移動させることを可能にします。生理学は再ターゲットできる部位に影響を与えるため、常識を適用する必要があります。したがって、ヒューマノイドに対してこの特殊効果を使用すれば、脚への命中をロールした攻撃者は、それを腹部まで移動させることができます。逆に、グリフォンの胸部を射撃する場合、前脚、翼、または頭部を選択できるようになります。

#### ダメージ最大化

クリティカル時、キャラクターは武器のダメージダイスの1つを最大値に置き換えることができます。例えば、通常1d6ダメージを与えるハンドアックスは代わりに6として扱われ、2d6ダメージを与えるグレートクラブは代わりに1d6+6ダメージを与えます。この特殊効果はスタック可能です。自然武器にも使用できますが、「ダメージ最大化」は攻撃者のダメージ修正には影響せず、ダメージ修正は通常通りロールする必要があります。

#### カウタ―準備

防御者は敵のパターンを読み取り、特定の特殊効果（秘密裏にメモしておくべき）に対するカウンターを準備します。戦闘中に相手が選択した特殊効果を与えようとした場合、防御者は即座に攻撃側の効果を自分自身の効果と置き換え、それは自動的に成功します。

#### 急速再装填

遠隔武器を使用する場合、攻撃側は次の射撃までの再装填時間を1つ減らします。この効果はスタック可能です。

#### 敵に傷跡

戦闘員は、喉を切り裂きそうになった傷や、胸に芸術的に刻まれた「Z」の文字など、その一生の間ずっと話題になるような傷跡を相手に与えます。

#### 標的選択

攻撃側がファンブルした場合、防御側は一撃を操作または偏向させ、代わりに隣接する傍観者に命中させることができます。これには、新しい標的が攻撃側の近接戦闘武器の範囲内にいるか、遠隔攻撃の場合は射線上に立っている必要があります。新しい犠牲者は予期せぬ事故によって完全に不意を突かれ、自動的に命中する攻撃を避けるチャンスはありません。しかしその補償として、彼らは特殊効果を受けません。

#### 離脱

クリティカル時、防御側は自動的に「絡め取り」、「掴み」、「拘束」から脱出できます。#### 部位判定の気絶

攻撃者は殴打武器を使用して、攻撃した部位を一時的に気絶させることができる。攻撃が防具ポイントを上回り、標的にダメージを与えた場合、防御側は「持久力」と元の攻撃ロールとの対抗判定を行わなければならない。防御側が失敗した場合、その部位判定は、与えられたダメージに等しい「ターン」の間、無力化される。胴体への打撃は、防御側をよろめかせ息切れ状態にし、防御のみが可能となる。頭部への打撃は、敵を短時間意識不明にし、行動不能にする。

#### 粉砕

攻撃者は斧などの適切な武器を使用して、対戦相手の防具や自然の防御を損傷させることができる。受け流しや魔法による軽減後のあらゆる武器ダメージは、その防御の防具ポイント値に対して適用される。防具ポイントを超えた余剰ダメージは、その防具部位の防具ポイントを減少させるために使用される（ストラップの切断、リングの破裂、プレートの凹み、あるいはモンスターの獣皮、鱗、甲殻を引き裂く）。防具が防具ポイント0まで減少した後にダメージが残っている場合、そのダメージは攻撃した部位のヒットポイントに持ち越される。

#### 転倒

キャラクターは、対戦相手のバランスを崩して地面に投げ倒そうと試みる。相手は「腕力」、「回避」、または「運動」を使って、キャラクターの元のロールと対抗判定を行わなければならない。標的が失敗した場合、標的は転倒状態になる。四足歩行の相手（またはそれ以上の脚を持つクリーチャー）は、「運動」技能を「回避」の代わりに代用でき、判定の難易度を1段階下げて扱うことができる。

#### 離脱

防御側は自動的に間合いの外へと退却し、その特定の相手との交戦を打ち切ることができる。

## 近接戦闘

近接戦闘とは、戦闘員が手に持った武器や武器を使わない自然な攻撃手段で互いに打ち合う、古典的な意味での格闘戦のことである。以下のガイドラインは、近接戦闘をより興味深いものにし、この章で以前に示唆されたいくつかの概念をさらに説明するのに役立つものである。

### 状況修正

状況修正は、特定の状況下で戦う場合や、特殊効果の結果として適用されることがある。例えば、暗闇の中で戦う場合、「至難」の難易度が課される可能性がある。特に記載がない限り、修正はゲームマスターが決定する。キャラクターに2つ以上の状況が当てはまる場合は、最も厳しいものを適用する。

一部の修正は状況に依存するが、難易度を適用するのではなく、関連する技能によって戦闘技能が制限される。例えば、馬の背から戦う場合、戦闘員の戦闘技能は「乗馬」技能によって上限が定められ、水中で戦う場合は「水泳」技能の値が上限となる。

| 状況 | 難易度 |
| --- | --- |
| 無防備な標的への攻撃 | 自動 |
| 狭い場所での攻撃 | 困難 |
| 下位の場所または騎乗した敵に対して防御する場合 | 困難 |
| 不安定な足場で戦う場合 | 困難 |
| 屈んだ姿勢または片膝をついて戦う場合 | 困難 |
| 視界不良の中で戦う場合（濃霧、吹雪など） | 困難 |
| 背後からの攻撃に対する防御 | 至難 |
| 伏せた状態で戦う場合 | 至難 |
| 部分的な暗闇で戦う場合（薄暗い照明） | 至難 |
| 真っ暗闇の中で戦う場合（照明がまったくない） | 超人的 |
| 目が見えない、または主要な知覚能力を失った状態 | 超人的 |

### 交戦

キャラクターは、相手の近接武器の間合い内にいる場合、「交戦中」と見なされる。これは必ずしも双方が互いに届く距離にいることを意味しない。どちらか一方がもう一方を攻撃できる可能性があるだけで十分である。キャラクターがいったん相手と「交戦」状態になると、自由にその戦いから離れることはできなくなる（通り抜けて突撃する場合は特別な例外である）。敵との接触を断つには、「機動」のような戦闘アクション、あるいは「離脱」特殊効果の使用など、何らかの意図的な行動が必要となる。

### 突撃

「突撃」アクションは、素早く移動して攻撃の威力と衝撃を高める行為である。突撃を行うには、攻撃者が突撃アクションを選択し、歩行あるいは疾走の速度で移動しなければならない。これが相手との接触をもたらす場合、そこで停止し、突撃用に修正された「攻撃」アクションを実行しなければならない。突撃が行われる前に移動しなければならない最低距離はない。移動距離よりも、得られた勢いの方が重要だからである。そのため、歩行や疾走が行われる。

突撃中、攻撃ロールには「困難」の難易度が課される。その代わり、突撃は攻撃武器の体格を1段階上昇させ、二足歩行の攻撃者のダメージ修正を1段階、四足歩行（あるいはそれ以上の脚を持つ生物）の場合は2段階上昇させる。騎乗しているキャラクターは、自身のダメージ修正を乗騎のものに代用できる。突撃キャラクターの最終的な位置は、戦闘の結果と、攻撃者が停止したいのか、あるいはそのまま通り過ぎて即座に交戦を終了したいのかによって決まる。

突撃を受けた側は、受け流しや回避を行う代わりに、突撃してくる攻撃者に対して同時に反撃することができる。この場合、より長い武器を持っている者が先に攻撃する。突撃を受け止めるように武器を構えられる場合（槍など）、受けた側は自身のダメージ修正の代わりに、突撃側のダメージ修正を使用できる。

### 遮蔽

相手は遮蔽物を利用して、自身に対する攻撃を妨害する。これは、介在する物質の硬さによって物理的に打撃を遮断するか、敵が正確にどこにいるかを隠蔽することによって行われる。遮蔽物の正確な値は、その防御の厚さと、どれだけ広範囲を覆っているかによって決まる。

遮蔽された部位判定に着弾した攻撃は、その遮蔽物固有の保護値の分だけ遮断される。遮蔽は、「部位選択」特殊効果を使用して標的の見える部分を狙うか、武器が貫通能力を持っているならば遮蔽物を突き抜けて攻撃することで、部分的に無効化できる。

遮蔽が完全である状況であっても、攻撃者が自分の攻撃が貫通すると確信している場合、隠れた標的に向かって盲目的に攻撃することができる。その場合、攻撃ロールの難易度は1段階上昇し、特殊効果を獲得しても「部位選択」は選択できない。これは、攻撃者が遮蔽物の後ろにいる標的の位置をかなり正確に把握していることを前提としている。

### 回避

戦闘における回避とは、圧倒的な攻撃から身を投じて避けることである。これには、防御側の「回避」技能と、攻撃者の適切なロールとの対抗判定が必要となる。これは、突進してくるバトルタンクに対する「運転」技能から、魔術師の呪文詠唱技能まで、あらゆるものが該当する。攻撃者が勝利した場合、通常通りダメージを与える。防御側が勝利した場合、ダメージは完全に回避される。

対抗判定の勝者が対戦相手に対して1つ以上の成功レベルを達成した場合、通常の戦闘と同様に適切な特殊効果を選択できる。結果がどうであれ、回避の試みは防御側を転倒状態にする。通常、キャラクターは次のターンに足場を立て直す必要がある（「立ち上がり」特殊効果を使用できる場合を除く）。

### ノックバック

受ける側（標的）の体格よりも多くのダメージを与える攻撃は、デフォルトでキャラクターを後退（ノックバック）させる結果となる。この状況でのダメージは、受け流しや防具による軽減を適用する前の値である。そのような打撃を受けた場合、標的は転倒を避けるために「簡単」な「アクロバット」または「標準」の「運動」ロールに成功しなければならない。また、標的は自身の体格を超えるダメージ8ポイントごとに（端数は切り捨て）、5フィート後方に突き飛ばされる。「踏ん張り」戦闘アクションを事前に使用することで、ノックバックの影響を軽減または無効化できる。

### 跳躍攻撃

跳躍攻撃はさまざまな状況から開始できる。そのほとんどは待ち伏せの一部として、あるいは突撃の終了時に誘発されるが、一部のクリーチャーは助走や高所を利用することなく、相手の上に飛びかかることができる。

跳躍攻撃は、跳躍者の「運動」技能と、防御側の「腕力」または「回避」技能との対抗判定で解決される。四足歩行の標的の場合、攻撃ロールの難易度が1段階上昇する。跳躍者が勝利した場合、防御側は自動的に転倒状態となり、攻撃者がその上にまたがる形となる。失敗した場合、防御側はその衝撃を耐え抜いたか、あるいは横にかわしたことになる。対抗判定の勝者が対戦相手に対して1つ以上の成功レベルを達成した場合、通常の戦闘と同様に適切な特殊効果を選択できる。

跳躍の一部としてダメージは与えられない。しかし、転倒状態になった犠牲者は、攻撃者が離れるか、あるいは最終的に立ち上がることを許可する特殊効果に勝利するまで、姿勢を立て直すことはできない。さらに、跳躍攻撃は攻撃者の体格の2倍までの大きさの相手にしか機能しない。標的は、跳躍攻撃が迫っていることを認識していれば、「踏ん張り」戦闘アクションを先制して使用することで、倒されにくくすることができる。

### 機動（アウトマヌーバ）

複数の相手と対峙するキャラクターは、移動を利用して同時に攻撃してくる人数を制限し、絶えず位置を変えて敵同士が邪魔し合うように仕向けることができる。機動を行うには、キャラクターが動き回る余地があり、狭い場所に追い詰められていないことが必要である。

機動には、キャラクターが相手を「回避」技能によるグループ対抗判定に巻き込む必要がある。機動を行うキャラクターと、彼を追い詰めようとする敵の両方の参加者全員が、行動ポイントを1ポイント消費しなければならない。その後、各自が一度ずつロールを行い、機動を行うキャラクターのロールを上回ることに失敗した者は、味方や地形の特徴に阻まれて、その戦闘ラウンドの残りの間、彼を攻撃することができなくなる。

機動を行うキャラクターがすべての対戦相手を上回った場合、そのラウンドの残りの間、単一の敵と安全に交戦するか、戦いから完全に離脱するかのどちらかを選択できる。

### 受動的ブロック

受動的ブロックにより、武器を持つキャラクターはその武器を特定の部位（盾を使用する場合は複数の部位）をカバーするように保持できるが、その代償としてその武器で積極的に「受け流し」を行うことができなくなる（「部位保護」を参照）。その部位に命中するあらゆる攻撃は、武器や盾の恩恵を自動的に受け、ダメージが通常通り減少する。この技術は、戦士が弱点や負傷した部位を守りたいときによく使用される。二刀流や、武器と盾を使用する戦闘員が、もう一方の武器で積極的に「受け流し」を行うことを妨げるものは何もない。

受動的ブロックは遮蔽物と同じ方法で機能するため、近接戦闘において「部位選択」特殊効果を使用してブロックを回避することはできない。ただし、対戦相手は引き続きこの効果を使用して、ブロックされていない他の場所を攻撃することは可能である。盾の後ろにしゃがみ込むことで、キャラクターは受動的ブロック中にカバーできる部位の数を2倍にすることができる。

### 不意打ち

不意打ちは、攻撃者の存在や意図に気づいていない相手に対して予期せぬ攻撃が仕掛けられたときに発生する。待ち伏せは前者の例であり、友好的な会話の最中に不意に味方を裏切ることは後者の例である。

不意打ちが標的に与える影響は強力である。

- 標的はイニシアチブに-10のペナルティを受ける。
- イニシアチブの順番が来るまで、標的は足が止まった状態と見なされ、防御ができない。
- 標的への最初の攻撃が成功した場合、ボーナス特殊効果を得る。
- ラウンドの残りの間、標的はいかなる攻撃的アクションも実行できない。

### スイープ攻撃

スイープ攻撃は、ゲームマスターの判断で発生する。巨大なドラゴンの薙ぎ払う尾や、止まらない巨大トリケラトプスの突撃のように、異常なサイズの武器やクリーチャーが密集したグループを攻撃し、複数の敵を同時に打ち払うような場合である。

スイープ攻撃は、武器やクリーチャーの単一の攻撃ロールを、その経路にいるすべての標的に適用することで行われる。各防御側は個別に攻撃の影響を解決しなければならず、攻撃者に課された特殊効果は同時に発生したものとして扱われる。

## 遠隔戦闘

遠隔戦闘には、標的に命中させるために撃ち出す、投げる、あるいは投石器を用いるすべての形態の武器が含まれる。遠隔攻撃は、近接戦闘と同じ方法で解決される。ただし、遠隔武器は通常、盾でしか受け流すことができない。盾を持たない者は、自然の遮蔽物に頼るか、「回避」を使用して銃撃のラインから飛び出す必要がある。したがって、軽装の敵に対して、遠隔武器は手強い抑止力となり得る。

各遠隔武器には、その有効性を決定するいくつかの特定の特性がある。戦闘に重要な影響を与えるものは以下の通りである。

- **体格（超能力）:** 遠隔武器における体格に相当する値。武器や弾薬が（盾による）受け流しを打ち破れるかどうかを判定するための、貫通力を示す抽象的な尺度。
- **ダメージ修正:** この特性は、攻撃者のダメージ修正を遠隔武器のダメージロールの強化に使用できるかどうかを示す。一般的に、弓や投擲武器のみが、ユーザーのダメージ修正を適用できる。
- **射程:** スラッシュで区切られた3つの数字で、武器や弾薬の「近距離」、「有効射程」、「長射程」の最大距離を表す。近距離は「部位選択」特殊効果を使用できる距離であり、標的が静止しているか、攻撃が迫っていることに気づいていないことが条件となる。有効射程には重要な修正はない。長射程では、武器は依然としてダメージを与えることができるが、ダメージ量は半分になり、体格（超能力）が1段階減少する。
- **再装填:** 弾薬を発射する武器を装填または再装填するのにかかるターン数。「高速再装填」特殊効果を使用することで、装填や準備にかかる時間を短縮できる。
- **刺突体格:** 突き刺した武器の体格は、それが攻撃する際の体格（超能力）とは異なる。「刺突」特殊効果によって引き起こされる障害を考慮する際、遠隔の刺突武器には実際の体格を示す特別な列がある。

### 状況修正

近接戦闘と同様に、特定の状況下で遠隔武器を使用する場合に状況修正が適用されることがある。馬に乗ったまま槍を投げるなど、困難な状況で武器を使用する場合、キャラクターの戦闘技能に上限が設けられることがある。

##### 遠隔戦闘の状況修正

| 状況 | 難易度 |
| :-- | :-- |
| 弱い風\* | 困難 |
| 中程度の風\* | 至難 |
| 強い風\* | 超人的 |
| 暴風、嵐、またはそれ以上\* | 絶望的 |
| 標的が歩行中 | 困難 |
| 標的が疾走中 | 至難 |
| 霧で標的が遮られている、または部分的な暗闇にいる | 困難 |
| 濃い煙で標的が遮られている、または暗闇にいる | 至難 |
| 標的が完全に遮られている | 超人的 |
| 標的が完全に見えない | 無駄\*\* |
| 標的が伏せている | 至難 |
| 攻撃者が伏せている\*\*\* | 超人的 |
| 攻撃者が不安定な足場にいる | 困難 |

_\* 投擲武器や弾薬が横風の影響を受けると想定され、通常の技能に対する風の通常ペナルティに優先して適用される。_

_\*\* 標的の一般的な位置が判明または既知でない限り、超人的として扱う。_

_\*\*\* 準備された位置からクロスボウを使用している場合は、ペナルティを無効化できる。_

### 狙い撃ち

遠隔武器で狙いを定めるために時間をかけることで、キャラクターは命中率を高める可能性がある。「狙い撃ち」には、武器を安定させ、リリースに最適な機会を待つために戦闘ラウンド全体を費やす必要がある。例えば、風が凪ぐ瞬間や、標的が2つの遮蔽物の間を通り抜けるまで弓の射撃を控えるなどである。狙い撃ちを行うことで、キャラクターは遠隔戦闘の状況修正の難易度を1段階軽減できる。狙い撃ちに追加のラウンドを費やしても、さらなる利点はない。

### 群衆への射撃

乱戦の渦中に射撃を行うことはリスクを伴うため、狙った標的以外の誰かに誤って命中させる危険性が常にある。群衆や乱戦の端にいる特定の標的に向けて射撃する場合、攻撃には「困難」の難易度が課される。群衆越しに射撃を試みる場合は、「至難」に引き上げられるべきである。危険を軽減するために「狙い撃ち」を行うことは依然として許可されている。

難易度ペナルティにもかかわらず攻撃ロールに成功した名手は、正確に狙い、標的に命中させる。しかし、名手がロールに失敗したものの、「群衆への射撃」ペナルティがなければ成功していたはずであった場合、代わりに隣接する犠牲者が命中する（この犠牲者は通常通り回避や受け流しを行える）。

射線上に複数の標的がいる場合、ゲームマスターがランダムに犠牲者を決定すること。攻撃の一部として獲得されたいかなる特殊効果も、誤って命中した傍観者ではなく、元の標的にのみ適用される。
