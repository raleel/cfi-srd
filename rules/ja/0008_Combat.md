# 第8章：戦闘

戦闘はロールプレイングゲームにおける重要な要素である。暴力的な対立は、復讐に燃える宿敵同士の争いから、戦争時における軍隊の衝突に至るまで、常に問題を解決するための手段であり続けてきた。とはいえ、戦闘は必ずしも死に至るような野蛮な戦いである必要はない。戦闘遭遇の中には、怪我をせずに終わる騎士道的な決闘や、あるいは少し陽気な酒場での喧嘩のようなものもあり得る。『Classic Fantasy Imperative』では、戦闘の核心的な要素を説明するためにいくつかの用語を使用する。これらは以下のセクションで説明するが、概要は以下の通りである。

- **戦闘スキル（Combat Skill）:** 文化や職業の一部として習得した、一連の武器を扱う技術。
- **戦闘ラウンド（Combat Rounds）:** 5秒ごとの記録用時間単位。
- **戦闘アクション（Combat Actions）:** アクションポイントを消費することで、キャラクターがラウンド中に行える可能な行動。
- **武器サイズ（Weapon Size）:** 特定の武器をパリィ（受け流し）することの難易度。
- **交戦（Engagement）:** 状況に応じて、戦闘員が相手を直接攻撃したり、攻撃を受けたりできる状態。
- **特殊効果（Special Effects）:** 一方の戦闘員が優位に立った場合に行える戦闘操作。

---
## 戦闘スキル

戦闘スキルは、クラスに関連する複数の武器を「パッケージ」として表すものであり、個々の武器を別々に学ぶ必要性を回避するものである。

戦闘スキルの最も重要な側面は、キャラクターがスキルに含まれる各武器の使い方を、単独でも組み合わせでも学び、必要に応じて交換できるようにすることである。戦闘訓練は単に特定の武器を最良の条件で使うことに集中するだけでなく、厳しい状況に置かれたときにどうすべきかも網羅する。このようなクロス・トレーニングは、武器の破損や武装解除の可能性が常にある戦場という予測不可能な出来事に備えるために不可欠である。

すべてのキャラクタークラスが戦闘スキルの訓練を提供する。メイジのようにわずかな武器の場合もあれば、ファイターのようにすべての武器や盾を含む全包括的なものまで様々である。

## 戦闘の進行

その臨場感を強調するため、戦闘は一撃ごとの進捗に基づいて追跡される。記録を容易にするため、戦いは5秒ごとの「戦闘ラウンド」に分割される。この期間中、戦闘員は近接攻撃やその防御、戦闘への出入り、遠隔武器の発射や投擲などを行うことができる。現実と同様に、ほとんどの戦闘は一度始まれば分単位ではなく秒単位で決着する。ゲーム用語で言えば、これは数ラウンド（通常3以下）を意味する。ただし、イニシアチブをリセットしたり、戦術的状況を再評価したり、あるいは再開前に一息つくために参加者が離脱する場合を除く。互角の敵同士や、敵が連続して登場する場合のみ、戦いは長引く傾向がある。

戦闘ラウンドでは、いくつかの重要な用語を使用する。

- **イニシアチブ（Initiative）:** ターンの順序であり、戦闘ラウンド中に誰がいつ行動するかを示す。ゲームマスター（GM）はイニシアチブ値を高い順からカウントダウンし、各参加者は自分の数値に達したときにターンを行う機会を得る。
- **ターン（Turns）:** 5秒間の各戦闘ラウンド中、参加者はそれぞれが持つアクションポイントの数と、その使用方法に応じて、1回以上のターンを行う機会を得る。ターンにおいて、参加者は1つの戦闘アクションを実行する。これには宣言、可能な移動、必要なダイスロール（リアクションを含む）、およびアクションの解決が含まれる。参加者にアクションポイントが残っている場合、プレイヤーはイニシアチブ順に再度ターンを行うことができる。アクションポイントが残っていない場合、または残りがリアクションのために保留されている場合、プレイは次の戦闘ラウンドに進む。

各用語については、以下で詳しく説明する。

### イニシアチブ

イニシアチブは、戦闘ラウンドにおける参加者のアクション順序を決定する。これは戦いの開始時にロールされ、各キャラクターがいつ行動するかを決定する。特定の戦闘アクションや特殊効果など、状況を変化させる何かが発生しない限り、イニシアチブは再ロールを強制されるまで有効である。

イニシアチブは、各参加者が1d10をロールし、イニシアチブ修正値を加算して計算する。最も高い結果を出した者が最初に行動し、次に2番目に高い者が続く。2人以上の参加者のスコアが同点の場合、DEXが高い方が先に行動する。それでも同点の場合は、それぞれがダイスを振り、高い目を出した方が先に行動する。

### 戦闘中のアクション

イニシアチブが決定されると、参加者は各戦闘ラウンド中に複数の戦闘アクションを実行する可能性がある。開始時のすべてのキャラクターはラウンドごとに2アクションポイントを獲得し、ランクが上がるにつれて増加するが、行動できるかどうかは、そのアクションが「プロアクティブ（能動的）」か「リアクティブ（受動的）」かによって制限される。プロアクティブ・アクションは、キャラクター自身のターン、つまりイニシアチブ中にのみ試みることができる。プロアクティブ・アクションとは、武器による攻撃など、キャラクターが仕掛けるものである。

リアクティブ・アクションは、自分に向けられた行動に対抗したり抵抗したりするためにキャラクターが行うものである。それぞれの脅威に対して1回のリアクション試行のみが許可される。例として、攻撃をパリィすることが挙げられる。

未使用のアクションポイントは、次のラウンドに持ち越すことはできない。

## 戦闘アクション

戦闘アクションとは、戦闘中に実行できる行為のことである。武器を抜く、呪文を唱える、攻撃から飛び退くなどはすべて戦闘アクションの例である。ほとんどは戦闘そのものの要素に関係するが、呪文や武器の領域外の活動に関連するものもある。

前述の通り、キャラクターがラウンドごとに何回行動できるかは、使用可能なアクションポイントによって制限される。これらは各戦闘ラウンドの過程で消費され、様々な戦闘アクションを実行する。戦闘員のアクションポイントが尽きると、そのラウンドの残りの時間は行動できなくなり、次のラウンドの開始時にポイントがリセットされるまで待たなければならない。

特に指定がない限り、すべての戦闘アクション（「フリー」アクションを除く）は1アクションポイントを消費する。したがって、戦闘員はどのように、いつアクションポイントを使うかを慎重に検討する必要がある。戦闘の進化する状況に動的に対応し、望む限り攻撃的にも防御的にも振る舞うことができる。

---
### プロアクティブ・アクション

以下は、アクションポイントを消費してターン中にキャラクターが試みることができる活動である。呪文詠唱やリロードなど、完了までに数ターンかかるアクションがあることに注意すること。各ターンがそれぞれのアクションポイントを消費する。

#### 攻撃（Attack）
キャラクターは近接武器での打撃や、遠隔武器の使用を試みることができる。

#### 構え（Brace）
キャラクターはしっかりと足を踏ん張り、迫りくる攻撃の方向に体重を傾けて構える。ノックバックや跳躍攻撃に抵抗する場合、キャラクターのSIZは50%大きいものとして扱われる。「強打（Bash）」特殊効果に対しては、SIZは2倍になる。

#### 魔法詠唱（Cast Magic）
キャラクターは呪文の詠唱、特定の種族やクラスの能力の発動、またはその他の魔法効果の生成を試みることができる。複雑な魔法は、詠唱を完了するために複数のアクションを必要とする場合がある。完了後、魔法は術者の次のターンまでいつでも解放できる。それ以降に持ち越すには、後述の【魔法保持（Hold Magic）】アクションが必要となる。

#### レンジ変更（Change Range）
キャラクターは相手に接近、あるいは相手から後退することを試みることができる。

#### 突撃（Charge）
突撃アクションにより、キャラクターは走行または疾走速度で交戦レンジに移動し、突撃の勢いを利用してより強力な近接攻撃を行うことができる。突撃については以下で詳しく解説する。

#### 遅延（Delay）
キャラクターは、割り込み（Interrupt）やパリィ（Parry）などのリアクティブ・アクションを後で行うために、1つ以上のアクションを温存する。遅延のアクションポイント消費は、最終的に実行された行為によって賄われる。もし遅延させたアクションが次のラウンドの自身のターンまでに実行されない場合、キャラクターは「パス」したものと見なされ、アクションポイントは失われる。

#### 躊躇（Dither）
別のアクションが選択されない場合のデフォルトのオプションであり、キャラクターはターンを無駄に過ごすだけである。

#### 魔法保持（Hold Magic）
詠唱完了後、キャラクターは魔法を一時的に保持し、解放する最適なタイミングを待つことができる。このアクションを後続のターンで継続する限り魔法は保持できるが、これは敵が魔法に関連するカウンタースペル（Counter Spell）リアクションを自由に使用できるようにする。実際に魔法を放つためのスキルロールは、魔法を解放する際に行う。

#### 急行（Hustle）
相手と交戦していない限り、キャラクターは移動（基本移動速度の最大3倍）または疾走（移動速度の最大5倍）で移動できる。ただし、このターン中は移動を含む他のプロアクティブ・アクションを実行できず、また実行済みであってはならない。

#### 騎乗（Mount）
キャラクターは騎乗生物や乗り物に乗り降りできる。特に巨大な乗り物は、完了するまでに数ターンを要する場合がある。

#### 移動（Move）
相手と交戦していない限り、キャラクターは基本移動速度まで移動できる。これにより敵と接触した場合、アクションを消費することなく近接攻撃を行うことができる。いずれにせよ、キャラクターは「交戦状態」と見なされる。「急行」アクションとは異なり、「移動」アクションは戦闘ラウンド中に複数回行うことができる。

#### 機動戦（Outmaneuver）
キャラクターは、回避スキルによるグループ対抗ロールで複数の相手と交戦できる。彼のロールに勝てなかった者は、その戦闘ラウンドにおいて彼を攻撃できない。詳細については[機動戦（Outmaneuvering）](0008_Combat.md?id=outmaneuvering)を参照のこと。

#### 準備（Ready）
武器やその他の物体を取り出す、抜く、鞘に収める、引き上げる、またはリロードする。近くに落ちている物体を拾うには2アクション必要である。1アクションは移動して物体に手を伸ばすため、もう1アクションは準備姿勢に戻るためである。一部の飛び道具はリロードに数アクション必要とする。

#### 足場回復（Regain Footing）
相手と交戦していない場合、転倒したり突き飛ばされたりした状態から自動的に足場を回復できる。交戦中の場合、キャラクターは立ち上がる前に相手との「筋力」または「運動」の対抗テストに勝利しなければならない。

#### 抵抗（Struggle）
キャラクターがある種の攻撃や特殊効果の犠牲者となった場合、その状況から脱出を試みることができる。例えば、組み付きからの脱出など。

#### 遮蔽（Take Cover）
遮蔽は、キャラクターが身近な遮蔽物の後ろに隠れることを可能にするプロアクティブ・アクションであり、遠隔攻撃や魔法に対してある程度の保護を得る。回避とは異なり、使用者を伏せ状態にはしないが、何らかの遮蔽物があることに依存する。例えば、廊下の角を曲がって隠れる、酒場のテーブルの下にしゃがみ込むなど。

### リアクティブ・アクション

このリストは、差し迫った脅威への応答として戦闘ラウンド中にいつでも使用できるリアクションを指定する。前のリストと同様に、リアクションの実行にはアクションポイントを1消費する。

#### カウンタースペル（Counter Spell）
キャラクターは飛来する呪文を打ち消したり対抗したりすることを試みることができる。これは対抗魔法の詠唱時間が1ターンの場合を想定しており、それ以外の場合は事前に準備し、「魔法保持」アクションを使用して一時的に保留しておく必要がある。この方法で魔法を正常に迎撃すると、複数の標的や効果範囲を持つ魔法であっても、呪文全体を無効化できると見なされる。

#### 回避（Evade）
キャラクターは回避スキルを使用して、飛来するミサイルや突撃攻撃などの脅威から飛び退くことができる。これは能力や特別な状況によって軽減されない限り、キャラクターを伏せ状態にする。そのため、次のターンは通常、再び立ち上がるために「足場回復」アクションを消費することになる。ブレス兵器やその他の範囲攻撃を回避する場合、効果範囲の端から10フィート以内にいれば、回避に成功することで安全な場所に飛び込み、半分のダメージではなくダメージを無効化できる。これは、そのペナルティを無効化する特別な結果があるかどうかにかかわらず、キャラクターを伏せ状態のままにする。詳細は[回避（Evading）](0008_Combat.md?id=evading)を参照のこと。

#### 割り込み（Interrupt）
遅延中のキャラクターのみ。このリアクティブ・アクションは、相手のターンを任意の時点で停止させ、遅延させたターンアクションを行う。戦術状況に変化がないと仮定すれば、相手はキャラクターのターン終了後にターンを継続する。元の宣言を達成できない場合、相手のアクションポイントは無駄になる。割り込みは、遅延中のキャラクターの近くを通り過ぎる相手や、武器の届く範囲にいる相手に対する機会攻撃としても使用できる。

#### パリィ（Parry）
キャラクターは、受け流し、傾き、しゃがみ込み、横歩きを組み合わせて打撃を最小限に抑えることで、飛来する攻撃に対する防御を試みることができる。

### フリー・アクション

フリー・アクション（以下にリスト）は戦闘ラウンド中いつでも実行でき、アクションポイントを消費しない。

#### 状況把握（Assess Situation）
非交戦中であれば、アクションポイントを消費せずに知覚ロールを行える。成功すれば、戦術状況の関連する変化（突撃を開始する敵を発見するなど）が明らかになる。「走行」中の把握はハードな知覚ロールとなり、「疾走」中の把握は恐るべき（Formidable）難易度となる。

#### アイテムを落とす（Drop Item）
アイテムを落とすのはフリー・アクションである。

#### 合図（Signal）
非交戦中であれば、1人以上の参加者への身振りや合図（相手がそれを知覚できれば）はフリー・アクションである。

#### 会話（Speak）
キャラクターは戦闘中いつでも話すことができるが、内容は5秒以内に話せる短いフレーズに制限されるべきである（例：「後ろに気をつけろ！」や「地獄へ落ちろ！」）。

#### 幸運ポイントの使用（Use Luck Point）
幸運ポイントを使用して、特定の判定結果を再ロールするなどを行うのはフリー・アクションである。

#### 位置防護（Ward Location）
キャラクターは武器を捧げて受動的にエリアをブロックし、特定のヒットロケーションを被弾から守る。そのロケーションに着弾したあらゆる打撃は、その武器のサイズに基づいた通常通りのパリィと同様に、ダメージが自動的に軽減される。このカバーは、捧げられた武器が攻撃やアクティブなパリィに使用されるまで継続する。カバーするヒットロケーションの設定や変更は、相手が攻撃ロールを行う前に行わなければならない。その設計上、盾は複数のエリアをカバーできる。

詳細については[受動的ブロック（Passive Blocking）](0008_Combat.md?id=passive-blocking)を参照のこと。

## 移動

以下のルールは戦闘における交戦を規定する：

- 移動は「移動（Move）」、「急行（Hustle）」、または「突撃（Charge）」アクションによって行われる。
- 「移動」アクションにより、キャラクターは自身の基本移動速度と等しい距離を移動できる。
- 「急行」アクションにより、キャラクターは移動速度の3倍の距離を「走行」、または5倍の距離を「疾走」できる。
- 移動は非交戦中のキャラクターのみが行える（機動戦などの特殊ケースを除く）。
- 特定のケース（突撃など）を除き、キャラクターが対象の相手の交戦レンジに入った時点で、すべての有意な移動は停止する。
- 特定のケース（突撃など）を除き、相手の交戦ゾーンに移動すると、各戦闘員は互いに交戦状態となる。
- 一度交戦すると、近接戦闘から「撤退（Withdraw）」しない限り、キャラクターは相手から離れて移動することはできない。
- 遅延アクションを使用している非交戦中の敵の前を通り抜けようとすると、（例外として）その相手が通り過ぎるキャラクターを攻撃したり、前進を阻止したりすることを許可され、次のターンまたはラウンドで近接戦闘を誘発する。

### 状況に応じた移動速度

これらの移動速度は状況依存であり、常に選択できるわけではない。多くは他の場所で詳細に記述されているが、便宜上ここに記載する。これらの状況に応じた速度の大部分は、設定された制限の下で通常の移動速度に加えて使用できる。そのような情報は、以下の個別の記述で詳細に説明される。

#### クライム（Climb）
登攀可能な表面や物体の隣に移動、または隣でターンを開始したキャラクターは、基本移動速度と等しい速度で登ることができる。キャラクターは「歩行」より速く移動した状態ではならず、移動力が残っていなければならない。登った距離は既に使用した移動力分減少する。装備している鎧は登攀を妨げ、軽装鎧で覆われた各ロケーションは持ち運んでいる「もの」として1加算され、重装鎧の場合は2加算される。

#### クロール（Crawl）
ターン開始時に伏せ状態のキャラクターは、通常の移動の代わりに、1ターンにつき最大5フィートの速度で匍匐移動できる。通常モードとして自然に這うクリーチャーは、代わりに前述の歩行、走行、疾走のルールを使用する。

#### ジャンプ（Jump）
跳躍可能な障害物の隣に移動、または隣でターンを開始したキャラクターは、それを飛び越えることを試みることができる。キャラクターは跳躍地点まで任意の速度で移動してよい。運動ロールに成功すれば、自身の身長の2倍の水平距離、または（最低15フィートの助走があれば）半分までの垂直距離を跳躍できる。立ち止まった状態から跳躍する場合、これらの距離は半分になる。ジャンプ距離（フィート）を、持ち運んでいる「もの」の合計の半分だけ減らす。装備している鎧は跳躍を妨げ、軽装鎧の各ロケーションは上記の計算で1「もの」としてカウントされ、重装鎧は2「もの」としてカウントされる。

詳細については[運動（Athletics）](0005_Skills.md?id=athletics-strdex)スキル記述を参照のこと。

クリティカル成功時、キャラクターは合計距離にさらに5フィートを追加し、着地時に直立姿勢を保つ。

ファンブルは、キャラクターが不格好に着地したことを示す。ただちに耐久力ロールを行わなければならない。耐久力ロールが成功すれば、脚の1つに1点のダメージを受ける。耐久力テストに失敗した場合、代わりに1d4点のダメージを受ける。

#### スイム（Swim）
水域の隣に移動、または隣でターンを開始したキャラクターは、基本移動速度から既に使用した移動分を引いた速度で泳ぐことができる。詳細については[水泳（Swim）](0005_Skills.md?id=swim-strcon)スキル記述を参照のこと。通常条件下での1ラウンドあたりの最大水泳速度は移動速度に等しく、キャラクターのSTRを超えて運ぶ「もの」1つにつき-1される。装備している鎧は泳ぎを妨げ、軽装鎧は1追加の「もの」として、重装鎧は2追加の「もの」として数えられる。もしENC合計が水泳距離を0以下に減少させた場合、キャラクターは自動的に溺れ始める（[窒息（Asphyxiation）](0007_Game_System.md?id=asphyxiation)のルールを参照）。

### ミニチュアと移動

ミニチュア戦闘は、1インチ正方形グリッドのバトルマットの使用を想定している。

#### スケール
これらのルールは、1インチが5フィートまたは10フィートに等しい場合に最も機能する。

#### 向き（Facing）
キャラクターの向きは、戦場において最も重要な考慮事項の1つである。側面や背中を攻撃に対して開いたままにするのは、不慮の死を迎える最も速い方法である。以下に2つの向きの図を示す。移動終了時、フィギュアは占有するマスのいずれかの辺、あるいは必要に応じて対角線の方を向いていなければならない。

![](_media/CFI_8_Combat_Mini_Facing_Has.png)

**攻撃**は、キャラクターの正面または側面のマスに対して行うことができる。

**回避**は、背面マスからの攻撃を除き、常に標準難易度である。背面からの攻撃は恐るべき難易度であり、攻撃が来ることを知るためだけでも知覚ロールの成功が必要である。

### 地形が移動に与える影響

戦場には通常、移動を妨げる何らかの地形があり、「障害物」または「難地形」として表現される。

障害物は、巨大な木、壁、高いフェンス、ドア、穴など、あらゆるものになり得る。障害物は移動を完全にブロックし、相手はそれを迂回する必要がある。ただし、幽霊や飛行するクリーチャーなど一部の存在は影響を受けない。椅子、小さな木、茂みなど、マスを完全に塞がない物体は「難地形」として扱われる。

難地形は進入するのに通常の2倍の移動力を消費する。したがって、5フィート四方の難地形エリアへの移動は、10フィートの移動としてカウントされる。難地形に妨げられた遅いクリーチャーでも、最低5フィートは移動できる。難地形の例としては、浅い水たまり、瓦礫、低いフェンス、茂み、背の高い草/雑草、死体などがある。幽霊や飛行クリーチャーは影響を受けない。基本移動速度より速い速度で難地形を通過するには、つまずきや転倒を避けるため、恐るべき運動ロールまたは標準のアクロバットロールが必要となる。

## 戦闘の仕組み

『Classic Fantasy Imperative』における戦いは、各攻撃やパリィが単一の刺突、スイング、呪文、または武器の射撃を表すように解決される。いかなる攻撃アクションも、リアクションによって抵抗される可能性がある。したがって、キャラクターが相手に打撃を与えられたとしても、敵は着弾する前にパリィができるかどうかを自身のロールで確認することが許可される。この同じ哲学は、飛び退いて遮蔽に入ろうとする標的に対する飛び道具攻撃であっても、巨大タコの鉄の締め付けから逃れようとする場合であっても使用される。

### 攻撃とパリィ

近接戦闘は、以下のステップバイステップで行われる：

1. ターンの攻撃者はアクションポイントを消費し、自身の戦闘スキルに対してロールし、結果を記録する。
2. 必要に応じて、防御者はアクションポイントを消費し、自身の戦闘スキルに対してロールし、結果を記録する。
3. 結果の成功レベルを[差分ロール（Differential Rolls）](0005_Skills.md?id=differential-rolls)に従って比較する。
4. その差によって、より良いロールを出した成功した戦闘員に1つ以上の特殊効果が与えられる。
5. 攻撃者が「成功」または「クリティカル」を達成した場合、武器ダメージをロールし、ダメージ修正値（もしあれば）を加算する。該当する場合、打撃のヒットロケーションが決定される。
6. 防御者が「成功」または「クリティカル」を達成した場合、関与する武器のサイズ比較に応じて、受けたダメージを軽減する。
7. 残りのダメージから、自然または装備している鎧の鎧ポイント分を減少させる。

交換によって生じた特殊効果は、ダメージを受けたかどうかとは独立していることに注意すること。防御者がより高い成功レベルを得たとしても、負傷を被る可能性は十分にある。

### 武器サイズ

『Classic Fantasy Imperative』のすべての武器は、与えるダメージから扱うために必要な手の数まで、いくつかの異なる属性を持つ。サイズは武器の質量、レバレッジ、安定性の組み合わせであり、武器がダメージを与えたりパリィしたりする能力を決定するために使用される。サイズカテゴリーは「小」「中」「大」「巨大」「甚大」である。クリーチャーの素手攻撃には、その物理的特徴に応じて同様のカテゴリーが割り当てられる。

### ダメージ軽減

防御者がパリィに成功した場合、使用した武器のサイズ比較に応じて、攻撃者のダメージ（もしあれば）を軽減できる。

- **同等かそれ以上**のサイズの武器や盾で攻撃をパリィすると、すべてのダメージを逸らす。
- **1サイズ小さい**武器や盾でパリィすると、ダメージの半分のみを逸らす。
- **2サイズ以上小さい**武器や盾でパリィすると、ダメージを全く逸らすことができない。

例えば、グレートアクス（巨大）をカイトシールド（これも巨大）でパリィすれば全ダメージをブロックできる。グレイヴ（大）でパリィすればダメージは半分になり、ショートソード（中）でパリィしてもダメージを止めることはできない。

### 鎧

防御者のパリィを貫通したダメージは、所持している自然の保護（鱗や殻など）や着用している鎧の鎧ポイントによってさらに減少する。防御者が両方持っている場合、その2つは積み重なってダメージを減少させる。

その質量と移動の制限により、キャラクターが「着用」している鎧の最高鎧ポイント値が、イニシアチブロールへのペナルティとして作用する。

### 外れた攻撃をパリィする

攻撃者が初期の攻撃ロールを外した場合でも、防御者はアクションポイントを消費してパリィする選択肢を持つ。すでに外れた攻撃をパリィするのは不誠実に見えるかもしれないが、熟練した防御者はこれを利用して1つ以上の特殊効果を得ることで、敵を弱体化または無力化し、次のターンを他のアクションのために温存することができる。

### パリィできない、またはしたくない場合

防御者がアクションポイントの残りがなくパリィできない状況、あるいは一撃を耐える自信があるためパリィしないことを選択した状況では、自動的に失敗をロールしたものとして扱われる。これは成功した攻撃者に1つ以上の特殊効果を与える結果となる。

### 不成功ロールとファンブル

両方の戦闘員がロールに失敗した場合、あるいは防御者が外れた攻撃を利用しないことを決定した場合、攻撃/パリィのシーケンスは終了し、戦闘は次のイニシアチブを持つ参加者に続く。

## 特殊効果

戦いは単に相手を傷つけたり殺したりするだけではない。戦闘術は、必ずしも相手に危害を加えることなく、無力化したり譲歩を強いたりする、敵を「打ち負かす」ための多くの方法を教える。特殊効果はこれらの技術を表し、プレイ中にどのように発生するかを制御する。

対戦相手がそれぞれの戦闘スキルの差分ロールを行う際、成功レベルの差は特殊効果が発生する機会を示す。これは、狡猾なトリックや戦術を使用して活用できる不利な状況に、戦闘員が相手を追い込んだことを反映している。

得られる特殊効果の数は、[差分ロール結果表](0005_Skills.md?id=differential-roll-results-table)に示されている通り、成功レベルの差に依存する。

交換中に特殊効果が獲得された場合、それらはダメージやヒットロケーションがロールされる前に選択されなければならない。特殊効果を受けることに加えて深刻な傷を負った場合、耐久力ロールは効果の適用後に解決される。

特殊効果は多様な状況や技術を網羅している。攻撃専用に設計されたものもあれば、防御用のものもあり、両方の状況に適応できるものも少しある。特定の特殊効果は、特定の武器タイプや特定のダイスロールに限定される場合もあり、例えばスキルチェックでクリティカルやファンブルの結果を要求する。

2つ以上の特殊効果が得られた場合、各効果の前提条件が満たされている限り、戦闘員は自由に組み合わせて選択できる。一部の効果は重ね合わせ（スタック）可能である。例えば、クリティカル成功をロールして2つの特殊効果を得た攻撃者は、「ダメージ最大化」を2つ選択し、2つの別々の攻撃的なマニューバを選ぶこともできる。

### 特殊効果の詳細

#### 偶発的負傷（Accidental Injury）
防御者が相手の攻撃を逸らしたりねじったりして、攻撃者がファンブルし、自身を傷つける。攻撃者は、使用した武器を使ってランダムなヒットロケーションに対して自分自身へのダメージをロールしなければならない。素手の場合、攻撃者は内部の何かを裂くか折ることになり、ダメージロールは鎧を無視する。

#### 立ち上がり（Arise）
防御者が一瞬の隙を利用して、足場まで立ち上がることを可能にする。

#### 強打（Bash）
攻撃者は意図的に相手を叩き、バランスを崩させる。防御者がどれだけ後ろや横にふらつくかは、使用する武器に依存する。盾は3ダメージごとに5フィート（鎧やパリィ等による軽減前）、打撃武器は5ダメージごとに5フィート相手をノックバックさせる。強打は攻撃者のSIZの2倍までのクリーチャーにのみ有効である。対象が後ろの障害物に押し付けられた場合、転倒を避けるためにアクロバットスキルまたは運動スキルのハード難易度ロールを行わなければならない。

#### 出血（Bleed）
攻撃が主要な血管を切り裂く。打撃が鎧ポイントを克服してターゲットを負傷させた場合、防御者は元の攻撃ロールに対して耐久力の対抗ロールを行わなければならない。防御者が失敗した場合、多量の出血が始まる。各戦闘ラウンドの開始時、対象は疲労レベルを1段階失い、最終的に倒れ、死に至る可能性がある。出血傷は応急手当スキルロールに成功すれば止血できるが、対象は傷口を再開させずに激しい動作を行うことはできない。[失血（Blood Loss）](0007_Game_System.md?id=blood-loss)を参照。

#### 盲目（Blind Opponent）
クリティカル成功時、防御者は砂を投げたり、盾で日光を反射させたり、その他の戦術で相手の視界を一時的に妨害し、相手を盲目にする。攻撃者は防御者の元のパリィロールに対して回避スキル（盾使用時は武器スキル）の対抗ロールを行わなければならない。攻撃者が失敗した場合、盲目の方法に応じて次の1d3ターンの間、ハードまたは恐るべき難易度の状況修正を受ける。

#### 鎧無視（Bypass Armor）
クリティカル成功時、攻撃者は防御者の自然または着用している鎧の隙間を見つける。防御者が自然な保護以上の鎧を着用している場合、どちらを無視するかを攻撃者が決定する。この効果は重ね合わせて両方を無視することもできる。この効果において、魔法によって得られる物理的な保護は「着用している鎧」として扱われる。

#### 場所選択（Choose Location）
近接武器を使用する場合、その部位が攻撃の範囲内であれば、攻撃者は打撃が着弾する場所を自由に選択できる。遠隔武器を使用する場合、「場所選択」はクリティカル成功時のみ可能である。ただし、標的が至近距離におり、静止しているか攻撃者に気づいていない場合は除く。

#### パリィ回避（Circumvent Parry）
クリティカル成功時、攻撃者は成功したパリィを完全に無効化できる。

#### 武器損傷（Damage Weapon）
攻撃またはパリィの一部として、相手の武器を損傷できる。攻撃の場合、キャラクターは具体的に防御者のパリィ武器を狙い、使用者にではなくその武器に対してダメージロールを適用する。対象の武器は、ダメージ抵抗のために独自の鎧ポイントを使用する。ヒットポイントがゼロに減少すると、武器は破損する。

#### 武装解除（Disarm Opponent）
キャラクターは相手の武器を叩く、引き抜く、またはねじることで手から落とさせる。相手は自身の戦闘スタイルとキャラクターの元のロールで対抗ロールを行わなければならない。武装解除された者が負けた場合、武器は解除した者の「ダメージ修正値×3フィート」の距離まで飛ばされる。ダメージ修正値がない場合、武器は武装解除された者の足元に落ちる。武器の相対的なサイズがロールに影響する。武装解除するキャラクターの武器が1サイズ大きくなるごとに、相手のロール難易度が1段階上がる。逆に、小さくなるごとに1段階簡単になる。武装解除は攻撃者のSTRの2倍までのクリーチャーにのみ有効である。

#### パリィ強化（Enhance Parry）
クリティカル成功時、防御者は武器のサイズに関係なく、攻撃の全力を受け流すことができる。

#### 絡め取り（Entangle）
鞭や網などの絡め取り武器を持つキャラクターが、打たれた部位を固定することを可能にする。絡め取られた腕は持っているものを使用できず、罠にかかった脚はターゲットの移動を妨げ、絡め取られた頭、胸、腹部はすべてのスキルロールを1段階難しくする。次のターン、持ち主はアクションポイントを消費して自動的な「転倒」試行を行うことができる。絡め取られた被害者は、自身のターンに「筋力」を使用して引き抜くための対抗ロールを試みるか、特殊効果に勝利して「武器損傷」「武装解除」「離脱」を選択することで脱出を試みることができる。

#### 失敗強制（Force Failure）
相手がファンブルした際に使用し、対抗ロールを必要とする他の特殊効果と組み合わせることができる。「失敗強制」は、相手をデフォルトで対抗ロール失敗状態にさせる。これにより、武装解除や転倒などが自動的に成功する。

#### 掴み（Grip）
相手が攻撃者の「素手戦闘」範囲内にいる場合、空いている手（または掴む能力のある四肢）を使って相手を保持し、戦闘から離脱できないようにできる。相手は自身のターンに脱出を試みることができ、掴んだ者が好むスキルとの「筋力」または「素手」の対抗ロールが必要となる。

#### 突き刺し（Impale）
武器ダメージを2回ロールし、攻撃者はその結果のどちらを攻撃に使用するかを選択する。近接武器と仮定し、鎧を貫通して傷を与えた場合、攻撃者は武器を傷口に残すか、次のターンに引き抜くかの選択肢を得る。武器を残すと、犠牲者の今後のスキル試行に難易度ペナルティを与える。ペナルティの深刻さは、クリーチャーと武器のサイズに依存する（下の「突き刺し効果表」を参照）。単純化のため、同じサイズの武器による追加の突き刺しは追加ペナルティを与えない。近接戦闘中に突き刺した武器を引き抜くには、「準備」戦闘アクションを使用する必要がある。持ち主は対抗ロールなしの「筋力」ロールに合格しなければならない（相手が抵抗する場合は「筋力」対抗ロールに勝つ必要がある）。成功すれば武器が引き抜かれ、同じロケーションに武器の通常ダメージロールの半分（ダメージ修正なし）が追加で与えられる。失敗は武器が傷口に刺さったままで効果がないことを意味するが、持ち主は次のターンに再試行できる。特にかえしのある武器（銛など）は通常ダメージを与える。鎧は引き抜きダメージを軽減しない。突き刺したままの間、攻撃者は突き刺している武器をパリィに使用できない。

#### 射撃名手（Sharpshooter）
射撃によるヒットロケーションを、隣接する部位へ1段階移動させることを許可する。生理学が再ターゲット可能な部位に影響を与えるため、常識を適用すること。人型生物の場合、脚へのヒットを腹部へ移動できる。逆にグリフォンの胸を撃つ場合、前脚、翼、頭を選択できる。

#### ダメージ最大化（Maximize Damage）
クリティカル成功時、キャラクターは武器のダメージダイスの1つを最大値に置き換えることができる。例えば、通常1d6ダメージのハンドアクスは6として扱い、2d6ダメージのグレートクラブは1d6+6ダメージを与える。この特殊効果はスタック可能である。自然の武器にも使用できるが、ダメージ最大化は攻撃者のダメージ修正値には影響せず、通常通りロールしなければならない。

#### カウンター準備（Prepare Counter）
防御者は敵のパターンを読み、特定の特殊効果に対するカウンターを準備する（秘密裏に書き留めておくこと）。相手が戦闘中にその特殊効果を加えようとした場合、防御者は瞬時に攻撃者の効果を自身の効果に置き換え、自動的に成功させる。

#### 急速リロード（Rapid Reload）
遠隔武器使用時、次弾のリロード時間を1減らす。この効果はスタック可能である。

#### 傷跡付け（Scar Foe）
キャラクターは相手に生涯残る傷跡（喉元を切り裂く、胸に「Z」の字を刻むなど）を残す。

#### 標的選択（Select Target）
攻撃者がファンブルした場合、防御者は打撃を操り、隣接する傍観者に当たるようにできる。これには、新しい標的が攻撃者の近接武器の射程内、または遠隔攻撃の場合は射線上にいる必要がある。新しい被害者は予期せぬ事故に完全に不意を突かれ、自動的に命中する攻撃を避けるチャンスはない。ただし、補償として彼らは特殊効果を受けない。

#### 離脱（Slip Free）
クリティカル成功時、防御者は絡め取り、掴み、ピン留め状態から自動的に逃れられる。

#### 部位気絶（Stun Location）
攻撃者は打撃武器を使用して、打たれた身体部位を一時的に気絶させることができる。打撃が鎧ポイントを克服して傷を与えた場合、防御者は「耐久力」対抗ロールを攻撃ロールに対して行わなければならない。失敗した場合、ヒットロケーションは与えたダメージ値と同ターンの間、「無力化」される。胴体への打撃は防御者をよろめかせ、防御しかできなくなる。頭部への打撃は相手を一時的に意識不明にし、行動不能にする。

#### 粉砕（Sunder）
攻撃者は斧などの適切な武器を使用して、相手の鎧や自然保護を損傷させることができる。パリィや魔法による軽減後の武器ダメージは、保護の鎧ポイント値に対して適用される。鎧ポイントを超えた余剰ダメージは、その鎧や場所のAP値を減少させるために使用される（ストラップを切る、リングを破壊する、プレートをへこませる、モンスターの皮や鱗を剥ぎ取るなど）。保護が0 APに減少した後もダメージが残っている場合、それは打撃を受けた場所のヒットポイントに持ち越される。

#### 転倒（Trip Opponent）
キャラクターは相手をバランスを崩させ、地面に倒すことを試みる。相手は「筋力」、「回避」、または「アクロバット」でキャラクターの元のロールに対して対抗ロールを行わなければならない。標的が失敗すれば、転倒状態（伏せ）になる。四足歩行の相手（またはより多くの脚を持つクリーチャー）は運動スキルを回避の代わりに代用でき、ロールを1段階簡単に扱える。

#### 撤退（Withdraw）
防御者は自動的に射程外へ後退し、その特定の相手との交戦を断ち切ることができる。

## 近接戦闘

近接戦闘とは、伝統的な意味での白兵戦であり、戦闘員が wielded（手にした）武器や自然の武器を使って互いに打ち合うことである。以下のガイドラインは近接戦闘をより興味深くし、この章の前半で示唆された概念のいくつかをさらに説明するのに役立つ。

### 状況修正

状況修正は、特定の条件下で戦う場合、または特殊効果の結果として適用される。例えば、暗闇での戦いは「超人的」難易度を伴う可能性がある。特に指定がない限り、修正はGMが決定する。キャラクターに2つ以上の状況が関連する場合、最も厳しいものを使用する。

一部の修正は状況依存であるが、難易度を適用する代わりに戦闘スキルが関連スキルによって制限される。例えば、馬の上から戦うと戦闘スキルは「騎乗」スキルにキャップされ、水中で戦うと「水泳」の値にキャップされる可能性がある。

##### 近接戦闘の状況修正

| 状況 | 難易度 |
| :-- | :-- |
| 無防備な標的への攻撃 | 自動成功 |
| 閉所での攻撃 | ハード |
| 低い場所または騎乗者に対する防御 | ハード |
| 不安定な足場での戦い | ハード |
| しゃがみまたは片膝立ちでの戦い | ハード |
| 視界不良（深い霧、吹雪）での戦い | ハード |
| 背後からの攻撃に対する防御 | 恐るべき |
| 伏せ状態での戦い | 恐るべき |
| 半光（薄暗い照明）での戦い | 恐るべき |
| 真っ暗闇（照明なし）での戦い | 超人的 |
| 盲目または主要な知覚感覚の喪失 | 超人的 |

### 交戦（Engagement）

キャラクターは、相手の近接武器射程内にいる場合「交戦状態」と見なされる。これは必ずしも双方が互いに届く必要はない。どちらか一方が他方に打撃を与えられる可能性があるだけでよい。一度キャラクターが相手と交戦すると、自由にその戦いから離れることはできない（突撃による通り抜けは特殊な例外である）。敵との接触を絶つには、「機動戦」や「撤退」特殊効果の使用など、何らかの意図的な行動が必要となる。

### 突撃（Charging）

突撃アクションは、攻撃の力と衝撃を高めるために素早く移動する行為である。突撃は攻撃者が突撃アクションを選択し、「走行」または「疾走」 gait（歩法）で移動することを要求する。これにより相手と接触した場合、そこで停止し、突撃用に修正された攻撃アクションを実行しなければならない。突撃ができるようになるまでの最低距離はない。移動距離は、達成された勢いほど重要ではないためである。したがって「走行」や「疾走」が必要となる。

突撃中、攻撃ロールはハードな難易度ペナルティを受ける。その代わり、突撃は攻撃武器のサイズを1段階上げ、二足歩行の攻撃者のダメージ修正値を1段階上げる（四足歩行以上の場合は2段階）。騎乗キャラクターは自身のダメージ修正値の代わりに、乗り物のダメージ修正値を使用できる。突撃キャラクターの最終位置は、交換の結果と、攻撃者が停止するか、そのまま通り抜けて即座に交戦を断ち切ることを望むかによって決まる。

パリィや回避の代わりに、突撃を受けた側は同時に突撃者に反撃できる。この場合、長い武器を持っている者が先に打撃を行う。槍のように突撃を待ち受ける設定ができる武器の場合、受け手は自身の代わりに突撃者のダメージ修正値を使用できる。

### 遮蔽（Cover）

相手は、中間にある物質の頑丈さで物理的に打撃をブロックするか、相手がどこにいるかを曖昧にすることで、攻撃に対する遮蔽を使用する。遮蔽の正確な値は、その保護の厚さとカバーの範囲に依存する。

覆い隠されたヒットロケーションに着弾した攻撃は、カバーが持つ保護の範囲までブロックされる。遮蔽は、「場所選択」特殊効果を使って相手の見える部分を狙うか、武器が貫通可能であればカバー越しに攻撃することで部分的に無効化できる。

遮蔽が完全である状況で、攻撃者が自分の攻撃が貫通すると信じている場合、隠れた標的に向かって盲目的に攻撃できる。その場合、攻撃ロールは1段階難しくなり、特殊効果に勝利しても場所選択は行えない。これは、攻撃者が遮蔽の背後にいる標的の位置をかなり正確に知っていることを前提としている。

### 回避（Evading）

戦闘中の回避は、圧倒的な攻撃から自身を投げ出すことである。これには防御者の回避スキルと攻撃者の関連するロールの対抗テストが必要である。これは、突撃する戦車の「運転」スキルから、魔術師の「呪文詠唱」スキルまで何でもあり得る。攻撃者が勝てば、通常通りダメージを与える。防御者が勝てば、ダメージを完全に回避できる。

対抗ロールの勝者が相手に対して1段階以上の成功レベルを達成した場合、通常の戦闘と同様に適切な特殊効果を選択できる。結果がどうであれ、この回避行動は防御者を伏せ状態にする。キャラクターは次のターンに足場を回復しなければならない（「立ち上がり」特殊効果を使用できる場合を除く）。

### ノックバック（Knockback）

標的のSIZを超えるダメージを与える攻撃は、デフォルトでキャラクターをノックバックさせる。この状況でのダメージは、パリィや鎧による軽減前の数値である。このような打撃を受けた場合、相手は転倒を避けるために「イージー」アクロバットロールまたは「標準」運動ロールに合格しなければならない。また、SIZを超えたダメージ8点ごとに5フィート（端数切り上げ）後ろへ押しやられる。「構え」戦闘アクションをプロアクティブに使用することで、ノックバックの影響を軽減または無効化できる。

### 跳躍攻撃（Leaping Attacks）

跳躍攻撃はさまざまな状況から仕掛けることができ、大部分は待ち伏せの一部として、または突撃の締めくくりとして誘発されるが、一部のクリーチャーは助走や高さのアドバンテージなしで相手の上に飛びかかることができる。

跳躍攻撃は、飛びかかる者の運動スキルと、防御者の筋力または回避スキルの対抗ロールで解決される。四足歩行の標的は、攻撃ロールを1段階難しくする。飛びかかる者が勝てば、防御者は自動的に転倒し、攻撃者がその上にまたがる。失敗は、防御者が衝撃を耐えたか、横に避けたことを意味する。対抗ロールの勝者が相手に対して1段階以上の成功レベルを達成した場合、通常の戦闘と同様に適切な特殊効果を選択できる。

跳躍自体ではダメージは与えられない。しかし、転倒させられた被害者は、攻撃者が離れるか、立ち上がることを許可する特殊効果を得るまで足場を回復できない。さらに、跳躍攻撃は攻撃者のSIZの2倍までの相手にのみ機能する。ターゲットは、跳躍攻撃が迫っていることに気づいていれば、「構え」戦闘アクションを事前に使用することで、転倒しにくくすることができる。

### 機動戦（Outmaneuvering）

複数の相手と向き合うキャラクターは、常に位置を変え、敵同士を干渉させることで、一度に自分を攻撃できる人数を制限する移動を使用できる。機動戦にはキャラクターが動き回る余地が必要であり、狭い場所でピン留めされていてはならない。

機動戦は、キャラクターが複数の相手と「回避」スキルによるグループ対抗ロールを行う必要がある。キャラクター自身と、彼を追い詰めたい敵のすべての参加者は、アクションポイントを消費しなければならない。次にそれぞれ一度ロールを行い、機動戦を行うキャラクターのロールに勝てなかった者は、味方や地形の特徴に邪魔され、その戦闘ラウンドの残りの間、彼を攻撃できない。

機動戦を行うキャラクターがすべての対戦相手に勝った場合、ラウンドの残りの時間、単一の敵と安全に交戦するか、戦いから完全に「撤退」するかを選択できる。

### 受動的ブロック（Passive Blocking）

受動的ブロックにより、武器を持つキャラクターは特定のロケーション（盾使用時は複数）をカバーするように武器を保持できるが、その代償としてその武器でアクティブなパリィはできなくなる（[位置防護（Ward Location）](0008_Combat.md?id=ward-location)を参照）。その場所をヒットする攻撃は、自動的に武器や盾の恩恵を受け、ダメージが通常通り軽減される。この技術は、戦士が弱点や負傷部位を守りたいときに一般的に使用される。二刀流、あるいは武器と盾を持つキャラクターが、もう一方の武器を使ってアクティブなパリィを行うことを妨げるものは何もない。

受動的ブロックは遮蔽と同じ方法で機能するため、近接戦闘において「場所選択」特殊効果でブロックを回避することはできない。ただし、相手は特殊効果を使用して、他のブロックされていない領域を攻撃することはできる。受動的ブロック中に盾の後ろにしゃがみ込むことで、キャラクターはカバーするロケーションの数を2倍にできる。

### 不意打ち（Surprise）

不意打ちは、攻撃者の存在や意図を知らない相手に対して予期せぬ攻撃が仕掛けられたときに発生する。前者の例は待ち伏せであり、後者は親しい会話の最中に裏切って友好的な味方を攻撃する図である。

ターゲットへの不意打ちの影響は強力である：

- ターゲットはイニシアチブに-10のペナルティを受ける。
- イニシアチブが来るまで、ターゲットは「足元が不自由」な状態と見なされ、防御できない。
- ターゲットへの最初の攻撃が成功すれば、ボーナスとして特殊効果を1つ得る。
- ラウンドの残りの間、ターゲットは攻撃的なアクションを実行できない。

### なぎ払い攻撃（Sweep Attacks）

なぎ払い攻撃は、巨大なドラゴンの尻尾や巨大なトリケラトプスの止まらない突撃など、通常とは異なるサイズの武器やクリーチャーが密集した敵の集団を攻撃する際に、GMの判断で発生する。これにより、複数の敵を同時に攻撃する。

なぎ払い攻撃は、武器やクリーチャーの単一の攻撃ロールを、経路内のすべてのターゲットに適用することで行われる。各防御者は攻撃の影響を個別に解決しなければならず、攻撃者に課せられた特殊効果は同時発生したものとして扱われる。

## 遠隔戦闘

遠隔戦闘には、標的に当てるために射撃、投擲、または投石を必要とするすべての武器形態が含まれる。遠隔攻撃は近接戦闘と全く同じ方法で解決される。しかし、遠隔武器は通常、盾でのみパリィできる。盾を持たない者は自然の遮蔽に頼るか、「回避」を使用して射線から飛び退かなければならない。したがって、軽装の敵に対して遠隔武器は恐るべき抑止力となり得る。

各遠隔武器には、その有効性を決定するいくつかの特定の属性がある。戦闘において重要な意味を持つ属性は以下の通り：

- **威力（Force）:** 遠隔武器版のサイズ。武器や弾薬の貫通力を抽象化した尺度であり、盾のパリィを克服できるかどうかを決定する。
- **ダメージ修正値（Damage Modifier）:** この属性は、攻撃者のダメージ修正値を遠隔武器のダメージロールをブーストするために使用できるかどうかを示す。一般的に、弓や投擲武器のみがユーザーのダメージ修正値の適用を許可する。
- **レンジ（Range）:** スラッシュで区切られた3つの数値で、武器や弾薬の最大「至近」「有効」「遠距離」を示す。至近レンジは「場所選択」特殊効果を使用できる距離であり、標的が静止しているか攻撃に気づいていない場合に限る。有効レンジには大きな修正はない。遠距離では、武器はまだ危害を与えられるが、ダメージは半分になり、威力は1段階減少する。
- **装填（Load）:** 弾薬を発射する武器のリロードや装填にかかるターン数。キャラクターは「急速リロード」特殊効果の使用により、ロードや準備の時間を短縮できる。
- **突き刺しサイズ（Impale Size）:** 突き刺さった武器のサイズは、打撃を与える威力とは異なる。「突き刺し」特殊効果による妨害を考慮する際、遠隔刺突武器は実際のサイズを示す特別な列を持つ。

### 状況修正

近接戦闘と同様に、特定の条件下で遠隔武器を使用する際に状況修正が適用される可能性がある。馬に乗りながら槍を投げるなど、困難な状況で武器を使用する場合、キャラクターの戦闘スキルがキャップされる可能性がある。

##### 遠隔戦闘の状況修正

| 状況 | 難易度 |
| :-- | :-- |
| 軽い風\* | ハード |
| 中程度の風\* | 恐るべき |
| 強風\* | 超人的 |
| 暴風雨、嵐、またはそれ以上\* | 絶望的 |
| 標的が走行中 | ハード |
| 標的が疾走中 | 恐るべき |
| 霧や薄暗がりにより標的が不明瞭 | ハード |
| 濃い煙や暗闇により標的が不明瞭 | 恐るべき |
| 標的が完全に見えない | 超人的 |
| 標的が完全に見えない | 不可能\*\* |
| 標的が伏せ状態 | 恐るべき |
| 攻撃者が伏せ状態\*\*\* | 超人的 |
| 攻撃者が不安定な足場にいる | ハード |

_\* 投擲武器や弾薬が横風に弱いことを前提としており、通常のスキルに風が与える通常ペナルティに優先する。_

_\*\* 標的の一般的な位置が判明または既知でない限り、超人的として扱う。_

_\*\*\* 準備された位置からクロスボウを使用している場合はペナルティを無効化できる。_

### 狙い（Aiming）

遠隔武器の照準に余分な時間を費やすことで、キャラクターは命中確率を高められる。狙いには武器を安定させ、風の凪や障害物の間を標的が移動するのを待つなど、最良の機会をリリースするために1戦闘ラウンド全体を必要とする。狙うことで、キャラクターは遠隔または状況修正の難易度を1段階下げられる。これ以上ラウンドを費やしてもさらなるメリットはない。

### 群衆への射撃

乱戦の渦中に射撃することは危険であり、標的以外の誰かに偶然当たるリスクが常にある。群衆や乱戦の端にいる特定の標的を狙う場合、攻撃はハード難易度を受ける。それを通り抜けて撃とうとする場合、難易度は「恐るべき」まで上がる。狙うことで危険を緩和できる。

ペナルティにもかかわらず攻撃ロールに成功した名手は、狙い通りに標的に命中させる。しかし、名手がロールに失敗し、「群衆への射撃」ペナルティがなければ成功していたはずだった場合、代わりに隣接する被害者が撃たれる（被害者は通常通り回避やパリィが可能）。

射線上に複数の標的がいる場合、GMは被害者をランダムに決定すべきである。攻撃の一部として獲得した特殊効果は、元の標的にのみ適用され、偶然当たった傍観者には適用されない。
