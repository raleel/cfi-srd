# 第1章：キャラクター

基本的なキャラクターは、その能力を記述する一連の異なる要素によって定義されます。これらの要素は以下の通りです。

- 特徴値（Characteristics）：筋力や魅力など
- 属性値（Attributes）：身長や移動力など
- 技能（Skills）：基本的な能力における専門知識

これらの要素のほとんどは数値で表され、一部は他の要素に依存していたり、他の要素から算出されたりします。各要素の意味と決定方法は、以下のセクションで説明します。

---
## ステップ1：キャラクターのコンセプト

まず、どのようなキャラクターを演じたいかというアイデアを持つことから始めると良いでしょう。例えば、鍛え上げられた戦士や、狡猾なローグなどです。この段階でキャラクターのコンセプトを詳細にする必要はありません。人種やクラスといった特定の選択を導くためのアイデアがあれば十分です。想像力をかき立てるためのキャラクターのアイデアをいくつか挙げます。

- 若く世間知らずの魔法使い
- 気性の荒いハーフオークの戦士
- 自信過剰なハーフリングのローグ
- 信心深いドワーフのクレリック

---
## ステップ2：特徴値

すべてのキャラクターは、そのキャラクターの性質を表す7つの「特徴値」によって定義されます。どれほど力が強いか、速いか、賢いか、あるいは健康かを示します。特徴値はすべての『Classic Fantasy Imperative』キャラクターの核心であり、属性値や技能といった他の多くの要素の基礎を形成します。7つの特徴値は以下の通りです。

- 筋力 (STR)
- 体質 (CON)
- サイズ (SIZ)
- 敏捷性 (DEX)
- 知性 (INT)
- 意志力 (POW)
- 魅力 (CHA)

特徴値を算出する前に、各特徴値が何を表すかを以下のセクションで説明します。

#### 筋力 (STR)

STRは物理的な力を表します。どれだけの重さを持てるか、どれだけ強く叩けるかなどです。STRは[ダメージ修正](0001_Characters.md?id=damage-modifier)の構成要素です（後述の[属性値](0001_Characters.md?id=step-3-attributes)セクションを参照）。キャラクターのSTRが0になると、移動や物を持ち上げる能力を失います。

#### 体質 (CON)

CONは健康と頑健さの尺度です。CONは[ヒットポイント](0001_Characters.md?id=hit-points)と[回復率](0001_Characters.md?id=healing-rate)を決定する構成要素です（後述を参照）。何らかの理由でCONが0になると、キャラクターは死亡します。

#### サイズ (SIZ)

SIZは質量を測定し、身長と体重を示す指標となります。SIZは[ヒットポイント](0001_Characters.md?id=hit-points)を算出するために使用されます。体が大きく重い生物は、ダメージに対してより耐久力がある傾向があるためです。SIZはキャラクターのダメージ修正を決定するためにも使用されます。質量があることで打撃の威力が増すためです。

#### 敏捷性 (DEX)

機敏さ、バランス感覚、反射神経はDEXで測定されます。これは[イニシアチブ](0001_Characters.md?id=initiative)の重要な側面です。キャラクターのDEXが0になると、機能的な麻痺状態に陥ります。

#### 知性 (INT)

INTは認知能力の尺度です。INTスコアが低い者が必ずしも愚かであるとは限りませんが、機転を利かせる創造的な能力は制限される可能性が高いでしょう。INTは[イニシアチブ](0001_Characters.md?id=initiative)を計算する際の要因となります。INTが0になると、キャラクターは完全に意識を失います。

#### 意志力 (POW)

POWはキャラクターの魂、精神、内なる衝動、または魔法の容量を測定するものです。POWはキャラクターの[マジックポイント](0001_Characters.md?id=magic-points)と[ラックポイント](0001_Characters.md?id=luck-points)を司ります。キャラクターのPOWが0になると、自立した意志をすべて失います。

#### 魅力 (CHA)

魅力は個性を測定するものであり、外見とは無関係です。CHAはキャラクターの[経験修正](0001_Characters.md?id=experience-modifier)に影響を与えます。CHAが0になると、キャラクターは他者と社会的に交流することができなくなり、非常に極端な内気さや反社会性から無視されたり、追い払われたりするようになります。

---
### 特徴値の算出

各特徴値には、その能力の高さを示す数値があります。ダイスロール結果の後の括弧内の数値は、その種族の平均値であり、種族の他のメンバーと比較してキャラクターの結果を評価するための基準として使用されます。特徴値を決定するための提案は以下の通りです。

- **ダイスロール:** 種族特徴値表に記載されているダイスをSTR、CON、SIZ、DEX、INT、POW、CHAごとに振り、出た目をそのままスコアとして使用します。これらの出目はある程度ランダムであるため、ダイスを振った後にキャラクターのコンセプトを決める方が良い場合が多いでしょう。そうでなければ、最終的な特徴値によって、あらかじめ決めていた役割が果たせなくなる可能性があるからです。STR、CON、DEX、POW、CHAには3d6を、SIZとINTには2d6+6を振ります。
- **ダイスロール＆割り当て:** 上記と同様ですが、プレイヤーは同じダイス範囲を持つ特徴値間で値を入れ替えることができます。例えば、人間を作成する場合、STR、CON、DEX、POW、CHAはすべて3d6の範囲なので、これらの間で値を入れ替えたり、2d6+6の範囲を持つSIZとINTの間で入れ替えたりできます。ただし、必ず同じダイスグループ内である必要があります。グループ間で値を入れ替えることはできません。
- **ダイスロール＆高値採用:** STR、CON、SIZ、DEX、INT、POW、CHAごとに指示されたダイスを1個余分に振り、最も低い結果を除外します。
- **ポイントビルド:** ダイスを振る代わりに、キャラクターの種族によって決められたポイントプールから能力値を構築します。この方法は、何をプレイしたいかが明確で、特定のクラスに合わせてキャラクターを調整したいグループに最適です。ポイントビルドには以下のルールが適用されます。
  - 下記のダイス範囲の後の括弧内に記載されている、7つの特徴値の種族平均値から開始します。
  - さらに10ポイント（人間）または6ポイント（亜人間）を消費して特徴値を上昇させます。
  - 特徴値を下げることでポイントを得ることもできます。例えば、STRを11から9に下げると2ポイントが得られます。
  - 特徴値は、そのダイスロールの可能性によって決定される最小値より「低く」したり、最大値より「高く」したりすることはできません。

ゲームマスターは、必要に応じて独自のメソッドやポイント値を自由に追加できます。

以下の表は、上記の方法それぞれに必要な情報をまとめたものです。ダイス範囲はダイスロールのいずれかの方法で使用し、括弧内の数字はポイントビルドで使用します。

## ステップ3：属性値

各キャラクターには属性値のセットもあります。これらは特徴値から導き出されるか、特徴値によって決定される能力であり、ゲームプレイの特定の要素を管理するために使用されます。

#### アクションポイント

キャラクターが[戦闘ラウンド](0008_Combat.md?id=combat-rounds)でどれだけ頻繁に行動できるかは、アクションポイントによって決定されます。初期キャラクターは2アクションポイントから始まりますが、ランクが上がるにつれて増加します。詳細は[クラス](0003_Classes.md)の関連するクラス成長表を参照してください。

#### ダメージ修正

キャラクターが物理的に攻撃したり力を加えたりした際に与えるボーナスダメージ量です。通常は戦闘状況で使用されますが、物を破壊しようとする際にも利用できます。ダメージ修正は、武器やツールが与えるダメージに追加、または差し引かれる追加のダイスロールです。負のダメージ修正によって武器のダメージが0以下になった場合、ダメージはまったく与えられません。

STRとSIZを合計し、ダメージ修正表を参照してください：

| 6–10 | –1d6 |
| 11–15 | –1d4 |
| 16–20 | –1d2 |
| 21–25 | +0 |
| 26–30 | +1d2 |
| 31–35 | +1d4 |
| 36–40 | +1d6 |
| 41–45 | +1d8 |
| 46–50 | +1d10 |
| 51–60 | +1d12 |
| 61–70 | +2d6 |
| 71–80 | +1d8+1d6 |

| 91–100 | +1d10+1d8 |
| 101–110 | +2d10 |
| 111–120 | +2d10+1d2 |
| 121–130 | +2d10+1d4 |
| 10ポイントごと | 進行を継続 |

#### 経験修正

プレイを通じて、キャラクターは技能と能力を向上させます。これは経験ロールを使用して達成されます。経験ロールについては[ゲームシステム](0007_Game_System.md?id=experience-rolls)セクションで詳しく説明されています。

キャラクターのCHAスコアは、キャラクターが持つ経験ロールの回数を調整することがあります。これは、仲間との関係やコミュニティ内での評判を反映しています。CHAが高ければ、人々はキャラクターが修行中に助言や支援を提供してくれます。逆にCHAが極端に低ければ、他人の助けなしに能力を向上させることは難しいかもしれません（例えば、対戦相手を見つけるなど）。

##### 経験修正表

| CHA | 経験修正 |
| :-: | :-: |
| 6以下 | -1 |
| 7-12 | +0 |
| 13-18 | +1 |
| 6ポイントごと | +1 |

#### 回復率

負傷した後、キャラクターは療養する必要があります。回復率は、傷からどれだけ早く自然に回復するかを決定します。怪我の深刻さ（[ダメージと負傷](0007_Game_System.md?id=damage-and-wound-levels)のセクションを参照）に応じて、回復率は1日、1週間、または1ヶ月あたりに回復するヒットポイントの数を示します。

##### 回復率表

| CON | 回復率 |
| :-: | :-: |
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

#### イニシアチブ

戦闘において誰がいつ反応するかは、イニシアチブによって決定されます。イニシアチブはイニシアチブロールへの修正値として機能します。イニシアチブが高いほど戦闘状況でより早く反応でき、いつ行動できるかが決まります。防具などのさらなる要因が修正を加えます。[戦闘](0008_Combat.md?)の章では、[イニシアチブ](0008_Combat.md?id=initiative)の使用方法について詳しく説明しています。

イニシアチブは、DEXとINTの特徴値の平均です。

#### ラックポイント

ラックポイントは、冒険する英雄と一般の人々を区別する不思議な力を表します。運命、カルマ、あるいは単なる幸運と呼ぶことができます。ラックポイントは以下のことに使用できます：

- 結果が好ましくない場合にダイスを振り直す。
- 物理的なダメージやその他の不運な状況を緩和する。
- 戦闘の重要な瞬間に優位に立つ。

使用方法やタイミングは「[ラックポイントの使用](0007_Game_System.md?id=using-luck-points)」セクションで説明されています。ラックポイントを消費すると、プールは減少します。ラックポイントがなくなると、次のゲームセッションで通常の数値に回復するまで（ゲームマスターによる臨時の報酬がない限り）使用できません。

##### ラックポイント表

| POW | ラックポイント |
| :-: | :-: |
| 6以下 | 1 |
| 7-12 | 2 |
| 13-18 | 3 |
| 6ポイントごと | +1 |

_\* 人間は上記に加えて、初期ラックポイントが1ポイント多くなります。_

_\*\* すべてのキャラクターは、新しいランクに到達するたびに追加のラックポイントを1ポイント得ます。_

#### マジックポイント

『Classic Fantasy Imperative』における神秘的な能力や呪文は、通常マジックポイントに依存します。キャンペーン設定や特定の魔法の職業によって魔法の使用が制限されている場合、一部のキャラクターにとってこの属性値は不要となる場合があります。

そのような力を使用できるキャラクターにとって、マジックポイントはPOWに等しい値です。これらのポイントは呪文を唱えるために使用され、そのコストは使用される魔法の種類によって異なります。詠唱者がマジックポイントを使い果たすと、ポイントが回復するまで呪文を唱える能力は失われます。

#### 移動力

すべての生物は移動力を持っています。これは特定の期間内に移動できるフィート数です。移動力は特徴値から算出されるものではなく、種族ごとに異なるデフォルト値です。人間の基本移動力は20フィートですが、特定の技能によってこれを向上させることができます。[移動](0008_Combat.md?id=movement)のセクションで詳細を説明しています。

| エルフ | 20 | 6 |

| ハーフエルフ | 20 | 6 |
| ハーフオーク | 20 | 6 |

#### ヒットポイント

ヒットポイントは、体の各部位がどれだけの負傷に耐えられるかを表します。これを超えると機能しなくなり、無力化、ひいてはキャラクターの死につながる可能性があります。すべての生物の体は別々の部位に分かれています（人間には頭部、胸部、腹部、腕、脚の7つの部位があり、それぞれに個別のヒットポイントがあります）。

モンスターや特定の動物など、一部の生物はその性質上、根本的に異なる身体構造を持っていますが、彼らが持つ各部位にもヒットポイントがあります。あらゆる種類のダメージを通じて部位のヒットポイントがあるレベルまで低下すると、キャラクターは怪我の深刻さを反映した特定の結末に苦しむことになります。負傷に関する詳細については、[ダメージと負傷](0007_Game_System.md?id=damage-and-wound-levels)セクションを参照してください。

## ステップ4：技能

デフォルトで、すべてのキャラクターは様々な程度の専門知識で多種多様な行動を行える一連の「標準技能」を持っています。これらの技能は[技能](0005_Skills.md)の章でより詳細に説明されていますが、専門的な訓練なしで誰でも使用できる日常的な活動と地域の知識をカバーしています。キャラクター作成のこの段階では、各標準技能の「基本値」を知るだけで十分です。

各標準技能の基本スコアは、2つの特徴値の合計、または単一の特徴値の倍数によって決定されます。この数値は各分野におけるキャラクターの生来の適性を表しており、文化や職業の一部として受ける形成的な訓練を受ける前の、素の才能を効果的に表したものです。

標準技能表は基本値の計算方法と、その技能が何であり何をするかについての簡単な説明を示しています。スコアは技能の成功率（パーセンテージ）を表します。例えば、運動スコアが25であれば、25%として表現されます。技能パーセンテージの仕組みやより詳細な説明は[技能](0005_Skills.md)の章で提供されています。

一部の技能の基本パーセンテージは文化と職業の両方によって修正されるため、キャラクター作成が進むにつれてこれらの開始値は変更されることに注意してください。

## ステップ5：種族／文化

『Classic Fantasy Imperative』では、プレイヤーは通常6つの種族から1つを選択できます：人間、または亜人種（ドワーフ、エルフ、ノーム、ハーフエルフ、ハーフオーク、ハーフリング）。人間の場合、さらに「蛮族」「文明人」「遊牧民」の3つの文化的背景からキャラクターを定義する必要があります。人間にとって、文化はキャラクターが育った社会の種類を決定し、そのためキャラクターが持つ可能性のある特定の視点や哲学を規定します。より実際的には、文化はキャラクターの全体的な能力を形成する様々な技能の値を定義するのに役立ちます。亜人種は一般的に、その種族のステレオタイプを体現した種族文化から生まれます。詳細については[第2章](0002_Culture_and_Races.md)の種族と文化の記述を参照してください。

すべてのキャラクターは「属性（Alignment）」を持っており、これは1つの倫理コードと1つの道徳コード、そして2つか3つの「情熱（Passions）」で構成されます。宗教団体、ギルド、組織に対する「誓約（Oath）」を持つ者もいます。各クラスの記述には、必要な属性や誓約が記載されています。先へ進む前に、[第2章](0002_Culture_and_Races.md)で自分の種族を調べ、推奨される属性と情熱をメモしてください。また、[クラス](0003_Classes.md)セクションを確認し、属性や誓約の要件があるかを確認してください。属性、情熱、誓約に関する詳細については、[第4章、属性と情熱](0004_Alignment_and_Passions.md)を参照してください。

各種族および文化には、キャラクターがその社会での形成的な成長の一環として学ぶ多様な標準技能がリストされています。これらは同じ文化背景を持つすべてのキャラクターがある程度向上させる中核的な能力です。キャラクターはまた、個人の関心に応じて、「専門技能（Professional Skills）」をいくつか学びます。

専門技能については[技能](0005_Skills.md)の章でさらに説明されていますが、簡単に言えば、長年の厳格な学習と専門的な訓練なしには試みることのできない技能を表しています。キャラクターはすべての標準技能において基本的な能力を持っていますが、文化的背景やクラスの一部として選択しない限り、専門技能の能力はゼロです。

選択した専門技能は、標準技能と同様に基本レベルの特徴値から始まります。工芸、言語、知識などの一部の専門技能には、専門分野の選択が用意されています。これらの場合、選択する専門分野はその文化に適したものにする必要があります。

### 種族別技能ポイント購入

オプションとして、ポイントを消費してキャラクターのコンセプトをカスタマイズできます。これにより、時間はかかりますが、より調整されたキャラクターを作成できます。技能を適用する際は、以下の手順に従ってください：

- 提供されているオプションから専門技能を3つ選択します（種族の説明については[第2章](0002_Culture_and_Races.md)を参照）。
- リストされた標準技能と選択した専門技能に100ポイントを分配し、改善するために費やした1ポイントにつき技能を1%ずつ上昇させます。各技能をどれだけ改善するかはプレイヤーの自由ですが、各技能には最低でも5%を割り当てる必要があり、15%を超えてはなりません。

## ステップ6：クラス

クラスはキャラクターが大人になる過程で踏み出したキャリアを表し、キャラクターの技能発達をさらに定義します。

プレイヤーは通常、ゲームマスターが適切と判断すれば、どのクラスを演じたいかを選択する自由があります。クラスの記述には、各種族／文化タイプで利用可能な一般的なクラスについてのガイダンスが記載されています。これは制限ではなく、一般的な傾向と見なすべきです。プレイヤーは自分のビジョンに最も適したクラスと種族の組み合わせを自由にプレイしてください。

種族／文化的背景と同様に、各クラスはその職業で一般的に使用される一連の標準技能および専門技能を向上させる機会を提供します。文化的背景とは異なり、すべての利用可能な技能にポイントを投資する必要はなく、特定の役割や文化に適したものだけを調整することができます。

### クラス別技能クイックピック

対象クラスに有用な技能の平均的な選択として、クラスのクイックピックを選択してください。必要に応じてポイントを入れ替えても構いませんが、基本レベル（専門技能を含む）で機能させるために技能を+0まで減らすことは可能であっても、どの技能も+15以上のボーナスを得ることはできません。これらの技能には、アビリティによるクラス技能ボーナスがすでに含まれています。

### クラス別技能ポイント購入

オプションとして、ポイントを消費してキャラクターのコンセプトをカスタマイズできます。上記と同様、時間はかかりますが、より調整されたキャラクターを作成できます。この方法を使用するキャラクターは、以下の方法でクラス技能を成長させます：

- そのクラスで利用可能な専門技能から最大3つを選択します。
- クラスのリストにある標準技能と選択した専門技能に100ポイントを分配し、改善するために費やした1ポイントにつき1%ずつ上昇させます。利用可能なすべての技能を向上させる必要はありませんが、個々の技能が15%を超える上昇を得ることはできません。一部のクラスは3つ以上の専門技能を付与しますが、合計ポイントは変わりません。
- すべてのクラスには、そのクラスが通常使用の訓練を受けている武器を網羅する「戦闘技能」が含まれます。これは魔法使いのように4〜5つの単純な武器であることもあれば、戦士のようにすべての武器と盾であることもあります。戦闘技能が標準技能のリストに含まれている場合、それは標準技能として扱われ、クラス技能ポイントで向上させることができます。魔法使いのように戦闘技能がリストから省略されている場合、それはキャラクター作成のステップ7でボーナス技能ポイントを使用してのみ向上させることができます。

新しく選択した専門技能とクラス戦闘技能は、基本レベルの特徴値から始まります。文化的背景を通じて獲得した専門技能を再び選択することは、この段階でキャラクターがクラス技能ポイントのいくつかをさらに割り当てることを可能にするだけです。工芸、言語、知識などの一部の技能には、専門分野の選択が用意されています。これらの場合、選択する専門分野はキャラクターの文化に適したものにする必要があります。

一部のクラスは他のクラスよりも選択肢が多いか、より多くの技能を選択できる場合があります。これは、すべてのキャラクターが同じ100ポイントで構築されるという事実によってバランスが取られています。つまり、より多くの技能を持つキャラクターは、多くのことを少しずつ知ることになり、技能の選択肢が少ないキャラクターはより専門化することになります。

#### クラスアビリティとランクに関する注記

すべてのクラスが、そのクラスの特殊アビリティを使用したり呪文を唱えたりするためには、少なくとも**「いずれか5つのクラス技能において技能レベルが40%以上」**である必要があることに留意してください。50%以上あれば、その技能に精通していると見なされます。したがって、ランク1の資格を得るには、いずれか5つのクラス技能が40%以上である必要があります。ランク2にはいずれか5つのクラス技能が70%以上、ランク3にはいずれか4つのクラス技能が90%以上といった具合です。

技能レベルが不十分な場合、ランク0から開始し、プレイ中にランク1に到達することも選択できますが、呪文を使用または詠唱するためにはこれらの前提条件を満たす必要があります。

#### 戦闘技能（STR+DEX）

戦闘技能は、戦いと武器の使用に関する技能です。これは、対象となるキャラクタークラスに関連する多くの専門分野を持つ多様な技能です。ほとんどの戦闘伝統は、同じ種類の複数の武器の訓練と、それらを効果的に使用するために必要な技術を網羅しています。したがって、戦闘技能は、関連する戦闘の側面を単一の能力の下に統合する傘のようなものであり、複数のサブ技能を購入する必要をなくします。

戦闘技能の基本パーセンテージはSTR+DEXに等しいです。

ほとんどの人は武器を手に取れば本能的に振ったり、投げたり、発射したりできるため、戦闘技能は標準技能と見なされます。しかし、その潜在的に多様な性質のため、個別に分類および定義されています。

すべてのキャラクターは、[第3章](0003_Classes.md)で説明されているように、選択したクラスの一部として戦闘技能を学びます。

## ステップ7：ボーナス技能ポイント

この段階で、すべてのキャラクターは経験レベルに基づいた追加の「フリー」技能ポイントを獲得し、既存の技能に分配できます。これらはキャラクターを充実させ、興味や専門分野を加えるために提供されます。新規キャラクターのデフォルトは100ポイントで、1技能につき最大10ポイントまで割り当てることができます。キャラクターがより経験豊富な場合、経験表に示されているように、技能ポイントの数や制限が異なります。

ボーナス技能ポイントは以下の方法で使用されます：

- 個人の趣味や興味を反映して、最後にもう1つ新しい専門技能を無料で選択するオプションをキャラクターに許可する。
- 代わりに、キャラクターは戦闘技能に新しい武器タイプを追加できる。
- 10個の異なる技能に+10ボーナスを追加するか、ポイントを分配して、改善のために費やした1ポイントにつき1%ずつ各技能を上昇させる。個々の技能は、経験レベルによって示される以上のポイントを得ることはできません。新しい専門技能を選択した場合は、そこにポイントを追加しなければなりません。
- 趣味の専門分野を除き、文化やクラスの一部として学習しなかった専門技能にポイントを割り当てることはできません。

### 経験豊富なキャラクターの作成

新規キャラクターは、実質的な経験がないランク1の状態で開始することをお勧めします。もちろん、キャラクターのレベルは設定や、ゲームが短期間の冒険か長期のキャンペーンかによって大きく異なります。プレイ中に死亡したキャラクターを交代させる際や、既存のキャンペーンに参加する際に、プレイヤーがより経験豊富なキャラクターを作成することも一般的です。

経験を「経験カテゴリー」に分類した表が提供されています。キャラクターの経験は、年齢や技能の能力と直接の相関関係があります。より経験豊富なキャラクターは、当然ながら若い仲間よりも多くの人生経験を積んでいます。ただし、記載されている年齢ボーナスは概算として扱ってください。キャンペーンは進む速度が異なるためです（アドベンチャーの間に多くのゲーム内時間が経過するキャンペーンもあれば、中断のないアドベンチャーが長く続くものもあります）。既存のキャラクターを変換する場合は、記載されている年齢を実際のものと置き換えてください。

この表は、クラスを使用して構築されたかキャリアとして構築されたかに関わらず、NPCにも使用でき、同じルールに従います。ただし1つ例外があります。キャリアとして構築されたノンプレイヤーキャラクターは、プレイヤーキャラクターと重要なノンプレイヤーキャラクターのみに予約されている追加のラックポイントを含む、特殊アビリティを持ちません。キャリアとして構築された初期NPCは、デフォルトでランク1であることに注意してください。

- ランクは、異なるスキルレベルのキャラクターを比較するための大まかなガイドです。
- 年齢は、種族に応じて年齢を計算し、記載されているボーナスを加算して決定します。時間はキャンペーンごとに異なるため、これは厳格なルールではなくガイドラインです。
- ボーナス技能ポイントは、キャラクターが技能開発に費やすポイント数を決定します。これは以前のランクのものと累積されません。例えば、ランク2のキャラクターは、ランク1からの100ポイントに300を足すのではなく、300ポイントで作成されます。
- 最大技能上昇値は、ボーナスポイントを1つの技能に適用できる上限です。
- 平均技能レベルは、各経験レベルにおけるキャラクターの最も重要なクラス関連技能の一般的な範囲を示します。これは参照用であり、基本特徴値が16であり、各ステップで最大技能ポイントを費やしたと仮定しています。実際の結果は異なります。
- 成長：これは、記載されたランクに到達するために必要なクラス技能の数です。例えば、ランク3に到達するには、関連するクラスの記述に記載されているクラス技能のうち4つが少なくとも90%である必要があります。
