# Classic Fantasy Imperative システムリファレンスドキュメント

バージョン1.0、2023年9月

_Classic Fantasy Imperative_ は、_Mythras_ ルールセットのオープンなORCライセンス版であり、ダンジョン探索、ハイ・アドベンチャー、そして宝物、魔法、恐るべき敵との緊迫した遭遇に焦点を当てています。_Classic Fantasy Imperative_ は、この趣味における最初のロールプレイングゲームの興奮を再現していますが、d20を使用するのではなく、d100（パーセンタイル）ベースの _Mythras_ ゲームシステムのレンズを通してアプローチしています。

本書は包括的ではありますが、網羅的なルールセットではありません。キャラクター作成、キャラクターの種族とクラス、技能、特定の典型的な状況のルール、戦闘、魔法などが含まれており、プレイヤーとゲームマスターの両方が開始し、さらなる発展のための強固な基盤を形成するのに十分以上の内容となっています。_Classic Fantasy_ は、_Classic Fantasy Imperative_、_Mythras_ コア・ルール、および _Mythras Imperative_ と完全に互換性があります。さらに、他のORCライセンスのパーセンタイル・ゲーム・システムとも互換性があります。

## ORCライセンス

_Classic Fantasy Imperative_ はORCライセンスを使用して公開されています。ORCライセンスは、ゲームクリエイターがゲームのメカニクスをオープンに共有し、下流のユーザーがこれらのゲームメカニクスの改変版を自由に利用、修正、再共有できるようにする方法を提供します。

ORCの下でオープンに共有されるものは **ライセンス素材（Licensed Material）** と呼ばれ、スタットブロック、ゲームルール、キャラクター特性値、ゲームをプレイする際に固有のメソッドやシステム、およびライセンサーが明示的に共有したいその他のものなど、ゲームの広範な機能的要素が含まれます。このライセンスは広範であり、印刷された書籍、ビデオゲーム、ポッドキャスト、AI、または将来存在する、あるいは作成される可能性のあるその他の技術に関連して、世界中でライセンス素材を使用することを許可します。_Classic Fantasy Imperative_ に含まれるコンテンツの大部分は、ライセンス素材を構成しています。

ORCの下で共有されないものは **留保素材（Reserved Material）** と呼ばれ、商標、ワールドの伝承、ストーリーアーク、特徴的なキャラクター、および視覚芸術が含まれます。以下のORC通知に、留保素材を記載しています。

ORCライセンスの下では、公開作品の中で適切な帰属表示を行う限り、ライセンス素材を自由に使用、共有、改変、発展させることができます。この通知は、上流のライセンサーとその作品への貢献をクレジットするだけでなく、下流のユーザーが通知が表示される作品の著者を簡単にクレジットする方法も提供します。ORCの下でライセンスされた素材を使用することにより、あなたは自動的に、自身の公開作品におけるゲームメカニクスを同じ条件でライセンスすることに同意したことになります。独自の留保素材を開発した場合、それはあなたの排他的な所有物となります。

## d100は初めてですか？

_Classic Fantasy Imperative_ はd100、またはパーセンタイル・システムです。パーセンタイルダイス、あるいは1d100は、技能の使用、戦闘、魔法の発動など、重要なアクションを解決するために使用されます。これはロールアンダー・システムであり、目標値がパーセンテージで表現され（例えば、運動 65%）、ゲームマスターとプレイヤー双方が、成功を収めるために1d100を使用して、この目標値以下の値を出すことを目指します。好みに応じて1d100をd20に置き換えることは非常に簡単で、すべてのパーセンテージを5で割る（端数は切り上げ）ことで、d20ロールの目標値を得ることができます。私たちの例であれば、運動 65% は運動 13 になります。しかし、1d100はゲーム全体を支える非常に高い柔軟性とニュアンスを提供するため、まずは1d100のアプローチを試すことをお勧めします。何かを下回るようにロールしなければならないのは直感に反するように思えるかもしれませんが（多くのゲームでは高い方が通常良いため！）、成功する必要がある範囲として目標値をパーセンテージで表現することで、成功の確率を簡単かつ単純に見ることができ、対抗ロール、クリティカル、ファンブル、その他このルールの後の方で探求されるいくつかの「ダイス・トリック」が可能になります。パーセンタイル・ロールプレイングは長い間存在しており、柔軟で直感的で、プレイ中に背景に溶け込んでしまうような、実績のある中核メカニズムを持つしっかりと確立されたゲームシステムです。

## 単純化

_Mythras_ と _Classic Fantasy_ を長年所有しているプレイヤーは、_Classic Fantasy Imperative_ のルールがいくつかの箇所で単純化されていることに気づくでしょう。これは、ゲームマスターが新しいプレイヤーに最小限の手間でより迅速にゲームを紹介できるようにするためです。_Classic Fantasy Imperative_ が異なるもう1つの点は、メートル法の代わりにヤード・ポンド法（インペリアル単位）を組み込んでいることです。両方を組み込むと場所を取りすぎ、遠隔武器などを扱う際に複数の表が必要になってしまいます。インペリアル・システムは、すでに存在する数多くのバトルマットをより簡単に使用できるようにするため、また、インペリアル単位を使用する他のゲームシステムの冒険をより簡単に変換できるようにするために選択されました。キャラクターシートに記入する際は、付録の換算表を使用して、最も便利で馴染みのある測定システムを自由に使用してください。

## 数値と結果の端数処理

場合によっては、数値を割る必要があることがあります。通常は技能の評価値に対して行われます（クリティカル成功を決定するためなど、技能値の1/10）。除算の結果が分数になった場合は、常に整数に切り上げてください。したがって、例えば 64% の 1/10 は 6.4 ですが、これは 7 に切り上げられます。

## ゲームで使用するダイス

_Classic Fantasy Imperative_ は、標準的な多面体ダイスセットを使用します：d4、d6、d8、d10、d12、d20、d100。さらに、以下のダイスが必要となります：

- **d2:** どのダイスでも振ってください。奇数は1、偶数は2とします。またはコインを投げて判断します。

- **d3:** 6面ダイスを振ります。1-2 = 1、3-4 = 2、5-6 = 3とします。
