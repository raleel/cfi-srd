# Classic Fantasy Imperative システムリソースドキュメント

バージョン 1.0、2023年9月

_Classic Fantasy Imperative_ は、ダンジョン探索、壮大な冒険、そして宝物、魔法、恐るべき敵との緊張感あふれる遭遇に焦点を当てた、オープンかつORCライセンス準拠の _Mythras_ ルールセットのバージョンです。_Classic Fantasy Imperative_ は、趣味の分野で最初のロールプレイングゲームが持っていたスリルを再現していますが、d20を使用するのではなく、1d100（パーセンタイル）をベースにした _Mythras_ ゲームシステムのレンズを通してアプローチしています。

本書は、キャラクター作成、キャラクターの種族とクラス、技能、特定の典型的な状況のルール、戦闘、魔法など、網羅的ではありませんが包括的なルールセットを提供します。これはプレイヤーとゲームマスターの両方が開始するために十分すぎる内容であり、さらなる発展のための強固な基盤を形成します。_Classic Fantasy Imperative_ は、_Classic Fantasy Imperative_、_Mythras_ コアルール、および _Mythras Imperative_ と完全に互換性があります。さらに、他のORCライセンスパーセンタイルゲームシステムとも互換性があります。

## ORCライセンス

_Classic Fantasy Imperative_ はORCライセンスを使用して発行されています。ORCライセンスは、ゲームクリエイターがゲームのメカニクスをオープンに共有し、下流のユーザーがこれらのゲームメカニクスの改変や再共有を自由に行えるようにするための方法を提供します。

ORCの下でオープンに共有されるものは **ライセンス対象資料 (Licensed Material)** として知られており、スタットブロック、ゲームルール、キャラクターの特性値、ゲームをプレイするために固有のメソッドやシステム、その他ライセンサーが明示的に共有したいと考えているものなど、ゲームの広範な機能要素が含まれます。このライセンスは広範であり、印刷書籍、ビデオゲーム、ポッドキャスト、AI、または現在および将来存在する可能性のあるあらゆる技術に関連して、世界中でライセンス対象資料を使用することを許可します。_Classic Fantasy Imperative_ に含まれるコンテンツの大部分はライセンス対象資料を構成します。

ORCの下で共有されないものは **予約資料 (Reserved Material)** として知られており、商標、ワールドの伝承、ストーリーアーク、特徴的なキャラクター、および視覚芸術が含まれます。以下にORC通知の中で予約資料を記載しています。

ORCライセンスの下では、ライセンス対象資料を、公開した作品の中に通知という形で適切な帰属表示を行う限り、必要に応じて自由に使用、共有、適応、構築することができます。この通知は、上流のライセンサーとその作品への貢献をクレジットすると同時に、下流のユーザーが通知が現れる作品の著者をクレジットするための簡単な方法を提供します。ORCの下でライセンスされた資料を使用することにより、あなたは自身の公開作品におけるゲームメカニクスを同じ条件でライセンスすることに自動的に同意したことになります。独自の予約資料を開発した場合、それはあなたの独占的財産となります。

## d100は初めてですか？

_Classic Fantasy Imperative_ はd100またはパーセンタイルシステムです。パーセンタイルダイス（1d100）は、技能の使用、戦闘、魔法の詠唱など、主要な行動を解決するために使用されます。これは「ロールアンダー（目標値以下）システム」であり、目標値がパーセンテージで表され（例：運動 65%）、ゲームマスターとプレイヤーの両方が、1d100を使用してその目標値以下を出すことで「成功」を得ようとするものです。必要であれば1d100をd20に置き換えるのは非常に簡単で、すべてのパーセンテージを5で割る（端数切り上げ）ことで、d20ロールの目標値を得ることができます。例として挙げた「運動 65%」は「運動 13」になります。しかし、1d100はゲーム全体を支える大きな柔軟性とニュアンスを提供するため、まずは1d100のアプローチを試すことをお勧めします。（多くのゲームでは高い数値が良いとされるため）何かより「小さい」値を出す必要があることに直感に反すると感じるかもしれませんが、達成すべきパーセンテージの範囲を目標値として提示することで、成功の確率を簡単かつシンプルに確認することができ、対抗ロール、クリティカル、ファンブルなど、本書の後半で探求するいくつかの「ダイスのトリック」を可能にします。パーセンタイルロールプレイングは長い歴史を持ち、柔軟かつ直感的で、プレイ中に背景に溶け込むような、試行錯誤された強固な中核メカニズムを持つ確立されたゲームシステムです。

## 簡略化

_Mythras_ や _Classic Fantasy_ の長期愛好家は、いくつかの場所で _Classic Fantasy Imperative_ のルールが簡略化されていることに気づくでしょう。これは、ゲームマスターが最小限の煩雑さで新しいプレイヤーにゲームを紹介できるようにするためです。_Classic Fantasy Imperative_ が異なるもう一つの点は、メートル法の代わりに帝国単位（ヤード・ポンド法）を採用していることです。両方を含めるとあまりにも多くのスペースを占有し、遠距離武器などを扱う際に複数の表が必要になってしまうためです。帝国単位を選択したのは、すでに存在する無数のバトルマットを使いやすくし、帝国単位を使用する他のゲームシステムからの冒険の変換を容易にするためです。キャラクターシートに記入する際は、付録の換算表を使用し、最も便利で馴染みのある測定システムを自由に使用してください。

## 数値と結果の端数処理

状況により、数値を割る必要がある場合があります。典型的なのは技能の評価値（クリティカル成功の判定など、技能値の1/10など）です。除算の結果、端数が生じた場合は、常にその上の整数に切り上げてください。例えば、64%の1/10は6.4ですが、これは7に切り上げられます。

## ゲームで使用するダイス

_Classic Fantasy Imperative_ では、標準的な多面体ダイスセット（d4、d6、d8、d10、d12、d20、d100）を使用します。さらに、以下のダイスも必要です。

- **d2:** どのダイスでも振ってください。奇数は1、偶数は2とします。またはコインを投げて決めてください。

- **d3:** 6面ダイスを振り、1〜2＝1、3〜4＝2、5〜6＝3とします。
