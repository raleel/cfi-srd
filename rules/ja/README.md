# Classic Fantasy Imperative システム・リソース・ドキュメント

バージョン 1.0、2023年9月

_Classic Fantasy Imperative_ は、『Mythras』ルールセットのオープンかつORCライセンス準拠のバージョンであり、ダンジョン探索、壮大な冒険、そして宝物、魔法、恐るべき敵との緊迫した遭遇に焦点を当てています。_Classic Fantasy Imperative_ は、この趣味の原点である最初のロールプレイングゲームが持つスリルを再現していますが、d20を使用するのではなく、1d100（パーセンタイル）ベースの『Mythras』ゲームシステムのレンズを通してアプローチしています。

本書は、キャラクター作成、キャラクターの種族とクラス、技能、特定の典型的な状況のルール、戦闘、魔法など、網羅的ではありませんが包括的なルールセットを提供しています。これはプレイヤーとゲームマスターの双方がゲームを始め、さらなる発展のための強固な基盤を築くのに十分すぎる内容です。_Classic Fantasy Imperative_ は、『Classic Fantasy Imperative』、『Mythras』コア・ルール、および『Mythras Imperative』と完全に互換性があります。さらに、他のORCライセンス準拠のパーセンタイル・ゲームシステムとも互換性があります。

## ORCライセンス

_Classic Fantasy Imperative_ はORCライセンスを使用して発行されています。ORCライセンスは、ゲームクリエイターがゲームのメカニクスをオープンに共有し、下流のユーザーがこれらのゲームメカニクスの適応版を自由に利用、改変、再共有できるようにする手段を提供します。

ORCの下でオープンに共有されるものは**ライセンス対象資料 (Licensed Material)** として知られ、スタットブロック、ゲームルール、キャラクター属性、ゲームプレイに固有の方法やシステム、その他ライセンサーが明示的に共有したいものなど、ゲームの広範な機能的要素が含まれます。このライセンスは非常に広範であり、印刷物、ビデオゲーム、ポッドキャスト、AI、または将来存在するかもしれない、あるいは作成されるかもしれないあらゆる技術に関連して、ライセンス対象資料を世界的に使用することを許可します。_Classic Fantasy Imperative_ に含まれるコンテンツの大部分は、ライセンス対象資料を構成しています。

ORCの下で共有されないものは**予約資料 (Reserved Material)** として知られ、商標、世界設定の伝承、ストーリーアーク、特徴的なキャラクター、視覚芸術が含まれます。予約資料については、以下のORC通知に記載しています。

ORCライセンスの下では、出版物に通知という形で適切な帰属表示を行う限り、ライセンス対象資料を自由に利用、共有、改変、構築することができます。この通知は、上流のライセンサーとその功績を称えるとともに、その通知が現れる作品の著者を下流のユーザーが簡単にクレジットできるようにするためのものです。ORCライセンスに基づいた資料を使用することで、あなたは出版物内のゲームメカニクスを同じ条件でライセンス供与することに自動的に同意したものとみなされます。独自の予約資料を開発した場合、それはあなたの独占的財産となります。

## d100は初めてですか？

_Classic Fantasy Imperative_ は、d100またはパーセンタイル・システムです。パーセンタイルダイス（1d100）は、技能の使用、戦闘、呪文の詠唱など、主要なアクションの結果を決定するために使用されます。これは「ロールアンダー」システムであり、目標数値がパーセンテージで表されます（例：運動 65%）。ゲームマスターとプレイヤーの両方は、成功を達成するために、1d100を振ってこの目標数値以下を出すことを目指します。好みに応じて1d100をd20に置き換えることも容易であり、すべてのパーセンテージを5で割る（端数は切り上げ）ことで、d20ロールの目標数値を得ることができます。前述の例であれば、運動65%は「運動13」となります。しかし、1d100はゲーム全体を支える大きな柔軟性とニュアンスを提供するため、最初は1d100のアプローチを試すことをお勧めします。何かより「小さい」数値を出す必要があるのは直感に反するように思えるかもしれませんが（多くのゲームでは高い方が良いことが多いため）、目標数値がパーセンテージ範囲として表現され、その「範囲内」に収まるように振るという仕組みは、成功率を簡単かつシンプルに把握することを可能にします。また、対抗ロール、クリティカル、ファンブル、その他本書で後述する様々な「ダイスのテクニック」を活用することもできます。パーセンタイルを用いたロールプレイングは長い歴史を持ち、柔軟で直感的であり、プレイ中には意識せずとも背景に溶け込むような、実績のあるコアメカニズムを備えた確立されたゲームシステムです。

## 簡略化

『Mythras』や『Classic Fantasy』の長年のプレイヤーは、_Classic Fantasy Imperative_ のルールの一部が簡略化されていることに気づくでしょう。これは、ゲームマスターが新しいプレイヤーに最小限の労力で素早くゲームを紹介できるようにするためです。_Classic Fantasy Imperative_ が異なるもう一つの点は、メートル法ではなくヤード・ポンド法（Imperial measurements）を採用していることです。両方を併記すると場所を取りすぎ、遠隔武器などを扱う際に複数の表が必要になってしまうためです。ヤード・ポンド法を採用したのは、すでに存在する無数のバトルマットをより簡単に使用できるようにし、ヤード・ポンド法を使用する他のゲームシステムの冒険のコンバートを単純化するためです。キャラクターシートに記入する際は、付録の換算表を自由に使用し、自分が最も使いやすく慣れ親しんだ計測システムを使用してください。

## 数値と結果の切り上げ

場合によっては、数値を割る必要があります（通常は技能の評価値。クリティカル成功を決定するための1/10など）。除算の結果に端数が出た場合は、常に切り上げて整数にします。例えば、64%の1/10は6.4ですが、これは切り上げられて7となります。

## ゲームで使用するダイス

_Classic Fantasy Imperative_ は、標準的な多面体ダイスセット（d4、d6、d8、d10、d12、d20、d100）を使用します。さらに、以下のダイスも使用します。

- **d2:** どのダイスでも振ってください。奇数が出れば1、偶数が出れば2とします。コイン投げでも構いません。

- **d3:** 6面体ダイスを振ります。1-2が出れば1、3-4が出れば2、5-6が出れば3とします。
