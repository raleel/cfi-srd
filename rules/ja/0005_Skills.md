# 第5章：技能

技能は「標準技能」と「専門技能」の2つのカテゴリーに分類されます。すべてのキャラクターは共通の標準技能セットを所有しています。一方、専門技能はキャラクターごとに異なり、経歴や、ある程度はその文化的な背景の中で培われた専門知識を反映しています。これらの区別はありますが、標準技能と専門技能はどちらも同じ方法で処理されます。

---
## 技能の仕組み

技能には、2つの特性値、あるいは1つの特性値を2倍した合計値に基づく「基本値」があります。技能値に上限はなく、100を超えることも可能です。ゲーム中、キャラクターの技能がそれほどまでに高まることは十分に考えられます。

キャラクターが何らかの判定、挑戦、あるいは専門的な能力を解決しようとする際、1d100をロールし、その結果を技能値と比較します。

- 技能値以下であれば「成功」となります。
- 技能値を上回れば「失敗」となります。

成功と失敗に関して注意すべき特別なケースがいくつかあります。

- 01〜05のロールは、常に「成功」となります。
- 96〜00のロールは、技能値がどれほど高くても常に「失敗」となります。

#### クリティカルとファンブル

クリティカル（決定的成功）とファンブル（致命的失敗）は、極めて優れた成功や失敗を表します。これはキャラクターが試みに卓越した成果を上げた、あるいは惨めなほどに失敗したケースを指します。

- **クリティカル（決定的成功）**は、技能値の10分の1（端数切り上げ）以下のロールです。これには修正値が含まれるため、修正によってクリティカルの範囲は変化します。例えば、ある技能が通常の2倍（40%から80%へ）に修正された場合、クリティカルの範囲は08以下となります。
- **ファンブル（致命的失敗）**は、99または00のロールです。技能値が100%を超える場合、ファンブルは00のロールのみとなります。

クリティカルやファンブルの結果、具体的に何が起こるかはゲームマスターの判断に委ねられます。状況に応じて、素晴らしい結果にも、悲惨な結果にもなり得ます。

#### 自動成功

ある状況下では、特定の技能判定を行う必要がない場合があります。これは、その作業が容易に達成できる場合や、十分な時間と集中力があれば成功が保証されている場合です。穏やかな牧草地で馬に乗ってゆっくりと歩くことは「自動成功」の一例であり、その活動に熟練していれば、単純な動作に技能判定は必要ありません。職人が木材から椅子の脚を削り出すのも、技能判定が不要な一例です。時間はかかりますが、職人はその作業方法を熟知しており、急いでいなければ成功は確実です。また、盗賊が邪魔されず、鍵開け道具を持っていれば、時間をかけて宝箱の簡単な鍵を開けることができます。

#### 技能への修正

技能判定が必要な場合でも、現在の状況を反映するために成功確率を調整しなければならないことがあります。例えば、盗賊から逃げる際には「運動（Athletics）」の判定が必要になるかもしれません。しかし、キャラクターが暗闇の中や、歩きにくい下草の中を逃げている場合はどうでしょうか？ そのような場合、ゲームマスターは状況を反映するために、キャラクターの技能に修正を加えるよう指示することができます。

『Classic Fantasy Imperative』では、技能の修正を決定するために一連の難易度等級を使用します。以下を参照してください。なお、修正には2種類の方法が提供されています。1つ目は標準的な方法で、計算を少し必要としますが、特に高い技能パーセンテージにおいてスケール調整のシミュレーションが優れています。もう1つの「簡易技能修正」は、単純な加算または減算を行うもので、導入が容易です。どちらの方法を採用するかはゲームに合う方を選んでください。ただし、同じ修正システムを一貫して適用するようにしてください。

##### 難易度等級表

| 難易度等級 | 技能修正 | 簡易技能修正 |
| :-- | :-- | :-- |
| 自動成功 | 判定不要 | 判定不要 |
| 非常に容易 | 技能値を2倍 | +40% |
| 容易 | 技能値の1.5倍 | +20% |
| 標準 | 調整なし | なし |
| 困難 | 技能値を1/3減少 | -20% |
| 極めて困難 | 技能値を半分に減少 | -40% |
| ヘラクレス級 | 技能値を1/5に減少 | -80% |
| 絶望的 | 試行不可能 | 試行不可能 |

他の状況によるペナルティを受けているキャラクターの場合、最も厳しい難易度等級が優先されます。

戦闘以外では、『Classic Fantasy Imperative』は技能修正を伴う状況や課題の決定的なリストを提供していません。特定の技能や文脈に対してどのような修正が必要かは、最終的にはキャラクターの能力、状況の難易度に対する認識、そしてその瞬間の劇的な緊張感を考慮して、ゲームマスターが決定します。

## 標準技能

#### 運動 (STR+DEX)

運動技能は、登る、跳ぶ、投げる、走るなど、幅広い身体活動をカバーします。これらの活動に対する技能判定はすべて、「運動」技能に対する単一のロールで処理されます。登る、跳ぶ、走ることに関する詳細は[移動](0008_Combat.md?id=movement)のセクションを参照してください。

#### ボート (STR+CON)

ボート技能は、川、湖、海岸近くでの小型船の操縦をカバーします。適切な船舶は、一般的に短い距離を移動し、外海の荒波には適さないボート、カヌー、いかだなどです。ほとんどはオール、パドル、竿、あるいは単純な帆を使って推進します。また、動物に曳かせることも可能です。大規模な乗組員を必要とする船や、長距離の外洋航海用に設計された船は、専門技能の[航海術](0005_Skills.md?id=seamanship-intcon)の対象となります。

#### 腕力 (STR+SIZ)

腕力は、純粋な物理的力を発揮する際の効率的なテクニックです。この技能は、持ち上げる、ドアを突き破る、力比べなど、物理的な強さを必要とする行為をカバーします。

#### 隠匿 (DEX+POW)

隠匿技能は、キャラクター自身を隠す[隠密](0005_Skills.md?id=stealth-dexint)の対極にあり、大きな物体を隠すための技能です。例えば、戦車を岩陰に隠したり、戦車の車輪の跡を消して追跡されないようにしたりするために使用できます。この技能は応用範囲が広く、図書館にある巻物を隠すことから、罠や隠し通路の存在をカモフラージュすることまで多岐にわたります。

#### 慣習 (INT x2+40)

慣習は、キャラクター自身のコミュニティにおける社会規範、儀式、タブーなどの知識を表します。この技能は、社会的に重要な慣習を正確に解釈・遂行したり、特定の状況下での振る舞いを求められたりする際に使用されます。

#### ダンス (DEX+CHA)

ほとんどの文化において、娯楽として、あるいは重要な儀式の一部としてダンスが何らかの形で利用されています。宮廷舞踊、戦いの踊り、あるいは祈りや儀式的な詠唱を伴う単純な一連の動きなど様々です。「ダンス」技能は、求められたときにリズムに合わせて正確に（ある程度の精度で）体を動かす能力を測定します。

#### 欺瞞 (INT+CHA)

欺瞞は、キャラクターが真実を隠蔽し、嘘をついたり、衛兵を欺いたり、カードゲームでブラフ（またはイカサマ）をしたりするあらゆる状況をカバーします。この技能は、本当の感情や動機を隠す必要がある場合（ひどく失望しているのに喜びを装う、あるいは敵対的な状況で友好的な態度を見せようとするなど）にも使用されます。「欺瞞」は「洞察」技能の対抗技能であり、他者が真実や動機を見抜こうとする際の判定に対する対抗ロールとして使用できます。

#### 運転 (DEX+POW)

運転は、荷車、馬車、戦車、そりなど、獣やその他の手段によって牽引される車両の制御をカバーします。運転判定は、キャラクターが車両を使って通常とは異なること（険しい地形を横断する、障害物を飛び越えるなど）を行いたい場合に必要です。また、運転する車両が普段使い慣れていない獣（例：牛の代わりに馬）に牽引されている場合や、獣の頭数が増減している場合にも判定が必要となります。

#### 耐久 (CON x2)

耐久は、物理的なストレス、痛み、疲労に耐える能力です。損傷や衰弱を引き起こす可能性のある状況に対処する身体能力を測定するもので、回復力、スタミナ、代謝の一般的な指標です。「意思力」と同様に様々な用途がありますが、特に毒や病気などの怪我による影響に抵抗するために使用されます。

#### 回避 (DEX x2)

回避は、目に見える差し迫った危険から逃れるために使用されます。遠隔攻撃（カバーに飛び込むなど）、罠の回避、戦闘での交戦距離の変更、そして潜在的な物理的脅威から逃れるために使われます。また、特定の種類の魔法に対する抵抗ロールとして使用することも可能です。「巧妙な逃げ手（Artful Dodger）」能力を持つ者は、回避を使って転倒せずに近接攻撃をかわすことができます。遠隔攻撃に対しては、判定に失敗した場合にのみ転倒状態となります。

#### 応急処置 (DEX+INT)

応急処置技能は、軽傷を治療し、より深刻な怪我を安定させる能力を測定します。応急処置は特定の怪我につき1回のみ適用可能で、1d3ポイントのダメージを回復します。

#### 影響力 (CHA x2)

これは、キャラクターが個人のカリスマ性を通じて他者を説得し、望む行動を取らせる能力を測定するものです。人の考えを変えることから、役人や衛兵への賄賂まで、幅広い状況で使用されます。「影響力」判定は、状況に応じて「知覚」、「意思力」、または相手の「影響力」技能によって対抗されるのが一般的であり、キャラクターがどれほど行動を促そうとしているかによって修正されます。親しい友人に馬を貸すよう説得するのは比較的容易かもしれませんが、滅多に収賄しない役人に賄賂を受け取らせるのは非常に困難です。

#### 洞察 (INT+POW)

洞察は、他者の言語的および非言語的な行動（ボディランゲージや話し方など）を読み取り、直感的に動機や精神状態を特定する能力です。誰かが嘘をついているかどうかを見抜く（相手の「欺瞞」技能と対抗する）ためや、特定の状況に対して誰かがどう感じているかを予測するために使用されます。洞察は人だけでなく状況に対しても適用できます。この酒場はトラブルの温床か？ 盗賊たちが近くの丘で待ち伏せを計画しているのではないか？ といった推測に役立ちます。

#### 地域知識 (INT x2)

地域知識は、キャラクターが人生の大部分を過ごしてきた場所、通常はコミュニティ内における地元の植物、動物、地形、天候に関する理解度を測定します。キャラクターは一般的な植物、木々、動物の特性や習性、どこで最高の魚が見つかるか、獲物の動き、避難場所の探し方、季節の天候、そして一般的な地域的な危険を把握しています。隣接する、しかし不慣れな場所では、地域知識の判定難易度は1段階以上上昇すべきです。

#### 母国語 (INT+CHA+40)

母国語は、幼少期に自らの文化で習得した言語を話し、読む能力です。人間の場合、これは共通語ですが、亜人種や他の種族にはそれぞれの母国語があります。母国語は、表現力、雄弁さ、語彙の深さを測定します。

他の技能とは異なり、母国語は直接ロールされることはありません。代わりに、全体的な流暢さを示す静的な指標として扱われ、会話による相互作用のレベルを制限します。これについては[言語](0005_Skills.md?id=language-intcha)技能で詳しく説明されていますが、初期キャラクターは通常、母国語を完全に流暢に話す状態でゲームを開始します。

この技能は2つの方法で使用できます。1つ目は、言語的起源を共有する近隣の人々のの方言を理解する助けとなります。その場合、判定は少なくとも1段階難しくなり、キャラクターの流暢さに影響を与える可能性があります。2つ目は、言語を深く理解する必要がある口頭技能のキャップ（上限）として機能します。

#### 知覚 (INT+POW)

知覚は、受動的な観察と焦点を絞った検知の両方に使用されます。特定のものを探す場合、エリア全体を見渡す場合、単に周囲を警戒する場合などが含まれます。暗闇などの特定の条件は、使用される主要な感覚に応じて技能判定の難易度等級に影響を与える場合があります。強い臭いがあれば嗅覚による「知覚」判定は「標準」ではなく「容易」になるかもしれませんが、騒がしい酒場での会話を盗み聞きしようとすれば、判定は「困難」になるでしょう。

#### 乗馬 (DEX+POW)

乗馬は、乗用に訓練された生物を制御し、騎乗し続ける能力をカバーします。ラバから象まで、あるいはジャイアントイーグルやイルカのような空を飛んだり泳いだりする生物に至るまで、多種多様な生物に適用可能です。慣れない種に乗る場合は常に難易度が1段階上がります。また、異なる環境の種に乗る場合（例：騎馬民族がドラゴンに乗る）は難易度が2段階上がります。野生の獣は、砕かれ、乗馬用の獣として訓練されるまでは建設的な方法で乗ることはできません。

#### 歌唱 (POW+CHA)

単調な詠唱から複雑なアリアまで、歌うことはすべて「歌唱」技能の対象です。歌唱はほとんどの文化において不可欠な要素であり、娯楽の主要な源であり、儀式でも使用されます。重要な歌は、求愛、戦前の兵士の鼓舞、あるいは歴史的な功績を語り継ぐために使われます。この技能は、リズムを維持し、音程を守り、正しい歌詞を記憶する能力を反映しています。

#### 隠密 (DEX+INT)

人目につかないように隠れたり、最小限の音で移動したりすることは「隠密」技能でカバーされます。カバー（隠れ場所）の状態や、暗闇や大きな環境音といった条件は、その環境の特性に応じて技能の難易度を改善します。同様に、隠れる場所の欠如や静かな夜といった悪条件は、技能の難易度を低下させます。状況も試行の難しさに影響します。例えば、重い鎧を着た戦士は、壁の後ろでじっとしているか、非常にゆっくりと動くのであれば容易に隠れることができますが、速く動こうとすれば鎧が鳴ってしまうかもしれません。

#### 水泳 (STR+CON)

特別な訓練を受けていない場合、泳ぐ能力はバタバタとあがいて短時間だけ頭を水面に出しておく程度に限られます。高い水泳パーセンテージは、溺れるリスクを減らし、より深く激しい水域を泳ぎ切る能力を示します。したがって、水泳判定は完全に状況に依存します。荒海、激流、ホワイトウォーター、離岸流などは、キャラクターの水泳への親和性に関わらず、技能の難易度を低下させます。水泳速度の計算を含む詳細は、[移動](0008_Combat.md?id=movement)のセクションを参照してください。

#### 素手 (STR+DEX)

素手はすべてのキャラクターに共通する戦闘技能であり、武器の補助なしで自分を守る能力を測定します。素手技能は、その文化で知られている格闘術やレスリングのテクニックをカバーします。

素手は戦闘技能であるため、そのクリティカルとファンブルの効果は[戦闘](0008_Combat.md)の章で詳述される戦闘ルールによって処理されます。

#### 意思力 (POW x2)

意思力は、集中し、意志の力を特定の方向に導き、あるいは精神的なショックに対して心を硬くする能力の指標です。個人の決意の強さでもあります。この技能は、精神的な回復力が必要なあらゆる状況で使用され、魔法への抵抗も含まれます。正気度の指標ではありませんが、最も健全で安定した精神すら揺るがすようなトラウマとなる出来事に耐えるために使用できます。「意思力」は「耐久」技能の精神的な対極です。

「耐久」や「回避」と同様に、「意思力」は対抗判定で最も頻繁に使用されます。標準判定として使用される場合、クリティカルに成功すれば、キャラクターは心と精神を硬くし、その後自分に影響を与えたり、決意を揺るがしたりする試みが一切効かなくなることを示します。魔法への抵抗の場合、クリティカル成功は、その遭遇中、対戦相手が唱える精神に影響を及ぼす呪文がキャラクターに一切効果を及ぼさないことを意味します。

## 専門技能

専門技能はキャラクターごとに異なり、より専門的な訓練と経験を表します。一部の専門技能は、名前が示す通り、文化的背景やキャラクターのクラスを通じて習得されます。キャラクターごとに異なりますが、機能は標準技能と同じです。

特定の魔法技能も専門技能に分類されます。例えば、神聖魔法に関連する「チャネリング」と「献身」の2つの技能がこれに当たります。これらについては[魔法](0009_Magic.md)の章の関連セクションを参照してください。

#### 演技 (CHA x2)

演技は、舞台演劇や社交の場を問わず、全く別人を模倣して演じる技術を司ります。俳優は、自分とは異なる個性や仕草を説得力を持って描写します。「変装」および「欺瞞」技能と組み合わせることで、全く別の人物になりきるための強力な手段となります。

#### アクロバット (STR+DEX)

アクロバットは、バランス、体操、ジャグリング、宙返りなどの行為をカバーします。聴衆を感動させるだけでなく、転倒時のダメージを軽減するためにも使用されます。成功すれば、不安定な足場や狭い場所でも全速力で確実に移動できます。予期せぬ転倒のダメージを軽減しようとする場合、アクロバットに成功すれば被ダメージが半分になります。さらに、判定に成功し、その転倒によって深刻な怪我（Serious）や重傷（Major Wound）を負わなかった場合、キャラクターは比較的安全に着地し、転倒状態にはなりません。

状況が許せば、アクロバットを回避の代わりに使用することも可能です。その利点は、転倒状態になるのではなく、キャラクターが自動的に体勢を立て直せることにあります。

アクロバットは、盗賊のランク1の[跳躍（Vaulting）](0003_Classes.md?id=rank-1-3)能力の基礎としても機能します。

#### 動物使い (POW+CHA)

この技能は、敵対的な動物を落ち着かせたり、犬に「座れ」「待て」などの芸を仕込んだり、馬を騎乗用に調教したりするなど、複数の機能を果たします。野生の動物を落ち着かせるために使用した場合、成功すれば追い払うことができます。ただし、空腹であったり、近くに子供がいたりする場合は、判定難易度が2段階上昇します。空腹の動物に食べ物を与えれば難易度が1〜2段階改善する場合もあれば、もっと食べるためにキャラクターの後を追うようになる場合もあります。

#### 秘術詠唱 (INT+POW)

秘術詠唱は、秘術魔法に不可欠な魔法技能です。呪文の書や巻物からあらかじめ記憶した呪文を成功裏に唱える能力です。また、詠唱に必要な正しい精神状態を見出し、ジェスチャーや詠唱を行うことも表します。この技能の習熟度を高めると、それを使って唱える呪文の最終的な威力（Intensity）も向上します。

#### 秘術知識 (INT x2)

秘術詠唱と同様に、この魔法技能は秘術魔法に不可欠です。魔法使いが蓄積した実際の呪文知識を表し、新しい呪文を学んだり、呪文の書に書き写したり、巻物を作成したり、唱えられている呪文を特定したりする際に使用されます。また、魔法使いの[ランク構造](0003_Classes.md?id=rank-structure-2)セクションで詳細に説明されているように、習得している初期呪文の数も決定します。

秘術知識は秘術の使い手に限定されません。実際に秘術魔法を実践していなくても、単に難解な学問を研究したい者が習得することも可能です。

#### 芸術 (POW+CHA)

絵画から詩、文学から彫刻まで、多くの特定の芸術形式があります。キャラクターはこの技能を習得する際に芸術の専門分野を選択します（例：芸術〈絵画〉）。その後の芸術形式は個別に成長させます。キャラクターが芸術的な媒体を通じて人を感銘させたり説得したりする必要がある場合に判定が行われます。

#### 官僚 (INT x2)

官僚技能は、行政手続き、記録、暗黙のルールを理解するためのものです。役人とやり取りしたり、関連する市民情報を発見したりするために使用されます。文化の洗練度にもよりますが、官僚は必ずしも読み書きができる必要はありません。ただし、官僚技能は、その業務で使用する言語または読み書き技能のスコアを超えることはできません。お役所仕事や行政の状況を切り抜ける必要がある場合は常に官僚判定が必要です。

#### 導き (INT+CHA)

導き（Channel）は、神々の力を呼び出し、操るために使用される魔法技能です。この技能の習熟度を高めると、それを使って唱える呪文の最終的な威力（Intensity）も向上します。

#### 商売 (INT+CHA)

商売技能は、商品や産品の価値を評価し、可能な限り有利な価格で取引するために使用されます。また、利益を確保することに加え、ビジネス上の取引の複雑な仕組みを理解するためにも使用されます。さらに、盗品や違法な商品を、可能な限り高い価格で処分するための最善の方法を見つける際にも役立ちます。当然、取引の際に使用され、相手側の「商売」または「意思力」技能と対抗して、取引を有利に進めようとする試みを反映させることができます。また、商品の市場価値を判断し、価格の見当をつけ、どこで取引するのが最善かを判断するためにも使われます。

#### 礼儀 (INT+CHA)

この技能は、社会的あるいは公的な状況で適切に行動する方法（呼びかけ方、儀式、行動規範など）を理解することをカバーします。誰に対していつお辞儀をするか、どの程度深くお辞儀をするか、どの称号をいつ使うべきか、あるいはいつ非公式に振る舞うのが適切か、といった全てが含まれます。

#### 製作 (DEX+INT)

製作技能は、製作〈陶芸〉のように細分化されており、職業の数だけ製作の分野が存在します。芸術と同様に、対象となるアイテムを作成するために使用されます。どれくらいの時間がかかるかは製品の性質に完全に依存します。例えば、絨毯を織るほうが壺を作るよりも時間がかかりますが、時間は必ずしも最も重要な要素ではありません。職人の技術、素材の品質、細部へのこだわりが重要です。

#### 文化 (INT x2)

文化は、標準技能である「慣習」のより専門的な形態であり、キャラクター自身の社会ではなく、外国の社会に関連するものです。各「文化」技能は、それが適用される特定の国家や社会を指定する必要があります。メカニカルには「慣習」技能と同じように機能します。

#### 献身 (POW+CHA)

献身は、聖職者が神への奉仕にどれほどコミットしているかを反映する魔法技能です。神への信仰の深さを測定するだけでなく、キャラクターが呼び出す神聖魔法の「規模（Magnitude）」を左右します。さらに、この技能は宗教組織内での地位を示すこともあります。

献身は神聖魔法の使い手に限定されません。実際に神聖魔法を実践していなくても、単に神々に敬意を表したい者が習得することも可能です。

#### 変装 (INT+CHA)

適切な素材（衣装、化粧、かつら、付け毛など）を使用して説得力のある変装を行うことは、「変装」技能でカバーされます。変装には時間と細部への注意が必要であり、説得力を持たせるための適切な素材へのアクセスも必要です。これらの要素の一部または全部が欠けている場合、変装判定の難易度は1段階以上上昇します。

#### 工学 (INT x2)

住宅から橋、門、攻城兵器に至るまで、大規模な構造物の設計と構築は「工学」技能の範疇です。大規模なプロジェクトを計画する際に正しい施工を確実にするために判定が必要となりますが、構造の完全性を評価したい場合（修理状態や弱点の確認など）にも行われます。

#### ギャンブル (INT+POW)

ギャンブル技能は、運の要素が強く、特に金銭を賭けるゲームにおけるキャラクターの能力を測定します。成功または失敗の確率を評価したり、誰かがイカサマをしているかを見抜いたりするために使用されます。この技能は状況に応じて、対抗ロールとしても、単独ロールとしても使用されます。安っぽいギャンブルの場では単純なテストで十分かもしれませんが、著名な人物が関わる高額なダイスゲームでは、数ラウンドの対抗ロールが必要になるかもしれません。

#### 治療 (INT+POW)

治療は、文化的慣習に基づく医学的処置の深い知識です。例えば、原始的または野蛮な文化では、治療はハーブや自然の治癒力の知識に基づきます。文明社会では、薬物やより高度な治療が一般的になります。すべての文化において、治療には骨折の固定、傷口の縫合などの能力が含まれます。当然、治療を施すには適切なリソースが必要であり、熟練した治療師は針、縫合糸、ハーブ（湿布用）などを手元に備えています。

#### 脅迫 (INT+CHA)

この技能は、個人を威嚇し、本来なら進んで行わないような行動をとらせるために使用されます。情報の引き出しや、暴力的な脅迫によって対戦相手を退かせるためによく使われます。脅迫チェックは、使用する方法や、相手が感じる危険レベルに基づいて修正される場合があります。脅迫は通常、被害者の「意思力」によって対抗されますが、拷問を伴う場合は「耐久」が適用される可能性があります。

#### 言語 (INT+CHA)

この技能は、キャラクター自身の言語以外の言語を話し、理解することをカバーします。言語技能は直接ロールされることはありませんが、全体的な流暢さを示す静的な指標として扱われます。その値は、プレイヤーがゲーム内のキャラクターと会話する際の口頭相互作用のレベルを制限するために、ゲームマスターによって使用されます。ガイドラインとして[言語の流暢さテーブル](0005_Skills.md?id=linguistic-fluency-table)を使用してください。

##### 言語の流暢さテーブル

| 言語% | 会話の流暢さ |
| :-- | :-- |
| 01-25% | 単語をいくつか理解できる程度。文章を構成できない。読み書き不可 |
| 26-50% | 「寺院はどこですか？」「食べ物はいくらですか？」のような断片的な単純な文章での理解と会話が可能。初等教育レベルの読解力 |
| 51-75% | 通常の会話には十分流暢。中等教育レベルの読解力 |
| 76%+ | 雄弁に表現可能。高等教育レベルの読解力 |

各言語技能は、学習時に選択する必要がある特定の種族語、国家語、または地域語に対応します。また、言語的起源を共有する似た方言を理解する助けにもなります。差異に応じて、技能判定は少なくとも1段階難しく扱われ、キャラクターの流暢さが低下する可能性があります。

言語技能には「読み書き（リテラシー）」が含まれます。情報を記録する方法は無限にあるため、リテラシーは必ずしも文字を書くことを意味しません。木や骨に記号を刻む文化もあれば、タペストリーの結び目の複雑なパターンで歴史を記録する文化もあります。また、すべてのリテラシーが音素アルファベットに基づいているわけではなく、ヒエログリフや表意文字も一般的です。

#### 言語（盗賊の隠語） (INT+CHA)

_(盗賊のみ)_：この隠語を基本レベルで習得するには盗賊ギルドへの誓約が必要です。この「言語」技能はスラングや暗示的な意味で構成されており、盗賊同士が人前で違法な活動について話し合う際に、他の関係者に情報を漏らさないために使用されます。このコミュニケーションは、侵入や強盗に関する議論に限定されます。盗賊ギルドの長期会員である盗賊は、自動的にこの技能を「基本レベル+40%」で習得しています。ゲーム中に習得した者は「基本レベル」から開始します。

#### 鍵開け (DEX x2)

鍵開けは、鍵やその鍵専用の装置の助けなしに機械的なロックシステムを開ける能力です。ボルトや閂（かんぬき）のかかったドアや窓を、損傷を与えずにこじ開けるテクニックも含まれます。鍵開けは「逆に鍵をかける」こと、つまり鍵がない状態でドアや宝箱をロックするためにも使用できます。

#### 伝承 (INT x2)

伝承は、最初に技能を学習する際に選択しなければならない特定の知識分野をカバーします（例：伝承〈錬金術〉）。錬金術、占星術、天文学、地理学、紋章学、歴史学、助産術、鉱物学、モンスター、政治学、宗教、戦略戦術などはすべて伝承技能の典型的な例です。伝承技能を持つということは、キャラクターがその基礎を理解し、直面した課題や問題にどのように適用できるかを知っており、そのトピックに関する有用な情報を思い出せることを意味します。

#### メカニズム (DEX+INT)

メカニズムは、罠などの機械仕掛けを組み立てたり分解したりするための知識と技能を表します。工学が大規模な建設物を扱うのに対し、メカニズム技能は一般的に小さな稼働部品を持つ繊細な仕掛けの製作に関わります。これは「鍵開け」とは異なる学問であり、相互に交換することはできません。

#### 音楽 (DEX+CHA)

音楽技能は楽器の演奏をカバーします。単純な葦笛からハープのような複雑な弦楽器まで、音楽技能の各バージョンは類似した楽器グループに適用されます。〈フルート〉技能を持つ音楽家は葦笛を演奏できますが、フルート、パンパイプ、リコーダーも演奏できます。これらは基本が同じだからです。しかし、ハープやリュートを演奏することはできません。

#### 航海術 (INT+POW)

主要なランドマーク、星、海水の味の変化などを使用して、移動を正確に誘導する能力は「航海術」技能でカバーされます。各航海術技能は、外洋や地下など、特定の地域や環境をカバーします。通常の旅ではない場合や、完全に不慣れな領土内にいる場合に判定を行うべきです。

#### 雄弁術 (POW+CHA)

雄弁術は、多くの人々の前で演説を行い、考え方を伝えたり揺さぶったりする技術です。政治家が政策を推進するためによく使う技能ですが、指揮官が兵士を鼓舞し、戦場で規律を維持するためにも使用されます。大勢の説得が必要な場合は、「影響力」ではなく「雄弁術」が使用されます。

#### 航海士 (INT+CON)

この技能は[ボート](0005_Skills.md?id=boating-strcon)と同じ方法で使用されますが、帆やオールで動く大型船舶に適用されます。船の整備や維持もカバーします。修理が必要な時期の評価、安全な停泊場所の判断、荒天の危険性などが含まれます。

#### 誘惑 (INT+CHA)

誘惑は、他者に対するロマンチックな、あるいは性的な説得であり、「影響力」とは大きく異なる技能です。言葉や身振りなどの明示的なシグナルを使って、性的にポジティブな反応を引き出します。かなりの時間を要します。ターゲットの道徳観によっては、成功までに数時間、数日、あるいは数週間かかることもあります。ターゲットは常に「意思力」で誘惑に抵抗を試みることができます。

#### 軽業 (DEX+CHA)

軽業は、小さな物を手品のように隠したり、指先で器用に操ったりすることをカバーし、スリ、財布切り、視覚的な注意をそらす試みも含まれます。当然、盗賊にとって不可欠な技能です。

#### 街の知識 (POW+CHA)

街の知識は、集落内の場所や社会的なコネクションに関する知識を表します。危険な地域の特定から、合法・非合法を問わず地元のサービスの探し方まで、あらゆることをカバーします。「街の知識」の試みにどれくらいの時間がかかるかは、何を求めているかによります。良い宿を見つけるのは、盗品をさばく闇商人や偽の取引許可証を探すよりも時間がかかりません。

#### 生存術 (CON+POW)

この技能は、文明の恩恵が欠如している地方や野外環境で生き残ることをカバーします。食料の採集、火起こし、避難場所や安全な睡眠場所の確保などです。適切に装備されていれば、テントや食料を携帯しているため、通常は判定不要です。装備から離れた場合や、環境条件が悪化したときのみ、この技能の使用が不可欠になります。そのような状況では、通常1日1回判定が行われます。

#### 追跡 (INT+CON)

追跡技能は、あらゆる種類の獲物や対象を追跡するために使用されます。足跡、傷ついた葉、散乱した花粉、動かされた石など、目に見える兆候だけでなく曖昧な兆候も使用して、獲物の痕跡を追い続けます。これらは熟練していない者には見えない小さな手がかりです。追跡ロールは周期的に行う必要があり、特に条件が急激に変化した場合（突然の雨など）は必要です。頻度は獲物がどれだけ狡猾かによります。「隠匿」ロールは、「追跡」ロールに対する対抗判定として使用できます。

## さまざまな状況における技能ルール

『Classic Fantasy Imperative』の技能使用ルールは非常に直感的ですが、プレイ中に発生する多様な状況では、技能を少し異なる方法で処理する必要がある場合があります。以下のセクションでは、これらの状況と、その対処法を示します。

#### 技能の再試行

状況によっては、キャラクターが技能の試行に失敗しても、再試行できる余地が残されている場合があります。例えば、鍵開けや切り立った壁の登攀などが該当します。単にそれ以降の試みをすべて拒否するのではなく、寛大なゲームマスターは、後続の「背水の陣」的な試みを許可するかもしれません。ただし、キャラクターはいくらかの動揺や自信の欠如を経験し、技能判定の難易度等級が1段階上昇します。

この2回目の試行も失敗に終わった場合、キャラクターは「全力を尽くした」とみなされ、当面の間はこれ以上の試みを行うことはできません。

### 対抗ロール

技能は頻繁に他の技能に対して使用されます。例えば、盗賊が貴族の財布を盗もうとする際の「隠密」対「知覚」や、盗賊が捕まった際にそれを否定しようとする「欺瞞」対「洞察」などがそうです。これらは「対抗ロール」として知られ、挑戦の結果が勝ちか負けか、成功か失敗かになる場合に使用されます。

- 対抗ロールは次のように決定されます。両方の参加者がそれぞれの技能をロールします。より高い「成功レベル」を得た者が勝者となります。参加者が同じ成功レベル（両方とも標準成功、あるいは両方ともクリティカルなど）を得た場合は、技能の成功範囲内でより高い出目を出した者が勝者となります。

対抗ロールで両方の参加者が失敗した場合、以下のいずれかを行います。

- 状況を説明し、両者を劇的な緊張状態のままにして、勝者を決めるために判定をやり直す。
- ゲームマスターが、失敗の性質にふさわしい説明や状況を作り出す。

対抗ロールは、怪我の影響を克服したり、戦闘の特殊効果に対抗したりするために、特定の戦闘状況で頻繁に使用されます。また、毒や病気に抵抗したり、邪悪な魔法の影響を振り払ったりするためにも使用されます。

##### 対抗ロールの例テーブル

| 活動 | 対抗技能の例 |
| :-- | :-- |
| 交渉・値切り | 商売 vs 商売, 影響力 vs 商売 |
| 追跡・競争 | 運動 vs 運動, 運動 vs 耐久, 乗馬 vs 乗馬 |
| 欺瞞・嘘 | 欺瞞 vs 洞察, 軽業 vs 知覚 |
| 忠誠の表明 | 情熱 vs 情熱, 情熱 vs 洞察, 情熱 vs 影響力 |
| 回避・脱出 | 回避 vs 運動, 回避 vs メカニズム, 回避 vs 乗馬 |
| 隠密・隠れ | 隠密 vs 知覚, 隠密 vs 追跡 |
| 地位による威圧 | 影響力 vs 意思力, 欺瞞 vs 意思力 |
| 継続・我慢 | 耐久 vs 耐久, 耐久 vs 腕力 |
| 群衆の扇動 | 雄弁術 vs 意思力 |
| 力試し | 腕力 vs 腕力, 腕力 vs 耐久 |
| 意思の戦い | 意思力 vs 意思力, 誘惑 vs 意思力 |

### 差分ロール

差分ロールは対抗ロールと似ていますが、単純な勝ち負けの結果ではなく、成功レベルの差を計算します。主に戦闘の解決に使用されますが、ゲームマスターが競技の詳細な結果を詳細化したい場合、他の状況でも使用できます。

差分ロールは次のように決定されます。参加者双方がそれぞれの技能でロールし、単独でテストされたかのように結果を適用します。そこには純粋な「勝者」はいませんが、より高い成功レベルを獲得した者が、その成功レベルの差に応じた有利を得ます（少なくとも一方が標準成功以上の成果を出した場合）。両方の参加者が同じ成功レベル（両方とも標準成功、あるいは両方ともクリティカル）を得た場合、追加の効果はありません。

##### 差分ロール結果テーブル

| ロール結果 | 対抗者クリティカル | 対抗者成功 | 対抗者失敗 | 対抗者ファンブル |
| :-- | :-- | :-- | :-- | :-- |
| 主役クリティカル | 利益なし | 主役が成功レベル1の差で勝利 | 主役が成功レベル2の差で勝利 | 主役が成功レベル3の差で勝利 |
| 主役成功 | 対抗者が成功レベル1の差で勝利 | 利益なし | 主役が成功レベル1の差で勝利 | 主役が成功レベル2の差で勝利 |
| 主役失敗 | 対抗者が成功レベル2の差で勝利 | 対抗者が成功レベル1の差で勝利 | 利益なし | 利益なし |
| 主役ファンブル | 対抗者が成功レベル3の差で勝利 | 対抗者が成功レベル2の差で勝利 | 利益なし | 利益なし |

### 100%を超える対抗技能

対抗ロールや差分ロールにおいて、最も高い技能値を持つ参加者が100%を超える技能値を持っている場合、その参加者は100と自身の技能値との差を、対戦者全員（自身を含む）の技能から差し引きます。これにより相手の技能値が低下し、自身は優位を維持できます。

誰が最も高い技能を持っているかの特定は、状況に応じた他の修正を適用した後に計算する必要があります。
