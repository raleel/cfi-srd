# 第5章：技能

技能分為兩個類別：標準技能與專業技能。所有角色都擁有相同的標準技能組。專業技能則因各個角色而異，反映了職業生涯以及在某種程度上文化背景所培養出的專業知識。儘管有這些區別，標準技能與專業技能的作用方式是相同的。

---
## 技能運作方式

一項技能擁有一個基礎數值，該數值基於兩個特性值，或是將一個特性值乘以二得出。技能數值沒有上限；它可以超過100，在遊戲中，角色完全可以期待他們的技能達到如此高度。

每當角色需要解決某種形式的測試、挑戰或專業能力時，需擲出1d100並將結果與該技能數值進行比較：

- 等於或小於技能數值，表示判定成功。
- 大於技能數值，表示判定失敗。

關於成功與失敗，有一些特殊情況需要注意：

- 任何01-05的骰點總是成功。
- 任何96-00的骰點總是失敗，無論該技能數值有多高。

#### 大成功與大失敗

大成功和大失敗代表了極其出色的成功與極其慘烈的失敗；這些情況下，角色要麼在嘗試中表現卓越，要麼慘敗得一塌糊塗。

- **大成功** 等於技能數值的十分之一（這包括了受到修正值的技能，因此經過修正的技能可能會有更高或更低的機率出現大成功）。計算大成功的範圍時，小數點需無條件進位。例如，如果一項技能被修正為正常數值的兩倍（假設從40%提升到80%），那麼其大成功範圍將是擲出08或更小。
- **大失敗** 是指擲出99或00。技能數值超過100%的技能，僅在擲出00時才算大失敗。

大成功或大失敗的具體性質由遊戲主持（GM）決定。根據具體情況，後果可能是美妙的，也可能是可怕的。

#### 自動成功

在某些情況下，對特定技能進行判定是不必要的——要麼是因為眼前的任務很容易完成，要麼是因為只要有足夠的時間和專注，成功是必然的。在開闊的草地上以輕快的慢跑速度騎馬，是一個自動成功的例子，這意味著僅僅擁有該活動的技能，簡單的動作就不需要進行任何技能判定來解決。工匠將一塊木頭雕刻成椅子腿是另一個不需要技能判定的例子；這需要時間來完成，但工匠知道如何進行這項工作，只要不趕時間，成功是有保證的。一名盜賊在無人打擾的情況下，擁有一套開鎖工具，只要有足夠的時間，就能成功打開寶箱的簡單鎖具。

#### 技能修正

在某些情況下，雖然需要進行技能判定，但需要調整成功機率以反映現有狀況。例如，逃離土匪可能需要進行運動判定。但如果角色是在黑暗中或穿過險惡的灌木叢中逃跑呢？在這種情況下，遊戲主持可以堅持要求修正角色的技能以反映環境狀況。

《古典奇幻必須》（_Classic Fantasy Imperative_）使用一系列等級來決定技能如何被修正。這些等級如下。請注意，提供了兩種類型的修正：第一種是預設方法，涉及少量的數學運算，但在縮放方面提供了更好的模擬，特別是在涉及較高技能百分比的情況下。簡化技能修正則是一種簡單的加減法，更容易實施。選擇最適合該遊戲的方法，但確保應用同一套修正系統時保持一致。

##### 難易度表

| 難易度 | 技能修正 | 簡化技能修正 |
| :-- | :-- | :-- |
| 自動 | 無需判定 | 無需判定 |
| 非常簡單 | 技能數值加倍 | +40% |
| 簡單 | 技能數值增加一半 | +20% |
| 標準 | 無調整 | 無 |
| 困難 | 技能數值減少三分之一 | -20% |
| 至難 | 技能數值減半 | -40% |

在戰鬥之外，《古典奇幻必須》並沒有提供一份關於哪些情況和挑戰會招致技能修正的明確清單。對於任何特定技能或環境需要什麼樣的修正，最終由遊戲主持根據角色的能力、他對情況難度的認知以及當時戲劇性的緊張氛圍來決定。

## 標準技能

#### 運動 (筋力+敏捷性)

運動涵蓋了一系列身體活動，包括攀爬、跳躍、投擲和奔跑。這些活動的任何技能判定都由一次對運動技能的判定來處理。參見 [移動](0008_Combat.md?id=movement) 章節，了解更多關於攀爬、跳躍和奔跑的資訊。

#### 操船 (筋力+体力)

操船技能涵蓋了在河流、湖泊和近海區域操作小型浮動工藝。適用的船隻通常是船、獨木舟或木筏，這些船隻航行距離短，不適合公海的嚴苛環境。大多數是使用槳、槳葉、撐船篙或簡單的帆推進；甚至可以由動物牽引。擁有大量船員或為長途海外航行而設計的船隻屬於 [航海術](0005_Skills.md?id=seamanship-intcon) 專業技能的範疇。

#### 腕力 (筋力+体格)

腕力是施加純粹物理力量時運用技巧的效率。該技能涵蓋了應用力量的行為，包括舉起重物、撞開門以及力量競賽。

#### 隱蔽 (敏捷性+霊力)

隱蔽是 [隱密](0005_Skills.md?id=stealth-dexint) 的對應技能，它是隱藏大型物體而不是角色自身。例如，隱蔽可用於將戰車隱藏在岩石後面，或清掃戰車的車輪痕跡以使其路徑無法被追蹤。該技能應用廣泛，從在圖書館裡藏匿卷軸到掩飾陷阱或密道的存在都可以。

#### 習慣 (知力 x2+40)

習慣代表角色對其自身社群的了解，包括其社會準則、儀式、慣例、禁忌等。當必須準確地解讀或執行任何具有社會重要性的習慣，或以特定方式行事時，會使用該技能。

#### 舞踊 (敏捷性+魅力)

幾乎每一種文化都會以某種方式使用舞踊——無論是作為娛樂還是作為重要儀式的一部分。它可能是宮廷舞、戰舞，或是伴隨祈禱或儀式吟唱的一套簡單動作。舞踊技能衡量角色在需要時（在合理範圍內）有節奏且準確地移動的能力。

#### 欺瞞 (知力+魅力)

欺瞞涵蓋了角色試圖掩蓋真相並提供某種欺騙的所有情況；如睜眼說瞎話、誤導守衛，甚或在紙牌遊戲中虛張聲勢（或作弊）。該技能也涵蓋了在需要隱藏真實情感或動機時的情況（或許在極度失望時假裝高興，或者在試圖表現得熱情開放而事實並非如此時）。欺瞞構成了 [洞察](0005_Skills.md?id=insight-intpow) 技能的對應技能，當他人試圖辨別真相或動機時，可以用來對抗洞察判定。

#### 運転 (敏捷性+霊力)

運転涵蓋了對輪式或牽引車輛的控制，無論是由一隻或多隻負重獸驅動，還是由更深奧的方式驅動：例如手推車、馬車、戰車或雪橇。當角色想要用車輛做一些不尋常的事情時，需要進行運転判定——例如穿越險惡地形、跳過障礙物等。如果所駕駛的車輛是由駕駛員不習慣的野獸（例如馬而不是牛）牽引，或者團隊中有更多或更少的野獸來拉車，也需要進行判定。

#### 持久力 (体力 x2)

持久力是角色承受身體壓力、疼痛和疲勞的能力。它衡量身體處理潛在損害或衰弱狀況的能力，是韌性、體力和新陳代謝的總體指標。持久力，就像其對應的 [意志力](0005_Skills.md?id=willpower-pow-x2) 一樣，可以用於多種方式，但最特別的是用於抵抗傷害的潛在影響，包括有害的毒藥和疾病。

#### 回避 (敏捷性 x2)

回避用於從觀察到的、即將到來的危險中逃脫，可用於對抗遠程武器（例如俯衝尋找掩護）、避開陷阱、在戰鬥中改變交戰距離，以及普遍避開潛在的物理危害。它也可以用作某些類型魔法的抵抗判定。擁有「靈巧閃避」能力的角色可以使用回避來躲避近戰攻擊而不倒地。如果對抗遠程攻擊，只有在判定失敗時才會倒地。

#### 応急手当 (敏捷性+知力)

応急手当技能衡量角色治療輕微傷害和穩定較嚴重傷害的能力。応急手当對特定傷害只能使用一次，並能治療1d3點傷害。

#### 説得 (魅力 x2)

這是衡量角色通過個人魅力說服他人以達到預期行為的能力。它用於各種情況；從改變某人的想法，到賄賂官員或守衛。説得判定通常由知覺、意志力或其他説得技能進行對抗（取決於情況），並根據角色試圖影響行為的程度進行修正。試圖說服好朋友借給你馬可能相對容易。讓一個通常不可賄賂的官僚接受賄賂則更困難。

#### 洞察 (知力+霊力)

洞察是閱讀或直觀定義他人言語和非言語行為（如肢體語言或說話方式）以確定其動機和心態的能力。洞察用於確定某人是否在撒謊（可以由對方的欺瞞技能對抗），或預測某人對特定情況的感受。洞察同樣可以應用於情況以及其他人身上：那家酒館是麻煩的避風港嗎？土匪是否可能在附近的丘陵中策劃伏擊？

#### 地域 (知力 x2)

地域衡量角色對其大部分生命（通常在社群內）所居住區域的當地動植物、地形和天氣的理解。角色了解常見的植物、樹木和動物，它們的屬性和行為：在哪裡可以找到最好的魚；狩獵生物的活動；在哪裡尋找避難所；當季的可能天氣，以及最常見的地區危險。在鄰近但陌生的地域，地域技能的判定應增加一個或多個難度等級。

#### 母語 (知力+魅力+40)

母語是說和讀自己語言的能力，這是成長於自身故鄉文化時所學到的語言。對於人類來說，這是通用語，而亞人類和其他種族則各有各的母語。母語衡量表達能力、口才和說話者詞彙的深度。

與其他技能不同，母語不直接進行判定。相反，它被視為整體流暢度的靜態表示，限制了對話互動的水平。這在 [語言](0005_Skills.md?id=language-intcha) 技能中有更詳細的描述，但起始角色通常在遊戲開始時就能完全流暢地使用母語。

該技能可以用兩種方式使用。首先，它可以幫助理解共享共同語言基礎或起源的鄰近民族的方言。在這種情況下，該技能被視為難度至少增加一個等級，這可能會影響角色的流暢度。其次，它可以用作需要良好語言掌握能力的口頭技能的上限。

#### 知覚 (知力+霊力)

知覚用於被動觀察和集中探測；無論是尋找特定事物、對區域進行全面掃描，還是對周圍環境的簡單意識。特定的情況（例如黑暗）可能會根據所使用的主要感官影響技能判定的難度等級。強烈的氣味可能會使嗅覺知覚判定變為「簡單」而不是「標準」，而試圖在擁擠且嘈雜的酒館中偷聽對話則會使判定變為「困難」。

#### 乗馬 (敏捷性+霊力)

乗馬涵蓋了控制和保持在受過訓練以供騎乘的生物背上的能力。該技能適用於多種生物，從騾子到大象，甚至是巨鷹或海豚等飛行或游泳生物。騎乘不熟悉的物種總是困難一個難度等級；而騎乘不同介質的物種（例如馬術師騎著龍）則困難兩個等級。在野性、未馴化的生物被馴服並訓練成為騎乘獸之前，無法以建設性的方式騎乘它們。

#### 歌唱 (霊力+魅力)

保持曲調由歌唱涵蓋，從單調的吟唱到複雜的詠嘆調皆包含在內。歌唱是大多數文化中固有的部分，是娛樂的主要來源，或許也用於其儀式中。重要的歌曲可能用於求愛、在戰鬥前激勵士兵，或僅僅是敘述歷史功績。該技能反映了使用者保持節奏、準確音高和記住正確歌詞的能力。

#### 隠密 (敏捷性+知力)

隱藏在視線之外或以最小的聲音移動由隠密技能涵蓋。掩體和環境（例如黑暗或嘈雜的背景噪音）會根據環境的細節提高技能等級。同樣，不利的條件（例如缺乏掩體或安靜的夜晚）會降低技能等級。環境也會影響嘗試的難度。例如，穿著重防具的戰士可以輕易地將自己隱藏在牆後，前提是他們保持靜止或移動非常緩慢，而快速移動可能會導致他們的防具發出叮噹聲。

#### 水泳 (筋力+体力)

如果沒有經過發展，游泳能力僅限於在短時間內掙扎並保持頭部露出水面。較高的水泳百分比表示能夠應對更深、更強的水域，且溺水的風險較小。因此，進行水泳判定完全取決於環境狀況。波濤洶湧的大海、強勁的水流、湍流和離岸流都會降低技能等級，無論角色對水的親和力如何。參見 [移動](0008_Combat.md?id=movement) 章節，了解更多關於游泳的資訊，包括計算游泳速度。

#### 徒手 (筋力+敏捷性)

徒手是一種通用的戰鬥技能，適用於所有角色，衡量在沒有武器幫助下自衛的能力。徒手技能涵蓋了該文化中已知的格鬥和摔角技術。

由於徒手是一種戰鬥技能，其大成功和大失敗效果由 [戰鬥](0008_Combat.md) 章節中詳述的戰鬥規則涵蓋。

#### 意志力 (霊力 x2)

意志力衡量角色專注的能力、在特定方向上引導意志力的能力，或增強心理以應對可能的精神衝擊的能力。它也是衡量個人決心的標準。該技能用於需要精神韌性的各種情況，這包括抵抗魔法。雖然它不是理智的衡量標準，但它可用於忍受即使是最理智、穩定的心靈也會動搖的創傷性事件。意志力是 [持久力](0005_Skills.md?id=endurance-con-x2) 的精神對應物。

同樣，像持久力和回避一樣，意志力最常被用於對抗測試。當作為標準測試使用時，大成功的意志力判定表示角色已經強化了他的心靈和精神，以至於任何進一步影響他或動搖他決心的嘗試都將無效。在抵抗魔法的情況下，大成功意味著對手施放的任何進一步的精神折磨法術對該角色在該遭遇戰剩餘時間內都沒有效果。

## 專業技能

專業技能在不同角色之間有所不同，代表了更專業化的訓練和經驗形式。正如名稱所暗示的那樣，一些專業技能是通過文化背景和角色的職業獲得的。儘管它們在角色之間有所不同，但它們與標準技能的運作方式相同。

某些魔法技能也被歸類為專業技能：例如，「引導」和「奉獻」是與神聖魔法相關的兩種技能。這裡僅對其進行了簡要描述。更多細節請參考 [魔法](0009_Magic.md) 章節的相關部分。

#### 演技 (魅力 x2)

演技掌管著 impersonate（模仿）並傳達完全不同角色的藝術，無論是在舞臺表演還是社交場合。演員以令人信服的方式描繪與自己不同的個性和舉止。結合變裝和欺瞞技能，這是一種完全變成另一個人的強大方式。

#### 特技 (筋力+敏捷性)

特技涵蓋了平衡、體操、雜耍和翻滾的行為。該技能可用於給觀眾留下深刻印象，也有助於減輕墜落造成的傷害。判定成功後，角色可以在不穩定或狹窄的表面上以全速且穩健地移動。如果試圖減輕意外墜落造成的傷害，成功的特技判定會將受到的任何傷害減半。此外，如果判定成功且角色沒有因墜落而遭受嚴重或重傷，角色會相對安全地落地且不會倒地。

如果情況需要，特技可以代替回避。這樣做的好處是角色會自動恢復站姿，而不是倒地。

特技也作為流氓等級1 [撐竿跳](0003_Classes.md?id=rank-1-3) 能力的基礎。

#### 動物操縱 (霊力+魅力)

此技能有多種功能，包括試圖安撫敵對動物或訓練家畜掌握某些技巧，例如教狗坐下、取物、停留或跟隨；馬匹可以馴服以供騎士騎乘等等。如果用於試圖安撫野性或敵對的動物，成功將驅趕它。然而，如果它很餓或有幼崽在場，該判定會變得更難兩個等級。提供飢餓的動物食物可能會使判定容易一或兩個難度等級，或者根據情況可能使動物開始跟隨角色以獲取更多食物。

#### 秘術施法 (知力+霊力)

秘術施法是秘術魔法不可或缺的魔法技能。這是魔法使用者成功施放先前從法術書或卷軸中記憶的法術的能力。它也代表施法者找到施放法術的正確精神狀態，配合手勢和咒語等等。此技能的勝任力提高也會提高任何由此施放的法術的最終強度。#### 魔力知識（知力x2）

魔力発動と同様、この魔法技能はアルカナ魔法において不可欠なものである。これは魔術師が蓄積してきた実際の呪文知識を表しており、新しい呪文の学習、呪文の書への書き写し、巻物の作成、詠唱中の呪文の特定などを試みる際に使用される。また、魔術師クラスの[階級構造](0003_Classes.md?id=rank-structure-2)の節で詳しく説明されているように、術者が最初に習得できる呪文の数を決定する。

魔力知識はアルカナ魔法の使い手に限定されるものではない。たとえアルカナ魔法を実際に実践していなくても、単に秘術の研究を望む者が習得することもできる。

#### 芸術（霊力+魅力）

特定の芸術形式は数多く存在する。絵画から詩、文学から彫刻まで多岐にわたる。キャラクターはこの技能を習得する際、芸術（絵画）のように特定の専門分野を選択する。その後の芸術形式は個別に成長させる。キャラクターが自身の芸術的媒体を通じて感銘を与えたり説得したりする必要があるたびに、判定が行われる。

#### 官僚（知力x2）

行政手続き、記録、そして明文化されていない慣習の理解は、官僚技能によってカバーされる。これは役人とやり取りしたり、関連する市民情報を発見したりするために使用される。文化の洗練度に応じて、官僚が必ずしも読み書きができる必要はない。ただし、その官僚技能の数値は、彼らが業務で使用する言語または読み書き技能の数値を上回ることはできない。赤テープ（官僚的弊害）や行政の状況を切り抜ける必要があるときは常に、官僚判定が必要となる。

#### 詠唱（知力+魅力）

詠唱は、神々の力を呼び出し、導くために使用される魔法技能である。この技能の熟練度を高めることは、それを使用して詠唱された呪文の最終的な強度も向上させる。

#### 商業（知力+魅力）

商業は、商品や産品の価値を評価し、それらを可能な限り有利な価格で取引するために使用される。また、利益の確保に加え、ビジネス取引の複雑さを理解するためにも使用される。さらなる用途として、盗品や違法品を処分する最善の方法を見つけることにも使われる（これもまた、可能な限り最善の価格で）。商業は明らかに取引時に使用されるものであり、相手の商業技能または意志力のいずれかと対抗判定を行うことができ、取引を自分たちに有利に進めようとする相手側の試みを反映する。また、商品の市場価値を判断し、価格の見当をつけ、どこで取引するのが最善かを把握するためにも使用される。

#### 礼儀（知力+魅力）

この技能は、社会的または公式な状況においてどのように行動するのが適切かを理解することを扱う。呼びかけの様式、儀式、行動の慣習などが含まれる。誰に対していつお辞儀をするか、どの程度深く頭を下げるかといったことから、特定の肩書きをいつ使用すべきか、いつカジュアルに振る舞うのが適切かまで、すべてが含まれる。

#### 工芸（敏捷性+知力）

各工芸は、工芸（陶芸）のように専門化された形式であり、それに対応する職業の数だけ工芸が存在する。芸術と同様、工芸は対象となるアイテムを作成するために使用される。どれくらいの時間がかかるかは製品の性質に完全に依存する。例えば、絨毯を織ることは陶器を作るよりも時間がかかるが、時間が必ずしも最も重要な要素ではない。作り手の技能、資源の質、そして細部への注意こそが重要である。

#### 文化（知力x2）

文化は標準技能である習慣のより特殊な形式であり、キャラクター自身のものとは異なる社会に関連する。各文化技能には、それが適用される特定の国家または社会を指定しなければならない。機械的には習慣技能と同じ方法で機能する。

#### 献身（霊力+魅力）

献身は、神職者の神への奉仕に対するコミットメントを反映する魔法技能である。神への献身の深さを測定するだけでなく、キャラクターが呼び出すあらゆる神聖呪文の規模を支配する。さらに、この技能は宗教組織内における神聖魔法の使い手の地位を示すこともある。

献身は神聖魔法の使い手に限定されるものではない。たとえ神聖魔法を実際に実践していなくても、単に神々への敬意を示すことを望む者が習得することもできる。

#### 変装（知力+魅力）

適切な材料（衣装、化粧品、かつら、付け毛）を使用して説得力のある変装を施すことは、変装技能によってカバーされる。変装を作成するには、時間と細部への注意、そしてそれを納得させるための適切な材料へのアクセスが必要となる。これらの要素の一部または全部が欠けている場合、変装判定の難易度は1段階以上上昇する。

#### 工学（知力x2）

家屋から橋、門から攻城兵器に至るまで、大規模な構造物の設計と建築は工学技能の管轄内である。正しい建設を確実にするために大規模なプロジェクトを計画する際に判定が必要となるが、工学者が何らかの理由（修理状態や弱点など）で構造物の健全性を評価したい場合にも行われる。

#### 賭博（知力+霊力）

賭博技能は、チャンスゲーム、特に結果に対して金銭が賭けられる状況におけるキャラクターの能力を測定する。成功や失敗の確率を評価したり、誰かがイカサマをしているのを見抜いたりするために使用される。この技能は、状況に応じて対抗判定または非対抗判定で使用できる。顔の見えない賭博場で一晩過ごす場合は単純な判定で済むかもしれないが、著名人が関わる高額なダイスゲームでは、代わりに数ラウンドの対抗判定が必要になる場合がある。

#### 応急手当（知力+霊力）

応急手当は、文化的慣習に基づく医学的手順の深い知識である。例えば、原始的または蛮族の文化では、応急手当はハーブや自然療法の知識に基づくだろう。文明化された文化では、薬物やより進んだ治療が一般的となる。あらゆる文化において、応急手当には骨折の固定、傷口の縫合などの能力が含まれる。当然のことながら、応急手当の適用には適切な資源が必要であり、ほとんどの現役の治療者はそのようなもの（針、縫合用の腸線や糸、湿布用のハーブなど）を手元に持っているだろう。

#### 威圧（知力+魅力）

この技能は、個人を脅して、さもなければやりたくない行動を取らせるために使用される。他者から情報を引き出したり、身体的暴力の脅しによって相手を退かせるためによく使用される。威圧判定は、使用される方法や、相手が感じる危険度に基づいて修正されることがある。威圧は通常、被害者の意志力と対抗判定を行うが、拷問で使用される場合は持久力が適用される可能性がある。

#### 言語（知力+魅力）

この技能は、キャラクター自身のもの以外の言語の会話と理解をカバーする。言語技能に対して直接判定は行わず、全体的な流暢さの静的な表現として扱う。その数値は、プレイヤーがゲーム内の個性と会話する際、ゲームマスターが会話の相互作用のレベルを制限するために使用される。[言語流暢性テーブル](0005_Skills.md?id=linguistic-fluency-table)をガイドラインとして使用すること。

##### 言語流暢性テーブル

| 言語% | 会話の流暢さ |
| :-: | :-- |
| 01-25% | いくつかの単純な単語しか理解できず、文章を作れない、または読めない |
| 26-50% | 「寺院はどこ？」「食料はいくら？」といった断片的な単純な文章で理解し、コミュニケーションが取れる。小学校レベルなら読める |
| 76%+ | 一般的な会話には十分流暢で、高校レベルなら読める |
| 76%+ | 流暢に自分自身を表現でき、大学レベルなら読める |

各言語技能は特定の種族、国家、または地域の言語に固有のものであり、習得時に選択しなければならない。共通の言語的基盤や起源を共有する類似の方言を理解する助けにもなる。その隔たりに応じて、技能判定の難易度は少なくとも1段階難しくなり、キャラクターの流暢さが低下する可能性がある。

言語技能には読み書きが含まれる。情報を記録する方法は無限にあるため、読み書きができるからといって必ずしも執筆が可能とは限らない。一部の文化では木や骨に記号を刻むかもしれないし、またある文化ではタペストリーの結び目の複雑な模様で歴史を記録するかもしれない。また、読み書きのすべての形式が音声アルファベットに基づいているわけではなく、ヒエログリフや表意文字も一般的である。

#### 言語（盗賊の隠語）（知力+魅力）

_（ローグ限定）_：このパトワ（方言）を基本レベルで習得するには、盗賊ギルドへの誓いが必要。この「言語」技能はスラングや暗示的な意味で構成されており、公共の場で第三者に情報を漏らすことなく、違法な追求について盗賊同士で議論するために使用される。このコミュニケーションは、侵入に関する議論に限定される。盗賊ギルドの長期会員であるローグは、この技能を自動的に基本レベル+40%で習得する。プレイ中に習得する者は基本レベルから開始する。

#### 解錠（敏捷性x2）

解錠は、鍵やそのロック専用に作られた他の装置の助けを借りずに、機械的な施錠システムを開ける能力である。これには、損傷を与えることなくボルトや棒で固定されたドアや窓をこじ開ける技術が含まれる。解錠は「逆の鍵開け」にも使用できる。つまり、鍵がないときにドアや宝箱などを施錠することである。

#### 伝承（知力x2）

伝承は、最初に習得したときに選択しなければならない特定の知識体系をカバーする。例：伝承（錬金術）。錬金術、占星術、天文学、地理学、紋章学、歴史学、助産術、鉱物学、モンスター、政治学、宗教、戦略と戦術：これらはすべて伝承技能の典型的な例である。伝承技能があるということは、キャラクターがその基本を理解し、当面の課題や問題にどのように適用できるかを理解しており、伝承（トピック）技能を使用して有益な情報を思い出すことができることを意味する。

#### 機構（敏捷性+知力）

機構は、罠などの機械装置を組み立てたり分解したりするための知識と技術を表す。機構の技術は一般的に小さな稼働部品を持つ繊細な装置の作成に関わるものであり、巨大な構造物を扱う工学とは対照的である。これは解錠とは異なる分野であり、その技能と入れ替えることはできない。

#### 音楽（敏捷性+魅力）

音楽は、単純な葦の笛からハープのような複雑な弦楽器まで、楽器の演奏をカバーする。音楽技能の各反復は、類似した楽器のグループに適用される。音楽（フルート）を持つ音楽家は葦の笛を演奏できるが、基本が同じであるためフルート、パンパイプ、リコーダーも演奏できる。しかし、ハープやリュートを演奏することはできない。

#### 航法（知力+霊力）

目立つランドマーク、星、あるいは海水の味の変化を利用するかにかかわらず、正確に移動を指示する能力は航法技能によってカバーされる。各航法技能は、例えば外洋や地下など、特定の地域または環境をカバーする。珍しい旅の最中や、完全に馴染みのない場所にいるときに行うべきである。

#### 演説（霊力+魅力）

演説は、考えを伝えたり揺さぶったりする目的で、大人数のグループに向けてスピーチを行う芸術である。政治家が政策を強調するためによく使用する技能だが、指揮官が軍隊を鼓舞し、戦場で規律を課すためにも使用される。集団への説得が必要な場所では、説得ではなく演説が使用される。

#### 船員術（知力+体力）

この技能は[操船](0005_Skills.md?id=boating-strcon)と同じ方法で使用されるが、帆や櫂の列で動く大型の海上船舶に適用される。また、船の維持管理もカバーする。修理が必要な時期の評価、停泊の安全な場所、荒天の危険性などを判断する。

#### 誘惑（知力+魅力）

誘惑は、他者に対するロマンチックまたは性的な説得であり、説得とは非常に異なる技能である。口頭および非口頭の明白なシグナルを使用して、性的に肯定的な反応を引き出す。また、かなりの時間を要する。成功した誘惑は、ターゲットの道徳観に応じて数時間、数日、数週間かかる場合があり、ターゲットは常に意志力で誘惑に抵抗を試みることができる。

#### 手先（敏捷性+魅力）

手先は小さな物体を隠したり隠蔽したりする試み（奇術や手品）をカバーし、スリ、財布の切り取り、または視覚的な注意をそらす試みを含む。当然ながら、これはローグにとって不可欠な技能である。

#### 市街通（霊力+魅力）

市街通は、居住地内の場所や社会的接触の知識を表す。危険な可能性のある近隣地域の特定から、合法的または違法な地元のサービスを見つけることまで、すべてをカバーする。市街通の試みにどれくらいの時間がかかるかは、何を探しているかによる。良い宿を見つけるのは、盗品の買い手や偽の取引許可証の場所を見つけるよりも時間がかからない。

#### サバイバル（体力+霊力）

この技能は、文明の恩恵がない田舎や荒野の環境で生き残ることをカバーする。食料の調達、火の構築、避難所や安全な睡眠場所の確保などである。適切に装備されていれば、テントや食料などの備品を運んでいる可能性があるため、判定は通常不要である。装備と引き離された場合や、環境条件が悪化したときのみ、この技能を活用することが不可欠になる。そのような状況では、通常1日1回判定が行われる。

#### 追跡（知力+体力）

追跡技能は、あらゆる種類の獲物や狩猟対象を追跡するために使用される。足跡、傷ついた葉、散らばった花粉、ずれた岩など、通り過ぎた際の明白かつ曖昧な兆候の両方を使用して獲物の跡を追い続ける。これらは技能のない者には見えない小さな目印である。追跡判定は定期的に行う必要があり、特に条件が急激に変化した場合（例えば、雨の降り始めなど）は重要になる。どのくらいの頻度が必要かは、獲物がどれだけ狡猾だったかによる。隠蔽判定を使用して追跡判定に対抗することができる。

## さまざまな状況における技能ルール

『Classic Fantasy Imperative』における技能使用の基本ルールは非常に簡単だが、プレイ中には技能を少し異なる方法で扱う必要が生じる多様な状況がある。以下の節では、これらの状況を見て、どのように対処するかを示す。

#### 技能の再試行

状況によっては、キャラクターが技能の試行に失敗しても、再び試すことができる可能性が残されている場合がある。例としては、鍵を開けたり、垂直な壁を登ろうとしたりする場合が挙げられる。単にそれ以上の試行を拒否するのではなく、寛容なゲームマスターは、最後の手段としての追試を許可してもよい。ただし、キャラクターはいくらかの不安や自信の欠如を経験し、技能判定の難易度を1段階上昇させる。

この2回目の努力も失敗に終わった場合、キャラクターはその「最善の努力」を尽くしたとみなされ、当面の間はこれ以上の試行を行うことはできない。

### 対抗判定

技能は、ローグが貴族の財布を切り取ろうとするときの隠密対知覚、あるいは同じローグが見つかったときにその試みを否定しようとするときの欺瞞対洞察のように、他の技能に対して頻繁に使用される。これらは、技能同士が一致する状況の好例である。これらは対抗判定として知られており、挑戦が勝利か敗北、成功か失敗のいずれかをもたらす場合に使用される。

- 対抗判定は次のように決定される：参加者は両者ともそれぞれの技能で判定を行う。勝者は、より良い成功等級を得た側である。参加者が同じ成功等級（標準成功同士、あるいはクリティカル同士）を出した場合、勝者は技能の成功範囲内でダイスロールの数値がより高い側となる。

対抗判定で両方の参加者が失敗した場合、以下のいずれかを行う：

- 状況を説明し、両者を劇的な緊張感の中に置いたまま、勝者を決定するために判定をやり直す。
- ゲームマスターは、失敗の性質に適した何らかの説明や状況を作り出すべきである。

対抗判定は、傷の影響を克服したり、戦闘の特殊効果に対抗したりするために、特定の戦闘状況で頻繁に使用される。また、毒や病気に抵抗したり、邪悪な魔法の影響を振り払うためにも使用される。

##### 対抗判定の例テーブル

| 行動 | 対抗技能の例 |
| :-- | :-- |
| 交渉/値切り | 商業対商業、説得対商業 |
| 追跡/レース | 運動対運動、運動対持久力、乗馬対乗馬 |
| 欺瞞または嘘 | 欺瞞対洞察、手先対知覚 |
| 忠誠心の表示 | 情熱対情熱、情熱対洞察、情熱対説得 |
| 道を切り抜ける | 回避対運動、回避対機構、回避対乗馬 |
| 隠れ身または隠密 | 隠密対知覚、隠密対追跡 |
| 階級を利用する | 説得対意志力、欺瞞対意志力 |
| コースを維持する | 持久力対持久力、持久力対腕力 |
| 群衆を揺さぶる | 演説対意志力 |
| 力比べ | 腕力対腕力、腕力対持久力 |
| 意志の試し合い | 意志力対意志力、誘惑対意志力 |

### 微分判定

微分判定は対抗判定と似ているが、単純な勝ち負けの結果ではなく、成功等級の差を計算する点が異なる。主に戦闘の解決に使用される微分判定は、ゲームマスターが対決の結果の詳細を増やしたい場合、他の状況でも使用できる。

微分判定は次のように決定される：両方の参加者がそれぞれの技能に対して判定を行い、単独で試された場合と同様に判定の結果を受ける。明確な「勝者」というものは存在しないが、より高い成功等級を得た側が、両者の成功等級の差に等しい利益を得る（少なくとも一方が標準成功以上の結果を出したと仮定する）。両方の参加者が同じ成功等級（標準成功同士、あるいはクリティカル同士）を出した場合、追加の効果は発生しない。

##### 微分判定の結果テーブル

| 判定の結果 | 敵対者のクリティカル | 敵対者の成功 | 敵対者の失敗 | 敵対者のファンブル |
| :-- | :-- | :-- | :-- | :-- |
| 主人公のクリティカル | 利益なし | 主人公が1等級の差で勝利 | 主人公が2等級の差で勝利 | 主人公が3等級の差で勝利 |
| 主人公の成功 | 敵対者が1等級の差で勝利 | 利益なし | 主人公が1等級の差で勝利 | 主人公が2等級の差で勝利 |
| 主人公の失敗 | 敵対者が2等級の差で勝利 | 敵対者が1等級の差で勝利 | 利益なし | 利益なし |
| 主人公のファンブル | 敵対者が3等級の差で勝利 | 敵対者が2等級の差で勝利 | 利益なし | 利益なし |

### 100%を超える対抗技能

対抗判定または微分判定において、最も高い技能を持つ参加者が100%を超える技能値を持っている場合、その参加者は100と自身の技能値の差分を、自身を含む参加者全員の技能から差し引く。これにより対戦相手の技能値は低下するが、自身の優位性は維持される。

誰が最も高い技能を持っているかの特定は、状況に応じた他の修正がすべて適用された後に行わなければならない。
