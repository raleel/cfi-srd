#### Appraise（鑑定）

(占術)

| | |
| :-- | :-- |
| **等級:** メイジ 0 | **詠唱時間:** 1ターン |
| **球体:** なし | **持続時間:** 瞬間 |
| **コスト:** 1 | **射程:** 接触 |
| **範囲:** 1アイテム | **抵抗:** なし |

鑑定は、詠唱者の霊力（霊力）と等しい体格（体格）または「物」の合計ENCを持つ物理財貨の品質を即座に評価することを可能にする。この呪文は、見た目が同一のアイテムが同じ、あるいは類似した品質であるか、あるいは一つ以上が欠陥品かより高品質であるかを判別する。この呪文は有機物には作用せず、無生物にのみ作用する。また、どのような欠陥や強化が存在するかを特定するものではなく、単にそれらが存在することを示すに過ぎない。魔法の識別や検知には何の役にも立たない。

#### 防具（鎧）

(召喚)

| | |
| :-- | :-- |
| **等級:** メイジ 1 | **詠唱時間:** 1ラウンド |
| **球体:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 +強度ごとに1 | **射程:** 接触 |
| **範囲:** 1対象 | **抵抗:** なし |

この呪文を詠唱すると、対象にスケイル・アーマーと同等の保護力を提供する目に見えない魔法の力場が与えられ、各部位判定の部位に4点の防具（防具）が加算される。既に鎧を着用している者に詠唱しても効果はない。ただし、持続時間中は、より優れた保護を提供するのであれば、自然の防具に優先して適用される。自然の防具が4点を超えるクリーチャーに詠唱した場合、すべての部位の防具が1点増加する。この魔法的な保護は、移動や呪文詠唱を妨げない。この呪文は魔法で解除されるか、あるいは単一の攻撃によって詠唱者が8点のダメージを受けるまで持続する。追加の強度レベルごとに+1される（下の表を参照）。もちろん、詠唱者は望めばいつでも呪文を解除することができ、睡眠をとるためにはそうしなければならない。

| 強度 | コスト | 変動効果 |
| :-: | :-: | :-- |
| 1 | 3 | 防具4点；1回の攻撃で8ダメージを受けるまで持続 |
| 2 | 4 | 防具4点；1回の攻撃で9ダメージを受けるまで持続 |
| 3 | 5 | 防具4点；1回の攻撃で10ダメージを受けるまで持続 |
| 4 | 6 | 防具4点；1回の攻撃で11ダメージを受けるまで持続 |
| +1 | +1 | 進行を継続 |

#### Astral Spell（アストラル移動）

(変容)

| | |
| :-- | :-- |
| **等級:** クレリック 5, メイジ 5 | **詠唱時間:** 2アクション |
| **球体:** アストラル | **持続時間:** 下記参照 |
| **コスト:** 3 +追加強度ごとに1 | **射程:** 接触 |
| **範囲:** 下記参照 | **抵抗:** 該当なし |

この呪文は、詠唱者と最大5名（追加強度レベルごとに1名）がアストラル界に突入することを可能にする。詠唱中、全員が接触し円陣を組んでいなければならない。旅人たちの肉体は元の次元に置き去りにされ、彼らは通常、魔法のオーラを放つもの以外、いかなる衣服や装備も持ち込まない。それらのアイテムは通常形態のアストラル同等品へと変化する。持続時間は詠唱者が終了を望むまで続く。しかし、Dispel Magicなどの外部からの力によって早期に終了させられる可能性がある。詠唱者の肉体を殺害することでも呪文は早期に終了するが、これには詠唱者に同行した旅人たちを取り残してしまうという不幸な副作用がある。

#### Augury（予兆）

(占術)

| | |
| :-- | :-- |
| **等級:** クレリック 2 | **詠唱時間:** 2分 |
| **球体:** 占術 | **持続時間:** 瞬間 |
| **コスト:** 3/強度 | **射程:** 60フィート |
| **範囲:** 詠唱者 | **抵抗:** 該当なし |

この呪文は、次の30分以内に行われる特定の行動が、個人やパーティの健康にとって有益か有害かを判定することを可能にする。兆候を識別するためには何らかの焦点が必要であり、最も一般的なものはドラゴンの爪や小さな骨、真珠、あるいは砕いたり溶かしたりした価値100GP以上の純金である。この呪文の最大強度は4である。このロールはゲームマスターが行うべきである。詠唱者は、結果が正しく解釈されたかどうかを確信を持って知ることは決してないはずだからである。

| 強度 | コスト | 変動効果 |
| :-: | :-: | :-- |
| 1 | 3 | チャネル（Channel）技能ロール：至難 |
| 2 | 6 | チャネル（Channel）技能ロール：困難 |
| 3 | 9 | チャネル（Channel）技能ロール：標準 |
| 4 | 12 | チャネル（Channel）技能ロール：簡単 |

占術ロールが成功した場合、以下のいずれかの結果が得られる。

| 予兆 | 意味 | 
| :-: | :-- |
| はい | その行動は有益である |
| いいえ | その行動は有害である |
| はいといいえ | その行動は有益かつ有害である |
| 何もなし | その行動は有益でも有害でもない |

ファンブルが発生した場合は、ゲームマスターが現実とは逆の結果を告げるべきである。

#### Befuddle（当惑）

(エンチャント（魅了）)

| | |
| :-- | :-- |
| **等級:** クレリック 0, メイジ 0 | **詠唱時間:** 1ターン |
| **球体:** 魅了 | **持続時間:** 30分 |
| **コスト:** 1 | **射程:** 60フィート |
| **範囲:** 1対象 | **抵抗:** 意志力 |

Befuddleは、肉体を持つ対象の精神に混乱を引き起こす。呪文の対象は思考をまとめることが困難になり、どこにいるのか、何をしているのか、なぜそうしているのかを忘れ、しばしば支離滅裂な思考に陥る。当惑した対象は自己防衛のために行動することはできるが、呪文が終了するまで建設的な行動を開始することはできない。どのような種類の攻撃や脅威的な行動も、それが当惑した対象に向けられたかどうかにかかわらず、即座に呪文を中断させる。

#### Blade Barrier（刃の障壁）

(召喚)

| | |
| :-- | :-- |
| **等級:** クレリック 4 | **詠唱時間:** 2アクション |
| **球体:** 守護、創造 | **持続時間:** 3ラウンド/強度 |
| **コスト:** 3+追加強度ごとに1 | **射程:** 100フィート |
| **範囲:** 半径5〜30フィート | **抵抗:** 下記参照 |

この呪文は、固定された点の周囲を回転して切り刻む剣、短剣、ナイフの障壁を作り出す。効果範囲内を通過する「あらゆるもの」の1d4+2のランダムな部位判定の部位に対し、1d8点のダメージを与える。防具は通常の半分の保護しか提供しない。魔法の防具値は通常通りダメージを軽減する。武器が目にも止まらぬ速さで回転しており、密集しているため、それらを回避したり受け流したりすることは不可能である。シールドを使用して、通常通りに部位をパッシブにブロックすることはできる。その場合、ロールしたダメージを盾の防具およびヒットポイントと比較することを忘れないこと。

この呪文は、クレリック自身や味方を保護するために防御的に詠唱することも、敵を罠にかけるために攻撃的に詠唱することもできる。ただし、障壁が形成される際、その端から5フィート以内にいる敵は、回避ロールを行って逃れることができる。成功の有無にかかわらず、相手は転倒状態で効果範囲のすぐ外側に追い出される。ロールが成功すればダメージは受けないが、そうでなければ完全な効果を受ける。

#### Bless \(R\)（祝福）

(召喚)

| | |
| :-- | :-- |
| **等級:** クレリック 1 | **詠唱時間:** 1ラウンド |
| **球体:** すべて | **持続時間:** 5分 |
| **コスト:** 1 | **射程:** 180フィート |
| **範囲:** 半径25フィート | **抵抗:** 意志力 |

この呪文が詠唱されると、クレリックは効果範囲内の味方グループを祝福する。影響を受けた者は、詠唱者の属性（善または悪）を放つ。中立の祝福は存在しない。呪文の範囲内のすべての味方は、すべての技能ロールおよび抵抗ロールに+5%のボーナスを得る。さらに、彼らの武器は、知性あるアンデッドや、天使、悪魔、デビルなど、詠唱者と対立する属性を持つ外部の次元のクリーチャーに対して+1d3のダメージを与える。スケルトンやゾンビのようなアニメイトされたアンデッドは本来的に邪悪ではないが、通常は邪悪な魔法によって動かされているため、このダメージを受けることに注意すること。

この呪文の逆であるCurse（呪い）は、クレリックが敵を呪うことを可能にし、前述の利点の逆のペナルティを技能に与える。呪われた武器のダメージはペナルティとして計算され、このダメージは最低でも1点未満にはならない。

#### 命令 (Command)

(付与術 (魅了))

| | |
| :-- | :-- |
| **階級:** クレリック 1 | **Casting Time:** 1 行動ポイント |
| **Sphere:** 魅了 | **Duration:** 1分 |
| **Cost:** 3 | **射程:** 100フィート |
| **Area:** 対象1体 | **Resist:** 意志力 |

この呪文を唱えると、クレリックは体格1〜20の生きているクリーチャー1体に対して一言の命令を発することができる。対象の次のターンに抵抗に失敗すれば、その命令に忠実に従う。これは本質的に、犠牲者が次のターンを費やして命令された行動を完了させることで、行動ポイントを無駄にさせる効果がある。もし犠牲者に残りの行動ポイントがない場合、次のラウンドの最初のターン中に行動が実行される。命令自体は対象に直接の身体的負傷を与えることはできないが、結果として二次的な負傷が生じることはある。

例えば、「死ね」という命令は、犠牲者が1ラウンドの間、昏睡状態のような状態で倒れ込むという結果を生むだけで、直接的なダメージはない。しかし、100フィートの崖を登っているクリーチャーに「落ちろ」と命じれば、致命的な結果をもたらす可能性がある。

命令の対象は術者が発した言葉を理解できなければならず、抵抗するために意志力テストを行うことができる。

**命令の例**

- **這う (Crawl):** 対象は伏せ状態になり、這い始める。
- **死ぬ (Die):** 対象は昏睡状態のような状態で倒れ込む。
- **倒れる (Fall):** 対象は伏せ状態になる。
- **ドジ (ファンブル):** 対象は実行しようとしていた身体的行動を失敗する。
- **眠る (Sleep):** 対象は居眠りする。
- **逃げる (Flee):** 対象は術者に背を向けて逃げ出す。
- **飛ぶ (Fly):** 対象は腕を羽ばたかせて円を描くように走る。
- **進む (Go):** 対象は向いている方向に歩き始める。
- **止まる (Halt):** 対象はその場に即座に停止し、立つ。
- **去る (Leave):** 対象は入ってきた方向を向いて立ち去る。
- **休む (Rest):** 対象は座り込んで息を整える。
- **走る (Run):** 対象は走り始める。
- **叫ぶ (Scream):** 対象はわめく。
- **沈む (Sink):** 対象は水泳を止める。
- **降伏 (Surrender):** 対象は武器を捨て、敵対行為を止める。

#### アイテム付与 (Enchant Item)

(付与)

| | |
| :-- | :-- |
| **階級:** メイジ 4 | **詠唱時間:** 下記参照 |
| **領域:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 + 下記参照 | **射程:** 接触 |
| **範囲:** 1アイテム | **抵抗:** なし |

この呪文を詠唱すると、アイテムを「付与（Enchantment）」のために準備する。物体は良好な状態であり、最高級の構造と職人技で作られたものでなければならない。追加の工具、彫刻、刺繍、宝石の装飾、刻印などの費用を賄うために、少なくとも100GPの追加費用が必要である。最後に、付与のプロセスには実験室や工房が必要となる。

呪文を詠唱している間、魔術師は1d8+2日間続く詠唱時間の間ずっと、そのアイテムに触れていなければならない。これには休息や睡眠の時間も含まれるが、その間、アイテムは詠唱者の手元（腕の届く範囲）に置かなければならない。詠唱中、魔術師は他の呪文を唱えたり、他の形態の魔法を行使したりすることは一切できない。これらの厳格な制限を破ると、自動的に呪文は失敗する。

詠唱に成功すると、アイテムは最終段階への準備が整い、詠唱者が望む呪文をアイテム内に収めることができる。これを行うには、呪文を記憶しているか巻物として持っている必要があり、24時間以内にアイテムに詠唱しなければならない。さもなくば、プロセス全体を最初からやり直す必要がある。選択した呪文の詠唱を開始すれば、そのプロセスは前述の24時間を超えてもよい。アイテムに選択した呪文を吹き込むには、望む強度に応じた通常の「マジックポイント」のコストがかかり、呪文ランクごとに1d12時間を要する。吹き込みのプロセス全体を通じて、詠唱者は上記と同様に、休息中もアイテムに触れているか腕の届く範囲に留まらなければならない。また、詠唱期間の終了時に「魔術詠唱（Arcane Casting）」判定を行い、呪文を吹き込む必要がある。通常の呪文詠唱の成功度が適用されるが、「失敗」の結果については、呪文を強引に実行することはできない。連続する呪文をアイテムに吹き込む場合、前の呪文が完了してから24時間以内に詠唱プロセスを開始すれば可能である。これは、以前の呪文が失敗した場合にも適用される。連続する各呪文には通常の詠唱コストが必要である。

アイテムを使用する際、含まれている各呪文は一度しか使用できないが、上記の手順に従えば、同じ呪文の複数のバージョンを吹き込むことも可能である。また、単一の呪文を吹き込んだ後、ランク4の呪文「永続（Permanency）」を重ねて詠唱することも可能である。この場合、呪文は「永続」の記述にある制限に従い、何度でも望むだけ詠唱できる。

特定の呪文に適合しない他の魔法効果をアイテムに吹き込むことは不可能であり、遠い過去の多くの魔法アイテムは、今日では単純に再現することができない。

この呪文は、詠唱時に決定した通り、熱または寒さの一般的な極端な状況から1体のクリーチャーを守る。呪文の対象は、氷点下や灼熱の砂漠の熱といった、自然界のありふれた極端な環境に対して免疫を持つ。この呪文が完全な保護を提供する「金属熱（Heat Metal）」を除き、レッドドラゴンの炎のブレスやメイジの「冷気円錐（cone of cold）」呪文といった魔法的な熱や冷気によるあらゆる「攻撃」は、どちらの属性に対して保護していたかに関わらず、自動的にこの保護を打ち消す。ただし、保護されている対象は、保護の種類が攻撃タイプと一致していると仮定した場合、呪文が失敗したラウンドにおいて、最初の10点のダメージを無視できる。範囲効果呪文の場合、ダメージは適用される前に軽減される。

#### 羽毛落下 (Feather Fall)

(変身)

| | |
| :-- | :-- |
| **階級:** メイジ 1 | **詠唱時間:** 即時 |

#### 使い魔召喚 (Find Familiar)

(召喚)

| | |
| :-- | :-- |
| **階級:** メイジ 1 | **詠唱時間:** 2d12時間 |
| **領域:** なし | **持続時間:** 特別 |
| **コスト:** 3/強度, +1経験点 | **射程:** 0 |
| **範囲:** 半径0.5マイル/強度 | **抵抗:** なし |

この呪文により、詠唱者は使い魔を召喚しようと試みることができる。使い魔は主人の感覚と力の拡張となる。使い魔は主人とテレパシーで会話でき、優れた警備役や斥候にもなる。使い魔が殺されると、その密接な繋がりゆえに魔術師にとって一定のリスクを伴うため、使い魔を持つことは低ランクの危険性を伴う。

使い魔を召喚するためには、魔術師は木炭を焚いた火鉢を維持しながら儀式を開始し、火力が十分に高まったら100GP相当の香を投入しなければならない。これらの材料を燃やしながら、詠唱者は使い魔が到着するか、あるいは詠唱時間が経過して成功せずに終わるまで儀式を続けなければならない。

この呪文が成功裏に詠唱されたとしても、適切な使い魔が魔術師の呼びかけに応じる確率はわずか50%であり、魔術師はこの呪文を1年に1度しか試みることができない。強度を1段階上げるごとに呪文の射程が0.5マイルずつ広がり、それによって潜在的な使い魔が見つかる確率が5%ずつ（最大95%まで）増加する。呼びかけに応じるクリーチャーの正確な種類を制御することはできないが、到着したものは忠実な召喚者であり同盟者となる。呼びかけに応じるかどうかはクリーチャー次第であるため、特定の種類のクリーチャーが生息していることで知られる地域にいたとしても、詠唱者の成功が保証されるわけではない。

クリーチャーが詠唱者の召喚に応じた場合、魔術師は依然として1つの「経験値ロール」を犠牲にして、自分と使い魔の間に精神的なリンクを作成する必要がある。これが完了すれば儀式は完了である。

使い魔が死亡した場合、詠唱者は5つの「経験値ロール」を失う。現在「経験値ロール」を一つも持っていない詠唱者は、バランスが支払われるまで、授与されるすべての将来の「経験値ロール」を没収されなければならない。

#### ファイア・シールド

(力術)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **詠唱時間:** 2アクション |
| **球体:** なし | **持続時間:** 2分/強度 |
| **コスト:** 3+1/追加の強度 | **射程:** 0 |
| **範囲:** 術者 | **抵抗:** 該当なし |

この呪文は、術者を包み込むがそれ自体ではダメージを与えない、薄い炎の盾を生成する。代わりに、この炎は、記憶している2つの変異のいずれかに依存して、火または冷気から対象を保護する。「チル・シールド」は青や緑の炎を作り出し、熱および火ベースのダメージから保護する。「ウォーム・シールド」は紫や青の炎を作り出し、冷気や氷ベースのダメージから保護する。炎の色は50%の確率で決定されるべきである。両タイプとも青い炎を放出する可能性があるため、攻撃者側に不確実性の要素が生じる。どちらを記憶するかは呪文の準備時に決定され、必要に応じて両方を記憶することもできる。これらの炎は熱を発さず、松明の半分の明るさで照らす。各変異の詳細は以下の通りである。

- **チル・シールド:** これらの炎は触れると冷たく、火や熱ベースのあらゆるダメージを合計の半分に軽減する。抵抗ロールに成功すると、すべてのダメージを無効化する。抵抗ロールは1等級簡単になり、回避の場合、防御者は伏せ状態にはならない。
- **ウォーム・シールド:** これらの炎は触れると温かく、冷気ベースのあらゆるダメージを合計の半分に軽減する。抵抗ロールに成功すると、すべてのダメージを無効化する。抵抗ロールは1等級簡単になり、回避の場合、防御者は伏せ状態にはならない。

いずれかの変異の対象に対する近接攻撃（徒手か武器かを問わず）は、保護されている元素を使用していない限り、通常のダメージを与える。保護されている元素を使用した場合、術者は攻撃の元素部分から保護され、攻撃者は受けたダメージと同等のダメージを受ける。攻撃者が着用している防具は保護を提供しないが、魔法の防具やクリーチャーの自然装甲は通常通りダメージを軽減する。先天的魔法抵抗を持つクリーチャーは、対象が最初に攻撃された時に意志力ロールに成功すればファイア・シールドを解呪できる。魔法抵抗ロールに失敗した場合、対戦相手は後にファイア・シールドを無効化することはできない。

#### マジック・ミサイル

(召喚)

| | |
| :-- | :-- |
| **階級:** メイジ 1 | **詠唱時間:** 1 アクション |
| **領域:** なし | **持続時間:** 即時 |

この呪文が詠唱されると、1つ以上の魔法エネルギーのミサイルが魔法使用者の指先から飛び出し、対象に命中する。生成可能な最大ミサイル数は、術者の「アルケイン詠唱」技能レベルに基づいており、60%で2発目、70%で3発目、80%で4発目、90%で5発目の最終ミサイルが生成される。これらのミサイルを生成するには、望むミサイル数と同じ強度で呪文を詠唱しなければならない。例えば、技能レベル60%未満の魔法使用者が強度3で「マジック・ミサイル」を詠唱した場合、より長い射程は得られるが、生成されるのはミサイル1発のみである。技能レベル70%の魔法使用者は、同じ強度3で詠唱すれば同じ射程を得られ、かつ3発のミサイルを生成できる。この呪文の「最大強度」は5である。以下の表を参照のこと。

「マジック・ミサイル」は、対象が近接戦闘中であっても、部分的な遮蔽物があっても必ず命中する。これらのミサイルを回避することはできない。ただし、完全な遮蔽物の中にいる相手は、この呪文の対象にはできない。「シールド」呪文は、対象が術者に気づいており、かつ術者と対峙している場合、自動的に「マジック・ミサイル」をそらす。「マジック・ミサイル」は1d6+1の「ダメージ」を与え、着用している「防具」は保護にならないが、クリーチャーの自然の「防具」や魔法的な「防具」の「ダメージ修正」は通常通り軽減される。「マジック・ミサイル」は、扉や鍵などの無生物にはダメージを与えない。

複数のミサイルを放つ際、術者はそれらを単一のクリーチャーに命中させるか、複数のクリーチャーをターゲットにすることができる。各ミサイルは「部位判定」の結果に基づいてランダムな箇所に命中する。特定の箇所を狙うことはできない。術者は「ダメージ」をロールする前に、各ミサイルの個別の対象を指定しなければならない。

#### マジック・マウス

(変容)

| | |
| :-- | :-- |
| **階級:** メイジ 2 | **詠唱時間:** 1分 |
| **領域:** なし | **持続時間:** 下記参照 |
| **コスト:** 3、+1/追加強度 | **射程:** 30フィート |
| **範囲:** 1つの物体 | **抵抗:** なし |

この呪文は、アイテムや物体の上に口を作り出す。これは、呪文が最初に詠唱されたときに術者が指定した特定のイベントや時間にトリガーされると魔法的に出現する。この口は、詠唱時に術者が選択したあらかじめ定義されたフレーズを話す。このフレーズは最大25単語以内でなければならず、口は1秒あたり約1単語の速度で話す。口は、力ある言葉を発したり、呪文を詠唱したりすることはできない。

この呪文は、柱や木から石壁、チェストに至るまで、通常は無生物であるあらゆる物体にかけることができる。しかし、 statue（彫像）にかけると特に効果的である。彫像自体が話しているかのように見えるからである。何らかの知能や本能を持つ生きているクリーチャーにはかけることができない。これは、かつて生きていたものにも適用される。この呪文を詠唱する際、魔法使用者はエンチャントを活性化する状況を決定する。話された言葉から騒音の発生まで、何でもトリガーに設計できる。範囲は「次の人がこの部屋に入ったとき…」といった一般的なものから、「土曜日にセドナの女性クレリックが廊下の端にある彫像から10フィート以内に近づいたとき…」という非常に具体的なものまで可能である。トリガーとなる影響は、不可視のクリーチャー、クリーチャーの「アライメント」「技能」「クラス」など、魔法的でない手段では判別できないものであってはならない。ただし、着用している衣服を指定することは可能である。呪文がトリガーされる最大距離は、強度1当たり25フィートである。

この呪文の「持続時間」は、エンチャントが起動して呪文が終了するまで永久である。

#### メテオ・シャワー

(召喚)

| | |
| :-- | :-- |
| **階級:** メイジ 5 | **詠唱時間:** 2 アクション |
| **領域:** なし | **持続時間:** 即時 |

魔法使用者がこの呪文を詠唱すると、「強度」のレベルごとに2つのマイクロ・メテオが突き出された手から放たれる。メテオは対象に向かって弧を描きながら落下し、火花と灰の跡を残しながら衝撃を与える。着弾すると、対象地点の周囲で何度も炎の爆発を引き起こす。最初のメテオは常に指定した対象地点に命中し、追加のメテオはそれぞれ30フィートの爆発範囲を持ち、対象の周囲にランダムに命中する。命中位置を決定するには、1d8をロールして方向を決めること。

各メテオは、効果範囲内にいる者に1d10ポイントの火炎「ダメージ」を与える。ただし、各爆発の半径により、多くが重なり合い、巻き込まれた不幸な者には追加の「ダメージ」が与えられる。「ダメージ」のロールは合計され、対象の各「部位判定」に適用される。着用している「防具」による保護は無視されるが、魔法的な「防具」やクリーチャーの自然の「防具」は通常通り軽減される。

効果範囲外であっても衝撃点から60フィート以内にいる者全員は、「運動」判定に成功しなければ、立ち続けることができない。

「メテオ・シャワー」には、「ダメージ」をロールした数値 x 5%の確率で可燃物を発火させる可能性がある。詳細については「[火](0007_Game_System.md?id=fire-based-attacks)」のセクションを参照のこと。

#### ミラー・イメージ

(幻影)

| | |
| :-- | :-- |
| **階級:** メイジ 2 | **詠唱時間:** 1 アクション |
| **領域:** なし | **持続時間:** 3ラウンド/強度 |
| **コスト:** 1/強度 | **射程:** 0 |
| **範囲:** 半径5フィート | **抵抗:** なし |

この呪文が詠唱されると、半径5フィート以内に2d4体の魔法使用者の分身が出現し、術者の動きを完璧に模倣する。さらに、効果範囲全体が揺らめき、術者の正確な位置を特定することが不可能になる。幻影を攻撃するとそれは消滅するが、残りのイメージには影響がない。術者を攻撃しても残りのイメージには影響せず、イメージは常に変化し続けているため、再度攻撃したとしてもどれが本物の術者であるかを知る方法はない。術者が負った怪我は、イメージにも同様にコピーされる。ゲームマスターが本物の術者に命中したか、イメージに命中したかを決定する方法は数多くある。一つは、術者を含む潜在的な対象の総数を決定し、最も近い数字のダイスを振る方法である。例えば、イメージ4体と術者1人で合計5体の場合、攻撃者は1d6を振り、6が出た場合は振り直すことで、1が出れば術者に命中したとする。もう一つの方法は、対象の数と同数のマーカーを用意し、そのうちの一つを術者としてマークしておく方法である。攻撃が行われるたびにマーカーを一つ引き、対象が命中すればダメージを適用する。外れた場合はイメージが消滅し、マーカーが一つ取り除かれる。イメージは呪文の「持続時間」が終了すると消滅する。

#### 永続化

(変身術)

| | |
| :-- | :-- |
| **ランク:** メイジ 4 | **詠唱時間:** 1アクション |
| **領域:** なし | **持続時間:** 永続 |
| **コスト:** 3、経験修正2 | **射程:** 下記参照 |

術者は対象となった実体を持つクリーチャーの姿を別のクリーチャーに変えることができる。強度1につき体格（体格）を最大5ポイント変更できる。したがって、体格16のオークを体格1のウサギに変えるには、3レベルの強度（15体格ポイントの差）が必要となる。この呪文の対象者は意志力ロールによる抵抗が許される。大型のクリーチャー（体格 21-40）は変身の影響を受けにくく、抵抗ロールは「簡単」となり、巨大なクリーチャー（体格 41+）の場合は「非常に簡単」となる。

変身の全工程には1ラウンドを要し、対象のクリーチャーにはかなりのストレスがかかるため、元の性格を維持するために意志力ロールが必要となる。失敗すると1d10分間気絶し、ファンブルすると精神的ショックで死亡する。クリーチャーの元の体格が倍増あるいは半減するごとに、性格維持の意志力ロールは1等級ずつ難しくなる。また、人間を魚に変えるような環境の完全な変化も同様である。成功すると、犠牲者は知力（知力）と魅力（魅力）、およびそれらの能力値を必要とする技能を維持できる。

変身により、対象は想定したクリーチャーの呼吸方法（通常と異なる場合）、自然攻撃、すべての日常的な移動手段を獲得する。そのクリーチャーが持つ強化能力や魔法的アビリティは得られない。例えば、ドラゴンに変身したとしても、そのクリーチャーのブレス攻撃や擬似呪文能力を得ることはないが、飛行能力、頑丈な外皮、致死的な噛みつき、爪による攻撃などは獲得する。さらに、犠牲者は運動、腕力、飛行、水泳といった新しい形態の身体技能、およびヒットポイントとダメージ修正を獲得する。変身した個体が知力を維持できていたとしても、新しい形態に言葉を発する能力がない限り、話すことはできない。元の形態で呪文を詠唱できた者は、言語的および動作的な構成要素を生成する能力さえあれば、新しい形態でも詠唱が可能である。二足歩行から四足歩行へ、あるいは陸上動物から海中生物へといった極端な変化の場合、ゲームマスターは新しい形態に順応するまで練習に時間を要する技能について、少なくとも1等級の難易度ペナルティを課してよい。これは運動、徒手、水泳、飛行、戦闘技能などの身体技能に特に当てはまる。

性格を維持するための意志力ロールは、失敗するまで変身している間、毎日行わなければならない。失敗した者は新しい形態の精神性に屈し、知性のないクリーチャーの場合は知力が「霊力（INS）」に置き換わる。変身が完了すると、凝視攻撃やブレス武器など、以前は獲得していなかった新しい形態固有の特殊・魔法的能力が使用可能となる。このようにアイデンティティを失ったキャラクターは、ゲームマスターの管理下にあるノンプレイヤーキャラクターとなる。

変身した個体が精神的に屈する前は、通常通りディスペル・マジックの影響を受け、抵抗ロールなしで元の姿に戻ることができる。これは、本来の姿に戻りたいという本人の潜在意識によるものである。変身の負荷に抵抗するためにはさらなる意志力ロールが必要であり、失敗すれば1d10分間気絶し、ファンブルすれば精神的ショックで死亡する。

犠牲者がすでに新しい形態の精神性に屈していた場合でもディスペル・マジックは使用できるが、犠牲者は意志力ロールを行って元の形態に戻ることに抵抗しようとする。このロールに失敗すると、犠牲者は元の形態に戻る。もちろん、この変身の精神的ショックに抵抗するために、再び意志力ロールが必要となる。一度失われた犠牲者の本来のアイデンティティは二度と取り戻せず、犠牲者はその奇妙で異質な姿を自然なものと思い込み、以前の「正常」な状態に戻ることを切望するようになる。*例えば、ウサギに変身させられそのアイデンティティを受け入れたオークは、自分は元々ウサギであり、無礼にもオークの姿に変えられてしまったのだと信じ込む。*「ウィッシュ」やその他の類似の魔法以外に、一度失われた犠牲者のアイデンティティを回復させる手段はない。

身につけている、あるいは持ち運んでいる装備品はすべて魔法的に新しい形態と融合する。ただし、一部のケースでは、マジックリングやブーツのように、新しい形態でも使用可能なアイテムは残ることをゲームマスターが許可してもよい。これにはクリーチャーの新しい体格が元の体格と大きく異なっていないことが必要である。ゲームマスターの承認を前提として、攻撃的でない性質のマジックアイテムがその効果を新しい形態に引き継ぐ確率は、霊力（霊力）x1%である。例えば、+1保護の指輪を持つクリーチャーは、その自然な防具ポイントに+1ボーナスを得ることができる。ドッペルゲンガーやライカンスロープのように変身能力を本来持つクリーチャーは通常通り変身するが、1ラウンド後には元の形態に戻ることができる。殺害されると、以前にアイデンティティを完全に失っていたとしても、変身したクリーチャーは元の形態に戻る。

(防護術)

| | |
| :-- | :-- |

この呪文は、通常、クリーチャーやアイテムにかかっているあらゆる呪いの効果を取り除く。武器、盾、防具などのアイテム自体が持つ呪われた性質を取り除くわけではないが、そのようなアイテムに苦しめられているクリーチャーがそれを手放すことを可能にする。一部の呪いは、特定の強度で詠唱した場合にのみ解除できるものがあり、通常、その特定の記述に記載されている。「病気治癒」または「呪い解除」のいずれかを使用してライカンスロピー（獣人病）を治療することができ、いずれも強度12が必要である。

- 51-75: 戦闘スタイルおよび抵抗ロールの難易度が2段階上昇する。
- 76-00: 失敗したすべての技能判定がファンブルとして扱われる。

#### 修復

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 3 | **詠唱時間:** 3分 |
| **領域:** 治癒 | **持続時間:** 永続 |

この呪文を詠唱すると、生命力吸収や類似の効果によって以前に生命力を奪われた犠牲者は、失われていた疲労レベルを1段階回復する。強度1では、この呪文は過去24時間以内に生命力を奪われたクリーチャーに対してのみ有効である。強度が1上がるごとに、有効な経過時間はさらに24時間延長される。例えば、48時間弱前に生命力を奪われた犠牲者の場合、この呪文を強度2で詠唱する必要がある。複数のレベルの疲労を奪われている場合は、追加の「修復」詠唱が必要となる。持続時間に関係なく、回復した疲労に加えて、この呪文は魔法やあらゆる形の狂気や認知症などによって失われた精神機能も完全に回復する。また「修復」は、特定の呪文などによる人工的な老化によって失われた年数を取り戻すためにも使用できる。この方法で呪文を詠唱する場合、通常の詠唱コストに加えて、クレリックは回復させる対象の標準的な寿命の1%（人間なら1年）につき1回の経験修正ロールを消費しなければならない。この呪文によって、対象の現在の年齢が実際の年齢よりも低くなることはない。

#### 復活 (R)

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 5 | **詠唱時間:** 10分 |
| **領域:** 死霊 | **持続時間:** 永続 |
| **コスト:** 3、追加強度につき+1、経験修正+2 | **射程:** 接触 |
| **範囲:** 1対象 | **抵抗:** なし（意志力） |

「復活」は、強度レベル1につき20年以内に死亡したあらゆるクリーチャーを蘇生させる。クリーチャーは単に生命を与えられるだけでなく、全快の体力まで回復し、負傷も治癒され、失った四肢さえも再生する。呪文が有効であるためには、クリーチャーの遺体がほとんど残っていなくてもよい。例えば、8の強度で詠唱すれば、たとえ指の骨一本しか残っていなくても、145年前に死んだ存在を復活させることが可能である。蘇生された個体は休息期間を必要とせず、即座に完全に機能する。この呪文は、天寿を全うして自然死したクリーチャーには効果がない。

対象の属性が「悪」以外であった場合、相手は「意志力」の対抗ロールで呪文に抵抗し、成功すれば効果を無効化できる。これは、死者の魂や霊が、一度永遠の安らぎを得た後に生者の世界へ戻ることを望むことは稀だからである。ただし、ゲームマスターは、対象にやり残した仕事がある場合、愛する人との別れが受け入れられない場合、あるいはその他英雄的な生きる理由がある場合には、ロールを免除してもよい。悪の魂の場合、永遠の破滅に苦しむよりも喜んで戻ろうとするため、抵抗するのは死者本人の「意志力」ではなく、彼らの罰を管理する悪魔や魔王などの「拷問者」の「意志力」となる。この場合、詠唱者は拷問者の「意志力」を上回らなければならない。もし拷問者の「意志力」が不明な場合は、魂の意志が強いほど、その者を破滅させるために配置された存在も強力であるという前提で、少なくとも死者のものより20ポイント高いと仮定すること。詠唱者が成功すれば対象の復活は成功し、失敗すれば犠牲者は戻る意思がないか、あるいは戻ることができない。

「復活」は非常に体力を消耗し、クレリックは自身の典型的な寿命の3%（人間の詠唱者の場合は3年）分、老化する。[Aging](0007_Game_System.md?id=aging)に関するルールを参照のこと。

この呪文の逆である「破壊」は、詠唱時にクレリックと接触している犠牲者を殺害するために使用できる。この犠牲者は「意志力」の抵抗ロールを許される。修正は、次の表に詳しく示すように、犠牲者の階級または体格のうち、犠牲者にとって有利な値が適用される。

| 対象階級 | 対象体格 | 意志力修正 |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | 至難 |
| 2 | 21-40 | 困難 |
| 3 | 41-60 | 標準 |
| 4 | 61-80 | 簡単 |
| 5 | 81+ | 非常に簡単 |

*\* この区分には、クラスを持たないキャラクターが含まれる。*

抵抗ロールに失敗した場合、対象は即座に殺害され、遺体は塵へと化す。この段階では「ウィッシュ」の詠唱のみが犠牲者を連れ戻すことができる。抵抗ロールに成功した場合でも、接触した部位判定の箇所に1d4ポイントのダメージを受け、HPはマイナスになる。防具はこのダメージを軽減できない。「破壊」を使用しても、詠唱者が老化することはない。

#### 毒遅延

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 1 | **詠唱時間:** 1アクション |
| **領域:** 治癒 | **持続時間:** 1時間/強度 |
| **コスト:** 3、追加強度につき+1 | **射程:** 接触 |
| **範囲:** 1対象 | **抵抗:** なし |

この呪文は、毒や毒液の効果を遅らせることを可能にする。ただし、毒自体を中和するわけではない。体内に広がる毒は、追加の治癒手段が見つかることを期待して十分遅らされる。毒の「発症時間」は、この呪文の持続時間が経過するまで始まらない。

例えば、コブラの毒の発症時間は、1d6+4分後に苦痛、1d6+6時間後に窒息である。「毒遅延」を強度1で使用すれば、発症時間を1時間延長し、その経過後に通常通り1d6+4分後に苦痛が始まる。

症状が出た後に犠牲者に「毒遅延」を詠唱した場合、呪文の持続時間が経過するまで症状は中断され、経過後に通常通り進行する。

最後の手段として、詠唱者が毒によって「死亡」して10分以内の個体に到達できた場合、「毒遅延」は強度1につき1時間、犠牲者の死を先延ばしにする。その間、犠牲者は昏睡状態のままとなる。この期間中に毒を治療できれば、犠牲者は生き延び、応急手当や魔法の治癒によって蘇生できる可能性がある。

#### Wizard Sight

(Transmutation)

| | |
| :-- | :-- |
| **階級:** Mage 3 | **Casting Time:** 1 分 |
| **Sphere:** None | **Duration:** 1 分/Intensity |
| **Cost:** 1/Intensity | **射程:** 0 |
| **Area:** See Below | **Resist:** NA |

この呪文は、呪文の持続時間中、魔術師が通して見ることができる小さな不可視の「目」を作り出す。この目はパーティーの先に移動させたり、部屋の隅や部屋の中を覗き込むために送ることができる。移動速度は1ラウンドにつき20フィート（1分につき240フィート）で、「明らかな」脅威や興味のあるアイテムをスキャンする場合に使用する。これは通常、床と低い壁にのみ及ぶ。より徹底的（壁全体や天井も調べる）に行う場合、移動速度は1ラウンドにつき10フィート（1分につき120フィート）に低下する。ゲームマスターは、必要に応じて視覚的な異常を見つけることに関して、術者が知覚ロールを行うことを許可してもよい。目は実体があり、固体を通り抜けることはできず、60フィート先まで通常の視覚を持ち、10フィート先まで暗視ができる。術者は持続時間中ずっと目への集中を維持しなければならず、そうでなければ集中が再び確立されるまで、目は不動のままである。術者に影響を与える可能性のある凝視攻撃は依然として通常通り術者に影響を与えるが、盲目や闇の呪文などに関して、目は術者から独立していると見なされる。小さな開口部を通り抜ける目的では、目のサイズは1インチ以下で、体格（体格）は1である。

#### Word of Recall

(Transmutation)

| | |
| :-- | :-- |
| **階級:** Cleric 4 | **Casting Time:** 1 Action |
| **Sphere:** Summoning | **Duration:** See Below |
| **Cost:** 3, +1/additional Intensity | **射程:** 0 |
| **Area:** The caster | **Resist:** NA |

この呪文を唱えると、クレリックは瞬時に、あらかじめ指定された聖域、および半径10フィート以下の指定された到着地点にテレポートする。テレポートする実際の距離には制限がなく、複数の次元間を移動することも可能である。単一の次元内では、失敗の可能性はないが、次元を1つでもまたぐと91-00%の確率でファンブル（ファンブル）が発生し、2つ次元をまたぐと81-00%でファンブルが発生する。これは術者の通常のファンブル率に置き換わる。次元をまたぐ際のファンブルは、クレリックが取り返しのつかないほど迷子になることを意味する。単一の次元内でのファンブルは、通常のルールに従う。

術者自身と運搬している装備に加え、クレリックは1つのIntensity（強度）ごとに、体格（体格）/9 'Things'以下の物体を3つまで一緒に転送できる。転送される追加の物質は、宝物、装備、あるいは生きている生物であってもよい。ただし、転送されるクリーチャーは、運搬している装備をカバーするために十分なレベルのIntensity（強度）で呪文を唱える必要がある。
