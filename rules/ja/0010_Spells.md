#### Appraise（鑑定）

(占術)

| | |
| :-- | :-- |
| **等級:** 魔術師 0 | **詠唱時間:** 1ターン |
| **領域:** なし | **持続時間:** 即時 |
| **コスト:** 1 | **射程:** 接触 |
| **範囲:** 1アイテム | **抵抗:** なし |

Appraise（鑑定）は、術者のPOWに等しい体格（体格）または「Things」のENC合計を持つ物理的な商品の品質を即座に評価することを可能にする。この呪文は、見た目が同一のアイテムが同じ、あるいは類似の品質であるか、あるいは一つ以上が欠陥品であるか、より高い品質であるかを判断する。この呪文は有機物には作用せず、無生物に対してのみ作用する。また、どのような欠陥や強化が存在するかを特定するものではなく、単にそれらが存在することを示すに留まる。魔法の識別や検知には何の役にも立たない。

#### 防具（鎧）

(召喚)

| | |
| :-- | :-- |
| **等級:** 魔術師 1 | **詠唱時間:** 1ラウンド |
| **領域:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 + 1/強度 | **射程:** 接触 |
| **範囲:** 1対象 | **抵抗:** なし |

この呪文を詠唱すると、対象にスケールアーマーと同等の魔法の力の見えないフィールドが付与され、各部位判定（部位判定）に4点の防具値（防具 Points）が与えられる。すでに鎧を着用している者に詠唱しても効果はない。しかし、持続時間中は、より優れた防護を提供するのであれば、自然防具に優先して適用される。自然防具が4点を超えるクリーチャーに詠唱した場合、代わりにすべての部位の防具値を1点増加させる。この魔法の防護は移動や呪文の詠唱を妨げない。この呪文は、魔法によって解除されるか、あるいは一度の攻撃で8点（強度レベルが上がるごとに+1）のダメージを受けるまで持続する（下記の表を参照）。もちろん、術者は望む時にいつでも呪文を解除することを選択でき、睡眠を取るためには解除しなければならない。

| 強度 | コスト | 可変効果 |
| :-: | :-: | :-- |
| 1 | 3 | 4 防具値; 1度の攻撃で8ダメージを受けるまで持続 |
| 2 | 4 | 4 防具値; 1度の攻撃で9ダメージを受けるまで持続 |
| 3 | 5 | 4 防具値; 1度の攻撃で10ダメージを受けるまで持続 |
| 4 | 6 | 4 防具値; 1度の攻撃で11ダメージを受けるまで持続 |
| +1 | +1 | 進行を継続 |

#### Astral Spell（アストラル移動）

(変容)

| | |
| :-- | :-- |
| **等級:** 聖職者 5, 魔術師 5 | **詠唱時間:** 2アクション |
| **領域:** アストラル | **持続時間:** 下記参照 |
| **コスト:** 3 + 1/追加の強度 | **射程:** 接触 |
| **範囲:** 下記参照 | **抵抗:** N/A |

この呪文は術者と最大5名（強度レベルが1上がるごとに1名追加）がアストラル界へ移動することを可能にする。全員が接触し、輪を作る状態で詠唱しなければならない。旅をする者の肉体は元の次元に残され、通常、それ自体が魔法のオーラを放つものを除き、衣服や装備は持ち込めない。魔法のオーラを放つアイテムは、通常形態のアストラル版へと変化する。持続時間は術者が望むまで続く。しかし、Dispel Magicのような外部からの力によって時期尚早に終了させられる可能性がある。術者の肉体を殺害することでも呪文は早期に終了するが、これには同行していた旅人が取り残されるという不幸な副作用がある。

#### Augury（予兆）

(占術)

| | |
| :-- | :-- |
| **等級:** 聖職者 2 | **詠唱時間:** 2分 |
| **領域:** 占術 | **持続時間:** 即時 |
| **コスト:** 3/強度 | **射程:** 60フィート |
| **範囲:** 術者 | **抵抗:** N/A |

この呪文は、今後30分以内に行う特定の行動が、個人やパーティの健康にとって有益か有害かを判断することを可能にする。予兆を見極めるためには何らかの焦点となるものが必要であり、最も一般的なものはドラゴンの爪や小さな骨、真珠、あるいは100GP以上の価値がある純金（砕いたり溶かしたりしたもの）である。この呪文の最大強度は4である。この判定は、術者が結果が正しく解釈されたのか決して疑いなく知ることができないように、ゲームマスターが行うべきである。

| 強度 | コスト | 可変効果 |
| :-: | :-: | :-- |
| 1 | 3 | 至難（至難）のChannel技能判定 |
| 2 | 6 | 困難（困難）のChannel技能判定 |
| 3 | 9 | 標準（標準）のChannel技能判定 |
| 4 | 12 | 簡単（Very 簡単）のChannel技能判定 |

占術判定が成功すれば、以下のいずれかの結果が得られる。

| 予兆 | 意味 | 
| :-: | :-- |
| はい | その行動は有益である |
| いいえ | その行動は有害である |
| はいといいえ | その行動は有益でもあり有害でもある |
| なし | その行動は有益でも有害でもない |

ファンブルが発生した場合、ゲームマスターは現実とは逆の結果を告げるべきである。

#### Befuddle（困惑）

(付呪 (魅力))

| | |
| :-- | :-- |
| **等級:** 聖職者 0, 魔術師 0 | **詠唱時間:** 1ターン |
| **領域:** 魅力 | **持続時間:** 30分 |
| **コスト:** 1 | **射程:** 60フィート |
| **範囲:** 1対象 | **抵抗:** 意志力 |

Befuddle（困惑）は、肉体を持つ対象の精神に混乱を引き起こす。呪文の対象は思考をまとめることが困難になり、どこにいるのか、何をしているのか、なぜそうしているのかを忘れ、しばしば思考が途切れた状態に陥る。困惑した対象は自己防衛のために行動することはできるが、呪文が終了するまで建設的な活動を開始することはできない。いかなる種類の攻撃や威嚇行動も、それが困惑した対象に向けられたか否かにかかわらず、即座に呪文を中断させる。

#### Blade Barrier（刃の障壁）

(召喚)

| | |
| :-- | :-- |
| **等級:** 聖職者 4 | **詠唱時間:** 2アクション |
| **領域:** 守護、創造 | **持続時間:** 3ラウンド/強度 |
| **コスト:** 3 + 1/追加の強度 | **射程:** 100フィート |
| **範囲:** 半径5～30フィート | **抵抗:** 下記参照 |

この呪文は、旋回する刃物、短剣、ナイフの障壁を作り出す。これらは固定されたポイントの周囲を激しく回転し、範囲内を通過する「あらゆる」者に1d8点のダメージを与え、1d4+2のランダムな部位判定（部位判定）を対象とする。鎧は通常の半分の防護しか提供しない。魔法の防具値（防具 Points）は通常通りダメージを軽減する。武器が目にも留まらぬ速さで回転し、密に詰まっているため、受け流し（Parry）や回避（回避）は不可能である。盾を使用して通常通り受動的に部位をブロックすることはできる。その場合、ロールされたダメージを盾の防具値やヒットポイントと比較することを忘れないこと。

この呪文は、聖職者やその味方を守るために防御的に、あるいは敵を罠に陥れるために攻撃的に詠唱できる。しかし、障壁が形成される際に境界から5フィート以内にいる敵は、回避（回避）ロールを行って逃れることができる。成功の如何にかかわらず、相手は障壁の範囲外で伏せ（prone）状態になる。成功すればダメージはない。失敗すれば、彼らは完全なダメージを受ける。

#### Bless \(R\)（祝福）

(召喚)

| | |
| :-- | :-- |
| **等級:** 聖職者 1 | **詠唱時間:** 1ラウンド |
| **領域:** 全て | **持続時間:** 5分 |
| **コスト:** 1 | **射程:** 180フィート |
| **範囲:** 半径25フィート | **抵抗:** 意志力 |

この呪文が詠唱されると、聖職者は範囲内の味方グループを祝福する。影響を受けた者は術者のアライメント（善または悪）を放つ。中立の祝福は存在しない。範囲内のすべての味方は、すべての技能判定および抵抗判定に+5%のボーナスを得る。さらに、彼らの武器は、知性あるアンデッドや、悪魔、デビル、天使のように術者とは対立するアライメントを持つ外方次元界のクリーチャーに対して+1d3ダメージを与える。スケルトンやゾンビのようなアニメートされたアンデッドは本質的に悪ではないが、通常は邪悪な魔法によってアニメートされているため、このダメージを受けることに注意すること。

この呪文の逆であるCurse（呪い）を使用すると、聖職者は敵に呪いをかけ、特定の技能に上記の利益の逆のペナルティを与えることができる。呪われた武器のダメージはペナルティとして計算され、そのダメージは1点未満にはならない。

#### アイテム付呪

(Enchantment)

| | |
| :-- | :-- |
| **階級:** メイジ 4 | **Casting Time:** 下記参照 |
| **Sphere:** なし | **Duration:** 下記参照 |
| **Cost:** 3 + 下記参照 | **射程:** 接触 |
| **Area:** 1 アイテム | **Resist:** N/A |

この呪文の詠唱は、アイテムを付呪（エンチャント）するために準備を行う。対象物は良好な状態であり、最高級の構造と職人技によるものである必要がある。追加の工具、彫刻、刺繍、宝石の埋め込み、刻印などの費用として、少なくとも100GPの追加費用が必要である。最後に、付呪プロセスには研究所または工房が必要となる。

呪文を詠唱している間、魔法使いは1d8+2日間の詠唱時間中、ずっとアイテムに触れていなければならない。これには休息や睡眠の時間も含まれるが、その間もアイテムは詠唱者の腕の届く範囲になければならない。詠唱中、魔法使いは他の呪文を唱えたり、他の形態の魔法を行ったりすることはできない。これらの厳格なルールを破ると、呪文は自動的に失敗する。

首尾よく詠唱が完了すると、アイテムは最終段階への準備が整い、詠唱者が望む呪文をアイテムに込めることになる。これを行うには、対象の呪文を記憶しているか、スクロールを持っている必要があり、24時間以内にアイテムに詠唱しなければならない。さもなくば、プロセス全体を最初からやり直さなければならない。選択した呪文の詠唱を開始すると、このプロセスは上記の24時間を超えてもよい。アイテムに選択した呪文を吹き込むには、望む強度に応じた通常のマジックポイントが必要であり、呪文ランク1つにつき1d12時間を要する。吹き込みプロセスの間、詠唱者は上記と同様にアイテムに触れているか、休息中に腕の届く範囲に留まらなければならず、詠唱期間の終了時に、呪文を首尾よく吹き込むための秘術詠唱判定が必要となる。通常の呪文詠唱の成功度に従うが、失敗の結果に関しては、呪文を強制することはできない。先行する呪文が完了してから24時間以内に詠唱プロセスを開始すれば、アイテム内に連続して呪文を吹き込むことができる。これは以前に呪文の吹き込みに失敗した場合でも適用される。各々の連続する呪文には通常の詠唱コストが必要である。

アイテムを使用する際、含まれる各呪文は一度だけ詠唱できるが、上記の手順に従うことで、同じ呪文の複数のバージョンを吹き込むことも可能である。また、単一の呪文を吹き込んだ後、ランク4の呪文「永続化（Permanency）」を唱えることも可能である。この場合、呪文は「永続化」の呪文説明に定められた制限に従い、望むだけ何度でも唱えることができる。

特定の呪文に適合しない他の魔法効果をアイテムに吹き込むことは不可能であり、遠い昔の多くの魔法アイテムは、現代では単に再現できないものである。

この呪文により、詠唱者は使い魔を召喚しようと試みることができる。使い魔は主人の感覚と力の延長となる。使い魔は主人とテレパシーで会話でき、優れた監視役や偵察役にもなる。使い魔が殺されると、彼らの密接な繋がりゆえに魔法使いには一定の危険が生じるため、使い魔を持つことは低ランクの危険性を伴う。

使い魔を召喚するには、魔法使いは木炭で火を熾した火鉢を維持しながら儀式を開始し、火が強くなったら100GP相当の香を投入しなければならない。これらの材料を燃やしながら、詠唱者は使い魔が到着するか、あるいは成果を得られずに詠唱時間が終了するまで儀式を継続しなければならない。

#### ファイアシールド (Fire Shield)

(召喚魔法)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **Casting Time:** 2アクション |
| **Sphere:** なし | **Duration:** 2分/強度 |
| **Cost:** 3+追加強度ごとに1 | **射程:** 0 |
| **Area:** 術者 | **Resist:** N/A |

この呪文は術者を包み込む揺らめく炎の盾を作り出すが、それ自体はダメージを与えない。代わりに、この炎は記憶している2つのバリエーションのいずれかに応じて、火または冷気から対象を保護する。青色または緑色の炎を作り出し、熱および火ベースのダメージから保護する「チルシールド」と、紫色または青色の炎を作り出し、冷気および氷ベースのダメージから保護する「ウォームシールド」である。炎の色は50%の確率でランダムに決定されるべきである。どちらのタイプも青い炎を発する可能性があるため、攻撃者には不確実な要素が生じる。どちらを記憶するかは呪文を準備する際に決定され、必要であれば両方を記憶することもできる。これらの炎は熱を発さず、松明の半分の明るさでしか光らない。各バリエーションの詳細は以下の通り。

- **チルシールド:** この炎は触れると冷たく、火または熱ベースのダメージを合計の半分に軽減する。抵抗判定に成功すると、すべてのダメージを無効化する。抵抗判定は1段階簡単になり、回避判定の場合、防御側を伏せ状態にすることはない。
- **ウォームシールド:** この炎は触れると温かく、冷気ベースのダメージを合計の半分に軽減する。抵抗判定に成功すると、すべてのダメージを無効化する。抵抗判定は1段階簡単になり、回避判定の場合、防御側を伏せ状態にすることはない。

いずれのバリエーションに対しても、武装・徒手を問わず、近接攻撃を行ってきた相手は、保護対象の属性を使用していない限り通常通りのダメージを受ける。保護対象の属性による攻撃を受けた場合、術者は攻撃の元素部分から保護され、攻撃者は受けたものと同等のダメージを受ける。攻撃者が着用している防具は防御として機能しないが、魔法の防具やクリーチャーの自然装甲は通常通りダメージを軽減する。天性の魔法抵抗力を持つクリーチャーは、対象が最初に攻撃された際に意志力判定に成功すればファイアシールドを打ち消すことができる。魔法抵抗力の判定に失敗した場合、相手は後からファイアシールドを無効化することはできない。

#### Magic Missile

#### Magic Mouth

(変容呪文)

| | |
| :-- | :-- |
| **階級:** メイジ 2 | **詠唱時間:** 1分 |
| **スフィア:** なし | **持続時間:** 下記参照 |
| **コスト:** 3, +1/追加等級 | **射程:** 30フィート |
| **範囲:** 1つの物体 | **抵抗:** なし |

この呪文はアイテムや物体に口を作り出す。これは呪文詠唱時に術者が定めた特定の事象や時間が到来した時に魔法的に出現する。この口は、詠唱時に術者が選択したあらかじめ定義されたフレーズを話す。フレーズは25語以内でなければならず、口は1秒あたり約1語の速度で話す。口は力の言葉を話したり、呪文を詠唱したりすることはできない。

この呪文は、柱や木から石壁、チェストに至るまで、通常は無生物であるあらゆる物体に詠唱できる。特に彫像に詠唱すると彫像自体が話しているように見えるため、極めて効果的である。知性や本能を持つあらゆる生き物には詠唱できない。これはかつて生きていたものにも適用される。この呪文を詠唱する際、魔法使いはエンチャントを起動する状況を決定する。言葉を発することから何らかの騒音が発生することまで、あらゆる事象をトリガーにできる。「次に部屋に入ってきた者が……」といった一般的なものから、「土曜日にセドナの女性クレリックがホールの端にある彫像から10フィート以内に近づいた時……」といった具体的なものまで可能である。トリガーとなる事象は、不可視のクリーチャーや属性、技能、クラスなど、非魔法的に判別できないものであってはならない。ただし、着用している衣服などは指定できる。呪文をトリガーできる最大距離は等級あたり25フィートである。

この呪文の持続時間は、エンチャントが起動されて呪文が終了するまで永続する。

(幻影呪文)

| | |
| :-- | :-- |
| **階級:** メイジ 2 | **詠唱時間:** 1アクション |

この呪文を詠唱すると、術者とまったく同じ動きをする2d4体の術者の複製が半径5フィート以内に出現する。さらに、範囲全体が揺らめき、きらめくため、術者の正確な位置を特定することは不可能になる。幻影の像の1つを攻撃すると消滅するが、残りの像には影響がない。術者を攻撃しても残りの像には影響せず、像は常に動き回っているため、再び攻撃された場合にターゲットが本物の術者であるかどうかを知る方法はない。術者が負った負傷は、像にも複製される。本物の術者が攻撃されたのか、像が攻撃されたのかを判断する方法はゲームマスターがいくつか用意できる。1つは、術者を含めて何体の潜在的なターゲットが存在するかを決定し、最も近い額面のダイスを振る方法である。例えば、4体の像と術者がいる場合、攻撃者は1d6を振り、6が出たら振り直す。1が出れば術者に命中したことになる。もう1つは、潜在的なターゲットの数と同じ数のマーカーを用意し、その1つを術者としてマークする方法である。攻撃が行われるたびにマーカーを1つ引き、ターゲットが命中すればダメージを適用し、そうでなければ像が消滅してマーカーが1つ取り除かれる。像は呪文の持続時間が終了すると消滅する。

#### 他者変身

(変容)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **詠唱時間:** 2アクション |
| **Sphere:** なし | **持続時間:** 永続 |

術者は対象となった実体を持つクリーチャー1体の姿を別の姿に変えることができる。等級1点につき体格（体格）を最大5ポイントまで変化させられる。したがって、体格 16のオークをSIZ 1のウサギに変えるには3レベルの等級（15のSIZポイントの差）が必要となる。この呪文の対象は意志力ロールで抵抗できる。大型のクリーチャー（体格 21-40）は変身の影響を受けにくく、抵抗ロールは「簡単」となり、巨大なクリーチャー（体格 41+）の場合は「非常に簡単」となる。

変身プロセス全体にはフルラウンドを要し、対象のクリーチャーにとっては非常に大きなストレスとなるため、元の性格を維持するために2回目の意志力ロールが必要となる。失敗すると対象は1d10分間気絶し、ファンブルすると精神的ショックにより死亡する。クリーチャーの元のSIZが半分になったり倍になったりするごとに、性格維持のための意志力ロールの難易度が1等級ずつ上昇する。人から魚に変えるような、環境が完全に変化する場合も同様である。ロールに成功すれば、犠牲者は知力（知力）と魅力（魅力）、およびそれらの能力値を必要とする技能を維持できる。

変身により、対象は変身後のクリーチャーが持つ呼吸方法（通常と異なる場合）、あらゆる自然攻撃、および通常の移動手段を得る。そのクリーチャーが持つ強化された能力や魔法的な能力は付与されない。例えば、ドラゴンに変身したクリーチャーは、ドラゴンのブレス攻撃や擬似呪文能力を得ることはないが、飛行能力、頑丈な皮、致命的な噛みつき、爪による攻撃などを得る。さらに、犠牲者は「運動」「腕力」「飛行」「水泳」といった物理技能に加え、そのクリーチャーのヒットポイントとダメージ修正を得る。変身した個体が知力を維持したと仮定しても、新しい形態が言葉を話す能力を持っていなければ、話す能力は失われる。変身前の形態で呪文を詠唱できた者は、言葉を発する能力と身振りを行う能力を維持している限り、新しい形態でも詠唱できる。二足歩行から四足歩行、陸上動物から海中生物への変化といった劇的な変化の場合、ゲームマスターは新しい形態に適応して学習するまで時間がかかる技能の使用に対して、少なくとも1段階の難易度ペナルティを与えることができる。これは特に、「運動」、「徒手」、「水泳」、「飛行」、「戦闘技能」などの物理技能に当てはまる。

性格維持のための意志力ロールは、失敗するまで変身したままの日々ごとに必要となる。失敗すると人物は最終的に新しい形態の精神性に屈し、非知性的なクリーチャーの場合は知力が「本能（INS）」に変更される。変身した形態が持つ、以前は所有していなかった視線攻撃やブレス武器などの特殊能力や魔法能力は、変身が完了した時点で利用可能になる。このようにして自己を失ったキャラクターは、ゲームマスターが管理するノンプレイヤーキャラクターとなる。

変身の精神性に屈する前であれば、多形化されたクリーチャーは通常の「魔法解除」の影響を受けやすく、無意識のうちに元に戻りたいと願うため、抵抗ロールは必要ない。変身には、負担に抵抗するための別の意志力ロールが必要となり、失敗すると対象は1d10分間気絶し、ファンブルすると精神的ショックにより死亡する。

犠牲者がすでに新しい形態の精神性に屈していた場合でも、「魔法解除」は使用できる。しかし、犠牲者は意志力ロールで自然な形態に戻ることに抵抗を試みる。このロールに失敗すると犠牲者は自然な形態に戻るが、もちろん、変身による精神的ショックに抵抗するための別の意志力ロールが必要となる。一度失われた犠牲者の本来の自己はもはや取り戻すことができず、代わりに犠牲者はその奇妙で異質な形態を「自然ではない」と見なし、以前の「正常」な状態に戻ることを切望するようになる。（例：ウサギに変身し、そのクリーチャーの自己を想定したオークは、自分は元々ウサギであり、無礼にもオークに変身させられたのだと信じ込む。）自己を失った後は、「願い」やそれに類する魔法以外に、犠牲者の自己を回復できる可能性はない。

装備しているものや持ち運んでいる装備品は魔法的に新しい形態と融合する。ただし、ゲームマスターの裁量により、指輪やブーツなど、新しい形態でも使用できる魔法アイテムは残る場合がある。これには新しい形態のSIZが元と大きく違わない必要がある。非攻撃的な魔法アイテムであれば、ゲームマスターの承認を条件に、変身後の形態に効果を移行する可能性が（霊力 x 1%）ある。例えば、+1加護の指輪を持つクリーチャーは、自然な防具ポイントに+1ボーナスを得る可能性がある。ドッペルゲンガーやライカンスロープのように、形状変化の自然能力を持つクリーチャーは通常通り変身するが、1ラウンド後には本来の姿に戻ることができる。殺害されると、たとえ以前に自己の痕跡をすべて失っていたとしても、多形化されたクリーチャーは自然な形態に戻る。

#### 復元

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 3 | **詠唱時間:** 3分 |
| **分野:** 治癒 | **持続時間:** 永続 |
| **コスト:** 3, +1/追加強度ごと | **射程:** 接触 |
| **範囲:** 1体 | **抵抗:** なし |

詠唱すると、「エネルギー吸収」や同様の効果によって生命力を奪われた犠牲者は、以前失った「疲労」レベルを1回復する。強度が1の場合、この呪文は過去24時間以内に吸収された対象にのみ有効である。強度が1上昇するごとに、経過していてもよい時間がさらに24時間ずつ延長される。例えば、48時間弱前に吸収された犠牲者の場合、強度が2で詠唱する必要がある。蓄積された複数の「疲労」レベルを回復するには、追加の「復元」の詠唱が必要である。持続時間に関係なく、回復した「疲労」に加え、魔法やあらゆる形態の精神疾患や認知症によって失われた精神能力も完全に回復する。また、「復元」は、特定の呪文などによる人為的な老化で失われた歳月を取り戻すためにも使用できる。この方法で呪文を詠唱する場合、通常の詠唱コストに加えて、クレリックは対象の標準的な寿命の1%を回復するごとに（人間の場合は1年）1経験ポイントのロールを消費しなければならない。この呪文は、対象の現在の年齢を実際の年齢未満に下げることはできない。

#### 復活 (R)

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 5 | **詠唱時間:** 10分 |
| **分野:** 死霊術 | **持続時間:** 永続 |
| **コスト:** 3, +1/追加強度ごと, +経験ポイント2 | **射程:** 接触 |
| **範囲:** 1体 | **抵抗:** なし（意志力） |

「復活」は、強度レベルあたり20年以内の間死亡していたあらゆる生物を蘇生させる。対象は生命を吹き返されるだけでなく、完全な力へと回復し、怪我も癒え、失った手足さえも元に戻る。呪文の効果を発揮するために、生物の身体がほとんど残っている必要はない。例えば、8の強度で詠唱すれば、たとえ指の骨しか残っていなくても、145年前に死んだ存在を蘇生させることが可能である。蘇生した者は休息期間を必要とせず、即座に完全に機能する。この呪文は、寿命が尽きて自然死した生物には効果がない。

対象の属性が「悪」以外であった場合、対象は「意志力」の対抗ロールで呪文に抵抗し、成功すればその効果を無効化できる。これは、死者の魂や霊が、一度永遠の安らぎに到達した後に現世に戻ることを望むことは稀だからである。ただし、対象がやり残した仕事がある、真実の愛から引き離される、その他生還するべき英雄的な理由がある場合、ゲームマスターはロールを免除してもよい。魂が永遠の責め苦の代わりに現世への復帰を望むであろう「悪」の魂の場合、抵抗するのは死者の「意志力」ではなく、罰の管理を任されている悪魔や悪霊などの管理人の「意志力」である。この場合、詠唱者は管理人の「意志力」を上回らなければならない。この値が不明な場合は、死者の「意志力」よりも少なくとも20ポイント高いと想定すること（魂の意志が強いほど、罰を司る存在も強力になることを意味する）。詠唱者が成功すれば対象は無事に復活し、ロールが失敗すれば犠牲者は戻ることを望まないか、戻ることができない結果となる。

「復活」は非常に消耗が激しく、クレリックは自身の標準的な寿命の3%分（人間の詠唱者の場合は3年）老化する。 [老化](0007_Game_System.md?id=aging)のルールを参照のこと。

逆の「破壊」は、詠唱時にクレリックと接触している犠牲者を殺害するために使用できる。この犠牲者は「意志力」ロールで抵抗することができ、以下の表で詳述するように、対象の「階級」または「体格」のうち、より有利な結果をもたらす方で修正される。

| 対象の階級 | 対象の体格 | 意志力修正値 |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | 至難 |
| 2 | 21-40 | 困難 |
| 3 | 41-60 | 標準 |
| 4 | 61-80 | 簡単 |
| 5 | 81+ | 非常に簡単 |

_\* このカテゴリーには「クラス」を持たないキャラクターが含まれる。_

この抵抗ロールに失敗した場合、対象は即座に死亡し、その身体は塵に帰る。この段階で犠牲者を連れ戻せるのは「願い」の詠唱のみである。ロールが成功した場合でも、対象は接触された「部位判定」の箇所にマイナス1d4のヒットポイントを受ける。防具はこのダメージを軽減できない。「破壊」を使用しても、詠唱者は老化しない。

#### 毒の遅延

(死霊術)

| | |
| :-- | :-- |
| **階級:** クレリック 1 | **詠唱時間:** 1 アクション |
| **分野:** 治癒 | **持続時間:** 1時間/強度 |
| **コスト:** 3, +1/追加強度ごと | **射程:** 接触 |
| **範囲:** 1体 | **抵抗:** なし |

この呪文は毒の毒素を遅延させるが、毒を中和するわけではない。体内に広がる毒素が、さらなる治療法が見つかるまで時間を稼げるよう、十分に速度を落とす。「発症時間」は、この呪文の持続時間が終了するまで発生しない。

例えば、コブラの毒の「発症時間」は、1d6+4分後に苦痛、1d6+6時間後に窒息である。「毒の遅延」の強度1は「発症時間」を1時間先送りするため、1時間が経過した後、通常通り1d6+4分後に苦痛が始まる。

症状が現れた後に「毒の遅延」を詠唱した場合、症状は持続時間が終了するまで止まり、その後通常通り進行する。

最後の手段として、毒で「死亡」した者に対して10分以内に詠唱できた場合、「毒の遅延」は強度1時間につき1人分の死亡を先送りにでき、その間対象は昏睡状態となる。この間に毒が解毒できれば、犠牲者は生存し、「応急手当」や魔法の治癒で回復できる可能性がある。
