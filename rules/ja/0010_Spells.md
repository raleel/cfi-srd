#### Appraise（鑑定）

(占術)

| | |
| :-- | :-- |
| **ランク:** メイジ0 | **詠唱時間:** 1ターン |
| **領域:** なし | **持続時間:** 瞬間 |
| **コスト:** 1 | **射程:** 接触 |
| **範囲:** アイテム1個 | **抵抗:** なし |

鑑定は、術者のPOWに等しいSIZ、または組み合わされた「もの」のENCである物理的商品の品質を即座に評価することを可能にする。この呪文は、一見同じに見えるアイテムが同一または類似の品質であるか、あるいは一つ以上が欠陥品かより高い品質であるかを判定する。この呪文は有機物には作用せず、無生物に対してのみ機能する。また、どのような欠陥や強化が存在するかを特定するわけではなく、それらが存在することだけを明らかにする。魔法の識別や検知には何の役にも立たない。

#### Armor（鎧）

(召喚)

| | |
| :-- | :-- |
| **ランク:** メイジ1 | **詠唱時間:** 1ラウンド |
| **領域:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 +1/強度 | **射程:** 接触 |
| **範囲:** 対象1体 | **抵抗:** なし |

この呪文が詠唱されると、対象はスケイルアーマーと同等の保護力を提供する目に見えない魔法の力場を与えられ、各ヒットロケーションに4の装甲ポイントを付与する。すでに鎧を着用している者に詠唱しても効果はない。ただし、持続時間中は自然の装甲よりも優先される（より優れた保護力を提供すると想定される場合）。4ポイント以上の自然装甲を持つクリーチャーに詠唱した場合、すべての場所で装甲ポイントを1増加させる。この魔法の保護は、移動や呪文の詠唱を妨げない。この呪文は、魔法によって解除されるか、術者が一度の攻撃で8ポイントのダメージを受け（強度レベルごとに+1）、持続する（下の表を参照）。もちろん、術者は望めばいつでも呪文を解除することができ、睡眠をとるためには解除しなければならない。

| 強度 | コスト | 可変効果 |
| :-: | :-: | :-- |
| 1 | 3 | 4装甲ポイント; 1度の攻撃で8ダメージを受けるまで持続 |
| 2 | 4 | 4装甲ポイント; 1度の攻撃で9ダメージを受けるまで持続 |
| 3 | 5 | 4装甲ポイント; 1度の攻撃で10ダメージを受けるまで持続 |
| 4 | 6 | 4装甲ポイント; 1度の攻撃で11ダメージを受けるまで持続 |
| +1 | +1 | 進行を継続 |

#### Astral Spell（アストラル移動）

(変成)

| | |
| :-- | :-- |
| **ランク:** クレリック5、メイジ5 | **詠唱時間:** 2アクション |
| **領域:** アストラル | **持続時間:** 下記参照 |
| **コスト:** 3 +1/追加強度 | **射程:** 接触 |
| **範囲:** 下記参照 | **抵抗:** なし |

この呪文により、術者と最大5人の仲間（追加強度レベルごとに1人）がアストラル界に入ることができる。詠唱中、全員が互いに触れ合い、輪を作っていなければならない。旅行者の肉体は元の次元に残され、通常、魔法のオーラを放射するもの以外、衣服や装備を持ち込むことはできない。これらのアイテムは通常の形の「アストラル版」に変換される。持続時間は術者が終了を望むまで続く。しかし、ディスペル・マジックのような外部の力によって早めに終了させられる可能性もある。術者の肉体を殺害することでも呪文は早期に終了するが、これには術者に同行している旅行者が取り残されるという不幸な副作用がある。

#### Augury（予兆）

(占術)

| | |
| :-- | :-- |
| **ランク:** クレリック2 | **詠唱時間:** 2分 |
| **領域:** 占術 | **持続時間:** 瞬間 |
| **コスト:** 3/強度 | **射程:** 60フィート |
| **範囲:** 術者 | **抵抗:** なし |

この呪文により、術者は今後30分以内にとる特定の行動が、個人やパーティの幸福にとって有益か有害かを判断できる。予兆を読み解くには何らかの焦点が必要であり、最も一般的なのはドラゴンの爪や小さな骨、あるいは粉砕または溶解された100GP以上の価値がある真珠や純金である。この呪文の最大強度は4である。この判定はゲームマスターが行うべきである。結果が正しく解釈されたかどうかを、術者が確信を持って知ることは決してないからである。

| 強度 | コスト | 可変効果 |
| :-: | :-: | :-- |
| 1 | 3 | 「困難」なチャネル技能判定 |
| 2 | 6 | 「ハード」なチャネル技能判定 |
| 3 | 9 | 「標準」なチャネル技能判定 |
| 4 | 12 | 「容易」なチャネル技能判定 |

占術判定が成功した場合、以下のいずれかの結果が得られる。

| 予兆 | 意味 | 
| :-: | :-- |
| はい | その行動は有益である |
| いいえ | その行動は有害である |
| はいといいえ | その行動は有益であり、かつ有害でもある |
| 何もなし | その行動は有益でも有害でもない |

ファンブルが発生した場合は、ゲームマスターは現実とは逆の結果を告げるべきである。

#### Befuddle（混乱）

(妖術（魅了）)

| | |
| :-- | :-- |
| **ランク:** クレリック0、メイジ0 | **詠唱時間:** 1ターン |
| **領域:** 魅了 | **持続時間:** 30分 |
| **コスト:** 1 | **射程:** 60フィート |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

Befuddleは肉体を持つ対象の精神に混乱を引き起こす。呪文の対象は思考を明確に保つことが困難になり、自分がどこにいるか、何をしているのか、なぜそうしているのかを忘れ、しばしば支離滅裂な思考に陥る。混乱した対象は自己防衛のために行動することはできるが、呪文が終了するまで建設的な活動を開始することはできない。どのような攻撃や脅威的な行動であれ、混乱した対象に向けられたかどうかにかかわらず、即座に呪文を中断させる。

#### Blade Barrier（刃の障壁）

(召喚)

| | |
| :-- | :-- |
| **ランク:** クレリック4 | **詠唱時間:** 2アクション |
| **領域:** 守護、創造 | **持続時間:** 3ラウンド/強度 |
| **コスト:** 3+1/追加強度 | **射程:** 100フィート |
| **範囲:** 半径5-30フィート | **抵抗:** 下記参照 |

この呪文は、特定の点を中心に回転し、切り刻む剣、短剣、ナイフの障壁を作り出す。効果範囲を通過する「あらゆる」者のランダムなヒットロケーション1d4+2箇所に1d8ポイントのダメージを与える。鎧は通常の半分の保護しか提供しない。魔法の装甲ポイントは通常通りダメージを軽減する。武器は目がくらむような速度で回転し、密集しているため、それらをパリィしたり回避したりすることは不可能である。盾を使用して通常通りヒットロケーションをパッシブにブロックすることはできる。その場合、ロールされたダメージを盾の装甲およびヒットポイントと比較することを忘れないこと。

この呪文はクレリックや一人以上の仲間を守るために防御的に詠唱することも、敵を罠に陥れるために攻撃的に詠唱することもできる。ただし、障壁が形成される際、その端から5フィート以内にいる敵は、回避判定を行って脱出することができる。成功の如何にかかわらず、相手は効果範囲のすぐ外側に伏せた状態で終了する。判定に成功すればダメージは受けない。それ以外の場合は、完全に効果を受ける。

#### Bless \(R\)（祝福）

(召喚)

| | |
| :-- | :-- |
| **ランク:** クレリック1 | **詠唱時間:** 1ラウンド |
| **領域:** 全て | **持続時間:** 5分 |
| **コスト:** 1 | **射程:** 180フィート |
| **範囲:** 半径25フィート | **抵抗:** 意志力 |

この呪文が詠唱されると、クレリックは効果範囲内の仲間グループを祝福する。影響を受けた者は術者の属性（善または悪）を放射する。中立の祝福は存在しない。呪文の半径内にいるすべての仲間は、すべての技能および抵抗判定に+5%のボーナスを得る。さらに、彼らの武器は知性あるアンデッドや、悪魔、デビル、天使など、術者と対立する属性を持つ外方界のクリーチャーに対して+1d3ダメージを与える。スケルトンやゾンビのようなアニメイトされたアンデッドは本来的に悪ではないが、通常は邪悪な魔法によって動かされているため、このダメージの対象となることに注意すること。

この呪文の逆であるCurse（呪い）は、クレリックが敵に呪いをかけ、前述の利益の逆を相手の技能に与えることを可能にする。呪われた武器のダメージはペナルティとして計算され、このダメージは1ポイントを下回ることはない。

この呪文は、術者の手から120度の弧を描いて炎を噴射させる。戦闘でミニチュアを使用している場合、Burning Handsは術者の正面のマスを占める各対象にダメージを与える。高強度のBurning Handsを詠唱するには、より高いランクのメイジが必要である。このダメージは、以下の通り、呪文の強度に基づくダメージで範囲内のすべての対象を飲み込む（最大強度9）。回避判定に成功し、伏せることで、犠牲者はダメージを受けない。「Artful Dodger（巧みな回避）」アビリティを持つ者は、伏せずに回避する選択肢がある。

| 強度 | コスト | 最低ランク | 可変効果 |

| 1 | 3 | 1 | 全ヒットロケーションに1d3+1ダメージ |

| 5 | 5 | 1 | 全ヒットロケーションに1d3+3ダメージ |

#### Command（命令）

(妖術（魅了）)

| | |
| :-- | :-- |
| **ランク:** クレリック1 | **詠唱時間:** 1アクション |
| **領域:** 魅了 | **持続時間:** 1分 |
| **コスト:** 3 | **射程:** 100フィート |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

この呪文が詠唱されると、クレリックはSIZ 1〜20の生きているクリーチャー1体に対して一言の命令を伝えることができ、対象が抵抗に失敗した場合、対象の次のターンに命令が文字通り実行される。これは本質的に犠牲者に次のターンを逃させ、行動を実行しながらアクションポイントを浪費させることになる。犠牲者がアクションポイントを使い切っている場合、次のラウンドの最初のターンに命令された行動が実行される。命令そのものは対象に実際の怪我を負わせることはできない。ただし、怪我が命令の二次的な効果として生じる可能性はある。

例えば、「死ね」という命令は、犠牲者が1ラウンドの間、死んだような状態で倒れる結果をもたらし、実際の怪我は生じない。しかし、100フィートの崖を登っているクリーチャーに「落ちろ」と命じれば、致命的になる可能性がある。

命令の対象は術者が話す言語を理解できなければならず、抵抗するために意志力判定が許可される。

**命令の例**

- **Crawl（這え）:** 対象は伏せて這い始める。
- **Die（死ね）:** 対象は死んだような昏睡状態で倒れる。
- **Fall（倒れろ）:** 対象は伏せる。
- **Fumble（失敗しろ）:** 対象は行おうとしている物理的なアクションを失敗する。
- **Sleep（眠れ）:** 対象は眠りにつく。
- **Flee（逃げろ）:** 対象は術者から背を向けて逃げ出す。
- **Fly（羽ばたけ）:** 対象は腕を羽ばたかせ、円を描いて走り回る。
- **Go（行け）:** 対象は向いている方向に歩き始める。
- **Halt（止まれ）:** 対象は即座に停止し、その場に立つ。
- **Leave（去れ）:** 対象は背を向けて入ってきた場所から去る。
- **Rest（休め）:** 対象は座り込み、息を整える。
- **Run（走れ）:** 対象は走り始める。
- **Scream（叫べ）:** 対象は叫ぶ。
- **Sink（沈め）:** 対象は泳ぐのを止める。
- **Surrender（降伏しろ）:** 対象は武器を捨て、敵対行動を停止する。

#### Enchant Item（アイテム付与）

(妖術)

| | |
| :-- | :-- |
| **ランク:** メイジ4 | **詠唱時間:** 下記参照 |
| **領域:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 + 下記参照 | **射程:** 接触 |
| **範囲:** アイテム1個 | **抵抗:** なし |

この呪文を詠唱すると、Enchantment（魔力付与）のためにアイテムが準備される。対象は良好な状態であり、最高級の構造と出来栄えのものでなければならない。追加の工具、彫刻、刺繍、宝石細工、刻印などに少なくとも100GPの追加コストが必要である。最後に、魔力付与プロセスには研究所またはワークショップが必要である。

呪文の詠唱中、メイジは1d8+2日の詠唱時間中ずっとアイテムに触れていなければならない。これには休息と睡眠の時間が含まれ、アイテムは術者の腕の届く範囲になければならない。この詠唱中、術者は他の呪文を唱えたり、いかなる形の魔法も行ったりしてはならない。これらの厳格なルールを破ると、呪文は自動的に失敗する。

成功すれば、アイテムは最終段階の準備が整い、術者が望む呪文をアイテムに置く。そのためには、術者は記憶しているか、スクロール上に持っている呪文を24時間以内にアイテムに詠唱しなければならず、さもなければプロセス全体を最初からやり直す必要がある。選択した呪文の詠唱が始まれば、前述の24時間を超えてもよい。アイテムに選択した呪文を注入するコストは、目的の強度に対する通常のマジックポイントコストがかかり、呪文ランク1につき1d12時間を要する。注入プロセス中、術者はアイテムに触れているか、休息中に腕の届く範囲にいなければならず、注入に成功するためには詠唱終了時に魔法の詠唱判定が必要となる。通常の呪文詠唱の成功度が続くが、失敗した場合は呪文を強制することはできない。以前に失敗した呪文の場合でも、各注入プロセスは通常通りに開始される必要がある。各注入呪文には通常の詠唱コストが必要である。

アイテムを使用する場合、含まれている各呪文は一度しか詠唱できないが、上記の手順に従って同じ呪文の複数のバージョンを注入することは可能である。単一の呪文を注入した後、ランク4呪文のPermanencyを詠唱することも可能である。その場合、Permanency呪文の記述にある制限に従い、必要に応じて何度でも詠唱できる。

特定の呪文に適合しない他の魔法効果をアイテムに注入することは不可能であり、古くから伝わる多くの魔法アイテムは現代では再現できない。

この呪文により、術者は使い魔を召喚しようと試みることができる。使い魔は主人の感覚と力の延長となる。使い魔は主人とテレパシーで会話でき、優秀な見張りや斥候となる。使い魔が殺されると、その密接な繋がりからメイジに一定のリスクが生じるため、使い魔を持つことは低ランクの危険性を伴う。

#### Fire Shield（炎の盾）

(召喚)

| | |
| :-- | :-- |
| **ランク:** メイジ3 | **詠唱時間:** 2アクション |
| **領域:** なし | **持続時間:** 2分/強度 |
| **コスト:** 3+1/追加強度 | **射程:** 0 |
| **範囲:** 術者 | **抵抗:** なし |

この呪文は、術者を焼き尽くすがそれ自体ではダメージを与えない、かすかな炎の盾を作る。その代わりに、この炎は以下の2つの変異のいずれかに依存して、火または冷気から受容者を保護する：熱や火ベースのダメージから保護する青や緑の炎を作る「Chill Shield（冷気の盾）」、または冷気や氷ベースのダメージから保護する紫や青の炎を作る「Warm Shield（暖気の盾）」。炎の色は50%の確率でランダムに決定される。いずれのタイプも青い炎を放つ可能性があるため、攻撃者には不確実性が生じる。どちらを記憶するかは呪文を準備する際に決定され、望めば両方を記憶することもできる。この炎は熱を発さず、松明の半分の明るさしか放たない。各変異の詳細は以下の通り。

- **Chill Shield:** この炎は冷たく、火や熱ベースのダメージを合計の半分に軽減する。抵抗判定の成功はすべてのダメージを無効にする。抵抗判定は1段階容易になり、回避の場合は、防御者を伏せ状態にはしない。
- **Warm Shield:** この炎は温かく、冷気ベースのダメージを合計の半分に軽減する。抵抗判定の成功はすべてのダメージを無効にする。抵抗判定は1段階容易になり、回避の場合は、防御者を伏せ状態にはしない。

変異を受けた者への近接攻撃は、保護された元素を使用しない限り通常ダメージを与える。この場合、術者は攻撃の元素部分から保護され、攻撃者は与えられたと同等のダメージを受ける。攻撃者が着用している鎧は防御を提供しないが、魔法の装甲ポイントまたはクリーチャーの自然装甲は通常通りダメージを軽減する。先天的な魔法抵抗力を持つクリーチャーは、受容者が最初に攻撃されたときにWillpowerロールを成功させることでFire Shieldを解除できる。魔法抵抗ロールが失敗した場合、対戦相手は後にFire Shieldを無効化できない。

詠唱すると、射程内の犠牲者が1人、Willpower抵抗ロールを行う。失敗すると、彼らと持っているすべての所持品が完全に固い石に変えられる。この変化は死ではなく、仮死状態の一種である。この呪文の逆バージョン、またはWishを使用して犠牲者を再び生き返らせることができる。石の状態の間に犠牲者が受けたダメージは持ち越され、元に戻った瞬間に効果が現れる。大型クリーチャー（SIZ 21-40）は石化しにくく、抵抗判定は「容易」となり、巨大クリーチャー（SIZ 41以上）は「非常に容易」となる。

この呪文の逆であるStone to Flesh（石の肉体化）は犠牲者を元に戻すために使用され、抵抗ロールは不要である。ただし、この呪文は、かつて生命を持たなかった石を変容させるためにも、いくつかの創造的な方法で使用できる。例えば、強度レベルにつき10立方フィートの石の壁を柔らかな肉に変えたり、幅3フィート、長さ強度レベルにつき10フィートの肉の「トンネル」を作り出したり、石像を遺体に戻したり、石のゴーレムを肉のゴーレムに変えることさえできる。ただし、後者の場合、石のゴーレムは通常通りWillpowerロールを行って抵抗できる。このように肉に変えられた石は柔らかくしなやかで、実際のヒットポイントは保持するが、装甲ポイントを持たないため、解体しやすくなる。

#### Meteor Shower（流星の雨）

(召喚)

| | |
| :-- | :-- |
| **ランク:** メイジ5 | **詠唱時間:** 2アクション |
| **領域:** なし | **持続時間:** 瞬間 |
| **コスト:** 3/強度 | **射程:** 20フィート/強度 |

メイジがこの呪文を詠唱すると、強度レベルにつき2個のマイクロ流星が指先から飛び出す。流星はターゲットに向かってアーチを描き、火花と灰の軌跡を残して落下する。衝突すると、ターゲットポイントを中心に複数の炎の爆発として Detonate（炸裂）する。最初の流星は常にターゲットポイントに命中し、追加の流星はランダムにその周囲に命中し、それぞれが30フィートの爆発範囲を持つ。どこに命中するかを決めるには、方向を1d8でロールすること。

A successful Evade roll allows the victim to suffer no damage. Someone with the Artful Dodger Ability has the option to Evade without going prone, but a Success in this case will only reduce damage by half, unless they are within 5 feet of the edge of the Area of Effect.

#### Polymorph Other（他者変身）

(変成)

| | |
| :-- | :-- |
| **ランク:** メイジ3 | **詠唱時間:** 2アクション |
| **領域:** なし | **持続時間:** 永久 |
| **コスト:** 3, +1/追加強度 (+1 EXP) | **射程:** 15フィート/強度 |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

術者は1体の corporeal（肉体を持つ）ターゲットクリーチャーを別のクリーチャーの姿に変えることができる。各強度ポイントにつき最大5ポイントのSIZを変容させられる。例えば、SIZ 16のオークをSIZ 1のウサギに変えるには3レベルの強度が必要となる（15 SIZポイントの違い）。呪文の対象はWillpower判定を行って抵抗できる。大型クリーチャー（SIZ 21-40）は変身しにくく、抵抗判定は「容易」となり、巨大クリーチャー（SIZ 41以上）は「非常に容易」となる。

変身プロセス全体には1フルラウンドかかり、クリーチャーにとってかなりのストレスとなる。元の性格を維持するために2回目のWillpower判定が必要であり、失敗すると1d10分間気絶し、ファンブルすると精神的ショックで死に至る可能性がある。クリーチャーの元のSIZが半分または倍になるたびに、性格を維持するためのWillpower判定が1段階難しくなり、完全な環境の変化（人間を魚に変えるような場合など）も同様である。判定に成功すれば、犠牲者はINTとCHA、およびそれらの特性を必要とする技能を維持できる。

変身は、もし通常の呼吸法とは異なる場合の新しい呼吸法、あらゆる自然攻撃、および世俗的な移動モードをすべて受容者に提供する。クリーチャーが持つ強化されたアビリティや魔法のアビリティを提供することはない。例えば、ドラゴンに変身させられたクリーチャーは、そのブレス攻撃や呪文のような能力を得ることはないが、飛行、頑丈な皮、致命的な噛みつき、鉤爪などの能力は得られる。さらに、犠牲者は新しい形の身体的技能（Athletics、Brawn、Fly、Swimなど）およびそのヒットポイントとダメージ修正を得る。以前の形のINTを保持していると仮定しても、新しい形が言葉を調音する能力を持たない限り、話す能力は失われる。以前の形で呪文を唱えることができた者は、言葉や身体的な要素を生み出す能力を保持している限り、新しい形で唱えることができる。二足歩行から四足歩行へ、あるいは陸生から水生へと劇的に変わる場合、ゲームマスターは新しい形に慣れるまで十分な練習時間を積むまで、スキルの使用を1段階困難にペナルティを与えることができる。これは特にAthletics、Unarmed、Swim、Fly、戦闘技能などの物理的技能において顕著である。

変身させられた犠牲者が、変身したままの日数だけ毎日、元の性格を維持するためのWillpowerロールが必要となる。失敗すると、犠牲者は最終的に新しい形の精神性に屈し、非知的クリーチャーの場合はINTがINSに変わる。変身が完了するにつれ、以前には取得していなかった新しい形のすべての特別な、あるいは魔法的なアビリティ（凝視攻撃、ブレスウェポンなど）がそのクリーチャーで利用可能になる。このようにアイデンティティを失ったキャラクターはゲームマスターのコントロール下のノンプレイヤーキャラクターとなる。

変身に精神的に屈する前、変身させられたクリーチャーは、それが正常な状態に戻る潜意識的な欲求であるため、Willpowerの抵抗ロールを必要とせず、通常通りDispel Magicの影響を受けやすい。この変身はストレスに抵抗するために別のWillpowerロールを必要とし、失敗すると1d10分間気絶し、ファンブルすると精神的ショックで死に至る。

犠牲者が新しい形に屈した後でも、Dispel Magicは使用できる。ただし、犠牲者はWillpowerロールを行って自然な姿に戻ることを抵抗する。このロールに失敗すると、犠牲者は自然な姿に戻るが、当然、変身の精神的ショックから抵抗するために別のWillpowerロールが必要になる。一度失われると、犠牲者の本来のアイデンティティは二度と到達できない。その代わり、犠牲者は奇妙で異質な姿を自然ではないと考え、以前の「普通」の状態に戻ることを切望するようになる。*例：ウサギに変身させられ、そのアイデンティティを受け入れたオークは、自分は本当はウサギなのに、オークに変身させられたのだと思い込むようになる。* 一度失われた後で犠牲者のアイデンティティを回復する可能性を持つのは、Wishやその他の類似の魔法だけである。

着用しているすべての装備は新しい形に魔法的に溶け込む。ただし、指輪やブーツのように、クリーチャーの新しい形で使用できる魔法アイテムは、そのまま残すことをゲームマスターが許可するかもしれない。そのためには、クリーチャーの新しいSIZが元のSIZと著しく異ならない必要がある。ゲームマスターの承認を受けた非攻撃的な性質の魔法アイテムが、クリーチャーの新しい形に効果を移すには、POW×1%のチャンスがある。例えば、+1の保護指輪を持つクリーチャーは、自然装甲ポイントに+1のボーナスを得るかもしれない。ドッペルゲンガーやライカンスロープのような変身能力を本来持つクリーチャーは、通常通り変身させられるが、1ラウンド後には元の姿に戻れる。倒された場合、たとえアイデンティティを完全に失っていたとしても、変身させられたクリーチャーは自然な姿に戻る。

| :-: | :-: | :-- |
| 1 | 3, +1 EXP | 射程15フィート; 1-5 SIZポイントの違い |
| 2 | 4, +1 EXP | 射程30フィート; 6-10 SIZポイントの違い |
| 3 | 5, +1 EXP | 射程45フィート; 11-15 SIZポイントの違い |
| 4 | 6, +1 EXP | 射程60フィート; 16-20 SIZポイントの違い |
| +1 | +1 | 進行を継続 |

#### Raise Dead \(R\)（死者蘇生）

(死霊)

| | |
| :-- | :-- |
| **ランク:** クレリック3 | **詠唱時間:** 1分 |
| **領域:** 死霊 | **持続時間:** 永久 |

この呪文は、強度レベルにつき24時間以内に死亡したクリーチャーの遺体に詠唱できる。対象の属性が悪以外であれば、対抗意志力判定を行って抵抗し、成功すれば呪文を無効化できる。これは、死者となった魂や精霊が、一度永遠の報酬に達してしまうと、生の世界に戻ることをほとんど望まないからである。受容者がやり残した仕事がある、真実の愛から切り離せない、あるいは生きるべき英雄的な理由がある場合、ゲームマスターは判定を免除できる。

悪の魂の場合、生の世界に戻ることを喜んで希望するが、抵抗するのは死者の意志ではなく、悪魔、デビルなど、彼らの処罰を担当する存在、つまり彼らの責め苦を与える者である。この場合、術者はその存在の意志力を克服しなければならない。これが不明な場合、魂の意志が強いほど、彼らの破滅を担当する存在も強力になることを表すため、死者の意志力より少なくとも20ポイント高いと想定すること。術者が成功すれば精神を肉体に戻したことになるが、ロールに失敗すれば犠牲者は戻ることを望まないか、できないことになる。

詠唱が成功すれば、対象は完全なヒットポイントで生き返るが、切断された四肢は失われたままである。つまり、首をはねられたり半分に切られた犠牲者は、頭や胴体が先につなぎ合わされるまで生き返らせることはできない。これはRaise Deadを詠唱する前に、ヒーラーキットとHealing技能の適用で物理的に再付着させることで行える。通常、明確で決定的な傷跡が残る。毒や病気などの他の不調はRaise Deadの詠唱前または詠唱後に処理しなければならず、そうでなければ結果は一時的なものとなる。最後に、Raise Deadは老衰で死んだ、寿命に達したクリーチャーには影響しない。

| 対象ランク | 対象SIZ | 意志力修正 |
| :-: | :-: | :-: |
| 0-1* | 1-20 | ハード |
| 2 | 21-40 | 標準 |
| 3 | 41-60 | 容易 |
| 4-5 | 61+ | 非常に容易 |

_* このカテゴリにはクラスを持たないキャラクターが含まれる。_

抵抗ロールが失敗すると、犠牲者は即座に殺される。成功ロールはCause Serious Woundsの効果として扱われる。鎧はこのダメージから防御を提供しない。

この呪文は通常、クリーチャーやアイテムを苦しめるあらゆる呪いの効果を取り除く。武器、盾、鎧のようなアイテムの呪われた性質そのものを取り除くわけではないが、そのようなアイテムに悩まされるクリーチャーがそれを取り除くことを可能にする。呪いの中には、特定の強度で唱えられた場合にのみ解除できるものもあり、これは通常、特定の記述に記されている。 lycanthropy（ライカンスロープ）を治すにはCure DiseaseまたはRemove Curseのいずれかを使用でき、どちらも強度12が必要である。

この呪文の逆であるBestow Curse（呪い付与）は、持続時間30分/強度で敵に以下の効果のいずれかを与える。 victim（犠牲者）は抵抗するために通常通り対抗Willpowerロールを行うことが許可される。 inflicte（与えられた）呪いの性質を決定するには1d100をロールすること：

- 01-25: STR、DEX、またはCONを使用するすべての技能が1段階難しくなる。イニシアチブ-4、ダメージ修正が2段階軽減。
- 26-50: INT、POW、またはCHAを使用するすべての技能が1段階難しくなる。イニシアチブ-4。
- 51-75: 戦闘技能と抵抗ロールが2段階難しくなる。
- 76-00: すべての失敗した技能ロールがファンブルとして扱われる。

#### Restoration（回復）

(死霊)

| | |
| :-- | :-- |
| **ランク:** クレリック3 | **詠唱時間:** 3分 |
| **領域:** 治癒 | **持続時間:** 永久 |
| **コスト:** 3, +1/追加強度 | **射程:** 接触 |

詠唱すると、Energy Drainや同様の効果によって以前に生命力を奪われた犠牲者は、以前に失われた疲労レベルを1レベル回復する。強度1レベルでは、この呪文は過去24時間以内に消耗したクリーチャーに対してのみ機能する。強度が増すごとに、経過できる時間はさらに24時間増加する。例えば、48時間弱前に消耗した犠牲者は、効果を得るために強度2で詠唱する必要がある。消耗した疲労の複数のレベルには、追加のRestorationの詠唱が必要である。持続時間とは無関係に、疲労回復に加えて、怪我やあらゆる形の精神疾患や痴呆によって失われた知的能力もすべて回復する。Restorationは、特定の呪文による人工的な老化によって失われた年数を取り除くためにも使用できる。その場合、通常の詠唱コストに加え、クレリックは受容者の典型的な寿命の1%が回復するごとに1 EXPロールを消費しなければならない（人間なら1年）。この呪文は、対象の現在の年齢を実際の年齢より低くすることはできない。

#### Resurrection \(R\)（蘇生）

(死霊)

| | |
| :-- | :-- |
| **ランク:** クレリック5 | **詠唱時間:** 10分 |
| **領域:** 死霊 | **持続時間:** 永久 |
| **コスト:** 3, +1/追加強度, +2 EXP | **射程:** 接触 |
| **範囲:** 対象1体 | **抵抗:** なし (意志力) |

Resurrectionは、強度レベルにつき20年以内に死亡したあらゆるクリーチャーを生き返らせる。クリーチャーは生き返るだけでなく、体力も完全に戻り、負傷からも回復し、失われた手足さえも修復される。呪文が効果的であるためには、クリーチャーがほとんど残っていなくても問題ない。例えば、強度が8で詠唱されれば、指の骨一つしか残っていなくても、145年後に死者を生き返らせることができる。生き返った個人は休息の期間を必要とせず、即座に完全に機能する。この呪文は、寿命が尽きて自然死したクリーチャーには効果がない。

対象の属性が悪以外であれば、対抗意志力判定を行って抵抗し、成功すれば呪文を無効化できる。これは死者となった魂や精霊が、一度永遠の報酬に達してしまうと、生の世界に戻ることをほとんど望まないからである。ただし、受容者がやり残した仕事がある、真実の愛から切り離せない、あるいは生きるべき英雄的な理由がある場合、ゲームマスターは判定を免除できる。悪の魂の場合、戻ることを喜んで希望するが、抵抗するのは死者の意志ではなく、彼らの責め苦を与える者である。術者が成功すれば復活できたことになるが、ロールに失敗すれば victim（犠牲者）は戻ることを望まないか、できないことになる。

Resurrectionは消耗が激しく、クレリックの典型的な寿命の3%（人間の術者の場合は3年）を老けさせる。[老化](0007_Game_System.md?id=aging)ルールを参照のこと。

逆に、Destruction（破壊）は、詠唱時に接触している1人の犠牲者を殺すために使用できる。この犠牲者はWillpowerロールを行って抵抗が許可され、ターゲットのランクまたはSIZ（いずれかターゲットにとってより有利な結果をもたらす方）によって変更される。

| 対象ランク | 対象SIZ | 意志力修正 |
| :-: | :-: | :-- |
| 0-1* | 1-20 | 困難 |
| 2 | 21-40 | ハード |
| 3 | 41-60 | 標準 |
| 4 | 61-80 | 容易 |
| 5 | 81+ | 非常に容易 |

_* このカテゴリにはクラスを持たないキャラクターが含まれる。_

この抵抗ロールが失敗すると、対象は即座に殺され、その体は塵になる。この段階ではWishの詠唱のみが犠牲者を取り戻せる。成功ロールの場合、対象は接触されたヒットロケーションでマイナス1d4ヒットポイントに減少するだけである。鎧はこのダメージから防御を提供しない。Destructionは使用時に術者を老けさせない。

#### Sleep（睡眠）

(妖術（魅了）)

| | |
| :-- | :-- |
| **ランク:** メイジ1 | **詠唱時間:** 1アクション |
| **領域:** なし | **持続時間:** 5分/強度 |
| **コスト:** 3, +1/追加強度 | **射程:** 60フィート |
| **範囲:** 半径10フィート | **抵抗:** 意志力 |

この呪文は、半径10フィートの円形エリア内の強度レベルにつき1体の生きているクリーチャーに魔法の眠りを誘う。呪文の効果範囲は空間または地面の一点に中心が置かれ、最も近いクリーチャーが最初に抵抗し、次に近いクリーチャーが順に抵抗する。同距離に2体以上がいる場合、誰が影響を受けるかをランダムに決定すること。各クリーチャーには抵抗ロールが許可され、成功した場合、合計で呪文の強度に等しい数のクリーチャーが影響を受けるか、効果範囲内にクリーチャーがいなくなるまで、別のクリーチャーが試さなければならない。警戒状態、または詠唱時に戦闘中のクリーチャーは抵抗判定が1段階容易になる。

| 4 | 6 | 20分持続; 4体 |

#### Slow Poison（毒遅延）

(死霊)

| | |
| :-- | :-- |
| **ランク:** クレリック1 | **詠唱時間:** 1アクション |
| **領域:** 治癒 | **持続時間:** 1時間/強度 |
| **コスト:** 3, +1/追加強度 | **射程:** 接触 |
| **範囲:** 対象1体 | **抵抗:** なし |

この呪文により、術者は毒や毒素の効果を遅らせることができる。ただし、毒素自体を無効化するわけではない。その代わりに、体内に広がる毒素を十分に遅らせることで、追加の治療措置が見つかるかもしれない。毒素の発症時間は呪文の持続時間が経過するまで始まらない。

例えば、コブラの毒の発症時間は以下の通りである：1d6+4分後に苦悶し、1d6+6時間後に窒息する。したがって、1強度分のSlow Poisonは発症時間を1時間先送りし、その後、通常通り1d6+4分後に苦悶が始まる。

Slow Poisonが症状が出てから犠牲者に唱えられた場合、症状は呪文の持続時間が経過するまで停止し、その後通常通り進行する。

最後の手段として、術者が毒で「死んで」から10分以内の個人に到達できれば、Slow Poisonは1強度につき1時間犠牲者の死を遅らせる。その間、犠牲者は昏睡状態のままである。この間に毒が治療できれば、犠牲者は生き延び、応急処置や魔法の治癒によって復活できる可能性がある。

#### Wall of Fire/Circle of Fire（炎の壁/円）

(召喚)

| | |
| :-- | :-- |
| **ランク:** クレリック3、メイジ3 | **詠唱時間:** 2アクション |

この呪文により、術者は詠唱時に望むように、紫または赤みがかった青色の燃え盛る炎の壁または円を召喚できる。呪文の持続時間は集中が維持されている間、あるいは集中が切れた後に強度1ラウンドにつき1ラウンド維持される。詳細は以下の通り：

**Wall of Fire:** この呪文のバージョンは強度につき長さ20フィートの静止した炎の壁を作る。最終的な強度に関係なく、壁は詠唱時に望む通り10〜20フィートの高さを持つ。Wall of Fireの射程は180フィートであり、水平に召喚することはできない。

Wishは現実を永続的かつ著しく変化させる。この呪文を詠唱するには、メイジは3マジックポイントと、希望する結果に応じて1つ以上のEXPロールを費やさなければならない。1ヶ月以内にWishを連続詠唱すると、必要なEXPの支出が通常倍になる。詠唱時間は通常、願いの具体的な内容を言葉で説明するために必要となる。完了すると、術者はEXP消費量に等しい疲労を失い、通常の寿命の5%（人間の場合は5年）を老けさせる。[老化](0007_Game_System.md?id=aging)を参照のこと。

Wishの結果は文字通りに解釈されるべきであり、ゲームマスターの解釈に委ねられる。貪欲な願いは通常、悪い結果をもたらす。貪欲な意図で行われたWishが裏目に出る確率は10%である。例えば、富を願うと、地元の領主や王の宝物庫からテレポートされる可能性がある。Wishは、そのような存在がそのWishを発行しない限り、神のような存在の命令をキャンセルすることはできない。
