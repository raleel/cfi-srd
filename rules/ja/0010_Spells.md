#### Appraise (鑑定)

(占い)

| | |
| :-- | :-- |
| **等級:** メイジ 0 | **詠唱時間:** 1ターン |
| **スフィア:** なし | **持続時間:** 即時 |
| **コスト:** 1 | **射程:** 接触 |
| **効果範囲:** 1アイテム | **抵抗:** なし |

鑑定は、術者の霊力(霊力)に等しい体格(体格)を持つ、または「Things」のENCを合計した物理的商品の品質を即座に評価することを可能にする。この呪文は、見た目が同一のアイテムが同等か類似の品質であるか、あるいは一つ以上が欠陥品かより高品質であるかを特定する。この呪文は有機物には作用せず、無生物の物体にのみ働く。また、存在する欠陥や強化の内容を特定するわけではなく、それらが存在することを確認するだけである。魔法の識別や検知には何の役にも立たない。

#### 防具 (防護の鎧)

(召喚)

| | |
| :-- | :-- |
| **等級:** メイジ 1 | **詠唱時間:** 1ラウンド |
| **スフィア:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 +1/強度 | **射程:** 接触 |
| **効果範囲:** 1対象 | **抵抗:** なし |

この呪文が唱えられると、対象には鱗の鎧と同等の守護を持つ目に見えない魔法の力場が与えられ、各部位判定に4の防護点が付与される。すでに防具を着用している者に唱えても効果はない。ただし、持続期間中であれば、より優れた防護を提供する限り、自然の装甲に取って代わる。4点を超える自然の装甲を持つクリーチャーに唱えた場合、代わりに全部位の防護点が1上昇する。この魔法の防護は移動や呪文の詠唱を妨げない。呪文は魔法によって解除されるか、術者が一度の攻撃で8点のダメージ（強度レベルごとに+1、下記表を参照）を受けるまで持続する。もちろん、術者が望めばいつでも呪文を解除することができ、睡眠をとるためには解除しなければならない。

| 強度 | コスト | 変動効果 |
| :-: | :-: | :-- |
| 1 | 3 | 4防護点。一度の攻撃で8ダメージを受けるまで持続 |
| 2 | 4 | 4防護点。一度の攻撃で9ダメージを受けるまで持続 |
| 3 | 5 | 4防護点。一度の攻撃で10ダメージを受けるまで持続 |
| 4 | 6 | 4防護点。一度の攻撃で11ダメージを受けるまで持続 |
| +1 | +1 | 進行を継続 |

#### Astral Spell (アストラル呪文)

(変容)

| | |
| :-- | :-- |
| **等級:** クレリック 5, メイジ 5 | **詠唱時間:** 2アクション |
| **スフィア:** アストラル | **持続時間:** 下記参照 |
| **コスト:** 3 +1/追加の強度 | **射程:** 接触 |
| **効果範囲:** 下記参照 | **抵抗:** 該当なし |

この呪文は、術者と最大5名（追加の強度レベルごとに1名）がアストラル界に進入することを可能にする。詠唱中、全員が接触して輪を作る必要がある。旅人の肉体は元の次元に置き去りにされ、魔法のオーラを放つもの以外、通常はいかなる衣服や装備も持ち込むことはできない。これらのアイテムは通常形態のアストラル版へと変換される。持続時間は術者が停止を望むまで続く。しかし、ディスペル・マジックのような外部の力によって早めに終了させられる可能性はある。術者の肉体を殺害することでも呪文は早期に終了するが、これには術者に同行している旅人を孤立させてしまうという不幸な副作用がある。

#### Augury (予兆)

(占い)

| | |
| :-- | :-- |
| **等級:** クレリック 2 | **詠唱時間:** 2分 |
| **スフィア:** 占い | **持続時間:** 即時 |
| **コスト:** 3/強度 | **射程:** 60フィート |
| **効果範囲:** 術者 | **抵抗:** 該当なし |

この呪文は、今後30分以内に行われる特定の行動が、個人やパーティの福利にとって有益か有害かを術者が判断することを可能にする。兆しを見極めるための何らかの焦点（フォーカス）が必要であり、最も一般的なものはドラゴンの爪や小さな骨、真珠、あるいは100GP以上の価値がある粉砕または溶解された純金である。この呪文の最大強度は4である。結果が正しく解釈されたかどうかを術者が確信を持って知ることは決してないため、この判定はゲームマスターが行うべきである。

| 強度 | コスト | 変動効果 |
| :-: | :-: | :-- |
| 1 | 3 | 至難の「交信」技能ロール |
| 2 | 6 | 困難な「交信」技能ロール |
| 3 | 9 | 標準の「交信」技能ロール |
| 4 | 12 | 簡単な「交信」技能ロール |

交信ロールが成功した場合、以下のいずれかの結果が得られる。

| 予兆 | 意味 | 
| :-: | :-- |
| はい | 行動は有益である |
| いいえ | 行動は有害である |
| はいといいえ | 行動は有益でもあり有害でもある |
| 何もなし | 行動は有益でも有害でもない |

ファンブルが発生した場合は、ゲームマスターは現実とは逆の結果を告げるべきである。

#### Befuddle (困惑)

(魔法（魅了）)

| | |
| :-- | :-- |
| **等級:** クレリック 0, メイジ 0 | **詠唱時間:** 1ターン |
| **スフィア:** 魅了 | **持続時間:** 30分 |
| **コスト:** 1 | **射程:** 60フィート |
| **効果範囲:** 1対象 | **抵抗:** 意志力 |

Befuddleは実体を持つ対象の精神に混乱を引き起こす。呪文の対象は論理的な思考が困難になり、場所や現在行っていること、理由を忘れてしまい、しばしば支離滅裂な思考状態に陥る。困惑した対象は自己防衛のための行動はとれるが、呪文が終了するまで建設的な活動を開始することはできない。攻撃や威嚇行動をとると、それが困惑した対象に向けられたかどうかにかかわらず、即座に呪文が解除される。

#### Blade Barrier (刃の障壁)

(召喚)

| | |
| :-- | :-- |
| **等級:** クレリック 4 | **詠唱時間:** 2アクション |
| **スフィア:** 守護、創造 | **持続時間:** 3ラウンド/強度 |
| **コスト:** 3+1/追加の強度 | **射程:** 100フィート |
| **効果範囲:** 半径5-30フィート | **抵抗:** 下記参照 |

この呪文は、固定された点の周囲を猛烈に回転・切り裂く剣や短剣、ナイフの障壁を作り出し、効果範囲を通過する「すべての者」の1d4+2のランダムな部位判定に1d8のダメージを与える。防具はその通常防護の半分しか提供しない。魔法防護点は通常通りダメージを軽減する。武器が目にも止まらぬ速さで回転し密集しているため、それらを「回避」や「パリィ」することは不可能である。盾を使用して、通常通り部位判定をパッシブにブロックすることは可能である。その場合、ロールされたダメージと盾の防護点およびヒットポイントを比較することを忘れないこと。

この呪文は、クレリックや一人または複数の味方を守るために防御的に唱えることも、敵を罠に嵌めるために攻撃的に唱えることもできる。ただし、障壁が形成される際にその端から5フィート以内にいる敵は、回避ロールを行って脱出することができる。成功かどうかにかかわらず、相手は効果範囲のすぐ外で転倒した状態で終了する。ロールが成功すればダメージは受けないが、そうでなければ完全な効果を受ける。

#### Bless \(R\) (祝福)

(召喚)

| | |
| :-- | :-- |
| **等級:** クレリック 1 | **詠唱時間:** 1ラウンド |
| **スフィア:** 全て | **持続時間:** 5分 |
| **コスト:** 1 | **射程:** 180フィート |
| **効果範囲:** 半径25フィート | **抵抗:** 意志力 |

この呪文が唱えられると、クレリックは効果範囲内の味方グループを祝福する。影響を受けた者は術者のアライメントである善または悪のいずれかを放つ。中立の祝福は存在しない。呪文の半径内にいるすべての味方は、全ての技能および抵抗ロールに+5%のボーナスを受ける。さらに、その武器は知性あるアンデッドや、悪魔、デビル、天使といった術者と相反するアライメントを持つ外界のクリーチャーに対して、追加で1d3のダメージを与える。スケルトンやゾンビのようなアニメーション化したアンデッドは本来的に悪ではないが、通常は邪悪な魔法で動かされているため、このダメージの対象となることに注意すること。

この呪文の逆である「呪い」は、クレリックが敵を呪うことを可能にし、前述の技能にボーナスの逆となるペナルティを課す。呪われた武器のダメージはペナルティとして計算され、このダメージは最低でも1点未満にはならない。

この呪文は、術者の手から120度の弧を描いて炎を噴射させる。戦闘でミニチュアを使用している場合、Burning Handsは術者の正面のマスを1つ占めるすべての対象にダメージを与える。高い強度レベルでBurning Handsを詠唱するには、より高い等級のメイジが必要である。このダメージは、強度が最大9までの範囲に基づき、範囲内の全ての対象を焼き払う。以下の表を参照のこと。回避ロールに成功し、身を伏せることで、犠牲者はダメージを受けない。「Artful Dodger（巧みな回避）」アビリティを持つ者は、伏せずに回避する選択肢を持つ。

| 強度 | コスト | 最低等級 | 変動効果 |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 全部位判定に1d3+1ダメージ |
| 3 | 4 | 1 | 全部位判定に1d3+2ダメージ |
| 5 | 5 | 1 | 全部位判定に1d3+3ダメージ |

| 9 | 7 | 3 | 全部位判定に1d3+5ダメージ |

着用している防具は保護にならないが、魔法防護点やクリーチャーの自然の装甲は通常通りダメージを軽減する。この強力な呪文は、射程が非常に短いという欠点があり、詠唱するには非常に不利な位置に近づかなければならないことを意味する。

より大型のクリーチャーは通常、この呪文の効果範囲よりも大きいため、ダメージを受ける部位判定の数が少なくなる。体格 21から30の対象は頭部、胸部、腹部、腕部にダメージを受け、体格 31以上の対象は腹部と脚部にダメージを受ける。ゲームマスターは対象の形状や術者との相対位置に応じてこれらの部位を調整すること。Burning Handsはロールしたダメージ×5%の確率で可燃物に引火する可能性がある。追加情報については[火災](0007_Game_System.md?id=fire-based-attacks)のセクションを参照のこと。

#### 命令 (Command)

(Enchantment (Charm))

| | |
| :-- | :-- |
| **ランク:** 僧侶 1 | **詠唱時間:** 1 行動ポイント |
| **領域:** 説得 | **持続時間:** 1 分 |
| **コスト:** 3 | **射程:** 100フィート |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

この呪文を詠唱すると、僧侶は生きているクリーチャー（体格1-20）1体に対して単語1つで命令を下すことができる。対象が抵抗に失敗した場合、次のターンにその命令を文字通りに実行する。これにより、被害者は次のターンを命令された行動の完了に費やし、その行動中にアクションポイントを浪費することになる。被害者のアクションポイントが残っていない場合、次のラウンドの最初のターン中に行動が実行される。命令そのものは対象に直接的な傷を与えることはできないが、副次的効果として傷を負う可能性はある。

例えば、「死ね」という命令は被害者を1ラウンドの間、仮死状態で崩れ落ちさせるだけであり、直接的なダメージは与えない。しかし、高さ100フィートの崖を登っているクリーチャーに対して「落ちろ」と命じれば、それは致命的な結果になり得る。

命令の対象は術者の話す言語を理解できなければならず、抵抗するために意志力テストを行うことができる。

**命令の例**

- **這え:** 対象は伏せ状態になり、這い始める。
- **死ね:** 対象は伏せ状態になり、仮死状態になる。
- **倒れろ:** 対象は伏せ状態になる。
- **失敗しろ:** 対象は実行しようとしている身体的行動にファンブルする。
- **眠れ:** 対象は居眠りを始める。
- **逃げろ:** 対象は向きを変え、術者から逃げる。
- **飛べ:** 対象は腕を羽ばたかせ、円を描いて走り回る。
- **進め:** 対象は向いていた方向に歩き始める。
- **止まれ:** 対象はその場で直ちに停止し立ち尽くす。
- **去れ:** 対象は向きを変え、来た道から立ち去る。
- **休め:** 対象は座り込み、呼吸を整える。
- **走れ:** 対象は走り始める。
- **叫べ:** 対象は怒鳴り声を上げる。
- **沈め:** 対象は水泳を止める。
- **降伏しろ:** 対象は武器を捨て、敵対行動を停止する。

#### アイテム付与 (Enchant Item)

(付与)

| | |
| :-- | :-- |
| **階級:** メイジ4 | **詠唱時間:** 下記参照 |
| **球体:** なし | **持続時間:** 下記参照 |
| **コスト:** 3 + 下記参照 | **射程:** 接触 |
| **範囲:** 1アイテム | **抵抗:** なし |

この呪文の詠唱は、アイテムを付与するために準備するものである。対象は良好な状態であり、最高級の構造と出来栄えでなければならない。追加の工具、彫刻、刺繍、宝石の埋め込み、彫金などの費用を賄うために、少なくとも100GPの追加コストが必要となる。最後に、付与のプロセスには実験室または工房が必要である。

呪文を唱えている間、魔法使いは詠唱時間（1d8+2日）の間ずっとアイテムに触れていなければならない。これには休息や睡眠の期間も含まれるが、その間アイテムは術者の腕の届く範囲に留まらなければならない。詠唱中、魔法使いは他の呪文を唱えたり、他の形態の魔法を行使したりしてはならない。これらの制約を破ると自動的に呪文は失敗する。

成功するとアイテムは最終段階の準備が整い、術者は目的の呪文をアイテムに込める。そのためには、その呪文を記憶しているか、スクロールを所持しており、24時間以内にアイテムに唱えなければならない。さもなくば最初からやり直しとなる。選んだ呪文の詠唱が始まれば、前述の24時間を超えてもよい。アイテムに呪文を込めるコストは、目的の強度に応じた通常のマジックポイント消費量で、呪文階級ごとに1d12時間を要する。込めている最中、術者はアイテムに触れているか、前述の休息期間中も腕の届く範囲内にいなければならず、詠唱期間の終わりに呪文を成功させるために「秘術詠唱（Arcane Casting）」判定が必要となる。通常の呪文詠唱の成功度に従うが、失敗した場合、呪文を強制的に込めることはできない。前の呪文が完了してから24時間以内に詠唱プロセスを開始すれば、アイテムに連続して別の呪文を込めることができる。これは以前に失敗した呪文の場合でも同様である。後続の呪文はそれぞれ通常の詠唱コストを必要とする。

アイテムを使用する際、含まれている各呪文は一度しか唱えられないが、上記の手順に従って同じ呪文を複数回分込めることも可能である。また、単一の呪文を込めた後、階級4の「永続化（Permanency）」を唱えることもできる。この場合、「永続化」の呪文説明に記載された制約に従い、望むだけ何度でも呪文を唱えることができる。

特定の呪文に準拠しない他の魔法効果をアイテムに込めることは不可能であり、遠い過去の多くの魔法アイテムは現代において再現することができない。

通常の武器に触れながらこの呪文を唱えると、その武器に一時的な付与が行われ、魔法の+1ダメージ修正が与えられる。これにより、+1以上の付与が施された武器でなければ害を与えられないクリーチャーに対して、通常の武器でも攻撃が可能になる。この呪文は、短剣、ナイフ、矢など、サイズがそれぞれ1/2「物（Thing）」単位に相当する武器2本を付与するために使用できる。それ以外の場合、1回の詠唱で1つの武器しか付与できない。既存の魔法武器のボーナスは、最大合計+3まで+1ずつ増加させることができる。+3ボーナスの武器は、ダメージを算出する目的でサイズが1段階増加する（大型→巨大、巨大→膨大、膨大→超巨大）。付与された武器は、そのタイプの武器について付与+1ごとに防具値+5、ヒットポイント+2を持つ。この呪文は、「アイテム付与」および「永続化」と組み合わせて、永続的な付与を持つ武器を作成することができる。

#### フェザーフォール (Feather Fall)

(変容)

| | |

鳥やドラゴンのような飛行クリーチャーにこの呪文を唱えると、その飛行特性が変化し、空中に留まりたい場合は呪文の持続時間中、毎ラウンド「困難」な飛行判定が必要となる。成功すれば、クリーチャーは望むように移動できるが、通常の移動速度の半分でしか移動できず、判定に失敗するとクリーチャーの試みは制御を失い、意図した移動速度に等しい距離だけランダムな方向に優しく転げ落ちる。単に落下を許容する場合、飛行クリーチャーは翼を使用して着地点を1ラウンドにつき5フィート調整できる。

#### 使い魔召喚 (Find Familiar)

(召喚)

| | |

| **コスト:** 3/強度、+1経験値 | **射程:** 0 |

この呪文は、術者の感覚と力の延長となる「使い魔」を召喚する試みを可能にする。使い魔は主人とテレパシーで会話でき、優れた見張りや斥候にもなる。使い魔が殺されると、その密接な繋がりゆえに魔法使いには一定のリスクが生じるため、使い魔を持つことは低ランクの危険性を伴う。

使い魔を召喚するには、魔法使いは木炭で火を焚いた火鉢を維持しながら儀式を開始し、火力が強まったら100GP相当の香を投じる必要がある。これらの材料が燃えている間、術者は使い魔が到着するか、成功しないまま詠唱時間が経過するまで儀式を続けなければならない。

この呪文が正常に唱えられたとしても、適切な使い魔が呼びかけに応じる確率はわずか50%であり、魔法使いはこの呪文を1年に一度しか試すことができない。最初のレベルを超える強度ごとに、呪文の範囲が0.5マイルずつ広がり、それによって使い魔が見つかる可能性が5%ずつ増加し、最大95%まで上がる。呼びかけに応じるクリーチャーの正確なタイプを制御することはできないが、到着したものは忠実な僕であり同盟者となる。呼びかけに応じるかどうかは特定のクリーチャー次第であるため、特定のクリーチャーが生息していることで知られる地域にいたとしても、術者の成功は保証されない。

#### ファイア・シールド

(力術)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **詠唱時間:** 2 アクション |
| **領域:** なし | **持続時間:** 2分/強度 |
| **コスト:** 3 + 1/追加強度 | **射程:** 0 |
| **範囲:** 術者自身 | **抵抗:** 該当なし |

この呪文は術者を焼くような薄い炎の盾を作り出すが、それ自体は術者にダメージを与えない。代わりに、この炎は「チル・シールド（青または緑の炎で、熱や火炎系のダメージを防ぐ）」か「ウォーム・シールド（紫または青の炎で、冷気や氷系のダメージを防ぐ）」のどちらか一方を記憶した内容に従い、対象を火または冷気から守る。炎の色は50%の確率でランダムに決定されるべきである。両方のタイプが青い炎を発することから、攻撃者にとっては不確実な要素が生じる。どちらを記憶するかは呪文準備時に決定され、望むなら両方を記憶することもできる。これらの炎は熱を発せず、松明の半分の明るさでしか光を放たない。各バリエーションの詳細は以下の通りである。

- **チル・シールド:** この炎は触れると冷たく、火または熱系のあらゆるダメージを合計の半分に軽減する。抵抗ロールの成功により、すべてのダメージを無効化する。抵抗ロールは難易度が1段階簡単になり、回避の場合、防御者は伏せ状態にならない。
- **ウォーム・シールド:** この炎は触れると温かく、あらゆる冷気系のダメージを合計の半分に軽減する。抵抗ロールの成功により、すべてのダメージを無効化する。抵抗ロールは難易度が1段階簡単になり、回避の場合、防御者は伏せ状態にならない。

このいずれかのバリエーションの対象に対する近接攻撃（徒手または武器使用を問わず）は、対象が防御している属性を使用しない限り、通常ダメージを与える。この場合、術者は攻撃の属性部分から保護され、攻撃者は自身が与えたのと同等のダメージを受ける。攻撃者が着用している防具は保護を提供しないが、魔法的な防具やクリーチャーの自然防具は通常通りダメージを軽減する。先天的魔法抵抗を持つクリーチャーは、対象が最初に攻撃を受けた際に意志力ロールに成功すれば、ファイア・シールドを打ち消すことができる。魔法抵抗ロールが失敗した場合、相手は後にファイア・シールドを無効化することはできない。

#### フレーム・ストライク

(力術)

| | |
| :-- | :-- |
| **階級:** クレリック 2 | **詠唱時間:** 2 アクション |
| **領域:** 戦闘、元素（火） | **持続時間:** 即時 |
| **コスト:** 3 + 1/追加強度 | **射程:** 100フィート + 20フィート/追加強度 |
| **範囲:** 半径5フィート | **抵抗:** 回避 |

詠唱に成功すると、高さ30フィートの炎の柱が上方から降り注ぎ、クレリックが指定した範囲を焼き払う。この柱は範囲内の全ての対象に、強度2ポイントにつき1d8ポイント（端数切り上げ）のダメージを与える。ダメージを一度だけダイスロールし、対象の各部位判定に適用する。着用している防具は半分の保護を提供するが、魔法的な防具やクリーチャーの自然防具は通常通りダメージを軽減する。回避判定に成功して範囲外へ転がり出るか身を投げ出し、伏せ状態で止まった場合、犠牲者はダメージを受けない。「巧妙な避難」のアビリティを持つ者は、伏せずに回避でき、範囲のすぐ外側へ自由に移動することができる。

フレーム・ストライクには、ダイスロールしたダメージ×5%の確率で可燃物に引火する可能性がある。追加情報については[火災](0007_Game_System.md?id=fire-based-attacks)のセクションを参照のこと。

| :-: | :-: | :-- |
| 1 | 3 | 射程100フィート、ダメージ1d8 |
| 2 | 4 | 射程120フィート、ダメージ1d8 |
| 3 | 5 | 射程140フィート、ダメージ2d8 |
| 4 | 6 | 射程160フィート、ダメージ2d8 |
| 5 | 7 | 射程180フィート、ダメージ3d8 |
| +1 | +1 | 進行を継続 |

#### フレッシュ・トゥ・ストーン \(R\)

(変成)

| | |
| :-- | :-- |
| **階級:** メイジ 4 | **詠唱時間:** 2 アクション |
| **領域:** なし | **持続時間:** 永続 |
| **コスト:** 3/強度 | **射程:** 30フィート/強度 |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

詠唱すると、射程内の犠牲者1体に対し、意志力による抵抗ロールが許される。失敗した場合、その人物と、持ち運びや着用している全ての所有物が完全に固い石へと変化する。この変化は死ではなく、一種の仮死状態である。この呪文の逆バージョン、または「ウィッシュ（願い）」の詠唱により、犠牲者を再び生き返らせることができる。石の状態の間に犠牲者が受けたダメージは持ち越され、復元された瞬間に適用される。大型のクリーチャー（体格21～40）はこの呪文の影響を受けにくく、抵抗ロールは「簡単」になり、巨大なクリーチャー（体格41以上）の抵抗ロールは「非常に簡単」になる。

この呪文の逆である「ストーン・トゥ・フレッシュ（石から肉へ）」は、犠牲者を元に戻すために使用され、抵抗ロールは必要ない。しかし、この呪文は、かつて生命を持ったことのない石を変化させるために逆にすることもでき、いくつかの創造的な方法で使用可能である。例えば、強度レベルにつき10立方フィートの石壁を柔らかい肉に変えたり、幅3フィート、長さ強度×10フィートの肉の「トンネル」を作り出したり、石像のような単一の対象を肉体に変えたり、この呪文によって石のゴーレムを肉のゴーレムに変えることさえできる。ただし、後者の場合、石のゴーレムは通常通り意志力ロールによる抵抗が許される。このようにして石から肉に変えられたものは柔らかくしなやかであり、本来のヒットポイントを保持しているものの、防具点を持たないため、切り裂くのが容易になる。

#### フローティング・ディスク

(召喚)

| | |

魔法使いはこの呪文を詠唱し、直径3フィートの円形に集中させた力の揺らめく円盤を作り出し、ばらばらの雑多なアイテムを運搬するために使用できる。このフローティング・ディスクは常に地面から3フィート上に留まり、強度1につき20「物」を超えず、円盤に乗るサイズであればいくつでも物品を運べる。比較として、体格1を3「物」とみなす。したがって、円盤は強度1につき6体格強を運搬できる。円盤の凹面は一般的にアイテムが転がり落ちるのを防ぎ、指示がなければ、ディスクは術者から5フィート以内に留まり、移動速度15フィートで追随する。しかし、魔法使いが精神集中すれば、ディスクは呪文の射程である60フィート以内の任意の地点へ操作でき、特定の場所に留まるよう命じることも可能である。魔法使いがディスクを60フィート以上離れるままにすると、ディスクは消滅し、運搬していた全てのアイテムが地面に落ちる。ディスクは地面から3フィート以上上昇するように命じることはできない。

#### フリー・アクション

(防御、付与)

| | |
| :-- | :-- |
| **階級:** クレリック 3 | **詠唱時間:** 2 アクション |
| **領域:** 魅力 | **持続時間:** 10分/強度 |
| **コスト:** 3 + 1/追加強度 | **射程:** 接触 |
| **範囲:** 対象1体 | **抵抗:** 該当なし |

詠唱すると、この呪文は対象が持続時間中、移動を妨げたり攻撃を制限したりする他の呪文や効果に関係なく、通常通りに行動することを可能にする。これには、泥や雪のような妨害的な地形からのペナルティを無効化することも含まれる。水中で、対象は通常の陸上移動速度で移動でき、振り回す武器（剣、斧、棍棒、メイスなど）は完全な効果で攻撃できる。ただし、この呪文は水中で呼吸する能力を与えない。この呪文は、エンタングル、スロー、ホールド、麻痺、ウェブなど、移動や行動ペナルティに関する妨害呪文を無効化する。

#### フロストバイト

(変成)

| | |
| :-- | :-- |
| **階級:** メイジ 0 | **詠唱時間:** 1 アクション |
| **領域:** なし | **持続時間:** 即時 |
| **コスト:** 1 | **射程:** 60フィート |
| **範囲:** 対象1体 | **抵抗:** 持久力 |

フロストバイトは生きた有機組織に直接働きかけ、対象の四肢（例えば指、つま先、臀部、鼻、耳など）に痺れと痛みを与える。術者は特定の四肢に接触するか、射程内で詠唱する場合はランダムにロールしなければならない。呪文が抵抗されなかった場合、影響を受けた部位は感覚の麻痺とそれに続く持続的な痛みを持続時間中経験し、その部位を利用する技能判定の難易度が1段階上昇する。フロストバイトは直接的なダメージを与えないが、影響を受けた部位をしばらくの間制限する。例えば、臀部に凍傷を負った犠牲者は、極度の不快感なしに座ることができない。

大型のクリーチャー（体格21～40）はこの呪文の影響を受けにくく、抵抗ロールは「簡単」になり、巨大なクリーチャー（体格41以上）の抵抗ロールは「非常に簡単」になる。

#### ファンブル

(付与（魅力）)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **詠唱時間:** 2 アクション |
| **領域:** なし | **持続時間:** 1ラウンド/強度 |
| **コスト:** 3 + 1/追加強度 | **射程:** 30フィート/強度 |
| **範囲:** 半径10フィート | **抵抗:** 意志力 |

この呪文は、範囲内の全ての相手を不器用にさせる。あらゆる物理技能ロールは難易度が1段階上昇し、全ての失敗がファンブルとして扱われる。落としたアイテムを拾う、歩くよりも速く移動する、階段を上るなど、通常は技能ロールを必要としない物理的な行動でさえ、運動技能ロールが必要となる。この場合の失敗はファンブルとなり、移動の場合は不格好な転倒を、拾おうとしてアイテムをさらに遠くへ蹴飛ばしてしまうといった結果を招く。ゲームマスターはファンブルの結果に対して創造的であるべきだが、非戦闘時には致命的なものはほとんどないはずである。しかし戦闘中、ファンブルは通常通りに扱われ、通常通り特殊効果をもたらす可能性がある。

抵抗ロールに成功すれば、犠牲者は現在のラウンドの間、この呪文の影響を避けることができる。しかし、次のラウンドで犠牲者がまだ範囲内に留まっている場合、通常通り再び抵抗ロールを行わなければならない。元の攻撃者の味方も範囲外に留まらない限り、敵と同じ制限を受けることになる。

この呪文は特定のクリーチャーを対象にすることもでき、抵抗ロールに失敗した場合、呪文の持続時間全体にわたってその影響を受ける。このように詠唱された場合、ファンブルは範囲を生じさせない。この場合、抵抗ロールに成功すると、犠牲者はランク2の呪文「スロー」の影響を受ける。

| :-: | :-: | :-- |
| 1 | 3 | 1ラウンド、射程30フィート |
| 2 | 4 | 2ラウンド、射程60フィート |
| 3 | 5 | 3ラウンド、射程90フィート |
| 4 | 6 | 4ラウンド、射程120フィート |
| +1 | +1 | 進行を継続 |

#### ゲート

(召喚)

| | |
| :-- | :-- |
| **階級:** クレリック 5、メイジ 5 | **詠唱時間:** 2ラウンド |
| **領域:** 召喚 | **持続時間:** 下記参照 |
| **コスト:** 3 + 1/強度、+3経験値 | **射程:** 100フィート |
| **範囲:** 下記参照 | **抵抗:** 意志力 |

ゲートの詠唱には、召喚する存在の真名を知る必要がある。これは通常、デーモンやデビル、天使、半神、あるいは神のような、他の次元の存在である。成功して詠唱されると、術者のいる次元と存在がいる次元との間にポータルが開く。呪文を詠唱すると、成功・失敗にかかわらず、自動的にその存在の注意を引く。この呪文は非常に強力で体力を消耗させるものであり、術者に記された3マジックポイントと3経験値ロールだけでなく、典型的な寿命の5%（人間の術者の場合5年）の年齢を与える。その存在が抵抗ロールに成功した場合、通常は直接現れることはないが、呪文が成功したと仮定すれば、「何か」が通り抜けてくる。以下の表は、一般的な存在、彼らの平均的な霊力、そして代わりに送られてくる典型的な下僕を決定するために使用される。ゲームマスターは現在のキャンペーンの性質に最も適したものを選ぶことができる。

##### 異次元存在表

| 強度 | コスト | 変動効果 | 霊力 |
| :-: | :-: | :-- | :-- |
| 1 | 3 | サブデーモンまたはサブデビル | 特定の存在に準ずる |
| 2 | 4 | 下級デーモンまたはデビル | 特定の存在に準ずる |
| 3 | 5 | 中級デーモンまたはデビル | 特定の存在に準ずる |
| 4 | 6 | 上級デーモンまたはデビル | 特定の存在に準ずる |

| 7 | 9 | 大神格 | 161-180% |

応答の形式は、その特定の存在、双方の属性、そして依頼の具体的な内容に大きく依存する。その存在が中断の理由を些細なものや重要でないものとみなした場合、彼らの反応は立ち去るだけから真っ向からの攻撃まで何でもあり得る。しかし、絶望的な状況、特にその存在が強く反対する何らかの脅威に術者がさらされている場合は、より好意的な反応が得られる可能性が高い。ゲームマスターがグレーゾーンを感じ、反応が疑問である場合、術者とその味方は、技能、お世辞、懇願、賄賂などを組み合わせてケースを主張しようと試みることができる。しかし、ほとんどの存在は同等以上の力を持つ者との衝突を避けようとし、多くは実行の前後に支払いを要求する。ゲートはその存在がこちら側に留まることを選択する限り開き続け、彼らが去ることを決めた時に背後で閉じる。この間、ゲートは他の者も通行可能であり、両方の現実間での往来が可能となる。

#### グラマー \(R\)

(付与（魅力）)

| | |
| :-- | :-- |
| **階級:** メイジ 0 | **詠唱時間:** 1 アクション |
| **領域:** なし | **持続時間:** 精神集中 |
| **コスト:** 1 | **射程:** 60フィート |
| **範囲:** 対象1体 | **抵抗:** 意志力 |

グラマーは対象を魅力的にし、人々が自然と惹きつけられるようにする。詠唱時にグラマーの性質を選択する必要があり、自然な美しさの向上、より柔らかく官能的な声、あるいは誘惑的な香水の香りまで何でもよい。この呪文は機械的な利益を一切与えないが、対象者が聴衆を集めるチャンスを得たり、接触したい相手の注意を引いたり、仲間が悪事を働くための隙を作るための陽動を提供することは保証する。

逆に、「リパグナンス（嫌悪）」は対象の容姿を歪め、見る者、聞く者、嗅ぐ者全てに嫌悪感を抱かせる。効果は詠唱時に選択する必要があり、鼻の頭にある大きなイボ、甲高い鼻声、あるいは鼻を突くような体臭まで何でもよい。何を選んだとしても、それは人々を犠牲者から背けさせたり、できるだけ早くその場を立ち去るための言い訳を作らせる原因となる。

---#### Glue

(Transmutation)

| | |
| :-- | :-- |
| **階級:** メイジ 0 | **Casting Time:** 1 Action |
| **Sphere:** なし | **Duration:** 24 時間 |
| **Cost:** 1 | **射程:** Touch |

Glueは、2つの固体で無生物の物体を、この呪文のDurationの間、接着する。例えば、荷車の車輪をその車軸に、あるいは扉をその枠に固定する。呪文の効果下にある間、それらのアイテムは、どれほどかけ離れたものであっても、何か他のものが積極的にそれらを引き剥がそうとしない限り、分かつことはできない。この状況では、この呪文は術者のPOW x5に等しいBrawn技能を持ち、それより優れたBrawnが対抗して仕掛けられた場合、対抗ロールで敗北し、呪文は失敗する。呪文が終了するか失敗すると、アイテムは完全に無傷のまま分かれる。

Healを詠唱することで、クレリックは身体の疾患、精神的な外傷、あるいはかなりの量の負傷を、一回のTouchで治癒することができる。この回復の実際の範囲は、以下のように呪文の強度に基づく。強度レベルごとに、呪文は対象のあらゆるPOTの疾患を1つ治癒し、あらゆる失明や難聴を治癒し、負傷や魔法によって引き起こされた精神障害を無効化し、あるいは単一のHit Locationsを最大12点のダメージまで治癒する。ただし、切断された四肢を回復させることはできない。それはRegenerateの呪文の詠唱を必要とするからである。追加の各強度は、別の疾患を治癒するか、別のHit Locationsを治癒するために使用できる。したがって、全身に火傷を負った個人を治癒するには強度7での詠唱が必要となる。長期的な負傷に対して効果を制限する低位の治癒呪文とは異なり、対象が負傷の影響を受けていたDurationによってこの呪文が制限されることはない。

#### Magic Missile

(召喚)

| | |
| :-- | :-- |
| **階級:** メイジ 1 | **詠唱時間:** 1アクション |
| **領域:** なし | **持続時間:** 即時 |

この呪文が詠唱されると、1発以上の魔法エネルギーのミサイルが魔法の使い手の指先から放たれ、対象に命中する。生成可能なミサイルの最大数は、術者の「秘術詠唱」技能レベルに基づいており、60%で2発目、70%で3発目、80%で4発目、90%で5発目が生成される。これらのミサイルを生成するには、希望するミサイル数と同等の等級で呪文を詠唱しなければならない。例えば、技能レベル60%未満の魔法の使い手が《Magic Missile》を等級3で詠唱した場合、長い射程は得られるが、ミサイルは1発しか生成されない。技能レベル70%の魔法の使い手であれば、同じ等級3で詠唱することで、同じ射程を得つつ3発のミサイルを生成できる。この呪文の最大等級は5である。下記の表を参照のこと。

複数のミサイルを放つ場合、単一のクリーチャーを狙うことも、複数のクリーチャーを狙うこともできる。各《Magic Missile》はランダムな部位判定箇所に命中し、特定の部位を狙うことはできない。術者はダメージロールを行う前に、各ミサイルの個別の対象を指定しなければならない。

各流星は影響範囲内にいる者に1d10の火ダメージを与える。ただし、各爆発の半径により多くが重複し、運悪く巻き込まれた者は追加のダメージを受ける。ダメージロールは合計され、対象の各部位判定箇所に適用される。着用している防具は保護にならないが、魔法の防具やクリーチャーの自然防具は通常通りダメージを軽減する。

回避ロールに成功すれば、犠牲者はダメージを受けない。《Artful Dodger（器用な避難者）》能力を持つ者は、伏せ状態にならずに回避する選択肢があるが、この場合の成功は、影響範囲の端から5フィート以内にいない限り、ダメージを半分に軽減するのみである。

影響範囲外であっても、着弾点から60フィート以内にいる者は全員、立っているために運動テストに成功しなければならない。

《Meteor Shower》は、ロールされたダメージ×5%の確率で可燃物を着火させる可能性がある。詳細については [Fires](0007_Game_System.md?id=fire-based-attacks) のセクションを参照すること。

#### Mirror Image

(幻影)

| | |
| :-- | :-- |
| **階級:** メイジ 2 | **詠唱時間:** 1アクション |
| **領域:** なし | **持続時間:** 3ラウンド/等級 |
| **コスト:** 1/等級 | **射程:** 0 |
| **範囲:** 半径5フィート | **抵抗:** なし |

この呪文を詠唱すると、魔法の使い手と全く同じ動きをする分身が2d4体、半径5フィート以内に出現する。さらに、影響範囲全体が揺らめき、術者の正確な位置を突き止めることを不可能にする。幻影を攻撃すると消滅するが、残りの分身には影響がない。術者自身を攻撃しても残りの分身には影響がなく、分身は常に動き回っているため、再攻撃時に標的が本物であるかどうかを知ることはできない。術者が受けた負傷は、分身にも同様に反映される。実際の術者が攻撃されたのか、あるいは分身の1体が攻撃されたのかを判断する方法はゲームマスターに一任されている。1つの方法は、術者を含めたターゲット数を数え、最も近い数値のダイスをロールすることである。例えば、4体の分身と術者を含めた5体が対象の場合、攻撃者は1d6をロールし（6が出た場合は再ロール）、1が出れば術者に命中したと判断できる。あるいは、ターゲット数と同数のマーカーを用意し、1つを術者としてマークする方法もある。攻撃がなされるたびにマーカーを引き、命中すればダメージを適用し、そうでなければ分身が消滅してマーカーを1つ取り除く。分身は呪文の持続時間が終了すると消滅する。

#### 他者変身 (Polymorph Other)

(変容術)

| | |
| :-- | :-- |
| **階級:** メイジ 3 | **詠唱時間:** 2 アクション |
| **領域:** なし | **持続時間:** 永続 |
| **コスト:** 3、追加の強度ごとに+1 (+1 経験修正) | **射程:** 15フィート/強度 |
| **範囲:** 1つの対象 | **抵抗:** 意志力 |

詠唱者は、ターゲットとなった有形のクリーチャー1体の姿を別のクリーチャーに変えることができる。強度1につき、体格（体格）を最大5ポイント変更できる。したがって、体格 16のオークをSIZ 1のウサギに変えるには、3レベルの強度（15 SIZの差）が必要となる。この呪文の対象は、意志力による抵抗を試みることができる。大型のクリーチャー（体格 21-40）は変身しにくく、抵抗判定は「簡単」となり、巨大なクリーチャー（体格 41+）の場合は「非常に簡単」となる。

変身のプロセス全体には丸1ラウンドを要し、対象のクリーチャーにとっては非常にストレスがかかるため、元の性格を維持するために2回目の意志力判定が必要となる。失敗すると対象は1d10分間気絶し、ファンブルすると精神的ショックにより死亡する。クリーチャーの元のSIZが半分になるか2倍になるごとに、性格維持のための意志力判定は等級が1段階難しくなる。人間を魚に変えるような、完全な環境の変化も同様である。成功すれば、犠牲者は知力（知力）と魅力（魅力）、およびそれらの能力値を必要とするすべての技能を保持できる。

変身によって、対象は呼吸方法が通常と異なる場合は新しい形態の呼吸法を得るほか、あらゆる自然攻撃と、その種族の通常の移動手段を得る。そのクリーチャーが持つ強化された能力や魔法能力は得られない。例えば、ドラゴンに変身したクリーチャーは、ドラゴンのブレス攻撃や擬似呪文能力を得ることはできないが、飛行能力、頑丈な皮、致命的な噛みつき、爪による攻撃などは得られる。さらに、犠牲者は運動、腕力、飛行、水泳といった新しい形態の身体技能、およびヒットポイントとダメージ修正を得る。変身した個体が知力（知力）を維持した場合でも、新しい形態に言葉を発する能力がない限り、話す能力は失われる。前形態で呪文を詠唱できた者は、呪文の言語的・身体的要素を生成する能力を維持していれば、新しい形態でも詠唱できる。二足歩行から四足歩行へ、あるいは陸上動物から水生生物へといった極端な変化の場合、ゲームマスターは新しい形態に順応するために練習が必要となる技能の使用に対して、少なくとも1段階の難易度ペナルティを与えるべきである。これは特に、運動、徒手、水泳、飛行、戦闘技能といった身体技能において顕著である。

性格を維持するための意志力判定は、変身した対象が元に戻らない限り毎日必要となる。判定に失敗すると対象は完全に新しい形態の精神に屈し、非知性的なクリーチャーの場合は知力（知力）が霊力（INS）に置き換わる。変身が完了すると、それ以前には所有していなかった新しい形態の特殊能力や魔法能力（凝視攻撃やブレス兵器など）がすべて使用可能になる。このようにして自己を失ったキャラクターは、ゲームマスターの管理下にあるノンプレイヤーキャラクターとなる。

変身の精神的屈服が起こる前であれば、変身したクリーチャーは通常通り「魔法解除」の影響を受け、抵抗判定は不要である（元に戻りたいという潜在意識があるため）。変身には、ストレスに抵抗するための別の意志力判定が必要であり、失敗すると1d10分間気絶し、ファンブルすると精神的ショックで死亡する。

犠牲者が既に新しい形態に屈服していた場合でも、依然として「魔法解除」を使用できるが、犠牲者は意志力判定を行って元の形態に戻ることに抵抗する。この判定に失敗すると、犠牲者は自然な形態に戻るが、もちろんその変身による精神的ショックに抵抗するための別の意志力判定が必要となる。一度失われた犠牲者の自然なアイデンティティは二度と取り戻すことができず、犠牲者はその奇妙で異質な形態こそが自然であり、以前の「正常」な状態に戻されることを切望するようになる。*例：ウサギに変身させられ、そのクリーチャーのアイデンティティを受け入れたオークは、自分はウサギなのに無礼にもオークに変身させられたのだと信じ込むようになる。*「ウィッシュ」やその他の類似の魔法以外に、一度失われた犠牲者のアイデンティティを回復する手段はない。

着用または携行している装備は魔法的に新しい形態と融合するが、ゲームマスターの裁量により、新しい形態でも使用可能な魔法の指輪やブーツなどは残してもよい。これには、クリーチャーの新しいSIZが元のSIZと大きく異なっていない必要がある。ゲームマスターの承認を前提として、攻撃的でない魔法のアイテムがその効果を新しい形態に引き継ぐ確率は、霊力（霊力）x 1%である。例えば、+1防護の指輪を持つクリーチャーは、その自然の防具ポイントに+1ボーナスを得られる可能性がある。ドッペルゲンガーやライカンスロープ（狼男など）のように自然に姿を変える能力を持つクリーチャーは通常通り変身するが、1ラウンド後には自分の自然な姿に戻ることができる。殺された場合、たとえ既にアイデンティティを完全に失っていたとしても、変身したクリーチャーは元の姿に戻る。

詠唱が成功すれば、対象はヒットポイント全快の状態で生き返るが、失われた四肢は戻らない。つまり、斬首されたり真っ二つにされた犠牲者は、頭部や胴体が再接合されない限り復活できない。これは「死者復活」の詠唱前に、医療キットと応急手当技能を成功させて物理的に部位を再接合することで可能であり、典型的には目立つ傷跡が残る。毒や病気などの他の病気は「死者復活」の詠唱前後に対処する必要があり、さもなければ結果は一時的なものに過ぎない。最後に、「死者復活」は寿命を迎えて老衰で死亡したクリーチャーには何の効果もない。

死から蘇るという行為は対象に大きな負担をかけ、死んでいた日数1日につき24時間の間、疲労レベルが「無力化」に減少する。この療養期間中、「疲労回復」を詠唱しても患者には効果がない。この期間を過ぎれば、キャラクターは制限なく通常通り疲労から回復する。

逆の「生者殺し」は、詠唱時にクレリックが指定した犠牲者1人を殺害するために使用できる。この犠牲者は、以下の表で詳述されるように、ターゲットの階級または体格（体格）のうち、ターゲットにとって有利な方で修正された意志力ロールによる抵抗が許される。

| :-: | :-: | :-: |
| 0-1\* | 1-20 | 困難 |
| 2 | 21-40 | 標準 |
| 3 | 41-60 | 簡単 |

抵抗ロールが失敗した場合、犠牲者は即死する。成功した場合は「重傷」の効果と同様に扱われる。防具はこのダメージを一切防げない。

#### 蘇生 (R)

(死霊)

| | |
| :-- | :-- |
| **階級:** クレリック 5 | **詠唱時間:** 10分 |
| **領域:** 死霊 | **持続時間:** 永続 |

「蘇生」は強度レベル1につき最大20年前に死亡したあらゆる生物を蘇らせる。対象は命を吹き返されるだけでなく、失った四肢まで含めて完全に健康な状態に回復する。この呪文が効果を発揮するために、本体の大部分が残っている必要はない。例えば、8の強度で詠唱すれば、たとえ指の骨一本しか残っていなくても、145年前に死んだ者を蘇生させることが可能である。蘇生した者は休息の必要はなく、直ちに完全に機能する。ただし、寿命によって自然死した生物に対してはこの呪文は効果がない。

対象の属性が悪以外であった場合、対抗の意志力ロールでこの呪文に抵抗し、成功すれば効果を無効化できる。これは、死者の魂が永遠の報いを得た後で現世に戻ることを望まない場合が多いためである。ただし、対象が成し遂げていない仕事がある、真実の愛から引き裂くことができない、あるいは生きるための他の英雄的な理由がある場合、ゲームマスターは判定を免除してもよい。悪の魂の場合、永遠の地獄の苦しみよりも戻ることを喜んで選ぶため、抵抗するのは死者本人の意志力ではなく、罰を与える責任者である悪魔や魔神などの意志力となる。この場合、詠唱者はその拷問者の意志力を上回らなければならない。もし拷問者の特性値が不明な場合は、死者の意志力よりも少なくとも20ポイント高いと想定すること（魂の意志が強いほど、その者を罰する存在も強力になることを表す）。詠唱者が成功すれば蘇生は成功し、失敗すれば対象は戻る意思がないか、あるいは戻ることができない。

蘇生は非常に消耗が激しく、クレリックは一般的な寿命の3%（人間なら3年分）加齢する。詳しくは[年齢](0007_Game_System.md?id=aging)のルールを参照のこと。

この呪文は、詠唱時に選択することで、紫色や赤青色に燃える炎の壁や円陣を召喚することができる。呪文の持続時間は、集中が維持されている間、または集中が終了してから霊力1あたり1ラウンドの間有効である。詳細は種類ごとに以下に記す。

**ウォール・オブ・ファイア:** このバージョンの呪文は、霊力1あたり長さ20フィートの静止した炎の壁を作り出す。最終的な霊力に関係なく、壁の高さは詠唱時に希望する10〜20フィートとなる。ウォール・オブ・ファイアの射程は180フィートであり、水平に召喚することはできない。

**サークル・オブ・ファイア:** このバージョンの呪文は、術者の周囲に術者と共に移動する炎の円陣を作り出す。半径は10フィートで、最初の1を超えた霊力1ごとに半径が5フィート増加する。最終的な霊力に関係なく、円陣の高さは詠唱時に希望する10〜20フィートとなる。サークル・オブ・ファイアは術者を取り囲まなければならず、射程は0である。

壁や円陣の術者とは反対側の面は灼熱の熱を発し、10フィート以内の全員にラウンドごとに1d6のダメージを与え、20フィート先まで1d4のダメージを与える。このダメージは通常、次のラウンドに進む前のラウンドの終了時に適用される。犠牲者が1ラウンド中に両方の熱ゾーンにいる場合、大きい方のダメージが適用される。炎の中を飛び越える者は、2d6ポイントのダメージに加え、最初の霊力を超える霊力1ごとに1ポイントのダメージを受ける。このダメージは各部位判定に適用され、着用している防具は保護効果を発揮しないが、魔法の防具値やクリーチャーの自然な防具は通常通りダメージを軽減する。回避の抵抗ロールに成功すれば、犠牲者は熱から飛び退いたり炎を通り過ぎたりして、呪文が発動したラウンドのダメージを受けない。火を使うクリーチャーはこのダメージを半分受け、氷を使うクリーチャーは2倍のダメージを受ける。炎には、可燃物を引火させる確率がある（ダメージの出目×5%）。詳細については[火](0007_Game_System.md?id=fire-based-attacks)のセクションを参照のこと。

#### ウェブ

(召喚)

| | |
| :-- | :-- |
| **階級:** メイジ 1 | **詠唱時間:** 1アクション |

| **範囲:** 半径20フィート | **抵抗:** 回避、および下記参照 |

この呪文は、術者の手からベタベタした長い蜘蛛の糸を放つ。これは通路を塞いだり進行を妨げたりするために、床から天井へ、あるいは壁から壁へと固定することができる。また、直接相手に吹き付けて絡め取ることもできる。

対象が蜘蛛の糸から脱出する余地がある場合、回避ロールに成功すれば対象は効果範囲外に出るが、これには行動ポイントが必要である。抵抗ロールに失敗すると、犠牲者は身動きが取れなくなり、1d3の部位判定が絡め取られる。[絡め取り](https://cfi-srd.mythras.net/#/0008_Combat?id=entangle)特殊効果と同様に、蜘蛛の糸で覆われた部位は使用不能になる。腕が絡まると持っているものは使えず、胸部、腹部、脚が拘束されると、すべての物理技能ロールが1等級難しくなる（拘束を解くための腕力ロールを除く）。頭が絡まると、[窒息](0007_Game_System.md?id=asphyxiation)の項で詳述されているように窒息する。

次のターン、犠牲者は行動ポイントを消費して蜘蛛の糸から脱出を試みることができる。魔法の蜘蛛の糸は非常に強靭かつ粘着性が高く、6の防具値と呪文の霊力の3倍のヒットポイントを持つ。脱出を試みるには、蜘蛛の糸の粘着力（術者の魔力発動技能に等しい）に対する腕力の対抗ロールに勝利しなければならない。これが失敗した場合、対象は縛られたままであり、筋力だけで脱出することはできない。切り裂いて脱出しようとすると、使用した道具や武器も同じプロセスに晒される。一般に信じられていることとは異なり、蜘蛛の糸は引火しないが、火を使って糸を縮ませることでゆっくりと焼き切ることはできる（火ダメージは蜘蛛の糸の防具値を無視する）。

ウィッシュは現実を永続的かつ重大な方法で変更できる。この呪文を唱えるには、魔術師は3マジックポイントを消費し、望む結果に応じて1つ以上の経験修正ロールを消費しなければならない。1ヶ月の期間内に続けてウィッシュを唱えるたびに、通常必要とされる経験修正の消費量が倍になる。詠唱時間は通常、ウィッシュの具体的な内容を言葉で説明するために必要とされる。完了すると、術者は消費した経験修正に等しい疲労を負い、通常の平均寿命の5%分だけ年齢を重ねる（人間の場合、5年分に相当する）。亜人種の平均寿命については[加齢](0007_Game_System.md?id=aging)を参照のこと。

ウィッシュの結果は文字通りに受け取られるべきであり、ゲームマスターによる解釈の余地がある。貪欲な願いは通常、悪い結果を招く。貪欲な意図で行われたウィッシュが何らかの形で裏目に出る確率は10%である。例えば、富を願った場合、地元の領主や王の宝物庫から富が転送されてくるかもしれない。ウィッシュは、神のような存在がそのウィッシュを発したのではない限り、神のような存在の命令を取り消すことはできない。

この呪文は小さな透明な「眼」を作り出し、術者は呪文の持続時間中、それを通して見ることができる。この眼はパーティーの先に移動させたり、曲がり角の先や部屋の中を覗き込むために送ることができる。移動速度は1ラウンドにつき20フィート（1分で240フィート）であり、「明らかな」脅威や興味のあるアイテムをスキャンするだけならこの速度となる。これは通常、床と低い壁面に限られる。より徹底的に調べる場合（壁全体や天井も調べる場合）、移動速度は1ラウンドにつき10フィート（1分で120フィート）に低下する。ゲームマスターは、視覚的な異常を発見する場合など、必要に応じて術者の知覚ロールを許可してよい。眼は実体があり、固体を通り抜けることはできず、60フィートまで通常の視界、10フィートまで赤外線視覚を持つ。術者は持続時間中ずっと眼への集中を維持しなければならず、維持されない場合は再び集中が確立されるまで眼は不動となる。本来術者に影響を与える視線攻撃は通常通り術者に影響する。ただし、眼は盲目、暗黒の呪文などに関しては術者とは独立しているとみなされる。小さな隙間を通る場合、眼は1インチ以下であり、体格は1である。

この呪文を唱えると、クレリックは即座に予め指定された聖域および10フィート半径以下の到着指定地点へとテレポートする。テレポートの実際の射程に制限はなく、複数の次元間であっても移動できる。単一の次元内では失敗の可能性はないが、1つの次元を超えるだけでも91-00%のファンブル確率が発生し、2つの次元なら81-00%でファンブルが発生する、といった具合になる。これは術者の通常のファンブル確率を置き換える。次元を超える際のファンブルは、クレリックが取り返しのつかないほど迷子になることを意味する。単一次元内のファンブルは通常のルールに従う。

術者自身と携行している装備に加え、クレリックは霊力1につき最大3つまでの物体を移動させることができる。それぞれは体格/9「モノ」以下の大きさでなければならない。移動させる追加の物質には宝物、装備、生きている存在が含まれる。ただし、移動させるクリーチャーが持ち込んでいる装備をカバーするには、十分に高い霊力レベルで呪文を唱える必要がある。
