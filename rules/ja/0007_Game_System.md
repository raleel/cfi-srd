# 第7章：ゲームシステム

『クラシック・ファンタジー・インペラティブ』のゲーム中には、様々な出来事が起こり得ます。一部は技能の使用や、戦闘や魔法といった主要なゲームメカニクスを通じて解決されますが、それ以外のものは独自の裁定ルールを必要とします。本章では、プレイヤーがゲーム中に遭遇する様々な状況に対するルールと指針を提供します。

ここに挙げたリストは網羅的なものではありませんが、最も一般的な状況を網羅しているはずです。もしゲームマスター（GM）が、ゲームシステムの裁定が必要な他の状況に遭遇し、それらが頻繁に発生すると判断した場合は、本章のルールを基盤として、独自のルールを開発または発展させることを推奨します。

## 年齢

すべてのキャラクターは年齢を重ね、年齢とともに特定の結末が伴います。加齢の兆候は「若中年（人間なら40歳。他の種族は下記に示すように、より早い、または遅い速度で加齢する）」から始まります。キャラクターが新しい年齢帯に達するたびに、指定された難易度で「持久力」判定と「意志力」判定の両方を行わなければなりません。判定に失敗した場合、そのキャラクターは「年齢による影響表」に示す加齢効果を被ります。

影響を受ける特性値はそれぞれ1d3ポイント減少します。これらのポイントは、年齢を重ねても体型を維持し、敏捷さを保つための努力を表現する「特性値の改善」を通じて、回復させるか、少なくとも部分的に相殺することができます。もし加齢によって特性値が0になった場合、そのキャラクターは末期的な虚弱により死亡します。一度キャラクターが「晩年」の年齢帯に達すると、種族に関係なく毎年加齢判定が行われます。

加齢プロセスの一環としてどのような具体的な衰弱効果が現れるかは、ゲームマスターが定義します。例えば、「筋力」「体力」「敏捷性」の減少は、関節のきしみや移動能力の段階的な喪失といった、身体の一般的な摩耗を表現します。「知力」の減少は、年齢が精神や記憶に悪影響を及ぼし始めていることを示し、「魅力」の減少は、年齢を重ねるにつれてキャラクターが気難しくなり、あるいは短気になる可能性があることを示しています。

## 窒息

キャラクターは「持久力」技能の値に等しい秒数の間、息を止めることができます。ただし、キャラクターは準備（肺に最大限の空気を吸い込む）をしている必要があります。もしそうでない場合、受動的な状況であればその時間は半分に、激しい活動に従事していた場合は5分の1に減少します。

息を止めていられる期間が過ぎると、キャラクターは「持久力」判定を行わなければなりません：

- 判定が「決定的成功」の場合、それ以上の悪化は起こりません。
- 判定が「成功」の場合、キャラクターは疲労レベルを1段階追加で蓄積します。
- 判定が「失敗」の場合、キャラクターはそのラウンドで1d2の疲労レベルを追加で受けます。
- 判定が「ファンブル」の場合、キャラクターはそのラウンドで1d3の疲労レベルを追加で受けます。

救助がなければ、窒息による死は通常迅速です。キャラクターが死亡する前に窒息が終わった場合、窒息によって失われた疲労レベルは比較的早く回復し、1分ごとに1レベルずつ回復します。

窒息の方法によっては、ゲームマスターは完全な回復を阻止し、煙や水の吸い込みによる肺への損傷を表現するために、持続的な疲労レベルを課すことを望むかもしれません。

## キャラクターの成長

すべての『クラシック・ファンタジー・インペラティブ』のキャラクターは、時間と経験を経て成長することができます。成長は以下のいくつかの分野で行われます：

- 既存の技能を向上させる
- 情熱を向上させる
- 新しい技能を習得する
- 新しい能力を習得する

#### 経験ロール

キャラクターの成長のための主要なメカニズムは「経験ロール」です。ゲームマスターは、キャンペーンの適切な節目、つまりシナリオやストーリーラインの終了時、またはストーリーが長く完了までに時間がかかる場合は2〜3回のセッション終了後に、経験ロールを授与します。頻度はゲームマスターの裁量に委ねられます。経験ロールの頻度が高いほど、キャラクターはより速い速度で成長します。

経験ロールを与えるのに正しいタイミングや間違ったタイミングはありませんが、ストーリーの自然な区切りが適切な時期を示唆することがあります。ただし、常に決定を下すのはゲームマスターです。プレイヤーは経験ロールを要求することはできませんが、ある程度のタイミングでそれを受け取ることを期待する権利があります。なぜなら、それなしではキャラクターを成長させることができないからです。

授与される経験ロールの数もゲームマスターによって決定されます。ただし、前回の授与以降のセッション数ごとに1〜3回の経験ロールを与えるのが目安となります。

#### 既存技能の向上

キャラクターシート上の技能であれば、「標準技能」でも「専門技能」でも、経験ロールを1回消費することで向上させることができます。プレイヤーは経験ロールを技能の向上に費やさないことを選択し、代わりに「クラス能力（下記参照）」などの他の要素を向上させるためにストックしておくことも可能です。

- プレイヤーは1d100を振り、向上させる技能と比較します。キャラクターの「知力」がロールの値に加えられます。
- 出目が向上させる技能の数値と**等しいかそれ以上**であれば、技能は1d4+1%増加します。
- 出目が選択した技能の数値**未満**であれば、技能は増加しますが、1%のみとなります。
- 前回のセッション（最後の経験ロール授与から現在まで）の間に、キャラクターがいずれかの技能でファンブルした場合、そのファンブルした技能は1%の無料増加を得ます。失敗から成功よりも多くを学ぶというのは真理であり、これは壊滅的な失敗の後にキャラクターが経験する内省を表現しています。同一技能での複数のファンブルは累積しません。ファンブルした技能を経験ロールで向上させる場合、ファンブルによる1%は経験ロールの判定前に行われます。

同一の技能は、セッションごとに一度しか経験ロールの恩恵を受けることはできません。

#### 情熱の向上

[情熱](0004_Alignment_and_Passions.md?id=passions)の項で説明した通り、情熱の値は技能と同じ方法で、経験ロールを使用して向上させることができます。ゲーム中の状況に応じて、ゲームマスターは経験ロールを使用して情熱を減らすことを許可するかもしれません。

例えば、報われない愛による絶え間ない拒絶は、熱烈な愛好家の情熱でさえ最終的にはすり減らしてしまうかもしれません。特に、過去の亡霊に悩まされることなく新しい関係を築きたいと望む者にとってはなおさらです。

#### 新しい技能の習得

一部のキャラクターは、文化やクラスからは学ぶ機会がなかった新しい「専門技能」を習得したいと望むかもしれません。経験ロールを投資し始める前に、その技能を学ぶための知識源を見つける必要があります。これは、騎士団やギルドが提供するような専門の指導者というありふれたものかもしれません。あるいは、古く朽ちかけた訓練用スクロールといった、よりエキゾチックな教育源である可能性もあります。

教育源が見つかったら、キャラクターはその技能の基礎的な土台を築くために、1ヶ月間フルタイムで学習と練習に費やす必要があります（基本レベルで習得）。これには経験ロールが3回必要であり、さらに指導者（もし存在すれば）への支払い、および必要となる道具や機材の購入（またはレンタル）にかかるゲーム内のコストが必要です。

#### 新しいクラス能力の習得

キャラクターが必要な「階級」と「技能レベル（存在する場合）」を満たしていると仮定し、1回以上の経験ロールを消費することで、クラス能力を獲得または向上させることができます。これについては、[第3章：クラス](0003_Classes.md)の該当するクラスの説明に詳しく記載されています。技能とは異なり、これには通常、関連する能力を学ぶための知識源を見つける必要はありません。必要な技能を繰り返し使用することで、高度な技術を習得したとみなされるからです。経験ロールのコストはキャラクターの現在の「階級」と同等であり、多くの能力は特定の階級に達するまでロックされています。

## 落下

落下によって被るダメージ量は、落下の距離に依存します。「防具」のポイントは落下ダメージを軽減しませんが、落下したキャラクターやクリーチャーの「ダメージ修正」がダメージロールに適用されます。

| :-- | :-- |
| 5フィート以下 | ダメージなし |
| 6〜15フィート | ランダムな1部位に1d6ダメージ |
| 16〜30フィート | ランダムな2部位にそれぞれ2d6ダメージ |
| 31〜45フィート | ランダムな3部位にそれぞれ3d6ダメージ |

| 15フィートごとに追加 | +1d6ダメージ |

#### 落下物

落下物は、その「体格」と落下の距離に応じたダメージを与えます。物体は「体格」6ポイント（またはその端数）ごとに1d6のダメージを与え、さらに落下距離表の「受けたダメージ」欄に等しいダメージ量を加算します（小型の物体に対する軽減を含みます）。

## 疲労

疲労は「疲れ」とその累積的な影響を測定します。激しい活動から病気の衰弱効果に至るまで、様々な事柄を追跡するために使用されます。

疲労を蓄積する主な方法は、何らかの身体活動に従事することです。運動や労働が過酷であればあるほど、キャラクターはより早く疲れます。ゲームマスターの裁量により、キャラクターは疲労レベルの獲得に抵抗するために、適切な技能ロール（「運動」「腕力」「持久力」のいずれか）を行わなければなりません。

判定に失敗するたびに、疲労レベルが1段階蓄積されます。[疲労レベル表](0007_Game_System.md?id=疲労レベル表)に示すように、各疲労レベルには、技能使用、移動、イニシアチブ、行動ポイントに対するペナルティが伴います。窒息、出血、その他の設定依存の効果も疲労の蓄積に寄与します。

ほとんどのキャラクターにとって、「無力化」レベルに達すると、あらゆる活動がほぼ不可能になります。この段階では、キャラクターは意識を保っていますが、最も切迫した活動以外は何もできなくなります。

「無力化」を超えると、キャラクターはまったく行動できなくなります。「半意識」「昏睡」「死亡」といった疲労レベルは、通常、窒息、病気、出血、飢餓、露出などの極端な影響を測定するために使用されます。

### 疲労からの回復

キャラクターは「治癒率」に応じて疲労から回復します。蓄積された疲労の各レベルから回復するために必要な完全な休息の量は、「回復期間」をキャラクターの「治癒率」で割ったものに等しくなります。

この表は身体活動による疲労の回復を表していることに注意してください。[窒息](0007_Game_System.md?id=f)からの回復は非常に速く、[出血](0007_Game_System.md?id=出血)からの回復の場合はより遅くなる可能性があります。

## 火

火は、武器として使用される場合や制御不能に燃え広がった場合、常に危険の源となります。以下の[火の強度表](0007_Game_System.md?id=火の強度表)は、熱によるダメージの5つの異なる強度と、その例を示しています。ラウンドごとに与えられるダメージは「ダメージ」の欄に示されています。比較的小さいため、強度1と2の火源は単一の「部位判定」にダメージを与えます（通常は火源に触れている部位）。強度3と4の火源はより大きく、1d4+1の最も近い部位判定にダメージを与え、放射熱の度合いを示しています。強度5の火源は、すべての部位判定に同時に影響を与えます。火は可燃物に引火する可能性があります。直ちに消火されない場合、そのような物質は火の強度に応じたラウンド数以内に燃焼します。一度引火すると、可燃物は物理的に消火されるまで燃え続けます。ダメージは「防具」のポイントを無視して物質の「ヒットポイント」に直接適用され、その下の肉体にも適用されます。制御されない場合、火はその強度に等しい数の部位判定に、ラウンドごとに広がります。

| :-: | :-- | :-: | :-: |
| 1 | ろうそく | 1d4 | 1d2 |
| 2 | 松明 | 1d3 | 1d4 |
| 3 | キャンプファイヤー | 1d2 | 1d6 |
| 4 | 部屋を埋め尽くす大火災 | 1d2 | 2d6 |
| 5 | 火山の溶岩 | 即時 | 3d6 |

#### 火炎系攻撃
 
火炎系攻撃は通常、1ラウンドで終了するため、可燃物に引火する確率をパーセンテージで持ちます。特に注記がない限り、この確率は火炎系攻撃の場合「出たダメージ×5%」、電気系攻撃の場合は「出たダメージ×1%」です。一度引火すると、可燃物は物理的に消火されるまで、ラウンドごとに1d3-1のダメージを与えます。このダメージは「防具」のポイントを無視して物質の「ヒットポイント」に直接適用され、その下の肉体にも適用されます。ただし、クリーチャーの自然防具は通常の保護を提供します。犠牲者は、伏せて「運動」判定を成功させることで火を消し止めることを試みることができます。これには「行動ポイント」が必要で、ターンごとに試みることができます。他の者が何らかの形で消火を支援する場合、判定の難易度は1段階簡単になります。ダメージロールの結果が0ダメージであった場合、その場所では自然に火が消えたことになります。自然に消えた部位ごとに、消火の判定も1段階簡単になります。

## ゲーム時間

『クラシック・ファンタジー・インペラティブ』において、時間は重要な要素です。主に何がどの順番で起こるかを決定し、ゲームメカニクスがしかるべき時に適用されるようにするために使用されます。ゲーム内の時間は、通常プレイに費やされる時間とは等しくないことを覚えておいてください。GMは「キャッスル・グレイマイアに到着するまで1週間かかる」というように、数日間の出来事を一文で要約する必要がある場合もあれば、特に戦闘中などは、わずか数秒の行動を解決するのに数分以上かかる場合もあります。

関連して：一部の呪文、アイテム、効果は、1日あたり1回以上使用可能と記載されています。これらを追跡するために各アクションがいつ行われたかを記録する代わりに、キャラクターが十分な夜の睡眠をとった後に時計がリセットされると仮定するのが簡単です。したがって、1日3回使用可能なマジックアイテムを2回使用した場合、たとえ前夜に寝る直前に使用したとしても、次にキャラクターが目覚めたときにはすべての使用回数が回復します。

以下は、ゲーム時間における重要な区別です：

#### 戦闘ラウンド

「戦闘ラウンド」は5秒のリアルタイムを表します。これは、完了するまでに瞬間を要する短く熱狂的な活動、あるいは一挙手一投足の解決を必要とする非常に詳細な活動を測定するために使用されます。例えば、狩人と獲物の間の追跡のように、ラウンドごとに追求のねじれや曲がり角が決まるような状況です。

#### 探索ラウンド

「探索ラウンド」は5分間のリアルタイムを表し、パーティーが「基本移動速度」の3倍の速度で移動することを可能にします（人間および人間サイズの亜人は60フィート、より小さな亜人種族は45フィート）。探索ラウンドは通常、ダンジョン内での移動を測定するために使用されます。そこでは、高い警戒心を維持することが重要です。キャラクターはゆっくりと移動し、罠や待ち伏せに注意を払い、隠密状態を維持しようとします。これは、パーティーの誰かが地図を作成していることも前提としています。誰も地図を作成していない場合、探索ラウンドは1分間として扱うことができます。探索ラウンドを使用すると、「知覚」判定をペナルティなしで行うことができますが、通常通り他のペナルティが適用される場合があります。光源（松明やランタンなど）を暗闇の場所で使用して自分の位置を明かしていない限り、敵が探索速度で移動しているパーティーを発見するのは1段階困難になります。キャラクターが警戒心を捨ててダンジョンを移動することに決めた場合、戦闘ラウンドを使用して移動することもできます。しかしその場合、「知覚」判定は1段階難しくなり、敵はキャラクターを発見する際、「知覚ペナルティ」を被りません。なお、プレイヤーにダンジョン全体を公開するバトルマットを使用している場合、あるいはゲームマスターが彼らのためにダンジョンを描いている場合は、**常に**パーティーが地図を作成しており、したがって探索速度で移動していると想定すべきです。

#### 技能時間

「技能時間」は数分から数時間の範囲を表し、戦闘ラウンドのような詳細な注意を必要とせず、決定的な結果を伴う特定の努力を必要とする活動を測定するために使用されます。錠前を開けるには5分かかるかもしれませんが、城の壁の周りで警備隊が行う巡回を観察するには数時間かかるかもしれません。どちらも技能時間の例です。#### 物語的時間

これはゲームマスター（GM）がプレイヤーに語りかける際、あるいはプレイヤーたちが議論している際に経過する時間である。特別な理由がない限り、実際のロールプレイのほとんどは物語の時間内で行われる。ロールプレイ中、物語の時間はリアルタイムに近く、会話にかかる時間はプレイする時間と同じだけかかる。ゲームセッションに長い旅や、正確な時間が重要ではない活動期間が含まれる場合、時間は大幅に圧縮され、ゲーム内時間で数瞬になる。

### 小休憩

小休憩は、冒険者たちが息を整えるために費やす約15分間の時間を表す。この間、読書、食事、飲酒、祈り、傷の手当てといった過度な負荷のかからない行動のみが行われる。パーティーがどれくらい休憩するかを決定し、関連する15分間のアクションを実行する。各プレイヤーは次のプレイヤーに移る前に1つのアクションを実行する。1日にパーティーがとれる小休憩の回数に制限はない。通常、キャンプを設営した後や、朝出発する前に、いくつかの休憩アクションが行われる。各15分間の休憩アクションの詳細は以下の通りで、特に明記されていない限り複数回実行できる。

- **食料を食べる:** この15分間の休憩アクションは、1日1回のみ実行できる。食料は日用品として管理されており、疲労困憊以下の任意の疲労を1段階取り除き、空腹を鎮める。この活動は過度な負荷を伴わないため、食べている間に疲れ以下の疲労であれば、さらに疲労を1段階軽減できる。
- **神格への祈りまたは呪文の書を学習:** 祈りや学習に費やした15分間の休憩アクションごとに、マジックポイントを1点回復する。この活動は過度な負荷を伴わないため、疲れ以下の疲労であれば、疲労を1段階軽減できる。
- **傷の手当て:** 15分間の休憩アクションを費やして応急手当技能を使用するか、4回の15分間休憩アクション（1時間）を費やして治癒技能を使用する。
- **1つ以上の呪文を詠唱:** 15分間の休憩アクションの間、パーティーのメンバーを回復や強化するために、使用可能なマジックポイントの範囲内で任意の数の呪文を詠唱できる。
- **新しい呪文の準備:** 少なくとも8時間の睡眠をとった後、呪文使いは15分間の休憩アクションを使用して、[呪文の記憶](0009_Magic.md?id=memorizing-spells)に記載された制限に従い、秘術呪文または神聖呪文を記憶（あるいは忘却）できる。
- **ためらう:** 他のアクションを選択しない限り、これがデフォルトの15分間の休憩アクションとなる。キャラクターは単に何の役にも立たない15分間を浪費する。この休憩アクションは、通常パーティーの他のメンバーがまだ休憩アクションを行っているときに、自分にはすることがない場合に行われる。この活動は過度な負荷を伴わないため、疲れ以下の疲労であれば、疲労を1段階軽減できる。

## 部位判定

成功した（武器による）攻撃のほとんどは、特定の部位判定に命中する。これはランダムに決定することも、場合によっては「部位選択」などの特殊効果によって選択することもできる。命中した部位をランダムに算出するには、1d20を振り、該当する人型生物またはクリーチャーの部位判定表と照合する。

動物やモンスターの部位判定表は、その独自の生理構造を反映するため、通常の人型生物とはわずかに異なる。これらは各存在の説明の一部として記載されており、通常はゲームマスターのみが使用する。

人型生物の部位判定表を参考として以下に再掲する。

### 人型生物の部位判定

| **1d20** | **部位** |
| :-: | :-- |
| 1-3 | 右脚 |
| 4-6 | 左脚 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右腕 |
| 16-18 | 左腕 |
| 19-20 | 頭部 |

魔法による攻撃や、特定のモンスター（レッドドラゴンの火炎のブレスなど）が放つ攻撃の中には、複数の部位判定に同時に命中するものがあることに注意すること。個々の部位は、着用している防具や、クリーチャーの表皮の自然な頑丈さによって防護されている場合がある。これは以下の「ダメージ」および「負傷レベル」を考慮する際に重要となる。

### ダメージと負傷レベル

攻撃が成功した場合、武器のダメージ評価に従ってダメージを与える（[お金と装備](0006_Money_and_Equipment.md?)章の[近接武器](0006_Money_and_Equipment.md?id=basic-melee-weapons)および[遠隔武器](0006_Money_and_Equipment.md?id=basic-ranged-weapons)の表を参照）。例えば、ショートソードは1d6のダメージを与える。

武器や攻撃で振られたダメージは、以下の順序で特定の条件により修正される：

- 攻撃を行うキャラクターのダメージ修正を適用する。
- 武器を強化（または減少）させる魔法によるダメージ修正を行う。
- パリー（受け流し）された場合、比較する武器の間合いに従って適切にダメージを減少させる。
- 命中した部位が防具を装備している場合、防具の値を差し引いてダメージを減少させる。

攻撃によって与えられたダメージが0より大きい場合、その部位はそのダメージ量を受け、その合計値が直ちにその部位のヒットポイントから差し引かれる。その部位のヒットポイントが残りいくつであるか、またどのような負傷カテゴリーに該当するかを記録すること。

- **軽傷:** 部位のヒットポイントが正の値。
- **重傷:** 部位のヒットポイントが0以下。
- **大怪我:** 部位のヒットポイントが、開始時のヒットポイントと同等かそれ以上の負傷の合計値（マイナス）に達した場合。

部位が重傷または大怪我を受けた場合は、以下のルールを使用する。持久力判定を必要とする負傷は、攻撃の出目に対して対抗ロールとして判定を行う。これは、熟練の戦士が高い殺傷力を持つ攻撃を繰り出せる能力を反映している。部位が再び負傷しない限り、持久力判定は繰り返さない。

#### 軽傷

軽傷とは、切り傷、擦り傷、打撲、捻挫のことである。痛みがあり出血することもあるが、犠牲者の動きを遅くしたり阻害したりするほど重大なものではない。

#### 重傷

部位のヒットポイントが0以下になった場合、犠牲者は重傷を負う。その部位には永久的な傷が残り、犠牲者は痛みによる気絶や動揺のため、次の1d3ターンは攻撃を行ったり呪文の詠唱を開始したりできない（ただし、パリーや回避は可能）。

四肢に重傷を負ったキャラクターは、即座に自身の持久力と敵の攻撃の出目による対抗ロールを行わなければならない。失敗すると、その部位のヒットポイントが正の値に回復するまで、その四肢は無力化される。脚の場合、犠牲者は転倒する。腕の場合、ストラップなどで固定されていない限り、手に持っていたものは落とす（ここは常識的に判断すること）。

腹部、胸部、または頭部に重傷を負ったキャラクターは、即座に自身の持久力と敵の攻撃の出目による対抗判定を行わなければならない。失敗すると、重傷を引き起こした攻撃のダメージ量と同じ分（分）の間、意識を失う。応急手当または治癒技能を使用して、意識を失った犠牲者が重傷を負った部位をさらに回復させる手助けをすることができる。

ゲームマスターの裁量により、キャラクターが行動可能であっても、その部位を使用するすべてのタスクは、負傷が軽傷に軽減されるまで、常に難易度1段階分のペナルティを受ける。

#### 大怪我

部位のヒットポイントが、開始時のヒットポイントと同等かそれ以上の負傷の合計値（マイナス）に達した場合、キャラクターは大怪我を負う。キャラクターは即座に無力化され、戦闘を続行できなくなる。大怪我により、四肢が切断、貫通、粉砕、あるいは引きちぎられる。キャラクターは転倒して物理的に無力化され、即座に自身の持久力と敵の攻撃の出目による対抗判定を行わなければならない。失敗すると激痛により意識を失う。切断、貫通、または引きちぎられた部位が、自身の治癒率の5倍の分（分）以内に処置されない場合、キャラクターは失血とショックにより死亡する。

腹部、胸部、または頭部に大怪我を負った犠牲者は、即座に意識を失って完全に無力化され、敵の攻撃の出目に対して持久力の対抗判定を行わなければならない。失敗すると、即死（斬首、真っ二つ、心臓を貫かれる、バラバラにされるなど）となる。生き延びたとしても、その部位がキャラクターの治癒率の2倍のラウンド数以内に処置されない場合、失血とショックにより死亡する。

ほとんどの大怪我には何らかの外科手術や強力な魔法による治療が必要となるため、負傷者が戦闘に復帰できるほど回復することはまずない。利用可能な治療法に応じて、負傷した部位は後遺症が残る可能性がある（[負傷からの回復](0007_Game_System.md?id=healing-from-injury)を参照）。

### 失血

通常、戦闘で負う外部および内部の負傷による失血は、キャラクターを非常に素早く衰弱させる。その影響は、[窒息](0007_Game_System.md?id=asphyxiation)と同様に、疲労レベルの蓄積によって測定される。医療措置を講じない限り、失血が止まらなければ通常は死に至る。窒息と異なり、深刻な失血による疲労への影響は長く続く。出血が止まった翌日から、1日につき1段階の割合で、失血によって失われた疲労を回復する。

#### 英雄の最後のアクション

重要なキャラクターが大怪我を負った特別なケースでは、ゲームマスターは英雄的な最後のアクションを許可してもよい。例えば、最後の呪文を放つ、自分を殺した敵を切り倒そうとする、這って隠れる、自分の傷を縛るなどである。キャラクターはアクションに適した機能する四肢を持っていなければならず、幸運ポイントを消費する必要がある。アクションを試みる機会を1回得た後、即座に意識を失い、おそらく死に至る。

## 負傷からの回復

傷や怪我の自然治癒は、キャラクターの治癒率に基づく。治癒率は、怪我の性質に応じて一定期間内に部位のヒットポイントがどれだけ回復するかを決定する：

- 軽傷：日単位
- 重傷：週単位
- 大怪我：月単位

したがって、治癒率が3のキャラクターが負傷してある部位が–3（重傷）になった場合、その部位が0以上になるまで週に3ヒットポイントずつ自然回復し、その後は完全に回復するまで1日3ヒットポイントずつ回復する。

自然治癒にはいくつかの制限がある：

- 回復中のキャラクターは過度な活動を行ってはならない。さもなければ、治癒率が1d3減少する。したがって、軽傷から回復中のキャラクターであっても、怪我を悪化させるような身体的な作業を行うと、治癒の進行が止まってしまう可能性がある。
- 大怪我に対する自然治癒は、犠牲者が[治癒](0005_Skills.md?id=healing-intpow)技能の成功による治療を受けるか、「傷の治癒」呪文のいずれかが詠唱されるまで始まらない。治癒技能の20分の1の日数以内に治療されなかった、切断を伴わない大怪我は、永久的な後遺症となり、その部位のヒットポイントが永続的に減少する。

### 魔法による治療

魔法の中には、犠牲者が負った傷を癒すものがある。しかし、各呪文で治療できる傷のレベルには特定の制限がある。例えば、神聖魔法の「軽傷治癒」呪文はその名の通り軽傷に最も効果的であり、「重傷治癒」呪文は軽傷と重傷の両方に最も効果的である。最も強力な魔法だけが、大怪我による外傷を即座に覆すことができる。

どんなに些細な回復呪文であっても、その適用はあらゆる種類の傷を安定させ、出血を防ぎ、たとえ根底にある怪我を実際に治癒しなくても即死を防ぐには十分である。これはあくまで大きな外傷に適用されるものであり、窒息や毒などによって引き起こされた状態には適用されないことに注意すること。

## 幸運ポイント

幸運ポイントは、英雄と一般人を区別するのに役立つ。これは、失敗を成功に変えたり、死を欺いたりするキャラクターの潜在的な能力を表す。

階級2に達し、その後すべての階級に達するたびに、キャラクターはボーナスとして幸運ポイントを1点得る。これはレベル制ゲームにおけるヒットポイントの増加を擬似的に表現したものであり、高階級のキャラクターがドラゴン、悪魔、魔王などを相手にしても、アフリカゾウ並みの耐久力を持つことなく立ち回れるようにするためのものである。

幸運ポイントはプレイ中に使用でき、次のセッションの開始時に通常の数値まで回復する。

#### 幸運ポイントの使用

幸運ポイントはさまざまな方法で使用できる。特定の1つのアクションをサポートするために使用できる幸運ポイントは1点のみである。幸運ポイントを経験点や訓練ロールに費やすことはできない。以下の各オプションには、幸運ポイントを1点消費する。

#### 運命の改竄

キャラクターは幸運ポイントを使用して、自分が行ったあらゆるダイスロールの振り直しや入れ替え（例えば75を57にするなど）ができる。これには技能ロール、ダメージロール、あるいは何らかの影響を及ぼすその他の判定が含まれる。キャラクターは敵に、自分に対して行われた攻撃ロールやダメージロールを強制的に振り直させることもできる。

#### 必死の努力

戦闘中にアクションポイントを使い果たし、無様な死を避けるために最後の必死のエネルギーが必要になった場合、キャラクターは幸運ポイントを消費して追加のアクションポイントを得ることができる。

#### ダメージの軽減

大怪我を負ったキャラクターは、幸運ポイントを消費して、その怪我を重傷に格下げすることができる。これにより、受けたダメージは大怪我を引き起こすために必要な数値よりも1ヒットポイント低い値まで軽減される。

## 罠

罠は、動物を捕獲するための落とし穴を掘ることから、永遠に墓を守るための死の罠に至るまで、あらゆる文化で使用される遍在する装置である。これらの装置は、警報を鳴らす、侵入者を捕らえる、あるいは泥棒を直接傷つけたり殺したりするために、それぞれ特定の目的で構築されている。

罠を建設するには、構築者が「機構」または「工学」技能を知っている必要がある。トラバサミや罠を仕掛けた錠前などの小さな罠には「機構」が必要であり、棘付きの落とし穴や転がる巨岩のような大規模な建設物には「工学」が必要である。

有能な職人を雇う以外に、罠には非常に高価な部品や人件費がかかることが多い。一般的なガイドラインとして、警報器は作成者の技能値を銅貨で、捕獲用の罠は銀貨で、そして死の罠は金貨で支払う必要がある。

すべての罠には、感知、解除、回避の難しさを示す難易度等級がある。この数値は、対抗ロールで抵抗される際の技能として扱われる。

語り手が語る多くの面白い物語にもかかわらず、罠、特に殺すことを目的とした罠は、一度作動し始めると、巧みに回避したりその影響を逆転させたりする方法はほとんどない。魔法や幸運がない限り、死の罠に捕らえられた者は、その極めて効率的な目的の犠牲になる。要するに、それらは生き残ることを意図していないのである。その罠に巧妙な設計や、ある種の永続的な魔法の付与が施されていない限り、一度作動した罠は手動でリセットしなければならない。

### 罠の特性

罠は以下の特性を使用して記述される。

#### 目的

罠の目的。大きく分けて4つのタイプがある：

- **警報:** 作動した際に無音または音響的な信号を送る。
- **捕獲:** 作動させた者や進入した者を捕らえるように設計されている。
- **傷害:** 作動させた者を致命的に負傷させることを意図している。
- **死:** 作動させた者の致死装置により殺害することを意図している。

#### トリガー

罠が作動する仕組み。

#### 難易度

罠の挑戦評価であり、それを作成した「機構」または「工学」技能の数値に等しい。例えば、「機構」70%の職人が宝箱の底に組み込んだ大鎌の罠は、難易度70%となる。この罠はその後、その鎌を見つけられるか、回避できるか、解除できるかを判断する対抗ロールにおいて、この数値を使用する。

#### 抵抗

罠がどのように抵抗されるか。通常は「腕力」、「回避」、または盾を組み込んだ「戦闘スタイル」でパリー（受け流し）を行う。抵抗は罠が作動した時に振られる。

#### 効果

罠が作動し、犠牲者が抵抗に失敗した場合に何が起こるか？通常、警報の場合は敵対者に警告が行き、捕獲用に設計された場合は犠牲者が捕らえられる。傷害や死の罠はもちろん犠牲者を負傷させるが、溺死や毒など、直接的なダメージ以外の手段を使用して危害を加える死の罠もある。あまりに致命的な罠を制限するために、ほとんどの機械装置が与えるダメージは作成者の技能によって制限される。ただし、毒を伴う罠など、作成者の実際の技能を考慮しないものもある。これは通常、使用される毒の費用によってバランスが取られている。これに対するもう一つの例外は落とし穴であり、ダメージは単純に穴の深さに基づく。これらの場合、作成者の技能は罠を見つけ、回避し、解除する確率を決定するために使用され、ダメージは毒の種類や落下距離に応じて適切に決定される。「体格（超能力）」は、パリー可能な発射体を発射する罠のために記載されている。

##### 死の罠のダメージ制限

| **作成者の技能** | **ダメージ** | **体格（超能力）** |
| :-: | :-: | :-: |
| 1-10% | 1d2 | 小型 |
| 11-20% | 1d4 | 小型 |
| 21-30% | 1d6 | 中型 |
| 31-40% | 1d8 | 中型 |
| 41-50% | 1d10 | 大型 |
| 51-60% | 2d6 | 大型 |
| 61-70% | 1d8+1d6 | 特大 |
| 71-80% | 2d8 | 特大 |
| 81-90% | 1d10+1d8 | 巨大 |
| 91-100% | 2d10 | 巨大 |

ダメージは複数のランダムな部位判定に影響を与える場合があり、追加の部位ごとに、「死の罠のダメージ制限」表のダメージが1等級ずつ減少する。例えば、技能50%の罠設計者は、1か所に1d10ダメージ、1d2の部位に1d8ダメージ、1d3の部位に1d6ダメージを与えるような罠を設計できる。潜在的な部位の数は罠の設計時に設定され、変更することはできない。追加の部位判定の数はランダムであるため、全体として与えられるダメージが少なくなる可能性がある。

### 罠のサンプル

#### 落とし穴

落とし穴は、あらゆる文化で使用される典型的な罠である。枝や葉で覆われた単純な掘り穴の形をしていることもあれば、犠牲者が落ちた後に蝶番で固定された偽の床が元の位置に戻るようにバランスがとられた、石壁の集水桝のような洗練されたものまである。

落とし穴は、特に深くある必要はない。捕獲を目的とする場合、単純なアンフォラやロブスターポットのような形状は、壁を彫って滑らかにしたり、キャラクターの体重で崩れるような脆い素材で作ったりすることで、よじ登りによる脱出を防ぐ。殺害を目的とする穴は、通常、底に何十本もの杭を密集させて敷き詰め、落ちたキャラクターが必然的に串刺しになるようにする。その他の選択肢として、底を弱い酸で満たしたり、溺れるのに十分な深さの水を張ったり、飢えたネズミを入れたりすることなどが考えられる。

- **目的:** 捕獲または死
- **トリガー:** 穴を覆っている偽の表面を歩くこと
- **難易度:** 60%
- **抵抗:** ジャンプして飛び越える「回避」、または落下する際にかろうじて縁を掴むための「運動」の「困難」判定。
- **効果:** 穴への落下は、ランダムな部位に2d6のダメージを与える。防具は保護しない。副次的な効果は、ゲームマスターの想像力に委ねられる。#### 毒針の罠

これは王の私室から忘れ去られた墓まで、至る所で見られるもう一つの一般的な罠である。この罠は通常、宝箱に仕掛けられているが、扉の鍵を保護していることもある。適切な鍵で開けなければ、この罠は、鍵を開けようとした者の手に小さな毒針を放つ。

- **目的:** 捕獲または殺害
- **トリガー:** 罠が仕掛けられた対象の鍵を開けようとする。
- **難易度:** 60%
- **抵抗:** 持久力
- **効果:** 発動すると、小さな毒針が飛び出し、鍵を開けようとした者の手に刺さる。毒針に塗る毒はどのようなものでも構わない。毒の詳細は、メインの『Classic Fantasy』ルールブックで詳しく扱われているため、ゲームマスターが具体的な内容を決定できる。
