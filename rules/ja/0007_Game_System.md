# 第7章：ゲームシステム

『クラシック・ファンタジー・インペラティブ』のゲーム中には、さまざまな出来事が起こり得ます。一部は技能の使用や、戦闘や魔法といった主要なゲームメカニクスを通じて解決されますが、それ以外のものは独自のルールに基づいて判定する必要があります。この章では、プレイヤーがゲームをプレイする際に遭遇する、多岐にわたるシナリオのルールと指針を提供します。

ここに挙げたリストは網羅的なものではありませんが、最も一般的な状況を表しているはずです。ゲームマスター（GM）が、ゲームシステムの判定を必要とする他の状況に遭遇し、かつそれらの状況が頻繁に発生すると判断した場合は、この章で提示されたルールを基礎として、独自のルールを作成・発展させることを推奨します。

## 年齢

すべてのキャラクターは年齢を重ね、それに伴い特定の帰結が生じます。加齢の兆候は「若中年」（人間で40歳。他の種族は以下に示す通り、より速い、または遅い速度で加齢します）から始まります。キャラクターが新しい年齢層に達するたびに、指定された難易度の持久力判定と意志力判定の両方を行わなければなりません。判定に失敗した場合、そのキャラクターは「年齢による影響」表に示される年齢の影響を受けます。

影響を受けた各能力値は1d3ポイント減少します。これらのポイントは、加齢に伴い自分自身を健康に保ち、活発であり続けようとする努力を表す「能力値向上」を通じて回復、あるいは少なくとも部分的に相殺することができます。加齢によって能力値がゼロまで減少した場合、キャラクターはその末期的な衰弱により死亡します。一度キャラクターが「老齢」の年齢層に達すると、種族にかかわらず毎年加齢判定が行われます。

加齢のプロセスの一部としてどのような具体的な衰弱が生じるかは、ゲームマスターが定義します。例えば、筋力、体力、敏捷性の減少は、関節のきしみや移動能力の段階的な喪失といった、身体の一般的な損耗を表します。知力の減少は、年齢が精神や記憶に悪影響を与え始めていることを示し、魅力の減少は、年を取るにつれてキャラクターが気難しくなり、おそらく短気になっていることを示しています。

## 窒息

キャラクターは自分の持久力技能の値に等しい秒数だけ息を止めることができます。ただし、キャラクターは準備をして（肺にできるだけ多くの空気を取り込んで）いる必要があります。そうでない場合、受動的な状況であればその時間は半分に、激しい活動に従事していた場合は5分の1に減少します。

息を止めていられる時間が過ぎたら、キャラクターは持久力判定を行わなければなりません：

- 判定がクリティカル成功であれば、それ以上の悪化は起こりません。
- 判定が成功であれば、キャラクターは疲労レベルを1段階追加で獲得します。
- 判定が失敗であれば、キャラクターはそのラウンド中に1d2段階の疲労を追加で受けます。
- 判定がファンブルであれば、キャラクターはそのラウンド中に1d3段階の疲労を追加で受けます。

助けがなければ、窒息による死は通常すぐ訪れます。窒息が終わる前にキャラクターが死亡しなかった場合、窒息によって失った疲労レベルは比較的早く回復し、1分ごとに1レベルずつ回復します。

窒息の方法によっては、ゲームマスターが完全な回復を妨げ、煙や水の吸い込みによって肺が受けた損傷を表すために、持続的な疲労レベルを課すことを望むかもしれません。

## キャラクターの向上

『クラシック・ファンタジー・インペラティブ』のすべてのキャラクターは、時間と経験とともに向上することができます。向上はいくつかの分野で行うことができます：

- 既存の技能を上げる
- 情熱を上げる
- 新しい技能を習得する
- 新しい能力を習得する

#### 経験判定

ほとんどのキャラクター向上のためのメカニズムは経験判定です。ゲームマスターは、キャンペーンの適切な節目で経験判定をプレイヤーに与えます。それは各シナリオやストーリーラインの終了時、あるいは、完了までに時間がかかる長いストーリーであれば、おそらく2～3回のセッションの後です。頻度はゲームマスターの裁量に委ねられます。経験判定の頻度が高ければ、キャラクターはより速い速度で成長します。

経験判定を与える正しいタイミングや間違ったタイミングはありませんが、ストーリーの自然な区切りが適切なタイミングを示唆しているかもしれません。しかし、決定を下すのは常にゲームマスターです。プレイヤーが経験判定を要求することはできませんが、ある特定の時期にそれを期待する権利はあります。なぜなら、経験判定がなければキャラクターは成長できないからです。

与えられる経験判定の数もゲームマスターによって決定されます。しかし、目安としては、前回の授与以降のセッションごとに1〜3回の経験判定が良いでしょう。

#### 既存技能の向上

キャラクターシート上の標準技能または専門技能は、経験判定を1回消費することで向上させることができます。プレイヤーは経験判定を技能向上に消費せず、蓄積して他のこと（クラス能力など、後述）の向上に使用することを選択できます。

- プレイヤーは1d100を振り、向上させようとしている技能と比較します。キャラクターの知力を判定値に加算します。
- 出目が向上させたい技能の値**以上**であれば、技能値は1d4+1%上昇します。
- 出目が選択した技能の値**未満**であれば、技能は上昇しますが、1%のみとなります。
- キャラクターが前回のセッション期間中（前回の経験判定から今回までの間）に技能判定でファンブルを起こしていた場合、ファンブルした技能は1%の無料上昇を得ます。成功から学ぶよりも失敗から学ぶことの方が多いというのは真理であり、これは壊滅的な失敗の後にキャラクターが経験する省察を表しています。同一技能で複数回ファンブルしても累積しません。ファンブルした技能を経験判定で向上させる場合、ファンブルによる1%は判定を行う前に適用されます。

同一セッション中に、同じ技能が2回以上の経験判定から恩恵を受けることはできません。

#### 情熱の向上

[情熱](0004_Alignment_and_Passions.md?id=passions)の項で説明した通り、情熱の値は技能と同じ方法で経験判定を使用して向上させることができます。プレイ内容によっては、ゲームマスターは経験判定を使用して情熱を低下させることを許可するかもしれません。

例えば、報われない恋による絶望的な拒絶は、最終的に最も熱心な恋人の情熱さえもすり減らすかもしれません。特に、過去の亡霊に悩まされることなく新しい関係を追求したいと願うキャラクターにとってはそうです。

#### 新しい技能の習得

一部のキャラクターは、故郷やクラスからは学ぶ機会がなかった新しい専門技能を学びたいと思うかもしれません。経験判定を投資し始める前に、まずは学ぶべき知識源を見つけなければなりません。これは、騎士団やギルドなどが提供する専門の教師のようにありふれたものかもしれません。あるいは、古く朽ちかけた訓練用スクロールのような、よりエキゾチックな教育源かもしれません。

教育源が見つかったら、キャラクターはまる1ヶ月間、学習と練習に費やしてその技能の基礎を身につける（ベースレベルで習得する）必要があります。これには3回の経験判定と、教師への支払い（もし存在する場合）、および必要な装備や道具を購入（またはレンタル）するためにかかるゲーム内の費用が必要です。

#### 新しいクラス能力の習得

キャラクターが必要な階級と技能レベル（もしあれば）を満たしていると仮定して、1回以上の経験判定を消費することでクラス能力を獲得または向上させることができます。これについては『第3章：クラス』の関連するクラス解説で詳述されています。技能とは異なり、これには通常、関連する能力を学ぶための知識源を探す必要はありません。必要な技能を繰り返し使用することで高度な技術を習得したと見なされるからです。経験判定のコストはキャラクターの現在の階級と等しく、多くの能力は特定の階級に達するまでロックされています。

## 落下

落下によって受けるダメージ量は、落下距離に依存します。防具による防護点は落下ダメージを軽減しませんが、落下したキャラクターやクリーチャーのダメージ修正はダメージロールに適用されます。

##### 落下距離表

| **落下高さ** | **ダメージ** |
| :-- | :-- |
| 5フィート以下 | ダメージなし |
| 6～15フィート | ランダムな1部位に1d6ダメージ |
| 16～30フィート | ランダムな2部位に2d6ダメージ |
| 31～45フィート | ランダムな3部位に3d6ダメージ |
| 46～60フィート | ランダムな4部位に4d6ダメージ |

#### 落下物

落下する物体は、その体格と落下距離に基づいてダメージを与えます。物体は体格6ポイントごとに（またはその端数）、1d6ダメージを与え、それに加えて「落下距離表」のダメージ欄に等しいダメージ（より小さなサイズの物体に対する減算を含む）を与えます。

## 疲労

疲労は疲れとその累積的な影響を測定します。激しい活動から病気の衰弱させる影響まで、さまざまな事柄を追跡するために使用されます。

疲労を獲得する主な方法は、何らかの身体活動に従事することです。運動や作業が過酷であればあるほど、キャラクターはより早く疲労します。ゲームマスターの裁量により、キャラクターは疲労レベルの獲得に抵抗するために、適切な技能判定（運動、腕力、持久力のいずれか）を行わなければなりません。

判定に失敗するたびに、疲労レベルを1段階獲得します。[疲労レベル表](0007_Game_System.md?id=疲労レベル表)に示すように、各疲労レベルは技能使用、移動、イニシアチブ、行動ポイントに対してペナルティを課します。窒息、失血、その他の設定に依存する影響も、疲労の累積に寄与します。

ほとんどのキャラクターにとって、「無力化」レベルに達するとどのような活動もほぼ不可能になります。この段階では、キャラクターは意識はありますが、最も切迫した活動以外は何もできません。

「無力化」を超えると、キャラクターはまったく行動できなくなります。「半意識」、「昏睡」、「死亡」といった疲労レベルは、通常、窒息、病気、失血、飢餓、露出などの最も極端な影響を測定するために残されています。

### 疲労からの回復

キャラクターは治癒率に応じて疲労から回復します。獲得した各疲労レベルから回復するために必要な完全な休息の時間は、回復期間をキャラクターの治癒率で割ったものに等しくなります。

この表は身体的労働による疲労回復を表していることに注意してください。[窒息](0007_Game_System.md?id=窒息)から回復する場合は疲労回復ははるかに速くなり、[失血](0007_Game_System.md?id=失血)から回復する場合は遅くなる可能性があります。

## 火

火は、武器として使用される場合や制御不能に燃え広がる場合、常に危険の源となります。以下の[火災強度表](0007_Game_System.md?id=火災強度表)は、熱ダメージの5つの強度と、その例を示しています。ラウンドごとに与えられるダメージはダメージ欄に記載されています。強度が1および2の火源は比較的小さいため、ダメージは1つの部位（通常は火源に触れている部位）に適用されます。強度3および4の火源はより大きく、最も近い1d4+1箇所の部位にダメージを与え、輻射熱の度合いを示しています。強度5の火源は、すべての部位に同時に影響を与えます。火は可燃物に引火する可能性があります。すぐ消火されない場合、そのような物質は火の強度に応じたラウンド数以内に燃え上がります。一度引火すると、可燃物は物理的に消火されるまで燃え続けます。ダメージは防具の防護点を無視して物体のヒットポイントに直接適用され、さらにその下の肉体にも適用されます。放置された場合、火は毎ラウンド、その強度に等しい数の部位へ燃え広がります。

##### 火災強度表

| **強度** | **例** | **引火までの時間** | **ダメージ** |
| :-: | :-- | :-: | :-: | :-: |
| 1 | 蝋燭 | 1d4 | 1d2 |
| 2 | 松明 | 1d3 | 1d4 |
| 3 | キャンプファイヤー | 1d2 | 1d6 |
| 4 | 部屋を満たす大火災 | 1d2 | 2d6 |
| 5 | 火山の溶岩 | 即時 | 3d6 |

#### 火属性の攻撃
 
火属性の攻撃は通常、1ラウンドで終了するため、可燃物に引火する確率をパーセンテージで持ちます。特に断りがない限り、火属性攻撃の場合は「ダメージロール×5%」、電気属性の場合は「ダメージロール×1%」の確率となります。一度引火すると、可燃物は物理的に消火されるまで毎ラウンド1d3-1のダメージを与えます。このダメージは防護点を無視して物体のヒットポイントに直接適用され、その下の肉体にも適用されます。ただし、クリーチャーの自然防護はその通常の防護を提供します。犠牲者は伏せて運動判定を成功させることで火を消そうと試みることができます。これには1行動ポイントを消費し、毎ターン試みることができます。他の者が何らかの方法で消火を手伝った場合、判定の難易度は1段階簡単になります。ダメージロールの結果が0ダメージであった場合、その部位の火は自然に消えています。自然に消えた部位ごとに、消火の判定難易度も1段階簡単になります。

## ゲーム時間

『クラシック・ファンタジー・インペラティブ』において、時間は重要な要素です。主に何がどの順番で起こるかを決定し、ゲームメカニクスを適用すべき時に適用するために使用されます。ゲーム内の時間は、通常プレイにかかる時間と同等ではないことを覚えておいてください。ゲームマスターは『城グレイマイヤーに到着するのに1週間かかる』といった一文で数日間の出来事を要約する必要があるかもしれません。その一方で、特に戦闘中などは、わずか数秒の時間が解決までに数分以上かかることもあります。

関連事項として：一部の呪文、アイテム、効果は1日に1回以上使用可能と記されています。これらを追跡するための簡単な方法は、各行動の発生日時を記録する代わりに、キャラクターが十分な夜の睡眠をとった後に時計がリセットされると仮定することです。したがって、1日に3回使用可能な魔法のアイテムを2回使用した場合、前日の夜に寝る直前に使用したとしても、次に目覚めたときにはすべての使用回数が回復します。

以下は、ゲーム時間における重要な区別です：

#### 戦闘ラウンド

戦闘ラウンドは現実時間の5秒を表します。これらは、完了するまでに瞬間を要する短く熱狂的な活動のバーストや、一撃ごとの解決が必要な非常に詳細な活動を測定するために使用されます。例えば、狩人と獲物の間の追跡戦において、各ラウンドが追跡の紆余曲折を決定します。

#### 探索ラウンド

探索ラウンドは現実時間の5分を表し、パーティがベース移動速度の3倍の速さで移動することを可能にします（人間や人間サイズの亜人は60フィート、より小さな亜人種族は45フィート）。探索ラウンドは通常、警戒を高く維持することが重要なダンジョン内での移動を測定するために使用されます。キャラクターは罠や待ち伏せに注意してゆっくりと移動し、隠密を維持しようとしています。また、パーティの誰かがマッピングを行っていると想定されます。誰もマッピングしていない場合、探索ラウンドは1分間として扱うことができます。探索ラウンドを使用すると、知覚判定をペナルティなしで行うことができます。ただし、通常通り他のペナルティが適用される場合があります。敵は探索速度で移動するパーティを発見することが1段階難しくなりますが、暗闇の場所で光源（松明やランタンなど）を使用している場合は、パーティの居場所が露見します。キャラクターが警戒を怠ってダンジョン内を移動することを決めた場合、探索ラウンドの代わりに戦闘ラウンドを使用して移動できます。ただし、その場合、知覚判定は1段階難しくなり、敵はパーティを発見する際の知覚ペナルティを受けません。プレイヤーにダンジョン全体を公開するバトルマットを使用しているとき、あるいはゲームマスターがダンジョンの地図を描いているときは、パーティは**常に**マッピングを行っており、探索速度で移動していると想定すべきであることに注意してください。

#### 技能時間

技能時間は数分から数時間の時間を表し、戦闘ラウンドのような詳細な注意を必要としないが、明確な結果を伴う特定の努力を必要とする活動を測定するために使用されます。鍵開けは5分かかるかもしれませんが、城壁の周りをパトロールする衛兵の動きを観察するには数時間を要するかもしれません。どちらも技能時間の例です。#### ナラティブ・タイム（物語時間）

これはゲームマスターがプレイヤーに対して物語を語る際や、プレイヤー同士が議論している時に経過する時間のことです。特別な理由がない限り、実際のロールプレイングのほとんどはナラティブ・タイム内で行われます。ロールプレイング中、ナラティブ・タイムはリアルタイムに近く、会話には実際にプレイするのと同じだけの時間がかかります。ゲームセッションに長時間の移動が含まれる場合や、正確な時間が重要ではない活動期間がある場合、時間はゲーム内時間においてごくわずかな瞬間へと大幅に圧縮されます。

### 短休憩

短休憩とは、冒険者たちが息を整えるために立ち止まる約15分間の時間を指します。この間、読書、飲食、祈り、傷の手当といった激しい動きを伴わない行動以上のことは行われません。パーティーはどれくらいの時間休憩するかを決定し、その後15分間の関連する行動をそれぞれ行います。各プレイヤーは次の行動に移る前に一つずつ行動を実行します。1日の間、パーティーが取れる短休憩の回数に制限はありません。通常、キャンプを設営した後や、出発前の朝などに、いくつかの休憩行動が行われます。各15分間の休憩行動は以下の通りで、特に記載がない限り複数回実行可能です。

- **食料を食べる:** この15分間の休憩行動は、食料が日次アイテムとして管理されているため、1日1回のみ実行可能です。これにより、「疲労困憊」以下の任意のレベルの「疲労」が1つ取り除かれ、あらゆる空腹が解消されます。キャラクターは激しい運動を伴わない活動であるため、食後、「息切れ」以下の状態であれば「疲労」をもう1レベル下げることができます。
- **神格への祈りまたは呪文の書を学習する:** 祈りや学習に費やした15分間の休憩行動ごとに「マジックポイント」を1点回復します。キャラクターは激しい運動を伴わない活動であるため、「息切れ」以下の状態であれば「疲労」を1レベル下げることができます。
- **傷の手当:** 「応急手当」技能を使用して15分間の休憩行動を消費する、あるいは「治癒」技能を使用して4回（1時間）の休憩行動を消費します。
- **1つ以上の呪文を唱える:** パーティーメンバーを回復または強化するために、15分間の休憩行動中に任意の数の呪文を唱えることができますが、利用可能な「マジックポイント」に制限されます。
- **新しい呪文を準備する:** 少なくとも8時間の睡眠をとった後、呪文の使い手は15分間の休憩行動を使用して、[呪文の記憶](0009_Magic.md?id=memorizing-spells)で詳述されている制限に従い、秘術呪文または神聖呪文を記憶（あるいは忘却）することができます。
- **ぐずぐずする:** 他の行動が選択されない場合のデフォルトの15分間の休憩行動です。キャラクターは役に立つことを何もせず15分間を浪費します。この休憩行動は、通常、パーティーの他のメンバーがまだ休憩行動を行っており、他にすることがない場合に行われます。キャラクターは激しい運動を伴わない活動であるため、「息切れ」以下の状態であれば「疲労」を1レベル下げることができます。

## 部位判定

ほとんどの成功した（武器による）攻撃は、特定の「部位判定」に着弾します。これはランダムに決定されるか、あるいは状況によっては「部位選択」などの「特殊効果」によって選択されることがあります。どの部位に命中したかをランダムに算出するには、1d20をロールし、その出目を該当する人型生物またはクリーチャーの「部位判定」表と比較します。

動物やモンスターは、自身の独自の生理機能を反映するため、通常、人型生物とはわずかに異なる「部位判定」表を持っています。これらは各存在の説明の一部として記載されており、通常はゲームマスターのみが利用します。

人型生物の「部位判定」表を以下に再掲します。

### 人型生物の部位判定

| **1d20** | **部位判定** |
| :-: | :-- |
| 1-3 | 右脚 |
| 4-6 | 左脚 |
| 7-9 | 腹部 |
| 10-12 | 胸部 |
| 13-15 | 右腕 |
| 16-18 | 左腕 |
| 19-20 | 頭部 |

一部の攻撃、特に魔法によるものや、特定のモンスター（レッドドラゴンの炎のブレスなど）が放つ攻撃は、複数の部位に同時に命中する可能性があることに注意してください。個々の部位には、装備による防護や、クリーチャーの外皮の本来の硬さによって、「防具」が適用される場合があります。これは以下の「ダメージ」と「負傷レベル」を考慮する際に重要です。

### ダメージと負傷レベル

攻撃が成功した場合、その武器のダメージ等級に従ってダメージを与えます（[お金と装備](0006_Money_and_Equipment.md?)章の[近接武器](0006_Money_and_Equipment.md?id=basic-melee-weapons)および[射撃武器](0006_Money_and_Equipment.md?id=basic-ranged-weapons)の表を参照）。例えば、ショートソードは1d6ダメージを与えます。

武器や攻撃のロールされたダメージは、以下の特定の順序で条件によって修正されます：

- 攻撃を行うキャラクターの「ダメージ修正」を適用する。
- 武器を強化（または減少）させる魔法からのダメージを修正する。
- 受け流した場合、比較する武器のサイズに従って適切にダメージを減少させる。
- 「部位判定」に「防具」がある場合、「防具」のポイント値分だけダメージを減少させる。

攻撃によって与えられたダメージがゼロより大きい場合、その部位は同量のダメージを受け、合計ダメージは即座にその部位の「ヒットポイント」から差し引かれます。その部位に何「ヒットポイント」が残っているか、そしてその結果としてどの負傷カテゴリーに該当するかを記録してください。

- **軽傷:** 部位の「ヒットポイント」がプラスの状態。
- **重傷:** 部位の「ヒットポイント」がゼロ以下になった状態。
- **致命傷:** 部位の「ヒットポイント」が、その開始時の「ヒットポイント」と同等以上のマイナス値にまで減少した状態。

部位が重傷または致命傷を受けた場合は、以下のルールを使用してください。負傷に対する「持久力」チェックは、攻撃側のロールの数値と対抗ロールを行う必要があることに注意してください。これは、熟練した戦士ほど致命的な打撃を与えることができる能力を反映しています。部位が再び負傷しない限り、「持久力」ロールは繰り返されません。

#### 軽傷

軽傷は切り傷、ひっかき傷、打撲、捻挫です。これらは痛み、出血することもありますが、犠牲者を減速させたり妨げたりするほど重大ではありません。

#### 重傷

部位の「ヒットポイント」がゼロ以下になった場合、犠牲者は重傷を負います。その部位には永久的な傷が残り、犠牲者はその痛みによる気絶や混乱のため、次の1d3ターンの間、攻撃や呪文の詠唱開始を行うことができません（ただし、「受け流し」や「回避」は可能です）。

手足に重傷を負ったキャラクターは、即座に自身の「持久力」と敵の攻撃成功ロールとの対抗ロールを行わなければなりません。失敗すると、その部位がプラスの「ヒットポイント」に回復するまで、手足は使用不能になります。脚であれば犠牲者は伏せ状態になります。腕であれば、ストラップなどで固定されていない限り、保持しているものは落とします（ここでは常識を働かせてください）。

腹部、胸部、または頭部に重傷を負ったキャラクターは、即座に自身の「持久力」と敵の攻撃成功ロールとの対抗テストを行わなければなりません。失敗すると、重傷を引き起こした攻撃で受けたダメージ量に等しい分数の間、意識を失います。気絶した犠牲者が重傷を負った部位をさらに回復させるために、「応急手当」または「治癒」技能を使用することができます。

ゲームマスターの裁量により、キャラクターが行動可能であっても、その部位を使用するすべてのタスクは、その負傷が「軽傷」に軽減されるまで、「難易度」が1段階低下するペナルティを受け続けます。

#### 致命傷

部位が開始時の「ヒットポイント」と同等以上のマイナススコアまで減少した場合、キャラクターは致命傷を負います。キャラクターは即座に「無力化」され、戦闘を継続できなくなります。致命傷によって手足は切断、貫通、粉砕、あるいは引きちぎられます。キャラクターは伏せ状態となり、身体的に「無力化」され、即座に自身の「持久力」と敵の攻撃成功ロールとの対抗テストを行わなければなりません。失敗すると苦悶のあまり意識を失います。切断、貫通、あるいは引きちぎられた部位が、「治癒率」の5倍に等しい分数の時間内に手当されなければ、キャラクターは出血とショックにより死亡します。

腹部、胸部、または頭部に致命傷を負った犠牲者は意識を失い、完全に「無力化」され、即座に自身の「持久力」と敵の攻撃成功ロールとの対抗テストを行わなければなりません。失敗すると、即座に惨たらしい死を迎えます（斬首、胴体切断、心臓への刺突、四肢の引き裂きなど）。生き残ったとしても、「治癒率」の2倍に等しい戦闘ラウンドの時間内にその部位が手当されなければ、依然として出血とショックにより死亡します。

ほとんどの致命傷は回復のために外科手術や強力な魔法を必要とするため、負傷者が致命傷から回復して戦闘に復帰することは非常に困難です。利用可能な治療法に応じて、負傷した部位は恒久的に不具になる可能性があります（[怪我からの回復](0007_Game_System.md?id=healing-from-injury)を参照）。

### 出血

通常戦闘で負う外傷や内傷による出血は、キャラクターを急速に消耗させます。その影響は[窒息](0007_Game_System.md?id=asphyxiation)と同様に、「疲労」レベルの蓄積によって測定されます。抑制されない出血は、医療処置がなければ通常、死に至ります。窒息とは異なり、深刻な出血が「疲労」に与える影響は長引きます。キャラクターは出血が止まった翌日から、1日1レベルの速度で出血によって失った「疲労」を回復します。

#### 英雄的な最後のアクション

重要なキャラクターが致命傷を負うという特殊なケースでは、ゲームマスターは英雄的な最後のアクションを許可するかもしれません。例えば、最後の一撃を放つ、自分を殺した相手を切り倒そうとする、這って隠れる、あるいは自分自身の傷を止血しようと試みるなどです。彼らはそのアクションに適した機能する手足を持っていなければならず、「幸運ポイント」を消費する必要があります。彼らはアクションを試みる機会を1回だけ得て、その後すぐに意識を失い、おそらく死亡します。

## 怪我からの回復

傷や怪我からの自然治癒は、キャラクターの「治癒率」に基づいています。「治癒率」は、怪我の性質に応じて、どの程度の期間で各部位の「ヒットポイント」が回復するかを規定します：

- 軽傷：日数
- 重傷：週数
- 致命傷：月数

したがって、「治癒率」が3のキャラクターがダメージを受けて部位が–3（重傷）になった場合、その傷がゼロを超えるまで週に3「ヒットポイント」ずつ自然治癒し、その後は完全に回復するまで1日につき3「ヒットポイント」ずつ回復します。

自然治癒には特定の制限があります：

- 治癒中のキャラクターは激しい活動に従事できません。さもなければ、「治癒率」が1d3減少します。したがって、軽傷から回復中のキャラクターであっても、怪我を悪化させる可能性のある物理的な作業に従事しようとすれば、回復が停滞する可能性があります。
- 自然治癒は、犠牲者が[治癒](0005_Skills.md?id=healing-intpow)技能の成功、または「キュア・ワンズ」呪文のいずれかによる治療を受けるまで、致命傷の治癒を開始しません。「治癒」技能の「治癒率」の20分の1に相当する日数以内に治療されなかった、四肢切断を伴わない致命傷は不具となり、その部位の「ヒットポイント」が恒久的に減少します。

### 魔法による回復

一部の魔法は犠牲者が負った傷を癒すことができます。しかし、各呪文で治療可能な傷のレベルには特定の制限があります。例えば、神聖魔法の「キュア・マイナー・ワンズ」呪文は、その名の通り軽傷に対して最も効果的ですが、「キュア・シリアス・ワンズ」呪文は軽傷と重傷の両方に対して最も効果的です。最も強力な魔法のみが、致命傷による外傷を即座に逆転させることができます。

どんなに些細な回復呪文であっても、その適用は、根本的な怪我を実際に治癒するものでなくとも、出血や即死を防ぐためにあらゆる種類の傷を安定させるのに十分です。これはあくまで総体的な物理的外傷に適用されるものであり、窒息や毒などによって引き起こされる状態には適用されないことに注意してください。

## 幸運ポイント

「幸運ポイント」は、英雄と一般人を区別するのに役立ちます。これは、失敗を成功に変え、さらには死を回避する可能性というキャラクターの能力を表しています。

ランク2に達した時、およびそれ以降の各ランクで、すべてのキャラクターはボーナスとして「幸運ポイント」を1点獲得します。これはレベル制ゲームにおける「ヒットポイント」の増加をある程度シミュレートするものであり、高ランクのキャラクターが、アフリカゾウ以上の打撃を受け続けさせられることなく、ドラゴンやデーモン、悪魔などに対してより上手く立ち回れるようにします。

「幸運ポイント」はプレイ中に使用でき、次のセッションの開始時に通常の数値まで補充されます。

#### 幸運ポイントの使用

「幸運ポイント」は様々な方法で使用できます。特定の「アクション」をサポートするために使用できる「幸運ポイント」は1回に1点のみです。「幸運ポイント」は、「経験」や「訓練」ロールに費やすことはできません。以下の各オプションは「幸運ポイント」を1点消費します。

#### 運命の操作

キャラクターは「幸運ポイント」を使用して、自分が行ったダイスロールを振り直すか、入れ替えることができます（例えば、75を57にするなど）。これは「技能」ロール、ダメージロール、あるいは何らかの影響を与えるその他のロールのいずれでも構いません。キャラクターは、自分に対して行われた敵の攻撃ロールやダメージロールを強制的に振り直させることさえできます。

#### 絶望的な努力

戦闘中にすべての「行動ポイント」を使い果たし、恐ろしい死を避けるために最後の絶望的なエネルギーを見出す必要がある場合、キャラクターは「幸運ポイント」を消費して追加の「行動ポイント」を1点獲得できます。

#### ダメージの軽減

致命傷を負ったキャラクターは、「幸運ポイント」を消費してその怪我を重傷に格下げできます。これにより、受けるダメージが致命傷を与えるのに必要な数値より1「ヒットポイント」少ない数値まで軽減されます。

## トラ罠

罠は、動物を捕らえるための落とし穴の掘削から、永遠に墓を守るための死の罠に至るまで、あらゆる文化で使用されている遍在的な装置です。これらの装置は、警報を鳴らす、侵入者を捕らえる、あるいは泥棒を直接傷つけたり殺したりするという、目的の範囲に合わせて構築されています。

罠を建設するには、作成者が「機械」または「工学」技能のいずれかを知っている必要があります。熊取り罠や仕掛け錠のような小さな罠には「機械」が必要ですが、スパイク付きの落とし穴や転がる大岩のような大規模な建設には「工学」が必要です。

有能な職人を雇う以外に、罠には非常に高価なコンポーネントや手作業による人件費がかかることがよくあります。一般的なガイドラインとして、警報は作成者の技能値を銅貨で換算したコストがかかり、捕獲用の罠は同じ数値の銀貨、死の罠は金貨での支払いが必要です。

すべての罠には「難易度」等級があり、これは感知、武装解除、または回避の難しさを表しています。「対抗ロール」で抵抗される際、この数値がその罠の技能として扱われます。

語り手が語る多くの面白い物語にもかかわらず、罠、特に殺すことを目的とした罠は、一度動き出すと巧みに回避したりその効果を反転させたりする方法はほとんどありません。魔法や幸運がない限り、死の罠に捕まった者は、通常、その非常に効率的な目的の前に屈することになります。要するに、それらは生き残ることを意図していません。罠に巧妙な設計があるか、一種の持続的な魔法の付与でない限り、一度発動すると手動でリセットする必要があります。

### 罠の特徴

罠は以下の特徴を使用して説明されます。

#### 目的

罠の目的です。4つの主要なタイプがあります：

- **警報:** 罠が作動したことを無音または音響信号で伝えます。
- **捕獲:** 罠は、作動させた者や侵入した者を捕らえるように設計されています。
- **傷害:** 罠は、作動させた者を致命的に負傷させることを意図しています。
- **死:** 罠は、その致死的な装置を作動させた者を殺すことを意図しています。

#### トリガー

罠が作動する方法です。

#### 難易度

罠の挑戦等級で、それを作成した「機械」または「工学」技能の数値に等しくなります。例えば、「機械」70%を持つ職人によって宝箱の底に組み込まれた大鎌の刃の罠は、罠に70%の「難易度」を与えます。それ以降、罠はこの数値を「対抗ロール」で使用し、刃が見つけられるか、回避できるか、武装解除できるかを確認します。

#### 抵抗

罠に対する抵抗方法です。通常は「腕力」、「回避」、または盾を組み込んだ「戦闘スタイル」での「受け流し」を使用します。抵抗は罠が作動した時にロールされます。

#### 効果

罠が発動し、犠牲者が抵抗に失敗した場合に何が起こるかです。通常、これは警報であれば敵対者への通報、捕獲用であれば犠牲者の捕獲という結果になります。傷害罠や死の罠は当然犠牲者を負傷させますが、溺死や毒など、直接的なダメージ以外を使用して危害を加える死の罠もあります。過度に致命的な罠を制限するために、ほとんどの機械装置が与えるダメージは作成者の技能によって制限されます。しかし、犠牲者を毒にさらす罠などの他のものは、作成者の実際の技能を考慮しません。これは通常、使用される毒の費用によってバランスが取られています。これのもう一つの例外は落とし穴であり、ダメージは単にピットの深さに基づいています。これらの場合、作成者の技能は罠を見つけ、回避し、武装解除する確率を決定するために使用されます。ダメージは、必要に応じて毒の種類や落下距離に従って決定されます。力は「受け流し」可能な発射体を発射する罠のために記載されています。

##### 死の罠のダメージ制限

| **作成者の技能** | **ダメージ** | **体格（超能力）** |
| :-: | :-: | :-: |
| 1-10% | 1d2 | 小 |
| 11-20% | 1d4 | 小 |
| 21-30% | 1d6 | 中 |
| 31-40% | 1d8 | 中 |
| 41-50% | 1d10 | 大 |
| 51-60% | 2d6 | 大 |
| 61-70% | 1d8+1d6 | 巨大 |
| 71-80% | 2d8 | 巨大 |
| 81-90% | 1d10+1d8 | 莫大 |
| 91-100% | 2d10 | 莫大 |

ダメージは複数のランダムな「部位判定」に影響を与える可能性があり、追加の各部位ごとに「死の罠のダメージ制限」表のダメージ等級を1つずつ減少させます。例えば、50%の技能を持つ罠設計者は、1つの部位に1d10ダメージ、1d2の「部位判定」に1d8ダメージ、1d3の部位に1d6ダメージなどを与える罠を設計できます。潜在的な部位の数は罠が設計される時に設定され、変更することはできません。追加の「部位判定」の数はランダムであるため、全体的に与えられるダメージが少なくなる可能性があります。

### サンプル罠

#### 落とし穴

落とし穴は、あらゆる文化で使用されている典型的な罠です。枝や葉で覆われた単純な掘られた穴の形をとることもあれば、犠牲者が落ちた後に蝶番のついた偽の床が元の位置に戻るようにバランスが取られた、石壁のくぼみのような洗練された形をとることもあります。

落とし穴は特に深くある必要はありません。捕獲を目的とする場合、単純なアンフォラやロブスターポットの形状が登って逃げるのを防ぎます。同様に、壁を滑らかに削ったり、キャラクターの体重で崩れるような脆い材料で作ったりすることでも可能です。殺すことを目的とする落とし穴は、通常、底に何十本もの杭が密集して敷き詰められており、落下したキャラクターは必然的に串刺しになります。その他の選択肢としては、底を弱酸、溺れるのに十分な深さの水、あるいは飢えたネズミで満たすことも考えられます。

- **目的:** 捕獲または死
- **トリガー:** 穴を覆う偽の地面の上を歩くこと
- **難易度:** 60%
- **抵抗:** ジャンプして飛び退くための「回避」、あるいは落下した際に端をつかむための「運動」の困難なロール。
- **効果:** 穴への落下は、ランダムな「部位判定」に2d6ダメージを与え、「防具」は保護しません。二次的な効果はゲームマスターの想像力に委ねられます。#### 毒針の罠

これは王の私室から忘れ去られた墓所まで、至る所で見られる一般的な罠である。この罠は通常、宝箱に仕掛けられているが、扉の鍵を守るために設置されていることもある。適切な鍵を使わずに開けようとすると、この罠は小さな毒針を射出し、錠前を開けようとした者の手に突き刺さる。

- **目的:** 拘束または死
- **トリガー:** 罠が仕掛けられた対象の錠前を開けようとすること。
- **難易度:** 60%
- **抵抗:** 持久力
- **効果:** トリガーが作動すると、小さな毒針が飛び出し、錠前を開けようとした者の手に突き刺さる。毒針にはいかなる毒も塗布することができる。毒の詳細は『Classic Fantasy』の基本ルールで詳述されており、ゲームマスターは毒の種類を決定できる。
