#### ヤード・ポンド法からメートル法への換算

『Classic Fantasy Imperative』の提示をよりクリーンにし、読みやすくし、記述や表を簡潔にするため、『Classic Fantasy Imperative』のラインナップではヤード・ポンド法とメートル法の両方ではなく、ヤード・ポンド法に焦点を当てます。このジャンルの他のゲームで使用されるアドベンチャー、バトルマット、マップのほとんどがヤード・ポンド法を採用しているため、既存の資料の変換をより円滑に行えるようヤード・ポンド法が選択されました。しかし、メートル法を使用したい方のために、最も一般的に使用される重量と長さの単位を以下の表で換算しています。通常、現実世界の生き物や呪文などを扱っているわけではないため、作成された重量や長さには多少の余裕を持たせることができます。正確な換算値を使用するよりも、覚えやすくゲームプレイを促進できる換算値を使用する方が簡単です。

#### 風力表

| 時速 (MPH) | タイプ | 技能への影響 | 移動への影響 |
| :-: | :-- | :-- | :-- |
| 0-10 | 無風 | なし | なし |
| 11-20 | 中程度のそよ風 | なし | なし |
| 21-30 | 強いそよ風 | なし | 3分の2 |
| 31-40 | 軽風 | 困難 | 3分の2 |
| 41-50 | 中程度の強風 | 困難 | 半分 |
| 51-60 | 強風 | 至難 | 半分 |
| 60+ | 嵐/ハリケーン | 至難 | 3分の1 |

風、特に非常に強い風は、活動に悪影響を及ぼす可能性があります。風の強さ（筋力）は時速（マイル毎時）で表されます。物理的な技能（筋力や敏捷性に関連するもの）への影響は「技能」の列に詳述されており、移動速度への影響は「移動速度」の列に詳述されています。

_例えば、時速40マイルの軽風は、人間の歩行速度を3分の2に減少させ、技能判定は困難難易度で行われます。_

#### 気温表

| 気温 (ºF) | タイプ | リスク |
| :-: | :-: | :-- |
| < 2º | 氷河期 | 直ちに暖を取る場所を探すこと |
| 3-14º | 氷点下 | 15分 |
| 13-32º | 寒冷 | 1時間 |
| 33-50º | 冷涼 | 日次 |
| 51-68º | 涼しい | - |
| 69-86º | 温暖 | - |
| > 86º | 高温 | 1時間 |

気温は、キャンペーンの世界やシナリオの設定場所によって、気候、季節、標高に応じて劇的に変化する可能性があります。上記の表は、極端な気温がキャラクターに与える影響のガイドラインを示しています。

適切な衣類を着用することで、キャラクターは「リスク」列に示されている通り、自身の「体力（体力）」の値を時間単位とした猶予期間を得られます。この時間を過ぎると、避難場所を探すか、あるいは「疲労」によるダメージを受け始めます。濡れているキャラクターは、リスク率が1段階寒冷側にシフトします。軽風または中程度の強風もリスク率を1段階寒冷側にシフトさせ、強風や嵐は2段階シフトさせます。
