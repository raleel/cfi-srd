# 付録：換算表

---
#### ヤード・ポンド法からメートル法への換算

『Classic Fantasy Imperative』をよりすっきりと見やすくし、説明や表を簡潔にするため、『Classic Fantasy Imperative』シリーズではヤード・ポンド法とメートル法の併記ではなく、ヤード・ポンド法を中心に記載しています。ヤード・ポンド法が採用された理由は、このジャンルの他のゲームで使用されている既存の冒険シナリオ、バトルマット、地図のほとんどがヤード・ポンド法に基づいているため、それらの換算を容易にするためです。とはいえ、メートル法の使用を希望される方のために、最も一般的に使用される重量や寸法の換算表を以下にまとめました。現実世界の生物や呪文などを扱っているわけではないため、作成された数値には多少の余裕を持たせています。厳密な換算を行うよりも、覚えやすい数値を使用する方がゲームプレイを円滑に進められるでしょう。

#### 風力表

| 時速(MPH) | 種類 | スキルへの影響 | 移動への影響 |
| :-: | :-- | :-- | :-- |
| 0-10 | 無風 | なし | なし |
| 11-20 | 微風 | なし | なし |
| 21-30 | 強風 | なし | 3分の2 |
| 31-40 | 軽度の嵐 | 困難(Hard) | 3分の2 |
| 41-50 | 中程度の嵐 | 困難(Hard) | 半分 |
| 51-60 | 強烈な嵐 | 非常に困難(Formidable) | 半分 |
| 60以上 | 暴風雨/ハリケーン | 非常に困難(Formidable) | 3分の1 |

風、特に非常に強い風は、活動に悪影響を及ぼす可能性があります。風の強度（STR）は時速（マイル）で表されます。STRやDEXを伴う身体的スキルへの影響は「スキル」欄に、移動速度への影響は「移動への影響」欄に詳しく記載されています。

_例えば、STR 40の「軽度の嵐」は人間の歩行速度を3分の2に減少させ、スキル判定は「困難(Hard)」で行われます。_

#### 温度表

| 温度 (ºF) | 種類 | リスク |
| :-: | :-: | :-- |
| 2º未満 | 極寒 | 直ちに暖を取る場所を探す |
| 3-14º | 凍結 | 15分ごと |
| 13-32º | 寒冷 | 1時間ごと |
| 33-50º | 冷涼 | 1日ごと |
| 51-68º | 涼しい | - |
| 69-86º | 温暖 | - |
| 86º超 | 高温 | 1時間ごと |

気温は、キャンペーンの世界設定やシナリオの舞台に応じて、気候、季節、標高により劇的に変化します。上記の表は、極端な気温がキャラクターに及ぼす影響のガイドラインを示しています。

適切な衣服を着用していれば、キャラクターは「リスク」欄に示された間隔の分だけ、CONの値に応じた猶予時間を得てから露出による影響を受け始めます。この時間を超えると、シェルターを探すか、疲労によるダメージを受け始めます。濡れているキャラクターは、リスク発生率が1段階寒冷側にシフトします。また、軽度または中程度の嵐の強風もリスク発生率を1段階寒冷側にシフトさせ、強烈な嵐や暴風雨の場合は2段階シフトさせます。
