#### ヤード・ポンド法からメートル法への換算

『Classic Fantasy Imperative』の提示をすっきりとさせ、読みやすくし、説明や表を簡潔にするため、『Classic Fantasy Imperative』ラインではヤード・ポンド法とメートル法の両方ではなく、ヤード・ポンド法に焦点を当てます。このジャンルの他のゲームで使用されているほとんどの冒険、バトルマット、地図がヤード・ポンド法を採用しているため、既存の資料の変換をより容易にするという理由でヤード・ポンド法が選ばれました。しかし、メートル法を使用したい人のために、最も一般的に使用される重量と長さの単位を以下の表で換算しました。通常、現実世界の生き物や呪文などを扱っているわけではないため、作成した重量や長さにある程度の余裕を持たせることができます。正確な換算値を使用するよりも、記憶しやすい値を使用した方がゲームプレイを促進しやすいためです。

#### 風力表

| MPH | 種類 | 技能への影響 | 移動への影響 |
| :-: | :-- | :-- | :-- |
| 0-10 | 無風 | なし | なし |
| 11-20 | 軽風 | なし | なし |
| 21-30 | 順風 | なし | 3分の2 |
| 31-40 | 弱風 | 困難 | 3分の2 |
| 41-50 | 中風 | 困難 | 半分 |
| 51-60 | 強風 | 至難 | 半分 |
| 60+ | 嵐/暴風 | 至難 | 3分の1 |

風、特に非常に強い風は、活動に悪影響を及ぼす可能性があります。風の強さ（筋力）は、時速（マイル）で表されます。物理的な技能（筋力または敏捷性に関係するもの）への影響は「技能」の列に詳述されており、移動速度への影響は「移動速度」の列に記載されています。
 
_例えば、筋力40の弱風は、人間の歩行速度を3分の2に減少させ、技能判定は「困難」難易度で行われます。_

#### 気温表

| 気温 (ºF) | 種類 | リスク |
| :-: | :-: | :-- |
| < 2º | 極寒 | 直ちに暖を取れ |
| 3-14º | 氷点下 | 15分 |
| 13-32º | 寒冷 | 1時間 |
| 33-50º | 冷涼 | 1日 |
| 51-68º | 涼しい | - |
| 69-86º | 温暖 | - |
| > 86º | 酷暑 | 1時間 |

気温は、キャンペーンの世界やシナリオの設定場所によって、気候、季節、標高により劇的に変化する可能性があります。上記の表は、極端な気温がキャラクターに与える影響のガイドラインを提供します。

適切な衣服を着用している場合、キャラクターは「リスク」の列に示されている時間（時間単位の体力値）の間、猶予期間を得てから影響を受け始めます。この時間を過ぎると、避難場所を探すか、疲労の喪失を受け始める必要があります。濡れているキャラクターは、リスク率が1段階寒くなります。軽風や中風もリスク率を1段階寒くし、強風や嵐は2段階寒くします。
