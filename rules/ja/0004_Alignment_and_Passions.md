# 第4章：属性と情熱

『Classic Fantasy Imperative』において属性と情熱を使用することは、キャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、さらにプレイヤーが自身のキャラクターが何者であり、何に駆り立てられているのかを理解する一助として、プレイヤーやゲームマスターにとって非常に役立ちます。本章で提示される具体的な属性や情熱の選択はプレイヤーに委ねられていますが、前章のキャラクター[クラス](0003_Classes.md)に関連するいくつかの項目は、そのキャラクターをプレイする上で必須となります。本書のクラスには特定の属性や情熱を要求するものはありませんが、クレリックや（盗賊ギルドに所属する）ローグのように、教団やギルドへの「誓い（Oath）」を必要とするものがあります。誓いは、ゲームシステム上では情熱として扱うことができます。

---
## 属性

すべてのキャラクターは、2つの要素から構成される属性を持たなければなりません。それは「倫理規範」と「道徳規範」です。倫理規範は法と混沌に対する姿勢を定義し、道徳規範は善と悪に対する感情を決定します。キャラクターはそれぞれについて1つまたは2つの定義要素を選択し、初期パーセンテージを決定します。例えば、「混沌（無秩序で強欲）55%」や「善（協力的で寛大）55%」といった具合です。中立を2回選択することはできません。その代わり、道徳規範と倫理規範の両方を無視し、単一の属性として「真なる中立」を選択します。倫理規範および道徳規範は、それぞれの定義要素とともに以下に詳述します。

#### 倫理規範

「秩序」、「中立」、「混沌」から1つを選択し、基本値を「知力+霊力+30」とします。

- **秩序** : あなたの倫理規範を最もよく表す定義要素を1つまたは2つ選択してください：_伝統の遵守、計算高い、偏狭、混沌を憎む、倫理的、正直、名誉を重んじる、批判的、適応力の欠如、ユーモアの欠如、正当な権威への服従、組織的、予測可能、信頼できる、人を信じる、信用に足る、行儀が良い。_
- **中立** : あなたの倫理規範を最もよく表す定義要素を1つ選択してください：_秩序と混沌は偏見であり危険な極端な考えだと信じている、慎重、うぬぼれが強い、秩序と混沌について強いこだわりがない、柔軟、行動の自由、確立された倫理規範を持たない、実用的、自然を尊重する。_
- **混沌** : あなたの倫理規範を最もよく表す定義要素を1つまたは2つ選択してください：_行儀が悪い、血に飢えている、好奇心旺盛、皮肉屋、不正直、不名誉、無秩序、正当な権威への無関心、利己主義、自由、秩序を憎む、無責任、無法者、誇大妄想、悪戯好き、短気、荒々しい、無謀、疑い深い、制御不能、信用できない、予測不能、信頼できない。_

#### 道徳規範

「善」、「中立」、「悪」から1つを選択し、基本値を「知力+霊力+30」とします。

- **善** : あなたの道徳規範を最もよく表す定義要素を1つまたは2つ選択してください：_称賛に値する、利他的、天使のような、権威ある、慈善的、罪なき者を傷つけることへの呵責、誠実、寛容、友好的、悪を憎む、協力的、親切、自然を愛する、慈悲深い、楽観的、前向き、菜食主義。_
- **中立** : あなたの道徳規範を最もよく表す定義要素を1つ選択してください：_善と悪は偏見であり危険な極端な考えだと信じている、慎重、善と悪について強いこだわりがない、柔軟、行動の自由、他人を守るためや助けるために犠牲を払うという決意が欠けている、個人的な関係によって他者にコミットしており、道徳規範によるものではない、確立された道徳規範を持たない、実用的、めったに仲間を求めない。_
- **悪** : あなたの道徳規範を最もよく表す定義要素を1つまたは2つ選択してください：_虐待的、人食い、強欲、残酷、横暴、罪なき者を傷つけることを楽しむ、貪欲、善を憎む、好色、操る、無慈悲、傲慢、サディスティック、自己中心的、利己的、奴隷所有者、執念深い、うぬぼれが強い、暴力的。_

#### 真なる中立

真なる中立の基本値は「知力+霊力+30」です。

- **真なる中立** : または、道徳規範と倫理規範の両方を欠いていることを最もよく表す定義要素を1つまたは2つ選択してください：_アンビバレント（両価的）、慎重、個人的な関係によって他者にコミットしている、柔軟、行動の自由、寛容、実用的、自然を尊重する、均衡を求める。_

## 情熱

情熱は、キャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、さらにプレイヤーが自身のキャラクターが何者であり、何に駆り立てられているのかを理解する一助として、プレイヤーやゲームマスターが使用します。

情熱は人、組織、理想、さらには物体など、何に対して抱いても構いません。情熱は通常、次のような動詞で記述されます：欲望、軽蔑、破壊、支持、恐怖、逃避、断念、憎悪、愛、忠誠、保護、拒絶、尊敬、追求、転覆、苦悩、支持。

情熱は技能と同じ方法で測定され、1から100（またはそれ以上）で評価されます。情熱は技能と同じ方法で成長させることができ、状況に応じてゲームマスターが増減させることも可能です。

キャラクター作成時、最大3つの情熱を選択できます。それぞれが2つの能力値に基づいており、重要度の順序はプレイヤーが決定し、最初の情熱に+40、2番目に+30、3番目に+20のボーナスを加えます。これらは文化、クラス、または個人的な弱点と結びつけることができます。例えば、「不信（ローグ）」、「女王への忠誠」、「家族愛」、「混沌の打倒」などです。情熱は次章で詳述するように、多くのキャラクタークラスにおいて特に重要な役割を果たします。これらのクラスの中には、クラス固有の特殊な能力を維持するために情熱を最低レベル以上に保つ必要があるものがあり、極端な状況下では情熱を失うことがクラスの喪失につながることもあります。

情熱の初期値は種類によって異なります。以下の[情熱表](0004_Alignment_and_Passions.md?id=passion-table)を参照してください。

このセクションでは、情熱が何を表すのかとそのデフォルト値についてのみ詳述します。情熱がゲーム内でどのように使用されるかについては、以下で説明します。

##### 情熱表

| 情熱の対象 | 初期パーセンテージ |
| :-- | :-- |
| 恋愛または家族的な文脈における人物 | 霊力+魅力 |
| 組織または人々の集団 | 霊力+知力 |
| 種族または種 | キャラクターの霊力 x2 |
| 場所 | キャラクターの霊力+知力 |
| 物体または物質 | キャラクターの霊力 x2 |
| 性格的な特性 | キャラクターの霊力+魅力 |

## 属性と情熱の使用

属性や情熱は、プレイ中にイベントに影響を与える能力を持つ、深く根ざしたコミットメントです。これらは単独の能力として使用できますが（これらを単なる技能と呼ぶのは過小評価です）、以下に情熱がどのように機能し、『Classic Fantasy Imperative』のキャラクターやキャンペーンにどのように影響を与えるかを詳しく説明します。

要約すると、属性と情熱は次のように使用できます：

- 別の技能を増強するため。これは、その感情の深さと、それが行動をどのように突き動かすかを反映します。この用途で使用する場合、その増強がテーマ的かつ劇的に重要であれば、属性や情熱の値の20%を現在使用している技能に加算します。
- 選択、欲望、感情的な行動や反応を突き動かすための能力として。このように使用する場合、キャラクターが何かについてどれほど強く考え、感じているかを決定するために、属性または情熱に対して標準の判定を行います。成功すれば、キャラクターは属性や情熱が命じる通りに行動します。失敗すれば、キャラクターは情熱の衝動に縛られることなく自由に行動できます。
- 他の属性や情熱と対抗するため。これは同一キャラクターが持つもの同士であっても同様です。これは通常、属性が情熱と矛盾する場合や、2つの情熱が競合する場合に使用されます。例えば、個人的な愛が、誓いや忠誠心に反する行動を促すような場合です。この場合、属性と情熱の間、あるいは2つの情熱の間で対抗判定を行い、より高い成功度を収めたほうがキャラクターの行動を決定します。
- 大義に対するコミットメント、信念、忠誠心の深さを測る一般的な尺度として。属性や情熱の値が高いほど、そのキャラクターは深くコミットしていることになります。似たような属性や情熱を持つキャラクター同士で値を比較し、どちらがより深い献身を示しているか判断できます。
- 心理的な操作や魔法による支配に抵抗するため。キャラクターが自身の属性や情熱に反する行為を強制されている場合、特定のケースでは対抗判定において意志力の代わりにそれらを代用することができます。

キャラクターが自身の選択した道徳や倫理を継続的に無視すると、プレイ中に属性値が低下する可能性があります。もしキャラクターの基本値よりも低くなった場合、それは対立する属性へと変化します（例：善から中立や悪へ）。ゲームマスターは状況に応じて新しい属性と値を決定してください。属性の変化により、クラス能力へのアクセスを失う可能性があります。詳細は該当するクラスの記述を参照してください。

新しい情熱は、状況が正当化されるのであれば、『Classic Fantasy Imperative』のセッション中いつでも獲得できます。誰かが激しい憎悪を抱くような行動をとった場合、瞬時に「憎悪：X」を獲得することもあるでしょう。領主や長が誓いを求めた場合、その誓いを立てた瞬間に「忠誠：X」という情熱が即座に確立されます。これについては、各[クラス](0003_Classes.md)の属性/誓いのセクションでさらに詳しく探求されています。

プレイ中にこのようにして発展した新しい情熱は、経験修正を消費せず、その場ですぐに確立されます。もちろん、キャラクターが成長の過程で経験修正を消費して情熱を基本値で確立することも可能です：[文化と種族](0002_Culture_and_Races.md)章の様々な属性と情熱のセクションを参照してください。

## 深まりと衰退

属性、情熱、誓いは、それを引き起こした出来事の強さに応じて、経験修正とは無関係にゲーム中に上昇することがあります。また、衰退することもあります。強く抱いていた信念は多くの出来事によって揺さぶられ、その結果、情熱が減少したり、極端な場合には完全に逆転したりすることがあります。

例えば、「族長への信頼」を持つキャラクターは、族長が裏切り行為を働いた場合、その情熱を減少させるか、同じパーセンテージで「族長への不信」に変化させることができます。情熱を減少させるべきか、逆転させるべきかはゲームマスターが判断する必要があります。減少する場合、変化をもたらした源の強さに応じてその値が減ります。
