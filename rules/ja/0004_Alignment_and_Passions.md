# 第4章：属性と情熱

『Classic Fantasy Imperative』において「属性（Alignment）」と「情熱（Passions）」を使用することは、プレイヤーとゲームマスターがキャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、プレイヤーが自分のキャラクターがどのような人物で、何に突き動かされているのかを理解する一助となります。本章で提示されている具体的な属性や情熱の選択はプレイヤーに委ねられていますが、前章の[クラス](0003_Classes.md)に関する記述にある通り、キャラクターをプレイするために必要なものもあります。本書のどのクラスも特定の属性や情熱を必須とはしていませんが、クレリックや（盗賊ギルドに所属する）ローグのように、所属する秩序やギルドへの「誓い（Oath）」を必要とするものがあります。誓いは、ゲームメカニクス上は情熱と同様に扱うことができます。

---
## 属性

すべてのキャラクターは、倫理規範（Ethical Code）と道徳規範（Moral Code）の2つの要素から構成される属性を持たなければなりません。倫理規範は「秩序」と「混沌」に対する立場を定義し、道徳規範は「善」と「悪」に対する感情を決定します。キャラクターは、それぞれに対して1つまたは2つの定義要素を選択し、初期パーセンテージを決定します。例：混沌（組織化されていない、貪欲）55%、善（協力的、寛大）55%。中立を2回選択することはできません。その代わりに、道徳規範と倫理規範の両方を無視し、「真なる中立（True Neutral）」を唯一の属性として選択します。倫理規範と道徳規範、およびそれぞれの定義要素の詳細は以下の通りです。

#### 倫理規範

「秩序（Lawful）」「中立（Neutral）」「混沌（Chaotic）」から1つを選択し、基本値を「INT + POW + 30」とします。

- **秩序 (Lawful)**：倫理規範を最もよく表す定義要素を1つまたは2つ選択してください：_伝統の順守、計算高い、狭量、混沌を憎む、倫理的、正直、名誉を重んじる、批判的、適応力の欠如、ユーモアのセンスがない、正当な権威への服従、組織的、予測可能、信頼できる、人を信じやすい、信頼に足る、礼儀正しい。_
- **中立 (Neutral)**：倫理規範を最もよく表す定義要素を1つ選択してください：_秩序と混沌は偏見であり危険な極端なものだと信じている、慎重、うぬぼれが強い、秩序と混沌に関してどちらかに強く傾倒することはない、柔軟、行動の自由、確立された倫理規範を持たない、現実的、自然を尊重する。_
- **混沌 (Chaotic)**：倫理規範を最もよく表す定義要素を1つまたは2つ選択してください：_行儀が悪い、血に飢えた、好奇心旺盛、冷笑的、不正直、不名誉、組織化されていない、正当な権威の無視、利己主義、自由、秩序を憎む、無責任、法を無視する、誇大妄想、いたずら好き、怒りっぽい、荒々しい、向こう見ず、疑い深い、抑制が効かない、信頼できない、予測不能、あてにならない。_

#### 道徳規範

「善（Good）」「中立（Neutral）」「悪（Evil）」から1つを選択し、基本値を「INT + POW + 30」とします。

- **善 (Good)**：道徳規範を最もよく表す定義要素を1つまたは2つ選択してください：_賞賛に値する、利他的、天使のような、権威的、寛大、無実の者を傷つけることへの罪悪感、きちんとしている、寛容、友好的、悪を憎む、協力的、親切、自然を愛する、慈悲深い、楽観的、肯定的、菜食主義。_
- **中立 (Neutral)**：道徳規範を最もよく表す定義要素を1つ選択してください：_善と悪は偏見であり危険な極端なものだと信じている、慎重、善と悪に関してどちらかに強く傾倒することはない、柔軟、行動の自由、他者を守ったり助けたりするために犠牲を払う意欲に欠ける、道徳規範ではなく個人的な関係によって他者と結びついている、確立された道徳規範を持たない、現実的、めったに他者と関わりを持とうとしない。_
- **悪 (Evil)**：道徳規範を最もよく表す定義要素を1つまたは2つ選択してください：_虐待的、人食い、強欲、残酷、威圧的、無実の者を傷つけることを楽しむ、貪欲、善を憎む、好色、操作的、無慈悲、自尊心が強い、サディスティック、自己中心的、利己的、奴隷所有者、意地悪、虚栄心が強い、暴力的。_

#### 真なる中立

真なる中立は、基本値を「INT + POW + 30」とします。

- **真なる中立 (True Neutral)**：あるいは、道徳規範と倫理規範の両方が欠如していることを最もよく表す定義要素を1つまたは2つ選択してください：_アンビバレント（両価的）、慎重、個人的な関係によって他者と結びついている、柔軟、行動の自由、寛容、現実的、自然を尊重する、調和を追い求める。_

## 情熱

情熱は、キャラクターの性質を深め、キャラクターの欲望や偏見に基づいたプロットフックを導入し、プレイヤーが自分のキャラクターがどのような人物で、何に突き動かされているのかを理解する一助として使用されます。

情熱は、人、組織、理想、さらには物体など、何に対するものであっても構いません。情熱は通常、「〜への欲望」「〜への蔑視」「〜を滅ぼす」「〜を支持する」「〜への恐怖」「〜から逃げる」「〜を否定する」「〜を憎む」「〜を愛する」「〜への忠誠」「〜を守る」「〜を拒絶する」「〜を尊重する」「〜を追い求める」「〜を破壊する」「〜を苦しめる」「〜を維持する」といった動詞で表現されます。

情熱はスキルと同様に測定され、1から100（またはそれ以上）の数値で評価されます。情熱はスキルと同じ方法で向上させることができるほか、状況に応じてゲームマスターによって増減させることも可能です。

キャラクター作成時、プレイヤーは最大3つの情熱を持つことができます。それぞれ2つの特性値に基づき、重要度の高い順に+40、+30、+20のボーナスを加えます。これらは文化、クラス、または個人的な癖に関連付けることができます。例：不信感（ローグ）、王への忠誠、家族愛、混沌の打破など。情熱は次章で詳しく述べるように、多くのキャラクタークラスにおいて特に重要な役割を果たします。これらのクラスの中には、クラス固有の特殊能力を維持するために情熱を最低レベル以上に保つ必要があるものがあり、極端な状況下では情熱を失うことがクラス喪失につながる場合もあります。

情熱の初期値は種類によって異なります。以下の[情熱テーブル](0004_Alignment_and_Passions.md?id=passion-table)を参照してください。

このセクションでは、情熱が何を表すのかとそのデフォルト値についてのみ詳述しています。情熱のゲーム内での使用方法については以下で説明します。

##### 情熱テーブル

| 情熱の対象 | 初期パーセンテージ |
| :-- | :-- |
| 恋愛や家族関係における特定の人物 | POW + CHA |
| 組織または人々の集団 | POW + INT |
| 人種または種族 | キャラクターのPOW x2 |
| 場所 | キャラクターのPOW + INT |
| 物体または物質 | キャラクターのPOW x2 |
| 性格的な特徴 | キャラクターのPOW + CHA |

## 属性と情熱の使用方法

属性や情熱とは、プレイ中に出来事に影響を与える可能性を持つ、深く抱かれたコミットメントのことです。これらは単独の「能力」として使用できますが（スキルと呼ぶのは不当な評価でしょう）、情熱については、『Classic Fantasy Imperative』のキャラクターやキャンペーンにどのように影響を与えるかについて、以下で詳しく説明します。

要約すると、属性と情熱は次のように使用できます。

- **他のスキルの補強**：感情の深さと、それが行動をどのように駆り立てるかを反映します。この用途で使用する場合、テーマ的およびドラマチックに重要であれば、その属性や情熱の20%を現在使用しているスキルに加算します。
- **選択、欲望、感情的な行動や反応を導く能力**：この方法で使用する場合、属性または情熱に対して標準ロールを行い、キャラクターが何かについてどれほど強く考え、感じているかを決定します。成功すれば、キャラクターはその属性や情熱が示す通りに行動します。失敗した場合、キャラクターは情熱の衝動に縛られることなく自由に行動できます。
- **他の属性や情熱への対抗**：同じキャラクターが持つもの同士であっても対抗させることができます。これは通常、属性が情熱と矛盾する場合や、2つの情熱が矛盾する場合に使用されます。例えば、個人的な愛が「誓い」や「忠誠心」と矛盾する行動を要求することがあります。この場合、属性と情熱、あるいは2つの情熱の間で対抗ロールを行い、より成功度の高かった方がキャラクターの行動を決定します。
- **コミットメント、信念、大義への忠誠心の深さの指標**：属性や情熱の値が高いほど、キャラクターはその対象に深くコミットしていることを示します。似たような属性や情熱を持つキャラクター同士で数値を比較し、どちらがより深いコミットメントを示しているかを判定できます。
- **心理的支配や魔法による支配への抵抗**：キャラクターが自身の属性や情熱に反する行動を強制されるような特定の状況では、対抗ロールにおいて「意志力（Willpower）」の代わりに属性や情熱を使用できます。

キャラクターの属性値は、選択した道徳や倫理を継続的に無視した場合、プレイ中に低下することがあります。キャラクターの基本値よりも低下した場合、例えば「善」が「中立」や「悪」へと、対立する属性に変化します。ゲームマスターは状況に応じて新しい属性とレベルを決定してください。属性の変化は、クラス能力の喪失につながる可能性があります。詳細は関連するクラスの解説を参照してください。

新しい情熱は、『Classic Fantasy Imperative』のゲームセッション中、状況が正当化されるのであればいつでも習得可能です。誰かが激しい憎悪を抱くような行為をした場合、瞬時に「〜への憎悪」を習得するかもしれません。領主や首長が誓いを求めた場合、その誓いを立てた瞬間に「〜への忠誠」という情熱が確立されます。これについては各[クラス](0003_Classes.md)の「属性/誓い」セクションで詳しく説明されています。

プレイ中に習得した新しい情熱に「経験ロール」は必要なく、その場ですぐに確立されます。もちろん、成長の過程で情熱を確立することを選択することもでき、その場合は経験ロールを消費して基本値の情熱を獲得します。[文化と人種](0002_Culture_and_Races.md)の章にある様々な属性と情熱のセクションを参照してください。

## 情熱の深化と減退

属性、情熱、誓いは、経験ロールとは別に、その増加を引き起こした出来事の強さに応じて、ゲーム中に上昇することがあります。また、それらは減退することもあります。強く抱いていた信念は多くの出来事によって揺らぐ可能性があり、その結果、情熱が減少するか、極端な状況下では完全に逆転することさえあります。

例えば、「首長への信頼」を持つキャラクターが、その首長が裏切り行為を働いた場合、情熱を減少させるか、同じパーセンテージで「首長への不信」に変化させることができます。情熱が減少するか逆転するかは、ゲームマスターが判断する必要があります。減少する場合、その変化の原因となった出来事の強さに応じて数値が減少します。

「深化と減退テーブル」は、情熱がどれだけ変化するかを示しています。

| 情熱の深さ | 情熱の修正値 |
| :-- | :-- |
| 弱い | 1d10 |
| 中程度 | 1d10+5 |
| 強い | 1d10+10 |
