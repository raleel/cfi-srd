## Descrições de Feitiços

---
#### Avaliar

(Adivinhação)

| | |
| :-- | :-- |
| **Nível:** Mago 0 | **Tempo de Conjuração:** 1 Turno |
| **Esfera:** Nenhuma | **Duração:** Instantânea |
| **Custo:** 1 | **Alcance:** Toque |
| **Área:** 1 Item | **Resistência:** Nenhuma |

Avaliar permite a avaliação imediata da qualidade de bens físicos com um ENC total em 'Coisas' ou TAM igual ao POD do conjurador. O feitiço determina se itens com aparência idêntica são da mesma qualidade ou de qualidade semelhante, ou se um ou mais deles possuem defeitos ou são de qualidade superior. O feitiço não funciona em seres orgânicos, apenas em objetos inanimados. Também não determina quais defeitos ou melhorias estão presentes, apenas que eles existem. Não tem utilidade na identificação ou detecção de magia.

---
#### Armadura

(Conjuração)

| | |
| :-- | :-- |
| **Nível:** Mago 1 | **Tempo de Conjuração:** 1 Rodada |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |
| **Custo:** 3 +1/Intensidade | **Alcance:** Toque |
| **Área:** 1 Alvo | **Resistência:** Nenhuma |

Quando este feitiço é conjurado, o sujeito é presenteado com um campo invisível de força mágica equivalente a uma armadura de escamas em proteção, concedendo 4 Pontos de Armadura a cada Local de Acerto. Não tem efeito se conjurado em alguém que já esteja usando armadura. No entanto, substituirá a armadura natural pela sua Duração, caso ofereça proteção superior. Se conjurado em uma criatura que possua mais de 4 pontos de armadura natural, ele aumentará os Pontos de Armadura em 1 em todos os locais. Esta proteção mágica não atrapalha o movimento ou a conjuração de feitiços. O feitiço persistirá até ser dissipado por magia, ou se o conjurador sofrer 8 pontos de dano de um único ataque, +1 por nível de Intensidade adicional (veja a tabela abaixo). Naturalmente, o conjurador pode escolher encerrar o feitiço a qualquer momento, se desejar, e deve fazê-lo para dormir.

| Intensidade | Custo | Efeito Variável |
| :-: | :-: | :-- |
| 1 | 3 | 4 Pontos de Armadura; Mantido até sofrer 8 de dano de 1 ataque |
| 2 | 4 | 4 Pontos de Armadura; Mantido até sofrer 9 de dano de 1 ataque |
| 3 | 5 | 4 Pontos de Armadura; Mantido até sofrer 10 de dano de 1 ataque |
| 4 | 6 | 4 Pontos de Armadura; Mantido até sofrer 11 de dano de 1 ataque |
| +1 | +1 | Continua a progressão |

#### Feitiço Astral

(Transmutação)

| | |
| :-- | :-- |
| **Nível:** Clérigo 5, Mago 5 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Astral | **Duração:** Veja abaixo |
| **Custo:** 3 +1/Intensidade adicional | **Alcance:** Toque |
| **Área:** Veja abaixo | **Resistência:** N/A |

Este feitiço permite que o conjurador e até cinco outros (um por nível adicional de Intensidade) entrem no Plano Astral. Todos devem estar se tocando e formando um círculo enquanto o feitiço é conjurado. Os corpos dos viajantes são deixados para trás no plano de origem e, normalmente, não levam consigo roupas ou equipamentos, exceto aqueles que irradiam uma aura mágica; esses itens se transformam em equivalentes astrais de sua forma normal. A Duração dura até o conjurador desejar que ela cesse. No entanto, é possível que seja encerrada prematuramente por uma força externa, como Dissipar Magia. Matar o corpo físico do conjurador também encerra o feitiço precocemente, embora isso tenha o efeito colateral lamentável de deixar presos quaisquer viajantes que acompanhem o conjurador.

#### Augúrio

(Adivinhação)

| | |
| :-- | :-- |
| **Nível:** Clérigo 2 | **Tempo de Conjuração:** 2 Minutos |
| **Esfera:** Adivinhação | **Duração:** Instantânea |
| **Custo:** 3/Intensidade | **Alcance:** 18m |
| **Área:** Conjurador | **Resistência:** N/A |

Este feitiço permite que o conjurador determine se uma ação específica a ser tomada nos próximos 30 minutos será benéfica ou prejudicial ao bem-estar de um indivíduo e/ou grupo. Um ponto focal de algum tipo é necessário para discernir os presságios, sendo os mais comuns as garras ou ossos menores de um dragão, uma pérola ou ouro puro avaliado em não menos que 100 PO, que foi esmagado ou derretido. O feitiço tem uma Intensidade Máxima de 4. Esta rolagem deve ser feita pelo Mestre, pois o conjurador nunca deve saber com certeza absoluta se os resultados foram interpretados corretamente.

| Intensidade | Custo | Efeito Variável |
| :-: | :-: | :-- |
| 1 | 3 | Rolagem de habilidade de Canalizar Formidável |
| 2 | 6 | Rolagem de habilidade de Canalizar Difícil |
| 3 | 9 | Rolagem de habilidade de Canalizar Padrão |
| 4 | 12 | Rolagem de habilidade de Canalizar Fácil |

Se a rolagem de adivinhação for bem-sucedida, ela concede um dos seguintes resultados:

| Augúrio | Implicação | 
| :-: | :-- |
| Sim | A ação será benéfica |
| Não | A ação será prejudicial |
| Sim e Não | A ação será tanto benéfica quanto prejudicial |
| Nada | A ação não será nem benéfica nem prejudicial |

Uma Falha Crítica deve resultar no Mestre dizendo o oposto da realidade.

#### Averter

(Abjuração)

| | |
| :-- | :-- |
| **Nível:** Clérigo 0, Mago 0 | **Tempo de Conjuração:** Instantâneo |
| **Esfera:** Proteção | **Duração:** Instantânea |
| **Custo:** 1 | **Alcance:** 18m |
| **Área:** 1 Feitiço | **Resistência:** Nenhuma |

Averter é usado para descartar outro feitiço de Nível 0 dentro do Alcance. Averter pode ser conjurado reativamente para neutralizar feitiços ofensivos de Nível 0, usando a Ação Reativa de Contra-Magia.

#### Confundir

(Encantamento (Encanto))

| | |
| :-- | :-- |
| **Nível:** Clérigo 0, Mago 0 | **Tempo de Conjuração:** 1 Turno |
| **Esfera:** Encanto | **Duração:** 30 Minutos |
| **Custo:** 1 | **Alcance:** 18m |
| **Área:** 1 Alvo | **Resistência:** Força de Vontade |

Confundir causa confusão na mente de um alvo corpóreo. O sujeito do feitiço tem dificuldade em pensar claramente, esquecendo onde está, o que está fazendo e por quê – muitas vezes lapsos em linhas de pensamento desassociadas. Alvos confundidos ainda podem agir em autodefesa, mas não podem iniciar qualquer atividade construtiva até que o feitiço termine. Qualquer tipo de ataque ou ação ameaçadora quebra instantaneamente o feitiço, independentemente de ter sido direcionado especificamente ao alvo confundido.

#### Barreira de Lâminas

(Evocação)

| | |
| :-- | :-- |
| **Nível:** Clérigo 4 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Guardião, Criação | **Duração:** 3 Rodadas/Intensidade |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 30m |
| **Área:** 1,5 a 9m de raio | **Resistência:** Veja abaixo |

Este feitiço cria uma barreira de espadas, adagas e facas giratórias que chicoteiam e cortam em torno de um ponto fixo e causam 1d8 pontos de dano a 1d4+2 Locais de Acerto aleatórios de *qualquer um* que passe pela Área de Efeito. A armadura oferece apenas metade da sua proteção normal. Pontos de Armadura mágicos reduzem o dano normalmente. Como as armas giram a uma velocidade ofuscante e estão densamente compactadas, é impossível Aparar ou Evadir delas. Pode-se usar um escudo para bloquear passivamente Locais de Acerto normalmente. Nesse caso, lembre-se de comparar o dano rolado com a armadura e os Pontos de Vida do escudo.

O feitiço pode ser conjurado defensivamente para proteger o clérigo ou um ou mais aliados, ou ofensivamente para prender inimigos. No entanto, inimigos cercados a menos de um metro e meio da borda da barreira enquanto ela se forma podem fazer uma rolagem de Evadir para escapar. Independentemente do sucesso, o oponente termina caído, logo fora da Área de Efeito. Uma rolagem bem-sucedida resulta em nenhum dano; caso contrário, eles sofrem o efeito total.

#### Bênção (R)

(Conjuração)

| | |
| :-- | :-- |
| **Nível:** Clérigo 1 | **Tempo de Conjuração:** 1 Rodada |
| **Esfera:** Todas | **Duração:** 5 Minutos |
| **Custo:** 1 | **Alcance:** 54m |
| **Área:** 7,5m de Raio | **Resistência:** Força de Vontade |

Quando este feitiço é conjurado, o clérigo abençoa um grupo de aliados dentro da Área de Efeito. Os afetados irradiam o Alinhamento do conjurador, seja Bom ou Mau. Não existem bênçãos de Neutralidade. Todos os aliados dentro do raio do feitiço recebem um bônus de +5% em todas as rolagens de habilidade e Resistência. Além disso, suas armas causam +1d3 de dano a mortos-vivos inteligentes, bem como criaturas de planos externos que tenham alinhamentos opostos ao do conjurador, como demônios, diabos ou anjos. Observe que, embora mortos-vivos animados, como esqueletos e zumbis, não sejam inerentemente maus, eles são tipicamente animados por magia maligna e, portanto, estão sujeitos a este dano.

A reversão deste feitiço, Maldição, permite ao clérigo amaldiçoar inimigos, fazendo com que as habilidades notadas sofram o inverso dos benefícios notados acima. O dano de uma arma amaldiçoada é calculado como uma penalidade, e esse dano não pode resultar em menos de 1 ponto.

#### Mãos Flamejantes

(Transmutação)

| | |
| :-- | :-- |
| **Nível:** Mago 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Nenhuma | **Duração:** Instantânea |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 0 |
| **Área:** Cone de 120 graus, 1,5m de comprimento | **Resistência:** Evadir |

Este feitiço faz com que chamas disparem das mãos do conjurador em um arco de 120 graus. Se usar miniaturas em combate, Mãos Flamejantes causará dano a cada alvo que ocupe 1 dos quadrados frontais do conjurador. Conjurando Mãos Flamejantes em níveis de Intensidade mais altos requer um mago de Nível superior. Esse dano engolfa todos os alvos dentro da área com dano baseado na Intensidade do feitiço, até uma Intensidade Máxima de 9, conforme segue. Uma rolagem de Evadir bem-sucedida, jogando-se ao chão, permite que a vítima não sofra dano. Alguém com a Habilidade Artista da Evasão tem a opção de Evadir sem cair.

| Intensidade | Custo | Nível Mínimo | Efeito Variável |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 pontos de dano em todos os Locais de Acerto |
| 3 | 4 | 1 | 1d3+2 pontos de dano em todos os Locais de Acerto |
| 5 | 5 | 1 | 1d3+3 pontos de dano em todos os Locais de Acerto |
| 7 | 6 | 2 | 1d3+4 pontos de dano em todos os Locais de Acerto |
| 9 | 7 | 3 | 1d3+5 pontos de dano em todos os Locais de Acerto |

Armadura vestida não protege, mas Pontos de Armadura mágicos ou a armadura natural de uma criatura reduzem o dano normalmente. Este feitiço poderoso é equilibrado pelo seu alcance notavelmente curto, significando que, para conjurá-lo, o usuário de magia deve estar perto o suficiente para estar em uma posição muito desvantajosa.

Como criaturas maiores são tipicamente maiores que a Área de Efeito do feitiço, elas tenderão a ter menos Locais de Acerto afetados. Aqueles de TAM 21 a 30 sofrem o dano em sua cabeça, tórax, abdômen e braços, enquanto aqueles de TAM 31+ sofrerão o dano em seu abdômen e pernas. Os Mestres devem ajustar esses locais dependendo da forma e posição do alvo em relação ao conjurador. Mãos Flamejantes tem uma chance de inflamar materiais inflamáveis igual ao dano rolado x5%. Veja a seção sobre [Fogo](0007_Game_System.md?id=fire-based-attacks) para informações adicionais.

(Transmutação)

| | |
| :-- | :-- |
| **Nível:** Mago 0 | **Tempo de Conjuração:** 1 Ação |

Limpar é usado para livrar um objeto, pessoa ou pequena área de sujeira, graxa, fuligem, maus odores, etc. Não organiza ou arruma o alvo ou a área; meramente os limpa até um estado impecável. #### Comandar

(Encantamento (Encanto))

| | |
| :-- | :-- |
| **Nível:** Clérigo 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Encanto | **Duração:** 1 Minuto |
| **Custo:** 3 | **Alcance:** 30 metros (100 pés) |
| **Área:** 1 Alvo | **Resistência:** POD |

Quando esta magia é conjurada, o clérigo pode proferir uma ordem de uma única palavra para uma criatura viva de TAM 1-20 e, no próximo Turno do sujeito, a ordem será seguida ao pé da letra se ele falhar na resistência. Isso essencialmente faz com que a vítima perca o próximo Turno completando a ação comandada e desperdiça um Ponto de Ação enquanto a realiza. Se a vítima não possuir mais Pontos de Ação, a ação comandada será realizada durante seu primeiro Turno da próxima Rodada. A ordem em si não pode causar nenhum ferimento real ao alvo; no entanto, ferimentos podem surgir como efeito secundário da ordem.

Por exemplo, uma ordem para morrer resultaria na vítima desmaiando em um estado semelhante à morte por 1 Rodada, sem causar ferimentos reais; no entanto, uma ordem para cair dada a uma criatura escalando um penhasco de 30 metros de altura poderia ser mais do que mortal.

O sujeito da ordem deve ser capaz de entender o idioma falado pelo conjurador e tem permissão para um teste de Poder de Vontade para resistir.

**Alguns Exemplos de Comandos**

- **Rastejar:** O sujeito cai no chão e começa a rastejar.
- **Morrer:** O sujeito cai no chão entrando em um estado comatoso semelhante à morte.
- **Cair:** O sujeito cai no chão.
- **Trapalhar:** O sujeito atrapalha uma ação física prestes a ser tomada.
- **Dormir:** O sujeito adormece.
- **Fugir:** O sujeito se vira e foge do conjurador.
- **Voar:** O sujeito bate os braços e corre em círculos.
- **Ir:** O sujeito começa a andar na direção em que estava voltado.
- **Parar:** O sujeito para imediatamente e fica parado no lugar.
- **Sair:** O sujeito se vira e sai pelo caminho que entrou.
- **Descansar:** O sujeito senta-se e recupera o fôlego.
- **Correr:** O sujeito começa a correr.
- **Gritar:** O sujeito grita.
- **Afundar:** O sujeito para de nadar.
- **Rendir-se:** O sujeito larga suas armas e cessa as hostilidades.

#### Encantar Item

(Encantamento)

| | |
| :-- | :-- |
| **Graduação:** Mago 4 | **Tempo de Conjuração:** Veja abaixo |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |
| **Custo:** 3 + Veja abaixo | **Alcance:** Toque |
| **Área:** 1 Item | **Resistência:** N/A |

A conjuração deste feitiço prepara um item para Encantamento. O objeto deve estar em boas condições e ser da melhor construção e mão de obra. Um custo adicional de pelo menos 100 PO é necessário para cobrir o custo de ferramentas adicionais, entalhe, bordado, joias, gravação e assim por diante. Finalmente, o processo de Encantamento requer um laboratório ou oficina.

Ao conjurar o feitiço, o usuário de magia deve estar tocando o item durante todo o Tempo de Conjuração de 1d8+2 dias. Isso contabiliza períodos de descanso e sono, durante os quais o item deve permanecer ao alcance do braço do conjurador. Em nenhum momento durante a conjuração o usuário de magia pode conjurar outro feitiço ou realizar qualquer outra forma de magia. Quebrar qualquer uma dessas diretrizes fará com que o feitiço falhe automaticamente.

Uma vez conjurado com sucesso, o item está pronto para o passo final, com o conjurador colocando o feitiço desejado nele. Para fazer isso, ele deve ter o feitiço na memória ou em um pergaminho e conjurá-lo no item dentro de 24 horas, ou todo o processo precisará ser reiniciado do zero. Uma vez que a conjuração do feitiço selecionado começa, o processo pode exceder as 24 horas mencionadas acima. Imbuir o item com o feitiço selecionado custa o número normal de Pontos de Magia para a Intensidade desejada e leva 1d12 horas por Graduação do feitiço. Durante todo o processo de imbuimento, o conjurador deve permanecer tocando o item ou permanecer ao alcance do braço durante os períodos de descanso, como acima, e um teste de Conjuração Arcana é necessário ao final do período de conjuração para imbuir o feitiço com sucesso. Os graus normais de sucesso da Conjuração de Feitiços são seguidos; no entanto, em relação a um resultado de Falha, o feitiço não pode ser forçado. Feitiços sucessivos podem ser imbuídos no item, desde que o processo de conjuração seja iniciado dentro de 24 horas após a conclusão do feitiço anterior. Isso se aplica mesmo no caso de um feitiço previamente falho. Cada feitiço sucessivo requer o Custo de Conjuração normal.

Ao usar o item, cada feitiço contido nele pode ser conjurado apenas uma vez; no entanto, múltiplas versões do mesmo feitiço podem ser imbuídas seguindo o procedimento acima. Também é possível imbuir um único feitiço, seguindo-o com uma conjuração do feitiço de Graduação 4 Permanência. Nesse caso, o feitiço pode ser conjurado quantas vezes desejar, seguindo as restrições estabelecidas na descrição do feitiço Permanência.

Não é possível imbuir outros efeitos mágicos em um item que não estejam em conformidade com um feitiço específico, e muitos itens mágicos de tempos passados simplesmente não podem ser recriados hoje em dia.

#### Exorcismo

(Abjuração)

| | |
| :-- | :-- |
| **Graduação:** Clérigo 3 | **Tempo de Conjuração:** 1d10x100 Minutos |
| **Esfera:** Proteção | **Duração:** Permanente |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 10 pés |

Por meio deste feitiço, clérigos clamam por sua divindade para expulsar um espírito ou outra força sobrenatural que atualmente possui um ser corpóreo, como na possessão demoníaca. Exorcismo também pode ser usado contra a dominação por certos objetos e itens mágicos, feitiços, maldições e até encantos. Se a possessão é dominante ou oculta é irrelevante. Assim, este feitiço pode ser potencialmente perigoso para o conjurador ou seus companheiros. O Tempo de Conjuração é muito aleatório e não pode ser interrompido sem atrapalhar o ritual.

#### Encontrar Familiar

(Conjuração)

| | |
| :-- | :-- |
| **Graduação:** Mago 1 | **Tempo de Conjuração:** 2d12 Horas |
| **Esfera:** Nenhuma | **Duração:** Especial |
| **Custo:** 3/Intensidade, +1 EXP | **Alcance:** 0 |
| **Área:** Raio de ½ Milha/Intensidade | **Resistência:** N/A |

Este feitiço permite que o conjurador tente invocar um familiar, que se torna uma extensão dos sentidos e do poder de seu mestre. Familiares podem conversar com seu mestre telepaticamente e são bons guardas e batedores também. Ter seu familiar morto apresenta certos riscos ao usuário de magia devido à sua conexão próxima, o que torna ter um familiar um perigo de baixo nível.

Para invocar um familiar, o usuário de magia deve começar o ritual mantendo um braseiro alimentado com carvão e, quando queimando com intensidade, adicionar 100 PO em incenso. Com esses ingredientes queimando, o conjurador deve então continuar o ritual até que o familiar chegue ou o Tempo de Conjuração expire sem sucesso.

Mesmo se este feitiço for conjurado com sucesso, a chance de um familiar adequado responder ao chamado do usuário de magia é de apenas 50%, e o usuário de magia só pode tentar este feitiço uma vez por ano. Cada nível adicional de Intensidade além do primeiro estende o Alcance do feitiço em mais meia milha, o que por sua vez aumenta a probabilidade de um familiar potencial ser encontrado em 5%, até um máximo de 95%. Não há controle sobre o tipo exato de criatura que responderá ao chamado, mas o que chegar será um servo e aliado fiel. Cabe à criatura específica responder ao chamado; portanto, estar em uma região conhecida por ser habitada por um certo tipo de criatura _não_ garante ao conjurador sucesso.

Se uma criatura responder ao chamado do conjurador, o usuário de magia ainda precisa sacrificar 1 Rolagem de Experiência para criar um vínculo espiritual entre si e o familiar. Uma vez feito isso, o ritual está completo.

Enquanto o familiar e seu mestre estiverem a 120 pés um do outro, o usuário de magia ganha a habilidade de usar os Pontos de Magia do familiar também. Além disso, o usuário de magia ganha um vínculo telepático com o familiar e quaisquer Habilidades especiais ou bônus de perícia adicionais anotados nas tabelas abaixo.

No caso da morte do familiar, o conjurador perde 5 Rolações de Experiência. Um conjurador que não tenha nenhuma Rolagem de Experiência atualmente deve perder todas as Rolações de Experiência futuras concedidas até que o saldo seja pago.

O tipo de familiar a aparecer, se houver, é determinado de acordo com a tabela a seguir. Na maioria das circunstâncias, familiares comuns não são excepcionalmente grandes, tendo entre TAM 1-4, e usam a descrição de Animal Pequeno.

#### Escudo de Fogo

(Evocação)

| | |
| :-- | :-- |
| **Grau:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** 2 Minutos/Intensidade |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 0 |
| **Área:** Conjurador | **Resistência:** N/A |

Esta magia cria um escudo de chamas tênues que imola o conjurador, mas não causa dano por si só. Em vez disso, as chamas protegem o recipiente contra fogo ou frio, dependendo de qual das duas variantes está na memória: Escudo de Gelo, que cria chamas azuis ou verdes e protege contra calor e danos baseados em fogo, ou Escudo de Calor, que cria chamas violetas ou azuis e protege contra danos baseados em frio e gelo. A cor das chamas deve ser determinada aleatoriamente com uma chance de 50% para qualquer uma, já que o fato de ambos os tipos poderem emitir chamas azuis cria um elemento de incerteza por parte de qualquer atacante. A decisão de qual memorizar é feita quando as magias são preparadas, e ambas podem ser memorizadas, se desejado. Essas chamas não emitem calor e fornecem luz com apenas metade do brilho de uma tocha. Os detalhes de cada variante são detalhados abaixo.

- **Escudo de Gelo:** Estas chamas são frias ao toque e reduzem qualquer dano baseado em fogo ou calor pela metade do total. Um teste de Resistência bem-sucedido anulará todo o dano. O teste de Resistência é um grau mais fácil e, no caso de Esquiva, não deixará o defensor caído.
- **Escudo de Calor:** Estas chamas são quentes ao toque e reduzem qualquer dano baseado em frio pela metade do total. Um teste de Resistência bem-sucedido anulará todo o dano. O teste de Resistência é um grau mais fácil e, no caso de Esquiva, não deixará o defensor caído.

Ataques corpo a corpo contra o recipiente de qualquer variante, armado ou desarmado, infligem dano normal, a menos que utilizem um dos elementos contra os quais estão protegidos. Neste caso, o conjurador é protegido da porção elemental do ataque, e o atacante recebe dano igual ao infligido. Armadura vestida pelo atacante não oferece proteção, mas Pontos de Armadura mágicos ou a armadura natural de uma criatura reduzem o dano normalmente. Criaturas com Resistência Mágica Inata podem dissipar o Escudo de Fogo em um teste de POD bem-sucedido quando o recipiente for atingido pela primeira vez. Se o teste de Resistência Mágica falhar, o oponente não pode anular o Escudo de Fogo posteriormente.

#### Carne em Pedra \(R\)

(Transmutação)

| | |
| :-- | :-- |
| **Grau:** Mago 4 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** Permanente |
| **Custo:** 3/Intensidade | **Alcance:** 9 m (30 pés)/Intensidade |
| **Área:** 1 Alvo | **Resistência:** POD |

Ao conjurar, uma vítima dentro do Alcance tem direito a um teste de Resistência de POD. Se não for bem-sucedida, ela e todos os pertences carregados e vestidos são completamente transformados em pedra sólida. Esta transformação não é a morte, mas sim uma forma de animação suspensa. A conjuração da versão reversa desta magia, ou um Desejo, pode ser usada para restaurar a vítima à vida novamente. Qualquer dano que a vítima sofra enquanto for pedra é acumulado, entrando em vigor imediatamente após a restauração. Criaturas grandes (TAM 21-40) são menos suscetíveis a esta magia, com o teste de Resistência sendo Fácil, e o teste de Resistência para criaturas enormes (TAM 41+) é Muito Fácil.

O reverso desta magia, Pedra em Carne, é usado para restaurar uma vítima e nenhum teste para resistir é necessário. No entanto, a magia também pode ser revertida para transformar pedra que nunca esteve viva anteriormente, sendo usada de uma das várias maneiras criativas. Por exemplo, uma parede de pedra de 0,3 metros cúbicos (10 pés cúbicos) por nível de Intensidade pode ser transformada em carne macia, um "túnel" de carne com até 0,9 metros de largura, com um comprimento de 3 metros por Intensidade poderia ser criado, um único alvo como uma estátua de pedra poderia ser transformado em um corpo, e até mesmo um golem de pedra poderia ser transformado em um golem de carne por meio desta magia. No entanto, neste último caso, o golem de pedra teria direito a um teste de POD para resistir normalmente. Pedra transformada em carne desta forma é macia e flexível, e embora retenha seus Pontos de Vida reais, não possui Pontos de Armadura, tornando-a mais fácil de cortar.

#### Mordida de Gelo

(Transmutação)

| | |
| :-- | :-- |

| **Esfera:** Nenhuma | **Duração:** Instantâneo |

Mordida de Gelo trabalha diretamente sobre o tecido orgânico vivo, causando dormência e dor em uma das extremidades do recipiente, por exemplo, dedos das mãos, dedos dos pés, nádegas, nariz e orelhas, e assim por diante. #### Trapalhada

(Encantamento (Encanto))

| | |
| :-- | :-- |
| **Grau:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** 1 Rodada/Intensidade |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 9 m (30 pés)/Intensidade |
| **Área:** 3 metros (10 pés) de raio | **Resistência:** POD |

Esta magia faz com que todos os oponentes na Área de Efeito se tornem desajeitados, com quaisquer testes de perícia física tornando-se um grau mais difíceis e fazendo com que todas as falhas resultem em uma Trapalhada. Mesmo ações físicas que normalmente não requerem um teste de perícia, como pegar um item derrubado, mover-se mais rápido que uma caminhada ou subir escadas, requerem um teste de perícia de Atletismo. Uma Falha neste caso resulta em uma Trapalhada e, tipicamente, em uma queda desajeitada no caso de movimento, ou chutar acidentalmente um item para mais longe enquanto tenta pegá-lo. O Mestre de Jogo deve ser criativo com os resultados de um teste Trapalhado; no entanto, poucos devem ser totalmente mortais em situações fora de combate. Em combate, no entanto, uma Trapalhada é tratada como qualquer outra e pode resultar em Efeitos Especiais normalmente.

Um teste de Resistência bem-sucedido permite que a vítima evite os efeitos da magia pela Rodada atual; no entanto, se a vítima ainda ocupar a Área de Efeito na rodada seguinte, outro teste de Resistência deve ser feito novamente como normal. Aliados do atacante original também precisarão ficar fora da Área de Efeito ou sofrer as mesmas limitações que seus oponentes.

Esta magia também pode ser direcionada a uma criatura específica, que sofrerá os efeitos por toda a Duração da magia em um teste de Resistência falho. Conjurada desta forma, Trapalhada não produz Área de Efeito. Neste caso, um teste de Resistência bem-sucedido resulta na vítima sofrendo os efeitos da magia de Grau 2, Lentidão.

#### Portal

(Conjuração)

| | |
| :-- | :-- |
| **Grau:** Clérigo 5, Mago 5 | **Tempo de Conjuração:** 2 Rodadas |
| **Esfera:** Invocação | **Duração:** Veja abaixo |
| **Custo:** 3 +1/Intensidade, +3 EXP | **Alcance:** 30 m (100 pés) |
| **Área:** Veja abaixo | **Resistência:** POD |

A conjuração de Portal exige que o conjurador conheça o nome verdadeiro da entidade a ser invocada, que tipicamente é uma criatura de um dos outros planos de existência, como um demônio ou diabo, um anjo, semideus ou até mesmo um deus. Quando conjurada com sucesso, um portal se abre entre o plano de ocupação do conjurador e o da entidade. Conjurar a magia automaticamente ganha a atenção da entidade, seja bem-sucedida ou não. Esta magia é imensamente poderosa e exaustiva, custando ao conjurador não apenas os 3 Pontos de Magia e 3 Rolagens de Experiência notados, mas também Envelhecendo-os em 5% de sua expectativa de vida típica (5 anos no caso de um conjurador humano). Se a entidade for bem-sucedida no teste de Resistência, eles tipicamente não se darão ao trabalho de vir pessoalmente, no entanto, assumindo que a magia seja bem-sucedida, 'algo' virá através dela. A tabela a seguir é usada para determinar algumas entidades comuns, seus PODs médios e servos típicos que seriam enviados em seu lugar. O Mestre de Jogo é livre para escolher o que melhor se adapta à natureza da campanha atual.

A forma da resposta dependerá muito da entidade específica, do Alinhamento de ambas as partes e dos detalhes do pedido. Se a entidade acreditar que os motivos para a interrupção são mesquinhos ou irrelevantes, sua resposta pode ser qualquer coisa, desde simplesmente ir embora até um ataque direto. No entanto, uma situação desesperadora, especialmente uma em que o conjurador é ameaçado por algo fortemente oposto pela entidade, provavelmente terá uma resposta mais favorável. Se o Mestre de Jogo sentir que há uma área cinzenta e a resposta estiver em questão, o conjurador e seus aliados podem tentar argumentar seu caso usando uma combinação de perícia, lisonja, súplica e/ou suborno. O portal permanecerá aberto pelo tempo que a entidade escolher permanecer deste lado, fechando-se atrás deles quando decidirem partir. Durante esse tempo, é possível que o portal seja atravessado por outros, oferecendo viagem de mão dupla entre ambas as realidades.

Glamour torna o alvo sedutor para que as pessoas sejam naturalmente atraídas por ele. Para cada nível de Intensidade, a magia cura o sujeito de uma doença de qualquer POT, cura qualquer cegueira ou surdez, nega um transtorno mental causado por ferimentos ou magia, ou cura um único Local de Ferimento de até 12 pontos de dano. Ela não restaurará, no entanto, um membro decepado, pois isso requer a conjuração da magia Regenerar. Cada Intensidade adicional pode ser usada para curar outra enfermidade ou curar outro Local de Ferimento. Portanto, seria necessária uma conjuração de Intensidade 7 para curar um indivíduo sofrendo queimaduras em todo o corpo. Ao contrário de magias de cura menores que limitam sua eficácia contra ferimentos de longo prazo, não há limites impostos pela magia quanto à Duração na qual o sujeito sofreu os efeitos do ferimento.

Quando revertida, Ferir inflige 12 pontos de dano mágico em um dos Locais de Ferimento da vítima em um teste de resistência falho. Alternativamente, uma enfermidade é infligida a eles, cujos efeitos são os mesmos da magia Causar Doença, o reverso de Curar Doença, mas com +20 POT. O teste de Canalizar do conjurador funciona como o teste para atingir o oponente e é assumido como parte da exigência somática da magia. Nenhum teste adicional para atingir é necessário. Nem armaduras gastas nem naturais oferecem proteção, mas Pontos de Armadura mágicos reduzem o dano normalmente e bloqueiam totalmente enfermidades infligidas. Cada Intensidade adicional afeta outro Local de Ferimento contíguo ao primeiro, com efeitos determinados pelo teste de Resistência inicial. Nenhuma das versões desta magia tem qualquer efeito sobre mortos-vivos, criaturas feridas apenas por ferro, prata ou armas mágicas, ou seres não corpóreos.

(Transmutação)

| | |

Esta magia pode ser utilizada de duas maneiras distintas: para Acender ou para Extinguir. A escolha é feita no momento da conjuração.

Esta magia cria uma ilusão visual de qualquer coisa que o conjurador desejar. Não tem efeito sobre outros sentidos, não fazendo som, produzindo odor, temperatura ou textura, e assim por diante.

Assim, por exemplo, se o conjurador desejasse fazer com que uma tocha ilusória derrubada fizesse folhas secas parecerem pegar fogo, o conjurador poderia se concentrar como uma Ação Livre para fazê-lo.

#### Magic Mouth

(Transmutação)

| | |
| :-- | :-- |
| **Grau:** Mago 2 | **Tempo de Conjuração:** 1 Minuto |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |

Este feitiço cria uma boca em um item ou objeto, que aparece magicamente quando desencadeada por um evento específico ou momento designado pelo usuário de magia quando o feitiço é conjurado pela primeira vez. Esta boca então dirá qualquer frase predefinida que o conjurador escolheu no momento da conjuração. Esta frase deve consistir em não mais que 25 palavras e é falada pela boca a uma taxa de aproximadamente 1 palavra por segundo. A boca não pode falar palavras de poder ou conjurar feitiços.

Este feitiço pode ser conjurado em qualquer objeto normalmente inanimado, de um pilar ou árvore a uma parede de pedra ou baú; no entanto, é particularmente eficaz quando conjurado em uma estátua, pois a própria estátua pareceria estar falando. No entanto, poderia designar roupas vestidas. A distância máxima que o feitiço pode ser acionado é de 7,5 metros por Intensidade.

A Duração deste feitiço é permanente até que o encantamento seja ativado e então o feitiço termina.

#### Polimorfismo (Outro)

(Transmutação)

| | |
| :-- | :-- |
| **Nível:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** Permanente |
| **Custo:** 3, +1 por Intensidade adicional (+1 EXP) | **Alcance:** 15 pés/Intensidade |
| **Área:** 1 Alvo | **Resistência:** Poder |

O conjurador pode alterar a forma de uma criatura corpórea alvo para a de outra, com cada ponto de Intensidade alterando o TAM em até 5 pontos. Portanto, transformar um orc de TAM 16 em um coelho de TAM 1 exigiria 3 níveis de Intensidade (15 pontos de diferença de TAM). O alvo desta magia tem direito a um teste de Poder para resistir. Criaturas grandes (TAM 21-40) são menos suscetíveis a serem polimorfizadas, com seu teste de Resistência sendo Fácil, enquanto o teste de Resistência para criaturas Enormes (TAM 41+) é Muito Fácil.

Todo o processo de transformação leva uma Rodada completa e pode ser bastante estressante para a criatura em questão, exigindo um segundo teste de Poder para manter sua personalidade original, com uma Falha atordoando o alvo por 1d10 minutos e um Erro Crítico resultando em morte por choque mental. Cada duplicação ou redução pela metade do TAM original da criatura torna o teste de Poder para manter a personalidade um grau mais difícil, assim como uma mudança completa de ambiente, como transformar uma pessoa em um peixe. Um teste bem-sucedido permite que a vítima retenha sua INT e CAR, bem como quaisquer perícias que exijam essas Características.

A transformação concede ao receptor a forma de respiração da criatura assumida, se diferente do normal; quaisquer ataques naturais; e todos os modos de movimento mundanos. Não concede quaisquer Habilidades elevadas ou mágicas possuídas pela criatura. Por exemplo, uma criatura que foi polimorfizada em um dragão não ganhará o ataque de sopro ou habilidades similares a magia da criatura, mas ganhará a capacidade de voar, sua pele resistente, mordida mortal, ataques de garra, e assim por diante. Além disso, a vítima ganha as perícias físicas da nova forma, como Atletismo, Briga, Voar, Nadar, bem como seus Pontos de Vida e Modificador de Dano. Assumindo que o indivíduo transformado reteve sua INT, ele ainda perde a capacidade de falar, a menos que a nova forma possua a habilidade de articular palavras. Aqueles que eram capazes de conjurar magias em sua forma anterior ainda seriam capazes de conjurar na nova forma, assumindo que ainda possuam a capacidade de produzir os componentes verbais e somáticos. No caso de uma mudança drástica, como ser mudado de bípede para quadrúpede, ou de um animal terrestre para uma criatura marinha, por exemplo, o Mestre de Jogo deve se sentir à vontade para penalizar em pelo menos um Grau de Dificuldade o uso de quaisquer perícias que levariam tempo para aprender enquanto se ajusta à nova forma até que tenha havido tempo suficiente para praticar. Isso é especialmente verdadeiro para perícias físicas como Atletismo, Desarmado, Nadar, Voar, Perícias de Combate, e assim por diante.

O teste de Poder para manter a própria personalidade é necessário a cada dia que o sujeito permanece transformado até que falhe, fazendo com que a pessoa finalmente sucumba à mentalidade da nova forma, com a INT mudando para INS no caso de uma criatura não sapiente. Todas as Habilidades especiais e mágicas possuídas pela nova forma que não foram adquiridas anteriormente, como ataques de olhar, armas de sopro, etc., estão agora disponíveis para a criatura à medida que a transformação é concluída. Personagens que perdem sua identidade desta forma tornam-se Personagens Não Jogadores sob o controle do Mestre de Jogo.

Antes de sucumbir mentalmente à transformação, a criatura polimorfizada é suscetível a Dissipar Magia normalmente, sem necessidade de teste de resistência, já que seria o desejo subconsciente de voltar ao normal. A transformação exige outro teste de Poder para resistir à tensão, com uma Falha atordoando o alvo por 1d10 minutos e um Erro Crítico resultando em morte por choque mental.

Se a vítima tivesse sucumbido anteriormente à nova forma, Dissipar Magia ainda pode ser usado; no entanto, a vítima tentará resistir a retornar à forma natural com um teste de Poder. Falhar neste teste significa que a vítima se transforma de volta na forma natural, o que, é claro, exige outro teste de Poder para resistir ao choque mental da transformação. Uma vez perdida, a identidade natural de uma vítima não é mais alcançável; em vez disso, a vítima assume que a forma estranha e alienígena não é natural e anseia por ser devolvida ao seu estado 'normal' anterior. _Por exemplo, um orc que foi polimorfizado em um coelho e assumiu a identidade da criatura acreditaria que agora é um coelho que foi rudemente transformado em um orc._ Apenas um Desejo, ou outra magia semelhante, tem qualquer chance de restaurar a identidade da vítima uma vez que ela tenha sido perdida.

Todo equipamento vestido e carregado se funde magicamente na nova forma; no entanto, em alguns casos, o Mestre de Jogo pode permitir que itens mágicos que ainda poderiam ser usados na nova forma da criatura permaneçam, como um anel mágico ou botas. Observe que isso exige que o novo TAM da criatura não seja vastamente diferente do original. Existe uma chance de POD x1% para cada item mágico vestido de natureza não ofensiva, sujeito à aprovação do Mestre de Jogo, de transferir seus efeitos para a nova forma da criatura. Uma criatura com um anel de proteção +1, por exemplo, poderia ganhar um bônus de +1 aos seus Pontos de Armadura naturais. Criaturas com a capacidade natural de mudar de forma, como doppelgängers e licantropos, serão transformadas normalmente, mas podem assumir sua forma normal após 1 Rodada. Se morta, uma criatura polimorfizada reverte à sua forma natural, mesmo que tenha perdido anteriormente todos os vestígios de identidade.

| :-: | :-: | :-- |
| 1 | 3, +1 EXP | Alcance de 15 pés; 1-5 pontos de diferença de TAM |
| 2 | 4, +1 EXP | Alcance de 30 pés; 6-10 pontos de diferença de TAM |
| 3 | 5, +1 EXP | Alcance de 45 pés; 11-15 pontos de diferença de TAM |
| 4 | 6, +1 EXP | Alcance de 60 pés; 16-20 pontos de diferença de TAM |
| +1 | +1 | Continua a progressão |

#### Ressuscitar \(R\)

(Necromancia)

| | |
| :-- | :-- |
| **Rank:** Clérigo 3 | **Tempo de Conjuração:** 1 Minuto |
| **Esfera:** Necromântica | **Duração:** Permanente |
| **Custo:** 3, +1/Intensidade adicional, +1 EXP | **Alcance:** 30 m |
| **Área:** 1 Alvo | **Resistência:** ND (Força de Vontade) |

Este feitiço pode ser conjurado no cadáver de uma criatura morta há menos de 24 horas por nível de Intensidade. Se o Alinhamento do sujeito fosse qualquer coisa além de maligno, ele pode resistir ao feitiço com um teste Oposto de Força de Vontade e, se for bem-sucedido, anular os efeitos do feitiço. Isso ocorre porque a alma ou espírito do falecido raramente está disposto a retornar aos vivos depois de ter alcançado sua recompensa eterna. O Mestre de Jogo pode decidir dispensar o teste se o recipiente tiver assuntos pendentes, não puder ser separado de seu verdadeiro amor ou tiver algum outro motivo heroico para viver.

No caso de almas malignas, que retornariam alegremente ao plano material em vez de sofrer a danação eterna, não é a Força de Vontade do falecido que está resistindo, mas a do demônio, diabo, etc., encarregado de seu castigo, seu tormentor. Nesse caso, o conjurador deve superar a Força de Vontade do tormentor. Se isso for desconhecido, assuma que é pelo menos 20 pontos maior que a do falecido para representar que quanto mais forte a vontade da alma, mais poderoso é o ser encarregado de sua danação. Se o conjurador tiver sucesso, ele devolveu com êxito o espírito ao corpo, enquanto um teste falho resulta no fato de a vítima não querer ou não ser capaz de retornar.

Se a conjuração for bem-sucedida, o sujeito retorna à vida com Pontos de Vida totais, embora membros decepados permaneçam perdidos. Isso significa que uma vítima decapitada ou cortada ao meio não pode ser ressuscitada até que sua cabeça ou torso seja primeiro recolocado. Isso pode ser feito antes da conjuração de Ressuscitar, recolocando fisicamente a localização decepada, o que requer um kit de curandeiro e uma aplicação bem-sucedida da perícia Cura, e normalmente deixa uma cicatriz óbvia e reveladora. Outras doenças, como veneno ou enfermidade, devem ser tratadas antes ou depois da conjuração de Ressuscitar, ou os resultados serão apenas temporários. Finalmente, Ressuscitar não tem efeito em uma criatura que atingiu o fim de sua vida útil natural e morreu de velhice.

O ato de ser ressuscitado dos mortos é muito desgastante para o sujeito, que é reduzido a um Nível de Fadiga de Incapacitado por um período de 24 horas para cada dia em que esteve morto. A conjuração de Curar Fadiga não tem efeito sobre o paciente durante este tempo de convalescença. Após esse ponto, o personagem se recupera da Fadiga normalmente e sem restrições.

Quando revertido, Matar Vivo, pode ser usado para matar uma vítima designada pelo clérigo no momento da conjuração. Esta vítima tem direito a um teste de Força de Vontade para resistir, modificado pelo Rank ou TAM do alvo, o que der o resultado mais benéfico para o alvo, conforme detalhado na tabela a seguir.

| Rank do Alvo | TAM do Alvo | Modificador de Força de Vontade |
| :-: | :-: | :-: |
| 0-1\* | 1-20 | Difícil |
| 2 | 21-40 | Padrão |
| 3 | 41-60 | Fácil |
| 4-5 | 61+ | Muito Fácil |

_\* Esta categoria inclui personagens que não possuem uma Classe._

Se o teste de Resistência não for bem-sucedido, a vítima é morta instantaneamente. Um teste bem-sucedido é tratado como os efeitos de Causar Ferimentos Graves. A armadura não oferece proteção contra este dano.

Pouco da criatura real precisa permanecer para que a magia ainda seja eficaz. Por exemplo, Ressurreição poderia ser usada para trazer um ser de volta dos mortos após 145 anos, mesmo possuindo nada mais do que um osso do dedo, assumindo que a magia seja conjurada com 8 de Intensidade. O indivíduo ressuscitado não requer período de descanso e está totalmente funcional imediatamente. A magia não tem efeito sobre uma criatura que morreu de causas naturais no final de sua vida útil.

Se o Alinhamento do sujeito fosse qualquer coisa que não fosse maligno, ele pode resistir à magia com um teste de POD oposto e, se bem-sucedido, anular os efeitos. Isso ocorre porque a alma ou espírito do falecido raramente está disposto a retornar aos vivos depois de ter alcançado sua recompensa eterna. Nesse caso, o conjurador deve superar o POD do algoz. Se este for desconhecido, presuma que seja pelo menos 20 pontos maior do que o do falecido para representar que quanto mais forte a vontade da alma, mais poderoso é o ser colocado no comando de sua danação. Se o conjurador obtiver sucesso, o sujeito foi ressuscitado com sucesso, enquanto um teste falho resulta na vítima não disposta ou incapaz de retornar.

Ressurreição é muito desgastante, envelhecendo o clérigo em 3% de sua expectativa de vida típica (3 anos no caso de um conjurador humano). Veja as regras para [Envelhecimento](0007_Game_System.md?id=aging).

| Nível do Alvo | TAM do Alvo | Modificador de POD |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | Formidável |

#### Retardar Veneno

(Necromancia)

| | |
| :-- | :-- |
| **Nível:** Clérigo 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Cura | **Duração:** 1 Hora por Intensidade |
| **Custo:** 3, +1 por Intensidade adicional | **Alcance:** Toque |
| **Área:** 1 Alvo | **Resistência:** ND |

Esta magia permite ao conjurador retardar os efeitos de venenos e peçonhas; ela não neutraliza, no entanto, a toxina. Em vez disso, as toxinas que se espalham pelo corpo são retardadas o suficiente para que, com sorte, medidas curativas adicionais possam ser encontradas. O Tempo de Início de uma toxina não entra em vigor até que a Duração da magia tenha expirado.

Por exemplo, o veneno de cobra possui um Tempo de Início como segue: agonia após 1d6+4 minutos, e Asfixia após 1d6+6 horas. Uma única Intensidade de Retardar Veneno, portanto, adia o Tempo de Início em 1 hora, após o que, 1d6+4 minutos depois, a agonia se instala normalmente.

Se Retardar Veneno for conjurado em uma vítima após os sintomas terem aparecido, eles cessam até que a Duração da magia expire e, então, continuam normalmente.

Como último recurso, se o conjurador conseguir chegar a um indivíduo que 'morreu' de envenenamento dentro de 10 minutos, Retardar Veneno atrasa a morte de uma vítima por 1 hora por Intensidade, durante a qual a vítima permanece em coma. Se durante este tempo a vítima puder ser curada do veneno, a vítima ainda pode viver e ser revivida por Primeiros Socorros ou cura mágica.

Este feitiço permite que o conjurador conjure uma parede ou um círculo de chamas ardentes, conforme desejado no momento da conjuração, queimando em uma cor púrpura ou azul-avermelhada. | **Área:** 1 ou mais Alvos | **Resistência:** ND |

Este feitiço confere a capacidade de o conjurador ou outros respirarem água durante toda a sua Duração. Ao ser conjurado, mais de um destinatário pode ser tocado e, portanto, ganhar os benefícios de Respirar na Água. Nesse caso, a Duração é dividida pelo número de sujeitos. A Duração exata do feitiço Respirar na Água é imprevisível e deve ser rolada pelo Mestre de Jogo, pois aqueles sob seus efeitos não devem saber especificamente quanto tempo resta. O reverso deste feitiço, Respirar no Ar, permite que uma criatura que de outra forma não seria capaz de respirar oxigênio o faça. A capacidade de respirar seu elemento natural ainda é mantida independentemente da variante do feitiço, então um peixe poderia respirar tanto em terra quanto sob a água durante a Duração do feitiço.

#### Teia

(Evocação)

| | |
| :-- | :-- |
| **Grau:** Mago 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Nenhuma | **Duração:** 20 Minutos/Intensidade |
| **Custo:** 3, +1/Intensidade adicional | **Alcance:** 9 metros/Intensidade |
| **Área:** Raio de 6 metros | **Resistência:** Esquivar, mais Veja abaixo |

Este feitiço faz com que longas tiras de teia pegajosa disparem da mão do conjurador, as quais podem ser ancoradas do chão ao teto, ou de parede a parede, para bloquear uma passagem ou impedir o progresso. Também pode ser borrifado diretamente sobre os oponentes para emaranhá-los.

Supondo que o alvo tenha espaço para escapar das teias, um teste de Esquiva bem-sucedido coloca o alvo fora da Área de Efeito; no entanto, isso requer que um Ponto de Ação esteja disponível. Um teste de resistência falho deixa a vítima imobilizada e 1d3 Locais de Acerto emaranhados. Como o Efeito Especial [Emaranhar](https://cfi-srd.mythras.net/#/0008_Combat?id=entangle), um local coberto por teia é inutilizável. Um braço emaranhado não pode usar o que estiver segurando; um peito, abdômen ou perna presos tornam todos os testes de perícia física um grau mais difíceis (Exceto testes de Força usados para tentar se libertar), e uma cabeça envolvida causa asfixia conforme detalhado em [Asfixia](0007_Game_System.md?id=asphyxiation).

No Turno seguinte, a vítima pode gastar um Ponto de Ação para tentar se libertar da teia. A teia mágica é incrivelmente forte e pegajosa, possuindo 6 Pontos de Armadura e Pontos de Vida iguais a 3x a Intensidade do feitiço. Tentar se libertar exige que a vítima vença um Teste Oposto de Força contra a Aderência da teia (igual à perícia de Conjuração Arcana do conjurador). Se isso falhar, o alvo permanece preso, incapaz de se libertar apenas pela força. Tentar cortar a teia expõe a ferramenta ou arma usada ao mesmo processo. Apesar da crença popular, as teias não são inflamáveis, mas um personagem pode lentamente queimar um caminho através de uma teia usando uma chama para encolher as tiras (o dano de fogo ignora os Pontos de Armadura da Teia).

#### Desejo

(Conjuração, Evocação)

| | |
| :-- | :-- |
| **Grau:** Mago 5 | **Tempo de Conjuração:** Veja abaixo |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |
| **Custo:** 3, +1 ou mais EXP | **Alcance:** Ilimitado |
| **Área:** Veja abaixo | **Resistência:** Veja abaixo |

Desejo pode mudar a realidade de uma forma permanente e significativa. Para conjurar este feitiço, o usuário de magia deve gastar 3 Pontos de Magia e 1 ou mais rolagens de EXP, dependendo dos resultados desejados. Cada conjuração sucessiva de Desejo em um período de 1 mês dobra o gasto de EXP necessário normalmente. O Tempo de Conjuração é tipicamente necessário para detalhar verbalmente as especificidades do Desejo. Após a conclusão, o conjurador sofre uma perda de Fadiga igual ao EXP gasto e envelhece 5% de sua expectativa de vida normal (para humanos, isso seriam cinco anos). Veja [Envelhecimento](0007_Game_System.md?id=aging) para as expectativas de vida médias das raças semi-humanas.

Os resultados de um Desejo devem ser tomados literalmente e estão abertos à interpretação pelo Mestre de Jogo. Desejos gananciosos normalmente terminam mal. Há uma chance de 10% de que um Desejo feito com intenções gananciosas saia pela culatra de alguma forma. Por exemplo, desejar riqueza poderia teletransportá-la dos cofres do tesouro do senhor local ou rei. Um Desejo não pode cancelar decretos de entidades semelhantes a divindades, a menos que tal ser tenha emitido o referido Desejo.

#### Visão do Mago

(Transmutação)

| | |
| :-- | :-- |
| **Grau:** Mago 3 | **Tempo de Conjuração:** 1 Minuto |
| **Esfera:** Nenhuma | **Duração:** 1 Minuto/Intensidade |
| **Custo:** 1/Intensidade | **Alcance:** 0 |
| **Área:** Veja abaixo | **Resistência:** ND |

Este feitiço cria um pequeno 'olho' invisível através do qual o usuário de magia pode ver durante a Duração do feitiço. Este olho pode ser movido à frente do grupo ou enviado para olhar ao redor de esquinas e para dentro de salas, possuindo uma Taxa de Movimento de 6 metros por Rodada (72 metros por minuto), se estiver apenas procurando por ameaças 'óbvias' ou itens de interesse. Isso normalmente se estenderá apenas ao chão e paredes inferiores. Se tentar ser mais completo (examinando as paredes completas e o teto também), sua Taxa de Movimento é reduzida para 3 metros por Rodada (36 metros por minuto). O Mestre de Jogo deve sentir-se à vontade para permitir testes de Percepção por parte do conjurador, onde necessário, com relação a identificar anomalias visuais. O olho é corpóreo, incapaz de passar através de matéria sólida, e possui visão normal até 18 metros e Visão no Escuro até 3 metros. O conjurador deve manter a Concentração no olho durante toda a Duração, ou ele permanecerá inerte até que a Concentração seja estabelecida novamente. Quaisquer ataques de olhar que normalmente afetariam o conjurador ainda afetam o conjurador normalmente; no entanto, o olho é considerado independente do conjurador com relação à cegueira, feitiços de escuridão e assim por diante. Para fins de passar por pequenas aberturas, o olho não é maior que 2,5 cm e tem um TAM de 1.

#### Palavra de Retorno

(Transmutação)

| | |
| :-- | :-- |
| **Grau:** Clérigo 4 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Invocação | **Duração:** Veja abaixo |
| **Custo:** 3, +1/Intensidade adicional | **Alcance:** 0 |
| **Área:** O conjurador | **Resistência:** ND |

Quando este feitiço é conjurado, o clérigo é instantaneamente teletransportado para um santuário pré-designado e um ponto de chegada designado não maior que 3 metros de raio. Não há limite para o Alcance real teletransportado, incluindo entre múltiplos planos. Dentro de um único plano, não há chance de um erro, no entanto, cruzar até mesmo um plano dá uma chance de Falha Crítica de 91-00%, dois planos dão uma Falha Crítica em uma rolagem de 81-00%, e assim por diante. Isso substitui a chance normal de Falha Crítica do conjurador. Uma Falha Crítica ao cruzar planos significa que o clérigo está irrevogavelmente perdido. Falhas Críticas dentro de um único plano seguem as regras normais.

Além de si mesmo e qualquer equipamento carregado, o clérigo pode transportar outros 3 objetos por Intensidade, cada um não maior que TAM/9 'Coisas'. O material adicional transportado pode ser tesouro, equipamento ou seres vivos. No entanto, as criaturas transportadas devem ter o feitiço conjurado em um nível de Intensidade suficiente para cobrir qualquer equipamento carregado.
