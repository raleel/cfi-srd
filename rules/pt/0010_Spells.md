## Descrições de Feitiços

---
#### Avaliar (Appraise)

(Adivinhação)

| | |
| :-- | :-- |
| **Rank:** Mago 0 | **Tempo de Conjuração:** 1 Turno |
| **Esfera:** Nenhuma | **Duração:** Instantânea |
| **Custo:** 1 | **Alcance:** Toque |
| **Área:** 1 Item | **Resistência:** Nenhuma |

Avaliar permite a avaliação imediata da qualidade de bens físicos com um ENC combinado em 'Coisas' ou TAM igual ao POD do conjurador. O feitiço determina se itens de aparência idêntica são de mesma qualidade ou semelhante, ou se um ou mais é defeituoso ou de qualidade superior. O feitiço não funciona em seres orgânicos, apenas em objetos inanimados. Também não determina quais defeitos ou melhorias estão presentes; apenas que existem. Não tem utilidade na identificação ou detecção de magia.

#### Armadura (Armor)

(Conjuração)

| | |
| :-- | :-- |
| **Rank:** Mago 1 | **Tempo de Conjuração:** 1 Rodada |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |
| **Custo:** 3 +1/Intensidade | **Alcance:** Toque |
| **Área:** 1 Alvo | **Resistência:** Nenhuma |

Quando este feitiço é conjurado, o alvo é presenteado com um campo invisível de força mágica equivalente a uma armadura de escamas em proteção, concedendo 4 Pontos de Armadura a cada Local de Acerto. Não tem efeito se conjurado em alguém que já esteja usando armadura. No entanto, substituirá a armadura natural pela sua Duração, assumindo que ofereça proteção superior. Se conjurado em uma criatura que possui mais de 4 pontos de armadura natural, aumentará os Pontos de Armadura em 1 em todos os locais. Esta proteção mágica não atrapalha o movimento ou a conjuração de feitiços. O feitiço persistirá até ser dissipado por magia, ou o conjurador sofrer 8 pontos de dano de um único ataque, +1 por nível de Intensidade adicional (veja a tabela abaixo). Naturalmente, o conjurador pode optar por encerrar o feitiço a qualquer momento, se desejar, e deve fazê-lo para dormir.

| Intensidade | Custo | Efeito Variável |
| :-: | :-: | :-- |
| 1 | 3 | 4 Pontos de Armadura; Mantido até sofrer 8 de dano de 1 ataque |
| 2 | 4 | 4 Pontos de Armadura; Mantido até sofrer 9 de dano de 1 ataque |
| 3 | 5 | 4 Pontos de Armadura; Mantido até sofrer 10 de dano de 1 ataque |
| 4 | 6 | 4 Pontos de Armadura; Mantido até sofrer 11 de dano de 1 ataque |
| +1 | +1 | Continua progressão |

#### Feitiço Astral (Astral Spell)

(Transmutação)

| | |
| :-- | :-- |
| **Rank:** Clérigo 5, Mago 5 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Astral | **Duração:** Veja abaixo |
| **Custo:** 3 +1/Intensidade adicional | **Alcance:** Toque |
| **Área:** Veja abaixo | **Resistência:** N/A |

Este feitiço permite ao conjurador e a até cinco outras pessoas (uma por nível adicional de Intensidade) entrar no Plano Astral. Todos devem estar se tocando e formando um círculo enquanto o feitiço é conjurado. Os corpos dos viajantes são deixados para trás no plano de origem, e eles normalmente não trazem consigo roupas ou equipamentos, exceto aqueles que irradiam uma aura mágica; esses itens transformam-se em equivalentes astrais de sua forma normal. A Duração dura até que o conjurador deseje que cesse. No entanto, é possível que seja encerrado prematuramente por uma força externa, como Dissipar Magia. Matar o corpo físico do conjurador também encerra o feitiço mais cedo, embora isso tenha o efeito colateral infeliz de deixar qualquer viajante que acompanhe o conjurador preso.

#### Augúrio (Augury)

(Adivinhação)

| | |
| :-- | :-- |
| **Rank:** Clérigo 2 | **Tempo de Conjuração:** 2 Minutos |
| **Esfera:** Adivinhação | **Duração:** Instantânea |
| **Custo:** 3/Intensidade | **Alcance:** 18 m (60 pés) |
| **Área:** Conjurador | **Resistência:** N/A |

Este feitiço permite ao conjurador determinar se uma ação específica a ser tomada nos próximos 30 minutos será benéfica ou prejudicial ao bem-estar de um indivíduo e/ou grupo. Um ponto focal de algum tipo é necessário para discernir os presságios, sendo os mais comuns as garras ou ossos menores de um dragão, uma pérola ou ouro puro avaliado em não menos que 100 PO, que foi esmagado ou derretido. O feitiço tem uma Intensidade Máxima de 4. Esta rolagem deve ser feita pelo Mestre de Jogo, pois o conjurador nunca deve saber sem sombra de dúvida se os resultados foram interpretados corretamente.

| Intensidade | Custo | Efeito Variável |
| :-: | :-: | :-- |
| 1 | 3 | Rolagem de habilidade Canalizar Formidável |
| 2 | 6 | Rolagem de habilidade Canalizar Difícil |
| 3 | 9 | Rolagem de habilidade Canalizar Padrão |
| 4 | 12 | Rolagem de habilidade Canalizar Fácil |

Se a rolagem de adivinhação for bem-sucedida, concede um dos seguintes resultados:

| Augúrio | Implicação | 
| :-: | :-- |
| Sim | A ação será benéfica |
| Não | A ação será prejudicial |
| Sim e Não | A ação será tanto benéfica quanto prejudicial |
| Nada | A ação não será nem benéfica nem prejudicial |

Uma falha crítica (Fumble) deve resultar no Mestre de Jogo dizendo o oposto da realidade.

#### Evitar (Avert)

(Abjuração)

| | |
| :-- | :-- |
| **Rank:** Clérigo 0, Mago 0 | **Tempo de Conjuração:** Instantâneo |
| **Esfera:** Proteção | **Duração:** Instantânea |
| **Custo:** 1 | **Alcance:** 18 m (60 pés) |
| **Área:** 1 Feitiço | **Resistência:** Nenhuma |

Evitar é usado para dispensar outro feitiço de Rank 0 dentro do Alcance. Evitar pode ser conjurado reativamente para neutralizar feitiços ofensivos de Rank 0, usando a Ação Reativa de Contra-Mágica.

#### Confundir (Befuddle)

(Encantamento (Encanto))

| | |
| :-- | :-- |
| **Rank:** Clérigo 0, Mago 0 | **Tempo de Conjuração:** 1 Turno |
| **Esfera:** Encanto | **Duração:** 30 Minutos |
| **Custo:** 1 | **Alcance:** 18 m (60 pés) |
| **Área:** 1 Alvo | **Resistência:** Força de Vontade |

Confundir causa confusão na mente de um alvo corpóreo. O sujeito do feitiço tem dificuldade em pensar direito, esquecendo onde está, o que está fazendo e por quê – muitas vezes caindo em linhas de pensamento dissociadas. Alvos confusos ainda podem agir em autodefesa, mas não podem iniciar nenhuma atividade construtiva até que o feitiço termine. Qualquer tipo de ataque ou ação ameaçadora quebra instantaneamente o feitiço, independentemente de ter sido direcionado especificamente ao alvo confundido.

#### Barreira de Lâminas (Blade Barrier)

(Evocação)

| | |
| :-- | :-- |
| **Rank:** Clérigo 4 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Guardião, Criação | **Duração:** 3 Rodadas/Intensidade |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 30 m (100 pés) |
| **Área:** Raio de 1,5 a 9 m (5-30 pés) | **Resistência:** Veja abaixo |

Este feitiço cria uma barreira de espadas, adagas e facas giratórias que chicoteiam e cortam ao redor de um ponto fixo e causam 1d8 pontos de dano a 1d4+2 Locais de Acerto aleatórios de *qualquer um* que passe pela Área de Efeito. A armadura oferece apenas metade de sua proteção normal. Pontos de Armadura mágicos reduzem o dano normalmente. Como as armas giram em velocidade ofuscante e estão bem compactadas, é impossível aparar ou desviar delas. Pode-se usar um escudo para bloquear passivamente os Locais de Acerto normalmente. Nesse caso, lembre-se de comparar o dano rolado com a armadura e os Pontos de Vida do escudo.

O feitiço pode ser conjurado defensivamente para proteger o clérigo ou um ou mais aliados, ou ofensivamente para prender inimigos. No entanto, inimigos cercados a menos de 1,5 metro da borda da barreira enquanto ela se forma podem fazer uma rolagem de Esquiva para escapar. Independentemente do sucesso, o oponente acaba caído, logo fora da Área de Efeito. Uma rolagem bem-sucedida resulta em nenhum dano; caso contrário, sofrem o efeito total.

#### Bênção (R) (Bless)

(Conjuração)

| | |
| :-- | :-- |
| **Rank:** Clérigo 1 | **Tempo de Conjuração:** 1 Rodada |
| **Esfera:** Todas | **Duração:** 5 Minutos |
| **Custo:** 1 | **Alcance:** 55 m (180 pés) |
| **Área:** Raio de 7,5 m (25 pés) | **Resistência:** Força de Vontade |

Quando este feitiço é conjurado, o clérigo abençoa um grupo de aliados dentro da Área de Efeito. Aqueles afetados irradiam o Alinhamento do conjurador, seja Bem ou Mal. Não existem bênçãos de Neutralidade. Todos os aliados dentro do raio do feitiço recebem um bônus de +5% em todas as rolagens de perícia e Resistência. Além disso, suas armas causam +1d3 de dano a mortos-vivos inteligentes, bem como a criaturas de planos externos que possuem alinhamentos opostos ao do conjurador, como demônios, diabos ou anjos. Observe que, embora mortos-vivos animados, como esqueletos e zumbis, não sejam inerentemente maus, eles são tipicamente animados por magia maligna e, portanto, sujeitos a esse dano.

A reversão deste feitiço, Maldição, permite ao clérigo amaldiçoar inimigos, fazendo com que as perícias notadas sofram o inverso dos benefícios notados acima. O dano de uma arma amaldiçoada é calculado como uma penalidade, e esse dano não pode resultar em menos de 1 ponto.

#### Mãos Flamejantes (Burning Hands)

(Transmutação)

| | |
| :-- | :-- |
| **Rank:** Mago 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Nenhuma | **Duração:** Instantânea |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 0 |
| **Área:** Cone de 120 graus, 1,5 m (5 pés) de comprimento | **Resistência:** Esquiva |

Este feitiço faz com que chamas disparem das mãos do conjurador em um arco de 120 graus. Se usar miniaturas em combate, Mãos Flamejantes causará dano a cada alvo que ocupe 1 dos quadrados frontais do conjurador. Conjurar Mãos Flamejantes em níveis de Intensidade mais altos requer um mago de Rank mais elevado. Este dano engolfa todos os alvos dentro da área com dano baseado na Intensidade do feitiço, até uma Intensidade Máxima de 9, conforme segue. Uma rolagem bem-sucedida de Esquiva, jogando-se no chão, permite que a vítima não sofra dano. Alguém com a Habilidade Artful Dodger tem a opção de Esquivar sem cair no chão.

| Intensidade | Custo | Rank Mín | Efeito Variável |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 pontos de dano em todos os Locais de Acerto |
| 3 | 4 | 1 | 1d3+2 pontos de dano em todos os Locais de Acerto |
| 5 | 5 | 1 | 1d3+3 pontos de dano em todos os Locais de Acerto |
| 7 | 6 | 2 | 1d3+4 pontos de dano em todos os Locais de Acerto |
| 9 | 7 | 3 | 1d3+5 pontos de dano em todos os Locais de Acerto |

Armadura usada não protege, mas Pontos de Armadura mágicos ou a armadura natural de uma criatura reduzem o dano normalmente. Este feitiço poderoso é equilibrado pelo seu alcance notavelmente curto, significando que, para conjurá-lo, o usuário de magia deve estar perto o suficiente para estar em uma posição muito desvantajosa.

Como criaturas maiores são tipicamente maiores que a Área de Efeito do feitiço, elas tenderão a ter menos Locais de Acerto afetados. Aqueles de TAM 21 a 30 sofrem dano na cabeça, peito, abdômen e braços, enquanto aqueles de TAM 31+ sofrem dano no abdômen e pernas. Os Mestres de Jogo devem ajustar esses locais dependendo da forma e posição do alvo em relação ao conjurador. Mãos Flamejantes tem uma chance de incendiar materiais inflamáveis igual ao dano rolado x5%. Veja a seção sobre [Fogos](0007_Game_System.md?id=fire-based-attacks) para obter informações adicionais.

#### Comando (Command)

(Encantamento (Encanto))

| | |
| :-- | :-- |
| **Rank:** Clérigo 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Encanto | **Duração:** 1 Minuto |
| **Custo:** 3 | **Alcance:** 30 m (100 pés) |
| **Área:** 1 Alvo | **Resistência:** Força de Vontade |

Quando este feitiço é conjurado, o clérigo pode proferir um comando de uma única palavra para uma criatura viva de TAM 1-20, e no próximo Turno do sujeito, o comando será seguido à risca se falharem em resistir. Isso essencialmente faz com que a vítima perca o próximo Turno completando a ação comandada e desperdice um Ponto de Ação enquanto a executa. Se a vítima não possuir mais Pontos de Ação, a ação comandada será realizada durante seu primeiro Turno da próxima Rodada. O comando em si não pode causar qualquer dano real ao alvo; no entanto, ferimentos podem vir como efeito secundário do comando.

Por exemplo, um comando para morrer resultaria na vítima colapsando em um estado de morte aparente por 1 Rodada, sem causar ferimentos reais; no entanto, um comando para cair dado a uma criatura escalando uma face de penhasco de 30 metros de altura poderia ser mais do que mortal.

O sujeito do comando deve ser capaz de entender a língua falada pelo conjurador e tem direito a um teste de Força de Vontade para resistir.

**Alguns Comandos de Exemplo**

- **Rastejar:** O sujeito fica de bruços e começa a rastejar.
- **Morrer:** O sujeito cai de bruços entrando em um estado comatoso semelhante à morte.
- **Cair:** O sujeito cai de bruços.
- **Trapalhar:** O sujeito atrapalha uma ação física prestes a ser realizada.
- **Dormir:** O sujeito cochila.
- **Fugir:** O sujeito se vira e foge do conjurador.
- **Voar:** O sujeito bate os braços e corre em círculos.
- **Ir:** O sujeito começa a caminhar na direção em que estava voltado.
- **Parar:** O sujeito para imediatamente e permanece no lugar.
- **Sair:** O sujeito se vira e sai por onde entrou.
- **Descansar:** O sujeito cai em uma posição sentada e recupera o fôlego.
- **Correr:** O sujeito começa a correr.
- **Gritar:** O sujeito grita.
- **Afundar:** O sujeito para de nadar.
- **Rendição:** O sujeito solta suas armas e cessa as hostilidades.

#### Encantar Item (Enchant Item)

(Encantamento)

| | |
| :-- | :-- |
| **Rank:** Mago 4 | **Tempo de Conjuração:** Veja abaixo |
| **Esfera:** Nenhuma | **Duração:** Veja abaixo |
| **Custo:** 3 + Veja abaixo | **Alcance:** Toque |
| **Área:** 1 Item | **Resistência:** N/A |

A conjuração deste feitiço prepara um item para o Encantamento. O objeto deve estar em boas condições e ter a melhor construção e mão de obra. Um custo adicional de pelo menos 100 PO é necessário para cobrir o custo de ferramentas adicionais, entalhe, bordado, cravação de joias, gravação, e assim por diante. Finalmente, o processo de Encantamento requer um laboratório ou oficina.

Ao conjurar o feitiço, o usuário de magia deve estar tocando o item durante todo o Tempo de Conjuração de 1d8+2 dias. Isso leva em conta períodos de descanso e sono, durante os quais o item deve permanecer ao alcance do braço do conjurador. Em nenhum momento durante a conjuração o usuário de magia pode conjurar outro feitiço ou realizar qualquer outra forma de magia. Quebrar qualquer uma dessas normas causará automaticamente a falha do feitiço.

Uma vez conjurado com sucesso, o item está pronto para o passo final, com o conjurador colocando o feitiço desejado nele. Para fazer isso, eles devem ter o feitiço na memória ou em um pergaminho e conjurá-lo no item dentro de 24 horas, ou todo o processo precisará ser iniciado do zero. Uma vez iniciada a conjuração do feitiço selecionado, o processo pode exceder as 24 horas mencionadas acima. Imbuir o item com o feitiço selecionado custa o número normal de Pontos de Magia para a Intensidade desejada e leva 1d12 horas por Rank de feitiço. Durante todo o processo de imbuir, o conjurador deve permanecer tocando o item ou permanecer ao alcance do braço durante períodos de descanso, como acima, e uma rolagem de Conjuração Arcana é necessária ao final do período de conjuração para imbuir o feitiço com sucesso. Os graus de sucesso normais de Conjuração de Feitiços são seguidos, no entanto, com relação a um resultado de Falha, o feitiço não pode ser forçado. Feitiços sucessivos podem ser imbuídos no item, desde que o processo de conjuração seja iniciado dentro de 24 horas da conclusão do feitiço anterior. Isso se aplica mesmo no caso de um feitiço falhado anteriormente. Cada feitiço sucessivo requer o Custo de Conjuração normal.

Ao usar o item, cada feitiço contido nele pode ser conjurado apenas uma vez; no entanto, múltiplas versões do mesmo feitiço podem ser imbuídas seguindo o procedimento acima. Também é possível imbuir um único feitiço, seguindo-o com uma conjuração do feitiço de Rank 4 Permanência. Nesse caso, o feitiço pode ser conjurado quantas vezes desejar, seguindo as restrições estabelecidas na descrição do feitiço Permanência.

Não é possível imbuir outros efeitos mágicos em um item que não se conformem a um feitiço específico, e muitos itens mágicos de tempos passados simplesmente não podem ser recriados nos dias de hoje.

#### Encontrar Familiar (Find Familiar)

(Conjuração)

| | |
| :-- | :-- |
| **Rank:** Mago 1 | **Tempo de Conjuração:** 2d12 Horas |

| **Custo:** 3/Intensidade, +1 EXP | **Alcance:** 0 |
| **Área:** Raio de 800 m (½ milha)/Intensidade | **Resistência:** N/A |

Este feitiço permite ao conjurador tentar invocar um familiar, que se torna uma extensão dos sentidos e poder de seu mestre. Familiares podem conversar com seu mestre telepaticamente e são bons guardas e batedores. Ter seu familiar morto apresenta certos riscos ao usuário de magia devido à sua conexão próxima, o que faz ter um familiar um perigo de baixo nível.

Para invocar um familiar, o usuário de magia deve começar o ritual mantendo um braseiro abastecido com carvão e, quando queimando com intensidade, adicionar 100 PO de incenso. Com esses ingredientes queimando, o conjurador deve então continuar o ritual até que o familiar chegue ou o Tempo de Conjuração expire sem sucesso.

Mesmo se este feitiço for conjurado com sucesso, a chance de um familiar adequado responder ao chamado do usuário de magia é de apenas 50%, e o usuário de magia só pode tentar este feitiço uma vez por ano. Cada nível adicional de Intensidade além do primeiro estende o Alcance do feitiço por mais 800 metros, o que por sua vez aumenta a probabilidade de encontrar um familiar potencial em 5%, para um máximo de 95%. Não há controle sobre o tipo exato de criatura que responderá ao chamado, mas o que chegar será um servo e aliado fiel. Cabe à criatura específica responder ao chamado, portanto, estar em uma região conhecida por ser habitada por um certo tipo de criatura não garante sucesso ao conjurador.

Se uma criatura responder aos chamados do conjurador, o usuário de magia ainda precisa sacrificar 1 Rolagem de Experiência para criar um elo espiritual entre si e o familiar. Uma vez feito isso, o ritual está completo.

Enquanto o familiar e seu mestre estão a menos de 36 metros (120 pés) um do outro, o usuário de magia ganha a habilidade de usar os Pontos de Magia do familiar também. Além disso, o usuário de magia ganha um elo telepático com o familiar e quaisquer Habilidades especiais adicionais ou bônus de perícia notados nas tabelas abaixo.

No caso da morte do familiar, o conjurador perde 5 Rolações de Experiência. Um conjurador que não possui nenhuma Rolagem de Experiência deve perder todas as Rolações de Experiência futuras concedidas até que o saldo seja pago.

#### Escudo de Fogo (Fire Shield)

(Evocação)

| | |
| :-- | :-- |
| **Rank:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** 2 Minutos/Intensidade |
| **Custo:** 3+1/Intensidade adicional | **Alcance:** 0 |
| **Área:** Conjurador | **Resistência:** N/A |

Este feitiço cria um escudo de chamas finas que imola o conjurador, mas não causa dano por si só. Em vez disso, as chamas protegem o recipiente contra fogo ou frio, dependendo de qual das duas variantes está na memória: Escudo de Frio, que cria chamas azuis ou verdes e protege contra calor e dano baseado em fogo, ou Escudo de Calor, que cria chamas violetas ou azuis e protege contra frio e dano baseado em gelo. A cor das chamas deve ser determinada aleatoriamente com 50% de chance para cada, já que o fato de que ambos os tipos podem emitir chamas azuis cria um elemento de incerteza por parte de qualquer atacante. A decisão de qual memorizar é feita quando os feitiços são preparados, e ambos podem ser memorizados se desejado. Essas chamas não emitem calor e emitem luz com apenas metade do brilho de uma tocha. Os detalhes de cada variante estão detalhados abaixo.

- **Escudo de Frio:** Essas chamas são frias ao toque e reduzem qualquer dano baseado em fogo ou calor à metade do total. Uma rolagem bem-sucedida de Resistência negará todo o dano. A rolagem de Resistência é um grau mais fácil e, no caso de Esquiva, não tornará o defensor caído.
- **Escudo de Calor:** Essas chamas são quentes ao toque e reduzem qualquer dano baseado em frio à metade do total. Uma rolagem bem-sucedida de Resistência negará todo o dano. A rolagem de Resistência é um grau mais fácil e, no caso de Esquiva, não tornará o defensor caído.

Ataques corpo a corpo contra o recipiente de qualquer variante, armados ou desarmados, infligem dano normal, a menos que usem um dos elementos contra os quais estão protegidos. Nesse caso, o conjurador está protegido da parte elemental do ataque, e o atacante recebe dano igual ao infligido. Armadura usada por parte do atacante não oferece proteção, mas Pontos de Armadura mágicos ou a armadura natural de uma criatura reduzem o dano normalmente. Criaturas com Resistência à Magia Inata podem dissipar Escudo de Fogo em uma rolagem bem-sucedida de Força de Vontade quando o recipiente é atingido pela primeira vez. Se a rolagem de Resistência à Magia falhar, o oponente não poderá negar o Escudo de Fogo mais tarde.

Cada Intensidade adicional pode ser usada para curar outra enfermidade ou curar outro Local de Acerto. Portanto, exigiria uma conjuração em Intensidade 7 para curar um indivíduo sofrendo de queimaduras em todo o seu corpo. Diferente dos feitiços de cura menores que limitam sua eficácia contra lesões de longo prazo, não há limites impostos ao feitiço pela Duração na qual o sujeito sofreu os efeitos da lesão.

A rolagem de Canalizar do conjurador funciona como a rolagem para atingir o oponente e é assumida como parte do requisito somático do feitiço. Nenhuma rolagem adicional para atingir é necessária. Nem a armadura usada nem a natural oferecem proteção, mas os Pontos de Armadura mágicos reduzem o dano normalmente e bloqueiam totalmente as enfermidades infligidas. Cada Intensidade adicional afeta outro Local de Acerto contíguo ao primeiro, com efeitos determinados pela rolagem inicial de Resistência. Nenhuma versão deste feitiço tem efeito sobre mortos-vivos, criaturas prejudicadas apenas por ferro, prata ou armas mágicas, ou seres não corpóreos.

(Transmutação)

| | |
| :-- | :-- |

Este feitiço cria uma boca em um item ou objeto, que aparece magicamente quando acionado por um evento específico ou tempo determinado pelo usuário de magia quando o feitiço é conjurado pela primeira vez. A distância máxima que o feitiço pode ser acionado é 7,5 metros por Intensidade.

A Duração deste feitiço é permanente até que o encanto seja ativado e então o feitiço termina.

| | |

| **Esfera:** Animal | **Duração:** Concentração |
| **Custo:** 1 | **Alcance:** Toque |
| **Área:** 1 Animal | **Resistência:** Força de Vontade |

Pet permite ao conjurador assumir o controle mental de uma pequena criatura, enviando-a para explorar, buscar ou realizar alguma outra tarefa complexa. Pode ser conjurado em qualquer criatura cujo TAM e INT não excedam metade do CHA do conjurador. Se a criatura visada já for o animal de estimação leal do conjurador, não precisa resistir ao feitiço. Enquanto se concentra, o conjurador pode acessar os sentidos do animal (visão, olfato, audição, e assim por diante).

#### Troca de Plano (Plane Shift)

(Transmutação)

| | |
| :-- | :-- |
| **Rank:** Clérigo 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Astral | **Duração:** Permanente |
| **Custo:** 3, +1/Intensidade adicional | **Alcance:** Toque |
| **Área:** Veja abaixo | **Resistência:** Força de Vontade |

Quando conjurado, o clérigo e até 7 outros (um por nível adicional de Intensidade) podem viajar para outro plano de existência. Todos devem estar se tocando e formando um círculo enquanto o clérigo conjura o feitiço. Além disso, o conjurador também pode usar o feitiço para transportar uma criatura independentemente de si mesmo, disposta ou não, para um plano de escolha do conjurador; no entanto, os relutantes podem fazer uma rolagem de Força de Vontade para resistir, com um Sucesso negando o feitiço. O ponto preciso de chegada raramente é o que o conjurador deseja. Se usar um mapa hexagonal, role 1d6 para determinar a direção e 1d10x10 para a distância em milhas.

Além de quaisquer componentes materiais genéricos, a conjuração de Troca de Plano requer hastes de vários metais raros, cada um especialmente sintonizado com um plano de existência. Essas hastes são raras e facilmente avaliadas em até 10.000 PO cada.

#### Polimorfismo (Polymorph Other)

(Transmutação)

| | |
| :-- | :-- |
| **Rank:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** Permanente |
| **Custo:** 3, +1/Intensidade adicional (+1 EXP) | **Alcance:** 4,5 m (15 pés)/Intensidade |
| **Área:** 1 Alvo | **Resistência:** Força de Vontade |

O conjurador pode alterar a forma de uma criatura corpórea visada para a de outra, com cada ponto de Intensidade alterando o TAM em até 5 pontos. Portanto, transformar um orc de TAM 16 em um coelho de TAM 1 exigiria 3 níveis de Intensidade (15 pontos de diferença de TAM). O sujeito deste feitiço tem direito a uma rolagem de Força de Vontade para resistir. Criaturas Grandes (TAM 21-40) são menos suscetíveis a serem polimorfadas, com sua rolagem de Resistência sendo Fácil, enquanto a rolagem de Resistência para criaturas Enormes (TAM 41+) é Muito Fácil.

Todo o processo de transformação leva uma Rodada completa e pode ser bastante estressante para a criatura em questão, exigindo uma segunda rolagem de Força de Vontade para reter sua personalidade original, com uma Falha atordoando o sujeito por 1d10 minutos, e um Fumble resultando em morte por choque mental. Cada duplicação ou divisão do TAM original da criatura torna a rolagem de Força de Vontade para reter a personalidade um grau mais difícil, assim como uma mudança completa de ambiente, como transformar uma pessoa em um peixe. Uma rolagem bem-sucedida permite que a vítima retenha seu INT e CHA, bem como quaisquer perícias que requeiram essas Características.

A transformação concede ao recipiente a forma de respiração da criatura assumida, se diferente da normal; quaisquer ataques naturais; e todos os modos mundanos de movimento. Não concede quaisquer Habilidades aprimoradas ou mágicas possuídas pela criatura. Por exemplo, uma criatura que foi polimorfada em um dragão não ganhará o sopro de ataque ou habilidades similares a feitiços da criatura, mas ganhará a capacidade de voar, sua pele dura, mordida mortal, ataques de garra, e assim por diante. Além disso, a vítima ganha as perícias físicas da nova forma, como Atletismo, Brawn, Voar, Nadar, bem como seus Pontos de Vida e Modificador de Dano. Assumindo que o indivíduo transformado reteve sua INT, eles ainda perdem a capacidade de falar, a menos que a nova forma possua a capacidade de articular palavras. Aqueles que eram capazes de conjurar feitiços em sua forma anterior ainda seriam capazes de conjurar na nova forma, assumindo que ainda possuam a capacidade de produzir os componentes verbais e somáticos. No caso de uma mudança drástica, como ser transformado de bípede em quadrúpede, ou um animal terrestre em uma criatura marinha, por exemplo, o Mestre de Jogo deve se sentir livre para penalizar em pelo menos um Grau de Dificuldade o uso de quaisquer perícias que levariam tempo para aprender enquanto se ajusta à nova forma até que haja tempo suficiente para praticar. Isso é especialmente verdadeiro para perícias físicas como Atletismo, Desarmado, Nadar, Voar, Perícias de Combate, e assim por diante.

A rolagem de Força de Vontade para reter sua personalidade é necessária a cada dia que o sujeito permanece transformado até falhar, fazendo com que a pessoa finalmente sucumba à mentalidade da nova forma, com INT mudando para INS no caso de uma criatura não sapiente. Todas as Habilidades especiais e mágicas possuídas pela nova forma que não foram adquiridas anteriormente, como ataques de olhar, armas de sopro, e assim por diante, estão agora disponíveis para a criatura à medida que a transformação é concluída. Personagens que perdem sua identidade desta forma tornam-se Personagens Não Jogáveis sob o controle do Mestre de Jogo.

Antes de sucumbir mentalmente à transformação, a criatura polimorfada é suscetível a Dissipar Magia normalmente, sem necessidade de rolagem para resistir, pois seria o desejo subconsciente de voltar ao normal. A transformação requer outra rolagem de Força de Vontade para resistir ao esforço, com uma Falha atordoando o sujeito por 1d10 minutos, e um Fumble resultando em morte por choque mental.

Se a vítima sucumbiu anteriormente à nova forma, Dissipar Magia ainda pode ser usado; no entanto, a vítima tentará resistir a retornar à forma natural com uma rolagem de Força de Vontade. Falhar nesta rolagem significa que a vítima se transforma de volta na forma natural, o que, é claro, requer outra rolagem de Força de Vontade para resistir ao choque mental da transformação. Uma vez perdida, a identidade natural de uma vítima não é mais atingível, em vez disso, a vítima assume que a forma estranha e alienígena é natural e anseia por ser devolvida ao seu estado anterior 'normal'. _Por exemplo, um orc que foi polimorfado em um coelho e assumiu a identidade da criatura acreditaria que agora é um coelho que foi transformado de forma bastante grosseira em um orc._ Apenas um Desejo, ou outra magia similar, tem qualquer chance de restaurar a identidade da vítima uma vez que tenha sido perdida.

Todo equipamento usado e carregado funde-se magicamente na nova forma; no entanto, em alguns casos, o Mestre de Jogo pode permitir que itens mágicos que ainda seriam capazes de ser usados na nova forma da criatura permaneçam, como um anel mágico ou botas. Observe que isso requer que o novo TAM da criatura não seja vastamente diferente do original. Há uma chance de POD x1% para cada item mágico usado de natureza não ofensiva, sujeito à aprovação do Mestre de Jogo, transferir seus efeitos para a nova forma da criatura. Uma criatura com um anel de proteção +1, por exemplo, poderia ganhar um bônus de +1 aos seus Pontos de Armadura naturais. Criaturas com a capacidade natural de mudar de forma, como doppelgängers e licantropos, serão transformadas normalmente, mas podem assumir sua forma normal após 1 Rodada. Se morta, uma criatura polimorfada reverte para sua forma natural, mesmo que tenha perdido anteriormente todos os vestígios de identidade.

| :-: | :-: | :-- |
| 1 | 3, +1 EXP | Alcance 4,5 m; 1-5 pontos de diferença de TAM |
| 2 | 4, +1 EXP | Alcance 9 m; 6-10 pontos de diferença de TAM |
| 3 | 5, +1 EXP | Alcance 13,5 m; 11-15 pontos de diferença de TAM |
| 4 | 6, +1 EXP | Alcance 18 m; 16-20 pontos de diferença de TAM |

#### Polimorfismo em Si Mesmo (Polymorph Self)

(Transmutação)

| | |
| :-- | :-- |
| **Rank:** Mago 3 | **Tempo de Conjuração:** 2 Ações |
| **Esfera:** Nenhuma | **Duração:** 20 Minutos/Intensidade |
| **Custo:** 3, +1/Intensidade adicional | **Alcance:** 0 |
| **Área:** Conjurador | **Resistência:** NA |

O conjurador pode assumir a forma de qualquer outra criatura corpórea, desde tão pequena quanto TAM 1 até TAM 40. Cada ponto de Intensidade permite um aumento ou diminuição de até 10 pontos de TAM. Portanto, um usuário de magia de TAM 13 poderia assumir a forma de um urso pardo de TAM 34 com 3 níveis de Intensidade. O processo de transformação leva uma Rodada completa e concede ao conjurador a forma de respiração da criatura assumida (se diferente da dele, por exemplo, respirar água), quaisquer ataques naturais, Pontos de Vida, Modificador de Dano e seu modo normal de movimento. Não concede quaisquer Habilidades aprimoradas ou mágicas possuídas pela criatura. Um usuário de magia que se polimorfou em um falcão, por exemplo, não ganhará a visão extraordinária do pássaro. O conjurador ganha as perícias físicas da criatura, como Atletismo, Brawn, Voar, Nadar, e assim por diante, mas retém quaisquer perícias mentais e sociais (aquelas que exigem INT e CHA). O conjurador perde a capacidade de falar, a menos que a criatura em questão possua a habilidade de articular palavras. Se possuir, o conjurador ainda pode conjurar feitiços na nova forma, assumindo que possa formar os componentes somáticos do feitiço.

O conjurador pode encerrar o efeito a qualquer momento e, no processo, todos os Ferimentos Leves ganhos enquanto na nova forma são perdidos, e Ferimentos Graves são reduzidos a Ferimentos Leves (metade dos Pontos de Vida perdidos em cada local aplicável). Ferimentos Grandes não são afetados pela transformação e transitam para a forma natural. Não há cura quando o conjurador se transforma da forma natural para a forma animal.

Polimorfismo está sujeito a Dissipar Magia. Nesse caso, o conjurador não se beneficia da cura. Se morto, o conjurador reverterá para sua forma natural. Se transformado em um voador e obrigado a fazer uma rolagem de perícia Voar, Atletismo ou Acrobacia podem ser substituídas em dois graus de dificuldade. No entanto, um personagem que usa esta forma frequentemente pode optar por desenvolver a perícia Voar normalmente com um Valor Base de FOR+DES.

| 2 | 4 | 40 min.; 11-20 pontos de diferença de TAM |

#### Proteção contra o Mal (Protection from Evil) (R)

(Abjuração)

| | |
| :-- | :-- |
| **Rank:** Clérigo 1, Mago 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Proteção | **Duração:** 2 Minutos/Intensidade |
| **Custo:** 1/Intensidade | **Alcance:** Toque |
| **Área:** 1 Alvo | **Resistência:** NA |

Quando conjurado, uma aura invisível de armadura mágica irradia do recipiente do feitiço (que pode ser o conjurador), concedendo três níveis diferentes de defesa.

Primeiro, ataques de criaturas com um Alinhamento Maligno recebem uma penalidade de -10% em seu Estilo de Combate ou perícia Desarmado. Rolagens de Resistência por parte do recipiente de Proteção contra o Mal recebem um bônus de +10%, mas apenas contra criaturas malignas.

Segundo, nem criaturas invocadas nem conjuradas, nem seres não nativos do plano material, podem fazer contato físico com o recipiente. Isso inclui demônios, diabos, gênios, elementais, servos aéreos, salamandras, e assim por diante. Ataques naturais dessas criaturas fazem com que recuem, falhando assim em fazer contato. Isso também inclui quaisquer monstros ou criaturas conjuradas por feitiços ou itens. Armas empunhadas por tais criaturas ainda podem entrar na barreira mágica e atingir o indivíduo protegido, no entanto.

Terceiro, quaisquer tentativas de controle mental (como por feitiços como Encantar ou Comando) ou possessão (como por feitiços como Jarro Mágico) falham automaticamente em penetrar a proteção mágica.

A Duração do feitiço termina se o indivíduo protegido fizer qualquer tipo de ataque corpo a corpo ou tentar impor o campo protetor contra uma criatura afetada.

A reversão deste feitiço, Proteção contra o Bem, funciona como acima com relação ao segundo e terceiro benefício, enquanto o primeiro benefício funciona como notado com relação a oponentes bons.

#### Ressuscitar (Raise Dead) (R)

(Necromancia)

| | |
| :-- | :-- |
| **Rank:** Clérigo 3 | **Tempo de Conjuração:** 1 Minuto |
| **Esfera:** Necromântica | **Duração:** Permanente |
| **Custo:** 3, +1/Intensidade adicional, +1 EXP | **Alcance:** 30 m (100 pés) |
| **Área:** 1 Alvo | **Resistência:** NA (Força de Vontade) |

Este feitiço pode ser conjurado no cadáver de uma criatura morta há menos de 24 horas por nível de Intensidade. Se o Alinhamento do sujeito fosse qualquer outro que não o mal, ele pode resistir ao feitiço com uma rolagem de Força de Vontade Oposta e, se bem-sucedido, negar os efeitos do feitiço. Isso ocorre porque a alma ou espírito do falecido raramente está disposto a retornar aos vivos depois de ter alcançado sua recompensa eterna. O Mestre de Jogo pode decidir dispensar a rolagem se o recipiente tiver negócios inacabados, não puder ser separado de seu verdadeiro amor ou tiver algum outro motivo heroico para viver.

No caso de almas malignas, que retornariam alegremente ao plano material em vez de sofrer a condenação eterna, não é a Força de Vontade do falecido que está resistindo, mas a do demônio, diabo, e assim por diante, colocado no comando de sua punição, seu tormentador. Nesse caso, o conjurador deve superar a Força de Vontade do tormentador. Se isso for desconhecido, assuma que é pelo menos 20 pontos maior do que a do falecido para representar que quanto mais forte a vontade da alma, mais poderoso o ser colocado no comando de sua condenação. Se o conjurador tiver sucesso, ele devolveu com sucesso o espírito ao corpo, enquanto uma rolagem falhada resulta na vítima estando indisposta ou incapaz de retornar.

Se a conjuração for bem-sucedida, o sujeito é trazido de volta à vida com Pontos de Vida completos, embora membros decepados permaneçam perdidos. Isso significa que uma vítima decapitada ou cortada ao meio não pode ser ressuscitada até que sua cabeça ou torso seja primeiro recolocado. Isso pode ser feito antes da conjuração de Ressuscitar recolocando fisicamente o local decepado, o que requer um kit de curandeiro e uma aplicação bem-sucedida da perícia Cura, e normalmente deixa uma cicatriz óbvia e reveladora. Outras enfermidades, como veneno ou doença, devem ser cuidadas antes ou depois da conjuração de Ressuscitar, ou os resultados são apenas temporários. Finalmente, Ressuscitar não tem efeito sobre uma criatura que atingiu o fim de sua vida natural e morreu de velhice.

O ato de ser ressuscitado dos mortos é muito exaustivo para o sujeito, que é reduzido a um Nível de Fadiga de Incapacitado por um período de 24 horas para cada dia que estiveram mortos. A conjuração de Curar Fadiga não tem efeito sobre o paciente durante este tempo de convalescença. Após este ponto, o personagem recupera da Fadiga normalmente, e sem restrição.

Quando revertido, Matar Vivo, pode ser usado para matar uma vítima designada pelo clérigo no momento da conjuração. Esta vítima tem direito a uma rolagem de Força de Vontade para resistir, modificada pelo Rank ou TAM do alvo, o que der o resultado mais benéfico ao alvo, conforme detalhado na tabela a seguir.

| Rank do Alvo | TAM do Alvo | Modificador de Força de Vontade |
| :-: | :-: | :-: |
| 0-1\* | 1-20 | Difícil |
| 2 | 21-40 | Padrão |
| 3 | 41-60 | Fácil |
| 4-5 | 61+ | Muito Fácil |

_\* Esta categoria inclui personagens que não possuem uma Classe._

Se a rolagem de Resistência for malsucedida, a vítima é morta instantaneamente. Uma rolagem bem-sucedida é tratada conforme os efeitos de Causar Ferimentos Moderados. Armadura não oferece proteção contra este dano. Matar Vivo não envelhece o conjurador quando usado.

#### Retardar Veneno (Slow Poison)

(Necromancia)

| | |
| :-- | :-- |
| **Rank:** Clérigo 1 | **Tempo de Conjuração:** 1 Ação |
| **Esfera:** Cura | **Duração:** 1 Hora/Intensidade |

Este feitiço permite ao conjurador retardar os efeitos de venenos e peçonha; não neutraliza, no entanto, a toxina. Como último recurso, se o conjurador conseguir chegar a um indivíduo que 'morreu' de envenenamento dentro de 10 minutos, Retardar Veneno atrasa a morte de uma vítima por 1 hora por Intensidade, durante a qual a vítima permanece em coma.
