#### Appraise

(దివ్యదృష్టి - Divination)

| | |
| :-- | :-- |
| **ర్యాంక్:** మేజ్ 0 | **మంత్రించే సమయం:** 1 టర్న్ |
| **గోళం:** ఏదీ లేదు | **వ్యవధి:** తక్షణమే |
| **ఖర్చు:** 1 | **పరిధి:** తాకడం (Touch) |
| **ఏరియా:** 1 వస్తువు | **నిరోధకత:** ఏదీ లేదు |

Appraise, మంత్రగాడి POWకి సమానమైన పరిమాణం గల భౌతిక వస్తువుల నాణ్యతను వెంటనే అంచనా వేయడానికి అనుమతిస్తుంది. ఈ మంత్రం ఒకేలా కనిపించే వస్తువులు ఒకే నాణ్యతతో ఉన్నాయా, లేదా ఏదైనా వస్తువులో లోపాలు ఉన్నాయా లేదా మెరుగైనదా అని నిర్ధారిస్తుంది. ఈ మంత్రం ప్రాణమున్న వాటిపై పనిచేయదు, కేవలం నిర్జీవమైన వస్తువులపై మాత్రమే పనిచేస్తుంది. లోపాలు లేదా మెరుగుదలలు ఏమిటో ఇది చెప్పదు, అవి ఉన్నాయని మాత్రమే చెబుతుంది. మ్యాజిక్‌ను గుర్తించడానికి లేదా కనుగొనడానికి ఇది ఉపయోగపడదు.

#### Armor

(కన్జురేషన్ - Conjuration)

| | |
| :-- | :-- |
| **ర్యాంక్:** మేజ్ 1 | **మంత్రించే సమయం:** 1 రౌండ్ |
| **గోళం:** ఏదీ లేదు | **వ్యవధి:** కింద చూడండి |
| **ఖర్చు:** 3 +1/తీవ్రత (Intensity) | **పరిధి:** తాకడం |
| **ఏరియా:** 1 లక్ష్యం | **నిరోధకత:** ఏదీ లేదు |

ఈ మంత్రాన్ని ప్రయోగించినప్పుడు, సదరు వ్యక్తికి అదృశ్యమైన మంత్ర శక్తి కవచం లభిస్తుంది, ఇది 4 ఆర్మర్ పాయింట్లను ఇస్తుంది. ఇప్పటికే కవచం ధరించిన వారిపై దీనికి ప్రభావం ఉండదు. మంత్రం ప్రభావం ఉన్నంత వరకు, ఇది సహజ కవచం కంటే ఎక్కువ రక్షణనిస్తే దాని స్థానాన్ని ఆక్రమిస్తుంది. ఇప్పటికే 4 కంటే ఎక్కువ సహజ ఆర్మర్ పాయింట్లు ఉన్న జీవులపై ప్రయోగిస్తే, అది అన్ని భాగాల్లో ఆర్మర్ పాయింట్లను 1 పెంచుతుంది. ఈ మాయా రక్షణ కదలికలకు లేదా మంత్రం ప్రయోగించడానికి ఆటంకం కలిగించదు. మంత్రాన్ని రద్దు చేసే వరకు లేదా ఒకే దాడిలో 8 పాయింట్ల నష్టం జరిగినప్పుడు (అదనపు తీవ్రత స్థాయికి +1) ఈ మంత్రం ప్రభావం ఉంటుంది. మంత్రగాడు ఎప్పుడైనా దీనిని వదులుకోవచ్చు, నిద్రించడానికి తప్పనిసరిగా వదులుకోవాలి.

#### Astral Spell

(ట్రాన్స్‌మ్యుటేషన్ - Transmutation)

| | |
| :-- | :-- |
| **ర్యాంక్:** క్లెరిక్ 5, మేజ్ 5 | **మంత్రించే సమయం:** 2 చర్యలు |
| **గోళం:** ఆస్ట్రల్ | **వ్యవధి:** కింద చూడండి |
| **ఖర్చు:** 3 +1/అదనపు తీవ్రత | **పరిధి:** తాకడం |
| **ఏరియా:** కింద చూడండి | **నిరోధకత:** వర్తించదు |

ఈ మంత్రం మంత్రగాడిని మరియు మరో ఐదుగురిని (ఒక్కో అదనపు తీవ్రతకు ఒక్కరు) ఆస్ట్రల్ ప్లేన్‌కు ప్రయాణించేలా చేస్తుంది. మంత్రించేటప్పుడు అందరూ తాకుతూ వలయంగా ఉండాలి. ప్రయాణీకుల భౌతిక శరీరాలు ఇక్కడే ఉండిపోతాయి, సాధారణంగా వారు బట్టలు లేదా వస్తువులను తీసుకెళ్లలేరు, మంత్ర ప్రభావం ఉన్న వస్తువులు మినహా, అవి ఆస్ట్రల్ రూపంలోకి మారతాయి. మంత్రగాడు కోరుకున్నంత వరకు ఈ వ్యవధి ఉంటుంది. అయితే, డిస్పెల్ మ్యాజిక్ వంటి బయటి శక్తులు దీనిని ముందుగానే ముగించవచ్చు. మంత్రగాడి భౌతిక శరీరం చనిపోతే కూడా మంత్రం ఆగిపోతుంది, దీనివల్ల తోటి ప్రయాణీకులు అక్కడ చిక్కుకుపోతారు.

#### Blade Barrier

(ఎవోకేషన్ - Evocation)

| | |
| :-- | :-- |
| **ర్యాంక్:** క్లెరిక్ 4 | **మంత్రించే సమయం:** 2 చర్యలు |
| **గోళం:** గార్డియన్, సృష్టి | **వ్యవధి:** 3 రౌండ్లు/తీవ్రత |
| **ఖర్చు:** 3+1/అదనపు తీవ్రత | **పరిధి:** 100 అడుగులు |
| **ఏరియా:** 5-30 అడుగుల వ్యాసార్థం | **నిరోధకత:** కింద చూడండి |

ఈ మంత్రం కత్తులు, బాకులతో కూడిన ఒక తిరిగే అడ్డంకిని సృష్టిస్తుంది. దీని ఏరియాలో ప్రవేశించే వారికి 1d8 పాయింట్ల నష్టం మరియు 1d4+2 యాదృచ్ఛిక హిట్ లోకేషన్లకు గాయం కలుగుతుంది. సాధారణ ఆర్మర్ సగం రక్షణ మాత్రమే ఇస్తుంది. మాయా ఆర్మర్ పాయింట్లు సాధారణంగా పనిచేస్తాయి. ఆయుధాలు అతి వేగంగా తిరుగుతాయి కాబట్టి వీటిని అడ్డుకోవడం (Parry) లేదా తప్పించుకోవడం (Evade) అసాధ్యం. షీల్డ్ ఉపయోగించి శరీర భాగాలను కాపాడుకోవచ్చు, అయితే షీల్డ్ యొక్క ఆర్మర్ మరియు హిట్ పాయింట్లను లెక్కలోకి తీసుకోవాలి.

దీనిని క్లెరిక్ లేదా మిత్రులను కాపాడుకోవడానికి లేదా శత్రువులను బంధించడానికి ఉపయోగించవచ్చు. ఏరియా అంచున ఉన్న శత్రువులు తప్పించుకోవడానికి ప్రయత్నించవచ్చు, సఫలీకృతం కాకపోయినా వారు బయట పడి పడిపోతారు. విజయవంతమైతే నష్టం ఉండదు, లేకపోతే పూర్తి నష్టం జరుగుతుంది.

ఈ మంత్రం మంత్రగాడిని మరొక మానవ రూపంలోకి మారుస్తుంది. ఎత్తు, బరువు ±5 SIZ వరకు మారవచ్చు. జుట్టు, బట్టలు, మరియు ముఖ కవళికలు కూడా మారవచ్చు. మంత్రగాడు ఎవరైనా నిర్దిష్ట వ్యక్తిని పోలి ఉండవచ్చు. ఇతర ఇల్యూషన్ మంత్రాల మాదిరిగానే ఇది కూడా 'అవిశ్వాసం' (Disbelief) కు లోబడి ఉంటుంది. వాసన మరియు స్పర్శ మారవు.
