# 부록: 변환 표

---
#### 야드파운드법과 미터법 변환

_Classic Fantasy Imperative_의 구성을 더 깔끔하고 읽기 쉽게 하며, 설명과 표를 간결하게 만들기 위해 _Classic Fantasy Imperative_ 라인은 야드파운드법과 미터법을 병기하는 대신 야드파운드법에 집중하기로 했습니다. 이 장르의 다른 게임에서 사용하는 대부분의 모험, 배틀매트, 지도는 야드파운드법을 사용하므로, 기존 자료를 더 쉽게 변환할 수 있도록 야드파운드법을 선택했습니다. 하지만 미터법 사용을 원하는 분들을 위해 가장 일반적으로 사용되는 무게와 치수를 다음 표를 통해 변환했습니다. 우리는 보통 현실 세계의 생물이나 주문 등을 다루는 것이 아니므로, 그에 맞춰 만들어진 무게와 치수에 어느 정도 여유를 둘 수 있습니다. 정확한 변환 수치를 사용하는 대신 기억하기 쉬운 수치를 사용하는 것이 게임 플레이를 더 원활하게 해줍니다.

#### 바람 표

| MPH(마일/시) | 유형 | 기술에 미치는 영향 | 이동에 미치는 영향 |
| :-: | :-- | :-- | :-- |
| 0-10 | 고요함 | 없음 | 없음 |
| 11-20 | 완만한 바람 | 없음 | 없음 |
| 21-30 | 강한 바람 | 없음 | 3분의 2 |
| 31-40 | 약한 폭풍 | 어려움(Hard) | 3분의 2 |
| 41-50 | 중간 폭풍 | 어려움(Hard) | 절반 |
| 51-60 | 강한 폭풍 | 매우 어려움(Formidable) | 절반 |
| 60+ | 폭풍/허리케인 | 매우 어려움(Formidable) | 3분의 1 |

바람, 특히 매우 강한 바람은 활동에 악영향을 미칠 수 있습니다. 바람의 세기(STR)는 시속 마일(mph)로 표시됩니다. STR 또는 DEX와 관련된 물리적 기술에 미치는 영향은 '기술' 열에 상세히 나와 있으며, 이동 속도에 미치는 영향은 '이동 속도' 열에 나와 있습니다.
 
_예를 들어, STR 40의 약한 폭풍은 인간의 걷기 속도를 3분의 2로 줄이고 기술 판정을 '어려움' 난이도로 수행하게 합니다._

#### 온도 표

| 온도 (ºF) | 유형 | 위험 |
| :-: | :-: | :-- |
| < 2º | 빙하기 | 즉시 따뜻한 곳을 찾으시오 |
| 3-14º | 결빙 | 15분 |
| 13-32º | 추움 | 매시간 |
| 33-50º | 쌀쌀함 | 매일 |
| 51-68º | 서늘함 | - |
| 69-86º | 따뜻함 | - |
| > 86º | 더움 | 매시간 |

기온은 캠페인 세계관과 시나리오 배경에 따라 기후, 계절, 고도에 따라 크게 달라질 수 있습니다. 위의 표는 극한 온도가 캐릭터에게 미치는 영향에 대한 지침을 제공합니다.

적절한 복장을 착용하면 캐릭터는 '위험' 열에 표시된 대로 노출이 시작되기 전 자신의 CON(건강) 수치(시간 단위)만큼 유예 기간을 가질 수 있습니다. 이 시간이 지나면 은신처를 찾거나 피로(Fatigue) 피해를 입기 시작해야 합니다. 젖은 캐릭터는 위험 속도가 한 단계 더 추운 환경으로 조정됩니다. 약한 폭풍이나 중간 폭풍 역시 위험 속도를 한 단계 더 추운 환경으로 조정하며, 강한 폭풍과 허리케인은 두 단계 더 조정합니다.
