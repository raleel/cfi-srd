# 부록: 변환 표

---
#### 야드파운드법과 미터법 변환

_Classic Fantasy Imperative_의 구성을 더 깔끔하고 읽기 쉽게 만들고, 설명과 표를 간략화하기 위해, _Classic Fantasy Imperative_ 라인은 야드파운드법과 미터법을 병기하는 대신 야드파운드법에 집중하기로 했습니다. 이 장르의 다른 게임에서 사용하는 대부분의 모험, 전투 매트, 지도가 야드파운드법을 활용하고 있기에, 기존 자료를 더 쉽게 변환할 수 있도록 야드파운드법을 선택했습니다. 하지만 미터법을 사용하고자 하는 분들을 위해, 가장 자주 사용되는 도량형을 아래 표를 통해 변환해 두었습니다. 우리는 일반적으로 현실 세계의 생물이나 주문 등을 다루는 것이 아니기에, 우리가 창조한 도량형에 어느 정도 융통성을 발휘할 수 있습니다. 정확한 변환 수치를 사용하는 대신 기억하기 쉬운 수치를 사용하는 것이 게임 플레이를 더 원활하게 촉진할 것입니다.

#### 바람 표

| MPH | 종류 | 기술에 미치는 영향 | 이동에 미치는 영향 |
| :-: | :-- | :-- | :-- |
| 0-10 | 고요함 | 없음 | 없음 |
| 11-20 | 완만한 바람 | 없음 | 없음 |
| 21-30 | 강한 바람 | 없음 | 3분의 2 |
| 31-40 | 약한 강풍 | 어려움 | 3분의 2 |
| 41-50 | 보통 강풍 | 어려움 | 절반 |
| 51-60 | 강한 강풍 | 매우 어려움 | 절반 |
| 60+ | 폭풍/허리케인 | 매우 어려움 | 3분의 1 |

바람, 특히 매우 강한 바람은 활동에 악영향을 줄 수 있습니다. 바람의 힘(힘)은 시속 마일(MPH)로 나타냅니다. 힘(힘)이나 민첩(민첩)과 관련된 물리적 기술에 미치는 영향은 기술 열에 상세히 나와 있으며, 이동 속도에 미치는 영향은 이동 속도 열에 나와 있습니다.

_예를 들어, 힘(힘) 40의 약한 강풍은 인간의 보행 속도를 3분의 2로 줄이고, 기술 판정은 어려움 난이도로 수행합니다._

#### 온도 표

| 온도 (ºF) | 종류 | 위험 |
| :-: | :-: | :-- |
| < 2º | 빙결 | 즉시 온기를 찾으시오 |
| 3-14º | 동결 | 15분 |
| 13-32º | 추위 | 매시간 |
| 33-50º | 쌀쌀함 | 매일 |
| 51-68º | 서늘함 | - |
| 69-86º | 따뜻함 | - |
| > 86º | 더움 | 매시간 |

온도는 캠페인 세계관과 시나리오가 설정된 장소에 따라 기후, 계절, 고도에 의해 극적으로 변할 수 있습니다. 위 표는 캐릭터가 극한 온도에 노출되었을 때의 영향에 대한 지침을 제공합니다.

적절한 의복을 착용하면 캐릭터는 위험 열에 표시된 대로 노출이 시작되기 전 자신의 체질(체질) 수치만큼의 시간(시간 단위) 동안 유예 기간을 갖습니다. 그 시간이 지나면 피난처를 찾아야 하며, 그렇지 않으면 피로도 감소를 겪기 시작합니다. 젖은 상태의 캐릭터는 위험 등급이 한 단계 더 추운 쪽으로 이동합니다. 약하거나 보통의 강풍 또한 위험 등급을 한 단계 더 추운 쪽으로 이동시키며, 강한 강풍과 폭풍은 두 단계 이동시킵니다.
