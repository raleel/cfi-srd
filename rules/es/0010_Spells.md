## Descripciones de los hechizos

---
#### Appraise (Tasación)

(Adivinación)

| | |
| :-- | :-- |
| **Rango:** Mago 0 | **Tiempo de lanzamiento:** 1 turno |
| **Esfera:** Ninguna | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** Tacto |
| **Área:** 1 objeto | **Resistencia:** Ninguna |

Appraise permite la evaluación inmediata de la calidad de bienes físicos con una ENC combinada en "Cosas" o un TAMAÑO igual al POD del lanzador. El hechizo determina si objetos de aspecto idéntico son de la misma calidad o similar, o si uno o más son defectuosos o de mayor calidad. El hechizo no funciona con cosas orgánicas, solo con objetos inanimados. Tampoco determina qué defectos o mejoras están presentes, meramente que existen. No tiene uso en la identificación o detección de magia.

---
#### Armor (Armadura)

(Conjuración)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 asalto |
| **Esfera:** Ninguna | **Duración:** Ver a continuación |
| **Coste:** 3 +1/Intensidad | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** Ninguna |

Cuando se lanza este hechizo, el sujeto recibe un campo invisible de fuerza mágica equivalente a una armadura de escamas en protección, otorgando 4 Puntos de Armadura a cada ubicación de golpe. No tiene efecto si se lanza sobre alguien que ya lleve armadura. Sin embargo, superará a la armadura natural durante su duración, suponiendo que ofrezca una protección superior. Si se lanza sobre una criatura que posea más de 4 puntos de armadura natural, en su lugar aumentará los Puntos de Armadura en 1 en todas las ubicaciones. Esta protección mágica no obstaculiza el movimiento ni el lanzamiento de hechizos. El hechizo persistirá hasta que sea disipado por magia, o el lanzador reciba 8 puntos de daño de un solo ataque, +1 por cada nivel de Intensidad adicional (ver la tabla a continuación). Por supuesto, el lanzador puede elegir dejar caer el hechizo en cualquier momento si lo desea y debe hacerlo para dormir.

| Intensidad | Coste | Efecto variable |
| :-: | :-: | :-- |
| 1 | 3 | 4 Puntos de Armadura; sostenido hasta recibir 8 puntos de daño de 1 ataque |
| 2 | 4 | 4 Puntos de Armadura; sostenido hasta recibir 9 puntos de daño de 1 ataque |
| 3 | 5 | 4 Puntos de Armadura; sostenido hasta recibir 10 puntos de daño de 1 ataque |
| 4 | 6 | 4 Puntos de Armadura; sostenido hasta recibir 11 puntos de daño de 1 ataque |
| +1 | +1 | Continuar progresión |

#### Astral Spell (Hechizo astral)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 5, Mago 5 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Astral | **Duración:** Ver a continuación |
| **Coste:** 3 +1/Intensidad adicional | **Alcance:** Tacto |
| **Área:** Ver a continuación | **Resistencia:** N/A |

Este hechizo permite al lanzador y hasta cinco personas más (una por cada nivel adicional de Intensidad) entrar en el Plano Astral. Todos deben estar tocándose y formando un círculo mientras se lanza el hechizo. Los cuerpos de los viajeros se quedan atrás en el plano de origen, y normalmente no llevan consigo ropa ni equipo, excepto aquel que irradia un aura mágica; estos objetos se transforman en equivalentes astrales de su forma normal. La duración dura hasta que el lanzador desee que termine. Sin embargo, es posible que sea terminado prematuramente por una fuerza externa como *Dispel Magic*. Matar el cuerpo físico del lanzador también termina el hechizo prematuramente, aunque esto tiene el desafortunado efecto secundario de dejar varados a cualquier viajero que acompañe al lanzador.

#### Augury (Augurio)

(Adivinación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 2 | **Tiempo de lanzamiento:** 2 minutos |
| **Esfera:** Adivinación | **Duración:** Instantánea |
| **Coste:** 3/Intensidad | **Alcance:** 60 pies (18 metros) |
| **Área:** Lanzador | **Resistencia:** N/A |

Este hechizo permite al lanzador determinar si una acción específica que se llevará a cabo en los próximos 30 minutos será beneficiosa o perjudicial para el bienestar de un individuo y/o grupo. Se requiere un punto focal de algún tipo para discernir los presagios, siendo los más comunes las garras o huesos pequeños de un dragón, una perla o oro puro valorado en no menos de 100 piezas de oro, que ha sido triturado o fundido. El hechizo tiene una Intensidad máxima de 4. Esta tirada debería ser realizada por el Director de Juego, ya que el lanzador nunca debería saber sin lugar a dudas si los resultados se interpretaron correctamente.

| Intensidad | Coste | Efecto variable |
| :-: | :-: | :-- |
| 1 | 3 | Tirada de habilidad de Canalización formidable |
| 2 | 6 | Tirada de habilidad de Canalización difícil |
| 3 | 9 | Tirada de habilidad de Canalización estándar |
| 4 | 12 | Tirada de habilidad de Canalización fácil |

Si la tirada de adivinación tiene éxito, otorga uno de los siguientes resultados:

| Augurio | Implicación | 
| :-: | :-- |
| Sí | La acción será beneficiosa |
| No | La acción será perjudicial |
| Sí y no | La acción será tanto beneficiosa como perjudicial |
| Nada | La acción no será ni beneficiosa ni perjudicial |

Una pifia debería resultar en que el Director de Juego diga lo opuesto a la realidad.

#### Avert (Desviar)

(Abjuración)

| | |
| :-- | :-- |
| **Rango:** Clérigo 0, Mago 0 | **Tiempo de lanzamiento:** Instantáneo |
| **Esfera:** Protección | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** 60 pies (18 metros) |
| **Área:** 1 hechizo | **Resistencia:** Ninguna |

*Avert* se utiliza para descartar otro hechizo de Rango 0 dentro del alcance. *Avert* puede lanzarse de forma reactiva para neutralizar hechizos ofensivos de Rango 0 utilizando la acción reactiva de Contramagia.

#### Befuddle (Confundir)

(Encantamiento (Encanto))

| | |
| :-- | :-- |
| **Rango:** Clérigo 0, Mago 0 | **Tiempo de lanzamiento:** 1 turno |
| **Esfera:** Encanto | **Duración:** 30 minutos |
| **Coste:** 1 | **Alcance:** 60 pies (18 metros) |
| **Área:** 1 objetivo | **Resistencia:** Fuerza de Voluntad |

*Befuddle* causa confusión en la mente de un objetivo corpóreo. El sujeto del hechizo tiene dificultad para pensar con claridad, olvidando dónde está, qué está haciendo y por qué, a menudo cayendo en líneas de pensamiento disociadas. Los objetivos confundidos aún pueden actuar en defensa propia, pero no pueden iniciar ninguna actividad constructiva hasta que termine el hechizo. Cualquier tipo de ataque o acción amenazante rompe instantáneamente el hechizo, independientemente de si estaba dirigido específicamente al objetivo confundido.

#### Blade Barrier (Barrera de cuchillas)

(Evocación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 4 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Guardián, Creación | **Duración:** 3 asaltos/Intensidad |
| **Coste:** 3 +1/Intensidad adicional | **Alcance:** 100 pies (30 metros) |
| **Área:** 5-30 pies de radio | **Resistencia:** Ver a continuación |

Este hechizo crea una barrera de espadas, dagas y cuchillos giratorios que azotan y cortan alrededor de un punto fijo y causan 1d8 puntos de daño a 1d4+2 ubicaciones de golpe aleatorias de _cualquiera_ que pase por el área de efecto. La armadura solo ofrece la mitad de su protección normal. Los Puntos de Armadura Mágica reducen el daño normalmente. Debido a que las armas giran a una velocidad cegadora y están muy compactas, es imposible pararlas o esquivarlas. Uno puede usar un escudo para bloquear pasivamente las ubicaciones de golpe normalmente. En este caso, recuerda comparar el daño obtenido con la armadura y los Puntos de Golpe del escudo.

El hechizo puede lanzarse defensivamente para proteger al clérigo o a uno o más aliados, u ofensivamente para atrapar enemigos. Sin embargo, los enemigos rodeados a menos de cinco pies del borde de la barrera mientras se forma pueden hacer una tirada de Esquiva para escapar. Independientemente del éxito, el oponente termina boca abajo, justo fuera del área de efecto. Una tirada exitosa resulta en que no recibe daño; de lo contrario, sufren el efecto completo.

#### Bless (R) (Bendición)

(Conjuración)

| | |
| :-- | :-- |
| **Rango:** Clérigo 1 | **Tiempo de lanzamiento:** 1 asalto |
| **Esfera:** Todas | **Duración:** 5 minutos |
| **Coste:** 1 | **Alcance:** 180 pies (55 metros) |
| **Área:** 25 pies de radio | **Resistencia:** Fuerza de Voluntad |

Cuando se lanza este hechizo, el clérigo bendice a un grupo de aliados dentro del área de efecto. Los afectados irradian la alineación del lanzador, ya sea Bien o Mal. No hay bendiciones de Neutralidad. Todos los aliados dentro del radio del hechizo reciben un bono del +5% a todas las tiradas de habilidad y resistencia. Además, sus armas causan +1d3 de daño a los muertos vivientes inteligentes así como a criaturas de los planos exteriores que tengan alineaciones opuestas a la del lanzador, como demonios, diablos o ángeles. Ten en cuenta que, aunque los muertos vivientes animados como esqueletos y zombis no son inherentemente malvados, suelen ser animados por magia malvada y, por lo tanto, están sujetos a este daño.

El reverso de este hechizo, *Maldición*, permite al clérigo maldecir a los enemigos, haciendo que las habilidades señaladas sufran la inversa de los beneficios señalados anteriormente. El daño de un arma maldita se calcula como una penalización en su lugar, y este daño no puede resultar en menos de 1 punto.

#### Burning Hands (Manos ardientes)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Ninguna | **Duración:** Instantánea |
| **Coste:** 3 +1/Intensidad adicional | **Alcance:** 0 |
| **Área:** Cono de 120 grados, 5 pies de largo | **Resistencia:** Esquiva |

Este hechizo hace que las llamas salgan disparadas de las manos del lanzador en un arco de 120 grados. Si se usan miniaturas en combate, *Burning Hands* dañará a cada objetivo que ocupe 1 de los cuadrados frontales del lanzador. Lanzar *Burning Hands* a niveles de Intensidad más altos requiere un mago de mayor rango. Este daño envuelve a todos los objetivos dentro del área con un daño basado en la Intensidad del hechizo, hasta una Intensidad máxima de 9, de la siguiente manera. Una tirada de Esquiva exitosa, lanzándose al suelo, permite que la víctima no sufra daño. Alguien con la habilidad "Artful Dodger" (Habilidoso) tiene la opción de esquivar sin caer al suelo.

| Intensidad | Coste | Rango mín. | Efecto variable |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 puntos de daño a todas las ubicaciones de golpe |
| 3 | 4 | 1 | 1d3+2 puntos de daño a todas las ubicaciones de golpe |
| 5 | 5 | 1 | 1d3+3 puntos de daño a todas las ubicaciones de golpe |
| 7 | 6 | 2 | 1d3+4 puntos de daño a todas las ubicaciones de golpe |
| 9 | 7 | 3 | 1d3+5 puntos de daño a todas las ubicaciones de golpe |

La armadura usada no protege, pero los Puntos de Armadura Mágica o la armadura natural de una criatura reducen el daño normalmente. Este poderoso hechizo se equilibra con su alcance notablemente corto, lo que significa que, para lanzarlo, el usuario de magia debe estar lo suficientemente cerca como para estar en una posición muy desventajosa.

Debido a que las criaturas más grandes suelen ser más grandes que el área de efecto del hechizo, tenderán a tener menos ubicaciones de golpe afectadas. Aquellos con un TAMAÑO de 21 a 30 reciben el daño en su cabeza, pecho, abdomen y brazos, mientras que los de TAMAÑO 31+ recibirán el daño en su abdomen y piernas. Los Directores de Juego deberían ajustar estas ubicaciones dependiendo de la forma y posición del objetivo en relación con el lanzador. *Burning Hands* tiene una posibilidad de incendiar materiales inflamables igual al daño obtenido x5%. Consulta la sección sobre [Fuegos](0007_Game_System.md?id=fire-based-attacks) para obtener información adicional.

#### Calm (Calma)

(Encantamiento (Encanto))

| | |
| :-- | :-- |
| **Rango:** Clérigo 0 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Encanto | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** Fuerza de Voluntad |

*Calm* intenta amortiguar las pasiones de un objetivo humanoide de TAMAÑO 1-20, quizás asegurando que un pretendiente enamorado no presione sus intenciones, un rival asustado no grite pidiendo ayuda, o que no se desenvainen armas con ira. #### Command (Comando)

(Encantamiento (Encanto))

| | |
| :-- | :-- |
| **Rango:** Clérigo 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Encanto | **Duración:** 1 minuto |
| **Coste:** 3 | **Alcance:** 100 pies (30 metros) |
| **Área:** 1 objetivo | **Resistencia:** Fuerza de Voluntad |

Cuando se lanza este hechizo, el clérigo puede pronunciar un comando de una sola palabra a una criatura viva de TAMAÑO 1-20, y en el próximo turno del sujeto, el comando será seguido al pie de la letra si fallan la resistencia. Esto esencialmente hace que la víctima pierda el siguiente turno completando la acción ordenada y gaste un Punto de Acción mientras la realiza. Si la víctima no posee más Puntos de Acción, la acción ordenada se realizará durante su primer turno del siguiente asalto. El comando en sí no puede causar ninguna lesión real al objetivo; sin embargo, la lesión puede ser un efecto secundario del comando.

Por ejemplo, un comando de morir daría como resultado que la víctima colapsara en un estado comatoso similar a la muerte durante 1 asalto sin causar ninguna lesión real; sin embargo, un comando de caer dado a una criatura que escala un acantilado de 100 pies de altura podría ser más que mortal.

El sujeto del comando debe ser capaz de entender el idioma hablado por el lanzador y se le permite una prueba de Fuerza de Voluntad para resistir.

**Algunos ejemplos de comandos:**

- **Crawl (Arrastrarse):** El sujeto se pone boca abajo y comienza a gatear.
- **Die (Morir):** El sujeto cae boca abajo entrando en un estado comatoso similar a la muerte.
- **Fall (Caer):** El sujeto cae boca abajo.
- **Fumble (Pifiar):** El sujeto pifia una acción física que está a punto de realizar.
- **Sleep (Dormir):** El sujeto se duerme.
- **Flee (Huir):** El sujeto se da la vuelta y huye del lanzador.
- **Fly (Volar):** El sujeto agita los brazos y corre en círculos.
- **Go (Ir):** El sujeto comienza a caminar en la dirección a la que se enfrentaba.
- **Halt (Detenerse):** El sujeto se detiene inmediatamente y se queda en su lugar.
- **Leave (Salir):** El sujeto se da la vuelta y sale por donde entró.
- **Rest (Descansar):** El sujeto cae en una posición sentada y recupera el aliento.
- **Run (Correr):** El sujeto comienza a correr.
- **Scream (Gritar):** El sujeto grita.
- **Sink (Hundirse):** El sujeto deja de nadar.
- **Surrender (Rendirse):** El sujeto deja caer sus armas y cesa las hostilidades.

#### Enchant Item (Encantar objeto)

(Encantamiento)

| | |
| :-- | :-- |
| **Rango:** Mago 4 | **Tiempo de lanzamiento:** Ver a continuación |
| **Esfera:** Ninguna | **Duración:** Ver a continuación |
| **Coste:** 3 + Ver a continuación | **Alcance:** Tacto |
| **Área:** 1 objeto | **Resistencia:** N/A |

El lanzamiento de este hechizo prepara un objeto para su encantamiento. El objeto debe estar en buenas condiciones y ser de la mejor construcción y mano de obra. Se requiere un coste adicional de al menos 100 PO para cubrir el costo de herramientas adicionales, tallado, bordado, joyería, grabado, etc. Finalmente, el proceso de encantamiento requiere un laboratorio o taller.

Mientras se lanza el hechizo, el usuario de magia debe estar tocando el objeto durante todo el tiempo de lanzamiento de 1d8+2 días. Esto cuenta los períodos de descanso y sueño, durante los cuales el objeto debe permanecer a una distancia de un brazo del lanzador. En ningún momento durante el lanzamiento el usuario de magia puede lanzar otro hechizo o realizar ninguna otra forma de magia. Romper cualquiera de estos requisitos hará que el hechizo falle automáticamente.

Una vez lanzado con éxito, el objeto está listo para el paso final, con el lanzador colocando el hechizo deseado en él. Para ello, deben tener el hechizo en la memoria o en un pergamino y lanzarlo sobre el objeto dentro de las 24 horas, o todo el proceso deberá iniciarse desde cero. Una vez que comienza el lanzamiento del hechizo seleccionado, el proceso puede exceder las 24 horas mencionadas. Imbuir el objeto con el hechizo seleccionado cuesta el número normal de Puntos de Magia para la Intensidad deseada y toma 1d12 horas por Rango de hechizo. Durante todo el proceso de imbuición, el lanzador debe permanecer tocando el objeto o permanecer al alcance del brazo durante los períodos de descanso, como se indicó anteriormente, y se requiere una tirada de Lanzamiento Arcano al final del período de lanzamiento para imbuir el hechizo con éxito. Se siguen los grados de éxito normales para el lanzamiento de hechizos; sin embargo, con respecto a un resultado de fallo, el hechizo no se puede forzar. Se pueden imbuir hechizos sucesivos dentro del objeto, siempre que el proceso de lanzamiento se inicie dentro de las 24 horas posteriores a la finalización del hechizo anterior. Esto se aplica incluso en el caso de un hechizo previamente fallido. Cada hechizo sucesivo requiere el costo de lanzamiento normal.

Al usar el objeto, cada hechizo contenido puede lanzarse solo una vez; sin embargo, se pueden imbuir múltiples versiones del mismo hechizo siguiendo el procedimiento anterior. También es posible imbuir un hechizo único, seguido de un lanzamiento del hechizo de Rango 4 *Permanency* (Permanencia). En este caso, el hechizo puede lanzarse tantas veces como se desee, siguiendo las restricciones establecidas en la descripción del hechizo *Permanency*.

No es posible imbuir otros efectos mágicos en un objeto que no se ajusten a un hechizo específico, y muchos objetos mágicos de tiempos lejanos simplemente no pueden recrearse en la actualidad.

#### Fire Shield (Escudo de fuego)

(Evocación)

| | |
| :-- | :-- |
| **Rango:** Mago 3 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Ninguna | **Duración:** 2 minutos/Intensidad |
| **Coste:** 3 +1/Intensidad adicional | **Alcance:** 0 |
| **Área:** Lanzador | **Resistencia:** N/A |

Este hechizo crea un escudo de llamas tenues que inmola al lanzador pero no causa daño por sí mismo. En cambio, las llamas protegen al receptor del fuego o el frío, dependiendo de cuál de las dos variantes esté en la memoria: *Chill Shield* (Escudo gélido), que crea llamas azules o verdes y protege contra el calor y el daño basado en fuego, o *Warm Shield* (Escudo cálido), que crea llamas violetas o azules y protege contra el daño basado en frío y hielo. El color de las llamas debe determinarse al azar con un 50% de probabilidad de cualquiera, ya que el hecho de que ambos tipos puedan emitir llamas azules crea un elemento de incertidumbre por parte de cualquier atacante. La decisión sobre cuál memorizar se toma cuando se preparan los hechizos, y se pueden memorizar ambos si se desea. Estas llamas no emiten calor y emiten luz a solo la mitad del brillo de una antorcha. Los detalles de cada variante se detallan a continuación.

- **Chill Shield:** Estas llamas son frías al tacto y reducen cualquier daño basado en fuego o calor a la mitad del total. Una tirada de Resistencia exitosa negará todo el daño. La tirada de Resistencia es un grado más fácil y, en el caso de Esquiva, no hará que el defensor caiga boca abajo.
- **Warm Shield:** Estas llamas son cálidas al tacto y reducen cualquier daño basado en frío a la mitad del total. Una tirada de Resistencia exitosa negará todo el daño. La tirada de Resistencia es un grado más fácil y, en el caso de Esquiva, no hará que el defensor caiga boca abajo.

Los ataques cuerpo a cuerpo contra el receptor de cualquiera de las variantes, ya sean armados o desarmados, infligen daño normal a menos que usen uno de los elementos protegidos. En este caso, el lanzador está protegido de la porción elemental del ataque, y el atacante recibe un daño igual al infligido. La armadura usada por el atacante no ofrece protección, pero los Puntos de Armadura Mágica o la armadura natural de una criatura reducen el daño normalmente. Las criaturas con Resistencia Mágica Innata pueden disipar *Fire Shield* con una tirada exitosa de Fuerza de Voluntad cuando el receptor es golpeado por primera vez. Si la tirada de Resistencia Mágica falla, el oponente no puede negar *Fire Shield* más tarde.

Por cada nivel de Intensidad, el hechizo cura al sujeto de una enfermedad de cualquier POT, cura cualquier ceguera o sordera, niega un trastorno mental provocado por lesiones o magia, o cura una única ubicación de golpe de hasta 12 puntos de daño. Sin embargo, no restaurará una extremidad cortada, ya que eso requiere un lanzamiento del hechizo *Regenerate*. Cada Intensidad adicional se puede usar para curar otra dolencia o curar otra ubicación de golpe. Por lo tanto, se requeriría un lanzamiento a Intensidad 7 para curar a un individuo que sufra quemaduras en todo el cuerpo. A diferencia de los hechizos de curación menores que limitan su eficacia contra lesiones a largo plazo, el hechizo no tiene límites impuestos por la duración en la que el sujeto ha sufrido los efectos de la lesión.

Cuando se revierte, *Harm* (Daño) inflige 12 puntos de lesión mágica a una de las ubicaciones de golpe de la víctima en una tirada fallida para resistir. Alternativamente, se le inflige una dolencia, cuyos efectos son los mismos que el hechizo *Cause Disease*, el reverso de *Cure Disease*, pero a POT+20. La tirada de Canalización del lanzador funciona como la tirada para golpear a su oponente y se asume como parte del requisito somático del hechizo. No es necesaria ninguna tirada adicional para golpear. Ni la armadura usada ni la natural ofrecen protección, pero los Puntos de Armadura Mágica reducen el daño normalmente y bloquean completamente las dolencias infligidas. Cada intensidad adicional afecta a otra ubicación de golpe contigua a la primera, con efectos determinados por la tirada de Resistencia inicial. Ninguna versión de este hechizo tiene efecto sobre los muertos vivientes, criaturas dañadas solo por hierro, plata o armas mágicas, o seres no corpóreos.

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 acción |

Cada *Magic Missile* golpeará una ubicación de golpe aleatoria; no se pueden seleccionar ubicaciones de golpe específicas. El lanzador debe designar objetivos individuales de cada misil antes de lanzar el daño.

(Transmutación)

| | |
| :-- | :-- |

La duración de este hechizo es permanente hasta que el encantamiento se activa y luego el hechizo termina.

#### Polymorph Other (Polimorfismo otro)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 3 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Ninguna | **Duración:** Permanente |
| **Coste:** 3 +1/Intensidad adicional (+1 EXP) | **Alcance:** 15 pies/Intensidad |
| **Área:** 1 objetivo | **Resistencia:** Fuerza de Voluntad |

El lanzador puede alterar la forma de una criatura corpórea objetivo a la de otra, con cada punto de Intensidad alterando el TAMAÑO en hasta 5 puntos. Por lo tanto, transformar un orco de TAMAÑO 16 en un conejo de TAMAÑO 1 requeriría 3 niveles de Intensidad (15 puntos de TAMAÑO de diferencia). El sujeto de este hechizo tiene derecho a una tirada de Resistencia de Fuerza de Voluntad. Las criaturas grandes (TAMAÑO 21-40) son menos susceptibles a ser polimorfizadas, siendo su tirada de Resistencia Fácil, mientras que la tirada de Resistencia para criaturas enormes (TAMAÑO 41+) es Muy Fácil.

Todo el proceso de transformación toma un asalto completo y puede ser bastante estresante para la criatura en cuestión, requiriendo una segunda tirada de Fuerza de Voluntad para retener su personalidad original, con un fallo aturdiendo al sujeto durante 1d10 minutos, y una pifia resultando en la muerte por shock mental. Cada duplicación o reducción a la mitad del TAMAÑO original de la criatura hace que la tirada de Fuerza de Voluntad para retener la personalidad sea un grado más difícil, al igual que un cambio completo de entorno, como transformar a una persona en un pez. Una tirada exitosa permite a la víctima retener su INT y CHA, así como cualquier habilidad que requiera esas características.

La transformación otorga al receptor la forma de respiración de la criatura asumida, si es distinta a la normal; cualquier ataque natural; y todos los modos mundanos de movimiento. No otorga ninguna capacidad aumentada o mágica poseída por la criatura. Por ejemplo, una criatura que ha sido polimorfizada en un dragón no obtendrá el ataque de aliento o habilidades tipo hechizo de la criatura, pero obtendrá la capacidad de volar, su dura piel, su mordida mortal, sus ataques de garra, etc. Además, la víctima obtiene las habilidades físicas de la nueva forma como Atletismo, Brawn (Fuerza física), Vuelo, Nadar, así como sus Puntos de Golpe y Modificador de Daño. Suponiendo que el individuo transformado retuvo su INT, aún pierde la capacidad de hablar, a menos que la nueva forma posea la capacidad de articular palabras. Aquellos que eran capaces de lanzar hechizos en su forma anterior aún podrían lanzar en la nueva forma, asumiendo que todavía poseen la capacidad de producir los componentes verbales y somáticos. En el caso de un cambio drástico, como pasar de bípedo a cuadrúpedo, o de un animal terrestre a una criatura marina, por ejemplo, el Director de Juego debería sentirse libre de penalizar en al menos un grado de dificultad, el uso de cualquier habilidad que tomaría tiempo aprender mientras se ajusta a la nueva forma hasta que haya habido suficiente tiempo para practicar. Esto es especialmente cierto en habilidades físicas como Atletismo, Sin armas, Nadar, Vuelo, Habilidades de combate, etc.

La tirada de Fuerza de Voluntad para retener la personalidad es necesaria cada día que el sujeto permanece transformado hasta que falle, causando que la persona finalmente sucumba a la mentalidad de la nueva forma, con la INT cambiando a INS en el caso de una criatura no sapiente. Todas las habilidades especiales y mágicas propiedad de la nueva forma que no se adquirieron anteriormente, como ataques de mirada, armas de aliento, etc., ahora están disponibles para la criatura a medida que se completa la transformación. Los personajes que pierden su identidad de esta manera se convierten en personajes no jugadores bajo el control del Director de Juego.

Antes de sucumbir mentalmente a la transformación, la criatura polimorfizada es susceptible a *Dispel Magic* normalmente, sin necesidad de tirada para resistir, ya que sería el deseo subconsciente de uno de volver a la normalidad. La transformación requiere otra tirada de Fuerza de Voluntad para resistir la tensión, con un fallo aturdiendo al sujeto durante 1d10 minutos, y una pifia resultando en la muerte por shock mental.

Si la víctima había sucumbido previamente a la nueva forma, *Dispel Magic* aún puede utilizarse; sin embargo, la víctima intentará resistirse a volver a la forma natural con una tirada de Fuerza de Voluntad. Fallar esta tirada significa que la víctima se transforma de nuevo a la forma natural, lo que, por supuesto, requiere otra tirada de Fuerza de Voluntad para resistir el shock mental de la transformación. Una vez perdida, la identidad natural de la víctima ya no es alcanzable, en su lugar la víctima asume que la forma extraña y alienígena no es natural y anhela volver a su anterior "normal". _Por ejemplo, un orco que fue polimorfizado en un conejo y asumió la identidad de la criatura creería que ahora es un conejo que ha sido bastante groseramente transformado en un orco._ Solo un *Wish* (Deseo), u otra magia similar, tiene alguna posibilidad de restaurar la identidad de la víctima una vez que se ha perdido.

Todo el equipo usado y transportado se funde mágicamente en la nueva forma; sin embargo, en algunos casos, el Director de Juego puede permitir que permanezcan los objetos mágicos que todavía podrían usarse en la nueva forma de la criatura, como un anillo mágico o botas. Ten en cuenta que esto requiere que el nuevo TAMAÑO de la criatura no sea vastamente diferente al original. Hay un POD x1% de probabilidad por cada objeto mágico usado de naturaleza no ofensiva, sujeto a la aprobación del Director de Juego, de transferir sus efectos a la nueva forma de la criatura. Una criatura con un anillo de protección +1 por ejemplo, podría obtener un bono de +1 a sus Puntos de Armadura naturales. Las criaturas con la capacidad natural de cambiar de forma, como doppelgängers y licántropos, se transformarán normalmente, pero pueden asumir su forma normal después de 1 asalto. Si se mata, una criatura polimorfizada vuelve a su forma natural, incluso si previamente ha perdido todos los rastros de identidad.

#### Raise Dead (R) (Resucitar)

(Nigromancia)

| | |
| :-- | :-- |
| **Rango:** Clérigo 3 | **Tiempo de lanzamiento:** 1 minuto |
| **Esfera:** Nigromántica | **Duración:** Permanente |

Este hechizo puede lanzarse sobre el cadáver de una criatura muerta hace menos de 24 horas por nivel de Intensidad. Si la alineación del sujeto era cualquier otra cosa que no fuera maligna, puede resistir el hechizo con una tirada opuesta de Fuerza de Voluntad y, si tiene éxito, negar los efectos del hechizo. Esto es porque el alma o espíritu del difunto rara vez está dispuesto a regresar a los vivos una vez que ha alcanzado su recompensa eterna. El Director de Juego puede decidir renunciar a la tirada si el receptor tiene asuntos pendientes, no puede separarse de su verdadero amor, o tiene alguna otra razón heroica para vivir.

En el caso de las almas malvadas, que regresarían alegremente al plano material en lugar de sufrir la condenación eterna, no es la Fuerza de Voluntad del difunto la que está resistiendo, sino la del demonio, diablo, etc., encargado de su castigo, su atormentador. En este caso, el lanzador debe superar la Fuerza de Voluntad del atormentador. Si se desconoce, asume que es al menos 20 puntos más alta que la del difunto para representar que cuanto más fuerte es la voluntad del alma, más poderoso es el ser encargado de su condenación. Si el lanzador tiene éxito, ha devuelto con éxito el espíritu al cuerpo, mientras que una tirada fallida resulta en que la víctima no quiera o no pueda regresar.

Si el lanzamiento tiene éxito, el sujeto vuelve a la vida con todos sus Puntos de Golpe, aunque las extremidades cortadas permanecen perdidas. Esto significa que una víctima decapitada o cortada por la mitad no puede ser resucitada hasta que su cabeza o torso sea primero reattached. Esto se puede hacer antes del lanzamiento de *Raise Dead* uniendo físicamente la ubicación cortada, lo que requiere un kit de sanador y una aplicación exitosa de la habilidad Curación, y normalmente deja una cicatriz obvia y reveladora. Otras dolencias, como veneno o enfermedad, deben ser atendidas antes o después del lanzamiento de *Raise Dead*, o los resultados son solo temporales. Finalmente, *Raise Dead* no tiene efecto sobre una criatura que ha llegado al final de su vida natural y ha muerto de vejez.

El acto de ser resucitado es muy estresante para el sujeto, que se reduce a un Nivel de Fatiga de Incapacitado durante un período de 24 horas por cada día que estuvo muerto. El lanzamiento de *Cure Fatigue* no tiene efecto sobre el paciente durante este tiempo de convalecencia. Después de este punto, el personaje se recupera de la Fatiga normalmente y sin restricciones.

Esta víctima tiene derecho a una tirada de Fuerza de Voluntad para resistir, modificada por el Rango o TAMAÑO del objetivo, lo que dé al objetivo el resultado más beneficioso, como se detalla en la siguiente tabla.

#### Slow Poison (Ralentizar veneno)

(Nigromancia)

| | |
| :-- | :-- |
| **Rango:** Clérigo 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Curación | **Duración:** 1 hora/Intensidad |
| **Coste:** 3 +1/Intensidad adicional | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** N/A |

Este hechizo permite al lanzador ralentizar los efectos de venenos; no neutraliza la toxina, sin embargo. En cambio, las toxinas que se propagan a través del cuerpo se ralentizan lo suficiente como para que, con suerte, se puedan encontrar medidas curativas adicionales. El tiempo de inicio de una toxina no se activa hasta después de que la duración del hechizo haya expirado.

Por ejemplo, el veneno de cobra posee un tiempo de inicio de la siguiente manera: agonía después de 1d6+4 minutos y asfixia después de 1d6+6 horas. Por lo tanto, una única Intensidad de *Slow Poison* pospone el tiempo de inicio en 1 hora, después de lo cual, 1d6+4 minutos más tarde, la agonía aparece normalmente.

Si *Slow Poison* se lanza sobre una víctima después de que los síntomas hayan aparecido, cesan hasta que la duración del hechizo expire y luego continúan normalmente.

Como último recurso, si el lanzador puede llegar a un individuo que ha "muerto" por envenenamiento dentro de los 10 minutos, *Slow Poison* retrasa la muerte de una víctima durante 1 hora por Intensidad, durante la cual la víctima permanece en coma. Si durante este tiempo, la víctima puede curarse del veneno, aún puede vivir y ser revivida por primeros auxilios o curación mágica.
