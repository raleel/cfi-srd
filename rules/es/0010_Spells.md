## Descripciones de hechizos

---
#### Appraise (Valorar)

(Adivinación)

| | |
| :-- | :-- |
| **Rango:** Mago 0 | **Tiempo de lanzamiento:** 1 turno |
| **Esfera:** Ninguna | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** Tacto |
| **Área:** 1 objeto | **Resistencia:** Ninguna |

Appraise permite la evaluación inmediata de la calidad de bienes físicos CON una ENC combinada en 'Cosas' o un TAM igual al POD del lanzador. El hechizo determina si objetos de aspecto idéntico son de la misma calidad o similar, o si uno o más están defectuosos o son de una calidad superior. El hechizo no funciona en cosas orgánicas, solo en objetos inanimados. Tampoco determina qué defectos o mejoras están presentes, solo que existen. No es útil para la identificación o detección de magia.

---
#### Armor (Armadura)

(Conjuración)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 asalto |
| **Esfera:** Ninguna | **Duración:** Ver abajo |
| **Coste:** 3 + 1/Intensidad | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** Ninguna |

Cuando se lanza este hechizo, el sujeto recibe un campo invisible de fuerza mágica equivalente a una armadura de escamas en protección, otorgando 4 Puntos de Armadura a cada Localización de impacto. No tiene efecto si se lanza sobre alguien que ya lleva armadura. Sin embargo, reemplazará la armadura natural durante su Duración, asumiendo que ofrece una protección superior. Si se lanza sobre una criatura que posee más de 4 puntos de armadura natural, en su lugar aumentará los Puntos de Armadura en 1 en todas las localizaciones. Esta protección mágica no obstaculiza el movimiento ni el lanzamiento de hechizos. El hechizo persistirá hasta que sea disipado por magia, o el lanzador reciba 8 puntos de daño de un solo ataque, +1 por cada nivel de Intensidad adicional (ver la tabla a continuación). Por supuesto, el lanzador puede optar por cancelar el hechizo en cualquier momento si lo desea, y debe hacerlo para dormir.

| Intensidad | Coste | Efecto variable |
| :-: | :-: | :-- |
| 1 | 3 | 4 Puntos de Armadura; sostenido hasta recibir 8 de daño de 1 ataque |
| 2 | 4 | 4 Puntos de Armadura; sostenido hasta recibir 9 de daño de 1 ataque |
| 3 | 5 | 4 Puntos de Armadura; sostenido hasta recibir 10 de daño de 1 ataque |
| 4 | 6 | 4 Puntos de Armadura; sostenido hasta recibir 11 de daño de 1 ataque |
| +1 | +1 | Continuar progresión |

#### Astral Spell (Hechizo astral)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 5, Mago 5 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Astral | **Duración:** Ver abajo |
| **Coste:** 3 + 1/Intensidad adicional | **Alcance:** Tacto |
| **Área:** Ver abajo | **Resistencia:** N/A |

Este hechizo permite al lanzador y hasta a otros cinco (uno por nivel de Intensidad adicional) entrar al Plano Astral. Todos deben estar tocándose y formando un círculo mientras se lanza el hechizo. Los cuerpos de los viajeros se quedan atrás en el plano de origen, y normalmente no llevan consigo ropa o equipo, excepto aquel que irradie un aura mágica; estos objetos se transforman en equivalentes astrales de su forma normal. La Duración dura hasta que el lanzador desee que cese. Sin embargo, es posible terminarla prematuramente mediante una fuerza externa, como Dispel Magic. Matar el cuerpo físico del lanzador también termina el hechizo prematuramente, aunque esto tiene el efecto secundario desafortunado de dejar varados a cualquier viajero que acompañe al lanzador.

#### Augury (Augurio)

(Adivinación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 2 | **Tiempo de lanzamiento:** 2 minutos |
| **Esfera:** Adivinación | **Duración:** Instantánea |
| **Coste:** 3/Intensidad | **Alcance:** 60 pies |
| **Área:** Lanzador | **Resistencia:** N/A |

Este hechizo permite al lanzador determinar si una acción específica que se llevará a cabo en los próximos 30 minutos será beneficiosa o perjudicial para el bienestar de un individuo o de un grupo. Se requiere un punto focal de algún tipo para discernir los augurios, siendo los más comunes las garras o huesos pequeños de un dragón, una perla o oro puro valorado en no menos de 100 PO, que haya sido triturado o fundido. El hechizo tiene una Intensidad máxima de 4. Esta tirada debería ser realizada por el Director de Juego, ya que el lanzador nunca debería saber sin lugar a dudas si los resultados se interpretaron correctamente.

| Intensidad | Coste | Efecto variable |
| :-: | :-: | :-- |
| 1 | 3 | Tirada de habilidad de Canalizar Formidable |
| 2 | 6 | Tirada de habilidad de Canalizar Difícil |
| 3 | 9 | Tirada de habilidad de Canalizar Estándar |
| 4 | 12 | Tirada de habilidad de Canalizar Fácil |

Si la tirada de adivinación tiene éxito, otorga uno de los siguientes resultados:

| Augurio | Implicación | 
| :-: | :-- |
| Sí | La acción será beneficiosa |
| No | La acción será perjudicial |
| Sí y no | La acción será tanto beneficiosa como perjudicial |
| Nada | La acción no será ni beneficiosa ni perjudicial |

Una pifia (Fumble) debería resultar en que el Director de Juego diga lo opuesto a la realidad.

#### Avert (Desviar)

(Abjuración)

| | |
| :-- | :-- |
| **Rango:** Clérigo 0, Mago 0 | **Tiempo de lanzamiento:** Instantáneo |
| **Esfera:** Protección | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** 60 pies |
| **Área:** 1 hechizo | **Resistencia:** Ninguna |

Avert se utiliza para descartar otro hechizo de Rango 0 dentro del Alcance. Avert puede lanzarse de forma reactiva para neutralizar hechizos ofensivos de Rango 0, utilizando la acción reactiva de Contramagia.

#### Befuddle (Confundir)

(Encantamiento (Hechizo))

| | |
| :-- | :-- |
| **Rango:** Clérigo 0, Mago 0 | **Tiempo de lanzamiento:** 1 turno |
| **Esfera:** Hechizo | **Duración:** 30 minutos |
| **Coste:** 1 | **Alcance:** 60 pies |
| **Área:** 1 objetivo | **Resistencia:** Voluntad |

Befuddle causa confusión en la mente de un objetivo corpóreo. El sujeto del hechizo tiene dificultades para pensar CON claridad, olvidando dónde está, qué está haciendo y por qué, a menudo cayendo en líneas de pensamiento disociadas. Los objetivos confundidos aún pueden actuar en defensa propia, pero no pueden iniciar ninguna actividad constructiva hasta que termine el hechizo. Cualquier tipo de ataque o acción amenazante rompe instantáneamente el hechizo, independientemente de si estaba dirigido específicamente al objetivo confundido.

#### Blade Barrier (Barrera de cuchillas)

(Evocación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 4 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Guardián, Creación | **Duración:** 3 asaltos/Intensidad |
| **Coste:** 3+1/Intensidad adicional | **Alcance:** 100 pies |
| **Área:** Radio de 5-30 pies | **Resistencia:** Ver abajo |

Este hechizo crea una barrera de espadas, dagas y cuchillos giratorios que azotan y cortan alrededor de un punto fijo y causan 1d8 puntos de daño a 1d4+2 Localizaciones de impacto aleatorias de *cualquiera* que pase a través del Área de efecto. La armadura solo ofrece la mitad de su protección normal. Los Puntos de Armadura mágicos reducen el daño normalmente. Debido a que las armas giran a una velocidad cegadora y están muy juntas, es imposible Pararlas o Evadirlas. Se puede usar un escudo para bloquear pasivamente las Localizaciones de impacto normalmente. En este caso, recuerda comparar el daño tirado CON la armadura y los Puntos de golpe del escudo.

El hechizo puede lanzarse defensivamente para proteger al clérigo o a uno o más aliados, o de forma ofensiva para atrapar a los enemigos. Sin embargo, los enemigos rodeados a menos de cinco pies del borde de la barrera mientras se está formando pueden realizar una tirada de Evadir para escapar. Independientemente del éxito, el oponente termina boca abajo, justo fuera del Área de efecto. Una tirada exitosa resulta en daño nulo; de lo contrario, sufren el efecto completo.

#### Bless \(R\) (Bendecir)

(Conjuración)

| | |
| :-- | :-- |
| **Rango:** Clérigo 1 | **Tiempo de lanzamiento:** 1 asalto |
| **Esfera:** Todas | **Duración:** 5 minutos |
| **Coste:** 1 | **Alcance:** 180 pies |
| **Área:** Radio de 25 pies | **Resistencia:** Voluntad |

Cuando se lanza este hechizo, el clérigo bendice a un grupo de aliados dentro del Área de efecto. Los afectados irradian la Alineación del lanzador, ya sea Bien o Mal. No existen bendiciones de Neutralidad. Todos los aliados dentro del radio del hechizo reciben un bonificador de +5% a todas las tiradas de habilidad y de Resistencia. Además, sus armas causan +1d3 de daño a los no muertos inteligentes, así como a criaturas de los planos exteriores que tengan alineaciones opuestas a la del lanzador, tales como demonios, diablos o ángeles. Ten en cuenta que, aunque los no muertos animados, como esqueletos y zombis, no son inherentemente malvados, suelen ser animados por magia maligna y, por tanto, sujetos a este daño.

La versión inversa de este hechizo, Maldición, permite al clérigo maldecir a los enemigos, haciendo que las habilidades señaladas sufran la inversa de los beneficios notados anteriormente. El daño de un arma maldita se calcula como una penalización, y este daño no puede resultar en menos de 1 punto.

#### Burning Hands (Manos ardientes)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Ninguna | **Duración:** Instantánea |
| **Coste:** 3+1/Intensidad adicional | **Alcance:** 0 |
| **Área:** Cono de 120 grados, 5 pies de largo | **Resistencia:** Evadir |

Este hechizo hace que broten llamas de las manos del lanzador en un arco de 120 grados. Si se usan miniaturas en combate, Burning Hands dañará a cada objetivo que ocupe 1 de los cuadrados frontales del lanzador. Lanzar Burning Hands a niveles más altos de Intensidad requiere un mago de Rango superior. Este daño engulle a todos los objetivos dentro del área CON un daño basado en la Intensidad del hechizo, hasta una Intensidad máxima de 9, de la siguiente manera. Una tirada exitosa de Evadir, arrojándose al suelo, permite a la víctima no sufrir daño. Alguien CON la habilidad Artful Dodger (Dodger ágil) tiene la opción de Evadir sin caer al suelo.

| Intensidad | Coste | Rango mín. | Efecto variable |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 puntos de daño a todas las Localizaciones de impacto |
| 3 | 4 | 1 | 1d3+2 puntos de daño a todas las Localizaciones de impacto |
| 5 | 5 | 1 | 1d3+3 puntos de daño a todas las Localizaciones de impacto |
| 7 | 6 | 2 | 1d3+4 puntos de daño a todas las Localizaciones de impacto |
| 9 | 7 | 3 | 1d3+5 puntos de daño a todas las Localizaciones de impacto |

La armadura llevada no protege, pero los Puntos de Armadura mágicos o la armadura natural de una criatura reducen el daño normalmente. Este poderoso hechizo está equilibrado por su rango notablemente corto, lo que significa que, para lanzarlo, el usuario de magia debe estar lo suficientemente cerca como para estar en una posición muy desventajosa.

Debido a que las criaturas más grandes son típicamente más grandes que el Área de efecto del hechizo, tenderán a tener menos Localizaciones de impacto afectadas. Aquellos de TAM 21 a 30 reciben el daño en la cabeza, pecho, abdomen y brazos, mientras que aquellos de TAM 31+ recibirán el daño en el abdomen y las piernas. Los Directores de Juego deberían ajustar estas localizaciones dependiendo de la forma y posición del objetivo CON respecto al lanzador. Burning Hands tiene una probabilidad de encender materiales inflamables igual al daño tirado x5%. Consulta la sección sobre [Fuegos](0007_Game_System.md?id=fire-based-attacks) para obtener información adicional.

#### Calm (Calmar)

(Encantamiento (Hechizo))

| | |
| :-- | :-- |
| **Rango:** Clérigo 0 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Hechizo | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** Voluntad |

Calm intenta amortiguar las Pasiones de un objetivo humanoide de TAM 1-20, tal vez asegurando que un pretendiente enamorado no presione su cortejo, que un rival asustado no grite pidiendo ayuda, o que no se desenvainen armas CON ira. #### Orden

(Encantamiento (Encanto))

| | |
| :-- | :-- |
| **Rango:** Clérigo 1 | **Tiempo de lanzamiento:** 1 Acción |
| **Esfera:** Encanto | **Duración:** 1 Minuto |
| **Coste:** 3 | **Alcance:** 100 pies |
| **Área:** 1 Objetivo | **Resistencia:** POD |

Cuando se lanza este conjuro, el clérigo puede pronunciar una orden de una sola palabra a una criatura viva de TAM 1-20, y en el siguiente Turno del sujeto, la orden será seguida al pie de la letra si falla en resistir. Esto esencialmente hace que la víctima pierda el siguiente Turno completando la acción ordenada y desperdicia un Punto de Acción mientras la realiza. Si la víctima no posee más Puntos de Acción, la acción ordenada se realizará durante su primer Turno de la siguiente Ronda. La orden en sí misma no puede causar ninguna lesión real al objetivo; sin embargo, la lesión puede surgir como un efecto secundario de la orden.

Por ejemplo, una orden de morir resultaría en que la víctima colapsara en un estado similar a la muerte durante 1 Ronda sin causar ninguna lesión real; sin embargo, una orden de caer dada a una criatura que escala un acantilado de 100 pies de altura podría ser más que mortal.

El sujeto de la orden debe ser capaz de entender el idioma hablado por el lanzador y se le permite una prueba de POD para resistir.

**Algunos ejemplos de Órdenes**

- **Gatear:** El sujeto se tira al suelo y comienza a gatear.
- **Morir:** El sujeto cae al suelo entrando en un estado comatoso similar a la muerte.
- **Caer:** El sujeto cae al suelo.
- **Pifiar:** El sujeto pifia una acción física que estaba a punto de realizar.
- **Dormir:** El sujeto se queda dormido.
- **Huir:** El sujeto se da la vuelta y huye del lanzador.
- **Volar:** El sujeto mueve los brazos y corre en círculos.
- **Ir:** El sujeto comienza a caminar en la dirección en la que estaba mirando.
- **Alto:** El sujeto se detiene inmediatamente y se queda en su lugar.
- **Salir:** El sujeto se da la vuelta y se va por donde entró.
- **Descansar:** El sujeto cae en posición sentada y recupera el aliento.
- **Correr:** El sujeto comienza a correr.
- **Gritar:** El sujeto grita.
- **Hundirse:** El sujeto deja de nadar.
- **Rendirse:** El sujeto suelta sus armas y cesa las hostilidades.

#### Encantar objeto

(Encantamiento)

| | |
| :-- | :-- |
| **Rango:** Mago 4 | **Tiempo de lanzamiento:** Ver abajo |
| **Esfera:** Ninguna | **Duración:** Ver abajo |
| **Coste:** 3 + Ver abajo | **Alcance:** Tacto |
| **Área:** 1 objeto | **Resistencia:** N/A |

El lanzamiento de este hechizo prepara un objeto para el Encantamiento. El objeto debe estar en buenas condiciones y ser de la mejor construcción y mano de obra. Se requiere un coste adicional de al menos 100 PO para cubrir los gastos de herramientas, tallado, bordado, incrustación de joyas, grabado, etc. Finalmente, el proceso de Encantamiento requiere un laboratorio o taller.

Mientras lanza el hechizo, el usuario de magia debe estar tocando el objeto durante todo el Tiempo de lanzamiento de 1d8+2 días. Esto tiene en cuenta los períodos de descanso y sueño, durante los cuales el objeto debe permanecer a una distancia de un brazo del lanzador. En ningún momento durante el lanzamiento el usuario de magia puede lanzar otro hechizo o realizar cualquier otra forma de magia. Romper cualquiera de estas restricciones hará que el hechizo falle automáticamente.

Una vez lanzado CON éxito, el objeto está listo para el paso final, CON el lanzador colocando el hechizo deseado en él. Para hacerlo, deben tener el hechizo en la memoria o en un pergamino y lanzarlo dentro del objeto en un plazo de 24 horas, o el proceso completo deberá comenzarse desde cero. Una vez que comienza el lanzamiento del hechizo seleccionado, el proceso puede exceder las 24 horas mencionadas. Infundir el objeto CON el hechizo seleccionado cuesta el número normal de Puntos Mágicos para la Intensidad deseada y toma 1d12 horas por Rango de hechizo. Durante todo el proceso de infusión, el lanzador debe permanecer tocando el objeto o permanecer al alcance del brazo durante los períodos de descanso, como se indicó anteriormente, y se requiere una tirada de Lanzamiento Arcano al final del período de lanzamiento para infundir el hechizo CON éxito. Se siguen los grados de éxito normales del Lanzamiento de Hechizos, sin embargo, CON respecto a un resultado de Fallo, el hechizo no puede ser forzado. Se pueden infundir hechizos sucesivos dentro del objeto, siempre que el proceso de lanzamiento se inicie dentro de las 24 horas posteriores a la finalización del hechizo anterior. Esto se aplica incluso en el caso de un hechizo que haya fallado anteriormente. Cada hechizo sucesivo requiere el Coste de Lanzamiento normal.

Al usar el objeto, cada hechizo contenido en él puede lanzarse solo una vez; sin embargo, se pueden infundir múltiples versiones del mismo hechizo siguiendo el procedimiento anterior. También es posible infundir un solo hechizo, seguido de un lanzamiento del hechizo de Rango 4 Permanencia. En este caso, el hechizo puede lanzarse tan a menudo como se desee, siguiendo las restricciones establecidas en la descripción del hechizo Permanencia.

No es posible infundir otros efectos mágicos en un objeto que no se ajusten a un hechizo específico, y muchos objetos mágicos de tiempos lejanos simplemente no pueden ser recreados en esta época.

Este hechizo permite al lanzador intentar invocar un familiar, que se convierte en una extensión de los sentidos y el poder de su maestro. #### Escudo de fuego

(Evocación)

| | |
| :-- | :-- |
| **Rango:** Mago 3 | **Tiempo de lanzamiento:** 2 Acciones |
| **Esfera:** Ninguna | **Duración:** 2 minutos/Intensidad |
| **Coste:** 3+1/Intensidad adicional | **Alcance:** 0 |
| **Área:** Lanzador | **Resistir:** N/A |

Este hechizo crea un escudo de llamas tenues que inmola al lanzador pero no causa daño por sí mismo. En su lugar, las llamas protegen al receptor del fuego o del frío, dependiendo de cuál de las dos variantes esté en memoria: Escudo gélido, que crea llamas azules o verdes y protege contra el calor y el daño basado en fuego, o Escudo cálido, que crea llamas violetas o azules y protege contra el frío y el daño basado en hielo. El color de las llamas debe determinarse aleatoriamente CON un 50% de probabilidad para cada una, ya que el hecho de que ambos tipos puedan emitir llamas azules crea un elemento de incertidumbre por parte de cualquier atacante. La decisión sobre cuál memorizar se toma cuando se preparan los hechizos, y ambos pueden memorizarse si se desea. Estas llamas no emiten calor y arrojan luz a solo la mitad del brillo de una antorcha. Los detalles de cada variante se detallan a continuación.

- **Escudo gélido:** Estas llamas están frías al tacto y reducen cualquier daño basado en fuego o calor a la mitad del total. Una tirada de Resistencia exitosa negará todo el daño. La tirada de Resistencia es un grado más fácil y, en el caso de Esquivar, no hará que el defensor caiga al suelo.
- **Escudo cálido:** Estas llamas están cálidas al tacto y reducen cualquier daño basado en frío a la mitad del total. Una tirada de Resistencia exitosa negará todo el daño. La tirada de Resistencia es un grado más fácil y, en el caso de Esquivar, no hará que el defensor caiga al suelo.

Los ataques cuerpo a cuerpo contra el receptor de cualquier variante, ya sea armado o desarmado, infligen daño normal a menos que utilicen uno de los elementos contra los que está protegido. En este caso, el lanzador está protegido de la porción elemental del ataque, y el atacante recibe un daño igual al infligido. La armadura vestida por parte del atacante no ofrece protección, pero los Puntos de Armadura mágicos o la armadura natural de una criatura reducen el daño normalmente. Las criaturas CON Resistencia Mágica Innata pueden disipar el Escudo de fuego CON una tirada exitosa de POD cuando el receptor es golpeado por primera vez. Si la tirada de Resistencia Mágica falla, el oponente no podrá negar el Escudo de fuego más tarde.

#### Curar (R)

(Nigromancia)

| | |
| :-- | :-- |
| **Rango:** Clérigo 4 | **Tiempo de lanzamiento:** 1 minuto |
| **Esfera:** Sanación | **Duración:** Permanente |
| **Coste:** 3 + 1/Intensidad | **Alcance:** Tacto |
| **Área:** 1 criatura | **Resistencia:** N/A (Resistencia o Esquivar) |

CON el lanzamiento de Curar, el clérigo puede curar una dolencia física, un trauma mental o una cantidad significativa de lesiones CON un solo toque. El alcance real de esta recuperación se basa en la Intensidad del hechizo de la siguiente manera: por cada nivel de Intensidad, el hechizo cura al sujeto de una enfermedad de cualquier POT, cura cualquier ceguera o sordera, anula un trastorno mental provocado por una lesión o magia, o cura una Ubicación de Impacto de hasta 12 puntos de daño. Por lo tanto, se requeriría un lanzamiento a Intensidad 7 para curar a un individuo que sufre quemaduras en todo el cuerpo. Alternativamente, se les inflige una dolencia cuyos efectos son los mismos que el hechizo Causar Enfermedad, la reversión de Curar Enfermedad, pero a +20 POT. La tirada de Canalizar del lanzador funciona como la tirada para impactar a su oponente y se asume como parte del requisito somático del hechizo. No es necesaria ninguna tirada adicional para impactar. Ni la armadura natural ni la vestida ofrecen protección, pero los Puntos de Armadura mágicos reducen el daño normalmente y bloquean completamente las dolencias infligidas. Cada Intensidad adicional afecta a otra Ubicación de Impacto contigua a la primera, CON los efectos determinados por la tirada de Resistencia inicial. Ninguna versión de este hechizo tiene efecto sobre los no muertos, las criaturas dañadas solo por hierro, plata o armas mágicas, ni los seres no corpóreos.

#### Identificar

(Adivinación)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 minuto |
| **Esfera:** Protección | **Duración:** 1 minuto/Intensidad |
| **Coste:** 1/Intensidad | **Alcance:** 0 |
| **Área:** Lanzador | **Resistencia:** N/A |

CON el lanzamiento de este hechizo, el usuario de magia puede intentar identificar las propiedades mágicas (si las hay) de un objeto que esté manejando. Simplemente tocar el objeto no suele ser suficiente; el objeto debe llevarse puesto o sostenerse de forma congruente CON su diseño; por ejemplo, un yelmo debe ponerse en la cabeza, un amuleto deslizarse sobre el cuello, un arma cuerpo a cuerpo sostenerse firmemente, un anillo colocarse en un dedo, y así sucesivamente. Una perla de al menos 100 PO de valor se muele hasta convertirla en polvo y se consume junto CON otros componentes mundanos de hechizos para lanzar este hechizo. Si se añade una Piedra de la Suerte pulverizada a la infusión, la dificultad de la tirada de Lanzamiento Arcano es normal y todas las propiedades mágicas de cualquier objeto manejado por minuto durante la Duración del hechizo se aprenden automáticamente, sin necesidad de tiradas adicionales.

#### Encender (R)

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 0 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Elemental (Fuego) | **Duración:** Instantánea |
| **Coste:** 1 | **Alcance:** 10 pies (aprox. 3 m) |
| **Área:** 1 fuego pequeño | **Resistencia:** N/A |

Este hechizo puede utilizarse de dos maneras diferentes, ya sea para Encender o Apagar. La elección de cuál se hace cuando se lanza.

Encender solo funciona en materia inorgánica inflamable, haciendo que un objeto pequeño o un área del tamaño de una mano estalle en llamas. Dependiendo de lo que se haya prendido fuego, una vez ardiendo, las llamas pueden extenderse a menos que se apaguen o se contrarresten de alguna manera. Este hechizo normalmente se usa para encender velas, antorchas o linternas desde lejos. También se puede usar para iniciar una fogata o un fuego de cocina en condiciones adversas, como usar yesca húmeda o CON vientos fuertes.

Apagar sofoca inmediatamente las llamas y los fuegos pequeños de tamaño y calor moderados. Es útil para apagar velas, linternas, antorchas o fuegos de cocina pequeños, pero no funcionará en conflagraciones mágicas o más grandes y feroces como piras, casas en llamas o fuego de dragón.

#### Ilusión

(Ilusión)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Ninguna | **Duración:** Concentración; ver a continuación |
| **Coste:** 1/Intensidad | **Alcance:** 100 pies (aprox. 30 m)/Intensidad |
| **Área:** 50 pies (aprox. 15 m) de radio/Intensidad | **Resistencia:** No creer |

Este hechizo crea una ilusión visual de cualquier cosa que el lanzador desee. No tiene efecto en otros sentidos, no haciendo sonido, produciendo olor, temperatura o textura, etcétera.

Esta ilusión puede ser cualquier cosa, desde un prado abierto hasta un antiguo dragón rojo, si cabe dentro del Área de Efecto del hechizo. La ilusión durará solo mientras el lanzador mantenga la Concentración, o una vez que un oponente la toque o entre en ella; hacerlo hace que la magia que la sustenta se deshaga y la ilusión se disipe. Sin embargo, el lanzador puede mantener la ilusión después del contacto físico gastando 1 Punto de Magia y dirigiéndola para que reaccione apropiadamente al contacto de modo que no cree sospechas. Por ejemplo, en circunstancias normales, la ilusión de un ogro desaparecería cuando fuera golpeada por una flecha; sin embargo, el lanzador podría hacer que el ogro parezca encogerse de hombros ante el golpe y cargar contra el atacante gastando 1 Punto de Magia. Cabe señalar que la flecha real no es detenida por la ilusión y aún puede golpear a algo o a alguien detrás de la manifestación.

Aunque la ilusión no puede causar daño real, ni crear temperatura, la mente puede convencerse de que siente dolor, sufriendo los efectos de una lesión o sintiendo extremos de calor o frío; sin embargo, los objetos no parecerán congelarse o arder, a menos que el lanzador también se concentre en estos efectos. Una vez que se ha lanzado el hechizo, el usuario de magia puede añadir efectos visuales adicionales a voluntad concentrándose en el efecto deseado. Esto normalmente no lleva tiempo y puede tratarse como una Acción Gratuita. Por ejemplo, si el lanzador deseara que una antorcha ilusoria caída hiciera que las hojas secas parecieran incendiarse, el lanzador podría concentrarse como una Acción Gratuita para hacerlo.

Consulta el capítulo de [Ilusiones y Fantasmas](0009_Magic.md?id=illusions-and-phantasms) para obtener más información.

#### Invisibilidad

(Ilusión)

| | |
| :-- | :-- |
| **Rango:** Mago 1 | **Tiempo de lanzamiento:** 1 acción |
| **Esfera:** Ninguna | **Duración:** 6 horas/Intensidad |
| **Coste:** 3, +1/Intensidad adicional | **Alcance:** Tacto |
| **Área:** 1 objetivo | **Resistencia:** N/A |

Cuando se lanza este hechizo, el sujeto y cualquier equipo que lleve desaparecen, invisibles para todas las formas de visión normal. Sin embargo, esto no hace que el individuo sea indetectable por otros medios como el oído, el tacto, el olfato, etcétera, o por Habilidades naturales como Sentir Vida o Sonar.

Aquellos bajo los efectos de Invisibilidad permanecen así durante toda la Duración del hechizo (máx. 24 horas), a menos que se disipe o el sujeto realice un ataque, en cuyo caso el hechizo se anula y el individuo reaparece *después* del ataque. Se consideraría que el objetivo está bajo los efectos de [Sorpresa](0008_Combat.md?id=surprise). Ninguna otra acción afecta negativamente a la Duración del hechizo, lo que permite al sujeto abrir puertas, hablar, trepar, correr, robar un bolsillo, etcétera. Incluso el lanzamiento de hechizos no terminará la Duración a menos que afecten negativamente a uno o más enemigos específicos en combate. Muchas de las acciones mencionadas anteriormente podrían permitir otros medios de detección, como una posible prueba de Percepción para oír a alguien corriendo, o para sentir que le roban un bolsillo. El Director de Juego asignará penalizaciones o bonificaciones a aquellos que intenten la detección según lo notable que sea.

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 2 | **Tiempo de lanzamiento:** 1 Minuto |

Este hechizo crea una boca en un artículo u objeto, que aparece mágicamente cuando es activado por un evento específico o un momento designado por el usuario de magia cuando se lanza el hechizo por primera vez. #### Polimorfismo de otro

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 3 | **Tiempo de lanzamiento:** 2 acciones |
| **Esfera:** Ninguna | **Duración:** Permanente |
| **Coste:** 3, +1 por Intensidad adicional (+1 EXP) | **Alcance:** 15 pies/Intensidad |
| **Área:** 1 objetivo | **Resistencia:** POD |

El lanzador puede alterar la forma de una criatura corpórea objetivo a la de otra, CON cada punto de Intensidad alterando el TAM en hasta 5 puntos. Por lo tanto, transformar un orco de TAM 16 en un conejo de TAM 1 requeriría 3 niveles de Intensidad (15 puntos de diferencia en TAM). El sujeto de este hechizo puede realizar una tirada de POD para resistirse. Las criaturas grandes (TAM 21-40) son menos susceptibles de ser polimorfizadas, siendo su tirada de Resistencia Fácil, mientras que la tirada de Resistencia para criaturas enormes (TAM 41+) es Muy Fácil.

Todo el proceso de transformación dura un asalto completo y puede resultar bastante estresante para la criatura en cuestión, requiriendo una segunda tirada de POD para mantener su personalidad original; un fallo aturde al sujeto durante 1d10 minutos, y una pifia resulta en la muerte por choque mental. Cada duplicación o reducción a la mitad del TAM original de la criatura hace que la tirada de POD para mantener la personalidad sea un grado más difícil, al igual que un cambio completo de entorno, como convertir a una persona en pez. Una tirada exitosa permite a la víctima conservar su INT y su CAR, así como cualquier habilidad que requiera esas características.

La transformación otorga al receptor la forma de respiración de la criatura asumida, si es distinta a la normal; cualquier ataque natural; y todos los modos de movimiento mundanos. No otorga ninguna capacidad aumentada o mágica que posea la criatura. Por ejemplo, una criatura que ha sido polimorfizada en dragón no obtendrá el ataque de aliento ni las habilidades similares a conjuros de la criatura, pero obtendrá la capacidad de volar, su piel dura, mordisco mortal, ataques de garra, etcétera. Además, la víctima obtiene las habilidades físicas de la nueva forma, tales como Atletismo, Brío, Volar, Nadar, así como sus Puntos de Golpe y su Modificador de Daño. Suponiendo que el individuo transformado conserve su INT, todavía pierde la capacidad de hablar, a menos que la nueva forma posea la capacidad de articular palabras. Aquellos que eran capaces de lanzar hechizos en su forma anterior aún podrían lanzarlos en la nueva forma, suponiendo que todavía posean la capacidad de producir los componentes verbales y somáticos. En el caso de un cambio drástico, como pasar de bípedo a cuadrúpedo, o de animal terrestre a criatura marina, por ejemplo, el Director de Juego debería sentirse libre de penalizar en al menos un grado de dificultad el uso de cualquier habilidad que requiriera tiempo de aprendizaje mientras se ajusta a la nueva forma hasta que haya pasado suficiente tiempo para practicar. Esto es especialmente cierto para habilidades físicas como Atletismo, Sin armas, Nadar, Volar, Habilidades de combate, etcétera.

La tirada de POD para mantener la personalidad es necesaria cada día que el sujeto permanece transformado hasta que falle, lo que hace que la persona sucumba finalmente a la mentalidad de la nueva forma, cambiando la INT a INS en el caso de una criatura no sapiente. Todas las habilidades especiales y mágicas que posea la nueva forma y que no se hayan adquirido anteriormente, como ataques de mirada, armas de aliento, etcétera, están ahora disponibles para la criatura una vez completada la transformación. Los personajes que pierden su identidad de esta manera se convierten en personajes no jugadores bajo el control del Director de Juego.

Antes de sucumbir mentalmente a la transformación, la criatura polimorfizada es susceptible a Disipar magia de forma normal, sin necesidad de tirada de resistencia, ya que sería el deseo subconsciente de uno mismo de volver a la normalidad. La transformación requiere otra tirada de POD para resistir la tensión; un fallo aturde al sujeto durante 1d10 minutos y una pifia resulta en la muerte por choque mental.

Si la víctima había sucumbido previamente a la nueva forma, aún se puede usar Disipar magia; sin embargo, la víctima intentará resistirse a volver a su forma natural CON una tirada de POD. Fallar esta tirada significa que la víctima vuelve a su forma natural, lo que, por supuesto, requiere otra tirada de POD para resistir el choque mental de la transformación. Una vez perdida, la identidad natural de la víctima ya no es alcanzable; en cambio, la víctima asume que la forma extraña y alienígena no es natural y anhela volver a su estado «normal» anterior. *Por ejemplo, un orco que fue polimorfizado en conejo y asumió la identidad de la criatura creería que ahora es un conejo que ha sido transformado de forma bastante grosera en un orco*. Solo un Deseo, u otra magia similar, tiene alguna posibilidad de restaurar la identidad de la víctima una vez que se ha perdido.

Todo el equipo usado y transportado se funde mágicamente en la nueva forma; sin embargo, en algunos casos, el Director de Juego puede permitir que permanezcan objetos mágicos que aún podrían usarse en la nueva forma de la criatura, como un anillo mágico o unas botas. Ten en cuenta que esto requiere que el nuevo TAM de la criatura no sea muy diferente del original. Existe una probabilidad de POD x1 % para que cada objeto mágico usado de naturaleza no ofensiva, sujeto a la aprobación del Director de Juego, transfiera sus efectos a la nueva forma de la criatura. Una criatura CON un anillo de protección +1, por ejemplo, podría obtener un bonificador +1 a sus Puntos de Armadura naturales. Las criaturas CON la capacidad natural de cambiar de forma, como los doppelgängers y los licántropos, se transformarán normalmente, pero pueden asumir su forma normal después de 1 asalto. Si es asesinada, una criatura polimorfizada vuelve a su forma natural, incluso si ha perdido previamente todos los rastros de identidad.

Un brazo enredado no puede usar lo que esté sosteniendo, un pecho, abdomen o pierna atrapado hace que todas las tiradas de habilidad física sean un grado más difíciles (Excepto las tiradas de Brawn usadas para intentar liberarse), y una cabeza enredada causa asfixia como se detalla en [Asfixia](0007_Game_System.md?id=asphyxiation).

En el siguiente Turno, la víctima puede gastar un Punto de Acción para intentar liberarse de la telaraña. La telaraña mágica es increíblemente fuerte y pegajosa, poseyendo 6 Puntos de Armadura y Puntos de Golpe iguales a 3x la Intensidad del hechizo. Intentar liberarse requiere que la víctima gane una Tirada opuesta de Brawn contra la Pegajosidad de la telaraña (igual a la habilidad de Lanzamiento Arcano del lanzador). Si esto falla, el objetivo permanece sujeto, incapaz de liberarse solo por fuerza. Intentar cortar para liberarse expone la herramienta o arma utilizada al mismo proceso. A pesar de la creencia popular, las telarañas no son inflamables, pero un personaje podría quemar lentamente un camino a través de una telaraña usando una llama para marchitar las hebras (el daño por fuego ignora los Puntos de Armadura de la Telaraña).

#### Deseo

(Conjuración, Evocación)

| | |
| :-- | :-- |
| **Rango:** Mago 5 | **Tiempo de lanzamiento:** Ver más abajo |
| **Esfera:** Ninguna | **Duración:** Ver más abajo |
| **Coste:** 3, +1 o más EXP | **Alcance:** Ilimitado |
| **Área:** Ver más abajo | **Resistencia:** Ver más abajo |

Deseo puede cambiar la realidad de una manera permanente y significativa. Para lanzar este hechizo, el usuario de magia debe gastar 3 Puntos Mágicos y 1 o más tiradas de EXP dependiendo de los resultados deseados. Cada lanzamiento sucesivo de Deseo en un lapso de 1 mes duplica el gasto de EXP normalmente requerido. El Tiempo de lanzamiento suele ser necesario para detallar verbalmente los detalles del Deseo. Al completarlo, el lanzador sufre una pérdida de Fatiga igual a la EXP gastada y envejece un 5% de su esperanza de vida normal (para los humanos, eso serían cinco años). Consulta [Envejecimiento](0007_Game_System.md?id=aging) para conocer las esperanzas de vida promedio de las razas semihumanas.

Los resultados de un Deseo deben tomarse literalmente y están abiertos a la interpretación del Director de Juego. Los deseos codiciosos suelen terminar mal. Hay un 10% de probabilidad de que un Deseo hecho CON intenciones codiciosas salga mal de alguna manera. Por ejemplo, desear riqueza podría teletransportarla desde las bóvedas del tesoro del señor o rey local. Un Deseo no puede cancelar los decretos de entidades similares a deidades a menos que dicho ser haya emitido dicho Deseo.

A continuación, se presentan algunos ejemplos de Deseos y el gasto de EXP requerido.

#### Vista del mago

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Mago 3 | **Tiempo de lanzamiento:** 1 Minuto |
| **Esfera:** Ninguna | **Duración:** 1 Minuto/Intensidad |
| **Coste:** 1/Intensidad | **Alcance:** 0 |
| **Área:** Ver más abajo | **Resistencia:** N/A |

Este hechizo crea un pequeño "ojo" invisible a través del cual el usuario de magia puede ver durante la Duración del hechizo. Este ojo puede moverse por delante del grupo o enviarse a mirar alrededor de las esquinas y dentro de las habitaciones, teniendo una Tasa de movimiento de 20 pies por Ronda (240 pies por minuto), si solo se escanea en busca de amenazas "obvias" o elementos de interés. Esto normalmente solo se extenderá al suelo y las paredes inferiores. Si se intenta ser más exhaustivo (examinando también las paredes completas y el techo), su Tasa de movimiento se reduce a 10 pies por Ronda (120 pies por minuto). El Director de Juego debe sentirse libre de permitir tiradas de Percepción por parte del lanzador, cuando sea necesario, CON respecto a detectar anomalías visuales. El ojo es corpóreo, incapaz de atravesar materia sólida, y posee visión normal hasta 60 pies, y Visión nocturna hasta 10 pies. El lanzador debe mantener la Concentración en el ojo durante toda la Duración, o permanecerá inerte hasta que se establezca nuevamente la Concentración. Cualquier ataque de mirada que normalmente afectaría al lanzador todavía afecta al lanzador normalmente; sin embargo, el ojo se considera independiente del lanzador CON respecto a la ceguera, hechizos de oscuridad, etcétera. Para los propósitos de caber a través de pequeñas aberturas, el ojo no es más grande de 1 pulgada y tiene un TAM de 1.

#### Palabra de retorno

(Transmutación)

| | |
| :-- | :-- |
| **Rango:** Clérigo 4 | **Tiempo de lanzamiento:** 1 Acción |
| **Esfera:** Invocación | **Duración:** Ver más abajo |
| **Coste:** 3, +1/Intensidad adicional | **Alcance:** 0 |
| **Área:** El lanzador | **Resistencia:** N/A |

Cuando se lanza este hechizo, el clérigo es teletransportado instantáneamente a un santuario predesignado, y a un punto de llegada designado no mayor a 10 pies de radio. No hay límite al Alcance real teletransportado, incluido entre múltiples planos. Dentro de un solo plano, no hay posibilidad de un percance; sin embargo, cruzar incluso un plano da una probabilidad de Pifia de 91-00%, dos planos dan una Pifia en una tirada de 81-00%, y así sucesivamente. Esto reemplaza la probabilidad de Pifia normal del lanzador. Una Pifia al cruzar planos significa que el clérigo está irrevocablemente perdido. Las pifias dentro de un solo plano siguen las reglas normales.

Además de a sí mismo y a cualquier equipo transportado, el clérigo puede transportar otros 3 objetos por Intensidad, cada uno no mayor a TAM/9 "Cosas". El material adicional transportado puede ser tesoro, equipo o seres vivos. Sin embargo, las criaturas transportadas deben tener el hechizo lanzado a un nivel suficiente de Intensidad para cubrir cualquier equipo transportado.
