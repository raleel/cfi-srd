# Bilaga: Omvandlingstabeller

---
#### Omvandling från brittiska enheter till metriska mått

För att ge _Classic Fantasy Imperative_ en renare presentation, göra det lättare att läsa, och för att korta ner beskrivningar och tabeller, kommer _Classic Fantasy Imperative_ att fokusera på brittiska måttenheter (Imperial) istället för både brittiska och metriska. Brittiska mått valdes för att underlätta konvertering av befintligt material, eftersom de flesta äventyr, spelplaner och kartor som används av andra spel i genren utnyttjar det brittiska systemet. För de som önskar använda det metriska systemet har dock de vanligaste vikterna och måtten konverterats med hjälp av följande tabeller. Eftersom vi vanligtvis inte har att göra med varelser, besvärjelser och liknande från den verkliga världen, kan vi tillåta oss en viss frihet med de vikter och mått vi hittat på för dem. Istället för att använda exakta omvandlingar är det enklare att använda mått som är lätta att komma ihåg, vilket underlättar spelandet.

#### Vindtabell

| MPH | Typ | Effekt på färdigheter | Effekt på förflyttning |
| :-: | :-- | :-- | :-- |
| 0-10 | Lugnt | Inget | Inget |
| 11-20 | Måttlig bris | Inget | Inget |
| 21-30 | Frisk bris | Inget | Två tredjedelar |
| 31-40 | Hård bris | Svårt | Två tredjedelar |
| 41-50 | Styv kuling | Svårt | Hälften |
| 51-60 | Hård kuling | Formidabelt | Hälften |
| 60+ | Storm/Orkan | Formidabelt | En tredjedel |

Vind, särskilt mycket starka vindar, kan ha en negativ effekt på aktivitet. Vindens styrka (STY) uttrycks i miles per timme. Dess effekt på fysiska färdigheter – de som involverar STY eller FIN – beskrivs i kolumnen Färdighet; effekter på förflyttningshastighet i kolumnen Förflyttningshastighet.

_Till exempel, en hård bris med STY 40 reducerar en människas gånghastighet till två tredjedelar och färdighetsslag sker med svårighetsgraden Svårt._

#### Temperaturtabell

| Temperatur (ºF) | Typ | Risk |
| :-: | :-: | :-- |
| < 2º | Glacial | Sök omedelbart värme |
| 3-14º | Frost | 15 minuter |
| 13-32º | Kallt | Varje timme |
| 33-50º | Kyligt | Varje dag |
| 51-68º | Svalt | - |
| 69-86º | Varmt | - |
| > 86º | Hett | Varje timme |

Temperaturen kan variera dramatiskt beroende på klimat, årstid och höjd över havet, beroende på kampanjvärlden och var scenarierna utspelar sig. Tabellen ovan ger riktlinjer för effekterna av extrema temperaturer på rollpersoner.

Att bära lämpliga kläder ger en rollperson en karenstid på deras UTH i timmar innan exponering börjar märkas, såsom visas i kolumnen Risk. Efter denna tidpunkt måste de söka skydd eller börja drabbas av utmattningsförlust. Blöta rollpersoner förflyttar risknivån ett steg mot kallare. Lätta eller måttliga vindar förflyttar också risknivån ett steg mot kallare, medan hårda vindar och stormar förflyttar den två steg.
