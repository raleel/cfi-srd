## Beskrivning av besvärjelser

---
#### Appraise

(Divination)

| | |
| :-- | :-- |
| **Rang:** Mage 0 | **Kasttid:** 1 Tur |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 1 | **Räckvidd:** Beröring |
| **Område:** 1 föremål | **Motstånd:** Inget |

Appraise tillåter omedelbar bedömning av kvaliteten på fysiska varor med en kombinerad ENC i "saker" eller SIZ lika med kastarens POW. Besvärjelsen avgör om identiskt utseende föremål är av samma eller liknande kvalitet, eller om ett eller flera är felaktiga eller av högre kvalitet. Besvärjelsen fungerar inte på organiska saker, endast på livlösa föremål. Den avgör inte heller vilka brister eller förbättringar som finns; bara att de existerar. Den är till ingen nytta vid identifiering eller detektering av magi.

#### Armor

(Conjuration)

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 Runda |
| **Sfär:** Ingen | **Varaktighet:** Se nedan |
| **Kostnad:** 3 +1/Intensitet | **Räckvidd:** Beröring |
| **Område:** 1 Mål | **Motstånd:** Inget |

När denna besvärjelse kastas, begåvas målet med ett osynligt fält av magisk kraft motsvarande fjällpansar i skydd, vilket ger 4 Pansarpoäng till varje träffplats. Den har ingen effekt om den kastas på någon som redan bär rustning. Den ersätter dock naturligt pansar under sin varaktighet, förutsatt att den erbjuder överlägset skydd. Om den kastas på en varelse med mer än 4 poängs naturligt pansar, ökar den istället Pansarpoängen med 1 på alla platser. Detta magiska skydd hindrar inte rörelse eller besvärjelsekastning. Besvärjelsen kvarstår tills den skingras av magi, eller kastaren tar 8 poängs skada från en enskild attack, +1 per nivå av ytterligare Intensitet (se tabellen nedan). Naturligtvis kan kastaren välja att släppa besvärjelsen när som helst om så önskas, och måste göra det för att sova.

| Intensitet | Kostnad | Variabel effekt |
| :-: | :-: | :-- |
| 1 | 3 | 4 Pansarpoäng; kvarstår tills 8 skada tagits från 1 attack |
| 2 | 4 | 4 Pansarpoäng; kvarstår tills 9 skada tagits från 1 attack |
| 3 | 5 | 4 Pansarpoäng; kvarstår tills 10 skada tagits från 1 attack |
| 4 | 6 | 4 Pansarpoäng; kvarstår tills 11 skada tagits från 1 attack |
| +1 | +1 | Fortsatt progression |

#### Astral Spell

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Kleriker 5, Mage 5 | **Kasttid:** 2 Handlingar |
| **Sfär:** Astral | **Varaktighet:** Se nedan |
| **Kostnad:** 3 +1/ytterligare Intensitet | **Räckvidd:** Beröring |
| **Område:** Se nedan | **Motstånd:** N/A |

Denna besvärjelse tillåter kastaren och upp till fem andra (en per ytterligare Intensitet-nivå) att gå in i Astralplanet. Alla måste röra vid varandra och bilda en cirkel medan besvärjelsen kastas. Resenärernas kroppar lämnas kvar i ursprungsplanet, och de tar vanligtvis inte med sig några kläder eller utrustning, förutom föremål som själva utstrålar en magisk aura; dessa föremål förvandlas till astrala motsvarigheter av sin normala form. Varaktigheten varar tills kastaren vill att den ska upphöra. Det är dock möjligt att den avslutas i förtid av en extern kraft som Dispel Magic. Att döda kastarens fysiska kropp avslutar också besvärjelsen tidigt, även om detta har den olyckliga bieffekten att resenärer som följer med kastaren blir strandade.

#### Augury

(Divination)

| | |
| :-- | :-- |
| **Rang:** Kleriker 2 | **Kasttid:** 2 Minuter |
| **Sfär:** Divination | **Varaktighet:** Omedelbar |
| **Kostnad:** 3/Intensitet | **Räckvidd:** 60 fot |
| **Område:** Kastare | **Motstånd:** N/A |

Denna besvärjelse tillåter kastaren att avgöra om en specifik handling som ska utföras inom de närmaste 30 minuterna kommer att vara fördelaktig eller skadlig för en individ och/eller grupps välbefinnande. En fokuspunkt av något slag krävs för att urskilja tecknen, där de vanligaste är klor eller mindre ben från en drake, en pärla eller rent guld värt minst 100 GP, som har krossats eller smälts ner. Besvärjelsen har en maxintensitet på 4. Detta slag bör göras av Spelledaren, eftersom kastaren aldrig ska veta bortom allt tvivel om resultaten tolkades korrekt.

| Intensitet | Kostnad | Variabel effekt |
| :-: | :-: | :-- |
| 1 | 3 | Formidabelt slag för Channel-färdighet |
| 2 | 6 | Svårt slag för Channel-färdighet |
| 3 | 9 | Standard slag för Channel-färdighet |
| 4 | 12 | Enkelt slag för Channel-färdighet |

Om divination-slaget lyckas ger det ett av följande resultat:

| Augury | Innebörd |
| :-: | :-- |
| Ja | Handlingen kommer att vara fördelaktig |
| Nej | Handlingen kommer att vara skadlig |
| Ja och Nej | Handlingen kommer att vara både fördelaktig och skadlig |
| Ingenting | Handlingen kommer att vara varken fördelaktig eller skadlig |

En Fummel bör resultera i att Spelledaren säger motsatsen till verkligheten.

#### Avert

(Abjuration)

| | |
| :-- | :-- |
| **Rang:** Kleriker 0, Mage 0 | **Kasttid:** Omedelbar |
| **Sfär:** Skydd | **Varaktighet:** Omedelbar |
| **Kostnad:** 1 | **Räckvidd:** 60 fot |
| **Område:** 1 Besvärjelse | **Motstånd:** Inget |

Avert används för att avvärja en annan besvärjelse av rang 0 inom räckvidden. Avert kan kastas reaktivt för att neutralisera offensiva besvärjelser av rang 0 genom att använda den reaktiva handlingen "Counter Magic".

#### Befuddle

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Kleriker 0, Mage 0 | **Kasttid:** 1 Tur |
| **Sfär:** Charm | **Varaktighet:** 30 Minuter |
| **Kostnad:** 1 | **Räckvidd:** 60 fot |
| **Område:** 1 Mål | **Motstånd:** Willpower |

Befuddle orsakar förvirring i sinnet hos ett kroppsligt mål. Målet för besvärjelsen har svårt att tänka klart, glömmer var det befinner sig, vad det gör och varför – och faller ofta in i sammanhangslösa tankebanor. Förvirrade mål kan fortfarande agera i självförsvar men kan inte initiera någon konstruktiv aktivitet förrän besvärjelsen upphör. Alla typer av attacker eller hotfulla handlingar bryter omedelbart besvärjelsen, oavsett om den var riktad specifikt mot det förvirrade målet eller inte.

#### Blade Barrier

(Evocation)

| | |
| :-- | :-- |
| **Rang:** Kleriker 4 | **Kasttid:** 2 Handlingar |
| **Sfär:** Väktare, Skapande | **Varaktighet:** 3 Rundor/Intensitet |
| **Kostnad:** 3+1/ytterligare Intensitet | **Räckvidd:** 100 fot |
| **Område:** 5-30 fots radie | **Motstånd:** Se nedan |

Denna besvärjelse skapar en barriär av virvlande, skärande svärd, dolkar och knivar som piskar och hugger runt en fixerad punkt och orsakar 1d8 poängs skada på 1d4+2 slumpmässiga träffplatser för *alla* som passerar genom effektområdet. Pansar erbjuder endast hälften av sitt normala skydd. Magiska Pansarpoäng reducerar skadan som vanligt. Eftersom vapnen virvlar runt i bländande hastighet och är tätt packade, är det omöjligt att parera eller undvika dem. Man kan använda en sköld för att passivt blockera träffplatser normalt. I detta fall, kom ihåg att jämföra den rullade skadan med sköldens pansar och träffpoäng.

Besvärjelsen kan kastas defensivt för att skydda klerikern eller en eller flera allierade, eller offensivt för att fånga fiender. Fiender som är inringade inom fem fot från barriärens kant när den bildas kan dock göra ett undvikandeslag för att fly. Oavsett framgång hamnar motståndaren liggande, precis utanför effektområdet. Ett lyckat slag resulterar i ingen skada; annars lider de full effekt.

#### Bless (R)

(Conjuration)

| | |
| :-- | :-- |
| **Rang:** Kleriker 1 | **Kasttid:** 1 Runda |
| **Sfär:** Alla | **Varaktighet:** 5 Minuter |
| **Kostnad:** 1 | **Räckvidd:** 180 fot |
| **Område:** 25 fots radie | **Motstånd:** Willpower |

När denna besvärjelse kastas välsignar klerikern en grupp allierade inom effektområdet. De som påverkas utstrålar kastarens inriktning (Alignment), antingen God eller Ond. Det finns inga välsignelser av Neutralitet. Alla allierade inom besvärjelsens radie får en bonus på +5 % på alla färdighets- och motståndsslag. Dessutom orsakar deras vapen +1d3 skada på intelligenta odöda samt varelser från yttre plan som har motsatta inriktningar mot kastarens, såsom demoner, djävlar eller änglar. Notera att även om animerade odöda som skelett och zombier inte är inneboende onda, animeras de vanligtvis av ond magi och är därför föremål för denna skada.

Besvärjelsens motsats, Curse (Förbannelse), tillåter klerikern att förbanna fiender, vilket gör att de noterade färdigheterna lider av inversen av fördelarna som noterats ovan. Ett förbannat vapens skada beräknas som ett avdrag istället, och denna skada kan inte resultera i mindre än 1 poäng.

#### Burning Hands

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 Handling |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 3+1/ytterligare Intensitet | **Räckvidd:** 0 |
| **Område:** 120-graders kon, 5 fot lång | **Motstånd:** Undvikande |

Denna besvärjelse får flammor att skjuta ut från kastarens händer i en 120-graders båge. Om miniatyrer används i strid kommer Burning Hands att skada varje mål som upptar 1 av kastarens främre rutor. Att kasta Burning Hands på högre intensitetsnivåer kräver en mage med högre rang. Denna skada uppslukar alla mål inom området med skada baserad på besvärjelsens intensitet, upp till en maximal intensitet på 9, enligt följande. Ett lyckat undvikandeslag, där man kastar sig ner på marken, gör att offret inte lider någon skada. Någon med förmågan "Artful Dodger" har möjlighet att undvika utan att kasta sig ner.

| Intensitet | Kostnad | Min Rang | Variabel effekt |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 skadepoäng på alla träffplatser |
| 3 | 4 | 1 | 1d3+2 skadepoäng på alla träffplatser |
| 5 | 5 | 1 | 1d3+3 skadepoäng på alla träffplatser |
| 7 | 6 | 2 | 1d3+4 skadepoäng på alla träffplatser |
| 9 | 7 | 3 | 1d3+5 skadepoäng på alla träffplatser |

Buren rustning skyddar inte, men magiska Pansarpoäng eller en varelses naturliga pansar reducerar skada som vanligt. Denna kraftfulla besvärjelse balanseras av dess märkbart korta räckvidd, vilket innebär att magianvändaren måste vara tillräckligt nära för att befinna sig i en mycket ogynnsam position.

Eftersom större varelser vanligtvis är större än besvärjelsens effektområde, tenderar de att ha färre träffplatser som påverkas. De med SIZ 21 till 30 tar skada på huvud, bröst, buk och armar, medan de med SIZ 31+ tar skada på buk och ben. Spelledare bör justera dessa platser beroende på målets form och position i förhållande till kastaren. Burning Hands har en chans att antända brandfarligt material lika med den rullade skadan x5 %. Se avsnittet om [Eld](0007_Game_System.md?id=fire-based-attacks) för ytterligare information.

#### Calm

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Kleriker 0 | **Kasttid:** 1 Handling |
| **Sfär:** Charm | **Varaktighet:** Omedelbar |
| **Kostnad:** 1 | **Räckvidd:** Beröring |

#### Command

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Kleriker 1 | **Kasttid:** 1 Handling |

| **Kostnad:** 3 | **Räckvidd:** 100 fot |
| **Område:** 1 Mål | **Motstånd:** Willpower |

När denna besvärjelse kastas kan klerikern yttra ett enordskommando till en levande varelse med SIZ 1-20, och på subjektets nästa tur kommer kommandot att följas till punkt och pricka om de misslyckas med att motstå. Detta gör i huvudsak att offret missar nästa tur med att slutföra den befallda handlingen och slösar en handlingspoäng medan den utförs. - **Crawl:** Subjektet lägger sig ner och börjar krypa.
- **Die:** Subjektet faller ner och går in i ett komatöst dödsliknande tillstånd.
- **Fall:** Subjektet faller ner.
- **Fumble:** Subjektet fumlar med en fysisk handling som ska utföras.
- **Sleep:** Subjektet nickar till.
- **Flee:** Subjektet vänder sig om och flyr från kastaren.
- **Fly:** Subjektet flaxar med armarna och springer i cirklar.
- **Go:** Subjektet börjar gå i riktningen det stod vänd mot.
- **Halt:** Subjektet stannar omedelbart och står stilla.
- **Leave:** Subjektet vänder sig om och lämnar vägen det kom in.
- **Rest:** Subjektet sjunker ner i sittande ställning och hämtar andan.
- **Run:** Subjektet börjar springa.
- **Scream:** Subjektet skriker.
- **Sink:** Subjektet slutar simma.
- **Surrender:** Subjektet tappar sina vapen och upphör med fientligheter.

#### Enchant Item

(Enchantment)

| | |
| :-- | :-- |
| **Rang:** Mage 4 | **Kasttid:** Se nedan |
| **Sfär:** Ingen | **Varaktighet:** Se nedan |
| **Kostnad:** 3 + Se nedan | **Räckvidd:** Beröring |
| **Område:** 1 Föremål | **Motstånd:** N/A |

Kastandet av denna besvärjelse förbereder ett föremål för förtrollning. Objektet måste vara i gott skick och av finaste konstruktion och utförande. En ytterligare kostnad på minst 100 GP krävs för att täcka kostnaden för extra verktyg, sniderier, broderier, smycken, gravyrer och så vidare. Slutligen kräver förtrollningsprocessen ett laboratorium eller en verkstad.

Medan besvärjelsen kastas måste magianvändaren röra föremålet under hela kasttiden på 1d8+2 dagar. Detta inkluderar perioder av vila och sömn, under vilken föremålet måste förbli inom en armlängds avstånd från kastaren. Vid inget tillfälle under kastandet får magianvändaren kasta en annan besvärjelse eller utföra någon annan form av magi. Att bryta mot någon av dessa föreskrifter kommer automatiskt att göra att besvärjelsen misslyckas.

När den väl har kastats framgångsrikt är föremålet redo för det sista steget, där kastaren placerar den önskade besvärjelsen i det. För att göra detta måste de ha besvärjelsen i minnet eller på en rulle och kasta den i föremålet inom 24 timmar, annars måste hela processen startas om från början. När väl kastandet av den valda besvärjelsen påbörjas kan processen överskrida de ovan nämnda 24 timmarna. Att genomsyra föremålet med den valda besvärjelsen kostar det normala antalet magipoäng för önskad intensitet och tar 1d12 timmar per besvärjelserang. Under hela genomsyringsprocessen måste kastaren förbli i kontakt med föremålet eller förbli inom räckhåll under perioder av vila, som ovan, och ett Arcane Casting-slag krävs i slutet av kastperioden för att framgångsrikt genomsyra besvärjelsen. De normala framgångsgraderna för besvärjelsekastning följs, dock när det gäller ett misslyckat resultat kan besvärjelsen inte tvingas. Efterföljande besvärjelser kan genomsyras i föremålet, förutsatt att kastprocessen påbörjas inom 24 timmar efter avslutandet av föregående besvärjelse. Detta gäller även i fallet med en tidigare misslyckad besvärjelse. Varje efterföljande besvärjelse kräver normal kastkostnad.

När föremålet används kan varje besvärjelse som finns inuti kastas endast en gång; dock kan flera versioner av samma besvärjelse genomsyras genom att följa proceduren ovan. Det är också möjligt att genomsyra en enskild besvärjelse, följt av ett kast av besvärjelsen Permanency av rang 4. I det här fallet kan besvärjelsen kastas så ofta som önskas, genom att följa restriktionerna som anges under besvärjelsen Permanency.

Det är inte möjligt att genomsyra andra magiska effekter i ett föremål som inte överensstämmer med en specifik besvärjelse, och många magiska föremål från svunna tider kan helt enkelt inte återskapas i dag.

#### Fire Shield

(Evocation)

| | |
| :-- | :-- |
| **Rang:** Mage 3 | **Kasttid:** 2 Handlingar |
| **Sfär:** Ingen | **Varaktighet:** 2 Minuter/Intensitet |
| **Kostnad:** 3+1/ytterligare Intensitet | **Räckvidd:** 0 |
| **Område:** Kastare | **Motstånd:** N/A |

Denna besvärjelse skapar en sköld av spröda flammor som bränner kastaren men inte orsakar skada i sig självt. Istället skyddar flammorna mottagaren från antingen eld eller kyla, beroende på vilken av två varianter som finns i minnet: Chill Shield, som skapar blå eller gröna flammor och skyddar mot värme- och eldskada, eller Warm Shield, som skapar violetta eller blå flammor och skyddar mot kyla och isskada. Flammornas färg bör bestämmas slumpmässigt med 50 % chans för vardera, eftersom det faktum att båda typerna kan avge blå flammor skapar ett element av osäkerhet hos alla angripare. Beslutet om vilken som ska memoreras fattas när besvärjelserna förbereds, och båda kan memoreras om så önskas. Dessa flammor avger ingen värme och avger ljus med endast hälften av ljusstyrkan hos en fackla. Detaljerna för varje variant redovisas nedan.

- **Chill Shield:** Dessa flammor är svala vid beröring och reducerar all eld- eller värmebaserad skada till hälften av totalen. Ett lyckat motståndsslag negerar all skada. Motståndsslaget är en grad lättare och i fallet med undvikande renderas försvararen inte liggande.
- **Warm Shield:** Dessa flammor är varma vid beröring och reducerar all köldbaserad skada till hälften av totalen. Ett lyckat motståndsslag negerar all skada. Motståndsslaget är en grad lättare och i fallet med undvikande renderas försvararen inte liggande.

Närstridsattacker mot mottagaren av någon av varianterna, oavsett om de är beväpnade eller obeväpnade, orsakar normal skada om inte ett av elementen som skyddas mot används. I detta fall skyddas kastaren från attackens elementära del, och angriparen tar skada lika med den som tillfogades. Buren rustning på angriparen erbjuder inget skydd, men magiska Pansarpoäng eller en varelses naturliga pansar reducerar skada som vanligt. Varelser med inneboende magiskt motstånd kan skingra Fire Shield genom ett lyckat Willpower-slag när mottagaren träffas första gången. Om slaget för magiskt motstånd misslyckas kan motståndaren inte senare negera Fire Shield.

#### Magic Missile

(Evocation)

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 Handling |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 1/Intensitet | **Räckvidd:** 100 fot/Intensitet |
| **Område:** 1-5 Mål | **Motstånd:** Se nedan |

När denna besvärjelse kastas skjuter en eller flera missiler av magisk energi ut från magianvändarens fingertoppar och träffar ett mål. Det maximala antalet missiler som kan genereras baseras på kastarens Arcane Casting-färdighetsnivå, där en andra missil genereras vid 60 % färdighet, en tredje vid 70 %, en fjärde vid 80 % och en femte och sista missil vid 90 %. För att generera dessa missiler måste besvärjelsen kastas med en intensitet som motsvarar antalet önskade missiler. Till exempel, under 60 % färdighet, skulle en magianvändare som kastar Magic Missile med 3 intensitetsenheter uppnå den längre räckvidden, men endast en enskild missil skulle genereras. Se tabellen nedan.

En Magic Missile träffar ofelbart, även om målet är i närstrid eller har delvis skydd. Dessa missiler kan inte undvikas; dock kan en motståndare i totalt skydd inte målas med denna besvärjelse. Shield-besvärjelsen kommer automatiskt att avleda Magic Missiles förutsatt att målet är medvetet om och/eller vänt mot kastaren. Magic Missiles gör 1d6+1 skadepoäng och buren rustning skyddar inte, men en varelses naturliga pansar eller magiska Pansarpoäng reducerar skada som vanligt. Magic Missiles orsakar ingen skada på livlösa föremål såsom dörrar, lås och så vidare.

När man skjuter flera missiler kan kastaren låta dem träffa en enskild varelse, eller måla flera varelser. Varje Magic Missile träffar en slumpmässig träffplats - specifika träffplatser får inte väljas. Kastaren måste utse individuella mål för varje missil innan de rullar för skada.

#### Magic Mouth

(Transmutation)

| | |
| :-- | :-- |

Denna besvärjelse skapar en mun på ett föremål eller objekt, som magiskt visas när den utlöses av en specifik händelse eller tid som utses av magianvändaren när besvärjelsen först kastas. Denna mun kommer sedan att tala vilken fördefinierad fras kastaren än valt vid kastandet. Denna fras måste bestå av högst 25 ord och talas av munnen i en takt av ungefär 1 ord per sekund. Munnen får inte tala ord av makt eller kasta besvärjelser.

Denna besvärjelse kan kastas på vilket normalt livlöst föremål som helst, från en pelare eller ett träd, till en stenvägg eller en kista; den är dock särskilt effektiv när den kastas på en staty, eftersom statyn själv skulle se ut som om den talade. Den utlösande effekten kan inte vara något som inte kan urskiljas icke-magiskt, såsom en osynlig varelse, en varelses inriktning, färdighet, klass, etc. Den kan dock utse buren klädsel. Det maximala avståndet som besvärjelsen kan utlösas på är 25 fot per intensitetsenhet.

Besvärjelsens varaktighet är permanent tills förtrollningen aktiveras och sedan avslutas besvärjelsen.

#### Polymorph Other

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Mage 3 | **Kasttid:** 2 Handlingar |
| **Sfär:** Ingen | **Varaktighet:** Permanent |
| **Kostnad:** 3, +1/ytterligare Intensitet (+1 ERF) | **Räckvidd:** 15 fot/Intensitet |
| **Område:** 1 Mål | **Motstånd:** Willpower |

Kastaren kan ändra formen på en kroppslig målad varelse till en annan, där varje intensitetsenhet ändrar SIZ med upp till 5 poäng. Att förvandla en orch med SIZ 16 till en kanin med SIZ 1 skulle därför kräva 3 intensitetsnivåer (15 SIZ-poängs skillnad). Subjektet för denna besvärjelse tillåts ett Willpower-slag för att motstå. Stora varelser (SIZ 21-40) är mindre mottagliga för att bli polymorfade, med ett enkelt motståndsslag, medan motståndsslaget för enorma varelser (SIZ 41+) är mycket enkelt.

Hela förvandlingsprocessen tar en hel runda och kan vara ganska stressande för den ifrågavarande varelsen, vilket kräver ett andra Willpower-slag för att behålla sin ursprungliga personlighet, där ett misslyckande bedövar subjektet i 1d10 minuter, och en fummel resulterar i döden av mental chock. Varje fördubbling eller halvering av varelsens ursprungliga SIZ gör Willpower-slaget för att behålla personligheten en grad svårare, liksom en total miljöförändring, såsom att förvandla en person till en fisk. Ett lyckat slag gör att offret behåller sin INT och CHA samt alla färdigheter som kräver dessa egenskaper.

Förvandlingen ger mottagaren den antagna varelsens form av andning, om annan än normal; alla naturliga attacker; och alla världsliga rörelseformer. Den ger inte några förhöjda eller magiska förmågor som varelsen besitter. Till exempel kommer en varelse som har polymorfats till en drake inte att få varelsens andningsattack eller besvärjelseliknande förmågor, men kommer att få förmågan att flyga, dess tuffa skinn, dödliga bett, kloattacker och så vidare. Dessutom vinner offret den nya formens fysiska färdigheter såsom Athletics, Brawn, Fly, Swim, samt dess träffpoäng och skademodifierare. Förutsatt att den förvandlade individen behöll sin INT, förlorar de fortfarande förmågan att tala, såvida inte den nya formen besitter förmågan att artikulera ord. De som kunde kasta besvärjelser i sin tidigare form skulle fortfarande kunna kasta i den nya formen, förutsatt att de fortfarande har förmågan att producera de verbala och somatiska komponenterna. I händelse av en drastisk förändring, såsom att bli förvandlad från tvåfotad till fyrfota, eller ett landdjur till ett havsdjur, bör spelledaren känna sig fri att straffa användningen av färdigheter som skulle ta tid att lära sig under anpassningen till den nya formen med minst en svårighetsgrad fram till att tillräcklig tid har gått för att öva. Detta gäller särskilt fysiska färdigheter såsom Athletics, Unarmed, Swim, Fly, stridsfärdigheter och så vidare.

Willpower-slaget för att behålla sin personlighet krävs varje dag som subjektet förblir förvandlat tills det misslyckas, vilket gör att personen till slut dukar under för den nya formens mentalitet, där INT ändras till INS i fallet med en icke-sapient varelse. Alla speciella och magiska förmågor som den nya formen äger och som inte förvärvats tidigare, såsom blickattacker, andningsvapen och så vidare, är nu tillgängliga för varelsen när förvandlingen är komplett. Karaktärer som förlorar sin identitet på detta sätt blir icke-spelar-karaktärer under kontroll av spelledaren.

Innan man mentalt dukar under för förvandlingen är den polymorfade varelsen mottaglig för Dispel Magic som normalt, utan något motståndsslag krävt, eftersom det skulle vara ens undermedvetna önskan att återgå till det normala. Förvandlingen kräver ett nytt Willpower-slag för att motstå ansträngningen, där ett misslyckande bedövar subjektet i 1d10 minuter, och en fummel resulterar i döden av mental chock.

Om offret tidigare hade dukat under för den nya formen kan Dispel Magic fortfarande användas; offret kommer dock att försöka motstå att återvända till sin naturliga form med ett Willpower-slag. Att misslyckas med detta slag innebär att offret förvandlas tillbaka till den naturliga formen, vilket naturligtvis kräver ett nytt Willpower-slag för att motstå den mentala chocken från förvandlingen. När den väl gått förlorad är offrets naturliga identitet inte längre uppnåelig, istället antar offret att den märkliga och främmande formen är naturlig och längtar efter att återföras till sin tidigare "normala". _Till exempel skulle en orch som polymorfades till en kanin och antog varelsens identitet tro att den nu är en kanin som blivit ganska oförskämt förvandlad till en orch._ Endast en Wish, eller annan liknande magi, har någon chans att återställa offrets identitet när den väl gått förlorad.

All burit och transporterad utrustning smälter magiskt in i den nya formen; i vissa fall kan dock spelledaren tillåta magiska föremål som fortfarande skulle kunna användas i varelsens nya form att förbli, såsom en magisk ring eller stövlar. Notera att detta kräver att varelsens nya SIZ inte är drastiskt annorlunda från den ursprungliga. Det finns en POW x1 % chans för varje buret magiskt föremål av icke-offensiv natur, föremål för spelledarens godkännande, att överföra sina effekter till varelsens nya form. En varelse med en +1 skyddsring till exempel, skulle kunna få en +1 bonus på sina naturliga Pansarpoäng. Varelser med den naturliga förmågan att formförvandlas, såsom doppelgängers och varulvar, kommer att förvandlas som normalt, men kan anta sin naturliga form efter 1 runda. Om den dödas återgår en polymorfad varelse till sin naturliga form, även om den tidigare har förlorat alla spår av identitet.

#### Sleep

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 Handling |
| **Sfär:** Ingen | **Varaktighet:** 5 Minuter/Intensitet |
| **Kostnad:** 3, +1/ytterligare Intensitet | **Räckvidd:** 60 fot |
| **Område:** 10 fots radie | **Motstånd:** Willpower |

Denna besvärjelse orsakar en magisk dvala att falla över en levande varelse per intensitetsnivå i ett cirkulärt område med 10 fots radie. Besvärjelsens effektområde är centrerat vid en punkt i rummet eller på marken och den närmaste varelsen kan motstå först, sedan nästa närmaste, och så vidare. Där två eller fler faller på lika avstånd, avgör slumpmässigt vem som påverkas. Varje varelse tillåts ett slag för att motstå och om ett är framgångsrikt måste ett annat försöka tills totalt lika många har påverkats som besvärjelsens intensitet, eller inga fler varelser upptar effektområdet. Varelser i ett tillstånd av förhöjd vakenhet, eller i strid när besvärjelsen kastas, finner slaget att motstå en grad lättare.

Stora varelser (SIZ 21-40) är mindre mottagliga för Sleep, med motståndsslaget som enkelt, medan motståndsslaget för enorma varelser (SIZ 41+) är mycket enkelt. Mindre varelser påverkas alltid före större; därför påverkas varelser med SIZ 20 eller mindre alltid före de med SIZ 21 till 40, som själva alltid påverkas före de med SIZ 41+.

Medan de sover är påverkade varelser hjälplösa och normalt buller kommer inte att störa dem, men de kan skakas eller slås vakna. Varje anfall, förutsatt att det inte är dödligt, kommer också att få dem att vakna (även om anfallet kommer som en överraskning). Att försöka väcka en varelse tar 1 stridsrunda.
