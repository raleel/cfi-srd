## Besvärjelsebeskrivningar

#### Appraise

(Divination)

| | |
| :-- | :-- |
| **Rang:** Mage 0 | **Kasttid:** 1 Tur |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 1 | **Räckvidd:** Beröring |
| **Område:** 1 föremål | **Motstånd:** Inget |

Appraise möjliggör en omedelbar bedömning av kvaliteten på fysiska varor med en kombinerad ENC i 'saker' eller STO motsvarande besvärjarens MAK. Besvärjelsen avgör om identiskt utseende föremål är av samma eller liknande kvalitet, eller om en eller flera är defekta eller av högre kvalitet. Besvärjelsen fungerar inte på organiska ting, endast på livlösa föremål. Den avgör heller inte vilka defekter eller förbättringar som finns; bara att de existerar. Den är till ingen nytta vid identifiering eller upptäckt av magi.

#### Armor

(Conjuration)

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 runda |
| **Sfär:** Ingen | **Varaktighet:** Se nedan |
| **Kostnad:** 3 +1/Intensitet | **Räckvidd:** Beröring |
| **Område:** 1 måltavla | **Motstånd:** Inget |

När denna besvärjelse kastas begåvas subjektet med ett osynligt fält av magisk kraft motsvarande fjällpansar i skydd, vilket ger 4 pansarpoäng till varje träffområde. Den har ingen effekt om den kastas på någon som redan bär pansar. Den kommer dock att ersätta naturligt pansar under sin varaktighet, förutsatt att den erbjuder överlägset skydd. Om den kastas på en varelse som besitter mer än 4 poäng naturligt pansar, kommer den istället att öka pansarpoängen med 1 på alla platser. Detta magiska skydd hindrar inte rörelse eller besvärjelsekastande. Besvärjelsen kvarstår tills den skingras av magi, eller besvärjaren tar 8 poäng skada från en enskild attack, +1 per nivå av ytterligare Intensitet (se tabellen nedan). Naturligtvis kan besvärjaren välja att släppa besvärjelsen när som helst om så önskas och måste göra det för att sova.

| Intensitet | Kostnad | Variabel effekt |
| :-: | :-: | :-- |
| 1 | 3 | 4 pansarpoäng; kvarstår tills 8 skada tas från 1 attack |
| 2 | 4 | 4 pansarpoäng; kvarstår tills 9 skada tas från 1 attack |
| 3 | 5 | 4 pansarpoäng; kvarstår tills 10 skada tas från 1 attack |
| 4 | 6 | 4 pansarpoäng; kvarstår tills 11 skada tas från 1 attack |
| +1 | +1 | Fortsätt progression |

#### Astral Spell

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Cleric 5, Mage 5 | **Kasttid:** 2 handlingar |
| **Sfär:** Astral | **Varaktighet:** Se nedan |
| **Kostnad:** 3 +1/ytterligare Intensitet | **Räckvidd:** Beröring |
| **Område:** Se nedan | **Motstånd:** N/A |

Denna besvärjelse tillåter besvärjaren och upp till fem andra (en per ytterligare nivå av Intensitet) att träda in i Astralplanet. Alla måste vidröra och bilda en cirkel medan besvärjelsen kastas. De resandes kroppar lämnas kvar i ursprungsplanet, och de tar vanligtvis inte med sig några kläder eller utrustning, förutom det som i sig utstrålar en magisk aura; dessa föremål förvandlas till astrala motsvarigheter av sin normala form. Varaktigheten varar tills besvärjaren önskar att den ska upphöra. Det är dock möjligt för den att avslutas i förtid av en extern kraft såsom Dispel Magic. Att döda besvärjarens fysiska kropp avslutar också besvärjelsen tidigt, även om detta har den olyckliga bieffekten att lämna alla resande som följer med besvärjaren strandade.

#### Augury

(Divination)

| | |
| :-- | :-- |
| **Rang:** Cleric 2 | **Kasttid:** 2 minuter |
| **Sfär:** Divination | **Varaktighet:** Omedelbar |
| **Kostnad:** 3/Intensitet | **Räckvidd:** 60 fot |
| **Område:** Besvärjare | **Motstånd:** N/A |

Denna besvärjelse tillåter besvärjaren att avgöra om en specifik åtgärd som ska vidtas inom de närmaste 30 minuterna kommer att vara fördelaktig eller skadlig för en individs och/eller grupps välbefinnande. En fokuspunkt av något slag krävs för att urskilja omenen, där de vanligaste är klor eller mindre ben från en drake, en pärla eller rent guld värt minst 100 GP, som har krossats eller smälts ner. Besvärjelsen har en maximal Intensitet på 4. Detta slag bör göras av Games Master, eftersom besvärjaren aldrig med säkerhet bör veta om resultaten tolkades korrekt.

| Intensitet | Kostnad | Variabel effekt |
| :-: | :-: | :-- |
| 1 | 3 | Formidabelt Channel-färdighetsslag |
| 2 | 6 | Svårt Channel-färdighetsslag |
| 3 | 9 | Standard Channel-färdighetsslag |
| 4 | 12 | Enkelt Channel-färdighetsslag |

Om divinationsslaget lyckas ger det ett av följande resultat:

| Augury | Innebörd | 
| :-: | :-- |
| Ja | Åtgärden kommer att vara fördelaktig |
| Nej | Åtgärden kommer att vara skadlig |
| Ja och nej | Åtgärden kommer att vara både fördelaktig och skadlig |
| Ingenting | Åtgärden kommer att vara varken fördelaktig eller skadlig |

En Fumble bör resultera i att Games Master säger motsatsen till verkligheten.

#### Befuddle

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Cleric 0, Mage 0 | **Kasttid:** 1 Tur |
| **Sfär:** Charm | **Varaktighet:** 30 minuter |
| **Kostnad:** 1 | **Räckvidd:** 60 fot |
| **Område:** 1 måltavla | **Motstånd:** Willpower |

Befuddle orsakar förvirring i sinnet hos ett kroppsligt mål. Subjektet för besvärjelsen har svårt att tänka klart, glömmer var det är, vad det gör och varför – ofta genom att falla in i associationsfria tankegångar. Förvirrade mål kan fortfarande agera i självförsvar men kan inte inleda någon konstruktiv aktivitet förrän besvärjelsen upphör. Varje form av attack eller hotfull handling bryter omedelbart besvärjelsen, oavsett om den var riktad specifikt mot det förvirrade målet eller inte.

#### Blade Barrier

(Evocation)

| | |
| :-- | :-- |
| **Rang:** Cleric 4 | **Kasttid:** 2 handlingar |
| **Sfär:** Guardian, Creation | **Varaktighet:** 3 rundor/Intensitet |
| **Kostnad:** 3+1/ytterligare Intensitet | **Räckvidd:** 100 fot |
| **Område:** 5-30 fots radie | **Motstånd:** Se nedan |

Denna besvärjelse skapar en barriär av virvlande, skärande svärd, dolkar och knivar som piskar och hugger runt en fixerad punkt och orsakar 1d8 poäng skada på 1d4+2 slumpmässiga träffområden för *alla* som passerar genom effektområdet. Pansar erbjuder endast hälften av sitt normala skydd. Magiska pansarpoäng minskar skada som vanligt. Eftersom vapnen virvlar runt med bländande hastighet och är tätt packade är det omöjligt att parera eller undvika dem. Man kan använda en sköld för att passivt blockera träffområden normalt. I detta fall, kom ihåg att jämföra den rullade skadan med pansaret och träffpoängen för skölden.

Besvärjelsen kan kastas defensivt för att skydda prästen eller en eller flera allierade, eller offensivt för att fånga fiender. Fiender som är omringade inom fem fot från barriärens kant när den bildas kan dock göra ett Evade-slag för att fly. Oavsett framgång hamnar motståndaren liggande, precis utanför effektområdet. Ett lyckat slag resulterar i ingen skada; annars lider de full effekt.

#### Bless \(R\)

(Conjuration)

| | |
| :-- | :-- |
| **Rang:** Cleric 1 | **Kasttid:** 1 runda |
| **Sfär:** Alla | **Varaktighet:** 5 minuter |
| **Kostnad:** 1 | **Räckvidd:** 180 fot |
| **Område:** 25 fots radie | **Motstånd:** Willpower |

När denna besvärjelse kastas välsignar prästen en grupp allierade inom effektområdet. De som påverkas utstrålar besvärjarens inriktning, antingen God eller Ond. Det finns inga välsignelser av neutralitet. Alla allierade inom besvärjelsens radie får en bonus på +5% på alla färdighets- och motståndsslag. Dessutom orsakar deras vapen +1d3 skada på intelligenta odöda samt varelser från de yttre planen som har motsatta inriktningar mot besvärjarens, såsom demoner, djävlar eller änglar. Notera att även om animerade odöda såsom skelett och zombier inte är inneboende onda, är de vanligtvis animerade av ond magi och därmed föremål för denna skada.

Den omvända versionen av denna besvärjelse, Curse, tillåter prästen att förbanna fiender, vilket gör att de noterade färdigheterna lider av motsatsen till de fördelar som noterats ovan. Ett förbannat vapens skada beräknas som en straffavgift istället, och denna skada kan inte resultera i mindre än 1 poäng.

#### Burning Hands

(Transmutation)

| | |
| :-- | :-- |
| **Rang:** Mage 1 | **Kasttid:** 1 handling |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 3+1/ytterligare Intensitet | **Räckvidd:** 0 |
| **Område:** 120-graders kon, 5 fot lång | **Motstånd:** Evade |

Denna besvärjelse gör att flammor skjuter ut från besvärjarens händer i en 120-graders båge. Om du använder miniatyrer i strid kommer Burning Hands att skada varje måltavla som upptar 1 av besvärjarens främre rutor. Att kasta Burning Hands på högre intensitetsnivåer kräver en mage av högre rang. Denna skada uppslukar alla måltavlor inom området med skada baserad på besvärjelsens intensitet, upp till en maximal intensitet på 9, enligt följande. Ett lyckat Evade-slag, där man kastar sig ned, gör att offret inte lider någon skada. Någon med förmågan Artful Dodger har möjlighet att undvika utan att kasta sig ned.

| Intensitet | Kostnad | Min Rang | Variabel effekt |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 poäng skada på alla träffområden |
| 3 | 4 | 1 | 1d3+2 poäng skada på alla träffområden |
| 5 | 5 | 1 | 1d3+3 poäng skada på alla träffområden |
| 7 | 6 | 2 | 1d3+4 poäng skada på alla träffområden |
| 9 | 7 | 3 | 1d3+5 poäng skada på alla träffområden |

Buret pansar skyddar inte, men magiska pansarpoäng eller en varelses naturliga pansar minskar skada som vanligt. Denna kraftfulla besvärjelse balanseras av dess märkbart korta räckvidd, vilket innebär att magianvändaren måste vara tillräckligt nära för att befinna sig i en mycket ogynnsam position.

Eftersom större varelser vanligtvis är större än besvärjelsens effektområde, tenderar de att ha färre påverkade träffområden. De med STO 21 till 30 tar skada på huvud, bröst, buk och armar, medan de med STO 31+ tar skada på buk och ben. Games Masters bör justera dessa platser beroende på måltavlans form och position i förhållande till besvärjaren. Burning Hands har en chans att antända brännbara material motsvarande den rullade skadan x 5%. Se avsnittet om [Eld](0007_Game_System.md?id=fire-based-attacks) för ytterligare information.

#### Calm

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rang:** Cleric 0 | **Kasttid:** 1 handling |
| **Sfär:** Charm | **Varaktighet:** Omedelbar |
| **Kostnad:** 1 | **Räckvidd:** Beröring |

- **Flyg:** Subjektet flaxar med armarna och springer i cirklar.
- **Gå:** Subjektet börjar gå i den riktning det var vänt.
- **Stanna:** Subjektet stannar omedelbart och står stilla.
- **Lämna:** Subjektet vänder sig om och lämnar genom vägen det kom in.
- **Vila:** Subjektet sätter sig ner och hämtar andan.
- **Spring:** Subjektet börjar springa.
- **Skrik:** Subjektet ropar.
- **Sjunk:** Subjektet slutar simma.
- **Ge upp:** Subjektet släpper sina vapen och upphör med fientligheter.

Att kasta denna besvärjelse förbereder ett föremål för Förtrollning. Objektet måste vara i gott skick och av finaste konstruktion och utförande. En extra kostnad på minst 100 GP krävs för att täcka kostnaden för extra verktyg, snideri, broderi, juvelinfattning, gravering och så vidare. Vid inget tillfälle under kastandet får magikern kasta en annan besvärjelse eller utföra någon annan form av magi. Att bryta mot någon av dessa föreskrifter gör att besvärjelsen automatiskt misslyckas.

För att göra detta måste de ha besvärjelsen i minnet eller på en rulle och kasta den in i föremålet inom 24 timmar, annars måste hela processen påbörjas från början. Under hela processen måste besvärjaren förbli i kontakt med föremålet eller förbli inom räckhåll under viloperioder, som ovan, och ett slag för Arkant kastande krävs i slutet av kastperioden för att framgångsrikt genomsyra besvärjelsen. De normala graderna av framgång för besvärjelser följs, dock, när det gäller ett resultat av misslyckande, kan besvärjelsen inte tvingas fram. Efterföljande besvärjelser kan genomsyras i föremålet, förutsatt att kastprocessen påbörjas inom 24 timmar efter att den föregående besvärjelsen slutförts. Detta gäller även i fallet med en tidigare misslyckad besvärjelse. Varje efterföljande besvärjelse kräver den normala Kastkostnaden.

När föremålet används kan varje besvärjelse som finns däri kastas endast en gång, dock kan flera versioner av samma besvärjelse genomsyras genom att följa ovanstående procedur. Det är också möjligt att genomsyra en enskild besvärjelse, följt av en kastning av grad 4-besvärjelsen Permanency. I detta fall kan besvärjelsen kastas så ofta som önskas, enligt de begränsningar som anges under besvärjelsebeskrivningen för Permanency.

Det är inte möjligt att genomsyra andra magiska effekter i ett föremål som inte överensstämmer med en specifik besvärjelse, och många magiska föremål från svunna tider kan helt enkelt inte återskapas i dagens tidsålder.

Denna besvärjelse skapar en sköld av fladdrande lågor som omsluter kastaren men inte orsakar någon skada i sig. #### Identifiera

(Spådom)

| | |
| :-- | :-- |
| **Grad:** Magiker 1 | **Kasttid:** 1 minut |
| **Sfär:** Skydd | **Varaktighet:** 1 minut/intensitet |
| **Kostnad:** 1/intensitet | **Räckvidd:** 0 |

Genom att kasta denna besvärjelse kan magikern försöka identifiera de magiska egenskaperna (om några) hos ett hanterat föremål eller objekt. Denna besvärjelse skapar en visuell illusion av vad kastaren än önskar. Den har ingen effekt på andra sinnen, vilket innebär att den inte skapar något ljud, inte producerar någon doft, temperatur eller textur, och så vidare.

Denna illusion kan vara allt från en öppen äng till en uråldrig röd drake, om den ryms inom besvärjelsens område. När besvärjelsen har kastats kan ytterligare visuella effekter läggas till av magikern efter behag genom att koncentrera sig på önskad effekt. Detta tar vanligtvis ingen tid och kan hanteras som en fri handling. Så, till exempel, om kastaren ville att en tappad illusionär fackla skulle få torra löv att se ut att fatta eld, kunde kastaren koncentrera sig som en fri handling för att göra så.

#### Magic Missile

(Evokation)

| | |
| :-- | :-- |
| **Grad:** Magiker 1 | **Kasttid:** 1 handling |
| **Sfär:** Ingen | **Varaktighet:** Omedelbar |
| **Kostnad:** 1/Intensitet | **Räckvidd:** 100 fot/intensitet |
| **Område:** 1-5 mål | **Motstånd:** Se nedan |

När denna besvärjelse kastas skjuter en eller flera missiler av magisk energi fram från magikerns fingertoppar och träffar ett mål. Det maximala antalet missiler som kan genereras baseras på utövarens färdighetsnivå i Arcane Casting, där en andra missil genereras vid 60 % färdighet, en tredje vid 70 %, en fjärde vid 80 % och en femte och sista missil vid 90 %. För att generera dessa missiler måste besvärjelsen kastas med en intensitet lika med antalet önskade missiler. Till exempel, under 60 %, skulle en magiker som kastar Magic Missile med 3 intensitet uppnå den längre räckvidden, men endast en enstaka missil skulle genereras. En magiker med 70 % färdighet kan kasta besvärjelsen med samma 3 intensitet och uppnå samma räckvidd men kunna generera 3 missiler. Denna besvärjelse har en maximal intensitet på 5. Se tabellen nedan.

En Magic Missile träffar ofelbart, även om målet är i närstrid eller har delvis skydd. Dessa missiler kan inte undvikas; dock kan en motståndare i totalt skydd inte målas med denna besvärjelse. Shield-besvärjelsen kommer automatiskt att avlänka Magic Missiles förutsatt att målet är medvetet om och/eller vänt mot utövaren. Magic Missiles gör 1t6+1 poängs skada och buren rustning skyddar inte, men en varelses naturliga rustning eller magiska rustningspoäng minskar skadan som vanligt. Magic Missiles orsakar ingen skada på livlösa föremål såsom dörrar, lås och så vidare.

När man skjuter flera missiler kan utövaren låta dem träffa en enstaka varelse eller rikta dem mot flera varelser. Varje Magic Missile kommer att träffa ett slumpmässigt träffområde - specifika träffområden kan inte väljas. Utövaren måste utse individuella mål för varje missil innan de slår för skada.

#### Magic Mouth

(Transmutation)

| | |
| :-- | :-- |
| **Grad:** Magiker 2 | **Kasttid:** 1 minut |
| **Sfär:** Ingen | **Varaktighet:** Se nedan |
| **Kostnad:** 3, +1/ytterligare intensitet | **Räckvidd:** 30 fot |
| **Område:** 1 föremål | **Motstånd:** NA |

Denna besvärjelse skapar en mun på ett föremål eller objekt, som magiskt visas när den utlöses av en specifik händelse eller tid som utsetts av magikern när besvärjelsen först kastas. Denna mun kommer sedan att tala den fördefinierade fras som utövaren valde vid tidpunkten för kastandet. Denna fras får bestå av högst 25 ord och sägs av munnen med en hastighet av ungefär 1 ord per sekund. Munnen får inte tala kraftens ord eller kasta besvärjelser.

Denna besvärjelse kan kastas på vilket normalt livlöst föremål som helst, från en pelare eller ett träd till en stenvägg eller en kista; den är dock särskilt effektiv när den kastas på en staty, eftersom statyn själv skulle se ut som om den talade. När magikern kastar denna besvärjelse avgör utövaren situationen som kommer att aktivera förtrollningen. Den kan utformas för att utlösas via allt från ett talat ord till skapandet av något ljud. Det kan vara så generellt som "när nästa person går in i detta rum..." till så specifikt som "när en kvinnlig klerk från Sedona kommer inom 10 fot från statyn i slutet av hallen på en lördag...". Den utlösande effekten kan inte vara något som inte kan urskiljas icke-magiskt, såsom en osynlig varelse, en varelses inriktning, färdighet, klass, etc. Den kan dock ange buren klädsel. Det maximala avståndet som besvärjelsen kan utlösas på är 25 fot per intensitet.

Besvärjelsens varaktighet är permanent tills förtrollningen aktiveras och sedan avslutas besvärjelsen.

#### Förvandla annan

(Transmutation)

| | |
| :-- | :-- |
| **Grad:** Magiker 3 | **Kasttid:** 2 handlingar |
| **Sfär:** Ingen | **Varaktighet:** Permanent |
| **Kostnad:** 3, +1 per ytterligare intensitet (+1 ERF) | **Räckvidd:** 15 fot/intensitet |
| **Område:** 1 mål | **Motstånd:** Viljestyrka |

Kastaren kan ändra formen på en kroppslig målvarelse till en annan, där varje intensitetspoäng ändrar STO med upp till 5 poäng. Att förvandla en ork med STO 16 till en kanin med STO 1 skulle alltså kräva 3 intensitetsnivåer (15 poängs STO-skillnad). Målet för denna besvärjelse tillåts ett slag för Viljestyrka för att motstå. Stora varelser (STO 21-40) är mindre mottagliga för att bli förvandlade, med deras motståndsslag som Enkelt, medan motståndsslaget för Enorma varelser (STO 41+) är Mycket enkelt.

Hela förvandlingsprocessen tar en full runda och kan vara mycket stressande för varelsen i fråga, vilket kräver ett andra slag för Viljestyrka för att behålla sin ursprungliga personlighet, där ett misslyckande bedövar subjektet i 1d10 minuter och ett fummel resulterar i döden av mental chock. Varje fördubbling eller halvering av varelsens ursprungliga STO gör slaget för Viljestyrka för att behålla personligheten en svårighetsgrad svårare, liksom en fullständig miljöförändring, såsom att förvandla en person till en fisk. Ett lyckat slag tillåter offret att behålla sin INT och KAR samt alla färdigheter som kräver dessa egenskaper.

Förvandlingen ger mottagaren den antagna varelses form av andning, om den skiljer sig från det normala; alla naturliga attacker; och alla vardagliga rörelseformer. Den ger inga förhöjda eller magiska förmågor som varelsen besitter. Till exempel får en varelse som förvandlats till en drake inte drakens andningsattack eller besvärjelselika förmågor, men får förmågan att flyga, dess hårda hud, dödliga bett, kloattacker och så vidare. Dessutom vinner offret den nya formens fysiska färdigheter såsom Atletik, Muskelstyrka, Flyga, Simma, samt dess träffpoäng och skademodifikator. Förutsatt att den förvandlade individen behöll sin INT, förlorar hen fortfarande förmågan att tala, såvida inte den nya formen besitter förmågan att formulera ord. De som kunde kasta besvärjelser i sin tidigare form skulle fortfarande kunna kasta i den nya formen, förutsatt att de fortfarande besitter förmågan att producera de verbala och somatiska komponenterna. Vid en drastisk förändring, såsom från tvåbent till fyrbent, eller landdjur till havsdjur, bör Spelledaren känna sig fri att bestraffa med minst en svårighetsgrad användningen av färdigheter som skulle ta tid att lära sig under anpassningen till den nya formen, tills tillräckligt med tid för övning funnits. Detta gäller särskilt fysiska färdigheter såsom Atletik, Obeväpnad strid, Simma, Flyga, Stridskonster och så vidare.

Slaget för Viljestyrka för att behålla sin personlighet krävs varje dag som subjektet förblir förvandlat tills det misslyckas, vilket får personen att slutligen ge efter för den nya formens mentalitet, där INT ändras till INS om det är en icke-sapiens varelse. Alla speciella och magiska förmågor som ägs av den nya formen och som inte förvärvats tidigare, såsom blickattacker, andningsvapen och så vidare, är nu tillgängliga för varelsen när förvandlingen är komplett. Karaktärer som förlorar sin identitet på detta sätt blir SLP under Spelledarens kontroll.

Innan offret mentalt ger efter för förvandlingen är den förvandlade varelsen mottaglig för Skingra magi som vanligt, utan att något motståndsslag krävs, eftersom det skulle vara ens undermedvetna önskan att återgå till det normala. Förvandlingen kräver dock ett annat slag för Viljestyrka för att motstå ansträngningen, där ett misslyckande bedövar subjektet i 1d10 minuter och ett fummel resulterar i döden av mental chock.

Om offret tidigare hade gett efter för den nya formen kan Skingra magi fortfarande användas; offret kommer dock att försöka motstå att återgå till den naturliga formen med ett slag för Viljestyrka. Att misslyckas med detta slag innebär att offret förvandlas tillbaka till den naturliga formen, vilket naturligtvis kräver ett nytt slag för Viljestyrka för att motstå den mentala chocken från förvandlingen. När den väl gått förlorad kan offrets naturliga identitet inte längre nås, istället antar offret att den märkliga och främmande formen är naturlig och längtar efter att återföras till sitt tidigare 'normala'. _Till exempel skulle en ork som förvandlats till en kanin och antagit varelsens identitet tro att den nu är en kanin som blivit ganska ohövligt förvandlad till en ork._ Endast en Önskan, eller annan liknande magi, har någon chans att återställa offrets identitet när den väl gått förlorad.

All buren och medförd utrustning smälter magiskt in i den nya formen; i vissa fall kan dock Spelledaren tillåta att magiska föremål som fortfarande skulle kunna användas i varelsens nya form förblir, såsom en magisk ring eller stövlar. Notera att detta kräver att varelsens nya STO inte skiljer sig väsentligt från originalet. Det finns en chans på MAK x1% för varje buret magiskt föremål av icke-offensiv natur, föremål för Spelledarens godkännande, att överföra sina effekter till varelsens nya form. En varelse med en skyddsring +1 kan till exempel få en bonus på +1 på sina naturliga pansarpoäng. Varelser med naturlig förmåga att byta form, såsom hamnskiftare och varulvar, förvandlas som vanligt, men kan återta sin naturliga form efter 1 runda. Om den dödas återgår en förvandlad varelse till sin naturliga form, även om den tidigare förlorat alla spår av identitet.

| :-: | :-: | :-- |
| 1 | 3, +1 ERF | 15 fots räckvidd; 1-5 poängs STO-skillnad |
| 2 | 4, +1 ERF | 30 fots räckvidd; 6-10 poängs STO-skillnad |

#### Uppståndelse (R)

(Nekromanti)

| | |
| :-- | :-- |
| **Grad:** Präst 5 | **Kasttid:** 10 minuter |
| **Sfär:** Nekromantisk | **Varaktighet:** Permanent |
| **Kostnad:** 3, +1/ytterligare Intensitet, +2 ERF | **Räckvidd:** Beröring |
| **Område:** 1 Mål | **Motstånd:** NA (Viljestyrka) |

*Uppståndelse* väcker alla varelser till liv som varit döda i högst 20 år per nivå av Intensitet. Varelsen ges inte bara liv, utan återställs till full styrka och läks från skador, och till och med förlorade lemmar återställs. Lite av den faktiska varelsen behöver finnas kvar för att besvärjelsen fortfarande ska vara effektiv. Till exempel kan *Uppståndelse* användas för att väcka en varelse från de döda efter 145 år, även om man inte har något annat än ett fingerben, förutsatt att besvärjelsen kastas med 8 i Intensitet. Den uppväckta individen kräver ingen viloperiod och är fullt fungerande omedelbart. Besvärjelsen har ingen effekt på en varelse som dött av naturliga orsaker vid slutet av sin tilldelade livslängd.

Om subjektets Anpassning var något annat än ond, kan de motstå besvärjelsen med ett Motstående Viljestyrka-slag och, om de lyckas, upphäva effekterna. Detta beror på att den avlidnes själ eller ande sällan är villig att återvända till de levande när den väl har nått sin eviga belöning. Spelledaren kan dock välja att efterskänka slaget om mottagaren har oavslutade affärer, inte kan skiljas från sin sanna kärlek eller har någon annan heroisk anledning att leva. I fallet med onda själar, som gärna skulle återvända istället för att lida evig fördömelse, är det inte den avlidnes Viljestyrka som gör motstånd, utan den hos demonen, djävulen eller liknande som ansvarar för deras straff, deras plågoande. I detta fall måste kastaren övervinna plågoandens Viljestyrka. Om denna är okänd, anta att den är minst 20 poäng högre än den avlidnes för att representera att ju starkare själens vilja är, desto mäktigare är den varelse som ansvarar för hans eller hennes fördömelse. Om kastaren lyckas, har subjektet framgångsrikt återuppstått, medan ett misslyckat slag resulterar i att offret antingen är ovilligt eller oförmöget att återvända.

*Uppståndelse* är mycket dränerande och åldrar prästen 3 % av deras typiska livslängd (3 år i fallet med en mänsklig kastare). Se reglerna för [Åldrande](0007_Game_System.md?id=aging).

När den vänds, kan *Förstörelse* användas för att döda ett offer som är i kontakt med prästen vid tidpunkten för kastandet. Detta offer tillåts ett Viljestyrka-slag för att motstå, modifierat av målets Grad eller STO, beroende på vilket som ger offret det mer fördelaktiga resultatet, som beskrivs i följande tabell.

| :-: | :-: | :-- |
| 0-1* | 1-20 | Formidabel |
| 2 | 21-40 | Svår |
| 3 | 41-60 | Standard |
| 4 | 61-80 | Enkel |
| 5 | 81+ | Mycket enkel |

_* Denna kategori inkluderar karaktärer som inte innehar en Klass._

Vid ett lyckat slag reduceras subjektet ändå till minus 1t4 Träffpoäng i den vidrörda Träffplatsen. Rustning ger inget skydd mot denna skada. *Förstörelse* åldrar inte kastaren när den används.

Denna besvärjelse tillåter besvärjaren att frammana en vägg eller cirkel av flammande eld, enligt önskemål vid kasttillfället, brinnande i en lila eller rödblå färg. Besvärjelsens varaktighet kvarstår om koncentration bibehålls, eller i 1 runda per intensitet när koncentrationen upphör. Detaljerna specificeras nedan beroende på typ:

**Wall of Fire:** Denna version av besvärjelsen skapar en stationär eldvägg 20 fot lång per intensitet. Oavsett slutlig intensitet har väggen en höjd på 10 till 20 fot enligt önskemål vid kast. Wall of Fire har en räckvidd på 180 fot och får inte frammanas horisontellt.

Sidan av väggen eller cirkeln som vätter bort från besvärjaren avger en brännande hetta, vilket orsakar 1d6 skada per runda till alla inom 10 fot, och 1d4 skada ut till 20 fot. Denna skada tillämpas vanligtvis i slutet av rundan innan man går vidare till nästa. Om ett offer upptar båda hettazoner under en enda runda tillämpas den högre skadan. Denna skada tillämpas på varje träffområde och buren rustning erbjuder inget skydd, men magiska rustningspoäng eller en varelses naturliga rustning minskar skadan som vanligt. Ett lyckat "Undvika"-motståndsslag tillåter offret att inte lida någon skada under den runda besvärjelsen uppstår, när offret försöker kasta sig bort från hettan eller förbi flammorna. Eldlevande varelser tar hälften av denna skada och köldlevande varelser dubbelt. Flammorna har en chans att antända brännbara material lika med den rullade skadan x 5 %. Denna besvärjelse får långa trådar av klibbig väv att skjuta ut från besvärjarens hand, vilka kan förankras från golv till tak, eller vägg till vägg, för att blockera en passage eller hindra framfart. Den kan också sprutas direkt på motståndare för att snärja dem.

Förutsatt att målet har utrymme att undkomma väven placerar ett lyckat Undvika-slag målet utanför effektområdet; detta kräver dock att en handlingspoäng finns tillgänglig. Ett misslyckat motståndsslag lämnar offret immobiliserat och 1d3 träffområden snärjda. Magisk väv är otroligt stark och klibbig, med 6 rustningspoäng och träffpoäng lika med 3x besvärjelsens intensitet. Att försöka bryta sig fri kräver att offret vinner ett motstående slag i Styrka mot vävens klibbighet (lika med besvärjarens färdighet i Arkant kastande). Om detta misslyckas förblir målet fastgjort, oförmöget att bryta sig fri genom enbart styrka. Att försöka skära sig fri utsätter verktyget eller vapnet som används för samma process. Trots populär tro är väv inte brännbar, men en karaktär kan långsamt bränna en väg genom en väv genom att använda en flamma för att få trådarna att skrumpna (eldskada ignorerar vävens rustningspoäng).

Wish kan förändra verkligheten på ett permanent och betydande sätt. För att kasta denna besvärjelse måste magianvändaren spendera 3 magipoäng och 1 eller fler ERF-rullningar beroende på önskat resultat. #### Word of Recall

(Transmutation)

| | |
| :-- | :-- |
| **Grad:** Kleriker 4 | **Kasttid:** 1 handling |
| **Sfär:** Frammaning | **Varaktighet:** Se nedan |
| **Kostnad:** 3, +1/ytterligare intensitet | **Räckvidd:** 0 |
| **Område:** Besvärjaren | **Motstånd:** NA |

När denna besvärjelse kastas blir klerikern omedelbart teleporterad till en förutbestämd fristad, och en utsedd ankomstpunkt inte större än 10 fots radie. Det finns ingen gräns för den faktiska räckvidden som teleporteras, inklusive mellan flera plan. Inom ett enskilt plan finns ingen risk för missöden, dock ger det att korsa även ett plan en fummelchans på 91-00 %, två plan ger fummel på ett slag på 81-00 %, och så vidare. Detta ersätter besvärjarens normala fummelchans. Ett fummel vid korsande av plan innebär att klerikern är oåterkalleligen vilse. Fummel inom ett enskilt plan följer de normala reglerna.

Utöver sig själv och buren utrustning kan klerikern transportera ytterligare 3 föremål per intensitet, vardera inte större än STO/9 "saker". Det ytterligare materialet som transporteras kan vara skatter, utrustning eller levande varelser. Transportade varelser måste dock ha besvärjelsen kastad på en tillräcklig intensitetsnivå för att täcka all buren utrustning.
