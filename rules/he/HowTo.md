3. באפשרותך לבצע את כל התהליך דרך הדפדפן מבלי לדעת גיט. עם זאת, לימוד Github Desktop יאפשר לך לבדוק כל שינוי באופן מקומי לפני העלתו לאוויר עבור כל העולם.

> אם יש לך שם דומיין רשום, תוכל להשתמש בו בתהליך זה כדי ליצור SRD כמו זה שיצרתי: https://srd.7thextinctionrpg.com

## הוספת התוכן שלך

### קבצי *.md

קבצי .md הם קבצי מארקדאון. מארקדאון היא שפת סימון קלה שבה ניתן להשתמש כדי להוסיף אלמנטים עיצוביים למסמכי טקסט פשוטים. בהתאם לגודל התוכן שלך, תוכל להציב את כל מידע המשחק בקובץ *.md יחיד, או ליצור קבצים נפרדים לכל פרק, כפי שעשיתי ב-[7thextinctionrpg.com](https://srd.7thextinctionrpg.com). הקובץ "sample.md" מספק כמה דוגמאות לעיצוב.

שפת המארקדאון קלה מאוד ללימוד; השתמש בקישור המופיע בנקודה 2 תחת "דרישות מוקדמות" לעיל לקבלת רשימה מלאה של התחביר.

### _Sidebar.md

זהו התפריט שלך, חלונית הניווט בצד שמאל של האתר. ברגע שהוספת קובץ מארקדאון למאגר שלך, עליך להוסיף את הקובץ לכאן כדי שתכניו ייכללו. פעל לפי העיצוב הקיים.

## שימוש בתוספי Fontawesome ו/או Material Icons להצגת אייקונים בחינם ב-SRD שלך

### Fontawesome

השתמש ב-Fontawesome כדי לקבל אייקונים בחינם ואייקונים מונפשים. משתמשים רשומים יכולים להשתמש ב-Pro Icons.

1. מצא את האייקון ב-[Fontawesome](https://fontawesome.com/icons)
2. בחר את האייקון.
3. בחלון הקופץ, תחת לשונית ה-HTML העתק את כל מה שבין ה-" "

```EXAMPLE
<i מעמד="fa-solid fa-dice-d20"></i>
```

4. הצב את הטקסט שהועתק בין `:` ללא רווחים

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

השתמש ב-Material Icons עבור עוד אייקונים בחינם.

1. מצא את האייקונים ב-[Material Icons](https://fonts.google.com/icons)
2. העתק והכנס את קישור ה-span ישירות לתוך קבצי המארקדאון שלך

```markup
<span מעמד="material-icons">face</span>
```
