# דרישות מוקדמות

1. הבנה בסיסית של [שפת המרקדאון](https://www.markdownguide.org/basic-syntax/).

2. תצטרך ליצור חשבון [GitHub](https://github.com/) חינמי אם אין לך כזה. אנו ממליצים להשתמש בשם משחק התפקידים שלך, כיוון שהוא יהפוך לחלק מכתובת ה-URL שבה אנשים ישתמשו כדי לגשת ל-SRD שלך.

3. ניתן לבצע את כל התהליך הזה דרך הדפדפן מבלי לדעת git. עם זאת, למידת GitHub Desktop תאפשר לך לבדוק שינויים באופן מקומי לפני פרסומם החי לעולם.

> אם יש לך שם דומיין רשום, תוכל להשתמש בו בתהליך זה כדי ליצור SRD כמו זה שיצרתי בכתובת https://srd.7thextinctionrpg.com

## הוספת התוכן שלך

### קבצי *.md

קבצי .md הם קבצי מרקדאון. מרקדאון היא שפת סימון קלה שניתן להשתמש בה כדי להוסיף אלמנטים עיצוביים למסמכי טקסט פשוטים. בהתאם להיקף התוכן שלך, תוכל להציב את כל המידע של המשחק שלך בקובץ *.md יחיד, או ליצור קבצים נפרדים לכל פרק, כפי שעשיתי ב-[7thextinctionrpg.com](https://srd.7thextinctionrpg.com). הקובץ "Sample.md" מספק מספר דוגמאות עיצוב.

שפת המרקדאון קלה מאוד ללמידה; השתמש בקישור המופיע בסעיף 2 תחת "דרישות מוקדמות" לעיל לרשימה מלאה של התחביר.

### _sidebar.md

זהו התפריט שלך, חלונית הניווט בצד שמאל של האתר. לאחר שהוספת קובץ מרקדאון למאגר שלך, עליך להוסיף את הקובץ לכאן כדי שתכניו ייכללו. עקוב אחר העיצוב הקיים.

## שימוש בתוסף Fontawesome ו/או Material Icons כדי להציג סמלים בחינם ב-SRD שלך

### Fontawesome

השתמש ב-Fontawesome כדי לקבל סמלים בחינם וסמלים מונפשים. משתמשים רשומים יכולים להשתמש בסמלי Pro.

1. מצא את הסמל ב-[Fontawesome](https://fontawesome.com/icons)
2. בחר את הסמל
3. בחלון הקופץ, תחת לשונית ה-HTML העתק את כל מה שבין " "

```EXAMPLE
<i מעמד="fa-solid fa-dice-d20"></i>
```

4. מקם את הטקסט שהועתק בין `:` ללא רווחים

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

השתמש ב-Material Icons עבור סמלים נוספים בחינם

1. מצא את הסמלים ב-[Material Icons](https://fonts.google.com/icons)
2. העתק והכנס את קישור ה-web span ישירות לקבצי המרקדאון שלך

```markup
<span מעמד="material-icons">face</span>
```
