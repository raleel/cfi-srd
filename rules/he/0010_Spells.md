#### הערכה (Appraise)

(חיזוי - Divination)

| | |
| :-- | :-- |
| **דרגה:** קוסם 0 | **זמן הטלה:** תור 1 |
| **ספירה:** ללא | **משך:** מיידי |
| **עלות:** 1 | **טווח:** מגע |
| **אזור:** פריט 1 | **התנגדות:** ללא |

הערכה מאפשרת הערכה מיידית של איכות מוצרים פיזיים עם ENC משולב ב'דברים' (Things) או גודל (SIZ) השווה ל-POW של המטיל. הלחש קובע האם פריטים שנראים זהים הם בעלי איכות זהה או דומה, או אם אחד או יותר פגומים או בעלי איכות גבוהה יותר. הלחש אינו עובד על דברים אורגניים, אלא רק על חפצים דוממים. הוא גם לא קובע אילו פגמים או שיפורים קיימים; רק שהם קיימים. אין לו שימוש בזיהוי או גילוי קסם.

#### שריון (Armor)

(כישוף - Conjuration)

| | |
| :-- | :-- |
| **דרגה:** קוסם 1 | **זמן הטלה:** סיבוב 1 |
| **ספירה:** ללא | **משך:** ראה להלן |
| **עלות:** 3 + 1 לכל דרגת עוצמה | **טווח:** מגע |
| **אזור:** מטרה 1 | **התנגדות:** ללא |

כאשר לחש זה מוטל, המטרה מקבלת שדה בלתי נראה של כוח קסום השווה לשריון קשקשים בהגנה, המעניק 4 נקודות שריון לכל מיקום פגיעה. אין לו השפעה אם הוא מוטל על מישהו שכבר לובש שריון. עם זאת, הוא יגבר על שריון טבעי למשך משכו, בהנחה שהוא מציע הגנה מעולה. אם מוטל על יצור בעל יותר מ-4 נקודות שריון טבעי, הוא יגדיל במקום זאת את נקודות השריון ב-1 בכל המיקומים. הגנה קסומה זו אינה מפריעה לתנועה או להטלת לחשים. הלחש יימשך עד שיפורק על ידי קסם, או שהמטיל יספוג 8 נקודות נזק מהתקפה בודדת, +1 לכל רמה של עוצמה נוספת (ראה הטבלה להלן). כמובן שהמטיל יכול לבחור להסיר את הלחש בכל עת אם ירצה, וחייב לעשות זאת כדי לישון.

| עוצמה | עלות | השפעה משתנה |
| :-: | :-: | :-- |
| 1 | 3 | 4 נקודות שריון; נמשך עד ספיגת 8 נזק מהתקפה אחת |
| 2 | 4 | 4 נקודות שריון; נמשך עד ספיגת 9 נזק מהתקפה אחת |
| 3 | 5 | 4 נקודות שריון; נמשך עד ספיגת 10 נזק מהתקפה אחת |
| 4 | 6 | 4 נקודות שריון; נמשך עד ספיגת 11 נזק מהתקפה אחת |
| +1 | +1 | המשך התקדמות |

#### לחש אסטרלי (Astral Spell)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** כהן 5, קוסם 5 | **זמן הטלה:** 2 פעולות |
| **ספירה:** אסטרלית | **משך:** ראה להלן |
| **עלות:** 3 + 1 לכל עוצמה נוספת | **טווח:** מגע |
| **אזור:** ראה להלן | **התנגדות:** לא ישים |

לחש זה מאפשר למטיל ועד חמישה אחרים (אחד לכל רמה נוספת של עוצמה) להיכנס למישור האסטרלי. כולם חייבים לגעת וליצור מעגל בזמן שהלחש מוטל. גופותיהם של המטיילים נשארים מאחור במישור המוצא, והם בדרך כלל לא מביאים איתם בגדים או ציוד, אלא אם כן הם עצמם מקרינים הילה קסומה; פריטים אלה הופכים למקבילים אסטרליים של צורתם הרגילה. המשך נמשך עד שהמטיל ירצה שיסתיים. עם זאת, ייתכן שהוא יסתיים בטרם עת על ידי כוח חיצוני כגון "פירוק קסם" (Dispel Magic). הריגת גופו הפיזי של המטיל מסיימת גם היא את הלחש מוקדם, אם כי לתופעת לוואי מצערת זו יש השפעה של השארת מטיילים המלווים את המטיל.

#### אומן (Augury)

(חיזוי - Divination)

| | |
| :-- | :-- |
| **דרגה:** כהן 2 | **זמן הטלה:** 2 דקות |
| **ספירה:** חיזוי | **משך:** מיידי |
| **עלות:** 3 לכל עוצמה | **טווח:** 60 רגל |
| **אזור:** מטיל | **התנגדות:** לא ישים |

לחש זה מאפשר למטיל לקבוע האם פעולה ספציפית שתינקט ב-30 הדקות הקרובות תהיה מועילה או מזיקה לרווחתו של אדם ו/או קבוצה. נדרשת נקודת מיקוד כלשהי כדי להבחין באותות, כאשר הנפוצות ביותר הן טפרים או עצמות קטנות יותר של דרקון, פנינה, או זהב טהור בשווי לא פחות מ-100GP, שרוסקו או הותכו. ללחש יש עוצמה מקסימלית של 4. גלגול זה צריך להתבצע על ידי מנחה המשחק (Games Master), מכיוון שהמטיל לעולם לא צריך לדעת מעל לכל צל של ספק אם התוצאות פורשו נכון.

| עוצמה | עלות | השפעה משתנה |
| :-: | :-: | :-- |
| 1 | 3 | גלגול מיומנות "ערוץ" (Channel) אדיר |
| 2 | 6 | גלגול מיומנות "ערוץ" קשה |
| 3 | 9 | גלגול מיומנות "ערוץ" סטנדרטי |
| 4 | 12 | גלגול מיומנות "ערוץ" קל |

אם גלגול החיזוי מצליח, הוא מעניק אחת מהתוצאות הבאות:

| אומן | משמעות |
| :-: | :-- |
| כן | הפעולה תהיה מועילה |
| לא | הפעולה תהיה מזיקה |
| כן ולא | הפעולה תהיה גם מועילה וגם מזיקה |
| כלום | הפעולה לא תהיה מועילה ולא מזיקה |

כישלון קריטי (Fumble) צריך להוביל לכך שמנחה המשחק יגיד את ההפך מהמציאות.

מניעה משמשת לביטול לחש דרגה 0 אחר בטווח. ניתן להטיל מניעה באופן תגובתי כדי לנטרל לחשי דרגה 0 התקפיים, על ידי שימוש בפעולת תגובה "נגד קסם" (Counter Magic).

#### בלבול (Befuddle)

(כישוף (קסם) - Enchantment (Charm))

| | |
| :-- | :-- |
| **דרגה:** כהן 0, קוסם 0 | **זמן הטלה:** תור 1 |
| **ספירה:** קסם | **משך:** 30 דקות |
| **עלות:** 1 | **טווח:** 60 רגל |
| **אזור:** מטרה 1 | **התנגדות:** כוח רצון |

בלבול גורם לבלבול במוחה של מטרה גשמית. נושא הלחש מתקשה לחשוב בבהירות, שוכח היכן הוא נמצא, מה הוא עושה ולמה – ולעתים קרובות שוקע לקווי מחשבה מנותקים. מטרות מבולבלות עדיין יכולות לפעול בהגנה עצמית אך אינן יכולות להתחיל בשום פעילות בונה עד לסיום הלחש. כל סוג של התקפה או פעולה מאיימת שובר מיידית את הלחש, בין אם הוא כוון ספציפית למטרה המבולבלת ובין אם לא.

#### מחסום להבים (Blade Barrier)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** כהן 4 | **זמן הטלה:** 2 פעולות |

| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 100 רגל |
| **אזור:** רדיוס 5-30 רגל | **התנגדות:** ראה להלן |

לחש זה יוצר מחסום של חרבות, פגיונות וסכינים מסתחררים ששוטפים וחותכים סביב נקודה קבועה וגורמים ל-1d8 נקודות נזק ל-1d4+2 מיקומי פגיעה אקראיים של *כל מי* שעובר דרך אזור ההשפעה. שריון מציע רק מחצית מהגנתו הרגילה. נקודות שריון קסומות מפחיתות נזק כרגיל. מכיוון שהנשקים מסתחררים במהירות מסנוורת והם צפופים, בלתי אפשרי לחסום (Parry) או להתחמק (Evade) מהם. ניתן להשתמש במגן כדי לחסום באופן פסיבי מיקומי פגיעה כרגיל. במקרה זה, זכור להשוות את הנזק שגולגל לשריון ולנקודות הפגיעה של המגן.

ניתן להטיל את הלחש באופן הגנתי כדי להגן על הכהן או בעל ברית אחד או יותר, או ללכוד אויבים באופן התקפי. עם זאת, אויבים המוקפים בטווח של חמישה רגל מקצה המחסום בעת היווצרותו יכולים לבצע גלגול התחמקות כדי להימלט. ללא קשר להצלחה, היריב מסיים במצב שכיבה, ממש מחוץ לאזור ההשפעה. גלגול מוצלח מוביל לאפס נזק; אחרת, הם סובלים מההשפעה המלאה.

#### ברכה (Bless) (R)

(כישוף - Conjuration)

| | |
| :-- | :-- |
| **דרגה:** כהן 1 | **זמן הטלה:** סיבוב 1 |
| **ספירה:** הכל | **משך:** 5 דקות |
| **עלות:** 1 | **טווח:** 180 רגל |
| **אזור:** רדיוס 25 רגל | **התנגדות:** כוח רצון |

כאשר לחש זה מוטל, הכהן מברך קבוצת בעלי ברית בתוך אזור ההשפעה. אלו המושפעים מקרינים את הנטייה (Alignment) של המטיל, טובה או רעה. אין ברכות לנייטרליות. כל בעלי הברית בתוך רדיוס הלחש מקבלים בונוס של +5% לכל גלגולי המיומנות וההתנגדות. בנוסף, הנשקים שלהם גורמים +1d3 נזק לאל-מתים אינטליגנטיים וכן ליצורים ממישורים חיצוניים בעלי נטיות מנוגדות לזו של המטיל, כגון שדים, שטן או מלאכים. שים לב שבעוד אל-מתים מונפשים כגון שלדים וזומבים אינם רעים מיסודם, הם בדרך כלל מונפשים על ידי קסם רע ולכן כפופים לנזק זה.

ההיפוך של לחש זה, קללה (Curse), מאפשר לכהן לקלל אויבים, מה שגורם למיומנויות המצוינות לסבול מההפך מהיתרונות שצוינו לעיל. הנזק של נשק מקולל מחושב כעונש במקום, ונזק זה אינו יכול להוביל לפחות מנקודה אחת.

#### ידיים בוערות (Burning Hands)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 1 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** מיידי |
| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 0 |

לחש זה גורם ללהבות לפרוץ מידיו של המטיל בקשת של 120 מעלות. אם משתמשים במיניאטורות בקרב, "ידיים בוערות" יפגעו בכל מטרה שתופסת אחת ממשבצות הקדמיות של המטיל. הטלת "ידיים בוערות" ברמות עוצמה גבוהות יותר דורשת קוסם בדרגה גבוהה יותר. נזק זה עוטף את כל המטרות בתוך האזור עם נזק המבוסס על העוצמה של הלחש, עד לעוצמה מקסימלית של 9, כדלקמן. גלגול התחמקות מוצלח, המפיל את עצמך למצב שכיבה, מאפשר לקורבן לא לסבול נזק. למישהו עם היכולת "מתחמק אמנותי" (Artful Dodger) יש אפשרות להתחמק מבלי לשכב.

| עוצמה | עלות | דרגה מינימלית | השפעה משתנה |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 נקודות נזק לכל מיקומי הפגיעה |
| 3 | 4 | 1 | 1d3+2 נקודות נזק לכל מיקומי הפגיעה |
| 5 | 5 | 1 | 1d3+3 נקודות נזק לכל מיקומי הפגיעה |

שריון לבוש אינו מגן, אך נקודות שריון קסומות או שריון טבעי של יצור מפחיתים נזק כרגיל. לחש עוצמתי זה מאוזן על ידי טווחו הקצר להפליא, מה שאומר שכדי להטיל אותו, על משתמש הקסם להיות קרוב מספיק כדי להיות במצב חיסרון רציני מאוד.

מכיוון שיצורים גדולים יותר הם בדרך כלל גדולים יותר מאזור ההשפעה של הלחש, הם נוטים למיקומי פגיעה פחות מושפעים. אלו בגודל (SIZ) 21 עד 30 סופגים את הנזק לראש, לחזה, לבטן ולזרועות, בעוד אלו בגודל 31+ יספגו את הנזק לבטן ולרגליים. מנחי המשחק צריכים להתאים את המיקומים הללו בהתאם לצורתו ומיקומו של היעד ביחס למטיל. ל"ידיים בוערות" יש סיכוי להצית חומרים דליקים השווה לנזק שגולגל כפול 5%. ראה את הסעיף על [שריפות](0007_Game_System.md?id=fire-based-attacks) למידע נוסף.

#### שרשרת ברקים (Chain Lightning)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 4 | **זמן הטלה:** 2 פעולות |
| **ספירה:** ללא | **משך:** מיידי |
| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 50 רגל לכל עוצמה |
| **אזור:** ראה להלן | **התנגדות:** התחמקות |

עם ההטלה, הקוסם משחרר ברק חשמלי ברוחב חמישה רגל מקצות אצבעותיו שיכול לפגוע במטרה אחת בטווח עבור 1d6+1 נקודות נזק לכל 2 נקודות עוצמה. הברק ואז מקשת לעצם או ליצור הקרוב ביותר, שסופג את הנזק שגולגל קודם פחות נקודה אחת, ואז מקשת לבא בתור, גורם לנזק שגולגל פחות 2 נקודות, וכן הלאה. הוא עלול אפילו לקשת בחזרה לבעל ברית או למטיל! בעוד שהמטרה הראשונית חייבת להיות גלויה למטיל, מטרות שנפגעות על ידי ברק מקשת אינן חייבות להיות.

לכל קשת יש טווח של 50 רגל משלה, מה שעלול להציב את הברק מחוץ לטווח המקורי כאשר הלחש הוטל. שרשרת ברקים ממשיכה לפגוע אם נותר לה נזק עד שהיא פוגעת בעצם שגורם לה להתארקק (כלוב מתכת או סורגים, בריכת מים גדולה, וכן הלאה) או שאין יותר עצמים או יצורים זמינים לפגיעה.

כל יצור שנפגע סופג את הנזק למיקום פגיעה בודד, כאשר שריון לבוש אינו מציע הגנה, ושריון טבעי ונקודות שריון קסומות מפחיתים נזק כרגיל.

עם גלגול התחמקות מוצלח, המפיל את עצמך למצב שכיבה, הקורבן לא סובל נזק. מישהו עם היכולת "מתחמק אמנותי" יכול להתחמק מבלי לשכב, אך הצלחה במקרה זה רק מפחיתה את הנזק בחצי.

לברק יש סיכוי להצית חומרים דליקים השווה לנזק שגולגל כפול 1%. ראה את הסעיף על [שריפות](0007_Game_System.md?id=fire-based-attacks) למידע נוסף. ברק עשוי גם לנפץ או להרוס חפצים דוממים מהפגיעה עצמה.

| :-: | :-: | :-- |
| 1 | 3 | טווח 50 רגל; 1d6+1 נזק |
| 2 | 4 | טווח 100 רגל; 1d6+1 נזק |
| 3 | 5 | טווח 150 רגל; 2d6+2 נזק |
| 4 | 6 | טווח 200 רגל; 2d6+2 נזק |
| 5 | 7 | טווח 250 רגל; 3d6+3 נזק |
| +1 | +1 | המשך התקדמות |

#### שינוי מראה (Change Appearance)

(אשליה - Illusion)

| | |
| :-- | :-- |
| **דרגה:** קוסם 1 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** 2d6 דקות לכל עוצמה |
| **עלות:** 1 לכל עוצמה | **טווח:** 0 |

לחש זה משנה את מראה המטיל לזה של כל צורת אדם או דו-רגלי דמוי אדם. השינוי בגובה ובמשקל מוגבל ל-±5 SIZ, בהתאמה, אך בטווח זה, מטיל יכול לבחור להיות שמן או רזה, גבוה או נמוך, או אפילו לשנות מין. שיער, בגדים וציוד עשויים להשתנות יחד עם המראה. ניתן לשנות את תווי הפנים של המטיל כרצונו, אפילו עד כדי חיקוי מושלם של אדם קיים אחר. הלחש כפוף ל[חוסר אמון](0009_Magic.md?id=attempting-to-disbelieve) כמו כל לחשי האשליה האחרים. הלחש אינו משנה את ריחו של המטיל, ואם נוגעים בו, המטיל עדיין מרגיש אותו הדבר כמו צורתו ובגדיו המקוריים.

#### פזמון (Chant)

#### קסם אדם (Charm Person)

(כישוף (קסם) - Enchantment (Charm))

| | |
| :-- | :-- |
| **דרגה:** קוסם 1 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** שבוע 1 לכל עוצמה |
| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 360 רגל |
| **אזור:** 1 בן אדם חי, חצי-אדם או דמוי אדם | **התנגדות:** כוח רצון |

כאשר לחש זה מוטל, מטרה דמוית-אדם אינטליגנטית אחת חיה (יצורים אל-מתים אינם מושפעים) בגודל 1-20 תפסיק את כל פעולות האיבה נגד משתמש הקסם ובעלי בריתו, ובמקום זאת תציע לעזור ולהגן עליהם אם המטרה תיכשל בגלגול התנגדות. שים לב שעזרה/הגנה יכולה להיות בעלת השפעה לא מכוונת או אפילו שלילית עבור המטיל, שכן הנושא פועל על סמך מה שהוא מרגיש שהוא דרך הפעולה הטובה ביותר להגן/לעזור. לגבי פקודות, מטרה לעולם לא תציית לפעולות התאבדותיות או מזיקות בעליל, אך עשויה להשתכנע שמשהו מסוכן ביותר שווה לעשותו.

כל פעולה עוינת נגד נושא הקסם על ידי משתמש הקסם או בעלי בריתו שוברת את הכישוף. הערה: אם אחרים מערערים על אופי הקסם, המטרה עשויה גם לבצע גלגול התנגדות, לפי שיקול דעתו של מנחה המשחק. משתמש הקסם חייב להיות מסוגל לדבר עם הקסום כדי לתת לו כל סוג של 'בקשה' מורכבת; לכן, ידיעת השפה של המטרה יכולה להיות חשובה, אך לא נדרשת עבור הכישוף הבסיסי.

לאחר הגלגול הראשוני להתנגדות, חייב לעבור שבוע לפני שהנושא יוכל לבצע גלגול התנגדות נוסף. ההשפעות נמשכות עד לביצוע גלגול התנגדות מוצלח. הטלת "קסם אדם" ברמות עוצמה גבוהות יותר דורשת קוסם בדרגה גבוהה יותר ובעלת משך מקסימלי של 4 שבועות. לאורך משך הלחש, סך נקודות הקסם של המטיל מופחת במספר שהוצא להטלת הלחש, לפי חוקי [עלויות קסם מתמשכות](0009_Magic.md?id=enduring-magic-costs).

| 1 | 3 | 1 | קסום למשך שבוע |
| 2 | 4 | 2 | קסום למשך שבועיים |
| 3 | 5 | 3 | קסום למשך 3 שבועות |

למעט החריגים שצוינו לעיל, לחש זה מתפקד כמו הלחשים [קסם אדם](0010_Spells.md?id=charm-person) ו"קסם מפלצת". ללחש רב-עוצמה זה יש סיכוי להקסים את כל היצורים בתוך אזור ההשפעה מכל גודל (SIZ). יצורים בגודל אדם וקטנים יותר (1-20) מוצאים את גלגוליהם להתנגדות קשים; יצורים גדולים (21-40) חייבים לבצע את גלגולי ההתנגדות שלהם ברמת קושי סטנדרטית, וגלגול ההתנגדות עבור יצורים ענקיים (41+) הוא קל.

(טרנסמוטציה - Transmutation)

ניקוי משמש להיפטר מחפץ, אדם או אזור קטן מלכלוך, שומן, פיח, ריחות רעים וכן הלאה. הוא אינו מארגן או מסדר את המטרה או האזור; רק מנקה אותם למצב נוצץ. לחש זה משמש לעתים קרובות לכביסת בגדים. המטיל יכול לנקות אזור שווה ל-POWx5 ברגל רבוע (ריבוע של 5 רגל הוא 25 רגל רבוע).

#### פקודה (Command)

(כישוף (קסם) - Enchantment (Charm))

| | |
| :-- | :-- |
| **דרגה:** כהן 1 | **זמן הטלה:** פעולה 1 |
| **ספירה:** קסם | **משך:** דקה 1 |
| **עלות:** 3 | **טווח:** 100 רגל |
| **אזור:** מטרה 1 | **התנגדות:** כוח רצון |

כאשר לחש זה מוטל, הכהן יכול להגות פקודה בת מילה אחת ליצור חי אחד בגודל 1-20, ובתורו הבא של הנושא, הפקודה תתבצע כלשונה אם הם ייכשלו בהתנגדות. זה גורם לקורבן להחמיץ את התור הבא בהשלמת הפעולה שנצטווה ובזבוז נקודת פעולה תוך ביצועה. אם לקורבן אין עוד נקודות פעולה, הפעולה המצווה תבוצע במהלך התור הראשון שלו בסיבוב הבא. הפקודה עצמה לא יכולה לגרום לפציעה ממשית למטרה; עם זאת, פציעה עלולה להגיע כהשפעה משנית של הפקודה.

למשל, פקודה למות תגרום לקורבן לקרוס במצב דמוי מוות למשך סיבוב אחד ללא גרימת פציעה ממשית; עם זאת, פקודה ליפול שניתנה ליצור המטפס על צוק בגובה 100 רגל עלולה להיות קטלנית ביותר.

הנושא של הפקודה חייב להיות מסוגל להבין את השפה שמדבר המטיל ומורשה לבצע מבחן כוח רצון כדי להתנגד.

**כמה דוגמאות לפקודות**

- **זחל (Crawl):** הנושא נופל למצב שכיבה ומתחיל לזחול.
- **מת (Die):** הנושא נופל למצב שכיבה ונכנס למצב קומה דמוי מוות.
- **פול (Fall):** הנושא נופל למצב שכיבה.
- **גמגם/פשל (Fumble):** הנושא מפשל פעולה פיזית שעומדת להתבצע.
- **ישן (Sleep):** הנושא נרדם.
- **ברח (Flee):** הנושא מסתובב ובורח מהמטיל.
- **עוף (Fly):** הנושא מנפנף בידיו ורץ במעגלים.
- **לך (Go):** הנושא מתחיל ללכת לכיוון אליו פנה.
- **עצור (Halt):** הנושא עוצר מיד ועומד במקומו.
- **עזוב (Leave):** הנושא מסתובב ועוזב בדרך שבה נכנס.
- **נוח (Rest):** הנושא נופל למצב ישיבה ומסדיר את נשימתו.
- **רוץ (Run):** הנושא מתחיל לרוץ.
- **צעק (Scream):** הנושא צועק.
- **שקע (Sink):** הנושא מפסיק לשחות.
- **היכנע (Surrender):** הנושא מפיל את נשקו ומפסיק את האיבה.

#### חרוט קור (Cone of Cold)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 3 | **זמן הטלה:** סיבוב 1 |
| **ספירה:** ללא | **משך:** מיידי |
| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 0 |
| **אזור:** ראה להלן | **התנגדות:** התחמקות |

המטיל יוצר חרוט של קור צורב המשתרע מידו. אזור ההשפעה הוא קשת של 90 מעלות (חרוט) המשתרעת ל-10 רגל באורך לכל רמת עוצמה. הלחש גורם ל-1d6+1 נקודות נזק לכל 2 נקודות עוצמה, או חלק ממנה, לכל הקורבנות באזור ההשפעה. גלגל את הנזק פעם אחת והחל אותו על כל אחד ממיקומי הפגיעה של המטרה, כאשר שריון לבוש מציע רק מחצית מההגנה, אך שריון טבעי של יצור או נקודות שריון קסומות מפחיתים נזק כרגיל. מנחה המשחק רשאי לבחור את מספר המיקומים המושפעים בכל אמצעי שימצא לנכון אם יצור ענק גדול יותר מאזור ההשפעה.

עם גלגול התחמקות מוצלח, המפיל את עצמך למצב שכיבה, הקורבן לא סובל נזק. מישהו עם היכולת "מתחמק אמנותי" יכול להתחמק מבלי לשכב, אך הצלחה במקרה זה רק מפחיתה את הנזק בחצי, אלא אם כן הם נמצאים בטווח של חמישה רגל מקצה אזור ההשפעה. ל"חרוט קור" יש סיכוי לצפות קורבן בשכבת קרח השווה לנזק שגולגל (לאחר התאמה) כפול 5%. אם קפא, פעם אחת בסיבוב, הקורבן רשאי לבזבז נקודת פעולה ולבצע גלגול שרירים כדי לנסות להשתחרר; עם זאת, עד להצלחה, הקורבן האומלל אינו יכול לזוז או לבצע פעולות אחרות.

#### הקסמת חפץ (Enchant Item)

(כישוף - Enchantment)

| | |
| :-- | :-- |
| **דרגה:** קוסם 4 | **זמן הטלה:** ראה להלן |
| **ספירה:** ללא | **משך:** ראה להלן |
| **עלות:** 3 + ראה להלן | **טווח:** מגע |
| **אזור:** חפץ 1 | **התנגדות:** לא ישים |

הטלת לחש זה מכינה חפץ לכישוף. האובייקט חייב להיות במצב טוב ובעל הביצוע והמלאכה הטובים ביותר. נדרשת עלות נוספת של לפחות 100GP כדי לכסות את עלות הכלים הנוספים, הגילוף, הרקמה, שיבוץ אבני חן, חריטה וכן הלאה. לבסוף, תהליך הכישוף דורש מעבדה או סדנה.

בזמן הטלת הלחש, משתמש הקסם חייב לגעת בחפץ לאורך כל זמן ההטלה של 1d8+2 ימים. זה לוקח בחשבון תקופות של מנוחה ושינה, שבמהלכן החפץ חייב להישאר במרחק של זרוע מהמטיל. בשום זמן במהלך ההטלה, משתמש הקסם אינו רשאי להטיל לחש אחר או לבצע כל סוג אחר של קסם. הפרת כל אחת מהמגבלות הללו תגרום ללחש להיכשל אוטומטית.

ברגע שהוטל בהצלחה, החפץ מוכן לשלב הסופי, כאשר המטיל מניח את הלחש הרצוי לתוכו. כדי לעשות זאת, עליהם להחזיק את הלחש בזיכרון או על מגילה ולהטיל אותו לתוך החפץ תוך 24 שעות, אחרת התהליך כולו יצטרך להתחיל מחדש מאפס. ברגע שמתחילה הטלת הלחש הנבחר, התהליך עשוי לעלות על 24 השעות הנזכרות לעיל. הטמעת החפץ עם הלחש הנבחר עולה את מספר נקודות הקסם הרגיל לעוצמה הרצויה ולוקחת 1d12 שעות לכל דרגת לחש. לאורך תהליך ההטמעה, המטיל חייב להישאר נוגע בחפץ או להישאר בטווח זרוע במהלך תקופות מנוחה, כפי שצוין לעיל, ונדרש גלגול הטלת קסם ארקני בסוף תקופת ההטלה כדי להטמיע את הלחש בהצלחה. דרגות ההצלחה הרגילות של הטלת לחשים עוקבות, עם זאת, לגבי תוצאת כישלון, לא ניתן לכפות את הלחש. ניתן להטמיע לחשים עוקבים בתוך החפץ, בתנאי שתהליך ההטלה מתחיל תוך 24 שעות מהשלמת הלחש הקודם. זה תקף גם במקרה של לחש שנכשל בעבר. כל לחש עוקב דורש את עלות ההטלה הרגילה.

בעת שימוש בחפץ, ניתן להטיל כל לחש הכלול בו פעם אחת בלבד; עם זאת, ניתן להטמיע גרסאות מרובות של אותו לחש בהתאם לנוהל לעיל. ניתן גם להטמיע לחש יחיד, ואחריו הטלה של לחש דרגה 4 "קביעות" (Permanency). במקרה זה, ניתן להטיל את הלחש לעתים קרובות ככל שתרצה, בעקבות המגבלות המפורטות תחת תיאור הלחש "קביעות".

לא ניתן להטמיע השפעות קסומות אחרות בחפץ שאינן תואמות לחש ספציפי, וחפצים קסומים רבים מזמנים רחוקים פשוט לא ניתן לשחזר בימינו אלה.

| **אזור:** רדיוס חצי מייל לכל עוצמה | **התנגדות:** לא ישים |

לחש זה מאפשר למטיל לנסות לזמן מכר, שהופך להארכה של חושיו וכוחו של אדונו. מכרים עשויים לשוחח עם אדונם טלפתית ולהוות שומרים וצופים טובים. הריגת המכר מציגה סיכונים מסוימים למשתמש הקסם עקב הקשר הקרוב ביניהם, מה שהופך את קיום המכר לסכנה בדרגה נמוכה.

כדי לזמן מכר, משתמש הקסם חייב להתחיל את הטקס תוך שמירה על מנגל דולק בפחם, וכאשר הוא בוער בעוצמה, להוסיף קטורת בשווי 100GP. עם המרכיבים הללו בוערים, המטיל חייב אז להמשיך את הטקס עד שהמכר מגיע או שזמן ההטלה יפוג ללא הצלחה.

גם אם לחש זה מוטל בהצלחה, הסיכוי שמכר מתאים יענה לקריאתו של משתמש הקסם הוא רק 50%, ומשתמש הקסם רשאי לנסות לחש זה רק פעם בשנה. כל רמת עוצמה נוספת מעבר לראשונה מרחיבה את טווח הלחש בחצי מייל נוסף, מה שמגדיל בתורו את הסבירות למציאת מכר פוטנציאלי ב-5%, עד למקסימום של 95%. אין שליטה על הסוג המדויק של היצור שיענה לקריאה, אך מה שיגיע יהיה משרת ובן ברית נאמן. תלוי ביצור הספציפי לענות לקריאה, לכן הימצאות באזור הידוע כמיושב על ידי סוג מסוים של יצור *אינה* מבטיחה למטיל הצלחה.

אם יצור עונה לקריאות המטיל, משתמש הקסם צריך עדיין להקריב גלגול ניסיון אחד (1 Experience Roll) כדי ליצור קשר רוחני בינו לבין המכר. ברגע שזה נעשה, הטקס הושלם.

בעוד המכר ואדונו נמצאים בטווח של 120 רגל זה מזה, משתמש הקסם מקבל את היכולת להשתמש גם בנקודות הקסם של המכר. בנוסף, משתמש הקסם מקבל קשר טלפתי עם המכר וכל יכולות מיוחדות נוספות או בונוסי מיומנות המצוינים בטבלאות להלן.

במקרה של מות המכר, המטיל מאבד 5 גלגולי ניסיון. מטיל שכרגע אין לו גלגולי ניסיון חייב להפסיד את כל גלגולי הניסיון הנוספים שיוענקו עד לתשלום היתרה.

סוג המכר שיגיע, אם בכלל, נקבע לפי הטבלה הבאה. ברוב הנסיבות, מכרים נפוצים אינם גדולים במיוחד, בגודל 1-4, ומשתמשים בתיאור "חיה קטנה".

#### מגן אש (Fire Shield)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 3 | **זמן הטלה:** 2 פעולות |
| **ספירה:** ללא | **משך:** 2 דקות לכל עוצמה |
| **עלות:** 3+1 לכל עוצמה נוספת | **טווח:** 0 |
| **אזור:** מטיל | **התנגדות:** לא ישים |

לחש זה יוצר מגן של להבות דקות ששורפות את המטיל אך לא גורמות נזק כשלעצמן. במקום זאת, הלהבות מגינות על המקבל מפני אש או קור, תלוי באיזה משתי גרסאות מאוחסן בזיכרון: "מגן צינון", היוצר להבות כחולות או ירוקות ומגן מפני חום ונזק מבוסס אש, או "מגן חום", היוצר להבות סגולות או כחולות ומגן מפני קור ונזק מבוסס קרח. יש לקבוע את צבע הלהבות באקראי עם סיכוי של 50% לכל אחד, שכן העובדה ששני הסוגים יכולים לפלוט להבות כחולות יוצרת אלמנט של אי-ודאות מצד כל תוקף. ההחלטה איזה לשנן מתקבלת בעת הכנת הלחשים, וניתן לשנן את שניהם אם רוצים. להבות אלו אינן פולטות חום ופולטות אור בבהירות של חצי לפיד בלבד. פרטי כל גרסה מפורטים להלן.

- **מגן צינון (Chill Shield):** להבות אלו קרירות למגע ומפחיתות כל נזק מבוסס חום או אש למחצית מהסך הכולל. גלגול התנגדות מוצלח יבטל את כל הנזק. גלגול ההתנגדות הוא בדרגה אחת קלה יותר ובמקרה של התחמקות, לא יהפוך את המגן לשוכב.
- **מגן חום (Warm Shield):** להבות אלו חמימות למגע ומפחיתות כל נזק מבוסס קור למחצית מהסך הכולל. גלגול התנגדות מוצלח יבטל את כל הנזק. גלגול ההתנגדות הוא בדרגה אחת קלה יותר ובמקרה של התחמקות, לא יהפוך את המגן לשוכב.

התקפות קפא"פ נגד מקבל הגרסה, בין אם חמושים או לא חמושים, גורמות נזק רגיל אלא אם כן משתמשים באחד היסודות המוגנים מפניהם. במקרה זה, המטיל מוגן מהחלק היסודי של ההתקפה, והתוקף סופג נזק השווה לזה שנגרם. שריון לבוש מצד התוקף אינו מציע הגנה, אך נקודות שריון קסומות או שריון טבעי של יצור מפחיתים נזק כרגיל. יצורים עם חסינות קסם מולדת יכולים לפרק את מגן האש בגלגול כוח רצון מוצלח כאשר המקבל נפגע לראשונה. אם גלגול חסינות הקסם נכשל, היריב לא יכול מאוחר יותר לבטל את מגן האש.

#### בשר לאבן (Flesh to Stone) (R)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 4 | **זמן הטלה:** 2 פעולות |
| **ספירה:** ללא | **משך:** קבוע |
| **עלות:** 3 לכל עוצמה | **טווח:** 30 רגל לכל עוצמה |
| **אזור:** מטרה 1 | **התנגדות:** כוח רצון |

כאשר מוטל, קורבן אחד בטווח מורשה לבצע גלגול התנגדות כוח רצון. אם נכשל, הוא וכל הציוד הנישא והלבוש הופכים לחלוטין לאבן מוצקה. טרנספורמציה זו אינה מוות, אלא צורה של תרדמת חורף. ניתן להשתמש בהטלת הגרסה ההפוכה של לחש זה, או "משאלה", כדי להשיב את הקורבן לחיים שוב. כל נזק שהקורבן סופג בזמן שהוא אבן עובר הלאה, ונכנס לתוקף מיד עם השחזור. יצורים גדולים (21-40) רגישים פחות ללחש זה כאשר גלגול ההתנגדות הוא קל, בעוד גלגול ההתנגדות עבור יצורים ענקיים (41+) הוא קל מאוד.

ההיפוך של לחש זה, "אבן לבשר", משמש להשבת קורבן ואין צורך בגלגול להתנגדות. עם זאת, הלחש עשוי להיות הפוך גם כדי להפוך אבן שמעולם לא הייתה חיה קודם לכן; בשימוש באחת מכמה דרכים יצירתיות. לדוגמה, קיר אבן בגודל 10 רגל מעוקב לכל רמת עוצמה עשוי להפוך לבשר רך, 'מנהרה' של בשר ברוחב של עד 3 רגל, עם אורך של 10 רגל לכל עוצמה עשויה להיווצר, מטרה אחת כגון פסל אבן עשויה להפוך לגוף, ואפילו גולם אבן עשוי להפוך לגולם בשר באמצעות לחש זה. עם זאת, במקרה האחרון, גולם האבן יורשה לבצע גלגול כוח רצון כדי להתנגד כרגיל. אבן שהפכה לבשר בדרך זו היא רכה וגמישה, ובעוד היא שומרת על נקודות הפגיעה האמיתיות שלה, אין לה נקודות שריון, מה שמקל על קיצוצה.

זוהר הופך את המטרה למושכת כך שאנשים נמשכים אליהם באופן טבעי. יש לבחור את אופי הזוהר בעת ההטלה, ויכול להיות כל דבר החל מיופי טבעי מוגבר, קול רך וסקסי יותר, או אפילו ריח גוף מבושם בצורה מפתה. בעוד שהלחש אינו מעניק יתרונות מכניים, הוא אכן מבטיח שהמקבל יקבל הזדמנות לאסוף לעצמו קהל, לעורר את תשומת ליבו של מישהו שהם רוצים ליצור איתו קשר, או לספק הסחת דעת המאפשרת לשותפים הזדמנות לבצע מעשים נלוזים.

כאשר הפוך, "דחייה" מעוותת את מראה המטרה כך שהם גורמים לסלידה בכל אלו שרואים, שומעים או מריחים אותם. יש לבחור את ההשפעה בעת ההטלה ויכולה להיות כל דבר החל מיבלת גדולה על קצה האף, קול מאונפף גבוה או אפילו ריח גוף חריף. מה שייבחר, זה יגרום לאנשים להתרחק מהקורבן או לחפש תירוצים לעזוב את נוכחותו מהר ככל האפשר.

#### ריפוי (Heal) (R)

(נקרומנסיה - Necromancy)

| | |
| :-- | :-- |
| **דרגה:** כהן 4 | **זמן הטלה:** דקה 1 |
| **ספירה:** ריפוי | **משך:** קבוע |
| **עלות:** 3 + 1 לכל עוצמה | **טווח:** מגע |
| **אזור:** יצור 1 | **התנגדות:** לא ישים (סיבולת או התחמקות) |

עם הטלת "ריפוי", הכהן יכול לרפא תחלואה פיזית, טראומה נפשית או כמות משמעותית של פציעה במגע בודד. היקף התאוששות זה מבוסס על עוצמת הלחש כדלקמן. לכל רמת עוצמה, הלחש מרפא את הנושא ממחלה אחת מכל POT, מרפא כל עיוורון או חירשות, מבטל הפרעה נפשית שהובאה על ידי פציעה או קסם, או מרפא מיקום פגיעה בודד של עד 12 נקודות נזק. עם זאת, הוא לא ישחזר איבר שנקטע, שכן זה דורש הטלת הלחש "התחדשות" (Regenerate). ניתן להשתמש בכל עוצמה נוספת כדי לרפא תחלואה אחרת או לרפא מיקום פגיעה אחר. לכן יידרש הטלה בעוצמה 7 כדי לרפא אדם הסובל מכוויות בכל גופו. בניגוד ללחשי ריפוי פחותים המגבילים את יעילותם נגד פציעות ארוכות טווח, אין מגבלות המוטלות על הלחש על ידי המשך שבו הנושא סבל מהשפעות הפציעה.

כאשר הפוך, "נזק" (Harm) מחדיר 12 נקודות פציעה קסומות לאחד ממיקומי הפגיעה של הקורבן בגלגול כושל להתנגדות. לחלופין, חולי מוטג עליהם, שהשפעותיו זהות ללחש "גרימת מחלה", ההיפוך של "ריפוי מחלה", אך ב-POT +20. גלגול ה"ערוץ" של המטיל מתפקד כגלגול לפגיעה ביריב ומונח כחלק מהדרישה הסומטית של הלחש. אין צורך בגלגול נוסף לפגיעה. לא שריון לבוש ולא שריון טבעי מציעים כל הגנה, אך נקודות שריון קסומות מפחיתות נזק כרגיל, וחוסמות לחלוטין תחלואות מוטלות. כל עוצמה נוספת משפיעה על מיקום פגיעה אחר הצמוד לראשון, עם השפעות כפי שנקבעו על ידי גלגול ההתנגדות הראשוני. לשתי הגרסאות של לחש זה אין השפעה על אל-מתים, יצורים שנפגעים רק על ידי ברזל, כסף או נשקי קסם, או ישויות שאינן גשמיות.

#### סופת קרח (Ice Storm)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 3 | **זמן הטלה:** 2 פעולות |
| **ספירה:** ללא | **משך:** ראה להלן |
| **עלות:** 3, +1 לכל עוצמה נוספת | **טווח:** 30 רגל/עוצמה |
| **אזור:** ראה להלן | **התנגדות:** ראה להלן |

לסופת קרח שתי השפעות, שאחת מהן נבחרת כאשר הלחש מוטל:

אבני ברד (משך: מיידי): גרסה זו של הלחש גורמת לכדורי ברד גדולים לרדת גשם באזור ברדיוס 60 רגל. אלו שנתפסים באזור סופגים 1d10 נקודות נזק לכל 2 נקודות עוצמה, או חלק ממנה. כל קוביית נזק מוגרלת בנפרד ומוחלת על מיקומי פגיעה אקראיים. יצורים משתמשי אש סופגים +3 נזק מכל פגיעת ברד, ויצורים משתמשי קור סופגים חצי נזק. שריון לבוש מציע רק מחצית מההגנה, אך שריון טבעי של יצור (או נקודות שריון קסומות) מפחיתים נזק כרגיל. גלגול התחמקות, נפילה למצב שכיבה, יעיל רק אם בטווח של 5 רגל ממחסה או מקצה אזור ההשפעה. אחרת, בלתי אפשרי להימנע מנזק. הצלחה בהתחמקות מאפשרת לקורבן לסבול מחצית מהנזק של כל גלגול. למישהו עם היכולת "מתחמק אמנותי" יש אפשרות להתחמק מבלי לשכב, ואם בטווח של 5 רגל ממחסה או קצה אזור ההשפעה, לא יספוג נזק בגלגול מוצלח, אחרת יספוג נזק כרגיל.

| :-: | :-: | :-- |
| 1 | 3 | טווח 30 רגל; 1d10 נזק |
| 2 | 4 | טווח 60 רגל; 1d10 נזק |
| 3 | 5 | טווח 90 רגל; 2d10 נזק |
| 4 | 6 | טווח 120 רגל; 2d10 נזק |
| 5 | 7 | טווח 150 רגל; 3d10 נזק |
| +1 | +1 | המשך התקדמות |

שלג דק (משך: סיבוב 1 לכל עוצמה): גרסה זו של הלחש יוצרת שלג דק ששוטף דרך אזור דמוי שביל ברוחב 60 רגל ובאורך 120 רגל, ומעוור את המושפעים. הנתיב בפועל עשוי להיות מצוין על ידי משתמש הקסם כאשר הלחש מוטל. בנוסף, הקרקע באזור המושפע קופאת, ומאיטה את קצב התנועה ב-50%, ומפילה לארץ מעופפים שנכשלים בגלגול מיומנות "עוף" אדיר. אלו שעל הקרקע חייבים להצליח בגלגול אתלטיקה בכל סיבוב כדי להתנגד לנפילה למצב שכיבה, כאשר הגלגול קשה בשתי דרגות אם נעים מהר יותר מהליכה. דמות בעלת אקרובטיקה עשויה להחליף את המיומנות אם תרצה. הקרח יימס לאחר שמשך הלחש יפוג בקצב שנקבע על ידי מנחה המשחק, בהתאם לטמפרטורת הסביבה; עם זאת, גם במזג אוויר חם הוא יימשך מינימום של 10 דקות. אש קטנה, כגון מדורות ולפידים, כבית אוטומטית. לחש זה יבטל את השפעות הלחש "חום מתכת".

כיבוי כבה מיד להבות ומדורות קטנות בגודל וחום צנועים. הוא שימושי לכיבוי נרות, פנסים, לפידים או מדורות בישול קטנות, אך לא יעבוד על קסם או על שריפות פראיות וגדולות יותר, כגון ערימות עצים, בתים בוערים או להבות דרקון.

#### אשליה (Illusion)

| **עלות:** 1 לכל עוצמה | **טווח:** 100 רגל לכל עוצמה |

לחש זה יוצר אשליה חזותית של כל מה שהמטיל חפץ בו. אין לו השפעה על חושים אחרים, שכן הוא אינו משמיע קול, מייצר ריח, טמפרטורה או מרקם, וכן הלאה.

אשליה זו עשויה להיות כל דבר מאחו פתוח ועד דרקון אדום עתיק, אם היא מתאימה לתוך אזור ההשפעה של הלחש. האשליה תימשך רק כל עוד המטיל שומר על ריכוז, או ברגע שיריב נוגע בה או נכנס אליה; פעולה זו גורמת לקסם שמקיים אותה להיפרם והאשליה להתפוגג. עם זאת, המטיל עשוי לשמור על האשליה לאחר מגע פיזי, על ידי הוצאת נקודת קסם אחת והנחייתה להגיב בהתאם למגע כדי לא לעורר חשד. לדוגמה, בנסיבות רגילות, אשליה של עוג תתפוגג כאשר תפגע על ידי חץ; עם זאת, המטיל יכול לגרום לעוג להיראות כמי שמושך בכתפיו מהפגיעה ומסתער על התוקף על ידי הוצאת נקודת קסם אחת. יש לציין כי החץ עצמו אינו נעצר על ידי האשליה ועלול עדיין לפגוע במשהו או במישהו מאחורי המופע.

בעוד שלא ניתן לגרום נזק ממשי על ידי האשליה, וגם לא ליצור טמפרטורה, המוח יכול להשתכנע שהוא מרגיש כאב, סובל מהשפעות של פציעה, או מרגיש קיצוניות של חום או קור; עם זאת, חפצים לא ייראו כקופאים או בוערים, אלא אם המטיל מתרכז בהשפעות אלו גם כן. ברגע שהלחש הוטל, ניתן להוסיף השפעות חזותיות נוספות על ידי משתמש הקסם כרצונו על ידי התרכזות בהשפעה הרצויה. זה בדרך כלל לא לוקח זמן וניתן לטפל בו כפעולה חופשית. אז, למשל, אם המטיל רצה שלפיד אשליה שהופל יגרום לעלים יבשים להיראות כאילו עלו באש, המטיל יכול להתרכז כפעולה חופשית כדי לעשות זאת.

ראה את הפרק [אשליות ופנטזמות](0009_Magic.md?id=illusions-and-phantasms) למידע נוסף.

#### אי-נראות (Invisibility)

כאשר לחש זה מוטל, הנושא וכל הציוד הנישא נעלמים, בלתי נראים לכל צורות הראייה הרגילה. זה לא, עם זאת, הופך את הפרט לבלתי ניתן לגילוי באמצעים אחרים כגון שמיעה, מגע, ריח וכן הלאה, או על ידי יכולות טבעיות כגון "חוש חיים" או סונאר.

אלו שתחת השפעות "אי-נראות" נשארים כך לאורך משך הלחש (מקסימום 24 שעות), אלא אם כן הוסרו או שהנושא מבצע התקפה, ובמקרה זה הלחש מבוטל, והפרט מופיע שוב *אחרי* ההתקפה. המטרה תיחשב תחת השפעות [הפתעה](0008_Combat.md?id=surprise). אף פעולה אחרת לא משפיעה לרעה על משך הלחש, מה שמאפשר לנושא לפתוח דלתות, לדבר, לטפס, לרוץ, לכייס וכן הלאה. אפילו הטלת לחשים לא תסיים את המשך אלא אם כן הם משפיעים לרעה על אויב אחד או יותר בקרב. פעולות רבות מהנזכרות לעיל עשויות לאפשר אמצעי גילוי אחרים, כגון גלגול תפיסה אפשרי לשמוע מישהו רץ, או להרגיש כיס שמתרוקן. מנחה המשחק יקצה עונשים או בונוסים לאלו שמנסים את הגילוי בהתאם לכמה זה מורגש.

#### ברק (Lightning Bolt)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 2 | **זמן הטלה:** 2 פעולות |

| **עלות:** 3, +1 לכל עוצמה נוספת | **טווח:** 50 רגל לכל עוצמה |
| **אזור:** נתיב ברוחב 10 רגל | **התנגדות:** התחמקות |

כאשר משתמש הקסם מתחיל את הלחש המילולי והמחוות בתור הראשון להטלה, מטען חשמלי מתחיל להשתחרר בין אצבעותיו. בתור השני, כשהלחש הושלם, משתמש הקסם שולח פיצוץ של ברק מקצה אצבע המקשת בקו ישר דרך כל המטרות בנתיב ברוחב 10 רגל לאורך טווח הלחש. נזק זה גורם ל-1d6 נקודות נזק לכל 2 נקודות עוצמה, או חלק ממנה, לכל הקורבנות באזור ההשפעה. נזק זה מוגרל פעם אחת, ומוחל על כל אחד ממיקומי הפגיעה של המטרה, כאשר שריון לבוש ושריון טבעי אינם מציעים כל הגנה, אך נקודות שריון קסומות מפחיתות נזק כרגיל.

גלגול התחמקות מוצלח, כתוצאה מנפילה למצב שכיבה, מאפשר לקורבן לא לסבול נזק. למישהו עם היכולת "מתחמק אמנותי" יש אפשרות להתחמק מבלי לשכב, אך הצלחה במקרה זה תפחית את הנזק בחצי, אלא אם הם נמצאים בטווח של 5 רגל מקצה אזור ההשפעה.

#### טיל קסם (Magic Missile)

(אווקציה - Evocation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 1 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** מיידי |
| **עלות:** 1 לכל עוצמה | **טווח:** 100 רגל לכל עוצמה |
| **אזור:** 1-5 מטרות | **התנגדות:** ראה להלן |

כאשר לחש זה מוטל, טיל אחד או יותר של אנרגיה קסומה מזנקים מקצות אצבעותיו של משתמש הקסם ופוגעים במטרה. המספר המקסימלי של טילים שניתן ליצור מבוסס על רמת מיומנות הטלת הקסם הארקני של המטיל, כאשר טיל שני נוצר ברמת מיומנות 60%, שלישי ב-70%, רביעי ב-80%, וטיל חמישי ואחרון ברמת 90%. כדי ליצור טילים אלו, יש להטיל את הלחש בעוצמה השווה למספר הטילים הרצוי. לדוגמה, מתחת ל-60%, משתמש קסם שמטיל טיל קסם בעוצמה 3 ישיג את הטווח הארוך יותר, עם זאת, ייווצר רק טיל בודד. משתמש קסם ברמת מיומנות 70% יכול להטיל את הלחש באותה עוצמה 3 ולהשיג את אותו הטווח אך להיות מסוגל ליצור 3 טילים. ללחש זה יש עוצמה מקסימלית של 5. ראה את הטבלה להלן.

טיל קסם יפגע ללא ספק, גם אם המטרה בקרב קפא"פ או שיש לה כיסוי חלקי. לא ניתן להתחמק מטילים אלו; עם זאת, יריב בכיסוי מלא לא ניתן למקד בלחש זה. לחש "מגן" יסיט אוטומטית טילים קסומים בהנחה שהמטרה מודעת ו/או פונה למטיל. טילים קסומים גורמים 1d6+1 נקודות נזק ושריון לבוש אינו מגן, אך שריון טבעי של יצור או נקודות שריון קסומות מפחיתים נזק כרגיל. טילים קסומים אינם גורמים נזק לחפצים דוממים כגון דלתות, מנעולים וכן הלאה.

בעת ירי טילים מרובים, המטיל עשוי לגרום להם לפגוע ביצור בודד, או למקד מספר יצורים. כל טיל קסם יפגע במיקום פגיעה אקראי - לא ניתן למקד מיקומי פגיעה ספציפיים. המטיל חייב לציין מטרות בודדות של כל טיל לפני שהוא מגלגל לנזק.

| 2 | 2 | טווח 200 רגל; 2 טילים ברמת 60% מיומנות |

#### פה קסום (Magic Mouth)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 2 | **זמן הטלה:** דקה 1 |
| **ספירה:** ללא | **משך:** ראה להלן |
| **עלות:** 3, +1 לכל עוצמה נוספת | **טווח:** 30 רגל |
| **אזור:** חפץ 1 | **התנגדות:** לא ישים |

לחש זה יוצר פה על פריט או חפץ, שמופיע בקסם כאשר מופעל על ידי אירוע ספציפי או זמן שנקבע על ידי משתמש הקסם כאשר הלחש מוטל לראשונה. פה זה ידבר אז כל ביטוי מוגדר מראש שהמטיל בחר בזמן ההטלה. ביטוי זה חייב לכלול לא יותר מ-25 מילים והוא נאמר על ידי הפה בקצב של בערך מילה לשנייה. הפה אינו רשאי להגות מילות כוח או להטיל לחשים.

ניתן להטיל לחש זה על כל חפץ דומם בדרך כלל, מעמוד או עץ, לקיר אבן או תיבה; עם זאת, הוא יעיל במיוחד כאשר מוטל על פסל, שכן הפסל עצמו ייראה כאילו הוא מדבר. לא ניתן להטיל אותו על אף יצור חי בעל תבונה או אינסטינקט. זה חל גם על אלו שהיו פעם בחיים. בעת הטלת לחש זה, משתמש הקסם קובע את המצב שיפעיל את הכישוף. הוא יכול להיות מתוכנן להפעלה באמצעות כל דבר החל ממילה מדוברת ועד ליצירת כל רעש. זה יכול להיות כללי כמו 'כשהאדם הבא יכנס לחדר הזה...' ועד ספציפי כמו, 'כאשר כוהנת נקבה של סדונה תגיע לטווח של 10 רגל מהפסל בקצה האולם ביום שבת...'. השפעת ההפעלה לא יכולה להיות משהו שלא ניתן להבחין בו ללא קסם, כגון יצור בלתי נראה, נטייה של יצור, מיומנות, דרגה וכו'. עם זאת, הוא יכול לציין לבוש שנלבש. המרחק המקסימלי שהלחש יכול להפעיל הוא 25 רגל לכל עוצמה.

משך לחש זה הוא קבוע עד להפעלת הכישוף ואז הלחש מסתיים.

כל מטאור עושה 1d10 נקודות נזק אש לאלו באזור ההשפעה. עם זאת, בשל רדיוס כל פיצוץ, רבים יחפפו, ויגרמו נזק נוסף לאלו חסרי המזל שייקלעו אליהם. גלגולי הנזק משולבים ומוחלים על כל אחד ממיקומי הפגיעה של המטרה, כאשר שריון לבוש אינו מציע הגנה, אך נקודות שריון קסומות או שריון טבעי של יצור מפחיתים נזק כרגיל.

גלגול התחמקות מוצלח מאפשר לקורבן לא לסבול נזק. למישהו עם היכולת "מתחמק אמנותי" יש אפשרות להתחמק מבלי לשכב, אך הצלחה במקרה זה תפחית את הנזק בחצי, אלא אם הם נמצאים בטווח של 5 רגל מקצה אזור ההשפעה.

כולם, כולל אלו שמחוץ לאזור ההשפעה אך בטווח של 60 רגל מנקודת פגיעה, נדרשים להצליח בגלגול אתלטיקה כדי להישאר עומדים.

למטר מטאורים יש סיכוי להצית חומרים דליקים השווה לנזק שגולגל כפול 5%. ראה את הסעיף על [שריפות](0007_Game_System.md?id=fire-based-attacks) למידע נוסף.

#### דמות מראה (Mirror Image)

(אשליה - Illusion)

| | |
| :-- | :-- |
| **דרגה:** קוסם 2 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** 3 סיבובים לכל עוצמה |
| **עלות:** 1 לכל עוצמה | **טווח:** 0 |
| **אזור:** רדיוס 5 רגל | **התנגדות:** לא ישים |

כאשר לחש זה מוטל, 2d4 כפילים של משתמש הקסם מופיעים ברדיוס של 5 רגל, בדיוק מחקים את תנועות המטיל. בנוסף, כל אזור ההשפעה רועד ומרצד, מה שהופך את מיקומו המדויק של המטיל לבלתי ניתן לבירור. פגיעה באחת מהדמויות האשליות גורמת לה להיעלם; עם זאת, הדמויות הנותרות אינן מושפעות. פגיעה במטיל אין לה השפעה על הדמויות הנותרות ומכיוון שהדמויות תמיד משתנות, אין דרך לדעת אם המטרה היא המטיל האמיתי אם הותקף שוב. כל פציעה שסובל המטיל משוכפלת גם על הדמויות. ישנן דרכים רבות שבהן מנחה המשחק יכול לקבוע אם המטיל בפועל נפגע או אחת מהדמויות. אחת היא לקבוע כמה מטרות פוטנציאליות זמינות, כולל המטיל, ולגלגל קובייה מהדנומינציה הקרובה ביותר. לדוגמה, עם 4 דמויות והמטיל, התוקף צריך לגלגל 1d6, לגלגל מחדש תוצאה של 6, כאשר המטיל נפגע בגלגול של 1. אחרת תהיה להחזיק כמה סמנים השווים למספר המטרות הפוטנציאליות, ולסמן אחד כלהיות המטיל. סמן נמשך בכל פעם שמבוצעת התקפה ואם המטרה נפגעת, נזק מוחל; אחרת, דמות נעלמת, ומסירה אחד מהסמנים. הדמויות נעלמות בסוף משך הלחש.

#### קביעות (Permanency)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 4 | **זמן הטלה:** פעולה 1 |
| **ספירה:** ללא | **משך:** קבוע |
| **עלות:** 3, +2 נק"נ | **טווח:** ראה להלן |
| **אזור:** ראה להלן | **התנגדות:** לא ישים |

הטלת לחש זה משנה את משך הזמן של לחשים אחרים מסוימים לקבוע. כדי להשתמש בלחש זה, משתמש הקסם יטיל תחילה את הלחש שייעשה קבוע. עם זאת, עם סיום הטלת הלחש ההוא הוא נשמר, ונקודת פעולה נוספת מושקעת בהטלת "קביעות", שלאחריה הלחש הנבחר מוטל בצורתו הקבועה. כל לחש שנעשה קבוע עולה למטיל 2 גלגולי ניסיון (נק"נ) וכן 3 נקודות הקסם המצוינות, בנוסף לעלות ההטלה הרגילה של הלחש המקורי. הטלת "פירוק קסם" במהלך הטלת "קביעות" לא רק מפרקת את "קביעות", אלא גם את הלחש המקורי.

"קביעות" היא גם יישום מפתח ביצירת חפצי קסם באמצעות הלחש "הקסמת חפץ". בנוסף ללחשים המצוינים להלן, ניתן להפוך לחשים אחרים לקבועים באישור מנחה המשחק.

הלחשים האישיים הבאים, אלו המשפיעים רק על המטיל, ייהנו מלחש זה. לא ניתן להפוך אותם לקבועים על יצורים אחרים:

- מניעה (Avert)
- תיאום (Coordination)
- ראיית לילה (Darkvision)
- הסטה (Deflect)
- גילוי רוע (Detect Evil)
- גילוי אי-נראות (Detect Invisibility)
- גילוי קסם (Detect Magic)
- זוהר (Glamour)
- ידיעת שפות (Know Languages)
- עוצמה (Might)
- שימור (Preserve)
- הגנה (עצמית)
- הגנה מרוע
- קריאת קסם (Read Magic)
- לשונות (Tongues)


ניתן להשתמש בלחש "קביעות" גם כדי להפוך את הלחשים הבאים, המוטלים על יצורים אחרים, חפצים או אזורים, לקבועים. לחשים המסומנים בכוכבית עשויים להפוך לקבועים רק על חפץ או אזור.

#### שינוי מישור (Plane Shift)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** כהן 3 | **זמן הטלה:** 2 פעולות |
| **ספירה:** אסטרלית | **משך:** קבוע |
| **עלות:** 3, +1 לכל עוצמה נוספת | **טווח:** מגע |
| **אזור:** ראה להלן | **התנגדות:** כוח רצון |

כאשר מוטל, הכהן ועד 7 אחרים (אחד לכל רמה נוספת של עוצמה) יכולים לנסוע למישור קיום אחר. כולם חייבים לגעת וליצור מעגל בזמן שהכהן מטיל את הלחש. בנוסף, המטיל עשוי גם להשתמש בלחש כדי להעביר יצור אחד באופן בלתי תלוי בעצמם, ברצון או לא, למישור לבחירת המטיל; עם זאת, אלו שלא מרצונם יכולים לבצע גלגול כוח רצון כדי להתנגד, כאשר הצלחה מבטלת את הלחש. נקודת ההגעה המדויקת היא לעתים רחוקות מה שהמטיל חפץ בו. אם משתמשים במפת משושים, גלגל 1d6 כדי לקבוע את הכיוון ו-1d10x10 עבור המרחק במיילים.

בנוסף לכל מרכיבי חומר גנריים, הטלת "שינוי מישור" דורשת מוטות ממתכות נדירות שונות, כל אחת מכוונת במיוחד למישור קיום. מוטות אלו נדירים וניתן להעריך אותם בקלות בשווי של עד 10,000GP כל אחד.

#### פולימורף אחר (Polymorph Other)

(טרנסמוטציה - Transmutation)

| | |
| :-- | :-- |
| **דרגה:** קוסם 3 | **זמן הטלה:** 2 פעולות |
| **ספירה:** ללא | **משך:** קבוע |
| **עלות:** 3, +1 לכל עוצמה נוספת (+1 נק"נ) | **טווח:** 15 רגל/עוצמה |
| **אזור:** מטרה 1 | **התנגדות:** כוח רצון |

המטיל יכול לשנות את צורתו של יצור ממוקד גשמי אחד לזה של אחר, כאשר כל נקודת עוצמה משנה את הגודל (SIZ) בעד 5 נקודות. לכן, הפיכת אורק בגודל 16 לארנב בגודל 1 תדרוש 3 רמות עוצמה (15 נקודות גודל של הבדל). הנושא של לחש זה מורשה לבצע גלגול כוח רצון כדי להתנגד. יצורים גדולים (21-40) רגישים פחות לשינוי צורה, כאשר גלגול ההתנגדות שלהם קל, בעוד גלגול ההתנגדות עבור יצורים ענקיים (41+) הוא קל מאוד.

תהליך הטרנספורמציה כולו לוקח סיבוב מלא ויכול להיות מלחיץ למדי עבור היצור המדובר, מה שדורש גלגול כוח רצון שני כדי לשמור על האישיות המקורית שלו, כאשר כישלון מהמם את הנושא למשך 1d10 דקות, וכישלון קריטי מוביל למוות מהלם מנטלי. כל הכפלה או חצייה של הגודל המקורי של היצור הופכת את גלגול כוח הרצון לשמירה על האישיות לדרגה אחת קשה יותר, וכך גם שינוי סביבה מוחלט, כגון שינוי אדם לדג. גלגול מוצלח מאפשר לקורבן לשמור על ה-INT וה-CHA שלו וכן על כל מיומנות הדורשת מאפיינים אלו.

הטרנספורמציה מעניקה למקבל את צורת הנשימה של היצור המשוער, אם אינה רגילה; כל התקפה טבעית; וכל מצבי התנועה הארציים. הוא אינו מעניק יכולות מוגברות או קסומות כלשהן שבהן מחזיק היצור. לדוגמה, יצור שעבר פולימורף לדרקון לא יקבל את נשיפת הדרקון או היכולות דמויות הלחש של היצור, אך יקבל את היכולת לעוף, עורו הקשוח, נשיכתו הקטלנית, התקפות טפרים וכן הלאה. בנוסף, הקורבן מקבל את המיומנויות הפיזיות של הצורה החדשה כגון אתלטיקה, שרירים, עוף, שחייה, וכן נקודות הפגיעה ומנחה הנזק שלו. בהנחה שהפרט שעבר טרנספורמציה שמר על ה-INT שלו, הוא עדיין מאבד את היכולת לדבר, אלא אם כן הצורה החדשה מחזיקה ביכולת לבטא מילים. אלו שהיו מסוגלים להטיל לחשים בצורתם הקודמת עדיין יוכלו להטיל בצורה החדשה, בהנחה שהם עדיין מחזיקים ביכולת לייצר את המרכיבים המילוליים והסומטיים. במקרה של שינוי דרסטי, כגון שינוי מדו-רגלי לבעל ארבע רגליים, או חיית יבשה לחיית ים, למשל, מנחה המשחק צריך להרגיש חופשי להעניש בדרגת קושי אחת לפחות את השימוש בכל מיומנות שייקח זמן ללמוד תוך הסתגלות לצורה החדשה עד שתהיה מספיק זמן לתרגל. זה נכון במיוחד למיומנויות פיזיות כגון אתלטיקה, לא חמוש, שחייה, עוף, מיומנויות קרב, וכן הלאה.

גלגול כוח הרצון כדי לשמור על האישיות של האדם נדרש בכל יום שהנושא נשאר בטרנספורמציה עד לכישלון, מה שגורם לאדם סוף סוף להיכנע למנטליות של הצורה החדשה, כאשר ה-INT משתנה ל-INS במקרה של יצור לא תבוני. כל היכולות המיוחדות והקסומות שבבעלות הצורה החדשה שלא נרכשו קודם לכן, כגון התקפות מבט, נשיפות, וכן הלאה, זמינות כעת ליצור ככל שהטרנספורמציה הושלמה. דמויות שמאבדות את זהותן בדרך זו הופכות לדמויות ללא שחקן תחת שליטת מנחה המשחק.

לפני הכניעה הנפשית לטרנספורמציה, היצור שעבר פולימורף רגיש ל"פירוק קסם" כרגיל, ללא צורך בגלגול להתנגדות, שכן זה יהיה הרצון התת-מודע של האדם לחזור למצב רגיל. הטרנספורמציה דורשת גלגול כוח רצון נוסף כדי להתנגד למאמץ, עם כישלון שמהמם את הנושא ל-1d10 דקות, וכישלון קריטי מוביל למוות מהלם מנטלי.

אם הקורבן נכנע בעבר לצורה החדשה, עדיין ניתן להשתמש ב"פירוק קסם"; עם זאת, הקורבן ינסה להתנגד לחזרה לצורה הטבעית עם גלגול כוח רצון. כישלון בגלגול זה אומר שהקורבן משתנה בחזרה לצורה הטבעית, מה ש, כמובן, דורש גלגול כוח רצון נוסף כדי להתנגד להלם המנטלי מהטרנספורמציה. ברגע שאבדה, זהותה הטבעית של הקורבן אינה ניתנת להשגה עוד, ובמקום זאת הקורבן מניח שהצורה המוזרה והחייזרית אינה טבעית וכמהה לחזור לצורתו ה'רגילה' הקודמת. _למשל, אורק שעבר פולימורף לארנב ואימץ את זהות היצור יאמין שהוא כעת ארנב שהפך בצורה גסה למדי לאורק._ רק "משאלה", או קסם דומה אחר, יש לו סיכוי כלשהו לשחזר את זהותו של הקורבן ברגע שאבדה.

כל הציוד הלבוש והנישא נמס בקסם לתוך הצורה החדשה; עם זאת, במקרים מסוימים, מנחה המשחק עשוי לאפשר לחפצי קסם שעדיין יהיה ניתן להשתמש בהם בצורתו החדשה של היצור להישאר, כגון טבעת קסם או מגפיים. שים לב שזה דורש שהגודל החדש של היצור לא יהיה שונה באופן דרסטי מהמקורי. יש סיכוי של POW x 1% לכל חפץ קסם לבוש שאינו התקפי, בכפוף לאישור מנחה המשחק, להעביר את השפעותיו לצורה החדשה של היצור. יצור עם טבעת הגנה +1 למשל, עשוי לקבל בונוס +1 לנקודות השריון הטבעיות שלו. יצורים עם היכולת הטבעית להשתנות צורה, כגון דופלגנגרים ואנשי-זאב, ישתנו כרגיל, אך עשויים להניח את צורתם הרגילה לאחר סיבוב אחד. אם נהרג, יצור שעבר פולימורף חוזר לצורתו הטבעית, גם אם איבד בעבר את כל עקבות זהותו.
