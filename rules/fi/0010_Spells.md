## Loitsukuvaukset

---
#### Arviointi (Appraise)

(Divinaatio)

| | |
| :-- | :-- |
| **Rank:** Maagi 0 | **Loitsimisaika:** 1 vuoro |
| **Sfääri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 1 | **Kantama:** Kosketus |
| **Alue:** 1 esine | **Vastustus:** Ei mitään |

Arviointi mahdollistaa fyysisten tavaroiden laadun välittömän arvioinnin, kun niiden ENC on 'Things'-yksiköissä tai SIZ vastaa loitsijan POW-arvoa. Loitsu määrittää, ovatko identtisiltä näyttävät esineet samaa tai samankaltaista laatua, vai onko jokin niistä viallinen tai korkealaatuisempi. Loitsu ei toimi orgaanisiin asioihin, vain elottomiin esineisiin. Se ei myöskään määritä, mitä vikoja tai parannuksia esineessä on, ainoastaan sen, että niitä on olemassa. Se ei auta magian tunnistamisessa tai havaitsemisessa.

#### Panssari (Armor)

(Konjuraatio)

| | |
| :-- | :-- |
| **Rank:** Maagi 1 | **Loitsimisaika:** 1 kierros |
| **Sfääri:** Ei mitään | **Kesto:** Katso alta |
| **Kustannus:** 3 +1/Intensiteetti | **Kantama:** Kosketus |
| **Alue:** 1 kohde | **Vastustus:** Ei mitään |

Tämän loitsun myötä kohteelle suodaan näkymätön maagisen voiman kenttä, joka suojaa yhtä hyvin kuin suomuhaarniska ja antaa 4 panssaripistettä jokaiseen osumakohtaan. Sillä ei ole vaikutusta, jos se loitsitaan haarniskaa jo käyttävälle henkilölle. Se kuitenkin korvaa luonnollisen panssarin kestonsa ajan, olettaen että se tarjoaa paremman suojan. Jos se loitsitaan olennolle, jolla on enemmän kuin 4 pistettä luonnollista panssaria, se kasvattaa panssaripisteitä 1 pisteellä kaikissa sijainneissa. Tämä maaginen suoja ei haittaa liikkumista tai loitsimista. Loitsu kestää kunnes se kumotaan magialla, tai loitsija ottaa 8 pistettä vahinkoa yksittäisestä hyökkäyksestä +1 per lisäintensiteettitaso (katso alla oleva taulukko). Loitsija voi tietenkin halutessaan lopettaa loitsun milloin tahansa, ja niin on tehtävä nukkumista varten.

| Intensiteetti | Kustannus | Muuttuva vaikutus |
| :-: | :-: | :-- |
| 1 | 3 | 4 panssaripistettä; kestää kunnes ottaa 8 vahinkoa 1 hyökkäyksestä |
| 2 | 4 | 4 panssaripistettä; kestää kunnes ottaa 9 vahinkoa 1 hyökkäyksestä |
| 3 | 5 | 4 panssaripistett; kestää kunnes ottaa 10 vahinkoa 1 hyökkäyksestä |
| 4 | 6 | 4 panssaripistett; kestää kunnes ottaa 11 vahinkoa 1 hyökkäyksestä |
| +1 | +1 | Jatkaa etenemistä |

#### Astraaliloitsu (Astral Spell)

(Transmutaatio)

| | |
| :-- | :-- |
| **Rank:** Pappi 5, Maagi 5 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Astraali | **Kesto:** Katso alta |
| **Kustannus:** 3 +1/lisäintensiteetti | **Kantama:** Kosketus |
| **Alue:** Katso alta | **Vastustus:** Ei sovelleta |

Tämä loitsu sallii loitsijan ja jopa viiden muun henkilön (yksi per lisäintensiteettitaso) siirtyä Astraalitasolle. Kaikkien on kosketettava toisiaan ja muodostettava piiri loitsua loitsittaessa. Matkustajien ruumiit jäävät lähtötasolle, eivätkä he tyypillisesti tuo mukanaan vaatteita tai varusteita, lukuun ottamatta niitä, jotka itsessään säteilevät maagista auraa; nämä esineet muuttuvat astraaliversioiksi normaalista muodostaan. Kesto jatkuu, kunnes loitsija haluaa sen päättyvän. Ulkopuolinen voima, kuten *Dispel Magic*, voi kuitenkin päättää sen ennenaikaisesti. Loitsijan fyysisen ruumiin kuolema lopettaa loitsun myös aikaisin, mikä valitettavasti jättää loitsijan mukana olevat matkustajat jumiin.

#### Ennustus (Augury)

(Divinaatio)

| | |
| :-- | :-- |
| **Rank:** Pappi 2 | **Loitsimisaika:** 2 minuuttia |
| **Sfääri:** Divinaatio | **Kesto:** Välitön |
| **Kustannus:** 3/Intensiteetti | **Kantama:** 60 jalkaa |
| **Alue:** Loitsija | **Vastustus:** Ei sovelleta |

Tämä loitsu mahdollistaa sen määrittämisen, onko seuraavan 30 minuutin aikana tehtävä toiminto hyödyllinen vai haitallinen yksilön ja/tai ryhmän hyvinvoinnille. Enteiden tulkitsemiseen tarvitaan jonkinlainen keskityspiste, yleisimpiä ovat lohikäärmeen kynnet tai pienet luut, helmi tai puhdas kulta, jonka arvo on vähintään 100 GP ja joka on murskattu tai sulatettu. Loitsun maksimi-intensiteetti on 4. Pelinjohtajan tulee tehdä tämä heitto, sillä loitsija ei saisi koskaan tietää varmuudella, tulkittiinko tulokset oikein.

| Intensiteetti | Kustannus | Muuttuva vaikutus |
| :-: | :-: | :-- |
| 1 | 3 | Formidable Channel-taitotarkistus |
| 2 | 6 | Hard Channel-taitotarkistus |
| 3 | 9 | Standard Channel-taitotarkistus |
| 4 | 12 | Easy Channel-taitotarkistus |

Jos divinaatioheitto onnistuu, se antaa yhden seuraavista tuloksista:

| Augury | Implikaatio | 
| :-: | :-- |
| Kyllä | Toiminto on hyödyllinen |
| Ei | Toiminto on haitallinen |
| Kyllä ja ei | Toiminto on sekä hyödyllinen että haitallinen |
| Ei mitään | Toiminto on neutraali |

Fumble johtaa siihen, että Pelinjohtaja kertoo totuuden vastakohdan.

#### Torjunta (Avert)

(Abjuraatio)

| | |
| :-- | :-- |
| **Rank:** Pappi 0, Maagi 0 | **Loitsimisaika:** Välitön |
| **Sfääri:** Suojaus | **Kesto:** Välitön |
| **Kustannus:** 1 | **Kantama:** 60 jalkaa |

*Avert*-loitsua käytetään toisen Rank 0 -loitsun kumoamiseen kantaman sisällä. *Avert* voidaan loitsia reaktiivisesti neutraloimaan hyökkääviä Rank 0 -loitsuja käyttämällä Counter Magic -reaktiotoimintoa.

#### Hämmennys (Befuddle)

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rank:** Pappi 0, Maagi 0 | **Loitsimisaika:** 1 vuoro |
| **Sfääri:** Charm | **Kesto:** 30 minuuttia |
| **Kustannus:** 1 | **Kantama:** 60 jalkaa |
| **Alue:** 1 kohde | **Vastustus:** Willpower |

*Befuddle* aiheuttaa hämmennystä ruumiillisen kohteen mielessä. Kohteella on vaikeuksia ajatella selkeästi, se unohtaa missä se on, mitä se tekee ja miksi – usein ajatukset katkeilevat. Hämmennyksen alaiset kohteet voivat silti toimia itsepuolustuksessa, mutta eivät voi aloittaa mitään rakentavaa toimintaa ennen kuin loitsu päättyy. Mikä tahansa hyökkäys tai uhkaava toiminta katkaisee loitsun välittömästi, riippumatta siitä, oliko se suunnattu nimenomaan hämmentyneeseen kohteeseen.

#### Terämuuri (Blade Barrier)

(Evokaatio)

| | |
| :-- | :-- |
| **Rank:** Pappi 4 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Vartija, Luominen | **Kesto:** 3 kierrosta/Intensiteetti |
| **Kustannus:** 3+1/lisäintensiteetti | **Kantama:** 100 jalkaa |
| **Alue:** 5–30 jalan säde | **Vastustus:** Katso alta |

Tämä loitsu luo pyörivien miekkojen, tikareiden ja veitsien muurin, joka viiltää ja raatelee kiinteän pisteen ympärillä. Se aiheuttaa 1d8 vahinkoa 1d4+2 satunnaiseen osumakohtaan kenelle tahansa, joka kulkee alueen läpi. Haarniska tarjoaa vain puolet normaalista suojastaan. Maagiset panssaripisteet vähentävät vahinkoa normaalisti. Koska aseet pyörivät sokaisevalla nopeudella ja ovat tiiviissä muodostelmassa, niitä on mahdotonta parryoida tai väistää (Evade). Kilpeä voi käyttää passiiviseen osumakohtien torjumiseen. Tällöin heitetty vahinko tulee verrata kilven panssariin ja osumapisteisiin.

Loitsu voidaan loitsia puolustuksellisesti suojaamaan pappia tai liittolaisia, tai hyökkäävästi vihollisten vangitsemiseksi. Kuitenkin piiritetyt viholliset, jotka ovat 5 jalan sisällä muurin reunasta sen muodostuessa, voivat tehdä Evade-heiton paetakseen. Onnistuneesta heitosta huolimatta vastustaja päätyy maahan loitsualueen ulkopuolelle. Onnistunut heitto ei aiheuta vahinkoa; muuten he kärsivät täyden vaikutuksen.

#### Siunaus (Bless) (R)

(Konjuraatio)

| | |
| :-- | :-- |
| **Rank:** Pappi 1 | **Loitsimisaika:** 1 kierros |
| **Sfääri:** Kaikki | **Kesto:** 5 minuuttia |
| **Kustannus:** 1 | **Kantama:** 180 jalkaa |
| **Alue:** 25 jalan säde | **Vastustus:** Willpower |

Kun tämä loitsu loitsitaan, pappi siunaa liittolaisten ryhmän alueen sisällä. Vaikutuksen alaiset säteilevät loitsijan linjausta, joko hyvää tai pahaa. Neutraaliuden siunauksia ei ole. Kaikki liittolaiset alueella saavat +5 % bonuksen kaikkiin taito- ja vastustustarkistuksiin. Lisäksi heidän aseensa aiheuttavat +1d3 vahinkoa älykkäille epäkuolleille sekä muilta tasoilta tulleille olennoille, joilla on vastakkainen linjaus, kuten demoneille, paholaisille tai enkeleille. Huomaa, että vaikka animoidut epäkuolleet, kuten luurangot ja zombit, eivät ole luonnostaan pahoja, ne animoidaan yleensä pahan magian avulla, joten ne ovat alttiita tälle vahingolle.

Loitsun kääntöpuoli, *Kirous (Curse)*, mahdollistaa vihollisten kiroamisen, jolloin heidän taitonsa kärsivät päinvastaisista vaikutuksista. Kirotun aseen vahinko lasketaan rangaistuksena, eikä se voi laskea alle 1 pisteen.

#### Polttavat kädet (Burning Hands)

(Transmutaatio)

| | |
| :-- | :-- |
| **Rank:** Maagi 1 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 3+1/lisäintensiteetti | **Kantama:** 0 |
| **Alue:** 120 asteen kartio, 5 jalkaa pitkä | **Vastustus:** Evade |

Tämä loitsu saa liekit purkautumaan loitsijan käsistä 120 asteen kaaressa. Jos käytetään figuureja, *Burning Hands* vahingoittaa jokaista kohdetta, joka on loitsijan etupuolella. *Burning Hands* loitsiminen korkeammalla intensiteetillä vaatii korkeamman tason maagin. Vahinko perustuu loitsun intensiteettiin (maksimi 9) alla olevan taulukon mukaan. Onnistunut Evade-heitto (maahan heittäytyminen) sallii kohteen välttää vahingon. Artful Dodger -kyvyn omaavilla on mahdollisuus väistää ilman maahan heittäytymistä.

| Intensiteetti | Kustannus | Min. Rank | Muuttuva vaikutus |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 vahinko kaikkiin sijainteihin |
| 3 | 4 | 1 | 1d3+2 vahinko kaikkiin sijainteihin |
| 5 | 5 | 1 | 1d3+3 vahinko kaikkiin sijainteihin |
| 7 | 6 | 2 | 1d3+4 vahinko kaikkiin sijainteihin |
| 9 | 7 | 3 | 1d3+5 vahinko kaikkiin sijainteihin |

Haarniska ei suojaa, mutta maagiset panssaripisteet tai luonnollinen panssari vähentävät vahinkoa normaalisti. Tämä loitsu on tasapainotettu lyhyellä kantamalla, mikä pakottaa maagin vaarallisen lähelle.

Koska suuremmat olennot ovat yleensä suurempia kuin loitsun alue, niillä on vähemmän vaikuttuneita osumakohtia. SIZ 21–30 ottavat vahinkoa päähän, rintaan, vatsaan ja käsiin, kun taas SIZ 31+ ottavat vahinkoa vatsaan ja jalkoihin. Pelinjohtajien tulee säätää kohteita kohteen muodon mukaan. *Burning Hands* voi sytyttää syttyviä materiaaleja mahdollisuudella (vahinko x 5 %).

#### Rauhoittaminen (Calm)

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rank:** Pappi 0 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Charm | **Kesto:** Välitön |
| **Kustannus:** 1 | **Kantama:** Kosketus |
| **Alue:** 1 kohde | **Vastustus:** Willpower |

*Calm* yrittää vaimentaa SIZ 1-20 humanoidikohteen tunteita, varmistaen esimerkiksi, ettei rakastunut henkilö ole liian hyökkäävä tai ettei peloissaan oleva kilpailija huuda apua. #### Ketjusalama (Chain Lightning)

(Evokaatio)

| | |
| :-- | :-- |
| **Rank:** Maagi 4 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 3+1/lisäintensiteetti | **Kantama:** 50 jalkaa/Intensiteetti |
| **Alue:** Katso alta | **Vastustus:** Evade |

Loitsija vapauttaa 5 jalkaa leveän sähköpurkauksen, joka iskee yhteen kohteeseen 1d6+1 vahingolla per 2 intensiteettiä. Salama kaareutuu sitten lähimpään kohteeseen, ottaen -1 vahinkoa, ja sitten seuraavaan (-2 vahinkoa), ja niin edelleen. Se voi jopa kaareutua takaisin liittolaiseen tai loitsijaan! Vaikka ensimmäisen kohteen on oltava näkyvissä, myöhempien kohteiden ei tarvitse olla.

Jokaisella kaarella on oma 50 jalan kantama. Salama jatkaa iskemistään, kunnes se osuu kohteeseen, joka maadoittaa sen, tai kunnes ei ole enää kohteita.

| Intensiteetti | Kustannus | Muuttuva vaikutus |
| :-: | :-: | :-- |
| 1 | 3 | 50 jalan kantama; 1d6+1 vahinko |
| 2 | 4 | 100 jalan kantama; 1d6+1 vahinko |
| 3 | 5 | 150 jalan kantama; 2d6+2 vahinko |
| 4 | 6 | 200 jalan kantama; 2d6+2 vahinko |
| 5 | 7 | 250 jalan kantama; 3d6+3 vahinko |
| +1 | +1 | Jatkaa etenemistä |

#### Charm Person

(Enchantment (Charm))

| | |
| :-- | :-- |
| **Rank:** Maagi 1 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Ei mitään | **Kesto:** 1 viikko/Intensiteetti |
| **Kustannus:** 3+1/lisäintensiteetti | **Kantama:** 360 jalkaa |
| **Alue:** 1 elävä ihminen, demiaikuinen tai humanoidi | **Vastustus:** Willpower |

Kun tämä loitsu loitsitaan, yksi elävä (epäkuolleet eivät vaikuta) humanoidikohde SIZ 1-20 lopettaa kaiken vihamielisyyden loitsijaa ja hänen liittolaisiaan kohtaan ja tarjoutuu auttamaan ja suojelemaan heitä, jos vastustustarkistus epäonnistuu. Huomaa, että auttaminen voi johtaa tahattomiin tai negatiivisiin seurauksiin, sillä kohde toimii parhaaksi katsomallaan tavalla. Kohde ei koskaan tottele itsetuhoisia tai selvästi haitallisia käskyjä.

Kaikki vihamieliset teot kohdetta kohtaan rikkovat loitsun. Loitsijan on osattava kohteen kieltä antaakseen monimutkaisia käskyjä, mutta se ei ole välttämätöntä peruslumoukselle. Kun intensiteetti kasvaa, maksimikesto on 4 viikkoa.

| Intensiteetti | Kustannus | Min. Rank | Muuttuva vaikutus |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | Lumottu 1 viikko |
| 2 | 4 | 2 | Lumottu 2 viikkoa |
| 3 | 5 | 3 | Lumottu 3 viikkoa |
| 4 | 6 | 4 | Lumottu 4 viikkoa |
