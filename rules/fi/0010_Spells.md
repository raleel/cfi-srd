## Loitsukuvaukset

---
#### Appraise (Arviointi)

(Divinaatio)

| | |
| :-- | :-- |
| **Rasti:** Velho 0 | **Loitsimisaika:** 1 vuoro |
| **Sfääri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 1 | **Kantama:** Kosketus |
| **Alue:** 1 esine | **Vastus:** Ei mitään |

Appraise mahdollistaa fyysisten tavaroiden laadun välittömän arvioinnin, kun niiden yhteenlaskettu ENC on "asioissa" tai KOK on yhtä suuri kuin loitsijan MAH. Loitsu määrittää, ovatko samalta näyttävät esineet samaa tai samanlaista laatua, tai onko yksi tai useampi niistä viallinen tai korkealaatuisempi. Loitsu ei toimi orgaanisiin asioihin, vain elottomiin esineisiin. Se ei myöskään määritä, mitä vikoja tai parannuksia esineissä on; vain sen, että niitä on olemassa. Siitä ei ole hyötyä taikuuden tunnistamisessa tai havaitsemisessa.

#### Armor (Panssari)

(Konjuuraatio)

| | |
| :-- | :-- |
| **Rasti:** Velho 1 | **Loitsimisaika:** 1 kierros |
| **Sfääri:** Ei mitään | **Kesto:** Katso alla |
| **Kustannus:** 3 +1/Voimakkuus | **Kantama:** Kosketus |
| **Alue:** 1 kohde | **Vastus:** Ei mitään |

Kun tämä loitsu loitsitaan, kohde saa näkymättömän maagisen voimakentän, joka vastaa suojaukseltaan suomuhaarniskaa ja antaa 4 Panssaripistettä jokaiseen osumakohtaan. Sillä ei ole vaikutusta, jos se loitsitaan haarniskaa jo kantavaan hahmoon. Se kuitenkin ohittaa luonnollisen panssarin keston ajaksi, olettaen että se tarjoaa paremman suojan. Jos se loitsitaan olentoon, jolla on yli 4 pistettä luonnollista panssaria, se kasvattaa Panssaripisteitä 1 pisteellä kaikissa sijainneissa. Tämä maaginen suoja ei haittaa liikkumista tai loitsimista. Loitsu kestää, kunnes se kumotaan taikuudella tai loitsija kärsii 8 pistettä vahinkoa yhdestä hyökkäyksestä, +1 per lisävoimakkuuden taso (katso alla oleva taulukko). Loitsija voi tietenkin valita lopettaa loitsun milloin tahansa, ja hänen on tehtävä niin nukkuakseen.

| Voimakkuus | Kustannus | Muuttuva vaikutus |
| :-: | :-: | :-- |
| 1 | 3 | 4 Panssaripistettä; Kestää, kunnes kärsii 8 vahinkoa 1 hyökkäyksestä |
| 2 | 4 | 4 Panssaripistettä; Kestää, kunnes kärsii 9 vahinkoa 1 hyökkäyksestä |
| 3 | 5 | 4 Panssaripistettä; Kestää, kunnes kärsii 10 vahinkoa 1 hyökkäyksestä |
| 4 | 6 | 4 Panssaripistettä; Kestää, kunnes kärsii 11 vahinkoa 1 hyökkäyksestä |
| +1 | +1 | Jatka etenemistä |

#### Astral Spell (Astraaliloitsu)

(Transmutaatio)

| | |
| :-- | :-- |
| **Rasti:** Pappi 5, Velho 5 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Astraali | **Kesto:** Katso alla |
| **Kustannus:** 3 +1/lisävoimakkuus | **Kantama:** Kosketus |
| **Alue:** Katso alla | **Vastus:** Ei sovellu |

Tämä loitsu antaa loitsijalle ja jopa viidelle muulle henkilölle (yksi per lisävoimakkuuden taso) mahdollisuuden siirtyä Astraalitasolle. Kaikkien on kosketettava toisiaan ja muodostettava piiri loitsua loitsittaessa. Matkailijoiden ruumiit jäävät alkuperäiselle tasolle, eivätkä he yleensä tuo mukanaan vaatteita tai varusteita, paitsi niitä, jotka itsessään säteilevät maagista auraa; nämä esineet muuttuvat normaalin muotonsa astraalisiksi vastineiksi. Kesto kestää, kunnes loitsija haluaa sen loppuvan. Ulkopuolinen voima, kuten Dispel Magic, voi kuitenkin päättää sen ennenaikaisesti. Loitsijan fyysisen ruumiin tappaminen päättää myös loitsun varhain, vaikka tällä on ikävä sivuvaikutus: loitsijan seurassa olevat matkailijat jäävät jumiin.

#### Augury (Ennustus)

(Divinaatio)

| | |
| :-- | :-- |
| **Rasti:** Pappi 2 | **Loitsimisaika:** 2 minuuttia |
| **Sfääri:** Divinaatio | **Kesto:** Välitön |
| **Kustannus:** 3/Voimakkuus | **Kantama:** 60 jalkaa |
| **Alue:** Loitsija | **Vastus:** Ei sovellu |

Tämä loitsu antaa loitsijalle mahdollisuuden määrittää, onko tietty seuraavan 30 minuutin aikana suoritettava toiminto hyödyllinen vai haitallinen yksilön ja/tai seurueen hyvinvoinnille. Enteiden havaitsemiseen tarvitaan jonkinlainen polttopiste, joista yleisimpiä ovat lohikäärmeen kynnet tai pienemmät luut, helmi, tai puhdas kulta, jonka arvo on vähintään 100 GP, ja joka on murskattu tai sulatettu. Loitsun maksimivoimakkuus on 4. Pelinjohtajan tulisi suorittaa tämä heitto, sillä loitsija ei saisi koskaan tietää varmasti, tulkittiinko tulokset oikein.

| Voimakkuus | Kustannus | Muuttuva vaikutus |
| :-: | :-: | :-- |
| 1 | 3 | Vaativa Kanavointi-taitotarkistus |
| 2 | 6 | Vaikea Kanavointi-taitotarkistus |
| 3 | 9 | Normaali Kanavointi-taitotarkistus |
| 4 | 12 | Helppo Kanavointi-taitotarkistus |

Jos divinaatioheitto onnistuu, se antaa yhden seuraavista tuloksista:

| Augury | Implikaatio | 
| :-: | :-- |
| Kyllä | Toiminto on hyödyllinen |
| Ei | Toiminto on haitallinen |
| Kyllä ja ei | Toiminto on sekä hyödyllinen että haitallinen |
| Ei mitään | Toiminto ei ole hyödyllinen eikä haitallinen |

Fumble-tuloksen pitäisi johtaa siihen, että pelinjohtaja kertoo totuuden vastakohdan.

Avertia käytetään kumoamaan toinen Rasti 0 -loitsu kantaman sisällä. Avert voidaan loitsia reaktiivisesti neutraloimaan hyökkääviä Rasti 0 -loitsuja käyttämällä Vastataika-reaktiotoimintoa.

#### Befuddle (Hämmennys)

(Lumous (Viehätys))

| | |
| :-- | :-- |
| **Rasti:** Pappi 0, Velho 0 | **Loitsimisaika:** 1 vuoro |
| **Sfääri:** Viehätys | **Kesto:** 30 minuuttia |
| **Kustannus:** 1 | **Kantama:** 60 jalkaa |
| **Alue:** 1 kohde | **Vastus:** Tahto |

Befuddle aiheuttaa hämmennystä fyysisen kohteen mielessä. Loitsun kohteella on vaikeuksia ajatella selkeästi; se unohtaa missä se on, mitä se tekee ja miksi – vajoten usein irrallisiin ajatusketjuihin. Hämmennetyt kohteet voivat yhä toimia itsepuolustuksessa, mutta eivät voi aloittaa mitään rakentavaa toimintaa ennen kuin loitsu päättyy. Mikä tahansa hyökkäys tai uhkaava toiminta rikkoo loitsun välittömästi, riippumatta siitä, kohdistettiinko se nimenomaisesti hämmennettyyn kohteeseen.

#### Blade Barrier (Terämuuri)

(Evokaatio)

| | |
| :-- | :-- |
| **Rasti:** Pappi 4 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Vartija, Luominen | **Kesto:** 3 kierrosta/Voimakkuus |
| **Kustannus:** 3+1/lisävoimakkuus | **Kantama:** 100 jalkaa |
| **Alue:** 5-30 jalan säde | **Vastus:** Katso alla |

Tämä loitsu luo kiertävien viiltävien miekkojen, tikarien ja veitsien muurin, joka piiskaa ja viiltää kiinteän pisteen ympärillä ja aiheuttaa 1d8 pistettä vahinkoa 1d4+2 satunnaiseen osumakohtaan kenelle tahansa, joka kulkee vaikutusalueen läpi. Haarniska tarjoaa vain puolet normaalista suojastaan. Maagiset Panssaripisteet vähentävät vahinkoa normaalisti. Koska aseet pyörivät sokaisevalla nopeudella ja ovat tiiviisti pakattuja, niitä on mahdotonta torjua tai väistää. Kilpeä voi käyttää passiiviseen osumakohtien estämiseen normaalisti. Tässä tapauksessa muista verrata heitettyä vahinkoa kilven panssariin ja osumapisteisiin.

Loitsu voidaan loitsia puolustuksellisesti papin tai yhden tai useamman liittolaisen suojelemiseksi tai hyökkäävästi vihollisten vangitsemiseksi. Kuitenkin piiritetyt viholliset, jotka ovat viiden jalan etäisyydellä muurin reunasta sen muodostuessa, voivat tehdä Väistö-heiton paetakseen. Onnistumisesta riippumatta vastustaja päätyy makaamaan maahan, aivan vaikutusalueen ulkopuolelle. Onnistunut heitto tarkoittaa, ettei vahinkoa synny; muuten he kärsivät täyden vaikutuksen.

#### Bless \(R\) (Siunaus)

(Konjuuraatio)

| | |
| :-- | :-- |
| **Rasti:** Pappi 1 | **Loitsimisaika:** 1 kierros |
| **Sfääri:** Kaikki | **Kesto:** 5 minuuttia |
| **Kustannus:** 1 | **Kantama:** 180 jalkaa |
| **Alue:** 25 jalan säde | **Vastus:** Tahto |

Kun tämä loitsu loitsitaan, pappi siunaa ryhmän liittolaisia vaikutusalueen sisällä. Vaikutuksen alaiset säteilevät loitsijan linjausta, joko Hyvää tai Pahaa. Neutraliteetin siunauksia ei ole olemassa. Kaikki liittolaiset loitsun säteellä saavat +5 % bonuksen kaikkiin taito- ja Vastusheittoihin. Lisäksi heidän aseensa aiheuttavat +1d3 vahinkoa älykkäille epäkuolleille sekä ulkomaailman olennoille, joilla on loitsijalle vastakkainen linjaus, kuten demoneille, paholaisille tai enkeleille. Huomaa, että vaikka animoidut epäkuolleet, kuten luurangot ja zombit, eivät ole luonnostaan pahoja, ne animoidaan yleensä pahalla taialla, joten ne altistuvat tälle vahingolle.

Tämän loitsun käänteinen muoto, Kiroaminen, mahdollistaa papin kirota vihollisia, jolloin huomioidut taidot kärsivät edellä mainittujen hyötyjen käänteisestä vaikutuksesta. Kirotun aseen vahinko lasketaan rangaistuksena, eikä tämä vahinko voi johtaa alle 1 pisteeseen.

#### Burning Hands (Polttavat kädet)

(Transmutaatio)

| | |
| :-- | :-- |
| **Rasti:** Velho 1 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 3+1/lisävoimakkuus | **Kantama:** 0 |
| **Alue:** 120 asteen kartio, 5 jalkaa pitkä | **Vastus:** Väistö |

Tämä loitsu aiheuttaa liekkien ampumisen loitsijan käsistä 120 asteen kaaressa. Jos käytät figuureja taistelussa, Burning Hands vahingoittaa jokaista kohdetta, joka vie 1 loitsijan eturuuduista. Burning Handsin loitsiminen korkeammilla Voimakkuuden tasoilla vaatii korkeamman rastin velhon. Tämä vahinko nielaisee kaikki alueella olevat kohteet loitsun Voimakkuuteen perustuvalla vahingolla, maksimivoimakkuuteen 9, seuraavasti. Onnistunut Väistö-heitto, itsensä maahan heittäminen, sallii uhrin välttyä vahingolta. Joku, jolla on Taitava Väistelijä -kyky, voi valita väistää menemättä makuulle.

| Voimakkuus | Kustannus | Min Rasti | Muuttuva vaikutus |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 pistettä vahinkoa kaikkiin osumakohtiin |
| 3 | 4 | 1 | 1d3+2 pistettä vahinkoa kaikkiin osumakohtiin |
| 5 | 5 | 1 | 1d3+3 pistettä vahinkoa kaikkiin osumakohtiin |
| 7 | 6 | 2 | 1d3+4 pistettä vahinkoa kaikkiin osumakohtiin |
| 9 | 7 | 3 | 1d3+5 pistettä vahinkoa kaikkiin osumakohtiin |

Päällä oleva haarniska ei suojaa, mutta maagiset Panssaripisteet tai olennon luonnollinen panssari vähentävät vahinkoa normaalisti. (Lumoaminen)

| | |

Jos se antaa vain itsensä pudota, lentävä olento voi käyttää siipiään säätääkseen laskeutumispistettään 5 jalkaa kierrosta kohden.

Jos loitsu kuluu loppuun ennen kuin vaikutuksen alaiset ovat laskeutuneet, he palaavat normaaliin putoamisnopeuteen ja putoamisvahinko lasketaan siitä hetkestä alkaen.

Loitsun välittömän loitsimisajan vuoksi maagi voi käyttää *Feather Fall*-loitsua sekä reaktiivisesti että proaktiivisesti. Tämä sallii loitsun suojata odottamattomilta putoamisilta tai jopa keskeyttää toisen toiminnon hidastaakseen ammuksia, kuten nuolia tai heitettyjä keihäitä, jotka sitten kelluvat kevyesti maahan hyökkääjän ja kohteen välissä aiheuttamatta vahinkoa.

Tämä loitsu sallii loitsijan yrittää kutsua familiar-hengen, josta tulee isäntänsä aistien ja voiman jatke. Familiarit voivat keskustella isäntänsä kanssa telepaattisesti ja ovat myös hyviä vartijoita ja tiedustelijoita. Familiarin kuoleminen aiheuttaa tiettyjä riskejä maaginkäyttäjälle heidän läheisen yhteytensä vuoksi, mikä tekee familiarin hankkimisesta matalan asteen vaaran.

Kutsuakseen familiarin maaginkäyttäjän on aloitettava rituaali pitämällä hiilihiillos hehkuvana, ja kun se palaa voimakkaasti, lisättävä 100 kultarahan arvosta suitsukkeita. Näiden ainesosien palaessa loitsijan on jatkettava rituaalia, kunnes familiar saapuu tai loitsimisaika umpeutuu ilman menestystä.

Vaikka tämä loitsu loitsittaisiin onnistuneesti, mahdollisuus siihen, että sopiva familiar vastaa maaginkäyttäjän kutsuun, on vain 50 %, ja maaginkäyttäjä voi yrittää tätä loitsua vain kerran vuodessa. Ei ole kontrollia sen suhteen, minkä tyyppinen olento kutsuun vastaa, mutta se mikä saapuu, on uskollinen palvelija ja liittolainen. Olennon tehtävä on vastata kutsuun, joten tietyllä alueella, jonka tiedetään olevan tietyn tyyppisen olennon asuttama, olo _ei_ takaa loitsijalle menestystä.

Jos olento vastaa loitsijan kutsuun, maaginkäyttäjän on silti uhrattava 1 kokemusheitto luodakseen henkisen linkin itsensä ja familiarin välille. Kun tämä on tehty, rituaali on valmis.

#### Tulikilpi

(Evokaatio)

| | |
| :-- | :-- |
| **Taso:** Maagi 3 | **Luoja-aika:** 2 toimintoa |
| **Sfääri:** Ei mitään | **Kesto:** 2 minuuttia/intensiteetti |
| **Kustannus:** 3+1/lisäintensiteetti | **Kantama:** 0 |
| **Alue:** Loitsija | **Vastus:** N/A |

Tämä loitsu luo hohdattomien liekkien kilven, joka ympäröi loitsijan mutta ei itsessään aiheuta vahinkoa. Sen sijaan liekit suojaavat vastaanottajaa joko tulelta tai kylmältä, riippuen siitä, kumpi kahdesta muunnelmasta on muistissa: Chill Shield, joka luo sinisiä tai vihreitä liekkejä ja suojaa kuumuudelta ja tulivahingoilta, tai Warm Shield, joka luo violetteja tai sinisiä liekkejä ja suojaa kylmältä ja jääpohjaisilta vahingoilta. Liekkien väri tulisi määrittää satunnaisesti 50 % mahdollisuudella kumpaankin, sillä se tosiasia, että molemmat tyypit voivat lähettää sinisiä liekkejä, luo epävarmuutta hyökkääjässä. Päätös siitä, kumpi opetellaan, tehdään loitsuja valmisteltaessa, ja molemmat voidaan opetella haluttaessa. Nämä liekit eivät anna lämpöä ja ne valaisevat vain puolet soihdun kirkkaudesta. Kummankin muunnelman yksityiskohdat on esitetty alla.

- **Chill Shield:** Nämä liekit tuntuvat koskettaessa viileiltä ja vähentävät kaikki tuli- tai kuumuuspohjaiset vahingot puoleen kokonaismäärästä. Onnistunut Vastus-heitto mitätöi kaiken vahingon. Vastus-heitto on yhden asteen helpompi, ja Väistön tapauksessa se ei kaada puolustajaa.
- **Warm Shield:** Nämä liekit tuntuvat koskettaessa lämpimiltä ja vähentävät kaikki kylmyyteen perustuvat vahingot puoleen kokonaismäärästä. Onnistunut Vastus-heitto mitätöi kaiken vahingon. Vastus-heitto on yhden asteen helpompi, ja Väistön tapauksessa se ei kaada puolustajaa.

Lähitaisteluhyökkäykset kumpaa tahansa muunnelmaa käyttävää vastaan, olivatpa ne aseistettuja tai aseettomia, aiheuttavat normaalia vahinkoa, ellei käytetä jotakin elementtiä, jolta on suojattu. Tässä tapauksessa loitsija on suojattu hyökkäyksen elementaaliselta osalta, ja hyökkääjä vastaanottaa vahinkoa, joka vastaa aiheutettua vahinkoa. Hyökkääjän yllä oleva haarniska ei tarjoa suojaa, mutta taianomaiset haarniskapisteet tai olennon luonnollinen haarniska vähentävät vahinkoa normaalisti. Olennot, joilla on Luonnollinen taikavastus, voivat hälventää Tulikilven onnistuneella MAJ-heitolla, kun vastaanottajaa lyödään ensimmäisen kerran. Jos Taikavastus-heitto epäonnistuu, vastustaja ei voi myöhemmin mitätöidä Tulikilpeä.

Portin luominen vaatii loitsijalta kutsuttavan olennon todellisen nimen, joka on tyypillisesti olento jostakin muusta olemassaolon tasosta, kuten demoni tai paholainen, enkeli, puolijumala tai jopa jumala. Varausten omaavat esineet paljastavat tällä hetkellä käytettävissä olevan kokonaismäärän sekä normaalin maksimin, samoin kuin esineet, joilla on Taikapistematriisi.

Kirotut esineet aktivoituvat yleensä, kun varustetta käytetään tai pidetään yllä ensimmäistä kertaa; siksi tämän loitsun loitsiminen altistaa taikakäyttäjän mahdollisille kirouksille. Jos Arkaaninen loitsimistaitotesti onnistuu, taikakäyttäjä saa tehdä Tahdonvoimatestin välttääkseen kirouksen vaikutukset. Tämä ei kuitenkaan poista kirousta esineestä, mutta se sallii loitsijan poistaa esineen ilman, että se vaikuttaa häneen.

Vähintään 100 GP:n arvoinen helmi jauhetaan pölyksi ja kulutetaan muiden arkipäiväisten loitsukomponenttien ohella tämän loitsun loitsimiseksi. Jos Onnenkivi jauhetaan ja lisätään infuusioon, Arkaanisen loitsimisheiton vaikeusaste on normaali, ja kaikki jokaisen minuutin aikana käsitellyn esineen maagiset ominaisuudet loitsun Keston aikana opitaan automaattisesti ilman lisäheittoja.

#### Magic Missile

(Evokaatio)

| | |
| :-- | :-- |
| **Taso:** Mage 1 | **Loitsimisaika:** 1 toiminto |
| **Piiri:** Ei mitään | **Kesto:** Välitön |
| **Kustannus:** 1/Voimakkuus | **Kantama:** 100 jalkaa/Voimakkuus |
| **Alue:** 1-5 kohdetta | **Vastus:** Katso alta |

Kun tämä loitsu langetetaan, yksi tai useampi maagisen energian ammus syöksyy taikuuden käyttäjän sormenpäistä ja osuu kohteeseen. Ammusten enimmäismäärä perustuu loitsijan Arcane Casting -taitotasoon, jolloin toinen ammus syntyy 60 %:n taitotasolla, kolmas 70 %:n, neljäs 80 %:n ja viides ja viimeinen ammus 90 %:n kohdalla. Näiden ammusten luomiseksi loitsu on langetettava voimakkuudella, joka vastaa haluttujen ammusten määrää. Esimerkiksi alle 60 %:n taitotasolla taikuuden käyttäjä, joka langettaa Magic Missilen 3 voimakkuudella, saavuttaa pidemmän kantaman, mutta vain yksi ammus syntyy. 70 %:n taitotasolla oleva taikuuden käyttäjä voisi langettaa loitsun samalla 3 voimakkuudella ja saavuttaa saman kantaman, mutta kykenee luomaan 3 ammusta. Tämän loitsun enimmäisvoimakkuus on 5. Katso alla oleva taulukko.

Magic Missile osuu erehtymättömästi, vaikka kohde olisi lähitaistelussa tai sillä olisi osittainen suoja. Näitä ammuksia ei voi väistää; täydellisessä suojassa olevaa vastustajaa ei kuitenkaan voi kohdistaa tällä loitsulla. Shield-loitsu heijastaa automaattisesti Magic Missilet, olettaen, että kohde on tietoinen loitsijasta ja/tai kääntynyt loitsijaa kohti. Magic Missilet aiheuttavat 1d6+1 vahinkopistettä eikä päällä oleva panssari suojaa, mutta olennon luonnollinen panssari tai maagiset panssaripisteet vähentävät vahinkoa normaalisti. Magic Missilet eivät aiheuta vahinkoa elottomille esineille, kuten oville, lukoille ja niin edelleen.

Ammuessaan useita ammuksia, loitsija voi antaa niiden osua yhteen olentoon tai kohdistaa ne useisiin olentoihin. Jokainen Magic Missile osuu satunnaiseen osumakohtaan – tiettyjä osumakohtia ei voi valita. Loitsijan on määritettävä kunkin ammuksen yksittäiset kohteet ennen kuin he heittävät vahinkoa.

#### Magic Mouth

(Muuntautuminen)

| | |
| :-- | :-- |
| **Taso:** Mage 2 | **Loitsimisaika:** 1 minuutti |
| **Piiri:** Ei mitään | **Kesto:** Katso alta |
| **Kustannus:** 3, +1/lisävoimakkuus | **Kantama:** 30 jalkaa |
| **Alue:** 1 esine | **Vastus:** NA |

Tämä loitsu luo suun esineeseen, joka ilmestyy maagisesti, kun loitsija on asettanut sen laukeamaan tietystä tapahtumasta tai ajasta loitsua langetettaessa. Tämä suu lausuu sitten loitsijan loitsimisen hetkellä valitseman ennalta määritetyn lauseen. Tässä lauseessa saa olla enintään 25 sanaa, ja suu lausuu ne noin yhden sanan sekuntivauhdilla. Suu ei voi lausua voimasanoja tai langettaa loitsuja.

Tämä loitsu voidaan langettaa mihin tahansa tavallisesti elottomaan esineeseen, pilarista tai puusta kiviseinään tai arkkuun; se on kuitenkin erityisen tehokas, kun se langetetaan patsaaseen, sillä patsas itse näyttäisi siltä kuin se puhuisi. Sitä ei voi langettaa mihinkään elävään olentoon, jolla on minkäänlaista älyä tai vaistoa. Tämä koskee niitä, jotka olivat aiemmin elossa. Tätä loitsua langetettaessa taikuuden käyttäjä määrittää tilanteen, joka aktivoi lumouksen. Se voidaan suunnitella laukeamaan mistä tahansa, aina puhutusta sanasta melun luomiseen. Se voi olla niin yleinen kuin "kun seuraava henkilö astuu tähän huoneeseen..." tai niin spesifi kuin "kun Sedonan naispuolinen pappi tulee 10 jalan etäisyydelle patsaasta käytävän päässä lauantaina...". Laukaiseva vaikutus ei voi olla jotain, mitä ei voi havaita ei-maagisesti, kuten näkymätön olento, olennon suuntaus, taito, luokka jne. Se voisi kuitenkin määrittää käytettävän vaatetuksen. Suurin etäisyys, josta loitsu voidaan laukaista, on 25 jalkaa per voimakkuus.

Tämän loitsun kesto on pysyvä, kunnes lumous aktivoituu, ja sen jälkeen loitsu päättyy.

#### Polymorph Other

(Transmutaatio)

| | |
| :-- | :-- |
| **Taso:** Maagi 3 | **Loitsimisaika:** 2 toimintoa |
| **Piiri:** Ei mitään | **Kesto:** Pysyvä |
| **Kustannus:** 3, +1/lisäintensiteetti (+1 EXP) | **Kantama:** 15 jalkaa/intensiteetti |
| **Alue:** 1 kohde | **Vastus:** Tahdonvoima |

Loitsija voi muuttaa yhden ruumiillisen kohdeolennon muodon toiseksi, jokaisen intensiteettipisteen muuttaessa KOK-arvoa jopa 5 pistettä. Siten, orkin muuttaminen KOK 16:sta KOK 1:n kaniksi vaatisi 3 intensiteettitasoa (15 KOK-pisteen ero). Tämän loitsun kohde saa tehdä Tahdonvoima-heiton vastustaakseen. Suuret olennot (KOK 21-40) ovat vähemmän alttiita muodonmuutokselle, niiden vastusheiton ollessa helppo, kun taas valtavien olentojen (KOK 41+) vastusheitto on erittäin helppo.

Koko muutosprosessi vie täyden kierroksen ja voi olla melko stressaava kyseiselle olennolle, vaatien toisen Tahdonvoima-heiton säilyttääkseen alkuperäisen persoonallisuutensa, jolloin epäonnistuminen tainnuttaa kohteen 1d10 minuutiksi ja moka (Fumble) johtaa kuolemaan henkisen shokin vuoksi. Olennon alkuperäisen KOK-arvon jokainen kaksinkertaistuminen tai puolittuminen tekee persoonallisuuden säilyttämisestä tehdystä Tahdonvoima-heitosta yhden vaikeustason vaikeamman, samoin kuin täydellinen ympäristön muutos, kuten henkilön muuttaminen kalaksi. Onnistunut heitto sallii uhrin säilyttää ÄLY- ja KAR-arvonsa sekä kaikki näitä ominaisuuksia vaativat taidot.

Muutos myöntää saajalle oletetun olennon hengitystavan, jos se poikkeaa normaalista; kaikki luonnolliset hyökkäykset; ja kaikki maalliset liikkumismuodot. Se ei myönnä mitään olennon hallitsemia korotettuja tai taianomaisia kykyjä. Esimerkiksi lohikäärmeeksi muutettu olento ei saa lohikäärmeen hengityshyökkäystä tai loitsumaisia kykyjä, mutta saa kyvyn lentää, kovan nahan, tappavan purennan, kynsihyökkäykset ja niin edelleen. Lisäksi uhri saa uuden muodon fyysiset taidot, kuten yleisurheilu, voimankäyttö, lentäminen, uiminen, sekä sen osumapisteet ja vahinkomuuttujan. Olettaen, että muutettu yksilö säilytti ÄLY-arvonsa, se menettää silti kykynsä puhua, ellei uudella muodolla ole kykyä artikuloida sanoja. Ne, jotka pystyivät heittämään loitsuja aiemmassa muodossaan, pystyisivät edelleen heittämään niitä uudessa muodossa, olettaen että niillä on yhä kyky tuottaa verbaaliset ja somaattiset komponentit. Radikaalissa muutoksessa, kuten muuttuminen kaksijalkaisesta nelijalkaiseksi tai maaeläimestä merieläimeksi, pelinjohtaja voi vapaasti penalisoida ainakin yhdellä vaikeustasolla sellaisten taitojen käyttöä, joiden oppiminen vie aikaa uuteen muotoon totutellessa, kunnes on ollut riittävästi aikaa harjoitella. Tämä pätee erityisesti fyysisiin taitoihin, kuten yleisurheiluun, aseettomaan taisteluun, uimiseen, lentämiseen, taistelutaitoihin ja niin edelleen.

Tahdonvoima-heitto persoonallisuuden säilyttämiseksi vaaditaan joka päivä, kunnes epäonnistutaan, jolloin henkilö lopulta murtuu uuden muodon mentaliteetin alle, ÄLY-arvon muuttuessa INS-arvoksi ei-älykkään olennon tapauksessa. Kaikki uuden muodon omistamat erityiset ja taianomaiset kyvyt, joita ei ollut aiemmin hankittu, kuten katsehyökkäykset, hengityshyökkäykset ja niin edelleen, ovat nyt olennon käytettävissä muutoksen ollessa täydellinen. Hahmoista, jotka menettävät identiteettinsä tällä tavoin, tulee pelinjohtajan hallitsemia ei-pelaajahahmoja.

Ennen henkistä murtumista muutoksen alla, muutettu olento on altis Dispel Magic -loitsulle normaalisti, ilman vastusheittoa, sillä se olisi yksilön alitajuinen halu palata normaaliksi. Muutos vaatii toisen Tahdonvoima-heiton vastustaakseen rasitusta, epäonnistumisen tainnuttaessa kohteen 1d10 minuutiksi ja mokan johtaessa kuolemaan henkisen shokin vuoksi.

Jos uhri oli aiemmin murtunut uuden muodon alle, Dispel Magic -loitsua voidaan yhä käyttää; kuitenkin uhri yrittää vastustaa luonnolliseen muotoon palaamista Tahdonvoima-heitolla. Tämän heiton epäonnistuminen tarkoittaa, että uhri muuttuu takaisin luonnolliseen muotoonsa, mikä tietenkin vaatii toisen Tahdonvoima-heiton vastustaakseen muutoksesta johtuvaa henkistä shokkia. Kun uhri on menettänyt luonnollisen identiteettinsä, se ei ole enää saavutettavissa; sen sijaan uhri olettaa, että vieras ja muukalainen muoto on luonnollinen, ja kaipaa päästä takaisin aiempaan "normaaliinsa". _Esimerkiksi orkki, joka muutettiin kaniksi ja omaksui olennon identiteetin, uskoisi olevansa nyt kani, joka on melko töykeästi muutettu orkiksi._ Vain Wish tai muu vastaava taikuus voi mahdollisesti palauttaa uhrin identiteetin, kun se on menetetty.

Kaikki ylläpidetyt ja kannetut varusteet sulautuvat taianomaisesti uuteen muotoon; kuitenkin joissakin tapauksissa pelinjohtaja voi sallia taikaesineiden, joita voitaisiin yhä käyttää olennon uudessa muodossa, pysyvän, kuten taikasormus tai saappaat. Huomaa, että tämä vaatii, ettei olennon uusi KOK ole valtavan erilainen alkuperäisestä. Jokaiselle ylläpidetylle ei-hyökkäävälle taikaesineelle on olemassa MAH x1 % mahdollisuus siirtää sen vaikutukset olennon uuteen muotoon, pelinjohtajan hyväksynnällä. Olento, jolla on esimerkiksi +1 suojaussormus, voisi saada +1 bonuksen luonnollisiin panssaripisteisiinsä. Olennot, joilla on luonnollinen kyky muodonmuutokseen, kuten doppelgängerit ja ihmissudet, muutetaan normaalisti, mutta ne voivat palata normaaliin muotoonsa 1 kierroksen jälkeen. Jos polymorfoitu olento tapetaan, se palautuu luonnolliseen muotoonsa, vaikka se olisi aiemmin menettänyt kaikki identiteettinsä rippeet.

Tämän loitsun voi langettaa olennon ruumiiseen, joka on ollut kuollut vähemmän kuin 24 tuntia per Intensiteettitaso. Jos kohteen suuntaus oli muu kuin paha, kohde voi vastustaa loitsua Vastustavalla Tahto-heitolla ja onnistuessaan mitätöidä loitsun vaikutukset. Tämä johtuu siitä, että vainajan sielu tai henki palaa harvoin halukkaasti elävien kirjoihin saavutettuaan iankaikkisen palkintonsa. Pelinjohtaja voi päättää sivuuttaa heiton, jos kohteella on keskeneräisiä asioita, hän ei voi erota rakastetustaan tai hänellä on jokin muu sankarillinen syy elää.

Lopuksi, Kuolleista herättäminen ei vaikuta olentoon, joka on saavuttanut luonnollisen elinikänsä ja kuollut vanhuuteen.

Kuolleista herättäminen on erittäin rasittavaa kohteelle, joka taantuu Uupumustasolle "Toimintakyvytön" 24 tunnin ajaksi jokaiselta päivältä, jonka hän oli kuollut. Väsymyksen parantaminen -loitsulla ei ole vaikutusta potilaaseen tämän toipumisaikana. Tämän jälkeen hahmo toipuu väsymyksestä normaalisti ja ilman rajoituksia.

Olento ei ainoastaan saa elämäänsä takaisin, vaan se palautetaan täyteen voimaan ja parannetaan vammoistaan, jopa menetettyjen raajojen palautuessa. Vain hyvin pieni osa alkuperäisestä olennosta tarvitsee olla jäljellä, jotta loitsu olisi tehokas. Esimerkiksi *Henkiinherätystä* voidaan käyttää tuomaan olento takaisin kuolleista 145 vuoden kuluttua, vaikka jäljellä olisi vain sormiluu, jos loitsu loitsitaan 8 intensiteetillä. Herätetty yksilö ei tarvitse lepoaikaa ja on täysin toimintakykyinen välittömästi. Loitsulla ei ole vaikutusta olentoon, joka on kuollut luonnollisiin syihin eliniän päättyessä.

Jos kohteen suuntaus oli muu kuin paha, he voivat vastustaa loitsua vastustavalla Älyluonteen heitolla ja, jos onnistuvat, kumota vaikutukset. Tämä johtuu siitä, että edesmenneen sielu tai henki on harvoin halukas palaamaan elävien kirjoihin kerran saavutettuaan iankaikkisen palkintonsa. Pelinjohtaja voi kuitenkin päättää jättää heiton väliin, jos kohteella on keskenjääneitä asioita, hän ei voi erota rakkaimmastaan tai hänellä on jokin muu sankarillinen syy elää. Pahan sielun kohdalla, joka palaisi mieluummin kuin kärsisi ikuisen kadotuksen, kyse ei ole edesmenneen Älyluonteen vastustuksesta, vaan demonin, paholaisen tai vastaavan tahon, joka vastaa rangaistuksesta, tahdosta. Tässä tapauksessa loitsijan on ylitettävä rankaisijan Älyluonne. Jos tätä ei tunneta, oleta sen olevan vähintään 20 pistettä korkeampi kuin edesmenneen, kuvastaen sitä, että mitä vahvempi sielun tahto on, sitä voimakkaampi olento on asetettu vastaamaan hänen kadotuksestaan. Jos loitsija onnistuu, kohde on herätetty onnistuneesti, kun taas epäonnistunut heitto johtaa siihen, että uhri on joko haluton tai kykenemätön palaamaan.

*Henkiinherätys* on hyvin uuvuttava, vanhentaen pappia 3 % hänen tyypillisestä eliniästään (3 vuotta ihmisloitsijan kohdalla). Katso säännöt kohdasta [Vanheneminen](0007_Game_System.md?id=aging).

Käänteisenä, *Tuho*, voidaan käyttää tappamaan yksi uhri, joka on kosketuksissa papin kanssa loitsimishetkellä. Uhri saa tehdä Älyluonteen heiton vastustaakseen, muokattuna kohteen tasolla tai KOK-arvolla, kumpi antaa uhrille hyödyllisemmän tuloksen, kuten seuraavassa taulukossa on yksityiskohtaisesti esitetty.

| Kohteen taso | Kohteen KOK | Älyluonteen muuttaja |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | Pelottava |
| 2 | 21-40 | Vaikea |
| 3 | 41-60 | Standardi |
| 4 | 61-80 | Helppo |
| 5 | 81+ | Erittäin helppo |

_\* Tämä luokka sisältää hahmot, joilla ei ole luokkaa._

Jos tämä vastustusheitto epäonnistuu, kohde kuolee välittömästi, ja hänen ruumiinsa muuttuu tuhkaksi. Vain *Toive*-loitsun loitsiminen voi tuoda uhrin takaisin tässä vaiheessa. Onnistuneella heitolla uhri saa silti -1d4 osumapistettä vauriota kosketettuun osumakohtaan. Haarniska ei tarjoa suojaa tätä vahinkoa vastaan. *Tuho* ei vanhenna loitsijaa käytettäessä.

| | |
| :-- | :-- |

#### Auringonsäde

(Evokaatio, Transmutaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Pappi 5 | **Loitsimisaika:** 2 toimintoa |

Langetettaessa pappi voi kutsua loistavan pyhän valon säteen käyttämällä "langeta taika" -toimintoa milloin tahansa loitsun keston aikana. Säde on luonnollista auringonvaloa ja sen säde on viisi jalkaa. Alueella olevien on väistettävä yrittääkseen suojata silmänsä tai he sokaistuvat 1d3 minuutiksi. Sienimäiset olennot sekä kaikenlaiset maanalaiset sienet kärsivät samat vaikutukset kuin epäkuolleet, mutta ne eivät voi tehdä vastustusheittoa.

#### Tulimuuri/Tulikehä

(Evokaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Pappi 3, Maagi 3 | **Loitsimisaika:** 2 toimintoa |
| **Sfääri:** Taistelu, Elementaalinen (Tuli) | **Kesto:** Katso alla |
| **Kustannus:** 3, +1/lisäintensiteetti | **Kantama:** Katso alla |
| **Alue:** Katso alla | **Vastus:** Katso alla |

Tämä loitsu mahdollistaa loitsijan luovan tulisen liekkimuurin tai -kehän, halutulla tavalla loitsintahetkellä, väriltään purppuraa tai punertavan sinistä. Loitsun kesto pysyy voimassa, jos keskittyminen säilyy, tai 1 kierroksen per intensiteetti keskittymisen päätyttyä. Yksityiskohdat on kuvattu alla tyypin mukaan:

**Tulimuuri:** Tämä versio loitsusta luo paikallaan pysyvän tulimuurin, jonka pituus on 20 jalkaa per intensiteetti. Lopullisesta intensiteetistä riippumatta muurin korkeus on 10–20 jalkaa loitsittaessa valitulla tavalla. Tulimuurin kantama on 180 jalkaa, eikä sitä voi luoda vaakasuoraan.

**Tulikehä:** Tämä versio loitsusta luo loitsijan ympärille tulikehän, joka liikkuu hänen mukanaan. Sen säde on 10 jalkaa, plus 5 jalkaa jokaisesta intensiteetistä ensimmäisen jälkeen. Lopullisesta intensiteetistä riippumatta kehän korkeus on 10–20 jalkaa loitsittaessa valitulla tavalla. Tulikehän on ympäröitävä loitsija, ja sen kantama on 0.

Muurin tai kehän loitsijasta poispäin oleva puoli säteilee polttavaa kuumuutta, aiheuttaen 1d6 vahinkoa kierroksessa kaikille 10 jalan sisällä, ja 1d4 vahinkoa 20 jalkaan saakka. Tämä vahinko kohdistuu yleensä kierroksen lopussa ennen seuraavaan siirtymistä. Jos uhri on molemmilla lämpövyöhykkeillä yhden kierroksen aikana, suurempi vahinko sovelletaan. Liekkien läpi hyppäävät kokevat 2d6 pistettä vahinkoa, plus yhden lisäpisteen vahinkoa jokaista ensimmäisen intensiteetin ylittävää intensiteettiä kohden. Tämä vahinko kohdistuu jokaiseen osumakohtaan, ja käytetty haarniska ei tarjoa suojaa, mutta maagiset panssaripisteet tai olennon luonnollinen panssari vähentävät vahinkoa normaalisti. Onnistunut Väistö-vastustusheitto sallii uhrin välttyä vahingolta kierroksella, jolloin loitsu syntyy, kun uhri yrittää sukeltaa pois kuumuudesta tai liekkien ohi. Tulta käyttävät olennot ottavat puolet tästä vahingosta ja kylmää käyttävät olennot tuplasti. Liekeillä on mahdollisuus sytyttää syttyviä materiaaleja todennäköisyydellä, joka on yhtä suuri kuin heitetty vahinko x 5%. Katso lisätietoja kohdasta [Tuli](0007_Game_System.md?id=fire-based-attacks).

#### Verkko

(Evokaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Maagi 1 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Ei mitään | **Kesto:** 20 minuuttia/Intensiteetti |
| **Kustannus:** 3, +1/lisäintensiteetti | **Kantama:** 30 jalkaa/Intensiteetti |
| **Alue:** 20 jalan säde | **Vastus:** Väistö, plus katso alla |

Tämä loitsu saa pitkiä tahmean verkon säikeitä ampumaan loitsijan kädestä, jotka voidaan ankkuroida lattiasta kattoon tai seinästä seinään kulkuväylän tukkimiseksi tai etenemisen estämiseksi. Se voidaan myös suihkuttaa suoraan vastustajien päälle heidän sitomisekseen.

Olettaen, että kohteella on tilaa paeta verkkoja, onnistunut Väistö-heitto asettaa kohteen vaikutusalueen ulkopuolelle; tämä vaatii kuitenkin käytettävissä olevan toimintapisteen. Epäonnistunut vastustusheitto jättää uhrin liikkumattomaksi ja 1d3 osumakohtaa sitoutuneiksi. Kuten [Sitominen](https://cfi-srd.mythras.net/#/0008_Combat?id=entangle) -erikoistehosteessa, verkottunut kohta on käyttökelvoton. Sitoitunut käsi ei voi käyttää sitä, mitä se pitelee; ansaan jäänyt rintakehä, vatsa tai jalka tekee kaikista fyysisistä taitojen heitoista yhden asteen vaikeampia (paitsi Voima-heitot, joita käytetään vapaaksi pääsemiseen); ja verkottunut pää aiheuttaa tukehtumisen, kuten on kuvattu kohdassa [Tukehtuminen](0007_Game_System.md?id=asphyxiation).

Seuraavalla vuorolla uhri voi käyttää toimintapisteen yrittääkseen vapautua verkosta. Maaginen verkko on uskomattoman vahva ja tahmea, sillä on 6 panssaripistettä ja osumapisteitä, jotka ovat 3 x loitsun intensiteetti. Vapaaksi yrittäminen vaatii uhrin voittamaan vastakkaisen heiton Voimassa verkon tahmeutta vastaan (yhtä suuri kuin loitsijan Arkaanisen loitsimisen taito). Jos tämä epäonnistuu, kohde pysyy kiinnitettynä, kykenemättömänä vapautumaan pelkällä voimalla. Vapaaksi leikkaaminen altistaa käytetyn työkalun tai aseen samalle prosessille. Yleisestä käsityksestä huolimatta verkot eivät ole syttyviä, mutta hahmo voisi hitaasti polttaa tiensä verkon läpi käyttämällä tulta säikeiden kuihduttamiseen (tulivahinko ohittaa Verkon panssaripisteet).

#### Toive

(Konjuraatio, Evokaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Maagi 5 | **Loitsimisaika:** Katso alla |
| **Sfääri:** Ei mitään | **Kesto:** Katso alla |
| **Kustannus:** 3, +1 tai enemmän kokemuspisteitä | **Kantama:** Rajoittamaton |
| **Alue:** Katso alla | **Vastus:** Katso alla |

Toive voi muuttaa todellisuutta pysyvällä ja merkittävällä tavalla. Tämän loitsun langettamiseksi taikuuden käyttäjän on käytettävä 3 taikapistettä ja 1 tai useampi kokemuspisteheitto halutuista tuloksista riippuen. Jokainen peräkkäinen Toive-loitsun langettaminen 1 kuukauden sisällä kaksinkertaistaa normaalisti vaaditun kokemuspisteiden kulutuksen. Loitsimisaika vaaditaan yleensä Toiveen yksityiskohtien suulliseen kuvaamiseen. Valmistumisen jälkeen loitsija kärsii uupumuksesta, joka vastaa käytettyjä kokemuspisteitä, ja vanhenee 5 % normaalista elinajanodotteestaan (ihmisillä se olisi viisi vuotta). Katso [Ikääntyminen](0007_Game_System.md?id=aging) puolihmisten rotujen keskimääräisistä elinajanodotteista.

Toiveen tulokset tulee ottaa kirjaimellisesti, ja ne ovat pelinjohtajan tulkittavissa. Ahneet toiveet päättyvät yleensä huonosti. On 10 % mahdollisuus, että ahnein aikein tehty Toive kääntyy jollain tavalla itseään vastaan. Esimerkiksi varallisuuden toivominen voisi teleportata sen paikallisen herran tai kuninkaan aarrekammioista. Toive ei voi kumota jumalankaltaisten olentojen asetuksia, ellei kyseinen olento itse esittänyt kyseistä toivetta.

#### Velhon katse

(Transmutaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Maagi 3 | **Loitsimisaika:** 1 minuutti |
| **Sfääri:** Ei mitään | **Kesto:** 1 minuutti/Intensiteetti |
| **Kustannus:** 1/Intensiteetti | **Kantama:** 0 |

Tämä loitsu luo pienen näkymättömän "silmän", jonka läpi taikuuden käyttäjä voi nähdä loitsun keston ajan. Tätä silmää voidaan liikuttaa seurueen edellä tai lähettää katsomaan kulmien taakse ja huoneisiin; sen liikenopeus on 20 jalkaa kierroksessa (240 jalkaa minuutissa), jos vain etsitään "ilmeisiä" uhkia tai kiinnostavia kohteita. Tämä ulottuu tyypillisesti vain lattiaan ja alempiin seiniin. Jos yritetään olla perusteellisempi (tutkien myös kaikki seinät ja katon), sen liikenopeus laskee 10 jalkaan kierroksessa (120 jalkaa minuutissa). Pelinjohtajan tulee tuntea vapautta sallia loitsijan Havainto-heitot tarvittaessa visuaalisten poikkeamien havaitsemiseksi. Silmä on fyysinen, ei kykene kulkemaan kiinteän aineen läpi, ja sillä on normaali näkö 60 jalkaan ja pimeänäkö 10 jalkaan. Loitsijan on säilytettävä keskittyminen silmään koko keston ajan, tai se pysyy inerttinä, kunnes keskittyminen jälleen muodostetaan. Kaikki katsehyökkäykset, jotka normaalisti vaikuttaisivat loitsijaan, vaikuttavat silti loitsijaan normaalisti; silmää pidetään kuitenkin loitsijasta riippumattomana sokeuden, pimeysloitsujen ja niin edelleen osalta. Pienten aukkojen läpi mahtumiseksi silmä ei ole yhtä tuumaa suurempi, ja sen KOK on 1.

#### Palautussana

(Transmutaatio)

| | |
| :-- | :-- |
| **Arvoaste:** Pappi 4 | **Loitsimisaika:** 1 toiminto |
| **Sfääri:** Kutsuminen | **Kesto:** Katso alla |
| **Kustannus:** 3, +1/lisäintensiteetti | **Kantama:** 0 |
| **Alue:** Loitsija | **Vastus:** Ei sovellu |

Kun tämä loitsu langetetaan, pappi teleportoituu välittömästi ennalta määrättyyn pyhäkköön ja määritettyyn saapumispisteeseen, joka on enintään 10 jalan säteellä. Itse teleportoitavalle etäisyydelle ei ole rajaa, mukaan lukien useiden tasojen välillä. Yhden tason sisällä ei ole virhemahdollisuutta, mutta yhdenkin tason ylittäminen antaa 91–00 % epäonnistumismahdollisuuden, kaksi tasoa antaa epäonnistumisen heitolla 81–00 % ja niin edelleen. Tämä korvaa loitsijan normaalin epäonnistumismahdollisuuden. Epäonnistuminen tasoja ylitettäessä tarkoittaa, että pappi on peruuttamattomasti eksyksissä. Epäonnistumiset yhden tason sisällä noudattavat normaaleja sääntöjä.

Itsensä ja kaikkien kannettujen varusteiden lisäksi pappi voi kuljettaa 3 muuta esinettä per intensiteetti, jokainen kooltaan enintään KOK/9 "asiaa". Lisämateriaali voi olla aarteita, varusteita tai eläviä olentoja. Kuljetettavilla olennoilla on kuitenkin oltava loitsu langetettuna riittävällä intensiteettitasolla kattamaan kaikki kannetut varusteet.
