# पूर्वअपेक्षित गोष्टी (Prerequisites)

1. [markdown भाषेचे](https://www.markdownguide.org/basic-syntax/) प्राथमिक ज्ञान.

2. जर तुमचे [github](https://github.com/) वर खाते नसेल, तर तुम्हाला ते विनामूल्य तयार करावे लागेल. आम्ही शिफारस करतो की तुम्ही तुमच्या RPG चे नाव वापरावे, कारण हे नाव तुमच्या SRD ला भेट देण्यासाठी लोक वापरणार असलेल्या URL चा एक भाग बनेल.

3. तुम्ही ही संपूर्ण प्रक्रिया git न शिकता थेट ब्राउझरद्वारे करू शकता. तथापि, github desktop शिकल्यास तुम्ही कोणतीही बदल थेट लाइव्ह करण्यापूर्वी स्थानिक पातळीवर (locally) तपासून पाहू शकता.

> जर तुमच्याकडे नोंदणीकृत डोमेन नाव असेल, तर तुम्ही त्याचा वापर करून माझ्यासारखे https://srd.7thextinctionrpg.com असे SRD तयार करू शकता.

# प्रक्रिया

## Github वर रिपॉझिटरी तयार करणे

1. Github मध्ये लॉगिन करा.

2. या सार्वजनिक टेम्पलेटवर जा: https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. "Use this template" वर क्लिक करा.

![Step3](/_media/Step3.png)

4. "Create a new repository" निवडा.

5. रिपॉझिटरीचे नाव टाका.

![Step5](/_media/Step5.png)

6. 'Private' निवडा.

7. 'Create repository' निवडा.

टेम्पलेट कॉपी होण्यासाठी ५-३० सेकंद लागतील, त्यानंतर तुमची स्वतःची प्रत तयार होईल.

8. तुमच्याकडे ".nojekyll" फाईल असल्याची खात्री करा. Github वर वेबसाइट होस्ट करताना ही एक रिकामी फाईल आवश्यक असते, अन्यथा SRD व्यवस्थित दिसणार नाही. *(हे GitHub Pages ला सूचित करते की प्रकाशित फाईल्स Jekyll द्वारे चालवू नका).*


## तुमची सामग्री जोडणे

### *.md फाईल्स

.md फाईल्स म्हणजे मार्कडाउन फाईल्स आहेत. मार्कडाउन ही एक हलकी मार्कअप भाषा आहे, ज्याचा वापर करून तुम्ही साध्या मजकुरात फॉरमॅटिंगचे घटक जोडू शकता. तुमच्या मजकुराच्या आकारानुसार, तुम्ही तुमच्या खेळाची सर्व माहिती एकाच *.md फाईलमध्ये ठेवू शकता, किंवा मी [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) वर केल्याप्रमाणे प्रत्येक प्रकरणासाठी स्वतंत्र फाईल्स तयार करू शकता. "sample.md" मध्ये काही फॉरमॅटिंगची उदाहरणे दिली आहेत.

मार्कडाउन भाषा शिकण्यास अतिशय सोपी आहे, सिंटॅक्सच्या संपूर्ण यादीसाठी वरील 'पूर्वअपेक्षित गोष्टी' मधील दुसऱ्या मुद्द्यात दिलेल्या लिंकचा वापर करा.

### _Sidebar.md

हे तुमचे मेनू (Menu) आहे, जे वेबसाइटच्या डाव्या बाजूला नेव्हिगेशन पेन म्हणून काम करते. एकदा तुम्ही तुमच्या रिपॉझिटरीमध्ये मार्कडाउन फाईल जोडली की, तुम्हाला ती फाईल येथे जोडावी लागेल जेणेकरून तिची सामग्री समाविष्ट केली जाईल. विद्यमान फॉरमॅटिंगचे पालन करा.

1. तुमच्या रिपॉझिटरीमध्ये 'Settings' वर क्लिक करा.

![Website-Step1](/_media/Website-Step1.png)

2. डाव्या बाजूच्या मेनूमध्ये 'Pages' निवडा.

![Website-Step2](/_media/Website-Step2.png)

    a. रिपॉझिटरी सार्वजनिक (public) करा, ज्यामुळे तुम्हाला तुमची SRD वेबसाइट मोफत होस्ट करण्यासाठी Github pages वापरता येईल.

4. 'Branch' अंतर्गत 'main' निवडा आणि 'save' वर क्लिक करा.

5. १०-२० सेकंद थांबा आणि पेज रिफ्रेश करा.

6. आता तुम्हाला तुमची URL दिसेल, जसे की https://coweater.github.io/mysrd/

## तुमच्या SRD मध्ये मोफत चिन्हे (icons) प्रदर्शित करण्यासाठी Fontawesome आणि/किंवा Material Icons प्लगइनचा वापर करणे

### Fontawesome

मोफत चिन्हे आणि ॲनिमेटेड चिन्हे मिळवण्यासाठी Fontawesome चा वापर करा. सबस्क्राइब केलेले वापरकर्ते Pro Icons वापरू शकतात.

1. [Fontawesome](https://fontawesome.com/icons) वर चिन्ह शोधा.
2. चिन्ह निवडा.
3. पॉपअप विंडोमध्ये, HTML टॅब अंतर्गत " " मधील सर्व मजकूर कॉपी करा.

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. कॉपी केलेला मजकूर `:` च्या दरम्यान ठेवा (कोणतीही जागा सोडू नका).

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

अधिक मोफत चिन्हांसाठी Material Icons चा वापर करा.

1. [Material Icons](https://fonts.google.com/icons) वर चिन्हे शोधा.
2. वेब span लिंक कॉपी करा आणि थेट तुमच्या मार्कडाउन फाईल्समध्ये टाका.

```markup
<span class="material-icons">face</span>
```
