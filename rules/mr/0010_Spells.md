#### Appraise (मुल्यमापन)

(दैवी ज्ञान)

| | |
| :-- | :-- |
| **श्रेणी:** जादूगार ० | **मंत्राचा कालावधी:** १ टर्न |
| **क्षेत्र:** नाही | **कालावधी:** तत्काळ |
| **खर्च:** १ | **व्याप्ती:** स्पर्श |
| **क्षेत्रफळ:** १ वस्तू | **विरोध:** नाही |

Appraise मंत्रामुळे वापरकर्त्याच्या POW (शक्ती) एवढ्या आकाराच्या (SIZ) किंवा 'वस्तूंच्या' (Things) एकत्रित ENC असलेल्या भौतिक वस्तूंच्या गुणवत्तेचे त्वरित मूल्यांकन करता येते. हा मंत्र समान दिसणाऱ्या वस्तू एकाच किंवा सारख्या गुणवत्तेच्या आहेत की नाही, हे ठरवतो; तसेच त्यातील एखादी वस्तू सदोष किंवा उच्च गुणवत्तेची आहे का, हेही सांगतो. हा मंत्र सेंद्रिय वस्तूंवर काम करत नाही, केवळ निर्जीव वस्तूंवर काम करतो. तसेच, त्यातील नेमके दोष किंवा सुधारणा काय आहेत हे सांगण्याऐवजी, फक्त त्या अस्तित्वात आहेत हे दर्शवतो. जादू ओळखण्यासाठी किंवा शोधण्यासाठी याचा उपयोग होत नाही.

#### Armor (कवच)

(मंत्रमुग्ध करणे)

| | |
| :-- | :-- |
| **श्रेणी:** जादूगार १ | **मंत्राचा कालावधी:** १ फेरी |
| **क्षेत्र:** नाही | **कालावधी:** खालीलप्रमाणे |
| **खर्च:** ३ +१/तीव्रता | **व्याप्ती:** स्पर्श |
| **क्षेत्रफळ:** १ लक्ष्य | **विरोध:** नाही |

हा मंत्र वापरल्यावर, लक्ष्याभोवती एक अदृश्य जादूचे कवच निर्माण होते, जे 'स्केल आर्मर' (Scale Armor) सारखी सुरक्षा देते आणि प्रत्येक हिट लोकेशनला ४ आर्मर पॉइंट्स प्रदान करते. आधीच चिलखत घातलेल्या व्यक्तीवर याचा प्रभाव पडत नाही. तथापि, जर एखाद्या प्राण्याकडे ४ पेक्षा जास्त नैसर्गिक आर्मर पॉइंट्स असतील, तर हा मंत्र सर्व ठिकाणी आर्मर पॉइंट्समध्ये १ ने वाढ करतो. ही जादूची सुरक्षा हालचाल किंवा मंत्र उच्चारण्यास अडथळा ठरत नाही. हा मंत्र जादूने नष्ट होईपर्यंत किंवा एका हल्ल्यातून ८ पॉइंट्सचे नुकसान (अधिक १ प्रति तीव्रता पातळी) होईपर्यंत टिकतो. वापरकर्ता हवा तेव्हा हा मंत्र काढून टाकू शकतो, आणि झोपताना हे करणे आवश्यक आहे.

| तीव्रता | खर्च | परिवर्तनीय परिणाम |
| :-: | :-: | :-- |
| १ | ३ | ४ आर्मर पॉइंट्स; एका हल्ल्यात ८ नुकसान होईपर्यंत |
| २ | ४ | ४ आर्मर पॉइंट्स; एका हल्ल्यात ९ नुकसान होईपर्यंत |
| ३ | ५ | ४ आर्मर पॉइंट्स; एका हल्ल्यात १० नुकसान होईपर्यंत |
| ४ | ६ | ४ आर्मर पॉइंट्स; एका हल्ल्यात ११ नुकसान होईपर्यंत |
| +१ | +१ | प्रगती सुरू ठेवा |

#### Astral Spell (अश्रल मंत्र)

(रूपांतरण)

| | |
| :-- | :-- |
| **श्रेणी:** धर्मगुरू ५, जादूगार ५ | **मंत्राचा कालावधी:** २ क्रिया |
| **क्षेत्र:** अस्ट्रल | **कालावधी:** खालीलप्रमाणे |
| **खर्च:** ३ +१/अतिरिक्त तीव्रता | **व्याप्ती:** स्पर्श |
| **क्षेत्रफळ:** खालीलप्रमाणे | **विरोध:** एन/ए |

हा मंत्र वापरकर्त्याला आणि इतर पाच जणांना (अतिरिक्त तीव्रता पातळीनुसार) 'अस्ट्रल प्लेन' (Astral Plane) मध्ये प्रवेश करण्याची परवानगी देतो. मंत्राच्या वेळी सर्वांनी स्पर्श करून वर्तुळ तयार करणे आवश्यक आहे. प्रवाशांचे शरीर मूळ ठिकाणी राहते आणि ते सहसा कोणतेही कपडे किंवा उपकरणे सोबत नेऊ शकत नाहीत, फक्त जादूची आभा असलेल्या वस्तूच सोबत नेल्या जातात; त्या वस्तू अस्ट्रल स्वरूपात रूपांतरित होतात. वापरकर्ता इच्छेपर्यंत हा कालावधी चालू राहतो. तथापि, 'Dispel Magic' सारख्या बाह्य शक्तीने हे अकाली संपू शकते. वापरकर्त्याचा मृत्यू झाल्यास मंत्र संपतो, परंतु यामुळे सोबतच्या प्रवाशांचे अस्तित्व तिथेच धोक्यात येते.

#### Augury (शकुन)

(दैवी ज्ञान)

| | |
| :-- | :-- |
| **श्रेणी:** धर्मगुरू २ | **मंत्राचा कालावधी:** २ मिनिटे |
| **क्षेत्र:** दैवी ज्ञान | **कालावधी:** तत्काळ |
| **खर्च:** ३/तीव्रता | **व्याप्ती:** ६० फूट |
| **क्षेत्रफळ:** वापरकर्ता | **विरोध:** एन/ए |

हा मंत्र वापरकर्त्याला पुढील ३० मिनिटांत उचलले जाणारे पाऊल फायदेशीर ठरेल की हानिकारक, हे ओळखण्यास मदत करतो. शकुन ओळखण्यासाठी ड्रॅगनचे पंजे, हाडे, मोती किंवा १०० GP मूल्याचे सोने अशा गोष्टींची आवश्यकता असते. या मंत्राची कमाल तीव्रता ४ आहे. हा रोल गेम्स मास्टरने करणे योग्य ठरते, कारण वापरकर्त्याला निकालाचा अर्थ नीट समजला आहे की नाही, याची खात्री नसावी.

| तीव्रता | खर्च | परिवर्तनीय परिणाम |
| :-: | :-: | :-- |
| १ | ३ | फॉर्मिडेबल चॅनेल स्किल रोल |
| २ | ६ | हार्ड चॅनेल स्किल रोल |
| ३ | ९ | स्टँडर्ड चॅनेल स्किल रोल |
| ४ | १२ | इझी चॅनेल स्किल रोल |

जर मंत्राचा रोल यशस्वी झाला, तर खालीलपैकी एक परिणाम मिळतो:

| शकुन | अर्थ | 
| :-: | :-- |
| हो | कृती फायदेशीर असेल |
| नाही | कृती हानिकारक असेल |
| हो आणि नाही | कृती फायदेशीर आणि हानिकारक दोन्ही असेल |
| काहीही नाही | कृती फायदेशीर किंवा हानिकारक नसेल |

'Fumble' झाल्यास गेम्स मास्टरने वास्तविकतेच्या अगदी उलट माहिती सांगावी.
