# Chapitre 4 : Alignement et Passions

L'utilisation de l'Alignement et des Passions dans _Classic Fantasy Imperative_ peut grandement aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des rebondissements basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite. Bien que le choix spécifique de l'Alignement et des Passions trouvé dans ce chapitre dépende du joueur, certains éléments du chapitre précédent concernant les [Classes](0003_Classes.md) des personnages sont requis pour jouer ce personnage. Aucune des Classes de ce document ne nécessite un Alignement ou des Passions spécifiques, mais certaines, comme le clerc et le voleur (qui rejoint une guilde de voleurs), nécessitent un Serment envers leur ordre ou leur guilde. Un Serment peut être traité comme une Passion en ce qui concerne ses mécaniques de jeu.

---
## Alignement

Tous les personnages doivent avoir un Alignement qui consiste en deux parties : un Code Éthique et un Code Moral. Le Code Éthique définit la position vis-à-vis de la loi et du chaos, tandis que le Code Moral détermine le sentiment vis-à-vis du bien et du mal. Les personnages choisissent ensuite un ou deux éléments déterminants pour chacun et déterminent les Pourcentages de Départ. Par exemple, Chaotique (Désorganisé et Cupide) 55 %, et Bon (Serviable et Charitable) 55 %. Vous ne pouvez pas choisir Neutre deux fois ; à la place, vous ignorez à la fois le Code Moral et le Code Éthique et choisissez Vrai Neutre comme seul Alignement. Les Codes Éthiques et Moraux, ainsi que leurs éléments déterminants, sont détaillés ci-dessous.

#### Code Éthique

Choisissez l'un des Lawful (Loi), Neutre ou Chaotic (Chaos) à un Niveau de Base de INT+POU+30.

- **Lawful (Loi)** : Choisissez un ou deux éléments déterminants qui décrivent le mieux votre Code Éthique : _Adhésion à la tradition ; Calculateur ; Fermé d'esprit ; Haine du Chaos ; Éthique ; Honnête ; Honorable ; Porté sur le jugement ; Manque d'adaptabilité ; Aucun sens de l'humour ; Obéissance à l'autorité légitime ; Organisé ; Prévisible ; Fiable ; Confiant ; Digne de confiance ; Bien élevé._
- **Neutre** : Choisissez un élément déterminant qui décrit le mieux votre Code Éthique : _Croit que la Loi et le Chaos sont des préjugés et des extrêmes dangereux ; Prudent ; Prétentieux ; Ne ressent pas fortement les choses dans un sens ou dans l'autre en ce qui concerne la Loi et le Chaos ; Flexible ; Liberté d'action ; N'a pas de Code Éthique établi ; Pragmatique ; Respectueux de la nature._
- **Chaotic (Chaos)** : Choisissez un ou deux éléments déterminants qui décrivent le mieux votre Code Éthique : _Mal élevé ; Sanguinaire ; Curieux ; Cynique ; Malhonnête ; Déshonorable ; Désorganisé ; Mépris de l'autorité légitime ; Égoïsme ; Liberté ; Haine de la Loi ; Irresponsable ; Sans foi ni loi ; Mégalomane ; Farceur ; Prompt à la colère ; Déchaîné ; Téméraire ; Suspicieux ; Incontrôlé ; Indigne de confiance ; Imprévisible ; Peu fiable._

#### Code Moral

Choisissez l'un des Good (Bien), Neutre ou Evil (Mal) à un Niveau de Base de INT+POU+30.

- **Good (Bien)** : Choisissez un ou deux éléments déterminants qui décrivent le mieux votre Code Moral : _Admirable ; Altruiste ; Angélique ; Faisant autorité ; Charitable ; Remords à l'idée de blesser des innocents ; Décent ; Pardonner ; Amical ; Haine du Mal ; Serviable ; Gentil ; Aime la nature ; Miséricordieux ; Optimiste ; Positif ; Végétarien._
- **Neutre** : Choisissez un élément déterminant qui décrit le mieux votre Code Moral : _Croit que le Bien et le Mal sont des préjugés et des extrêmes dangereux ; Prudent ; Ne ressent pas fortement les choses dans un sens ou dans l'autre en ce qui concerne le Bien et le Mal ; Flexible ; Liberté d'Action ; Manque d'engagement pour faire des sacrifices afin de protéger ou d'aider les autres ; Engagé envers les autres par des relations personnelles, pas par un Code Moral ; N'a pas de Code Moral établi ; Pragmatique ; Cherche rarement la compagnie._
- **Evil (Mal)** : Choisissez un ou deux éléments déterminants qui décrivent le mieux votre Code Moral : _Abusif ; Cannibale ; Convoiteux ; Cruel ; Dominateur ; Prends plaisir à blesser des innocents ; Cupide ; Haine du Bien ; Luxurieux ; Manipulateur ; Impitoyable ; Fier ; Sadique ; Égocentrique ; Égoïste ; Esclavagiste ; Rancunier ; Vain ; Violent._

#### Vrai Neutre

Vrai Neutre commence à un Niveau de Base de INT+POU+30.

- **Vrai Neutre** : Alternativement, choisissez un ou deux éléments déterminants qui décrivent le mieux votre absence à la fois de Code Moral et de Code Éthique : _Ambivalent ; Prudent ; Engagé envers les autres par des relations personnelles ; Flexible ; Liberté d'action ; Ouvert d'esprit ; Pragmatique ; Respectueux de la Nature ; Recherche l'équilibre._

## Passions

Les Passions sont utilisées pour aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des rebondissements basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite.

Une Passion peut concerner n'importe quoi – une personne, une organisation, un idéal, voire un objet. Les Passions sont généralement décrites par un verbe tel que : Désirer, Mépriser, Détruire, Soutenir, Craindre, Fuir, Renier, Haïr, Aimer, Loyauté envers, Protéger, Répudier, Respecter, Rechercher, Subvertir, Tourmenter ou Défendre.

Les Passions sont mesurées de la même manière que les compétences ; elles sont notées entre 1 et 100 (ou plus). Une Passion peut être améliorée de la même manière qu'une compétence, ou elle peut être augmentée ou diminuée par le Maître de Jeu en fonction des circonstances.

Les personnages débutants peuvent commencer avec jusqu'à trois Passions, chacune basée sur deux Caractéristiques, avec un bonus de +40 à la première, +30 à la deuxième et +20 à la troisième, le joueur décidant de l'ordre d'importance. Celles-ci peuvent être liées à la Culture, à la Classe ou à des défauts personnels. Par exemple, Méfiance (Voleurs) ; Loyal à la Reine ; Aime la Famille ; Vaincre le Chaos. Les Passions jouent un rôle particulièrement important dans de nombreuses Classes de personnages, comme détaillé dans le chapitre suivant. Pour certaines de ces Classes, maintenir une Passion à un niveau minimum est requis pour conserver des Capacités spéciales spécifiques à la Classe, et dans des situations extrêmes, perdre une Passion peut entraîner la perte de la Classe.

La valeur de départ de la Passion varie en fonction de son type ; voir la [Table des Passions](0004_Alignment_and_Passions.md?id=passion-table), ci-dessous.

Cette section détaille uniquement ce que représentent les Passions et leurs valeurs par défaut. La manière dont les Passions sont utilisées dans le jeu est discutée ci-dessous.

##### Table des Passions

| Objet de la Passion | Pourcentage de Départ |
| :-- | :-- |
| Une personne, dans un contexte romantique ou familial | POU+CHA |
| Une organisation ou un groupe de personnes | POU+INT |
| Une Espèce ou une espèce | POU du Personnage x2 |
| Un lieu | POU+INT du Personnage |
| Un objet ou une substance | POU du Personnage x2 |
| Un trait de personnalité | POU+CHA du Personnage |

## Utilisation de l'Alignement et des Passions

Un Alignement ou une Passion est tout engagement profondément ancré qui a la capacité d'influencer les événements pendant le jeu. Bien qu'ils puissent être utilisés comme des Capacités autonomes (les appeler des compétences serait leur rendre un mauvais service), les Passions sont développées plus en détail ci-dessous pour expliquer comment elles fonctionnent et comment elles peuvent influencer les personnages et les campagnes de _Classic Fantasy Imperative_.

En résumé, l'Alignement et les Passions peuvent être utilisés ainsi :

- Pour augmenter une autre compétence, reflétant la profondeur de ses sentiments et la manière dont cela motive l'action. Lorsqu'il est utilisé à cet égard, l'Alignement ou la Passion ajoute 20 % de sa valeur à une compétence utilisée, si l'augmentation est thématiquement et dramatiquement importante.
- En tant que Capacité pour diriger les choix, les désirs et les actions et réponses émotionnelles. Lorsqu'il est utilisé de cette manière, un jet Standard est effectué contre un Alignement ou une Passion pour déterminer avec quelle force le personnage pense et ressent quelque chose. Si le jet est un Succès, alors le personnage agit en accord avec ce que dicterait l'Alignement ou la Passion. Si le jet Échoue, alors le personnage peut agir librement sans se sentir limité par les pulsions de la Passion.
- Pour s'opposer à d'autres Alignements ou Passions – même ceux détenus par le même personnage. Cela est généralement utilisé lorsqu'un Alignement entrerait en conflit avec une Passion, ou même lorsque deux Passions entreraient en conflit. Par exemple, un amour personnel pourrait dicter un plan d'action qui serait contraire à un Serment ou à une loyauté. Utilisez ici un Jet Opposé entre l'Alignement et la Passion, ou les deux Passions, le résultat le plus réussi déterminant la façon dont le personnage agit.
- En tant que mesure générale de la profondeur de l'engagement, de la croyance et de la loyauté envers une cause. Plus la valeur de l'Alignement ou de la Passion est élevée, plus le personnage est engagé. Les personnages ayant des Alignements ou des Passions similaires peuvent comparer leurs Notes pour déterminer qui affiche l'engagement le plus profond.
- Pour résister à une forme de manipulation psychologique ou de domination magique. Dans certains cas où un personnage est forcé d'accomplir un acte contraire à son Alignement ou à ses Passions, il peut substituer l'un ou l'autre à la Volonté lors du Jet Opposé.

Le score d'Alignement d'un personnage peut chuter en cours de jeu si le personnage ignore continuellement la moralité et/ou l'éthique qu'il a choisies. S'il tombe en dessous du Niveau de Base du personnage, il changera pour un Alignement opposé, du Bien vers le Neutre ou le Mal par exemple. Le Maître de Jeu doit déterminer le nouvel Alignement et le nouveau Niveau, en fonction des circonstances. Un changement d'Alignement peut entraîner la perte de l'accès aux Capacités de Classe. Voir la description de la Classe concernée pour plus de détails.

De nouvelles Passions peuvent être développées à tout moment au cours d'une session de jeu de _Classic Fantasy Imperative_ si les circonstances le justifient. On peut instantanément développer 'Haïr X' si quelqu'un fait quelque chose qui susciterait fortement la haine. Un seigneur ou un chef appelant à un Serment établirait immédiatement une Passion de 'Loyauté envers X' dès que ce Serment est pris ou prêté – ce qui est exploré plus en détail dans la section Alignement/Serments de chacune des [Classes](0003_Classes.md).

Les nouvelles Passions développées en cours de jeu de cette manière ne coûtent aucun Jet d'Expérience et sont établies sur-le-champ. Bien sûr, les personnages peuvent également choisir d'établir une Passion lors de l'amélioration, au prix d'un Jet d'Expérience pour gagner une Passion à sa Valeur de Base : voir les différentes sections Alignements et Passions dans le chapitre [Culture et Espèces](0002_Culture_and_Races.md).

## Approfondissement et Déclin

L'Alignement, les Passions et les Serments peuvent augmenter au cours d'une partie indépendamment des Jets d'Expérience, en fonction de la force de ce qui a provoqué l'augmentation. De plus, ils peuvent décliner, et ils le font. Une croyance fortement ancrée peut être ébranlée par de nombreuses choses, conduisant cette Passion à être soit réduite, soit, dans des circonstances plus extrêmes, complètement inversée.

Par exemple, un personnage ayant 'Confiance envers le Chef' pourrait, si son chef agit de manière traîtresse, soit réduire sa Passion, soit la transformer en 'Méfiance envers le Chef' avec le même pourcentage. Le Maître de Jeu doit déterminer si une Passion se réduit ou s'inverse. Si elle se réduit, elle le fait alors en fonction de la force de la source du changement.
