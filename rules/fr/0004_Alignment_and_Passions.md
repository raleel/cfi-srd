# Chapitre 4 : Alignement et Passions

L'utilisation de l'Alignement et des Passions dans _Classic Fantasy Imperative_ peut grandement aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des éléments de scénario basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite. Bien que le choix spécifique de l'Alignement et des Passions par le joueur dans ce chapitre lui appartienne, certains éléments trouvés dans le chapitre précédent concernant les [Classes](0003_Classes.md) de personnage sont requis pour jouer ce personnage. Aucune des Classes de ce document ne nécessite un Alignement ou des Passions spécifiques, mais certaines, comme le clerc et le roublard (qui rejoint une guilde de voleurs), exigent un Serment envers leur ordre ou leur guilde. Un Serment peut être traité comme une Passion en ce qui concerne ses mécaniques de jeu.

---
## Alignement

Tous les personnages doivent avoir un Alignement qui se compose de deux parties : un Code Éthique et un Code Moral. Le Code Éthique définit la position vis-à-vis de la loi et du chaos, tandis que le Code Moral détermine le sentiment vis-à-vis du bien et du mal. Les personnages choisissent ensuite un ou deux éléments définitoires pour chacun et déterminent les Pourcentages de départ. Par exemple, Chaotique (Désorganisé et Cupide) 55 %, et Bon (Serviable et Charitable) 55 %. Vous ne pouvez pas choisir Neutre deux fois ; au lieu de cela, vous ignorez à la fois le Code Moral et le Code Éthique et choisissez Neutre Absolu comme Alignement unique. Les Codes Éthiques et Moraux, ainsi que leurs éléments définitoires, sont détaillés ci-dessous.

#### Code Éthique

Choisissez l'un des alignements suivants : Loyal, Neutre ou Chaotique, avec un Niveau de Base de INT+POW+30.

- **Loyal** : Choisissez un ou deux éléments définitoires qui décrivent le mieux votre Code Éthique : _Adhésion à la tradition ; Calculateur ; Esprit fermé ; Haine du Chaos ; Éthique ; Honnête ; Honorable ; Porté sur le jugement ; Manque d'adaptabilité ; Absence de sens de l'humour ; Obéissance à l'autorité légitime ; Organisé ; Prévisible ; Fiable ; Confiant ; Digne de confiance ; Bien élevé._
- **Neutre** : Choisissez un élément définitoire qui décrit le mieux votre Code Éthique : _Croit que la Loi et le Chaos sont des préjugés et des extrêmes dangereux ; Prudent ; Prétentieux ; N'a pas de sentiment fort dans un sens ou dans l'autre en ce qui concerne la Loi et le Chaos ; Flexible ; Liberté d'action ; N'a pas de Code Éthique établi ; Pragmatique ; Respectueux de la nature._
- **Chaotique** : Choisissez un ou deux éléments définitoires qui décrivent le mieux votre Code Éthique : _Mal élevé ; Sanguinaire ; Curieux ; Cynique ; Malhonnête ; Déshonorable ; Désorganisé ; Mépris de l'autorité légitime ; Égoïsme ; Liberté ; Haine de la Loi ; Irresponsable ; Sans foi ni loi ; Mégalomane ; Farceur ; Prompt à la colère ; Déchaîné ; Imprudent ; Méfiant ; Incontrôlé ; Indigne de confiance ; Imprévisible ; Peu fiable._

#### Code Moral

Choisissez l'un des alignements suivants : Bon, Neutre ou Mauvais, avec un Niveau de Base de INT+POW+30.

- **Bon** : Choisissez un ou deux éléments définitoires qui décrivent le mieux votre Code Moral : _Admirable ; Altruiste ; Angélique ; Autoritaire ; Charitable ; Remords à l'idée de blesser des innocents ; Décent ; Pardonner ; Amical ; Haine du Mal ; Utile ; Gentil ; Amour de la nature ; Miséricordieux ; Optimiste ; Positif ; Végétarien._
- **Neutre** : Choisissez un élément définitoire qui décrit le mieux votre Code Moral : _Croit que le Bien et le Mal sont des préjugés et des extrêmes dangereux ; Prudent ; N'a pas de sentiment fort dans un sens ou dans l'autre en ce qui concerne le Bien et le Mal ; Flexible ; Liberté d'Action ; Manque d'engagement pour faire des sacrifices afin de protéger ou d'aider les autres ; Engagé envers les autres par des relations personnelles, et non par un Code Moral ; N'a pas de Code Moral établi ; Pragmatique ; Cherche rarement la compagnie._
- **Mauvais** : Choisissez un ou deux éléments définitoires qui décrivent le mieux votre Code Moral : _Abusif ; Cannibale ; Convoiteux ; Cruel ; Dominateur ; Apprécie de blesser des innocents ; Cupide ; Haine du Bien ; Luxurieux ; Manipulateur ; Impitoyable ; Fier ; Sadique ; Égocentrique ; Égoïste ; Esclavagiste ; Rancunier ; Vain ; Violent._

#### Neutre Absolu

Le Neutre Absolu commence avec un Niveau de Base de INT+POW+30.

- **Neutre Absolu** : Alternativement, choisissez un ou deux éléments définitoires qui décrivent le mieux votre absence de Code Moral et Éthique : _Ambivalent ; Prudent ; Engagé envers les autres par des relations personnelles ; Flexible ; Liberté d'action ; Ouvert d'esprit ; Pragmatique ; Respectueux de la Nature ; Recherche l'équilibre._

## Passions

Les Passions sont utilisées pour aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des éléments de scénario basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite.

Une Passion peut concerner n'importe quoi – une personne, une organisation, un idéal, voire un objet. Les Passions sont généralement décrites par un verbe tel que : Désirer, Mépriser, Détruire, Soutenir, Craindre, Fuir, Renier, Haïr, Aimer, Loyauté envers, Protéger, Répudier, Respecter, Chercher, Subvertir, Tourmenter ou Défendre.

Les Passions sont mesurées de la même manière que les compétences ; elles sont notées entre 1 et 100 (ou plus). Une Passion peut être améliorée de la même manière qu'une compétence, ou elle peut être augmentée ou diminuée par le Maître de Jeu selon les circonstances.

Les personnages débutants peuvent commencer avec jusqu'à trois Passions, chacune basée sur deux Caractéristiques, avec un bonus de +40 pour la première, +30 pour la deuxième et +20 pour la troisième, le joueur décidant de l'ordre d'importance. Celles-ci peuvent être liées à la culture, à la Classe ou aux travers personnels. Par exemple, Méfiance (Roublards) ; Loyauté envers la Reine ; Amour de la famille ; Vaincre le Chaos. Les Passions jouent un rôle particulièrement important dans de nombreuses Classes de personnages comme détaillé dans le chapitre suivant. Pour certaines de ces Classes, maintenir une Passion à un niveau minimum est requis pour conserver les Capacités spéciales spécifiques à la Classe, et dans des situations extrêmes, perdre une Passion peut entraîner la perte de la Classe.

La valeur de départ de la Passion varie selon son type ; voir le [Tableau des Passions](0004_Alignment_and_Passions.md?id=passion-table), ci-dessous.

Cette section détaille uniquement ce que représentent les Passions et leurs valeurs par défaut. La façon dont les Passions sont utilisées dans le jeu est discutée ci-dessous.

| Objet de la Passion | Pourcentage de départ |

| Une race ou une espèce | POW du personnage x2 |

## Utilisation de l'Alignement et des Passions

Un Alignement ou une Passion est tout engagement profondément ancré qui a la capacité d'influencer les événements pendant le jeu. Bien qu'ils puissent être utilisés comme des Capacités autonomes (les appeler des compétences serait leur rendre un mauvais service), les Passions sont développées plus en détail ci-dessous pour expliquer comment elles fonctionnent et comment elles peuvent influencer les personnages et les campagnes de _Classic Fantasy Imperative_.

En résumé, l'Alignement et les Passions peuvent être utilisés ainsi :

- Pour augmenter une autre compétence, reflétant la profondeur de ses sentiments et la façon dont cela motive l'action. Lorsqu'utilisé à cet égard, l'Alignement ou la Passion ajoute 20 % de sa valeur à une compétence utilisée, si l'augmentation est thématiquement et dramatiquement importante.
- En tant que Capacité pour diriger les choix, les désirs et les actions et réponses émotionnelles. Lorsqu'utilisé de cette façon, un jet Standard est effectué contre un Alignement ou une Passion pour déterminer à quel point le personnage pense et ressent quelque chose. Si le jet est une Réussite, alors le personnage agit en accord avec ce que l'Alignement ou la Passion dicterait. Si le jet Échoue, alors le personnage peut agir librement sans se sentir contraint par les pulsions de la Passion.
- Pour s'opposer à d'autres Alignements ou Passions – même ceux détenus par le même personnage. Ceci est généralement utilisé lorsqu'un Alignement entrerait en conflit avec une Passion, ou même lorsque deux Passions entreraient en conflit. Par exemple, un amour personnel pourrait dicter une ligne de conduite qui serait contraire à un Serment ou à une loyauté. Ici, utilisez un Jet Opposé entre l'Alignement et la Passion, ou les deux Passions, le résultat le plus réussi déterminant comment le personnage agit.
- Comme mesure générale de la profondeur de l'engagement, de la croyance et de la loyauté envers une cause. Plus la valeur de l'Alignement ou de la Passion est élevée, plus le personnage est engagé. Les personnages ayant des Alignements ou des Passions similaires peuvent comparer leurs notes pour déterminer qui affiche l'engagement le plus profond.
- Pour résister à une forme de manipulation psychologique ou de domination magique. Dans certains cas où un personnage est forcé d'accomplir un acte contraire à ses Alignements ou Passions, il peut substituer l'un ou l'autre à la Volonté dans le Jet Opposé.

Le score d'Alignement d'un personnage peut chuter pendant le jeu si le personnage ignore continuellement sa moralité et/ou son éthique choisies. S'il tombe en dessous du Niveau de Base du personnage, il changera pour un Alignement opposé, Bon vers Neutre ou Mauvais par exemple. Le Maître de Jeu doit déterminer le nouvel Alignement et le nouveau Niveau, en fonction des circonstances. Un changement d'Alignement peut entraîner la perte de l'accès aux Capacités de Classe. Voir la description de la Classe concernée pour plus de détails.

De nouvelles Passions peuvent être développées à tout moment au cours d'une session de jeu de _Classic Fantasy Imperative_ si les circonstances le justifient. On pourrait instantanément développer 'Haïr X' si quelqu'un d'autre fait quelque chose qui susciterait fortement la haine. Un seigneur ou un chef appelant à un Serment établirait immédiatement une Passion de 'Loyauté envers X' dès que ce Serment est pris ou prêté – ce qui est exploré plus en détail dans la section Alignement/Serments de chacune des [Classes](0003_Classes.md).

Les nouvelles Passions développées pendant le jeu de cette manière ne coûtent aucun Jet d'Expérience et sont établies sur-le-champ. Bien sûr, les personnages peuvent également choisir d'établir une Passion pendant l'amélioration, au coût d'un Jet d'Expérience pour obtenir une Passion à sa Valeur de Base : voir les sections sur les divers Alignements et Passions dans le chapitre [Culture et Races](0002_Culture_and_Races.md).

## Approfondissement et Déclin

L'Alignement, les Passions et les Serments peuvent augmenter pendant un jeu indépendamment des Jets d'Expérience, en fonction de la force de ce qui s'est produit pour déclencher l'augmentation. De plus, ils peuvent, et vont, décliner. Une croyance fortement ancrée peut être ébranlée par de nombreuses choses, conduisant cette Passion à être soit réduite, soit, dans des circonstances plus extrêmes, complètement inversée.

Par exemple, un personnage ayant 'Confiance envers le Chef' pourrait, si son chef agit de manière traîtresse, soit réduire sa Passion, soit la transformer en 'Méfiance envers le Chef' au même pourcentage. Le Maître de Jeu doit déterminer si une Passion diminue ou s'inverse. Si elle diminue, alors elle le fait selon la force de la source du changement.
