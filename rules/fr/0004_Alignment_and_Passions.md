# Chapitre 4 : Alignement et Passions

L'utilisation de l'Alignement et des Passions dans *Classic Fantasy Imperative* peut grandement aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des ressorts scénaristiques basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite. Bien que le choix spécifique de l'Alignement et des Passions par le joueur dans ce chapitre soit libre, certains choix trouvés dans le chapitre précédent concernant les [Classes](0003_Classes.md) de personnages sont nécessaires pour jouer ce personnage. Aucune des Classes de ce document ne nécessite un Alignement ou des Passions spécifiques, mais certaines, comme le clerc et le voleur (qui rejoint une guilde de voleurs), exigent un Serment envers leur ordre ou leur guilde. Un Serment peut être traité comme une Passion en ce qui concerne ses mécaniques de jeu.

---
## Alignement

Tous les personnages doivent avoir un Alignement qui se compose de deux parties : un Code Éthique et un Code Moral. Le Code Éthique définit la position vis-à-vis de la loi et du chaos, tandis que le Code Moral détermine le sentiment envers le bien et le mal. Les joueurs choisissent ensuite un ou deux éléments définissants pour chaque code et déterminent les Pourcentages de départ. Par exemple, Chaotique (Désorganisé et Cupide) 55 %, et Bon (Serviable et Charitable) 55 %. Vous ne pouvez pas choisir Neutre deux fois ; à la place, vous ignorez à la fois le Code Moral et le Code Éthique et choisissez Neutre Absolu comme Alignement unique. Les Codes Éthique et Moral, ainsi que leurs éléments définissants, sont détaillés ci-dessous.

#### Code Éthique

Choisissez entre Loyal, Neutre ou Chaotique à un Niveau de Base de INT+POW+30.

- **Loyal** : Choisissez un ou deux éléments définissants qui décrivent le mieux votre Code Éthique : *Adhésion à la tradition ; Calculateur ; Esprit étroit ; Haine du Chaos ; Éthique ; Honnête ; Honorable ; Jugeur ; Manque d'adaptabilité ; Aucun sens de l'humour ; Obéissance à l'autorité légitime ; Organisé ; Prévisible ; Fiable ; Confiant ; Digne de confiance ; Bien élevé.*
- **Neutre** : Choisissez un élément définissant qui décrit le mieux votre Code Éthique : *Croit que la Loi et le Chaos sont des préjugés et des extrêmes dangereux ; Prudent ; Prétentieux ; N'a pas de sentiment fort dans un sens ou dans l'autre concernant la Loi et le Chaos ; Flexible ; Liberté d'action ; N'a pas de Code Éthique établi ; Pragmatique ; Respectueux de la nature.*
- **Chaotique** : Choisissez un ou deux éléments définissants qui décrivent le mieux votre Code Éthique : *Mal élevé ; Sanguinaire ; Curieux ; Cynique ; Malhonnête ; Déshonorant ; Désorganisé ; Mépris de l'autorité légitime ; Égoïste ; Liberté ; Haine de la Loi ; Irresponsable ; Sans foi ni loi ; Mégalomane ; Farceur ; Prompt à la colère ; Déchaîné ; Téméraire ; Méfiant ; Incontrôlé ; Indigne de confiance ; Imprévisible ; Peu fiable.*

#### Code Moral

Choisissez entre Bon, Neutre ou Mauvais à un Niveau de Base de INT+POW+30.

- **Bon** : Choisissez un ou deux éléments définissants qui décrivent le mieux votre Code Moral : *Admirable ; Altruiste ; Angélique ; Autoritaire ; Charitable ; Scrupules à blesser des innocents ; Décent ; Pardonner ; Amical ; Haine du Mal ; Utile ; Gentil ; Aime la nature ; Miséricordieux ; Optimiste ; Positif ; Végétarien.*
- **Neutre** : Choisissez un élément définissant qui décrit le mieux votre Code Moral : *Croit que le Bien et le Mal sont des préjugés et des extrêmes dangereux ; Prudent ; N'a pas de sentiment fort dans un sens ou dans l'autre concernant le Bien et le Mal ; Flexible ; Liberté d'Action ; Manque d'engagement pour faire des sacrifices afin de protéger ou d'aider les autres ; Engagé envers les autres par des relations personnelles, et non par un Code Moral ; N'a pas de Code Moral établi ; Pragmatique ; Cherche rarement la compagnie.*
- **Mauvais** : Choisissez un ou deux éléments définissants qui décrivent le mieux votre Code Moral : *Abusif ; Cannibale ; Convoiteux ; Cruel ; Dominateur ; Prends plaisir à blesser des innocents ; Cupide ; Haine du Bien ; Luxurieux ; Manipulateur ; Impitoyable ; Fier ; Sadique ; Égocentrique ; Égoïste ; Esclavagiste ; Rancunier ; Vain ; Violent.*

#### Neutre Absolu

Le Neutre Absolu commence à un Niveau de Base de INT+POW+30.

- **Neutre Absolu** : Alternativement, choisissez un ou deux éléments définissants qui décrivent le mieux votre manque de Code Moral et Éthique : *Ambivalent ; Prudent ; Engagé envers les autres par des relations personnelles ; Flexible ; Liberté d'action ; Ouvert d'esprit ; Pragmatique ; Respectueux de la Nature ; Recherche l'équilibre.*

## Passions

Les Passions sont utilisées pour aider les joueurs et les Maîtres de Jeu à approfondir la nature du personnage, à introduire des ressorts scénaristiques basés sur les désirs ou les préjugés d'un personnage, et à aider le joueur à comprendre qui est son personnage, ce qui le motive, et ainsi de suite.

Une Passion peut concerner n'importe quoi – une personne, une organisation, un idéal, voire un objet. Les Passions sont généralement décrites par un verbe tel que : Désirer, Mépriser, Détruire, Soutenir, Craindre, Fuir, Répudier, Haïr, Aimer, Loyauté envers, Protéger, Répudier, Respecter, Chercher, Subvertir, Tourmenter ou Défendre.

Les Passions sont mesurées de la même manière que les compétences ; elles sont notées entre 1 et 100 (ou plus). Une Passion peut être améliorée de la même manière qu'une compétence, ou elle peut être augmentée ou diminuée par le Maître de Jeu selon les circonstances.

Les personnages débutants peuvent commencer avec jusqu'à trois Passions, chacune basée sur deux Caractéristiques, avec un bonus de +40 à la première, +30 à la deuxième et +20 à la troisième, le joueur décidant de l'ordre d'importance. Celles-ci peuvent être liées à la culture, à la Classe ou à des particularités personnelles. Par exemple, Méfiance (Voleurs) ; Loyal envers la Reine ; Aimer sa famille ; Vaincre le Chaos. Les Passions jouent un rôle particulièrement important dans de nombreuses Classes de personnages, comme détaillé dans le chapitre suivant. Pour certaines de ces Classes, maintenir une Passion à un niveau minimum est requis pour conserver des Capacités spéciales spécifiques à la Classe, et dans des situations extrêmes, perdre une Passion peut entraîner la perte de la Classe.

La valeur de départ de la Passion varie en fonction de son type ; voir le [Tableau des Passions](0004_Alignment_and_Passions.md?id=passion-table), ci-dessous.

Cette section détaille uniquement ce que représentent les Passions et leurs valeurs par défaut. La manière dont les Passions sont utilisées dans le jeu est discutée ci-dessous.

| Objet de la Passion | Pourcentage de départ |
| :-- | :-- |
| Une personne, dans un contexte romantique ou familial | POW+CHA |

| Une race ou une espèce | POW du personnage x2 |

## Utilisation de l'Alignement et des Passions

Un Alignement ou une Passion est tout engagement profondément ancré capable d'influencer les événements pendant le jeu. Bien qu'ils puissent être utilisés comme des Capacités autonomes (les appeler des compétences serait leur rendre un mauvais service), les Passions sont développées plus en détail ci-dessous pour expliquer leur fonctionnement et leur influence sur les personnages et les campagnes de *Classic Fantasy Imperative*.

En résumé, l'Alignement et les Passions peuvent être utilisés ainsi :

- Pour augmenter une autre compétence, reflétant la profondeur de ses sentiments et la manière dont ils motivent l'action. Lorsqu'il est utilisé à cet égard, l'Alignement ou la Passion ajoute 20 % de sa valeur à la compétence utilisée, si l'augmentation est thématiquement et dramatiquement importante.
- Comme une Capacité pour diriger les choix, les désirs et les actions et réponses émotionnelles. Lorsqu'il est utilisé ainsi, un jet Standard est effectué contre un Alignement ou une Passion pour déterminer avec quelle force le personnage pense et ressent quelque chose. Si le jet est une Réussite, le personnage agit en accord avec ce que dicterait l'Alignement ou la Passion. Si le jet Échoue, le personnage peut agir librement sans se sentir contraint par les motivations de la Passion.
- Pour s'opposer à d'autres Alignements ou Passions – même ceux détenus par le même personnage. Ceci est généralement utilisé lorsqu'un Alignement entrerait en conflit avec une Passion, ou même lorsque deux Passions entreraient en conflit. Par exemple, un amour personnel pourrait dicter un plan d'action contraire à un Serment ou à une loyauté. Ici, utilisez un Jet Opposé entre l'Alignement et la Passion, ou entre les deux Passions, la réussite la plus importante déterminant la façon dont le personnage agit.
- Comme une mesure générale de la profondeur de l'engagement, de la croyance et de la loyauté envers une cause. Plus la valeur de l'Alignement ou de la Passion est élevée, plus le personnage est engagé. Les personnages ayant des Alignements ou des Passions similaires peuvent comparer leurs notes pour déterminer qui affiche l'engagement le plus profond.
- Pour résister à certaines formes de manipulation psychologique ou de domination magique. Dans certains cas où un personnage est forcé d'accomplir un acte contraire à ses Alignements ou Passions, il peut substituer l'un ou l'autre à la Volonté lors d'un Jet Opposé.

Le score d'Alignement d'un personnage peut diminuer pendant le jeu si le personnage ignore continuellement sa moralité et/ou son éthique choisies. S'il tombe en dessous du Niveau de Base du personnage, il changera pour un Alignement opposé, Bon vers Neutre ou Mauvais par exemple. Le Maître de Jeu doit déterminer le nouvel Alignement et le nouveau Niveau, en fonction des circonstances. Un changement d'Alignement peut entraîner la perte d'accès aux Capacités de Classe. Voir la description de la Classe concernée pour plus de détails.

De nouvelles Passions peuvent être développées à tout moment lors d'une session de jeu *Classic Fantasy Imperative* si les circonstances le justifient. On pourrait instantanément développer 'Haïr X' si quelqu'un fait quelque chose qui susciterait fortement la haine. Un seigneur ou un chef appelant à un Serment établirait immédiatement une Passion de 'Loyauté envers X' dès que ce Serment est pris ou prêté – un point exploré plus en détail dans la section Alignement/Serments de chacune des [Classes](0003_Classes.md).

Les nouvelles Passions développées en cours de jeu de cette manière ne coûtent aucun Jet d'Expérience et sont établies sur-le-champ. Bien sûr, les personnages peuvent également choisir d'établir une Passion pendant l'amélioration, au coût d'un Jet d'Expérience pour gagner une Passion à sa Valeur de Base : voir les sections sur les divers Alignements et Passions dans le chapitre [Culture et Races](0002_Culture_and_Races.md).

## Approfondissement et Déclin

L'Alignement, les Passions et les Serments peuvent augmenter pendant une partie indépendamment des Jets d'Expérience, en fonction de la force de ce qui s'est produit pour déclencher l'augmentation. De même, ils peuvent, et vont, décliner. Une croyance fortement ancrée peut être ébranlée par de nombreux facteurs, conduisant à ce que cette Passion soit soit réduite, soit, dans des circonstances plus extrêmes, complètement inversée.

Par exemple, un personnage ayant 'Confiance envers le Chef' pourrait, si son chef agit de manière perfide, soit réduire sa Passion, soit la transformer en 'Méfiance envers le Chef' au même pourcentage. Le Maître de Jeu doit déterminer si une Passion diminue ou s'inverse. Si elle diminue, elle le fait en fonction de la force de la source du changement.
