## Descriptions des sorts

---
#### Appraise

(Divination)

| | |
| :-- | :-- |
| **Rang :** Mage 0 | **Temps d'incantation :** 1 tour |
| **Sphère :** Aucune | **Durée :** Instantanée |
| **Coût :** 1 | **Portée :** Toucher |
| **Zone :** 1 objet | **Résistance :** Aucune |

Appraise permet l'évaluation immédiate de la qualité de biens physiques dont la somme de l'encombrement (ENC) en « Choses » ou la taille (SIZ) est égale à la puissance (POW) du lanceur. Le sort détermine si des objets d'aspect identique sont de qualité identique ou similaire, ou si l'un d'eux est défectueux ou de meilleure qualité. Le sort ne fonctionne pas sur les objets organiques, seulement sur les objets inanimés. Il ne permet pas non plus de déterminer quels sont les défauts ou les améliorations présents ; seulement qu'ils existent. Il est inutile pour l'identification ou la détection de la magie.

#### Armor

(Conjuration)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 round |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3 +1/Intensité | **Portée :** Toucher |
| **Zone :** 1 cible | **Résistance :** Aucune |

Lorsqu'il est lancé, le sujet est doté d'un champ invisible de force magique équivalent à une armure d'écailles, conférant 4 points d'armure à chaque zone corporelle touchée. Il n'a aucun effet s'il est lancé sur quelqu'un portant déjà une armure. Il remplacera cependant l'armure naturelle pour sa durée, en supposant qu'il offre une protection supérieure. S'il est lancé sur une créature possédant plus de 4 points d'armure naturelle, il augmentera à la place les points d'armure de 1 sur toutes les zones. Cette protection magique n'entrave ni le mouvement ni l'incantation. Le sort persistera jusqu'à ce qu'il soit dissipé par magie, ou que le lanceur subisse 8 points de dégâts provenant d'une seule attaque, +1 par niveau d'Intensité supplémentaire (voir le tableau ci-dessous). Bien entendu, le lanceur peut choisir d'arrêter le sort à tout moment s'il le souhaite, et doit le faire pour dormir.

| Intensité | Coût | Effet variable |
| :-: | :-: | :-- |
| 1 | 3 | 4 points d'armure ; maintenu jusqu'à 8 dégâts d'une attaque |
| 2 | 4 | 4 points d'armure ; maintenu jusqu'à 9 dégâts d'une attaque |
| 3 | 5 | 4 points d'armure ; maintenu jusqu'à 10 dégâts d'une attaque |
| 4 | 6 | 4 points d'armure ; maintenu jusqu'à 11 dégâts d'une attaque |
| +1 | +1 | Poursuite de la progression |

#### Astral Spell

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Cleric 5, Mage 5 | **Temps d'incantation :** 2 actions |
| **Sphère :** Astrale | **Durée :** Voir ci-dessous |
| **Coût :** 3 +1/Intensité supplémentaire | **Portée :** Toucher |
| **Zone :** Voir ci-dessous | **Résistance :** N/A |

Ce sort permet au lanceur et jusqu'à cinq autres personnes (une par niveau d'Intensité supplémentaire) d'entrer dans le Plan Astral. Tous doivent se toucher et former un cercle pendant l'incantation. Les corps des voyageurs sont laissés derrière eux dans le plan d'origine, et ils n'apportent généralement ni vêtements ni équipement, sauf ce qui irradie une aura magique ; ces objets se transforment en équivalents astraux de leur forme normale. La durée dure jusqu'à ce que le lanceur souhaite y mettre fin. Cependant, il est possible qu'elle soit interrompue prématurément par une force extérieure telle que Dispel Magic. Tuer le corps physique du lanceur met également fin au sort prématurément, bien que cela ait l'effet secondaire malheureux de bloquer tous les voyageurs accompagnant le lanceur.

#### Augury

(Divination)

| | |
| :-- | :-- |
| **Rang :** Cleric 2 | **Temps d'incantation :** 2 minutes |
| **Sphère :** Divination | **Durée :** Instantanée |
| **Coût :** 3/Intensité | **Portée :** 18 m (60 ft) |
| **Zone :** Lanceur | **Résistance :** N/A |

Ce sort permet au lanceur de déterminer si une action spécifique entreprise dans les 30 prochaines minutes sera bénéfique ou néfaste au bien-être d'un individu et/ou d'un groupe. Un point de focalisation est nécessaire pour discerner les présages, le plus courant étant les griffes ou les petits os d'un dragon, une perle, ou de l'or pur d'une valeur d'au moins 100 po, qui a été broyé ou fondu. Le sort a une Intensité maximale de 4. Ce jet doit être effectué par le Maître de Jeu, car le lanceur ne devrait jamais savoir avec une certitude absolue si les résultats ont été interprétés correctement.

| Intensité | Coût | Effet variable |
| :-: | :-: | :-- |
| 1 | 3 | Jet de compétence Canalisation Difficile |
| 2 | 6 | Jet de compétence Canalisation Difficile |
| 3 | 9 | Jet de compétence Canalisation Standard |
| 4 | 12 | Jet de compétence Canalisation Facile |

Si le jet de divination réussit, il donne l'un des résultats suivants :

| Augure | Implication | 
| :-: | :-- |
| Oui | L'action sera bénéfique |
| Non | L'action sera nuisible |
| Oui et Non | L'action sera à la fois bénéfique et nuisible |
| Rien | L'action ne sera ni bénéfique ni nuisible |

Un échec critique (Fumble) devrait amener le Maître de Jeu à dire le contraire de la réalité.

#### Avert

(Abjuration)

| | |
| :-- | :-- |
| **Rang :** Cleric 0, Mage 0 | **Temps d'incantation :** Instantané |
| **Sphère :** Protection | **Durée :** Instantanée |
| **Coût :** 1 | **Portée :** 18 m (60 ft) |
| **Zone :** 1 sort | **Résistance :** Aucune |

Avert est utilisé pour annuler un autre sort de rang 0 à portée. Avert peut être lancé de manière réactive pour neutraliser les sorts offensifs de rang 0, en utilisant l'Action Réactive de Contre-magie.

#### Befuddle

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Cleric 0, Mage 0 | **Temps d'incantation :** 1 tour |
| **Sphère :** Charme | **Durée :** 30 minutes |
| **Coût :** 1 | **Portée :** 18 m (60 ft) |
| **Zone :** 1 cible | **Résistance :** Volonté |

Befuddle provoque une confusion dans l'esprit d'une cible corporelle. Le sujet du sort a des difficultés à penser clairement, oublie où il est, ce qu'il fait et pourquoi, sombrant souvent dans des lignes de pensée dissociées. Les cibles confuses peuvent toujours agir en légitime défense mais ne peuvent engager aucune activité constructive jusqu'à la fin du sort. Toute forme d'attaque ou d'action menaçante rompt instantanément le sort, qu'elle soit dirigée spécifiquement vers la cible confuse ou non.

#### Blade Barrier

(Évocation)

| | |
| :-- | :-- |
| **Rang :** Cleric 4 | **Temps d'incantation :** 2 actions |
| **Sphère :** Gardien, Création | **Durée :** 3 rounds/Intensité |
| **Coût :** 3+1/Intensité supplémentaire | **Portée :** 30 m (100 ft) |
| **Zone :** Rayon de 1,5 à 9 m (5-30 ft) | **Résistance :** Voir ci-dessous |

Ce sort crée une barrière d'épées, de poignards et de couteaux tourbillonnants qui tranchent et coupent autour d'un point fixe et infligent 1d8 points de dégâts à 1d4+2 zones corporelles aléatoires de *quiconque* traverse la zone d'effet. L'armure n'offre que la moitié de sa protection normale. Les points d'armure magiques réduisent les dégâts normalement. Parce que les armes tourbillonnent à une vitesse fulgurante et sont serrées, il est impossible de les parer ou de les esquiver. On peut utiliser un bouclier pour bloquer passivement les zones corporelles normalement. Dans ce cas, n'oubliez pas de comparer les dégâts obtenus aux points d'armure et aux points de vie du bouclier.

Le sort peut être lancé défensivement pour protéger le clerc ou un ou plusieurs alliés, ou pour piéger offensivement des ennemis. Cependant, les ennemis encerclés à moins d'un mètre cinquante (5 pieds) du bord de la barrière au moment où elle se forme peuvent effectuer un jet d'Esquive pour s'échapper. Indépendamment du succès, l'adversaire finit à terre, juste à l'extérieur de la zone d'effet. Un jet réussi n'entraîne aucun dégât ; sinon, ils subissent le plein effet.

#### Bless \(R\)

(Conjuration)

| | |
| :-- | :-- |
| **Rang :** Cleric 1 | **Temps d'incantation :** 1 round |
| **Sphère :** Toutes | **Durée :** 5 minutes |
| **Coût :** 1 | **Portée :** 55 m (180 ft) |
| **Zone :** Rayon de 7,5 m (25 ft) | **Résistance :** Volonté |

Lorsque ce sort est lancé, le clerc bénit un groupe d'alliés dans la zone d'effet. Ceux affectés irradient l'alignement du lanceur, soit Bon, soit Mauvais. Il n'existe pas de bénédiction de Neutralité. Tous les alliés dans le rayon du sort reçoivent un bonus de +5 % à tous les jets de compétence et de résistance. De plus, leurs armes infligent +1d3 dégâts aux morts-vivants intelligents ainsi qu'aux créatures des plans extérieurs ayant des alignements opposés à celui du lanceur, tels que les démons, les diables ou les anges. Notez que si les morts-vivants animés tels que les squelettes et les zombies ne sont pas intrinsèquement mauvais, ils sont généralement animés par une magie mauvaise et sont donc sujets à ces dégâts.

L'inverse de ce sort, Curse, permet au clerc de maudire des ennemis, faisant subir aux compétences notées l'inverse des avantages notés ci-dessus. Les dégâts d'une arme maudite sont calculés comme une pénalité, et ces dégâts ne peuvent pas être inférieurs à 1 point.

#### Burning Hands

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Aucune | **Durée :** Instantanée |
| **Coût :** 3+1/Intensité supplémentaire | **Portée :** 0 |
| **Zone :** Cône de 120 degrés, 1,5 m de long | **Résistance :** Esquive |

Ce sort provoque des flammes jaillissant des mains du lanceur dans un arc de 120 degrés. Si vous utilisez des figurines au combat, Burning Hands endommagera chaque cible occupant l'une des cases situées devant le lanceur. Lancer Burning Hands à des niveaux d'Intensité plus élevés nécessite un mage de rang supérieur. Ces dégâts engloutissent toutes les cibles dans la zone avec des dégâts basés sur l'Intensité du sort, jusqu'à une Intensité maximale de 9, comme suit. Un jet d'Esquive réussi, se jetant à terre, permet à la victime de ne subir aucun dégât. Quelqu'un avec l'aptitude Artful Dodger (As de l'esquive) a l'option d'Esquiver sans se jeter à terre.

| Intensité | Coût | Rang min | Effet variable |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 points de dégâts à toutes les zones corporelles |
| 3 | 4 | 1 | 1d3+2 points de dégâts à toutes les zones corporelles |
| 5 | 5 | 1 | 1d3+3 points de dégâts à toutes les zones corporelles |
| 7 | 6 | 2 | 1d3+4 points de dégâts à toutes les zones corporelles |
| 9 | 7 | 3 | 1d3+5 points de dégâts à toutes les zones corporelles |

L'armure portée ne protège pas, mais les points d'armure magiques ou l'armure naturelle d'une créature réduisent les dégâts normalement. Ce sort puissant est équilibré par sa portée remarquablement courte, ce qui signifie que pour le lancer, l'utilisateur de magie doit être suffisamment proche pour être dans une position très désavantageuse.

Parce que les plus grandes créatures sont généralement plus grandes que la zone d'effet du sort, elles auront tendance à avoir moins de zones corporelles affectées. Celles de taille (SIZ) 21 à 30 prennent les dégâts à la tête, à la poitrine, à l'abdomen et aux bras, tandis que celles de taille 31+ prendront les dégâts à l'abdomen et aux jambes. Les Maîtres de Jeu doivent ajuster ces zones en fonction de la forme et de la position de la cible par rapport au lanceur. Burning Hands a une chance d'enflammer les matériaux inflammables égale aux dégâts obtenus x5%. Voir la section sur les [Feux](0007_Game_System.md?id=fire-based-attacks) pour plus d'informations.

#### Command

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Cleric 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Charme | **Durée :** 1 minute |
| **Coût :** 3 | **Portée :** 30 m (100 ft) |
| **Zone :** 1 cible | **Résistance :** Volonté |

Lorsque ce sort est lancé, le clerc peut prononcer un ordre en un mot à une créature vivante de SIZ 1-20, et au prochain tour du sujet, l'ordre sera suivi à la lettre s'il échoue à résister. Cela amène essentiellement la victime à manquer le tour suivant pour effectuer l'action commandée et gaspille un Point d'Action tout en l'exécutant. Si la victime ne possède plus de Points d'Action, l'action commandée sera effectuée lors de son premier tour du prochain round. L'ordre lui-même ne peut causer aucune blessure réelle à la cible ; cependant, une blessure peut survenir comme effet secondaire de l'ordre.

Par exemple, un ordre de mourir entraînerait la victime à s'effondrer dans un état comatique semblable à la mort pendant 1 round, sans causer de blessure réelle ; cependant, un ordre de tomber donné à une créature escaladant une falaise de 30 mètres pourrait être plus que mortel.

Le sujet de l'ordre doit être capable de comprendre la langue parlée par le lanceur et a droit à un test de Volonté pour résister.

**Quelques exemples d'ordres**

- **Ramper :** Le sujet tombe à terre et commence à ramper.
- **Mourir :** Le sujet tombe à terre en entrant dans un état comatique semblable à la mort.
- **Tomber :** Le sujet tombe à terre.
- **Fumble :** Le sujet rate (fumble) une action physique sur le point d'être effectuée.
- **Dormir :** Le sujet s'assoupit.
- **Fuir :** Le sujet se retourne et fuit le lanceur.
- **Voler :** Le sujet agite ses bras et court en cercles.
- **Aller :** Le sujet commence à marcher dans la direction où il faisait face.
- **Halte :** Le sujet s'arrête immédiatement et reste sur place.
- **Partir :** Le sujet se retourne et part par le chemin qu'il a emprunté.
- **Reposer :** Le sujet s'assoit et reprend son souffle.
- **Courir :** Le sujet commence à courir.
- **Crier :** Le sujet hurle.
- **Couler :** Le sujet arrête de nager.
- **Se rendre :** Le sujet lâche ses armes et cesse les hostilités.

#### Enchant Item

(Enchantement)

| | |
| :-- | :-- |
| **Rang :** Mage 4 | **Temps d'incantation :** Voir ci-dessous |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3 + Voir ci-dessous | **Portée :** Toucher |
| **Zone :** 1 objet | **Résistance :** N/A |

L'incantation de ce sort prépare un objet à l'enchantement. L'objet doit être en bon état et de la plus belle construction et finition. Un coût supplémentaire d'au moins 100 po est requis pour couvrir le coût de l'outillage, de la sculpture, de la broderie, de l'ornementation, de la gravure, etc. Enfin, le processus d'enchantement nécessite un laboratoire ou un atelier.

Pendant l'incantation, l'utilisateur de magie doit toucher l'objet tout au long du temps d'incantation de 1d8+2 jours. Cela compte les périodes de repos et de sommeil, pendant lesquelles l'objet doit rester à portée de main du lanceur. À aucun moment pendant l'incantation, l'utilisateur de magie ne peut lancer un autre sort ou effectuer toute autre forme de magie. Rompre l'une de ces restrictions fera automatiquement échouer le sort.

Une fois lancé avec succès, l'objet est prêt pour l'étape finale, le lanceur plaçant le sort souhaité à l'intérieur. Pour ce faire, il doit avoir le sort en mémoire ou sur un parchemin et le lancer dans l'objet dans les 24 heures, sinon tout le processus devra être recommencé à zéro. Une fois que l'incantation du sort sélectionné commence, le processus peut dépasser les 24 heures susmentionnées. Imprégner l'objet du sort sélectionné coûte le nombre normal de points de magie pour l'Intensité souhaitée et prend 1d12 heures par rang de sort. Tout au long du processus d'imprégnation, le lanceur doit rester en contact avec l'objet ou à portée de main pendant les périodes de repos, comme ci-dessus, et un jet d'incantation arcanique est requis à la fin de la période d'incantation pour imprégner le sort avec succès. Les degrés de réussite normaux du lancer de sorts sont suivis, cependant, concernant un résultat d'échec, le sort ne peut pas être forcé. Des sorts successifs peuvent être imprégnés dans l'objet, à condition que le processus d'incantation soit commencé dans les 24 heures suivant l'achèvement du sort précédent. Cela s'applique même dans le cas d'un sort précédemment échoué. Chaque sort successif nécessite le coût d'incantation normal.

Lors de l'utilisation de l'objet, chaque sort contenu peut être lancé une seule fois, cependant plusieurs versions du même sort peuvent être imprégnées suivant la procédure ci-dessus. Il est également possible d'imprégner un seul sort, en le suivant d'une incantation du sort de rang 4 Permanency. Dans ce cas, le sort peut être lancé aussi souvent qu'on le souhaite, en suivant les restrictions énoncées dans la description du sort Permanency.

Il n'est pas possible d'imprégner d'autres effets magiques dans un objet qui ne se conforment pas à un sort spécifique, et de nombreux objets magiques d'autrefois ne peuvent tout simplement pas être recréés de nos jours.

#### Exorcism

(Abjuration)

| | |
| :-- | :-- |
| **Rang :** Cleric 3 | **Temps d'incantation :** 1d10x100 minutes |
| **Sphère :** Protection | **Durée :** Permanente |
| **Coût :** 3+1/Intensité supplémentaire | **Portée :** 3 m (10 ft) |
| **Zone :** 1 cible | **Résistance :** Volonté |

Au moyen de ce sort, les clercs appellent leur divinité pour chasser un esprit ou une autre force surnaturelle possédant actuellement un être corporel, comme dans le cas d'une possession démoniaque. Exorcism peut également être utilisé contre la domination par certains objets et objets magiques, sorts, malédictions, et même charmes. Ce qui se passe ensuite dépend de l'attitude et du type d'entité, s'il y en a une, mais les entités belligérantes capables de se désincorporer pourraient être tentées d'engager d'autres cibles proches dans un combat spirituel. Traitez cela comme un duel magique ; cependant, si l'entité gagne, elle peut posséder le perdant. Si l'entité perd, elle est renvoyée dans son plan d'origine. Ainsi, ce sort peut être potentiellement dangereux pour le lanceur ou ses compagnons. Le temps d'incantation est très aléatoire et ne peut être interrompu sans perturber le rituel.

Lorsque ce sort est lancé, plusieurs personnes, créatures ou objets dans la zone d'effet du sort, avec une SIZ combinée totale ne dépassant pas 20 par Intensité, ont leur poids réduit à celui d'une plume. Cela permet au sort de protéger contre les chutes inattendues ou même d'interrompre l'action d'autrui pour ralentir les projectiles propulsés comme les flèches ou les lances projetées, qui flottent ensuite doucement vers le sol entre l'attaquant et la cible, ne causant aucun dégât.

#### Find Familiar

(Conjuration)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 2d12 heures |

| **Coût :** 3/Intensité, +1 EXP | **Portée :** 0 |
| **Zone :** Rayon de 0,8 km/Intensité | **Résistance :** N/A |

Ce sort permet au lanceur de tenter d'invoquer un familier, qui devient une extension des sens et de la puissance de son maître. Les familiers peuvent converser avec leur maître télépathiquement et font de bons gardes et éclaireurs. Faire tuer son familier présente certains risques pour l'utilisateur de magie en raison de leur lien étroit, ce qui fait d'avoir un familier un danger de rang inférieur.

Pour invoquer un familier, l'utilisateur de magie doit commencer le rituel tout en gardant un brasero alimenté avec du charbon de bois, et lorsqu'il brûle avec intensité, ajouter de l'encens d'une valeur de 100 po. Avec ces ingrédients brûlant, le lanceur doit ensuite poursuivre le rituel jusqu'à ce que le familier arrive ou que le temps d'incantation expire sans succès.

Même si ce sort est lancé avec succès, la chance qu'un familier approprié réponde à l'appel de l'utilisateur de magie n'est que de 50 %, et l'utilisateur de magie ne peut tenter ce sort qu'une fois par an. Chaque niveau d'Intensité supplémentaire au-delà du premier étend la portée du sort d'un demi-mile supplémentaire (0,8 km), ce qui augmente à son tour la probabilité qu'un familier potentiel soit trouvé de 5 %, jusqu'à un maximum de 95 %. Il n'y a aucun contrôle sur le type exact de créature qui répondra à l'appel, mais ce qui arrivera sera un serviteur et allié fidèle. C'est à la créature spécifique de répondre à l'appel, donc être dans une région connue pour être habitée par un certain type de créature n'assure *pas* au lanceur le succès.

Si une créature répond aux invocations du lanceur, l'utilisateur de magie doit encore sacrifier 1 jet d'expérience pour créer un lien spirituel entre lui et le familier. Une fois cela fait, le rituel est terminé.

Tant que le familier et son maître sont à moins de 36 mètres (120 pieds) l'un de l'autre, l'utilisateur de magie gagne également la capacité d'utiliser les points de magie du familier. De plus, l'utilisateur de magie gagne un lien télépathique avec le familier et tous les avantages supplémentaires ou bonus de compétence notés sur les tableaux ci-dessous.

En cas de mort du familier, le lanceur perd 5 jets d'expérience. Un lanceur ne possédant actuellement aucun jet d'expérience doit renoncer à tous les autres jets d'expérience attribués jusqu'à ce que le solde soit payé.

Ce sort crée un bouclier de flammes vaporeuses qui immole le lanceur mais ne cause aucun dommage en soi. Au lieu de cela, les flammes protègent le bénéficiaire soit du feu, soit du froid, selon laquelle des deux variantes est en mémoire : Chill Shield, qui crée des flammes bleues ou vertes et protège contre les dégâts de chaleur et de feu, ou Warm Shield, qui crée des flammes violettes ou bleues et protège contre les dégâts de froid et de glace. La couleur des flammes doit être déterminée au hasard avec 50 % de chances pour l'une ou l'autre, car le fait que les deux types puissent émettre des flammes bleues crée un élément d'incertitude de la part de tout attaquant. La décision quant à laquelle mémoriser est prise lorsque les sorts sont préparés, et les deux peuvent être mémorisées si désiré. Ces flammes ne dégagent aucune chaleur et ne projettent de la lumière qu'à la moitié de la luminosité d'une torche. Les spécificités de chaque variante sont détaillées ci-dessous.

- **Chill Shield :** Ces flammes sont froides au toucher et réduisent tout dégât de feu ou de chaleur à la moitié du total. Un jet de résistance réussi annulera tous les dégâts. Le jet de résistance est un degré plus facile et, dans le cas de l'Esquive, ne rendra pas le défenseur à terre.
- **Warm Shield :** Ces flammes sont chaudes au toucher et réduisent tout dégât de froid à la moitié du total. Un jet de résistance réussi annulera tous les dégâts. Le jet de résistance est un degré plus facile et, dans le cas de l'Esquive, ne rendra pas le défenseur à terre.

Les attaques de mêlée contre le bénéficiaire de l'une ou l'autre variante, qu'elles soient armées ou non armées, infligent des dégâts normaux à moins d'utiliser l'un des éléments contre lesquels il est protégé. Dans ce cas, le lanceur est protégé de la portion élémentaire de l'attaque, et l'attaquant reçoit des dégâts égaux à ceux infligés. L'armure portée par l'attaquant n'offre aucune protection, mais les points d'armure magiques ou l'armure naturelle d'une créature réduisent les dégâts normalement. Les créatures dotées d'une résistance magique innée peuvent dissiper Fire Shield sur un jet de Volonté réussi lorsque le bénéficiaire est frappé pour la première fois. Si le jet de résistance magique échoue, l'adversaire ne pourra pas annuler le Fire Shield ultérieurement.

(Transmutation)

#### Illusion

(Illusion)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |

| **Coût :** 1/Intensité | **Portée :** 30 m/Intensité |
| **Zone :** Rayon de 15 m/Intensité | **Résistance :** Doute (Disbelieve) |

Ce sort crée une illusion visuelle de tout ce que le lanceur désire. Il n'a aucun effet sur les autres sens, ne faisant aucun bruit, ne produisant aucune odeur, température, texture, etc.

Cette illusion peut être n'importe quoi, d'une prairie ouverte à un ancien dragon rouge, si elle tient dans la zone d'effet du sort. L'illusion ne durera que tant que le lanceur maintient sa Concentration, ou une fois qu'un adversaire la touche ou y entre ; faire cela provoque le dénouement de la magie qui la soutient et la dissipation de l'illusion. Cependant, le lanceur peut maintenir l'illusion après un contact physique, en dépensant 1 point de magie et en la dirigeant pour réagir de manière appropriée au contact afin de ne pas créer de suspicion. Par exemple, dans des circonstances normales, l'illusion d'un ogre disparaîtrait lorsqu'elle est frappée par une flèche ; cependant, le lanceur pourrait faire en sorte que l'ogre semble hausser les épaules face au coup et charger l'attaquant en dépensant 1 point de magie. Bien qu'aucun dommage réel ne puisse être infligé par l'illusion, ni aucune température créée, l'esprit peut être convaincu qu'il ressent de la douleur, subissant les effets d'une blessure, ou ressentant des extrêmes de chaleur ou de froid ; cependant, les objets ne sembleront pas geler ou brûler, à moins que le lanceur ne se concentre sur ces effets également. Une fois le sort lancé, des effets visuels supplémentaires peuvent être ajoutés par l'utilisateur de magie à volonté en se concentrant sur l'effet désiré. Cela ne prend généralement aucun temps et peut être traité comme une action libre. Donc, par exemple, si le lanceur souhaitait qu'une torche illusoire tombée fasse paraître des feuilles sèches comme si elles prenaient feu, le lanceur pourrait se concentrer en tant qu'action libre pour le faire.

#### Magic Mouth

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 2 | **Temps d'incantation :** 1 minute |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3, +1/Intensité supplémentaire | **Portée :** 9 m (30 ft) |
| **Zone :** 1 objet | **Résistance :** N/A |

Ce sort crée une bouche sur un objet, qui apparaît magiquement lorsqu'elle est déclenchée par un événement spécifique ou un moment désigné par l'utilisateur de magie lors du premier lancement du sort. Cette bouche prononcera ensuite n'importe quelle phrase prédéfinie choisie par le lanceur au moment de l'incantation. Cette phrase doit consister en pas plus de 25 mots et est prononcée par la bouche à un rythme d'environ 1 mot par seconde. La bouche ne peut pas prononcer de mots de pouvoir ni lancer de sorts.

Ce sort peut être lancé sur n'importe quel objet normalement inanimé, d'un pilier ou d'un arbre, à un mur de pierre ou un coffre ; cependant, il est particulièrement efficace lorsqu'il est lancé sur une statue, car la statue elle-même semblerait parler. Il ne peut être lancé sur aucune créature vivante dotée d'une forme d'intelligence ou d'instinct. Cela s'applique à ceux qui étaient autrefois vivants. Lors du lancement de ce sort, l'utilisateur de magie détermine la situation qui déclenchera l'enchantement. Il peut être conçu pour se déclencher via n'importe quoi, d'un mot prononcé à la création de n'importe quel bruit. Cela pourrait être aussi général que "quand la prochaine personne entre dans cette pièce..." à aussi spécifique que, "quand une clerc femelle de Sedona arrive à moins de 3 mètres de la statue au bout du couloir un samedi...". L'effet déclencheur ne peut pas être quelque chose qui ne peut être discerné non magiquement, comme une créature invisible, l'alignement, la compétence, la classe, etc. d'une créature. Cependant, il pourrait désigner les vêtements portés. La distance maximale à laquelle le sort peut être déclenché est de 7,5 mètres par Intensité.

La durée de ce sort est permanente jusqu'à ce que l'enchantement soit activé, après quoi le sort se termine.

#### Polymorph Other

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 3 | **Temps d'incantation :** 2 actions |
| **Sphère :** Aucune | **Durée :** Permanente |
| **Coût :** 3, +1/Intensité supplémentaire (+1 EXP) | **Portée :** 4,5 m/Intensité |
| **Zone :** 1 cible | **Résistance :** Volonté |

Le lanceur peut modifier la forme d'une créature corporelle ciblée en celle d'une autre, chaque point d'Intensité modifiant la SIZ jusqu'à 5 points. Par conséquent, transformer un orc de SIZ 16 en un lapin de SIZ 1 nécessiterait 3 niveaux d'Intensité (15 points de SIZ de différence). Le sujet de ce sort a droit à un jet de résistance de Volonté. Les créatures grandes (SIZ 21-40) sont moins sensibles à être polymorphées, leur jet de résistance étant Facile, tandis que le jet de résistance pour les créatures Énormes (SIZ 41+) est Très Facile.

Le processus de transformation complet prend un round complet et peut être assez stressant pour la créature en question, nécessitant un deuxième jet de Volonté pour conserver sa personnalité originale, un échec étourdissant le sujet pendant 1d10 minutes, et un échec critique (Fumble) résultant en la mort par choc mental. Chaque doublement ou halage de la SIZ originale de la créature rend le jet de Volonté pour conserver la personnalité un degré plus difficile, tout comme un changement complet d'environnement, tel que changer une personne en poisson. Un jet réussi permet à la victime de conserver son INT et CHA ainsi que toutes les compétences nécessitant ces caractéristiques.

La transformation confère au bénéficiaire la forme de respiration de la créature supposée, si elle est autre que normale ; toutes les attaques naturelles ; et tous les modes de mouvement mondains. Elle ne confère aucune capacité accrue ou magique possédée par la créature. Par exemple, une créature qui a été polymorphée en dragon ne gagnera pas l'attaque de souffle ou les capacités de type sort de la créature, mais gagnera la capacité de voler, sa peau résistante, morsure mortelle, attaques de griffes, etc. De plus, la victime gagne les compétences physiques de la nouvelle forme comme Athlétisme, Brawn, Fly, Swim, ainsi que ses points de vie et modificateur de dégâts. En supposant que l'individu transformé ait conservé son INT, il perd toujours la capacité de parler, à moins que la nouvelle forme ne possède la capacité d'articuler des mots. Ceux qui étaient capables de lancer des sorts dans leur forme précédente seraient toujours capables de lancer dans la nouvelle forme, en supposant qu'ils possèdent toujours la capacité de produire les composants verbaux et somatiques. Dans le cas d'un changement radical, comme passer de bipède à quadrupède, ou d'un animal terrestre à une créature marine, par exemple, le Maître de Jeu devrait se sentir libre de pénaliser d'au moins un degré de difficulté l'utilisation de toute compétence qui prendrait du temps à apprendre tout en s'ajustant à la nouvelle forme jusqu'à ce qu'il y ait eu suffisamment de temps pour pratiquer. Cela est particulièrement vrai pour les compétences physiques telles que l'athlétisme, le combat à mains nues, la nage, le vol, les compétences de combat, etc.

Le jet de Volonté pour conserver sa personnalité est requis chaque jour où le sujet reste transformé jusqu'à ce qu'il échoue, faisant finalement succomber la personne à la mentalité de la nouvelle forme, l'INT passant à l'INS dans le cas d'une créature non sapiente. Toutes les capacités spéciales et magiques possédées par la nouvelle forme qui n'étaient pas acquises précédemment, telles que les attaques de regard, les armes de souffle, etc., sont maintenant disponibles pour la créature une fois la transformation complète. Les personnages qui perdent leur identité de cette manière deviennent des personnages non-joueurs sous le contrôle du Maître de Jeu.

Avant de succomber mentalement à la transformation, la créature polymorphée est sensible à Dispel Magic normalement, sans jet pour résister requis, car ce serait le désir subconscient de revenir à la normale. La transformation nécessite un autre jet de Volonté pour résister à la tension, un échec étourdissant le sujet pendant 1d10 minutes, et un échec critique entraînant la mort par choc mental.

Si la victime avait succombé à la nouvelle forme, Dispel Magic peut toujours être utilisé ; cependant, la victime tentera de résister à un retour à la forme naturelle avec un jet de Volonté. Échouer à ce jet signifie que la victime se transforme en forme naturelle, ce qui, bien sûr, nécessite un autre jet de Volonté pour résister au choc mental de la transformation. Une fois perdue, l'identité naturelle d'une victime n'est plus atteignable, au lieu de cela la victime suppose que la forme étrange et extraterrestre est naturelle et aspire à retourner à sa précédente "normale". _Par exemple, un orc qui a été polymorphé en lapin et a assumé l'identité de la créature croirait qu'il est maintenant un lapin qui a été assez grossièrement transformé en orc._ Seul un Wish, ou une autre magie similaire, a une chance de restaurer l'identité de la victime une fois qu'elle a été perdue.

Tous les équipements portés et transportés se fondent magiquement dans la nouvelle forme ; cependant, dans certains cas, le Maître de Jeu peut permettre aux objets magiques qui pourraient encore être utilisés dans la nouvelle forme de la créature de rester, comme un anneau magique ou des bottes. Notez que cela nécessite que la SIZ de la nouvelle créature ne soit pas très différente de l'originale. Il y a une chance de POW x1 % pour chaque objet magique porté de nature non offensive, sous réserve de l'approbation du Maître de Jeu, de transférer ses effets à la nouvelle forme de la créature. Une créature avec un anneau de protection +1, par exemple, pourrait gagner un bonus de +1 à ses points d'armure naturelle. Les créatures ayant la capacité naturelle de changer de forme, comme les doppelgängers et les lycanthropes, seront transformées normalement, mais peuvent assumer leur forme normale après 1 round. S'il est tué, une créature polymorphée revient à sa forme naturelle, même si elle avait précédemment perdu toute trace d'identité.

#### Raise Dead \(R\)

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Cleric 3 | **Temps d'incantation :** 1 minute |
| **Sphère :** Nécromantique | **Durée :** Permanente |
| **Coût :** 3, +1/Intensité supplémentaire, +1 EXP | **Portée :** 30 m (100 ft) |
| **Zone :** 1 cible | **Résistance :** N/A (Volonté) |

Ce sort peut être lancé sur le cadavre d'une créature morte depuis moins de 24 heures par niveau d'Intensité. Si l'alignement du sujet était autre que mauvais, il peut résister au sort avec un jet de Volonté opposé et, en cas de succès, annuler les effets du sort. C'est parce que l'âme ou l'esprit du défunt est rarement disposé à retourner chez les vivants une fois qu'il a atteint sa récompense éternelle. Le Maître de Jeu peut décider d'annuler le jet si le bénéficiaire a des affaires en suspens, ne peut être séparé de son véritable amour, ou a une autre raison héroïque de vivre.

Dans le cas des âmes mauvaises, qui retourneraient volontiers sur le plan matériel plutôt que de souffrir la damnation éternelle, ce n'est pas la volonté du défunt qui résiste, mais celle du démon, diable, etc., placé en charge de sa punition, son tourmenteur. Dans ce cas, le lanceur doit surmonter la volonté du tourmenteur. Si celle-ci est inconnue, supposez qu'elle est au moins 20 points supérieure à celle du défunt pour représenter que plus la volonté de l'âme est forte, plus l'être placé en charge de sa damnation est puissant. Si le lanceur réussit, il a renvoyé avec succès l'esprit dans le corps, tandis qu'un jet raté entraîne que la victime est soit non disposée, soit incapable de retourner.

Si l'incantation réussit, le sujet revient à la vie avec tous ses points de vie, bien que les membres sectionnés restent perdus. Cela signifie qu'une victime décapitée ou coupée en deux ne peut être ressuscitée avant que sa tête ou son torse ne soit d'abord rattaché. Cela peut être fait avant l'incantation de Raise Dead en rattachant physiquement la zone sectionnée, ce qui nécessite une trousse de soins et une application réussie de la compétence Guérison, et laisse généralement une cicatrice évidente. D'autres affections, telles que le poison ou la maladie, doivent être prises en charge avant ou après l'incantation de Raise Dead, sinon les résultats ne sont que temporaires. Enfin, Raise Dead n'a aucun effet sur une créature ayant atteint la fin de sa durée de vie naturelle et morte de vieillesse.

L'acte d'être ramené à la vie est très éprouvant pour le sujet, qui est réduit à un niveau de fatigue "Incapable" pendant une période de 24 heures pour chaque jour passé mort. L'incantation de Cure Fatigue n'a aucun effet sur le patient pendant ce temps de convalescence. Après cela, le personnage récupère normalement de sa fatigue, sans restriction.

Lorsqu'il est inversé, Slay Living, peut être utilisé pour tuer une victime désignée par le clerc au moment de l'incantation. Cette victime a droit à un jet de Volonté pour résister, modifié par le rang ou la SIZ de la cible, selon ce qui donne le résultat le plus bénéfique à la cible, comme détaillé sur le tableau suivant.

| Rang de la cible | SIZ de la cible | Modificateur de Volonté |
| :-: | :-: | :-: |
| 0-1\* | 1-20 | Difficile |
| 2 | 21-40 | Standard |
| 3 | 41-60 | Facile |
| 4-5 | 61+ | Très Facile |

_\* Cette catégorie inclut les personnages qui ne possèdent pas de classe._

Si le jet de résistance échoue, la victime est tuée sur le coup. Un jet réussi est traité comme les effets de Cause Serious Wounds. L'armure n'offre aucune protection contre ces dégâts.

#### Read Magic

(Toutes)

| | |
| :-- | :-- |
| **Rang :** Mage 0 | **Temps d'incantation :** 1 minute |
| **Sphère :** Aucune | **Durée :** 2 minutes/Intensité |
| **Coût :** 1/Intensité | **Portée :** 0 |
| **Zone :** Lanceur | **Résistance :** N/A |

Ce sort est le premier sort enseigné aux apprentis utilisateurs de magie, car c'est grâce à lui qu'ils peuvent lire les écrits magiques d'un autre lanceur de sorts. Les écrits magiques des mages leur sont toujours intelligibles. Lire une écriture magique n'active généralement pas un sort contenu tel que celui trouvé sur des parchemins magiques ; cependant, les parchemins magiques maudits et similaires sont activés en utilisant ce sort, lançant tout sort que le parchemin contenait.

Lorsqu'il est utilisé pour identifier un sort contenu sur un parchemin ou dans un grimoire, 1 minute est requise pour chaque rang de sort ; les sorts de rang 1 prennent 1 minute, les sorts de rang 2 prennent 2 minutes, et ainsi de suite. Si la durée est suffisante, d'autres sorts peuvent être identifiés pendant ce temps. Une fois que ce sort a été utilisé pour lire et identifier un ensemble d'inscriptions magiques, l'utilisateur de magie n'a pas besoin de lancer Read Magic pour les relire ; cependant, le même sort sur un parchemin, un livre, etc. séparé, nécessiterait une autre incantation de Read Magic.

Read Magic est utilisable par toutes les écoles de magie.

#### Regenerate \(R\)

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Cleric 4 | **Temps d'incantation :** 3 minutes |
| **Sphère :** Guérison | **Durée :** Permanente |
| **Coût :** 3/Intensité | **Portée :** Toucher |
| **Zone :** 1 créature | **Résistance :** N/A (Parade ou Esquive) |

Lorsqu'il est lancé, le clerc peut toucher une créature et régénérer une zone corporelle sectionnée. Les membres perdus repousseront complètement à un rythme de 1 point de vie toutes les 10 minutes jusqu'à la guérison complète. Cependant, si la zone sectionnée est présente et touche la victime, tout le temps de récupération est réduit à 1 minute. Ce sort ne peut être utilisé pour "cloner" un individu en régénérant deux parties séparées, seule la portion connectée au cerveau et au système nerveux central bénéficiant des effets du sort. Chaque niveau d'Intensité fera repousser une zone corporelle séparée. Bien que le sort puisse être utilisé pour guérir lentement une blessure mineure, il existe des sorts de rang inférieur, moins coûteux, pour le faire.

Lorsqu'il est inversé, Wither provoquera le flétrissement d'une zone touchée par le lanceur, qui finira par tomber de la victime. Le processus provoque la perte d'un point de vie de dégât sur la zone touchée toutes les 10 minutes, la zone devenant inutilisable à 0 point de vie, et tombant lorsqu'elle est totalement négative. Les effets ne peuvent être annulés que par une incantation de Regenerate.

#### Remove Curse \(R\)

(Abjuration)

| | |
| :-- | :-- |
| **Rang :** Cleric 2, Mage 3 | **Temps d'incantation :** 2 actions |
| **Sphère :** ?? | **Durée :** Permanente |
| **Coût :** 3, +1/Intensité supplémentaire | **Portée :** Toucher |
| **Zone :** 1 cible | **Résistance :** N/A |

Ce sort supprime généralement les effets de toute malédiction affligeant une créature ou un objet. Il ne supprime pas la nature maudite d'un objet tel qu'une arme, un bouclier ou une armure, mais permet à une créature affligée par un tel objet de s'en débarrasser. Certaines malédictions ne peuvent être supprimées que si le sort est lancé à une certaine Intensité, généralement notée dans la description spécifique. Cure Disease ou Remove Curse peuvent être utilisés pour guérir la lycanthropie, l'un ou l'autre nécessitant une Intensité de 12.

L'inverse de ce sort, Bestow Curse, inflige l'un des effets suivants sur un ennemi avec une durée de 30 minutes par Intensité. La victime a droit à un jet de Volonté opposé pour résister normalement. Lancez 1d100 pour déterminer la nature de la malédiction infligée :

- 01-25 : Toutes les compétences utilisant STR, DEX ou CON sont un degré plus difficiles. Initiative -4, modificateur de dégâts réduit de 2 paliers.
- 26-50 : Toutes les compétences utilisant INT, POW ou CHA sont un degré plus difficiles. Initiative -4.
- 51-75 : Les compétences de combat et les jets de résistance sont 2 degrés plus difficiles.
- 76-00 : Tous les jets de compétence ratés sont traités comme des Fumbles.

#### Remove Fear \(R\)

(Abjuration (Charme))

| | |
| :-- | :-- |
| **Rang :** Cleric 1 | **Temps d'incantation :** 1 action |

Le lanceur de ce sort peut bannir les effets de la peur d'un individu par Intensité, lui accordant un jet supplémentaire pour résister. Remove Fear peut également protéger divinement contre la peur pendant 10 minutes lorsqu'il est lancé sur quelqu'un ne souffrant pas encore de ses effets. Dans les deux cas, le jet de résistance requis du sujet est un degré plus facile. Alors que le clerc pourrait lancer ce sort sur lui-même pour se protéger contre la peur, il ne pourrait pas le lancer pour supprimer les effets continus de la peur qui empêcheraient l'incantation de sorts.

L'inverse de ce sort, Cause Fear, nécessite de toucher la victime au combat. Ceux qui échouent à un jet de résistance de Volonté fuient en terreur au sprint pendant 1d4 rounds. La direction doit être opposée au lanceur du sort. Cause Fear peut être contré par Remove Fear et vice versa.

#### Restoration

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Cleric 3 | **Temps d'incantation :** 3 minutes |
| **Sphère :** Guérison | **Durée :** Permanente |
| **Coût :** 3, +1/Intensité supplémentaire | **Portée :** Toucher |
| **Zone :** 1 cible | **Résistance :** N/A |

Lorsqu'il est lancé, une victime précédemment drainée de sa force vitale en utilisant Energy Drain ou des effets similaires regagne un niveau de fatigue précédemment perdu. À 1 niveau d'Intensité, ce sort ne fonctionne que sur une créature drainée au cours des dernières 24 heures. Chaque Intensité supplémentaire augmente le délai qui peut s'être écoulé de 24 heures supplémentaires. Par exemple, une victime précédemment drainée il y a un peu moins de 48 heures nécessiterait que le sort soit lancé à 2 Intensités pour fonctionner. Plusieurs niveaux de fatigue drainée nécessitent des incantations supplémentaires de Restoration. Indépendamment de la durée et en plus de toute fatigue restaurée, ce sort restaure également toutes les capacités mentales, telles que celles perdues par la magie ou toute forme de folie ou de démence. Restoration peut également être utilisé pour supprimer des années perdues dues au vieillissement artificiel, comme celui provenant de certains sorts. Pour que le sort soit lancé de cette manière, en plus du coût d'incantation normal, le clerc doit dépenser 1 jet EXP pour chaque 1 % de l'espérance de vie typique du bénéficiaire à restaurer (1 an pour un humain). Le sort ne peut pas réduire l'âge actuel du sujet en dessous de celui de son âge réel.

C'est parce que l'âme ou l'esprit du défunt est rarement disposé à retourner chez les vivants une fois qu'il a atteint sa récompense éternelle. Si le lanceur réussit, le sujet a été ressuscité avec succès, tandis qu'un jet raté entraîne que la victime est soit non disposée, soit incapable de retourner.

Resurrection est très épuisant, vieillissant le clerc de 3 % de son espérance de vie typique (3 ans dans le cas d'un lanceur humain). Voir les règles sur le [Vieillissement](0007_Game_System.md?id=aging).

#### Silence

#### Sleep

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Aucune | **Durée :** 5 minutes/Intensité |
| **Coût :** 3, +1/Intensité supplémentaire | **Portée :** 18 m (60 ft) |
| **Zone :** Rayon de 3 m (10 ft) | **Résistance :** Volonté |

Ce sort provoque un sommeil magique chez une créature vivante par niveau d'Intensité dans une zone circulaire de 3 mètres de rayon. La zone d'effet du sort est centrée sur un point dans l'espace ou au sol et la créature la plus proche peut résister en premier, puis la suivante, et ainsi de suite. Là où deux ou plusieurs tombent à égale distance, déterminez au hasard qui est affecté. Chaque créature a droit à un jet pour résister et si l'un réussit, un autre doit essayer jusqu'à ce qu'un total ait été affecté égal à l'Intensité du sort, ou qu'aucune autre créature n'occupe la zone d'effet. Les créatures dans un état d'alerte élevé, ou au combat lorsque le sort est lancé, trouvent le jet pour résister un degré plus facile.

Les créatures grandes (SIZ 21-40) sont moins sensibles à Sleep, le jet de résistance étant Facile, tandis que le jet de résistance pour les créatures énormes (SIZ 41+) est Très Facile. Les plus petites créatures sont toujours affectées avant les plus grandes ; par conséquent, les créatures de SIZ 20 ou moins sont toujours affectées avant celles de SIZ 21 à 40, qui sont elles-mêmes toujours affectées avant celles de SIZ 41+.

Pendant qu'elles dorment, les créatures affectées sont impuissantes et un bruit normal ne les dérangera pas, mais elles peuvent être secouées ou giflées pour se réveiller. Toute attaque, en supposant qu'elle ne soit pas fatale, les réveillera également (bien que l'attaque se produise par surprise). Tenter de réveiller une créature prend 1 round de combat.

#### Slow Poison

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Cleric 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Guérison | **Durée :** 1 heure/Intensité |
| **Coût :** 3, +1/Intensité supplémentaire | **Portée :** Toucher |
| **Zone :** 1 cible | **Résistance :** N/A |

Ce sort permet au lanceur de ralentir les effets des poisons et du venin ; il ne neutralise cependant pas la toxine. Au lieu de cela, les toxines se propageant dans le corps sont ralenties suffisamment pour que des mesures curatives supplémentaires puissent être trouvées. Le temps d'apparition d'une toxine ne commence qu'après l'expiration de la durée du sort.

Par exemple, le venin de cobra possède un temps d'apparition comme suit : agonie après 1d6+4 minutes, et asphyxie après 1d6+6 heures. Une seule Intensité de Slow Poison reporte donc le temps d'apparition d'une heure, après quoi, 1d6+4 minutes plus tard, l'agonie commence normalement.

Si Slow Poison est lancé sur une victime après l'apparition des symptômes, ils cessent jusqu'à l'expiration de la durée du sort, puis continuent normalement.

En dernier recours, si le lanceur peut atteindre un individu "mort" d'empoisonnement dans les 10 minutes, Slow Poison retarde la mort d'une victime d'une heure par Intensité, pendant laquelle la victime reste dans le coma. Si pendant ce temps la victime peut être guérie du poison, elle peut encore vivre et être ranimée par les premiers soins ou la guérison magique.

#### Sun Ray

(Évocation, Transmutation)

| | |
| :-- | :-- |
| **Rang :** Cleric 5 | **Temps d'incantation :** 2 actions |
| **Sphère :** Soleil | **Durée :** 1d4+1 rounds |
| **Coût :** 3/Intensité | **Portée :** 9 m/Intensité |
| **Zone :** Rayon de 1,5 m (5 ft) | **Résistance :** Voir ci-dessous |

Lorsqu'il est lancé, le clerc peut invoquer un faisceau brillant de lumière sacrée en utilisant une action Cast Magic à tout moment pendant la durée du sort. Le faisceau est de la lumière du soleil naturelle et a un rayon d'un mètre cinquante. Ceux dans la zone d'effet doivent Esquiver pour tenter de protéger leurs yeux ou devenir aveuglés pendant 1d3 minutes. S'ils échouent à leur jet de résistance, le Sun Ray aveugle les créatures utilisant la vision nocturne pendant 2d4 minutes et elles perdent leur capacité de vision nocturne pendant 1d4+1 minutes jusqu'à 6 mètres au-delà de la zone d'effet. Les créatures pour qui la lumière du soleil naturelle est nocive à la vision sont aveuglées de façon permanente sur un jet de résistance raté ou aveuglées pendant 2d6 rounds si le jet est réussi.

Les morts-vivants dans la zone d'effet subissent 2d6 points de dégâts à chaque zone corporelle. L'armure, naturelle ou autre, n'offre aucune protection, mais les points d'armure magiques réduisent les dégâts normalement. Ceux à moins d'un mètre cinquante du bord de la zone d'effet peuvent Esquiver pour ne subir aucun dégât. Les morts-vivants à moins de 6 mètres de la zone d'effet subissent toujours 1d6+1 points de dégâts mais ne subissent aucun dégât sur un jet de résistance réussi. Les morts-vivants spécifiquement blessés par la lumière du soleil, comme les vampires, sont détruits s'ils échouent à leur esquive. Les créatures fongiques ainsi que toutes les formes de champignons souterrains subissent les mêmes effets que les morts-vivants mais ne peuvent pas effectuer de jet de résistance.
