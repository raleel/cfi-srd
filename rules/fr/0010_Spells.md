#### Expertise

(Divination)

| | |
| :-- | :-- |
| **Rang :** Mage 0 | **Temps d'incantation :** 1 tour |
| **Sphère :** Aucune | **Durée :** Instantanée |
| **Coût :** 1 | **Portée :** Contact |
| **Zone :** 1 objet | **Résistance :** Aucune |

L'Expertise permet d'évaluer immédiatement la qualité de marchandises physiques d'un encombrement combiné en 'Objets' ou une TAIL égale à la POU du lanceur. Le sort détermine si des objets d'aspect identique sont de même qualité ou similaire, ou si l'un ou plusieurs sont défectueux ou de qualité supérieure. Le sort ne fonctionne pas sur les choses organiques, uniquement sur les objets inanimés. Il ne détermine pas non plus quels défauts ou améliorations sont présents ; simplement qu'ils existent. Il est inutile pour l'identification ou la détection de magie.

#### Armure

(Conjuration)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 round |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3 + 1/Intensité | **Portée :** Contact |
| **Zone :** 1 cible | **Résistance :** Aucune |

Lorsqu'il est lancé, le sujet est doté d'un champ invisible de force magique équivalente à une armure d'écailles, accordant 4 Points d'Armure à chaque Emplacement de Toucher. Il n'a aucun effet s'il est lancé sur quelqu'un portant déjà une armure. Il supplante cependant l'armure naturelle pour sa Durée, en supposant qu'il offre une meilleure protection. S'il est lancé sur une créature possédant plus de 4 points d'armure naturelle, il augmentera plutôt les Points d'Armure de 1 à tous les emplacements. Cette protection magique n'entrave pas le mouvement ou le lancement de sorts. Le sort persistera jusqu'à ce qu'il soit dissipé par magie, ou que le lanceur subisse 8 points de dégâts d'une seule attaque, +1 par niveau d'Intensité supplémentaire (voir le tableau ci-dessous). Bien entendu, le lanceur peut choisir d'abandonner le sort à tout moment s'il le souhaite et doit le faire pour dormir.

| Intensité | Coût | Effet variable |
| :-: | :-: | :-- |
| 1 | 3 | 4 Points d'Armure ; maintenu jusqu'à 8 dégâts en 1 attaque |
| 2 | 4 | 4 Points d'Armure ; maintenu jusqu'à 9 dégâts en 1 attaque |
| 3 | 5 | 4 Points d'Armure ; maintenu jusqu'à 10 dégâts en 1 attaque |
| 4 | 6 | 4 Points d'Armure ; maintenu jusqu'à 11 dégâts en 1 attaque |
| +1 | +1 | Progression continue |

#### Sort astral

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Clerc 5, Mage 5 | **Temps d'incantation :** 2 actions |
| **Sphère :** Astral | **Durée :** Voir ci-dessous |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** Contact |
| **Zone :** Voir ci-dessous | **Résistance :** N/A |

Ce sort permet au lanceur et jusqu'à cinq autres personnes (une par niveau d'Intensité supplémentaire) d'entrer dans le Plan Astral. Tous doivent se toucher et former un cercle pendant le lancement. Les corps des voyageurs restent dans le plan d'origine et ils n'apportent généralement ni vêtements ni équipement, sauf ce qui rayonne lui-même d'une aura magique ; ces objets se transforment en équivalents astraux. La durée dure jusqu'à ce que le lanceur souhaite qu'elle cesse. Cependant, il est possible qu'elle soit interrompue prématurément par une force extérieure telle que Dissipation de la magie. Tuer le corps physique du lanceur met également fin au sort plus tôt, bien que cela ait l'effet secondaire malheureux de bloquer tous les voyageurs accompagnant le lanceur.

#### Augure

(Divination)

| | |
| :-- | :-- |
| **Rang :** Clerc 2 | **Temps d'incantation :** 2 minutes |
| **Sphère :** Divination | **Durée :** Instantanée |
| **Coût :** 3/Intensité | **Portée :** 18 m ; |
| **Zone :** Lanceur | **Résistance :** N/A |

Ce sort permet au lanceur de déterminer si une action spécifique entreprise dans les 30 prochaines minutes sera bénéfique ou néfaste pour le bien-être d'un individu et/ou d'un groupe. Un point focal est requis pour discerner les présages, les plus courants étant les griffes ou les petits os d'un dragon, une perle, ou de l'or pur d'une valeur d'au moins 100 PO, qui a été broyé ou fondu. Le sort a une Intensité maximale de 4. Ce jet doit être effectué par le Maître de Jeu, car le lanceur ne devrait jamais savoir sans l'ombre d'un doute si les résultats ont été interprétés correctement.

| Intensité | Coût | Effet variable |
| :-: | :-: | :-- |
| 1 | 3 | Jet de compétence Canaliser Formidable |
| 2 | 6 | Jet de compétence Canaliser Difficile |
| 3 | 9 | Jet de compétence Canaliser Standard |
| 4 | 12 | Jet de compétence Canaliser Facile |

Si le jet de divination réussit, il donne l'un des résultats suivants :

| Augure | Implication | 
| :-: | :-- |
| Oui | L'action sera bénéfique |
| Non | L'action sera néfaste |
| Oui et Non | L'action sera à la fois bénéfique et néfaste |
| Rien | L'action ne sera ni bénéfique ni néfaste |

Un Fumble devrait conduire le Maître de Jeu à dire le contraire de la réalité.

#### Abasourdir

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Clerc 0, Mage 0 | **Temps d'incantation :** 1 tour |
| **Sphère :** Charme | **Durée :** 30 minutes |
| **Coût :** 1 | **Portée :** 18 m |
| **Zone :** 1 cible | **Résistance :** Volonté |

Abasourdir provoque la confusion dans l'esprit d'une cible corporelle. Le sujet du sort a du mal à réfléchir, oubliant où il est, ce qu'il fait et pourquoi – retombant souvent dans des lignes de pensée dissociées. Les cibles abasourdies peuvent toujours agir en légitime défense mais ne peuvent engager aucune activité constructive avant la fin du sort. Toute attaque ou action menaçante rompt instantanément le sort, qu'elle soit dirigée spécifiquement vers la cible abasourdie ou non.

#### Barrière de lames

(Évocation)

| | |
| :-- | :-- |
| **Rang :** Clerc 4 | **Temps d'incantation :** 2 actions |
| **Sphère :** Gardien, Création | **Durée :** 3 rounds/Intensité |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** 30 m |
| **Zone :** Rayon de 1,5 à 9 m | **Résistance :** Voir ci-dessous |

Ce sort crée une barrière d'épées, de poignards et de couteaux tranchants tournoyants qui fouettent et tranchent autour d'un point fixe et causent 1d8 points de dégâts à 1d4+2 emplacements de toucher aléatoires de *quiconque* traverse la zone d'effet. L'armure n'offre que la moitié de sa protection normale. Les Points d'Armure magiques réduisent les dégâts normalement. Parce que les armes tourbillonnent à une vitesse fulgurante et sont serrées, il est impossible de les parer ou de les esquiver. On peut utiliser un bouclier pour bloquer passivement les emplacements de toucher normalement. Dans ce cas, rappelez-vous de comparer les dégâts obtenus à l'armure et aux Points de Vie du bouclier.

Le sort peut être lancé défensivement pour protéger le clerc ou un ou plusieurs alliés, ou offensivement pour piéger des ennemis. Cependant, les ennemis encerclés à moins d'un mètre cinquante du bord de la barrière alors qu'elle se forme peuvent faire un jet d'Esquive pour s'échapper. Indépendamment du succès, l'adversaire finit à terre, juste en dehors de la zone d'effet. Un jet réussi entraîne zéro dégât ; sinon, ils subissent le plein effet.

#### Bénédiction (R)

(Conjuration)

| | |
| :-- | :-- |
| **Rang :** Clerc 1 | **Temps d'incantation :** 1 round |
| **Sphère :** Tout | **Durée :** 5 minutes |
| **Coût :** 1 | **Portée :** 55 m |
| **Zone :** Rayon de 7,5 m | **Résistance :** Volonté |

Lorsqu'il est lancé, le clerc bénit un groupe d'alliés dans la zone d'effet. Ceux affectés rayonnent de l'alignement du lanceur, soit Bon, soit Mauvais. Il n'y a pas de bénédictions de Neutralité. Tous les alliés dans le rayon du sort reçoivent un bonus de +5 % à tous les jets de compétence et de Résistance. De plus, leurs armes causent +1d3 dégâts aux morts-vivants intelligents ainsi qu'aux créatures des plans extérieurs ayant des alignements opposés à celui du lanceur, comme les démons, les diables ou les anges. Notez que si les morts-vivants animés tels que les squelettes et les zombies ne sont pas intrinsèquement mauvais, ils sont généralement animés par une magie maléfique et sont donc sujets à ces dégâts.

L'inverse de ce sort, Malédiction, permet au clerc de maudire les ennemis, faisant subir aux compétences notées l'inverse des avantages indiqués ci-dessus. Les dégâts d'une arme maudite sont calculés comme une pénalité, et ces dégâts ne peuvent pas entraîner moins de 1 point.

#### Mains brûlantes

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Aucune | **Durée :** Instantanée |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** 0 |
| **Zone :** Cône de 120 degrés, 1,5 m de long | **Résistance :** Esquive |

Ce sort fait jaillir des flammes des mains du lanceur dans un arc de 120 degrés. Si vous utilisez des figurines au combat, Mains brûlantes endommagera chaque cible occupant 1 des cases devant le lanceur. Lancer Mains brûlantes à des niveaux d'Intensité plus élevés nécessite un mage de rang plus élevé. Ces dégâts engloutissent toutes les cibles dans la zone avec des dégâts basés sur l'Intensité du sort, jusqu'à une Intensité maximale de 9, comme suit. Un jet d'Esquive réussi, se jetant à terre, permet à la victime de ne subir aucun dégât. Quelqu'un avec l'aptitude Artiste de l'Esquive a la possibilité d'Esquiver sans se mettre à terre.

| Intensité | Coût | Rang min | Effet variable |
| :-: | :-: | :-: | :-- |
| 1 | 3 | 1 | 1d3+1 points de dégâts sur tous les emplacements de toucher |
| 3 | 4 | 1 | 1d3+2 points de dégâts sur tous les emplacements de toucher |
| 5 | 5 | 1 | 1d3+3 points de dégâts sur tous les emplacements de toucher |
| 7 | 6 | 2 | 1d3+4 points de dégâts sur tous les emplacements de toucher |
| 9 | 7 | 3 | 1d3+5 points de dégâts sur tous les emplacements de toucher |

L'armure portée ne protège pas, mais les Points d'Armure magiques ou l'armure naturelle d'une créature réduisent les dégâts normalement. Ce sort puissant est équilibré par sa portée remarquablement courte, ce qui signifie que pour le lancer, l'utilisateur de magie doit être suffisamment proche pour se trouver dans une position très désavantageuse.

Parce que les créatures plus grandes sont généralement plus grandes que la zone d'effet du sort, elles auront tendance à avoir moins d'emplacements de toucher affectés. Celles de TAIL 21 à 30 prennent les dégâts à la tête, à la poitrine, à l'abdomen et aux bras, tandis que celles de TAIL 31+ prendront les dégâts à l'abdomen et aux jambes. Les Maîtres de Jeu devraient ajuster ces emplacements en fonction de la forme et de la position de la cible par rapport au lanceur. #### Commandement

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Clerc 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Charme | **Durée :** 1 minute |
| **Coût :** 3 | **Portée :** 30 m |
| **Zone :** 1 cible | **Résistance :** Volonté |

Lorsqu'il est lancé, le clerc peut prononcer un commandement d'un seul mot à une créature vivante de TAIL 1-20, et au tour suivant du sujet, le commandement sera suivi à la lettre s'il échoue à résister. Cela amène essentiellement la victime à manquer le tour suivant pour effectuer l'action commandée et gaspille un Point d'Action en l'accomplissant. Si la victime ne possède plus de Points d'Action, l'action commandée sera effectuée lors de son premier tour du round suivant. Le commandement lui-même ne peut causer aucune blessure réelle à la cible ; cependant, des blessures peuvent survenir comme effet secondaire de l'ordre.

Par exemple, un ordre de mourir entraînerait la victime à s'effondrer dans un état comateux semblable à la mort pendant 1 round sans causer de blessure réelle ; cependant, un ordre de tomber donné à une créature escaladant une falaise de 30 mètres de haut pourrait être plus que mortel.

Le sujet du commandement doit être capable de comprendre la langue parlée par le lanceur et a droit à un test de Volonté pour résister.

**Exemples de commandements**

- **Ramper :** Le sujet se met à terre et commence à ramper.
- **Mourir :** Le sujet tombe à terre dans un état comateux semblable à la mort.
- **Tomber :** Le sujet tombe à terre.
- **Maladroit :** Le sujet rate une action physique sur le point d'être effectuée.
- **Dormir :** Le sujet s'endort.
- **Fuir :** Le sujet se retourne et fuit le lanceur.
- **Voler :** Le sujet agite les bras et court en cercle.
- **Avancer :** Le sujet commence à marcher dans la direction où il faisait face.
- **Halte :** Le sujet s'arrête immédiatement et reste sur place.
- **Partir :** Le sujet se retourne et part par où il est entré.
- **Repos :** Le sujet s'assoit et reprend son souffle.
- **Courir :** Le sujet commence à courir.
- **Crier :** Le sujet hurle.
- **Couler :** Le sujet arrête de nager.
- **Capituler :** Le sujet lâche ses armes et cesse les hostilités.

Dissipation de la magie commence avec la magie la plus puissante dans la zone d'effet. S'il échoue à éliminer un sort (parce que la Magnitude du sort est trop élevée), alors le sort se termine et aucune autre magie ne peut être éliminée.

Dissipation de la magie peut être utilisé défensivement pour neutraliser les sorts offensifs entrants, en utilisant l'action réactive Contre-sort.

#### Enchantement d'objet

(Enchantement)

| | |
| :-- | :-- |
| **Rang :** Mage 4 | **Temps d'incantation :** Voir ci-dessous |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3 + Voir ci-dessous | **Portée :** Contact |
| **Zone :** 1 objet | **Résistance :** N/A |

Le lancement de ce sort prépare un objet à l'Enchantement. L'objet doit être en bon état et d'une finesse de fabrication exceptionnelle. Un coût supplémentaire d'au moins 100 PO est requis pour couvrir le coût de l'outillage, de la sculpture, de la broderie, de la joaillerie, de la gravure, etc. Enfin, le processus d'Enchantement nécessite un laboratoire ou un atelier.

Pendant le lancement du sort, l'utilisateur de magie doit toucher l'objet pendant toute la durée du temps d'incantation de 1d8+2 jours. Cela prend en compte les périodes de repos et de sommeil, pendant lesquelles l'objet doit rester à portée de main du lanceur. À aucun moment pendant le lancement, l'utilisateur de magie ne peut lancer un autre sort ou effectuer une autre forme de magie. Briser l'une de ces strictures entraînera automatiquement l'échec du sort.

Une fois lancé avec succès, l'objet est prêt pour l'étape finale, le lanceur plaçant le sort souhaité à l'intérieur. Pour ce faire, il doit avoir le sort en mémoire ou sur un parchemin et le lancer dans l'objet dans les 24 heures, sinon tout le processus devra être recommencé depuis le début. Une fois le lancement du sort sélectionné commencé, le processus peut dépasser les 24 heures mentionnées ci-dessus. Imprégner l'objet du sort sélectionné coûte le nombre normal de Points de Magie pour l'Intensité souhaitée et prend 1d12 heures par rang de sort. Tout au long du processus d'imprégnation, le lanceur doit rester en contact avec l'objet ou rester à portée de main pendant les périodes de repos, comme ci-dessus, et un jet d'Incantation arcanique est requis à la fin de la période d'incantation pour réussir à imprégner le sort. Les degrés de succès normaux de Lancement de sort sont suivis, cependant, en ce qui concerne un résultat d'échec, le sort ne peut être forcé. Des sorts successifs peuvent être imprégnés dans l'objet, à condition que le processus de lancement soit commencé dans les 24 heures suivant l'achèvement du sort précédent. Cela s'applique même dans le cas d'un sort précédemment échoué. Chaque sort successif nécessite le coût de lancement normal.

Lors de l'utilisation de l'objet, chaque sort contenu peut être lancé une seule fois ; cependant, plusieurs versions du même sort peuvent être imprégnées suivant la procédure ci-dessus. Il est également possible d'imprégner un seul sort, en le faisant suivre d'un lancement du sort de rang 4 Permanence. Dans ce cas, le sort peut être lancé aussi souvent que souhaité, suivant les restrictions énoncées dans la description du sort Permanence.

Il n'est pas possible d'imprégner d'autres effets magiques dans un objet qui ne se conforment pas à un sort spécifique, et de nombreux objets magiques d'autrefois ne peuvent tout simplement pas être recréés de nos jours.

#### Bouclier de feu

(Évocation)

| | |
| :-- | :-- |
| **Rang :** Mage 3 | **Temps d'incantation :** 2 actions |
| **Sphère :** Aucune | **Durée :** 2 minutes / Intensité |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** 0 |
| **Zone :** Lanceur | **Résistance :** N/A |

Ce sort crée un bouclier de flammes vaporeuses qui immole le lanceur mais ne cause aucun dégât en soi. Au lieu de cela, les flammes protègent le destinataire du feu ou du froid, selon laquelle de deux variantes est en mémoire : Bouclier de frisson, qui crée des flammes bleues ou vertes et protège contre les dégâts basés sur la chaleur et le feu, ou Bouclier de chaleur, qui crée des flammes violettes ou bleues et protège contre les dégâts basés sur le froid et la glace. La couleur des flammes devrait être déterminée au hasard avec 50 % de chances pour l'une ou l'autre, car le fait que les deux types puissent émettre des flammes bleues crée une incertitude de la part de tout attaquant. La décision quant à laquelle mémoriser est prise lors de la préparation des sorts, et les deux peuvent être mémorisées si désiré. Ces flammes ne dégagent aucune chaleur et ne projettent de la lumière qu'à la moitié de la luminosité d'une torche. Les spécificités de chaque variante sont détaillées ci-dessous.

- **Bouclier de frisson :** Ces flammes sont fraîches au toucher et réduisent tout dégât basé sur le feu ou la chaleur à la moitié du total. Un jet de Résistance réussi annulera tous les dégâts. Le jet de Résistance est un cran plus facile et, dans le cas de l'Esquive, ne rendra pas le défenseur à terre.
- **Bouclier de chaleur :** Ces flammes sont chaudes au toucher et réduisent tout dégât basé sur le froid à la moitié du total. Un jet de Résistance réussi annulera tous les dégâts. Le jet de Résistance est un cran plus facile et, dans le cas de l'Esquive, ne rendra pas le défenseur à terre.

Les attaques de mêlée contre le destinataire de l'une ou l'autre variante, qu'elles soient armées ou non armées, infligent des dégâts normaux à moins d'utiliser l'un des éléments contre lesquels il est protégé. Dans ce cas, le lanceur est protégé de la partie élémentaire de l'attaque, et l'attaquant reçoit des dégâts égaux à ceux infligés. L'armure portée sur l'attaquant n'offre aucune protection, mais les Points d'Armure magiques ou l'armure naturelle d'une créature réduisent les dégâts normalement. Les créatures dotées d'une Résistance magique innée peuvent dissiper Bouclier de feu sur un jet de Volonté réussi lorsque le destinataire est frappé pour la première fois. Si le jet de Résistance magique échoue, l'adversaire ne peut pas annuler Bouclier de feu plus tard.

#### Chair en pierre (R)

(Transmutation)

| | |

Lorsqu'il est lancé, une victime à portée a droit à un jet de Résistance de Volonté. En cas d'échec, elle et tous ses biens transportés et portés sont complètement transformés en pierre solide. Aucun jet supplémentaire pour toucher n'est nécessaire. Ni l'armure portée ni l'armure naturelle n'offrent de protection, mais les Points d'Armure magiques réduisent les dégâts normalement et bloquent entièrement les affections infligées. Chaque Intensité supplémentaire affecte un autre emplacement de toucher contigu au premier, avec des effets déterminés par le jet de Résistance initial. Aucune version de ce sort n'a d'effet sur les morts-vivants, les créatures uniquement blessées par le fer, l'argent ou des armes magiques, ou les êtres non corporels.

#### Projectile magique

(Évocation)

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Aucune | **Durée :** Instantanée |
| **Coût :** 1 / Intensité | **Portée :** 30 m / Intensité |
| **Zone :** 1-5 cibles | **Résistance :** Voir ci-dessous |

Lorsqu'il est lancé, un ou plusieurs projectiles d'énergie magique jaillissent du bout des doigts de l'utilisateur de magie et frappent une cible. Le nombre maximum de projectiles pouvant être générés est basé sur le niveau de compétence d'Incantation arcanique du lanceur, un deuxième projectile étant généré à 60 % de compétence, un troisième à 70 %, un quatrième à 80 %, et un cinquième et dernier projectile à 90 %. Pour générer ces projectiles, le sort doit être lancé à une Intensité égale au nombre de projectiles désiré. Par exemple, à moins de 60 %, un utilisateur de magie qui lance Projectile magique à 3 Intensité atteindra la portée plus longue, cependant seul un seul projectile sera généré. Un utilisateur de magie avec un niveau de compétence de 70 % pourrait lancer le sort à la même Intensité de 3 et atteindre la même portée mais être capable de générer 3 projectiles. Ce sort a une Intensité maximale de 5. Voir le tableau ci-dessous.

Un Projectile magique frappera infailliblement, même si la cible est en combat de mêlée ou a une couverture partielle. Ces projectiles ne peuvent pas être esquivés ; cependant, un adversaire en couverture totale ne peut pas être ciblé par ce sort. Le sort Bouclier déviera automatiquement les Projectiles magiques en supposant que la cible est consciente et/ou face au lanceur. Les Projectiles magiques font 1d6+1 points de dégâts et l'armure portée ne protège pas, mais l'armure naturelle d'une créature ou les Points d'Armure magiques réduisent les dégâts normalement. Les Projectiles magiques ne causent aucun dégât aux objets inanimés tels que les portes, serrures, etc.

Lors du tir de projectiles multiples, le lanceur peut les faire frapper une seule créature, ou cibler plusieurs créatures. Chaque Projectile magique frappera un emplacement de toucher aléatoire - des emplacements de toucher spécifiques ne peuvent pas être ciblés. Le lanceur doit désigner des cibles individuelles pour chaque projectile avant de lancer les dégâts.

#### Bouche magique

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 2 | **Temps d'incantation :** 1 minute |
| **Sphère :** Aucune | **Durée :** Voir ci-dessous |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** 9 m |
| **Zone :** 1 objet | **Résistance :** N/A |

Ce sort crée une bouche sur un objet, qui apparaît magiquement lorsqu'elle est déclenchée par un événement spécifique ou un moment désigné par l'utilisateur de magie lors du lancement du sort. Cette bouche prononcera alors n'importe quelle phrase prédéfinie choisie par le lanceur au moment du lancement. Cette phrase doit consister en pas plus de 25 mots et est prononcée par la bouche à un rythme d'environ 1 mot par seconde. La bouche ne peut pas prononcer de mots de pouvoir ou lancer de sorts.

Ce sort peut être lancé sur tout objet normalement inanimé, d'un pilier ou d'un arbre, à un mur de pierre ou un coffre ; cependant, il est particulièrement efficace lorsqu'il est lancé sur une statue, car la statue elle-même semblerait parler. Il ne peut être lancé sur aucune créature vivante ayant une forme d'intelligence ou d'instinct. Cela s'applique à ceux qui étaient autrefois vivants. Lors du lancement de ce sort, l'utilisateur de magie détermine la situation qui déclenchera l'enchantement. Il peut être conçu pour se déclencher via n'importe quoi, d'un mot prononcé à la création de n'importe quel bruit. Il pourrait être aussi général que "quand la prochaine personne entre dans cette pièce..." ou aussi spécifique que, "quand une clerc femelle de Sedona arrive à moins de 3 mètres de la statue au bout du couloir un samedi...". L'effet déclencheur ne peut pas être quelque chose qui ne peut pas être discerné de manière non magique, comme une créature invisible, l'alignement d'une créature, sa compétence, sa classe, etc. Cependant, il pourrait désigner les vêtements portés. La distance maximale à laquelle le sort peut être déclenché est de 7,5 mètres par Intensité.

La durée de ce sort est permanente jusqu'à ce que l'enchantement soit activé, après quoi le sort se termine.

#### Polymorphisme autre

(Transmutation)

| | |
| :-- | :-- |
| **Rang :** Mage 3 | **Temps d'incantation :** 2 actions |
| **Sphère :** Aucune | **Durée :** Permanente |
| **Coût :** 3, +1/Intensité supplémentaire (+1 EXP) | **Portée :** 4,5 m / Intensité |
| **Zone :** 1 cible | **Résistance :** Volonté |

Le lanceur peut modifier la forme d'une créature ciblée corporelle en celle d'une autre, chaque point d'Intensité modifiant la TAIL jusqu'à 5 points. Par conséquent, transformer un orc de TAIL 16 en un lapin de TAIL 1 nécessiterait 3 niveaux d'Intensité (15 points de différence de TAIL). Le sujet de ce sort a droit à un jet de Volonté pour résister. Les créatures de grande taille (TAIL 21-40) sont moins sensibles à être polymorphées, leur jet de Résistance étant Facile, tandis que le jet de résistance pour les créatures immenses (TAIL 41+) est Très Facile.

Le processus de transformation complet prend un round complet et peut être assez stressant pour la créature en question, nécessitant un deuxième jet de Volonté pour conserver sa personnalité d'origine, un échec étourdissant le sujet pendant 1d10 minutes, et un Fumble entraînant la mort par choc mental. Chaque doublement ou réduction de moitié de la TAIL d'origine de la créature rend le jet de Volonté pour conserver sa personnalité un cran plus difficile, tout comme un changement complet d'environnement, comme transformer une personne en poisson. Un jet réussi permet à la victime de conserver sa INT et CHA ainsi que toute compétence nécessitant ces caractéristiques.

La transformation accorde au destinataire la forme de respiration de la créature supposée, si elle est différente de la normale ; toute attaque naturelle ; et tous les modes de mouvement mondains. Elle n'accorde aucune aptitude surélevée ou magique possédée par la créature. Par exemple, une créature qui a été polymorphée en dragon ne gagnera pas l'attaque de souffle de la créature ou ses aptitudes semblables à des sorts, mais gagnera la capacité de voler, sa peau dure, sa morsure mortelle, ses attaques de griffes, etc. De plus, la victime gagne les compétences physiques de la nouvelle forme telles qu'Athlétisme, Brawn, Vol, Nage, ainsi que ses Points de Vie et son Modificateur de dégâts. En supposant que l'individu transformé ait conservé sa INT, il perd toujours la capacité de parler, à moins que la nouvelle forme ne possède la capacité d'articuler des mots. Ceux qui étaient capables de lancer des sorts sous leur forme précédente seraient toujours capables de lancer sous la nouvelle forme, en supposant qu'ils possèdent toujours la capacité de produire les composants verbaux et somatiques. Dans le cas d'un changement drastique, tel que passer de bipède à quadrupède, ou d'un animal terrestre à une créature marine, par exemple, le Maître de Jeu devrait se sentir libre de pénaliser d'au moins un cran de difficulté l'utilisation de toute compétence qui prendrait du temps à apprendre tout en s'ajustant à la nouvelle forme jusqu'à ce qu'il y ait eu suffisamment de temps pour pratiquer. C'est particulièrement vrai des compétences physiques telles qu'Athlétisme, Non armé, Nage, Vol, Compétences de combat, etc.

Le jet de Volonté pour conserver sa personnalité est requis chaque jour où le sujet reste transformé jusqu'à échec, ce qui fait que la personne succombe finalement à la mentalité de la nouvelle forme, avec une INT changeant en INS dans le cas d'une créature non sapiente. Toutes les aptitudes spéciales et magiques possédées par la nouvelle forme qui n'étaient pas acquises précédemment, telles que les attaques de regard, les armes de souffle, etc., sont maintenant disponibles pour la créature car la transformation est complète. Les personnages qui perdent leur identité de cette façon deviennent des personnages non-joueurs sous le contrôle du Maître de Jeu.

Avant de succomber mentalement à la transformation, la créature polymorphée est sensible à Dissipation de la magie comme normal, sans aucun jet pour résister requis, car ce serait le désir subconscient de revenir à la normale. La transformation nécessite un autre jet de Volonté pour résister à la tension, un échec étourdissant le sujet pendant 1d10 minutes, et un Fumble entraînant la mort par choc mental.

Si la victime avait précédemment succombé à la nouvelle forme, Dissipation de la magie peut toujours être utilisé ; cependant, la victime tentera de résister au retour à la forme naturelle avec un jet de Volonté. Échouer à ce jet signifie que la victime se transforme en forme naturelle, ce qui, bien sûr, nécessite un autre jet de Volonté pour résister au choc mental de la transformation. Une fois perdue, l'identité naturelle d'une victime n'est plus atteignable, au lieu de cela, la victime suppose que la forme étrange et extraterrestre n'est pas naturelle et aspire à être retournée à sa forme 'normale' précédente. _Par exemple, un orc qui a été polymorphé en lapin et a assumé l'identité de la créature croirait qu'il est maintenant un lapin qui a été assez grossièrement transformé en orc._ Seul un Souhait, ou une autre magie similaire, a une chance de restaurer l'identité de la victime une fois qu'elle a été perdue.

Tout équipement porté et transporté se fond magiquement dans la nouvelle forme ; cependant, dans certains cas, le Maître de Jeu peut autoriser les objets magiques qui pourraient encore être utilisés sous la nouvelle forme de la créature à rester, comme un anneau magique ou des bottes. Notez que cela nécessite que la nouvelle TAIL de la créature ne soit pas très différente de l'originale. Il y a 1 % de chance par POU pour chaque objet magique porté de nature non offensive, sous réserve de l'approbation du Maître de Jeu, de transférer ses effets à la nouvelle forme de la créature. Une créature avec un anneau de protection +1 par exemple, pourrait gagner un bonus de +1 à ses Points d'Armure naturels. Les créatures ayant la capacité naturelle de changer de forme, telles que les doppelgängers et les lycanthropes, seront transformées normalement, mais peuvent assumer leur forme normale après 1 round. S'il est tué, une créature polymorphée revient à sa forme naturelle, même si elle a déjà perdu toute trace d'identité.

Le lanceur peut assumer la forme de toute autre créature corporelle, d'aussi petit que TAIL 1 jusqu'à TAIL 40. S'il est transformé en flyer et tenu de faire un jet de compétence Vol, Athlétisme ou Acrobaties peuvent être substitués à deux crans de difficulté. Cependant, un personnage qui utilise cette forme fréquemment peut choisir de développer la compétence Vol normalement à une valeur de base de FOR+DEX.

#### Rappel à la vie (R)

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Clerc 3 | **Temps d'incantation :** 1 minute |
| **Sphère :** Nécromancie | **Durée :** Permanente |
| **Coût :** 3 + 1/Intensité supplémentaire, +1 EXP | **Portée :** 30 m |
| **Zone :** 1 cible | **Résistance :** N/A (Volonté) |

Ce sort peut être lancé sur le cadavre d'une créature morte depuis moins de 24 heures par niveau d'Intensité. Si l'alignement du sujet était autre chose que mauvais, il peut résister au sort avec un jet opposé de Volonté et, en cas de succès, annuler les effets du sort. C'est parce que l'âme ou l'esprit du défunt est rarement disposé à revenir parmi les vivants une fois qu'il a atteint sa récompense éternelle. Le Maître de Jeu peut décider d'annuler le jet si le destinataire a des affaires inachevées, ne peut être séparé de son véritable amour, ou a une autre raison héroïque de vivre.

Dans le cas des âmes mauvaises, qui reviendraient volontiers sur le plan matériel au lieu de souffrir de damnation éternelle, ce n'est pas la volonté du défunt qui résiste, mais celle du démon, diable, etc., chargé de sa punition, son tourmenteur. Dans ce cas, le lanceur doit surmonter la Volonté du tourmenteur. Si elle est inconnue, supposez qu'elle est au moins 20 points supérieure à celle du défunt pour représenter que plus la volonté de l'âme est forte, plus puissant est l'être placé en charge de sa damnation. Si le lanceur réussit, il a renvoyé avec succès l'esprit dans le corps, tandis qu'un jet raté signifie que la victime est soit non disposée, soit incapable de revenir.

Si le lancement est réussi, le sujet est ramené à la vie avec tous ses Points de Vie, bien que les membres sectionnés restent perdus. Cela signifie qu'une victime décapitée ou coupée en deux ne peut être rappelée à la vie tant que sa tête ou son torse n'est pas d'abord rattaché. Cela peut être fait avant le lancement de Rappel à la vie en rattachant physiquement l'emplacement sectionné, ce qui nécessite une trousse de soins et une application réussie de la compétence Guérison, et laisse généralement une cicatrice évidente. D'autres maladies, telles que le poison ou la maladie, doivent être prises en charge avant ou après le lancement de Rappel à la vie, sinon les résultats ne sont que temporaires. Enfin, Rappel à la vie n'a aucun effet sur une créature qui a atteint la fin de sa durée de vie naturelle et est morte de vieillesse.

L'acte d'être ramené d'entre les morts est très éprouvant pour le sujet, qui est réduit à un niveau de Fatigue d'Incapacitation pendant une période de 24 heures pour chaque jour passé mort. Le lancement de Guérison de la fatigue n'a aucun effet sur le patient pendant ce temps de convalescence. Après cela, le personnage récupère normalement de la fatigue, et sans restriction.

Lorsqu'il est inversé, Tuer un vivant peut être utilisé pour tuer une victime désignée par le clerc au moment du lancement. Cette victime a droit à un jet de Volonté pour résister, modifié par le rang ou la TAIL de la cible, selon celui qui donne le résultat le plus bénéfique pour la cible, comme détaillé dans le tableau suivant.

| Rang de la cible | TAIL de la cible | Modificateur de Volonté |
| :-: | :-: | :-: |
| 0-1* | 1-20 | Difficile |
| 2 | 21-40 | Standard |
| 3 | 41-60 | Facile |
| 4-5 | 61+ | Très facile |

_* Cette catégorie inclut les personnages qui ne possèdent pas de Classe._

Si le jet de Résistance est infructueux, la victime est tuée sur le coup. Un jet réussi est traité selon les effets de Transmission des blessures graves. L'armure n'offre aucune protection contre ces dégâts.

#### Sommeil

(Enchantement (Charme))

| | |
| :-- | :-- |
| **Rang :** Mage 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Aucune | **Durée :** 5 minutes / Intensité |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** 18 m |
| **Zone :** Rayon de 3 m | **Résistance :** Volonté |

Ce sort fait tomber un sommeil magique sur une créature vivante par niveau d'Intensité dans une zone circulaire de 3 mètres de rayon. La zone d'effet du sort est centrée sur un point dans l'espace ou sur le sol et la créature la plus proche peut résister en premier, puis la suivante la plus proche, et ainsi de suite. Là où deux créatures ou plus sont à égale distance, déterminez au hasard qui est affecté. Chaque créature a droit à un jet pour résister et si l'un réussit, un autre doit essayer jusqu'à ce qu'un total ait été affecté égal à l'Intensité du sort, ou qu'aucune créature n'occupe plus la zone d'effet. Les créatures dans un état d'alerte élevé, ou en combat lorsque le sort est lancé, trouvent le jet pour résister un cran plus facile.

Les créatures plus petites sont toujours affectées avant les plus grandes ; par conséquent, les créatures de TAIL 20 ou moins sont toujours affectées avant celles de TAIL 21 à 40, qui sont elles-mêmes toujours affectées avant celles de TAIL 41+.

Toute attaque, en supposant qu'elle ne soit pas fatale, les réveillera également (bien que l'attaque se produise en Surprise). Tenter de réveiller une créature prend 1 round de combat.

#### Slow poison

(Nécromancie)

| | |
| :-- | :-- |
| **Rang :** Clerc 1 | **Temps d'incantation :** 1 action |
| **Sphère :** Guérison | **Durée :** 1 heure / Intensité |
| **Coût :** 3 + 1/Intensité supplémentaire | **Portée :** Contact |
| **Zone :** 1 cible | **Résistance :** N/A |

Ce sort permet au lanceur de ralentir les effets des poisons et venins ; il ne neutralise cependant pas la toxine. Au lieu de cela, les toxines se propageant dans le corps sont suffisamment ralenties pour qu'on puisse trouver des mesures curatives supplémentaires. Le temps d'apparition d'une toxine ne commence qu'après l'expiration de la durée du sort.

Par exemple, le venin de cobra possède un temps d'apparition comme suit : agonie après 1d6+4 minutes, et asphyxie après 1d6+6 heures. Une seule Intensité de Slow poison reporte donc le temps d'apparition d'une heure, après quoi, 1d6+4 minutes plus tard, l'agonie s'installe normalement.

Si Slow poison est lancé sur une victime après l'apparition des symptômes, ils cessent jusqu'à l'expiration de la durée du sort, puis continuent normalement.

En dernier recours, si le lanceur peut atteindre un individu qui est 'mort' d'empoisonnement dans les 10 minutes, Slow poison retarde la mort d'une victime pendant 1 heure par Intensité, pendant laquelle la victime reste dans le coma. Si pendant ce temps, la victime peut être guérie du poison, elle peut encore vivre et être réanimée par les premiers soins ou la guérison magique.
