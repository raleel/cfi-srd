# পূর্বশর্তসমূহ

১. [মার্কডাউন ল্যাঙ্গুয়েজ](https://www.markdownguide.org/basic-syntax/) সম্পর্কে প্রাথমিক ধারণা।

২. আপনার যদি [গিটহাব (github)](https://github.com/) অ্যাকাউন্ট না থাকে, তবে একটি বিনামূল্যে অ্যাকাউন্ট তৈরি করতে হবে। আমরা পরামর্শ দিই যে আপনার আরপিজি (RPG)-এর নামেই অ্যাকাউন্টটি তৈরি করুন, কারণ এটি সেই ইউআরএল (URL)-এর অংশ হয়ে যাবে যা ব্যবহার করে মানুষ আপনার এসআরডি (SRD) দেখতে পাবে।

৩. আপনি গিট (git) না জেনেই ব্রাউজারের মাধ্যমে এই পুরো প্রক্রিয়াটি সম্পন্ন করতে পারবেন। যদিও গিটহাব ডেস্কটপ (github desktop) শিখে নিলে আপনি সরাসরি পাবলিশ করার আগে আপনার পরিবর্তনগুলো লোকাল ডিভাইসে পরীক্ষা করে নিতে পারবেন।

> আপনার যদি নিজস্ব ডোমেইন নাম কেনা থাকে, তবে সেটি ব্যবহার করেও আপনি আমার মতো করে এসআরডি তৈরি করতে পারবেন: https://srd.7thextinctionrpg.com

## আপনার বিষয়বস্তু যোগ করা

### *.md ফাইলসমূহ

.md ফাইলগুলো হলো মার্কডাউন ফাইল। মার্কডাউন হলো একটি হালকা মার্কআপ ল্যাঙ্গুয়েজ যা ব্যবহার করে আপনি সাধারণ টেক্সট ডকুমেন্টে ফরম্যাটিং এলিমেন্ট যোগ করতে পারেন। আপনার বিষয়বস্তুর আকার অনুযায়ী আপনি চাইলে আপনার গেমের সব তথ্য একটি মাত্র *.md ফাইলে রাখতে পারেন, অথবা আমার মতো [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) সাইটে প্রতিটি অধ্যায়ের জন্য আলাদা আলাদা ফাইল তৈরি করতে পারেন। "sample.md" ফাইলটিতে কিছু ফরম্যাটিং উদাহরণ দেওয়া আছে।

মার্কডাউন ল্যাঙ্গুয়েজ শেখা খুবই সহজ, সিনট্যাক্সের সম্পূর্ণ তালিকার জন্য উপরে উল্লেখিত পূর্বশর্তের ২ নম্বর পয়েন্টের লিঙ্কে ক্লিক করুন।

### _Sidebar.md

এটি আপনার মেনু, যা ওয়েবসাইটের বাম পাশে নেভিগেশন প্যান হিসেবে কাজ করে। আপনার রিপোজিটরিতে কোনো মার্কডাউন ফাইল যোগ করার পর, সেটি যাতে এখানে অন্তর্ভুক্ত হয় সেজন্য ফাইলটি এখানে যুক্ত করতে হবে। বিদ্যমান ফরম্যাটিং অনুসরণ করুন।

## আপনার এসআরডিতে ফ্রি আইকন দেখানোর জন্য Fontawesome এবং/অথবা Material Icons প্লাগইন ব্যবহার করা

### Fontawesome

ফ্রি আইকন এবং অ্যানিমেটেড আইকন পেতে Fontawesome ব্যবহার করুন। সাবস্ক্রাইব করা ব্যবহারকারীরা প্রো আইকন ব্যবহার করতে পারবেন।

১. [Fontawesome](https://fontawesome.com/icons) এ গিয়ে আইকন খুঁজুন।
২. আইকনটি সিলেক্ট করুন।
৩. পপআপ উইন্ডোতে, HTML ট্যাবের নিচে " " এর ভেতরের সবকিছু কপি করুন।

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

৪. কপি করা টেক্সটটুকু `:` এর মাঝে স্পেস ছাড়া বসান।

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

আরও ফ্রি আইকনের জন্য Material Icons ব্যবহার করুন।

১. [Material Icons](https://fonts.google.com/icons) এ গিয়ে আইকন খুঁজুন।
২. ওয়েব স্প্যান লিঙ্কটি কপি করে সরাসরি আপনার মার্কডাউন ফাইলে ইনসার্ট করুন।

```markup
<span class="material-icons">face</span>
```
