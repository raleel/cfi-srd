# ބޭނުންވާ ކަންތައްތައް (Prerequisites)

1. [markdown language](https://www.markdownguide.org/basic-syntax/) އާ ބެހޭ އަސާސީ މައުލޫމާތު ހުރުން.

2. [github](https://github.com/) އެކައުންޓެއް ނެތްނަމަ ހިލޭ އެކައުންޓެއް ހަދަން ޖެހޭނެއެވެ. ތިބާގެ RPG ގެ ނަން ބޭނުންކުރުމަށް ރިކޮމެންޑް ކުރަން، އެއީ ތިބާގެ SRD އަށް ވަނުމަށް މީހުން ބޭނުންކުރާ URL ގެ ބަޔަކަށް ވާނެތީއެވެ.

3. މި މުޅި މަސައްކަތް git އާ ނުލައިވެސް ބްރައުޒާ މެދުވެރިކޮށް ކުރެވޭނެއެވެ. ނަމަވެސް github desktop ދަސްކުރުމުން، ލައިވް ކުރުމުގެ ކުރިން އަމިއްލަ ކޮމްޕިއުޓަރުގައި ބަދަލުތައް ޓެސްޓްކޮށްލެވޭނެއެވެ.

> ތިބާގެ އަމިއްލަ ޑޮމެއިން ނަމެއް ރަޖިސްޓްރީކޮށްފައިވާނަމަ، އަހަރެން މިހެން ހަދާފައިވާ ގޮތަށް https://srd.7thextinctionrpg.com ފަދަ SRD އެއް އުފެއްދުމަށް އެ ބޭނުންކުރެވިދާނެއެވެ.

## މައުލޫމާތުތައް އިތުރުކުރުން

### *.md ފައިލްތައް

.md ފައިލްތަކަކީ މާކްޑައުން ފައިލްތަކެކެވެ. މާކްޑައުންއަކީ ލުއި މާކްއަޕް ބަހެކެވެ. މިއީ ޕްލެއިން ޓެކްސްޓް ޑޮކިއުމަންޓްތަކަށް ފޯމެޓިންގެ އެކި ބައިތައް އިތުރުކުރަން ބޭނުންކުރެވޭ އެއްޗެކެވެ. ތިބާގެ މައުލޫމާތުތައް ހުރި ވަރަކުން، ހުރިހާ މައުލޫމާތެއް އެއް *.md ފައިލެއްގައި ހިމެނިދާނެ، ނުވަތަ އަހަރެން [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) ގައި ހަދާފައިވާ ގޮތަށް ކޮންމެ ބާބަކަށް ވަކި ފައިލެއް ހެދިދާނެއެވެ. "sample.md" ގައި ފޯމެޓިންގެ ބައެއް މިސާލުތައް ހުންނާނެއެވެ.

މާކްޑައުން ބަހަކީ ދަސްކުރަން ވަރަށް ފަސޭހަ އެއްޗެކެވެ. ސިންޓެކްސްގެ ފުރިހަމަ ލިސްޓެއް ބޭނުންނަމަ، މަތީގައިވާ Prerequisites ގެ 2 ވަނަ ނަންބަރުގައިވާ ލިންކު ބޭނުން ކުރައްވާށެވެ.

### _Sidebar.md

މިއީ ވެބްސައިޓްގެ ވާތްފަރާތުގައި އިންނަ މެނޫ ނުވަތަ ނެވިގޭޝަން ޕޭންއެވެ. މާކްޑައުން ފައިލެއް ރިޕޮސިޓްރީއަށް އިތުރުކުރުމަށްފަހު، އެ ފައިލްގެ ކޮންޓެންޓްތައް ފެންނަން ހުރުމަށްޓަކައި މިތަނަށް އެ ފައިލް އިތުރުކުރަން ޖެހޭނެއެވެ. މިހާރު ހުރި ފޯމެޓިންގއާ އެއްގޮތަށް އަމަލު ކުރައްވާށެވެ.

## Fontawesome އަދި/ނުވަތަ Material Icons ޕްލަގިން ބޭނުންކޮށްގެން SRD ގައި ހިލޭ އައިކަންތައްތައް ދެއްކުން

### Fontawesome

ހިލޭ އައިކަންތަކާއި އެނިމޭޓެޑް އައިކަންތައްތައް ހޯދުމަށް Fontawesome ބޭނުން ކުރައްވާ. ސަބްސްކްރައިބް ކޮށްފައިވާ ޔޫޒަރުންނަށް Pro Icons ބޭނުން ކުރެވޭނެއެވެ.

1. [Fontawesome](https://fontawesome.com/icons) އިން އައިކަންއެއް ހޯއްދަވާ
2. އެ އައިކަން ހިޔާރު ކުރައްވާ
3. ޕޮޕްއަޕް ވިންޑޯގެ HTML ޓެބްގެ ދަށުން " " ދެމެދުގައިވާ ހުރިހާ އެއްޗެއް ކޮޕީ ކުރައްވާ

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. ކޮޕީ ކުރި ޓެކްސްޓް `:` ދެމެދުގައި ޖާގައެއް ނުދީ ލައްވާ

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

އިތުރު ހިލޭ އައިކަންތައްތަކަށް Material Icons ބޭނުން ކުރައްވާ

1. [Material Icons](https://fonts.google.com/icons) އިން އައިކަންތައް ހޯއްދަވާ
2. ވެބް ސްޕޭން ލިންކު ކޮޕީކޮށް ސީދާ ތިބާގެ މާކްޑައުން ފައިލްތަކަށް ލައްވާ

```markup
<span class="material-icons">face</span>
```
