#### Appraise (އެޕްރައިޒް)

(Divination - ނަބީކަން/އެނގުން)

| | |
| :-- | :-- |
| **ރޭންކް:** މޭޖް 0 | **ކާސްޓް ކުރާ ވަގުތު:** 1 ޓާން |
| **ސްފިއާ:** ނެތް | **މުއްދަތު:** ވަގުތުން |
| **ޚަރަދު:** 1 | **ރޭންޖް:** ގައިގައި އަތްލުން |
| **ސަރަޙައްދު:** 1 އެއްޗެއް | **މުޤާބަލާ:** ނެތް |

އެޕްރައިޒްގެ ސަބަބުން ޖާދޫކުރާ ފަރާތުގެ POW އާ އެއްވަރުގެ SIZ އެއް ހުންނަ ނުވަތަ ENC އެއްކުރެވިފައިވާ ޖިސްމާނީ މުދަލެއްގެ ފެންވަރު ވަގުތުން ވަޒަންކުރެވޭނެއެވެ. މި ޖާދޫއިން އެއްގޮތަކަށް ހުންނަ ތަކެތީގެ ފެންވަރު އެއްވަރުތޯ ނުވަތަ ތަފާތުތޯ، ނުވަތަ އޭގެ ތެރެއިން އެއްޗެއް ނުވަތަ އެތައް އެއްޗެއްގައި އުނިކަމެއް ނުވަތަ މަތީ ފެންވަރެއް ހުރިތޯ ބަލައިދެއެވެ. މި ޖާދޫ މަސައްކަތްކުރަނީ ދިރޭ ތަކެއްޗަށް ނޫން، ހަމައެކަނި ފުރާނަ ނެތް ތަކެއްޗަށެވެ. އަދި އޭގައި ހުރި އުނިކަމެއް ނުވަތަ ރަނގަޅު ކަމެއް ކޮބައިކަން މިއަކުން ނޭނގޭނެއެވެ، ހަމައެކަނި އެފަދަ ކަމެއް ހުރިކަން އެނގޭނެއެވެ. ޖާދޫ ފާހަގަކުރުމަށް މިއީ ބޭނުންތެރި ޖާދޫއެއް ނޫނެވެ.

#### Armor (އާމަރ)

(Conjuration - ހާޒިރުކުރުން)

| | |
| :-- | :-- |
| **ރޭންކް:** މޭޖް 1 | **ކާސްޓް ކުރާ ވަގުތު:** 1 ރައުންޑް |
| **ސްފިއާ:** ނެތް | **މުއްދަތު:** ތިރީގައި މިވަނީ |
| **ޚަރަދު:** 3 +1/އިންޓެންސިޓީ އަކަށް | **ރޭންޖް:** ގައިގައި އަތްލުން |
| **ސަރަޙައްދު:** 1 އަމާޒު | **މުޤާބަލާ:** ނެތް |

މި ޖާދޫ ކާސްޓް ކުރުމުން، ލިބޭ މީހާގެ ގައި ވަށައިގެން ޖާދޫއީ ބާރެއްގެ އައްޑަނައެއް އުފެދެއެވެ. މިއީ ސްކޭލް އާމަރއެއްގެ ދިފާއީ ބާރާ އެއްވަރުގެ ބާރެކެވެ. މިއީ ހަށިގަނޑުގެ ކޮންމެ ހިސާބަކަށް 4 އާމަރ ޕޮއިންޓް ދެއެވެ. ކުރިން ވެސް އާމަރ ލައިގެން ހުރި މީހަކަށް މި ޖާދޫ މަސައްކަތެއް ނުކުރާނެއެވެ. ނަމަވެސް، މި ޖާދޫގެ މުއްދަތުގައި، ހަށިގަނޑުގެ އަމިއްލަ ދިފާއީ ބާރަށް ވުރެ މަތީ ދިފާއީ ބާރެއް މިއިން ލިބޭނަމަ މިއީ އިސްކުރެވޭނެއެވެ. 4 އާމަރ ޕޮއިންޓަށް ވުރެ މަތީ ދިފާއީ ބާރެއް ހުރި ދިރޭ އެއްޗަކަށް މި ޖާދޫ ދިނުމުން، ހުރިހާ ހިސާބަކަށް 1 އާމަރ ޕޮއިންޓް އިތުރުވާނެއެވެ. މި ޖާދޫއީ ދިފާއީ ބާރުގެ ސަބަބުން ހަރަކާތްތެރިވުމަކަށް ނުވަތަ ޖާދޫ ކުރުމަކަށް ހުރަހެއް ނޭޅޭނެއެވެ. ޖާދޫ ފިލުވާލަންދެން ނުވަތަ އެއް ހަމަލާއަކުން 8 ޕޮއިންޓްގެ ގެއްލުން ލިބެންދެން (އިތުރު އިންޓެންސިޓީއަކަށް +1) މި ޖާދޫ ދެމިހުންނާނެއެވެ (ތިރީގައިވާ ޓޭބަލް ބައްލަވާ). ބޭނުން ނަމަ ކާސްޓްކުރާ ފަރާތަށް ކޮންމެ ވަގުތަކު ވެސް ޖާދޫ ފިލުވާލެވިދާނެއެވެ، އަދި ނިދަންވެއްޖެނަމަ އެގޮތަށް ކަންތައް ކުރަން ޖެހޭނެއެވެ.

#### Astral Spell (އެސްޓްރަލް ސްޕެލް)

(Transmutation - ބަދަލުކުރުން)

| | |
| :-- | :-- |
| **ރޭންކް:** ކްލެރިކް 5، މޭޖް 5 | **ކާސްޓް ކުރާ ވަގުތު:** 2 އެކްޝަން |
| **ސްފިއާ:** އެސްޓްރަލް | **މުއްދަތު:** ތިރީގައި މިވަނީ |
| **ޚަރަދު:** 3 +1/އިތުރު އިންޓެންސިޓީ | **ރޭންޖް:** ގައިގައި އަތްލުން |
| **ސަރަޙައްދު:** ތިރީގައި މިވަނީ | **މުޤާބަލާ:** ނެތް |

މި ޖާދޫއިން ޖާދޫކުރާ ފަރާތަށާއި އިތުރު ފަސް މީހަކަށް (ކޮންމެ އިތުރު އިންޓެންސިޓީއަކަށް އެކަކު) އެސްޓްރަލް ޕްލޭންއަށް ދެވޭނެއެވެ. ޖާދޫ ކާސްޓް ކުރާއިރު އެންމެން އެކަކު އަނެކަކުގެ ގައިގައި އަތްލައިގެން ދާއިރާއެއް ހަދައިގެން ތިބެން ޖެހޭނެއެވެ. ދަތުރުވެރިންގެ ހަށިގަނޑު މި ދުނިޔޭގައި ބެހެއްޓޭނެއެވެ. ޖާދޫއީ އަސަރު ހުރި ތަކެތި ފިޔަވައި އެހެން އެއްޗެއް ގެންދިއުމަކީ ނުވާނެ ކަމެކެވެ. ގެންދެވޭ ތަކެތި އެސްޓްރަލް ޕްލޭންއަށް ލާފައިވާ ގޮތަށް ބަދަލުވާނެއެވެ. ޖާދޫކުރާ ފަރާތް ބޭނުންވާ ވަގުތަކާ ހަމައަށް ޖާދޫ ދެމިހުންނާނެއެވެ. ނަމަވެސް، ޑިސްޕެލް މެޖިކް ފަދަ ބޭރުގެ ބާރުތަކުން ޖާދޫ ކުރިން ހުއްޓުވިދާނެއެވެ. ޖާދޫކުރާ ފަރާތުގެ ހަށިގަނޑު މަރުވެއްޖެނަމަ ޖާދޫ ކުއްލިއަކަށް ހުއްޓޭނެއެވެ، މިކަމުގެ ސަބަބުން އެހެން ދަތުރުވެރިން އެސްޓްރަލް ޕްލޭންގައި ތާށިވެދާނެއެވެ.

#### Befuddle (ބިފަޑަލް)

(Enchantment (Charm) - ޖާދޫއީ އަސަރު/މަސްތުކުރުން)

| | |
| :-- | :-- |
| **ރޭންކް:** ކްލެރިކް 0، މޭޖް 0 | **ކާސްޓް ކުރާ ވަގުތު:** 1 ޓާން |
| **ސްފިއާ:** ޗާމް | **މުއްދަތު:** 30 މިނެޓް |
| **ޚަރަދު:** 1 | **ރޭންޖް:** 60 ފޫޓު |
| **ސަރަޙައްދު:** 1 އަމާޒު | **މުޤާބަލާ:** ވިލްޕަވަރ |

ބިފަޑަލް އިން ޖިސްމާނީ އަމާޒެއްގެ ސިކުނޑި އޮޅުންބޮޅުން ކުރުވައެވެ. މި ޖާދޫ ޖެހޭ މީހަކަށް ސީދާ ވިސްނުމަށް އުނދަގޫވެ، އޭނާ ހުރީ ކޮންތަނެއްގައިކަން ނުވަތަ ކުރަނީ ކީއްކަން ހަނދާން ނެތެއެވެ. މި މީހުންނަށް އަމިއްލަ ދިފާއުގައި ހަރަކާތްތެރިވެވުނަސް، ޖާދޫ ފިލަންދެން އެއްވެސް އުފެއްދުންތެރި މަސައްކަތެއް ނުކުރެވޭނެއެވެ. ކޮންމެފަދަ ހަމަލާއެއް ނުވަތަ ބިރުދެއްކުމެއްގެ ސަބަބުން މި ޖާދޫ ވަގުތުން ފިލައިގެން ދާނެއެވެ.

#### Blade Barrier (ބްލޭޑް ބެރިއަރ)

(Evocation - ޖާދޫއީ ބާރު)

| | |
| :-- | :-- |
| **ރޭންކް:** ކްލެރިކް 4 | **ކާސްޓް ކުރާ ވަގުތު:** 2 އެކްޝަން |
| **ސްފިއާ:** ގާޑިއަން، ކްރިއޭޝަން | **މުއްދަތު:** 3 ރައުންޑް/އިންޓެންސިޓީ |
| **ޚަރަދު:** 3+1/އިތުރު އިންޓެންސިޓީ | **ރޭންޖް:** 100 ފޫޓު |
| **ސަރަޙައްދު:** 5-30 ފޫޓު ރޭޑިއަސް | **މުޤާބަލާ:** ތިރީގައި މިވަނީ |

މި ޖާދޫއިން ވަށައިގެން އެނބުރޭ ކަނޑި، ދަގަނޑު، އަދި ވަޅިތަކެއްގެ ފާރެއް އުފައްދައެވެ. މިއީ ސަރަޙައްދުގެ ތެރެއިން ދާ ކޮންމެ އެއްޗަކަށް 1d8 ގެ ގެއްލުން ދޭނެއެވެ. އާމަރ އިން ދެނީ އޭގެ ދެބައިކުޅަ އެއްބައި ދިފާއެވެ. މިހާ ބާރަށް އެނބުރޭ އެއްޗެއް ވީމާ، މިއިން ދިފާއުވުމަކީ ކުރެވޭނެ ކަމެއް ނޫނެވެ. އައްޑަނައެއް ބޭނުންކޮށްގެން ހަމަލާތައް ބްލޮކް ކުރެވިދާނެއެވެ.

މި ޖާދޫ ދިފާއުވުމަށާއި ހަމަލާ ދިނުމަށް ވެސް ބޭނުން ކުރެވިދާނެއެވެ. ޖާދޫ އުފެދޭއިރު އޭގެ ކައިރީގައި ތިބޭ މީހުންނަށް އިވޭޑް (Evade) ރޯލެއް ކޮށްގެން ސަލާމަތްވެވިދާނެއެވެ. އެހެންނޫނީ ފުރިހަމަ ގެއްލުން ލިބޭނެއެވެ.

(Evocation - ޖާދޫއީ ބާރު)

| | |
| :-- | :-- |
| **ރޭންކް:** މޭޖް 0 | **ކާސްޓް ކުރާ ވަގުތު:** 1 އެކްޝަން |
| **ސްފިއާ:** ނެތް | **މުއްދަތު:** ވަގުތުން |
| **ޚަރަދު:** 1 | **ރޭންޖް:** ގައިގައި އަތްލުން |
| **ސަރަޙައްދު:** 1 އަމާޒު | **މުޤާބަލާ:** ނެތް |

ޗިލް އިން އެއްޗެއް ވަރަށް ބޮޑަށް ފިނިކޮށްލައެވެ. މިއީ ވަރަށް ފިނި ކޮށްލަން ބޭނުންކުރާ ޖާދޫއެކެވެ. މިއީ އެއްވެސް ގެއްލުމެއް ލިބޭ ޖާދޫއެއް ނޫނެވެ.

މިއީ ޗިލް (Chill) ގެ އިދިކޮޅު ޖާދޫއެވެ: ހީޓް (Heat) އިން އެއްޗެއް ވަރަށް ބޮޑަށް ހޫނު ކޮށްލައެވެ.

(Transmutation - ބަދަލުކުރުން)

| | |
| :-- | :-- |
| **ރޭންކް:** މޭޖް 0 | **ކާސްޓް ކުރާ ވަގުތު:** 1 އެކްޝަން |
| **ސްފިއާ:** ނެތް | **މުއްދަތު:** ވަގުތުން |

ކްލީންސް އިން އެއްޗެއް ނުވަތަ ތަނެއް ސާފު ކުރެއެވެ. ޑިޝެވެލް (Dishevel) އަކީ މީގެ އިދިކޮޅު ޖާދޫއެވެ.
