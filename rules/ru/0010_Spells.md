#### Оценка (Appraise)

(Прорицание)

| | |
| :-- | :-- |
| **Ранг:** Маг 0 | **Время наложения:** 1 ход |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 1 | **Дистанция:** Касание |
| **Область:** 1 предмет | **Сопротивление:** Нет |

Оценка позволяет мгновенно определить качество физических товаров общим весом (ENC) в «Вещах» или РАЗ, равным МОЩ заклинателя. Заклинание позволяет определить, являются ли внешне одинаковые предметы товарами одного или схожего качества, либо один из них является бракованным или более высокого качества. Заклинание не работает на органические объекты, только на неодушевленные предметы. Оно также не определяет, какие именно дефекты или улучшения присутствуют; лишь подтверждает их наличие. Оно бесполезно при идентификации или обнаружении магии.

#### Доспех (Armor)

(Вызов)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время наложения:** 1 раунд |
| **Сфера:** Нет | **Длительность:** См. ниже |
| **Стоимость:** 3 +1/Интенсивность | **Дистанция:** Касание |
| **Область:** 1 цель | **Сопротивление:** Нет |

При сотворении этого заклинания цель получает невидимое поле магической силы, эквивалентное по защите чешуйчатому доспеху, что дает 4 Очка Брони каждой пораженной зоне. Заклинание не действует, если наложено на того, кто уже носит доспехи. Однако оно заменит естественную броню на время действия, если предлагает лучшую защиту. Если заклинание наложено на существо с более чем 4 очками естественной брони, оно вместо этого увеличит Очки Брони на 1 во всех зонах. Эта магическая защита не препятствует движению или сотворению заклинаний. Заклинание сохраняется до тех пор, пока оно не будет развеяно магией, или пока заклинатель не получит 8 очков урона от одной атаки +1 за каждый уровень дополнительной Интенсивности (см. таблицу ниже). Конечно, заклинатель может по желанию снять заклинание в любой момент, и должен сделать это перед сном.

| Интенсивность | Стоимость | Переменный эффект |
| :-: | :-: | :-- |
| 1 | 3 | 4 Очка Брони; действует до получения 8 ед. урона от 1 атаки |
| 2 | 4 | 4 Очка Брони; действует до получения 9 ед. урона от 1 атаки |
| 3 | 5 | 4 Очка Брони; действует до получения 10 ед. урона от 1 атаки |
| 4 | 6 | 4 Очка Брони; действует до получения 11 ед. урона от 1 атаки |
| +1 | +1 | Продолжение прогрессии |

#### Астральное заклинание (Astral Spell)

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Клирик 5, Маг 5 | **Время наложения:** 2 действия |
| **Сфера:** Астральная | **Длительность:** См. ниже |
| **Стоимость:** 3 +1/дополнительная Интенсивность | **Дистанция:** Касание |
| **Область:** См. ниже | **Сопротивление:** Н/Д |

Это заклинание позволяет заклинателю и еще пяти другим (по одному на каждый дополнительный уровень Интенсивности) войти на Астральный план. Все должны касаться друг друга и образовывать круг во время сотворения. Тела путешественников остаются в исходном плане, и они, как правило, не берут с собой одежду или снаряжение, за исключением того, что само по себе излучает магическую ауру; эти предметы преобразуются в астральные эквиваленты своей обычной формы. Длительность продолжается, пока заклинатель не пожелает её прекратить. Однако заклинание может быть преждевременно прервано внешней силой, такой как «Рассеивание магии» (Dispel Magic). Убийство физического тела заклинателя также преждевременно завершает заклинание, хотя это имеет печальный побочный эффект: сопровождающие заклинателя путешественники окажутся заперты [в Астрале].

#### Знамение (Augury)

(Прорицание)

| | |
| :-- | :-- |
| **Ранг:** Клирик 2 | **Время наложения:** 2 минуты |
| **Сфера:** Прорицание | **Длительность:** Мгновенно |
| **Стоимость:** 3/Интенсивность | **Дистанция:** 60 футов |
| **Область:** Заклинатель | **Сопротивление:** Н/Д |

Это заклинание позволяет заклинателю определить, будет ли конкретное действие, которое предстоит совершить в течение следующих 30 минут, полезным или вредным для благополучия индивида и/или группы. Для распознавания предзнаменований требуется некий фокус, наиболее распространенными из которых являются когти или мелкие кости дракона, жемчужина или чистое золото стоимостью не менее 100 золотых монет, которые были раздавлены или расплавлены. Максимальная Интенсивность заклинания — 4. Этот бросок должен делать Мастер Игры, так как заклинатель никогда не должен знать наверняка, правильно ли были истолкованы результаты.

| Интенсивность | Стоимость | Переменный эффект |
| :-: | :-: | :-- |
| 1 | 3 | Бросок навыка «Канал» (Channel) — Серьезный |
| 2 | 6 | Бросок навыка «Канал» — Сложный |
| 3 | 9 | Бросок навыка «Канал» — Стандартный |
| 4 | 12 | Бросок навыка «Канал» — Легкий |

Если бросок прорицания успешен, он дает один из следующих результатов:

| Знамение | Значение | 
| :-: | :-- |
| Да | Действие будет полезным |
| Нет | Действие будет вредным |
| Да и Нет | Действие будет одновременно полезным и вредным |
| Ничего | Действие не будет ни полезным, ни вредным |

Провал (Fumble) должен привести к тому, что Мастер Игры сообщит противоположное реальности.

#### Одурманивание (Befuddle)

(Зачарование (Очарование))

| | |
| :-- | :-- |
| **Ранг:** Клирик 0, Маг 0 | **Время наложения:** 1 ход |
| **Сфера:** Очарование | **Длительность:** 30 минут |
| **Стоимость:** 1 | **Дистанция:** 60 футов |
| **Область:** 1 цель | **Сопротивление:** Сила воли |

«Одурманивание» вызывает замешательство в разуме телесной цели. У субъекта заклинания возникают трудности с ясным мышлением, он забывает, где находится, что делает и зачем — часто переходя к бессвязным линиям мышления. Одурманенные цели все еще могут действовать в целях самообороны, но не могут начинать какую-либо конструктивную деятельность до окончания действия заклинания. Любая атака или угрожающее действие мгновенно прерывает заклинание, независимо от того, было ли оно направлено специально на одурманенную цель.

#### Стена клинков (Blade Barrier)

(Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Клирик 4 | **Время наложения:** 2 действия |
| **Сфера:** Страж, Созидание | **Длительность:** 3 раунда/Интенсивность |
| **Стоимость:** 3+1/дополнительная Интенсивность | **Дистанция:** 100 футов |
| **Область:** Радиус 5–30 футов | **Сопротивление:** См. ниже |

Это заклинание создает барьер из вращающихся режущих мечей, кинжалов и ножей, которые мечутся и кромсают вокруг фиксированной точки, нанося 1d8 очков урона 1d4+2 случайным пораженным зонам любого, кто проходит через область действия. Броня предлагает лишь половину своей обычной защиты. Магические Очки Брони уменьшают урон как обычно. Поскольку оружие вращается с ослепительной скоростью и расположено плотно, его невозможно парировать или уклониться от него. Можно использовать щит для пассивного блокирования пораженных зон как обычно. В этом случае не забудьте сравнить выпавший урон с броней и Хит-поинтами щита.

Заклинание может быть наложено оборонительно для защиты клирика или одного или нескольких союзников, либо наступательно — для поимки врагов в ловушку. Тем не менее враги, окруженные в пределах пяти футов от края барьера в момент его формирования, могут совершить бросок «Уклонения», чтобы спастись. Вне зависимости от успеха, противник падает ничком прямо за пределами области действия. Успешный бросок означает отсутствие урона; в противном случае они получают полный эффект.

Благословений Нейтралитета не существует. Все союзники в радиусе действия заклинания получают бонус +5% ко всем броскам навыков и сопротивлений. Кроме того, их оружие наносит +1d3 урона разумной нежити, а также существам из внешних планов, имеющим противоположное мировоззрение по сравнению с заклинателем (например, демонам, дьяволам или ангелам). Заметьте, что, хотя оживленная нежить, такая как скелеты и зомби, не является изначально злой, она обычно анимируется злой магией и поэтому подвержена этому урону.

Обратная сторона этого заклинания, «Проклятие», позволяет клирику проклинать врагов, заставляя указанные навыки испытывать инверсию преимуществ, отмеченных выше. Урон проклятого оружия рассчитывается как штраф, и этот урон не может составить менее 1 очка.

#### Горящие руки (Burning Hands)

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время наложения:** 1 действие |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 3+1/дополнительная Интенсивность | **Дистанция:** 0 |

Это заклинание вызывает пламя, вырывающееся из рук заклинателя в дуге 120 градусов. Урон поглощает все цели в области, основываясь на Интенсивности заклинания (до максимума в 9), следующим образом: Успешный бросок на «Уклонение» (падение ничком) позволяет жертве избежать урона. (Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 3+1/доп. интенсивность | **Дистанция:** 50 футов/интенсивность |
| **Область:** См. ниже | **Сопротивление:** Уклонение |

При сотворении заклинатель выпускает из кончиков пальцев электрический разряд шириной пять футов, который поражает одну цель в пределах дистанции, нанося 1к6+1 очков урона за каждые 2 единицы интенсивности. Затем разряд перескакивает на ближайший объект или существо, которые получают ранее выброшенное количество урона минус 1 очко, после чего перескакивает на следующий ближайший, нанося полученный урон минус 2 очка, и так далее. Разряд может даже вернуться к союзнику или самому заклинателю! Хотя первая цель должна быть видна заклинателю, цели, поражаемые отскакивающим разрядом, не обязаны находиться в поле зрения.

У каждого скачка своя дистанция в 50 футов, из-за чего разряд может уйти за пределы исходной дальности, на которой было сотворено заклинание. «Цепная молния» продолжает поражать цели, пока у нее остается урон, либо пока не ударит в объект, который ее заземлит (металлическая клетка или решетка, большой водоем и т. д.), либо пока поблизости не останется объектов или существ.

Каждое пораженное существо получает урон в одну точку попадания; носимая броня не дает защиты, а естественная броня и магические очки брони снижают урон как обычно.

При успешном броске на Уклонение, сопровождающемся падением ничком, жертва не получает урона. Персонаж со способностью «Искусный уклонист» может уклониться, не падая ничком, но в этом случае успех лишь наполовину снижает урон.

Молния имеет шанс поджечь легковоспламеняющиеся материалы, равный результату броска урона х1%. Дополнительную информацию см. в разделе [Огонь](0007_Game_System.md?id=fire-based-attacks). Молния также может разбить или уничтожить неодушевленные предметы под действием мощного удара.

| 4 | 6 | Дистанция 200 футов; 2к6+2 урона |

| +1 | +1 | Продолжение прогрессии |

(Вызов)

| | |
| :-- | :-- |
| **Ранг:** Клирик 2 | **Время сотворения:** 2 действия |

#### Очарование личности

(Зачарование (Очарование))

| | |
| :-- | :-- |

При сотворении этого заклинания одна живая (нежить не подвержена) разумная гуманоидная цель с РАЗ 1–20 прекращает все враждебные действия против мага и его союзников и вместо этого предлагает им помощь и защиту, если цель проваливает бросок на Сопротивление. Заметьте, что помощь/защита могут иметь непреднамеренные или даже негативные последствия для заклинателя, поскольку субъект действует исходя из того, что он считает наилучшим способом защитить/помочь. Что касается приказов, цель никогда не подчинится суицидальным или заведомо вредным действиям, но может быть убеждена, что совершить что-то крайне опасное — стоит того.

Любой враждебный акт против объекта очарования со стороны мага или его союзников разрушает Зачарование. Примечание: Если другие ставят под сомнение природу Очарования, цель может совершить бросок на Сопротивление по усмотрению Мастера игры. Маг должен иметь возможность разговаривать с очарованным, чтобы дать ему какой-либо сложный «запрос»; поэтому знание языка цели может быть важным, но не обязательным для базового Зачарования.

В течение всей длительности заклинания общее количество магических очков заклинателя уменьшается на количество очков, потраченных на сотворение заклинания, согласно правилам [Длительных магических затрат](0009_Magic.md?id=enduring-magic-costs).

#### Приказ

(Зачарование (Очарование))

| | |
| :-- | :-- |
| **Ранг:** Клирик 1 | **Время сотворения:** 1 действие |
| **Сфера:** Очарование | **Длительность:** 1 минута |
| **Стоимость:** 3 | **Дистанция:** 100 футов |
| **Область:** 1 цель | **Сопротивление:** МОЩ |

При сотворении этого заклинания клирик может произнести односложный приказ одному живому существу с РАЗ 1–20, и в свой следующий ход субъект выполнит этот приказ в точности, если не сможет оказать сопротивление. Это фактически заставляет жертву пропустить следующий ход, выполняя приказ, и тратит Очко Действия. Если у жертвы не осталось Очков Действия, приказ будет выполнен в течение первого хода следующего раунда. Сам приказ не может нанести цели фактических увечий; однако травма может стать побочным эффектом выполнения приказа.

Например, приказ «Умри» приведет к тому, что жертва упадет в состояние, подобное смерти, на 1 раунд, не получая никаких реальных повреждений; однако приказ «Упади», данный существу, лезущему по отвесной 100-футовой скале, может оказаться более чем смертельным.

Субъект приказа должен понимать язык, на котором говорит заклинатель, и имеет право на проверку МОЩ для сопротивления.

**Некоторые примеры приказов**

- **Ползи:** Субъект падает ничком и начинает ползти.
- **Умри:** Субъект падает ничком, погружаясь в коматозное состояние, подобное смерти.
- **Упади:** Субъект падает ничком.
- **Урони:** Субъект роняет предмет, который собирался использовать.
- **Спи:** Субъект засыпает.
- **Беги:** Субъект разворачивается и убегает от заклинателя.
- **Лети:** Субъект машет руками и бегает кругами.
- **Иди:** Субъект начинает идти в направлении, в котором был обращен.
- **Стой:** Субъект немедленно останавливается и остается на месте.
- **Уйди:** Субъект разворачивается и уходит тем же путем, каким пришел.
- **Отдохни:** Субъект садится, чтобы перевести дух.
- **Беги (быстро):** Субъект начинает бежать.
- **Кричи:** Субъект вопит.
- **Тонуть:** Субъект перестает плыть.
- **Сдавайся:** Субъект бросает оружие и прекращает враждебные действия.

#### Конус холода

(Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Время сотворения:** 1 раунд |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 3+1/доп. интенсивность | **Дистанция:** 0 |
| **Область:** См. ниже | **Сопротивление:** Уклонение |

Заклинатель создает конус обжигающего холода, исходящий из его руки. Область действия представляет собой 90-градусный сектор («конус») длиной 10 футов за каждый уровень интенсивности. Заклинание наносит 1к6+1 очков урона за каждые 2 единицы интенсивности (или их часть) всем жертвам в области действия. Бросьте урон один раз и примените его к каждой точке попадания цели; носимая броня дает лишь половинную защиту, но естественная броня существа или магические очки брони снижают урон как обычно. Мастер игры может выбрать количество затронутых зон любым подходящим способом, если огромное существо больше области действия.

При успешном броске на Уклонение, сопровождающемся падением ничком, жертва не получает урона. Персонаж со способностью «Искусный уклонист» может уклониться, не падая ничком, но в этом случае успех лишь наполовину снижает урон, если только персонаж не находится в пределах пяти футов от края области действия. «Конус холода» имеет шанс покрыть жертву слоем льда, равный значению нанесенного урона (после модификаций) х5%. Если жертва заморожена, она может один раз в раунд потратить Очко Действия и сделать бросок на СИЛ, чтобы попытаться вырваться; однако, пока попытка не увенчается успехом, несчастная жертва не может двигаться или совершать другие действия.

Эффекты заклинания неподвижны, но его можно сотворить на переносном или перемещаемом предмете.

(Некромантия)

| | |
| :-- | :-- |

Это заклинание исцеляет последствия любой обычной или магической болезни, поразившей цель, чей показатель Мощи меньше, чем Интенсивность заклинания × 30. Как только исцеление вступило в силу, начинается восстановление согласно описанию конкретной болезни. Недуги, вызванные паразитическими существами, такими как зелёная слизь, гнилостные личинки и даже ликантропы, могут быть нейтрализованы Исцелением болезни. Однако, в отношении последних недугов, Снятие болезни должно быть сотворено в течение 72 часов и с Интенсивностью 12 или выше, в то время как первые могут быть вылечены с Интенсивностью всего 1. | :-: | :-: | :-- |

| 2 | 6 | Исцеление болезни МОЩ 60 |
| 3 | 9 | Исцеление болезни МОЩ 90 |
| 4 | 12 | Исцеление болезни МОЩ 120, ликантропии |
| +1 | +1 | Продолжение прогрессии |

Обратное заклинание, Наведение болезни, насылает на врага магический недуг. В случае успеха заклинатель может выбрать любую известную болезнь для поражения цели; однако показатель Интенсивности × 30 должен быть равен или превышать Мощь выбранной болезни. Как только болезнь успешно наложена, она действует как любая другая болезнь в отношении сопротивления, времени начала, длительности и так далее. Единственное исключение состоит в том, что раннее выздоровление возможно только при сотворении Снятия болезни или Исцеления. Навык Исцеление не оказывает эффекта на магически наведённые болезни.

Это заклинание функционирует как Исцеление лёгких ран, за исключением того, что указано ниже.

Это заклинание исцеляет одну Часть тела, страдающую от Тяжёлой раны, независимо от того, была ли она раздроблена или изувечена. Выброшенные очки здоровья усредняются и восстанавливаются в течение указанного Периода восстановления. Если этот Период восстановления прерывается до завершения исцеления, часть тела остаётся искалеченной и непригодной к использованию, излечить её можно будет только заклинанием Исцеление.

При обращении, Наведение тяжёлых ран может быть использовано для снижения здоровья одной Части тела на 1к8+4 очка. Бросок Канала заклинателя функционирует как бросок попадания по противнику и считается частью соматического компонента заклинания. Дополнительный бросок на попадание не требуется. Это заклинание не может отсечь часть тела, но может раздробить или изувечить её обычным образом. Ни ношение брони, ни естественная броня не дают никакой защиты, но очки магической Брони снижают урон обычным образом.

При сотворении на существо, страдающее от Лёгкой раны, 1к4+1 очко здоровья в повреждённой части тела восстанавливается мгновенно. Оно имеет ограниченный эффект на Серьёзные и Тяжёлые раны, восстанавливая лишь одно очко здоровья. Однако заклинание стабилизирует часть тела независимо от повреждений, останавливая кровотечение и предотвращая неминуемую смерть.

Альтернативно, если субъект страдает от незначительного недомогания, такого как головная боль, боль в спине, похмелье, простуда, бородавки и тому подобное, сотворение Исцеления лёгких ран снимает один из эффектов. Такой вариант заклинания стоит всего одно Очко магии.

При обращении, Наведение лёгких ран уменьшает здоровье затронутой части тела на 1к4+1 очко, в остальном действуя так же. Наведение лёгких ран наносит лишь 1 очко урона части тела с Серьёзной или Тяжёлой раной, избыточный урон теряется. Это заклинание не может отсечь часть тела, но может раздробить или изувечить её обычным образом.

Альтернативно, заклинание может вызвать незначительный недуг, такой как головная боль, боль в спине, похмелье, простуда, бородавки и тому подобное. Такой вариант заклинания стоит всего одно Очко магии.

Бросок Канала заклинателя функционирует как бросок попадания по противнику и считается частью соматического компонента заклинания. Дополнительный бросок на попадание не требуется. Ни ношение брони, ни естественная броня не дают никакой защиты, но очки магической Брони снижают урон обычным образом.

#### Заклинание смерти

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 3 +1/Интенсивность, +2 ОП | **Дистанция:** 30 футов/Интенсивность |
| **Область:** Радиус 15 футов | **Сопротивление:** Выносливость |

Успешное сотворение этого заклинания убивает переменное число существ с РАЗ 40 или меньше в области действия. Маг бросает 1к6 на каждый уровень Интенсивности, чтобы определить число затронутых существ. Там, где в области действия находятся существа разных категорий РАЗ, всегда сначала затрагиваются существа человеческого размера (РАЗ 1-20), а затем более крупные. Крупные существа (РАЗ 21-40) с большей вероятностью сопротивляются гибели, их бросок Сопротивления считается Лёгким, однако каждое Крупное существо считается за 5 существ человеческого размера. Существа с РАЗ более 40 невосприимчивы к этому заклинанию.

| Интенсивность | Стоимость | Переменные эффекты |
| :-: | :-: | :-- |
| 1 | 3 +2 ОП | Дистанция 30 футов; затронуто 1к6 существ |
| 2 | 4 +2 ОП | Дистанция 60 футов; затронуто 2к6 существ |
| 3 | 5 +2 ОП | Дистанция 90 футов; затронуто 3к6 существ |
| 4 | 6 +2 ОП | Дистанция 120 футов; затронуто 4к6 существ |
| +1 | +1 | Продолжение прогрессии |

Желательно сотворять заклинание с Интенсивностью, достаточной для того, чтобы она была равна или превышала число потенциальных целей, поскольку недостающие очки теряются. Это заклинание не действует на ликантропов, нежить или других потусторонних существ. Только заклинание Желание может вернуть к жизни тех, кто был затронут этим заклинанием.

_Пример: Ренгарт сотворяет Заклинание смерти в область, занятую четырьмя орками РАЗ 16 и двумя горными великанами РАЗ 32, выбирая Интенсивность 3. Бросок 3к6 для эффектов заклинания (по 1к6 на Интенсивность) даёт 12 очков. В то время как для убийства каждого горного великана требуется 5 очков, первыми затрагиваются более мелкие орки. Трое из четырёх орков проваливают бросок Сопротивления и умирают. Поскольку каждый орк равен 1 очку, остаётся 8 очков. Этого достаточно, чтобы воздействовать на одного горного великана (5 очков), оставшиеся 3 очка теряются. Однако разъярённый горный великан без проблем проходит свой Лёгкий бросок Сопротивления и бросается на Ренгарта._

Эффекты заклинания нельзя устранить частично.

Развеивание магии начинается с самой мощной магии в области действия. Если оно не может устранить какое-либо заклинание (потому что его Магическая мощь слишком высока), то заклинание завершается, и никакая другая магия не может быть устранена.

Развеивание магии можно использовать защитно для нейтрализации входящих атакующих заклинаний, используя Реактивное действие Встречное заклинание.#### Гадание

#### Зачарование предмета

(Зачарование)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Время сотворения:** См. ниже |
| **Сфера:** Нет | **Длительность:** См. ниже |
| **Стоимость:** 3 + См. ниже | **Дистанция:** Касание |
| **Область:** 1 предмет | **Сопротивление:** Н/Д |

Сотворение этого заклинания подготавливает предмет к зачарованию. Объект должен быть в хорошем состоянии и иметь высочайшее качество изготовления. Требуется дополнительная стоимость не менее 100 золотых монет на покрытие расходов по доработке, резьбе, вышивке, инкрустации драгоценными камнями, гравировке и т. д. Наконец, процесс зачарования требует наличия лаборатории или мастерской.

Во время сотворения заклинания маг должен касаться предмета в течение всего времени сотворения, составляющего 1д8+2 дня. В это время включены периоды отдыха и сна, во время которых предмет должен оставаться на расстоянии вытянутой руки от заклинателя. Ни в какой момент сотворения маг не может произносить другое заклинание или использовать другие формы магии. Нарушение любого из этих условий автоматически приведет к провалу заклинания.

После успешного сотворения предмет готов к последнему шагу: заклинатель накладывает на него желаемое заклинание. Для этого оно должно быть у него в памяти или на свитке, и он должен сотворить его в предмет в течение 24 часов, иначе весь процесс придется начинать заново. Как только начнется сотворение выбранного заклинания, процесс может превысить вышеупомянутые 24 часа. Наполнение предмета выбранным заклинанием стоит обычное количество магических очков для желаемой интенсивности и занимает 1д12 часов на каждый ранг заклинания. На протяжении всего процесса наполнения заклинатель должен оставаться в контакте с предметом или в пределах досягаемости во время отдыха, как указано выше, и в конце периода сотворения требуется бросок магического сотворения для успешного завершения. Следует придерживаться обычных степеней успеха сотворения заклинаний, однако в случае результата «Провал» заклинание нельзя «протолкнуть» насильно. В предмет можно последовательно вкладывать несколько заклинаний, при условии, что процесс сотворения каждого начинается в течение 24 часов после завершения предыдущего. Это применимо даже в случае предыдущего неудачного сотворения. Каждое последующее заклинание требует обычной стоимости сотворения.

При использовании предмета каждое содержащееся в нем заклинание может быть использовано только один раз, однако с помощью вышеуказанной процедуры можно вложить несколько версий одного и того же заклинания. Также возможно вложить единственное заклинание, а затем сотворить заклинание 4-го ранга «Постоянство» (Permanency). В этом случае заклинание можно использовать столько раз, сколько пожелается, следуя ограничениям, установленным в описании заклинания «Постоянство».

Невозможно наделить предмет другими магическими эффектами, которые не соответствуют конкретному заклинанию, и многие магические предметы из давно ушедших времен просто не могут быть воссозданы в наши дни.

#### Зачарование оружия

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Время сотворения:** 1 минута |
| **Сфера:** Нет | **Длительность:** 5 минут/интенсивность |
| **Стоимость:** 3+1/доп. интенсивность | **Дистанция:** Касание |
| **Область:** 1 оружие | **Сопротивление:** Н/Д |

Когда это заклинание сотворяется при касании обычного оружия, оно наделяется временным зачарованием, дающим магический модификатор урона +1. Это также позволяет обычному оружию поражать существо, которое можно ранить только оружием, имеющим зачарование не менее +1. Заклинание можно использовать для зачарования двух видов оружия размером по ½ «вещи» каждое, таких как кинжалы, ножи, стрелы и так далее. В противном случае, за одно сотворение можно зачаровать не более одного оружия. Бонус существующего магического оружия может быть увеличен на +1 до общего максимального совокупного бонуса +3. Оружие с бонусом +3 увеличивает свой размер на одну категорию для целей нанесения урона: с «Большого» до «Огромного», с «Огромного» до «Громадного», с «Громадного» до «Колоссального». Зачарованное оружие обладает +5 пунктами брони и +2 пунктами здоровья на каждый +1 зачарования для оружия своего типа. Это заклинание можно комбинировать с заклинаниями «Зачарование предмета» и «Постоянство» для создания оружия с длительным зачарованием.

В случае заклинаний с площадью поражения урон уменьшается перед применением.

#### Истощение энергии

(Эвокация или Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Маг 5 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Постоянно |
| **Стоимость:** 3 | **Дистанция:** Касание |
| **Область:** 1 цель | **Сопротивление:** Выносливость |

При сотворении это заклинание накладывает два уровня постоянной потери усталости на жертву, провалившую бросок сопротивления. Потеря усталости через «Истощение энергии» суммируется с обычной потерей усталости; следовательно, противники, уже ослабленные боем или путешествием, более восприимчивы к «Истощению энергии». Заклинания и зелья «Исцеление усталости» не влияют на усталость, потерянную из-за «Истощения энергии»; однако заклинания и свитки «Восстановление» могут навсегда вылечить потерянную усталость. Броня не влияет на «Истощение энергии».

#### Изгнание

(Абьюрация)

| | |
| :-- | :-- |
| **Ранг:** Жрец 3 | **Время сотворения:** 1д10x100 минут |
| **Сфера:** Защита | **Длительность:** Постоянно |
| **Стоимость:** 3+1/доп. интенсивность | **Дистанция:** 10 футов |

С помощью этого заклинания жрецы призывают свое божество изгнать духа или другую сверхъестественную силу, в данный момент вселившуюся в телесное существо, как, например, при демоническом одержании. Изгнание также может быть использовано против подчинения со стороны определенных объектов и магических предметов, заклинаний, проклятий и даже очарований. Является ли одержание доминирующим или скрытым — не имеет значения. Магия изгоняет все формы одержания с интенсивностью до половины интенсивности самого заклинания. Что произойдет дальше, зависит от отношения и типа сущности, если она есть, но воинственные сущности, обладающие силой развоплощения, могут попытаться вовлечь другие близлежащие цели в «Духовный бой» (Spirit Combat). Рассматривайте это как «Магическую дуэль», однако если сущность побеждает, она может вселиться в проигравшего. Если сущность проигрывает, она отправляется обратно на свой план происхождения. Таким образом, это заклинание может быть потенциально опасным для заклинателя или его товарищей. Время сотворения очень случайно и не может быть прервано без разрушения ритуала.

#### Падение перышком

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** Мгновенно |
| **Сфера:** Нет | **Длительность:** 1 минута/интенсивность |
| **Стоимость:** 1/интенсивность | **Дистанция:** 30 футов/интенсивность |
| **Область:** радиус 5 футов | **Сопротивление:** Н/Д |

Когда это заклинание сотворяется, несколько человек, существ или объектов в области действия заклинания с суммарным РАЗ не более 20 на единицу интенсивности уменьшаются в весе до веса перышка. Находящиеся под влиянием заклинания падают не быстрее, чем 10 футов в раунд (120 футов в минуту), при этом урон от падения не наносится, пока длится действие заклинания. Они настолько легкие, что фактически невосприимчивы к любому отбрасыванию более чем на 5 футов, и не получают урона при столкновении с чем-либо, так как просто медленно отлетают назад.

Сотворение этого заклинания на летающее существо, такое как птица или дракон, изменяет динамику его полета таким образом, что требуются броски «Сложного» полета каждый раунд действия заклинания, если они хотят остаться в воздухе. В случае успеха существо может двигаться по желанию, но только с половиной своей обычной скорости передвижения, в то время как провал броска приводит к тому, что существо беспорядочно кувыркается в случайном направлении на расстояние, равное его предполагаемой скорости передвижения. Если оно просто позволяет себе упасть, летающее существо может использовать крылья, чтобы скорректировать точку приземления на 5 футов за раунд.

Если действие заклинания заканчивается до того, как затронутые им существа приземлились, они возобновляют обычную скорость падения и получают урон от падения с этой точки.

Это позволяет заклинанию защищать от неожиданных падений или даже прерывать действие другого, чтобы замедлить летящие снаряды, такие как стрелы или метательные копья, которые затем мягко опускаются на землю между атакующим и целью, не причиняя урона.

#### Поиск фамильяра

(Призыв)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 2д12 часов |
| **Сфера:** Нет | **Длительность:** Особая |
| **Стоимость:** 3/интенсивность, +1 ОП | **Дистанция:** 0 |
| **Область:** радиус ½ мили/интенсивность | **Сопротивление:** Н/Д |

Это заклинание позволяет заклинателю попытаться призвать фамильяра, который становится продолжением чувств и силы своего хозяина. Фамильяры могут телепатически общаться со своим хозяином и являются хорошими стражами и разведчиками. Гибель собственного фамильяра несет определенные риски для мага из-за их тесной связи, что делает наличие фамильяра опасностью низкого ранга.

Чтобы призвать фамильяра, маг должен начать ритуал, поддерживая жаровню с тлеющим древесным углем, и, когда он разгорится, добавить благовония стоимостью 100 золотых монет. С этими горящими ингредиентами заклинатель должен продолжать ритуал до тех пор, пока фамильяр не прибудет или время сотворения не истечет без успеха.

Даже если заклинание успешно сотворено, шанс того, что подходящий фамильяр ответит на зов мага, составляет всего 50%, и маг может пытаться использовать это заклинание только раз в год. Каждый дополнительный уровень интенсивности сверх первого увеличивает дистанцию заклинания еще на полмили, что, в свою очередь, увеличивает вероятность обнаружения потенциального фамильяра на 5%, максимум до 95%. Нет контроля над точным типом существа, которое ответит на зов, но то, что прибудет, будет верным слугой и союзником. Именно существо решает, отвечать ли на зов, поэтому нахождение в регионе, который, как известно, населен определенным типом существ, _не_ гарантирует заклинателю успеха.

Если существо отвечает на зов заклинателя, маг должен пожертвовать 1 броском опыта, чтобы создать духовную связь между собой и фамильяром. Как только это сделано, ритуал завершен.

Пока фамильяр и его хозяин находятся в пределах 120 футов друг от друга, маг получает возможность использовать и магические очки фамильяра. Кроме того, маг получает телепатическую связь с фамильяром и любые дополнительные особые способности или бонусы к навыкам, указанные в таблицах ниже.

В случае смерти фамильяра заклинатель теряет 5 бросков опыта. Заклинатель, у которого в данный момент нет бросков опыта, должен отказаться от всех дальнейших присуждаемых бросков опыта до тех пор, пока баланс не будет погашен.

#### Огненный щит

(Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** 2 минуты/Интенсивность |
| **Стоимость:** 3+1/доп. Интенсивность | **Дистанция:** 0 |
| **Область:** Заклинатель | **Сопротивление:** Н/Д |

Это заклинание создает щит из призрачного пламени, которое охватывает заклинателя, но само по себе урона не наносит. Напротив, пламя защищает владельца либо от огня, либо от холода, в зависимости от того, какой из двух вариантов был сохранен в памяти: «Ледяной щит», создающий синее или зеленое пламя и защищающий от жара и огненного урона, или «Теплый щит», создающий фиолетовое или синее пламя и защищающий от холода и ледяного урона. Цвет пламени определяется случайным образом (вероятность 50/50), так как оба типа могут испускать синее пламя, что создает элемент неопределенности для любого атакующего. Решение о том, какой вариант запомнить, принимается во время подготовки заклинаний; при желании можно запомнить оба. Это пламя не излучает тепла и дает свет, равный лишь половине яркости факела. Подробности каждого варианта приведены ниже.

- **Ледяной щит:** Это пламя прохладное на ощупь и снижает любой урон от огня или жара вдвое. Успешная проверка Сопротивления полностью отменяет урон. Проверка Сопротивления проходит на одну ступень легче, а в случае с Уклонением не приводит к падению защищающегося ниц.
- **Теплый щит:** Это пламя теплое на ощупь и снижает любой урон от холода вдвое. Успешная проверка Сопротивления полностью отменяет урон. Проверка Сопротивления проходит на одну ступень легче, а в случае с Уклонением не приводит к падению защищающегося ниц.

Атаки ближнего боя по владельцу любого из вариантов, вооруженные или безоружные, наносят обычный урон, если только не используют элементы, против которых действует защита. В таком случае заклинатель защищен от элементальной части атаки, а атакующий получает урон, равный нанесенному. Носимая атакующим броня не дает никакой защиты, но магические Пункты Брони или естественная броня существа снижают урон обычным образом. Существа с Врожденным Магическим Сопротивлением могут развеять «Огненный щит» при успешной проверке МОЩ, если проверка совершена при первом же ударе. Если проверка Магического Сопротивления провалена, противник не сможет развеять «Огненный щит» впоследствии.

#### Превращение плоти в камень \(R\)

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 4 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Постоянно |
| **Стоимость:** 3/Интенсивность | **Дистанция:** 30 футов/Интенсивность |
| **Область:** 1 цель | **Сопротивление:** МОЩ |

При сотворении одна жертва в пределах дистанции совершает проверку Сопротивления МОЩ. В случае неудачи она и все её носимые и переносимые вещи полностью превращаются в твердый камень. Это превращение не является смертью, но представляет собой форму анабиоза. Сотворение обратной версии этого заклинания или «Желания» может быть использовано для возвращения жертвы к жизни. Любой урон, полученный жертвой в каменном состоянии, сохраняется и вступает в силу немедленно после восстановления. Крупные существа (РАЗ 21–40) менее восприимчивы к этому заклинанию — проверка Сопротивления для них Легкая, а для Огромных существ (РАЗ 41+) — Очень Легкая.

Обратная версия заклинания, «Превращение камня в плоть», используется для оживления жертвы, и проверка на сопротивление не требуется. Однако заклинание можно обратить и для превращения камня, который никогда не был живым, используя его одним из нескольких творческих способов. Например, стену из камня размером 10 кубических футов на каждый уровень Интенсивности можно превратить в мягкую плоть; можно создать «туннель» из плоти шириной до 3 футов и длиной 10 футов на каждый пункт Интенсивности; отдельную цель, такую как каменная статуя, можно превратить в тело; и даже каменного голема можно превратить в мясного голема с помощью этого заклинания. В последнем случае каменный голем может совершить проверку МОЩ для сопротивления обычным образом. Превращенный таким образом камень становится мягким и податливым, и, хотя он сохраняет свои фактические Пункты Здоровья, он теряет Пункты Брони, что делает его легче для разрубания.

#### Парящий диск

(Призыв)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** 30 минут/Интенсивность |
| **Стоимость:** 1/Интенсивность | **Дистанция:** 60 футов |
| **Область:** Диск шириной 3 фута | **Сопротивление:** Н/Д |

Маг может сотворить это заклинание, чтобы создать мерцающий диск силы в форме круга диаметром 3 фута и использовать его для переноски незакрепленных, мелких предметов. Этот парящий диск всегда остается на высоте 3 футов над землей и может перевозить любое количество груза, если он не превышает 20 «единиц» на каждый пункт Интенсивности и помещается на диске. Для сравнения: примите, что 1 РАЗ равен 3 «единицам»; таким образом, диск может нести чуть более 6 РАЗ на каждый пункт Интенсивности. Вогнутая форма диска обычно удерживает предметы от скатывания, и если диск оставить без присмотра, он будет держаться в пределах 5 футов от заклинателя, следуя за ним со скоростью перемещения 15 футов. Однако диском можно управлять в любой точке в пределах области действия заклинания в 60 футов, если маг концентрируется, или даже заставить его оставаться на месте. Если маг позволит диску удалиться более чем на 60 футов, диск исчезнет, уронив все переносимые предметы на землю. Диск нельзя заставить подняться выше 3 футов над землей.

#### Свобода действий

(Ограждение, Очарование)

| | |

При сотворении это заклинание позволяет субъекту действовать нормально в течение всей длительности, независимо от других заклинаний или эффектов, которые затрудняют движение или штрафуют атаки. #### Обморожение

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 0 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 1 | **Дистанция:** 60 футов |
| **Область:** 1 цель | **Сопротивление:** ТЕЛ |

«Обморожение» действует непосредственно на живые органические ткани, вызывая онемение и боль в одной из конечностей жертвы, например, пальцах рук, пальцах ног, ягодицах, носу, ушах и т. д. Заклинатель должен либо коснуться конкретной конечности, либо выбросить случайную, если заклинание применяется на дистанции. Если заклинание не было отражено, пораженная область испытывает сенсорное онемение, сопровождающееся ноющей болью в течение длительности, что делает проверки навыков, использующие эту локацию, на одну ступень сложности выше. «Обморожение» не наносит прямого урона, но делает пораженную область ограниченно пригодной к использованию на некоторое время. Например, жертва, страдающая от обморожения ягодиц, не может сидеть без крайнего дискомфорта.

Крупные существа (РАЗ 21–40) менее восприимчивы к этому заклинанию — проверка Сопротивления для них Легкая, а для Огромных существ (РАЗ 41+) — Очень Легкая.

#### Неуклюжесть

(Очарование (Обаяние))

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** 1 раунд/Интенсивность |
| **Стоимость:** 3+1/доп. Интенсивность | **Дистанция:** 30 футов/Интенсивность |
| **Область:** Радиус 10 футов | **Сопротивление:** МОЩ |

Это заклинание заставляет всех противников в области поражения стать неуклюжими: любые проверки физических навыков становятся на одну ступень сложнее, а любая неудача приводит к промаху (Fumble). Даже физические действия, которые обычно не требуют проверки навыков, такие как поднятие уроненного предмета, передвижение быстрее шага или подъем по лестнице, требуют проверки навыка «Атлетика». Провал в этом случае приводит к «Неуклюжести», а при передвижении — как правило, к нелепому падению или случайному отфутболиванию предмета дальше в сторону при попытке его поднять. Мастер игры должен творчески подходить к результатам проваленных бросков; однако немногие из них должны быть смертельными во внебоевых ситуациях. В бою же «Неуклюжесть» рассматривается как любая другая и может привести к спецэффектам обычным образом.

Успешная проверка Сопротивления позволяет жертве избежать эффектов заклинания на текущий раунд; однако, если в следующем раунде жертва все еще остается в области действия, проверку Сопротивления нужно будет совершить снова. Союзникам исходного атакующего также придется держаться подальше от области поражения, иначе они разделят ту же участь, что и противники.

Это заклинание также может быть направлено на конкретное существо, которое будет страдать от эффектов в течение всей длительности заклинания в случае провала проверки Сопротивления. При сотворении таким образом «Неуклюжесть» не создает области поражения. В этом случае успех при проверке Сопротивления приводит к тому, что жертва страдает от эффектов заклинания 2-го ранга «Замедление».

#### Врата

(Призыв)

| | |
| :-- | :-- |
| **Ранг:** Жрец 5, Маг 5 | **Время сотворения:** 2 раунда |
| **Сфера:** Вызов | **Длительность:** См. ниже |
| **Стоимость:** 3 + 1/Интенсивность, + 3 ОП | **Дистанция:** 100 футов |
| **Область:** См. ниже | **Сопротивление:** МОЩ |

Сотворение «Врат» требует, чтобы заклинатель знал истинное имя призываемой сущности, которая обычно является существом с другого плана бытия, таким как демон, дьявол, ангел, полубог или даже бог. При успешном сотворении открывается портал между планом заклинателя и планом сущности. Сотворение заклинания автоматически привлекает внимание сущности, независимо от того, было оно успешным или нет. Это заклинание чрезвычайно мощное и изматывающее: оно стоит заклинателю не только указанных 3 Магических пунктов и 3 Бросков Опыта, но и состаривает его на 5% от его типичной продолжительности жизни (5 лет в случае заклинателя-человека). Если сущность успешно проходит проверку Сопротивления, она, как правило, не утруждает себя личным явлением, однако, при успешном заклинании, через портал «что-то» пройдет. Следующая таблица используется для определения некоторых распространенных сущностей, их средних показателей МОЩ и типичных слуг, которые будут посланы вместо них. Мастер игры волен выбирать сущность так, как это лучше всего соответствует характеру текущей кампании.

| 1 | 3 | Суб-демон или Суб-дьявол | Согласно конкретной сущности |

Форма ответа будет сильно зависеть от конкретной сущности, Мировоззрения обеих сторон и специфики запроса. Если сущность сочтет причины прерывания пустяковыми или несущественными, ее ответом может быть что угодно: от простого ухода до прямой атаки. Однако на отчаянную ситуацию, особенно если заклинателю угрожает нечто, чему сущность решительно противостоит, скорее всего, последует более благоприятный ответ. Если Мастер игры чувствует, что вопрос спорный, заклинатель и его союзники могут попытаться аргументировать свою позицию, используя комбинацию навыков, лести, мольбы и/или подкупа. Тем не менее, большинство сущностей будут избегать втягивания в конфликт с другими сущностями равной или большей силы, и многие потребуют плату — до или после выполнения дела. Врата будут оставаться открытыми столько, сколько сущность пожелает оставаться на этой стороне, и закроются за ней, когда она решит уйти. В течение этого времени через врата могут пройти другие, что обеспечивает двухстороннее перемещение между реальностями.

«Очарование» делает цель притягательной, так что люди начинают испытывать к ней естественную симпатию. Характер очарования должен быть выбран при сотворении: это может быть что угодно, от усиления природной красоты и мягкого, бархатного голоса до соблазнительного парфюмерного аромата тела. Хотя заклинание не дает никаких механических преимуществ, оно гарантирует, что владелец получит шанс собрать аудиторию, привлечь внимание того, с кем хочет связаться, или обеспечить отвлекающий маневр, дающий сообщникам возможность совершить коварные дела.

При обращении, «Отвращение» искажает облик цели так, что она вызывает неприязнь у всех, кто ее видит, слышит или чувствует запах. Эффект должен быть выбран при сотворении: это может быть что угодно, от огромной бородавки на кончике носа и пронзительного гнусавого голоса до едкого запаха тела. Что бы ни было выбрано, это заставит людей отворачиваться от жертвы или придумывать оправдания, чтобы поскорее покинуть её присутствие.

#### Исцеление \(О\)

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Клирик 4 | **Время сотворения:** 1 минута |
| **Сфера:** Исцеление | **Длительность:** Постоянно |
| **Стоимость:** 3 + 1 за интенсивность | **Дистанция:** Касание |
| **Область:** 1 существо | **Сопротивление:** Н/Д (Телосложение или Уклонение) |

С помощью «Исцеления» клирик может вылечить физический недуг, ментальную травму или значительное количество повреждений одним прикосновением. Фактическая степень восстановления основана на интенсивности заклинания следующим образом. За каждый уровень интенсивности заклинание исцеляет субъекта от одной болезни любого ПОТ, излечивает любую слепоту или глухоту, устраняет ментальное расстройство, вызванное травмой или магией, или исцеляет одну Часть тела, восстанавливая до 12 пунктов повреждений. Однако оно не восстановит отсеченную конечность, так как для этого требуется сотворение заклинания «Регенерация». Каждую дополнительную интенсивность можно использовать для лечения еще одного недуга или исцеления еще одной Части тела. Таким образом, для исцеления человека, страдающего от ожогов всего тела, потребуется сотворение с интенсивностью 7. В отличие от низших исцеляющих заклинаний, эффективность которых ограничена при долгосрочных травмах, на это заклинание не накладываются ограничения по длительности периода, в течение которого субъект страдал от последствий травмы.

При обращении «Вред» наносит 12 пунктов магических повреждений одной из Частей тела жертвы в случае провала броска на сопротивление. Альтернативно, на жертву накладывается недуг, эффект которого совпадает с заклинанием «Навлечь болезнь», обратным заклинанию «Излечить болезнь», но с модификатором +20 к ПОТ. Бросок «Канала» заклинателя функционирует как бросок на попадание по оппоненту и считается частью соматических требований заклинания. Дополнительный бросок на попадание не требуется. Ни носимая, ни естественная броня не обеспечивают никакой защиты, но магические Пункты брони уменьшают урон обычным образом и полностью блокируют наложенные недуги. (Дивинация)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 1 минута |

С сотворением этого заклинания магический пользователь может попытаться определить магические свойства (если таковые имеются) одного предмета, который он держит в руках. Простого прикосновения к предмету обычно недостаточно; предмет должен быть надет или удерживаться в соответствии с его назначением, например, шлем должен быть надет на голову, амулет надет на шею, оружие ближнего боя крепко сжато в руке, кольцо надето на палец и так далее. Предметы с зарядами покажут общее количество доступных зарядов вместе с нормальным максимумом, так же как и предметы, обладающие матрицей Магических очков.

Проклятые предметы обычно активируются при первом надевании или использовании элемента экипировки; поэтому сотворение этого заклинания подвергнет магического пользователя эффектам любого проклятия, если оно присутствует. Если тест навыка Арканного сотворения успешен, магическому пользователю разрешается тест на Силу воли, чтобы избежать эффектов любого проклятия. Это не рассеивает проклятие на объекте, однако позволяет заклинателю снять предмет, не подвергаясь его воздействию.

Жемчужина стоимостью не менее 100 ЗМ растирается в пыль и потребляется вместе с другими обычными компонентами заклинания для его сотворения. Если в настой добавить растертый Камень удачи, сложность броска Арканного сотворения будет нормальной, и все магические свойства любого одного предмета, удерживаемого в течение каждой минуты на протяжении всей длительности заклинания, автоматически узнаются, и никаких дальнейших бросков не требуется.

Многие из ранее упомянутых действий могут позволить другие способы обнаружения, такие как возможная проверка Восприятия, чтобы услышать, как кто-то пробегает мимо, или почувствовать, что из кармана крадут. #### Магическая стрела

(Эвокация)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 1/Интенсивность | **Дистанция:** 100 футов/Интенсивность |
| **Область:** 1-5 целей | **Сопротивление:** См. ниже |

При сотворении этого заклинания один или несколько снарядов магической энергии вылетают с кончиков пальцев мага и поражают цель. Максимальное количество снарядов зависит от уровня навыка «Магическое сотворение» заклинателя: второй снаряд появляется на 60% навыка, третий на 70%, четвертый на 80%, пятый и последний на 90%. Чтобы сгенерировать эти снаряды, заклинание должно быть сотворено с Интенсивностью, равной количеству желаемых снарядов. Например, при уровне ниже 60% маг, сотворивший «Магическую стрелу» с 3 Интенсивностью, получит увеличенную дистанцию, однако будет сгенерирован только один снаряд. Маг с навыком 70% мог бы сотворить то же заклинание с 3 Интенсивностью, получить ту же дистанцию и выпустить 3 снаряда. Максимальная Интенсивность этого заклинания — 5. См. таблицу ниже.

«Магическая стрела» попадает безошибочно, даже если цель находится в ближнем бою или имеет частичное укрытие. От этих снарядов нельзя уклониться; однако противник с полным укрытием не может стать целью этого заклинания. Заклинание «Щит» автоматически отразит «Магические стрелы», если цель знает об этом и/или повернута лицом к заклинателю. «Магические стрелы» наносят 1d6+1 очков урона, и носимая броня не защищает от них, но естественная броня или магические очки брони уменьшают урон как обычно. «Магические стрелы» не наносят урона неодушевленным предметам, таким как двери, замки и т. д.

При стрельбе несколькими стрелами заклинатель может направить их в одну цель или в разных существ. Каждая «Магическая стрела» попадает в случайную часть тела — целиться в конкретные части нельзя. Заклинатель должен назначить цели каждой стрелы перед броском на урон.

| :-: | :-: | :-- |
| 1 | 1 | дистанция 100 футов; 1 снаряд |
| 2 | 2 | дистанция 200 футов; 2 снаряда при навыке 60% |
| 3 | 3 | дистанция 300 футов; 3 снаряда при навыке 70% |
| 4 | 4 | дистанция 400 футов; 4 снаряда при навыке 80% |
| 5 макс. | 5 | дистанция 500 футов; 5 снарядов при навыке 90% |

#### Магические уста

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 2 | **Время сотворения:** 1 минута |
| **Сфера:** Нет | **Длительность:** См. ниже |
| **Стоимость:** 3, +1/доп. Интенсивность | **Дистанция:** 30 футов |
| **Область:** 1 объект | **Сопротивление:** Нет |

Это заклинание создает рот на предмете или объекте, который магически появляется, когда срабатывает триггер — определенное событие или время, назначенное магом при сотворении. Этот рот затем произносит заранее определенную фразу, выбранную заклинателем в момент сотворения. Фраза должна состоять не более чем из 25 слов и произносится ртом со скоростью примерно 1 слово в секунду. Рот не может произносить слова силы или творить заклинания.

Заклинание можно наложить на любой обычно неодушевленный объект — от колонны или дерева до каменной стены или сундука; однако оно особенно эффективно на статуях, так как будет казаться, что говорит сама статуя. Его нельзя наложить на любое живое существо, обладающее хоть каким-то Интеллектом или Инстинктами. Это относится и к тем, кто был жив ранее. При сотворении заклинатель определяет ситуацию, которая активирует чары. Это может быть что угодно: от произнесенного слова до появления любого шума. Это может быть как общее условие («когда следующий человек войдет в эту комнату…»), так и специфическое («когда клирик-женщина Седоны подойдет на 10 футов к статуе в конце зала в субботу…»). Триггер не может зависеть от того, что нельзя определить без магии, например, невидимое существо, мировоззрение существа, навык, класс и т. д. Однако можно указать тип носимой одежды. Максимальное расстояние для срабатывания заклинания — 25 футов за единицу Интенсивности.

Длительность заклинания постоянна до тех пор, пока чары не будут активированы, после чего заклинание заканчивается.

(Колдовство)

Фокусы — отличная форма развлечения среди простого люда, угнетенных и особенно детей. Некоторые эффекты, обычно создаваемые с помощью фокусов: порывы ветра, чтобы задуть свечи; извлечение серебряной монеты из-за уха ребенка; быстрое распускание цветка; карточные фокусы; создание жуткой неземной музыки, доносящейся из ниоткуда, и так далее. Фокусы не способны нанести ни единого очка урона или вызвать хоть сколько-нибудь значимое отвлечение в бою, но могут быть использованы, чтобы занять толпу, пока остальная группа прокрадывается мимо.

#### Метеоритный дождь

(Эвокация)

| | |
| :-- | :-- |
| **Ранг:** Маг 5 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Мгновенно |
| **Стоимость:** 3/Интенсивность | **Дистанция:** 20 футов/Интенсивность |
| **Область:** См. ниже | **Сопротивление:** Уклонение |

Когда маг творит это заклинание, два микрометеорита на каждую единицу Интенсивности срываются с вытянутой руки. Метеориты летят по дуге к цели, падая по нисходящей траектории и оставляя за собой шлейф искр и пепла. При ударе они детонируют множественными огненными взрывами вокруг целевой точки. Первый метеорит всегда попадает в назначенное место, в то время как любые дополнительные метеориты падают случайным образом вокруг него, каждый с радиусом взрыва 30 футов. Чтобы определить, куда они попадут, бросьте 1d8 для направления.

<div style="text-align: center;">
    <img src="_media/CFI_10_Meteor_Shower_Grid.png" style="width: 25%;" />
</div>

Каждый метеорит наносит 1d10 очков урона огнем тем, кто находится в области действия. Однако из-за радиуса каждого взрыва многие из них будут перекрываться, нанося дополнительный урон тем, кому не посчастливилось попасть в эпицентр. Броски урона суммируются и применяются к каждой пораженной части тела цели. Носимая броня не дает защиты, но магические очки брони или естественная броня существа уменьшают урон как обычно.

Успешная проверка Уклонения позволяет жертве избежать урона. Кто-то с талантом «Ловкач» может уклониться, не падая ниц, но успех в этом случае снизит урон только наполовину, если только они не находятся в пределах 5 футов от края области действия.

Все, включая тех, кто находится вне области действия, но в пределах 60 футов от точки удара, обязаны преуспеть в проверке Атлетики, чтобы устоять на ногах.

«Метеоритный дождь» имеет шанс воспламенить легковоспламеняющиеся материалы, равный брошенному урону x5%. См. раздел [Огонь](0007_Game_System.md?id=fire-based-attacks) для дополнительной информации.

(Иллюзия)

| | |
| :-- | :-- |
| **Ранг:** Маг 2 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** 3 раунда/Интенсивность |
| **Стоимость:** 1/Интенсивность | **Дистанция:** 0 |
| **Область:** Радиус 5 футов | **Сопротивление:** Нет |

Когда это заклинание сотворено, в радиусе 5 футов появляются 2d4 копии мага, точно имитирующие движения заклинателя. В дополнение к этому, вся область действия колеблется и мерцает, делая невозможным определение точного местоположения заклинателя. Удар по одному из иллюзорных изображений заставляет его исчезнуть; однако остальные изображения остаются незатронутыми. Удар по заклинателю не влияет на оставшиеся изображения, и, поскольку изображения постоянно смещаются, невозможно узнать, является ли цель настоящим магом, если атака повторится. Любые ранения, полученные заклинателем, дублируются и на изображениях. Существует множество способов, которыми Мастер игры может определить, был ли поражен настоящий заклинатель или одно из изображений. Один из них — определить, сколько потенциальных целей доступно, включая заклинателя, и бросить кубик ближайшего номинала. Например, с 4 изображениями и заклинателем атакующий должен бросить 1d6, перебрасывая результат 6, где заклинатель будет поражен при выпадении 1. Другой способ — иметь несколько маркеров, равных числу потенциальных целей, пометив один как заклинателя. Маркер вытягивается каждый раз, когда совершается атака, и если цель поражена, применяется урон; в противном случае изображение исчезает, убирая один из маркеров. Точная точка прибытия редко бывает той, которую желает заклинатель. Если используется карта с гексами, бросьте 1d6, чтобы определить направление, и 1d10x10 для расстояния в милях.

В дополнение к любым обычным материальным компонентам, для сотворения «Сдвига планов» требуются жезлы из различных редких металлов, каждый из которых специально настроен на план бытия. Эти жезлы редки и легко оцениваются в 10 000 золотых монет каждый.

#### Полиморф (другого)

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Маг 3 | **Время сотворения:** 2 действия |
| **Сфера:** Нет | **Длительность:** Постоянно |
| **Стоимость:** 3, +1 за каждый дополнительный уровень интенсивности (+1 ОП) | **Дистанция:** 15 футов/уровень интенсивности |
| **Область:** 1 цель | **Сопротивление:** Мощь (МОЩ) |

Заклинатель может изменить форму одного телесного целевого существа на форму другого, при этом каждый пункт интенсивности изменяет РАЗ (РАЗ) на величину до 5 пунктов. Таким образом, превращение орка с РАЗ 16 в кролика с РАЗ 1 потребует 3 уровней интенсивности (15 пунктов РАЗ разницы). Субъекту этого заклинания разрешается проверка Мощи (МОЩ) для сопротивления. Крупные существа (РАЗ 21-40) менее восприимчивы к полиморфу, их проверка сопротивления является «Легкой», в то время как проверка сопротивления для Огромных существ (РАЗ 41+) — «Очень легкой».

Весь процесс трансформации занимает полный раунд и может быть весьма стрессовым для данного существа, требуя второй проверки Мощи (МОЩ), чтобы сохранить свою исходную личность, при провале субъект оглушается на 1d10 минут, а при критическом провале наступает смерть от ментального шока. Каждое удвоение или уменьшение вдвое исходного РАЗ (РАЗ) существа делает проверку Мощи (МОЩ) для сохранения личности на один уровень сложнее, как и полная смена среды обитания, например, превращение человека в рыбу. Успешная проверка позволяет жертве сохранить свой ИНТ (ИНТ) и ХАР (ХАР), а также любые навыки, требующие этих характеристик.

Трансформация дает получателю форму дыхания предполагаемого существа, если оно отличается от нормального; любые естественные атаки; и все обычные способы передвижения. Она не дает никаких повышенных или магических способностей, которыми обладает существо. Например, существо, которое было полиморфно в дракона, не получит дыхательную атаку существа или заклинательные способности, но получит способность летать, его жесткую шкуру, смертельный укус, атаки когтями и так далее. Кроме того, жертва получает физические навыки новой формы, такие как Атлетика, Брак, Полет, Плавание, а также ее хиты и модификатор урона. Предполагая, что трансформированный человек сохранил свой ИНТ (ИНТ), он все равно теряет способность говорить, если новая форма не обладает способностью членораздельно произносить слова. Те, кто был способен творить заклинания в своей предыдущей форме, по-прежнему смогут творить заклинания в новой форме, если они все еще обладают способностью воспроизводить вербальные и соматические компоненты. В случае радикального изменения, например, при превращении из двуногого в четвероногого или из наземного животного в морское существо, Мастер игры должен свободно назначать штраф как минимум на один уровень сложности при использовании любых навыков, на обучение которым потребовалось бы время, пока не пройдет достаточно времени для практики при адаптации к новой форме. Это особенно верно для физических навыков, таких как Атлетика, Рукопашный бой, Плавание, Полет, Боевые навыки и так далее.

Проверка Мощи (МОЩ) для сохранения личности требуется каждый день, пока субъект остается трансформированным, до тех пор, пока она не будет провалена, что приведет к тому, что человек окончательно поддастся менталитету новой формы, при этом ИНТ (ИНТ) изменится на ИНТ (соответствующее неразумному существу). Все особые и магические способности, принадлежащие новой форме, которые не были приобретены ранее, такие как атаки взглядом, дыхательное оружие и так далее, теперь доступны существу по завершении трансформации. Персонажи, которые теряют свою идентичность таким образом, становятся неигровыми персонажами под контролем Мастера игры.

До того, как ментально поддаться трансформации, полиморфное существо восприимчиво к «Рассеиванию магии» как обычно, без необходимости проверки на сопротивление, так как это подсознательное желание вернуться к нормальному состоянию. Трансформация требует еще одной проверки Мощи (МОЩ), чтобы противостоять напряжению, при провале субъект оглушается на 1d10 минут, а критический провал приводит к смерти от ментального шока.

Если жертва ранее поддалась новой форме, «Рассеивание магии» все еще может быть использовано; однако жертва будет пытаться сопротивляться возвращению в естественную форму с помощью проверки Мощи (МОЩ). Провал этой проверки означает, что жертва трансформируется обратно в естественную форму, что, конечно, требует еще одной проверки Мощи (МОЩ), чтобы сопротивляться ментальному шоку от трансформации. Как только естественная идентичность жертвы утрачена, она больше недостижима, вместо этого жертва предполагает, что странная и чуждая форма является нормальной, и жаждет вернуться в свое предыдущее «нормальное» состояние. _Например, орк, который был превращен в кролика и принял идентичность существа, будет считать, что он теперь кролик, которого довольно грубо превратили в орка._ Только «Желание» или другая подобная магия имеют хоть какой-то шанс восстановить идентичность жертвы после того, как она была утрачена.

Вся носимая и переносимая экипировка магически сливается с новой формой; однако в некоторых случаях Мастер игры может позволить остаться магическим предметам, которые все еще могут быть использованы в новой форме существа, таким как магическое кольцо или сапоги. Обратите внимание, что для этого требуется, чтобы новый РАЗ (РАЗ) существа не сильно отличался от исходного. Существует шанс МОЩ (МОЩ) x1% для каждого надетых магического предмета неагрессивного характера, при условии одобрения Мастера игры, передать свои эффекты новой форме существа. Существо с кольцом защиты +1, например, может получить бонус +1 к своим естественным очкам брони. Существа с естественной способностью к изменению формы, такие как доппельгангеры и ликантропы, будут трансформированы как обычно, но могут принять свою нормальную форму через 1 раунд. Если существо убито, полиморфное существо возвращается в свою естественную форму, даже если оно ранее потеряло все следы идентичности.

При сотворении от получателя заклинания (которым может быть и сам заклинатель) начинает исходить невидимая аура магического доспеха, дарующая три уровня защиты.

Во-первых, атаки существ со злым Мировоззрением получают штраф -10% к их боевому стилю или навыку безоружного боя. Проверки Сопротивления со стороны получателя «Защиты от зла» получают бонус +10%, но только против злых существ.

Обратное заклинание, «Защита от добра», работает так же в отношении второго и третьего эффектов, в то время как первый эффект действует аналогично указанному, но в отношении добрых оппонентов.

#### Воскрешение (О)

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Жрец 3 | **Время сотворения:** 1 минута |
| **Сфера:** Некромантия | **Длительность:** Постоянно |
| **Стоимость:** 3, +1 за доп. Интенсивность, +1 Опыт | **Дистанция:** 100 футов |
| **Зона:** 1 цель | **Сопротивление:** Нет (Сила воли) |

Это заклинание может быть наложено на труп существа, умершего не более 24 часов назад на уровень Интенсивности. Если Мировоззрение субъекта было любым, кроме злого, он может сопротивляться заклинанию с помощью встречной проверки Силы воли и, в случае успеха, аннулировать эффекты заклинания. Это происходит потому, что душа или дух умершего редко желают возвращаться к жизни, достигнув своей вечной награды. Мастер игры может принять решение отменить проверку, если у получателя остались незавершенные дела, если он не может разлучиться со своей истинной любовью или если у него есть иная героическая причина жить.

В случае со злыми душами, которые с радостью вернулись бы на материальный план вместо того, чтобы страдать в вечном проклятии, сопротивляется не Сила воли умершего, а Сила воли демона, дьявола и так далее, поставленного следить за их наказанием, их мучителя. В этом случае заклинатель должен преодолеть Силу воли мучителя. Если она неизвестна, считайте, что она как минимум на 20 пунктов выше, чем у умершего, чтобы показать, что чем сильнее воля души, тем могущественнее существо, поставленное во главе их проклятия. Если заклинатель преуспевает, он успешно возвращает дух в тело, в то время как проваленная проверка означает, что жертва либо не желает, либо не способна вернуться.

Если сотворение успешно, субъект возвращается к жизни с полным здоровьем, хотя потерянные конечности остаются утраченными. Это означает, что обезглавленную или разрубленную пополам жертву нельзя воскресить, пока голова или туловище не будут предварительно присоединены. Это можно сделать до сотворения «Воскрешения», физически прикрепив отсеченную часть, что требует набора лекаря и успешного применения навыка «Лечение», и обычно оставляет заметный и говорящий шрам. Другие недуги, такие как яд или болезнь, должны быть вылечены до или после сотворения «Воскрешения», иначе результаты будут лишь временными. Наконец, «Воскрешение» не оказывает эффекта на существо, достигшее конца своего естественного срока жизни и умершее от старости.

Акт воскрешения из мертвых очень утомителен для субъекта, который переходит на уровень Усталости «Недееспособный» на период 24 часов за каждый день, проведенный в смерти. Сотворение «Исцеления усталости» не оказывает эффекта на пациента в это время выздоровления. По прошествии этого времени персонаж восстанавливается от усталости нормально и без ограничений.

Обратное заклинание, «Смертоубийство», может быть использовано, чтобы убить одну жертву, указанную жрецом в момент сотворения. Этой жертве разрешается бросок Силы воли для сопротивления, модифицированный Рангом или РАЗ цели (в зависимости от того, что дает более выгодный для цели результат), как подробно описано в следующей таблице.

| Ранг цели | РАЗ цели | Модификатор Силы воли |
| :-: | :-: | :-: |
| 0-1* | 1-20 | Сложно |
| 2 | 21-40 | Стандартно |
| 3 | 41-60 | Легко |
| 4-5 | 61+ | Очень легко |

* Эта категория включает персонажей, у которых нет Класса.

Если проверка Сопротивления неудачна, жертва погибает на месте. Успешная проверка трактуется в соответствии с эффектами заклинания «Нанесение серьезных ран». Доспехи не дают защиты от этого урона.

#### Чтение магии

(Все)

| | |
| :-- | :-- |

Это первое заклинание, которому обучают начинающих магических пользователей, ибо именно через него они могут читать магические письмена другого заклинателя. #### Регенерация (О)

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Жрец 4 | **Время сотворения:** 3 минуты |
| **Сфера:** Исцеление | **Длительность:** Постоянно |
| **Стоимость:** 3/Интенсивность | **Дистанция:** Касание |
| **Зона:** 1 существо | **Сопротивление:** Нет (Парирование или Уклонение) |

При сотворении жрец может коснуться одного существа и регенерировать утраченную часть тела (Хит-локацию). Потерянные конечности полностью отрастают со скоростью 1 Очко здоровья каждые 10 минут, пока не заживут полностью. Однако, если отсеченная часть присутствует и касается жертвы, все время восстановления сокращается до 1 минуты. Это заклинание нельзя использовать для «клонирования» индивида путем регенерации двух отдельных частей — эффекты заклинания получает только та часть, которая соединена с мозгом и центральной нервной системой. Каждый уровень Интенсивности отращивает одну отдельную Хит-локацию. Хотя заклинание можно использовать для медленного заживления менее серьезных травм, для этого существуют заклинания более низкого Ранга и меньшей стоимости.

Обратное заклинание, «Увядание», заставляет часть тела, которой коснулся заклинатель, сморщиться и в конечном итоге отпасть от жертвы. Процесс вызывает потерю 1 Очка здоровья у пораженной части каждые 10 минут; часть становится непригодной к использованию при 0 ОЗ и отпадает, когда накопленный урон становится полностью отрицательным. Эффекты могут быть отменены только сотворением «Регенерации».

Если Мировоззрение жертвы было любым, кроме злого, жертва сопротивляется заклинанию с помощью встречной проверки Силы воли и, в случае успеха, аннулирует эффекты заклинания. Это происходит потому, что душа или дух умершего редко желают входить в новое тело, достигнув своей вечной награды. Мастер игры может принять решение отменить проверку, если у получателя остались незавершенные дела, если он не может разлучиться со своей истинной любовью или если у него есть иная героическая причина жить.

В случае со злыми душами, которые с радостью вернулись бы на материальный план вместо того, чтобы страдать в вечном проклятии, сопротивляется не Сила воли умершего, а Сила воли демона, дьявола и так далее, поставленного следить за их наказанием, их мучителя. В этом случае заклинатель должен преодолеть Силу воли мучителя. Если она неизвестна, считайте, что она как минимум на 20 пунктов выше, чем у умершего, чтобы показать, что чем сильнее воля души, тем могущественнее существо, поставленное во главе их проклятия. Если заклинатель преуспевает, он успешно закрепляет дух в носителе, в то время как проваленная проверка означает, что жертва либо не желает, либо не способна вернуться.

Если сотворение успешно, через 1к6х10 минут появляется полностью сформированное взрослое тело, содержащее сознание умершего. Заклинатель не контролирует форму или пол, в котором возвращается душа — бросьте кости по таблице ниже. Прежний Класс и Ранг персонажа сохраняются. Это означает, что персонажу может потребоваться приложить усилия, чтобы убедить друзей, семью и бывших знакомых в том, что он тот, за кого себя выдает; это касается и их ордена или гильдии, когда придет время для Продвижения (если применимо). Лучше всего это отражается проверками Влияния со стороны персонажа, модифицированными в зависимости от того, насколько радикальны изменения, что определяется Мастером игры. Например, дворфу, переродившемуся в другого дворфа, может потребоваться стандартная проверка Влияния, чтобы убедить бывшего союзника в своей личности, в то время как перерождение в гнома или полурослика может сделать проверку на одну степень сложнее. Наконец, тому же персонажу может быть в две степени сложнее убедить других в своей личности, если он превратился в нечто столь экстремальное, как гоблин, орк или тролль.

Все Характеристики определяются случайным образом в соответствии с новой формой, за исключением ИНТ, МОЩ и ХАР, которые остаются неизменными. Пересчитайте Базовые уровни навыков персонажа и соответствующим образом скорректируйте итоговые значения навыков. Страсти остаются без изменений. Любые прежние расовые Способности теряются и заменяются способностями нового вида. Если новая форма не подходит для старого Класса персонажа, единственный вариант — смириться с этим или выучить новый Класс. Перерожденный индивид помнит большую часть своей прежней жизни, хотя Мастер игры может потребовать от персонажа сделать проверку Силы воли, чтобы вспомнить важные факты в течение первой недели. «Желание» может вернуть перерожденного индивида в прежнюю форму, если позже возникнет такое желание.

#### Восстановление

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Жрец 3 | **Время сотворения:** 3 минуты |
| **Сфера:** Исцеление | **Длительность:** Постоянная |
| **Стоимость:** 3, +1 за каждый дополнительный уровень Интенсивности | **Дистанция:** Касание |
| **Область:** 1 цель | **Сопротивление:** Н/Д |

При сотворении жертва, ранее лишенная жизненной силы с помощью «Высасывания энергии» или подобных эффектов, восстанавливает один потерянный ранее уровень Усталости. На 1-м уровне Интенсивности это заклинание работает только на существо, истощенное в течение последних 24 часов. Каждый дополнительный уровень Интенсивности увеличивает допустимый прошедший промежуток времени еще на 24 часа. Например, чтобы помочь жертве, истощенной чуть менее 48 часов назад, заклинание нужно сотворить с Интенсивностью 2. Независимо от длительности и в дополнение к любой восстановленной Усталости, это заклинание также восстанавливает все ментальные способности, утраченные из-за магии или любой формы безумия или слабоумия. «Восстановление» также можно использовать для устранения лет, потерянных из-за искусственного старения, вызванного, например, некоторыми заклинаниями. Чтобы сотворить заклинание таким образом, в дополнение к обычной стоимости, жрец должен потратить 1 Бросок ОП за каждый 1% типичного срока жизни получателя, который нужно восстановить (1 год для человека). Заклинание не может снизить текущий возраст субъекта ниже его фактического возраста.

#### Воскрешение (С)

(Некромантия)

| | |
| :-- | :-- |
| **Ранг:** Жрец 5 | **Время сотворения:** 10 минут |
| **Сфера:** Некромантическая | **Длительность:** Постоянная |
| **Стоимость:** 3, +1 за каждый дополнительный уровень Интенсивности, +2 ОП | **Дистанция:** Касание |
| **Область:** 1 цель | **Сопротивление:** Н/Д (Воля) |

«Воскрешение» возвращает к жизни любое существо, мертвое не более 20 лет за каждый уровень Интенсивности. Существо не просто оживляется, но восстанавливается до полной силы и исцеляется от травм, включая возвращение утраченных конечностей. Для эффективности заклинания требуется лишь малая часть останков существа. Например, «Воскрешение» можно использовать, чтобы вернуть существо к жизни через 145 лет, даже если от него осталась лишь кость пальца, при условии, что заклинание сотворено с Интенсивностью 8. Воскрешенному не требуется отдых, и он полностью функционален немедленно. Заклинание не действует на существо, умершее естественной смертью по истечении отведенного ему срока жизни.

Если мировоззрение субъекта было любым, кроме злого, он может сопротивляться заклинанию с помощью противопоставленной проверки Воли и, в случае успеха, аннулировать эффекты. Это происходит потому, что душа или дух умершего редко желает возвращаться к жизни, достигнув вечной награды. Однако Мастер игры может решить отменить проверку, если у получателя остались незавершенные дела, он не может быть разлучен с истинной любовью или имеет другую героическую причину жить. В случае со злыми душами, которые с радостью вернулись бы вместо страданий в вечном проклятии, сопротивляется не Воля умершего, а воля демона, дьявола и тому подобных существ, назначенных ответственными за их наказание — их мучителя. В этом случае заклинатель должен преодолеть Волю мучителя. Если она неизвестна, считайте, что она как минимум на 20 пунктов выше, чем у умершего, чтобы показать, что чем сильнее воля души, тем могущественнее существо, поставленное во главе его или ее проклятия. Если заклинатель преуспевает, субъект успешно воскрешен, в то время как проваленная проверка приводит к тому, что жертва либо не желает, либо не может вернуться.

«Воскрешение» очень сильно истощает силы, состаривая жреца на 3% от его типичного срока жизни (3 года в случае заклинателя-человека). См. правила для [Старения](0007_Game_System.md?id=aging).

Обратный вариант, «Разрушение», может быть использован, чтобы убить одну жертву, контактирующую с жрецом во время сотворения. Эта жертва имеет право на проверку Воли для сопротивления, модифицированную Рангом или РАЗ цели (в зависимости от того, что дает жертве более выгодный результат), как подробно описано в следующей таблице.

| Ранг цели | РАЗ цели | Модификатор Воли |
| :-: | :-: | :-- |
| 0-1\* | 1-20 | Грозный |
| 2 | 21-40 | Сложный |
| 3 | 41-60 | Стандартный |
| 4 | 61-80 | Легкий |
| 5 | 81+ | Очень легкий |

_\* Эта категория включает персонажей, у которых нет класса._

Если эта проверка Сопротивления безуспешна, субъект убивается мгновенно, а его тело рассыпается в прах. Только сотворение «Желания» вернет жертву на этой стадии. При успешной проверке субъект все равно получает отрицательные 1d4 хитов в затронутую локацию тела. Доспехи не дают защиты от этого урона. «Разрушение» не состаривает заклинателя при использовании.

#### Щит

(Эвокация)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** 5 раундов/Интенсивность |

«Щит» создает невидимый подвижный диск силы, который парит перед магическим пользователем, повышая сложность атак, направленных с этой стороны, отклоняя их. #### Солнечный луч

(Воплощение, Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Жрец 5 | **Время сотворения:** 2 действия |
| **Сфера:** Солнце | **Длительность:** 1d4+1 раунд |
| **Стоимость:** 3/интенсивность | **Дистанция:** 30 футов/интенсивность |
| **Область:** Радиус 5 футов | **Сопротивление:** См. ниже |

При сотворении жрец может призвать яркий луч священного света, используя действие «Сотворение магии» в любой момент в течение длительности заклинания. Нежить, которой вредит именно солнечный свет, например вампиры, уничтожается при провале Уклонения. Грибковые существа, а также все формы подземных грибов получают те же эффекты, что и нежить, но не могут совершить бросок на сопротивление.

«Голос» усиливает интонацию и подачу получателя, делая его речь убедительной при отдаче устных команд. Все, кто слышит говорящего, вынуждены слушать. Его вокализация также проносится сквозь самый громкий фоновый шум (завывание ветра, рев водопада, лязг оружия на поле боя) на расстояние, в 30 раз превышающее ХАР получателя в футах.

#### Стена огня/Круг огня

(Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Жрец 3, Маг 3 | **Время сотворения:** 2 действия |
| **Сфера:** Бой, Стихийная (Огонь) | **Длительность:** См. ниже |
| **Стоимость:** 3, +1 за каждую дополнительную интенсивность | **Дистанция:** См. ниже |
| **Область:** См. ниже | **Сопротивление:** См. ниже |

Это заклинание позволяет заклинателю сотворить стену или круг пылающего пламени, по желанию в момент сотворения, горящего фиолетовым или красно-синим цветом. Длительность заклинания сохраняется, если поддерживается Концентрация, или 1 раунд за интенсивность после прекращения Концентрации. Детали зависят от типа:

**Стена огня:** Эта версия заклинания создает неподвижную стену огня длиной 20 футов за интенсивность. Независимо от итоговой интенсивности, высота стены составляет от 10 до 20 футов по желанию при сотворении. Стена огня имеет дистанцию 180 футов и не может быть сотворена горизонтально.

**Круг огня:** Эта версия заклинания создает круг огня вокруг заклинателя, который движется вместе с ним. Он имеет радиус 10 футов плюс еще 5 футов за каждую дополнительную интенсивность сверх первой. Независимо от итоговой интенсивности, высота круга составляет от 10 до 20 футов по желанию при сотворении. Круг огня должен окружать заклинателя и имеет дистанцию 0.

Сторона стены или круга, обращенная от заклинателя, излучает палящий жар, нанося 1d6 урона за раунд всем в пределах 10 футов и 1d4 урона на расстоянии до 20 футов. Этот урон обычно наносится в конце раунда перед переходом к следующему. Если жертва занимает обе зоны жара в одном раунде, применяется больший урон. Те, кто прыгает сквозь пламя, получают 2d6 единиц урона плюс дополнительный пункт урона за интенсивность сверх первой. Этот урон наносится в каждую локацию тела, и носимая броня не дает защиты, но магические Очки Брони или естественная броня существа уменьшают урон как обычно. Успешный бросок на сопротивление Уклонения позволяет жертве не получить урона в раунде, когда заклинание вступает в силу, поскольку жертва пытается нырнуть прочь от жара или мимо пламени. Существа, использующие огонь, получают половину этого урона, а существа, использующие холод, — двойной. Пламя имеет шанс воспламенить легковоспламеняющиеся материалы, равный брошенному урону x5%. Дополнительную информацию см. в разделе [Пожары](0007_Game_System.md?id=fire-based-attacks).

#### Паутина

(Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Маг 1 | **Время сотворения:** 1 действие |
| **Сфера:** Нет | **Длительность:** 20 минут/интенсивность |
| **Стоимость:** 3, +1 за каждую дополнительную интенсивность | **Дистанция:** 30 футов/интенсивность |
| **Область:** Радиус 20 футов | **Сопротивление:** Уклонение, плюс см. ниже |

Это заклинание заставляет длинные пряди липкой паутины вылетать из руки заклинателя, которые могут быть закреплены от пола до потолка или от стены до стены, чтобы заблокировать проход или затруднить движение. Их также можно распылить прямо на противников, чтобы запутать их.

Если у цели есть место, чтобы выбраться из паутины, успешный бросок Уклонения перемещает цель за пределы области действия; однако для этого требуется наличие очка действия. Проваленный бросок на сопротивление оставляет жертву обездвиженной, а 1d3 локации тела — запутанными. Как и в случае со спецэффектом [Запутывание](https://cfi-srd.mythras.net/#/0008_Combat?id=entangle), запутанная локация непригодна для использования. Запутанная рука не может использовать то, что держит; опутанная грудь, живот или нога делают все проверки физических навыков на одну степень сложнее (кроме проверок Силы, используемых для попытки вырваться); а запутавшаяся голова вызывает удушье, как подробно описано в разделе [Асфиксия](0007_Game_System.md?id=asphyxiation).

На следующем ходу жертва может потратить очко действия, чтобы попытаться вырваться из паутины. Магическая паутина невероятно прочная и липкая, обладает 6 Очками Брони и Очками Здоровья, равными 3x интенсивности заклинания. Попытка вырваться требует, чтобы жертва выиграла встречную проверку Силы против «Липкости» паутины (равной навыку Заклинания тайной магии заклинателя). Если попытка провалена, цель остается зафиксированной, не в силах вырваться только за счет силы. Попытка вырезаться подвергает используемый инструмент или оружие тому же процессу. Вопреки распространенному мнению, паутина не огнеопасна, но персонаж может медленно прожечь путь через паутину, используя пламя, чтобы съежились пряди (огненный урон игнорирует Очки Брони Паутины).

| :-: | :-: | :-- |

| 3 | 5 | 60 мин.; дистанция 90 футов; 6 брони, 9 ОЗ |
| 4 | 6 | 80 мин.; дистанция 120 футов; 6 брони, 12 ОЗ |

#### Желание

(Призыв, Воплощение)

| | |
| :-- | :-- |
| **Ранг:** Маг 5 | **Время сотворения:** См. ниже |
| **Сфера:** Нет | **Длительность:** См. ниже |
| **Стоимость:** 3, +1 или более ОПР | **Дистанция:** Без ограничений |

«Желание» может изменить реальность постоянным и значительным образом. Чтобы сотворить это заклинание, магический пользователь должен потратить 3 Магических Очка и 1 или более ОПР (очков развития) в зависимости от желаемых результатов. Каждое последующее сотворение «Желания» в течение одного месяца удваивает затраты ОПР, требуемые обычно. Время сотворения обычно требуется для того, чтобы устно изложить детали «Желания». После завершения заклинатель страдает от потери Усталости, равной затраченным ОПР, и стареет на 5% от своей нормальной продолжительности жизни (для людей это было бы пять лет). См. [Старение](0007_Game_System.md?id=aging) для средней продолжительности жизни получеловеческих рас.

Результаты «Желания» следует воспринимать буквально, и они открыты для интерпретации Мастером игры. Жадные желания обычно плохо заканчиваются. Существует 10% шанс, что «Желание», загаданное с жадными намерениями, обернется каким-либо негативным образом. Например, желание богатства может телепортировать его из сокровищницы местного лорда или короля. «Желание» не может отменить указы божественных сущностей, если только такое существо само не издало это «Желание».

| **Стоимость:** 1/интенсивность | **Дистанция:** 0 |
| **Область:** См. ниже | **Сопротивление:** Н/Д |

Это заклинание создает маленький невидимый «глаз», сквозь который магический пользователь может видеть в течение длительности заклинания. Этот глаз можно перемещать впереди группы или отправлять осматривать углы и комнаты, имея скорость движения 20 футов за раунд (240 футов в минуту), если проводится только сканирование на наличие «очевидных» угроз или предметов интереса. Глаз материален, не может проходить сквозь твердую материю и обладает нормальным зрением на расстоянии до 60 футов и темным зрением на расстоянии до 10 футов. Заклинатель должен поддерживать Концентрацию на глазу в течение всей длительности, иначе он останется инертным до тех пор, пока Концентрация не будет установлена снова. Любые атаки взглядом, которые обычно воздействовали бы на заклинателя, все равно воздействуют на него как обычно; однако глаз считается независимым от заклинателя в отношении слепоты, заклинаний тьмы и т. д. Для прохождения сквозь небольшие отверстия глаз не превышает 1 дюйма и имеет РАЗ 1.

#### Слово возврата

(Трансмутация)

| | |
| :-- | :-- |
| **Ранг:** Жрец 4 | **Время сотворения:** 1 действие |
| **Сфера:** Призыв | **Длительность:** См. ниже |
| **Стоимость:** 3, +1 за каждую дополнительную интенсивность | **Дистанция:** 0 |
| **Область:** Заклинатель | **Сопротивление:** Н/Д |

Когда это заклинание сотворено, жрец мгновенно телепортируется в заранее назначенное святилище и указанную точку прибытия радиусом не более 10 футов. Нет ограничений на фактическую дистанцию телепортации, включая перемещение между несколькими планами. В пределах одного плана нет шанса на неудачу, однако пересечение даже одного плана дает шанс Осечки 91-00%, два плана дают Осечку при броске 81-00% и так далее. Это заменяет нормальный шанс Осечки заклинателя. Осечка при пересечении планов означает, что жрец безвозвратно потерян. Осечки в пределах одного плана следуют обычным правилам.

Помимо себя и любого переносимого оборудования, жрец может перевезти еще 3 объекта за интенсивность, каждый размером не более РАЗ/9 «вещей». Дополнительный перевозимый материал может быть сокровищами, оборудованием или живыми существами. Однако для перевозки существ заклинание должно быть сотворено на достаточном уровне интенсивности, чтобы покрыть всё переносимое ими оборудование.
