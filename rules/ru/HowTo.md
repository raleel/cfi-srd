# Предварительные требования

1. Базовое понимание [языка разметки markdown](https://www.markdownguide.org/basic-syntax/).

2. Вам потребуется создать бесплатную учетную запись [GitHub](https://github.com/). Мы рекомендуем использовать название вашей НРИ, так как оно станет частью URL-адреса, который люди будут использовать для доступа к вашему SRD.

3. Вы можете выполнить весь процесс через браузер, не изучая git. Хотя освоение GitHub Desktop позволит вам тестировать любые изменения локально, прежде чем публиковать их для всеобщего обозрения.

> Если у вас зарегистрировано доменное имя, вы можете использовать его в этом процессе для создания SRD, как это сделал я: https://srd.7thextinctionrpg.com

# Процесс

## Создание репозитория на GitHub

1. Войдите в GitHub.

2. Перейдите к публичному шаблону https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Нажмите «Use this template» (Использовать этот шаблон).

![Step3](/_media/Step3.png)

4. Выберите «Create a new repository» (Создать новый репозиторий).

5. Введите название репозитория.

![Step5](/_media/Website-Step5.png)

6. Выберите «Private» (Приватный).

7. Нажмите «Create repository» (Создать репозиторий).

Копирование шаблона займет 5-30 секунд, после чего у вас появится собственная копия.

8. Убедитесь, что у вас есть файл «.nojekyll». Это пустой файл, который необходим при размещении веб-сайта на GitHub, иначе SRD будет отображаться некорректно. *(Указывает GitHub Pages не обрабатывать опубликованные файлы через Jekyll).*


## Добавление контента

### Файлы *.md

Файлы .md — это файлы разметки markdown. Markdown — это облегченный язык разметки, который можно использовать для добавления элементов форматирования к обычному тексту. В зависимости от объема вашего контента, вы можете разместить всю информацию об игре в одном файле *.md или, как это сделал я на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), создать отдельные файлы для каждой главы. Файл «Sample.md» содержит несколько примеров форматирования.

Язык Markdown очень прост в освоении, используйте ссылку, указанную в пункте 2 раздела «Предварительные требования» выше, для получения полного списка синтаксиса.

### _sidebar.md

Это ваше меню, панель навигации в левой части сайта. Как только вы добавите файл markdown в свой репозиторий, вам нужно добавить его сюда, чтобы его содержимое было включено в меню. Следуйте существующему форматированию.


## Включение GitHub Pages для превращения репозитория в веб-сайт

1. В своем репозитории нажмите «Settings» (Настройки).

![Website-Step1](/_media/Website-Step1.png)

2. Выберите «Pages» в меню слева.

![Website-Step2](/_media/Website-Step2.png)

3. Если вы не сделали репозиторий «публичным», у вас есть два варианта:
    a. Сделать репозиторий публичным, что позволит вам использовать GitHub Pages для бесплатного размещения вашего сайта SRD.
    b. Обновить свою учетную запись GitHub (на момент написания этого текста стоимость составляет $4 в месяц или $48 в год).

4. В разделе «Branch» выберите «main» и нажмите «Save» (Сохранить).

5. Подождите 10-20 секунд, затем обновите страницу.

6. Теперь вы увидите свой URL, например https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)


## Смена шрифтов

1. Отредактируйте файл /_assets/style.css

2. В разделе «body» вы найдете siteFont и headingFont.

3. Измените их на шрифты, которые вы хотите использовать.


## Использование плагинов Fontawesome и/или Material Icons для отображения бесплатных иконок в вашем SRD

### Fontawesome

Используйте Fontawesome для получения бесплатных и анимированных иконок. Подписчики могут использовать Pro-иконки.

1. Найдите иконку на [Fontawesome](https://fontawesome.com/icons)
2. Выберите иконку.
3. В открывшемся окне, на вкладке HTML скопируйте все, что находится между « ».

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Поместите скопированный текст между `:` без пробелов.

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Используйте Material Icons для получения большего количества бесплатных иконок.

1. Найдите иконки на [Material Icons](https://fonts.google.com/icons)
2. Скопируйте и вставьте веб-ссылку span напрямую в ваши файлы markdown.

```markup
<span class="material-icons">face</span>
```
