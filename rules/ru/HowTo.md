# Предварительные требования

1. Базовое понимание [языка разметки markdown](https://www.markdownguide.org/basic-syntax/).

2. Вам потребуется создать бесплатную учетную запись [github](https://github.com/), если у вас её еще нет. Рекомендую использовать название вашей ролевой игры, так как оно станет частью URL-адреса, который люди будут использовать для доступа к вашему SRD.

3. Вы можете выполнить весь процесс через браузер, не изучая git. Однако изучение Github Desktop позволит вам тестировать любые изменения локально, прежде чем публиковать их для всеобщего обозрения.

> Если у вас зарегистрировано доменное имя, вы можете использовать его в этом процессе для создания SRD, как это сделал я: https://srd.7thextinctionrpg.com

# Процесс

## Создание репозитория на Github

1. Войдите в Github.

2. Перейдите к публичному шаблону https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Нажмите "Use this template" (Использовать этот шаблон).

![Step3](/_media/Step3.png)

4. Выберите "Create a new repository" (Создать новый репозиторий).

5. Введите название репозитория.

![Step5](/_media/Step5.png)

6. Выберите "Private" (Частный).

7. Выберите "Create repository" (Создать репозиторий).

Копирование шаблона займет от 5 до 30 секунд, после чего у вас будет собственная копия.

8. Убедитесь, что у вас есть файл ".nojekyll" — это пустой файл, необходимый при размещении веб-сайта на Github, иначе SRD не будет отображаться должным образом. *(Сообщает GitHub Pages не обрабатывать опубликованные файлы через Jekyll).*


## Добавление вашего контента

### Файлы *.md

Файлы .md — это файлы markdown. Markdown — это облегченный язык разметки, который можно использовать для добавления элементов форматирования в текстовые документы. В зависимости от объема вашего контента, вы можете либо разместить всю информацию об игре в одном файле *.md, либо, как я сделал на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), создать отдельные файлы для каждой главы. Файл "sample.md" содержит несколько примеров форматирования.

Язык Markdown очень прост в изучении; используйте ссылку, предоставленную в пункте 2 раздела "Предварительные требования", для получения полного списка синтаксиса.

### _Sidebar.md

Это ваше меню, панель навигации в левой части сайта. Как только вы добавите файл markdown в свой репозиторий, вам нужно добавить его сюда, чтобы его содержимое было включено в меню. Следуйте существующему форматированию.


## Включение Github Pages для превращения репозитория в веб-сайт

1. В своем репозитории нажмите "Settings" (Настройки).

![Website-Step1](/_media/Website-Step1.png)

2. Выберите "Pages" в меню слева.

![Website-Step2](/_media/Website-Step2.png)

3. Если вы не сделали репозиторий публичным, у вас есть два варианта:
    a. Сделать репозиторий публичным, что позволит вам бесплатно использовать Github Pages для размещения вашего сайта SRD.
    b. Обновить свою учетную запись Github (на момент написания этого текста стоимость составляет 4 доллара в месяц или 48 долларов в год).

4. В разделе "Branch" (Ветка) выберите "main" и нажмите "Save" (Сохранить).

5. Подождите 10-20 секунд, а затем обновите страницу.

6. Теперь вы увидите свой URL, например: https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)


## Изменение шрифтов

1. Отредактируйте файл /_assets/style.css.

2. В разделе "body" вы найдете siteFont и headingFont.

3. Измените их на те шрифты, которые хотите использовать.


## Использование плагинов Fontawesome и/или Material Icons для отображения бесплатных значков в вашем SRD

### Fontawesome

Используйте Fontawesome для получения бесплатных и анимированных иконок. Подписчики могут использовать Pro-иконки.

1. Найдите значок на [Fontawesome](https://fontawesome.com/icons).
2. Выберите значок.
3. Во всплывающем окне на вкладке HTML скопируйте все, что находится между кавычками " ".

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Поместите скопированный текст между `:` без пробелов.

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Используйте Material Icons для получения дополнительных бесплатных значков.

1. Найдите значки на [Material Icons](https://fonts.google.com/icons).
2. Скопируйте и вставьте веб-ссылку span непосредственно в свои файлы markdown.

```markup
<span class="material-icons">face</span>
```
